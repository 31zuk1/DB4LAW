# 第八十一条 

## 
法人の代表者又は法人若しくは人の代理人、使用人その他の従業者がその法人又は人の業務に関し、[[laws/水先法/本文/第75条.md|第七十五条]]第一号、[[laws/水先法/本文/第76条.md|第七十六条]]第一号若しくは第二号、[[laws/水先法/本文/第77条.md|第七十七条]]第四号又は[[laws/水先法/本文/第78条.md|第七十八条]]第一号から第三号までの違反行為をしたときは、行為者を罰するほか、その法人又は人に対し、各本条の罰金刑を科する。
