# 第八十一条 （一般社団法人と理事との間の訴えにおける法人の代表）

## 
[[laws/一般社団法人及び一般財団法人に関する法律/本文/第77条.md|第七十七条]]第四項の規定にかかわらず、一般社団法人が理事（理事であった者を含む。以下この条において同じ。）に対し、又は理事が一般社団法人に対して訴えを提起する場合には、社員総会は、当該訴えについて一般社団法人を代表する者を定めることができる。
