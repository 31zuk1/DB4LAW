# 第三百二十三条 （新設合併による設立の登記の申請）

## 
新設合併による設立の登記の申請書には、次に掲げる書面を添付しなければならない。新設合併契約書定款[[laws/418AC0000000048/本文/第318条.md|第三百十八条]]第二項第二号から第四号まで又は[[laws/418AC0000000048/本文/第319条.md|第三百十九条]]第二項第四号、第五号及び第六号（イを除く。）に掲げる書面新設合併消滅法人の登記事項証明書。ただし、当該登記所の管轄区域内に新設合併消滅法人の主たる事務所がある場合を除く。[[laws/418AC0000000048/本文/第257条.md|第二百五十七条]]の規定による新設合併契約の承認があったことを証する書面新設合併消滅法人において[[laws/418AC0000000048/本文/第258条.md|第二百五十八条]]第二項の規定による公告及び催告（同条第三項の規定により公告を官報のほか[[laws/418AC0000000048/本文/第331条.md|第三百三十一条]]第一項の規定による定めに従い同項第二号又は第三号に掲げる方法によってした場合にあっては、これらの方法による公告）をしたこと並びに異議を述べた債権者があるときは、当該債権者に対し弁済し若しくは相当の担保を提供し若しくは当該債権者に弁済を受けさせることを目的として相当の財産を信託したこと又は当該新設合併をしても当該債権者を害するおそれがないことを証する書面

- 一 新設合併契約書
- 二 定款
- 三 [[laws/418AC0000000048/本文/第318条.md|第三百十八条]]第二項第二号から第四号まで又は[[laws/418AC0000000048/本文/第319条.md|第三百十九条]]第二項第四号、第五号及び第六号（イを除く。）に掲げる書面
- 四 新設合併消滅法人の登記事項証明書。ただし、当該登記所の管轄区域内に新設合併消滅法人の主たる事務所がある場合を除く。
- 五 [[laws/418AC0000000048/本文/第257条.md|第二百五十七条]]の規定による新設合併契約の承認があったことを証する書面
- 六 新設合併消滅法人において[[laws/418AC0000000048/本文/第258条.md|第二百五十八条]]第二項の規定による公告及び催告（同条第三項の規定により公告を官報のほか[[laws/418AC0000000048/本文/第331条.md|第三百三十一条]]第一項の規定による定めに従い同項第二号又は第三号に掲げる方法によってした場合にあっては、これらの方法による公告）をしたこと並びに異議を述べた債権者があるときは、当該債権者に対し弁済し若しくは相当の担保を提供し若しくは当該債権者に弁済を受けさせることを目的として相当の財産を信託したこと又は当該新設合併をしても当該債権者を害するおそれがないことを証する書面
