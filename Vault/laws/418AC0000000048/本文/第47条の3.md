# 第四十七条の三 （電子提供措置）

## 
電子提供措置をとる旨の定款の定めがある一般社団法人の理事は、[[laws/一般社団法人及び一般財団法人に関する法律/本文/第39条.md|第三十九条]]第二項各号に掲げる場合には、社員総会の日の三週間前の日又は同条第一項の通知を発した日のいずれか早い日（[[laws/一般社団法人及び一般財団法人に関する法律/本文/第47条の6.md|第四十七条の六]]第三号において「電子提供措置開始日」という。）から社員総会の日後三箇月を経過する日までの間（[[laws/一般社団法人及び一般財団法人に関する法律/本文/第47条の6.md|第四十七条の六]]において「電子提供措置期間」という。）、次に掲げる事項に係る情報について継続して電子提供措置をとらなければならない。[[laws/一般社団法人及び一般財団法人に関する法律/本文/第38条.md|第三十八条]]第一項各号に掲げる事項[[laws/一般社団法人及び一般財団法人に関する法律/本文/第41条.md|第四十一条]]第一項に規定する場合には、社員総会参考書類及び議決権行使書面に記載すべき事項[[laws/一般社団法人及び一般財団法人に関する法律/本文/第42条.md|第四十二条]]第一項に規定する場合には、社員総会参考書類に記載すべき事項[[laws/一般社団法人及び一般財団法人に関する法律/本文/第45条.md|第四十五条]]第一項の規定による請求があった場合には、同項の議案の要領一般社団法人が理事会設置一般社団法人である場合において、理事が定時社員総会を招集するときは、[[laws/一般社団法人及び一般財団法人に関する法律/本文/第125条.md|第百二十五条]]の計算書類及び事業報告並びに監査報告に記載され、又は記録された事項前各号に掲げる事項を修正したときは、その旨及び修正前の事項

- 一 [[laws/一般社団法人及び一般財団法人に関する法律/本文/第38条.md|第三十八条]]第一項各号に掲げる事項
- 二 [[laws/一般社団法人及び一般財団法人に関する法律/本文/第41条.md|第四十一条]]第一項に規定する場合には、社員総会参考書類及び議決権行使書面に記載すべき事項
- 三 [[laws/一般社団法人及び一般財団法人に関する法律/本文/第42条.md|第四十二条]]第一項に規定する場合には、社員総会参考書類に記載すべき事項
- 四 [[laws/一般社団法人及び一般財団法人に関する法律/本文/第45条.md|第四十五条]]第一項の規定による請求があった場合には、同項の議案の要領
- 五 一般社団法人が理事会設置一般社団法人である場合において、理事が定時社員総会を招集するときは、[[laws/一般社団法人及び一般財団法人に関する法律/本文/第125条.md|第百二十五条]]の計算書類及び事業報告並びに監査報告に記載され、又は記録された事項
- 六 前各号に掲げる事項を修正したときは、その旨及び修正前の事項
## ２
前項の規定にかかわらず、理事が[[laws/一般社団法人及び一般財団法人に関する法律/本文/第39条.md|第三十九条]]第一項の通知に際して社員に対し議決権行使書面を交付するときは、議決権行使書面に記載すべき事項に係る情報については、前項の規定により電子提供措置をとることを要しない。
