# 第二十八条の三 （介護補償の月額）

## 
介護補償の月額は、前条の表に掲げる介護を要する状態の区分に応じ、労働者災害補償保険法[[laws/人事院規則一六―〇（職員の災害補償）/本文/第19条の2.md|第十九条の二]]の規定により厚生労働大臣が定める額に準じて人事院が定める額とする。
