# 第三十八条 

## 
左の各号の一に該当する場合においては、その違反行為をした会社の取締役又はこれに準ずる者は、二年以下の懲役又は二十万円以下の罰金に処する。[[laws/ドイツ財産管理令/本文/第18条.md|第十八条]]第一項の規定に違反したとき。[[laws/ドイツ財産管理令/本文/第20条.md|第二十条]]第一項又は第二項の規定に違反して再評価積立金を資本に組み入れたとき。[[laws/ドイツ財産管理令/本文/第20条.md|第二十条]]第四項の規定に違反して再評価積立金を取りくずしたとき。[[laws/ドイツ財産管理令/本文/第20条の2.md|第二十条の二]]第一項又は第二項の規定に違反して資本準備金を資本に組み入れたとき。[[laws/ドイツ財産管理令/本文/第20条の2.md|第二十条の二]]第四項の規定に違反して資本準備金を取りくずしたとき。[[laws/ドイツ財産管理令/本文/第21条.md|第二十一条]]第一項の規定に違反したとき。[[laws/ドイツ財産管理令/本文/第22条.md|第二十二条]]第一項若しくは第四項又は[[laws/ドイツ財産管理令/本文/第22条の2.md|第二十二条の二]]第二項若しくは第三項の規定に基く主務大臣の命令に違反して株式の譲渡又は株券の引渡をしなかつたとき。[[laws/ドイツ財産管理令/本文/第22条.md|第二十二条]]第三項若しくは第四項又は[[laws/ドイツ財産管理令/本文/第22条の2.md|第二十二条の二]]第二項若しくは第三項の規定に基く主務大臣の命令に違反して株式の売却をせず、又は支払うべき金額の支払をしなかつたとき。[[laws/ドイツ財産管理令/本文/第22条.md|第二十二条]]第四項又は[[laws/ドイツ財産管理令/本文/第22条の2.md|第二十二条の二]]第三項の規定に基く主務大臣の命令に違反して新株を発行しなかつたとき。

- 一 [[laws/ドイツ財産管理令/本文/第18条.md|第十八条]]第一項の規定に違反したとき。
- 二 [[laws/ドイツ財産管理令/本文/第20条.md|第二十条]]第一項又は第二項の規定に違反して再評価積立金を資本に組み入れたとき。
- 三 [[laws/ドイツ財産管理令/本文/第20条.md|第二十条]]第四項の規定に違反して再評価積立金を取りくずしたとき。
- 四 [[laws/ドイツ財産管理令/本文/第20条の2.md|第二十条の二]]第一項又は第二項の規定に違反して資本準備金を資本に組み入れたとき。
- 五 [[laws/ドイツ財産管理令/本文/第20条の2.md|第二十条の二]]第四項の規定に違反して資本準備金を取りくずしたとき。
- 六 [[laws/ドイツ財産管理令/本文/第21条.md|第二十一条]]第一項の規定に違反したとき。
- 七 [[laws/ドイツ財産管理令/本文/第22条.md|第二十二条]]第一項若しくは第四項又は[[laws/ドイツ財産管理令/本文/第22条の2.md|第二十二条の二]]第二項若しくは第三項の規定に基く主務大臣の命令に違反して株式の譲渡又は株券の引渡をしなかつたとき。
- 八 [[laws/ドイツ財産管理令/本文/第22条.md|第二十二条]]第三項若しくは第四項又は[[laws/ドイツ財産管理令/本文/第22条の2.md|第二十二条の二]]第二項若しくは第三項の規定に基く主務大臣の命令に違反して株式の売却をせず、又は支払うべき金額の支払をしなかつたとき。
- 九 [[laws/ドイツ財産管理令/本文/第22条.md|第二十二条]]第四項又は[[laws/ドイツ財産管理令/本文/第22条の2.md|第二十二条の二]]第三項の規定に基く主務大臣の命令に違反して新株を発行しなかつたとき。
