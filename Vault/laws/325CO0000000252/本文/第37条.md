# 第三十七条 

## 
左の各号の一に該当する者は、二年以下の懲役又は二十万円以下の罰金に処する。[[laws/ドイツ財産管理令/本文/第6条.md|第六条]]第一項又は第三項の規定に違反した者[[laws/ドイツ財産管理令/本文/第10条.md|第十条]]第一項の規定による主務大臣の指示に違反する管理若しくは処分をした者[[laws/ドイツ財産管理令/本文/第16条の7.md|第十六条の七]]第一項又は第二項の規定に違反した者[[laws/ドイツ財産管理令/本文/第16条の15.md|第十六条の十五]]の規定に違反して決定清算計画書に従わないで清算を行つた者[[laws/ドイツ財産管理令/本文/第16条の20.md|第十六条の二十]]において準用する民法[[laws/民法/本文/第72条.md|第七十二条]]若しくは[[laws/民法/本文/第688条.md|第六百八十八条]]第二項若しくは商法第四百二十五条又は有限会社法[[laws/会社法/本文/第73条.md|第七十三条]]の規定に違反して引渡、分割又は分配をした者[[laws/会社法/本文/第27条.md|第二十七条]]第一項の規定に違反して報告をせず、又は虚偽の報告をした者

- 一 [[laws/ドイツ財産管理令/本文/第6条.md|第六条]]第一項又は第三項の規定に違反した者
- 二 [[laws/ドイツ財産管理令/本文/第10条.md|第十条]]第一項の規定による主務大臣の指示に違反する管理若しくは処分をした者
- 三 [[laws/ドイツ財産管理令/本文/第16条の7.md|第十六条の七]]第一項又は第二項の規定に違反した者
- 四 [[laws/ドイツ財産管理令/本文/第16条の15.md|第十六条の十五]]の規定に違反して決定清算計画書に従わないで清算を行つた者
- 五 [[laws/ドイツ財産管理令/本文/第16条の20.md|第十六条の二十]]において準用する民法[[laws/民法/本文/第72条.md|第七十二条]]若しくは[[laws/民法/本文/第688条.md|第六百八十八条]]第二項若しくは商法第四百二十五条又は有限会社法[[laws/会社法/本文/第73条.md|第七十三条]]の規定に違反して引渡、分割又は分配をした者
- 六 [[laws/ドイツ財産管理令/本文/第27条.md|第二十七条]]第一項の規定に違反して報告をせず、又は虚偽の報告をした者
