# 第十九条 （証明書の記載事項）

## 
法[[laws/ガス用品の技術上の基準等に関する省令/本文/第146条.md|第百四十六条]]第二項の証明書の記載事項は、次の各号に掲げるものとする。国内登録ガス用品検査機関又は外国登録ガス用品検査機関の名称申請者の氏名又は名称及び住所特定ガス用品の型式の区分特定ガス用品の製造番号及び製造期間（法[[laws/ガス用品の技術上の基準等に関する省令/本文/第146条.md|第百四十六条]]第一項第一号に係る検査に係るものに限る。）特定ガス用品を製造する工場又は事業場の名称及び所在地（輸入事業者にあつては、当該特定ガス用品の製造事業者の氏名又は名称及び住所）検査の方法法[[laws/ガス用品の技術上の基準等に関する省令/本文/第145条.md|第百四十五条]]第一項の経済産業省令で定める技術上の基準及び法[[laws/ガス用品の技術上の基準等に関する省令/本文/第146条.md|第百四十六条]]第二項の経済産業省令で定める基準（法[[laws/ガス用品の技術上の基準等に関する省令/本文/第146条.md|第百四十六条]]第一項第二号に係る検査に係るものに限る。）に適合している旨証明書の交付年月日

- 一 国内登録ガス用品検査機関又は外国登録ガス用品検査機関の名称
- 二 申請者の氏名又は名称及び住所
- 三 特定ガス用品の型式の区分
- 四 特定ガス用品の製造番号及び製造期間（法[[laws/ガス用品の技術上の基準等に関する省令/本文/第146条.md|第百四十六条]]第一項第一号に係る検査に係るものに限る。）
- 五 特定ガス用品を製造する工場又は事業場の名称及び所在地（輸入事業者にあつては、当該特定ガス用品の製造事業者の氏名又は名称及び住所）
- 六 検査の方法
- 七 法[[laws/ガス用品の技術上の基準等に関する省令/本文/第145条.md|第百四十五条]]第一項の経済産業省令で定める技術上の基準及び法[[laws/ガス用品の技術上の基準等に関する省令/本文/第146条.md|第百四十六条]]第二項の経済産業省令で定める基準（法[[laws/ガス用品の技術上の基準等に関する省令/本文/第146条.md|第百四十六条]]第一項第二号に係る検査に係るものに限る。）に適合している旨
- 八 証明書の交付年月日
