# 第百八十七条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、五十万円以下の罰金に処する。[[laws/放送法/本文/第97条.md|第九十七条]]第一項の規定に違反して[[laws/放送法/本文/第93条.md|第九十三条]]第二項第七号から第九号までに掲げる事項を変更したとき。[[laws/放送法/本文/第105条の2.md|第百五条の二]]第四項の規定に違反して地上基幹放送の業務に用いる電気通信設備等を変更したとき。[[laws/放送法/本文/第114条.md|第百十四条]]又は[[laws/放送法/本文/第123条.md|第百二十三条]]の規定による命令に違反したとき。[[laws/放送法/本文/第117条.md|第百十七条]]第一項の規定に違反して放送局設備供給契約の申込みを拒んだとき。[[laws/放送法/本文/第117条.md|第百十七条]]第二項の規定に違反して放送局設備供給契約の申込みを承諾したとき。[[laws/放送法/本文/第118条.md|第百十八条]]第一項の規定により届け出た提供条件によらないで、放送局設備供給役務を提供したとき。[[laws/放送法/本文/第120条.md|第百二十条]]の規定による命令に違反したとき。[[laws/放送法/本文/第130条.md|第百三十条]]第一項の規定に違反して[[laws/放送法/本文/第126条.md|第百二十六条]]第二項第二号から第四号までに掲げる事項を変更したとき。[[laws/放送法/本文/第138条.md|第百三十八条]]又は[[laws/放送法/本文/第141条.md|第百四十一条]]の規定による命令に違反したとき。[[laws/放送法/本文/第140条.md|第百四十条]]第二項の規定により届け出た契約約款によらないで、同条第一項の規定による再放送の役務を提供したとき。[[laws/放送法/本文/第147条.md|第百四十七条]]第一項の規定により届け出た有料基幹放送契約約款によらないで、有料基幹放送の役務を提供したとき。[[laws/放送法/本文/第148条.md|第百四十八条]]の規定に違反して有料放送の役務の提供を拒んだとき。[[laws/放送法/本文/第152条.md|第百五十二条]]第一項の規定に違反して有料放送管理業務を行つたとき。[[laws/放送法/本文/第156条.md|第百五十六条]]の規定による命令に違反したとき。

- 一 [[laws/放送法/本文/第97条.md|第九十七条]]第一項の規定に違反して[[laws/放送法/本文/第93条.md|第九十三条]]第二項第七号から第九号までに掲げる事項を変更したとき。
- 二 [[laws/放送法/本文/第105条の2.md|第百五条の二]]第四項の規定に違反して地上基幹放送の業務に用いる電気通信設備等を変更したとき。
- 三 [[laws/放送法/本文/第114条.md|第百十四条]]又は[[laws/放送法/本文/第123条.md|第百二十三条]]の規定による命令に違反したとき。
- 四 [[laws/放送法/本文/第117条.md|第百十七条]]第一項の規定に違反して放送局設備供給契約の申込みを拒んだとき。
- 五 [[laws/放送法/本文/第117条.md|第百十七条]]第二項の規定に違反して放送局設備供給契約の申込みを承諾したとき。
- 六 [[laws/放送法/本文/第118条.md|第百十八条]]第一項の規定により届け出た提供条件によらないで、放送局設備供給役務を提供したとき。
- 七 [[laws/放送法/本文/第120条.md|第百二十条]]の規定による命令に違反したとき。
- 八 [[laws/放送法/本文/第130条.md|第百三十条]]第一項の規定に違反して[[laws/放送法/本文/第126条.md|第百二十六条]]第二項第二号から第四号までに掲げる事項を変更したとき。
- 九 [[laws/放送法/本文/第138条.md|第百三十八条]]又は[[laws/放送法/本文/第141条.md|第百四十一条]]の規定による命令に違反したとき。
- 十 [[laws/放送法/本文/第140条.md|第百四十条]]第二項の規定により届け出た契約約款によらないで、同条第一項の規定による再放送の役務を提供したとき。
- 十一 [[laws/放送法/本文/第147条.md|第百四十七条]]第一項の規定により届け出た有料基幹放送契約約款によらないで、有料基幹放送の役務を提供したとき。
- 十二 [[laws/放送法/本文/第148条.md|第百四十八条]]の規定に違反して有料放送の役務の提供を拒んだとき。
- 十三 [[laws/放送法/本文/第152条.md|第百五十二条]]第一項の規定に違反して有料放送管理業務を行つたとき。
- 十四 [[laws/放送法/本文/第156条.md|第百五十六条]]の規定による命令に違反したとき。
