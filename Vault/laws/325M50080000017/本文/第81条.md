# 第八十一条 （遭難呼出し及び遭難通報の送信の反復）

## 
遭難呼出し及び遭難通報の送信は、[[laws/325M50080000017/本文/第82条.md|第八十二条]]の規定による応答があるまで、必要な間隔を置いて反復しなければならない。
