# 第三条 （農業信用保険業務、林業信用保証業務及び漁業信用保険業務に係る業務方法書の記載事項）

## 
信用基金が行う法[[laws/415M60000240004/独立行政法人農林漁業信用基金の業務運営等_law.md|第十二条]]第一項及び第三項に規定する業務並びに暫定措置法[[laws/415M60000240004/本文/第6条.md|第六条]]第一項に規定する業務に係る通則法[[laws/415M60000240004/独立行政法人農林漁業信用基金の業務運営等_law.md|第二十八条]]第二項の主務省令で定める事項は、次のとおりとする。法[[laws/415M60000240004/独立行政法人農林漁業信用基金の業務運営等_law.md|第十二条]]第一項第一号から第四号までに掲げる業務に関する事項法[[laws/415M60000240004/独立行政法人農林漁業信用基金の業務運営等_law.md|第十二条]]第一項第五号及び第六号に掲げる業務（暫定措置法[[laws/415M60000240004/本文/第6条.md|第六条]]第一項第一号から第三号までに掲げる業務を含む。）及び法[[laws/415M60000240004/独立行政法人農林漁業信用基金の業務運営等_law.md|第十二条]]第三項に規定する業務に関する事項法[[laws/415M60000240004/独立行政法人農林漁業信用基金の業務運営等_law.md|第十二条]]第一項第七号から第十号までに掲げる業務に関する事項業務委託の基準競争入札その他契約に関する基本的事項その他業務の執行に関して必要な事項

- 一 法[[laws/415M60000240004/独立行政法人農林漁業信用基金の業務運営等_law.md|第十二条]]第一項第一号から第四号までに掲げる業務に関する事項
- 二 法[[laws/415M60000240004/独立行政法人農林漁業信用基金の業務運営等_law.md|第十二条]]第一項第五号及び第六号に掲げる業務（暫定措置法[[laws/415M60000240004/本文/第6条.md|第六条]]第一項第一号から第三号までに掲げる業務を含む。）及び法[[laws/415M60000240004/独立行政法人農林漁業信用基金の業務運営等_law.md|第十二条]]第三項に規定する業務に関する事項
- 三 法[[laws/415M60000240004/独立行政法人農林漁業信用基金の業務運営等_law.md|第十二条]]第一項第七号から第十号までに掲げる業務に関する事項
- 四 業務委託の基準
- 五 競争入札その他契約に関する基本的事項
- 六 その他業務の執行に関して必要な事項
