# 第三条 （連結法人の減価償却資産の償却の方法に関する経過措置）

## 
第一条の規定による改正後の法人税法施行規則[[laws/340M50000040012/本文/第37条.md|第三十七条]]第一項（個別益金額又は個別損金額の計算における届出等の規定の適用）の規定は、改正令附則第十一条（連結法人の減価償却資産の償却の方法に関する経過措置）において準用する改正令第一条の規定による改正後の法人税法施行令第百五十五条の六第一項第二号（個別益金額又は個別損金額の計算における届出等の規定の適用）の規定により連結親法人が各連結法人について届出を行う場合における前条第一号に規定する名称、納税地及び法人番号並びに氏名について準用する。
