# 第二条 

## 
令[[laws/321M30000F40002/昭和二十一年大蔵省・厚生省・農林省・商工_law.md|第二十四条]]に規定する政府に準ずる機関（以下特定機関といふ。）は左に掲げるものをいふ。国民更生金庫産業設備営団帝国鉱業開発株式会社日本石炭株式会社日本倉庫統制株式会社損害保険中央会木船保険組合漁船保険組合旧戦時特殊損害保険法[[laws/321M30000F40002/本文/第2条.md|第二条]]の規定により指定を受けた保険会社その他財務大臣の指定するもの

- 一 国民更生金庫
- 二 産業設備営団
- 三 帝国鉱業開発株式会社
- 四 日本石炭株式会社
- 五 日本倉庫統制株式会社
- 六 損害保険中央会
- 七 木船保険組合
- 八 漁船保険組合
- 九 旧戦時特殊損害保険法[[laws/321M30000F40002/本文/第2条.md|第二条]]の規定により指定を受けた保険会社
- 十 その他財務大臣の指定するもの
