# 第百二十三条の三 （適用の範囲）

## 
法[[laws/放送法施行規則/本文/第111条.md|第百十一条]]第一項の基準のうち設備等維持業務のための業務管理体制に関する基準（同条第二項第一号に係るものに限る。）及び法[[laws/放送法施行規則/本文/第121条.md|第百二十一条]]第一項の基準のうち設備等維持業務のための業務管理体制に関する基準（同条第二項第一号に係るものに限る。）はこの款の定めるところによる。
