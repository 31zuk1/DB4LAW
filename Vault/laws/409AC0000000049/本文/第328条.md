# 第三百二十八条 

## 
次の各号のいずれかに該当する場合には、計画整備組合の役員又は清算人を二十万円以下の過料に処する。この法律の規定に基づいて計画整備組合が行うことができる事業以外の事業を行ったとき。[[laws/409AC0000000049/本文/第44条.md|第四十四条]]第一項の規定に基づく政令で定める登記を怠り、又は虚偽の登記をしたとき。[[laws/409AC0000000049/本文/第54条.md|第五十四条]]、[[laws/409AC0000000049/本文/第56条.md|第五十六条]]第二項後段、[[laws/409AC0000000049/本文/第67条.md|第六十七条]]又は[[laws/409AC0000000049/本文/第69条.md|第六十九条]]第一項の規定に違反したとき。[[laws/409AC0000000049/本文/第69条.md|第六十九条]]第三項又は第六項（これらの規定を[[laws/409AC0000000049/本文/第74条.md|第七十四条]]第四項において準用する場合を含む。）の規定に違反したとき。[[laws/409AC0000000049/本文/第72条.md|第七十二条]]第一項若しくは第二項若しくは[[laws/409AC0000000049/本文/第73条.md|第七十三条]]第一項の規定に違反して、書類を備えて置かず、その書類に記載すべき事項を記載せず、若しくは虚偽の記載をし、又は正当な理由がないのに[[laws/409AC0000000049/本文/第72条.md|第七十二条]]第四項若しくは[[laws/409AC0000000049/本文/第73条.md|第七十三条]]第二項の規定による閲覧を拒んだとき。[[laws/409AC0000000049/本文/第74条.md|第七十四条]]第五項又は[[laws/409AC0000000049/本文/第76条.md|第七十六条]]第六項の規定に違反したとき。[[laws/409AC0000000049/本文/第82条.md|第八十二条]]第一項、第二項、第三項若しくは第五項の規定に違反して出資一口の金額を減少し、又は[[laws/409AC0000000049/本文/第98条.md|第九十八条]]第四項において準用する[[laws/409AC0000000049/本文/第82条.md|第八十二条]]第一項、第二項、第三項若しくは第五項の規定に違反して計画整備組合の合併を行ったとき。[[laws/409AC0000000049/本文/第83条.md|第八十三条]]から[[laws/409AC0000000049/本文/第85条.md|第八十五条]]までの規定に違反したとき。[[laws/409AC0000000049/本文/第87条.md|第八十七条]]の規定に違反して、組合員の持分を取得し、又は質権の目的としてこれを受けたとき。[[laws/409AC0000000049/本文/第97条.md|第九十七条]]第五項の規定に違反したとき。[[laws/409AC0000000049/本文/第103条.md|第百三条]]第一項又は第三項の書類に記載すべき事項を記載せず、又は虚偽の記載をしたとき。[[laws/409AC0000000049/本文/第103条.md|第百三条]]第二項の規定に違反して、計画整備組合の財産を分配したとき。[[laws/409AC0000000049/本文/第103条の2.md|第百三条の二]]第一項又は[[laws/409AC0000000049/本文/第103条の4.md|第百三条の四]]第一項に規定する公告を怠り、又は不正の公告をしたとき。[[laws/409AC0000000049/本文/第103条の2.md|第百三条の二]]第一項の期間内に債権者に弁済したとき。[[laws/409AC0000000049/本文/第103条の4.md|第百三条の四]]第一項の規定に違反して、破産手続開始の申立てを怠ったとき。

- 一 この法律の規定に基づいて計画整備組合が行うことができる事業以外の事業を行ったとき。
- 二 [[laws/409AC0000000049/本文/第44条.md|第四十四条]]第一項の規定に基づく政令で定める登記を怠り、又は虚偽の登記をしたとき。
- 三 [[laws/409AC0000000049/本文/第54条.md|第五十四条]]、[[laws/409AC0000000049/本文/第56条.md|第五十六条]]第二項後段、[[laws/409AC0000000049/本文/第67条.md|第六十七条]]又は[[laws/409AC0000000049/本文/第69条.md|第六十九条]]第一項の規定に違反したとき。
- 四 [[laws/409AC0000000049/本文/第69条.md|第六十九条]]第三項又は第六項（これらの規定を[[laws/409AC0000000049/本文/第74条.md|第七十四条]]第四項において準用する場合を含む。）の規定に違反したとき。
- 五 [[laws/409AC0000000049/本文/第72条.md|第七十二条]]第一項若しくは第二項若しくは[[laws/409AC0000000049/本文/第73条.md|第七十三条]]第一項の規定に違反して、書類を備えて置かず、その書類に記載すべき事項を記載せず、若しくは虚偽の記載をし、又は正当な理由がないのに[[laws/409AC0000000049/本文/第72条.md|第七十二条]]第四項若しくは[[laws/409AC0000000049/本文/第73条.md|第七十三条]]第二項の規定による閲覧を拒んだとき。
- 六 [[laws/409AC0000000049/本文/第74条.md|第七十四条]]第五項又は[[laws/409AC0000000049/本文/第76条.md|第七十六条]]第六項の規定に違反したとき。
- 七 [[laws/409AC0000000049/本文/第82条.md|第八十二条]]第一項、第二項、第三項若しくは第五項の規定に違反して出資一口の金額を減少し、又は[[laws/409AC0000000049/本文/第98条.md|第九十八条]]第四項において準用する[[laws/409AC0000000049/本文/第82条.md|第八十二条]]第一項、第二項、第三項若しくは第五項の規定に違反して計画整備組合の合併を行ったとき。
- 八 [[laws/409AC0000000049/本文/第83条.md|第八十三条]]から[[laws/409AC0000000049/本文/第85条.md|第八十五条]]までの規定に違反したとき。
- 九 [[laws/409AC0000000049/本文/第87条.md|第八十七条]]の規定に違反して、組合員の持分を取得し、又は質権の目的としてこれを受けたとき。
- 十 [[laws/409AC0000000049/本文/第97条.md|第九十七条]]第五項の規定に違反したとき。
- 十一 [[laws/409AC0000000049/本文/第103条.md|第百三条]]第一項又は第三項の書類に記載すべき事項を記載せず、又は虚偽の記載をしたとき。
- 十二 [[laws/409AC0000000049/本文/第103条.md|第百三条]]第二項の規定に違反して、計画整備組合の財産を分配したとき。
- 十三 [[laws/409AC0000000049/本文/第103条の2.md|第百三条の二]]第一項又は[[laws/409AC0000000049/本文/第103条の4.md|第百三条の四]]第一項に規定する公告を怠り、又は不正の公告をしたとき。
- 十四 [[laws/409AC0000000049/本文/第103条の2.md|第百三条の二]]第一項の期間内に債権者に弁済したとき。
- 十五 [[laws/409AC0000000049/本文/第103条の4.md|第百三条の四]]第一項の規定に違反して、破産手続開始の申立てを怠ったとき。
