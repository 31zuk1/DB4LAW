# 第三百三十条 

## 
次の各号のいずれかに該当する場合においては、その行為をした事業組合の理事、監事又は清算人を二十万円以下の過料に処する。事業組合が防災街区整備事業以外の事業を営んだとき。[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第148条.md|第百四十八条]]第三項において準用する都市再開発法[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第27条.md|第二十七条]]第八項の規定に違反して、正当な理由がないのに帳簿及び書類の閲覧又は謄写を拒んだとき。[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第148条.md|第百四十八条]]第三項において準用する都市再開発法[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第27条.md|第二十七条]]第十項の規定に違反して、監事が理事又は事業組合の職員と兼ねたとき。[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第151条.md|第百五十一条]]若しくは[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第154条.md|第百五十四条]]第四項において準用する都市再開発法[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第31条.md|第三十一条]]第一項、第三項若しくは第六項の規定又は[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第153条.md|第百五十三条]]第三項において準用する同法第三十一条第三項若しくは第六項の規定に違反して、総会、総会の部会又は総代会を招集しなかったとき。[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第151条.md|第百五十一条]]において準用する都市再開発法[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第31条.md|第三十一条]]第九項の規定に違反して、書類を備えず、又はその書類に記載すべき事項を記載せず、若しくは不実の記載をしたとき。[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第151条.md|第百五十一条]]において準用する都市再開発法[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第31条.md|第三十一条]]第十項の規定に違反して、正当な理由がないのに書類の閲覧又は謄写を拒んだとき。[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第157条.md|第百五十七条]]第二項において準用する[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第129条.md|第百二十九条]]第三項の規定又は[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第163条.md|第百六十三条]]第三項の規定に違反したとき。[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第164条.md|第百六十四条]]において準用する都市再開発法[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第47条.md|第四十七条]]又は[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第49条.md|第四十九条]]に規定する書類に記載すべき事項を記載せず、又は不実の記載をしたとき。[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第164条.md|第百六十四条]]において準用する都市再開発法[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第48条.md|第四十八条]]の規定に違反して、事業組合の残余財産を処分したとき。[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第278条.md|第二百七十八条]]第一項の規定に違反して、簿書を備えず、又はその簿書に記載すべき事項を記載せず、若しくは不実の記載をしたとき。[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第278条.md|第二百七十八条]]第二項の規定に違反して、正当な理由がないのに簿書の閲覧又は謄写を拒んだとき。都道府県知事若しくは市町村長又は総会、総会の部会若しくは総代会に対し、不実の申立てをし、又は事実を隠したとき。この法律の規定による公告をせず、又は不実の公告をしたとき。

- 一 事業組合が防災街区整備事業以外の事業を営んだとき。
- 二 [[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第148条.md|第百四十八条]]第三項において準用する都市再開発法[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第27条.md|第二十七条]]第八項の規定に違反して、正当な理由がないのに帳簿及び書類の閲覧又は謄写を拒んだとき。
- 三 [[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第148条.md|第百四十八条]]第三項において準用する都市再開発法[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第27条.md|第二十七条]]第十項の規定に違反して、監事が理事又は事業組合の職員と兼ねたとき。
- 四 [[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第151条.md|第百五十一条]]若しくは[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第154条.md|第百五十四条]]第四項において準用する都市再開発法[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第31条.md|第三十一条]]第一項、第三項若しくは第六項の規定又は[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第153条.md|第百五十三条]]第三項において準用する同法第三十一条第三項若しくは第六項の規定に違反して、総会、総会の部会又は総代会を招集しなかったとき。
- 五 [[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第151条.md|第百五十一条]]において準用する都市再開発法[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第31条.md|第三十一条]]第九項の規定に違反して、書類を備えず、又はその書類に記載すべき事項を記載せず、若しくは不実の記載をしたとき。
- 六 [[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第151条.md|第百五十一条]]において準用する都市再開発法[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第31条.md|第三十一条]]第十項の規定に違反して、正当な理由がないのに書類の閲覧又は謄写を拒んだとき。
- 七 [[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第157条.md|第百五十七条]]第二項において準用する[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第129条.md|第百二十九条]]第三項の規定又は[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第163条.md|第百六十三条]]第三項の規定に違反したとき。
- 八 [[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第164条.md|第百六十四条]]において準用する都市再開発法[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第47条.md|第四十七条]]又は[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第49条.md|第四十九条]]に規定する書類に記載すべき事項を記載せず、又は不実の記載をしたとき。
- 九 [[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第164条.md|第百六十四条]]において準用する都市再開発法[[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第48条.md|第四十八条]]の規定に違反して、事業組合の残余財産を処分したとき。
- 十 [[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第278条.md|第二百七十八条]]第一項の規定に違反して、簿書を備えず、又はその簿書に記載すべき事項を記載せず、若しくは不実の記載をしたとき。
- 十一 [[laws/密集市街地における防災街区の整備の促進に関する法律/本文/第278条.md|第二百七十八条]]第二項の規定に違反して、正当な理由がないのに簿書の閲覧又は謄写を拒んだとき。
- 十二 都道府県知事若しくは市町村長又は総会、総会の部会若しくは総代会に対し、不実の申立てをし、又は事実を隠したとき。
- 十三 この法律の規定による公告をせず、又は不実の公告をしたとき。
