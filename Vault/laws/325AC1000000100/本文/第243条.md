# 第二百四十三条 （選挙運動に関する各種制限違反、その一）

## 
次の各号のいずれかに該当する者は、二年以下の拘禁刑又は五十万円以下の罰金に処する。[[laws/公職選挙法/本文/第139条.md|第百三十九条]]の規定に違反して飲食物を提供した者[[laws/公職選挙法/本文/第140条の2.md|第百四十条の二]]第一項の規定に違反して連呼行為をした者[[laws/公職選挙法/本文/第141条.md|第百四十一条]]第一項又は第四項の規定に違反して自動車、船舶又は拡声機を使用した者[[laws/公職選挙法/本文/第141条の2.md|第百四十一条の二]]第二項の規定に違反して乗車し又は乗船した者[[laws/公職選挙法/本文/第141条の3.md|第百四十一条の三]]の規定に違反して選挙運動をした者[[laws/公職選挙法/本文/第142条.md|第百四十二条]]の規定に違反して文書図画を頒布した者[[laws/公職選挙法/本文/第142条の4.md|第百四十二条の四]]第二項（同条第三項又は第四項において読み替えて適用される場合を含む。）又は第六項の規定に違反して選挙運動用電子メールの送信をした者[[laws/公職選挙法/本文/第142条の6.md|第百四十二条の六]]の規定に違反して広告を文書図画に掲載させた者[[laws/公職選挙法/本文/第143条.md|第百四十三条]]又は[[laws/公職選挙法/本文/第144条.md|第百四十四条]]の規定に違反して文書図画を掲示した者[[laws/公職選挙法/本文/第146条.md|第百四十六条]]の規定に違反して文書図画を頒布し又は掲示した者[[laws/公職選挙法/本文/第147条.md|第百四十七条]]の規定による撤去の処分（同条第一号、第二号又は第五号に該当する文書図画に係るものに限る。）に従わなかつた者[[laws/公職選挙法/本文/第148条.md|第百四十八条]]第二項又は[[laws/公職選挙法/本文/第149条.md|第百四十九条]]第五項の規定に違反して新聞紙又は雑誌を頒布し又は掲示した者[[laws/公職選挙法/本文/第149条.md|第百四十九条]]第一項又は第四項の規定に違反して新聞広告をした者削除[[laws/公職選挙法/本文/第164条の2.md|第百六十四条の二]]第一項の規定に違反して立札若しくは看板の類を掲示しなかつた者又は同条第二項若しくは第四項の規定に違反して文書図画を掲示した者[[laws/公職選挙法/本文/第164条の3.md|第百六十四条の三]]の規定に違反して演説会を開催した者[[laws/公職選挙法/本文/第164条の5.md|第百六十四条の五]]第一項の規定に違反して街頭演説をした者削除[[laws/公職選挙法/本文/第164条の7.md|第百六十四条の七]]第二項の規定に違反して選挙運動に従事した者[[laws/公職選挙法/本文/第165条の2.md|第百六十五条の二]]の規定に違反して演説会を開催し又は演説若しくは連呼行為をした者[[laws/公職選挙法/本文/第166条.md|第百六十六条]]の規定に違反して演説又は連呼行為をした者

- 一 [[laws/公職選挙法/本文/第139条.md|第百三十九条]]の規定に違反して飲食物を提供した者
- 一の二 [[laws/公職選挙法/本文/第140条の2.md|第百四十条の二]]第一項の規定に違反して連呼行為をした者
- 二 [[laws/公職選挙法/本文/第141条.md|第百四十一条]]第一項又は第四項の規定に違反して自動車、船舶又は拡声機を使用した者
- 二の二 [[laws/公職選挙法/本文/第141条の2.md|第百四十一条の二]]第二項の規定に違反して乗車し又は乗船した者
- 二の三 [[laws/公職選挙法/本文/第141条の3.md|第百四十一条の三]]の規定に違反して選挙運動をした者
- 三 [[laws/公職選挙法/本文/第142条.md|第百四十二条]]の規定に違反して文書図画を頒布した者
- 三の二 [[laws/公職選挙法/本文/第142条の4.md|第百四十二条の四]]第二項（同条第三項又は第四項において読み替えて適用される場合を含む。）又は第六項の規定に違反して選挙運動用電子メールの送信をした者
- 三の三 [[laws/公職選挙法/本文/第142条の6.md|第百四十二条の六]]の規定に違反して広告を文書図画に掲載させた者
- 四 [[laws/公職選挙法/本文/第143条.md|第百四十三条]]又は[[laws/公職選挙法/本文/第144条.md|第百四十四条]]の規定に違反して文書図画を掲示した者
- 五 [[laws/公職選挙法/本文/第146条.md|第百四十六条]]の規定に違反して文書図画を頒布し又は掲示した者
- 五の二 [[laws/公職選挙法/本文/第147条.md|第百四十七条]]の規定による撤去の処分（同条第一号、第二号又は第五号に該当する文書図画に係るものに限る。）に従わなかつた者
- 六 [[laws/公職選挙法/本文/第148条.md|第百四十八条]]第二項又は[[laws/公職選挙法/本文/第149条.md|第百四十九条]]第五項の規定に違反して新聞紙又は雑誌を頒布し又は掲示した者
- 七 [[laws/公職選挙法/本文/第149条.md|第百四十九条]]第一項又は第四項の規定に違反して新聞広告をした者
- 八 削除
- 八の二 [[laws/公職選挙法/本文/第164条の2.md|第百六十四条の二]]第一項の規定に違反して立札若しくは看板の類を掲示しなかつた者又は同条第二項若しくは第四項の規定に違反して文書図画を掲示した者
- 八の三 [[laws/公職選挙法/本文/第164条の3.md|第百六十四条の三]]の規定に違反して演説会を開催した者
- 八の四 [[laws/公職選挙法/本文/第164条の5.md|第百六十四条の五]]第一項の規定に違反して街頭演説をした者
- 八の五 削除
- 八の六 [[laws/公職選挙法/本文/第164条の7.md|第百六十四条の七]]第二項の規定に違反して選挙運動に従事した者
- 九 [[laws/公職選挙法/本文/第165条の2.md|第百六十五条の二]]の規定に違反して演説会を開催し又は演説若しくは連呼行為をした者
- 十 [[laws/公職選挙法/本文/第166条.md|第百六十六条]]の規定に違反して演説又は連呼行為をした者
## ２
候補者届出政党、衆議院名簿届出政党等若しくは参議院名簿届出政党等が[[laws/公職選挙法/本文/第142条の2.md|第百四十二条の二]]の規定に違反してパンフレット若しくは書籍を頒布したとき若しくは[[laws/公職選挙法/本文/第149条.md|第百四十九条]]第一項から第三項までの規定に違反して新聞広告をしたとき又は候補者届出政党若しくは衆議院名簿届出政党等が[[laws/公職選挙法/本文/第164条の2.md|第百六十四条の二]]第一項の規定に違反して立札若しくは看板の類を掲示しなかつたとき若しくは[[laws/公職選挙法/本文/第165条の2.md|第百六十五条の二]]の規定に違反して政党演説会若しくは政党等演説会を開催したときは、当該候補者届出政党、衆議院名簿届出政党等又は参議院名簿届出政党等の役職員又は構成員として当該違反行為をした者は、二年以下の拘禁刑又は五十万円以下の罰金に処する。
