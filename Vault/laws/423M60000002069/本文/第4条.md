# 第四条 （復興推進計画の認定の申請）

## 
法[[laws/東日本大震災復興特別区域法施行規則/本文/第4条.md|第四条]]第一項の規定により認定の申請をしようとする特定地方公共団体（同項に規定する特定地方公共団体をいう。次条及び[[laws/東日本大震災復興特別区域法施行規則/本文/第7条.md|第七条]]第二項において同じ。）は、別記様式第一の一による申請書その他の法[[laws/東日本大震災復興特別区域法施行規則/本文/第4条.md|第四条]]第二項各号に掲げる事項を明らかにする書類に、次に掲げる図書を添えて、これらを内閣総理大臣に提出するものとする。復興推進計画（法[[laws/東日本大震災復興特別区域法施行規則/本文/第4条.md|第四条]]第一項に規定する復興推進計画をいう。以下同じ。）の区域に含まれる行政区画を表示した図面又は縮尺、方位、目標となる地物及び復興推進計画の区域を表示した付近見取図法[[laws/東日本大震災復興特別区域法施行規則/本文/第4条.md|第四条]]第二項第四号イからハまでに掲げる区域を定める場合にあっては、当該区域に含まれる行政区画を表示した図面又は縮尺、方位、目標となる地物及び当該区域を表示した付近見取図法第三章第二節の規定による特別の措置の適用を受ける主体の特定の状況を明らかにすることができる書類法[[laws/東日本大震災復興特別区域法施行規則/本文/第4条.md|第四条]]第三項の規定により聴いた関係地方公共団体及び同条第二項第五号に規定する実施主体の意見の概要法[[laws/東日本大震災復興特別区域法施行規則/本文/第4条.md|第四条]]第四項の提案を踏まえた復興推進計画についての同条第一項の規定による認定の申請をする場合にあっては、当該提案の概要法[[laws/東日本大震災復興特別区域法施行規則/本文/第4条.md|第四条]]第六項の規定による協議をした場合にあっては、当該協議の概要法[[laws/東日本大震災復興特別区域法施行規則/本文/第11条.md|第十一条]]第一項の規定による提案と併せて法[[laws/東日本大震災復興特別区域法施行規則/本文/第4条.md|第四条]]第一項の規定による認定の申請をする場合にあっては、当該提案に係る書類の写し前各号に掲げるもののほか、内閣総理大臣が必要と認める事項を記載した書類

- 一 復興推進計画（法[[laws/東日本大震災復興特別区域法施行規則/本文/第4条.md|第四条]]第一項に規定する復興推進計画をいう。以下同じ。）の区域に含まれる行政区画を表示した図面又は縮尺、方位、目標となる地物及び復興推進計画の区域を表示した付近見取図
- 二 法[[laws/東日本大震災復興特別区域法施行規則/本文/第4条.md|第四条]]第二項第四号イからハまでに掲げる区域を定める場合にあっては、当該区域に含まれる行政区画を表示した図面又は縮尺、方位、目標となる地物及び当該区域を表示した付近見取図
- 三 法第三章第二節の規定による特別の措置の適用を受ける主体の特定の状況を明らかにすることができる書類
- 四 法[[laws/東日本大震災復興特別区域法施行規則/本文/第4条.md|第四条]]第三項の規定により聴いた関係地方公共団体及び同条第二項第五号に規定する実施主体の意見の概要
- 五 法[[laws/東日本大震災復興特別区域法施行規則/本文/第4条.md|第四条]]第四項の提案を踏まえた復興推進計画についての同条第一項の規定による認定の申請をする場合にあっては、当該提案の概要
- 六 法[[laws/東日本大震災復興特別区域法施行規則/本文/第4条.md|第四条]]第六項の規定による協議をした場合にあっては、当該協議の概要
- 七 法[[laws/東日本大震災復興特別区域法施行規則/本文/第11条.md|第十一条]]第一項の規定による提案と併せて法[[laws/東日本大震災復興特別区域法施行規則/本文/第4条.md|第四条]]第一項の規定による認定の申請をする場合にあっては、当該提案に係る書類の写し
- 八 前各号に掲げるもののほか、内閣総理大臣が必要と認める事項を記載した書類
