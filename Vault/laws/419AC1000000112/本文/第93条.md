# 第九十三条 

## 
次の各号のいずれかに該当する場合には、その違反行為をした者は、三十万円以下の罰金に処する。不正の手段によって[[laws/419AC1000000112/本文/第8条.md|第八条]]の登録、計画の認定又は[[laws/419AC1000000112/本文/第72条.md|第七十二条]]第一項の認定を受けたとき。[[laws/419AC1000000112/本文/第12条.md|第十二条]]第一項、[[laws/419AC1000000112/本文/第14条.md|第十四条]]第一項、[[laws/419AC1000000112/本文/第44条.md|第四十四条]]第三項、[[laws/419AC1000000112/本文/第74条.md|第七十四条]]第一項又は[[laws/419AC1000000112/本文/第75条.md|第七十五条]]第一項の規定による届出をせず、又は虚偽の届出をしたとき。[[laws/419AC1000000112/本文/第31条.md|第三十一条]]第一項、[[laws/419AC1000000112/本文/第48条.md|第四十八条]]、[[laws/419AC1000000112/本文/第67条.md|第六十七条]]第一項又は[[laws/419AC1000000112/本文/第76条.md|第七十六条]]第一項の規定に違反して、帳簿を備え付けず、帳簿に記載せず、若しくは帳簿に虚偽の記載をし、又は帳簿を保存しなかったとき。[[laws/419AC1000000112/本文/第31条.md|第三十一条]]第二項、[[laws/419AC1000000112/本文/第67条.md|第六十七条]]第二項又は[[laws/419AC1000000112/本文/第76条.md|第七十六条]]第二項の規定に違反したとき。[[laws/419AC1000000112/本文/第33条.md|第三十三条]]第一項、[[laws/419AC1000000112/本文/第54条.md|第五十四条]]第一項、[[laws/419AC1000000112/本文/第69条.md|第六十九条]]第一項若しくは[[laws/419AC1000000112/本文/第78条.md|第七十八条]]第一項の規定による報告をせず、若しくは虚偽の報告をし、又はこれらの規定による検査を拒み、妨げ、若しくは忌避し、若しくはこれらの規定による質問に対して答弁せず、若しくは虚偽の答弁をしたとき。[[laws/419AC1000000112/本文/第34条.md|第三十四条]]第一項の規定による許可を受けないで登録事務の全部を廃止したとき。

- 一 不正の手段によって[[laws/419AC1000000112/本文/第8条.md|第八条]]の登録、計画の認定又は[[laws/419AC1000000112/本文/第72条.md|第七十二条]]第一項の認定を受けたとき。
- 二 [[laws/419AC1000000112/本文/第12条.md|第十二条]]第一項、[[laws/419AC1000000112/本文/第14条.md|第十四条]]第一項、[[laws/419AC1000000112/本文/第44条.md|第四十四条]]第三項、[[laws/419AC1000000112/本文/第74条.md|第七十四条]]第一項又は[[laws/419AC1000000112/本文/第75条.md|第七十五条]]第一項の規定による届出をせず、又は虚偽の届出をしたとき。
- 三 [[laws/419AC1000000112/本文/第31条.md|第三十一条]]第一項、[[laws/419AC1000000112/本文/第48条.md|第四十八条]]、[[laws/419AC1000000112/本文/第67条.md|第六十七条]]第一項又は[[laws/419AC1000000112/本文/第76条.md|第七十六条]]第一項の規定に違反して、帳簿を備え付けず、帳簿に記載せず、若しくは帳簿に虚偽の記載をし、又は帳簿を保存しなかったとき。
- 四 [[laws/419AC1000000112/本文/第31条.md|第三十一条]]第二項、[[laws/419AC1000000112/本文/第67条.md|第六十七条]]第二項又は[[laws/419AC1000000112/本文/第76条.md|第七十六条]]第二項の規定に違反したとき。
- 五 [[laws/419AC1000000112/本文/第33条.md|第三十三条]]第一項、[[laws/419AC1000000112/本文/第54条.md|第五十四条]]第一項、[[laws/419AC1000000112/本文/第69条.md|第六十九条]]第一項若しくは[[laws/419AC1000000112/本文/第78条.md|第七十八条]]第一項の規定による報告をせず、若しくは虚偽の報告をし、又はこれらの規定による検査を拒み、妨げ、若しくは忌避し、若しくはこれらの規定による質問に対して答弁せず、若しくは虚偽の答弁をしたとき。
- 六 [[laws/419AC1000000112/本文/第34条.md|第三十四条]]第一項の規定による許可を受けないで登録事務の全部を廃止したとき。
