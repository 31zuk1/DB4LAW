# 第五十六条 （中央制御場所）

## 
国際航海に従事する旅客船であつて旅客定員が三六人を超えるもの及び係留船には、中央制御場所（次の各号に掲げる設備を集中配置した制御場所であつて船員が継続的に配置されるものをいう。）を設けなければならない。ただし、係留船については、管海官庁が当該船舶の用途、大きさ等を考慮して適当と認める程度に応じて当該設備の一部の配置を省略することができる。主垂直区域隔壁、主水平区域若しくは調理室の境界となる隔壁又は階段囲壁に設けるＡ級防火戸の制御装置（車両区域の出入口に設けるものであつて自動閉鎖の動力開閉装置を有するものの制御装置を除く。）及び当該防火戸の開閉状態を示す表示盤船舶設備規程[[laws/355M50000800011/船舶防火構造規則_law.md|第二百八十六条]]に規定する通風装置の停止装置及び送風機の作動状態を示す表示盤船舶消防設備規則[[laws/355M50000800011/船舶防火構造規則_law.md|第五十条]]第一項の規定により備え付ける自動スプリンクラ装置の表示盤船舶消防設備規則[[laws/355M50000800011/船舶防火構造規則_law.md|第五十条]]第一項の規定により備え付ける火災探知装置の制御盤及び表示盤船舶消防設備規則[[laws/355M50000800011/本文/第52条.md|第五十二条]]第一項及び第三項の規定により備え付ける手動火災警報装置の制御盤及び表示盤船舶区画規程[[laws/355M50000800011/本文/第53条.md|第五十三条]]の規定により設ける水密すべり戸の操作装置及び開閉指示器

- 一 主垂直区域隔壁、主水平区域若しくは調理室の境界となる隔壁又は階段囲壁に設けるＡ級防火戸の制御装置（車両区域の出入口に設けるものであつて自動閉鎖の動力開閉装置を有するものの制御装置を除く。）及び当該防火戸の開閉状態を示す表示盤
- 二 船舶設備規程[[laws/355M50000800011/船舶防火構造規則_law.md|第二百八十六条]]に規定する通風装置の停止装置及び送風機の作動状態を示す表示盤
- 三 船舶消防設備規則[[laws/355M50000800011/船舶防火構造規則_law.md|第五十条]]第一項の規定により備え付ける自動スプリンクラ装置の表示盤
- 四 船舶消防設備規則[[laws/355M50000800011/船舶防火構造規則_law.md|第五十条]]第一項の規定により備え付ける火災探知装置の制御盤及び表示盤
- 五 船舶消防設備規則[[laws/355M50000800011/本文/第52条.md|第五十二条]]第一項及び第三項の規定により備え付ける手動火災警報装置の制御盤及び表示盤
- 六 船舶区画規程[[laws/355M50000800011/本文/第53条.md|第五十三条]]の規定により設ける水密すべり戸の操作装置及び開閉指示器
