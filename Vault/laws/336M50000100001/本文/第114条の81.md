# 第百十四条の八十一 （準用）

## 
法[[laws/335AC0000000145/本文/第23条の2.md|第二十三条の二]]の十七第一項又は同条第五項において準用する法[[laws/335AC0000000145/本文/第23条の2.md|第二十三条の二]]の五第十五項の承認については、[[laws/336M50000100001/本文/第114条の18.md|第百十四条の十八]]、[[laws/336M50000100001/本文/第114条の19.md|第百十四条の十九]]の二から[[laws/336M50000100001/本文/第114条の26.md|第百十四条の二十六]]まで、[[laws/336M50000100001/本文/第114条の28.md|第百十四条の二十八]]及び[[laws/336M50000100001/本文/第114条の32.md|第百十四条の三十二]]から[[laws/336M50000100001/本文/第114条の46.md|第百十四条の四十六]]までの規定を準用する。この場合において、第百十四の二十二の四第一項中「様式第二十二の二」とあるのは「様式第五十四の四」と、[[laws/336M50000100001/本文/第114条の24.md|第百十四条の二十四]]第一項中「様式第六十三の九」とあるのは「様式第六十三の二十三」と、[[laws/336M50000100001/本文/第114条の26.md|第百十四条の二十六]]第一項中「様式第六十三の十」とあるのは「様式第六十三の二十四」と、[[laws/336M50000100001/本文/第114条の28.md|第百十四条の二十八]]第一項中「様式第六十三の十一」とあるのは「様式第六十三の二十五」と、[[laws/336M50000100001/本文/第114条の33.md|第百十四条の三十三]]第二項中「様式第六十三の十三」とあるのは「様式第六十三の二十六」と、[[laws/336M50000100001/本文/第114条の34.md|第百十四条の三十四]]第一項中「様式第六十三の十四」とあるのは「様式第六十三の二十七」と、[[laws/336M50000100001/本文/第114条の37.md|第百十四条の三十七]]第三項及び第五項中「様式第六十三の十五」とあるのは「様式第六十三の二十八」と、同条第八項中「様式第二十七の二」とあるのは「様式第五十八の二」と、[[laws/336M50000100001/本文/第114条の38.md|第百十四条の三十八]]第二項中「様式第六十三の十二」とあるのは「様式第六十三の二十九」と、[[laws/336M50000100001/本文/第114条の39.md|第百十四条の三十九]]中「様式第六十三の十七」とあるのは「様式第六十三の三十」と、[[laws/336M50000100001/本文/第114条の44.md|第百十四条の四十四]]第二項中「様式第六十三の十八」とあるのは「様式第六十三の三十一」と、[[laws/336M50000100001/本文/第114条の45.md|第百十四条の四十五]]の二第一項中「様式第六十三の十九の二」とあるのは「様式第六十三の三十一の二」と、同条第二項中「様式第六十三の十九の三」とあるのは「様式第六十三の三十一の三」と、[[laws/336M50000100001/本文/第114条の45.md|第百十四条の四十五]]の七中「様式第六十三の十九の四」とあるのは「様式第六十三の三十一の四」と、[[laws/336M50000100001/本文/第114条の45.md|第百十四条の四十五]]の九第一項中「様式第六十三の十九の五」とあるのは「様式第六十三の三十一の五」と、同条第三項中「様式第六十三の十九の六」とあるのは「様式第六十三の三十一の六」と、[[laws/336M50000100001/本文/第114条の45.md|第百十四条の四十五]]の十中「様式第六十三の十九の七」とあるのは「様式第六十三の三十一の七」と、[[laws/336M50000100001/本文/第114条の45.md|第百十四条の四十五]]の十四第一項中「様式第六十三の十九の八」とあるのは「様式第六十三の三十一の八」と、[[laws/336M50000100001/本文/第114条の45.md|第百十四条の四十五]]の十五第二項中「様式第六十三の十九の九」とあるのは「様式第六十三の三十一の九」と、[[laws/336M50000100001/本文/第114条の45.md|第百十四条の四十五]]の十六第一項中「様式第六十三の十九の十」とあるのは「様式第六十三の三十一の十」と、同条第二項中「様式第六十三の十九の十一」とあるのは「様式第六十三の三十一の十一」と、[[laws/336M50000100001/本文/第114条の46.md|第百十四条の四十六]]第二項中「様式第六十三の二十」とあるのは「様式第六十三の三十二」と読み替えるものとする。
