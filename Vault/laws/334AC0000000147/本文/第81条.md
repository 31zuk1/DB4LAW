# 第八十一条 （質権者等への差押解除の通知）

## 
税務署長は、差押を解除した場合において、[[laws/国税徴収法/本文/第55条.md|第五十五条]]各号（質権者等に対する差押の通知）に掲げる者のうち知れている者及び交付要求をしている者があるときは、これらの者にその旨その他必要な事項を通知しなければならない。
