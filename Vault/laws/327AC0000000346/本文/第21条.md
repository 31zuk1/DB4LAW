# 第二十一条 （業務方法書に記載すべき事項）

## 
協会の業務方法書には、次の事項を記載しなければならない。被保証人の資格及び保証に係る借入資金（手形の割引に係る保証にあつては当該手形の割引により融通を受ける資金をいい、[[laws/327AC0000000346/本文/第4条.md|第四条]]第一項第二号に掲げる保証にあつては株式会社日本政策金融公庫又は沖縄振興開発金融公庫の委託を受けて漁業協同組合又は信用漁業協同組合連合会が貸し付ける資金をいう。第五号において同じ。）の種類保証の範囲一被保証人についての保証の金額の最高限度保証の金額の合計額の最高限度保証に係る借入資金の借入れの期間（手形の割引に係る保証にあつては、手形の割引を受けた時から当該手形の満期までの期間）の最高限度保証料に関する事項その他被保証人の守るべき条件に関する事項保証の申込み及び承諾並びに保証契約の締結に関する事項保証債務の弁済の事由、弁済の時期その他保証債務の弁済に関する事項保証契約の変更に関する事項第三章第一節の規定による保証保険の付保に関する事項求償権の消却に関する事項違約金に関する事項委託業務に関する準則保証債務の弁済に充てるための基金及び[[laws/327AC0000000346/本文/第43条の2.md|第四十三条の二]]第一項の資金の管理方法[[laws/327AC0000000346/本文/第4条.md|第四条]]第一項第三号に掲げる業務に関し主務省令で定める事項

- 一 被保証人の資格及び保証に係る借入資金（手形の割引に係る保証にあつては当該手形の割引により融通を受ける資金をいい、[[laws/327AC0000000346/本文/第4条.md|第四条]]第一項第二号に掲げる保証にあつては株式会社日本政策金融公庫又は沖縄振興開発金融公庫の委託を受けて漁業協同組合又は信用漁業協同組合連合会が貸し付ける資金をいう。第五号において同じ。）の種類
- 二 保証の範囲
- 三 一被保証人についての保証の金額の最高限度
- 四 保証の金額の合計額の最高限度
- 五 保証に係る借入資金の借入れの期間（手形の割引に係る保証にあつては、手形の割引を受けた時から当該手形の満期までの期間）の最高限度
- 六 保証料に関する事項その他被保証人の守るべき条件に関する事項
- 七 保証の申込み及び承諾並びに保証契約の締結に関する事項
- 八 保証債務の弁済の事由、弁済の時期その他保証債務の弁済に関する事項
- 九 保証契約の変更に関する事項
- 十 第三章第一節の規定による保証保険の付保に関する事項
- 十一 求償権の消却に関する事項
- 十二 違約金に関する事項
- 十三 委託業務に関する準則
- 十四 保証債務の弁済に充てるための基金及び[[laws/327AC0000000346/本文/第43条の2.md|第四十三条の二]]第一項の資金の管理方法
- 十五 [[laws/327AC0000000346/本文/第4条.md|第四条]]第一項第三号に掲げる業務に関し主務省令で定める事項
