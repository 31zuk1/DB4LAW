# 第八十九条 

## 
次の場合には、協会の役員又は清算人を二十万円以下の過料に処する。この法律の規定により主務大臣の認可を受けなければならない場合にその認可を受けなかつたとき。[[laws/327AC0000000346/本文/第8条.md|第八条]]第一項の規定に基づく政令の規定による登記をすることを怠つたとき。この法律の規定に基づき協会が行うことができる事業以外の事業をしたとき。[[laws/327AC0000000346/本文/第14条.md|第十四条]]の規定に違反したとき。[[laws/327AC0000000346/本文/第26条.md|第二十六条]]の規定に違反したとき。[[laws/327AC0000000346/本文/第28条.md|第二十八条]]第一項、[[laws/327AC0000000346/本文/第29条.md|第二十九条]]第一項又は[[laws/327AC0000000346/本文/第30条.md|第三十条]]の規定に違反したとき。[[laws/327AC0000000346/本文/第32条.md|第三十二条]]又は[[laws/327AC0000000346/本文/第33条.md|第三十三条]]の規定に違反して書類を備えて置かず、その書類に記載すべき事項を記載せず、若しくは虚偽の記載をし、又は正当な理由がないのにその書類の閲覧を拒んだとき。[[laws/327AC0000000346/本文/第34条.md|第三十四条]]第四項若しくは第五項又は[[laws/327AC0000000346/本文/第37条.md|第三十七条]]第四項の規定に違反したとき。[[laws/327AC0000000346/本文/第43条.md|第四十三条]]、[[laws/327AC0000000346/本文/第43条の2.md|第四十三条の二]]第一項又は[[laws/327AC0000000346/本文/第43条の3.md|第四十三条の三]]第一項の規定に違反して資金を管理したとき。[[laws/327AC0000000346/本文/第44条.md|第四十四条]]第一項若しくは第三項又は[[laws/327AC0000000346/本文/第44条の2.md|第四十四条の二]]の規定に違反する経理をしたとき。[[laws/327AC0000000346/本文/第55条.md|第五十五条]]又は[[laws/327AC0000000346/本文/第56条.md|第五十六条]]第二項（これらの規定を[[laws/327AC0000000346/本文/第59条の2.md|第五十九条の二]]第七項において準用する場合を含む。）の規定に違反して合併又は事業の全部の譲渡を行つたとき。[[laws/327AC0000000346/本文/第55条.md|第五十五条]]第五項（[[laws/327AC0000000346/本文/第59条の2.md|第五十九条の二]]第七項において準用する場合を含む。）において準用する会社法[[laws/417AC0000000086/本文/第941条.md|第九百四十一条]]の規定に違反して同条の調査を求めなかつたとき。[[laws/327AC0000000346/本文/第61条.md|第六十一条]]又は[[laws/417AC0000000086/本文/第63条.md|第六十三条]]の書類又は電磁的記録に記載し、若しくは記録すべき事項を記載せず、若しくは記録せず、又は虚偽の記載若しくは記録をしたとき。[[laws/327AC0000000346/本文/第61条の2.md|第六十一条の二]]第一項又は[[laws/417AC0000000086/会社法_law.md|第六十一条の四]]第一項の規定による公告を怠り、又は虚偽の公告をしたとき。[[laws/327AC0000000346/本文/第61条の2.md|第六十一条の二]]第一項の期間内に債権者に弁済をしたとき。[[laws/327AC0000000346/本文/第61条の4.md|第六十一条の四]]第一項の規定に違反して破産手続開始の申立てを怠つたとき。[[laws/327AC0000000346/本文/第62条.md|第六十二条]]第一項又は第二項の規定に違反したとき。[[laws/327AC0000000346/本文/第66条の2.md|第六十六条の二]]第一項の規定による命令（改善計画の提出を求めることを含む。）に違反したとき。

- 一 この法律の規定により主務大臣の認可を受けなければならない場合にその認可を受けなかつたとき。
- 二 [[laws/327AC0000000346/本文/第8条.md|第八条]]第一項の規定に基づく政令の規定による登記をすることを怠つたとき。
- 三 この法律の規定に基づき協会が行うことができる事業以外の事業をしたとき。
- 四 [[laws/327AC0000000346/本文/第14条.md|第十四条]]の規定に違反したとき。
- 五 [[laws/327AC0000000346/本文/第26条.md|第二十六条]]の規定に違反したとき。
- 六 [[laws/327AC0000000346/本文/第28条.md|第二十八条]]第一項、[[laws/327AC0000000346/本文/第29条.md|第二十九条]]第一項又は[[laws/327AC0000000346/本文/第30条.md|第三十条]]の規定に違反したとき。
- 七 [[laws/327AC0000000346/本文/第32条.md|第三十二条]]又は[[laws/327AC0000000346/本文/第33条.md|第三十三条]]の規定に違反して書類を備えて置かず、その書類に記載すべき事項を記載せず、若しくは虚偽の記載をし、又は正当な理由がないのにその書類の閲覧を拒んだとき。
- 八 [[laws/327AC0000000346/本文/第34条.md|第三十四条]]第四項若しくは第五項又は[[laws/327AC0000000346/本文/第37条.md|第三十七条]]第四項の規定に違反したとき。
- 八の二 [[laws/327AC0000000346/本文/第43条.md|第四十三条]]、[[laws/327AC0000000346/本文/第43条の2.md|第四十三条の二]]第一項又は[[laws/327AC0000000346/本文/第43条の3.md|第四十三条の三]]第一項の規定に違反して資金を管理したとき。
- 九 [[laws/327AC0000000346/本文/第44条.md|第四十四条]]第一項若しくは第三項又は[[laws/327AC0000000346/本文/第44条の2.md|第四十四条の二]]の規定に違反する経理をしたとき。
- 十 [[laws/327AC0000000346/本文/第55条.md|第五十五条]]又は[[laws/327AC0000000346/本文/第56条.md|第五十六条]]第二項（これらの規定を[[laws/327AC0000000346/本文/第59条の2.md|第五十九条の二]]第七項において準用する場合を含む。）の規定に違反して合併又は事業の全部の譲渡を行つたとき。
- 十の二 [[laws/327AC0000000346/本文/第55条.md|第五十五条]]第五項（[[laws/327AC0000000346/本文/第59条の2.md|第五十九条の二]]第七項において準用する場合を含む。）において準用する会社法[[laws/417AC0000000086/本文/第941条.md|第九百四十一条]]の規定に違反して同条の調査を求めなかつたとき。
- 十一 [[laws/327AC0000000346/本文/第61条.md|第六十一条]]又は[[laws/327AC0000000346/本文/第63条.md|第六十三条]]の書類又は電磁的記録に記載し、若しくは記録すべき事項を記載せず、若しくは記録せず、又は虚偽の記載若しくは記録をしたとき。
- 十二 [[laws/327AC0000000346/本文/第61条の2.md|第六十一条の二]]第一項又は[[laws/327AC0000000346/本文/第61条の4.md|第六十一条の四]]第一項の規定による公告を怠り、又は虚偽の公告をしたとき。
- 十三 [[laws/327AC0000000346/本文/第61条の2.md|第六十一条の二]]第一項の期間内に債権者に弁済をしたとき。
- 十四 [[laws/327AC0000000346/本文/第61条の4.md|第六十一条の四]]第一項の規定に違反して破産手続開始の申立てを怠つたとき。
- 十五 [[laws/327AC0000000346/本文/第62条.md|第六十二条]]第一項又は第二項の規定に違反したとき。
- 十六 [[laws/327AC0000000346/本文/第66条の2.md|第六十六条の二]]第一項の規定による命令（改善計画の提出を求めることを含む。）に違反したとき。
