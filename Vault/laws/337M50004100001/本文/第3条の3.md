# 第三条の三 （測定又は推計する時の降雨）

## 
令[[laws/337M50004100001/本文/第6条.md|第六条]]第二項の国土交通省令・環境省令で定める降雨は、その降雨量が十ミリメートル以上三十ミリメートル以下のものとする。
