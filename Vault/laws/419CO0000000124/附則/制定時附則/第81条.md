# 第八十一条 （暫定国営土地改良事業特別会計の廃止に伴う権利義務の帰属等に関する経過措置）

## 
法附則第二百三十条第四項ただし書の規定により国営土地改良事業経過勘定（同条第一項に規定する国営土地改良事業経過勘定をいう。次条及び附則第八十三条において同じ。）に帰属する権利義務の範囲、帰属の時期その他帰属に関し必要な事項は、農林水産大臣が財務大臣に協議して定める。
