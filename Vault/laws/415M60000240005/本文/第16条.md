# 第十六条 （長期借入金の認可の申請）

## 
信用基金は、法[[laws/415M60000240005/本文/第12条.md|第十二条]]第一項第四号、第六号及び第十号に掲げる業務並びに暫定措置法[[laws/415M60000240005/本文/第6条.md|第六条]]第一項第一号及び第二号に掲げる業務に関して法[[laws/415M60000240005/本文/第17条.md|第十七条]]（暫定措置法[[laws/415M60000240005/本文/第7条.md|第七条]]の規定により読み替えて適用する場合を含む。）の規定により長期借入金の認可を受けようとするときは、次の事項を記載した申請書を農林水産大臣及び財務大臣に提出しなければならない。借入れを必要とする理由借入金の額借入先借入金の利率借入金の償還の方法及び期限利息の支払の方法及び期限その他必要な事項

- 一 借入れを必要とする理由
- 二 借入金の額
- 三 借入先
- 四 借入金の利率
- 五 借入金の償還の方法及び期限
- 六 利息の支払の方法及び期限
- 七 その他必要な事項
