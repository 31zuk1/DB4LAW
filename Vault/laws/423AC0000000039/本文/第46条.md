# 第四十六条 

## 
次の各号のいずれかに該当する場合には、その違反行為をした会社の取締役、執行役、会計参与若しくはその職務を行うべき社員又は監査役は、百万円以下の過料に処する。この法律の規定により財務大臣の認可又は承認を受けなければならない場合において、その認可又は承認を受けなかったとき。この法律の規定により財務大臣に届出をしなければならない場合において、その届出をしなかったとき。[[laws/株式会社国際協力銀行法/本文/第11条.md|第十一条]]に規定する業務以外の業務を行い、又は[[laws/株式会社国際協力銀行法/本文/第12条.md|第十二条]]の規定に違反して[[laws/株式会社国際協力銀行法/本文/第11条.md|第十一条]]に規定する業務を行ったとき。[[laws/株式会社国際協力銀行法/本文/第13条の3.md|第十三条の三]]第二項又は[[laws/株式会社国際協力銀行法/本文/第38条.md|第三十八条]]第二項の規定による財務大臣の命令に違反したとき。[[laws/株式会社国際協力銀行法/本文/第33条.md|第三十三条]]第六項（同条第九項において準用する場合を含む。）の規定に違反して資金の借入れ若しくは社債の発行をし、又は同条第八項（同条第九項において準用する場合を含む。）の規定に違反して資金の貸付け、貸付債権の譲受け、公社債等の取得、債務の保証等若しくは出資をしたとき。[[laws/株式会社国際協力銀行法/本文/第36条.md|第三十六条]]の規定に違反して業務上の余裕金を運用したとき。

- 一 この法律の規定により財務大臣の認可又は承認を受けなければならない場合において、その認可又は承認を受けなかったとき。
- 二 この法律の規定により財務大臣に届出をしなければならない場合において、その届出をしなかったとき。
- 三 [[laws/株式会社国際協力銀行法/本文/第11条.md|第十一条]]に規定する業務以外の業務を行い、又は[[laws/株式会社国際協力銀行法/本文/第12条.md|第十二条]]の規定に違反して[[laws/株式会社国際協力銀行法/本文/第11条.md|第十一条]]に規定する業務を行ったとき。
- 四 [[laws/株式会社国際協力銀行法/本文/第13条の3.md|第十三条の三]]第二項又は[[laws/株式会社国際協力銀行法/本文/第38条.md|第三十八条]]第二項の規定による財務大臣の命令に違反したとき。
- 五 [[laws/株式会社国際協力銀行法/本文/第33条.md|第三十三条]]第六項（同条第九項において準用する場合を含む。）の規定に違反して資金の借入れ若しくは社債の発行をし、又は同条第八項（同条第九項において準用する場合を含む。）の規定に違反して資金の貸付け、貸付債権の譲受け、公社債等の取得、債務の保証等若しくは出資をしたとき。
- 六 [[laws/株式会社国際協力銀行法/本文/第36条.md|第三十六条]]の規定に違反して業務上の余裕金を運用したとき。
