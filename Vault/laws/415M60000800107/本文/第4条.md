# 第四条 （業務方法書の記載事項）

## 
機構に係る通則法[[laws/415M60000800107/本文/第28条.md|第二十八条]]第二項の主務省令で定める事項は、次のとおりとする。騒防法[[laws/415M60000800107/本文/第28条.md|第二十八条]]第一項第一号に規定する緑地帯その他の緩衝地帯の造成、管理及び譲渡に関する事項騒防法[[laws/415M60000800107/本文/第28条.md|第二十八条]]第一項第二号に規定する土地の造成、管理及び譲渡に関する事項騒防法[[laws/415M60000800107/本文/第28条.md|第二十八条]]第一項第三号に規定する助成に関する事項騒防法[[laws/415M60000800107/本文/第28条.md|第二十八条]]第一項第四号に規定する損失の補償及び土地の買入れに関する事務に関する事項騒防法[[laws/415M60000800107/本文/第28条.md|第二十八条]]第一項第五号に規定する附帯する業務に関する事項騒防法[[laws/415M60000800107/本文/第28条.md|第二十八条]]第二項に規定する緑地帯その他の緩衝地帯の造成に関する事項業務の委託に関する基準競争入札その他の契約に関する事項その他業務の執行に関して必要な事項

- 一 騒防法[[laws/415M60000800107/本文/第28条.md|第二十八条]]第一項第一号に規定する緑地帯その他の緩衝地帯の造成、管理及び譲渡に関する事項
- 二 騒防法[[laws/415M60000800107/本文/第28条.md|第二十八条]]第一項第二号に規定する土地の造成、管理及び譲渡に関する事項
- 三 騒防法[[laws/415M60000800107/本文/第28条.md|第二十八条]]第一項第三号に規定する助成に関する事項
- 四 騒防法[[laws/415M60000800107/本文/第28条.md|第二十八条]]第一項第四号に規定する損失の補償及び土地の買入れに関する事務に関する事項
- 五 騒防法[[laws/415M60000800107/本文/第28条.md|第二十八条]]第一項第五号に規定する附帯する業務に関する事項
- 六 騒防法[[laws/415M60000800107/本文/第28条.md|第二十八条]]第二項に規定する緑地帯その他の緩衝地帯の造成に関する事項
- 七 業務の委託に関する基準
- 八 競争入札その他の契約に関する事項
- 九 その他業務の執行に関して必要な事項
