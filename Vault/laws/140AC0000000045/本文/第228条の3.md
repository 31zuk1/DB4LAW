# 第二百二十八条の三 （身の代金目的略取等予備）

## 
[[laws/刑法/本文/第225条の2.md|第二百二十五条の二]]第一項の罪を犯す目的で、その予備をした者は、二年以下の拘禁刑に処する。ただし、実行に着手する前に自首した者は、その刑を減軽し、又は免除する。
