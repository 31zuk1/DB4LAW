# 第二百条 （設計課の所掌事務）

## 
設計課は、次に掲げる事務をつかさどる。農村振興部の所掌に属する事務の調整に関すること。土地改良事業計画の技術的な基準に関すること。土地改良事業の工事の設計に関すること。土地改良事業に関する長期計画に関すること。水資源の農業上の利用の確保に関すること（防災課の所掌に属するものを除く。）。農業水利に関すること。土地改良事業に用いる機械器具の管理に関すること。前各号に掲げるもののほか、農村振興部の所掌事務で他の所掌に属しないものに関すること。

- 一 農村振興部の所掌に属する事務の調整に関すること。
- 二 土地改良事業計画の技術的な基準に関すること。
- 三 土地改良事業の工事の設計に関すること。
- 四 土地改良事業に関する長期計画に関すること。
- 五 水資源の農業上の利用の確保に関すること（防災課の所掌に属するものを除く。）。
- 六 農業水利に関すること。
- 七 土地改良事業に用いる機械器具の管理に関すること。
- 八 前各号に掲げるもののほか、農村振興部の所掌事務で他の所掌に属しないものに関すること。
