# 第八十一条 

## 
[[laws/行政手続における特定の個人を識別するための番号の利用等に関する法律第十九条第八号に基づく利用特定個人情報の提供に関する命令/本文/第2条.md|第二条]]の表七十九の項で定める事務は、次の各号に掲げる事務とし、同項で定める情報は、当該各号に掲げる事務の区分に応じ当該各号に定める情報とする。薬剤師法[[laws/行政手続における特定の個人を識別するための番号の利用等に関する法律第十九条第八号に基づく利用特定個人情報の提供に関する命令/本文/第2条.md|第二条]]の薬剤師の免許の申請に係る事実についての審査に関する事務当該申請を行う者に係る戸籍関係情報薬剤師法施行令（昭和三十六年政令第十三号）[[laws/行政手続における特定の個人を識別するための番号の利用等に関する法律第十九条第八号に基づく利用特定個人情報の提供に関する命令/本文/第5条.md|第五条]]第一項の薬剤師の登録事項の変更の申請に係る事実についての審査に関する事務当該申請に係る者に係る戸籍関係情報薬剤師法施行令[[laws/行政手続における特定の個人を識別するための番号の利用等に関する法律第十九条第八号に基づく利用特定個人情報の提供に関する命令/本文/第6条.md|第六条]]第二項の薬剤師の登録の消除の申請に係る事実についての審査に関する事務当該申請に係る者に係る戸籍関係情報薬剤師法施行令[[laws/行政手続における特定の個人を識別するための番号の利用等に関する法律第十九条第八号に基づく利用特定個人情報の提供に関する命令/本文/第8条.md|第八条]]第一項の薬剤師免許証の書換交付の申請に係る事実についての審査に関する事務当該申請を行う者に係る戸籍関係情報薬剤師法施行令[[laws/行政手続における特定の個人を識別するための番号の利用等に関する法律第十九条第八号に基づく利用特定個人情報の提供に関する命令/本文/第9条.md|第九条]]第一項の薬剤師免許証の再交付の申請に係る事実についての審査に関する事務当該申請を行う者に係る戸籍関係情報
