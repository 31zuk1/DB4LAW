# 第九十七条 

## 
[[laws/506M60004008009/本文/第2条.md|第二条]]の表九十五の項で定める事務は、次の各号に掲げる事務とし、同項で定める情報は、当該各号に掲げる事務の区分に応じ当該各号に定める情報とする。母子保健法[[laws/506M60004008009/行政手続における特定の個人を識別するため_law.md|第九条の二]]第一項の母子保健に関する相談及び同条第二項の支援に関する事務当該相談及び支援に係る妊産婦又は乳児若しくは幼児に係る同条第一項の規定による相談、同条第二項の規定による支援、[[laws/506M60004008009/本文/第10条.md|第十条]]の規定による保健指導、[[laws/506M60004008009/本文/第11条.md|第十一条]]の規定による訪問指導、[[laws/506M60004008009/本文/第12条.md|第十二条]]第一項若しくは[[laws/506M60004008009/本文/第13条.md|第十三条]]第一項の規定による健康診査、[[laws/506M60004008009/本文/第17条.md|第十七条]]第一項の規定による訪問指導、[[laws/506M60004008009/行政手続における特定の個人を識別するため_law.md|第十七条の二]]の規定による産後ケア事業又は[[laws/506M60004008009/本文/第19条.md|第十九条]]の規定による訪問指導（以下この条において「乳幼児健康診査等」という。）に関する情報母子保健法[[laws/506M60004008009/本文/第10条.md|第十条]]の保健指導の実施又は勧奨に関する事務当該保健指導の実施又は勧奨に係る妊産婦若しくはその配偶者又は乳児若しくは幼児に係る乳幼児健康診査等に関する情報母子保健法[[laws/506M60004008009/本文/第11条.md|第十一条]]の新生児の訪問指導に関する事務当該訪問指導に係る乳児に係る乳幼児健康診査等に関する情報母子保健法[[laws/506M60004008009/本文/第12条.md|第十二条]]第一項の健康診査の実施に関する事務当該健康診査の実施に係る幼児に係る乳幼児健康診査等に関する情報母子保健法[[laws/506M60004008009/本文/第13条.md|第十三条]]第一項の健康診査の実施又は勧奨に関する事務当該健康診査の実施又は勧奨に係る妊産婦又は乳児若しくは幼児に係る乳幼児健康診査等に関する情報母子保健法[[laws/506M60004008009/本文/第17条.md|第十七条]]第一項の妊産婦の訪問指導又は勧奨に関する事務当該訪問指導又は勧奨に係る妊産婦に係る乳幼児健康診査等に関する情報母子保健法[[laws/506M60004008009/行政手続における特定の個人を識別するため_law.md|第十七条の二]]第一項の産後ケア事業の実施に関する事務当該事業の実施に係る出産後一年を経過しない女子及び乳児に係る乳幼児健康診査等に関する情報母子保健法[[laws/506M60004008009/本文/第19条.md|第十九条]]の未熟児の訪問指導に関する事務当該訪問指導に係る乳児に係る乳幼児健康診査等に関する情報母子保健法[[laws/506M60004008009/本文/第22条.md|第二十二条]]第一項のこども家庭センターが行う同項第二号から第五号までに掲げる事業の実施に関する事務当該事業の実施に係る妊産婦又は乳児若しくは幼児に係る乳幼児健康診査等に関する情報

- 一 母子保健法[[laws/506M60004008009/行政手続における特定の個人を識別するため_law.md|第九条の二]]第一項の母子保健に関する相談及び同条第二項の支援に関する事務当該相談及び支援に係る妊産婦又は乳児若しくは幼児に係る同条第一項の規定による相談、同条第二項の規定による支援、[[laws/506M60004008009/本文/第10条.md|第十条]]の規定による保健指導、[[laws/506M60004008009/本文/第11条.md|第十一条]]の規定による訪問指導、[[laws/506M60004008009/本文/第12条.md|第十二条]]第一項若しくは[[laws/506M60004008009/本文/第13条.md|第十三条]]第一項の規定による健康診査、[[laws/506M60004008009/本文/第17条.md|第十七条]]第一項の規定による訪問指導、[[laws/506M60004008009/行政手続における特定の個人を識別するため_law.md|第十七条の二]]の規定による産後ケア事業又は[[laws/506M60004008009/本文/第19条.md|第十九条]]の規定による訪問指導（以下この条において「乳幼児健康診査等」という。）に関する情報
- 二 母子保健法[[laws/506M60004008009/本文/第10条.md|第十条]]の保健指導の実施又は勧奨に関する事務当該保健指導の実施又は勧奨に係る妊産婦若しくはその配偶者又は乳児若しくは幼児に係る乳幼児健康診査等に関する情報
- 三 母子保健法[[laws/506M60004008009/本文/第11条.md|第十一条]]の新生児の訪問指導に関する事務当該訪問指導に係る乳児に係る乳幼児健康診査等に関する情報
- 四 母子保健法[[laws/506M60004008009/本文/第12条.md|第十二条]]第一項の健康診査の実施に関する事務当該健康診査の実施に係る幼児に係る乳幼児健康診査等に関する情報
- 五 母子保健法[[laws/506M60004008009/本文/第13条.md|第十三条]]第一項の健康診査の実施又は勧奨に関する事務当該健康診査の実施又は勧奨に係る妊産婦又は乳児若しくは幼児に係る乳幼児健康診査等に関する情報
- 六 母子保健法[[laws/506M60004008009/本文/第17条.md|第十七条]]第一項の妊産婦の訪問指導又は勧奨に関する事務当該訪問指導又は勧奨に係る妊産婦に係る乳幼児健康診査等に関する情報
- 七 母子保健法[[laws/506M60004008009/行政手続における特定の個人を識別するため_law.md|第十七条の二]]第一項の産後ケア事業の実施に関する事務当該事業の実施に係る出産後一年を経過しない女子及び乳児に係る乳幼児健康診査等に関する情報
- 八 母子保健法[[laws/506M60004008009/本文/第19条.md|第十九条]]の未熟児の訪問指導に関する事務当該訪問指導に係る乳児に係る乳幼児健康診査等に関する情報
- 九 母子保健法[[laws/506M60004008009/本文/第22条.md|第二十二条]]第一項のこども家庭センターが行う同項第二号から第五号までに掲げる事業の実施に関する事務当該事業の実施に係る妊産婦又は乳児若しくは幼児に係る乳幼児健康診査等に関する情報
