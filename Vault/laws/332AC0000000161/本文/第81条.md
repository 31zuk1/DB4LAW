# 第八十一条 （国立公園等との関係）

## 
国立公園若しくは国定公園又は自然環境保全法[[laws/332AC0000000161/本文/第14条.md|第十四条]]第一項の規定により指定された原生自然環境保全地域の区域は、都道府県立自然公園の区域に含まれないものとする。
