# 第十三条 （都道府県が処理する事務）

## 
法及びこの政令に定める厚生労働大臣の権限に属する事務のうち、次に掲げるものは、都道府県知事が行うこととする。この場合においては、法及びこの政令の規定中当該事務に係る厚生労働大臣に関する規定は、都道府県知事に関する規定として都道府県知事に適用があるものとする。法[[laws/338CO0000000358/本文/第4条.md|第四条]]に規定する権限（公務上の傷病につき恩給法の規定による増加恩給、傷病年金、傷病賜金その他これらに相当する給付の裁定を受けた者以外の者に係る公務上の傷病の認定に関する権限を除く。）に属する事務公務上の傷病につき恩給法の規定による増加恩給、傷病年金、傷病賜金その他これらに相当する給付の裁定を受けた者以外の者に係る法[[laws/338CO0000000358/本文/第4条.md|第四条]]の規定による公務上の傷病の認定に必要な調査に関する事務法[[laws/338CO0000000358/本文/第5条.md|第五条]]及び[[laws/338CO0000000358/本文/第6条.md|第六条]]に規定する権限に属する事務法[[laws/338CO0000000358/本文/第12条.md|第十二条]]並びに[[laws/338CO0000000358/本文/第13条.md|第十三条]]第二項、[[laws/338CO0000000358/本文/第15条.md|第十五条]]第一項及び[[laws/338AC1000000168/本文/第16条.md|第十六条]]（法[[laws/338AC1000000168/本文/第20条.md|第二十条]]第三項においてこれらの規定を準用する場合を含む。）に規定する権限に属する事務法[[laws/338AC1000000168/本文/第17条.md|第十七条]]第一項及び第三項（法[[laws/338AC1000000168/本文/第20条.md|第二十条]]第五項において準用する場合を含む。）に規定する権限に属する事務法[[laws/338AC1000000168/本文/第18条.md|第十八条]]第一項、[[laws/338AC1000000168/本文/第19条.md|第十九条]]第一項及び第二項並びに[[laws/338AC1000000168/本文/第20条.md|第二十条]]第一項及び第四項に規定する権限に属する事務法[[laws/338AC1000000168/本文/第21条.md|第二十一条]]第一項及び第四項に規定する権限（補装具の種類を定める権限を除く。）に属する事務法[[laws/338AC1000000168/本文/第24条.md|第二十四条]]に規定する権限に属する事務[[laws/338CO0000000358/本文/第5条.md|第五条]]の規定による戦傷病者手帳交付台帳の備付けに関する事務[[laws/338CO0000000358/本文/第6条.md|第六条]]に規定する権限に属する事務

- 一 法[[laws/338CO0000000358/本文/第4条.md|第四条]]に規定する権限（公務上の傷病につき恩給法の規定による増加恩給、傷病年金、傷病賜金その他これらに相当する給付の裁定を受けた者以外の者に係る公務上の傷病の認定に関する権限を除く。）に属する事務
- 二 公務上の傷病につき恩給法の規定による増加恩給、傷病年金、傷病賜金その他これらに相当する給付の裁定を受けた者以外の者に係る法[[laws/338CO0000000358/本文/第4条.md|第四条]]の規定による公務上の傷病の認定に必要な調査に関する事務
- 三 法[[laws/338CO0000000358/本文/第5条.md|第五条]]及び[[laws/338CO0000000358/本文/第6条.md|第六条]]に規定する権限に属する事務
- 四 法[[laws/338CO0000000358/本文/第12条.md|第十二条]]並びに[[laws/338CO0000000358/本文/第13条.md|第十三条]]第二項、[[laws/338CO0000000358/本文/第15条.md|第十五条]]第一項及び[[laws/338AC1000000168/本文/第16条.md|第十六条]]（法[[laws/338AC1000000168/本文/第20条.md|第二十条]]第三項においてこれらの規定を準用する場合を含む。）に規定する権限に属する事務
- 五 法[[laws/338AC1000000168/本文/第17条.md|第十七条]]第一項及び第三項（法[[laws/338AC1000000168/本文/第20条.md|第二十条]]第五項において準用する場合を含む。）に規定する権限に属する事務
- 六 法[[laws/338AC1000000168/本文/第18条.md|第十八条]]第一項、[[laws/338AC1000000168/本文/第19条.md|第十九条]]第一項及び第二項並びに[[laws/338AC1000000168/本文/第20条.md|第二十条]]第一項及び第四項に規定する権限に属する事務
- 七 法[[laws/338AC1000000168/本文/第21条.md|第二十一条]]第一項及び第四項に規定する権限（補装具の種類を定める権限を除く。）に属する事務
- 八 法[[laws/338AC1000000168/本文/第24条.md|第二十四条]]に規定する権限に属する事務
- 九 [[laws/338CO0000000358/本文/第5条.md|第五条]]の規定による戦傷病者手帳交付台帳の備付けに関する事務
- 十 [[laws/338CO0000000358/本文/第6条.md|第六条]]に規定する権限に属する事務
