# 第六十八条 

## 
次の各号のいずれかに該当する者は、二十万円以下の罰金に処する。[[laws/338M50000800041/本文/第40条.md|第四十条]]（[[laws/338M50000800041/本文/第43条.md|第四十三条]]第二項において準用する場合を含む。）の規定に違反した者[[laws/338M50000800041/本文/第42条.md|第四十二条]]第三項の規定に違反した者[[laws/338M50000800041/本文/第46条.md|第四十六条]]第四項の規定に違反した者[[laws/338M50000800041/本文/第55条の2.md|第五十五条の二]]の規定に違反して書類を船舶所有者若しくは船長に提出せず、又は同条の規定により船舶所有者若しくは船長に提出された書類に虚偽の記載をした者[[laws/338M50000800041/本文/第60条.md|第六十条]]の規定に違反した者[[laws/338M50000800041/本文/第60条の4.md|第六十条の四]]第一項の規定に違反した者[[laws/338M50000800041/本文/第61条.md|第六十一条]]の規定に違反した者

- 一 [[laws/338M50000800041/本文/第40条.md|第四十条]]（[[laws/338M50000800041/本文/第43条.md|第四十三条]]第二項において準用する場合を含む。）の規定に違反した者
- 二 [[laws/338M50000800041/本文/第42条.md|第四十二条]]第三項の規定に違反した者
- 三 [[laws/338M50000800041/本文/第46条.md|第四十六条]]第四項の規定に違反した者
- 四 [[laws/338M50000800041/本文/第55条の2.md|第五十五条の二]]の規定に違反して書類を船舶所有者若しくは船長に提出せず、又は同条の規定により船舶所有者若しくは船長に提出された書類に虚偽の記載をした者
- 五 [[laws/338M50000800041/本文/第60条.md|第六十条]]の規定に違反した者
- 六 [[laws/338M50000800041/本文/第60条の4.md|第六十条の四]]第一項の規定に違反した者
- 七 [[laws/338M50000800041/本文/第61条.md|第六十一条]]の規定に違反した者
