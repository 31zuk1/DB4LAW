# 第八十一条 

## 
司法書士会又は日本司法書士会連合会が[[laws/325AC1000000197/本文/第55条.md|第五十五条]]第一項（[[laws/325AC1000000197/本文/第66条.md|第六十六条]]において準用する場合を含む。）の規定に基づく政令に違反して登記をすることを怠つたときは、その司法書士会又は日本司法書士会連合会の代表者は、三十万円以下の過料に処する。
