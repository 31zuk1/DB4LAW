# 第九十五条の三の三 （企業結合に係る特定勘定の取崩益の注記）

## 
企業結合に係る特定勘定の取崩益が生じた場合には、重要性が乏しい場合を除き、内容及び金額を注記しなければならない。

## ２
前項に規定する事項は、連結財務諸表において同一の内容が記載される場合には、記載することを要しない。この場合には、その旨を記載しなければならない。
