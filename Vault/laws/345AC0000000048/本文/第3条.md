# 第三条 （著作物の発行）

## 
著作物は、その性質に応じ公衆の要求を満たすことができる相当程度の部数の複製物が、[[laws/著作権法/本文/第21条.md|第二十一条]]に規定する権利を有する者若しくはその許諾（[[laws/著作権法/本文/第63条.md|第六十三条]]第一項の規定による利用の許諾をいう。以下この項、次条第一項、[[laws/著作権法/本文/第4条の2.md|第四条の二]]及び[[laws/著作権法/本文/第63条.md|第六十三条]]を除き、以下この章及び次章において同じ。）を得た者又は[[laws/著作権法/本文/第79条.md|第七十九条]]の出版権の設定を受けた者若しくはその複製許諾（[[laws/著作権法/本文/第80条.md|第八十条]]第三項の規定による複製の許諾をいう。以下同じ。）を得た者によつて作成され、頒布された場合（[[laws/著作権法/本文/第26条.md|第二十六条]]、[[laws/著作権法/本文/第26条の2.md|第二十六条の二]]第一項又は[[laws/著作権法/本文/第26条の3.md|第二十六条の三]]に規定する権利を有する者の権利を害しない場合に限る。）において、発行されたものとする。

## ２
二次的著作物である翻訳物の前項に規定する部数の複製物が[[laws/著作権法/本文/第28条.md|第二十八条]]の規定により[[laws/著作権法/本文/第21条.md|第二十一条]]に規定する権利と同一の権利を有する者又はその許諾を得た者によつて作成され、頒布された場合（[[laws/著作権法/本文/第28条.md|第二十八条]]の規定により[[laws/著作権法/本文/第26条.md|第二十六条]]、[[laws/著作権法/本文/第26条の2.md|第二十六条の二]]第一項又は[[laws/著作権法/本文/第26条の3.md|第二十六条の三]]に規定する権利と同一の権利を有する者の権利を害しない場合に限る。）には、その原著作物は、発行されたものとみなす。

## ３
著作物がこの法律による保護を受けるとしたならば前二項の権利を有すべき者又はその者からその著作物の利用の承諾を得た者は、それぞれ前二項の権利を有する者又はその許諾を得た者とみなして、前二項の規定を適用する。
