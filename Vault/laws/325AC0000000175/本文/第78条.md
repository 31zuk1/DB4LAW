# 第七十八条 

## 
次の各号のいずれかに該当する場合には、その違反行為をした者は、一年以下の拘禁刑又は百万円以下の罰金に処する。[[laws/325AC0000000175/本文/第8条.md|第八条]]の規定に違反したとき。[[laws/325AC0000000175/本文/第10条.md|第十条]]第六項又は第七項の規定に違反したとき。[[laws/325AC0000000175/本文/第12条の2.md|第十二条の二]]第三項又は第四項の規定に違反したとき。本邦において[[laws/325AC0000000175/本文/第30条.md|第三十条]]第五項において準用する[[laws/325AC0000000175/本文/第10条.md|第十条]]第六項又は第七項の規定に違反したとき。[[laws/325AC0000000175/本文/第37条.md|第三十七条]]の規定に違反したとき。[[laws/325AC0000000175/本文/第38条.md|第三十八条]]の規定に違反したとき。[[laws/325AC0000000175/本文/第39条.md|第三十九条]]第一項から第三項までの規定による格付の表示、外国格付の表示又は適合の表示の除去又は抹消の命令に違反したとき。[[laws/325AC0000000175/本文/第40条.md|第四十条]]の規定に違反したとき。[[laws/325AC0000000175/本文/第41条.md|第四十一条]]第一項の規定に違反したとき。[[laws/325AC0000000175/本文/第41条の2.md|第四十一条の二]]の規定に違反したとき。[[laws/325AC0000000175/本文/第57条.md|第五十七条]]の規定に違反したとき。[[laws/325AC0000000175/本文/第58条.md|第五十八条]]の規定に違反したとき。[[laws/325AC0000000175/本文/第61条.md|第六十一条]]第三項の規定による命令に違反したとき。[[laws/325AC0000000175/本文/第64条.md|第六十四条]]の規定による処分に違反したとき。

- 一 [[laws/325AC0000000175/本文/第8条.md|第八条]]の規定に違反したとき。
- 二 [[laws/325AC0000000175/本文/第10条.md|第十条]]第六項又は第七項の規定に違反したとき。
- 三 [[laws/325AC0000000175/本文/第12条の2.md|第十二条の二]]第三項又は第四項の規定に違反したとき。
- 四 本邦において[[laws/325AC0000000175/本文/第30条.md|第三十条]]第五項において準用する[[laws/325AC0000000175/本文/第10条.md|第十条]]第六項又は第七項の規定に違反したとき。
- 五 [[laws/325AC0000000175/本文/第37条.md|第三十七条]]の規定に違反したとき。
- 六 [[laws/325AC0000000175/本文/第38条.md|第三十八条]]の規定に違反したとき。
- 七 [[laws/325AC0000000175/本文/第39条.md|第三十九条]]第一項から第三項までの規定による格付の表示、外国格付の表示又は適合の表示の除去又は抹消の命令に違反したとき。
- 八 [[laws/325AC0000000175/本文/第40条.md|第四十条]]の規定に違反したとき。
- 九 [[laws/325AC0000000175/本文/第41条.md|第四十一条]]第一項の規定に違反したとき。
- 十 [[laws/325AC0000000175/本文/第41条の2.md|第四十一条の二]]の規定に違反したとき。
- 十一 [[laws/325AC0000000175/本文/第57条.md|第五十七条]]の規定に違反したとき。
- 十二 [[laws/325AC0000000175/本文/第58条.md|第五十八条]]の規定に違反したとき。
- 十三 [[laws/325AC0000000175/本文/第61条.md|第六十一条]]第三項の規定による命令に違反したとき。
- 十四 [[laws/325AC0000000175/本文/第64条.md|第六十四条]]の規定による処分に違反したとき。
