# 第三百九十一条 

## 
次の各号のいずれかに該当する者は、三十万円以下の罰金に処する。[[laws/332M50000800030/本文/第4条.md|第四条]]第一項の規定に違反して危険物を船舶に持ち込んだ者[[laws/332M50000800030/本文/第5条.md|第五条]]第一項、第二項、第三項、第四項又は第六項の規定に違反して工事その他の作業を行つた者[[laws/332M50000800030/本文/第7条.md|第七条]]第一項の規定に違反して船舶により運送することが禁止されている危険物を船舶により運送した者[[laws/332M50000800030/本文/第7条.md|第七条]]第二項の規定に違反して旅客船により運送することが禁止されている危険物を旅客船により運送した者[[laws/332M50000800030/本文/第337条.md|第三百三十七条]]第二項の規定に違反して引火性液体物質を木製のタンク船のタンクに積載して運送した者[[laws/332M50000800030/本文/第348条.md|第三百四十八条]]第二項の規定に違反して引火性液体物質を同項の木製の油はしけのタンクに積載して運送した者

- 一 [[laws/332M50000800030/本文/第4条.md|第四条]]第一項の規定に違反して危険物を船舶に持ち込んだ者
- 二 [[laws/332M50000800030/本文/第5条.md|第五条]]第一項、第二項、第三項、第四項又は第六項の規定に違反して工事その他の作業を行つた者
- 三 [[laws/332M50000800030/本文/第7条.md|第七条]]第一項の規定に違反して船舶により運送することが禁止されている危険物を船舶により運送した者
- 四 [[laws/332M50000800030/本文/第7条.md|第七条]]第二項の規定に違反して旅客船により運送することが禁止されている危険物を旅客船により運送した者
- 五 [[laws/332M50000800030/本文/第337条.md|第三百三十七条]]第二項の規定に違反して引火性液体物質を木製のタンク船のタンクに積載して運送した者
- 六 [[laws/332M50000800030/本文/第348条.md|第三百四十八条]]第二項の規定に違反して引火性液体物質を同項の木製の油はしけのタンクに積載して運送した者
