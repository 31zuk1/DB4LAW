# 第百九十三条の二 （毒性の貨物に係る通風装置）

## 
毒性の貨物を運送する船舶に備え付ける[[laws/危険物船舶運送及び貯蔵規則/本文/第190条.md|第百九十条]]第一項及び[[laws/危険物船舶運送及び貯蔵規則/本文/第191条.md|第百九十一条]]第一項の機械通風装置は、常に作動させておかなければならない。
