# 第六十四条 （特定社債の種類）

## 
法[[laws/資産の流動化に関する法律施行規則/本文/第125条.md|第百二十五条]]において準用する会社法[[laws/会社法/本文/第681条.md|第六百八十一条]]第一号に規定する内閣府令で定める事項は、次に掲げる事項とする。特定社債の利率特定社債の償還の方法及び期限利息支払の方法及び期限特定社債券を発行するときは、その旨特定社債権者が法[[laws/資産の流動化に関する法律施行規則/本文/第125条.md|第百二十五条]]において準用する会社法[[laws/会社法/本文/第698条.md|第六百九十八条]]の規定による請求の全部又は一部をすることができないこととするときは、その旨特定社債管理者を定めないこととするときは、その旨特定社債管理者が特定社債権者集会の決議によらずに法[[laws/資産の流動化に関する法律施行規則/本文/第127条.md|第百二十七条]]第四項第二号に掲げる行為をすることができることとするときは、その旨特定社債管理補助者を定めることとするときは、その旨特定社債管理者を定めたときは、その名称及び住所並びに法[[laws/資産の流動化に関する法律施行規則/本文/第126条.md|第百二十六条]]の規定による委託に係る契約の内容特定社債管理補助者を定めたときは、その氏名又は名称及び住所並びに法[[laws/資産の流動化に関する法律施行規則/本文/第127条の2.md|第百二十七条の二]]第一項の規定による委託に係る契約の内容特定社債原簿管理人を定めたときは、その氏名又は名称及び住所特定社債が担保付特定社債であるときは、法[[laws/資産の流動化に関する法律施行規則/本文/第130条.md|第百三十条]]において特定社債を社債とみなして適用する担保付社債信託法[[laws/信託法/本文/第19条.md|第十九条]]第一号、第十一号及び第十三号に掲げる事項

- 一 特定社債の利率
- 二 特定社債の償還の方法及び期限
- 三 利息支払の方法及び期限
- 四 特定社債券を発行するときは、その旨
- 五 特定社債権者が法[[laws/資産の流動化に関する法律施行規則/本文/第125条.md|第百二十五条]]において準用する会社法[[laws/会社法/本文/第698条.md|第六百九十八条]]の規定による請求の全部又は一部をすることができないこととするときは、その旨
- 六 特定社債管理者を定めないこととするときは、その旨
- 七 特定社債管理者が特定社債権者集会の決議によらずに法[[laws/資産の流動化に関する法律施行規則/本文/第127条.md|第百二十七条]]第四項第二号に掲げる行為をすることができることとするときは、その旨
- 八 特定社債管理補助者を定めることとするときは、その旨
- 九 特定社債管理者を定めたときは、その名称及び住所並びに法[[laws/資産の流動化に関する法律施行規則/本文/第126条.md|第百二十六条]]の規定による委託に係る契約の内容
- 十 特定社債管理補助者を定めたときは、その氏名又は名称及び住所並びに法[[laws/資産の流動化に関する法律施行規則/本文/第127条の2.md|第百二十七条の二]]第一項の規定による委託に係る契約の内容
- 十一 特定社債原簿管理人を定めたときは、その氏名又は名称及び住所
- 十二 特定社債が担保付特定社債であるときは、法[[laws/資産の流動化に関する法律施行規則/本文/第130条.md|第百三十条]]において特定社債を社債とみなして適用する担保付社債信託法[[laws/信託法/本文/第19条.md|第十九条]]第一号、第十一号及び第十三号に掲げる事項
