# 第二百一条 （委託することができる業務）

## 
法[[laws/農業保険法施行規則/本文/第188条.md|第百八十八条]]第一項の農林水産省令で定める業務は、次に掲げる業務とする。農業経営収入保険（法[[laws/農業保険法施行規則/本文/第182条.md|第百八十二条]]第一項の特約を含む。）の引受けに係る業務（保険関係の成立についての申込みの承諾の決定に係るものを除く。）保険金又は特約補塡金の支払に係る業務（保険金又は特約補塡金の額の決定に係るものを除く。）法[[laws/農業保険法施行規則/本文/第182条.md|第百八十二条]]第一項第一号の積立金の受領に係る業務事務費の徴収に係る業務農業経営収入保険事業の実施に必要な調査に係る業務保険事故の発生の防止に係る業務

- 一 農業経営収入保険（法[[laws/農業保険法施行規則/本文/第182条.md|第百八十二条]]第一項の特約を含む。）の引受けに係る業務（保険関係の成立についての申込みの承諾の決定に係るものを除く。）
- 二 保険金又は特約補塡金の支払に係る業務（保険金又は特約補塡金の額の決定に係るものを除く。）
- 三 法[[laws/農業保険法施行規則/本文/第182条.md|第百八十二条]]第一項第一号の積立金の受領に係る業務
- 四 事務費の徴収に係る業務
- 五 農業経営収入保険事業の実施に必要な調査に係る業務
- 六 保険事故の発生の防止に係る業務
