# 第三条の二 （法第三十一条第一項の規定により読み替えて適用される法第十一条の三第一項の国土交通省令で定める妊娠又は出産に関する事由）

## 
法[[laws/船員に関する雇用の分野における男女の均等な機会及び待遇の確保等に関する法律施行規則/本文/第31条.md|第三十一条]]第一項の規定により読み替えて適用される法[[laws/船員に関する雇用の分野における男女の均等な機会及び待遇の確保等に関する法律施行規則/本文/第11条の3.md|第十一条の三]]第一項の国土交通省令で定める妊娠又は出産に関する事由は、次のとおりとする。妊娠したこと。出産したこと。法[[laws/船員に関する雇用の分野における男女の均等な機会及び待遇の確保等に関する法律施行規則/本文/第31条.md|第三十一条]]第一項の規定により読み替えて適用される法[[laws/船員に関する雇用の分野における男女の均等な機会及び待遇の確保等に関する法律施行規則/本文/第12条.md|第十二条]]若しくは法[[laws/船員に関する雇用の分野における男女の均等な機会及び待遇の確保等に関する法律施行規則/本文/第13条.md|第十三条]]第一項の規定による措置を求めようとし、若しくは措置を求め、又はこれらの規定による措置を受けたこと。船員法[[laws/船員に関する雇用の分野における男女の均等な機会及び待遇の確保等に関する法律施行規則/本文/第87条.md|第八十七条]]第一項若しくは第二項の規定により作業に従事できず、若しくは作業に従事しなかつたこと、船員職業安定法[[laws/船員に関する雇用の分野における男女の均等な機会及び待遇の確保等に関する法律施行規則/本文/第92条.md|第九十二条]]第五項の規定により読み替えて適用される船員法[[laws/船員に関する雇用の分野における男女の均等な機会及び待遇の確保等に関する法律施行規則/本文/第87条.md|第八十七条]]第一項本文若しくは第二項本文の規定によつて船員派遣の役務に従事できず、若しくは船員派遣の役務に従事しなかつたこと又は船員の雇用の促進に関する特別措置法[[laws/船員に関する雇用の分野における男女の均等な機会及び待遇の確保等に関する法律施行規則/本文/第14条.md|第十四条]]第六項の規定により読み替えて適用される船員法[[laws/船員に関する雇用の分野における男女の均等な機会及び待遇の確保等に関する法律施行規則/本文/第87条.md|第八十七条]]第一項本文若しくは第二項本文の規定によつて船員労務供給の役務に従事できず、若しくは船員労務供給の役務に従事しなかつたこと。船員法[[laws/船員に関する雇用の分野における男女の均等な機会及び待遇の確保等に関する法律施行規則/本文/第87条.md|第八十七条]]第三項の規定による申出をしようとし、若しくは申出をし、又は軽易な作業に従事したこと。船員法[[laws/船員に関する雇用の分野における男女の均等な機会及び待遇の確保等に関する法律施行規則/本文/第88条.md|第八十八条]]の規定により作業に従事できなかつたこと。船員法[[laws/船員に関する雇用の分野における男女の均等な機会及び待遇の確保等に関する法律施行規則/本文/第88条の2.md|第八十八条の二]]の二第一項から第三項までの規定により同法[[laws/船員に関する雇用の分野における男女の均等な機会及び待遇の確保等に関する法律施行規則/本文/第60条.md|第六十条]]第一項の労働時間を超えて作業に従事することができず、又は作業に従事しなかつたこと。船員法[[laws/船員に関する雇用の分野における男女の均等な機会及び待遇の確保等に関する法律施行規則/本文/第88条の3.md|第八十八条の三]]第一項及び第三項の規定により休日に作業に従事できず、又は作業に従事しなかつたこと。船員法[[laws/船員に関する雇用の分野における男女の均等な機会及び待遇の確保等に関する法律施行規則/本文/第88条の4.md|第八十八条の四]]の規定により午後八時から翌日の午前五時までの間において作業に従事できず、又は作業に従事しなかつたこと。妊娠又は出産に起因する症状により労務の提供ができないこと若しくはできなかつたこと又は労働能率が低下したこと。

- 一 妊娠したこと。
- 二 出産したこと。

- 五 船員法[[laws/船員に関する雇用の分野における男女の均等な機会及び待遇の確保等に関する法律施行規則/本文/第87条.md|第八十七条]]第三項の規定による申出をしようとし、若しくは申出をし、又は軽易な作業に従事したこと。
- 六 船員法[[laws/船員に関する雇用の分野における男女の均等な機会及び待遇の確保等に関する法律施行規則/本文/第88条.md|第八十八条]]の規定により作業に従事できなかつたこと。
