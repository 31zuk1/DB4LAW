# 第八十一条 （継続申込特約に関する規定の準用）

## 
[[laws/339M50010000035/本文/第54条の4.md|第五十四条の四]]、[[laws/339M50010000035/本文/第54条の5.md|第五十四条の五]]及び[[laws/339M50010000035/本文/第71条.md|第七十一条]]の規定は、漁業施設共済の共済契約について準用する。この場合において、[[laws/339M50010000035/本文/第71条.md|第七十一条]]第一項第一号中「の共済金額が法[[laws/339AC0000000158/本文/第120条.md|第百二十条]]第二項の農林水産大臣が定める共済金額の」とあるのは「に係る法[[laws/339AC0000000158/本文/第131条.md|第百三十一条]]第一項の割合が同条第二項の農林水産大臣が定める」と、同項第二号中「[[laws/339AC0000000158/本文/第121条.md|第百二十一条]]第一項の単位当たり共済価額又は法[[laws/339AC0000000158/本文/第122条.md|第百二十二条]]第二項の基準共済掛金率」とあるのは「[[laws/339AC0000000158/本文/第133条.md|第百三十三条]]第二項の規定により農林水産大臣が定める純共済掛金率の基準となる率」と、同条第二項第一号中「[[laws/339AC0000000158/本文/第120条.md|第百二十条]]第二項」とあるのは「[[laws/339AC0000000158/本文/第131条.md|第百三十一条]]第二項」と、「共済金額の最高限度の共済価額に対する」とあるのは「最高限度の」と読み替えるものとする。
