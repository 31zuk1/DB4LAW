# 第六十六条 （組織変更の認可）

## 
法[[laws/技術研究組合法施行規則/本文/第77条.md|第七十七条]]第二項の規定により株式会社への組織変更の認可を受けようとする者は、様式第十による申請書に次の書類（官公署が証明する書面の場合には、認可の申請の日前三月以内に作成されたものに限る。）を添えて提出しなければならない。組織変更の理由及び組織変更計画の内容を記載した書面組織変更の効力発生日の属する事業年度の事業計画書組織変更計画を承認した総会の議事録の謄本直前事業年度の決算関係書類等現に存する純資産額を証する書面法[[laws/技術研究組合法施行規則/本文/第67条.md|第六十七条]]の規定により組織変更時発行株式を発行するときは、次に掲げる書面組織変更時発行株式の引受けの申込みを証する書面金銭を出資の目的とするときは、法[[laws/技術研究組合法施行規則/本文/第72条.md|第七十二条]]第一項の規定による払込みがあったことを証する書面金銭以外の財産を出資の目的とするときは、次に掲げる書面検査役が選任されたときは、検査役の調査報告を記載した書面及びその附属書類法[[laws/技術研究組合法施行規則/本文/第75条.md|第七十五条]]において準用する会社法[[laws/会社法/本文/第207条.md|第二百七条]]第九項第三号に掲げる場合には、有価証券の市場価格を証する書面法[[laws/会社法/本文/第75条.md|第七十五条]]において準用する会社法[[laws/会社法/本文/第207条.md|第二百七条]]第九項第四号に掲げる場合には、同号に規定する証明を記載した書面及びその附属書類法[[laws/技術研究組合法施行規則/本文/第75条.md|第七十五条]]において準用する会社法[[laws/会社法/本文/第207条.md|第二百七条]]第九項第五号に掲げる場合には、同号の金銭債権について記載された会計帳簿検査役の報告に関する裁判があったときは、その謄本法[[laws/技術研究組合法施行規則/本文/第64条.md|第六十四条]]第二項の規定による公告及び催告（法[[laws/技術研究組合法施行規則/本文/第64条.md|第六十四条]]第三項の規定により公告を官報のほか法[[laws/技術研究組合法施行規則/本文/第16条.md|第十六条]]第五項の規定による定款の定めに従い同項第二号又は第三号に掲げる公告方法によってした場合にあっては、これらの方法による公告）をしたこと並びに異議を述べた債権者があるときは、法[[laws/技術研究組合法施行規則/本文/第64条.md|第六十四条]]第五項の規定により当該債権者に対し弁済し、若しくは相当の担保を提供し、若しくは当該債権者に弁済を受けさせることを目的として相当の財産を信託したこと又は当該組織変更をしても当該債権者を害するおそれがないことを証する書面法[[laws/技術研究組合法施行規則/本文/第65条.md|第六十五条]]第一項の規定による株式の割当てが組織変更をする組合の事業に対して組合員がした負担及び寄与の程度を勘案して定められていることを証する書面組織変更をする組合の組合員であって法[[laws/技術研究組合法施行規則/本文/第62条.md|第六十二条]]第一項第五号の株式の割当てを受けない者の利益に関する事項が記載された書面

- 一 組織変更の理由及び組織変更計画の内容を記載した書面
- 二 組織変更の効力発生日の属する事業年度の事業計画書
- 三 組織変更計画を承認した総会の議事録の謄本
- 四 直前事業年度の決算関係書類等
- 五 現に存する純資産額を証する書面
- 六 法[[laws/技術研究組合法施行規則/本文/第67条.md|第六十七条]]の規定により組織変更時発行株式を発行するときは、次に掲げる書面
- 七 法[[laws/技術研究組合法施行規則/本文/第64条.md|第六十四条]]第二項の規定による公告及び催告（法[[laws/技術研究組合法施行規則/本文/第64条.md|第六十四条]]第三項の規定により公告を官報のほか法[[laws/技術研究組合法施行規則/本文/第16条.md|第十六条]]第五項の規定による定款の定めに従い同項第二号又は第三号に掲げる公告方法によってした場合にあっては、これらの方法による公告）をしたこと並びに異議を述べた債権者があるときは、法[[laws/技術研究組合法施行規則/本文/第64条.md|第六十四条]]第五項の規定により当該債権者に対し弁済し、若しくは相当の担保を提供し、若しくは当該債権者に弁済を受けさせることを目的として相当の財産を信託したこと又は当該組織変更をしても当該債権者を害するおそれがないことを証する書面
- 八 法[[laws/技術研究組合法施行規則/本文/第65条.md|第六十五条]]第一項の規定による株式の割当てが組織変更をする組合の事業に対して組合員がした負担及び寄与の程度を勘案して定められていることを証する書面
- 九 組織変更をする組合の組合員であって法[[laws/技術研究組合法施行規則/本文/第62条.md|第六十二条]]第一項第五号の株式の割当てを受けない者の利益に関する事項が記載された書面
