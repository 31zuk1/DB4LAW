# 第八十一条 （新設分割計画）

## 
法[[laws/336AC0000000081/本文/第110条.md|第百十条]]第六号に規定する主務省令で定める事項は、新設分割設立組合（法[[laws/336AC0000000081/本文/第109条.md|第百九条]]第四項に規定する新設分割設立組合をいう。以下同じ。）の試験研究の実施計画又はその要旨とする。
