# 第二十三条 （地方財政審議会の意見の聴取）

## 
総務大臣は、次に掲げる場合には、地方財政審議会の意見を聴かなければならない。交付税の交付に関する命令の制定又は改廃の立案をしようとするとき。[[laws/325AC0000000211/本文/第7条.md|第七条]]に規定する翌年度の地方団体の歳入歳出総額の見込額に関する書類の原案を作成しようとするとき。[[laws/325AC0000000211/本文/第10条.md|第十条]]又は[[laws/325AC0000000211/本文/第15条.md|第十五条]]の規定により各地方団体に交付すべき交付税の額を決定し、又は変更しようとするとき。[[laws/325AC0000000211/本文/第18条.md|第十八条]]第二項の規定により地方団体の審査の申立てについて決定をしようとするとき。[[laws/325AC0000000211/本文/第19条.md|第十九条]]第四項の規定により交付税を返還させようとするとき。[[laws/325AC0000000211/本文/第19条.md|第十九条]]第八項（[[laws/325AC0000000211/本文/第20条の2.md|第二十条の二]]第四項において準用する場合を含む。）の規定により地方団体の異議の申出について決定をしようとするとき。[[laws/325AC0000000211/本文/第20条.md|第二十条]]第三項の規定により同条第二項に規定する決定又は処分を取り消し、又は変更しようとするとき。[[laws/325AC0000000211/本文/第20条の2.md|第二十条の二]]第四項の規定により交付税を減額し、又は返還させようとするとき。

- 一 交付税の交付に関する命令の制定又は改廃の立案をしようとするとき。
- 二 [[laws/325AC0000000211/本文/第7条.md|第七条]]に規定する翌年度の地方団体の歳入歳出総額の見込額に関する書類の原案を作成しようとするとき。
- 三 [[laws/325AC0000000211/本文/第10条.md|第十条]]又は[[laws/325AC0000000211/本文/第15条.md|第十五条]]の規定により各地方団体に交付すべき交付税の額を決定し、又は変更しようとするとき。
- 四 [[laws/325AC0000000211/本文/第18条.md|第十八条]]第二項の規定により地方団体の審査の申立てについて決定をしようとするとき。
- 五 [[laws/325AC0000000211/本文/第19条.md|第十九条]]第四項の規定により交付税を返還させようとするとき。
- 六 [[laws/325AC0000000211/本文/第19条.md|第十九条]]第八項（[[laws/325AC0000000211/本文/第20条の2.md|第二十条の二]]第四項において準用する場合を含む。）の規定により地方団体の異議の申出について決定をしようとするとき。
- 七 [[laws/325AC0000000211/本文/第20条.md|第二十条]]第三項の規定により同条第二項に規定する決定又は処分を取り消し、又は変更しようとするとき。
- 八 [[laws/325AC0000000211/本文/第20条の2.md|第二十条の二]]第四項の規定により交付税を減額し、又は返還させようとするとき。
