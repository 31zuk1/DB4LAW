# 第二十七条 （登録の取消し等）

## 
文部科学大臣は、登録施設利用促進機関が次の各号のいずれかに該当するときは、その登録を取り消し、又は期間を定めて利用促進業務の全部若しくは一部の停止を命ずることができる。[[laws/特定先端大型研究施設の共用の促進に関する法律/本文/第10条.md|第十条]]第一号又は第三号に該当するに至ったとき。[[laws/特定先端大型研究施設の共用の促進に関する法律/本文/第11条.md|第十一条]]第三項、[[laws/特定先端大型研究施設の共用の促進に関する法律/本文/第12条.md|第十二条]]、[[laws/特定先端大型研究施設の共用の促進に関する法律/本文/第18条.md|第十八条]]、[[laws/特定先端大型研究施設の共用の促進に関する法律/本文/第19条.md|第十九条]]第一項、[[laws/特定先端大型研究施設の共用の促進に関する法律/本文/第20条.md|第二十条]]又は[[laws/特定先端大型研究施設の共用の促進に関する法律/本文/第22条.md|第二十二条]]の規定に違反したとき。[[laws/特定先端大型研究施設の共用の促進に関する法律/本文/第17条.md|第十七条]]第一項の認可を受けた業務規程によらないで利用促進業務を行ったとき。[[laws/特定先端大型研究施設の共用の促進に関する法律/本文/第17条.md|第十七条]]第二項又は前二条の規定による命令に違反したとき。正当な理由がないのに[[laws/特定先端大型研究施設の共用の促進に関する法律/本文/第19条.md|第十九条]]第二項各号の規定による請求を拒んだとき。不正の手段により登録を受けたとき。

- 一 [[laws/特定先端大型研究施設の共用の促進に関する法律/本文/第10条.md|第十条]]第一号又は第三号に該当するに至ったとき。
- 二 [[laws/特定先端大型研究施設の共用の促進に関する法律/本文/第11条.md|第十一条]]第三項、[[laws/特定先端大型研究施設の共用の促進に関する法律/本文/第12条.md|第十二条]]、[[laws/特定先端大型研究施設の共用の促進に関する法律/本文/第18条.md|第十八条]]、[[laws/特定先端大型研究施設の共用の促進に関する法律/本文/第19条.md|第十九条]]第一項、[[laws/特定先端大型研究施設の共用の促進に関する法律/本文/第20条.md|第二十条]]又は[[laws/特定先端大型研究施設の共用の促進に関する法律/本文/第22条.md|第二十二条]]の規定に違反したとき。
- 三 [[laws/特定先端大型研究施設の共用の促進に関する法律/本文/第17条.md|第十七条]]第一項の認可を受けた業務規程によらないで利用促進業務を行ったとき。
- 四 [[laws/特定先端大型研究施設の共用の促進に関する法律/本文/第17条.md|第十七条]]第二項又は前二条の規定による命令に違反したとき。
- 五 正当な理由がないのに[[laws/特定先端大型研究施設の共用の促進に関する法律/本文/第19条.md|第十九条]]第二項各号の規定による請求を拒んだとき。
- 六 不正の手段により登録を受けたとき。
