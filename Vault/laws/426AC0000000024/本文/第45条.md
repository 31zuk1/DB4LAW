# 第四十五条 

## 
次の各号のいずれかに該当する場合には、その違反行為をした機構の取締役、会計参与若しくはその職務を行うべき社員又は監査役は、百万円以下の過料に処する。[[laws/株式会社海外交通・都市開発事業支援機構法/本文/第5条.md|第五条]]第一項の規定に違反して、募集株式、募集新株予約権若しくは募集社債を引き受ける者の募集をし、株式交換若しくは株式交付に際して株式、社債若しくは新株予約権を発行し、又は資金を借り入れたとき。[[laws/株式会社海外交通・都市開発事業支援機構法/本文/第5条.md|第五条]]第二項の規定に違反して、株式を発行した旨の届出を行わなかったとき。[[laws/株式会社海外交通・都市開発事業支援機構法/本文/第21条.md|第二十一条]]第一項又は第四項の規定に違反して、登記することを怠ったとき。[[laws/株式会社海外交通・都市開発事業支援機構法/本文/第23条.md|第二十三条]]第二項の規定に違反して、業務を行ったとき。[[laws/株式会社海外交通・都市開発事業支援機構法/本文/第25条.md|第二十五条]]第二項又は[[laws/株式会社海外交通・都市開発事業支援機構法/本文/第27条.md|第二十七条]]の規定に違反して、決定を行ったとき。[[laws/株式会社海外交通・都市開発事業支援機構法/本文/第30条.md|第三十条]]第一項の規定に違反して、予算の認可を受けなかったとき。[[laws/株式会社海外交通・都市開発事業支援機構法/本文/第32条.md|第三十二条]]の規定に違反して、貸借対照表、損益計算書若しくは事業報告書を提出せず、又は虚偽の記載若しくは記録をしたこれらのものを提出したとき。[[laws/株式会社海外交通・都市開発事業支援機構法/本文/第34条.md|第三十四条]]第二項の規定による命令に違反したとき。

- 一 [[laws/株式会社海外交通・都市開発事業支援機構法/本文/第5条.md|第五条]]第一項の規定に違反して、募集株式、募集新株予約権若しくは募集社債を引き受ける者の募集をし、株式交換若しくは株式交付に際して株式、社債若しくは新株予約権を発行し、又は資金を借り入れたとき。
- 二 [[laws/株式会社海外交通・都市開発事業支援機構法/本文/第5条.md|第五条]]第二項の規定に違反して、株式を発行した旨の届出を行わなかったとき。
- 三 [[laws/株式会社海外交通・都市開発事業支援機構法/本文/第21条.md|第二十一条]]第一項又は第四項の規定に違反して、登記することを怠ったとき。
- 四 [[laws/株式会社海外交通・都市開発事業支援機構法/本文/第23条.md|第二十三条]]第二項の規定に違反して、業務を行ったとき。
- 五 [[laws/株式会社海外交通・都市開発事業支援機構法/本文/第25条.md|第二十五条]]第二項又は[[laws/株式会社海外交通・都市開発事業支援機構法/本文/第27条.md|第二十七条]]の規定に違反して、決定を行ったとき。
- 六 [[laws/株式会社海外交通・都市開発事業支援機構法/本文/第30条.md|第三十条]]第一項の規定に違反して、予算の認可を受けなかったとき。
- 七 [[laws/株式会社海外交通・都市開発事業支援機構法/本文/第32条.md|第三十二条]]の規定に違反して、貸借対照表、損益計算書若しくは事業報告書を提出せず、又は虚偽の記載若しくは記録をしたこれらのものを提出したとき。
- 八 [[laws/株式会社海外交通・都市開発事業支援機構法/本文/第34条.md|第三十四条]]第二項の規定による命令に違反したとき。
