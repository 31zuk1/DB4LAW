# 第四十一条 （都道府県知事等及び法第五十七条第二項本文の規定による届出の相手方として公告された者の公告事項）

## 
法[[laws/都市計画法施行規則/本文/第57条.md|第五十七条]]第一項の規定により都道府県知事等（法[[laws/都市計画法施行規則/本文/第55条.md|第五十五条]]第四項の規定により法[[laws/都市計画法施行規則/本文/第57条.md|第五十七条]]第二項本文の規定による届出の相手方として公告された者があるときは、その者）の公告すべき事項は、次に掲げるものとする。市街地開発事業又は法[[laws/都市計画法施行規則/本文/第55条.md|第五十五条]]第一項の規定による指定に係る都市計画施設の種類及び名称法[[laws/都市計画法施行規則/本文/第57条.md|第五十七条]]第二項本文の規定による届出の相手方の氏名及び住所届出をすべき土地の所在

- 一 市街地開発事業又は法[[laws/都市計画法施行規則/本文/第55条.md|第五十五条]]第一項の規定による指定に係る都市計画施設の種類及び名称
- 二 法[[laws/都市計画法施行規則/本文/第57条.md|第五十七条]]第二項本文の規定による届出の相手方の氏名及び住所
- 三 届出をすべき土地の所在
