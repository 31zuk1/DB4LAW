# 第七十三条 （国土交通大臣による通知等）

## 
法[[laws/住宅の品質確保の促進等に関する法律施行規則/本文/第53条.md|第五十三条]]第二項の規定により国土交通大臣が行う通知及び公示は、次に掲げる事項について行うものとする。住宅型式性能認定書の交付を受けた者の氏名又は名称及び住所住宅型式性能認定を受けた型式に係る住宅又はその部分の種類当該型式に係る性能表示事項当該型式が住宅に係るものである場合にあっては、当該型式の性能当該型式の認定番号当該型式を認定した登録住宅型式性能認定等機関の名称

- 一 住宅型式性能認定書の交付を受けた者の氏名又は名称及び住所
- 二 住宅型式性能認定を受けた型式に係る住宅又はその部分の種類
- 三 当該型式に係る性能表示事項
- 四 当該型式が住宅に係るものである場合にあっては、当該型式の性能
- 五 当該型式の認定番号
- 六 当該型式を認定した登録住宅型式性能認定等機関の名称
