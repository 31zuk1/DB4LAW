# 第三十八条 （発行保証金信託契約の全部の解除）

## 
前払式支払手段発行者は、発行保証金信託契約の全部を解除しようとするときは、別紙様式第十六号により作成した発行保証金信託契約全部解除届出書を金融庁長官に提出するものとする。
