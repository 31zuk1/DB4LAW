# 第八十一条 （適用）

## 
この節の規定は、タンカー（その貨物艙そうがばら積みの引火性を有する液体貨物（以下この節において「貨物」という。）の輸送のための構造を有する船舶（危険物船舶運送及び貯蔵規則[[laws/船舶機関規則/本文/第142条.md|第百四十二条]]の液化ガスばら積船（[[laws/船舶機関規則/本文/第100条の2.md|第百条の二]]において「液化ガスばら積船」という。）に該当する船舶及び同令[[laws/船舶機関規則/本文/第257条.md|第二百五十七条]]の液体化学薬品ばら積船（同令[[laws/船舶機関規則/本文/第257条の2.md|第二百五十七条の二]]に規定する船舶を除く。）に該当する船舶を除く。）をいう。）に適用する。
