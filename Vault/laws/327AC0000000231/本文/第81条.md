# 第八十一条 （最低安全高度）

## 
航空機は、離陸又は着陸を行う場合を除いて、地上又は水上の人又は物件の安全及び航空機の安全を考慮して国土交通省令で定める高度以下の高度で飛行してはならない。但し、国土交通大臣の許可を受けた場合は、この限りでない。
