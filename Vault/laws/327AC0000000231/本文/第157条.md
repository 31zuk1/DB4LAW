# 第百五十七条 

## 
本邦航空運送事業者又は航空機使用事業者が次の各号のいずれかに該当するときは、その違反行為をした者は、百万円以下の罰金に処する。[[laws/航空法/本文/第103条の2.md|第百三条の二]]第一項の規定による届出をしないで、又は届出をした安全管理規程（同条第二項第二号及び第三号に係る部分に限る。）によらないで、事業を行つたとき。[[laws/航空法/本文/第103条の2.md|第百三条の二]]第三項若しくは第七項、[[laws/航空法/本文/第108条.md|第百八条]]第二項若しくは[[laws/航空法/本文/第112条.md|第百十二条]]（これらの規定を[[laws/航空法/本文/第124条.md|第百二十四条]]において準用する場合を含む。）又は[[laws/航空法/本文/第111条の2.md|第百十一条の二]]の規定による命令に違反したとき（前条第一項第二号に該当する場合を除く。）。[[laws/航空法/本文/第103条の2.md|第百三条の二]]第四項の規定に違反して、安全統括管理者を選任しなかつたとき。[[laws/航空法/本文/第103条の2.md|第百三条の二]]第五項の規定による届出をせず、又は虚偽の届出をしたとき。[[laws/航空法/本文/第104条.md|第百四条]]第一項の規定による認可を受けないで、又は認可を受けた運航規程若しくは整備規程によらないで、航空機を運航し、又は整備したとき。[[laws/航空法/本文/第104条.md|第百四条]]第三項の規定による届出をしないで、又は届出をした運航規程若しくは整備規程によらないで、航空機を運航し、又は整備したとき。[[laws/航空法/本文/第105条.md|第百五条]]第一項の規定による届出をしないで、又は届出をした運賃若しくは料金によらないで、運賃又は料金を収受したとき。[[laws/航空法/本文/第105条.md|第百五条]]第二項の規定による命令に違反して、運賃又は料金を収受したとき。[[laws/航空法/本文/第105条.md|第百五条]]第三項の規定による認可を受けないで、又は認可を受けた運賃若しくは料金によらないで、運賃又は料金を収受したとき。[[laws/航空法/本文/第106条.md|第百六条]]第一項の規定による認可を受けないで、又は認可を受けた運送約款によらないで、運送契約を締結したとき。[[laws/航空法/本文/第107条の2.md|第百七条の二]]第一項の規定による届出をしないで、国内定期航空運送事業を経営したとき。[[laws/航空法/本文/第107条の2.md|第百七条の二]]第二項又は第三項の規定による届出をしないで、運航計画を変更したとき。[[laws/航空法/本文/第107条の2.md|第百七条の二]]第四項又は[[laws/航空法/本文/第107条の3.md|第百七条の三]]第八項の規定による届出をしないで、又は虚偽の届出をして、国内定期航空運送事業を廃止したとき。[[laws/航空法/本文/第107条の3.md|第百七条の三]]第一項の規定による許可を受けないで、混雑空港を使用して運航を行つたとき。[[laws/航空法/本文/第107条の3.md|第百七条の三]]第六項の規定による認可を受けないで、運航計画を変更したとき。[[laws/航空法/本文/第109条.md|第百九条]]第一項（[[laws/航空法/本文/第124条.md|第百二十四条]]において準用する場合を含む。）の規定による認可を受けないで、事業計画を変更したとき。[[laws/航空法/本文/第109条.md|第百九条]]第三項（[[laws/航空法/本文/第124条.md|第百二十四条]]において準用する場合を含む。）の規定による届出をしないで、事業計画を変更したとき。[[laws/航空法/本文/第111条.md|第百十一条]]第一項の規定による認可を受けないで、協定を締結し、又はその内容を変更したとき。

- 一 [[laws/航空法/本文/第103条の2.md|第百三条の二]]第一項の規定による届出をしないで、又は届出をした安全管理規程（同条第二項第二号及び第三号に係る部分に限る。）によらないで、事業を行つたとき。
- 二 [[laws/航空法/本文/第103条の2.md|第百三条の二]]第三項若しくは第七項、[[laws/航空法/本文/第108条.md|第百八条]]第二項若しくは[[laws/航空法/本文/第112条.md|第百十二条]]（これらの規定を[[laws/航空法/本文/第124条.md|第百二十四条]]において準用する場合を含む。）又は[[laws/航空法/本文/第111条の2.md|第百十一条の二]]の規定による命令に違反したとき（前条第一項第二号に該当する場合を除く。）。
- 三 [[laws/航空法/本文/第103条の2.md|第百三条の二]]第四項の規定に違反して、安全統括管理者を選任しなかつたとき。
- 四 [[laws/航空法/本文/第103条の2.md|第百三条の二]]第五項の規定による届出をせず、又は虚偽の届出をしたとき。
- 五 [[laws/航空法/本文/第104条.md|第百四条]]第一項の規定による認可を受けないで、又は認可を受けた運航規程若しくは整備規程によらないで、航空機を運航し、又は整備したとき。
- 五の二 [[laws/航空法/本文/第104条.md|第百四条]]第三項の規定による届出をしないで、又は届出をした運航規程若しくは整備規程によらないで、航空機を運航し、又は整備したとき。
- 六 [[laws/航空法/本文/第105条.md|第百五条]]第一項の規定による届出をしないで、又は届出をした運賃若しくは料金によらないで、運賃又は料金を収受したとき。
- 七 [[laws/航空法/本文/第105条.md|第百五条]]第二項の規定による命令に違反して、運賃又は料金を収受したとき。
- 八 [[laws/航空法/本文/第105条.md|第百五条]]第三項の規定による認可を受けないで、又は認可を受けた運賃若しくは料金によらないで、運賃又は料金を収受したとき。
- 九 [[laws/航空法/本文/第106条.md|第百六条]]第一項の規定による認可を受けないで、又は認可を受けた運送約款によらないで、運送契約を締結したとき。
- 十 [[laws/航空法/本文/第107条の2.md|第百七条の二]]第一項の規定による届出をしないで、国内定期航空運送事業を経営したとき。
- 十一 [[laws/航空法/本文/第107条の2.md|第百七条の二]]第二項又は第三項の規定による届出をしないで、運航計画を変更したとき。
- 十二 [[laws/航空法/本文/第107条の2.md|第百七条の二]]第四項又は[[laws/航空法/本文/第107条の3.md|第百七条の三]]第八項の規定による届出をしないで、又は虚偽の届出をして、国内定期航空運送事業を廃止したとき。
- 十三 [[laws/航空法/本文/第107条の3.md|第百七条の三]]第一項の規定による許可を受けないで、混雑空港を使用して運航を行つたとき。
- 十四 [[laws/航空法/本文/第107条の3.md|第百七条の三]]第六項の規定による認可を受けないで、運航計画を変更したとき。
- 十五 [[laws/航空法/本文/第109条.md|第百九条]]第一項（[[laws/航空法/本文/第124条.md|第百二十四条]]において準用する場合を含む。）の規定による認可を受けないで、事業計画を変更したとき。
- 十六 [[laws/航空法/本文/第109条.md|第百九条]]第三項（[[laws/航空法/本文/第124条.md|第百二十四条]]において準用する場合を含む。）の規定による届出をしないで、事業計画を変更したとき。
- 十七 [[laws/航空法/本文/第111条.md|第百十一条]]第一項の規定による認可を受けないで、協定を締結し、又はその内容を変更したとき。
## ２
[[laws/航空法/本文/第113条の2.md|第百十三条の二]]第一項の許可を受けた受託者が同条第三項の規定による命令に違反したときは、その違反行為をした者は、百万円以下の罰金に処する。
