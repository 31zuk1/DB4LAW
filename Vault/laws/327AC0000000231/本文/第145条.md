# 第百四十五条 （所定の航空従事者を乗り組ませない等の罪）

## 
航空機の使用者が次の各号のいずれかに該当するときは、その違反行為をした者は、百万円以下の罰金に処する。[[laws/327AC0000000231/本文/第14条の3.md|第十四条の三]]第一項の規定による命令に違反したとき。[[laws/327AC0000000231/本文/第58条.md|第五十八条]]第一項の規定に違反して、航空日誌を備えなかつたとき。[[laws/327AC0000000231/本文/第58条.md|第五十八条]]第二項の規定により航空日誌に記載すべき事項を記載せず、又は虚偽の記載をしたとき。[[laws/327AC0000000231/本文/第59条.md|第五十九条]]の規定に違反して、所定の書類を備え付けないで、航空機を航空の用に供したとき。[[laws/327AC0000000231/本文/第60条.md|第六十条]]の規定に違反して、航空機の航行の安全を確保するために必要な装置を装備しないで、航空機を航空の用に供したとき。[[laws/327AC0000000231/本文/第61条.md|第六十一条]]第一項の規定に違反して、航空機の運航の状況を記録するための装置を装備しないで、又はこれを作動させないで、航空機を航空の用に供したとき。[[laws/327AC0000000231/本文/第61条.md|第六十一条]]第二項の規定に違反して、航空機の運航の状況を記録するための装置による記録を保存しなかつたとき。[[laws/327AC0000000231/本文/第62条.md|第六十二条]]の規定に違反して、救急用具を装備しないで、航空機を航空の用に供したとき。[[laws/327AC0000000231/本文/第63条.md|第六十三条]]の規定に違反して、所定の燃料を携行させないで、航空機を出発させたとき。[[laws/327AC0000000231/本文/第64条.md|第六十四条]]の規定に違反して、航空機を灯火で表示しなかつたとき。[[laws/327AC0000000231/本文/第65条.md|第六十五条]]第一項若しくは第二項又は[[laws/327AC0000000231/本文/第66条.md|第六十六条]]第一項の規定に違反して、航空機に所定の航空従事者を乗り組ませなかつたとき。[[laws/327AC0000000231/本文/第68条.md|第六十八条]]の規定に違反して、航空従事者を航空業務に従事させたとき。[[laws/327AC0000000231/本文/第76条.md|第七十六条]]第一項ただし書の規定による報告をせず、又は虚偽の報告をしたとき。[[laws/327AC0000000231/本文/第83条の2.md|第八十三条の二]]の規定に違反して、同条の特別な方式による航行を行つたとき。[[laws/327AC0000000231/本文/第86条.md|第八十六条]]第一項の規定に違反して、同項の物件を航空機で輸送したとき。[[laws/327AC0000000231/本文/第87条.md|第八十七条]]第二項の規定による飛行の方法の限定に違反して、航空機を飛行させたとき。[[laws/327AC0000000231/本文/第88条.md|第八十八条]]の規定に違反して、航空機に物件のえい航をさせたとき。[[laws/327AC0000000231/本文/第127条.md|第百二十七条]]の規定に違反して、航空機を本邦内の各地間において航空の用に供したとき。[[laws/327AC0000000231/本文/第128条.md|第百二十八条]]の規定に違反して、同条の軍需品を輸送したとき。

- 一 [[laws/327AC0000000231/本文/第14条の3.md|第十四条の三]]第一項の規定による命令に違反したとき。
- 二 [[laws/327AC0000000231/本文/第58条.md|第五十八条]]第一項の規定に違反して、航空日誌を備えなかつたとき。
- 三 [[laws/327AC0000000231/本文/第58条.md|第五十八条]]第二項の規定により航空日誌に記載すべき事項を記載せず、又は虚偽の記載をしたとき。
- 四 [[laws/327AC0000000231/本文/第59条.md|第五十九条]]の規定に違反して、所定の書類を備え付けないで、航空機を航空の用に供したとき。
- 五 [[laws/327AC0000000231/本文/第60条.md|第六十条]]の規定に違反して、航空機の航行の安全を確保するために必要な装置を装備しないで、航空機を航空の用に供したとき。
- 六 [[laws/327AC0000000231/本文/第61条.md|第六十一条]]第一項の規定に違反して、航空機の運航の状況を記録するための装置を装備しないで、又はこれを作動させないで、航空機を航空の用に供したとき。
- 六の二 [[laws/327AC0000000231/本文/第61条.md|第六十一条]]第二項の規定に違反して、航空機の運航の状況を記録するための装置による記録を保存しなかつたとき。
- 七 [[laws/327AC0000000231/本文/第62条.md|第六十二条]]の規定に違反して、救急用具を装備しないで、航空機を航空の用に供したとき。
- 八 [[laws/327AC0000000231/本文/第63条.md|第六十三条]]の規定に違反して、所定の燃料を携行させないで、航空機を出発させたとき。
- 九 [[laws/327AC0000000231/本文/第64条.md|第六十四条]]の規定に違反して、航空機を灯火で表示しなかつたとき。
- 十 [[laws/327AC0000000231/本文/第65条.md|第六十五条]]第一項若しくは第二項又は[[laws/327AC0000000231/本文/第66条.md|第六十六条]]第一項の規定に違反して、航空機に所定の航空従事者を乗り組ませなかつたとき。
- 十一 [[laws/327AC0000000231/本文/第68条.md|第六十八条]]の規定に違反して、航空従事者を航空業務に従事させたとき。
- 十二 [[laws/327AC0000000231/本文/第76条.md|第七十六条]]第一項ただし書の規定による報告をせず、又は虚偽の報告をしたとき。
