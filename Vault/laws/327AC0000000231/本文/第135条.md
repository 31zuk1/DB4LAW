# 第百三十五条 （手数料の納付）

## 
次に掲げる者（国及び独立行政法人（独立行政法人通則法（平成十一年法律第百三号）第二条第一項に規定する独立行政法人であつて当該独立行政法人の業務の内容その他の事情を勘案して政令で定めるものに限る。）を除く。）は、実費を勘案して政令で定める額の手数料を国（指定試験機関が試験事務を行う場合にあつては、指定試験機関）に納めなければならない。航空機登録原簿の謄本若しくは抄本の交付又は航空機登録原簿の閲覧を請求する者[[laws/327AC0000000231/本文/第10条.md|第十条]]第一項の耐空証明を申請する者[[laws/327AC0000000231/本文/第12条.md|第十二条]]第一項の型式証明を申請する者[[laws/327AC0000000231/本文/第13条.md|第十三条]]第一項、[[laws/327AC0000000231/本文/第13条の2.md|第十三条の二]]第一項若しくは第三項又は[[laws/327AC0000000231/本文/第18条.md|第十八条]]第一項若しくは第三項の承認を申請する者[[laws/327AC0000000231/本文/第17条.md|第十七条]]第一項の修理改造検査を受けようとする者[[laws/327AC0000000231/本文/第20条.md|第二十条]]第一項の認定を申請する者[[laws/327AC0000000231/本文/第22条.md|第二十二条]]の航空従事者技能証明を申請する者[[laws/327AC0000000231/本文/第29条の2.md|第二十九条の二]]第一項の航空従事者技能証明についての限定の変更を申請する者国土交通大臣が行う[[laws/327AC0000000231/本文/第31条.md|第三十一条]]第一項の航空身体検査証明を申請する者[[laws/327AC0000000231/本文/第33条.md|第三十三条]]第一項の航空英語能力証明を申請する者[[laws/327AC0000000231/本文/第34条.md|第三十四条]]第一項の計器飛行証明又は同条第二項の操縦教育証明を申請する者[[laws/327AC0000000231/本文/第35条.md|第三十五条]]第一項第一号の航空機の操縦の練習の許可を受けようとする者航空機登録証明書、耐空証明書、航空従事者技能証明書、航空身体検査証明書又は航空機操縦練習許可書の再交付を申請する者[[laws/327AC0000000231/本文/第38条.md|第三十八条]]第一項の空港等又は航空保安施設の設置の許可を申請する者空港等について[[laws/327AC0000000231/本文/第42条.md|第四十二条]]第一項の完成検査を受けようとする者航空保安施設について[[laws/327AC0000000231/本文/第42条.md|第四十二条]]第一項の完成検査を受けようとする者空港等について[[laws/327AC0000000231/本文/第43条.md|第四十三条]]第二項において準用する[[laws/327AC0000000231/本文/第42条.md|第四十二条]]第一項の検査を受けようとする者航空保安施設について[[laws/327AC0000000231/本文/第43条.md|第四十三条]]第二項において準用する[[laws/327AC0000000231/本文/第42条.md|第四十二条]]第一項の検査を受けようとする者空港等について[[laws/327AC0000000231/本文/第44条.md|第四十四条]]第四項（[[laws/327AC0000000231/本文/第45条.md|第四十五条]]第二項において準用する場合を含む。）の検査を受けようとする者航空保安施設について[[laws/327AC0000000231/本文/第45条.md|第四十五条]]第二項において準用する[[laws/327AC0000000231/本文/第44条.md|第四十四条]]第四項の検査を受けようとする者空港等について[[laws/327AC0000000231/本文/第47条.md|第四十七条]]第三項の検査を受ける者航空保安施設について[[laws/327AC0000000231/本文/第47条.md|第四十七条]]第三項の検査を受ける者[[laws/327AC0000000231/本文/第71条の5.md|第七十一条の五]]第一項に規定する技能発揮訓練のうち国土交通大臣が行うものを受けようとする者[[laws/327AC0000000231/本文/第78条.md|第七十八条]]第二項の運航管理者技能検定を受けようとする者[[laws/327AC0000000231/ - 一 航空機登録原簿の謄本若しくは抄本の交付又は航空機登録原簿の閲覧を請求する者
- 二 [[laws/327AC0000000231/本文/第10条.md|第十条]]第一項の耐空証明を申請する者
- 三 [[laws/327AC0000000231/本文/第12条.md|第十二条]]第一項の型式証明を申請する者

- 五 [[laws/327AC0000000231/本文/第17条.md|第十七条]]第一項の修理改造検査を受けようとする者
- 六 [[laws/327AC0000000231/本文/第20条.md|第二十条]]第一項の認定を申請する者
- 七 [[laws/327AC0000000231/本文/第22条.md|第二十二条]]の航空従事者技能証明を申請する者

- 九 国土交通大臣が行う[[laws/327AC0000000231/本文/第31条.md|第三十一条]]第一項の航空身体検査証明を申請する者
- 九の二 [[laws/327AC0000000231/本文/第33条.md|第三十三条]]第一項の航空英語能力証明を申請する者
- 十 [[laws/327AC0000000231/本文/第34条.md|第三十四条]]第一項の計器飛行証明又は同条第二項の操縦教育証明を申請する者
- 十一 [[laws/327AC0000000231/本文/第35条.md|第三十五条]]第一項第一号の航空機の操縦の練習の許可を受けようとする者
- 十二 航空機登録証明書、耐空証明書、航空従事者技能証明書、航空身体検査証明書又は航空機操縦練習許可書の再交付を申請する者
- 十三 [[laws/327AC0000000231/本文/第38条.md|第三十八条]]第一項の空港等又は航空保安施設の設置の許可を申請する者
- 十四 空港等について[[laws/327AC0000000231/本文/第42条.md|第四十二条]]第一項の完成検査を受けようとする者
- 十五 航空保安施設について[[laws/327AC0000000231/本文/第42条.md|第四十二条]]第一項の完成検査を受けようとする者
- 十六 空港等について[[laws/327AC0000000231/本文/第43条.md|第四十三条]]第二項において準用する[[laws/327AC0000000231/本文/第42条.md|第四十二条]]第一項の検査を受けようとする者
- 十七 航空保安施設について[[laws/327AC0000000231/本文/第43条.md|第四十三条]]第二項において準用する[[laws/327AC0000000231/本文/第42条.md|第四十二条]]第一項の検査を受けようとする者
- 十八 空港等について[[laws/327AC0000000231/本文/第44条.md|第四十四条]]第四項（[[laws/327AC0000000231/本文/第45条.md|第四十五条]]第二項において準用する場合を含む。）の検査を受けようとする者
- 十九 航空保安施設について[[laws/327AC0000000231/本文/第45条.md|第四十五条]]第二項において準用する[[laws/327AC0000000231/本文/第44条.md|第四十四条]]第四項の検査を受けようとする者
- 二十 空港等について[[laws/327AC0000000231/本文/第47条.md|第四十七条]]第三項の検査を受ける者
- 二十一 航空保安施設について[[laws/327AC0000000231/本文/第47条.md|第四十七条]]第三項の検査を受ける者
- 二十一の二 [[laws/327AC0000000231/本文/第71条の5.md|第七十一条の五]]第一項に規定する技能発揮訓練のうち国土交通大臣が行うものを受けようとする者
- 二十二 [[laws/327AC0000000231/本文/第78条.md|第七十八条]]第二項の運航管理者技能検定を受けようとする者
- 二十三 [[laws/327AC0000000231/本文/第132条の4.md|第百三十二条の四]]第一項の登録を申請する者
- 二十四 [[laws/327AC0000000231/本文/第132条の6.md|第百三十二条の六]]第一項の登録の更新を申請する者
- 二十五 [[laws/327AC0000000231/本文/第132条の13.md|第百三十二条の十三]]第一項の機体認証（国土交通大臣が検査を行う場合に限る。）を申請する者
- 二十六 機体認証書又は型式認証書の再交付を申請する者
- 二十七 [[laws/327AC0000000231/本文/第132条の16.md|第百三十二条の十六]]第一項の型式認証（国土交通大臣が検査を行う場合に限る。）を申請する者
- 二十八 [[laws/327AC0000000231/本文/第132条の17.md|第百三十二条の十七]]第一項の承認（国土交通大臣が検査を行う場合に限る。）を申請する者
- 二十九 [[laws/327AC0000000231/本文/第132条の40.md|第百三十二条の四十]]の無人航空機操縦者技能証明を申請する者
- 三十 無人航空機操縦者技能証明書の再交付を申請する者
- 三十一 [[laws/327AC0000000231/本文/第132条の51.md|第百三十二条の五十一]]第二項の無人航空機操縦者技能証明の有効期間の更新を申請する者
- 三十二 [[laws/327AC0000000231/本文/第132条の51.md|第百三十二条の五十一]]第三項の規定による無人航空機操縦者技能証明の有効期間の更新のための講習（国土交通大臣が行うものに限る。）を受ける者
- 三十三 [[laws/327AC0000000231/本文/第132条の52.md|第百三十二条の五十二]]第一項の無人航空機操縦者技能証明についての限定の変更を申請する者
