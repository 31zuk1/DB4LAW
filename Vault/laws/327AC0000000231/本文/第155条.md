# 第百五十五条 （航空運送事業者等の業務に関する罪）

## 
次の各号のいずれかに該当するときは、その違反行為をした者は、三年以下の拘禁刑若しくは三百万円以下の罰金に処し、又はこれを併科する。[[laws/327AC0000000231/本文/第100条.md|第百条]]第一項又は[[laws/327AC0000000231/本文/第123条.md|第百二十三条]]第一項の規定による許可を受けてしなければならない事項を許可を受けないでしたとき。[[laws/327AC0000000231/本文/第113条.md|第百十三条]]第一項（[[laws/327AC0000000231/本文/第124条.md|第百二十四条]]において準用する場合を含む。）の規定に違反して、その名義を他人に利用させたとき。[[laws/327AC0000000231/本文/第113条.md|第百十三条]]第二項（[[laws/327AC0000000231/本文/第124条.md|第百二十四条]]において準用する場合を含む。）の規定に違反して、その事業を他人にその名において経営させたとき。[[laws/327AC0000000231/本文/第129条.md|第百二十九条]]第一項の規定により許可を受けてしなければならない事項を許可を受けないでしたとき。[[laws/327AC0000000231/本文/第130条.md|第百三十条]]の規定に違反して、同条の航空機を運送の用に供したとき。[[laws/327AC0000000231/本文/第130条の2.md|第百三十条の二]]の規定により許可を受けてしなければならない事項を許可を受けないでしたとき。

- 一 [[laws/327AC0000000231/本文/第100条.md|第百条]]第一項又は[[laws/327AC0000000231/本文/第123条.md|第百二十三条]]第一項の規定による許可を受けてしなければならない事項を許可を受けないでしたとき。
- 二 [[laws/327AC0000000231/本文/第113条.md|第百十三条]]第一項（[[laws/327AC0000000231/本文/第124条.md|第百二十四条]]において準用する場合を含む。）の規定に違反して、その名義を他人に利用させたとき。
- 三 [[laws/327AC0000000231/本文/第113条.md|第百十三条]]第二項（[[laws/327AC0000000231/本文/第124条.md|第百二十四条]]において準用する場合を含む。）の規定に違反して、その事業を他人にその名において経営させたとき。
- 四 [[laws/327AC0000000231/本文/第129条.md|第百二十九条]]第一項の規定により許可を受けてしなければならない事項を許可を受けないでしたとき。
- 五 [[laws/327AC0000000231/本文/第130条.md|第百三十条]]の規定に違反して、同条の航空機を運送の用に供したとき。
- 六 [[laws/327AC0000000231/本文/第130条の2.md|第百三十条の二]]の規定により許可を受けてしなければならない事項を許可を受けないでしたとき。
