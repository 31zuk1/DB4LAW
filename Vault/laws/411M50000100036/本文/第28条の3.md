# 第二十八条の三 

## 
要介護被保険者又は居宅要支援被保険者は、法[[laws/介護保険法施行規則/本文/第41条.md|第四十一条]]第三項（法[[laws/介護保険法施行規則/本文/第42条の2.md|第四十二条の二]]第九項、法[[laws/介護保険法施行規則/本文/第48条.md|第四十八条]]第七項、法[[laws/介護保険法施行規則/本文/第53条.md|第五十三条]]第七項及び法[[laws/介護保険法施行規則/本文/第54条の2.md|第五十四条の二]]第九項において準用する場合を含む。）の規定により指定居宅サービス事業者（法[[laws/介護保険法施行規則/本文/第41条.md|第四十一条]]第一項に規定する指定居宅サービス事業者をいう。以下同じ。）、指定地域密着型サービス事業者（法[[laws/介護保険法施行規則/本文/第42条の2.md|第四十二条の二]]第一項に規定する指定地域密着型サービス事業者をいう。以下同じ。）、介護保険施設（法[[laws/介護保険法施行規則/本文/第8条.md|第八条]]第二十四項に規定する介護保険施設をいう。以下同じ。）、指定介護予防サービス事業者（法[[laws/介護保険法施行規則/本文/第53条.md|第五十三条]]第一項に規定する指定介護予防サービス事業者をいう。以下同じ。）又は指定地域密着型介護予防サービス事業者（法[[laws/介護保険法施行規則/本文/第54条の2.md|第五十四条の二]]第一項に規定する指定地域密着型介護予防サービス事業者をいう。以下同じ。）に被保険者証を提示するときは、負担割合証を添えなければならない。
