# 第百四十条の六十六の三 （地域包括支援センターの事業の内容及び運営に関する情報の公表内容）

## 
法[[laws/409AC0000000123/本文/第115条の46.md|第百十五条の四十六]]第十項に規定する地域包括支援センターの事業の内容及び運営に関する情報の公表は、次の各号に掲げる内容を含むものとする。名称及び所在地法[[laws/409AC0000000123/本文/第115条の47.md|第百十五条の四十七]]第一項の委託を受けた者である場合はその名称営業日及び営業時間担当する区域職員の職種及び員数事業の内容及び活動実績その他市町村が必要と認める事項

- 一 名称及び所在地
- 二 法[[laws/409AC0000000123/本文/第115条の47.md|第百十五条の四十七]]第一項の委託を受けた者である場合はその名称
- 三 営業日及び営業時間
- 四 担当する区域
- 五 職員の職種及び員数
- 六 事業の内容及び活動実績
- 七 その他市町村が必要と認める事項
