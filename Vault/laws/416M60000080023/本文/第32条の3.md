# 第三十二条の三 （学資支給返還金の返還期限の猶予）

## 
機構は、学資支給返還金要返還者が災害又は傷病により学資支給返還金を返還することが困難となったこと、大学、大学院若しくは高等専門学校又は専修学校の専門課程に在学することその他文部科学大臣の認めるやむを得ない事由があるときは、その返還の期限を猶予することができる。
