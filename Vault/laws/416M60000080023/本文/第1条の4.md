# 第一条の四 （業務方法書に記載すべき事項）

## 
機構に係る通則法[[laws/416M60000080023/本文/第28条.md|第二十八条]]第二項の主務省令で定める業務方法書に記載すべき事項は、次のとおりとする。法[[laws/416M60000080023/本文/第13条.md|第十三条]]第一項第一号に規定する学資の貸与及び支給その他必要な援助に関する事項法[[laws/416M60000080023/本文/第13条.md|第十三条]]第一項第二号に規定する学資の支給その他必要な援助に関する事項法[[laws/416M60000080023/本文/第13条.md|第十三条]]第一項第三号に規定する施設の設置及び運営に関する事項法[[laws/416M60000080023/本文/第13条.md|第十三条]]第一項第四号に規定する試験に関する事項法[[laws/416M60000080023/本文/第13条.md|第十三条]]第一項第五号に規定する日本語教育に関する事項法[[laws/416M60000080023/本文/第13条.md|第十三条]]第一項第六号に規定する助成金の支給に関する事項法[[laws/416M60000080023/本文/第13条.md|第十三条]]第一項第七号に規定する催しの実施、情報及び資料の収集、整理及び提供その他留学生交流の推進を図るための事業に関する事項法[[laws/416M60000080023/本文/第13条.md|第十三条]]第一項第八号に規定する研修並びに情報及び資料の収集、整理及び提供に関する事項法[[laws/416M60000080023/本文/第13条.md|第十三条]]第一項第九号に規定する調査及び研究に関する事項法[[laws/416M60000080023/本文/第13条.md|第十三条]]第一項第十号に規定する附帯業務に関する事項法[[laws/416M60000080023/本文/第13条.md|第十三条]]第二項に規定する施設の供用に関する事項業務委託の基準競争入札その他契約に関する基本的事項その他機構の業務の執行に関して必要な事項

- 一 法[[laws/416M60000080023/本文/第13条.md|第十三条]]第一項第一号に規定する学資の貸与及び支給その他必要な援助に関する事項
- 二 法[[laws/416M60000080023/本文/第13条.md|第十三条]]第一項第二号に規定する学資の支給その他必要な援助に関する事項
- 三 法[[laws/416M60000080023/本文/第13条.md|第十三条]]第一項第三号に規定する施設の設置及び運営に関する事項
- 四 法[[laws/416M60000080023/本文/第13条.md|第十三条]]第一項第四号に規定する試験に関する事項
- 五 法[[laws/416M60000080023/本文/第13条.md|第十三条]]第一項第五号に規定する日本語教育に関する事項
- 六 法[[laws/416M60000080023/本文/第13条.md|第十三条]]第一項第六号に規定する助成金の支給に関する事項
- 七 法[[laws/416M60000080023/本文/第13条.md|第十三条]]第一項第七号に規定する催しの実施、情報及び資料の収集、整理及び提供その他留学生交流の推進を図るための事業に関する事項
- 八 法[[laws/416M60000080023/本文/第13条.md|第十三条]]第一項第八号に規定する研修並びに情報及び資料の収集、整理及び提供に関する事項
- 九 法[[laws/416M60000080023/本文/第13条.md|第十三条]]第一項第九号に規定する調査及び研究に関する事項
- 十 法[[laws/416M60000080023/本文/第13条.md|第十三条]]第一項第十号に規定する附帯業務に関する事項
- 十一 法[[laws/416M60000080023/本文/第13条.md|第十三条]]第二項に規定する施設の供用に関する事項
- 十二 業務委託の基準
- 十三 競争入札その他契約に関する基本的事項
- 十四 その他機構の業務の執行に関して必要な事項
