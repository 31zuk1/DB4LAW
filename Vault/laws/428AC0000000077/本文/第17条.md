# 第十七条 （許可の取消し等）

## 
内閣総理大臣は、衛星リモートセンシング装置使用者が次の各号のいずれかに該当するときは、[[laws/428AC0000000077/本文/第4条.md|第四条]]第一項の許可を取り消し、又は一年以内の期間を定めて当該衛星リモートセンシング装置の使用の停止を命ずることができる。偽りその他不正の手段により[[laws/428AC0000000077/本文/第4条.md|第四条]]第一項若しくは[[laws/428AC0000000077/本文/第7条.md|第七条]]第一項の許可又は[[laws/428AC0000000077/本文/第13条.md|第十三条]]第一項、第三項若しくは第四項の認可を受けたとき。[[laws/428AC0000000077/本文/第5条.md|第五条]]各号のいずれかに該当することとなったとき。[[laws/428AC0000000077/本文/第6条.md|第六条]]各号のいずれかに適合しないこととなったとき。[[laws/428AC0000000077/本文/第7条.md|第七条]]第一項の規定により許可を受けなければならない事項を同項の許可を受けないで変更したとき。[[laws/428AC0000000077/本文/第10条.md|第十条]]第一項の規定に違反して衛星リモートセンシング装置から送信された検出情報電磁的記録を受信したとき。この項、[[laws/428AC0000000077/本文/第19条.md|第十九条]]第一項又は[[laws/428AC0000000077/本文/第29条.md|第二十九条]]第一項若しくは第二項の規定による命令に違反したとき。次条第三項の規定に違反して衛星リモートセンシング記録を提供したとき。[[laws/428AC0000000077/本文/第30条.md|第三十条]]第一項の規定により[[laws/428AC0000000077/本文/第4条.md|第四条]]第一項若しくは[[laws/428AC0000000077/本文/第7条.md|第七条]]第一項の許可又は[[laws/428AC0000000077/本文/第13条.md|第十三条]]第一項、第三項若しくは第四項の認可に付された条件に違反したとき。

- 一 偽りその他不正の手段により[[laws/428AC0000000077/本文/第4条.md|第四条]]第一項若しくは[[laws/428AC0000000077/本文/第7条.md|第七条]]第一項の許可又は[[laws/428AC0000000077/本文/第13条.md|第十三条]]第一項、第三項若しくは第四項の認可を受けたとき。
- 二 [[laws/428AC0000000077/本文/第5条.md|第五条]]各号のいずれかに該当することとなったとき。
- 三 [[laws/428AC0000000077/本文/第6条.md|第六条]]各号のいずれかに適合しないこととなったとき。
- 四 [[laws/428AC0000000077/本文/第7条.md|第七条]]第一項の規定により許可を受けなければならない事項を同項の許可を受けないで変更したとき。
- 五 [[laws/428AC0000000077/本文/第10条.md|第十条]]第一項の規定に違反して衛星リモートセンシング装置から送信された検出情報電磁的記録を受信したとき。
- 六 この項、[[laws/428AC0000000077/本文/第19条.md|第十九条]]第一項又は[[laws/428AC0000000077/本文/第29条.md|第二十九条]]第一項若しくは第二項の規定による命令に違反したとき。
- 七 次条第三項の規定に違反して衛星リモートセンシング記録を提供したとき。
- 八 [[laws/428AC0000000077/本文/第30条.md|第三十条]]第一項の規定により[[laws/428AC0000000077/本文/第4条.md|第四条]]第一項若しくは[[laws/428AC0000000077/本文/第7条.md|第七条]]第一項の許可又は[[laws/428AC0000000077/本文/第13条.md|第十三条]]第一項、第三項若しくは第四項の認可に付された条件に違反したとき。
## ２
衛星リモートセンシング装置使用者が前項の規定により[[laws/428AC0000000077/本文/第4条.md|第四条]]第一項の許可を取り消されたときは、当該衛星リモートセンシング装置の使用に係る事業の譲渡について[[laws/428AC0000000077/本文/第13条.md|第十三条]]第一項の認可を受けた場合を除き、その取消しの日から百二十日以内に、終了措置を講じなければならない。この場合において、当該事業の譲渡が行われ、又は当該終了措置が完了するまでの間（[[laws/428AC0000000077/本文/第11条.md|第十一条]]に規定する場合にあっては、同条の規定による届出があるまでの間）は、その者を衛星リモートセンシング装置使用者とみなして、[[laws/428AC0000000077/本文/第8条.md|第八条]]から[[laws/428AC0000000077/本文/第10条.md|第十条]]まで、[[laws/428AC0000000077/本文/第11条.md|第十一条]]前段、[[laws/428AC0000000077/本文/第12条.md|第十二条]]、[[laws/428AC0000000077/本文/第13条.md|第十三条]]第一項及び第五項、[[laws/428AC0000000077/本文/第27条.md|第二十七条]]、[[laws/428AC0000000077/本文/第28条.md|第二十八条]]並びに[[laws/428AC0000000077/本文/第29条.md|第二十九条]]第一項の規定（これらの規定に係る罰則を含む。）を適用する。
