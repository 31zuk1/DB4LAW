# 第百八条の三 （配置販売に関する文書の添付）

## 
配置販売業者は、医薬品を配置するときは、次の各号に掲げる事項を記載した書面を添えて配置しなければならない。許可番号営業の区域許可の区分の別配置販売業者の氏名又は名称区域管理者の氏名当該区域に勤務する薬剤師又は登録販売者の別及び氏名相談時の対応方法に関する解説営業時間及び営業時間外に相談に応ずることができる時間及び当該相談に応ずる電話番号その他の連絡先

- 一 許可番号
- 二 営業の区域
- 三 許可の区分の別
- 四 配置販売業者の氏名又は名称
- 五 区域管理者の氏名
- 六 当該区域に勤務する薬剤師又は登録販売者の別及び氏名
- 七 相談時の対応方法に関する解説
- 八 営業時間及び営業時間外に相談に応ずることができる時間及び当該相談に応ずる電話番号その他の連絡先
