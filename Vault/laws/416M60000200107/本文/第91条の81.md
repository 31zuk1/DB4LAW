# 第九十一条の八十一 （製造販売業の許可の更新の申請）

## 
法[[laws/動物用医薬品等取締規則/本文/第23条の20.md|第二十三条の二十]]第四項の規定による許可の更新の申請は、別記様式第二号による申請書を農林水産大臣に提出してしなければならない。
