# 第三十五条 （農政課の所掌事務）

## 
農政課は、次に掲げる事務をつかさどる。農林水産部の所掌事務に関する総合的な政策の企画及び立案に関すること。農林水産部の所掌事務に関する総合調整に関すること。農林水産部の所掌事務に係る公文書類の審査に関すること。農林水産部の所掌事務に係る広報に関すること。農林水産部の所掌事務に係る災害対策に関する事務の総括に関すること。農畜産物、飲食料品及び油脂についての物価対策に関する事務のうち農林水産部の所掌に係るものの総括に関すること。農林水産部の所掌事務に係る情報の収集、整理、分析及び提供に関すること（消費・安全課の所掌に属するものを除く。）。農林水産部の情報システムの整備及び管理に関すること。農林水産部の保有する情報の公開に関すること。農林水産部の保有する情報の安全の確保に関すること。農林水産部の保有する個人情報の保護に関すること。食料安定供給特別会計の食糧管理勘定の経理に関すること。振興開発計画の作成及び推進に関する事務で農林水産部の所掌事務に関すること。農林水産部の所掌事務に関する相談に関すること。前各号に掲げるもののほか、農林水産部の所掌事務で他の所掌に属しないものに関すること。

- 一 農林水産部の所掌事務に関する総合的な政策の企画及び立案に関すること。
- 二 農林水産部の所掌事務に関する総合調整に関すること。
- 三 農林水産部の所掌事務に係る公文書類の審査に関すること。
- 四 農林水産部の所掌事務に係る広報に関すること。
- 五 農林水産部の所掌事務に係る災害対策に関する事務の総括に関すること。
- 六 農畜産物、飲食料品及び油脂についての物価対策に関する事務のうち農林水産部の所掌に係るものの総括に関すること。
- 七 農林水産部の所掌事務に係る情報の収集、整理、分析及び提供に関すること（消費・安全課の所掌に属するものを除く。）。
- 八 農林水産部の情報システムの整備及び管理に関すること。
- 九 農林水産部の保有する情報の公開に関すること。
- 十 農林水産部の保有する情報の安全の確保に関すること。
- 十一 農林水産部の保有する個人情報の保護に関すること。
- 十二 食料安定供給特別会計の食糧管理勘定の経理に関すること。
- 十三 振興開発計画の作成及び推進に関する事務で農林水産部の所掌事務に関すること。
- 十四 農林水産部の所掌事務に関する相談に関すること。
- 十五 前各号に掲げるもののほか、農林水産部の所掌事務で他の所掌に属しないものに関すること。
