# 第六十二条 

## 
次の各号のいずれかに該当する者は、五十万円以下の罰金に処する。[[laws/鉱山保安法/本文/第11条.md|第十一条]]第一項、[[laws/鉱山保安法/本文/第12条.md|第十二条]]、[[laws/鉱山保安法/本文/第13条.md|第十三条]]第二項、[[laws/鉱山保安法/本文/第19条.md|第十九条]]第四項、[[laws/鉱山保安法/本文/第30条.md|第三十条]]又は[[laws/鉱山保安法/本文/第42条.md|第四十二条]]の規定に違反した者[[laws/鉱山保安法/本文/第13条.md|第十三条]]第一項、[[laws/鉱山保安法/本文/第15条.md|第十五条]]、[[laws/鉱山保安法/本文/第19条.md|第十九条]]第一項若しくは第二項、[[laws/鉱山保安法/本文/第22条.md|第二十二条]]第四項（[[laws/鉱山保安法/本文/第23条.md|第二十三条]]第三項（[[laws/鉱山保安法/本文/第26条.md|第二十六条]]第二項において準用する場合を含む。）若しくは[[laws/鉱山保安法/本文/第26条.md|第二十六条]]第二項において準用する場合を含む。）又は[[laws/鉱山保安法/本文/第24条.md|第二十四条]]第一項の規定に違反して届出をせず、又は虚偽の届出をした者[[laws/鉱山保安法/本文/第14条.md|第十四条]]第一項、[[laws/鉱山保安法/本文/第16条.md|第十六条]]又は[[laws/鉱山保安法/本文/第18条.md|第十八条]]第一項から第三項までの規定に違反して、記録をせず、虚偽の記録をし、又は記録を保存しなかつた者[[laws/鉱山保安法/本文/第41条.md|第四十一条]]の規定による報告をせず、又は虚偽の報告をした者[[laws/鉱山保安法/本文/第44条.md|第四十四条]]第三項の規定に違反して書面を携帯せず、又はこれを提示しなかつた者[[laws/鉱山保安法/本文/第47条.md|第四十七条]]第一項の規定による報告をせず、若しくは虚偽の報告をし、立入り若しくは検査を拒み、妨げ、若しくは忌避し、又は質問に対して陳述をせず、若しくは虚偽の陳述をした者

- 一 [[laws/鉱山保安法/本文/第11条.md|第十一条]]第一項、[[laws/鉱山保安法/本文/第12条.md|第十二条]]、[[laws/鉱山保安法/本文/第13条.md|第十三条]]第二項、[[laws/鉱山保安法/本文/第19条.md|第十九条]]第四項、[[laws/鉱山保安法/本文/第30条.md|第三十条]]又は[[laws/鉱山保安法/本文/第42条.md|第四十二条]]の規定に違反した者
- 二 [[laws/鉱山保安法/本文/第13条.md|第十三条]]第一項、[[laws/鉱山保安法/本文/第15条.md|第十五条]]、[[laws/鉱山保安法/本文/第19条.md|第十九条]]第一項若しくは第二項、[[laws/鉱山保安法/本文/第22条.md|第二十二条]]第四項（[[laws/鉱山保安法/本文/第23条.md|第二十三条]]第三項（[[laws/鉱山保安法/本文/第26条.md|第二十六条]]第二項において準用する場合を含む。）若しくは[[laws/鉱山保安法/本文/第26条.md|第二十六条]]第二項において準用する場合を含む。）又は[[laws/鉱山保安法/本文/第24条.md|第二十四条]]第一項の規定に違反して届出をせず、又は虚偽の届出をした者
- 三 [[laws/鉱山保安法/本文/第14条.md|第十四条]]第一項、[[laws/鉱山保安法/本文/第16条.md|第十六条]]又は[[laws/鉱山保安法/本文/第18条.md|第十八条]]第一項から第三項までの規定に違反して、記録をせず、虚偽の記録をし、又は記録を保存しなかつた者
- 四 [[laws/鉱山保安法/本文/第41条.md|第四十一条]]の規定による報告をせず、又は虚偽の報告をした者
- 五 [[laws/鉱山保安法/本文/第44条.md|第四十四条]]第三項の規定に違反して書面を携帯せず、又はこれを提示しなかつた者
- 六 [[laws/鉱山保安法/本文/第47条.md|第四十七条]]第一項の規定による報告をせず、若しくは虚偽の報告をし、立入り若しくは検査を拒み、妨げ、若しくは忌避し、又は質問に対して陳述をせず、若しくは虚偽の陳述をした者
