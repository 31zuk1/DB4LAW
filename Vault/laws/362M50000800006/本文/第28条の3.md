# 第二十八条の三 （設計確認書の添付）

## 
認定鉄道事業者は、法[[laws/362M50000800006/本文/第8条.md|第八条]]第一項、[[laws/362M50000800006/本文/第9条.md|第九条]]第一項若しくは第三項（法[[laws/362M50000800006/本文/第12条.md|第十二条]]第四項において準用する場合を含む。以下次条において同じ。）、[[laws/362M50000800006/本文/第12条.md|第十二条]]第一項若しくは第二項又は[[laws/362M50000800006/本文/第13条.md|第十三条]]の規定に基づく認可若しくは確認の申請又は届出（次条第二項において「認可等の申請等」という。）に際し、[[laws/362M50000800006/本文/第27条.md|第二十七条]]から前条までの規定に基づく簡略化された手続によりこれをしようとするときは、当該申請又は届出に当たつて添付しなければならない書類及び図面のほか、設計確認書（認定事務所が鉄道施設等を設計し、かつ、設計の確認をしたことを証する書類をいう。）を添付しなければならない。
