# 第三十六条の八 （国土交通大臣による輸送の安全に関わる情報の公表）

## 
法[[laws/鉄道事業法施行規則/本文/第19条の3.md|第十九条の三]]の国土交通省令で定める輸送の安全に関わる情報は、次のとおりとする。法[[laws/鉄道事業法施行規則/本文/第19条.md|第十九条]]の規定による届出に係る事項法[[laws/鉄道事業法施行規則/本文/第19条の2.md|第十九条の二]]の規定による届出に係る事項法[[laws/鉄道事業法施行規則/本文/第23条.md|第二十三条]]第一項の規定による命令（輸送の安全に関してされたものに限る。）に係る事項踏切道改良促進法（昭和三十六年法律第百九十五号）第十七条第一項から第四項までの規定による勧告に係る事項鉄道事業者に対してされた行政指導（行政手続法（平成五年法律第八十八号）第二条第六号に規定する行政指導のうち、輸送の安全に関してされたものに限る。）に係る事項鉄道事業者が前号の行政指導に基づき講じた改善措置に係る事項鉄道事業者による輸送の安全に関わる設備投資の状況に係る事項輸送の安全に関わる鉄道施設の状況に係る事項前各号に掲げるもののほか、輸送の安全に重大な関係を有する事項がある場合には、その事項

- 一 法[[laws/鉄道事業法施行規則/本文/第19条.md|第十九条]]の規定による届出に係る事項
- 二 法[[laws/鉄道事業法施行規則/本文/第19条の2.md|第十九条の二]]の規定による届出に係る事項
- 三 法[[laws/鉄道事業法施行規則/本文/第23条.md|第二十三条]]第一項の規定による命令（輸送の安全に関してされたものに限る。）に係る事項
- 四 踏切道改良促進法（昭和三十六年法律第百九十五号）第十七条第一項から第四項までの規定による勧告に係る事項
- 五 鉄道事業者に対してされた行政指導（行政手続法（平成五年法律第八十八号）第二条第六号に規定する行政指導のうち、輸送の安全に関してされたものに限る。）に係る事項
- 六 鉄道事業者が前号の行政指導に基づき講じた改善措置に係る事項
- 七 鉄道事業者による輸送の安全に関わる設備投資の状況に係る事項
- 八 輸送の安全に関わる鉄道施設の状況に係る事項
- 九 前各号に掲げるもののほか、輸送の安全に重大な関係を有する事項がある場合には、その事項
## ２
法[[laws/鉄道事業法施行規則/本文/第19条の3.md|第十九条の三]]の規定による公表は、インターネットの利用その他の適切な方法により行うものとする。
