# 第十七条の三の三 

## 
遺族特例年金給付の算定の基礎となった旧適用法人施行日前期間のうちに追加費用対象期間があり、かつ、次の各号に掲げる場合の区分に応じ、当該各号に定める額が控除調整下限額を下回る場合における[[laws/厚生年金保険法等の一部を改正する法律の施行に伴う国家公務員共済組合法による長期給付等に関する経過措置に関する政令/本文/第17条の3.md|第十七条の三]]の規定の適用については、平成二十四年一元化法改正前施行法[[laws/厚生年金保険法等の一部を改正する法律の施行に伴う国家公務員共済組合法による長期給付等に関する経過措置に関する政令/本文/第13条の4.md|第十三条の四]]第一項若しくは第二項又は平成二十四年一元化法改正前昭和六十年改正法附則第二十一条第二項若しくは第三項の規定の適用がないとしたならば求められることとなる額から平成八年改正法附則第三十三条第二項に規定する政令で定める額を控除した額（職域相当額があるときは、当該職域相当額を控除して得た額とし、以下「控除前仮定遺族特例年金給付額」という。）を[[laws/厚生年金保険法等の一部を改正する法律の施行に伴う国家公務員共済組合法による長期給付等に関する経過措置に関する政令/本文/第17条の3.md|第十七条の三]]の仮定遺族特例年金給付額とみなし、[[laws/厚生年金保険法等の一部を改正する法律の施行に伴う国家公務員共済組合法による長期給付等に関する経過措置に関する政令/本文/第17条の2.md|第十七条の二]]第一項第一号に規定する退職を給付事由とする年金たる給付のいずれかが退職共済年金額控除規定の適用を受ける場合には、退職共済年金額控除規定を適用しないとしたならば求められることとなる額を[[laws/厚生年金保険法等の一部を改正する法律の施行に伴う国家公務員共済組合法による長期給付等に関する経過措置に関する政令/本文/第17条の3.md|第十七条の三]]の老齢厚生年金等合計額とみなす。平成二十四年一元化法附則第三十七条第一項に規定する給付のうち退職共済年金若しくは平成二十四年一元化法附則第四十一条年金のうち退職共済年金、平成二十四年一元化法附則第六十一条第一項に規定する給付のうち退職共済年金若しくは平成二十四年一元化法附則第六十五条年金のうち退職共済年金又は厚生年金保険法による年金たる保険給付（第二号厚生年金又は第三号厚生年金に限る。）のうち老齢厚生年金（次号において「退職共済年金等」と総称する。）の受給権者が平成二十四年一元化法改正前国共済法[[laws/厚生年金保険法等の一部を改正する法律の施行に伴う国家公務員共済組合法による長期給付等に関する経過措置に関する政令/本文/第91条の2.md|第九十一条の二]]、平成二十四年一元化法改正前地共済法[[laws/厚生年金保険法等の一部を改正する法律の施行に伴う国家公務員共済組合法による長期給付等に関する経過措置に関する政令/本文/第99条の4.md|第九十九条の四]]の二又は厚生年金保険法[[laws/厚生年金保険法等の一部を改正する法律の施行に伴う国家公務員共済組合法による長期給付等に関する経過措置に関する政令/本文/第64条の2.md|第六十四条の二]]の規定の適用を受ける場合（次号に掲げる場合を除く。）平成二十七年国共済経過措置政令[[laws/厚生年金保険法等の一部を改正する法律の施行に伴う国家公務員共済組合法による長期給付等に関する経過措置に関する政令/本文/第138条.md|第百三十八条]]第一項に規定する控除前退職共済年金等の額と同項に規定する控除前遺族共済年金等の額とのうちいずれか多い額に[[laws/厚生年金保険法等の一部を改正する法律の施行に伴う国家公務員共済組合法による長期給付等に関する経過措置に関する政令/本文/第17条の3.md|第十七条の三]]の規定により算定される額（以下「控除前遺族特例年金給付額」という。）を加えた額退職共済年金等の受給権者が平成二十四年一元化法改正前国共済法[[laws/厚生年金保険法等の一部を改正する法律の施行に伴う国家公務員共済組合法による長期給付等に関する経過措置に関する政令/本文/第91条の2.md|第九十一条の二]]、平成二十四年一元化法改正前地共済法[[laws/厚生年金保険法等の一部を改正する法律の施行に伴う国家公務員共済組合法による長期給付等に関する経過措置に関する政令/本文/第99条の4.md|第九十九条の四]]の二又は厚生年金保険法[[laws/厚生年金保険法等の一部を改正する法律の施行に伴う国家公務員共済組合法による長期給付等に関する経過措置に関する政令/本文/第64条の2.md|第六十四条の二]]の規定の適用を受ける場合（当該退職共済年金等と併
