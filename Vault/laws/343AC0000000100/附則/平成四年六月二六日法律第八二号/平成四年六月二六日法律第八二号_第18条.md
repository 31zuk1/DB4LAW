# 第十八条 （屋外広告物法等の一部改正に伴う経過措置）

## 
この法律の施行の際現に旧都市計画法の規定により定められている都市計画区域内の用途地域に関しては、この法律の施行の日から起算して三年を経過する日までの間は、この法律による改正前の次に掲げる法律の規定は、なおその効力を有する。屋外広告物法土地収用法駐車場法新住宅市街地開発法新都市基盤整備法大都市地域における住宅及び住宅地の供給の促進に関する特別措置法

- 一 屋外広告物法
- 二 土地収用法
- 三 駐車場法
- 四 新住宅市街地開発法
- 五 新都市基盤整備法
- 六 大都市地域における住宅及び住宅地の供給の促進に関する特別措置法
