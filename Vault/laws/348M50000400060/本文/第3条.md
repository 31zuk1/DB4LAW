# 第三条 （特定施設から除かれる施設）

## 
法[[laws/金属鉱業等鉱害対策特別措置法施行規則/本文/第2条.md|第二条]]第三項の経済産業省令で定める施設は、次のとおりとする。坑口を有しない坑道専ら金属鉱物等以外の鉱物の採掘及びこれに附属する選鉱、製錬その他の事業の用に供される坑道及び捨石又は鉱さいの集積場金属鉱物等の鉱床以外の土地の部分の掘さくによつて生ずる捨石のみの集積場

- 一 坑口を有しない坑道
- 二 専ら金属鉱物等以外の鉱物の採掘及びこれに附属する選鉱、製錬その他の事業の用に供される坑道及び捨石又は鉱さいの集積場
- 三 金属鉱物等の鉱床以外の土地の部分の掘さくによつて生ずる捨石のみの集積場
