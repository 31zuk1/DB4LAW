# 第十六条 （試験科目）

## 
学科試験の試験科目は、次のとおりとする。調理一般調理法材料食品衛生及び公衆衛生食品及び栄養関係法規安全衛生

- 一 調理一般
- 二 調理法
- 三 材料
- 四 食品衛生及び公衆衛生
- 五 食品及び栄養
- 六 関係法規
- 七 安全衛生
## ２
実技試験の試験科目は、次の各号に掲げるもののうち、技術審査を受けようとする者があらかじめ選択した一の科目とする。日本料理西洋料理麺めん料理中国料理すし料理給食用特殊料理

- 一 日本料理
- 二 西洋料理
- 三 麺めん料理
- 四 中国料理
- 五 すし料理
- 六 給食用特殊料理
