# 第二十七条 （内閣総理大臣との協議）

## 
防衛大臣は、次の場合には、あらかじめ、内閣総理大臣と協議するものとする。法[[laws/327CO0000000368/本文/第4条.md|第四条]]第四項ただし書、[[laws/327AC0000000266/本文/第4条の2.md|第四条の二]]第二項及び[[laws/327CO0000000368/本文/第12条.md|第十二条]]第二項の規定、法[[laws/327CO0000000368/本文/第14条.md|第十四条]]第二項において読み替えて準用する一般職給与法[[laws/327CO0000000368/防衛省の職員の給与等に関する法律施行令_law.md|第十一条の五]]、[[laws/327CO0000000368/防衛省の職員の給与等に関する法律施行令_law.md|第十一条の七]]第一項及び第二項並びに[[laws/327CO0000000368/本文/第14条.md|第十四条]]第一項の規定並びに法[[laws/327CO0000000368/本文/第23条.md|第二十三条]]第六項ただし書の規定により防衛省令を定めようとするとき。法[[laws/327CO0000000368/本文/第6条の2.md|第六条の二]]第二項及び第三項並びに[[laws/327CO0000000368/本文/第7条.md|第七条]]第二項の規定による俸給月額の決定をしようとするとき。国家公務員の寒冷地手当に関する法律[[laws/327CO0000000368/本文/第5条.md|第五条]]において読み替えて準用する同法第一条第二号、[[laws/327CO0000000368/本文/第2条.md|第二条]]第一項、第二項、第三項第三号及び第四項並びに[[laws/327CO0000000368/本文/第3条.md|第三条]]第一項の規定による定めをしようとするとき。[[laws/327CO0000000368/本文/第1条の2.md|第一条の二]]第二項から第四項まで、[[laws/327CO0000000368/本文/第3条.md|第三条]]第十一項、[[laws/327CO0000000368/本文/第4条.md|第四条]]第一項及び第二項、[[laws/327CO0000000368/本文/第8条の2.md|第八条の二]]第二項並びに[[laws/327CO0000000368/本文/第10条の4.md|第十条の四]]第四項の規定により防衛省令を定めようとするとき。[[laws/327CO0000000368/本文/第6条の20.md|第六条の二十]]第一項の規定による定めをしようとするとき。[[laws/327CO0000000368/本文/第6条の20.md|第六条の二十]]第二項の規定による指定をしようとするとき。

- 一 法[[laws/327CO0000000368/本文/第4条.md|第四条]]第四項ただし書、[[laws/327AC0000000266/本文/第4条の2.md|第四条の二]]第二項及び[[laws/327CO0000000368/本文/第12条.md|第十二条]]第二項の規定、法[[laws/327CO0000000368/本文/第14条.md|第十四条]]第二項において読み替えて準用する一般職給与法[[laws/327CO0000000368/防衛省の職員の給与等に関する法律施行令_law.md|第十一条の五]]、[[laws/327CO0000000368/防衛省の職員の給与等に関する法律施行令_law.md|第十一条の七]]第一項及び第二項並びに[[laws/327CO0000000368/本文/第14条.md|第十四条]]第一項の規定並びに法[[laws/327CO0000000368/本文/第23条.md|第二十三条]]第六項ただし書の規定により防衛省令を定めようとするとき。
- 二 法[[laws/327CO0000000368/本文/第6条の2.md|第六条の二]]第二項及び第三項並びに[[laws/327CO0000000368/本文/第7条.md|第七条]]第二項の規定による俸給月額の決定をしようとするとき。
- 三 国家公務員の寒冷地手当に関する法律[[laws/327CO0000000368/本文/第5条.md|第五条]]において読み替えて準用する同法第一条第二号、[[laws/327CO0000000368/本文/第2条.md|第二条]]第一項、第二項、第三項第三号及び第四項並びに[[laws/327CO0000000368/本文/第3条.md|第三条]]第一項の規定による定めをしようとするとき。
- 四 [[laws/327CO0000000368/本文/第1条の2.md|第一条の二]]第二項から第四項まで、[[laws/327CO0000000368/本文/第3条.md|第三条]]第十一項、[[laws/327CO0000000368/本文/第4条.md|第四条]]第一項及び第二項、[[laws/327CO0000000368/本文/第8条の2.md|第八条の二]]第二項並びに[[laws/327CO0000000368/本文/第10条の4.md|第十条の四]]第四項の規定により防衛省令を定めようとするとき。
- 五 [[laws/327CO0000000368/本文/第6条の20.md|第六条の二十]]第一項の規定による定めをしようとするとき。
- 六 [[laws/327CO0000000368/本文/第6条の20.md|第六条の二十]]第二項の規定による指定をしようとするとき。
