# 第二十四条 

## 
法[[laws/324M50000001009/本文/第38条.md|第三十八条]]第六号に規定する法務省令で定める事項は、次に掲げる事項とする。公正証書の作成場所嘱託人の生年月日電磁的記録をもつて公正証書を作成するときは、指定公証人の氏名、その所属する法務局又は地方法務局の名称公正証書の作成に当たり通訳人に通訳をさせ、又は証人を立ち会わせたときは、これらの者の住所及び生年月日代理人によつて嘱託されたときは、当該代理人の住所及び生年月日[[laws/324M50000001009/本文/第22条.md|第二十二条]]第三項ただし書に該当するときはその旨第三者の許可又は同意があつたときは、その旨及びその事由並びに当該第三者の住所及び氏名（法人にあつては、主たる事務所の所在地及び名称又は商号）官公署の作成した印鑑に関する証明書若しくは法[[laws/324M50000001009/本文/第28条.md|第二十八条]]に規定する署名用電子証明書等を提供する方法その他これに準ずる確実な方法により本人であることを証明させ、又は官公署の作成した印鑑若しくは署名に関する証明書若しくは同条に規定する署名用電子証明書等を提供させて法[[laws/324M50000001009/本文/第32条.md|第三十二条]]第二項又は[[laws/324M50000001009/本文/第34条.md|第三十四条]]第一項の書面若しくは電磁的記録が真正であることを証明させたときは、その旨及びその事由法[[laws/324M50000001009/本文/第32条.md|第三十二条]]第三項ただし書に規定する場合には、その旨及びその事由法[[laws/324M50000001009/本文/第37条.md|第三十七条]]第二項又は[[laws/324M50000001009/本文/第40条.md|第四十条]]第三項の規定により映像と音声の送受信により相手の状態を相互に認識しながら通話をすることができる方法によつて遺言公正証書を作成する場合において、証人が嘱託人と同席しているときは、その旨

- 一 公正証書の作成場所
- 二 嘱託人の生年月日
- 三 電磁的記録をもつて公正証書を作成するときは、指定公証人の氏名、その所属する法務局又は地方法務局の名称
- 四 公正証書の作成に当たり通訳人に通訳をさせ、又は証人を立ち会わせたときは、これらの者の住所及び生年月日
- 五 代理人によつて嘱託されたときは、当該代理人の住所及び生年月日
- 六 [[laws/324M50000001009/本文/第22条.md|第二十二条]]第三項ただし書に該当するときはその旨
- 七 第三者の許可又は同意があつたときは、その旨及びその事由並びに当該第三者の住所及び氏名（法人にあつては、主たる事務所の所在地及び名称又は商号）
- 八 官公署の作成した印鑑に関する証明書若しくは法[[laws/324M50000001009/本文/第28条.md|第二十八条]]に規定する署名用電子証明書等を提供する方法その他これに準ずる確実な方法により本人であることを証明させ、又は官公署の作成した印鑑若しくは署名に関する証明書若しくは同条に規定する署名用電子証明書等を提供させて法[[laws/324M50000001009/本文/第32条.md|第三十二条]]第二項又は[[laws/324M50000001009/本文/第34条.md|第三十四条]]第一項の書面若しくは電磁的記録が真正であることを証明させたときは、その旨及びその事由
- 九 法[[laws/324M50000001009/本文/第32条.md|第三十二条]]第三項ただし書に規定する場合には、その旨及びその事由
- 十 法[[laws/324M50000001009/本文/第37条.md|第三十七条]]第二項又は[[laws/324M50000001009/本文/第40条.md|第四十条]]第三項の規定により映像と音声の送受信により相手の状態を相互に認識しながら通話をすることができる方法によつて遺言公正証書を作成する場合において、証人が嘱託人と同席しているときは、その旨
