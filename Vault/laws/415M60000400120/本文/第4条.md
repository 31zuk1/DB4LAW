# 第四条 （業務方法書の記載事項）

## 
機構が行う業務に係る通則法[[laws/415M60000400120/本文/第28条.md|第二十八条]]第二項の主務省令で定める業務方法書に記載すべき事項は、次のとおりとする。機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第一号に規定する同号イからニまでに掲げる技術の開発に関する事項機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第二号に規定する鉱工業技術の研究開発に関する事項機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第三号に規定する鉱工業技術に関する研究開発の助成に関する事項機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第三号の二に規定する鉱工業技術に関する研究開発の成果の企業化に必要な事業活動に要する資金に充てるための補助金の交付に関する事項機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第四号に規定する同条第一号に掲げる技術の有効性の海外における実証に関する事項機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第五号に規定する同条第一号ハ及びニに掲げる技術の導入に要する資金に充てるための補助金の交付に関する事項機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第六号に規定する情報の収集及び提供並びに指導に関する事項機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第七号に規定する鉱工業技術に係る技術者の養成及び資質の向上を図るための研修に関する事項機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第八号に規定する技術経営力の強化に関する助言に関する事項機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第八号の二に規定する助言に関する事項機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第八号の三に規定する出資（金銭の出資を除く。）並びに人的及び技術的援助に関する事項機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第九号に規定する附帯する業務に関する事項機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第十号に規定する非化石エネルギーの開発及び導入の促進に関する法律（昭和五十五年法律第七十一号）[[laws/415M60000400120/本文/第11条.md|第十一条]]に規定する業務に関する事項機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第十一号に規定する基盤技術研究円滑化法（昭和六十年法律第六十五号）第十一条に規定する業務に関する事項機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第十二号に規定する福祉用具の研究開発及び普及の促進に関する法律（平成五年法律第三十八号）[[laws/415M60000400120/本文/第7条.md|第七条]]に規定する業務に関する事項機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第十三号に規定する新エネルギー利用等の促進に関する特別措置法（平成九年法律第三十七号）第十条に規定する業務に関する事項機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第十四号に規定する特定高度情報通信技術活用システムの開発供給及び導入の促進に関する法律（令和二年法律第三十七号）[[laws/415M60000400120/本文/第29条.md|第二十九条]]に規定する業務に関する事項機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第十五号に規定する安定供給確保支援業務に関する事項機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]各号に掲げる業務のうち科学技術・イノベーション創出の活性化に関する法律（平成二十年法律第六十三号）[[laws/415M60000400120/国立研究開発法人新エネルギー・産業技術総_law.md|第二十七条の二]]第一項に規定する特定公募型研究開発業務として行うものに要する費用に充てるための基金に関する事項業務委託の基準競争入札その他契約に関する基本的事項その他機構の業務の執行に関して必要な事項

- 一 機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第一号に規定する同号イからニまでに掲げる技術の開発に関する事項
- 二 機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第二号に規定する鉱工業技術の研究開発に関する事項
- 三 機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第三号に規定する鉱工業技術に関する研究開発の助成に関する事項
- 三の二 機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第三号の二に規定する鉱工業技術に関する研究開発の成果の企業化に必要な事業活動に要する資金に充てるための補助金の交付に関する事項
- 四 機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第四号に規定する同条第一号に掲げる技術の有効性の海外における実証に関する事項
- 五 機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第五号に規定する同条第一号ハ及びニに掲げる技術の導入に要する資金に充てるための補助金の交付に関する事項
- 六 機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第六号に規定する情報の収集及び提供並びに指導に関する事項
- 七 機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第七号に規定する鉱工業技術に係る技術者の養成及び資質の向上を図るための研修に関する事項
- 八 機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第八号に規定する技術経営力の強化に関する助言に関する事項
- 八の二 機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第八号の二に規定する助言に関する事項
- 八の三 機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第八号の三に規定する出資（金銭の出資を除く。）並びに人的及び技術的援助に関する事項
- 九 機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第九号に規定する附帯する業務に関する事項
- 十 機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第十号に規定する非化石エネルギーの開発及び導入の促進に関する法律（昭和五十五年法律第七十一号）[[laws/415M60000400120/本文/第11条.md|第十一条]]に規定する業務に関する事項
- 十一 機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第十一号に規定する基盤技術研究円滑化法（昭和六十年法律第六十五号）第十一条に規定する業務に関する事項
- 十二 機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第十二号に規定する福祉用具の研究開発及び普及の促進に関する法律（平成五年法律第三十八号）[[laws/415M60000400120/本文/第7条.md|第七条]]に規定する業務に関する事項
- 十三 機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第十三号に規定する新エネルギー利用等の促進に関する特別措置法（平成九年法律第三十七号）第十条に規定する業務に関する事項
- 十四 機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第十四号に規定する特定高度情報通信技術活用システムの開発供給及び導入の促進に関する法律（令和二年法律第三十七号）[[laws/415M60000400120/本文/第29条.md|第二十九条]]に規定する業務に関する事項
- 十五 機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]第十五号に規定する安定供給確保支援業務に関する事項
- 十六 機構法[[laws/415M60000400120/本文/第15条.md|第十五条]]各号に掲げる業務のうち科学技術・イノベーション創出の活性化に関する法律（平成二十年法律第六十三号）[[laws/415M60000400120/国立研究開発法人新エネルギー・産業技術総_law.md|第二十七条の二]]第一項に規定する特定公募型研究開発業務として行うものに要する費用に充てるための基金に関する事項
- 十七 業務委託の基準
- 十八 競争入札その他契約に関する基本的事項
- 十九 その他機構の業務の執行に関して必要な事項
