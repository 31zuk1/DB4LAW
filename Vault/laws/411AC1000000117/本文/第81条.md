# 第八十一条 （啓発活動等及び技術的援助等）

## 
国及び地方公共団体は、特定事業の実施について、知識の普及、情報の提供等を行うとともに、住民の理解、同意及び協力を得るための啓発活動を推進するものとする。

## ２
国及び地方公共団体は、特定事業の円滑かつ効率的な遂行を図るため、民間事業者に対する技術的な援助について必要な配慮をするとともに、特許等の技術の利用の調整その他民間事業者の有する技術の活用について特別の配慮をするものとする。
