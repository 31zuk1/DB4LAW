# 第九十三条 

## 
次の各号のいずれかに該当する場合には、その違反行為をした機構の取締役、会計参与若しくはその職務を行うべき社員又は監査役は、百万円以下の過料に処する。[[laws/民間資金等の活用による公共施設等の整備等の促進に関する法律/本文/第34条.md|第三十四条]]第一項の規定に違反して、募集株式、募集新株予約権若しくは募集社債を引き受ける者の募集をし、株式交換若しくは株式交付に際して株式、社債若しくは新株予約権を発行し、又は資金を借り入れたとき。[[laws/民間資金等の活用による公共施設等の整備等の促進に関する法律/本文/第34条.md|第三十四条]]第二項の規定に違反して、株式を発行した旨の届出を行わなかったとき。[[laws/民間資金等の活用による公共施設等の整備等の促進に関する法律/本文/第50条.md|第五十条]]第一項又は第四項の規定に違反して、登記することを怠ったとき。[[laws/民間資金等の活用による公共施設等の整備等の促進に関する法律/本文/第52条.md|第五十二条]]第二項の規定に違反して、業務を行ったとき。[[laws/民間資金等の活用による公共施設等の整備等の促進に関する法律/本文/第54条.md|第五十四条]]第二項又は[[laws/民間資金等の活用による公共施設等の整備等の促進に関する法律/本文/第56条.md|第五十六条]]第一項の規定に違反して、内閣総理大臣に通知をしなかったとき。[[laws/民間資金等の活用による公共施設等の整備等の促進に関する法律/本文/第58条.md|第五十八条]]第一項の規定に違反して、予算の認可を受けなかったとき。[[laws/民間資金等の活用による公共施設等の整備等の促進に関する法律/本文/第60条.md|第六十条]]の規定に違反して、貸借対照表、損益計算書若しくは事業報告書を提出せず、又は虚偽の記載若しくは記録をしたこれらのものを提出したとき。[[laws/民間資金等の活用による公共施設等の整備等の促進に関する法律/本文/第62条.md|第六十二条]]第二項の規定による命令に違反したとき。

- 一 [[laws/民間資金等の活用による公共施設等の整備等の促進に関する法律/本文/第34条.md|第三十四条]]第一項の規定に違反して、募集株式、募集新株予約権若しくは募集社債を引き受ける者の募集をし、株式交換若しくは株式交付に際して株式、社債若しくは新株予約権を発行し、又は資金を借り入れたとき。
- 二 [[laws/民間資金等の活用による公共施設等の整備等の促進に関する法律/本文/第34条.md|第三十四条]]第二項の規定に違反して、株式を発行した旨の届出を行わなかったとき。
- 三 [[laws/民間資金等の活用による公共施設等の整備等の促進に関する法律/本文/第50条.md|第五十条]]第一項又は第四項の規定に違反して、登記することを怠ったとき。
- 四 [[laws/民間資金等の活用による公共施設等の整備等の促進に関する法律/本文/第52条.md|第五十二条]]第二項の規定に違反して、業務を行ったとき。
- 五 [[laws/民間資金等の活用による公共施設等の整備等の促進に関する法律/本文/第54条.md|第五十四条]]第二項又は[[laws/民間資金等の活用による公共施設等の整備等の促進に関する法律/本文/第56条.md|第五十六条]]第一項の規定に違反して、内閣総理大臣に通知をしなかったとき。
- 六 [[laws/民間資金等の活用による公共施設等の整備等の促進に関する法律/本文/第58条.md|第五十八条]]第一項の規定に違反して、予算の認可を受けなかったとき。
- 七 [[laws/民間資金等の活用による公共施設等の整備等の促進に関する法律/本文/第60条.md|第六十条]]の規定に違反して、貸借対照表、損益計算書若しくは事業報告書を提出せず、又は虚偽の記載若しくは記録をしたこれらのものを提出したとき。
- 八 [[laws/民間資金等の活用による公共施設等の整備等の促進に関する法律/本文/第62条.md|第六十二条]]第二項の規定による命令に違反したとき。
