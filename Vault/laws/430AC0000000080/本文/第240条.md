# 第二百四十条 

## 
次の各号のいずれかに該当するときは、その違反行為をした者は、六月以下の拘禁刑若しくは五十万円以下の罰金に処し、又はこれを併科する。[[laws/特定複合観光施設区域整備法/本文/第61条.md|第六十一条]]第一項（[[laws/特定複合観光施設区域整備法/本文/第131条.md|第百三十一条]]、[[laws/特定複合観光施設区域整備法/本文/第141条.md|第百四十一条]]及び[[laws/特定複合観光施設区域整備法/本文/第164条.md|第百六十四条]]において準用する場合を含む。以下この号において同じ。）の規定に違反して役員を変更したとき、又は偽りその他不正の手段により同項の承認を受けたとき。[[laws/特定複合観光施設区域整備法/本文/第70条.md|第七十条]]第五項の規定に違反して、入場等回数制限対象者該当性についての確認以外の目的のためにカジノ管理委員会に対し照会をし、又は回答情報を当該確認以外の目的に使用し、若しくは第三者に提供したとき。情を知って、前号の違反行為をした者から回答情報の提供を受けたとき。[[laws/特定複合観光施設区域整備法/本文/第70条.md|第七十条]]第六項の規定に違反して、回答情報を使用し、又は第三者に提供したとき。情を知って、前号の違反行為をした者から回答情報の提供を受けたとき。[[laws/特定複合観光施設区域整備法/本文/第91条.md|第九十一条]]第二項（同条第六項において準用する場合を含む。）の申請書又は添付書類に虚偽の記載をして提出したとき。[[laws/特定複合観光施設区域整備法/本文/第96条.md|第九十六条]]第一項（[[laws/特定複合観光施設区域整備法/本文/第101条.md|第百一条]]第三項（[[laws/特定複合観光施設区域整備法/本文/第133条.md|第百三十三条]]第四項において準用する場合を含む。以下この号において同じ。）及び[[laws/特定複合観光施設区域整備法/本文/第133条.md|第百三十三条]]第四項において準用する場合を含む。）の申請書又は[[laws/特定複合観光施設区域整備法/本文/第96条.md|第九十六条]]第二項（[[laws/特定複合観光施設区域整備法/本文/第101条.md|第百一条]]第三項及び[[laws/特定複合観光施設区域整備法/本文/第133条.md|第百三十三条]]第四項において準用する場合を含む。）の規定によりこれに添付すべき書類に虚偽の記載をして提出したとき。[[laws/特定複合観光施設区域整備法/本文/第114条.md|第百十四条]]、[[laws/特定複合観光施設区域整備法/本文/第134条.md|第百三十四条]]第一項若しくは[[laws/特定複合観光施設区域整備法/本文/第158条.md|第百五十八条]]第一項の規定に違反してその雇用する者その他の者を特定カジノ業務、特定カジノ施設供用業務若しくは特定カジノ関連機器等製造業務等に従事させたとき、又は偽りその他不正の手段によりこれらの規定の確認を受けたとき。偽りその他不正の手段により[[laws/特定複合観光施設区域整備法/本文/第117条.md|第百十七条]]第二項（[[laws/特定複合観光施設区域整備法/本文/第134条.md|第百三十四条]]第二項及び[[laws/特定複合観光施設区域整備法/本文/第158条.md|第百五十八条]]第三項において準用する場合を含む。）の更新を受けたとき。[[laws/特定複合観光施設区域整備法/本文/第148条.md|第百四十八条]]第二項又は[[laws/特定複合観光施設区域整備法/本文/第149条.md|第百四十九条]]において準用する[[laws/特定複合観光施設区域整備法/本文/第52条.md|第五十二条]]第一項の規定に違反して、業務方法書又は定款を変更したとき。[[laws/特定複合観光施設区域整備法/本文/第199条.md|第百九十九条]]第一項若しくは[[laws/特定複合観光施設区域整備法/本文/第200条.md|第二百条]]第一項の規定による報告若しくは資料の提出をせず、若しくは虚偽の報告若しくは資料の提出をしたとき、又は[[laws/特定複合観光施設区域整備法/本文/第199条.md|第百九十九条]]第二項若しくは[[laws/特定複合観光施設区域整備法/本文/第200条.md|第二百条]]第二項の規定による質問に対して答弁をせず、若しくは虚偽の答弁をし、若しくはこれらの規定による検査を拒み、妨げ、若しくは忌避したとき。[[laws/特定複合観光施設区域整備法/本文/第205条.md|第二百五条]]第一項又は[[laws/特定複合観光施設区域整備法/本文/第207条.md|第二百七条]]第一項の規定による命令に違反したとき。

- 一 [[laws/特定複合観光施設区域整備法/本文/第61条.md|第六十一条]]第一項（[[laws/特定複合観光施設区域整備法/本文/第131条.md|第百三十一条]]、[[laws/特定複合観光施設区域整備法/本文/第141条.md|第百四十一条]]及び[[laws/特定複合観光施設区域整備法/本文/第164条.md|第百六十四条]]において準用する場合を含む。以下この号において同じ。）の規定に違反して役員を変更したとき、又は偽りその他不正の手段により同項の承認を受けたとき。
- 二 [[laws/特定複合観光施設区域整備法/本文/第70条.md|第七十条]]第五項の規定に違反して、入場等回数制限対象者該当性についての確認以外の目的のためにカジノ管理委員会に対し照会をし、又は回答情報を当該確認以外の目的に使用し、若しくは第三者に提供したとき。
- 三 情を知って、前号の違反行為をした者から回答情報の提供を受けたとき。
- 四 [[laws/特定複合観光施設区域整備法/本文/第70条.md|第七十条]]第六項の規定に違反して、回答情報を使用し、又は第三者に提供したとき。
- 五 情を知って、前号の違反行為をした者から回答情報の提供を受けたとき。
- 六 [[laws/特定複合観光施設区域整備法/本文/第91条.md|第九十一条]]第二項（同条第六項において準用する場合を含む。）の申請書又は添付書類に虚偽の記載をして提出したとき。
- 七 [[laws/特定複合観光施設区域整備法/本文/第96条.md|第九十六条]]第一項（[[laws/特定複合観光施設区域整備法/本文/第101条.md|第百一条]]第三項（[[laws/特定複合観光施設区域整備法/本文/第133条.md|第百三十三条]]第四項において準用する場合を含む。以下この号において同じ。）及び[[laws/特定複合観光施設区域整備法/本文/第133条.md|第百三十三条]]第四項において準用する場合を含む。）の申請書又は[[laws/特定複合観光施設区域整備法/本文/第96条.md|第九十六条]]第二項（[[laws/特定複合観光施設区域整備法/本文/第101条.md|第百一条]]第三項及び[[laws/特定複合観光施設区域整備法/本文/第133条.md|第百三十三条]]第四項において準用する場合を含む。）の規定によりこれに添付すべき書類に虚偽の記載をして提出したとき。
- 八 [[laws/特定複合観光施設区域整備法/本文/第114条.md|第百十四条]]、[[laws/特定複合観光施設区域整備法/本文/第134条.md|第百三十四条]]第一項若しくは[[laws/特定複合観光施設区域整備法/本文/第158条.md|第百五十八条]]第一項の規定に違反してその雇用する者その他の者を特定カジノ業務、特定カジノ施設供用業務若しくは特定カジノ関連機器等製造業務等に従事させたとき、又は偽りその他不正の手段によりこれらの規定の確認を受けたとき。
- 九 偽りその他不正の手段により[[laws/特定複合観光施設区域整備法/本文/第117条.md|第百十七条]]第二項（[[laws/特定複合観光施設区域整備法/本文/第134条.md|第百三十四条]]第二項及び[[laws/特定複合観光施設区域整備法/本文/第158条.md|第百五十八条]]第三項において準用する場合を含む。）の更新を受けたとき。
- 十 [[laws/特定複合観光施設区域整備法/本文/第148条.md|第百四十八条]]第二項又は[[laws/特定複合観光施設区域整備法/本文/第149条.md|第百四十九条]]において準用する[[laws/特定複合観光施設区域整備法/本文/第52条.md|第五十二条]]第一項の規定に違反して、業務方法書又は定款を変更したとき。
- 十一 [[laws/特定複合観光施設区域整備法/本文/第199条.md|第百九十九条]]第一項若しくは[[laws/特定複合観光施設区域整備法/本文/第200条.md|第二百条]]第一項の規定による報告若しくは資料の提出をせず、若しくは虚偽の報告若しくは資料の提出をしたとき、又は[[laws/特定複合観光施設区域整備法/本文/第199条.md|第百九十九条]]第二項若しくは[[laws/特定複合観光施設区域整備法/本文/第200条.md|第二百条]]第二項の規定による質問に対して答弁をせず、若しくは虚偽の答弁をし、若しくはこれらの規定による検査を拒み、妨げ、若しくは忌避したとき。
- 十二 [[laws/特定複合観光施設区域整備法/本文/第205条.md|第二百五条]]第一項又は[[laws/特定複合観光施設区域整備法/本文/第207条.md|第二百七条]]第一項の規定による命令に違反したとき。
