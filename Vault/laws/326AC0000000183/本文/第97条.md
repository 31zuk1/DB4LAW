# 第九十七条 

## 
次の各号のいずれかに該当するときは、その違反行為をした者は、一年以下の拘禁刑若しくは百五十万円以下の罰金に処し、又はこれを併科する。[[laws/道路運送法/本文/第25条.md|第二十五条]]（[[laws/道路運送法/本文/第43条.md|第四十三条]]第五項において準用する場合を含む。）、[[laws/道路運送法/本文/第78条.md|第七十八条]]又は[[laws/道路運送法/本文/第83条.md|第八十三条]]の規定に違反したとき。[[laws/道路運送法/本文/第27条.md|第二十七条]]第四項の規定による命令（輸送の安全の確保に係るものに限り、一般乗用旅客自動車運送事業者に対するものを除く。）に違反したとき。[[laws/道路運送法/本文/第35条.md|第三十五条]]第一項又は[[laws/道路運送法/本文/第70条の2.md|第七十条の二]]第一項の規定により許可を受けてしなければならない事項を許可を受けないでしたとき。[[laws/道路運送法/本文/第40条.md|第四十条]]（[[laws/道路運送法/本文/第43条.md|第四十三条]]第五項及び[[laws/道路運送法/本文/第72条.md|第七十二条]]において準用する場合を含む。）の規定による輸送施設の使用の停止又は事業の停止の処分に違反したとき。[[laws/道路運送法/本文/第43条.md|第四十三条]]第一項の規定に違反して、特定旅客自動車運送事業を経営したとき。[[laws/道路運送法/本文/第57条.md|第五十七条]]第一項、[[laws/道路運送法/本文/第58条.md|第五十八条]]第一項、[[laws/道路運送法/本文/第60条.md|第六十条]]第一項（[[laws/道路運送法/本文/第75条.md|第七十五条]]第三項において準用する場合を含む。）又は[[laws/道路運送法/本文/第75条.md|第七十五条]]第一項の規定による検査を受けないで、又はこれに合格しないで、自動車道の供用を開始したとき（[[laws/道路運送法/本文/第59条.md|第五十九条]]第一項の規定により一般自動車道の一部につき検査を受け、これに合格した場合において、その部分につき供用を開始したときを除く。）。不正の手段により[[laws/道路運送法/本文/第79条.md|第七十九条]]の登録又は[[laws/道路運送法/本文/第79条の6.md|第七十九条の六]]第一項の有効期間の更新の登録を受けたとき。[[laws/道路運送法/本文/第81条.md|第八十一条]]第一項の規定による処分に違反したとき。

- 一 [[laws/道路運送法/本文/第25条.md|第二十五条]]（[[laws/道路運送法/本文/第43条.md|第四十三条]]第五項において準用する場合を含む。）、[[laws/道路運送法/本文/第78条.md|第七十八条]]又は[[laws/道路運送法/本文/第83条.md|第八十三条]]の規定に違反したとき。
- 二 [[laws/道路運送法/本文/第27条.md|第二十七条]]第四項の規定による命令（輸送の安全の確保に係るものに限り、一般乗用旅客自動車運送事業者に対するものを除く。）に違反したとき。
- 三 [[laws/道路運送法/本文/第35条.md|第三十五条]]第一項又は[[laws/道路運送法/本文/第70条の2.md|第七十条の二]]第一項の規定により許可を受けてしなければならない事項を許可を受けないでしたとき。
- 四 [[laws/道路運送法/本文/第40条.md|第四十条]]（[[laws/道路運送法/本文/第43条.md|第四十三条]]第五項及び[[laws/道路運送法/本文/第72条.md|第七十二条]]において準用する場合を含む。）の規定による輸送施設の使用の停止又は事業の停止の処分に違反したとき。
- 五 [[laws/道路運送法/本文/第43条.md|第四十三条]]第一項の規定に違反して、特定旅客自動車運送事業を経営したとき。
- 六 [[laws/道路運送法/本文/第57条.md|第五十七条]]第一項、[[laws/道路運送法/本文/第58条.md|第五十八条]]第一項、[[laws/道路運送法/本文/第60条.md|第六十条]]第一項（[[laws/道路運送法/本文/第75条.md|第七十五条]]第三項において準用する場合を含む。）又は[[laws/道路運送法/本文/第75条.md|第七十五条]]第一項の規定による検査を受けないで、又はこれに合格しないで、自動車道の供用を開始したとき（[[laws/道路運送法/本文/第59条.md|第五十九条]]第一項の規定により一般自動車道の一部につき検査を受け、これに合格した場合において、その部分につき供用を開始したときを除く。）。
- 七 不正の手段により[[laws/道路運送法/本文/第79条.md|第七十九条]]の登録又は[[laws/道路運送法/本文/第79条の6.md|第七十九条の六]]第一項の有効期間の更新の登録を受けたとき。
- 八 [[laws/道路運送法/本文/第81条.md|第八十一条]]第一項の規定による処分に違反したとき。
