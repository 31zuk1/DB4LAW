# 第百五条 

## 
次の各号のいずれかに該当する者は、五十万円以下の過料に処する。[[laws/道路運送法/本文/第12条.md|第十二条]]、[[laws/道路運送法/本文/第15条の2.md|第十五条の二]]第六項、[[laws/道路運送法/本文/第38条.md|第三十八条]]第四項（[[laws/道路運送法/本文/第70条の3.md|第七十条の三]]第三項において準用する場合を含む。）、[[laws/道路運送法/本文/第64条.md|第六十四条]]又は[[laws/道路運送法/本文/第95条.md|第九十五条]]の規定による公示若しくは表示をせず、又は虚偽の公示若しくは表示をした者[[laws/道路運送法/本文/第14条.md|第十四条]]の規定に違反した者[[laws/道路運送法/本文/第15条.md|第十五条]]第四項（[[laws/道路運送法/本文/第43条.md|第四十三条]]第五項において準用する場合を含む。）、[[laws/道路運送法/本文/第15条の2.md|第十五条の二]]第五項（[[laws/道路運送法/本文/第38条.md|第三十八条]]第三項において準用する場合を含む。）、[[laws/道路運送法/本文/第15条の3.md|第十五条の三]]第三項、[[laws/道路運送法/本文/第29条.md|第二十九条]]（[[laws/道路運送法/本文/第43条.md|第四十三条]]第五項において準用する場合を含む。）、[[laws/道路運送法/本文/第43条.md|第四十三条]]第八項若しくは第十項、[[laws/道路運送法/本文/第54条.md|第五十四条]]第三項（[[laws/道路運送法/本文/第67条.md|第六十七条]]（[[laws/道路運送法/本文/第75条.md|第七十五条]]第三項において準用する場合を含む。）及び[[laws/道路運送法/本文/第75条.md|第七十五条]]第三項において準用する場合を含む。）、[[laws/道路運送法/本文/第66条.md|第六十六条]]第三項、[[laws/道路運送法/本文/第79条の7.md|第七十九条の七]]第三項、[[laws/道路運送法/本文/第79条の10.md|第七十九条の十]]、[[laws/道路運送法/本文/第79条の11.md|第七十九条の十一]]又は[[laws/道路運送法/本文/第92条.md|第九十二条]]の規定による届出をせず、又は虚偽の届出をした者正当な理由なく、[[laws/道路運送法/本文/第23条の3.md|第二十三条の三]]の規定による命令に違反して、運行管理者資格者証を返納しなかつた者[[laws/道路運送法/本文/第29条の3.md|第二十九条の三]]（[[laws/道路運送法/本文/第43条.md|第四十三条]]第五項において準用する場合を含む。）の規定による公表をせず、又は虚偽の公表をした者[[laws/道路運送法/本文/第43条.md|第四十三条]]第六項の規定による届出をしないで、又は届け出た運賃若しくは料金によらないで、運賃又は料金を収受した者[[laws/道路運送法/本文/第68条.md|第六十八条]]第四項（[[laws/道路運送法/本文/第75条.md|第七十五条]]第三項において準用する場合を含む。）の規定による報告をせず、又は虚偽の報告をした者[[laws/道路運送法/本文/第79条の8.md|第七十九条の八]]第一項の規定による公示をせず、若しくは虚偽の公示をし、又は説明をしなかつた者

- 一 [[laws/道路運送法/本文/第12条.md|第十二条]]、[[laws/道路運送法/本文/第15条の2.md|第十五条の二]]第六項、[[laws/道路運送法/本文/第38条.md|第三十八条]]第四項（[[laws/道路運送法/本文/第70条の3.md|第七十条の三]]第三項において準用する場合を含む。）、[[laws/道路運送法/本文/第64条.md|第六十四条]]又は[[laws/道路運送法/本文/第95条.md|第九十五条]]の規定による公示若しくは表示をせず、又は虚偽の公示若しくは表示をした者
- 二 [[laws/道路運送法/本文/第14条.md|第十四条]]の規定に違反した者
- 三 [[laws/道路運送法/本文/第15条.md|第十五条]]第四項（[[laws/道路運送法/本文/第43条.md|第四十三条]]第五項において準用する場合を含む。）、[[laws/道路運送法/本文/第15条の2.md|第十五条の二]]第五項（[[laws/道路運送法/本文/第38条.md|第三十八条]]第三項において準用する場合を含む。）、[[laws/道路運送法/本文/第15条の3.md|第十五条の三]]第三項、[[laws/道路運送法/本文/第29条.md|第二十九条]]（[[laws/道路運送法/本文/第43条.md|第四十三条]]第五項において準用する場合を含む。）、[[laws/道路運送法/本文/第43条.md|第四十三条]]第八項若しくは第十項、[[laws/道路運送法/本文/第54条.md|第五十四条]]第三項（[[laws/道路運送法/本文/第67条.md|第六十七条]]（[[laws/道路運送法/本文/第75条.md|第七十五条]]第三項において準用する場合を含む。）及び[[laws/道路運送法/本文/第75条.md|第七十五条]]第三項において準用する場合を含む。）、[[laws/道路運送法/本文/第66条.md|第六十六条]]第三項、[[laws/道路運送法/本文/第79条の7.md|第七十九条の七]]第三項、[[laws/道路運送法/本文/第79条の10.md|第七十九条の十]]、[[laws/道路運送法/本文/第79条の11.md|第七十九条の十一]]又は[[laws/道路運送法/本文/第92条.md|第九十二条]]の規定による届出をせず、又は虚偽の届出をした者
- 四 正当な理由なく、[[laws/道路運送法/本文/第23条の3.md|第二十三条の三]]の規定による命令に違反して、運行管理者資格者証を返納しなかつた者
- 五 [[laws/道路運送法/本文/第29条の3.md|第二十九条の三]]（[[laws/道路運送法/本文/第43条.md|第四十三条]]第五項において準用する場合を含む。）の規定による公表をせず、又は虚偽の公表をした者
- 六 [[laws/道路運送法/本文/第43条.md|第四十三条]]第六項の規定による届出をしないで、又は届け出た運賃若しくは料金によらないで、運賃又は料金を収受した者
- 七 [[laws/道路運送法/本文/第68条.md|第六十八条]]第四項（[[laws/道路運送法/本文/第75条.md|第七十五条]]第三項において準用する場合を含む。）の規定による報告をせず、又は虚偽の報告をした者
- 八 [[laws/道路運送法/本文/第79条の8.md|第七十九条の八]]第一項の規定による公示をせず、若しくは虚偽の公示をし、又は説明をしなかつた者
