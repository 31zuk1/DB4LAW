# 第三十四条 （電磁的記録媒体による手続）

## 
次の各号に掲げる書類の提出については、当該書類に記載すべきこととされている事項を記録した電磁的記録媒体（電磁的記録に係る記録媒体をいう。）及び様式第十七の電磁的記録媒体提出票を提出することにより行うことができる。[[laws/328M50000400043/本文/第3条.md|第三条]]第一項の武器製造事業許可申請書並びに同条第二項第一号、第三号及び第四号に掲げる添付書類（同号に掲げる定款を除く。）[[laws/328M50000400043/本文/第5条.md|第五条]]の武器製造許可申請書及び添付書類[[laws/328M50000400043/本文/第8条.md|第八条]]の武器製造事業承継届出書[[laws/328M50000400043/本文/第9条.md|第九条]]第一項の武器種類変更許可申請書並びに同条第二項第一号、第三号及び第四号に掲げる添付書類[[laws/328M50000400043/本文/第11条.md|第十一条]]第一項の特定設備新設等許可申請書及び同条第二項第一号に掲げる添付書類[[laws/328M50000400043/本文/第12条.md|第十二条]]第一項の保管規程認可申請書及び保管規程[[laws/328M50000400043/本文/第13条.md|第十三条]]第一項の武器工場等移転許可申請書並びに同条第二項第一号及び第二号に掲げる添付書類[[laws/328M50000400043/本文/第14条.md|第十四条]]の武器製造事業廃止届出書

- 一 [[laws/328M50000400043/本文/第3条.md|第三条]]第一項の武器製造事業許可申請書並びに同条第二項第一号、第三号及び第四号に掲げる添付書類（同号に掲げる定款を除く。）
- 二 [[laws/328M50000400043/本文/第5条.md|第五条]]の武器製造許可申請書及び添付書類
- 三 [[laws/328M50000400043/本文/第8条.md|第八条]]の武器製造事業承継届出書
- 四 [[laws/328M50000400043/本文/第9条.md|第九条]]第一項の武器種類変更許可申請書並びに同条第二項第一号、第三号及び第四号に掲げる添付書類
- 五 [[laws/328M50000400043/本文/第11条.md|第十一条]]第一項の特定設備新設等許可申請書及び同条第二項第一号に掲げる添付書類
- 六 [[laws/328M50000400043/本文/第12条.md|第十二条]]第一項の保管規程認可申請書及び保管規程
- 七 [[laws/328M50000400043/本文/第13条.md|第十三条]]第一項の武器工場等移転許可申請書並びに同条第二項第一号及び第二号に掲げる添付書類
- 八 [[laws/328M50000400043/本文/第14条.md|第十四条]]の武器製造事業廃止届出書
