# 第八十一条 （特定関係者との間の取引）

## 
法[[laws/413M60000202016/本文/第59条.md|第五十九条]]第一号の主務省令で定める取引は、農林中央金庫が、その営む業務の種類、規模及び信用度等に照らして当該特定関係者と同様であると認められる当該特定関係者以外の者との間で、当該特定関係者との間で行う取引と同種及び同量の取引を同様の状況の下で行った場合に成立することとなる取引の条件と比べて、農林中央金庫に不利な条件で行われる取引をいう。
