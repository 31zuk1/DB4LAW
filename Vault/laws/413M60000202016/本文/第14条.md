# 第十四条 （理事会の議事録）

## 
法[[laws/413AC0000000093/本文/第27条の2.md|第二十七条の二]]第三項の規定による理事会の議事録は、書面又は電磁的記録をもって作成しなければならない。

## ２
理事会の議事録は、次に掲げる事項を内容とするものでなければならない。理事会が開催された日時及び場所（当該場所に存しない理事又は監事が理事会に出席をした場合における当該出席の方法を含む。）理事会が次に掲げるいずれかのものに該当するときは、その旨法[[laws/413AC0000000093/本文/第27条の2.md|第二十七条の二]]第六項において準用する会社法[[laws/417AC0000000086/本文/第366条.md|第三百六十六条]]第二項の規定による理事の請求を受けて招集されたもの法[[laws/417AC0000000086/会社法_law.md|第二十七条の二]]第六項において準用する会社法[[laws/417AC0000000086/本文/第366条.md|第三百六十六条]]第三項の規定により理事が招集したもの法[[laws/413M60000202016/本文/第32条.md|第三十二条]]第五項において準用する会社法[[laws/417AC0000000086/本文/第383条.md|第三百八十三条]]第二項の規定による監事の請求を受けて招集されたもの法[[laws/417AC0000000086/本文/第32条.md|第三十二条]]第五項において読み替えて準用する会社法[[laws/417AC0000000086/本文/第383条.md|第三百八十三条]]第三項の規定により監事が招集したもの理事会の議事の経過の要領及びその結果決議を要する事項について特別の利害関係を有する理事があるときは、当該理事の氏名次に掲げる規定により理事会において述べられた意見又は発言があるときは、その意見又は発言の内容の概要法[[laws/413M60000202016/本文/第32条.md|第三十二条]]第三項法[[laws/413M60000202016/本文/第32条.md|第三十二条]]第五項において準用する会社法[[laws/417AC0000000086/本文/第383条.md|第三百八十三条]]第一項本文理事会の議長が存するときは、議長の氏名

- 一 理事会が開催された日時及び場所（当該場所に存しない理事又は監事が理事会に出席をした場合における当該出席の方法を含む。）
- 二 理事会が次に掲げるいずれかのものに該当するときは、その旨
- 三 理事会の議事の経過の要領及びその結果
- 四 決議を要する事項について特別の利害関係を有する理事があるときは、当該理事の氏名
- 五 次に掲げる規定により理事会において述べられた意見又は発言があるときは、その意見又は発言の内容の概要
- 六 理事会の議長が存するときは、議長の氏名
