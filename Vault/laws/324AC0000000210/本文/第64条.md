# 第六十四条 

## 
次の各号のいずれかに該当する者は、三十万円以下の罰金に処する。[[laws/324AC0000000210/本文/第25条.md|第二十五条]]第三項の規定により全国通訳案内士の名称の使用の停止を命ぜられた者で、当該停止を命ぜられた期間中に、全国通訳案内士の名称を使用したもの[[laws/324AC0000000210/本文/第31条.md|第三十一条]]（[[laws/324AC0000000210/本文/第59条.md|第五十九条]]において準用する場合を含む。）の規定に違反した者[[laws/324AC0000000210/本文/第34条.md|第三十四条]]（[[laws/324AC0000000210/本文/第59条.md|第五十九条]]において準用する場合を含む。）の規定による報告をせず、又は虚偽の報告をした者[[laws/324AC0000000210/本文/第52条.md|第五十二条]]の規定に違反した者[[laws/324AC0000000210/本文/第57条.md|第五十七条]]において準用する[[laws/324AC0000000210/本文/第25条.md|第二十五条]]第三項の規定により地域通訳案内士の名称の使用の停止を命ぜられた者で、当該停止を命ぜられた期間中に、地域通訳案内士の名称を使用したもの[[laws/324AC0000000210/本文/第58条.md|第五十八条]]の規定に違反した者[[laws/324AC0000000210/本文/第60条.md|第六十条]]の規定に違反した者

- 一 [[laws/324AC0000000210/本文/第25条.md|第二十五条]]第三項の規定により全国通訳案内士の名称の使用の停止を命ぜられた者で、当該停止を命ぜられた期間中に、全国通訳案内士の名称を使用したもの
- 二 [[laws/324AC0000000210/本文/第31条.md|第三十一条]]（[[laws/324AC0000000210/本文/第59条.md|第五十九条]]において準用する場合を含む。）の規定に違反した者
- 三 [[laws/324AC0000000210/本文/第34条.md|第三十四条]]（[[laws/324AC0000000210/本文/第59条.md|第五十九条]]において準用する場合を含む。）の規定による報告をせず、又は虚偽の報告をした者
- 四 [[laws/324AC0000000210/本文/第52条.md|第五十二条]]の規定に違反した者
- 五 [[laws/324AC0000000210/本文/第57条.md|第五十七条]]において準用する[[laws/324AC0000000210/本文/第25条.md|第二十五条]]第三項の規定により地域通訳案内士の名称の使用の停止を命ぜられた者で、当該停止を命ぜられた期間中に、地域通訳案内士の名称を使用したもの
- 六 [[laws/324AC0000000210/本文/第58条.md|第五十八条]]の規定に違反した者
- 七 [[laws/324AC0000000210/本文/第60条.md|第六十条]]の規定に違反した者
