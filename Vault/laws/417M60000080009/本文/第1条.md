# 第一条 （文化財登録原簿の記載事項）

## 
文化財保護法（以下「法」という。）[[laws/417M60000080009/登録記念物に係る文化財登録原簿、標識等の_law.md|第百三十二条]]第一項の文化財登録原簿には、次に掲げる事項を記載するものとする。登録記念物の名称登録年月日及び登録番号登録記念物の所在地所有者の氏名又は名称及び住所管理責任者がある場合は、その氏名又は名称及び住所管理団体がある場合は、その名称及び住所登録記念物の内容を示す事項その他参考となるべき事項

- 一 登録記念物の名称
- 二 登録年月日及び登録番号
- 三 登録記念物の所在地
- 四 所有者の氏名又は名称及び住所
- 五 管理責任者がある場合は、その氏名又は名称及び住所
- 六 管理団体がある場合は、その名称及び住所
- 七 登録記念物の内容を示す事項
- 八 その他参考となるべき事項
