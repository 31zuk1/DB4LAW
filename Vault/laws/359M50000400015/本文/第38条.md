# 第三十八条 （試験事務規程の記載事項）

## 
法[[laws/359M50000400015/エネルギー管理士の試験及び免状の交付に関_law.md|第六十一条]]第二項の試験事務規程で定めるべき事項は、次のとおりとする。試験の実施の方法に関する事項手数料の収納の方法に関する事項合格証の交付及び再交付に関する事項試験事務に関して知り得た秘密の保持に関する事項試験事務に関する帳簿及び書類の保存に関する事項その他試験事務の実施に関し必要な事項

- 一 試験の実施の方法に関する事項
- 二 手数料の収納の方法に関する事項
- 三 合格証の交付及び再交付に関する事項
- 四 試験事務に関して知り得た秘密の保持に関する事項
- 五 試験事務に関する帳簿及び書類の保存に関する事項
- 六 その他試験事務の実施に関し必要な事項
