# 第四条 （業務方法書の記載事項）

## 
機構に係る通則法[[laws/413M60000800052/独立行政法人海技教育機構に関する省令_law.md|第二十八条]]第二項の主務省令で定める事項は、次のとおりとする。機構法[[laws/413M60000800052/本文/第11条.md|第十一条]]第一項第一号に規定する教授及び航海訓練に関する事項機構法[[laws/413M60000800052/本文/第11条.md|第十一条]]第一項第二号に規定する研究に関する事項機構法[[laws/413M60000800052/本文/第11条.md|第十一条]]第一項第三号に規定する附帯する業務に関する事項機構法[[laws/413M60000800052/本文/第11条.md|第十一条]]第二項の規定に基づく国際航海船舶及び国際港湾施設の保安の確保等に関する法律（平成十六年法律第三十一号）[[laws/413M60000800052/本文/第8条.md|第八条]]第一項の講習の実施に関する事項業務の委託に関する基準競争入札その他の契約に関する事項その他業務の執行に関して必要な事項

- 一 機構法[[laws/413M60000800052/本文/第11条.md|第十一条]]第一項第一号に規定する教授及び航海訓練に関する事項
- 二 機構法[[laws/413M60000800052/本文/第11条.md|第十一条]]第一項第二号に規定する研究に関する事項
- 三 機構法[[laws/413M60000800052/本文/第11条.md|第十一条]]第一項第三号に規定する附帯する業務に関する事項
- 四 機構法[[laws/413M60000800052/本文/第11条.md|第十一条]]第二項の規定に基づく国際航海船舶及び国際港湾施設の保安の確保等に関する法律（平成十六年法律第三十一号）[[laws/413M60000800052/本文/第8条.md|第八条]]第一項の講習の実施に関する事項
- 五 業務の委託に関する基準
- 六 競争入札その他の契約に関する事項
- 七 その他業務の執行に関して必要な事項
