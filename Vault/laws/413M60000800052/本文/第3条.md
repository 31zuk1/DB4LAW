# 第三条 （監事の調査の対象となる書類）

## 
機構に係る通則法[[laws/独立行政法人海技教育機構に関する省令/本文/第19条.md|第十九条]]第六項第二号に規定する主務省令で定める書類は、独立行政法人海技教育機構法（平成十一年法律第二百十四号。以下「機構法」という。）の規定に基づき国土交通大臣に提出する書類とする。
