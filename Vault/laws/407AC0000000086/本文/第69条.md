# 第六十九条 

## 
次の各号のいずれかに該当する場合においては、更生保護法人の理事、監事又は清算人は、二十万円以下の過料に処する。[[laws/更生保護事業法/本文/第8条.md|第八条]]第一項の規定による政令に違反して、登記することを怠ったとき。[[laws/更生保護事業法/本文/第14条の2.md|第十四条の二]]の規定に違反して、財産目録を備え置かず、又はこれに記載すべき事項を記載せず、若しくは不実の記載をしたとき。[[laws/更生保護事業法/本文/第27条.md|第二十七条]]第三項の規定に違反して、届出をせず、又は虚偽の届出をしたとき。[[laws/更生保護事業法/本文/第29条.md|第二十九条]]第一項の規定に違反して、書類を備え置かず、又はこれに記載すべき事項を記載せず、若しくは不実の記載をしたとき。[[laws/更生保護事業法/本文/第31条の2.md|第三十一条の二]]第二項又は[[laws/更生保護事業法/本文/第31条の11.md|第三十一条の十一]]第一項の規定に違反して、破産手続開始の申立てをしなかったとき。[[laws/更生保護事業法/本文/第31条の9.md|第三十一条の九]]第一項又は[[laws/更生保護事業法/本文/第31条の11.md|第三十一条の十一]]第一項の規定に違反して、公告をせず、又は不正の公告をしたとき。[[laws/更生保護事業法/本文/第35条.md|第三十五条]]第一項の規定に違反して、書類の作成をせず、又はこれに記載すべき事項を記載せず、若しくは不実の記載をしたとき。[[laws/更生保護事業法/本文/第35条.md|第三十五条]]第二項又は[[laws/更生保護事業法/本文/第36条.md|第三十六条]]第二項の規定に違反したとき。

- 一 [[laws/更生保護事業法/本文/第8条.md|第八条]]第一項の規定による政令に違反して、登記することを怠ったとき。
- 二 [[laws/更生保護事業法/本文/第14条の2.md|第十四条の二]]の規定に違反して、財産目録を備え置かず、又はこれに記載すべき事項を記載せず、若しくは不実の記載をしたとき。
- 三 [[laws/更生保護事業法/本文/第27条.md|第二十七条]]第三項の規定に違反して、届出をせず、又は虚偽の届出をしたとき。
- 四 [[laws/更生保護事業法/本文/第29条.md|第二十九条]]第一項の規定に違反して、書類を備え置かず、又はこれに記載すべき事項を記載せず、若しくは不実の記載をしたとき。
- 五 [[laws/更生保護事業法/本文/第31条の2.md|第三十一条の二]]第二項又は[[laws/更生保護事業法/本文/第31条の11.md|第三十一条の十一]]第一項の規定に違反して、破産手続開始の申立てをしなかったとき。
- 六 [[laws/更生保護事業法/本文/第31条の9.md|第三十一条の九]]第一項又は[[laws/更生保護事業法/本文/第31条の11.md|第三十一条の十一]]第一項の規定に違反して、公告をせず、又は不正の公告をしたとき。
- 七 [[laws/更生保護事業法/本文/第35条.md|第三十五条]]第一項の規定に違反して、書類の作成をせず、又はこれに記載すべき事項を記載せず、若しくは不実の記載をしたとき。
- 八 [[laws/更生保護事業法/本文/第35条.md|第三十五条]]第二項又は[[laws/更生保護事業法/本文/第36条.md|第三十六条]]第二項の規定に違反したとき。
