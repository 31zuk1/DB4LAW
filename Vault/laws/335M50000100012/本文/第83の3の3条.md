# 第八十三条の三の三 （変更の届出）

## 
指定全額免除申請事務取扱者は、前条第一号から第三号までに掲げる事項に変更が生じたときは、その事実を証明する書類を添えて、速やかに、その旨を厚生労働大臣に届け出なければならない。ただし、その事実を厚生労働大臣が確認できるときは、当該書類を添えることを要しない。
