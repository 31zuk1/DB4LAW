# 第八十一条 （経由）

## 
令[[laws/335M50000100012/本文/第1条の2.md|第一条の二]]第七号、第八号又は第九号に規定する申請、申出又は請求を行うべき市町村は、当該申請者、申出者又は請求者の住所地の市町村とする。
