# 第百六十条 

## 
次の各号のいずれかに該当する場合には、その違反行為をした機構の取締役、会計参与（会計参与が法人であるときは、その職務を行うべき社員）又は監査役は、百万円以下の過料に処する。[[laws/産業競争力強化法/本文/第83条.md|第八十三条]]第一項の規定に違反して、募集株式、募集新株予約権若しくは募集社債を引き受ける者の募集をし、株式交換若しくは株式交付に際して株式、社債若しくは新株予約権を発行し、又は資金を借り入れたとき。[[laws/産業競争力強化法/本文/第83条.md|第八十三条]]第二項の規定に違反して、株式を発行した旨の届出を行わなかったとき。[[laws/産業競争力強化法/本文/第99条.md|第九十九条]]第一項又は第四項の規定に違反して、登記することを怠ったとき。[[laws/産業競争力強化法/本文/第101条.md|第百一条]]第三項の規定に違反して、業務を行ったとき。[[laws/産業競争力強化法/本文/第103条.md|第百三条]]第二項又は[[laws/産業競争力強化法/本文/第105条.md|第百五条]]第一項の規定に違反して、資金供給の認可を受けなかったとき。[[laws/産業競争力強化法/本文/第106条.md|第百六条]]第三項の規定に違反して、報告をせず、又は虚偽の報告をしたとき。[[laws/産業競争力強化法/本文/第108条.md|第百八条]]第二項又は[[laws/産業競争力強化法/本文/第110条.md|第百十条]]第一項の規定に違反して、経済産業大臣に通知をしなかったとき。[[laws/産業競争力強化法/本文/第114条.md|第百十四条]]第一項の規定に違反して、株式の譲渡の認可を受けなかったとき。[[laws/産業競争力強化法/本文/第116条.md|第百十六条]]第一項の規定に違反して、予算の認可を受けなかったとき。[[laws/産業競争力強化法/本文/第118条.md|第百十八条]]の規定に違反して、貸借対照表、損益計算書若しくは事業報告書を提出せず、又は虚偽の記載若しくは記録をしたこれらのものを提出したとき。[[laws/産業競争力強化法/本文/第121条.md|第百二十一条]]第二項の規定による命令に違反したとき。

- 一 [[laws/産業競争力強化法/本文/第83条.md|第八十三条]]第一項の規定に違反して、募集株式、募集新株予約権若しくは募集社債を引き受ける者の募集をし、株式交換若しくは株式交付に際して株式、社債若しくは新株予約権を発行し、又は資金を借り入れたとき。
- 二 [[laws/産業競争力強化法/本文/第83条.md|第八十三条]]第二項の規定に違反して、株式を発行した旨の届出を行わなかったとき。
- 三 [[laws/産業競争力強化法/本文/第99条.md|第九十九条]]第一項又は第四項の規定に違反して、登記することを怠ったとき。
- 四 [[laws/産業競争力強化法/本文/第101条.md|第百一条]]第三項の規定に違反して、業務を行ったとき。
- 五 [[laws/産業競争力強化法/本文/第103条.md|第百三条]]第二項又は[[laws/産業競争力強化法/本文/第105条.md|第百五条]]第一項の規定に違反して、資金供給の認可を受けなかったとき。
- 六 [[laws/産業競争力強化法/本文/第106条.md|第百六条]]第三項の規定に違反して、報告をせず、又は虚偽の報告をしたとき。
- 七 [[laws/産業競争力強化法/本文/第108条.md|第百八条]]第二項又は[[laws/産業競争力強化法/本文/第110条.md|第百十条]]第一項の規定に違反して、経済産業大臣に通知をしなかったとき。
- 八 [[laws/産業競争力強化法/本文/第114条.md|第百十四条]]第一項の規定に違反して、株式の譲渡の認可を受けなかったとき。
- 九 [[laws/産業競争力強化法/本文/第116条.md|第百十六条]]第一項の規定に違反して、予算の認可を受けなかったとき。
- 十 [[laws/産業競争力強化法/本文/第118条.md|第百十八条]]の規定に違反して、貸借対照表、損益計算書若しくは事業報告書を提出せず、又は虚偽の記載若しくは記録をしたこれらのものを提出したとき。
- 十一 [[laws/産業競争力強化法/本文/第121条.md|第百二十一条]]第二項の規定による命令に違反したとき。
