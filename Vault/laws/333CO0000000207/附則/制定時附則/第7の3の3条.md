# 第七条の三の三 （一時金の請求ができない事由となる受給権を有したことのある給付）

## 
法附則第十三条の二第一項ただし書に規定する政令で定める給付は、平成二十四年一元化法附則第三十七条の二第一項第一号に定める場合に該当するときに支給を受けることができる同号に規定する給付とする。
