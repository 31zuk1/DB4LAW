# 第九十三条 

## 
次の各号のいずれかに該当する場合においては、医療法人の理事、監事若しくは清算人又は地域医療連携推進法人の理事、監事若しくは清算人は、これを二十万円以下の過料に処する。ただし、その行為について刑を科すべきときは、この限りでない。この法律に基づく政令の規定による登記をすることを怠つたとき。[[laws/医療法/本文/第46条.md|第四十六条]]第二項の規定による財産目録の備付けを怠り、又はこれに記載すべき事項を記載せず、若しくは虚偽の記載をしたとき。[[laws/医療法/本文/第46条の3.md|第四十六条の三]]の六において読み替えて準用する一般社団法人及び一般財団法人に関する法律第四十七条の三第一項の規定に違反して、電子提供措置（電磁的方法により社員が情報の提供を受けることができる状態に置く措置であつて、厚生労働省令で定めるものをいう。）をとらなかつたとき。[[laws/医療法/本文/第46条の3.md|第四十六条の三]]の六において準用する一般社団法人及び一般財団法人に関する法律第五十七条第二項から第四項まで、[[laws/一般社団法人及び一般財団法人に関する法律/本文/第46条の4.md|第四十六条の四]]の七において準用する同法第百九十三条第二項から第四項まで若しくは[[laws/一般社団法人及び一般財団法人に関する法律/本文/第46条の7.md|第四十六条の七]]の二第一項において準用する同法第九十七条第一項から第三項までの規定による議事録の備付けを怠り、これに記載し、若しくは記録すべき事項を記載せず、若しくは記録せず、若しくは虚偽の記載若しくは記録をし、又はこれらの規定による閲覧若しくは謄写を拒んだとき。[[laws/医療法/本文/第51条の3.md|第五十一条の三]]第一項（[[laws/医療法/本文/第70条の14.md|第七十条の十四]]において準用する場合を含む。）の規定による公告を怠り、又は虚偽の公告をしたとき。[[laws/医療法/本文/第51条の4.md|第五十一条の四]]第一項（同条第四項において準用する場合を含む。以下この号において同じ。）、第二項（同条第四項（[[laws/医療法/本文/第70条の14.md|第七十条の十四]]において読み替えて準用する場合を含む。以下この号において同じ。）及び[[laws/医療法/本文/第70条の14.md|第七十条の十四]]において読み替えて準用する場合を含む。以下この号において同じ。）若しくは第三項（[[laws/医療法/本文/第51条の4.md|第五十一条の四]]第四項及び[[laws/医療法/本文/第70条の14.md|第七十条の十四]]において読み替えて準用する場合を含む。）の規定による書類の備付けを怠り、その書類に記載すべき事項を記載せず、若しくは虚偽の記載をし、又は正当の理由がないのに[[laws/医療法/本文/第51条の4.md|第五十一条の四]]第一項若しくは第二項の規定による閲覧を拒んだとき。[[laws/医療法/本文/第52条.md|第五十二条]]第一項（[[laws/医療法/本文/第70条の14.md|第七十条の十四]]において準用する場合を含む。）又は[[laws/医療法/本文/第54条の9.md|第五十四条の九]]第五項（[[laws/医療法/本文/第70条の18.md|第七十条の十八]]第一項において準用する場合を含む。）の規定に違反して、届出をせず、又は虚偽の届出をしたとき。[[laws/医療法/本文/第54条.md|第五十四条]]（[[laws/医療法/本文/第70条の14.md|第七十条の十四]]において準用する場合を含む。）の規定に違反して剰余金の配当をしたとき。[[laws/医療法/本文/第55条.md|第五十五条]]第五項又は[[laws/医療法/本文/第56条の10.md|第五十六条の十]]第一項（これらの規定を[[laws/医療法/本文/第70条の15.md|第七十条の十五]]において準用する場合を含む。）の規定による破産手続開始の申立てを怠つたとき。[[laws/医療法/本文/第56条の8.md|第五十六条の八]]第一項又は[[laws/医療法/本文/第56条の10.md|第五十六条の十]]第一項（これらの規定を[[laws/医療法/本文/第70条の15.md|第七十条の十五]]において準用する場合を含む。）の規定による公告を怠り、又は虚偽の公告をしたとき。[[laws/医療法/本文/第58条の3.md|第五十八条の三]]第二項（[[laws/医療法/本文/第59条の2.md|第五十九条の二]]において準用する場合を含む。）又は[[laws/医療法/本文/第60条の4.md|第六十条の四]]第二項（[[laws/医療法/本文/第61条の3.md|第六十一条の三]]において準用する場合を含む。）の規定による書類の備付けを怠り、その書類に記載すべき事項を記載せず、若しくは虚偽の記載をし、又はこれらの規定による閲覧を拒んだとき。[[laws/医療法/本文/第58条の4.md|第五十八条の四]]第一項若しくは第三項（これらの規定を[[laws/医療法/本文/第59条の2.md|第五十九条の二]]において準用する場合を含む。）又は[[laws/医療法/本文/第60条の5.md|第六十条の五]]第一項若しくは第三項（これらの規定を[[laws/医療法/本文/第61条の3.md|第六十一条の三]]において準用する場合を含む。）の規定に違反して、吸収合併、新設合併、吸収分割又は新設分割をしたとき。[[laws/医療法/本文/第63条.md|第六十三条]]第一項（[[laws/医療法/本文/第70条の20.md|第七十条の二十]]において準用する場合を含む。以下この号において同じ。）の規定による報告を怠り、若しくは虚偽の報告をし、又は同項の規定による検査を拒み、妨げ、若しくは忌避したとき。[[laws/医療法/本文/第64条.md|第六十四条]]第二項（[[laws/医療法/本文/第70条の20.md|第七十条の二十]]において準用する場合を含む。）又は[[laws/医療法/本文/第64条の2.md|第六十四条の二]]第一項の規定による命令に違反して業務を行つたとき。

- 一 この法律に基づく政令の規定による登記をすることを怠つたとき。
- 二 [[laws/医療法/本文/第46条.md|第四十六条]]第二項の規定による財産目録の備付けを怠り、又はこれに記載すべき事項を記載せず、若しくは虚偽の記載をしたとき。
- 三 [[laws/医療法/本文/第46条の3.md|第四十六条の三]]の六において読み替えて準用する一般社団法人及び一般財団法人に関する法律第四十七条の三第一項の規定に違反して、電子提供措置（電磁的方法により社員が情報の提供を受けることができる状態に置く措置であつて、厚生労働省令で定めるものをいう。）をとらなかつたとき。
- 四 [[laws/医療法/本文/第46条の3.md|第四十六条の三]]の六において準用する一般社団法人及び一般財団法人に関する法律第五十七条第二項から第四項まで、[[laws/一般社団法人及び一般財団法人に関する法律/本文/第46条の4.md|第四十六条の四]]の七において準用する同法第百九十三条第二項から第四項まで若しくは[[laws/一般社団法人及び一般財団法人に関する法律/本文/第46条の7.md|第四十六条の七]]の二第一項において準用する同法第九十七条第一項から第三項までの規定による議事録の備付けを怠り、これに記載し、若しくは記録すべき事項を記載せず、若しくは記録せず、若しくは虚偽の記載若しくは記録をし、又はこれらの規定による閲覧若しくは謄写を拒んだとき。
- 五 [[laws/医療法/本文/第51条の3.md|第五十一条の三]]第一項（[[laws/医療法/本文/第70条の14.md|第七十条の十四]]において準用する場合を含む。）の規定による公告を怠り、又は虚偽の公告をしたとき。
- 六 [[laws/医療法/本文/第51条の4.md|第五十一条の四]]第一項（同条第四項において準用する場合を含む。以下この号において同じ。）、第二項（同条第四項（[[laws/医療法/本文/第70条の14.md|第七十条の十四]]において読み替えて準用する場合を含む。以下この号において同じ。）及び[[laws/医療法/本文/第70条の14.md|第七十条の十四]]において読み替えて準用する場合を含む。以下この号において同じ。）若しくは第三項（[[laws/医療法/本文/第51条の4.md|第五十一条の四]]第四項及び[[laws/医療法/本文/第70条の14.md|第七十条の十四]]において読み替えて準用する場合を含む。）の規定による書類の備付けを怠り、その書類に記載すべき事項を記載せず、若しくは虚偽の記載をし、又は正当の理由がないのに[[laws/医療法/本文/第51条の4.md|第五十一条の四]]第一項若しくは第二項の規定による閲覧を拒んだとき。
- 七 [[laws/医療法/本文/第52条.md|第五十二条]]第一項（[[laws/医療法/本文/第70条の14.md|第七十条の十四]]において準用する場合を含む。）又は[[laws/医療法/本文/第54条の9.md|第五十四条の九]]第五項（[[laws/医療法/本文/第70条の18.md|第七十条の十八]]第一項において準用する場合を含む。）の規定に違反して、届出をせず、又は虚偽の届出をしたとき。
- 八 [[laws/医療法/本文/第54条.md|第五十四条]]（[[laws/医療法/本文/第70条の14.md|第七十条の十四]]において準用する場合を含む。）の規定に違反して剰余金の配当をしたとき。
- 九 [[laws/医療法/本文/第55条.md|第五十五条]]第五項又は[[laws/医療法/本文/第56条の10.md|第五十六条の十]]第一項（これらの規定を[[laws/医療法/本文/第70条の15.md|第七十条の十五]]において準用する場合を含む。）の規定による破産手続開始の申立てを怠つたとき。
- 十 [[laws/医療法/本文/第56条の8.md|第五十六条の八]]第一項又は[[laws/医療法/本文/第56条の10.md|第五十六条の十]]第一項（これらの規定を[[laws/医療法/本文/第70条の15.md|第七十条の十五]]において準用する場合を含む。）の規定による公告を怠り、又は虚偽の公告をしたとき。
- 十一 [[laws/医療法/本文/第58条の3.md|第五十八条の三]]第二項（[[laws/医療法/本文/第59条の2.md|第五十九条の二]]において準用する場合を含む。）又は[[laws/医療法/本文/第60条の4.md|第六十条の四]]第二項（[[laws/医療法/本文/第61条の3.md|第六十一条の三]]において準用する場合を含む。）の規定による書類の備付けを怠り、その書類に記載すべき事項を記載せず、若しくは虚偽の記載をし、又はこれらの規定による閲覧を拒んだとき。
- 十二 [[laws/医療法/本文/第58条の4.md|第五十八条の四]]第一項若しくは第三項（これらの規定を[[laws/医療法/本文/第59条の2.md|第五十九条の二]]において準用する場合を含む。）又は[[laws/医療法/本文/第60条の5.md|第六十条の五]]第一項若しくは第三項（これらの規定を[[laws/医療法/本文/第61条の3.md|第六十一条の三]]において準用する場合を含む。）の規定に違反して、吸収合併、新設合併、吸収分割又は新設分割をしたとき。
- 十三 [[laws/医療法/本文/第63条.md|第六十三条]]第一項（[[laws/医療法/本文/第70条の20.md|第七十条の二十]]において準用する場合を含む。以下この号において同じ。）の規定による報告を怠り、若しくは虚偽の報告をし、又は同項の規定による検査を拒み、妨げ、若しくは忌避したとき。
- 十四 [[laws/医療法/本文/第64条.md|第六十四条]]第二項（[[laws/医療法/本文/第70条の20.md|第七十条の二十]]において準用する場合を含む。）又は[[laws/医療法/本文/第64条の2.md|第六十四条の二]]第一項の規定による命令に違反して業務を行つたとき。
