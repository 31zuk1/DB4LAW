# 第三条 （補導援護費）

## 
法[[laws/420M60000010041/更生保護委託費支弁基準_law.md|第八十五条]]第一項本文の規定によりとる措置（[[laws/420M60000010041/本文/第8条.md|第八条]]に掲げる措置を除く。）のうち、次の各号に掲げるものに要する費用の支弁は、被保護者一人一日につき百四十九円とする。宿泊場所への帰住を助けること。医療又は療養を助けること。犯罪をした者及び非行のある少年に対する社会内における処遇に関する規則（平成二十年法務省令第二十八号。以下「規則」という。）[[laws/420M60000010041/更生保護委託費支弁基準_law.md|第百十七条]]において準用する規則[[laws/420M60000010041/更生保護委託費支弁基準_law.md|第五十六条]]第一項の規定による措置教養訓練を助けること。規則[[laws/420M60000010041/更生保護委託費支弁基準_law.md|第百十七条]]において準用する規則[[laws/420M60000010041/更生保護委託費支弁基準_law.md|第五十七条]]の規定による措置。生活環境の改善又は調整を図ること。その他被保護者の改善更生を助けるために必要な措置をとること。

- 一 宿泊場所への帰住を助けること。
- 二 医療又は療養を助けること。
- 三 犯罪をした者及び非行のある少年に対する社会内における処遇に関する規則（平成二十年法務省令第二十八号。以下「規則」という。）[[laws/420M60000010041/更生保護委託費支弁基準_law.md|第百十七条]]において準用する規則[[laws/420M60000010041/更生保護委託費支弁基準_law.md|第五十六条]]第一項の規定による措置
- 四 教養訓練を助けること。
- 五 規則[[laws/420M60000010041/更生保護委託費支弁基準_law.md|第百十七条]]において準用する規則[[laws/420M60000010041/更生保護委託費支弁基準_law.md|第五十七条]]の規定による措置。
- 六 生活環境の改善又は調整を図ること。
- 七 その他被保護者の改善更生を助けるために必要な措置をとること。
