# 第二百条 

## 
次の各号のいずれかに該当する場合には、その違反行為をした漁業共済団体の役員又は清算人は、二十万円以下の過料に処する。この法律の規定により農林水産大臣の認可を受けなければならない場合において、その認可を受けなかつたとき。漁業共済団体がこの法律の規定により行うことができる事業以外の事業を行つたとき。[[laws/339AC0000000158/本文/第9条.md|第九条]]第一項の政令の規定に違反して登記をすることを怠つたとき。[[laws/339AC0000000158/本文/第15条.md|第十五条]]（[[laws/339AC0000000158/本文/第67条.md|第六十七条]]第一項において準用する場合を含む。）の規定に違反して、組合員の持分を取得し、又は質権の目的としてこれを受けたとき。[[laws/339AC0000000158/本文/第17条.md|第十七条]]第一項（[[laws/339AC0000000158/本文/第67条の4.md|第六十七条の四]]第二項において準用する場合を含む。）の規定に違反して組合への加入を拒み、又は[[laws/339AC0000000158/本文/第18条.md|第十八条]]第二項後段（[[laws/339AC0000000158/本文/第67条の4.md|第六十七条の四]]第二項において準用する場合を含む。）の規定に違反して弁明の機会を与えなかつたとき。[[laws/339AC0000000158/本文/第28条.md|第二十八条]]（[[laws/339AC0000000158/本文/第67条.md|第六十七条]]第二項において準用する場合を含む。）の規定に違反して兼職したとき。[[laws/339AC0000000158/本文/第30条.md|第三十条]]第一項、[[laws/339AC0000000158/本文/第31条.md|第三十一条]]第一項又は[[laws/339AC0000000158/本文/第32条.md|第三十二条]]（これらの規定を[[laws/339AC0000000158/本文/第67条.md|第六十七条]]第二項において準用する場合及び[[laws/339AC0000000158/本文/第32条.md|第三十二条]]の規定を[[laws/339AC0000000158/本文/第36条.md|第三十六条]]第四項後段（[[laws/339AC0000000158/本文/第67条.md|第六十七条]]第二項において準用する場合を含む。）において準用する場合を含む。）の規定に違反して総会を招集しなかつたとき。[[laws/339AC0000000158/本文/第34条.md|第三十四条]]第一項から第三項まで又は[[laws/339AC0000000158/本文/第35条.md|第三十五条]]第一項（これらの規定を[[laws/339AC0000000158/本文/第67条.md|第六十七条]]第二項において準用する場合を含む。）の規定に違反して、書類を備えて置かず、その書類に記載すべき事項を記載せず、若しくは虚偽の記載をし、又は正当な理由がないのに[[laws/339AC0000000158/本文/第34条.md|第三十四条]]第四項若しくは[[laws/339AC0000000158/本文/第35条.md|第三十五条]]第二項（これらの規定を[[laws/339AC0000000158/本文/第67条.md|第六十七条]]第二項において準用する場合を含む。）の規定による閲覧を拒んだとき。[[laws/339AC0000000158/本文/第36条.md|第三十六条]]第四項前段若しくは第五項又は[[laws/339AC0000000158/本文/第39条.md|第三十九条]]第四項（これらの規定を[[laws/339AC0000000158/本文/第67条.md|第六十七条]]第二項において準用する場合を含む。）の規定に違反したとき。[[laws/339AC0000000158/本文/第50条.md|第五十条]]第五項（[[laws/339AC0000000158/本文/第67条.md|第六十七条]]第四項において準用する場合を含む。）の規定に違反して解散の届出をしなかつたとき。[[laws/339AC0000000158/本文/第52条.md|第五十二条]]又は[[laws/339AC0000000158/本文/第53条.md|第五十三条]]第二項（これらの規定を[[laws/339AC0000000158/本文/第67条の3.md|第六十七条の三]]において準用する場合を含む。）の規定に違反して組合の合併をしたとき。[[laws/339AC0000000158/本文/第58条.md|第五十八条]]又は[[laws/339AC0000000158/本文/第60条.md|第六十条]]（これらの規定を[[laws/339AC0000000158/本文/第67条.md|第六十七条]]第四項において準用する場合を含む。）の規定に違反して、書類若しくは電磁的記録を提出せず、若しくは提供せず、又はその書類若しくは電磁的記録に記載し、若しくは記録すべき事項を記載せず、若しくは記録せず、若しくは虚偽の記載若しくは記録をしたとき。[[laws/339AC0000000158/本文/第58条の2.md|第五十八条の二]]第一項又は[[laws/339AC0000000158/本文/第58条の4.md|第五十八条の四]]第一項（これらの規定を[[laws/339AC0000000158/本文/第67条.md|第六十七条]]第四項において準用する場合を含む。）の規定による公告を怠り、又は虚偽の公告をしたとき。[[laws/339AC0000000158/本文/第58条の2.md|第五十八条の二]]第一項（[[laws/339AC0000000158/本文/第67条.md|第六十七条]]第四項において準用する場合を含む。）の期間内に債権者に弁済をしたとき。[[laws/339AC0000000158/本文/第58条の4.md|第五十八条の四]]第一項（[[laws/339AC0000000158/本文/第67条.md|第六十七条]]第四項において準用する場合を含む。）の規定に違反して破産手続開始の申立てを怠つたとき。[[laws/339AC0000000158/本文/第59条.md|第五十九条]]（[[laws/339AC0000000158/本文/第67条.md|第六十七条]]第四項において準用する場合を含む。）の規定に違反して残余財産を処分したとき。[[laws/339AC0000000158/本文/第72条.md|第七十二条]]の規定による命令に従わなかつたとき。[[laws/339AC0000000158/本文/第97条.md|第九十七条]]から[[laws/339AC0000000158/本文/第99条.md|第九十九条]]まで（これらの規定を[[laws/339AC0000000158/本文/第147条.md|第百四十七条]]（[[laws/339AC0000000158/本文/第196条の19.md|第百九十六条の十九]]において準用する場合を含む。）、[[laws/339AC0000000158/本文/第147条の2.md|第百四十七条の二]]第二項又は[[laws/339AC0000000158/本文/第196条の17.md|第百九十六条の十七]]（[[laws/339AC0000000158/本文/第196条の20.md|第百九十六条の二十]]第二項において準用する場合を含む。）において準用する場合を含む。）の規定に違反したとき。

- 一 この法律の規定により農林水産大臣の認可を受けなければならない場合において、その認可を受けなかつたとき。
- 二 漁業共済団体がこの法律の規定により行うことができる事業以外の事業を行つたとき。
- 三 [[laws/339AC0000000158/本文/第9条.md|第九条]]第一項の政令の規定に違反して登記をすることを怠つたとき。
- 四 [[laws/339AC0000000158/本文/第15条.md|第十五条]]（[[laws/339AC0000000158/本文/第67条.md|第六十七条]]第一項において準用する場合を含む。）の規定に違反して、組合員の持分を取得し、又は質権の目的としてこれを受けたとき。
- 五 [[laws/339AC0000000158/本文/第17条.md|第十七条]]第一項（[[laws/339AC0000000158/本文/第67条の4.md|第六十七条の四]]第二項において準用する場合を含む。）の規定に違反して組合への加入を拒み、又は[[laws/339AC0000000158/本文/第18条.md|第十八条]]第二項後段（[[laws/339AC0000000158/本文/第67条の4.md|第六十七条の四]]第二項において準用する場合を含む。）の規定に違反して弁明の機会を与えなかつたとき。
- 六 [[laws/339AC0000000158/本文/第28条.md|第二十八条]]（[[laws/339AC0000000158/本文/第67条.md|第六十七条]]第二項において準用する場合を含む。）の規定に違反して兼職したとき。
- 七 [[laws/339AC0000000158/本文/第30条.md|第三十条]]第一項、[[laws/339AC0000000158/本文/第31条.md|第三十一条]]第一項又は[[laws/339AC0000000158/本文/第32条.md|第三十二条]]（これらの規定を[[laws/339AC0000000158/本文/第67条.md|第六十七条]]第二項において準用する場合及び[[laws/339AC0000000158/本文/第32条.md|第三十二条]]の規定を[[laws/339AC0000000158/本文/第36条.md|第三十六条]]第四項後段（[[laws/339AC0000000158/本文/第67条.md|第六十七条]]第二項において準用する場合を含む。）において準用する場合を含む。）の規定に違反して総会を招集しなかつたとき。
- 八 [[laws/339AC0000000158/本文/第34条.md|第三十四条]]第一項から第三項まで又は[[laws/339AC0000000158/本文/第35条.md|第三十五条]]第一項（これらの規定を[[laws/339AC0000000158/本文/第67条.md|第六十七条]]第二項において準用する場合を含む。）の規定に違反して、書類を備えて置かず、その書類に記載すべき事項を記載せず、若しくは虚偽の記載をし、又は正当な理由がないのに[[laws/339AC0000000158/本文/第34条.md|第三十四条]]第四項若しくは[[laws/339AC0000000158/本文/第35条.md|第三十五条]]第二項（これらの規定を[[laws/339AC0000000158/本文/第67条.md|第六十七条]]第二項において準用する場合を含む。）の規定による閲覧を拒んだとき。
- 九 [[laws/339AC0000000158/本文/第36条.md|第三十六条]]第四項前段若しくは第五項又は[[laws/339AC0000000158/本文/第39条.md|第三十九条]]第四項（これらの規定を[[laws/339AC0000000158/本文/第67条.md|第六十七条]]第二項において準用する場合を含む。）の規定に違反したとき。
- 十 [[laws/339AC0000000158/本文/第50条.md|第五十条]]第五項（[[laws/339AC0000000158/本文/第67条.md|第六十七条]]第四項において準用する場合を含む。）の規定に違反して解散の届出をしなかつたとき。
- 十一 [[laws/339AC0000000158/本文/第52条.md|第五十二条]]又は[[laws/339AC0000000158/本文/第53条.md|第五十三条]]第二項（これらの規定を[[laws/339AC0000000158/本文/第67条の3.md|第六十七条の三]]において準用する場合を含む。）の規定に違反して組合の合併をしたとき。
- 十二 [[laws/339AC0000000158/本文/第58条.md|第五十八条]]又は[[laws/339AC0000000158/本文/第60条.md|第六十条]]（これらの規定を[[laws/339AC0000000158/本文/第67条.md|第六十七条]]第四項において準用する場合を含む。）の規定に違反して、書類若しくは電磁的記録を提出せず、若しくは提供せず、又はその書類若しくは電磁的記録に記載し、若しくは記録すべき事項を記載せず、若しくは記録せず、若しくは虚偽の記載若しくは記録をしたとき。
- 十三 [[laws/339AC0000000158/本文/第58条の2.md|第五十八条の二]]第一項又は[[laws/339AC0000000158/本文/第58条の4.md|第五十八条の四]]第一項（これらの規定を[[laws/339AC0000000158/本文/第67条.md|第六十七条]]第四項において準用する場合を含む。）の規定による公告を怠り、又は虚偽の公告をしたとき。
- 十四 [[laws/339AC0000000158/本文/第58条の2.md|第五十八条の二]]第一項（[[laws/339AC0000000158/本文/第67条.md|第六十七条]]第四項において準用する場合を含む。）の期間内に債権者に弁済をしたとき。
- 十五 [[laws/339AC0000000158/本文/第58条の4.md|第五十八条の四]]第一項（[[laws/339AC0000000158/本文/第67条.md|第六十七条]]第四項において準用する場合を含む。）の規定に違反して破産手続開始の申立てを怠つたとき。
