# 第二条 （事業実施計画の記載事項）

## 
法[[laws/独立行政法人水資源機構法施行令/本文/第13条.md|第十三条]]第一項の事業実施計画には、当該事業実施計画に係る法[[laws/独立行政法人水資源機構法施行令/本文/第12条.md|第十二条]]第一項第一号の業務に関し、次の事項を記載しなければならない。事業の名称事業の目的施設の位置及び概要貯水、放流、取水又は導水に関する計画かんがい排水に係る業務にあっては、その受益地の区域工期費用及びその負担方法その他業務に関する重要事項

- 一 事業の名称
- 二 事業の目的
- 三 施設の位置及び概要
- 四 貯水、放流、取水又は導水に関する計画
- 五 かんがい排水に係る業務にあっては、その受益地の区域
- 六 工期
- 七 費用及びその負担方法
- 八 その他業務に関する重要事項
