# 第十三条 （施設管理規程の記載事項）

## 
法[[laws/415CO0000000329/本文/第16条.md|第十六条]]第一項又は第二項の施設管理規程には、当該施設管理規程に係る法[[laws/415CO0000000329/本文/第12条.md|第十二条]]第一項第二号の業務に関し、操作を伴う施設に係るものにあっては次に掲げる事項、その他の施設に係るものにあっては第一号、第二号、第五号及び第八号から第十号までに掲げる事項を定めなければならない。施設の名称貯水、放流、取水又は導水に関する計画施設の操作の方法に関する事項（操作特定施設にあっては、その操作の基準となる水位、流量等に関する事項を含む。）放流の際にとるべき措置施設の点検及び整備に関する事項施設を操作するため必要な機械器具等の点検及び整備に関する事項水象又は気象の観測に関する事項管理を他の者に委託するときは、その委託に関する事項費用及びその負担方法その他管理に関する重要事項

- 一 施設の名称
- 二 貯水、放流、取水又は導水に関する計画
- 三 施設の操作の方法に関する事項（操作特定施設にあっては、その操作の基準となる水位、流量等に関する事項を含む。）
- 四 放流の際にとるべき措置
- 五 施設の点検及び整備に関する事項
- 六 施設を操作するため必要な機械器具等の点検及び整備に関する事項
- 七 水象又は気象の観測に関する事項
- 八 管理を他の者に委託するときは、その委託に関する事項
- 九 費用及びその負担方法
- 十 その他管理に関する重要事項
