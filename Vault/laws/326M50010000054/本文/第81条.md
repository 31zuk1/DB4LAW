# 第八十一条 （保安施設地区の指定に係る通知等の内容）

## 
法[[laws/326M50010000054/本文/第44条.md|第四十四条]]において準用する法[[laws/326M50010000054/本文/第29条.md|第二十九条]]の規定による通知は、同条に規定する事項のほか、保安施設地区の指定の有効期間についてするものとする。

## ２
法[[laws/326M50010000054/本文/第44条.md|第四十四条]]において準用する法[[laws/326M50010000054/本文/第33条.md|第三十三条]]第一項の規定（保安施設地区の指定の場合に限る。）による告示及び通知は、同項に規定する事項のほか、保安施設地区の指定の有効期間についてするものとする。
