# 第二十八条 （公認会計士等と認定設置運営事業者等との特別の利害関係）

## 
法[[laws/特定複合観光施設区域整備法に基づく設置運営事業等の監査及び会計に関する省令/本文/第28条.md|第二十八条]]第十五項に規定する公認会計士に係る国土交通省令で定めるものは、次のいずれかに該当する場合における関係とする。公認会計士法（昭和二十三年法律第百三号）第二十四条第一項又は第三項（これらの規定を同法第十六条の二第六項において準用する場合を含む。）に規定する関係を有する場合公認会計士法[[laws/特定複合観光施設区域整備法に基づく設置運営事業等の監査及び会計に関する省令/本文/第24条の2.md|第二十四条の二]]（同法第十六条の二第六項において準用する場合を含む。）の規定により同法[[laws/特定複合観光施設区域整備法に基づく設置運営事業等の監査及び会計に関する省令/本文/第2条.md|第二条]]第一項に規定する業務を行ってはならない場合公認会計士法[[laws/特定複合観光施設区域整備法に基づく設置運営事業等の監査及び会計に関する省令/本文/第24条の3.md|第二十四条の三]]第一項（同法第十六条の二第六項において準用する場合を含む。）の規定により同法[[laws/特定複合観光施設区域整備法に基づく設置運営事業等の監査及び会計に関する省令/本文/第24条の3.md|第二十四条の三]]第三項に規定する監査関連業務を行ってはならない場合監査証明を受けようとする認定設置運営事業者等（以下この条において「被監査会社」という。）について行う監査に補助者として従事する者（以下この条において「補助者」という。）が、公認会計士法[[laws/特定複合観光施設区域整備法に基づく設置運営事業等の監査及び会計に関する省令/本文/第24条.md|第二十四条]]第一項第一号若しくは第二号若しくは第三項又は公認会計士法施行令（昭和二十七年政令第三百四十三号）[[laws/特定複合観光施設区域整備法に基づく設置運営事業等の監査及び会計に関する省令/本文/第7条.md|第七条]]第一項第一号、第四号から第六号まで、第八号若しくは第九号に掲げる関係を有する場合公認会計士の二親等以内の親族が、公認会計士法[[laws/特定複合観光施設区域整備法に基づく設置運営事業等の監査及び会計に関する省令/本文/第24条.md|第二十四条]]第一項第一号又は公認会計士法施行令[[laws/特定複合観光施設区域整備法に基づく設置運営事業等の監査及び会計に関する省令/本文/第7条.md|第七条]]第一項第一号に掲げる関係を有する場合公認会計士若しくはその配偶者又は補助者が、被監査会社の連結子会社又は持分法適用会社（連結財務諸表の用語、様式及び作成方法に関する規則（昭和五十一年大蔵省令第二十八号）[[laws/特定複合観光施設区域整備法に基づく設置運営事業等の監査及び会計に関する省令/本文/第2条.md|第二条]]第八号に規定する持分法が適用される非連結子会社（同条第六号に規定する非連結子会社をいう。）又は関連会社（同条第七号に規定する関連会社をいう。）をいう。次項において同じ。）との間に公認会計士法[[laws/特定複合観光施設区域整備法に基づく設置運営事業等の監査及び会計に関する省令/本文/第24条.md|第二十四条]]第一項第一号若しくは第二号若しくは第三項又は公認会計士法施行令[[laws/特定複合観光施設区域整備法に基づく設置運営事業等の監査及び会計に関する省令/本文/第7条.md|第七条]]第一項第一号若しくは第四号から第七号まで（補助者にあっては、同号を除く。）に掲げる関係を有する場合

- 一 公認会計士法（昭和二十三年法律第百三号）第二十四条第一項又は第三項（これらの規定を同法第十六条の二第六項において準用する場合を含む。）に規定する関係を有する場合

- 三 公認会計士法[[laws/特定複合観光施設区域整備法に基づく設置運営事業等の監査及び会計に関する省令/本文/第24条の3.md|第二十四条の三]]第一項（同法第十六条の二第六項において準用する場合を含む。）の規定により同法[[laws/特定複合観光施設区域整備法に基づく設置運営事業等の監査及び会計に関する省令/本文/第24条の3.md|第二十四条の三]]第三項に規定する監査関連業務を行ってはならない場合
- 四 監査証明を受けようとする認定設置運営事業者等（以下この条において「被監査会社」という。）について行う監査に補助者として従事する者（以下この条において「補助者」という。）が、公認会計士法[[laws/特定複合観光施設区域整備法に基づく設置運営事業等の監査及び会計に関する省令/本文/第24条.md|第二十四条]]第一項第一号若しくは第二号若しくは第三項又は公認会計士法施行令（昭和二十七年政令第三百四十三号）[[laws/特定複合観光施設区域整備法に基づく設置運営事業等の監査及び会計に関する省令/本文/第7条.md|第七条]]第一項第一号、第四号から第六号まで、第八号若しくは第九号に掲げる関係を有する場合
- 五 公認会計士の二親等以内の親族が、公認会計士法[[laws/特定複合観光施設区域整備法に基づく設置運営事業等の監査及び会計に関する省令/本文/第24条.md|第二十四条]]第一項第一号又は公認会計士法施行令[[laws/特定複合観光施設区域整備法に基づく設置運営事業等の監査及び会計に関する省令/本文/第7条.md|第七条]]第一項第一号に掲げる関係を有する場合
- 六 公認会計士若しくはその配偶者又は補助者が、被監査会社の連結子会社又は持分法適用会社（連結財務諸表の用語、様式及び作成方法に関する規則（昭和五十一年大蔵省令第二十八号）[[laws/特定複合観光施設区域整備法に基づく設置運営事業等の監査及び会計に関する省令/本文/第2条.md|第二条]]第八号に規定する持分法が適用される非連結子会社（同条第六号に規定する非連結子会社をいう。）又は関連会社（同条第七号に規定する関連会社をいう。）をいう。次項において同じ。）との間に公認会計士法[[laws/特定複合観光施設区域整備法に基づく設置運営事業等の監査及び会計に関する省令/本文/第24条.md|第二十四条]]第一項第一号若しくは第二号若しくは第三項又は公認会計士法施行令[[laws/特定複合観光施設区域整備法に基づく設置運営事業等の監査及び会計に関する省令/本文/第7条.md|第七条]]第一項第一号若しくは第四号から第七号まで（補助者にあっては、同号を除く。）に掲げる関係を有する場合
