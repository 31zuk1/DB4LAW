# 第七十一条 

## 
次の各号のいずれかに該当するときは、その違反行為をした者は、六月以下の拘禁刑又は五十万円以下の罰金に処する。[[laws/外国為替及び外国貿易法/本文/第19条.md|第十九条]]第三項の規定による届出をせず、又は虚偽の届出をして、同条第一項に規定する支払手段又は証券若しくは貴金属を輸出し、又は輸入したとき。[[laws/外国為替及び外国貿易法/本文/第55条.md|第五十五条]]第一項の規定による報告をせず、又は虚偽の報告をしたとき。[[laws/外国為替及び外国貿易法/本文/第55条の3.md|第五十五条の三]]第一項又は第二項の規定による報告をせず、又は虚偽の報告をしたとき。[[laws/外国為替及び外国貿易法/本文/第55条の3.md|第五十五条の三]]第五項の規定による帳簿書類を作成せず、これに同項に規定する事項を記載せず、若しくは虚偽の記載をし、又はこれを保存しなかつたとき。[[laws/外国為替及び外国貿易法/本文/第55条の4.md|第五十五条の四]]の規定による報告をせず、又は虚偽の報告をしたとき。[[laws/外国為替及び外国貿易法/本文/第55条の5.md|第五十五条の五]]第一項（同条第二項又は第三項の規定によりみなして適用する場合を含む。）の規定による報告をせず、又は虚偽の報告をしたとき。[[laws/外国為替及び外国貿易法/本文/第55条の6.md|第五十五条の六]]第一項の規定による報告をせず、又は虚偽の報告をしたとき。[[laws/外国為替及び外国貿易法/本文/第55条の7.md|第五十五条の七]]の規定に基づく命令の規定に違反して、報告をせず、又は虚偽の報告をしたとき。[[laws/外国為替及び外国貿易法/本文/第55条の8.md|第五十五条の八]]の規定に基づく命令の規定に違反して、報告をせず、又は虚偽の報告をしたとき。[[laws/外国為替及び外国貿易法/本文/第55条の9.md|第五十五条の九]]の四第二項の規定による命令に違反したとき。[[laws/外国為替及び外国貿易法/本文/第55条の12.md|第五十五条の十二]]第二項の規定による命令に違反したとき。[[laws/外国為替及び外国貿易法/本文/第68条.md|第六十八条]]第一項の規定による検査を拒み、妨げ、又は忌避したとき。[[laws/外国為替及び外国貿易法/本文/第68条.md|第六十八条]]第一項の規定による質問に対して答弁をせず、又は虚偽の答弁をしたとき。

- 一 [[laws/外国為替及び外国貿易法/本文/第19条.md|第十九条]]第三項の規定による届出をせず、又は虚偽の届出をして、同条第一項に規定する支払手段又は証券若しくは貴金属を輸出し、又は輸入したとき。
- 二 [[laws/外国為替及び外国貿易法/本文/第55条.md|第五十五条]]第一項の規定による報告をせず、又は虚偽の報告をしたとき。
- 三 [[laws/外国為替及び外国貿易法/本文/第55条の3.md|第五十五条の三]]第一項又は第二項の規定による報告をせず、又は虚偽の報告をしたとき。
- 四 [[laws/外国為替及び外国貿易法/本文/第55条の3.md|第五十五条の三]]第五項の規定による帳簿書類を作成せず、これに同項に規定する事項を記載せず、若しくは虚偽の記載をし、又はこれを保存しなかつたとき。
- 五 [[laws/外国為替及び外国貿易法/本文/第55条の4.md|第五十五条の四]]の規定による報告をせず、又は虚偽の報告をしたとき。
- 六 [[laws/外国為替及び外国貿易法/本文/第55条の5.md|第五十五条の五]]第一項（同条第二項又は第三項の規定によりみなして適用する場合を含む。）の規定による報告をせず、又は虚偽の報告をしたとき。
- 七 [[laws/外国為替及び外国貿易法/本文/第55条の6.md|第五十五条の六]]第一項の規定による報告をせず、又は虚偽の報告をしたとき。
- 八 [[laws/外国為替及び外国貿易法/本文/第55条の7.md|第五十五条の七]]の規定に基づく命令の規定に違反して、報告をせず、又は虚偽の報告をしたとき。
- 九 [[laws/外国為替及び外国貿易法/本文/第55条の8.md|第五十五条の八]]の規定に基づく命令の規定に違反して、報告をせず、又は虚偽の報告をしたとき。
- 十 [[laws/外国為替及び外国貿易法/本文/第55条の9.md|第五十五条の九]]の四第二項の規定による命令に違反したとき。
- 十一 [[laws/外国為替及び外国貿易法/本文/第55条の12.md|第五十五条の十二]]第二項の規定による命令に違反したとき。
- 十二 [[laws/外国為替及び外国貿易法/本文/第68条.md|第六十八条]]第一項の規定による検査を拒み、妨げ、又は忌避したとき。
- 十三 [[laws/外国為替及び外国貿易法/本文/第68条.md|第六十八条]]第一項の規定による質問に対して答弁をせず、又は虚偽の答弁をしたとき。
