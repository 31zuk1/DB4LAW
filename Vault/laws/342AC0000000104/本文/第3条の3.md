# 第三条の三 （昭和四十五年度における旧法による年金の額の改定）

## 
[[laws/342AC0000000104/本文/第1条の3.md|第一条の三]]の規定は、前条の規定の適用を受ける年金（[[laws/342AC0000000104/本文/第3条.md|第三条]]第一項の規定の適用を受ける年金に係るものに限る。）の額の改定について、[[laws/342AC0000000104/本文/第2条の3.md|第二条の三]]の規定は、前条の規定の適用を受ける年金（[[laws/342AC0000000104/本文/第3条.md|第三条]]第二項の規定の適用を受ける年金に係るものに限る。）の額の改定について、それぞれ準用する。
