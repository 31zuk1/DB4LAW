# 第三条の三 （運搬証明書の再交付）

## 
運搬証明書の交付を受けた者は、当該運搬証明書を喪失し、汚損し、又は盗取されたときは、国家公安委員会規則で定めるところにより、その事由を付して交付を受けた都道府県公安委員会にその再交付を文書で申請しなければならない。
