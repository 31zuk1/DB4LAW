# 第六十五条 

## 
次の各号のいずれかに該当する場合には、その違反行為をした機構の取締役、会計参与若しくはその職務を行うべき社員又は監査役は、百万円以下の過料に処する。[[laws/株式会社産業再生機構法/本文/第4条.md|第四条]]第二項の規定に違反して、募集株式を引き受ける者の募集をしたとき。[[laws/株式会社産業再生機構法/本文/第18条.md|第十八条]]第一項の規定に違反して、登記することを怠ったとき。[[laws/株式会社産業再生機構法/本文/第19条.md|第十九条]]第二項の規定に違反して、業務を行ったとき。[[laws/株式会社産業再生機構法/本文/第22条.md|第二十二条]]第六項、[[laws/株式会社産業再生機構法/本文/第25条.md|第二十五条]]第四項又は[[laws/株式会社産業再生機構法/本文/第29条.md|第二十九条]]第一項の規定に違反して、主務大臣の意見を聴かなかったとき。[[laws/株式会社産業再生機構法/本文/第35条.md|第三十五条]]の規定に違反して、予算の認可を受けなかったとき。[[laws/株式会社産業再生機構法/本文/第38条.md|第三十八条]]の規定に違反して、貸借対照表、損益計算書及び事業報告書の承認を受けなかったとき。[[laws/株式会社産業再生機構法/本文/第39条.md|第三十九条]]第一項の規定に違反して、資金を借り入れ、又は社債を発行したとき。[[laws/株式会社産業再生機構法/本文/第41条.md|第四十一条]]第二項の規定による命令に違反したとき。

- 一 [[laws/株式会社産業再生機構法/本文/第4条.md|第四条]]第二項の規定に違反して、募集株式を引き受ける者の募集をしたとき。
- 二 [[laws/株式会社産業再生機構法/本文/第18条.md|第十八条]]第一項の規定に違反して、登記することを怠ったとき。
- 三 [[laws/株式会社産業再生機構法/本文/第19条.md|第十九条]]第二項の規定に違反して、業務を行ったとき。
- 四 [[laws/株式会社産業再生機構法/本文/第22条.md|第二十二条]]第六項、[[laws/株式会社産業再生機構法/本文/第25条.md|第二十五条]]第四項又は[[laws/株式会社産業再生機構法/本文/第29条.md|第二十九条]]第一項の規定に違反して、主務大臣の意見を聴かなかったとき。
- 五 [[laws/株式会社産業再生機構法/本文/第35条.md|第三十五条]]の規定に違反して、予算の認可を受けなかったとき。
- 六 [[laws/株式会社産業再生機構法/本文/第38条.md|第三十八条]]の規定に違反して、貸借対照表、損益計算書及び事業報告書の承認を受けなかったとき。
- 七 [[laws/株式会社産業再生機構法/本文/第39条.md|第三十九条]]第一項の規定に違反して、資金を借り入れ、又は社債を発行したとき。
- 八 [[laws/株式会社産業再生機構法/本文/第41条.md|第四十一条]]第二項の規定による命令に違反したとき。
