# 第二十六条の五十八 （貸金業協会の登録事務）

## 
金融庁長官は、法[[laws/358AC1000000032/本文/第24条の33.md|第二十四条の三十三]]第一項の規定に基づき、貸金業協会に、次に掲げる主任者登録に関する事務の全部又は一部を行わせるものとする。主任者登録法[[laws/358AC1000000032/本文/第24条の26.md|第二十四条の二十六]]第一項（法[[laws/358AC1000000032/本文/第24条の32.md|第二十四条の三十二]]第二項において準用する場合を含む。）の規定による登録申請書の受理法[[laws/358AC1000000032/本文/第24条の26.md|第二十四条の二十六]]第四項及び[[laws/358AC1000000032/本文/第24条の27.md|第二十四条の二十七]]第二項（これらの規定を法[[laws/358AC1000000032/本文/第24条の32.md|第二十四条の三十二]]第二項において準用する場合を含む。）の規定による通知法[[laws/358AC1000000032/本文/第24条の27.md|第二十四条の二十七]]第一項（法[[laws/358AC1000000032/本文/第24条の32.md|第二十四条の三十二]]第二項において準用する場合を含む。）の規定による主任者登録の拒否法[[laws/358AC1000000032/本文/第24条の28.md|第二十四条の二十八]]の規定による主任者登録の変更の申請の受理法[[laws/358AC1000000032/本文/第24条の29.md|第二十四条の二十九]]の規定による死亡等の届出の受理法[[laws/358AC1000000032/本文/第24条の30.md|第二十四条の三十]]の規定による主任者登録の取消し法[[laws/358AC1000000032/本文/第24条の31.md|第二十四条の三十一]]の規定による主任者登録の抹消

- 一 主任者登録
- 二 法[[laws/358AC1000000032/本文/第24条の26.md|第二十四条の二十六]]第一項（法[[laws/358AC1000000032/本文/第24条の32.md|第二十四条の三十二]]第二項において準用する場合を含む。）の規定による登録申請書の受理
- 三 法[[laws/358AC1000000032/本文/第24条の26.md|第二十四条の二十六]]第四項及び[[laws/358AC1000000032/本文/第24条の27.md|第二十四条の二十七]]第二項（これらの規定を法[[laws/358AC1000000032/本文/第24条の32.md|第二十四条の三十二]]第二項において準用する場合を含む。）の規定による通知
- 四 法[[laws/358AC1000000032/本文/第24条の27.md|第二十四条の二十七]]第一項（法[[laws/358AC1000000032/本文/第24条の32.md|第二十四条の三十二]]第二項において準用する場合を含む。）の規定による主任者登録の拒否
- 五 法[[laws/358AC1000000032/本文/第24条の28.md|第二十四条の二十八]]の規定による主任者登録の変更の申請の受理
- 六 法[[laws/358AC1000000032/本文/第24条の29.md|第二十四条の二十九]]の規定による死亡等の届出の受理
- 七 法[[laws/358AC1000000032/本文/第24条の30.md|第二十四条の三十]]の規定による主任者登録の取消し
- 八 法[[laws/358AC1000000032/本文/第24条の31.md|第二十四条の三十一]]の規定による主任者登録の抹消
