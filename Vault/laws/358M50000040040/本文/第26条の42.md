# 第二十六条の四十二 （試験事務規程の記載事項）

## 
法[[laws/358AC1000000032/本文/第24条の13.md|第二十四条の十三]]第一項前段に規定する内閣府令で定める試験事務の実施に関する事項は、次のとおりとする。組織及び運営に関する事項試験事務を行う時間及び休日に関する事項試験事務を行う事務所及び試験地に関する事項受験手数料（法[[laws/358AC1000000032/本文/第24条の22.md|第二十四条の二十二]]第一項に規定する受験手数料をいう。）の収納の方法に関する事項試験委員の選任に関する事項試験事務に関する秘密の保持に関する事項試験事務の一部の処理の第三者への委託に関する事項試験事務に関する帳簿及び書類の管理に関する事項資格試験の実施に係る公示の方法に関する事項その他試験事務の実施に関し必要な事項

- 一 組織及び運営に関する事項
- 二 試験事務を行う時間及び休日に関する事項
- 三 試験事務を行う事務所及び試験地に関する事項
- 四 受験手数料（法[[laws/358AC1000000032/本文/第24条の22.md|第二十四条の二十二]]第一項に規定する受験手数料をいう。）の収納の方法に関する事項
- 五 試験委員の選任に関する事項
- 六 試験事務に関する秘密の保持に関する事項
- 七 試験事務の一部の処理の第三者への委託に関する事項
- 八 試験事務に関する帳簿及び書類の管理に関する事項
- 九 資格試験の実施に係る公示の方法に関する事項
- 十 その他試験事務の実施に関し必要な事項
