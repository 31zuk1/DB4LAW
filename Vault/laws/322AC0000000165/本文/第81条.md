# 第八十一条 （郵便禁制品を差し出す罪）

## 
[[laws/322AC0000000165/本文/第12条.md|第十二条]]の規定の違反があつたときは、その違反行為をした者を五十万円以下の罰金に処し、その郵便物として差し出した物を没収する。
