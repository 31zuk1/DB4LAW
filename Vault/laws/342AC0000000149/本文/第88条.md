# 第八十八条 （公示）

## 
経済産業大臣は、次の場合には、その旨を官報に公示しなければならない。[[laws/342AC0000000149/本文/第35条の6.md|第三十五条の六]]第一項の認定をしたとき。[[laws/342AC0000000149/本文/第35条の6.md|第三十五条の六]]第一項の認定を取り消したとき。[[laws/342AC0000000149/本文/第37条の5.md|第三十七条の五]]第四項の指定をしたとき。[[laws/342AC0000000149/本文/第38条の4.md|第三十八条の四]]第二項第二号の指定をしたとき。[[laws/342AC0000000149/本文/第38条の6.md|第三十八条の六]]第一項の指定をしたとき。[[laws/342AC0000000149/本文/第38条の9.md|第三十八条の九]]第一項の指定をしたとき。[[laws/342AC0000000149/本文/第38条の17.md|第三十八条の十七]]第一項の規定による届出があつたとき。[[laws/342AC0000000149/本文/第38条の19.md|第三十八条の十九]]第一項の許可をしたとき。[[laws/342AC0000000149/本文/第38条の26.md|第三十八条の二十六]]第一項若しくは第二項の規定により指定を取り消し、又は同項の規定により試験事務の全部若しくは一部の停止を命じたとき。[[laws/342AC0000000149/本文/第47条.md|第四十七条]]第一項の登録をしたとき。[[laws/342AC0000000149/本文/第50条.md|第五十条]]の規定により表示を付することを禁止したとき。[[laws/342AC0000000149/本文/第56条.md|第五十六条]]（[[laws/342AC0000000149/本文/第63条.md|第六十三条]]第二項において準用する場合を含む。）の規定による届出があつたとき。[[laws/342AC0000000149/本文/第58条.md|第五十八条]]（[[laws/342AC0000000149/本文/第63条.md|第六十三条]]第二項において準用する場合を含む。）の規定による届出があつたとき。[[laws/342AC0000000149/本文/第61条.md|第六十一条]]の規定により登録を取り消し、又は適合性検査の業務の停止を命じたとき。[[laws/342AC0000000149/本文/第62条.md|第六十二条]]第一項の規定により経済産業大臣が適合性検査の業務の全部若しくは一部を自ら行うものとするとき、又は自ら行つていた適合性検査の業務の全部若しくは一部を行わないこととするとき。[[laws/342AC0000000149/本文/第62条.md|第六十二条]]第二項の規定により経済産業大臣が機構に適合性検査の業務の全部若しくは一部を行わせることとするとき、又は機構に行わせていた適合性検査の業務の全部若しくは一部を行わせないこととするとき。[[laws/342AC0000000149/本文/第64条.md|第六十四条]]第一項の規定により登録を取り消したとき。

- 一 [[laws/342AC0000000149/本文/第35条の6.md|第三十五条の六]]第一項の認定をしたとき。
- 一の二 [[laws/342AC0000000149/本文/第35条の6.md|第三十五条の六]]第一項の認定を取り消したとき。

- 二の四 [[laws/342AC0000000149/本文/第38条の9.md|第三十八条の九]]第一項の指定をしたとき。

- 六 [[laws/342AC0000000149/本文/第58条.md|第五十八条]]（[[laws/342AC0000000149/本文/第63条.md|第六十三条]]第二項において準用する場合を含む。）の規定による届出があつたとき。

- 八 [[laws/342AC0000000149/本文/第62条.md|第六十二条]]第一項の規定により経済産業大臣が適合性検査の業務の全部若しくは一部を自ら行うものとするとき、又は自ら行つていた適合性検査の業務の全部若しくは一部を行わないこととするとき。

- 十 [[laws/342AC0000000149/本文/第64条.md|第六十四条]]第一項の規定により登録を取り消したとき。
## ２
都道府県知事は、次の場合には、その旨を公示しなければならない。[[laws/342AC0000000149/本文/第35条の6.md|第三十五条の六]]第一項の認定をしたとき。[[laws/342AC0000000149/本文/第35条の6.md|第三十五条の六]]第一項の認定を取り消したとき。[[laws/342AC0000000149/本文/第38条の6.md|第三十八条の六]]第一項の規定により協会又は指定試験機関に試験事務を行わせることとしたとき。[[laws/342AC0000000149/本文/第38条の6.md|第三十八条の六]]第一項の規定により協会又は指定試験機関に行わせることとした試験事務を協会又は指定試験機関に行わせないこととしたとき。[[laws/342AC0000000149/本文/第38条の17.md|第三十八条の十七]]第二項の規定による届出があつたとき。[[laws/342AC0000000149/本文/第38条の27.md|第三十八条の二十七]]第一項の規定により試験事務の全部若しくは一部を自ら行うこととするとき、又は同項の規定により自ら行つていた試験事務の全部若しくは一部を行わないこととするとき。

- 二 [[laws/342AC0000000149/本文/第38条の6.md|第三十八条の六]]第一項の規定により協会又は指定試験機関に行わせることとした試験事務を協会又は指定試験機関に行わせないこととしたとき。
