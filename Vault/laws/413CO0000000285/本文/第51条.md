# 第五十一条 （認定農林中央金庫電子決済等代行事業者協会に係る名称の使用制限の適用除外）

## 
法[[laws/413AC0000000093/本文/第95条の5.md|第九十五条の五]]の十第一項において準用する銀行法[[laws/413CO0000000285/農林中央金庫法施行令_law.md|第五十二条の六十一]]の二十一第二項の政令で定めるものは、次に掲げる認定のいずれかを受けた者とする。農業協同組合法第九十二条の五の六の規定による認定水産業協同組合法[[laws/323AC0000000242/本文/第114条.md|第百十四条]]の規定による認定協同組合による金融事業に関する法律（昭和二十四年法律第百八十三号）[[laws/323AC0000000242/水産業協同組合法_law.md|第六条の五]]の七の規定による認定労働金庫法（昭和二十八年法律第二百二十七号）第八十九条の十の規定による認定銀行法[[laws/323AC0000000242/水産業協同組合法_law.md|第五十二条の六十一]]の十九の規定による認定株式会社商工組合中央金庫法（平成十九年法律第七十四号）第六十条の二十一の規定による認定

- 一 農業協同組合法第九十二条の五の六の規定による認定
- 二 水産業協同組合法第百十四条の規定による認定
- 三 協同組合による金融事業に関する法律（昭和二十四年法律第百八十三号）[[laws/413CO0000000285/農林中央金庫法施行令_law.md|第六条の五]]の七の規定による認定
- 四 労働金庫法（昭和二十八年法律第二百二十七号）第八十九条の十の規定による認定
- 五 銀行法[[laws/413CO0000000285/農林中央金庫法施行令_law.md|第五十二条の六十一]]の十九の規定による認定
- 六 株式会社商工組合中央金庫法（平成十九年法律第七十四号）第六十条の二十一の規定による認定
## ２
法[[laws/413AC0000000093/本文/第95条の5.md|第九十五条の五]]の十第一項において準用する銀行法[[laws/413CO0000000285/農林中央金庫法施行令_law.md|第五十二条の六十一]]の二十一第三項の政令で定めるものは、次に掲げる者のいずれかの社員である者とする。農業協同組合法第九十二条の五の七に規定する認定特定信用事業電子決済等代行事業者協会水産業協同組合法[[laws/323AC0000000242/本文/第115条.md|第百十五条]]に規定する認定特定信用事業電子決済等代行事業者協会協同組合による金融事業に関する法律[[laws/323AC0000000242/水産業協同組合法_law.md|第六条の五]]の八に規定する認定信用協同組合電子決済等代行事業者協会労働金庫法[[laws/323AC0000000242/水産業協同組合法_law.md|第八十九条の十一]]に規定する認定労働金庫電子決済等代行事業者協会銀行法[[laws/323AC0000000242/本文/第2条.md|第二条]]第二十三項に規定する認定電子決済等代行事業者協会株式会社商工組合中央金庫法[[laws/323AC0000000242/水産業協同組合法_law.md|第六十条の二]]第三項に規定する認定商工組合中央金庫電子決済等代行事業者協会

- 一 農業協同組合法第九十二条の五の七に規定する認定特定信用事業電子決済等代行事業者協会
- 二 水産業協同組合法第百十五条に規定する認定特定信用事業電子決済等代行事業者協会
- 三 協同組合による金融事業に関する法律[[laws/413CO0000000285/農林中央金庫法施行令_law.md|第六条の五]]の八に規定する認定信用協同組合電子決済等代行事業者協会
- 四 労働金庫法第八十九条の十一に規定する認定労働金庫電子決済等代行事業者協会
- 五 銀行法[[laws/413CO0000000285/本文/第2条.md|第二条]]第二十三項に規定する認定電子決済等代行事業者協会
- 六 株式会社商工組合中央金庫法[[laws/413CO0000000285/農林中央金庫法施行令_law.md|第六十条の二]]第三項に規定する認定商工組合中央金庫電子決済等代行事業者協会
