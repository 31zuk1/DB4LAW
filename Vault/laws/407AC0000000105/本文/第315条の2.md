# 第三百十五条の二 

## 
次に掲げる違反があった場合においては、その違反行為をした者は、二年以下の拘禁刑若しくは三百万円以下の罰金に処し、又はこれを併科する。[[laws/407AC0000000105/本文/第271条の18.md|第二百七十一条の十八]]第一項の規定による内閣総理大臣の認可を受けないで、同項各号に掲げる取引若しくは行為により保険会社を子会社とする持株会社になったとき、又は保険会社を子会社とする持株会社を設立したとき。[[laws/407AC0000000105/本文/第271条の18.md|第二百七十一条の十八]]第三項の規定に違反して同項に規定する猶予期限日を超えて保険会社を子会社とする持株会社であったとき。[[laws/407AC0000000105/本文/第271条の18.md|第二百七十一条の十八]]第五項の規定による命令に違反して保険会社を子会社とする持株会社であったとき又は[[laws/407AC0000000105/本文/第271条の30.md|第二百七十一条の三十]]第二項の規定に違反して同項に規定する内閣総理大臣が指定する期間を超えて保険会社を子会社とする持株会社であったとき。[[laws/407AC0000000105/本文/第272条の35.md|第二百七十二条の三十五]]第一項の規定による内閣総理大臣の承認を受けないで、同項各号に掲げる取引若しくは行為により少額短期保険業者を子会社とする持株会社になったとき、又は少額短期保険業者を子会社とする持株会社を設立したとき。[[laws/407AC0000000105/本文/第272条の35.md|第二百七十二条の三十五]]第三項の規定に違反して同項に規定する猶予期限日を超えて少額短期保険業者を子会社とする持株会社であったとき。[[laws/407AC0000000105/本文/第272条の35.md|第二百七十二条の三十五]]第五項の規定による命令に違反して少額短期保険業者を子会社とする持株会社であったとき、又は[[laws/407AC0000000105/本文/第272条の40.md|第二百七十二条の四十]]第二項において準用する[[laws/407AC0000000105/本文/第271条の30.md|第二百七十一条の三十]]第二項の規定に違反して同項に規定する内閣総理大臣が指定する期間を超えて少額短期保険業者を子会社とする持株会社であったとき。

- 一 [[laws/407AC0000000105/本文/第271条の18.md|第二百七十一条の十八]]第一項の規定による内閣総理大臣の認可を受けないで、同項各号に掲げる取引若しくは行為により保険会社を子会社とする持株会社になったとき、又は保険会社を子会社とする持株会社を設立したとき。
- 二 [[laws/407AC0000000105/本文/第271条の18.md|第二百七十一条の十八]]第三項の規定に違反して同項に規定する猶予期限日を超えて保険会社を子会社とする持株会社であったとき。
- 三 [[laws/407AC0000000105/本文/第271条の18.md|第二百七十一条の十八]]第五項の規定による命令に違反して保険会社を子会社とする持株会社であったとき又は[[laws/407AC0000000105/本文/第271条の30.md|第二百七十一条の三十]]第二項の規定に違反して同項に規定する内閣総理大臣が指定する期間を超えて保険会社を子会社とする持株会社であったとき。
- 四 [[laws/407AC0000000105/本文/第272条の35.md|第二百七十二条の三十五]]第一項の規定による内閣総理大臣の承認を受けないで、同項各号に掲げる取引若しくは行為により少額短期保険業者を子会社とする持株会社になったとき、又は少額短期保険業者を子会社とする持株会社を設立したとき。
- 五 [[laws/407AC0000000105/本文/第272条の35.md|第二百七十二条の三十五]]第三項の規定に違反して同項に規定する猶予期限日を超えて少額短期保険業者を子会社とする持株会社であったとき。
- 六 [[laws/407AC0000000105/本文/第272条の35.md|第二百七十二条の三十五]]第五項の規定による命令に違反して少額短期保険業者を子会社とする持株会社であったとき、又は[[laws/407AC0000000105/本文/第272条の40.md|第二百七十二条の四十]]第二項において準用する[[laws/407AC0000000105/本文/第271条の30.md|第二百七十一条の三十]]第二項の規定に違反して同項に規定する内閣総理大臣が指定する期間を超えて少額短期保険業者を子会社とする持株会社であったとき。
