# 第三百十七条の二 

## 
次の各号のいずれかに該当する者は、一年以下の拘禁刑若しくは百万円以下の罰金に処し、又はこれを併科する。[[laws/保険業法/本文/第99条.md|第九十九条]]第八項（[[laws/保険業法/本文/第199条.md|第百九十九条]]において準用する場合を含む。）において準用する信託業法[[laws/保険業法/本文/第11条.md|第十一条]]第五項の規定に違反して、保険金信託業務を開始した者[[laws/保険業法/本文/第99条.md|第九十九条]]第八項（[[laws/保険業法/本文/第199条.md|第百九十九条]]において準用する場合を含む。）において準用する信託業法[[laws/保険業法/本文/第24条の2.md|第二十四条の二]]又は[[laws/保険業法/本文/第300条の2.md|第三百条の二]]において準用する金融商品取引法第三十九条第二項の規定に違反した者[[laws/金融商品取引法/本文/第272条の2.md|第二百七十二条の二]]第一項の登録申請書又は同条第二項の書類に虚偽の記載をして提出した者[[laws/金融商品取引法/本文/第275条.md|第二百七十五条]]第一項各号に掲げる者でない者であって、保険募集を行った者不正の手段により[[laws/金融商品取引法/本文/第276条.md|第二百七十六条]]又は[[laws/金融商品取引法/本文/第286条.md|第二百八十六条]]の登録を受けた者[[laws/金融商品取引法/本文/第291条.md|第二百九十一条]]第五項の規定に違反した者[[laws/金融商品取引法/本文/第300条.md|第三百条]]第一項の規定に違反して、同項第一号に掲げる行為（運用実績連動型保険契約に係るものを除く。）をした者又は同項第二号若しくは第三号に掲げる行為をした者[[laws/金融商品取引法/本文/第300条の2.md|第三百条の二]]において準用する金融商品取引法第三十七条の三第一項（第二号及び第六号を除く。以下この号において同じ。）の規定に違反して、同項の規定による情報（同項各号に掲げる事項に係るものに限る。以下この号において同じ。）の提供をせず、又は虚偽の情報の提供をした者[[laws/金融商品取引法/本文/第307条.md|第三百七条]]第一項の規定による業務の全部又は一部の停止の命令に違反した者[[laws/金融商品取引法/本文/第308条の4.md|第三百八条の四]]第一項の規定に違反して、その職務に関して知り得た秘密を漏らし、又は自己の利益のために使用した者

- 一 [[laws/保険業法/本文/第99条.md|第九十九条]]第八項（[[laws/保険業法/本文/第199条.md|第百九十九条]]において準用する場合を含む。）において準用する信託業法[[laws/保険業法/本文/第11条.md|第十一条]]第五項の規定に違反して、保険金信託業務を開始した者
- 二 [[laws/保険業法/本文/第99条.md|第九十九条]]第八項（[[laws/保険業法/本文/第199条.md|第百九十九条]]において準用する場合を含む。）において準用する信託業法[[laws/保険業法/本文/第24条の2.md|第二十四条の二]]又は[[laws/保険業法/本文/第300条の2.md|第三百条の二]]において準用する金融商品取引法第三十九条第二項の規定に違反した者
- 三 [[laws/保険業法/本文/第272条の2.md|第二百七十二条の二]]第一項の登録申請書又は同条第二項の書類に虚偽の記載をして提出した者
- 四 [[laws/保険業法/本文/第275条.md|第二百七十五条]]第一項各号に掲げる者でない者であって、保険募集を行った者
- 五 不正の手段により[[laws/保険業法/本文/第276条.md|第二百七十六条]]又は[[laws/保険業法/本文/第286条.md|第二百八十六条]]の登録を受けた者
- 六 [[laws/保険業法/本文/第291条.md|第二百九十一条]]第五項の規定に違反した者
- 七 [[laws/保険業法/本文/第300条.md|第三百条]]第一項の規定に違反して、同項第一号に掲げる行為（運用実績連動型保険契約に係るものを除く。）をした者又は同項第二号若しくは第三号に掲げる行為をした者
- 八 [[laws/保険業法/本文/第300条の2.md|第三百条の二]]において準用する金融商品取引法第三十七条の三第一項（第二号及び第六号を除く。以下この号において同じ。）の規定に違反して、同項の規定による情報（同項各号に掲げる事項に係るものに限る。以下この号において同じ。）の提供をせず、又は虚偽の情報の提供をした者
- 九 [[laws/保険業法/本文/第307条.md|第三百七条]]第一項の規定による業務の全部又は一部の停止の命令に違反した者
- 十 [[laws/保険業法/本文/第308条の4.md|第三百八条の四]]第一項の規定に違反して、その職務に関して知り得た秘密を漏らし、又は自己の利益のために使用した者
