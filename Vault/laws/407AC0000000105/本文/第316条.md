# 第三百十六条 

## 
次の各号のいずれかに該当する者は、二年以下の拘禁刑若しくは三百万円以下の罰金に処し、又はこれを併科する。[[laws/保険業法/本文/第5条.md|第五条]]第二項（[[laws/保険業法/本文/第187条.md|第百八十七条]]第五項において準用する場合を含む。）又は[[laws/保険業法/本文/第221条.md|第二百二十一条]]第二項の規定により付した条件に違反した者[[laws/保険業法/本文/第132条.md|第百三十二条]]第一項、[[laws/保険業法/本文/第133条.md|第百三十三条]]、[[laws/保険業法/本文/第204条.md|第二百四条]]第一項、[[laws/保険業法/本文/第205条.md|第二百五条]]、[[laws/保険業法/本文/第230条.md|第二百三十条]]第一項、[[laws/保険業法/本文/第231条.md|第二百三十一条]]、[[laws/保険業法/本文/第241条.md|第二百四十一条]]第一項、[[laws/保険業法/本文/第271条の30.md|第二百七十一条の三十]]第一項若しくは第四項（[[laws/保険業法/本文/第272条の40.md|第二百七十二条の四十]]第二項において準用する場合を含む。）又は[[laws/保険業法/本文/第272条の26.md|第二百七十二条の二十六]]第一項の規定による業務の全部又は一部の停止の命令に違反した者[[laws/保険業法/本文/第240条の3.md|第二百四十条の三]]の規定による業務の停止の命令に違反した者[[laws/保険業法/本文/第186条.md|第百八十六条]]第一項の規定に違反した者[[laws/保険業法/本文/第188条.md|第百八十八条]]第一項の規定により付した条件に違反した者[[laws/保険業法/本文/第190条.md|第百九十条]]第五項、[[laws/保険業法/本文/第223条.md|第二百二十三条]]第五項又は[[laws/保険業法/本文/第272条の5.md|第二百七十二条の五]]第五項の規定に違反した者[[laws/保険業法/本文/第245条.md|第二百四十五条]]（[[laws/保険業法/本文/第258条.md|第二百五十八条]]第二項において準用する場合を含む。）、[[laws/保険業法/本文/第250条.md|第二百五十条]]第五項（[[laws/保険業法/本文/第270条の4.md|第二百七十条の四]]第九項において準用する場合を含む。）、[[laws/保険業法/本文/第254条.md|第二百五十四条]]第四項又は[[laws/保険業法/本文/第255条の2.md|第二百五十五条の二]]第三項の規定に違反して業務を行った者

- 二 [[laws/保険業法/本文/第132条.md|第百三十二条]]第一項、[[laws/保険業法/本文/第133条.md|第百三十三条]]、[[laws/保険業法/本文/第204条.md|第二百四条]]第一項、[[laws/保険業法/本文/第205条.md|第二百五条]]、[[laws/保険業法/本文/第230条.md|第二百三十条]]第一項、[[laws/保険業法/本文/第231条.md|第二百三十一条]]、[[laws/保険業法/本文/第241条.md|第二百四十一条]]第一項、[[laws/保険業法/本文/第271条の30.md|第二百七十一条の三十]]第一項若しくは第四項（[[laws/保険業法/本文/第272条の40.md|第二百七十二条の四十]]第二項において準用する場合を含む。）又は[[laws/保険業法/本文/第272条の26.md|第二百七十二条の二十六]]第一項の規定による業務の全部又は一部の停止の命令に違反した者

- 六 [[laws/保険業法/本文/第190条.md|第百九十条]]第五項、[[laws/保険業法/本文/第223条.md|第二百二十三条]]第五項又は[[laws/保険業法/本文/第272条の5.md|第二百七十二条の五]]第五項の規定に違反した者
