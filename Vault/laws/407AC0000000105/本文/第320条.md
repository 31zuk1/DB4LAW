# 第三百二十条 

## 
次の各号のいずれかに該当する者は、三十万円以下の罰金に処する。[[laws/保険業法/本文/第102条.md|第百二条]]第一項（[[laws/保険業法/本文/第199条.md|第百九十九条]]において準用する場合を含む。）の規定による認可を受けてしなければならない事項を認可を受けないでした者[[laws/保険業法/本文/第122条の2.md|第百二十二条の二]]第四項の規定による報告をせず、若しくは虚偽の報告をし、又は同項の規定による検査を拒み、妨げ、若しくは忌避した者[[laws/保険業法/本文/第265条の31.md|第二百六十五条の三十一]]第一項、[[laws/保険業法/本文/第266条.md|第二百六十六条]]第二項（[[laws/保険業法/本文/第267条.md|第二百六十七条]]第四項において準用する場合を含む。）、[[laws/保険業法/本文/第267条.md|第二百六十七条]]第二項、[[laws/保険業法/本文/第270条の3.md|第二百七十条の三]]の十一第二項、[[laws/保険業法/本文/第270条の6.md|第二百七十条の六]]の二第二項、[[laws/保険業法/本文/第270条の6.md|第二百七十条の六]]の六第二項又は[[laws/保険業法/本文/第270条の8.md|第二百七十条の八]]の二第二項の規定による資料を提出せず、又は虚偽の資料を提出した者[[laws/保険業法/本文/第277条.md|第二百七十七条]]第一項の登録申請書若しくは同条第二項の書類又は[[laws/保険業法/本文/第287条.md|第二百八十七条]]第一項の登録申請書若しくは同条第二項の書類に虚偽の記載をして提出した者[[laws/保険業法/本文/第303条.md|第三百三条]]の規定に違反して、帳簿書類を備えず、これに同条に規定する事項を記載せず、若しくは虚偽の記載をし、又はこれを保存しなかった者[[laws/保険業法/本文/第304条.md|第三百四条]]の規定に違反して、同条に規定する書類を提出せず、又はこれに記載すべき事項を記載せず、若しくは虚偽の記載をしてこれを提出した者[[laws/保険業法/本文/第305条.md|第三百五条]]第一項又は第二項の規定による報告若しくは資料の提出をせず、又は虚偽の報告若しくは資料の提出をした者[[laws/保険業法/本文/第305条.md|第三百五条]]第一項又は第二項の規定による質問に対して答弁をせず、若しくは虚偽の答弁をし、又はこれらの規定による検査を拒み、妨げ、若しくは忌避した者[[laws/保険業法/本文/第306条.md|第三百六条]]の規定による命令に違反した者[[laws/保険業法/本文/第308条の8.md|第三百八条の八]]第一項の規定による報告をせず、又は虚偽の報告をした者[[laws/保険業法/本文/第308条の18.md|第三百八条の十八]]第一項、[[laws/保険業法/本文/第308条の19.md|第三百八条の十九]]又は[[laws/保険業法/本文/第308条の23.md|第三百八条の二十三]]第二項の規定による届出をせず、又は虚偽の届出をした者[[laws/保険業法/本文/第308条の23.md|第三百八条の二十三]]第三項又は[[laws/保険業法/本文/第308条の24.md|第三百八条の二十四]]第四項の規定による通知をせず、又は虚偽の通知をした者

- 一 [[laws/保険業法/本文/第102条.md|第百二条]]第一項（[[laws/保険業法/本文/第199条.md|第百九十九条]]において準用する場合を含む。）の規定による認可を受けてしなければならない事項を認可を受けないでした者
- 一の二 [[laws/保険業法/本文/第122条の2.md|第百二十二条の二]]第四項の規定による報告をせず、若しくは虚偽の報告をし、又は同項の規定による検査を拒み、妨げ、若しくは忌避した者
- 一の三 [[laws/保険業法/本文/第265条の31.md|第二百六十五条の三十一]]第一項、[[laws/保険業法/本文/第266条.md|第二百六十六条]]第二項（[[laws/保険業法/本文/第267条.md|第二百六十七条]]第四項において準用する場合を含む。）、[[laws/保険業法/本文/第267条.md|第二百六十七条]]第二項、[[laws/保険業法/本文/第270条の3.md|第二百七十条の三]]の十一第二項、[[laws/保険業法/本文/第270条の6.md|第二百七十条の六]]の二第二項、[[laws/保険業法/本文/第270条の6.md|第二百七十条の六]]の六第二項又は[[laws/保険業法/本文/第270条の8.md|第二百七十条の八]]の二第二項の規定による資料を提出せず、又は虚偽の資料を提出した者
- 二 [[laws/保険業法/本文/第277条.md|第二百七十七条]]第一項の登録申請書若しくは同条第二項の書類又は[[laws/保険業法/本文/第287条.md|第二百八十七条]]第一項の登録申請書若しくは同条第二項の書類に虚偽の記載をして提出した者
- 三 [[laws/保険業法/本文/第303条.md|第三百三条]]の規定に違反して、帳簿書類を備えず、これに同条に規定する事項を記載せず、若しくは虚偽の記載をし、又はこれを保存しなかった者
- 四 [[laws/保険業法/本文/第304条.md|第三百四条]]の規定に違反して、同条に規定する書類を提出せず、又はこれに記載すべき事項を記載せず、若しくは虚偽の記載をしてこれを提出した者
- 五 [[laws/保険業法/本文/第305条.md|第三百五条]]第一項又は第二項の規定による報告若しくは資料の提出をせず、又は虚偽の報告若しくは資料の提出をした者
- 六 [[laws/保険業法/本文/第305条.md|第三百五条]]第一項又は第二項の規定による質問に対して答弁をせず、若しくは虚偽の答弁をし、又はこれらの規定による検査を拒み、妨げ、若しくは忌避した者
- 七 [[laws/保険業法/本文/第306条.md|第三百六条]]の規定による命令に違反した者
- 八 [[laws/保険業法/本文/第308条の8.md|第三百八条の八]]第一項の規定による報告をせず、又は虚偽の報告をした者
- 九 [[laws/保険業法/本文/第308条の18.md|第三百八条の十八]]第一項、[[laws/保険業法/本文/第308条の19.md|第三百八条の十九]]又は[[laws/保険業法/本文/第308条の23.md|第三百八条の二十三]]第二項の規定による届出をせず、又は虚偽の届出をした者
- 十 [[laws/保険業法/本文/第308条の23.md|第三百八条の二十三]]第三項又は[[laws/保険業法/本文/第308条の24.md|第三百八条の二十四]]第四項の規定による通知をせず、又は虚偽の通知をした者
