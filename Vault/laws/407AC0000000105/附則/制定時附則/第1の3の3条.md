# 第一条の三の三 （保険金請求権等の買取りの特例）

## 
平成十三年三月三十一日までに機構が[[laws/407AC0000000105/本文/第270条の6.md|第二百七十条の六]]の八第一項の規定による決定をした場合における同条及び[[laws/407AC0000000105/本文/第270条の6.md|第二百七十条の六]]の十の規定の適用については、同項中「補償対象契約」とあるのは「補償対象契約（附則第一条の三第一項第一号に規定する特例期間補償対象契約（以下この条において「特例期間補償対象契約」という。）を含む。[[laws/407AC0000000105/本文/第270条の6.md|第二百七十条の六]]の十において同じ。）」と、[[laws/407AC0000000105/本文/第270条の6.md|第二百七十条の六]]の八第二項中「補償対象契約」とあるのは「補償対象契約（特例期間補償対象契約を除く。）」と、「得た額」とあるのは「得た額又は特例期間補償対象契約の保険金その他の給付金の額に内閣府令・財務省令で定める率を乗じて得た額」とする。
