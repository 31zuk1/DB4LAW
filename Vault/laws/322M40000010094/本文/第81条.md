# 第八十一条 

## 
市町村の区域の変更によつて、管轄法務局若しくは地方法務局又はその支局の所管に変更を生じたときは、旧所管区域内の本籍人の戸籍及び除かれた戸籍の副本（電磁的記録を除く。）並びにこれに関する書類は、新所管法務局若しくは地方法務局又はその支局にこれを引き継がなければならない。
