# 第八十七条 （収容継続の申請の方式等）

## 
法[[laws/少年院法施行規則/本文/第138条.md|第百三十八条]]第一項又は法[[laws/少年院法施行規則/本文/第139条.md|第百三十九条]]第一項の申請は、書面でしなければならない。

## ２
前項の書面には、次に掲げる事項を記載しなければならない。保護処分在院者の氏名、生年月日、本籍及び住居保護者の氏名、年齢及び住居保護処分在院者を送致した家庭裁判所の名称及び当該送致に係る保護処分の決定の年月日保護処分在院者が法[[laws/少年院法施行規則/本文/第138条.md|第百三十八条]]第一項各号又は[[laws/少年院法施行規則/本文/第139条.md|第百三十九条]]第一項各号に掲げる者のいずれかに該当する旨法[[laws/少年院法施行規則/本文/第138条.md|第百三十八条]]第一項各号又は[[laws/少年院法施行規則/本文/第139条.md|第百三十九条]]第一項各号に定める日の年月日申請の理由必要とする収容期間その他参考となる事項

- 一 保護処分在院者の氏名、生年月日、本籍及び住居
- 二 保護者の氏名、年齢及び住居
- 三 保護処分在院者を送致した家庭裁判所の名称及び当該送致に係る保護処分の決定の年月日
- 四 保護処分在院者が法[[laws/少年院法施行規則/本文/第138条.md|第百三十八条]]第一項各号又は[[laws/少年院法施行規則/本文/第139条.md|第百三十九条]]第一項各号に掲げる者のいずれかに該当する旨
- 五 法[[laws/少年院法施行規則/本文/第138条.md|第百三十八条]]第一項各号又は[[laws/少年院法施行規則/本文/第139条.md|第百三十九条]]第一項各号に定める日の年月日
- 六 申請の理由
- 七 必要とする収容期間
- 八 その他参考となる事項
