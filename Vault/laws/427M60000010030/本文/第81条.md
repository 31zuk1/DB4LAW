# 第八十一条 （処理結果通知）

## 
在院者に対する処理結果通知は、法[[laws/少年院法施行規則/本文/第125条.md|第百二十五条]]の規定による処理の結果（法[[laws/少年院法施行規則/本文/第126条.md|第百二十六条]]第一項の規定による法務大臣の措置を含む。次項及び次条第二項において「処理結果」という。）を記載した書面を少年院の長に送付し、少年院の長にこれをその救済の申出をした者に交付させることにより行うものとする。ただし、救済の申出の内容がその申出をした者に対する法[[laws/少年院法施行規則/本文/第126条.md|第百二十六条]]第一項各号に掲げる少年院の長の措置又は法[[laws/少年院法施行規則/本文/第121条.md|第百二十一条]]第一項第五号から第七号までに掲げる少年院の職員による行為に係るもの以外のものであるときは、少年院の長又はその指名する少年院の職員に口頭で行わせることができる。

## ２
出院した者に対する処理結果通知は、処理結果を記載した書面をその者が[[laws/少年院法施行規則/本文/第76条.md|第七十六条]]第二項若しくは[[laws/少年院法施行規則/本文/第77条.md|第七十七条]]第二項の規定により届け出た場所又は同条第一項第二号の住所若しくは居所に送付することにより行うものとする。
