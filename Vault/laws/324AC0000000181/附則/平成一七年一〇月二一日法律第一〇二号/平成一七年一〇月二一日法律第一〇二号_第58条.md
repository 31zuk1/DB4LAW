# 第五十八条 （無尽業法等の一部改正に伴う経過措置）

## 
旧郵便貯金は、第七条、第八条、第二十条、第二十二条、第二十四条、第二十八条、第三十九条、第四十三条、第八十八条、第百八条及び第百十一条の規定による改正後の次に掲げる法律の規定の適用については、銀行への預金とみなす。略中小企業等協同組合法[[laws/324AC0000000181/本文/第57条の5.md|第五十七条の五]]第一号

- 一から五まで 略
- 六 中小企業等協同組合法第五十七条の五第一号
