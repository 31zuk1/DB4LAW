# 第三条 （監査事項）

## 
監査は、次の各号について行う。免許、許可、登録、認可、認定、認証及び届出に係る事項の実施状況路線及び運行の状況車両管理及び施設の状況財務の状況労務の状況その他前条の目的を達成するために必要と認める事項

- 一 免許、許可、登録、認可、認定、認証及び届出に係る事項の実施状況
- 二 路線及び運行の状況
- 三 車両管理及び施設の状況
- 四 財務の状況
- 五 労務の状況
- 六 その他前条の目的を達成するために必要と認める事項
