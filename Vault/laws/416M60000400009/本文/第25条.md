# 第二十五条 （長期借入金の認可の申請）

## 
機構は、機構法[[laws/独立行政法人エネルギー・金属鉱物資源機構の業務運営、財務及び会計並びに人事管理に関する省令/本文/第14条.md|第十四条]]第一項の規定により長期借入金の認可を受けようとするときは、次に掲げる事項を記載した申請書を経済産業大臣に提出しなければならない。借入れを必要とする理由借入金の額借入先借入金の利率借入金の償還の方法及び期限利息の支払の方法及び期限その他必要な事項

- 一 借入れを必要とする理由
- 二 借入金の額
- 三 借入先
- 四 借入金の利率
- 五 借入金の償還の方法及び期限
- 六 利息の支払の方法及び期限
- 七 その他必要な事項
