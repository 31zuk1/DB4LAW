# 第百十九条 

## 
輸出令別表第二の三第二号の二（３１）に掲げる貨物であって、経済産業省令で定めるものは、次に掲げるものとする。関税率表第七三・〇一項に該当するもの関税率表第七三・〇二項に該当するもの関税率表第七三・〇三項、第七三・〇四項、第七三・〇五項及び第七三・〇六項に該当するもの関税率表第七三・〇七項に該当するもの関税率表第七三・〇八項に該当するもの関税率表第七三・〇九項に該当するもの関税率表第七三・一〇項に該当するもの関税率表第七三・一一項に該当するもの関税率表第七三一四・一二号に該当するもの関税率表第七三一八・二四号に該当するもの関税率表第七三二〇・二〇号に該当するもの関税率表第七三二二・九〇号に該当するもの関税率表第七三二四・二九号に該当するもの

- 一 関税率表第七三・〇一項に該当するもの
- 二 関税率表第七三・〇二項に該当するもの
- 三 関税率表第七三・〇三項、第七三・〇四項、第七三・〇五項及び第七三・〇六項に該当するもの
- 四 関税率表第七三・〇七項に該当するもの
- 五 関税率表第七三・〇八項に該当するもの
- 六 関税率表第七三・〇九項に該当するもの
- 七 関税率表第七三・一〇項に該当するもの
- 八 関税率表第七三・一一項に該当するもの
- 九 関税率表第七三一四・一二号に該当するもの
- 十 関税率表第七三一八・二四号に該当するもの
- 十一 関税率表第七三二〇・二〇号に該当するもの
- 十二 関税率表第七三二二・九〇号に該当するもの
- 十三 関税率表第七三二四・二九号に該当するもの
