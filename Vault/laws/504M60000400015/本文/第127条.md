# 第百二十七条 

## 
輸出令別表第二の三第二号の二（３９）に掲げる貨物であって、経済産業省令で定めるものは、次に掲げるものとする。関税率表第八二〇二・二〇号に該当するもの関税率表第八二〇五・五九号及び第八二・〇七項に該当するもの関税率表第八二・〇八項に該当するもの関税率表第八二・一四項及び第八二・一五項に該当するもの関税率表第八三〇一・二〇号及び第八三〇一・七〇号に該当するもの関税率表第八三〇二・三〇号に該当するもの関税率表第八三・〇七項に該当するもの関税率表第八三・〇九項に該当するもの

- 一 関税率表第八二〇二・二〇号に該当するもの
- 二 関税率表第八二〇五・五九号及び第八二・〇七項に該当するもの
- 三 関税率表第八二・〇八項に該当するもの
- 四 関税率表第八二・一四項及び第八二・一五項に該当するもの
- 五 関税率表第八三〇一・二〇号及び第八三〇一・七〇号に該当するもの
- 六 関税率表第八三〇二・三〇号に該当するもの
- 七 関税率表第八三・〇七項に該当するもの
- 八 関税率表第八三・〇九項に該当するもの
