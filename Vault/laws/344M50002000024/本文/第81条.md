# 第八十一条 （権限の委任）

## 
法[[laws/職業能力開発促進法施行規則/本文/第98条の2.md|第九十八条の二]]の規定により、法[[laws/職業能力開発促進法施行規則/本文/第26条の3.md|第二十六条の三]]第三項（法[[laws/職業能力開発促進法施行規則/本文/第26条の4.md|第二十六条の四]]第三項において準用する場合を含む。）及び[[laws/職業能力開発促進法施行規則/本文/第26条の4.md|第二十六条の四]]第二項に規定する厚生労働大臣の権限は、所轄都道府県労働局長に委任する。ただし、同項に規定する権限にあつては、厚生労働大臣が自らその権限を行うことを妨げない。
