# 第三条 （勘定区分）

## 
法[[laws/株式会社日本政策金融公庫の会計に関する省令/本文/第41条.md|第四十一条]]の規定により設ける勘定は、次に掲げる勘定とする。法[[laws/株式会社日本政策金融公庫の会計に関する省令/本文/第41条.md|第四十一条]]第一号に掲げる業務に係る勘定国民一般向け業務勘定法[[laws/株式会社日本政策金融公庫の会計に関する省令/本文/第41条.md|第四十一条]]第二号に掲げる業務に係る勘定農林水産業者向け業務勘定法[[laws/株式会社日本政策金融公庫の会計に関する省令/本文/第41条.md|第四十一条]]第三号に掲げる業務に係る勘定中小企業者向け融資・証券化支援保証業務勘定法[[laws/株式会社日本政策金融公庫の会計に関する省令/本文/第41条.md|第四十一条]]第四号に掲げる業務に係る勘定中小企業者向け証券化支援買取業務勘定法[[laws/株式会社日本政策金融公庫の会計に関する省令/本文/第41条.md|第四十一条]]第五号に掲げる業務に係る勘定信用保険等業務勘定削除法[[laws/株式会社日本政策金融公庫の会計に関する省令/本文/第41条.md|第四十一条]]第七号に掲げる業務に係る勘定危機対応円滑化業務勘定

- 一 法[[laws/株式会社日本政策金融公庫の会計に関する省令/本文/第41条.md|第四十一条]]第一号に掲げる業務に係る勘定国民一般向け業務勘定
- 二 法[[laws/株式会社日本政策金融公庫の会計に関する省令/本文/第41条.md|第四十一条]]第二号に掲げる業務に係る勘定農林水産業者向け業務勘定
- 三 法[[laws/株式会社日本政策金融公庫の会計に関する省令/本文/第41条.md|第四十一条]]第三号に掲げる業務に係る勘定中小企業者向け融資・証券化支援保証業務勘定
- 四 法[[laws/株式会社日本政策金融公庫の会計に関する省令/本文/第41条.md|第四十一条]]第四号に掲げる業務に係る勘定中小企業者向け証券化支援買取業務勘定
- 五 法[[laws/株式会社日本政策金融公庫の会計に関する省令/本文/第41条.md|第四十一条]]第五号に掲げる業務に係る勘定信用保険等業務勘定
- 六 削除
