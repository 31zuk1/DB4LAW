# 第八条の三の三 （法附則第二十九条の九第三項の認定又は評価）

## 
法附則第二十九条の九第三項に規定する総務省令で定める認定又は評価は、低排出ガス車認定実施要領[[laws/329M50000002023/本文/第5条.md|第五条]]の規定による認定（附則第八条の三の五及び附則第八条の四において「低排出ガス車認定」という。）又は自動車の燃費性能の評価及び公表に関する実施要領（附則第八条の四において「燃費評価実施要領」という。）[[laws/329M50000002023/本文/第3条.md|第三条]]から第四条の三までの規定による評価とする。
