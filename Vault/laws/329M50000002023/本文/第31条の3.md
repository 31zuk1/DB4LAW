# 第三十一条の三 （法第七百八十三条第二項の総務省令で定める事項）

## 
法[[laws/325AC0000000226/本文/第783条.md|第七百八十三条]]第二項に規定する総務省令で定める事項は、次に掲げる事項とする。法[[laws/325AC0000000226/本文/第782条.md|第七百八十二条]]第一号に掲げる機構処理税務事務（法[[laws/325AC0000000226/本文/第762条.md|第七百六十二条]]第二号に規定する機構処理税務事務をいう。次条第一項において同じ。）に関する事項法[[laws/325AC0000000226/本文/第782条.md|第七百八十二条]]第二号に掲げる教育及び研修に関する事項法[[laws/325AC0000000226/本文/第782条.md|第七百八十二条]]第三号に掲げる調査研究に関する事項法[[laws/325AC0000000226/本文/第782条.md|第七百八十二条]]第四号に掲げる広報その他の啓発活動に関する事項法[[laws/325AC0000000226/本文/第782条.md|第七百八十二条]]第五号に掲げる開発及び運用に関する事項法[[laws/325AC0000000226/本文/第782条.md|第七百八十二条]]第六号に掲げる事務の受託に関する事項法[[laws/325AC0000000226/本文/第782条.md|第七百八十二条]]第七号に掲げる情報の提供その他の支援に関する事項その他機構の業務の執行に関して必要な事項

- 一 法[[laws/325AC0000000226/本文/第782条.md|第七百八十二条]]第一号に掲げる機構処理税務事務（法[[laws/325AC0000000226/本文/第762条.md|第七百六十二条]]第二号に規定する機構処理税務事務をいう。次条第一項において同じ。）に関する事項
- 二 法[[laws/325AC0000000226/本文/第782条.md|第七百八十二条]]第二号に掲げる教育及び研修に関する事項
- 三 法[[laws/325AC0000000226/本文/第782条.md|第七百八十二条]]第三号に掲げる調査研究に関する事項
- 四 法[[laws/325AC0000000226/本文/第782条.md|第七百八十二条]]第四号に掲げる広報その他の啓発活動に関する事項
- 五 法[[laws/325AC0000000226/本文/第782条.md|第七百八十二条]]第五号に掲げる開発及び運用に関する事項
- 六 法[[laws/325AC0000000226/本文/第782条.md|第七百八十二条]]第六号に掲げる事務の受託に関する事項
- 七 法[[laws/325AC0000000226/本文/第782条.md|第七百八十二条]]第七号に掲げる情報の提供その他の支援に関する事項
- 八 その他機構の業務の執行に関して必要な事項
