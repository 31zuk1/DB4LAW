# 第一条の七 （法第十九条第九号の処分）

## 
法[[laws/地方税法施行規則/本文/第19条.md|第十九条]]第九号の総務省令で定める処分は、次の各号に掲げるものとする。納付又は納入すべき金額及び納付又は納入の期限の告知徴収の猶予、換価の猶予及び滞納処分の執行停止に関する処分担保の徴取及び担保の処分に関する処分還付又は充当に関する処分減免に関する処分過少申告加算金、不申告加算金及び重加算金の決定法[[laws/地方税法施行規則/本文/第11条.md|第十一条]]第一項（これを準用する場合を含む。）の規定による告知法[[laws/地方税法施行規則/本文/第13条の2.md|第十三条の二]]第三項（法[[laws/地方税法施行規則/本文/第14条の18.md|第十四条の十八]]第四項において準用する場合を含む。）の規定による告知法[[laws/地方税法施行規則/本文/第13条の3.md|第十三条の三]]第二項の規定による通知法[[laws/地方税法施行規則/本文/第14条の16.md|第十四条の十六]]第四項の規定による通知に係る処分法[[laws/地方税法施行規則/本文/第14条の18.md|第十四条の十八]]第二項の規定による告知法[[laws/地方税法施行規則/本文/第16条の4.md|第十六条の四]]の規定による保全差押に関する処分法[[laws/地方税法施行規則/本文/第20条の5.md|第二十条の五]]の二の規定による期限の延長に関する処分法[[laws/地方税法施行規則/本文/第20条の9.md|第二十条の九]]の三第四項の規定による通知に係る処分法[[laws/地方税法施行規則/本文/第45条の2.md|第四十五条の二]]第二項又は[[laws/地方税法施行規則/本文/第317条の2.md|第三百十七条の二]]第二項の規定による処分法[[laws/地方税法施行規則/本文/第53条.md|第五十三条]]第七十二項若しくは第七十五項又は[[laws/地方税法施行規則/本文/第321条の8.md|第三百二十一条の八]]第六十九項若しくは第七十二項の規定による通知法[[laws/地方税法施行規則/本文/第72条の25.md|第七十二条の二十五]]第二項から第四項まで（これらの規定を法[[laws/地方税法施行規則/本文/第72条の28.md|第七十二条の二十八]]第二項又は[[laws/地方税法施行規則/本文/第72条の29.md|第七十二条の二十九]]第二項において準用する場合を含む。）又は第五項（法[[laws/地方税法施行規則/本文/第72条の28.md|第七十二条の二十八]]第二項又は[[laws/地方税法施行規則/本文/第72条の29.md|第七十二条の二十九]]第二項若しくは第六項において準用する場合を含む。）の規定による承認に関する処分法[[laws/地方税法施行規則/本文/第72条の32.md|第七十二条の三十二]]の二第四項又は第七項の規定による通知法[[laws/地方税法施行規則/本文/第74条の11.md|第七十四条の十一]]第一項の規定による納期限の延長に関する処分法[[laws/地方税法施行規則/本文/第321条の4.md|第三百二十一条の四]]第一項（同条第六項において準用する場合を含む。）又は[[laws/地方税法施行規則/本文/第321条の6.md|第三百二十一条の六]]第一項の規定による通知法[[laws/地方税法施行規則/本文/第474条.md|第四百七十四条]]第一項の規定による納期限の延長に関する処分法[[laws/地方税法施行規則/本文/第603条の2.md|第六百三条の二]]第四項の規定による通知法[[laws/地方税法施行規則/本文/第629条.md|第六百二十九条]]第四項の規定による通知法附則第二十九条の五第六項の規定による通知政令[[laws/地方税法施行規則/本文/第48条の9.md|第四十八条の九]]の十第四項（政令[[laws/地方税法施行規則/本文/第48条の17.md|第四十八条の十七]]において準用する場合を含む。）の規定による通知

- 一 納付又は納入すべき金額及び納付又は納入の期限の告知
- 二 徴収の猶予、換価の猶予及び滞納処分の執行停止に関する処分
- 三 担保の徴取及び担保の処分に関する処分
- 四 還付又は充当に関する処分
- 五 減免に関する処分
- 六 過少申告加算金、不申告加算金及び重加算金の決定
- 七 法[[laws/地方税法施行規則/本文/第11条.md|第十一条]]第一項（これを準用する場合を含む。）の規定による告知
- 八 法[[laws/地方税法施行規則/本文/第13条の2.md|第十三条の二]]第三項（法[[laws/地方税法施行規則/本文/第14条の18.md|第十四条の十八]]第四項において準用する場合を含む。）の規定による告知
- 九 法[[laws/地方税法施行規則/本文/第13条の3.md|第十三条の三]]第二項の規定による通知
- 十 法[[laws/地方税法施行規則/本文/第14条の16.md|第十四条の十六]]第四項の規定による通知に係る処分
- 十一 法[[laws/地方税法施行規則/本文/第14条の18.md|第十四条の十八]]第二項の規定による告知
- 十二 法[[laws/地方税法施行規則/本文/第16条の4.md|第十六条の四]]の規定による保全差押に関する処分

- 十四 法[[laws/地方税法施行規則/本文/第20条の9.md|第二十条の九]]の三第四項の規定による通知に係る処分
- 十五 法[[laws/地方税法施行規則/本文/第45条の2.md|第四十五条の二]]第二項又は[[laws/地方税法施行規則/本文/第317条の2.md|第三百十七条の二]]第二項の規定による処分
- 十六 法[[laws/地方税法施行規則/本文/第53条.md|第五十三条]]第七十二項若しくは第七十五項又は[[laws/地方税法施行規則/本文/第321条の8.md|第三百二十一条の八]]第六十九項若しくは第七十二項の規定による通知
- 十七 法[[laws/地方税法施行規則/本文/第72条の25.md|第七十二条の二十五]]第二項から第四項まで（これらの規定を法[[laws/地方税法施行規則/本文/第72条の28.md|第七十二条の二十八]]第二項又は[[laws/地方税法施行規則/本文/第72条の29.md|第七十二条の二十九]]第二項において準用する場合を含む。）又は第五項（法[[laws/地方税法施行規則/本文/第72条の28.md|第七十二条の二十八]]第二項又は[[laws/地方税法施行規則/本文/第72条の29.md|第七十二条の二十九]]第二項若しくは第六項において準用する場合を含む。）の規定による承認に関する処分
- 十八 法[[laws/地方税法施行規則/本文/第72条の32.md|第七十二条の三十二]]の二第四項又は第七項の規定による通知
- 十九 法[[laws/地方税法施行規則/本文/第74条の11.md|第七十四条の十一]]第一項の規定による納期限の延長に関する処分
- 二十 法[[laws/地方税法施行規則/本文/第321条の4.md|第三百二十一条の四]]第一項（同条第六項において準用する場合を含む。）又は[[laws/地方税法施行規則/本文/第321条の6.md|第三百二十一条の六]]第一項の規定による通知
- 二十一 法[[laws/地方税法施行規則/本文/第474条.md|第四百七十四条]]第一項の規定による納期限の延長に関する処分
