# 第一条の三の三 （事業所税に関する規定の都への準用）

## 
法[[laws/325AC0000000226/本文/第735条.md|第七百三十五条]]第一項の規定により都がその特別区の存する区域内において課する事業所税については、[[laws/329M50000002023/本文/第1条.md|第一条]]の規定にかかわらず、都を市とみなして[[laws/329M50000002023/本文/第24条の2.md|第二十四条の二]]から[[laws/329M50000002023/本文/第24条の29.md|第二十四条の二十九]]までの規定を準用する。
