# 第七条の三の三 （政令第三十六条の三第一項第六号の施設）

## 
政令[[laws/329M50000002023/地方税法施行規則_law.md|第三十六条の三]]第一項第六号に規定する総務省令で定める施設は、飲食店、喫茶店及び物品販売施設（これらの施設のうち同号に規定する病院又は診療所の利用者の利便に供することを目的とするものを除く。）並びに駐車施設とする。
