# 第一条の四 （業務方法書の記載事項）

## 
機構に係る通則法[[laws/415M60000100152/独立行政法人勤労者退職金共済機構の業務運_law.md|第二十八条]]第二項の主務省令で定める事項は、次のとおりとする。法[[laws/415M60000100152/独立行政法人勤労者退職金共済機構の業務運_law.md|第七十条]]第一項第一号に規定する中小企業退職金共済事業に関する事項法[[laws/415M60000100152/独立行政法人勤労者退職金共済機構の業務運_law.md|第七十条]]第一項第二号に規定する附帯業務に関する事項法[[laws/415M60000100152/独立行政法人勤労者退職金共済機構の業務運_law.md|第七十条]]第二項第一号に規定する勤労者財産形成促進法[[laws/415M60000100152/本文/第9条.md|第九条]]第一項に規定する業務に関する事項法[[laws/415M60000100152/独立行政法人勤労者退職金共済機構の業務運_law.md|第七十条]]第二項第二号に規定する附帯業務に関する事項業務委託の基準競争入札その他契約に関する基本的事項その他機構の業務の執行に関して必要な事項

- 一 法[[laws/415M60000100152/独立行政法人勤労者退職金共済機構の業務運_law.md|第七十条]]第一項第一号に規定する中小企業退職金共済事業に関する事項
- 二 法[[laws/415M60000100152/独立行政法人勤労者退職金共済機構の業務運_law.md|第七十条]]第一項第二号に規定する附帯業務に関する事項
- 三 法[[laws/415M60000100152/独立行政法人勤労者退職金共済機構の業務運_law.md|第七十条]]第二項第一号に規定する勤労者財産形成促進法[[laws/415M60000100152/本文/第9条.md|第九条]]第一項に規定する業務に関する事項
- 四 法[[laws/415M60000100152/独立行政法人勤労者退職金共済機構の業務運_law.md|第七十条]]第二項第二号に規定する附帯業務に関する事項
- 五 業務委託の基準
- 六 競争入札その他契約に関する基本的事項
- 七 その他機構の業務の執行に関して必要な事項
