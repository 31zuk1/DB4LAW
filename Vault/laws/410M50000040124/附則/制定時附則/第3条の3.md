# 第三条の三 （譲受債権等に係る損失の減少した事由及び額）

## 
令附則第四条第二号に規定する内閣府令・財務省令で定める事由は、次条第一号又は第二号に掲げる事由に該当して損失の生じた譲受金銭債権につき、当該損失の生じた事業年度の翌事業年度以後弁済を受けたこととし、令附則第四条第二号に規定する内閣府令・財務省令で定める額は、当該弁済を受けた金額に相当する額とする。
