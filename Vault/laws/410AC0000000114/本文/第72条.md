# 第七十二条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、一年以下の拘禁刑又は百万円以下の罰金に処する。[[laws/感染症の予防及び感染症の患者に対する医療に関する法律/本文/第56条の11.md|第五十六条の十一]]第一項本文の許可を受けないで[[laws/感染症の予防及び感染症の患者に対する医療に関する法律/本文/第56条の6.md|第五十六条の六]]第二項第二号から第四号までに掲げる事項を変更したとき。[[laws/感染症の予防及び感染症の患者に対する医療に関する法律/本文/第56条の14.md|第五十六条の十四]]において読み替えて準用する[[laws/感染症の予防及び感染症の患者に対する医療に関する法律/本文/第56条の11.md|第五十六条の十一]]第一項の規定に違反して同項本文の許可を受けないで[[laws/感染症の予防及び感染症の患者に対する医療に関する法律/本文/第56条の12.md|第五十六条の十二]]第二項第二号から第七号までに掲げる事項を変更したとき。[[laws/感染症の予防及び感染症の患者に対する医療に関する法律/本文/第56条の19.md|第五十六条の十九]]第一項の規定に違反したとき。[[laws/感染症の予防及び感染症の患者に対する医療に関する法律/本文/第56条の22.md|第五十六条の二十二]]第一項の規定に違反したとき。[[laws/感染症の予防及び感染症の患者に対する医療に関する法律/本文/第56条の29.md|第五十六条の二十九]]第一項の規定に違反し、又は[[laws/感染症の予防及び感染症の患者に対する医療に関する法律/本文/第56条の37.md|第五十六条の三十七]]の規定による命令に違反したとき。[[laws/感染症の予防及び感染症の患者に対する医療に関する法律/本文/第56条の30.md|第五十六条の三十]]の規定による報告をせず、又は虚偽の報告をしたとき。[[laws/感染症の予防及び感染症の患者に対する医療に関する法律/本文/第56条の31.md|第五十六条の三十一]]第一項の規定による立入り、検査若しくは収去を拒み、妨げ、若しくは忌避し、又は質問に対して陳述をせず、若しくは虚偽の陳述をしたとき。[[laws/感染症の予防及び感染症の患者に対する医療に関する法律/本文/第56条の38.md|第五十六条の三十八]]第二項の規定による立入り若しくは検査を拒み、妨げ、若しくは忌避し、又は質問に対して陳述をせず、若しくは虚偽の陳述をしたとき。

- 一 [[laws/感染症の予防及び感染症の患者に対する医療に関する法律/本文/第56条の11.md|第五十六条の十一]]第一項本文の許可を受けないで[[laws/感染症の予防及び感染症の患者に対する医療に関する法律/本文/第56条の6.md|第五十六条の六]]第二項第二号から第四号までに掲げる事項を変更したとき。
- 二 [[laws/感染症の予防及び感染症の患者に対する医療に関する法律/本文/第56条の14.md|第五十六条の十四]]において読み替えて準用する[[laws/感染症の予防及び感染症の患者に対する医療に関する法律/本文/第56条の11.md|第五十六条の十一]]第一項の規定に違反して同項本文の許可を受けないで[[laws/感染症の予防及び感染症の患者に対する医療に関する法律/本文/第56条の12.md|第五十六条の十二]]第二項第二号から第七号までに掲げる事項を変更したとき。
- 三 [[laws/感染症の予防及び感染症の患者に対する医療に関する法律/本文/第56条の19.md|第五十六条の十九]]第一項の規定に違反したとき。
- 四 [[laws/感染症の予防及び感染症の患者に対する医療に関する法律/本文/第56条の22.md|第五十六条の二十二]]第一項の規定に違反したとき。
- 五 [[laws/感染症の予防及び感染症の患者に対する医療に関する法律/本文/第56条の29.md|第五十六条の二十九]]第一項の規定に違反し、又は[[laws/感染症の予防及び感染症の患者に対する医療に関する法律/本文/第56条の37.md|第五十六条の三十七]]の規定による命令に違反したとき。
- 六 [[laws/感染症の予防及び感染症の患者に対する医療に関する法律/本文/第56条の30.md|第五十六条の三十]]の規定による報告をせず、又は虚偽の報告をしたとき。
- 七 [[laws/感染症の予防及び感染症の患者に対する医療に関する法律/本文/第56条の31.md|第五十六条の三十一]]第一項の規定による立入り、検査若しくは収去を拒み、妨げ、若しくは忌避し、又は質問に対して陳述をせず、若しくは虚偽の陳述をしたとき。
- 八 [[laws/感染症の予防及び感染症の患者に対する医療に関する法律/本文/第56条の38.md|第五十六条の三十八]]第二項の規定による立入り若しくは検査を拒み、妨げ、若しくは忌避し、又は質問に対して陳述をせず、若しくは虚偽の陳述をしたとき。
