# 第八十一条 （処分、手続等に関する経過措置）

## 
前条に規定するもののほか、沖縄の海岸法又はこれに基づく命令の規定によつてした処分、手続その他の行為は、海岸法又はこれに基づく命令の相当規定によつてした処分、手続その他の行為とみなす。
