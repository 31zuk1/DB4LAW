# 第八十一条 （条例又は規約への委任）

## 
[[laws/333AC0000000192/本文/第76条.md|第七十六条]]から前条までに規定するもののほか、賦課額、保険料率、納期、減額賦課その他保険料の賦課及び徴収等に関する事項は、政令で定める基準に従つて条例又は規約で定める。
