# 第三条 （担保金等の提供期間の延長）

## 
担保金等の提出期間の延長を求める者は、次に掲げる事項を記載した書面を取締官に提出しなければならない。提供期間の延長を求める者の氏名又は名称、住所及び違反者との関係事件に係る船舶の名称違反者の氏名逮捕等の年月日告知の年月日希望する延長期間提供期間の延長を求める理由その他必要な事項

- 一 提供期間の延長を求める者の氏名又は名称、住所及び違反者との関係
- 二 事件に係る船舶の名称
- 三 違反者の氏名
- 四 逮捕等の年月日
- 五 告知の年月日
- 六 希望する延長期間
- 七 提供期間の延長を求める理由
- 八 その他必要な事項
## ２
取締官は、前項の書面の提出があったときは、当該書面に係る担保金等の提供期間の延長を求めた者に対し、次に掲げる事項を通知するものとする。提供期間の延長を求めた者の氏名又は名称及び住所事件に係る船舶の名称違反者の氏名逮捕等の年月日提供期間の延長を認める旨又は認めない旨及び延長を認める場合は、延長後の担保金等の提供期限通知をする取締官の氏名及びその者が法[[laws/408M50000802001/海洋汚染等及び海上災害の防止に関する法律_law.md|第六十五条]]第一項の取締官である旨その他必要な事項

- 一 提供期間の延長を求めた者の氏名又は名称及び住所
- 二 事件に係る船舶の名称
- 三 違反者の氏名
- 四 逮捕等の年月日
- 五 提供期間の延長を認める旨又は認めない旨及び延長を認める場合は、延長後の担保金等の提供期限
- 六 通知をする取締官の氏名及びその者が法[[laws/408M50000802001/海洋汚染等及び海上災害の防止に関する法律_law.md|第六十五条]]第一項の取締官である旨
- 七 その他必要な事項
