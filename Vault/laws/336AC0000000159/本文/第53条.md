# 第五十三条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、五十万円以下の罰金に処する。[[laws/336AC0000000159/本文/第3条.md|第三条]]第一項又は[[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の二第一項の規定に違反して示さなかつたとき。[[laws/336AC0000000159/本文/第3条.md|第三条]]第四項、[[laws/336AC0000000159/本文/第29条の2.md|第二十九条の二]]第三項、[[laws/336AC0000000159/本文/第30条.md|第三十条]]第四項又は[[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の二第二項の規定に違反して表示しなかつたとき。[[laws/336AC0000000159/本文/第3条.md|第三条]]第二項若しくは第三項、[[laws/336AC0000000159/本文/第4条.md|第四条]]、[[laws/336AC0000000159/本文/第29条の2.md|第二十九条の二]]第一項若しくは第二項、[[laws/336AC0000000159/本文/第29条の3.md|第二十九条の三]]、[[laws/336AC0000000159/本文/第30条.md|第三十条]]第三項、[[laws/336AC0000000159/本文/第30条の2.md|第三十条の二]]の三第四項若しくは第六項、[[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の八又は[[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の九第一項若しくは第三項の規定に違反して書面を交付しなかつたとき。[[laws/336AC0000000159/本文/第30条.md|第三十条]]第一項若しくは第二項又は[[laws/336AC0000000159/本文/第30条の2.md|第三十条の二]]の三第一項から第三項まで若しくは第五項の規定に違反して情報を提供しなかつたとき。[[laws/336AC0000000159/本文/第30条の2.md|第三十条の二]]第四項、[[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の三第四項、[[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の五第二項又は[[laws/336AC0000000159/本文/第35条の17.md|第三十五条の十七]]の八第五項の規定に違反して調査に関する記録を作成せず、若しくは虚偽の記録を作成し、又はこれを保存しなかつたとき。[[laws/336AC0000000159/本文/第30条の5.md|第三十条の五]]の五第三項又は[[laws/336AC0000000159/本文/第35条の2.md|第三十五条の二]]の四第三項の規定に違反して算定に関する記録を作成せず、若しくは虚偽の記録を作成し、又はこれを保存しなかつたとき。[[laws/336AC0000000159/本文/第40条.md|第四十条]]第一項、第二項、第五項から第七項まで、第九項、第十二項若しくは第十三項の規定による報告をせず、又は虚偽の報告をしたとき。[[laws/336AC0000000159/本文/第40条.md|第四十条]]第三項、第四項、第八項又は第十一項の規定による報告をせず、若しくは虚偽の報告をし、又はこれらの規定による物件を提出せず、若しくは虚偽の物件を提出したとき。[[laws/336AC0000000159/本文/第40条.md|第四十条]]第十項の規定による報告をせず、若しくは虚偽の報告をし、又は同項の規定による資料を提出せず、若しくは虚偽の資料を提出したとき。[[laws/336AC0000000159/本文/第41条.md|第四十一条]]第一項から第六項までの規定による検査を拒み、妨げ、又は忌避したとき。

- 一 [[laws/336AC0000000159/本文/第3条.md|第三条]]第一項又は[[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の二第一項の規定に違反して示さなかつたとき。
- 二 [[laws/336AC0000000159/本文/第3条.md|第三条]]第四項、[[laws/336AC0000000159/本文/第29条の2.md|第二十九条の二]]第三項、[[laws/336AC0000000159/本文/第30条.md|第三十条]]第四項又は[[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の二第二項の規定に違反して表示しなかつたとき。
- 三 [[laws/336AC0000000159/本文/第3条.md|第三条]]第二項若しくは第三項、[[laws/336AC0000000159/本文/第4条.md|第四条]]、[[laws/336AC0000000159/本文/第29条の2.md|第二十九条の二]]第一項若しくは第二項、[[laws/336AC0000000159/本文/第29条の3.md|第二十九条の三]]、[[laws/336AC0000000159/本文/第30条.md|第三十条]]第三項、[[laws/336AC0000000159/本文/第30条の2.md|第三十条の二]]の三第四項若しくは第六項、[[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の八又は[[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の九第一項若しくは第三項の規定に違反して書面を交付しなかつたとき。
- 四 [[laws/336AC0000000159/本文/第30条.md|第三十条]]第一項若しくは第二項又は[[laws/336AC0000000159/本文/第30条の2.md|第三十条の二]]の三第一項から第三項まで若しくは第五項の規定に違反して情報を提供しなかつたとき。
- 五 [[laws/336AC0000000159/本文/第30条の2.md|第三十条の二]]第四項、[[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の三第四項、[[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の五第二項又は[[laws/336AC0000000159/本文/第35条の17.md|第三十五条の十七]]の八第五項の規定に違反して調査に関する記録を作成せず、若しくは虚偽の記録を作成し、又はこれを保存しなかつたとき。
- 六 [[laws/336AC0000000159/本文/第30条の5.md|第三十条の五]]の五第三項又は[[laws/336AC0000000159/本文/第35条の2.md|第三十五条の二]]の四第三項の規定に違反して算定に関する記録を作成せず、若しくは虚偽の記録を作成し、又はこれを保存しなかつたとき。
- 七 [[laws/336AC0000000159/本文/第40条.md|第四十条]]第一項、第二項、第五項から第七項まで、第九項、第十二項若しくは第十三項の規定による報告をせず、又は虚偽の報告をしたとき。
- 八 [[laws/336AC0000000159/本文/第40条.md|第四十条]]第三項、第四項、第八項又は第十一項の規定による報告をせず、若しくは虚偽の報告をし、又はこれらの規定による物件を提出せず、若しくは虚偽の物件を提出したとき。
- 九 [[laws/336AC0000000159/本文/第40条.md|第四十条]]第十項の規定による報告をせず、若しくは虚偽の報告をし、又は同項の規定による資料を提出せず、若しくは虚偽の資料を提出したとき。
- 十 [[laws/336AC0000000159/本文/第41条.md|第四十一条]]第一項から第六項までの規定による検査を拒み、妨げ、又は忌避したとき。
