# 第五十二条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした許可割賦販売業者、供託委託契約の受託者、指定信用情報機関、[[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の六十一の許可を受けた者又は指定受託機関の代表者、管理人、代理人、使用人その他の従業者は、五十万円以下の罰金に処する。[[laws/336AC0000000159/本文/第16条.md|第十六条]]第三項（[[laws/336AC0000000159/本文/第18条.md|第十八条]]第二項（[[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の六十二において準用する場合を含む。）又は[[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の六十二において準用する場合を含む。）の規定に違反して前払式割賦販売又は前払式特定取引の営業を開始したとき。[[laws/336AC0000000159/本文/第18条の3.md|第十八条の三]]第一項（[[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の六十二において準用する場合を含む。）の規定に違反して新たに前払式割賦販売又は前払式特定取引の契約を締結したとき。[[laws/336AC0000000159/本文/第19条の2.md|第十九条の二]]（[[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の六十二において準用する場合を含む。）の規定に違反して帳簿を備えず、[[laws/336AC0000000159/本文/第19条の2.md|第十九条の二]]（[[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の六十二において準用する場合を含む。）に規定する事項の記載をせず、若しくは虚偽の記載をし、又は帳簿を保存しなかつたとき。[[laws/336AC0000000159/本文/第20条の3.md|第二十条の三]]第四項（[[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の六十二において準用する場合を含む。）の規定に違反して前受業務保証金を供託しなかつたとき。[[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の四十一第一項本文の規定に違反して、他の業務を行つたとき。[[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の四十三第一項の規定に違反して業務規程を定めず、若しくは経済産業大臣の認可を受けず、又は経済産業大臣の認可を受けずに業務規程の変更をしたとき。[[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の四十五（[[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の四十七第四項において準用する場合を含む。）の規定による記録の作成若しくは保存をせず、又は虚偽の記録を作成したとき。[[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の五十一第一項の規定による業務及び財産に関する報告書を提出せず、又は虚偽の記載をした業務及び財産に関する報告書を提出したとき。[[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の五十三第一項の規定に違反したとき。[[laws/336AC0000000159/本文/第35条の8.md|第三十五条の八]]第一項の事業計画書若しくは同条第三項の事業報告書を提出せず、又は虚偽の記載をした事業計画書若しくは事業報告書を提出したとき。[[laws/336AC0000000159/本文/第35条の9.md|第三十五条の九]]の規定に違反して受託事業以外の事業を営んだとき。

- 一 [[laws/336AC0000000159/本文/第16条.md|第十六条]]第三項（[[laws/336AC0000000159/本文/第18条.md|第十八条]]第二項（[[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の六十二において準用する場合を含む。）又は[[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の六十二において準用する場合を含む。）の規定に違反して前払式割賦販売又は前払式特定取引の営業を開始したとき。
- 二 [[laws/336AC0000000159/本文/第18条の3.md|第十八条の三]]第一項（[[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の六十二において準用する場合を含む。）の規定に違反して新たに前払式割賦販売又は前払式特定取引の契約を締結したとき。
- 三 [[laws/336AC0000000159/本文/第19条の2.md|第十九条の二]]（[[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の六十二において準用する場合を含む。）の規定に違反して帳簿を備えず、[[laws/336AC0000000159/本文/第19条の2.md|第十九条の二]]（[[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の六十二において準用する場合を含む。）に規定する事項の記載をせず、若しくは虚偽の記載をし、又は帳簿を保存しなかつたとき。
- 四 [[laws/336AC0000000159/本文/第20条の3.md|第二十条の三]]第四項（[[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の六十二において準用する場合を含む。）の規定に違反して前受業務保証金を供託しなかつたとき。
- 五 [[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の四十一第一項本文の規定に違反して、他の業務を行つたとき。
- 六 [[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の四十三第一項の規定に違反して業務規程を定めず、若しくは経済産業大臣の認可を受けず、又は経済産業大臣の認可を受けずに業務規程の変更をしたとき。
- 七 [[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の四十五（[[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の四十七第四項において準用する場合を含む。）の規定による記録の作成若しくは保存をせず、又は虚偽の記録を作成したとき。
- 八 [[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の五十一第一項の規定による業務及び財産に関する報告書を提出せず、又は虚偽の記載をした業務及び財産に関する報告書を提出したとき。
- 九 [[laws/336AC0000000159/本文/第35条の3.md|第三十五条の三]]の五十三第一項の規定に違反したとき。
- 十 [[laws/336AC0000000159/本文/第35条の8.md|第三十五条の八]]第一項の事業計画書若しくは同条第三項の事業報告書を提出せず、又は虚偽の記載をした事業計画書若しくは事業報告書を提出したとき。
- 十一 [[laws/336AC0000000159/本文/第35条の9.md|第三十五条の九]]の規定に違反して受託事業以外の事業を営んだとき。
