# 第八十一条 

## 
次の各号のいずれかに該当する場合には、その違反行為をした会社の取締役、執行役、会計参与若しくはその職務を行うべき社員又は監査役は、百万円以下の過料に処する。この法律の規定により経済産業大臣の認可又は承認を受けなければならない場合において、その認可又は承認を受けなかつたとき。[[laws/貿易保険法/本文/第12条.md|第十二条]]第一項、第二項及び第四項に規定する業務以外の業務を行つたとき。[[laws/貿易保険法/本文/第16条.md|第十六条]]第二項の規定に違反して、経済産業大臣に通知をしなかつたとき。[[laws/貿易保険法/本文/第20条.md|第二十条]]の規定に違反して、財務諸表を提出せず、又は虚偽の記載若しくは記録をした財務諸表を提出したとき。[[laws/貿易保険法/本文/第21条.md|第二十一条]]第四項、[[laws/貿易保険法/本文/第31条.md|第三十一条]]第二項又は[[laws/貿易保険法/本文/第40条.md|第四十条]]第二項の規定による命令に違反したとき。[[laws/貿易保険法/本文/第22条.md|第二十二条]]の規定に違反して責任準備金を積み立てなかつたとき。[[laws/貿易保険法/本文/第23条.md|第二十三条]]の規定に違反して支払備金を積み立てなかつたとき。[[laws/貿易保険法/本文/第29条.md|第二十九条]]の規定に違反して業務上の余裕金を運用したとき。[[laws/貿易保険法/本文/第40条.md|第四十条]]第三項の規定に違反して貿易保険を引き受けたとき。

- 一 この法律の規定により経済産業大臣の認可又は承認を受けなければならない場合において、その認可又は承認を受けなかつたとき。
- 二 [[laws/貿易保険法/本文/第12条.md|第十二条]]第一項、第二項及び第四項に規定する業務以外の業務を行つたとき。
- 三 [[laws/貿易保険法/本文/第16条.md|第十六条]]第二項の規定に違反して、経済産業大臣に通知をしなかつたとき。
- 四 [[laws/貿易保険法/本文/第20条.md|第二十条]]の規定に違反して、財務諸表を提出せず、又は虚偽の記載若しくは記録をした財務諸表を提出したとき。
- 五 [[laws/貿易保険法/本文/第21条.md|第二十一条]]第四項、[[laws/貿易保険法/本文/第31条.md|第三十一条]]第二項又は[[laws/貿易保険法/本文/第40条.md|第四十条]]第二項の規定による命令に違反したとき。
- 六 [[laws/貿易保険法/本文/第22条.md|第二十二条]]の規定に違反して責任準備金を積み立てなかつたとき。
- 七 [[laws/貿易保険法/本文/第23条.md|第二十三条]]の規定に違反して支払備金を積み立てなかつたとき。
- 八 [[laws/貿易保険法/本文/第29条.md|第二十九条]]の規定に違反して業務上の余裕金を運用したとき。
- 九 [[laws/貿易保険法/本文/第40条.md|第四十条]]第三項の規定に違反して貿易保険を引き受けたとき。
