# 第五十二条 

## 
次の各号のいずれかに該当するときは、その違反行為をした者は、百万円以下の罰金に処する。[[laws/324AC0000000100/本文/第26条.md|第二十六条]]第一項から第三項まで又は[[laws/324AC0000000100/本文/第26条の3.md|第二十六条の三]]第七項の規定による主任技術者又は監理技術者を置かなかつたとき。[[laws/324AC0000000100/本文/第26条の2.md|第二十六条の二]]の規定に違反したとき。[[laws/324AC0000000100/本文/第29条の3.md|第二十九条の三]]第一項後段の規定による通知をしなかつたとき。[[laws/324AC0000000100/本文/第27条の24.md|第二十七条の二十四]]第四項又は[[laws/324AC0000000100/本文/第27条の26.md|第二十七条の二十六]]第四項の規定による報告をせず、若しくは資料の提出をせず、又は虚偽の報告をし、若しくは虚偽の資料を提出したとき。[[laws/324AC0000000100/本文/第31条.md|第三十一条]]第一項、[[laws/324AC0000000100/本文/第41条の2.md|第四十一条の二]]第四項又は[[laws/324AC0000000100/本文/第42条の2.md|第四十二条の二]]第一項の規定による報告をせず、又は虚偽の報告をしたとき。[[laws/324AC0000000100/本文/第31条.md|第三十一条]]第一項、[[laws/324AC0000000100/本文/第41条の2.md|第四十一条の二]]第四項又は[[laws/324AC0000000100/本文/第42条の2.md|第四十二条の二]]第一項の規定による検査を拒み、妨げ、又は忌避したとき。[[laws/324AC0000000100/本文/第41条の2.md|第四十一条の二]]第三項の規定による命令に違反したとき。

- 一 [[laws/324AC0000000100/本文/第26条.md|第二十六条]]第一項から第三項まで又は[[laws/324AC0000000100/本文/第26条の3.md|第二十六条の三]]第七項の規定による主任技術者又は監理技術者を置かなかつたとき。
- 二 [[laws/324AC0000000100/本文/第26条の2.md|第二十六条の二]]の規定に違反したとき。
- 三 [[laws/324AC0000000100/本文/第29条の3.md|第二十九条の三]]第一項後段の規定による通知をしなかつたとき。
- 四 [[laws/324AC0000000100/本文/第27条の24.md|第二十七条の二十四]]第四項又は[[laws/324AC0000000100/本文/第27条の26.md|第二十七条の二十六]]第四項の規定による報告をせず、若しくは資料の提出をせず、又は虚偽の報告をし、若しくは虚偽の資料を提出したとき。
- 五 [[laws/324AC0000000100/本文/第31条.md|第三十一条]]第一項、[[laws/324AC0000000100/本文/第41条の2.md|第四十一条の二]]第四項又は[[laws/324AC0000000100/本文/第42条の2.md|第四十二条の二]]第一項の規定による報告をせず、又は虚偽の報告をしたとき。
- 六 [[laws/324AC0000000100/本文/第31条.md|第三十一条]]第一項、[[laws/324AC0000000100/本文/第41条の2.md|第四十一条の二]]第四項又は[[laws/324AC0000000100/本文/第42条の2.md|第四十二条の二]]第一項の規定による検査を拒み、妨げ、又は忌避したとき。
- 七 [[laws/324AC0000000100/本文/第41条の2.md|第四十一条の二]]第三項の規定による命令に違反したとき。
