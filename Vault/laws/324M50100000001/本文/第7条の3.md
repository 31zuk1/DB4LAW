# 第七条の三 （行政執行法人担当委員会議の付議事項）

## 
中労委の行政執行法人担当委員会議に付議すべき事項は、次のとおりとする。行労法[[laws/324M50100000001/本文/第26条.md|第二十六条]]第一項の規定によるあつせんを行う決議に関する事項行労法[[laws/324M50100000001/本文/第26条.md|第二十六条]]第二項の規定によるあつせん員の委嘱に係る同意に関する事項行労法[[laws/324M50100000001/本文/第27条.md|第二十七条]]第三号及び第四号の規定による調停を行う決議に関する事項行労法[[laws/324M50100000001/本文/第28条.md|第二十八条]]の規定による調停委員会の設置に関する事項行労法[[laws/324M50100000001/本文/第29条.md|第二十九条]]第四項及び行労法施行令[[laws/324M50100000001/本文/第7条.md|第七条]]第一項の規定による調停委員候補者の委嘱及び調停委員候補者名簿の作成並びに同令[[laws/324M50100000001/本文/第7条.md|第七条]]第三項の規定による調停委員候補者の解任の同意に関する事項行労法[[laws/324M50100000001/本文/第31条.md|第三十一条]]の規定により調停委員会に報告させ又は指示することに関する事項行労法[[laws/324M50100000001/本文/第33条.md|第三十三条]]第四号に規定する仲裁を行う決議に関する事項[[laws/324M50100000001/本文/第81条の5.md|第八十一条の五]]の規定によるあつせんを行う認定に関する事項[[laws/324M50100000001/本文/第81条の10.md|第八十一条の十]]の規定によるあつせんに係る措置に関する事項その他会長が必要と認める事項

- 一 行労法[[laws/324M50100000001/本文/第26条.md|第二十六条]]第一項の規定によるあつせんを行う決議に関する事項
- 二 行労法[[laws/324M50100000001/本文/第26条.md|第二十六条]]第二項の規定によるあつせん員の委嘱に係る同意に関する事項
- 三 行労法[[laws/324M50100000001/本文/第27条.md|第二十七条]]第三号及び第四号の規定による調停を行う決議に関する事項
- 四 行労法[[laws/324M50100000001/本文/第28条.md|第二十八条]]の規定による調停委員会の設置に関する事項
- 五 行労法[[laws/324M50100000001/本文/第29条.md|第二十九条]]第四項及び行労法施行令[[laws/324M50100000001/本文/第7条.md|第七条]]第一項の規定による調停委員候補者の委嘱及び調停委員候補者名簿の作成並びに同令[[laws/324M50100000001/本文/第7条.md|第七条]]第三項の規定による調停委員候補者の解任の同意に関する事項
- 六 行労法[[laws/324M50100000001/本文/第31条.md|第三十一条]]の規定により調停委員会に報告させ又は指示することに関する事項
- 七 行労法[[laws/324M50100000001/本文/第33条.md|第三十三条]]第四号に規定する仲裁を行う決議に関する事項
- 八 [[laws/324M50100000001/本文/第81条の5.md|第八十一条の五]]の規定によるあつせんを行う認定に関する事項
- 九 [[laws/324M50100000001/本文/第81条の10.md|第八十一条の十]]の規定によるあつせんに係る措置に関する事項
- 十 その他会長が必要と認める事項
