# 第八十一条の二十 （仲裁の申請）

## 
仲裁の申請は、次の事項を記載し、申請者の代表者が氏名を記載した仲裁申請書を中労委に提出することによつて行う。申請者の名称、代表者の氏名及び主たる事務所の所在地他の関係当事者の名称、代表者の氏名及び主たる事務所の所在地仲裁を求める事項申請に至るまでの経過及び主張の対立点労働協約の定めに基づく申請であるときは、その労働協約の関係条項申請の日付

- 一 申請者の名称、代表者の氏名及び主たる事務所の所在地
- 二 他の関係当事者の名称、代表者の氏名及び主たる事務所の所在地
- 三 仲裁を求める事項
- 四 申請に至るまでの経過及び主張の対立点
- 五 労働協約の定めに基づく申請であるときは、その労働協約の関係条項
- 六 申請の日付
## ２
[[laws/労働委員会規則/本文/第81条の4.md|第八十一条の四]]第二項の規定は、前項の申請について準用する。
