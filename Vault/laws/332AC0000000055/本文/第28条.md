# 第二十八条 

## 
次の各号のいずれかに該当する者は、一年以下の拘禁刑又は五十万円以下の罰金に処する。[[laws/揮発油税法/本文/第10条.md|第十条]]第一項又は[[laws/揮発油税法/本文/第11条.md|第十一条]]第一項の規定による申告書をその提出期限までに提出しなかつた者[[laws/揮発油税法/本文/第11条.md|第十一条]]第二項の規定による申告書をその提出期限までに提出せず、又は偽りの申告書を提出した者[[laws/揮発油税法/本文/第14条.md|第十四条]]第七項（[[laws/揮発油税法/本文/第16条の3.md|第十六条の三]]第四項において準用する場合を含む。）の規定による書類をその提出期限までに提出せず、又は偽りの書類を提出した者[[laws/揮発油税法/本文/第16条の3.md|第十六条の三]]第五項本文（[[laws/揮発油税法/本文/第16条の5.md|第十六条の五]]第四項において準用する場合を含む。）の規定に違反した者[[laws/揮発油税法/本文/第23条.md|第二十三条]]の規定による申告をせず、又は偽つた者[[laws/揮発油税法/本文/第24条.md|第二十四条]]の規定による帳簿の記載をせず、若しくは偽り、又はその帳簿を隠匿した者

- 一 [[laws/揮発油税法/本文/第10条.md|第十条]]第一項又は[[laws/揮発油税法/本文/第11条.md|第十一条]]第一項の規定による申告書をその提出期限までに提出しなかつた者
- 二 [[laws/揮発油税法/本文/第11条.md|第十一条]]第二項の規定による申告書をその提出期限までに提出せず、又は偽りの申告書を提出した者
- 三 [[laws/揮発油税法/本文/第14条.md|第十四条]]第七項（[[laws/揮発油税法/本文/第16条の3.md|第十六条の三]]第四項において準用する場合を含む。）の規定による書類をその提出期限までに提出せず、又は偽りの書類を提出した者
- 四 [[laws/揮発油税法/本文/第16条の3.md|第十六条の三]]第五項本文（[[laws/揮発油税法/本文/第16条の5.md|第十六条の五]]第四項において準用する場合を含む。）の規定に違反した者
- 五 [[laws/揮発油税法/本文/第23条.md|第二十三条]]の規定による申告をせず、又は偽つた者
- 六 [[laws/揮発油税法/本文/第24条.md|第二十四条]]の規定による帳簿の記載をせず、若しくは偽り、又はその帳簿を隠匿した者
