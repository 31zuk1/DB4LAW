# 第二十七条 （個人型年金に係る規約に定めるその他の事項）

## 
法[[laws/確定拠出年金法施行令/本文/第55条.md|第五十五条]]第二項第八号の政令で定める事項は、次のとおりとする。法[[laws/確定拠出年金法施行令/本文/第75条.md|第七十五条]]第一項に規定する個人型年金規約策定委員会（以下「策定委員会」という。）に関する事項法[[laws/確定拠出年金法施行令/本文/第60条.md|第六十条]]第一項の規定による運営管理業務の委託に係る契約（同条第三項の規定による再委託に係る契約を含む。）に関する事項法[[laws/確定拠出年金法施行令/本文/第61条.md|第六十一条]]第一項の規定により同項第三号及び第四号に掲げる事務の委託を受けた者の名称、住所及びその行う業務並びに当該事務の委託に係る契約に関する事項個人型年金加入者掛金の納付に関する事項（個人型年金加入者掛金の最低額に関する事項を含む。）中小事業主（法[[laws/確定拠出年金法施行令/本文/第55条.md|第五十五条]]第二項第四号の二に規定する中小事業主をいう。[[laws/確定拠出年金法施行令/本文/第29条.md|第二十九条]]第四号及び[[laws/確定拠出年金法施行令/本文/第35条の2.md|第三十五条の二]]第二項において同じ。）が法[[laws/確定拠出年金法施行令/本文/第68条の2.md|第六十八条の二]]第一項の規定により中小事業主掛金を拠出することを定める場合にあっては、中小事業主掛金の納付に関する事項法[[laws/確定拠出年金法施行令/本文/第73条.md|第七十三条]]において準用する法[[laws/確定拠出年金法施行令/本文/第22条.md|第二十二条]]の規定による措置の内容法[[laws/確定拠出年金法施行令/本文/第74条の2.md|第七十四条の二]]第一項の規定により脱退一時金相当額等又は残余財産（同項に規定する残余財産をいう。以下同じ。）の移換を受ける場合にあっては、脱退一時金相当額等又は残余財産の移換に関する事項法[[laws/確定拠出年金法施行令/本文/第74条の4.md|第七十四条の四]]第二項の規定により個人別管理資産を移換する場合にあっては、個人別管理資産の移換に関する事項個人型年金の事業年度に関する事項公告に関する事項

- 一 法[[laws/確定拠出年金法施行令/本文/第75条.md|第七十五条]]第一項に規定する個人型年金規約策定委員会（以下「策定委員会」という。）に関する事項
- 二 法[[laws/確定拠出年金法施行令/本文/第60条.md|第六十条]]第一項の規定による運営管理業務の委託に係る契約（同条第三項の規定による再委託に係る契約を含む。）に関する事項
- 三 法[[laws/確定拠出年金法施行令/本文/第61条.md|第六十一条]]第一項の規定により同項第三号及び第四号に掲げる事務の委託を受けた者の名称、住所及びその行う業務並びに当該事務の委託に係る契約に関する事項
- 四 個人型年金加入者掛金の納付に関する事項（個人型年金加入者掛金の最低額に関する事項を含む。）
- 五 中小事業主（法[[laws/確定拠出年金法施行令/本文/第55条.md|第五十五条]]第二項第四号の二に規定する中小事業主をいう。[[laws/確定拠出年金法施行令/本文/第29条.md|第二十九条]]第四号及び[[laws/確定拠出年金法施行令/本文/第35条の2.md|第三十五条の二]]第二項において同じ。）が法[[laws/確定拠出年金法施行令/本文/第68条の2.md|第六十八条の二]]第一項の規定により中小事業主掛金を拠出することを定める場合にあっては、中小事業主掛金の納付に関する事項
- 六 法[[laws/確定拠出年金法施行令/本文/第73条.md|第七十三条]]において準用する法[[laws/確定拠出年金法施行令/本文/第22条.md|第二十二条]]の規定による措置の内容
- 七 法[[laws/確定拠出年金法施行令/本文/第74条の2.md|第七十四条の二]]第一項の規定により脱退一時金相当額等又は残余財産（同項に規定する残余財産をいう。以下同じ。）の移換を受ける場合にあっては、脱退一時金相当額等又は残余財産の移換に関する事項
- 八 法[[laws/確定拠出年金法施行令/本文/第74条の4.md|第七十四条の四]]第二項の規定により個人別管理資産を移換する場合にあっては、個人別管理資産の移換に関する事項
- 九 個人型年金の事業年度に関する事項
- 十 公告に関する事項
