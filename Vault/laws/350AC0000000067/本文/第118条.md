# 第百十八条 

## 
次の各号に掲げる場合においては、その行為をした住宅街区整備組合の理事、監事又は清算人は、二十万円以下の過料に処する。住宅街区整備組合が住宅街区整備事業以外の事業を営んだとき。[[laws/大都市地域における住宅及び住宅地の供給の促進に関する特別措置法/本文/第51条.md|第五十一条]]において準用する土地区画整理法[[laws/大都市地域における住宅及び住宅地の供給の促進に関する特別措置法/本文/第39条.md|第三十九条]]第三項、[[laws/大都市地域における住宅及び住宅地の供給の促進に関する特別措置法/本文/第45条.md|第四十五条]]第四項若しくは[[laws/大都市地域における住宅及び住宅地の供給の促進に関する特別措置法/本文/第50条.md|第五十条]]第五項の規定又は[[laws/大都市地域における住宅及び住宅地の供給の促進に関する特別措置法/本文/第101条.md|第百一条]]において準用する同法第百二十八条第三項の規定に違反したとき。[[laws/大都市地域における住宅及び住宅地の供給の促進に関する特別措置法/本文/第51条.md|第五十一条]]において準用する土地区画整理法[[laws/大都市地域における住宅及び住宅地の供給の促進に関する特別措置法/本文/第47条.md|第四十七条]]又は[[laws/大都市地域における住宅及び住宅地の供給の促進に関する特別措置法/本文/第49条.md|第四十九条]]に掲げる書類に記載すべき事項を記載せず、又は不実の記載をしたとき。[[laws/大都市地域における住宅及び住宅地の供給の促進に関する特別措置法/本文/第51条.md|第五十一条]]において準用する土地区画整理法[[laws/大都市地域における住宅及び住宅地の供給の促進に関する特別措置法/本文/第48条.md|第四十八条]]の規定に違反して住宅街区整備組合の残余財産を処分したとき。[[laws/大都市地域における住宅及び住宅地の供給の促進に関する特別措置法/本文/第96条.md|第九十六条]]において準用する土地区画整理法[[laws/大都市地域における住宅及び住宅地の供給の促進に関する特別措置法/本文/第125条.md|第百二十五条]]第一項又は第二項の規定による都府県知事の検査を妨げたとき。[[laws/大都市地域における住宅及び住宅地の供給の促進に関する特別措置法/本文/第96条.md|第九十六条]]において準用する土地区画整理法[[laws/大都市地域における住宅及び住宅地の供給の促進に関する特別措置法/本文/第125条.md|第百二十五条]]第三項の規定による都府県知事の命令に違反したとき。国土交通大臣、都府県知事若しくは市町村長又は総会、総会の部会若しくは総代会に対し、不実の申立てをし、又は事実を隠したとき。住宅街区整備組合がこの法律の規定による公告をすべき場合において、公告をせず、又は不実の公告をしたとき。

- 一 住宅街区整備組合が住宅街区整備事業以外の事業を営んだとき。
- 二 [[laws/大都市地域における住宅及び住宅地の供給の促進に関する特別措置法/本文/第51条.md|第五十一条]]において準用する土地区画整理法[[laws/大都市地域における住宅及び住宅地の供給の促進に関する特別措置法/本文/第39条.md|第三十九条]]第三項、[[laws/大都市地域における住宅及び住宅地の供給の促進に関する特別措置法/本文/第45条.md|第四十五条]]第四項若しくは[[laws/大都市地域における住宅及び住宅地の供給の促進に関する特別措置法/本文/第50条.md|第五十条]]第五項の規定又は[[laws/大都市地域における住宅及び住宅地の供給の促進に関する特別措置法/本文/第101条.md|第百一条]]において準用する同法第百二十八条第三項の規定に違反したとき。
- 三 [[laws/大都市地域における住宅及び住宅地の供給の促進に関する特別措置法/本文/第51条.md|第五十一条]]において準用する土地区画整理法[[laws/大都市地域における住宅及び住宅地の供給の促進に関する特別措置法/本文/第47条.md|第四十七条]]又は[[laws/大都市地域における住宅及び住宅地の供給の促進に関する特別措置法/本文/第49条.md|第四十九条]]に掲げる書類に記載すべき事項を記載せず、又は不実の記載をしたとき。
- 四 [[laws/大都市地域における住宅及び住宅地の供給の促進に関する特別措置法/本文/第51条.md|第五十一条]]において準用する土地区画整理法[[laws/大都市地域における住宅及び住宅地の供給の促進に関する特別措置法/本文/第48条.md|第四十八条]]の規定に違反して住宅街区整備組合の残余財産を処分したとき。
- 五 [[laws/大都市地域における住宅及び住宅地の供給の促進に関する特別措置法/本文/第96条.md|第九十六条]]において準用する土地区画整理法[[laws/大都市地域における住宅及び住宅地の供給の促進に関する特別措置法/本文/第125条.md|第百二十五条]]第一項又は第二項の規定による都府県知事の検査を妨げたとき。
- 六 [[laws/大都市地域における住宅及び住宅地の供給の促進に関する特別措置法/本文/第96条.md|第九十六条]]において準用する土地区画整理法[[laws/大都市地域における住宅及び住宅地の供給の促進に関する特別措置法/本文/第125条.md|第百二十五条]]第三項の規定による都府県知事の命令に違反したとき。
- 七 国土交通大臣、都府県知事若しくは市町村長又は総会、総会の部会若しくは総代会に対し、不実の申立てをし、又は事実を隠したとき。
- 八 住宅街区整備組合がこの法律の規定による公告をすべき場合において、公告をせず、又は不実の公告をしたとき。
