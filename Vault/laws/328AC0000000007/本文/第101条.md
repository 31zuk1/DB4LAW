# 第百一条 

## 
次の各号のいずれかに該当する場合においては、酒類業組合等の発起人、理事、監事若しくは清算人又は酒類製造業者若しくは酒類販売業者は、十万円以下の過料に処する。この法律の規定に基づいて酒類業組合等が行うことができる事業以外の事業を営んだとき。この法律に定める登記を怠つたとき。この法律に定める公告を怠り、又は不正の公告をしたとき。[[laws/328AC0000000007/本文/第10条.md|第十条]]（[[laws/328AC0000000007/本文/第83条.md|第八十三条]]において準用する場合を含む。）の規定に違反したとき。[[laws/328AC0000000007/本文/第13条.md|第十三条]]第二項（[[laws/328AC0000000007/本文/第83条.md|第八十三条]]において準用する場合を含む。）の規定に違反したとき。[[laws/328AC0000000007/本文/第18条.md|第十八条]]第十一項、[[laws/328AC0000000007/本文/第26条.md|第二十六条]]第四項（[[laws/328AC0000000007/本文/第58条.md|第五十八条]]第二項において準用する場合を含む。）若しくは[[laws/328AC0000000007/本文/第38条の3.md|第三十八条の三]]（これらの規定を[[laws/328AC0000000007/本文/第83条.md|第八十三条]]において準用する場合を含む。）の規定又は[[laws/328AC0000000007/本文/第58条.md|第五十八条]]第一項（[[laws/328AC0000000007/本文/第83条.md|第八十三条]]において準用する場合を含む。）において準用する会社法[[laws/417AC0000000086/本文/第492条.md|第四百九十二条]]第一項（財産目録等の作成等）の規定に違反して議事録若しくは財産目録を作成せず、又はこれらの書類に記載すべき事項を記載せず、若しくは偽りの記載をしたとき。[[laws/328AC0000000007/本文/第28条.md|第二十八条]]、[[laws/417AC0000000086/本文/第29条.md|第二十九条]]又は[[laws/417AC0000000086/本文/第40条.md|第四十条]]第二項若しくは第三項（これらの規定を[[laws/328AC0000000007/本文/第58条.md|第五十八条]]第二項及び[[laws/417AC0000000086/本文/第83条.md|第八十三条]]において準用する場合を含む。）の規定に違反して書類を備えて置かず、その書類に記載すべき事項を記載せず、若しくは偽りの記載をし、又は正当な理由がないのにその書類の閲覧若しくは謄写を拒んだとき。この法律又は定款で定めた理事又は監事の定数を欠くに至つた場合において、その選任手続をすることを怠つたとき。[[laws/328AC0000000007/本文/第31条.md|第三十一条]]第二項又は第三項（[[laws/328AC0000000007/本文/第58条.md|第五十八条]]第二項及び[[laws/328AC0000000007/本文/第83条.md|第八十三条]]において準用する場合を含む。）の規定による調査を妨げたとき。[[laws/328AC0000000007/本文/第33条.md|第三十三条]]（[[laws/328AC0000000007/本文/第83条.md|第八十三条]]において準用する場合を含む。）において準用する会社法[[laws/417AC0000000086/本文/第430条の2.md|第四百三十条の二]]第四項（補償契約）の規定に違反して理事会に報告せず、又は虚偽の報告をしたとき。[[laws/328AC0000000007/本文/第34条.md|第三十四条]]第一項（[[laws/328AC0000000007/本文/第58条.md|第五十八条]]第二項及び[[laws/417AC0000000086/本文/第83条.md|第八十三条]]において準用する場合を含む。）の規定に違反したとき。[[laws/328AC0000000007/本文/第41条.md|第四十一条]]（[[laws/328AC0000000007/本文/第58条.md|第五十八条]]第二項及び[[laws/417AC0000000086/本文/第83条.md|第八十三条]]において準用する場合を含む。）の規定に違反して正当な理由がないのに帳簿又は書類の閲覧又は謄写を拒んだとき。[[laws/328AC0000000007/本文/第43条.md|第四十三条]]第三項（[[laws/328AC0000000007/本文/第83条.md|第八十三条]]において準用する場合を含む。）、[[laws/417AC0000000086/本文/第46条.md|第四十六条]]第二項（[[laws/328AC0000000007/本文/第83条.md|第八十三条]]において準用する場合を含む。）、[[laws/417AC0000000086/会社法_law.md|第八十六条の九]]第四項又は[[laws/417AC0000000086/本文/第87条.md|第八十七条]]の規定による届出を怠つたとき。[[laws/328AC0000000007/本文/第58条.md|第五十八条]]第一項（[[laws/328AC0000000007/本文/第83条.md|第八十三条]]において準用する場合を含む。）において準用する会社法[[laws/417AC0000000086/本文/第484条.md|第四百八十四条]]第一項（清算株式会社についての破産手続の開始）の規定に違反して破産手続開始の申立てをすることを怠つたとき。[[laws/328AC0000000007/本文/第58条.md|第五十八条]]第一項（[[laws/328AC0000000007/本文/第83条.md|第八十三条]]において準用する場合を含む。）において準用する会社法[[laws/417AC0000000086/本文/第499条.md|第四百九十九条]]第一項（債権者に対する公告等）の期間を不当に定めたとき。[[laws/328AC0000000007/本文/第58条.md|第五十八条]]第一項（[[laws/328AC0000000007/本文/第83条.md|第八十三条]]において準用する場合を含む。）において準用する会社法[[laws/417AC0000000086/本文/第500条.md|第五百条]]第一項（債務の弁済の制限）の規定に違反して債務の弁済をしたとき。[[laws/328AC0000000007/本文/第58条.md|第五十八条]]第一項（[[laws/328AC0000000007/本文/第83条.md|第八十三条]]において準用する場合を含む。）において準用する会社法[[laws/417AC0000000086/本文/第502条.md|第五百二条]]（債務の弁済前における残余財産の分配の制限）の規定に違反して財産を処分したとき。裁判所の選任した清算人に事務の引渡しをしないとき。[[laws/328AC0000000007/本文/第87条の2.md|第八十七条の二]]の規定に違反して書類を提出せず、又は虚偽の書類を提出したとき。

- 一 この法律の規定に基づいて酒類業組合等が行うことができる事業以外の事業を営んだとき。
- 二 この法律に定める登記を怠つたとき。
- 三 この法律に定める公告を怠り、又は不正の公告をしたとき。
- 四 [[laws/328AC0000000007/本文/第10条.md|第十条]]（[[laws/328AC0000000007/本文/第83条.md|第八十三条]]において準用する場合を含む。）の規定に違反したとき。
- 五 [[laws/328AC0000000007/本文/第13条.md|第十三条]]第二項（[[laws/328AC0000000007/本文/第83条.md|第八十三条]]において準用する場合を含む。）の規定に違反したとき。
- 六 [[laws/328AC0000000007/本文/第18条.md|第十八条]]第十一項、[[laws/328AC0000000007/本文/第26条.md|第二十六条]]第四項（[[laws/328AC0000000007/本文/第58条.md|第五十八条]]第二項において準用する場合を含む。）若しくは[[laws/328AC0000000007/本文/第38条の3.md|第三十八条の三]]（これらの規定を[[laws/328AC0000000007/本文/第83条.md|第八十三条]]において準用する場合を含む。）の規定又は[[laws/328AC0000000007/本文/第58条.md|第五十八条]]第一項（[[laws/328AC0000000007/本文/第83条.md|第八十三条]]において準用する場合を含む。）において準用する会社法[[laws/417AC0000000086/本文/第492条.md|第四百九十二条]]第一項（財産目録等の作成等）の規定に違反して議事録若しくは財産目録を作成せず、又はこれらの書類に記載すべき事項を記載せず、若しくは偽りの記載をしたとき。
- 七 [[laws/328AC0000000007/本文/第28条.md|第二十八条]]、[[laws/328AC0000000007/本文/第29条.md|第二十九条]]又は[[laws/328AC0000000007/本文/第40条.md|第四十条]]第二項若しくは第三項（これらの規定を[[laws/328AC0000000007/本文/第58条.md|第五十八条]]第二項及び[[laws/328AC0000000007/本文/第83条.md|第八十三条]]において準用する場合を含む。）の規定に違反して書類を備えて置かず、その書類に記載すべき事項を記載せず、若しくは偽りの記載をし、又は正当な理由がないのにその書類の閲覧若しくは謄写を拒んだとき。
- 八 この法律又は定款で定めた理事又は監事の定数を欠くに至つた場合において、その選任手続をすることを怠つたとき。
- 九 [[laws/328AC0000000007/本文/第31条.md|第三十一条]]第二項又は第三項（[[laws/328AC0000000007/本文/第58条.md|第五十八条]]第二項及び[[laws/328AC0000000007/本文/第83条.md|第八十三条]]において準用する場合を含む。）の規定による調査を妨げたとき。
- 九の二 [[laws/328AC0000000007/本文/第33条.md|第三十三条]]（[[laws/328AC0000000007/本文/第83条.md|第八十三条]]において準用する場合を含む。）において準用する会社法[[laws/417AC0000000086/本文/第430条の2.md|第四百三十条の二]]第四項（補償契約）の規定に違反して理事会に報告せず、又は虚偽の報告をしたとき。
- 十 [[laws/328AC0000000007/本文/第34条.md|第三十四条]]第一項（[[laws/328AC0000000007/本文/第58条.md|第五十八条]]第二項及び[[laws/328AC0000000007/本文/第83条.md|第八十三条]]において準用する場合を含む。）の規定に違反したとき。
- 十一 [[laws/328AC0000000007/本文/第41条.md|第四十一条]]（[[laws/328AC0000000007/本文/第58条.md|第五十八条]]第二項及び[[laws/328AC0000000007/本文/第83条.md|第八十三条]]において準用する場合を含む。）の規定に違反して正当な理由がないのに帳簿又は書類の閲覧又は謄写を拒んだとき。
- 十二 [[laws/328AC0000000007/本文/第43条.md|第四十三条]]第三項（[[laws/328AC0000000007/本文/第83条.md|第八十三条]]において準用する場合を含む。）、[[laws/328AC0000000007/本文/第46条.md|第四十六条]]第二項（[[laws/328AC0000000007/本文/第83条.md|第八十三条]]において準用する場合を含む。）、[[laws/328AC0000000007/本文/第86条の9.md|第八十六条の九]]第四項又は[[laws/328AC0000000007/本文/第87条.md|第八十七条]]の規定による届出を怠つたとき。
- 十三 [[laws/328AC0000000007/本文/第58条.md|第五十八条]]第一項（[[laws/328AC0000000007/本文/第83条.md|第八十三条]]において準用する場合を含む。）において準用する会社法[[laws/417AC0000000086/本文/第484条.md|第四百八十四条]]第一項（清算株式会社についての破産手続の開始）の規定に違反して破産手続開始の申立てをすることを怠つたとき。

- 十五 [[laws/328AC0000000007/本文/第58条.md|第五十八条]]第一項（[[laws/328AC0000000007/本文/第83条.md|第八十三条]]において準用する場合を含む。）において準用する会社法[[laws/417AC0000000086/本文/第500条.md|第五百条]]第一項（債務の弁済の制限）の規定に違反して債務の弁済をしたとき。
