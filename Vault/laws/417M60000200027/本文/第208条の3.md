# 第二百八条の三 （組合の継続の届出）

## 
組合は、法[[laws/322AC0000000132/本文/第64条の3.md|第六十四条の三]]第三項の規定による届出をしようとするときは、届出書に組合の継続を決議した総会の議事録及び継続の登記に係る登記事項証明書を添付して行政庁に提出しなければならない。
