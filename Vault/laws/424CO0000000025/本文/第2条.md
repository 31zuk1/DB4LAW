# 第二条 （実施に関する計画を定める事業）

## 
法[[laws/424CO0000000025/復興庁設置法第四条第二項第三号イ及びロの_law.md|第四条]]第二項第三号ロの政令で定める事業は、前条に規定する事業のうち次に掲げるものに係るものとする。東日本大震災に対処するための特別の財政援助及び助成に関する法律（平成二十三年法律第四十号）[[laws/424CO0000000025/復興庁設置法第四条第二項第三号イ及びロの_law.md|第七条]]に規定する消防の用に供する施設の復旧（内閣総理大臣が定めるものに限る。）文化財保護法（昭和二十五年法律第二百十四号）第三十五条第一項（同法第八十三条、[[laws/424CO0000000025/復興庁設置法第四条第二項第三号イ及びロの_law.md|第百十八条]]、[[laws/424CO0000000025/復興庁設置法第四条第二項第三号イ及びロの_law.md|第百二十条]]、[[laws/424CO0000000025/復興庁設置法第四条第二項第三号イ及びロの_law.md|第百七十二条]]第五項及び[[laws/424CO0000000025/復興庁設置法第四条第二項第三号イ及びロの_law.md|第百七十四条]]第三項において準用する場合を含む。）、[[laws/424CO0000000025/復興庁設置法第四条第二項第三号イ及びロの_law.md|第七十四条]]第一項、[[laws/424CO0000000025/復興庁設置法第四条第二項第三号イ及びロの_law.md|第七十七条]]第一項（同法第九十一条において準用する場合を含む。）、[[laws/424CO0000000025/復興庁設置法第四条第二項第三号イ及びロの_law.md|第八十七条]]第一項、[[laws/424CO0000000025/復興庁設置法第四条第二項第三号イ及びロの_law.md|第九十九条]]第四項、[[laws/424CO0000000025/復興庁設置法第四条第二項第三号イ及びロの_law.md|第百四十一条]]第三項、[[laws/424CO0000000025/復興庁設置法第四条第二項第三号イ及びロの_law.md|第百四十六条]]及び[[laws/424CO0000000025/復興庁設置法第四条第二項第三号イ及びロの_law.md|第百五十二条]]の規定による国の補助私立学校振興助成法（昭和五十年法律第六十一号）第七条の規定による国の補助東日本大震災に対処するための特別の財政援助及び助成に関する法律[[laws/424CO0000000025/復興庁設置法第四条第二項第三号イ及びロの_law.md|第三条]]第一項第一号に掲げる施設の災害復旧事業土地改良法（昭和二十四年法律第百九十五号）第二条第二項に規定する土地改良事業漁港及び漁場の整備等に関する法律（昭和二十五年法律第百三十七号）[[laws/424CO0000000025/復興庁設置法第四条第二項第三号イ及びロの_law.md|第十七条]]第一項に規定する特定漁港漁場整備事業農林水産業施設災害復旧事業費国庫補助の暫定措置に関する法律（昭和二十五年法律第百六十九号）[[laws/424CO0000000025/本文/第2条.md|第二条]]第六項に規定する災害復旧事業森林法（昭和二十六年法律第二百四十九号）第百九十三条に規定する造林及び地域森林計画に定める林道の開設又は拡張海岸法（昭和三十一年法律第百一号）第二条第一項に規定する海岸保全施設の新設及び改良激甚じん災害に対処するための特別の財政援助等に関する法律（昭和三十七年法律第百五十号）[[laws/424CO0000000025/復興庁設置法第四条第二項第三号イ及びロの_law.md|第三条]]第一項第一号及び第二号に掲げる事業激甚じん災害に対処するための特別の財政援助等に関する法律[[laws/424CO0000000025/復興庁設置法第四条第二項第三号イ及びロの_law.md|第五条]]第一項に規定する災害関連事業国立研究開発法人森林研究・整備機構法（平成十一年法律第百九十八号）第十三条第一項第四号及び第六号（第四号に係る部分に限る。）に掲げる事業国有林野の管理経営に関する法律（昭和二十六年法律第二百四十六号）[[laws/424CO0000000025/本文/第2条.md|第二条]]第二項に規定する国有林野事業森林法[[laws/424CO0000000025/復興庁設置法第四条第二項第三号イ及びロの_law.md|第十条の十五]]第四項第四号に規定する治山事業（第七号又は第十号に掲げる事業であるものを除く。）農山漁村の活性化のための定住等及び地域間交流の促進に関する法律（平成十九年法律第四十八号）[[laws/424CO0000000025/復興庁設置法第四条第二項第三号イ及びロの_law.md|第五条]]第二項第二号に規定する活性化事業東日本大震災に対処するための特別の財政援助及び助成に関する法律[[laws/424CO0000000025/復興庁設置法第四条第二項第三号イ及びロの_law.md|第三条]]第一項第七号に掲げる施設の災害復旧事業東日本大震災に対処するための土地改良法の特例に関する法律（平成二十三年法律第四十三号）[[laws/424CO0000000025/本文/第2条.md|第二条]]第一項に規定する除塩砂防法（明治三十年法律第二十九号）第一条に規定する砂防設備に関する事業（第十号に掲げる事業であるものを除く。）港湾法（昭和二十五年法律第二百十八号）第二条第五項に規定する港湾施設の建設又は改良の事業及びこれらの事業以外の事業で港湾その他の海域における汚泥その他公害の原因となる物質の堆積の排除、汚濁水の浄化その他の公害防止のために行うものであって、国土交通大臣又は港湾管理者が施行するもの（第十号に掲げる事業であるものを除く。）港湾法[[laws/424CO0000000025/復興庁設置法第四条第二項第三号イ及びロの_law.md|第四十三条の六]]の規定により国土交通大臣が施行する開発保全航路の開発及び保全の事業港湾法[[laws/424CO0000000025/復興庁設置法第四条第二項第三号イ及びロの_law.md|第四十八条の四]]第一項の規定による電子情報処理組織の設置及び管理の事業道路法（昭和二十七年法律第百八十号）第二条第一項に規定する道路の管理（第十号に掲げる事業であるものを除く。）特定多目的ダム法（昭和三十二年法律第三十五号）第二条第一項に規定する多目的ダムの建設工事に関する事業（第十号に掲げる事業であるものを除く。）地すべり等防止法（昭和三十三年法律第三十号）第五十一条第一項第一号又は第三号ロに規定する地すべり地域又はぼた山に関して同法第三条又は[[laws/424CO0000000025/復興庁設置法第四条第二項第三号イ及びロの_law.md|第四条]]の規定によって指定された地すべり防止区域又はぼた山崩壊防止区域における地すべり防止工事又はぼた山崩壊防止工事に関する事業（第十号に掲げる事業であるものを除く。）河川法（昭和三十九年法律第百六十七号）第三条第一項に規定する河川（同法第百条の規定により同法の二級河川に関する規定が準用される河川を含む。）に関する事業（第十号又は第二十三号に掲げる事業であるもの及び独立行政法人水資源機構法（平成十四年法律第百八十二号）第十二条第一項第一号若しくは第二号（同号イに係る部分に限る。）又は附則第四条第一項に規定する業務に該当するものを除く。）特別会計に関する法律（平成十九年法律第二十三号）附則第二百五十九条の三第二項に規定する空港整備事業自然公園法（昭和三十二年法律第百六十一号）第二条第六号に規定する公園事業東日本大震災に対処するための特別の財政援助及び助成に関する法律[[laws/332AC0000000161/本文/第3条.md|第三条]]第一項第六号に掲げる施設の災害復旧事業前各号に掲げるもののほか、東日本大震災からの復興に関する事業のうち内閣総理大臣が定めるもの

- 三 私立学校振興助成法（昭和五十年法律第六十一号）第七条の規定による国の補助

- 六 漁港及び漁場の整備等に関する法律（昭和二十五年法律第百三十七号）[[laws/424CO0000000025/復興庁設置法第四条第二項第三号イ及びロの_law.md|第十七条]]第一項に規定する特定漁港漁場整備事業
