# 第二百一条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、一年以下の拘禁刑若しくは百万円以下の罰金に処し、又はこれを併科する。[[laws/金融商品取引法/本文/第30条.md|第三十条]]第一項の規定による認可を受けないで同項に規定する業務を行つたとき（同項ただし書の規定により行う場合を除く。）。[[laws/金融商品取引法/本文/第30条の2.md|第三十条の二]]第一項（[[laws/金融商品取引法/本文/第87条の2.md|第八十七条の二]]第三項、[[laws/金融商品取引法/本文/第87条の3.md|第八十七条の三]]第五項、[[laws/金融商品取引法/本文/第106条の3.md|第百六条の三]]第六項、[[laws/金融商品取引法/本文/第106条の10.md|第百六条の十]]第五項、[[laws/金融商品取引法/本文/第106条の17.md|第百六条の十七]]第五項、[[laws/金融商品取引法/本文/第106条の24.md|第百六条の二十四]]第二項、[[laws/金融商品取引法/本文/第155条.md|第百五十五条]]第二項、[[laws/金融商品取引法/本文/第156条の5.md|第百五十六条の五]]の五第六項及び[[laws/金融商品取引法/本文/第156条の20.md|第百五十六条の二十]]の十六第四項において準用する場合を含む。）、[[laws/金融商品取引法/本文/第59条.md|第五十九条]]第二項、[[laws/金融商品取引法/本文/第60条.md|第六十条]]第二項（[[laws/金融商品取引法/本文/第60条の14.md|第六十条の十四]]第二項において準用する場合を含む。）、[[laws/金融商品取引法/本文/第85条.md|第八十五条]]第二項又は[[laws/金融商品取引法/本文/第156条の6.md|第百五十六条の六]]第四項（[[laws/金融商品取引法/本文/第156条の19.md|第百五十六条の十九]]第四項において準用する場合を含む。）の規定により付した条件に違反したとき。[[laws/金融商品取引法/本文/第31条.md|第三十一条]]第六項の規定に違反したとき。[[laws/金融商品取引法/本文/第31条の2.md|第三十一条の二]]第五項、[[laws/金融商品取引法/本文/第33条.md|第三十三条]]第一項、[[laws/金融商品取引法/本文/第33条の2.md|第三十三条の二]]、[[laws/金融商品取引法/本文/第41条の3.md|第四十一条の三]]から[[laws/金融商品取引法/本文/第41条の5.md|第四十一条の五]]まで、[[laws/金融商品取引法/本文/第42条の5.md|第四十二条の五]]、[[laws/金融商品取引法/本文/第42条の6.md|第四十二条の六]]又は[[laws/金融商品取引法/本文/第66条の13.md|第六十六条の十三]]の規定に違反したとき。[[laws/金融商品取引法/本文/第35条.md|第三十五条]]第四項の規定による承認を受けないで金融商品取引業並びに同条第一項に規定する業務及び同条第二項各号に掲げる業務以外の業務を行つたとき。[[laws/金融商品取引法/本文/第52条.md|第五十二条]]第一項（[[laws/金融商品取引法/本文/第30条.md|第三十条]]第一項の認可に係るものに限る。）又は[[laws/金融商品取引法/本文/第52条の2.md|第五十二条の二]]第一項の規定による業務の停止の処分に違反したとき。[[laws/金融商品取引法/本文/第64条.md|第六十四条]]第二項（[[laws/金融商品取引法/本文/第66条の25.md|第六十六条の二十五]]において準用する場合を含む。）の規定に違反して、外務員の職務を行わせたとき。[[laws/金融商品取引法/本文/第67条の7.md|第六十七条の七]]、[[laws/金融商品取引法/本文/第97条.md|第九十七条]]又は[[laws/金融商品取引法/本文/第102条の21.md|第百二条の二十一]]の規定に違反したとき。[[laws/金融商品取引法/本文/第85条.md|第八十五条]]第一項の規定に違反して内閣総理大臣の認可を受けないで同項に規定する自主規制法人に[[laws/金融商品取引法/本文/第84条.md|第八十四条]]第二項に規定する自主規制業務の委託を行つたとき。[[laws/金融商品取引法/本文/第106条の7.md|第百六条の七]]第四項において準用する同条第一項又は[[laws/金融商品取引法/本文/第106条の21.md|第百六条の二十一]]第四項において準用する同条第一項の規定による命令に違反したとき。[[laws/金融商品取引法/本文/第106条の28.md|第百六条の二十八]]第一項（[[laws/金融商品取引法/本文/第109条.md|第百九条]]において準用する場合を含む。）の規定による命令に違反したとき。[[laws/金融商品取引法/本文/第156条の27.md|第百五十六条の二十七]]第三項の規定による承認を受けないで[[laws/金融商品取引法/本文/第156条の24.md|第百五十六条の二十四]]第一項及び[[laws/金融商品取引法/本文/第156条の27.md|第百五十六条の二十七]]第一項各号に規定する業務以外の業務を行つたとき。[[laws/金融商品取引法/本文/第156条の28.md|第百五十六条の二十八]]第一項の規定による認可を受けないで、同項の規定により内閣総理大臣の認可を受けてできることとされる行為をしたとき。

- 一 [[laws/金融商品取引法/本文/第30条.md|第三十条]]第一項の規定による認可を受けないで同項に規定する業務を行つたとき（同項ただし書の規定により行う場合を除く。）。
- 二 [[laws/金融商品取引法/本文/第30条の2.md|第三十条の二]]第一項（[[laws/金融商品取引法/本文/第87条の2.md|第八十七条の二]]第三項、[[laws/金融商品取引法/本文/第87条の3.md|第八十七条の三]]第五項、[[laws/金融商品取引法/本文/第106条の3.md|第百六条の三]]第六項、[[laws/金融商品取引法/本文/第106条の10.md|第百六条の十]]第五項、[[laws/金融商品取引法/本文/第106条の17.md|第百六条の十七]]第五項、[[laws/金融商品取引法/本文/第106条の24.md|第百六条の二十四]]第二項、[[laws/金融商品取引法/本文/第155条.md|第百五十五条]]第二項、[[laws/金融商品取引法/本文/第156条の5.md|第百五十六条の五]]の五第六項及び[[laws/金融商品取引法/本文/第156条の20.md|第百五十六条の二十]]の十六第四項において準用する場合を含む。）、[[laws/金融商品取引法/本文/第59条.md|第五十九条]]第二項、[[laws/金融商品取引法/本文/第60条.md|第六十条]]第二項（[[laws/金融商品取引法/本文/第60条の14.md|第六十条の十四]]第二項において準用する場合を含む。）、[[laws/金融商品取引法/本文/第85条.md|第八十五条]]第二項又は[[laws/金融商品取引法/本文/第156条の6.md|第百五十六条の六]]第四項（[[laws/金融商品取引法/本文/第156条の19.md|第百五十六条の十九]]第四項において準用する場合を含む。）の規定により付した条件に違反したとき。
- 三 [[laws/金融商品取引法/本文/第31条.md|第三十一条]]第六項の規定に違反したとき。
- 四 [[laws/金融商品取引法/本文/第31条の2.md|第三十一条の二]]第五項、[[laws/金融商品取引法/本文/第33条.md|第三十三条]]第一項、[[laws/金融商品取引法/本文/第33条の2.md|第三十三条の二]]、[[laws/金融商品取引法/本文/第41条の3.md|第四十一条の三]]から[[laws/金融商品取引法/本文/第41条の5.md|第四十一条の五]]まで、[[laws/金融商品取引法/本文/第42条の5.md|第四十二条の五]]、[[laws/金融商品取引法/本文/第42条の6.md|第四十二条の六]]又は[[laws/金融商品取引法/本文/第66条の13.md|第六十六条の十三]]の規定に違反したとき。
- 五 [[laws/金融商品取引法/本文/第35条.md|第三十五条]]第四項の規定による承認を受けないで金融商品取引業並びに同条第一項に規定する業務及び同条第二項各号に掲げる業務以外の業務を行つたとき。
- 六 [[laws/金融商品取引法/本文/第52条.md|第五十二条]]第一項（[[laws/金融商品取引法/本文/第30条.md|第三十条]]第一項の認可に係るものに限る。）又は[[laws/金融商品取引法/本文/第52条の2.md|第五十二条の二]]第一項の規定による業務の停止の処分に違反したとき。
- 七 [[laws/金融商品取引法/本文/第64条.md|第六十四条]]第二項（[[laws/金融商品取引法/本文/第66条の25.md|第六十六条の二十五]]において準用する場合を含む。）の規定に違反して、外務員の職務を行わせたとき。
- 八 [[laws/金融商品取引法/本文/第67条の7.md|第六十七条の七]]、[[laws/金融商品取引法/本文/第97条.md|第九十七条]]又は[[laws/金融商品取引法/本文/第102条の21.md|第百二条の二十一]]の規定に違反したとき。
- 九 [[laws/金融商品取引法/本文/第85条.md|第八十五条]]第一項の規定に違反して内閣総理大臣の認可を受けないで同項に規定する自主規制法人に[[laws/金融商品取引法/本文/第84条.md|第八十四条]]第二項に規定する自主規制業務の委託を行つたとき。
- 十 [[laws/金融商品取引法/本文/第106条の7.md|第百六条の七]]第四項において準用する同条第一項又は[[laws/金融商品取引法/本文/第106条の21.md|第百六条の二十一]]第四項において準用する同条第一項の規定による命令に違反したとき。
- 十一 [[laws/金融商品取引法/本文/第106条の28.md|第百六条の二十八]]第一項（[[laws/金融商品取引法/本文/第109条.md|第百九条]]において準用する場合を含む。）の規定による命令に違反したとき。
- 十二 [[laws/金融商品取引法/本文/第156条の27.md|第百五十六条の二十七]]第三項の規定による承認を受けないで[[laws/金融商品取引法/本文/第156条の24.md|第百五十六条の二十四]]第一項及び[[laws/金融商品取引法/本文/第156条の27.md|第百五十六条の二十七]]第一項各号に規定する業務以外の業務を行つたとき。
- 十三 [[laws/金融商品取引法/本文/第156条の28.md|第百五十六条の二十八]]第一項の規定による認可を受けないで、同項の規定により内閣総理大臣の認可を受けてできることとされる行為をしたとき。
