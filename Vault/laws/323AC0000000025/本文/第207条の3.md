# 第二百七条の三 

## 
認可金融商品取引業協会、金融商品取引所、[[laws/323AC0000000025/本文/第85条.md|第八十五条]]第一項に規定する自主規制法人又は金融商品取引所持株会社の役員（仮理事及び仮監事並びに仮取締役、仮会計参与、仮監査役及び仮執行役を含む。）は、次の場合においては、百万円以下の過料に処する。[[laws/323AC0000000025/本文/第73条.md|第七十三条]]又は[[laws/323AC0000000025/本文/第153条.md|第百五十三条]]（[[laws/323AC0000000025/本文/第153条の4.md|第百五十三条の四]]において準用する場合を含む。）の規定による命令に違反したとき。[[laws/323AC0000000025/本文/第101条の8.md|第百一条の八]]に規定する資本準備金の額を計上しなかつたとき。[[laws/323AC0000000025/本文/第101条の10.md|第百一条の十]]第一項又は第四項の規定による通知をしなかつたとき。[[laws/323AC0000000025/本文/第101条の20.md|第百一条の二十]]第一項の規定による登記をすることを怠つたとき。[[laws/323AC0000000025/本文/第102条の31.md|第百二条の三十一]]第一項又は[[laws/323AC0000000025/本文/第105条の16.md|第百五条の十六]]第一項の規定に違反して、議事録を備え置かなかつたとき。[[laws/323AC0000000025/本文/第105条の5.md|第百五条の五]]第一項の規定に違反して、自主規制委員の過半数を社外取締役から選定しなかつたとき。[[laws/323AC0000000025/本文/第105条の18.md|第百五条の十八]]の規定による名簿を公衆の縦覧に供することを怠つたとき。

- 一 [[laws/323AC0000000025/本文/第73条.md|第七十三条]]又は[[laws/323AC0000000025/本文/第153条.md|第百五十三条]]（[[laws/323AC0000000025/本文/第153条の4.md|第百五十三条の四]]において準用する場合を含む。）の規定による命令に違反したとき。
- 二 [[laws/323AC0000000025/本文/第101条の8.md|第百一条の八]]に規定する資本準備金の額を計上しなかつたとき。
- 三 [[laws/323AC0000000025/本文/第101条の10.md|第百一条の十]]第一項又は第四項の規定による通知をしなかつたとき。
- 四 [[laws/323AC0000000025/本文/第101条の20.md|第百一条の二十]]第一項の規定による登記をすることを怠つたとき。
- 五 [[laws/323AC0000000025/本文/第102条の31.md|第百二条の三十一]]第一項又は[[laws/323AC0000000025/本文/第105条の16.md|第百五条の十六]]第一項の規定に違反して、議事録を備え置かなかつたとき。
- 六 [[laws/323AC0000000025/本文/第105条の5.md|第百五条の五]]第一項の規定に違反して、自主規制委員の過半数を社外取締役から選定しなかつたとき。
- 七 [[laws/323AC0000000025/本文/第105条の18.md|第百五条の十八]]の規定による名簿を公衆の縦覧に供することを怠つたとき。
