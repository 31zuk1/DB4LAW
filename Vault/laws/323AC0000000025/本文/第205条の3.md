# 第二百五条の三 

## 
次の各号のいずれかに該当する者は、二十万円以下の罰金に処する。[[laws/金融商品取引法/本文/第177条.md|第百七十七条]]第一項第一号の規定による事件関係人又は参考人に対する処分に違反して、出頭せず、陳述をせず、若しくは虚偽の陳述をし、又は報告をせず、若しくは虚偽の報告をした者[[laws/金融商品取引法/本文/第177条.md|第百七十七条]]第一項第二号の規定による事件関係人に対する処分に違反して物件を提出しない者[[laws/金融商品取引法/本文/第185条.md|第百八十五条]]第一項の規定による参考人に対する処分に違反して出頭せず、陳述をせず、又は虚偽の陳述をした者[[laws/金融商品取引法/本文/第185条.md|第百八十五条]]第二項又は[[laws/金融商品取引法/本文/第185条の4.md|第百八十五条の四]]第三項において準用する民事訴訟法[[laws/民事訴訟法/本文/第201条.md|第二百一条]]第一項の規定による参考人又は鑑定人に対する命令に違反して宣誓をしない者[[laws/民事訴訟法/本文/第185条の3.md|第百八十五条の三]]第二項の規定による物件の所持人に対する処分に違反して物件を提出しない者[[laws/民事訴訟法/本文/第185条の4.md|第百八十五条の四]]第一項の規定による鑑定人に対する処分に違反して鑑定をせず、又は虚偽の鑑定をした者

- 一 [[laws/金融商品取引法/本文/第177条.md|第百七十七条]]第一項第一号の規定による事件関係人又は参考人に対する処分に違反して、出頭せず、陳述をせず、若しくは虚偽の陳述をし、又は報告をせず、若しくは虚偽の報告をした者
- 二 [[laws/金融商品取引法/本文/第177条.md|第百七十七条]]第一項第二号の規定による事件関係人に対する処分に違反して物件を提出しない者
- 三 [[laws/金融商品取引法/本文/第185条.md|第百八十五条]]第一項の規定による参考人に対する処分に違反して出頭せず、陳述をせず、又は虚偽の陳述をした者
- 四 [[laws/金融商品取引法/本文/第185条.md|第百八十五条]]第二項又は[[laws/金融商品取引法/本文/第185条の4.md|第百八十五条の四]]第三項において準用する民事訴訟法[[laws/民事訴訟法/本文/第201条.md|第二百一条]]第一項の規定による参考人又は鑑定人に対する命令に違反して宣誓をしない者
- 五 [[laws/金融商品取引法/本文/第185条の3.md|第百八十五条の三]]第二項の規定による物件の所持人に対する処分に違反して物件を提出しない者
- 六 [[laws/金融商品取引法/本文/第185条の4.md|第百八十五条の四]]第一項の規定による鑑定人に対する処分に違反して鑑定をせず、又は虚偽の鑑定をした者
