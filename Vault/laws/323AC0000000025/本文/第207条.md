# 第二百七条 

## 
法人（法人でない団体で代表者又は管理人の定めのあるものを含む。以下この項及び次項において同じ。）の代表者又は法人若しくは人の代理人、使用人その他の従業者が、その法人又は人の業務又は財産に関し、次の各号に掲げる規定の違反行為をしたときは、その行為者を罰するほか、その法人に対して当該各号に定める罰金刑を、その人に対して各本条の罰金刑を科する。[[laws/323AC0000000025/本文/第197条.md|第百九十七条]]七億円以下の罰金刑[[laws/323AC0000000025/本文/第197条の2.md|第百九十七条の二]]（第十一号及び第十二号を除く。）又は[[laws/323AC0000000025/金融商品取引法_law.md|第百九十七条の三五]]億円以下の罰金刑[[laws/323AC0000000025/本文/第198条.md|第百九十八条]]第一項（第五号を除く。）又は[[laws/323AC0000000025/本文/第198条の3.md|第百九十八条の三]]から[[laws/323AC0000000025/本文/第198条の5.md|第百九十八条の五]]まで三億円以下の罰金刑[[laws/323AC0000000025/本文/第198条の6.md|第百九十八条の六]]（第八号、第九号、第十二号、第十三号及び第十五号を除く。）又は[[laws/323AC0000000025/本文/第199条.md|第百九十九条]]二億円以下の罰金刑[[laws/323AC0000000025/本文/第200条.md|第二百条]]（第十二号の三、第十五号の二、第十七号、第十八号の二及び第十九号を除く。）又は[[laws/323AC0000000025/本文/第201条.md|第二百一条]]第一号、第二号、第四号、第六号若しくは第九号から第十一号まで一億円以下の罰金刑[[laws/323AC0000000025/本文/第198条.md|第百九十八条]]第一項第五号、[[laws/323AC0000000025/本文/第198条の6.md|第百九十八条の六]]第八号、第九号、第十二号、第十三号若しくは第十五号、[[laws/323AC0000000025/本文/第200条.md|第二百条]]第十二号の三、第十五号の二、第十七号、第十八号の二若しくは第十九号、[[laws/323AC0000000025/本文/第201条.md|第二百一条]]（第一号、第二号、第四号、第六号及び第九号から第十一号までを除く。）、[[laws/323AC0000000025/本文/第205条.md|第二百五条]]から[[laws/323AC0000000025/本文/第205条の2.md|第二百五条の二]]の二まで、[[laws/323AC0000000025/本文/第205条の2.md|第二百五条の二]]の三第一項又は前条第一項各本条の罰金刑

- 一 [[laws/323AC0000000025/本文/第197条.md|第百九十七条]]七億円以下の罰金刑
- 二 [[laws/323AC0000000025/本文/第197条の2.md|第百九十七条の二]]（第十一号及び第十二号を除く。）又は[[laws/323AC0000000025/金融商品取引法_law.md|第百九十七条の三五]]億円以下の罰金刑
- 三 [[laws/323AC0000000025/本文/第198条.md|第百九十八条]]第一項（第五号を除く。）又は[[laws/323AC0000000025/本文/第198条の3.md|第百九十八条の三]]から[[laws/323AC0000000025/本文/第198条の5.md|第百九十八条の五]]まで三億円以下の罰金刑
- 四 [[laws/323AC0000000025/本文/第198条の6.md|第百九十八条の六]]（第八号、第九号、第十二号、第十三号及び第十五号を除く。）又は[[laws/323AC0000000025/本文/第199条.md|第百九十九条]]二億円以下の罰金刑
- 五 [[laws/323AC0000000025/本文/第200条.md|第二百条]]（第十二号の三、第十五号の二、第十七号、第十八号の二及び第十九号を除く。）又は[[laws/323AC0000000025/本文/第201条.md|第二百一条]]第一号、第二号、第四号、第六号若しくは第九号から第十一号まで一億円以下の罰金刑
- 六 [[laws/323AC0000000025/本文/第198条.md|第百九十八条]]第一項第五号、[[laws/323AC0000000025/本文/第198条の6.md|第百九十八条の六]]第八号、第九号、第十二号、第十三号若しくは第十五号、[[laws/323AC0000000025/本文/第200条.md|第二百条]]第十二号の三、第十五号の二、第十七号、第十八号の二若しくは第十九号、[[laws/323AC0000000025/本文/第201条.md|第二百一条]]（第一号、第二号、第四号、第六号及び第九号から第十一号までを除く。）、[[laws/323AC0000000025/本文/第205条.md|第二百五条]]から[[laws/323AC0000000025/本文/第205条の2.md|第二百五条の二]]の二まで、[[laws/323AC0000000025/本文/第205条の2.md|第二百五条の二]]の三第一項又は前条第一項各本条の罰金刑
## ２
前項の規定により[[laws/323AC0000000025/本文/第197条.md|第百九十七条]]、[[laws/323AC0000000025/本文/第197条の2.md|第百九十七条の二]]（第十一号及び第十二号を除く。）又は[[laws/323AC0000000025/本文/第197条の3.md|第百九十七条の三]]の違反行為につき法人又は人に罰金刑を科する場合における時効の期間は、これらの規定の罪についての時効の期間による。

## ３
第一項の規定により法人でない団体を処罰する場合には、その代表者又は管理人がその訴訟行為につきその団体を代表するほか、法人を被告人又は被疑者とする場合の刑事訴訟に関する法律の規定を準用する。
