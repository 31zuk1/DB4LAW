# 第二百九条 

## 
次の各号のいずれかに該当する者は、十万円以下の過料に処する。[[laws/金融商品取引法/本文/第23条の13.md|第二十三条の十三]]第一項、第三項又は第四項（これらの規定を[[laws/金融商品取引法/本文/第27条.md|第二十七条]]において準用する場合を含む。）の規定に違反した者[[laws/金融商品取引法/本文/第23条の13.md|第二十三条の十三]]第二項又は第五項（これらの規定を[[laws/金融商品取引法/本文/第27条.md|第二十七条]]において準用する場合を含む。）の規定に違反して、書面の交付をしなかつた者[[laws/金融商品取引法/本文/第24条の4.md|第二十四条の四]]の二第五項（[[laws/金融商品取引法/本文/第24条の5.md|第二十四条の五]]の二第一項において準用し、及びこれらの規定を[[laws/金融商品取引法/本文/第27条.md|第二十七条]]において準用する場合を含む。）において準用する[[laws/金融商品取引法/本文/第6条.md|第六条]]の規定による確認書の写し又は[[laws/金融商品取引法/本文/第24条の4.md|第二十四条の四]]の三第二項（[[laws/金融商品取引法/本文/第24条の5.md|第二十四条の五]]の二第二項において準用し、及びこれらの規定を[[laws/金融商品取引法/本文/第27条.md|第二十七条]]において準用する場合を含む。）において準用する[[laws/金融商品取引法/本文/第6条.md|第六条]]の規定による訂正確認書の写しを提出しなかつた者[[laws/金融商品取引法/本文/第24条の5.md|第二十四条の五]]の二第一項（[[laws/金融商品取引法/本文/第27条.md|第二十七条]]において準用する場合を含む。）において準用する[[laws/金融商品取引法/本文/第24条の4.md|第二十四条の四]]の二第一項（同条第三項（同条第四項において準用する場合を含む。）及び第四項において準用し、並びにこれらの規定を[[laws/金融商品取引法/本文/第27条.md|第二十七条]]において準用する場合を含む。）の規定による確認書又は[[laws/金融商品取引法/本文/第24条の5.md|第二十四条の五]]の二第二項（[[laws/金融商品取引法/本文/第27条.md|第二十七条]]において準用する場合を含む。）において準用する[[laws/金融商品取引法/本文/第24条の4.md|第二十四条の四]]の三第一項（[[laws/金融商品取引法/本文/第27条.md|第二十七条]]において準用する場合を含む。）において読み替えて準用する[[laws/金融商品取引法/本文/第9条.md|第九条]]第一項若しくは[[laws/金融商品取引法/本文/第10条.md|第十条]]第一項の規定による訂正確認書を提出しなかつた者[[laws/金融商品取引法/本文/第25条.md|第二十五条]]第二項（[[laws/金融商品取引法/本文/第27条.md|第二十七条]]において準用する場合を含む。）の規定に違反して書類（[[laws/金融商品取引法/本文/第25条.md|第二十五条]]第一項第四号及び第七号に掲げる書類に限る。）の写しを公衆の縦覧に供しない者[[laws/金融商品取引法/本文/第27条の24.md|第二十七条の二十四]]の規定に違反して、通知書を交付せず、又は同条に規定する事項を記載しない通知書若しくは虚偽の記載をした通知書を交付した者[[laws/金融商品取引法/本文/第40条の5.md|第四十条の五]]第一項の規定に違反した者[[laws/金融商品取引法/本文/第60条の4.md|第六十条の四]]第二項（[[laws/金融商品取引法/本文/第60条の14.md|第六十条の十四]]第二項において準用する場合を含む。）、[[laws/金融商品取引法/本文/第65条.md|第六十五条]]第二項、[[laws/金融商品取引法/本文/第66条の46.md|第六十六条の四十六]]第二項又は[[laws/金融商品取引法/本文/第66条の90.md|第六十六条の九十]]第二項の規定による命令に違反した者[[laws/金融商品取引法/本文/第62条.md|第六十二条]]第一項若しくは第三項又は[[laws/金融商品取引法/本文/第79条の10.md|第七十九条の十]]第一項の規定による届出をせず、又は虚偽の届出をした者[[laws/金融商品取引法/本文/第62条.md|第六十二条]]第二項又は[[laws/金融商品取引法/本文/第189条.md|第百八十九条]]第一項の規定による報告若しくは資料の提出をせず、又は虚偽の報告若しくは資料の提出をした者[[laws/金融商品取引法/本文/第79条の15.md|第七十九条の十五]]、[[laws/金融商品取引法/本文/第156条の54.md|第百五十六条の五十四]]又は[[laws/金融商品取引法/本文/第156条の76.md|第百五十六条の七十六]]の規定に違反した者

- 一 [[laws/金融商品取引法/本文/第23条の13.md|第二十三条の十三]]第一項、第三項又は第四項（これらの規定を[[laws/金融商品取引法/本文/第27条.md|第二十七条]]において準用する場合を含む。）の規定に違反した者
- 二 [[laws/金融商品取引法/本文/第23条の13.md|第二十三条の十三]]第二項又は第五項（これらの規定を[[laws/金融商品取引法/本文/第27条.md|第二十七条]]において準用する場合を含む。）の規定に違反して、書面の交付をしなかつた者
- 三 [[laws/金融商品取引法/本文/第24条の4.md|第二十四条の四]]の二第五項（[[laws/金融商品取引法/本文/第24条の5.md|第二十四条の五]]の二第一項において準用し、及びこれらの規定を[[laws/金融商品取引法/本文/第27条.md|第二十七条]]において準用する場合を含む。）において準用する[[laws/金融商品取引法/本文/第6条.md|第六条]]の規定による確認書の写し又は[[laws/金融商品取引法/本文/第24条の4.md|第二十四条の四]]の三第二項（[[laws/金融商品取引法/本文/第24条の5.md|第二十四条の五]]の二第二項において準用し、及びこれらの規定を[[laws/金融商品取引法/本文/第27条.md|第二十七条]]において準用する場合を含む。）において準用する[[laws/金融商品取引法/本文/第6条.md|第六条]]の規定による訂正確認書の写しを提出しなかつた者
- 四 [[laws/金融商品取引法/本文/第24条の5.md|第二十四条の五]]の二第一項（[[laws/金融商品取引法/本文/第27条.md|第二十七条]]において準用する場合を含む。）において準用する[[laws/金融商品取引法/本文/第24条の4.md|第二十四条の四]]の二第一項（同条第三項（同条第四項において準用する場合を含む。）及び第四項において準用し、並びにこれらの規定を[[laws/金融商品取引法/本文/第27条.md|第二十七条]]において準用する場合を含む。）の規定による確認書又は[[laws/金融商品取引法/本文/第24条の5.md|第二十四条の五]]の二第二項（[[laws/金融商品取引法/本文/第27条.md|第二十七条]]において準用する場合を含む。）において準用する[[laws/金融商品取引法/本文/第24条の4.md|第二十四条の四]]の三第一項（[[laws/金融商品取引法/本文/第27条.md|第二十七条]]において準用する場合を含む。）において読み替えて準用する[[laws/金融商品取引法/本文/第9条.md|第九条]]第一項若しくは[[laws/金融商品取引法/本文/第10条.md|第十条]]第一項の規定による訂正確認書を提出しなかつた者
- 五 [[laws/金融商品取引法/本文/第25条.md|第二十五条]]第二項（[[laws/金融商品取引法/本文/第27条.md|第二十七条]]において準用する場合を含む。）の規定に違反して書類（[[laws/金融商品取引法/本文/第25条.md|第二十五条]]第一項第四号及び第七号に掲げる書類に限る。）の写しを公衆の縦覧に供しない者
- 六 [[laws/金融商品取引法/本文/第27条の24.md|第二十七条の二十四]]の規定に違反して、通知書を交付せず、又は同条に規定する事項を記載しない通知書若しくは虚偽の記載をした通知書を交付した者
- 六の二 [[laws/金融商品取引法/本文/第40条の5.md|第四十条の五]]第一項の規定に違反した者
- 七 [[laws/金融商品取引法/本文/第60条の4.md|第六十条の四]]第二項（[[laws/金融商品取引法/本文/第60条の14.md|第六十条の十四]]第二項において準用する場合を含む。）、[[laws/金融商品取引法/本文/第65条.md|第六十五条]]第二項、[[laws/金融商品取引法/本文/第66条の46.md|第六十六条の四十六]]第二項又は[[laws/金融商品取引法/本文/第66条の90.md|第六十六条の九十]]第二項の規定による命令に違反した者
- 八 [[laws/金融商品取引法/本文/第62条.md|第六十二条]]第一項若しくは第三項又は[[laws/金融商品取引法/本文/第79条の10.md|第七十九条の十]]第一項の規定による届出をせず、又は虚偽の届出をした者
- 九 [[laws/金融商品取引法/本文/第62条.md|第六十二条]]第二項又は[[laws/金融商品取引法/本文/第189条.md|第百八十九条]]第一項の規定による報告若しくは資料の提出をせず、又は虚偽の報告若しくは資料の提出をした者
- 十 [[laws/金融商品取引法/本文/第79条の15.md|第七十九条の十五]]、[[laws/金融商品取引法/本文/第156条の54.md|第百五十六条の五十四]]又は[[laws/金融商品取引法/本文/第156条の76.md|第百五十六条の七十六]]の規定に違反した者
