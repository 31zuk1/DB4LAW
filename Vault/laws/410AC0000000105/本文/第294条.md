# 第二百九十四条 

## 
次の各号に掲げる違反があった場合においては、その違反行為をした者は、三年以下の拘禁刑若しくは三百万円以下の罰金に処し、又はこれを併科する。[[laws/資産の流動化に関する法律/本文/第4条.md|第四条]]第一項又は[[laws/資産の流動化に関する法律/本文/第11条.md|第十一条]]第一項の規定に違反して届出をしないで資産の流動化に係る業務を行ったとき。[[laws/資産の流動化に関する法律/本文/第7条.md|第七条]]第二項（[[laws/資産の流動化に関する法律/本文/第11条.md|第十一条]]第五項において準用する場合を含む。以下この号において同じ。）に違反して[[laws/資産の流動化に関する法律/本文/第7条.md|第七条]]第二項に規定する資料（これらの資料が電磁的記録で作成されている場合における内閣府令で定める電磁的記録又は当該電磁的記録に記録された事項を記載した書面を含む。）を提出しないで資産対応証券を発行したとき。[[laws/資産の流動化に関する法律/本文/第9条.md|第九条]]第一項の規定に違反して届出をしなかったとき。[[laws/資産の流動化に関する法律/本文/第195条.md|第百九十五条]]第一項の規定に違反したとき。[[laws/資産の流動化に関する法律/本文/第196条.md|第百九十六条]]の規定に違反したとき。[[laws/資産の流動化に関する法律/本文/第203条.md|第二百三条]]の規定に違反して同条に規定する者に同条に規定する業務を委託せず、当該業務を行ったとき。[[laws/資産の流動化に関する法律/本文/第207条.md|第二百七条]]の規定に違反して募集等に係る事務を行ったとき。[[laws/資産の流動化に関する法律/本文/第208条.md|第二百八条]]第二項（[[laws/資産の流動化に関する法律/本文/第286条.md|第二百八十六条]]第一項において準用する場合を含む。）の規定に違反して届出をしないで募集等の取扱いを行ったとき。[[laws/資産の流動化に関する法律/本文/第209条.md|第二百九条]]第一項（[[laws/資産の流動化に関する法律/本文/第286条.md|第二百八十六条]]第一項において準用する場合を含む。）において準用する金融商品取引法第三十九条第一項の規定に違反したとき。[[laws/資産の流動化に関する法律/本文/第225条.md|第二百二十五条]]第一項の規定に違反して届出をしないで特定目的信託契約を締結したとき、又は虚偽の届出をしたとき。[[laws/資産の流動化に関する法律/本文/第227条.md|第二百二十七条]]第一項の規定に違反して届出をしなかったとき。[[laws/資産の流動化に関する法律/本文/第4条.md|第四条]]第二項（[[laws/資産の流動化に関する法律/本文/第11条.md|第十一条]]第五項において準用する場合を含む。）の届出書若しくは[[laws/資産の流動化に関する法律/本文/第4条.md|第四条]]第三項各号（[[laws/資産の流動化に関する法律/本文/第11条.md|第十一条]]第五項において準用する場合を含む。）に掲げる資料若しくは[[laws/資産の流動化に関する法律/本文/第4条.md|第四条]]第四項（[[laws/資産の流動化に関する法律/本文/第11条.md|第十一条]]第五項において準用する場合を含む。）に掲げる電磁的記録、[[laws/資産の流動化に関する法律/本文/第7条.md|第七条]]第二項（[[laws/資産の流動化に関する法律/本文/第11条.md|第十一条]]第五項において準用する場合を含む。）に規定する資料、[[laws/資産の流動化に関する法律/本文/第9条.md|第九条]]第二項（[[laws/資産の流動化に関する法律/本文/第227条.md|第二百二十七条]]第二項において準用する場合を含む。）の届出書若しくは[[laws/資産の流動化に関する法律/本文/第9条.md|第九条]]第三項各号（[[laws/資産の流動化に関する法律/本文/第227条.md|第二百二十七条]]第二項において準用する場合を含む。）に掲げる書類、[[laws/資産の流動化に関する法律/本文/第11条.md|第十一条]]第三項の書類又は[[laws/資産の流動化に関する法律/本文/第225条.md|第二百二十五条]]第二項各号に掲げる書類に虚偽の記載又は記録をして提出したとき。

- 一 [[laws/資産の流動化に関する法律/本文/第4条.md|第四条]]第一項又は[[laws/資産の流動化に関する法律/本文/第11条.md|第十一条]]第一項の規定に違反して届出をしないで資産の流動化に係る業務を行ったとき。
- 二 [[laws/資産の流動化に関する法律/本文/第7条.md|第七条]]第二項（[[laws/資産の流動化に関する法律/本文/第11条.md|第十一条]]第五項において準用する場合を含む。以下この号において同じ。）に違反して[[laws/資産の流動化に関する法律/本文/第7条.md|第七条]]第二項に規定する資料（これらの資料が電磁的記録で作成されている場合における内閣府令で定める電磁的記録又は当該電磁的記録に記録された事項を記載した書面を含む。）を提出しないで資産対応証券を発行したとき。

- 五 [[laws/資産の流動化に関する法律/本文/第196条.md|第百九十六条]]の規定に違反したとき。
- 六 [[laws/資産の流動化に関する法律/本文/第203条.md|第二百三条]]の規定に違反して同条に規定する者に同条に規定する業務を委託せず、当該業務を行ったとき。
- 七 [[laws/資産の流動化に関する法律/本文/第207条.md|第二百七条]]の規定に違反して募集等に係る事務を行ったとき。
- 八 [[laws/資産の流動化に関する法律/本文/第208条.md|第二百八条]]第二項（[[laws/資産の流動化に関する法律/本文/第286条.md|第二百八十六条]]第一項において準用する場合を含む。）の規定に違反して届出をしないで募集等の取扱いを行ったとき。
- 九 [[laws/資産の流動化に関する法律/本文/第209条.md|第二百九条]]第一項（[[laws/資産の流動化に関する法律/本文/第286条.md|第二百八十六条]]第一項において準用する場合を含む。）において準用する金融商品取引法第三十九条第一項の規定に違反したとき。
- 十 [[laws/資産の流動化に関する法律/本文/第225条.md|第二百二十五条]]第一項の規定に違反して届出をしないで特定目的信託契約を締結したとき、又は虚偽の届出をしたとき。
- 十一 [[laws/資産の流動化に関する法律/本文/第227条.md|第二百二十七条]]第一項の規定に違反して届出をしなかったとき。
- 十二 [[laws/資産の流動化に関する法律/本文/第4条.md|第四条]]第二項（[[laws/資産の流動化に関する法律/本文/第11条.md|第十一条]]第五項において準用する場合を含む。）の届出書若しくは[[laws/資産の流動化に関する法律/本文/第4条.md|第四条]]第三項各号（[[laws/資産の流動化に関する法律/本文/第11条.md|第十一条]]第五項において準用する場合を含む。）に掲げる資料若しくは[[laws/資産の流動化に関する法律/本文/第4条.md|第四条]]第四項（[[laws/資産の流動化に関する法律/本文/第11条.md|第十一条]]第五項において準用する場合を含む。）に掲げる電磁的記録、[[laws/資産の流動化に関する法律/本文/第7条.md|第七条]]第二項（[[laws/資産の流動化に関する法律/本文/第11条.md|第十一条]]第五項において準用する場合を含む。）に規定する資料、[[laws/資産の流動化に関する法律/本文/第9条.md|第九条]]第二項（[[laws/資産の流動化に関する法律/本文/第227条.md|第二百二十七条]]第二項において準用する場合を含む。）の届出書若しくは[[laws/資産の流動化に関する法律/本文/第9条.md|第九条]]第三項各号（[[laws/資産の流動化に関する法律/本文/第227条.md|第二百二十七条]]第二項において準用する場合を含む。）に掲げる書類、[[laws/資産の流動化に関する法律/本文/第11条.md|第十一条]]第三項の書類又は[[laws/資産の流動化に関する法律/本文/第225条.md|第二百二十五条]]第二項各号に掲げる書類に虚偽の記載又は記録をして提出したとき。
