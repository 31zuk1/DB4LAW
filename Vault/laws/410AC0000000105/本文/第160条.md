# 第百六十条 （解散の事由）

## 
特定目的会社は、次に掲げる事由によって解散する。定款で定めた存続期間の満了定款で定めた解散の事由の発生社員総会の決議破産手続開始の決定[[laws/410AC0000000105/本文/第162条.md|第百六十二条]]第一項又は[[laws/410AC0000000105/本文/第163条.md|第百六十三条]]において準用する会社法[[laws/417AC0000000086/本文/第824条.md|第八百二十四条]]第一項の規定による解散を命ずる裁判[[laws/417AC0000000086/本文/第220条.md|第二百二十条]]の規定による内閣総理大臣の発する解散命令資産流動化計画に記載し、又は記録する特定資産（従たる特定資産を除く。）の譲受け、資産対応証券の発行又は特定借入れの実行の不能その他政令で定める事由の発生

- 一 定款で定めた存続期間の満了
- 二 定款で定めた解散の事由の発生
- 三 社員総会の決議
- 四 破産手続開始の決定
- 五 [[laws/410AC0000000105/本文/第162条.md|第百六十二条]]第一項又は[[laws/410AC0000000105/本文/第163条.md|第百六十三条]]において準用する会社法[[laws/417AC0000000086/本文/第824条.md|第八百二十四条]]第一項の規定による解散を命ずる裁判
- 六 [[laws/410AC0000000105/本文/第220条.md|第二百二十条]]の規定による内閣総理大臣の発する解散命令
- 七 資産流動化計画に記載し、又は記録する特定資産（従たる特定資産を除く。）の譲受け、資産対応証券の発行又は特定借入れの実行の不能
- 八 その他政令で定める事由の発生
## ２
会社法[[laws/417AC0000000086/本文/第926条.md|第九百二十六条]]（解散の登記）の規定は、前項（第四号及び第五号を除く。）の規定により特定目的会社が解散した場合について準用する。
