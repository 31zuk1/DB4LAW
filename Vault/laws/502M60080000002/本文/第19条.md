# 第十九条 （マネジメントレビューに用いる情報）

## 
原子力事業者等は、マネジメントレビューにおいて、少なくとも次に掲げる情報を報告しなければならない。内部監査の結果組織の外部の者の意見プロセスの運用状況使用前事業者検査、定期事業者検査及び使用前検査（以下「使用前事業者検査等」という。）並びに自主検査等の結果品質目標の達成状況健全な安全文化の育成及び維持の状況関係法令の遵守状況不適合並びに是正処置及び未然防止処置の状況従前のマネジメントレビューの結果を受けて講じた措置品質マネジメントシステムに影響を及ぼすおそれのある変更部門又は要員からの改善のための提案資源の妥当性保安活動の改善のために講じた措置の実効性

- 一 内部監査の結果
- 二 組織の外部の者の意見
- 三 プロセスの運用状況
- 四 使用前事業者検査、定期事業者検査及び使用前検査（以下「使用前事業者検査等」という。）並びに自主検査等の結果
- 五 品質目標の達成状況
- 六 健全な安全文化の育成及び維持の状況
- 七 関係法令の遵守状況
- 八 不適合並びに是正処置及び未然防止処置の状況
- 九 従前のマネジメントレビューの結果を受けて講じた措置
- 十 品質マネジメントシステムに影響を及ぼすおそれのある変更
- 十一 部門又は要員からの改善のための提案
- 十二 資源の妥当性
- 十三 保安活動の改善のために講じた措置の実効性
