# 第八十八条 

## 
次の各号のいずれかに該当する場合においては、宗教法人の代表役員、その代務者、仮代表役員又は清算人は、十万円以下の過料に処する。所轄庁に対し虚偽の記載をした書類を添付してこの法律の規定による認証（[[laws/326AC0000000126/本文/第12条.md|第十二条]]第一項の規定による認証を除く。）の申請をしたとき。[[laws/326AC0000000126/本文/第9条.md|第九条]]又は[[laws/326AC0000000126/本文/第43条.md|第四十三条]]第三項の規定による届出を怠り、又は虚偽の届出をしたとき。[[laws/326AC0000000126/本文/第23条.md|第二十三条]]の規定に違反して同条の規定による公告をしないで同条各号に掲げる行為をしたとき。[[laws/326AC0000000126/本文/第25条.md|第二十五条]]第一項若しくは第二項の規定に違反してこれらの規定に規定する書類若しくは帳簿の作成若しくは備付けを怠り、又は同条第二項各号に掲げる書類若しくは帳簿に虚偽の記載をしたとき。[[laws/326AC0000000126/本文/第25条.md|第二十五条]]第四項の規定による書類の写しの提出を怠つたとき。[[laws/326AC0000000126/本文/第48条.md|第四十八条]]第二項又は[[laws/326AC0000000126/本文/第49条の5.md|第四十九条の五]]第一項の規定による破産手続開始の申立てを怠つたとき。[[laws/326AC0000000126/本文/第49条の3.md|第四十九条の三]]第一項又は[[laws/326AC0000000126/本文/第49条の5.md|第四十九条の五]]第一項の規定による公告を怠り、又は不正の公告をしたとき。[[laws/326AC0000000126/本文/第51条.md|第五十一条]]第二項の規定による裁判所の検査を妨げたとき。第七章第一節の規定による登記をすることを怠つたとき。[[laws/326AC0000000126/本文/第78条の2.md|第七十八条の二]]第一項の規定による報告をせず、若しくは虚偽の報告をし、又は同項の規定による当該職員の質問に対して答弁をせず、若しくは虚偽の答弁をしたとき。[[laws/326AC0000000126/本文/第79条.md|第七十九条]]第一項の規定による事業の停止の命令に違反して事業を行つたとき。

- 一 所轄庁に対し虚偽の記載をした書類を添付してこの法律の規定による認証（[[laws/326AC0000000126/本文/第12条.md|第十二条]]第一項の規定による認証を除く。）の申請をしたとき。
- 二 [[laws/326AC0000000126/本文/第9条.md|第九条]]又は[[laws/326AC0000000126/本文/第43条.md|第四十三条]]第三項の規定による届出を怠り、又は虚偽の届出をしたとき。
- 三 [[laws/326AC0000000126/本文/第23条.md|第二十三条]]の規定に違反して同条の規定による公告をしないで同条各号に掲げる行為をしたとき。
- 四 [[laws/326AC0000000126/本文/第25条.md|第二十五条]]第一項若しくは第二項の規定に違反してこれらの規定に規定する書類若しくは帳簿の作成若しくは備付けを怠り、又は同条第二項各号に掲げる書類若しくは帳簿に虚偽の記載をしたとき。
- 五 [[laws/326AC0000000126/本文/第25条.md|第二十五条]]第四項の規定による書類の写しの提出を怠つたとき。
- 六 [[laws/326AC0000000126/本文/第48条.md|第四十八条]]第二項又は[[laws/326AC0000000126/本文/第49条の5.md|第四十九条の五]]第一項の規定による破産手続開始の申立てを怠つたとき。
- 七 [[laws/326AC0000000126/本文/第49条の3.md|第四十九条の三]]第一項又は[[laws/326AC0000000126/本文/第49条の5.md|第四十九条の五]]第一項の規定による公告を怠り、又は不正の公告をしたとき。
- 八 [[laws/326AC0000000126/本文/第51条.md|第五十一条]]第二項の規定による裁判所の検査を妨げたとき。
- 九 第七章第一節の規定による登記をすることを怠つたとき。
- 十 [[laws/326AC0000000126/本文/第78条の2.md|第七十八条の二]]第一項の規定による報告をせず、若しくは虚偽の報告をし、又は同項の規定による当該職員の質問に対して答弁をせず、若しくは虚偽の答弁をしたとき。
- 十一 [[laws/326AC0000000126/本文/第79条.md|第七十九条]]第一項の規定による事業の停止の命令に違反して事業を行つたとき。
