# 第四条 （業務方法書の記載事項）

## 
機構に係る通則法[[laws/独立行政法人自動車技術総合機構に関する省令/本文/第28条.md|第二十八条]]第二項の主務省令で定める事項は、次のとおりとする。機構法[[laws/独立行政法人自動車技術総合機構に関する省令/本文/第12条.md|第十二条]]第一号に規定する審査に関する事項機構法[[laws/独立行政法人自動車技術総合機構に関する省令/本文/第12条.md|第十二条]]第二号に規定する技術的な検証に関する事項機構法[[laws/独立行政法人自動車技術総合機構に関する省令/本文/第12条.md|第十二条]]第三号に規定する調査に関する事項機構法[[laws/独立行政法人自動車技術総合機構に関する省令/本文/第12条.md|第十二条]]第四号に規定する試験、調査、研究及び開発に関する事項機構法[[laws/独立行政法人自動車技術総合機構に関する省令/本文/第12条.md|第十二条]]第五号に規定する成果の普及に関する事項機構法[[laws/独立行政法人自動車技術総合機構に関する省令/本文/第12条.md|第十二条]]第六号に規定する附帯する業務に関する事項業務の委託に関する基準競争入札その他の契約に関する事項その他業務の執行に関して必要な事項

- 一 機構法[[laws/独立行政法人自動車技術総合機構に関する省令/本文/第12条.md|第十二条]]第一号に規定する審査に関する事項
- 二 機構法[[laws/独立行政法人自動車技術総合機構に関する省令/本文/第12条.md|第十二条]]第二号に規定する技術的な検証に関する事項
- 三 機構法[[laws/独立行政法人自動車技術総合機構に関する省令/本文/第12条.md|第十二条]]第三号に規定する調査に関する事項
- 四 機構法[[laws/独立行政法人自動車技術総合機構に関する省令/本文/第12条.md|第十二条]]第四号に規定する試験、調査、研究及び開発に関する事項
- 五 機構法[[laws/独立行政法人自動車技術総合機構に関する省令/本文/第12条.md|第十二条]]第五号に規定する成果の普及に関する事項
- 六 機構法[[laws/独立行政法人自動車技術総合機構に関する省令/本文/第12条.md|第十二条]]第六号に規定する附帯する業務に関する事項
- 七 業務の委託に関する基準
- 八 競争入札その他の契約に関する事項
- 九 その他業務の執行に関して必要な事項
