# 第二十八条の三 

## 
[[laws/330AC0000000168/本文/第9条の13.md|第九条の十三]]第二項（[[laws/330AC0000000168/本文/第15条の7.md|第十五条の七]]において準用する場合を含む。）の規定による登録事務又は試験事務の停止の命令に違反したときは、その違反行為をした指定登録機関又は指定試験機関の役員又は職員は、一年以下の拘禁刑又は五十万円以下の罰金に処する。
