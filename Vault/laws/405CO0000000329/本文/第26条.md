# 第二十六条 （指定検定機関の指定の区分）

## 
法[[laws/404AC0000000051/本文/第106条.md|第百六条]]第一項の政令で定める区分は、次のとおりとする。非自動はかり自動捕捉式はかり[[laws/405CO0000000329/本文/第2条.md|第二条]]第三号イ（１）に掲げるガラス製温度計ガラス製体温計抵抗体温計水道メーター及び温水メーター燃料油メーター（[[laws/405CO0000000329/本文/第5条.md|第五条]]第四号に掲げるものを除く。以下同じ。）液化石油ガスメーターガスメーター（[[laws/405CO0000000329/本文/第5条.md|第五条]]第五号に掲げるものを除く。以下同じ。）アネロイド型血圧計積算熱量計最大需要電力計電力量計無効電力量計照度計騒音計振動レベル計ジルコニア式酸素濃度計、溶液導電率式二酸化硫黄濃度計、磁気式酸素濃度計、紫外線式二酸化硫黄濃度計、紫外線式窒素酸化物濃度計、非分散型赤外線式二酸化硫黄濃度計、非分散型赤外線式窒素酸化物濃度計、非分散型赤外線式一酸化炭素濃度計及び化学発光式窒素酸化物濃度計ガラス電極式水素イオン濃度検出器及びガラス電極式水素イオン濃度指示計

- 一 非自動はかり
- 二 自動捕捉式はかり
- 三 [[laws/405CO0000000329/本文/第2条.md|第二条]]第三号イ（１）に掲げるガラス製温度計
- 四 ガラス製体温計
- 五 抵抗体温計
- 六 水道メーター及び温水メーター
- 七 燃料油メーター（[[laws/405CO0000000329/本文/第5条.md|第五条]]第四号に掲げるものを除く。以下同じ。）
- 八 液化石油ガスメーター
- 九 ガスメーター（[[laws/405CO0000000329/本文/第5条.md|第五条]]第五号に掲げるものを除く。以下同じ。）
- 十 アネロイド型血圧計
- 十一 積算熱量計
- 十二 最大需要電力計
- 十三 電力量計
- 十四 無効電力量計
- 十五 照度計
- 十六 騒音計
- 十七 振動レベル計
- 十八 ジルコニア式酸素濃度計、溶液導電率式二酸化硫黄濃度計、磁気式酸素濃度計、紫外線式二酸化硫黄濃度計、紫外線式窒素酸化物濃度計、非分散型赤外線式二酸化硫黄濃度計、非分散型赤外線式窒素酸化物濃度計、非分散型赤外線式一酸化炭素濃度計及び化学発光式窒素酸化物濃度計
- 十九 ガラス電極式水素イオン濃度検出器及びガラス電極式水素イオン濃度指示計
