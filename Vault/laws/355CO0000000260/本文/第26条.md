# 第二十六条 （事務の委任）

## 
財務大臣又は経済産業大臣が法[[laws/外国為替令/本文/第69条.md|第六十九条]]第一項の規定に基づき日本銀行に取り扱わせる法（第一章、第三章、第四章及び第六章の二（[[laws/外国為替令/本文/第55条の2.md|第五十五条の二]]、[[laws/外国為替令/本文/第55条の5.md|第五十五条の五]]及び[[laws/外国為替令/本文/第55条の6.md|第五十五条の六]]を除く。）に限る。第十号において同じ。）の施行に関する事務は、次に掲げる事務のうち財務省令又は経済産業省令で定める事務とする。法[[laws/外国為替令/本文/第23条.md|第二十三条]]第一項の規定に基づく届出の受理に関する事務法[[laws/外国為替令/本文/第23条.md|第二十三条]]第三項の規定に基づく期間の短縮の通知に関する事務法[[laws/外国為替令/本文/第23条.md|第二十三条]]第四項の規定に基づく勧告の内容を記載した文書の送付に関する事務法[[laws/外国為替令/本文/第23条.md|第二十三条]]第六項の規定に基づく応諾に関する通知の受理に関する事務法[[laws/外国為替令/本文/第23条.md|第二十三条]]第九項の規定に基づく命令の内容を記載した文書の送付に関する事務法[[laws/外国為替令/本文/第25条.md|第二十五条]]第五項の規定又は[[laws/外国為替令/本文/第6条.md|第六条]]第二項、[[laws/外国為替令/本文/第11条.md|第十一条]]第三項、[[laws/外国為替令/本文/第15条.md|第十五条]]第二項若しくは[[laws/外国為替令/本文/第18条.md|第十八条]]第四項の規定による許可に関する事務法[[laws/外国為替令/本文/第55条.md|第五十五条]]、[[laws/外国為替令/本文/第55条の3.md|第五十五条の三]]、[[laws/外国為替令/本文/第55条の4.md|第五十五条の四]]、[[laws/外国為替令/本文/第55条の7.md|第五十五条の七]]又は[[laws/外国為替令/本文/第55条の8.md|第五十五条の八]]（この政令の[[laws/外国為替令/本文/第18条の8.md|第十八条の八]]に係る部分に限る。）の規定に基づく報告の受理（前条第五項の規定により財務局長又は福岡財務支局長が行う報告の徴求に係るものを除く。）に関する事務法[[laws/外国為替令/本文/第55条の9.md|第五十五条の九]]の規定に基づく対外の貸借及び国際収支に関する統計の作成に関する事務[[laws/外国為替令/本文/第6条の2.md|第六条の二]]第四項、[[laws/外国為替令/本文/第11条の3.md|第十一条の三]]第二項、[[laws/外国為替令/本文/第16条.md|第十六条]]第二項又は[[laws/外国為替令/本文/第18条の3.md|第十八条の三]]第二項の規定による許可に関する事務前各号に掲げる事務のほか、法及びこの政令の施行のため必要な事務

- 一 法[[laws/外国為替令/本文/第23条.md|第二十三条]]第一項の規定に基づく届出の受理に関する事務
- 二 法[[laws/外国為替令/本文/第23条.md|第二十三条]]第三項の規定に基づく期間の短縮の通知に関する事務
- 三 法[[laws/外国為替令/本文/第23条.md|第二十三条]]第四項の規定に基づく勧告の内容を記載した文書の送付に関する事務
- 四 法[[laws/外国為替令/本文/第23条.md|第二十三条]]第六項の規定に基づく応諾に関する通知の受理に関する事務
- 五 法[[laws/外国為替令/本文/第23条.md|第二十三条]]第九項の規定に基づく命令の内容を記載した文書の送付に関する事務
- 六 法[[laws/外国為替令/本文/第25条.md|第二十五条]]第五項の規定又は[[laws/外国為替令/本文/第6条.md|第六条]]第二項、[[laws/外国為替令/本文/第11条.md|第十一条]]第三項、[[laws/外国為替令/本文/第15条.md|第十五条]]第二項若しくは[[laws/外国為替令/本文/第18条.md|第十八条]]第四項の規定による許可に関する事務
- 七 法[[laws/外国為替令/本文/第55条.md|第五十五条]]、[[laws/外国為替令/本文/第55条の3.md|第五十五条の三]]、[[laws/外国為替令/本文/第55条の4.md|第五十五条の四]]、[[laws/外国為替令/本文/第55条の7.md|第五十五条の七]]又は[[laws/外国為替令/本文/第55条の8.md|第五十五条の八]]（この政令の[[laws/外国為替令/本文/第18条の8.md|第十八条の八]]に係る部分に限る。）の規定に基づく報告の受理（前条第五項の規定により財務局長又は福岡財務支局長が行う報告の徴求に係るものを除く。）に関する事務
- 八 法[[laws/外国為替令/本文/第55条の9.md|第五十五条の九]]の規定に基づく対外の貸借及び国際収支に関する統計の作成に関する事務
- 九 [[laws/外国為替令/本文/第6条の2.md|第六条の二]]第四項、[[laws/外国為替令/本文/第11条の3.md|第十一条の三]]第二項、[[laws/外国為替令/本文/第16条.md|第十六条]]第二項又は[[laws/外国為替令/本文/第18条の3.md|第十八条の三]]第二項の規定による許可に関する事務
- 十 前各号に掲げる事務のほか、法及びこの政令の施行のため必要な事務
