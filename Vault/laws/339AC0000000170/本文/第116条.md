# 第百十六条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、三年以下の拘禁刑若しくは三百万円以下の罰金に処し、又はこれを併科する。[[laws/339AC0000000170/本文/第3条.md|第三条]]の規定に違反して一般送配電事業を営んだとき。[[laws/339AC0000000170/本文/第27条の4.md|第二十七条の四]]の規定に違反して送電事業を営んだとき。[[laws/339AC0000000170/本文/第27条の12.md|第二十七条の十二]]の二の規定に違反して配電事業を営んだとき。[[laws/339AC0000000170/本文/第27条の29.md|第二十七条の二十九]]の五の規定による命令に違反したとき。[[laws/339AC0000000170/本文/第40条.md|第四十条]]（原子力発電工作物に係る場合に限る。）の規定による命令又は処分に違反したとき。[[laws/339AC0000000170/本文/第47条.md|第四十七条]]第一項（原子力発電工作物に係る場合に限る。）の規定に違反して電気工作物の設置又は変更の工事をしたとき。

- 一 [[laws/339AC0000000170/本文/第3条.md|第三条]]の規定に違反して一般送配電事業を営んだとき。
- 二 [[laws/339AC0000000170/本文/第27条の4.md|第二十七条の四]]の規定に違反して送電事業を営んだとき。
- 三 [[laws/339AC0000000170/本文/第27条の12.md|第二十七条の十二]]の二の規定に違反して配電事業を営んだとき。
- 四 [[laws/339AC0000000170/本文/第27条の29.md|第二十七条の二十九]]の五の規定による命令に違反したとき。
- 五 [[laws/339AC0000000170/本文/第40条.md|第四十条]]（原子力発電工作物に係る場合に限る。）の規定による命令又は処分に違反したとき。
- 六 [[laws/339AC0000000170/本文/第47条.md|第四十七条]]第一項（原子力発電工作物に係る場合に限る。）の規定に違反して電気工作物の設置又は変更の工事をしたとき。
