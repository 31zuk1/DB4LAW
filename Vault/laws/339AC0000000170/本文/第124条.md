# 第百二十四条 

## 
次の各号のいずれかに該当する場合には、その違反行為をした推進機関の発起人又は役員は、二十万円以下の過料に処する。この法律の規定により経済産業大臣の認可を受けなければならない場合において、その認可を受けなかつたとき。[[laws/339AC0000000170/本文/第28条の8.md|第二十八条の八]]第一項の規定による政令に違反して登記することを怠つたとき。[[laws/339AC0000000170/本文/第28条の10.md|第二十八条の十]]第二項の規定に違反したとき。[[laws/339AC0000000170/本文/第28条の13.md|第二十八条の十三]]第二項の規定による公告をすることを怠り、又は不正の公告をしたとき。[[laws/339AC0000000170/本文/第28条の40.md|第二十八条の四十]]第一項及び第二項に規定する業務以外の業務を行つたとき。[[laws/339AC0000000170/本文/第28条の44.md|第二十八条の四十四]]第二項又は第三項の規定に違反して、報告をせず、又は虚偽の報告をしたとき。[[laws/339AC0000000170/本文/第28条の46.md|第二十八条の四十六]]第三項、[[laws/339AC0000000170/本文/第28条の48.md|第二十八条の四十八]]第四項又は[[laws/339AC0000000170/本文/第28条の59.md|第二十八条の五十九]]の規定による命令に違反したとき。[[laws/339AC0000000170/本文/第28条の46.md|第二十八条の四十六]]第四項の規定による届出をせず、又は虚偽の届出をしたとき。[[laws/339AC0000000170/本文/第28条の53.md|第二十八条の五十三]]第一項又は第二項に規定する書類を提出せず、又は虚偽の書類を提出したとき。[[laws/339AC0000000170/本文/第28条の57.md|第二十八条の五十七]]の規定に違反して業務上の余裕金を運用したとき。

- 一 この法律の規定により経済産業大臣の認可を受けなければならない場合において、その認可を受けなかつたとき。
- 二 [[laws/339AC0000000170/本文/第28条の8.md|第二十八条の八]]第一項の規定による政令に違反して登記することを怠つたとき。
- 三 [[laws/339AC0000000170/本文/第28条の10.md|第二十八条の十]]第二項の規定に違反したとき。
- 四 [[laws/339AC0000000170/本文/第28条の13.md|第二十八条の十三]]第二項の規定による公告をすることを怠り、又は不正の公告をしたとき。
- 五 [[laws/339AC0000000170/本文/第28条の40.md|第二十八条の四十]]第一項及び第二項に規定する業務以外の業務を行つたとき。
- 六 [[laws/339AC0000000170/本文/第28条の44.md|第二十八条の四十四]]第二項又は第三項の規定に違反して、報告をせず、又は虚偽の報告をしたとき。
- 七 [[laws/339AC0000000170/本文/第28条の46.md|第二十八条の四十六]]第三項、[[laws/339AC0000000170/本文/第28条の48.md|第二十八条の四十八]]第四項又は[[laws/339AC0000000170/本文/第28条の59.md|第二十八条の五十九]]の規定による命令に違反したとき。
- 八 [[laws/339AC0000000170/本文/第28条の46.md|第二十八条の四十六]]第四項の規定による届出をせず、又は虚偽の届出をしたとき。
- 九 [[laws/339AC0000000170/本文/第28条の53.md|第二十八条の五十三]]第一項又は第二項に規定する書類を提出せず、又は虚偽の書類を提出したとき。
- 十 [[laws/339AC0000000170/本文/第28条の57.md|第二十八条の五十七]]の規定に違反して業務上の余裕金を運用したとき。
