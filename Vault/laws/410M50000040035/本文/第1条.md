# 第一条 （承継国債の告示）

## 
財務大臣は、日本国有鉄道清算事業団の債務の負担の軽減を図るために平成九年度において緊急に講ずべき特別措置に関する法律（平成九年法律第七十三号）[[laws/政府が承継した日本国有鉄道清算事業団債務に係る国債の取扱い等に関する省令/本文/第2条.md|第二条]]第一項又は日本国有鉄道清算事業団の債務等の処理に関する法律（平成十年法律第百三十六号）[[laws/政府が承継した日本国有鉄道清算事業団債務に係る国債の取扱い等に関する省令/本文/第2条.md|第二条]]第一項の規定により、政府が日本国有鉄道清算事業団の債務を承継したときは、その承継した債務に係る国債（以下「承継国債」という。）について、遅滞なく次に掲げる事項を告示するものとする。名称及び記号額面総額額面金額の種類利率利子支払期償還期限償還金額その他必要な事項

- 一 名称及び記号
- 二 額面総額
- 三 額面金額の種類
- 四 利率
- 五 利子支払期
- 六 償還期限
- 七 償還金額
- 八 その他必要な事項
