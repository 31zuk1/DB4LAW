# 第一条の四 （業務方法書に記載すべき事項）

## 
国立美術館に係る通則法[[laws/独立行政法人国立美術館に関する省令/本文/第28条.md|第二十八条]]第二項の主務省令で定める業務方法書に記載すべき事項は、次のとおりとする。国立美術館法[[laws/独立行政法人国立美術館に関する省令/本文/第11条.md|第十一条]]第一号の規定に基づく東京国立近代美術館、京都国立近代美術館、国立映画アーカイブ、国立西洋美術館、国立国際美術館及び国立新美術館の設置に関する事項国立美術館法[[laws/独立行政法人国立美術館に関する省令/本文/第11条.md|第十一条]]第二号に規定する美術に関する作品その他の資料の収集、保管及び供覧に関する事項国立美術館法[[laws/独立行政法人国立美術館に関する省令/本文/第11条.md|第十一条]]第三号に規定する調査及び研究に関する事項国立美術館法[[laws/独立行政法人国立美術館に関する省令/本文/第11条.md|第十一条]]第四号に規定する情報及び資料の収集、整理及び提供に関する事項国立美術館法[[laws/独立行政法人国立美術館に関する省令/本文/第11条.md|第十一条]]第五号に規定する教育及び普及の事業に関する事項国立美術館法[[laws/独立行政法人国立美術館に関する省令/本文/第11条.md|第十一条]]第六号に規定する美術館の供用に関する事項国立美術館法[[laws/独立行政法人国立美術館に関する省令/本文/第11条.md|第十一条]]第七号に規定する研修に関する事項国立美術館法[[laws/独立行政法人国立美術館に関する省令/本文/第11条.md|第十一条]]第八号に規定する援助及び助言に関する事項国立美術館法[[laws/独立行政法人国立美術館に関する省令/本文/第11条.md|第十一条]]第九号に規定する附帯業務に関する事項業務委託の基準競争入札その他契約に関する基本的事項その他国立美術館の業務の執行に関して必要な事項

- 一 国立美術館法[[laws/独立行政法人国立美術館に関する省令/本文/第11条.md|第十一条]]第一号の規定に基づく東京国立近代美術館、京都国立近代美術館、国立映画アーカイブ、国立西洋美術館、国立国際美術館及び国立新美術館の設置に関する事項
- 二 国立美術館法[[laws/独立行政法人国立美術館に関する省令/本文/第11条.md|第十一条]]第二号に規定する美術に関する作品その他の資料の収集、保管及び供覧に関する事項
- 三 国立美術館法[[laws/独立行政法人国立美術館に関する省令/本文/第11条.md|第十一条]]第三号に規定する調査及び研究に関する事項
- 四 国立美術館法[[laws/独立行政法人国立美術館に関する省令/本文/第11条.md|第十一条]]第四号に規定する情報及び資料の収集、整理及び提供に関する事項
- 五 国立美術館法[[laws/独立行政法人国立美術館に関する省令/本文/第11条.md|第十一条]]第五号に規定する教育及び普及の事業に関する事項
- 六 国立美術館法[[laws/独立行政法人国立美術館に関する省令/本文/第11条.md|第十一条]]第六号に規定する美術館の供用に関する事項
- 七 国立美術館法[[laws/独立行政法人国立美術館に関する省令/本文/第11条.md|第十一条]]第七号に規定する研修に関する事項
- 八 国立美術館法[[laws/独立行政法人国立美術館に関する省令/本文/第11条.md|第十一条]]第八号に規定する援助及び助言に関する事項
- 九 国立美術館法[[laws/独立行政法人国立美術館に関する省令/本文/第11条.md|第十一条]]第九号に規定する附帯業務に関する事項
- 十 業務委託の基準
- 十一 競争入札その他契約に関する基本的事項
- 十二 その他国立美術館の業務の執行に関して必要な事項
