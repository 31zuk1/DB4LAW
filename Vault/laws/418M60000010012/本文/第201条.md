# 第二百一条 （吸収分割承継株式会社の事後開示事項）

## 
法[[laws/会社法施行規則/本文/第801条.md|第八百一条]]第二項に規定する法務省令で定める事項は、次に掲げる事項とする。吸収分割が効力を生じた日吸収分割合同会社における法[[laws/会社法施行規則/本文/第793条.md|第七百九十三条]]第二項において準用する法[[laws/会社法施行規則/本文/第789条.md|第七百八十九条]]の規定による手続の経過吸収分割承継株式会社における次に掲げる事項法[[laws/会社法施行規則/本文/第796条の2.md|第七百九十六条の二]]の規定による請求に係る手続の経過法[[laws/会社法施行規則/本文/第797条.md|第七百九十七条]]及び[[laws/会社法施行規則/本文/第799条.md|第七百九十九条]]の規定による手続の経過吸収分割により吸収分割承継株式会社が吸収分割合同会社から承継した重要な権利義務に関する事項法[[laws/会社法施行規則/本文/第923条.md|第九百二十三条]]の変更の登記をした日前各号に掲げるもののほか、吸収分割に関する重要な事項

- 一 吸収分割が効力を生じた日
- 二 吸収分割合同会社における法[[laws/会社法施行規則/本文/第793条.md|第七百九十三条]]第二項において準用する法[[laws/会社法施行規則/本文/第789条.md|第七百八十九条]]の規定による手続の経過
- 三 吸収分割承継株式会社における次に掲げる事項
- 四 吸収分割により吸収分割承継株式会社が吸収分割合同会社から承継した重要な権利義務に関する事項
- 五 法[[laws/会社法施行規則/本文/第923条.md|第九百二十三条]]の変更の登記をした日
- 六 前各号に掲げるもののほか、吸収分割に関する重要な事項
