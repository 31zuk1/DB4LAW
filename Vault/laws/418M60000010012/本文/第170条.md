# 第百七十条 （社債管理者の資格）

## 
法[[laws/会社法施行規則/本文/第703条.md|第七百三条]]第三号に規定する法務省令で定める者は、次に掲げる者とする。担保付社債信託法[[laws/信託法/本文/第3条.md|第三条]]の免許を受けた者株式会社商工組合中央金庫農業協同組合法[[laws/農業協同組合法/本文/第10条.md|第十条]]第一項第二号及び第三号の事業を併せ行う農業協同組合又は農業協同組合連合会信用協同組合又は中小企業等協同組合法第九条の九第一項第一号の事業を行う協同組合連合会信用金庫又は信用金庫連合会労働金庫連合会長期信用銀行法[[laws/中小企業等協同組合法/本文/第2条.md|第二条]]に規定する長期信用銀行保険業法[[laws/中小企業等協同組合法/本文/第2条.md|第二条]]第二項に規定する保険会社農林中央金庫

- 一 担保付社債信託法[[laws/信託法/本文/第3条.md|第三条]]の免許を受けた者
- 二 株式会社商工組合中央金庫
- 三 農業協同組合法第十条第一項第二号及び第三号の事業を併せ行う農業協同組合又は農業協同組合連合会
- 四 信用協同組合又は中小企業等協同組合法第九条の九第一項第一号の事業を行う協同組合連合会
- 五 信用金庫又は信用金庫連合会
- 六 労働金庫連合会
- 七 長期信用銀行法[[laws/会社法施行規則/本文/第2条.md|第二条]]に規定する長期信用銀行
- 八 保険業法第二条第二項に規定する保険会社
- 九 農林中央金庫
