# 第六十四条 （電話勧誘販売における禁止行為）

## 
法[[laws/特定商取引に関する法律施行規則/本文/第22条.md|第二十二条]]第一項第五号の主務省令で定める行為は、次に掲げるものとする。電話勧誘販売に係る売買契約若しくは役務提供契約の締結について迷惑を覚えさせるような仕方で勧誘をし、又は電話勧誘販売に係る売買契約若しくは役務提供契約の申込みの撤回若しくは解除について迷惑を覚えさせるような仕方でこれを妨げること。若年者、高齢者その他の者の判断力の不足に乗じ、電話勧誘販売に係る売買契約又は役務提供契約を締結させること。電話勧誘顧客の知識、経験及び財産の状況に照らして不適当と認められる勧誘を行うこと（法[[laws/特定商取引に関する法律施行規則/本文/第22条.md|第二十二条]]第一項第四号に定めるものを除く。）。電話勧誘販売に係る売買契約又は役務提供契約を締結するに際し、当該契約に係る書面に年齢、職業その他の事項について虚偽の記載をさせること。電話勧誘販売に係る売買契約又は役務提供契約の相手方に当該契約に基づく債務を履行させるため、次に掲げる行為を行うこと。当該電話勧誘販売に係る売買契約又は役務提供契約の相手方の年収、預貯金又は借入れの状況その他の支払能力に関する事項について虚偽の申告をさせること。当該電話勧誘販売に係る売買契約又は役務提供契約の相手方に割賦販売法[[laws/特定商取引に関する法律施行規則/本文/第35条の3.md|第三十五条の三]]の三第一項に規定する個別信用購入あつせん関係受領契約若しくは金銭の借入れに係る契約を締結させ、又は預貯金を引き出させるため、迷惑を覚えさせるような仕方でこれを勧誘すること。法[[laws/特定商取引に関する法律施行規則/本文/第26条.md|第二十六条]]第五項第一号の政令で定める商品の売買契約の解除を妨げるため、当該売買契約を締結した際、購入者に当該商品を使用させ又はその全部若しくは一部を消費させること。法[[laws/特定商取引に関する法律施行規則/本文/第18条.md|第十八条]]第二項（法[[laws/特定商取引に関する法律施行規則/本文/第19条.md|第十九条]]第三項において準用する場合を含む。）の規定により法[[laws/特定商取引に関する法律施行規則/本文/第18条.md|第十八条]]第一項の規定により交付する書面（法[[laws/特定商取引に関する法律施行規則/本文/第19条.md|第十九条]]第三項において準用する場合にあつては同条第一項又は第二項の規定により交付する書面）に記載すべき事項を電磁的方法により又は法[[laws/特定商取引に関する法律施行規則/本文/第20条.md|第二十条]]第二項の規定により同条第一項の規定により通知する書面に記載すべき事項を電磁的方法により提供するに際し、次に掲げる行為を行うこと。電磁的方法による提供を希望しない旨の意思を表示した顧客又は購入者若しくは役務の提供を受ける者に対し、電磁的方法による提供に係る手続を進める行為顧客又は購入者若しくは役務の提供を受ける者の判断に影響を及ぼすこととなるものにつき、不実のことを告げる行為（法[[laws/特定商取引に関する法律施行規則/本文/第21条.md|第二十一条]]第一項に規定する行為を除く。）威迫して困惑させる行為（法[[laws/特定商取引に関する法律施行規則/本文/第21条.md|第二十一条]]第三項に規定する行為を除く。）財産上の利益を供与する行為法[[laws/特定商取引に関する法律施行規則/本文/第18条.md|第十八条]]第一項又は法[[laws/特定商取引に関する法律施行規則/本文/第19条.md|第十九条]]第一項若しくは第二項の規定による書面の交付又は法[[laws/特定商取引に関する法律施行規則/本文/第20条.md|第二十条]]第一項の規定による書面による通知につき、費用の徴収その他財産上の不利益を与える行為（ニに掲げる行為を除く。）[[laws/特定商取引に関する法律施行規則/本文/第50条.md|第五十条]]第三項又は[[laws/特定商取引に関する法律施行規則/本文/第60条.md|第六十条]]第三項の確認に際し、偽りその他不正の手段により顧客又は購入者若しくは役務の提供を受ける者に不当な影響を与える行為[[laws/特定商取引に関する法律施行規則/本文/第50条.md|第五十条]]第三項又は[[laws/特定商取引に関する法律施行規則/本文/第60条.md|第六十条]]第三項の確認をせず、又は確認ができない顧客又は購入者若しくは役務の提供を受ける者に対し電磁的方法による提供をする行為偽りその他不正の手段により顧客又は購入者若しくは役務の提供を受ける者の承諾を代行し、又は電磁的方法により提供される事項の受領を代行する行為イからチまでに掲げるもののほか、顧客又は購入者若しくは役務の提供を受ける者の意に反して承諾させ、又は電磁的方法により提供される事項を受領させる行為

- 一 電話勧誘販売に係る売買契約若しくは役務提供契約の締結について迷惑を覚えさせるような仕方で勧誘をし、又は電話勧誘販売に係る売買契約若しくは役務提供契約の申込みの撤回若しくは解除について迷惑を覚えさせるような仕方でこれを妨げること。
- 二 若年者、高齢者その他の者の判断力の不足に乗じ、電話勧誘販売に係る売買契約又は役務提供契約を締結させること。
- 三 電話勧誘顧客の知識、経験及び財産の状況に照らして不適当と認められる勧誘を行うこと（法[[laws/特定商取引に関する法律施行規則/本文/第22条.md|第二十二条]]第一項第四号に定めるものを除く。）。
- 四 電話勧誘販売に係る売買契約又は役務提供契約を締結するに際し、当該契約に係る書面に年齢、職業その他の事項について虚偽の記載をさせること。
- 五 電話勧誘販売に係る売買契約又は役務提供契約の相手方に当該契約に基づく債務を履行させるため、次に掲げる行為を行うこと。
- 六 法[[laws/特定商取引に関する法律施行規則/本文/第26条.md|第二十六条]]第五項第一号の政令で定める商品の売買契約の解除を妨げるため、当該売買契約を締結した際、購入者に当該商品を使用させ又はその全部若しくは一部を消費させること。
- 七 法[[laws/特定商取引に関する法律施行規則/本文/第18条.md|第十八条]]第二項（法[[laws/特定商取引に関する法律施行規則/本文/第19条.md|第十九条]]第三項において準用する場合を含む。）の規定により法[[laws/特定商取引に関する法律施行規則/本文/第18条.md|第十八条]]第一項の規定により交付する書面（法[[laws/特定商取引に関する法律施行規則/本文/第19条.md|第十九条]]第三項において準用する場合にあつては同条第一項又は第二項の規定により交付する書面）に記載すべき事項を電磁的方法により又は法[[laws/特定商取引に関する法律施行規則/本文/第20条.md|第二十条]]第二項の規定により同条第一項の規定により通知する書面に記載すべき事項を電磁的方法により提供するに際し、次に掲げる行為を行うこと。
