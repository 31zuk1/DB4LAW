# 第三十四条 （法第三十二条の七第一項第十号に規定する厚生労働省令で定める事務）

## 
法[[laws/416AC1000000166/本文/第32条の7.md|第三十二条の七]]第一項第十号に規定する厚生労働省令で定める事務は、次の各号に掲げる事務とする。[[laws/417M60000100049/本文/第2条.md|第二条]]第一項の規定による交付に係る事務並びに同条第二項及び第三項の規定による通知に係る事務[[laws/417M60000100049/本文/第4条.md|第四条]]第二項第五号、[[laws/417M60000100049/本文/第7条の2.md|第七条の二]]第五項及び[[laws/417M60000100049/本文/第7条の3.md|第七条の三]]第一項の規定による指定に係る事務[[laws/417M60000100049/本文/第16条.md|第十六条]]の規定による通知に係る事務[[laws/417M60000100049/本文/第21条.md|第二十一条]]第一項の規定による添付書類の省略に係る事務住民基本台帳法[[laws/342AC0000000081/本文/第30条の9.md|第三十条の九]]の規定による機構保存本人確認情報の提供を受けることに係る事務番号利用法[[laws/342AC0000000081/本文/第22条.md|第二十二条]]第一項の規定による利用特定個人情報（番号利用法[[laws/342AC0000000081/本文/第19条.md|第十九条]]第八号に規定する利用特定個人情報をいう。）の提供を受けることに係る事務

- 一 [[laws/417M60000100049/本文/第2条.md|第二条]]第一項の規定による交付に係る事務並びに同条第二項及び第三項の規定による通知に係る事務
- 二 [[laws/417M60000100049/本文/第4条.md|第四条]]第二項第五号、[[laws/417M60000100049/本文/第7条の2.md|第七条の二]]第五項及び[[laws/417M60000100049/本文/第7条の3.md|第七条の三]]第一項の規定による指定に係る事務
- 三 [[laws/417M60000100049/本文/第16条.md|第十六条]]の規定による通知に係る事務
- 四 [[laws/417M60000100049/本文/第21条.md|第二十一条]]第一項の規定による添付書類の省略に係る事務
- 五 住民基本台帳法第三十条の九の規定による機構保存本人確認情報の提供を受けることに係る事務
- 六 番号利用法[[laws/417M60000100049/本文/第22条.md|第二十二条]]第一項の規定による利用特定個人情報（番号利用法[[laws/417M60000100049/本文/第19条.md|第十九条]]第八号に規定する利用特定個人情報をいう。）の提供を受けることに係る事務
