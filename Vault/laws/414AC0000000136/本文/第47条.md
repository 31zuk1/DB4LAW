# 第四十七条 

## 
次の各号のいずれかに該当する場合には、その違反行為をした機構の役員又は職員は、二十万円以下の過料に処する。[[laws/独立行政法人国際協力機構法/本文/第13条.md|第十三条]]に規定する業務以外の業務を行ったとき。この法律の規定により外務大臣又は財務大臣の承認を受けなければならない場合において、その承認を受けなかったとき。この法律の規定により主務大臣の認可を受けなければならない場合において、その認可を受けなかったとき。この法律の規定により財務大臣又は主務大臣に届出をしなければならない場合において、その届出をせず、又は虚偽の届出をしたとき。[[laws/独立行政法人国際協力機構法/本文/第33条.md|第三十三条]]第一項の規定に違反して資金の借入れ又は債券の発行をしたとき。[[laws/独立行政法人国際協力機構法/本文/第36条.md|第三十六条]]の規定に違反して業務上の余裕金を運用したとき。

- 一 [[laws/独立行政法人国際協力機構法/本文/第13条.md|第十三条]]に規定する業務以外の業務を行ったとき。
- 二 この法律の規定により外務大臣又は財務大臣の承認を受けなければならない場合において、その承認を受けなかったとき。
- 三 この法律の規定により主務大臣の認可を受けなければならない場合において、その認可を受けなかったとき。
- 四 この法律の規定により財務大臣又は主務大臣に届出をしなければならない場合において、その届出をせず、又は虚偽の届出をしたとき。
- 五 [[laws/独立行政法人国際協力機構法/本文/第33条.md|第三十三条]]第一項の規定に違反して資金の借入れ又は債券の発行をしたとき。
- 六 [[laws/独立行政法人国際協力機構法/本文/第36条.md|第三十六条]]の規定に違反して業務上の余裕金を運用したとき。
