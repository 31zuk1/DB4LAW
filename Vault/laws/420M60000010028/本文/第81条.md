# 第八十一条 （通告の方式）

## 
法[[laws/犯罪をした者及び非行のある少年に対する社会内における処遇に関する規則/本文/第68条.md|第六十八条]]第一項の規定による通告は、次に掲げる事項を記載した書面によらなければならない。保護観察処分少年の氏名、生年月日、職業、本籍及び住居保護者の氏名、年齢、職業及び住居保護処分をした家庭裁判所の名称及びその年月日通告の理由必要とする保護処分の種類及び期間（期間については、保護観察処分少年が二十歳以上である場合に限る。）その他参考となる事項

- 一 保護観察処分少年の氏名、生年月日、職業、本籍及び住居
- 二 保護者の氏名、年齢、職業及び住居
- 三 保護処分をした家庭裁判所の名称及びその年月日
- 四 通告の理由
- 五 必要とする保護処分の種類及び期間（期間については、保護観察処分少年が二十歳以上である場合に限る。）
- 六 その他参考となる事項
## ２
前条第二項の規定は、前項の通告について準用する。
