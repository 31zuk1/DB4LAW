# 第三十三条 （準備書の作成）

## 
事業者は、法[[laws/道路事業に係る環境影響評価の項目並びに当該項目に係る調査、予測及び評価を合理的に行うための手法を選定するための指針、環境の保全のための措置に関する指針等を定める省令/本文/第14条.md|第十四条]]第一項の規定により対象道路事業に係る準備書に法[[laws/道路事業に係る環境影響評価の項目並びに当該項目に係る調査、予測及び評価を合理的に行うための手法を選定するための指針、環境の保全のための措置に関する指針等を定める省令/本文/第5条.md|第五条]]第一項第二号に規定する対象事業の内容を記載するに当たっては、次に掲げる事項を記載しなければならない。[[laws/道路事業に係る環境影響評価の項目並びに当該項目に係る調査、予測及び評価を合理的に行うための手法を選定するための指針、環境の保全のための措置に関する指針等を定める省令/本文/第17条.md|第十七条]]第一項第一号から第五号までに掲げる事項対象道路事業に係る道路の区間対象道路事業に係る道路の区分、計画交通量及び構造の概要（盛土、切土、トンネル、橋若しくは高架又はその他の構造の別を含む。）対象道路事業の工事計画の概要対象道路事業に係る道路のインターチェンジ等区域（高速自動車国道と交通の用に供する施設を連結させるための高速自動車国道の施設その他道路と交通の用に供する施設を連結させるための施設で当該高速自動車国道の施設に準ずる規模を有するものを設置する区域をいう。）の位置前各号に掲げるもののほか、対象道路事業の内容に関する事項（既に決定されている内容に係るものに限る。）であって、その変更により環境影響が変化することとなるもの

- 一 [[laws/道路事業に係る環境影響評価の項目並びに当該項目に係る調査、予測及び評価を合理的に行うための手法を選定するための指針、環境の保全のための措置に関する指針等を定める省令/本文/第17条.md|第十七条]]第一項第一号から第五号までに掲げる事項
- 二 対象道路事業に係る道路の区間
- 三 対象道路事業に係る道路の区分、計画交通量及び構造の概要（盛土、切土、トンネル、橋若しくは高架又はその他の構造の別を含む。）
- 四 対象道路事業の工事計画の概要
- 五 対象道路事業に係る道路のインターチェンジ等区域（高速自動車国道と交通の用に供する施設を連結させるための高速自動車国道の施設その他道路と交通の用に供する施設を連結させるための施設で当該高速自動車国道の施設に準ずる規模を有するものを設置する区域をいう。）の位置
- 六 前各号に掲げるもののほか、対象道路事業の内容に関する事項（既に決定されている内容に係るものに限る。）であって、その変更により環境影響が変化することとなるもの
