# 第七条 （特定復興再生拠点区域復興再生計画の認定の申請）

## 
法[[laws/424AC0000000025/本文/第17条の2.md|第十七条の二]]第一項に規定する特定避難指示区域市町村（以下「特定避難指示区域市町村」という。）の長は、同項の規定により認定の申請をしようとするときは、別記様式第四による申請書その他の同条第二項各号に掲げる事項を明らかにする書類に、次に掲げる図書を添えて、これらを内閣総理大臣に提出するものとする。特定復興再生拠点区域（法[[laws/424AC0000000025/本文/第17条の2.md|第十七条の二]]第一項に規定する特定復興再生拠点区域をいう。以下この号及び次号において同じ。）に含まれる行政区画を表示した図面又は縮尺、方位、目標となる地物及び特定復興再生拠点区域を表示した付近見取図特定復興再生拠点区域が法[[laws/424AC0000000025/本文/第17条の2.md|第十七条の二]]第一項各号に掲げる条件のいずれにも該当するものであることを示す書類特定復興再生拠点区域復興再生計画（法[[laws/424AC0000000025/本文/第17条の2.md|第十七条の二]]第一項に規定する特定復興再生拠点区域復興再生計画をいう。以下この条及び[[laws/424M60000004003/本文/第10条.md|第十条]]において同じ。）の工程表及びその内容を説明した文書法[[laws/424AC0000000025/本文/第17条の2.md|第十七条の二]]第三項の規定により特定避難指示区域市町村以外の者が実施する事業に係る事項を記載している場合にあっては、同条第四項に規定する同意を得たことを証する書類法[[laws/424AC0000000025/本文/第17条の2.md|第十七条の二]]第五項の規定による福島県知事との協議の結果法[[laws/424AC0000000025/本文/第17条の10.md|第十七条の十]]第一項の提案を踏まえた特定復興再生拠点区域復興再生計画についての法[[laws/424AC0000000025/本文/第17条の2.md|第十七条の二]]第一項の規定による認定の申請をする場合にあっては、当該提案の概要前各号に掲げるもののほか、内閣総理大臣が必要と認める事項を記載した書類

- 一 特定復興再生拠点区域（法[[laws/424AC0000000025/本文/第17条の2.md|第十七条の二]]第一項に規定する特定復興再生拠点区域をいう。以下この号及び次号において同じ。）に含まれる行政区画を表示した図面又は縮尺、方位、目標となる地物及び特定復興再生拠点区域を表示した付近見取図
- 二 特定復興再生拠点区域が法[[laws/424AC0000000025/本文/第17条の2.md|第十七条の二]]第一項各号に掲げる条件のいずれにも該当するものであることを示す書類
- 三 特定復興再生拠点区域復興再生計画（法[[laws/424AC0000000025/本文/第17条の2.md|第十七条の二]]第一項に規定する特定復興再生拠点区域復興再生計画をいう。以下この条及び[[laws/424M60000004003/本文/第10条.md|第十条]]において同じ。）の工程表及びその内容を説明した文書
- 四 法[[laws/424AC0000000025/本文/第17条の2.md|第十七条の二]]第三項の規定により特定避難指示区域市町村以外の者が実施する事業に係る事項を記載している場合にあっては、同条第四項に規定する同意を得たことを証する書類
- 五 法[[laws/424AC0000000025/本文/第17条の2.md|第十七条の二]]第五項の規定による福島県知事との協議の結果
- 六 法[[laws/424AC0000000025/本文/第17条の10.md|第十七条の十]]第一項の提案を踏まえた特定復興再生拠点区域復興再生計画についての法[[laws/424AC0000000025/本文/第17条の2.md|第十七条の二]]第一項の規定による認定の申請をする場合にあっては、当該提案の概要
- 七 前各号に掲げるもののほか、内閣総理大臣が必要と認める事項を記載した書類
