# 第三条 （認定福島復興再生計画の変更の認定の申請）

## 
福島県知事は、法[[laws/424AC0000000025/本文/第7条の2.md|第七条の二]]第一項において読み替えて準用する東日本大震災復興特別区域法[[laws/424M60000004003/本文/第6条.md|第六条]]第一項の規定により認定福島復興再生計画（法[[laws/424M60000004003/本文/第8条.md|第八条]]第一項に規定する認定福島復興再生計画をいう。次条において同じ。）の変更の認定を受けようとするときは、別記様式第二による申請書に、[[laws/424M60000004003/本文/第1条.md|第一条]]各号に掲げる図書のうち当該認定福島復興再生計画の変更に伴いその内容が変更されるものを添えて、これらを内閣総理大臣に提出するものとする。
