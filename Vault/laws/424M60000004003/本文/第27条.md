# 第二十七条 （生活の拠点を形成するために必要な事業）

## 
法[[laws/福島復興再生特別措置法施行規則/本文/第45条.md|第四十五条]]第二項第三号ハの復興庁令で定める事業は、次に掲げるものとする。文化財保護法[[laws/福島復興再生特別措置法施行規則/本文/第99条.md|第九十九条]]第一項に規定する埋蔵文化財の調査のために行う土地の発掘に関する事業都市公園法[[laws/福島復興再生特別措置法施行規則/本文/第2条.md|第二条]]第一項に規定する都市公園の新設又は改築に関する事業下水道法[[laws/福島復興再生特別措置法施行規則/本文/第2条.md|第二条]]第二号に規定する下水道の設置又は改築に関する事業道路法[[laws/福島復興再生特別措置法施行規則/本文/第2条.md|第二条]]第一項に規定する道路の修繕に関する事業法[[laws/福島復興再生特別措置法施行規則/本文/第45条.md|第四十五条]]第二項第二号に掲げる事業、同項第三号イ及びロに掲げる事業又は前各号に掲げる事業を実施する者に対し補助する事業その他内閣総理大臣が定める事業

- 一 文化財保護法[[laws/福島復興再生特別措置法施行規則/本文/第99条.md|第九十九条]]第一項に規定する埋蔵文化財の調査のために行う土地の発掘に関する事業
- 二 都市公園法[[laws/福島復興再生特別措置法施行規則/本文/第2条.md|第二条]]第一項に規定する都市公園の新設又は改築に関する事業
- 三 下水道法[[laws/福島復興再生特別措置法施行規則/本文/第2条.md|第二条]]第二号に規定する下水道の設置又は改築に関する事業
- 四 道路法[[laws/福島復興再生特別措置法施行規則/本文/第2条.md|第二条]]第一項に規定する道路の修繕に関する事業
- 五 法[[laws/福島復興再生特別措置法施行規則/本文/第45条.md|第四十五条]]第二項第二号に掲げる事業、同項第三号イ及びロに掲げる事業又は前各号に掲げる事業を実施する者に対し補助する事業
- 六 その他内閣総理大臣が定める事業
