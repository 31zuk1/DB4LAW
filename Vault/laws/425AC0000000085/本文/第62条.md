# 第六十二条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、五十万円以下の罰金に処する。[[laws/再生医療等の安全性の確保等に関する法律/本文/第4条.md|第四条]]第一項の規定に違反して、再生医療等提供計画を提出せず、又はこれに記載すべき事項を記載せず、若しくは虚偽の記載をしてこれを提出して、再生医療等を提供したとき（[[laws/再生医療等の安全性の確保等に関する法律/本文/第60条.md|第六十条]]第一項第一号の規定に該当する場合を除く。）。[[laws/再生医療等の安全性の確保等に関する法律/本文/第5条.md|第五条]]第一項の規定に違反して、変更後の再生医療等提供計画を提出せず、又はこれに記載すべき事項を記載せず、若しくは虚偽の記載をしてこれを提出して、再生医療等を提供したとき（[[laws/再生医療等の安全性の確保等に関する法律/本文/第60条.md|第六十条]]第一項第二号の規定に該当する場合を除く。）。[[laws/再生医療等の安全性の確保等に関する法律/本文/第13条.md|第十三条]]の規定に違反して再生医療等を行ったとき（[[laws/再生医療等の安全性の確保等に関する法律/本文/第60条.md|第六十条]]第一項第五号の規定に該当する場合を除く。）。[[laws/再生医療等の安全性の確保等に関する法律/本文/第16条.md|第十六条]]第一項の規定に違反して記録を作成せず、又は虚偽の記録を作成したとき。[[laws/再生医療等の安全性の確保等に関する法律/本文/第16条.md|第十六条]]第二項の規定に違反して記録を保存しなかったとき。[[laws/再生医療等の安全性の確保等に関する法律/本文/第23条.md|第二十三条]]第二項（第一種再生医療等に係る部分を除く。）の規定による命令に違反したとき。[[laws/再生医療等の安全性の確保等に関する法律/本文/第24条.md|第二十四条]]第一項若しくは第二項の報告をせず、若しくは虚偽の報告をし、同条第一項若しくは第二項の規定による立入検査を拒み、妨げ、若しくは忌避し、又は同条第一項若しくは第二項の規定による質問に対し、正当な理由なしに答弁せず、若しくは虚偽の答弁をしたとき。

- 一 [[laws/再生医療等の安全性の確保等に関する法律/本文/第4条.md|第四条]]第一項の規定に違反して、再生医療等提供計画を提出せず、又はこれに記載すべき事項を記載せず、若しくは虚偽の記載をしてこれを提出して、再生医療等を提供したとき（[[laws/再生医療等の安全性の確保等に関する法律/本文/第60条.md|第六十条]]第一項第一号の規定に該当する場合を除く。）。
- 二 [[laws/再生医療等の安全性の確保等に関する法律/本文/第5条.md|第五条]]第一項の規定に違反して、変更後の再生医療等提供計画を提出せず、又はこれに記載すべき事項を記載せず、若しくは虚偽の記載をしてこれを提出して、再生医療等を提供したとき（[[laws/再生医療等の安全性の確保等に関する法律/本文/第60条.md|第六十条]]第一項第二号の規定に該当する場合を除く。）。
- 三 [[laws/再生医療等の安全性の確保等に関する法律/本文/第13条.md|第十三条]]の規定に違反して再生医療等を行ったとき（[[laws/再生医療等の安全性の確保等に関する法律/本文/第60条.md|第六十条]]第一項第五号の規定に該当する場合を除く。）。
- 四 [[laws/再生医療等の安全性の確保等に関する法律/本文/第16条.md|第十六条]]第一項の規定に違反して記録を作成せず、又は虚偽の記録を作成したとき。
- 五 [[laws/再生医療等の安全性の確保等に関する法律/本文/第16条.md|第十六条]]第二項の規定に違反して記録を保存しなかったとき。
- 六 [[laws/再生医療等の安全性の確保等に関する法律/本文/第23条.md|第二十三条]]第二項（第一種再生医療等に係る部分を除く。）の規定による命令に違反したとき。
- 七 [[laws/再生医療等の安全性の確保等に関する法律/本文/第24条.md|第二十四条]]第一項若しくは第二項の報告をせず、若しくは虚偽の報告をし、同条第一項若しくは第二項の規定による立入検査を拒み、妨げ、若しくは忌避し、又は同条第一項若しくは第二項の規定による質問に対し、正当な理由なしに答弁せず、若しくは虚偽の答弁をしたとき。
