# 第三条 （国庫負担）

## 
国は、法令により地方公共団体（港湾法（昭和二十五年法律第二百十八号）に基づく港務局を含む。次条、[[laws/公共土木施設災害復旧事業費国庫負担法/本文/第4条の2.md|第四条の二]]及び[[laws/公共土木施設災害復旧事業費国庫負担法/本文/第6条.md|第六条]]第一項を除き、以下同じ。）又はその機関の維持管理に属する次に掲げる施設のうち政令で定める公共土木施設に関する災害の災害復旧事業で、当該地方公共団体又はその機関が施行するものについては、その事業費の一部を負担する。河川海岸砂防設備林地荒廃防止施設地すべり防止施設急傾斜地崩壊防止施設道路港湾漁港水道下水道公園

- 一 河川
- 二 海岸
- 三 砂防設備
- 四 林地荒廃防止施設
- 五 地すべり防止施設
- 六 急傾斜地崩壊防止施設
- 七 道路
- 八 港湾
- 九 漁港
- 十 水道
- 十一 下水道
- 十二 公園
