# 第二十七条 

## 
次の各号のいずれかに該当する場合には、その違反行為をした指定会社の取締役、執行役、会計参与若しくはその職務を行うべき社員又は監査役は、百万円以下の過料に処する。[[laws/中部国際空港の設置及び管理に関する法律/本文/第5条.md|第五条]]第四項の規定に違反して、新株若しくは募集新株予約権を引き受ける者の募集をし、又は株式交換若しくは株式交付に際して株式若しくは新株予約権を発行したとき。[[laws/中部国際空港の設置及び管理に関する法律/本文/第5条.md|第五条]]第五項の規定に違反して、株式を発行した旨の届出を行わなかったとき。[[laws/中部国際空港の設置及び管理に関する法律/本文/第6条.md|第六条]]第二項の規定に違反して、事業を行ったとき。[[laws/中部国際空港の設置及び管理に関する法律/本文/第14条.md|第十四条]]の規定に違反して、事業計画の認可を受けなかったとき。[[laws/中部国際空港の設置及び管理に関する法律/本文/第15条.md|第十五条]]第一項の規定に違反して、募集社債を引き受ける者の募集をし、株式交換若しくは株式交付に際して社債を発行し、又は資金を借り入れたとき。[[laws/中部国際空港の設置及び管理に関する法律/本文/第16条.md|第十六条]]の規定に違反して、財産を譲渡し、又は担保に供したとき。[[laws/中部国際空港の設置及び管理に関する法律/本文/第18条.md|第十八条]]の規定に違反して、貸借対照表、損益計算書若しくは事業報告書を提出せず、又は不実の記載若しくは記録をしたこれらのものを提出したとき。[[laws/中部国際空港の設置及び管理に関する法律/本文/第19条.md|第十九条]]の規定による命令に違反したとき。

- 一 [[laws/中部国際空港の設置及び管理に関する法律/本文/第5条.md|第五条]]第四項の規定に違反して、新株若しくは募集新株予約権を引き受ける者の募集をし、又は株式交換若しくは株式交付に際して株式若しくは新株予約権を発行したとき。
- 二 [[laws/中部国際空港の設置及び管理に関する法律/本文/第5条.md|第五条]]第五項の規定に違反して、株式を発行した旨の届出を行わなかったとき。
- 三 [[laws/中部国際空港の設置及び管理に関する法律/本文/第6条.md|第六条]]第二項の規定に違反して、事業を行ったとき。
- 四 [[laws/中部国際空港の設置及び管理に関する法律/本文/第14条.md|第十四条]]の規定に違反して、事業計画の認可を受けなかったとき。
- 五 [[laws/中部国際空港の設置及び管理に関する法律/本文/第15条.md|第十五条]]第一項の規定に違反して、募集社債を引き受ける者の募集をし、株式交換若しくは株式交付に際して社債を発行し、又は資金を借り入れたとき。
- 六 [[laws/中部国際空港の設置及び管理に関する法律/本文/第16条.md|第十六条]]の規定に違反して、財産を譲渡し、又は担保に供したとき。
- 七 [[laws/中部国際空港の設置及び管理に関する法律/本文/第18条.md|第十八条]]の規定に違反して、貸借対照表、損益計算書若しくは事業報告書を提出せず、又は不実の記載若しくは記録をしたこれらのものを提出したとき。
- 八 [[laws/中部国際空港の設置及び管理に関する法律/本文/第19条.md|第十九条]]の規定による命令に違反したとき。
