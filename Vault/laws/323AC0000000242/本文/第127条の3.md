# 第百二十七条の三 （財務大臣への通知）

## 
内閣総理大臣は、[[laws/水産業協同組合法/本文/第11条.md|第十一条]]第一項第四号、[[laws/水産業協同組合法/本文/第87条.md|第八十七条]]第一項第四号、[[laws/水産業協同組合法/本文/第93条.md|第九十三条]]第一項第二号又は[[laws/水産業協同組合法/本文/第97条.md|第九十七条]]第一項第二号の事業を行う組合に対し次に掲げる処分をしたときは、速やかに、その旨を財務大臣に通知するものとする。[[laws/水産業協同組合法/本文/第11条の5.md|第十一条の五]]第一項又は第三項（同項の規定にあつては、信用事業規程の廃止に係る場合に限る。）（これらの規定を[[laws/水産業協同組合法/本文/第92条.md|第九十二条]]第一項、[[laws/水産業協同組合法/本文/第96条.md|第九十六条]]第一項及び[[laws/水産業協同組合法/本文/第100条.md|第百条]]第一項において準用する場合を含む。）の規定による認可[[laws/水産業協同組合法/本文/第64条.md|第六十四条]]の規定による設立の認可[[laws/水産業協同組合法/本文/第68条.md|第六十八条]]第二項（[[laws/水産業協同組合法/本文/第96条.md|第九十六条]]第五項において準用する場合を含む。）、[[laws/水産業協同組合法/本文/第69条.md|第六十九条]]第二項（[[laws/水産業協同組合法/本文/第91条の2.md|第九十一条の二]]第二項（[[laws/水産業協同組合法/本文/第100条.md|第百条]]第五項において準用する場合を含む。）、[[laws/水産業協同組合法/本文/第92条.md|第九十二条]]第五項、[[laws/水産業協同組合法/本文/第96条.md|第九十六条]]第五項及び[[laws/水産業協同組合法/本文/第100条.md|第百条]]第五項において準用する場合を含む。）又は[[laws/水産業協同組合法/本文/第91条.md|第九十一条]]第二項（[[laws/水産業協同組合法/本文/第100条.md|第百条]]第五項において準用する場合を含む。）の規定による認可[[laws/水産業協同組合法/本文/第91条.md|第九十一条]]第五項第二号（[[laws/水産業協同組合法/本文/第100条.md|第百条]]第五項において準用する場合を含む。）に規定する不認可の処分[[laws/水産業協同組合法/本文/第123条の2.md|第百二十三条の二]]第一項若しくは第二項又は[[laws/水産業協同組合法/本文/第124条.md|第百二十四条]]第一項若しくは第二項の規定による命令（改善計画の提出を求めることを含み、信用事業に関するものに限る。）[[laws/水産業協同組合法/本文/第124条.md|第百二十四条]]第三項の規定による[[laws/水産業協同組合法/本文/第11条の5.md|第十一条の五]]第一項の認可の取消し[[laws/水産業協同組合法/本文/第124条の2.md|第百二十四条の二]]の規定による解散の命令

- 一 [[laws/水産業協同組合法/本文/第11条の5.md|第十一条の五]]第一項又は第三項（同項の規定にあつては、信用事業規程の廃止に係る場合に限る。）（これらの規定を[[laws/水産業協同組合法/本文/第92条.md|第九十二条]]第一項、[[laws/水産業協同組合法/本文/第96条.md|第九十六条]]第一項及び[[laws/水産業協同組合法/本文/第100条.md|第百条]]第一項において準用する場合を含む。）の規定による認可
- 二 [[laws/水産業協同組合法/本文/第64条.md|第六十四条]]の規定による設立の認可
- 三 [[laws/水産業協同組合法/本文/第68条.md|第六十八条]]第二項（[[laws/水産業協同組合法/本文/第96条.md|第九十六条]]第五項において準用する場合を含む。）、[[laws/水産業協同組合法/本文/第69条.md|第六十九条]]第二項（[[laws/水産業協同組合法/本文/第91条の2.md|第九十一条の二]]第二項（[[laws/水産業協同組合法/本文/第100条.md|第百条]]第五項において準用する場合を含む。）、[[laws/水産業協同組合法/本文/第92条.md|第九十二条]]第五項、[[laws/水産業協同組合法/本文/第96条.md|第九十六条]]第五項及び[[laws/水産業協同組合法/本文/第100条.md|第百条]]第五項において準用する場合を含む。）又は[[laws/水産業協同組合法/本文/第91条.md|第九十一条]]第二項（[[laws/水産業協同組合法/本文/第100条.md|第百条]]第五項において準用する場合を含む。）の規定による認可
- 四 [[laws/水産業協同組合法/本文/第91条.md|第九十一条]]第五項第二号（[[laws/水産業協同組合法/本文/第100条.md|第百条]]第五項において準用する場合を含む。）に規定する不認可の処分
- 五 [[laws/水産業協同組合法/本文/第123条の2.md|第百二十三条の二]]第一項若しくは第二項又は[[laws/水産業協同組合法/本文/第124条.md|第百二十四条]]第一項若しくは第二項の規定による命令（改善計画の提出を求めることを含み、信用事業に関するものに限る。）
- 六 [[laws/水産業協同組合法/本文/第124条.md|第百二十四条]]第三項の規定による[[laws/水産業協同組合法/本文/第11条の5.md|第十一条の五]]第一項の認可の取消し
- 七 [[laws/水産業協同組合法/本文/第124条の2.md|第百二十四条の二]]の規定による解散の命令
