# 第二十三条 （特定投資家の範囲）

## 
法[[laws/金融商品取引法第二条に規定する定義に関する内閣府令/本文/第2条.md|第二条]]第三十一項第四号に規定する内閣府令で定める法人は、次に掲げるものとする。特別の法律により特別の設立行為をもって設立された法人法[[laws/金融商品取引法第二条に規定する定義に関する内閣府令/本文/第79条の21.md|第七十九条の二十一]]に規定する投資者保護基金預金保険機構農水産業協同組合貯金保険機構保険業法[[laws/保険業法/本文/第259条.md|第二百五十九条]]に規定する保険契約者保護機構特定目的会社金融商品取引所に上場されている株券の発行者である会社取引の状況その他の事情から合理的に判断して資本金の額が五億円以上であると見込まれる株式会社金融商品取引業者、法[[laws/保険業法/本文/第63条.md|第六十三条]]第五項に規定する特例業務届出者又は法[[laws/保険業法/本文/第63条の9.md|第六十三条の九]]第四項に規定する海外投資家等特例業務届出者である法人外国法人

- 一 特別の法律により特別の設立行為をもって設立された法人
- 二 法[[laws/金融商品取引法第二条に規定する定義に関する内閣府令/本文/第79条の21.md|第七十九条の二十一]]に規定する投資者保護基金
- 三 預金保険機構
- 四 農水産業協同組合貯金保険機構
- 五 保険業法第二百五十九条に規定する保険契約者保護機構
- 六 特定目的会社
- 七 金融商品取引所に上場されている株券の発行者である会社
- 八 取引の状況その他の事情から合理的に判断して資本金の額が五億円以上であると見込まれる株式会社
- 九 金融商品取引業者、法[[laws/金融商品取引法第二条に規定する定義に関する内閣府令/本文/第63条.md|第六十三条]]第五項に規定する特例業務届出者又は法[[laws/金融商品取引法第二条に規定する定義に関する内閣府令/本文/第63条の9.md|第六十三条の九]]第四項に規定する海外投資家等特例業務届出者である法人
- 十 外国法人
