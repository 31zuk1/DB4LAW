# 第十一条の三の三 （構成組合に行わせることができる業務）

## 
令[[laws/地方公務員等共済組合法施行規則/本文/第17条の2.md|第十七条の二]]第一項第六号に規定する総務省令で定める業務は、次に掲げる業務とする。厚生年金保険法[[laws/地方公務員等共済組合法施行規則/本文/第78条の2.md|第七十八条の二]]第二項に規定する標準報酬改定請求の受理及びその請求に係る事実についての審査を行うこと。厚生年金保険法[[laws/地方公務員等共済組合法施行規則/本文/第78条の4.md|第七十八条の四]]第一項に規定する標準報酬改定請求を行うために必要な情報の提供の請求の受理及び当該情報を提供すること。厚生年金保険法[[laws/地方公務員等共済組合法施行規則/本文/第78条の5.md|第七十八条の五]]に規定する必要な資料を提供すること。厚生年金保険法[[laws/地方公務員等共済組合法施行規則/本文/第78条の14.md|第七十八条の十四]]第一項に規定する特定被保険者及び被扶養配偶者についての標準報酬の改定又は決定に係る請求の受理及びその請求に係る事実についての審査を行うこと。平成二十四年一元化法附則第六十三条第一項各号に規定する退職一時金及びその給付に係る利子に相当する額の返還を請求し、若しくはこれを受け、又はその額に相当する金額を厚生年金保険給付から控除することにより返還する旨の申出を受けること。法[[laws/地方公務員等共済組合法施行規則/本文/第144条の25.md|第百四十四条の二十五]]の二及び厚生年金保険法[[laws/地方公務員等共済組合法施行規則/本文/第100条の2.md|第百条の二]]の規定に係る資料を作成すること。国民年金法[[laws/地方公務員等共済組合法施行規則/本文/第108条.md|第百八条]]第一項及び第二項並びに同法附則第八条に規定する資料を作成すること。施行規程[[laws/地方公務員等共済組合法施行規則/本文/第91条の3.md|第九十一条の三]]第一項に規定するみなし組合員原票を備え、必要な事項を記載して整理すること。施行規程[[laws/地方公務員等共済組合法施行規則/本文/第91条の5.md|第九十一条の五]]第一項に規定する被扶養配偶者みなし組合員原票を備え、必要な事項を記載して整理すること。施行規程第四章第一節及び第三節に規定する請求書、申請書、申出書又は届書の受理及びこれらの書類に係る事実についての審査を行うこと。施行規程[[laws/地方公務員等共済組合法施行規則/本文/第121条.md|第百二十一条]]第二項、第百二十二条、第百五十五条第一項及び第百五十六条第二項の規定に基づき年金証書を交付すること。法による長期給付（第五号に規定する退職一時金を除く。）の過誤払いの返還を請求し、若しくはこれを受け、又は法による年金である給付から控除することにより返還する旨の申出を受けること。

- 一 厚生年金保険法[[laws/地方公務員等共済組合法施行規則/本文/第78条の2.md|第七十八条の二]]第二項に規定する標準報酬改定請求の受理及びその請求に係る事実についての審査を行うこと。
- 二 厚生年金保険法[[laws/地方公務員等共済組合法施行規則/本文/第78条の4.md|第七十八条の四]]第一項に規定する標準報酬改定請求を行うために必要な情報の提供の請求の受理及び当該情報を提供すること。
- 三 厚生年金保険法[[laws/地方公務員等共済組合法施行規則/本文/第78条の5.md|第七十八条の五]]に規定する必要な資料を提供すること。
- 四 厚生年金保険法[[laws/地方公務員等共済組合法施行規則/本文/第78条の14.md|第七十八条の十四]]第一項に規定する特定被保険者及び被扶養配偶者についての標準報酬の改定又は決定に係る請求の受理及びその請求に係る事実についての審査を行うこと。
- 五 平成二十四年一元化法附則第六十三条第一項各号に規定する退職一時金及びその給付に係る利子に相当する額の返還を請求し、若しくはこれを受け、又はその額に相当する金額を厚生年金保険給付から控除することにより返還する旨の申出を受けること。
- 六 法[[laws/地方公務員等共済組合法施行規則/本文/第144条の25.md|第百四十四条の二十五]]の二及び厚生年金保険法[[laws/地方公務員等共済組合法施行規則/本文/第100条の2.md|第百条の二]]の規定に係る資料を作成すること。
- 七 国民年金法[[laws/地方公務員等共済組合法施行規則/本文/第108条.md|第百八条]]第一項及び第二項並びに同法附則第八条に規定する資料を作成すること。
- 八 施行規程[[laws/地方公務員等共済組合法施行規則/本文/第91条の3.md|第九十一条の三]]第一項に規定するみなし組合員原票を備え、必要な事項を記載して整理すること。
- 九 施行規程[[laws/地方公務員等共済組合法施行規則/本文/第91条の5.md|第九十一条の五]]第一項に規定する被扶養配偶者みなし組合員原票を備え、必要な事項を記載して整理すること。
- 十 施行規程第四章第一節及び第三節に規定する請求書、申請書、申出書又は届書の受理及びこれらの書類に係る事実についての審査を行うこと。
- 十一 施行規程[[laws/地方公務員等共済組合法施行規則/本文/第121条.md|第百二十一条]]第二項、[[laws/地方公務員等共済組合法施行規則/本文/第122条.md|第百二十二条]]、[[laws/地方公務員等共済組合法施行規則/本文/第155条.md|第百五十五条]]第一項及び[[laws/地方公務員等共済組合法施行規則/本文/第156条.md|第百五十六条]]第二項の規定に基づき年金証書を交付すること。
- 十二 法による長期給付（第五号に規定する退職一時金を除く。）の過誤払いの返還を請求し、若しくはこれを受け、又は法による年金である給付から控除することにより返還する旨の申出を受けること。
