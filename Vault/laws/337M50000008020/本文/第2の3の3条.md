# 第二条の三の三 （一部負担金の額の特例に係る特別の事情）

## 
法[[laws/地方公務員等共済組合法施行規則/本文/第57条の2.md|第五十七条の二]]第一項に規定する総務省令で定める特別の事情は、健康保険法[[laws/地方公務員等共済組合法施行規則/本文/第75条の2.md|第七十五条の二]]第一項に規定する厚生労働省令で定める特別の事情とする。
