# 第四十九条 

## 
次の各号のいずれかに該当する者は、三十万円以下の罰金に処する。[[laws/商品投資に係る事業の規制に関する法律/本文/第10条.md|第十条]]の規定による届出をせず、又は虚偽の届出をした者[[laws/商品投資に係る事業の規制に関する法律/本文/第13条.md|第十三条]]第一項の規定に違反して、主務省令で定める様式の標識を掲示せず、又は公衆の閲覧に供しなかった者[[laws/商品投資に係る事業の規制に関する法律/本文/第13条.md|第十三条]]第二項の規定に違反して、同条第一項の標識又はこれに類似する標識を掲示し、又は公衆の閲覧に供した者[[laws/商品投資に係る事業の規制に関する法律/本文/第23条.md|第二十三条]]の規定に違反して、書類を備え置かず、若しくは顧客の求めに応じて閲覧させず、又は虚偽の記載のある書類を備え置き、若しくは顧客に閲覧させた者[[laws/商品投資に係る事業の規制に関する法律/本文/第24条.md|第二十四条]]第二項の規定に違反して、相当の理由がないのに、帳簿書類の閲覧又は謄写の請求を拒んだ者[[laws/商品投資に係る事業の規制に関する法律/本文/第29条.md|第二十九条]]の規定による帳簿書類の作成若しくは保存をせず、又は虚偽の帳簿書類の作成をした者[[laws/商品投資に係る事業の規制に関する法律/本文/第30条.md|第三十条]]第一項（[[laws/商品投資に係る事業の規制に関する法律/本文/第37条.md|第三十七条]]において準用する場合を含む。）の規定による報告をせず、若しくは虚偽の報告をし、又は同項の規定による検査を拒み、妨げ、若しくは忌避した者[[laws/商品投資に係る事業の規制に関する法律/本文/第31条.md|第三十一条]]の規定による命令に違反した者

- 一 [[laws/商品投資に係る事業の規制に関する法律/本文/第10条.md|第十条]]の規定による届出をせず、又は虚偽の届出をした者
- 二 [[laws/商品投資に係る事業の規制に関する法律/本文/第13条.md|第十三条]]第一項の規定に違反して、主務省令で定める様式の標識を掲示せず、又は公衆の閲覧に供しなかった者
- 三 [[laws/商品投資に係る事業の規制に関する法律/本文/第13条.md|第十三条]]第二項の規定に違反して、同条第一項の標識又はこれに類似する標識を掲示し、又は公衆の閲覧に供した者
- 四 [[laws/商品投資に係る事業の規制に関する法律/本文/第23条.md|第二十三条]]の規定に違反して、書類を備え置かず、若しくは顧客の求めに応じて閲覧させず、又は虚偽の記載のある書類を備え置き、若しくは顧客に閲覧させた者
- 五 [[laws/商品投資に係る事業の規制に関する法律/本文/第24条.md|第二十四条]]第二項の規定に違反して、相当の理由がないのに、帳簿書類の閲覧又は謄写の請求を拒んだ者
- 六 [[laws/商品投資に係る事業の規制に関する法律/本文/第29条.md|第二十九条]]の規定による帳簿書類の作成若しくは保存をせず、又は虚偽の帳簿書類の作成をした者
- 七 [[laws/商品投資に係る事業の規制に関する法律/本文/第30条.md|第三十条]]第一項（[[laws/商品投資に係る事業の規制に関する法律/本文/第37条.md|第三十七条]]において準用する場合を含む。）の規定による報告をせず、若しくは虚偽の報告をし、又は同項の規定による検査を拒み、妨げ、若しくは忌避した者
- 八 [[laws/商品投資に係る事業の規制に関する法律/本文/第31条.md|第三十一条]]の規定による命令に違反した者
