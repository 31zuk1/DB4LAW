# 第四十九条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、五年以下の拘禁刑若しくは千万円以下の罰金に処し、又はこれを併科する。[[laws/323AC0000000122/本文/第3条.md|第三条]]第一項の規定に違反して同項の許可を受けないで風俗営業を営んだとき。偽りその他不正の手段により[[laws/323AC0000000122/本文/第3条.md|第三条]]第一項の許可又は[[laws/323AC0000000122/本文/第7条.md|第七条]]第一項、[[laws/323AC0000000122/本文/第7条の2.md|第七条の二]]第一項若しくは[[laws/323AC0000000122/本文/第7条の3.md|第七条の三]]第一項の承認を受けたとき。[[laws/323AC0000000122/本文/第11条.md|第十一条]]の規定に違反したとき。[[laws/323AC0000000122/本文/第26条.md|第二十六条]]、[[laws/323AC0000000122/本文/第30条.md|第三十条]]、[[laws/323AC0000000122/本文/第31条の5.md|第三十一条の五]]第一項若しくは第二項又は[[laws/323AC0000000122/本文/第31条の6.md|第三十一条の六]]第二項第二号若しくは第三号の規定による公安委員会の処分に違反したとき。[[laws/323AC0000000122/本文/第28条.md|第二十八条]]第一項（[[laws/323AC0000000122/本文/第31条の3.md|第三十一条の三]]第二項の規定により適用する場合を含む。）の規定に違反したとき。[[laws/323AC0000000122/本文/第28条.md|第二十八条]]第二項（[[laws/323AC0000000122/本文/第31条の3.md|第三十一条の三]]第二項の規定により適用する場合を含む。）の規定に基づく都道府県の条例の規定に違反したとき。

- 一 [[laws/323AC0000000122/本文/第3条.md|第三条]]第一項の規定に違反して同項の許可を受けないで風俗営業を営んだとき。
- 二 偽りその他不正の手段により[[laws/323AC0000000122/本文/第3条.md|第三条]]第一項の許可又は[[laws/323AC0000000122/本文/第7条.md|第七条]]第一項、[[laws/323AC0000000122/本文/第7条の2.md|第七条の二]]第一項若しくは[[laws/323AC0000000122/本文/第7条の3.md|第七条の三]]第一項の承認を受けたとき。
- 三 [[laws/323AC0000000122/本文/第11条.md|第十一条]]の規定に違反したとき。
- 四 [[laws/323AC0000000122/本文/第26条.md|第二十六条]]、[[laws/323AC0000000122/本文/第30条.md|第三十条]]、[[laws/323AC0000000122/本文/第31条の5.md|第三十一条の五]]第一項若しくは第二項又は[[laws/323AC0000000122/本文/第31条の6.md|第三十一条の六]]第二項第二号若しくは第三号の規定による公安委員会の処分に違反したとき。
- 五 [[laws/323AC0000000122/本文/第28条.md|第二十八条]]第一項（[[laws/323AC0000000122/本文/第31条の3.md|第三十一条の三]]第二項の規定により適用する場合を含む。）の規定に違反したとき。
- 六 [[laws/323AC0000000122/本文/第28条.md|第二十八条]]第二項（[[laws/323AC0000000122/本文/第31条の3.md|第三十一条の三]]第二項の規定により適用する場合を含む。）の規定に基づく都道府県の条例の規定に違反したとき。
