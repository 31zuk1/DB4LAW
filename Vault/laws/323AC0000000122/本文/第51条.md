# 第五十一条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、一年以下の拘禁刑若しくは百万円以下の罰金に処し、又はこれを併科する。[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第9条.md|第九条]]第一項（[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第20条.md|第二十条]]第十項及び[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第31条の23.md|第三十一条の二十三]]において準用する場合を含む。以下この号及び次号において同じ。）の規定に違反して[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第9条.md|第九条]]第一項の承認を受けないで営業所の構造又は設備（[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第4条.md|第四条]]第四項に規定する遊技機を含む。）の変更をしたとき。偽りその他不正の手段により[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第9条.md|第九条]]第一項の承認を受けたとき。偽りその他不正の手段により[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第10条の2.md|第十条の二]]第一項（[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第31条の23.md|第三十一条の二十三]]において準用する場合を含む。）の認定を受けたとき。[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第22条.md|第二十二条]]第一項第三号の規定又は同項第四号から第六号まで（これらの規定を[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第31条の23.md|第三十一条の二十三]]及び[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第32条.md|第三十二条]]第三項において準用する場合を含む。）の規定に違反したとき。[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第28条.md|第二十八条]]第十二項第三号の規定又は同項第四号若しくは第五号（これらの規定を[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第31条の3.md|第三十一条の三]]第二項の規定により適用する場合を含む。）の規定に違反したとき。[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第31条の3.md|第三十一条の三]]第三項第一号の規定に違反したとき。[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第31条の10.md|第三十一条の十]]又は[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第31条の11.md|第三十一条の十一]]第二項第二号の規定による公安委員会の命令に従わなかつたとき。[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第31条の13.md|第三十一条の十三]]第二項第三号から第六号までの規定に違反したとき。[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第31条の18.md|第三十一条の十八]]第二項第一号の規定に違反したとき。[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第33条.md|第三十三条]]第四項の規定に基づく都道府県の条例の規定に違反したとき。

- 一 [[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第9条.md|第九条]]第一項（[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第20条.md|第二十条]]第十項及び[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第31条の23.md|第三十一条の二十三]]において準用する場合を含む。以下この号及び次号において同じ。）の規定に違反して[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第9条.md|第九条]]第一項の承認を受けないで営業所の構造又は設備（[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第4条.md|第四条]]第四項に規定する遊技機を含む。）の変更をしたとき。
- 二 偽りその他不正の手段により[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第9条.md|第九条]]第一項の承認を受けたとき。
- 三 偽りその他不正の手段により[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第10条の2.md|第十条の二]]第一項（[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第31条の23.md|第三十一条の二十三]]において準用する場合を含む。）の認定を受けたとき。
- 四 [[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第22条.md|第二十二条]]第一項第三号の規定又は同項第四号から第六号まで（これらの規定を[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第31条の23.md|第三十一条の二十三]]及び[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第32条.md|第三十二条]]第三項において準用する場合を含む。）の規定に違反したとき。
- 五 [[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第28条.md|第二十八条]]第十二項第三号の規定又は同項第四号若しくは第五号（これらの規定を[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第31条の3.md|第三十一条の三]]第二項の規定により適用する場合を含む。）の規定に違反したとき。
- 六 [[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第31条の3.md|第三十一条の三]]第三項第一号の規定に違反したとき。
- 七 [[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第31条の10.md|第三十一条の十]]又は[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第31条の11.md|第三十一条の十一]]第二項第二号の規定による公安委員会の命令に従わなかつたとき。
- 八 [[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第31条の13.md|第三十一条の十三]]第二項第三号から第六号までの規定に違反したとき。
- 九 [[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第31条の18.md|第三十一条の十八]]第二項第一号の規定に違反したとき。
- 十 [[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第33条.md|第三十三条]]第四項の規定に基づく都道府県の条例の規定に違反したとき。
## ２
[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第22条.md|第二十二条]]第一項第三号若しくは第四号（[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第31条の23.md|第三十一条の二十三]]及び[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第32条.md|第三十二条]]第三項において準用する場合を含む。）、[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第28条.md|第二十八条]]第十二項第三号、[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第31条の3.md|第三十一条の三]]第三項第一号、[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第31条の13.md|第三十一条の十三]]第二項第三号若しくは第四号又は[[laws/風俗営業等の規制及び業務の適正化等に関する法律/本文/第31条の18.md|第三十一条の十八]]第二項第一号に掲げる行為をした者は、当該十八歳未満の者の年齢を知らないことを理由として、前項の規定による処罰を免れることができない。ただし、過失のないときは、この限りでない。
