# 第五十五条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、五十万円以下の罰金に処する。[[laws/323AC0000000122/本文/第5条.md|第五条]]第一項（[[laws/323AC0000000122/本文/第31条の23.md|第三十一条の二十三]]において準用する場合を含む。）の許可申請書又は添付書類であつて虚偽の記載のあるものを提出したとき。[[laws/323AC0000000122/本文/第9条.md|第九条]]第五項後段（[[laws/323AC0000000122/本文/第31条の23.md|第三十一条の二十三]]において準用する場合を含む。以下この号において同じ。）の規定に違反して、届出書を提出せず、又は同項後段の届出書若しくは添付書類であつて虚偽の記載のあるものを提出したとき。[[laws/323AC0000000122/本文/第10条の2.md|第十条の二]]第二項（[[laws/323AC0000000122/本文/第31条の23.md|第三十一条の二十三]]において準用する場合を含む。）の認定申請書又は添付書類であつて虚偽の記載のあるものを提出したとき。[[laws/323AC0000000122/本文/第23条.md|第二十三条]]第一項第三号又は第四号（これらの規定を同条第三項において準用する場合を含む。）の規定に違反したとき。[[laws/323AC0000000122/本文/第24条.md|第二十四条]]第一項（[[laws/323AC0000000122/本文/第31条の23.md|第三十一条の二十三]]において準用する場合を含む。）の規定に違反したとき。[[laws/323AC0000000122/本文/第27条.md|第二十七条]]第二項（[[laws/323AC0000000122/本文/第31条の12.md|第三十一条の十二]]第二項において準用する場合を含む。以下この号において同じ。）、[[laws/323AC0000000122/本文/第31条の2.md|第三十一条の二]]第二項（[[laws/323AC0000000122/本文/第31条の7.md|第三十一条の七]]第二項及び[[laws/323AC0000000122/本文/第31条の17.md|第三十一条の十七]]第二項において準用する場合を含む。以下この号において同じ。）又は[[laws/323AC0000000122/本文/第33条.md|第三十三条]]第一項の規定に違反して、届出書を提出せず、又は[[laws/323AC0000000122/本文/第27条.md|第二十七条]]第二項、[[laws/323AC0000000122/本文/第31条の2.md|第三十一条の二]]第二項若しくは[[laws/323AC0000000122/本文/第33条.md|第三十三条]]第一項の届出書若しくはこれらの届出書に係る[[laws/323AC0000000122/本文/第27条.md|第二十七条]]第三項（[[laws/323AC0000000122/本文/第31条の12.md|第三十一条の十二]]第二項において準用する場合を含む。）、[[laws/323AC0000000122/本文/第31条の2.md|第三十一条の二]]第三項（[[laws/323AC0000000122/本文/第31条の7.md|第三十一条の七]]第二項及び[[laws/323AC0000000122/本文/第31条の17.md|第三十一条の十七]]第二項において準用する場合を含む。）若しくは[[laws/323AC0000000122/本文/第33条.md|第三十三条]]第三項の添付書類であつて虚偽の記載のあるものを提出したとき。

- 一 [[laws/323AC0000000122/本文/第5条.md|第五条]]第一項（[[laws/323AC0000000122/本文/第31条の23.md|第三十一条の二十三]]において準用する場合を含む。）の許可申請書又は添付書類であつて虚偽の記載のあるものを提出したとき。
- 二 [[laws/323AC0000000122/本文/第9条.md|第九条]]第五項後段（[[laws/323AC0000000122/本文/第31条の23.md|第三十一条の二十三]]において準用する場合を含む。以下この号において同じ。）の規定に違反して、届出書を提出せず、又は同項後段の届出書若しくは添付書類であつて虚偽の記載のあるものを提出したとき。
- 三 [[laws/323AC0000000122/本文/第10条の2.md|第十条の二]]第二項（[[laws/323AC0000000122/本文/第31条の23.md|第三十一条の二十三]]において準用する場合を含む。）の認定申請書又は添付書類であつて虚偽の記載のあるものを提出したとき。
- 四 [[laws/323AC0000000122/本文/第23条.md|第二十三条]]第一項第三号又は第四号（これらの規定を同条第三項において準用する場合を含む。）の規定に違反したとき。
- 五 [[laws/323AC0000000122/本文/第24条.md|第二十四条]]第一項（[[laws/323AC0000000122/本文/第31条の23.md|第三十一条の二十三]]において準用する場合を含む。）の規定に違反したとき。
- 六 [[laws/323AC0000000122/本文/第27条.md|第二十七条]]第二項（[[laws/323AC0000000122/本文/第31条の12.md|第三十一条の十二]]第二項において準用する場合を含む。以下この号において同じ。）、[[laws/323AC0000000122/本文/第31条の2.md|第三十一条の二]]第二項（[[laws/323AC0000000122/本文/第31条の7.md|第三十一条の七]]第二項及び[[laws/323AC0000000122/本文/第31条の17.md|第三十一条の十七]]第二項において準用する場合を含む。以下この号において同じ。）又は[[laws/323AC0000000122/本文/第33条.md|第三十三条]]第一項の規定に違反して、届出書を提出せず、又は[[laws/323AC0000000122/本文/第27条.md|第二十七条]]第二項、[[laws/323AC0000000122/本文/第31条の2.md|第三十一条の二]]第二項若しくは[[laws/323AC0000000122/本文/第33条.md|第三十三条]]第一項の届出書若しくはこれらの届出書に係る[[laws/323AC0000000122/本文/第27条.md|第二十七条]]第三項（[[laws/323AC0000000122/本文/第31条の12.md|第三十一条の十二]]第二項において準用する場合を含む。）、[[laws/323AC0000000122/本文/第31条の2.md|第三十一条の二]]第三項（[[laws/323AC0000000122/本文/第31条の7.md|第三十一条の七]]第二項及び[[laws/323AC0000000122/本文/第31条の17.md|第三十一条の十七]]第二項において準用する場合を含む。）若しくは[[laws/323AC0000000122/本文/第33条.md|第三十三条]]第三項の添付書類であつて虚偽の記載のあるものを提出したとき。
