# 第五十三条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、六月以下の拘禁刑若しくは百万円以下の罰金に処し、又はこれを併科する。[[laws/323AC0000000122/本文/第22条.md|第二十二条]]第一項第一号若しくは第二号（これらの規定を[[laws/323AC0000000122/本文/第31条の23.md|第三十一条の二十三]]及び[[laws/323AC0000000122/本文/第32条.md|第三十二条]]第三項において準用する場合を含む。）、[[laws/323AC0000000122/本文/第28条.md|第二十八条]]第十二項第一号若しくは第二号（これらの規定を[[laws/323AC0000000122/本文/第31条の3.md|第三十一条の三]]第二項の規定により適用する場合を含む。）又は[[laws/323AC0000000122/本文/第31条の13.md|第三十一条の十三]]第二項第一号若しくは第二号の規定に違反したとき。[[laws/323AC0000000122/本文/第22条の2.md|第二十二条の二]]の規定に違反したとき。[[laws/323AC0000000122/本文/第23条.md|第二十三条]]第一項第一号又は第二号の規定に違反したとき。[[laws/323AC0000000122/本文/第23条.md|第二十三条]]第二項の規定に違反したとき。[[laws/323AC0000000122/本文/第27条.md|第二十七条]]第一項、[[laws/323AC0000000122/本文/第31条の2.md|第三十一条の二]]第一項、[[laws/323AC0000000122/本文/第31条の7.md|第三十一条の七]]第一項、[[laws/323AC0000000122/本文/第31条の12.md|第三十一条の十二]]第一項又は[[laws/323AC0000000122/本文/第31条の17.md|第三十一条の十七]]第一項の届出書を提出しないで性風俗関連特殊営業を営んだとき。前号に規定する届出書又はこれらの届出書に係る[[laws/323AC0000000122/本文/第27条.md|第二十七条]]第三項（[[laws/323AC0000000122/本文/第31条の12.md|第三十一条の十二]]第二項において準用する場合を含む。）若しくは[[laws/323AC0000000122/本文/第31条の2.md|第三十一条の二]]第三項（[[laws/323AC0000000122/本文/第31条の7.md|第三十一条の七]]第二項及び[[laws/323AC0000000122/本文/第31条の17.md|第三十一条の十七]]第二項において準用する場合を含む。）の添付書類であつて虚偽の記載のあるものを提出したとき。[[laws/323AC0000000122/本文/第28条.md|第二十八条]]第十三項（[[laws/323AC0000000122/本文/第31条の3.md|第三十一条の三]]第一項において準用する場合を含む。）の規定に違反したとき。

- 一 [[laws/323AC0000000122/本文/第22条.md|第二十二条]]第一項第一号若しくは第二号（これらの規定を[[laws/323AC0000000122/本文/第31条の23.md|第三十一条の二十三]]及び[[laws/323AC0000000122/本文/第32条.md|第三十二条]]第三項において準用する場合を含む。）、[[laws/323AC0000000122/本文/第28条.md|第二十八条]]第十二項第一号若しくは第二号（これらの規定を[[laws/323AC0000000122/本文/第31条の3.md|第三十一条の三]]第二項の規定により適用する場合を含む。）又は[[laws/323AC0000000122/本文/第31条の13.md|第三十一条の十三]]第二項第一号若しくは第二号の規定に違反したとき。
- 二 [[laws/323AC0000000122/本文/第22条の2.md|第二十二条の二]]の規定に違反したとき。
- 三 [[laws/323AC0000000122/本文/第23条.md|第二十三条]]第一項第一号又は第二号の規定に違反したとき。
- 四 [[laws/323AC0000000122/本文/第23条.md|第二十三条]]第二項の規定に違反したとき。
- 五 [[laws/323AC0000000122/本文/第27条.md|第二十七条]]第一項、[[laws/323AC0000000122/本文/第31条の2.md|第三十一条の二]]第一項、[[laws/323AC0000000122/本文/第31条の7.md|第三十一条の七]]第一項、[[laws/323AC0000000122/本文/第31条の12.md|第三十一条の十二]]第一項又は[[laws/323AC0000000122/本文/第31条の17.md|第三十一条の十七]]第一項の届出書を提出しないで性風俗関連特殊営業を営んだとき。
- 六 前号に規定する届出書又はこれらの届出書に係る[[laws/323AC0000000122/本文/第27条.md|第二十七条]]第三項（[[laws/323AC0000000122/本文/第31条の12.md|第三十一条の十二]]第二項において準用する場合を含む。）若しくは[[laws/323AC0000000122/本文/第31条の2.md|第三十一条の二]]第三項（[[laws/323AC0000000122/本文/第31条の7.md|第三十一条の七]]第二項及び[[laws/323AC0000000122/本文/第31条の17.md|第三十一条の十七]]第二項において準用する場合を含む。）の添付書類であつて虚偽の記載のあるものを提出したとき。
- 七 [[laws/323AC0000000122/本文/第28条.md|第二十八条]]第十三項（[[laws/323AC0000000122/本文/第31条の3.md|第三十一条の三]]第一項において準用する場合を含む。）の規定に違反したとき。
