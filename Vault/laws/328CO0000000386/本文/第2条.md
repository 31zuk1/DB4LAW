# 第二条 （籍の登録事項）

## 
保健師籍、助産師籍又は看護師籍には、次に掲げる事項を登録する。登録番号及び登録年月日本籍地都道府県名（日本の国籍を有しない者については、その国籍）、氏名及び生年月日保健師籍又は看護師籍にあつては、性別保健師国家試験、助産師国家試験又は看護師国家試験合格の年月法[[laws/保健師助産師看護師法施行令/本文/第14条.md|第十四条]]第一項の規定による処分に関する事項法[[laws/保健師助産師看護師法施行令/本文/第15条の2.md|第十五条の二]]第三項に規定する保健師等再教育研修を修了した旨その他厚生労働大臣の定める事項

- 一 登録番号及び登録年月日
- 二 本籍地都道府県名（日本の国籍を有しない者については、その国籍）、氏名及び生年月日
- 三 保健師籍又は看護師籍にあつては、性別
- 四 保健師国家試験、助産師国家試験又は看護師国家試験合格の年月
- 五 法[[laws/保健師助産師看護師法施行令/本文/第14条.md|第十四条]]第一項の規定による処分に関する事項
- 六 法[[laws/保健師助産師看護師法施行令/本文/第15条の2.md|第十五条の二]]第三項に規定する保健師等再教育研修を修了した旨
- 七 その他厚生労働大臣の定める事項
## ２
准看護師籍には、次に掲げる事項を登録する。登録番号及び登録年月日本籍地都道府県名（日本の国籍を有しない者については、その国籍）、氏名、生年月日及び性別准看護師試験合格の年月及び試験施行地都道府県名法[[laws/保健師助産師看護師法施行令/本文/第14条.md|第十四条]]第二項の規定による処分に関する事項法[[laws/保健師助産師看護師法施行令/本文/第15条の2.md|第十五条の二]]第四項に規定する准看護師再教育研修を修了した旨その他厚生労働大臣の定める事項

- 一 登録番号及び登録年月日
- 二 本籍地都道府県名（日本の国籍を有しない者については、その国籍）、氏名、生年月日及び性別
- 三 准看護師試験合格の年月及び試験施行地都道府県名
- 四 法[[laws/保健師助産師看護師法施行令/本文/第14条.md|第十四条]]第二項の規定による処分に関する事項
- 五 法[[laws/保健師助産師看護師法施行令/本文/第15条の2.md|第十五条の二]]第四項に規定する准看護師再教育研修を修了した旨
- 六 その他厚生労働大臣の定める事項
