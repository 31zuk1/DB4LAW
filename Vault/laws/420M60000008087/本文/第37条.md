# 第三十七条 （機構債券の種類）

## 
令[[laws/地方公共団体金融機構の財務及び会計に関する省令/本文/第9条.md|第九条]]第一項第一号の総務省令で定める事項は、次に掲げるものとする。機構債券の利率機構債券の償還の方法及び期限利息支払の方法及び期限機構債券を発行するときは、その旨機構債券の発行に関する事務の委託を受ける者を定めたときは、その名称及び住所機構債券に係る債務の担保に供するため法[[laws/地方公共団体金融機構の財務及び会計に関する省令/本文/第42条.md|第四十二条]]の規定により貸付債権を信託するときは、その旨、当該信託の受託者の名称及び住所並びに当該貸付債権の概要

- 一 機構債券の利率
- 二 機構債券の償還の方法及び期限
- 三 利息支払の方法及び期限
- 四 機構債券を発行するときは、その旨
- 五 機構債券の発行に関する事務の委託を受ける者を定めたときは、その名称及び住所
- 六 機構債券に係る債務の担保に供するため法[[laws/地方公共団体金融機構の財務及び会計に関する省令/本文/第42条.md|第四十二条]]の規定により貸付債権を信託するときは、その旨、当該信託の受託者の名称及び住所並びに当該貸付債権の概要
