# 第三条 

## 
次条各号ニ掲グル業務ヲ除クノ外左ニ掲グル業務ニ従事スル漁船（小型漁船ヲ除ク）ノ従業制限ハ之ヲ第一種トス一本釣漁業延縄漁業流網漁業刺網漁業旋網漁業敷網漁業突棒漁業曳縄漁業曳網漁業（トロール漁業ヲ除ク）小型捕鯨業前各号ニ掲グルモノノ外主務大臣（国土交通大臣及農林水産大臣ヲ謂フ次条第九号ニ於テ同ジ）ニ於テ前各号ノ業務ニ準ズルモノト認メタル業務

- 一 一本釣漁業
- 二 延縄漁業
- 三 流網漁業
- 四 刺網漁業
- 五 旋網漁業
- 六 敷網漁業
- 七 突棒漁業
- 八 曳縄漁業
- 九 曳網漁業（トロール漁業ヲ除ク）
- 十 小型捕鯨業
- 十一 前各号ニ掲グルモノノ外主務大臣（国土交通大臣及農林水産大臣ヲ謂フ次条第九号ニ於テ同ジ）ニ於テ前各号ノ業務ニ準ズルモノト認メタル業務
