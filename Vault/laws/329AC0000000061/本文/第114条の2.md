# 第百十四条の二 

## 
次の各号のいずれかに該当する者は、一年以下の拘禁刑又は五十万円以下の罰金に処する。[[laws/329AC0000000061/本文/第15条.md|第十五条]]第七項、第八項又は第十三項（入港手続）の規定による報告をせず、又は偽つた報告をした者[[laws/329AC0000000061/本文/第15条の2.md|第十五条の二]]第二項（積荷に関する事項の報告）の規定による報告をせず、又は偽つた報告をした者[[laws/329AC0000000061/本文/第16条.md|第十六条]]第一項（貨物の積卸し）の規定による報告をせず、かつ、書類の提出をせず、若しくは偽つた報告若しくは偽つた書類の提出をして貨物の積卸しをした者又は同条第二項の規定による書類を提示せず、若しくは偽つた書類を提示して貨物の積卸しをした者[[laws/329AC0000000061/本文/第16条.md|第十六条]]第三項の規定に違反して同項ただし書の規定による許可を受けないで積荷の船卸しをした者[[laws/329AC0000000061/本文/第17条.md|第十七条]]第四項（出港手続）の規定による報告をせず、又は偽つた報告をした者[[laws/329AC0000000061/本文/第20条.md|第二十条]]第四項（不開港への出入）の規定による報告をせず、又は偽つた報告をした者[[laws/329AC0000000061/本文/第23条.md|第二十三条]]第一項又は第二項（船用品又は機用品の積込み等）の規定に違反して船用品又は機用品を積み込んだ者[[laws/329AC0000000061/本文/第23条.md|第二十三条]]第五項本文の規定による書類を提出せず、又は偽つた書類を提出した者[[laws/329AC0000000061/本文/第24条.md|第二十四条]]第一項、第二項又は第四項（船舶又は航空機と陸地との交通等）の規定に違反して交通又は貨物の積卸しを行つた者[[laws/329AC0000000061/本文/第63条.md|第六十三条]]第一項若しくは第三項（保税運送）、[[laws/329AC0000000061/本文/第63条の2.md|第六十三条の二]]第一項若しくは第二項（保税運送の特例）又は[[laws/329AC0000000061/本文/第63条の9.md|第六十三条の九]]第一項若しくは第二項（郵便物の保税運送）の規定に違反して外国貨物を運送した者[[laws/329AC0000000061/本文/第63条.md|第六十三条]]第五項本文、[[laws/329AC0000000061/本文/第63条の2.md|第六十三条の二]]第三項又は[[laws/329AC0000000061/本文/第63条の9.md|第六十三条の九]]第三項の規定による確認を受けなかつた者[[laws/329AC0000000061/本文/第64条.md|第六十四条]]第一項（難破貨物等の運送）の規定に違反して同項各号に掲げる外国貨物を運送した者又は同条第三項の規定に違反して書類を提出しなかつた者[[laws/329AC0000000061/本文/第66条.md|第六十六条]]第一項（内国貨物の運送）の規定に違反して内国貨物を外国貿易船等に積んで本邦内の場所相互間を運送した者又は同条第二項の規定に違反して書類を提出しなかつた者[[laws/329AC0000000061/本文/第76条.md|第七十六条]]第一項ただし書（郵便物の輸出入の簡易手続）の検査その他郵便物に係る税関の審査に際し、偽つた証明をした者[[laws/329AC0000000061/本文/第77条の5.md|第七十七条の五]]第二項（違法行為等の是正）の規定による報告をせず、又は偽つた報告をした者[[laws/329AC0000000061/本文/第105条.md|第百五条]]第一項（税関職員の権限）の規定による税関職員の質問に対して答弁せず、若しくは偽りの陳述をし、又はその職務の執行を拒み、妨げ、若しくは忌避した者[[laws/329AC0000000061/本文/第105条.md|第百五条]]第一項第四号の二又は第六号の規定による物件の提示又は提出の要求に対し、正当な理由がなくこれに応じず、又は偽りの記載若しくは記録をした帳簿書類その他の物件（その写しを含む。）を提示し、若しくは提出した者[[laws/329AC0000000061/本文/第106条.md|第百六条]]（特別の場合における税関長の権限）の規定による税関長（[[laws/329AC0000000061/本文/第107条.md|第百七条]]（税関長の権限の委任）の規定により権限の一部を委任された者を含む。）の処分の執行を拒み、妨げ、又は忌避した者

- 一 [[laws/329AC0000000061/本文/第15条.md|第十五条]]第七項、第八項又は第十三項（入港手続）の規定による報告をせず、又は偽つた報告をした者
- 二 [[laws/329AC0000000061/本文/第15条の2.md|第十五条の二]]第二項（積荷に関する事項の報告）の規定による報告をせず、又は偽つた報告をした者
- 三 [[laws/329AC0000000061/本文/第16条.md|第十六条]]第一項（貨物の積卸し）の規定による報告をせず、かつ、書類の提出をせず、若しくは偽つた報告若しくは偽つた書類の提出をして貨物の積卸しをした者又は同条第二項の規定による書類を提示せず、若しくは偽つた書類を提示して貨物の積卸しをした者
- 四 [[laws/329AC0000000061/本文/第16条.md|第十六条]]第三項の規定に違反して同項ただし書の規定による許可を受けないで積荷の船卸しをした者
- 五 [[laws/329AC0000000061/本文/第17条.md|第十七条]]第四項（出港手続）の規定による報告をせず、又は偽つた報告をした者
- 六 [[laws/329AC0000000061/本文/第20条.md|第二十条]]第四項（不開港への出入）の規定による報告をせず、又は偽つた報告をした者
- 七 [[laws/329AC0000000061/本文/第23条.md|第二十三条]]第一項又は第二項（船用品又は機用品の積込み等）の規定に違反して船用品又は機用品を積み込んだ者
- 八 [[laws/329AC0000000061/本文/第23条.md|第二十三条]]第五項本文の規定による書類を提出せず、又は偽つた書類を提出した者
- 九 [[laws/329AC0000000061/本文/第24条.md|第二十四条]]第一項、第二項又は第四項（船舶又は航空機と陸地との交通等）の規定に違反して交通又は貨物の積卸しを行つた者
- 十 [[laws/329AC0000000061/本文/第63条.md|第六十三条]]第一項若しくは第三項（保税運送）、[[laws/329AC0000000061/本文/第63条の2.md|第六十三条の二]]第一項若しくは第二項（保税運送の特例）又は[[laws/329AC0000000061/本文/第63条の9.md|第六十三条の九]]第一項若しくは第二項（郵便物の保税運送）の規定に違反して外国貨物を運送した者
- 十一 [[laws/329AC0000000061/本文/第63条.md|第六十三条]]第五項本文、[[laws/329AC0000000061/本文/第63条の2.md|第六十三条の二]]第三項又は[[laws/329AC0000000061/本文/第63条の9.md|第六十三条の九]]第三項の規定による確認を受けなかつた者
- 十二 [[laws/329AC0000000061/本文/第64条.md|第六十四条]]第一項（難破貨物等の運送）の規定に違反して同項各号に掲げる外国貨物を運送した者又は同条第三項の規定に違反して書類を提出しなかつた者
- 十三 [[laws/329AC0000000061/本文/第66条.md|第六十六条]]第一項（内国貨物の運送）の規定に違反して内国貨物を外国貿易船等に積んで本邦内の場所相互間を運送した者又は同条第二項の規定に違反して書類を提出しなかつた者
- 十四 [[laws/329AC0000000061/本文/第76条.md|第七十六条]]第一項ただし書（郵便物の輸出入の簡易手続）の検査その他郵便物に係る税関の審査に際し、偽つた証明をした者
- 十五 [[laws/329AC0000000061/本文/第77条の5.md|第七十七条の五]]第二項（違法行為等の是正）の規定による報告をせず、又は偽つた報告をした者
- 十六 [[laws/329AC0000000061/本文/第105条.md|第百五条]]第一項（税関職員の権限）の規定による税関職員の質問に対して答弁せず、若しくは偽りの陳述をし、又はその職務の執行を拒み、妨げ、若しくは忌避した者
- 十七 [[laws/329AC0000000061/本文/第105条.md|第百五条]]第一項第四号の二又は第六号の規定による物件の提示又は提出の要求に対し、正当な理由がなくこれに応じず、又は偽りの記載若しくは記録をした帳簿書類その他の物件（その写しを含む。）を提示し、若しくは提出した者
- 十八 [[laws/329AC0000000061/本文/第106条.md|第百六条]]（特別の場合における税関長の権限）の規定による税関長（[[laws/329AC0000000061/本文/第107条.md|第百七条]]（税関長の権限の委任）の規定により権限の一部を委任された者を含む。）の処分の執行を拒み、妨げ、又は忌避した者
