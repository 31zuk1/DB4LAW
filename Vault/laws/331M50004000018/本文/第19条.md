# 第十九条 （権限の委任）

## 
法に規定する国土交通大臣の権限のうち次に掲げるものは、地方整備局長及び北海道開発局長に委任する。法[[laws/331M50004000018/本文/第10条.md|第十条]]第一項又は第四項の規定により許可し、同条第五項の規定による届出を受理し、及び同条第六項又は第七項の規定により通知すること。法[[laws/331M50004000018/本文/第11条.md|第十一条]]第一項又は第五項の規定により許可し、同条第七項の規定による届出を受理し、及び同条第九項の規定により通知すること。法[[laws/331M50004000018/本文/第15条.md|第十五条]]第一項又は第四項の規定により許可し、同条第五項の規定による届出を受理し、及び同条第六項の規定により通知すること。法[[laws/331M50004000018/本文/第18条.md|第十八条]]第二項又は第三項の規定による届出を受理し、及び同条第四項の規定により通知すること。法[[laws/331M50004000018/本文/第19条.md|第十九条]]第二項又は第三項の規定による届出を受理すること。法[[laws/331AC0000000007/本文/第20条.md|第二十条]]第一項の規定により資金の貸付けを行うこと（指定都市高速道路に係るものを除く。）。法[[laws/331AC0000000007/本文/第21条.md|第二十一条]]第一項の規定により許可し、及び同条第五項の規定により通知すること（地方道路公社が行う一般国道、都道府県道又は市町村道（指定都市高速道路を除く。）の新設又は改築に係るものに限る。）。法[[laws/331AC0000000007/本文/第21条.md|第二十一条]]第四項の規定による届出を受理すること。法[[laws/331AC0000000007/本文/第24条.md|第二十四条]]第三項の規定により認可すること（地方道路公社（指定都市高速道路を管理する場合を除く。）又は有料道路管理者が定める通行方法に係るものに限る。）。法[[laws/331AC0000000007/本文/第27条.md|第二十七条]]第一項又は第二項の規定により検査し、及び同条第三項の規定により必要な措置をとるべきことを命じ、又は同条第四項の規定により必要な措置をとるべき旨の要求をすること（都道府県若しくは指定市である道路管理者の行う工事又は地方道路公社の行う工事のうち一般国道、都道府県道若しくは指定市の市道（指定都市高速道路を除く。）に係るものに限る。）。法[[laws/331AC0000000007/本文/第27条.md|第二十七条]]第六項の規定による報告を徴収すること。法[[laws/331AC0000000007/本文/第32条の2.md|第三十二条の二]]第三項の規定により通知し、及び公示すること。法[[laws/331AC0000000007/本文/第32条の2.md|第三十二条の二]]第四項の規定による権限を行うこと。法[[laws/331AC0000000007/本文/第38条.md|第三十八条]]第一項の規定により他の道路の道路管理者（高速自動車国道の道路管理者である場合を除く。）として協議して分担すべき金額及び分担の方法を定めること。法[[laws/331AC0000000007/本文/第38条.md|第三十八条]]第二項の規定により裁定をし、同条第三項において準用する法[[laws/331M50004000018/本文/第9条.md|第九条]]第三項の規定により意見を聴くこと（会社等が地方道路公社（指定都市高速道路を管理する場合を除く。以下この号において同じ。）である場合及び他の道路の道路管理者が地方公共団体又は地方道路公社である場合に限る。）。法[[laws/331AC0000000007/本文/第46条.md|第四十六条]]第一項の規定により必要な処分を命じ、又は必要な措置をとることを命ずること（地方道路公社の管理する一般国道、都道府県道又は市町村道（指定都市高速道路を除く。）に係るものに限る。）。法[[laws/331AC0000000007/本文/第48条.md|第四十八条]]第一項の規定により必要な勧告、助言又は援助をすること（地方道路公社の管理する一般国道、都道府県道又は市町村道（指定都市高速道路を除く。）に係るものに限る。）。法[[laws/331AC0000000007/本文/第50条.md|第五十条]]第五項の規定により許可すること。

- 一 法[[laws/331M50004000018/本文/第10条.md|第十条]]第一項又は第四項の規定により許可し、同条第五項の規定による届出を受理し、及び同条第六項又は第七項の規定により通知すること。
- 二 法[[laws/331M50004000018/本文/第11条.md|第十一条]]第一項又は第五項の規定により許可し、同条第七項の規定による届出を受理し、及び同条第九項の規定により通知すること。
- 三 法[[laws/331M50004000018/本文/第15条.md|第十五条]]第一項又は第四項の規定により許可し、同条第五項の規定による届出を受理し、及び同条第六項の規定により通知すること。
- 四 法[[laws/331M50004000018/本文/第18条.md|第十八条]]第二項又は第三項の規定による届出を受理し、及び同条第四項の規定により通知すること。
- 五 法[[laws/331M50004000018/本文/第19条.md|第十九条]]第二項又は第三項の規定による届出を受理すること。
- 六 法[[laws/331AC0000000007/本文/第20条.md|第二十条]]第一項の規定により資金の貸付けを行うこと（指定都市高速道路に係るものを除く。）。
- 七 法[[laws/331AC0000000007/本文/第21条.md|第二十一条]]第一項の規定により許可し、及び同条第五項の規定により通知すること（地方道路公社が行う一般国道、都道府県道又は市町村道（指定都市高速道路を除く。）の新設又は改築に係るものに限る。）。
- 八 法[[laws/331AC0000000007/本文/第21条.md|第二十一条]]第四項の規定による届出を受理すること。
- 九 法[[laws/331AC0000000007/本文/第24条.md|第二十四条]]第三項の規定により認可すること（地方道路公社（指定都市高速道路を管理する場合を除く。）又は有料道路管理者が定める通行方法に係るものに限る。）。
- 十 法[[laws/331AC0000000007/本文/第27条.md|第二十七条]]第一項又は第二項の規定により検査し、及び同条第三項の規定により必要な措置をとるべきことを命じ、又は同条第四項の規定により必要な措置をとるべき旨の要求をすること（都道府県若しくは指定市である道路管理者の行う工事又は地方道路公社の行う工事のうち一般国道、都道府県道若しくは指定市の市道（指定都市高速道路を除く。）に係るものに限る。）。
- 十一 法[[laws/331AC0000000007/本文/第27条.md|第二十七条]]第六項の規定による報告を徴収すること。
- 十二 法[[laws/331AC0000000007/本文/第32条の2.md|第三十二条の二]]第三項の規定により通知し、及び公示すること。
- 十三 法[[laws/331AC0000000007/本文/第32条の2.md|第三十二条の二]]第四項の規定による権限を行うこと。
- 十四 法[[laws/331AC0000000007/本文/第38条.md|第三十八条]]第一項の規定により他の道路の道路管理者（高速自動車国道の道路管理者である場合を除く。）として協議して分担すべき金額及び分担の方法を定めること。
- 十五 法[[laws/331AC0000000007/本文/第38条.md|第三十八条]]第二項の規定により裁定をし、同条第三項において準用する法[[laws/331M50004000018/本文/第9条.md|第九条]]第三項の規定により意見を聴くこと（会社等が地方道路公社（指定都市高速道路を管理する場合を除く。以下この号において同じ。）である場合及び他の道路の道路管理者が地方公共団体又は地方道路公社である場合に限る。）。
- 十六 法[[laws/331AC0000000007/本文/第46条.md|第四十六条]]第一項の規定により必要な処分を命じ、又は必要な措置をとることを命ずること（地方道路公社の管理する一般国道、都道府県道又は市町村道（指定都市高速道路を除く。）に係るものに限る。）。

- 十八 法[[laws/331AC0000000007/本文/第50条.md|第五十条]]第五項の規定により許可すること。
