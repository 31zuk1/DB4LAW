# 第四条 （農林業等活性化基盤施設設置事業計画の認定申請手続）

## 
法[[laws/特定農山村地域における農林業等の活性化のための基盤整備の促進に関する法律施行規則/本文/第7条.md|第七条]]の認定の申請は、農林業等活性化基盤施設（特定施設を除く。以下同じ。）の設置に係る事業に関する計画（以下「農林業等活性化基盤施設設置事業計画」という。）に次に掲げる事項を記載してこれを提出してしなければならない。農林業等活性化基盤施設の位置農林業等活性化基盤施設の設置に係る事業を行う者に関する事項農林業等活性化基盤施設の概要及び規模農林業等活性化基盤施設の運営に関する事項農林業等活性化基盤施設の設置に係る事業の実施時期資金計画

- 一 農林業等活性化基盤施設の位置
- 二 農林業等活性化基盤施設の設置に係る事業を行う者に関する事項
- 三 農林業等活性化基盤施設の概要及び規模
- 四 農林業等活性化基盤施設の運営に関する事項
- 五 農林業等活性化基盤施設の設置に係る事業の実施時期
- 六 資金計画
