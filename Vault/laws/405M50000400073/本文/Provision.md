# 附則

## 
計量法附則第十九条第一項の日を定める政令（平成五年政令第三百三十号）第二項の通商産業省令で定める日は、次の各号に掲げる特定計量器を製造する者が属する事業の区分ごとに当該各号に定める日とする。質量計を製造する事業であって次に掲げるもの計量法施行規則（平成五年通商産業省令第六十九号。以下「規則」という。）別表第一第二号平成六年五月一日規則別表第一第三号平成九年五月一日規則別表第一第四号平成十年五月一日温度計を製造する事業であって次に掲げるもの規則別表第一第八号平成七年五月一日規則別表第一第六号及び第七号平成十年五月一日体積計を製造する事業であって次に掲げるもの規則別表第一第十二号平成七年五月一日規則別表第一第十八号から第二十号平成八年五月一日規則別表第一第十号、第十一号、第十三号から第十七号及び第二十三号平成九年五月一日アネロイド型圧力計を製造する事業であって次に掲げるもの規則別表第一第二十八号及び第二十九号平成六年五月一日規則別表第一第二十六号及び第二十七号平成八年五月一日熱量計を製造する事業であって次に掲げるもの規則別表第一第三十二号平成七年五月一日規則別表第一第三十号及び第三十一号平成十年五月一日濃度計を製造する事業であって次に掲げるもの規則別表第一第四十号平成六年五月一日規則別表第一第四十一号平成八年五月一日規則別表第一第三十九号平成九年五月一日規則別表第一第二十四号平成十年五月一日

- 一 質量計を製造する事業であって次に掲げるもの
- 二 温度計を製造する事業であって次に掲げるもの
- 三 体積計を製造する事業であって次に掲げるもの
- 四 アネロイド型圧力計を製造する事業であって次に掲げるもの
- 五 熱量計を製造する事業であって次に掲げるもの
- 六 濃度計を製造する事業であって次に掲げるもの
