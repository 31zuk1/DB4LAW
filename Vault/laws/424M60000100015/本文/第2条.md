# 第二条 （定義）

## 
この府令において、次の各号に掲げる用語の定義は、それぞれ当該各号に定めるところによる。通所給付決定保護者法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第6条の2.md|第六条の二]]の二第八項に規定する通所給付決定保護者をいう。指定障害児通所支援事業者法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第21条の5.md|第二十一条の五]]の三第一項に規定する指定障害児通所支援事業者をいう。指定通所支援法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第21条の5.md|第二十一条の五]]の三第一項に規定する指定通所支援をいう。指定通所支援費用基準額法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第21条の5.md|第二十一条の五]]の三第二項第一号（法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第21条の5.md|第二十一条の五]]の十三第二項の規定により、同条第一項に規定する放課後等デイサービス障害児通所給付費等の支給について適用する場合を含む。）に掲げる額をいう。通所利用者負担額法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第21条の5.md|第二十一条の五]]の三第二項第二号（法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第21条の5.md|第二十一条の五]]の十三第二項の規定により、同条第一項に規定する放課後等デイサービス障害児通所給付費等の支給について適用する場合を含む。）に掲げる額及び肢体不自由児通所医療（法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第21条の5.md|第二十一条の五]]の二十九第一項に規定する肢体不自由児通所医療をいう。以下同じ。）につき健康保険の療養に要する費用の額の算定方法の例により算定した費用の額から当該肢体不自由児通所医療につき支給された肢体不自由児通所医療費の額を控除して得た額の合計額をいう。通所給付決定法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第21条の5.md|第二十一条の五]]の五第一項に規定する通所給付決定をいう。支給量法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第21条の5.md|第二十一条の五]]の七第七項に規定する支給量をいう。通所給付決定の有効期間法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第21条の5.md|第二十一条の五]]の七第八項に規定する通所給付決定の有効期間をいう。通所受給者証法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第21条の5.md|第二十一条の五]]の七第九項に規定する通所受給者証をいう。法定代理受領法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第21条の5.md|第二十一条の五]]の七第十一項（法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第21条の5.md|第二十一条の五]]の十三第二項の規定により、同条第一項に規定する放課後等デイサービス障害児通所給付費等の支給について適用する場合を含む。）の規定により通所給付決定保護者に代わり市町村（特別区を含む。以下同じ。）が支払う指定通所支援に要した費用の額又は法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第21条の5.md|第二十一条の五]]の二十九第三項の規定により通所給付決定保護者に代わり市町村が支払う肢体不自由児通所医療に要した費用の額の一部を指定障害児通所支援事業者が受けることをいう。共生型通所支援法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第21条の5.md|第二十一条の五]]の十七第一項の申請に係る法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第21条の5.md|第二十一条の五]]の三第一項の指定を受けた者による指定通所支援をいう。児童発達支援センター法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第43条.md|第四十三条]]に規定する児童発達支援センターをいう。多機能型事業所[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第4条.md|第四条]]に規定する指定児童発達支援の事業、[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第65条.md|第六十五条]]に規定する指定放課後等デイサービスの事業、[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第71条の7.md|第七十一条の七]]に規定する指定居宅訪問型児童発達支援の事業及び[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第72条.md|第七十二条]]に規定する指定保育所等訪問支援の事業並びに障害者の日常生活及び社会生活を総合的に支援するための法律に基づく指定障害福祉サービスの事業等の人員、設備及び運営に関する基準（平成十八年厚生労働省令第百七十一号。以下「指定障害福祉サービス等基準」という。）[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第77条.md|第七十七条]]に規定する指定生活介護の事業、指定障害福祉サービス等基準[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第155条.md|第百五十五条]]に規定する指定自立訓練（機能訓練）の事業、指定障害福祉サービス等基準[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第165条.md|第百六十五条]]に規定する指定自立訓練（生活訓練）の事業、指定障害福祉サービス等基準[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第174条.md|第百七十四条]]に規定する指定就労移行支援の事業、指定障害福祉サービス等基準[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第185条.md|第百八十五条]]に規定する指定就労継続支援Ａ型の事業及び指定障害福祉サービス等基準[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第198条.md|第百九十八条]]に規定する指定就労継続支援Ｂ型の事業のうち二以上の事業を一体的に行う事業所（指定障害福祉サービス等基準に規定する事業のみを行う事業所を除く。）のことをいう。

- 一 通所給付決定保護者法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第6条の2.md|第六条の二]]の二第八項に規定する通所給付決定保護者をいう。
- 二 指定障害児通所支援事業者法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第21条の5.md|第二十一条の五]]の三第一項に規定する指定障害児通所支援事業者をいう。
- 三 指定通所支援法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第21条の5.md|第二十一条の五]]の三第一項に規定する指定通所支援をいう。
- 四 指定通所支援費用基準額法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第21条の5.md|第二十一条の五]]の三第二項第一号（法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第21条の5.md|第二十一条の五]]の十三第二項の規定により、同条第一項に規定する放課後等デイサービス障害児通所給付費等の支給について適用する場合を含む。）に掲げる額をいう。
- 五 通所利用者負担額法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第21条の5.md|第二十一条の五]]の三第二項第二号（法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第21条の5.md|第二十一条の五]]の十三第二項の規定により、同条第一項に規定する放課後等デイサービス障害児通所給付費等の支給について適用する場合を含む。）に掲げる額及び肢体不自由児通所医療（法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第21条の5.md|第二十一条の五]]の二十九第一項に規定する肢体不自由児通所医療をいう。以下同じ。）につき健康保険の療養に要する費用の額の算定方法の例により算定した費用の額から当該肢体不自由児通所医療につき支給された肢体不自由児通所医療費の額を控除して得た額の合計額をいう。
- 六 通所給付決定法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第21条の5.md|第二十一条の五]]の五第一項に規定する通所給付決定をいう。
- 七 支給量法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第21条の5.md|第二十一条の五]]の七第七項に規定する支給量をいう。
- 八 通所給付決定の有効期間法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第21条の5.md|第二十一条の五]]の七第八項に規定する通所給付決定の有効期間をいう。
- 九 通所受給者証法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第21条の5.md|第二十一条の五]]の七第九項に規定する通所受給者証をいう。
- 十 法定代理受領法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第21条の5.md|第二十一条の五]]の七第十一項（法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第21条の5.md|第二十一条の五]]の十三第二項の規定により、同条第一項に規定する放課後等デイサービス障害児通所給付費等の支給について適用する場合を含む。）の規定により通所給付決定保護者に代わり市町村（特別区を含む。以下同じ。）が支払う指定通所支援に要した費用の額又は法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第21条の5.md|第二十一条の五]]の二十九第三項の規定により通所給付決定保護者に代わり市町村が支払う肢体不自由児通所医療に要した費用の額の一部を指定障害児通所支援事業者が受けることをいう。
- 十一 共生型通所支援法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第21条の5.md|第二十一条の五]]の十七第一項の申請に係る法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第21条の5.md|第二十一条の五]]の三第一項の指定を受けた者による指定通所支援をいう。
- 十二 児童発達支援センター法[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第43条.md|第四十三条]]に規定する児童発達支援センターをいう。
- 十三 多機能型事業所[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第4条.md|第四条]]に規定する指定児童発達支援の事業、[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第65条.md|第六十五条]]に規定する指定放課後等デイサービスの事業、[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第71条の7.md|第七十一条の七]]に規定する指定居宅訪問型児童発達支援の事業及び[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第72条.md|第七十二条]]に規定する指定保育所等訪問支援の事業並びに障害者の日常生活及び社会生活を総合的に支援するための法律に基づく指定障害福祉サービスの事業等の人員、設備及び運営に関する基準（平成十八年厚生労働省令第百七十一号。以下「指定障害福祉サービス等基準」という。）[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第77条.md|第七十七条]]に規定する指定生活介護の事業、指定障害福祉サービス等基準[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第155条.md|第百五十五条]]に規定する指定自立訓練（機能訓練）の事業、指定障害福祉サービス等基準[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第165条.md|第百六十五条]]に規定する指定自立訓練（生活訓練）の事業、指定障害福祉サービス等基準[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第174条.md|第百七十四条]]に規定する指定就労移行支援の事業、指定障害福祉サービス等基準[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第185条.md|第百八十五条]]に規定する指定就労継続支援Ａ型の事業及び指定障害福祉サービス等基準[[laws/児童福祉法に基づく指定通所支援の事業等の人員、設備及び運営に関する基準/本文/第198条.md|第百九十八条]]に規定する指定就労継続支援Ｂ型の事業のうち二以上の事業を一体的に行う事業所（指定障害福祉サービス等基準に規定する事業のみを行う事業所を除く。）のことをいう。
