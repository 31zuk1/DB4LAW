# 第百三条 

## 
次の各号のいずれかに該当する者は、一年以下の拘禁刑又は五十万円以下の罰金に処する。[[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第27条.md|第二十七条]]第一項の規定に違反して登録を受けないでフロン類の充塡又は回収を業として行った者不正の手段によって[[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第27条.md|第二十七条]]第一項の登録（[[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第30条.md|第三十条]]第一項の登録の更新を含む。）を受けた者[[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第35条.md|第三十五条]]第一項の規定による業務の停止の命令に違反した者[[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第50条.md|第五十条]]第一項の規定に違反して許可を受けないでフロン類の再生を業として行った者不正の手段によって[[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第50条.md|第五十条]]第一項の許可（[[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第52条.md|第五十二条]]第一項の許可の更新を含む。）を受けた者[[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第53条.md|第五十三条]]第一項の規定に違反して[[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第50条.md|第五十条]]第二項第三号から第五号までに掲げる事項を変更した者[[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第55条.md|第五十五条]]の規定による業務の停止の命令に違反した者[[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第63条.md|第六十三条]]第一項の規定に違反して許可を受けないでフロン類の破壊を業として行った者不正の手段によって[[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第63条.md|第六十三条]]第一項の許可（[[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第65条.md|第六十五条]]第一項の許可の更新を含む。）を受けた者[[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第66条.md|第六十六条]]第一項の規定に違反して[[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第63条.md|第六十三条]]第二項第三号から第五号までに掲げる事項を変更した者[[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第67条.md|第六十七条]]の規定による業務の停止の命令に違反した者[[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第81条.md|第八十一条]]の規定に違反した者[[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第86条.md|第八十六条]]の規定に違反して特定製品に冷媒として充塡されているフロン類を大気中に放出した者

- 一 [[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第27条.md|第二十七条]]第一項の規定に違反して登録を受けないでフロン類の充塡又は回収を業として行った者
- 二 不正の手段によって[[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第27条.md|第二十七条]]第一項の登録（[[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第30条.md|第三十条]]第一項の登録の更新を含む。）を受けた者
- 三 [[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第35条.md|第三十五条]]第一項の規定による業務の停止の命令に違反した者
- 四 [[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第50条.md|第五十条]]第一項の規定に違反して許可を受けないでフロン類の再生を業として行った者
- 五 不正の手段によって[[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第50条.md|第五十条]]第一項の許可（[[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第52条.md|第五十二条]]第一項の許可の更新を含む。）を受けた者
- 六 [[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第53条.md|第五十三条]]第一項の規定に違反して[[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第50条.md|第五十条]]第二項第三号から第五号までに掲げる事項を変更した者
- 七 [[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第55条.md|第五十五条]]の規定による業務の停止の命令に違反した者
- 八 [[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第63条.md|第六十三条]]第一項の規定に違反して許可を受けないでフロン類の破壊を業として行った者
- 九 不正の手段によって[[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第63条.md|第六十三条]]第一項の許可（[[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第65条.md|第六十五条]]第一項の許可の更新を含む。）を受けた者
- 十 [[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第66条.md|第六十六条]]第一項の規定に違反して[[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第63条.md|第六十三条]]第二項第三号から第五号までに掲げる事項を変更した者
- 十一 [[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第67条.md|第六十七条]]の規定による業務の停止の命令に違反した者
- 十二 [[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第81条.md|第八十一条]]の規定に違反した者
- 十三 [[laws/フロン類の使用の合理化及び管理の適正化に関する法律/本文/第86条.md|第八十六条]]の規定に違反して特定製品に冷媒として充塡されているフロン類を大気中に放出した者
