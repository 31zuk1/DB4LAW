# 第四十六条 

## 
次の各号のいずれかに該当する者は、三十万円以下の罰金に処する。[[laws/民間あっせん機関による養子縁組のあっせんに係る児童の保護等に関する法律/本文/第6条.md|第六条]]第二項（[[laws/民間あっせん機関による養子縁組のあっせんに係る児童の保護等に関する法律/本文/第12条.md|第十二条]]第五項において準用する場合を含む。）に規定する申請書又は[[laws/民間あっせん機関による養子縁組のあっせんに係る児童の保護等に関する法律/本文/第6条.md|第六条]]第三項（[[laws/民間あっせん機関による養子縁組のあっせんに係る児童の保護等に関する法律/本文/第12条.md|第十二条]]第五項において準用する場合を含む。）に規定する書類に虚偽の記載をして提出した者[[laws/民間あっせん機関による養子縁組のあっせんに係る児童の保護等に関する法律/本文/第13条.md|第十三条]]第一項の規定による届出をせず、若しくは虚偽の届出をし、又は同項に規定する書類に虚偽の記載をして提出した者[[laws/民間あっせん機関による養子縁組のあっせんに係る児童の保護等に関する法律/本文/第14条.md|第十四条]]第一項の規定による届出をせず、又は虚偽の届出をした者[[laws/民間あっせん機関による養子縁組のあっせんに係る児童の保護等に関する法律/本文/第18条.md|第十八条]]の規定に違反して帳簿を備え付けず、帳簿に記載せず、若しくは帳簿に虚偽の記載をし、又は同条若しくは[[laws/民間あっせん機関による養子縁組のあっせんに係る児童の保護等に関する法律/本文/第19条.md|第十九条]]第二項の規定に違反して帳簿を保存しなかった者[[laws/民間あっせん機関による養子縁組のあっせんに係る児童の保護等に関する法律/本文/第32条.md|第三十二条]]第一項若しくは第二項の規定による報告をせず、若しくは虚偽の報告をし、又は同条第三項の規定による届出をせず、若しくは虚偽の届出をした者[[laws/民間あっせん機関による養子縁組のあっせんに係る児童の保護等に関する法律/本文/第35条.md|第三十五条]]第一項の規定に違反して秘密を漏らした者[[laws/民間あっせん機関による養子縁組のあっせんに係る児童の保護等に関する法律/本文/第36条.md|第三十六条]]第一項の規定に違反した者[[laws/民間あっせん機関による養子縁組のあっせんに係る児童の保護等に関する法律/本文/第39条.md|第三十九条]]第一項の規定による報告をせず、又は虚偽の報告をした者[[laws/民間あっせん機関による養子縁組のあっせんに係る児童の保護等に関する法律/本文/第39条.md|第三十九条]]第二項の規定による立入り若しくは検査を拒み、妨げ、若しくは忌避し、又は質問に対して答弁をせず、若しくは虚偽の陳述をした者

- 一 [[laws/民間あっせん機関による養子縁組のあっせんに係る児童の保護等に関する法律/本文/第6条.md|第六条]]第二項（[[laws/民間あっせん機関による養子縁組のあっせんに係る児童の保護等に関する法律/本文/第12条.md|第十二条]]第五項において準用する場合を含む。）に規定する申請書又は[[laws/民間あっせん機関による養子縁組のあっせんに係る児童の保護等に関する法律/本文/第6条.md|第六条]]第三項（[[laws/民間あっせん機関による養子縁組のあっせんに係る児童の保護等に関する法律/本文/第12条.md|第十二条]]第五項において準用する場合を含む。）に規定する書類に虚偽の記載をして提出した者
- 二 [[laws/民間あっせん機関による養子縁組のあっせんに係る児童の保護等に関する法律/本文/第13条.md|第十三条]]第一項の規定による届出をせず、若しくは虚偽の届出をし、又は同項に規定する書類に虚偽の記載をして提出した者
- 三 [[laws/民間あっせん機関による養子縁組のあっせんに係る児童の保護等に関する法律/本文/第14条.md|第十四条]]第一項の規定による届出をせず、又は虚偽の届出をした者
- 四 [[laws/民間あっせん機関による養子縁組のあっせんに係る児童の保護等に関する法律/本文/第18条.md|第十八条]]の規定に違反して帳簿を備え付けず、帳簿に記載せず、若しくは帳簿に虚偽の記載をし、又は同条若しくは[[laws/民間あっせん機関による養子縁組のあっせんに係る児童の保護等に関する法律/本文/第19条.md|第十九条]]第二項の規定に違反して帳簿を保存しなかった者
- 五 [[laws/民間あっせん機関による養子縁組のあっせんに係る児童の保護等に関する法律/本文/第32条.md|第三十二条]]第一項若しくは第二項の規定による報告をせず、若しくは虚偽の報告をし、又は同条第三項の規定による届出をせず、若しくは虚偽の届出をした者
- 六 [[laws/民間あっせん機関による養子縁組のあっせんに係る児童の保護等に関する法律/本文/第35条.md|第三十五条]]第一項の規定に違反して秘密を漏らした者
- 七 [[laws/民間あっせん機関による養子縁組のあっせんに係る児童の保護等に関する法律/本文/第36条.md|第三十六条]]第一項の規定に違反した者
- 八 [[laws/民間あっせん機関による養子縁組のあっせんに係る児童の保護等に関する法律/本文/第39条.md|第三十九条]]第一項の規定による報告をせず、又は虚偽の報告をした者
- 九 [[laws/民間あっせん機関による養子縁組のあっせんに係る児童の保護等に関する法律/本文/第39条.md|第三十九条]]第二項の規定による立入り若しくは検査を拒み、妨げ、若しくは忌避し、又は質問に対して答弁をせず、若しくは虚偽の陳述をした者
