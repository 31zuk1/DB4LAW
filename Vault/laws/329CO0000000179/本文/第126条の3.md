# 第百二十六条の三 （教育訓練の受託及びその実施の委任）

## 
防衛大臣は、法[[laws/自衛隊法施行令/本文/第100条の2.md|第百条の二]]の規定による教育訓練の受託及びその実施をその指定する者に委任することができる。ただし、外国人の教育訓練の受託については、この限りでない。
