# 第五十一条の六 （課長の官職に準ずる官職）

## 
法[[laws/自衛隊法施行令/本文/第30条の2.md|第三十条の二]]第一項第七号に規定する政令で定める官職は、次に掲げる官職とする。防衛省本省の参事官訟務管理官建設制度官提供施設計画官服務管理官衛生官防衛装備庁の参事官プロジェクト管理総括官革新技術戦略官調達総括官総務官人事官会計官監察監査・評価官装備開発官艦船設計官事業計画官事業監理官装備技術官技術計画官技術振興官原価管理官需品調達官武器調達官電子音響調達官艦船調達官航空機調達官輸入調達官前各号に掲げる官職に準ずる官職として防衛大臣が定める官職

- 一 防衛省本省の参事官
- 二 訟務管理官
- 三 建設制度官
- 四 提供施設計画官
- 五 服務管理官
- 六 衛生官
- 七 防衛装備庁の参事官
- 八 プロジェクト管理総括官
- 九 革新技術戦略官
- 十 調達総括官
- 十一 総務官
- 十二 人事官
- 十三 会計官
- 十四 監察監査・評価官
- 十五 装備開発官
- 十六 艦船設計官
- 十七 事業計画官
- 十八 事業監理官
- 十九 装備技術官
- 二十 技術計画官
- 二十一 技術振興官
- 二十二 原価管理官
- 二十三 需品調達官
- 二十四 武器調達官
- 二十五 電子音響調達官
- 二十六 艦船調達官
- 二十七 航空機調達官
- 二十八 輸入調達官
- 二十九 前各号に掲げる官職に準ずる官職として防衛大臣が定める官職
