# 第三十八条の三 （法第二十五条第五項の政令で定める陸上自衛隊の学校）

## 
法[[laws/329CO0000000179/本文/第25条.md|第二十五条]]第五項の政令で定める陸上自衛隊の学校は、陸上自衛隊高等工科学校とする。
