# 第八十七条の十六 （事務次官、防衛省本省の局長又は防衛装備庁長官の職に準ずる職）

## 
法[[laws/自衛隊法施行令/本文/第65条の4.md|第六十五条の四]]第三項に規定する政令で定める職は、次に掲げるものとする。国家行政組織法[[laws/自衛隊法施行令/本文/第18条.md|第十八条]]第四項に規定する職及び同法第二十一条第二項に規定する官房の長統合幕僚長陸上幕僚長海上幕僚長航空幕僚長情報本部長防衛監察監

- 一 国家行政組織法[[laws/自衛隊法施行令/本文/第18条.md|第十八条]]第四項に規定する職及び同法第二十一条第二項に規定する官房の長
- 二 統合幕僚長
- 三 陸上幕僚長
- 四 海上幕僚長
- 五 航空幕僚長
- 六 情報本部長
- 七 防衛監察監
