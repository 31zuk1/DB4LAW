# 第八十一条 （特定遊興飲食店営業の相続の承認の申請）

## 
[[laws/360M50400000001/本文/第13条.md|第十三条]]の規定は、法[[laws/323AC0000000122/本文/第31条の23.md|第三十一条の二十三]]において準用する法[[laws/360M50400000001/本文/第7条.md|第七条]]第一項の規定により相続の承認を受けようとする者について準用する。この場合において、[[laws/360M50400000001/本文/第13条.md|第十三条]]第二項第一号中「風俗営業者（法[[laws/360M50400000001/本文/第2条.md|第二条]]第二項の風俗営業者であつて申請に係る公安委員会の法[[laws/360M50400000001/本文/第3条.md|第三条]]第一項の許可又は法[[laws/360M50400000001/本文/第7条.md|第七条]]第一項の承認（以下「風俗営業許可等」とあるのは「特定遊興飲食店営業者（法[[laws/360M50400000001/本文/第2条.md|第二条]]第十二項の特定遊興飲食店営業者であつて申請に係る公安委員会の法[[laws/323AC0000000122/本文/第31条の22.md|第三十一条の二十二]]の許可又は法[[laws/323AC0000000122/本文/第31条の23.md|第三十一条の二十三]]において準用する法[[laws/360M50400000001/本文/第7条.md|第七条]]第一項の承認（以下「特定遊興飲食店営業許可等」と、「[[laws/360M50400000001/本文/第1条.md|第一条]]第五号」とあるのは「[[laws/360M50400000001/本文/第17条.md|第十七条]]において準用する府令[[laws/360M50400000001/本文/第1条.md|第一条]]第五号」と、同項第二号中「風俗営業許可等」とあるのは「特定遊興飲食店営業許可等」と、「[[laws/360M50400000001/本文/第1条.md|第一条]]第六号」とあるのは「[[laws/360M50400000001/本文/第17条.md|第十七条]]において準用する府令[[laws/360M50400000001/本文/第1条.md|第一条]]第六号」と、同項第三号中「[[laws/360M50400000001/本文/第1条.md|第一条]]第四号」とあるのは「[[laws/360M50400000001/本文/第17条.md|第十七条]]において準用する府令[[laws/360M50400000001/本文/第1条.md|第一条]]第四号」と読み替えるものとする。
