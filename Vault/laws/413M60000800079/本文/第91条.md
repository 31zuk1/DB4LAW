# 第九十一条 （社会資本システム研究室の所掌事務）

## 
社会資本システム研究室は、社会資本の整備に必要な情報の収集及び利用に関するシステムに係る調査、試験、研究及び開発並びに技術の指導に関する事務（社会資本施工高度化研究室の所掌に属するものを除く。）をつかさどる。
