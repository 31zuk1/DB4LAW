# 第四十三条の三の三 （廃止措置実施方針の公表）

## 
法[[laws/使用済燃料の貯蔵の事業に関する規則/本文/第43条の26.md|第四十三条の二十六]]の四第一項及び第三項の規定による公表は、廃止措置実施方針の作成又は変更を行った後、遅滞なく、インターネットの利用により行うものとする。
