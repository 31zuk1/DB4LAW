# 第四十三条 

## 
厚生労働大臣は、登録検査機関が次の各号のいずれかに該当するときは、その登録を取り消し、又は期間を定めて製品検査の業務の全部若しくは一部の停止を命ずることができる。この章の規定に違反したとき。[[laws/322AC0000000233/本文/第32条.md|第三十二条]]第一号又は第三号に該当するに至つたとき。[[laws/322AC0000000233/本文/第37条.md|第三十七条]]第一項の認可を受けた業務規程によらないで製品検査を行つたとき。[[laws/322AC0000000233/本文/第37条.md|第三十七条]]第三項又は前二条の規定による命令に違反したとき。正当な理由がないのに[[laws/322AC0000000233/本文/第39条.md|第三十九条]]第二項各号の規定による請求を拒んだとき。不正の手段により[[laws/322AC0000000233/本文/第33条.md|第三十三条]]第一項の登録を受けたとき。

- 一 この章の規定に違反したとき。
- 二 [[laws/322AC0000000233/本文/第32条.md|第三十二条]]第一号又は第三号に該当するに至つたとき。
- 三 [[laws/322AC0000000233/本文/第37条.md|第三十七条]]第一項の認可を受けた業務規程によらないで製品検査を行つたとき。
- 四 [[laws/322AC0000000233/本文/第37条.md|第三十七条]]第三項又は前二条の規定による命令に違反したとき。
- 五 正当な理由がないのに[[laws/322AC0000000233/本文/第39条.md|第三十九条]]第二項各号の規定による請求を拒んだとき。
- 六 不正の手段により[[laws/322AC0000000233/本文/第33条.md|第三十三条]]第一項の登録を受けたとき。
