# 第六十二条 

## 
国庫は、政令で定めるところにより、次に掲げる都道府県又は保健所を設置する市の費用に対して、その二分の一を負担する。[[laws/食品衛生法/本文/第28条.md|第二十八条]]第一項（[[laws/食品衛生法/本文/第68条.md|第六十八条]]第一項及び第三項において準用する場合を含む。）の規定による収去に要する費用[[laws/食品衛生法/本文/第30条.md|第三十条]]第一項（[[laws/食品衛生法/本文/第68条.md|第六十八条]]第一項及び第三項において準用する場合を含む。）の規定による食品衛生監視員の設置に要する費用[[laws/食品衛生法/本文/第55条.md|第五十五条]]第一項（[[laws/食品衛生法/本文/第68条.md|第六十八条]]第一項において準用する場合を含む。）の規定による営業の許可に要する費用[[laws/食品衛生法/本文/第59条.md|第五十九条]]（[[laws/食品衛生法/本文/第68条.md|第六十八条]]第一項及び第三項において準用する場合を含む。）の規定による廃棄に要する費用[[laws/食品衛生法/本文/第64条.md|第六十四条]]第一項又は第二項（[[laws/食品衛生法/本文/第68条.md|第六十八条]]第一項において準用する場合を含む。）の規定による死体の解剖に要する費用この法律の施行に関する訴訟事件に要する費用及びその結果支払う賠償の費用

- 一 [[laws/食品衛生法/本文/第28条.md|第二十八条]]第一項（[[laws/食品衛生法/本文/第68条.md|第六十八条]]第一項及び第三項において準用する場合を含む。）の規定による収去に要する費用
- 二 [[laws/食品衛生法/本文/第30条.md|第三十条]]第一項（[[laws/食品衛生法/本文/第68条.md|第六十八条]]第一項及び第三項において準用する場合を含む。）の規定による食品衛生監視員の設置に要する費用
- 三 [[laws/食品衛生法/本文/第55条.md|第五十五条]]第一項（[[laws/食品衛生法/本文/第68条.md|第六十八条]]第一項において準用する場合を含む。）の規定による営業の許可に要する費用
- 四 [[laws/食品衛生法/本文/第59条.md|第五十九条]]（[[laws/食品衛生法/本文/第68条.md|第六十八条]]第一項及び第三項において準用する場合を含む。）の規定による廃棄に要する費用
- 五 [[laws/食品衛生法/本文/第64条.md|第六十四条]]第一項又は第二項（[[laws/食品衛生法/本文/第68条.md|第六十八条]]第一項において準用する場合を含む。）の規定による死体の解剖に要する費用
- 六 この法律の施行に関する訴訟事件に要する費用及びその結果支払う賠償の費用
