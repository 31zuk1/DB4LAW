# 第四十一条 

## 
次ノ場合ニ於テハ取締役、執行役、会計参与若ハ其ノ職務ヲ行フベキ社員、監査役、支配人、代理店主（代理店主法人ナルトキハ其ノ業務ヲ執行スル社員、取締役、執行役其ノ他法人ノ代表者）若ハ清算人又ハ[[laws/306AC0000000042/本文/第21条.md|第二十一条]]ノ六ノ規定ニ依ル管理ノ受託無尽会社ノ取締役、執行役、会計参与若ハ其ノ職務ヲ行フベキ社員、監査役若ハ支配人ヲ十万円以下ノ過料ニ処ス但シ其ノ行為ニ付刑ヲ科スベキトキハ此ノ限ニ在ラズ[[laws/306AC0000000042/本文/第5条.md|第五条]]、[[laws/306AC0000000042/本文/第7条.md|第七条]]、[[laws/306AC0000000042/本文/第8条.md|第八条]]、[[laws/306AC0000000042/本文/第10条.md|第十条]]、[[laws/306AC0000000042/本文/第13条.md|第十三条]]、[[laws/306AC0000000042/本文/第14条.md|第十四条]]、[[laws/306AC0000000042/本文/第17条.md|第十七条]]又ハ[[laws/306AC0000000042/本文/第19条.md|第十九条]]ノ規定ニ違反シタルトキ[[laws/306AC0000000042/本文/第6条.md|第六条]]ノ規定ニ依リ定メタル営業区域外ニ於テ営業ヲ為シタルトキ無尽会社ガ[[laws/306AC0000000042/本文/第12条.md|第十二条]]ノ規定ニ違反シタルトキ正当ノ理由ナクシテ[[laws/306AC0000000042/本文/第20条.md|第二十条]]ノ説明書ノ交付ヲ拒ミ又ハ之ニ虚偽ノ記載ヲ為シタルトキ[[laws/306AC0000000042/本文/第21条.md|第二十一条]]ノ四ノ規定ニ違反シテ事業ノ全部又ハ一部ノ譲渡又ハ譲受ヲ為シタルトキ本法ニ依リ無尽会社ニ備ヘ置クベキ書類ノ備付若ハ内閣総理大臣ニ提出スベキ書類又ハ電磁的記録ノ提出ヲ怠リ、之ニ記載若ハ記録スベキ事項ヲ記載若ハ記録セズ又ハ之ニ虚偽ノ記載若ハ記録ヲ為シタルトキ[[laws/306AC0000000042/本文/第24条.md|第二十四条]]、[[laws/306AC0000000042/本文/第25条.md|第二十五条]]、[[laws/306AC0000000042/本文/第28条.md|第二十八条]]又ハ[[laws/306AC0000000042/本文/第31条.md|第三十一条]]ノ規定ニ依リ内閣総理大臣又ハ裁判所ノ為シタル命令ニ違反シタルトキ本法ニ基キテ発スル命令ニ違反シタルトキ

- 一 [[laws/306AC0000000042/本文/第5条.md|第五条]]、[[laws/306AC0000000042/本文/第7条.md|第七条]]、[[laws/306AC0000000042/本文/第8条.md|第八条]]、[[laws/306AC0000000042/本文/第10条.md|第十条]]、[[laws/306AC0000000042/本文/第13条.md|第十三条]]、[[laws/306AC0000000042/本文/第14条.md|第十四条]]、[[laws/306AC0000000042/本文/第17条.md|第十七条]]又ハ[[laws/306AC0000000042/本文/第19条.md|第十九条]]ノ規定ニ違反シタルトキ
- 二 [[laws/306AC0000000042/本文/第6条.md|第六条]]ノ規定ニ依リ定メタル営業区域外ニ於テ営業ヲ為シタルトキ
- 三 無尽会社ガ[[laws/306AC0000000042/本文/第12条.md|第十二条]]ノ規定ニ違反シタルトキ
- 四 正当ノ理由ナクシテ[[laws/306AC0000000042/本文/第20条.md|第二十条]]ノ説明書ノ交付ヲ拒ミ又ハ之ニ虚偽ノ記載ヲ為シタルトキ
- 四ノ二 [[laws/306AC0000000042/本文/第21条.md|第二十一条]]ノ四ノ規定ニ違反シテ事業ノ全部又ハ一部ノ譲渡又ハ譲受ヲ為シタルトキ
- 五 本法ニ依リ無尽会社ニ備ヘ置クベキ書類ノ備付若ハ内閣総理大臣ニ提出スベキ書類又ハ電磁的記録ノ提出ヲ怠リ、之ニ記載若ハ記録スベキ事項ヲ記載若ハ記録セズ又ハ之ニ虚偽ノ記載若ハ記録ヲ為シタルトキ
- 六 [[laws/306AC0000000042/本文/第24条.md|第二十四条]]、[[laws/306AC0000000042/本文/第25条.md|第二十五条]]、[[laws/306AC0000000042/本文/第28条.md|第二十八条]]又ハ[[laws/306AC0000000042/本文/第31条.md|第三十一条]]ノ規定ニ依リ内閣総理大臣又ハ裁判所ノ為シタル命令ニ違反シタルトキ
- 七 本法ニ基キテ発スル命令ニ違反シタルトキ
