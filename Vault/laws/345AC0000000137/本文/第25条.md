# 第二十五条 

## 
次の各号のいずれかに該当する者は、五年以下の拘禁刑若しくは千万円以下の罰金に処し、又はこれを併科する。[[laws/廃棄物の処理及び清掃に関する法律/本文/第7条.md|第七条]]第一項若しくは第六項、[[laws/廃棄物の処理及び清掃に関する法律/本文/第14条.md|第十四条]]第一項若しくは第六項又は[[laws/廃棄物の処理及び清掃に関する法律/本文/第14条の4.md|第十四条の四]]第一項若しくは第六項の規定に違反して、一般廃棄物又は産業廃棄物の収集若しくは運搬又は処分を業として行つた者不正の手段により[[laws/廃棄物の処理及び清掃に関する法律/本文/第7条.md|第七条]]第一項若しくは第六項、[[laws/廃棄物の処理及び清掃に関する法律/本文/第14条.md|第十四条]]第一項若しくは第六項又は[[laws/廃棄物の処理及び清掃に関する法律/本文/第14条の4.md|第十四条の四]]第一項若しくは第六項の許可（[[laws/廃棄物の処理及び清掃に関する法律/本文/第7条.md|第七条]]第二項若しくは第七項、[[laws/廃棄物の処理及び清掃に関する法律/本文/第14条.md|第十四条]]第二項若しくは第七項又は[[laws/廃棄物の処理及び清掃に関する法律/本文/第14条の4.md|第十四条の四]]第二項若しくは第七項の許可の更新を含む。）を受けた者[[laws/廃棄物の処理及び清掃に関する法律/本文/第7条の2.md|第七条の二]]第一項、[[laws/廃棄物の処理及び清掃に関する法律/本文/第14条の2.md|第十四条の二]]第一項又は[[laws/廃棄物の処理及び清掃に関する法律/本文/第14条の5.md|第十四条の五]]第一項の規定に違反して、一般廃棄物又は産業廃棄物の収集若しくは運搬又は処分の事業を行つた者不正の手段により[[laws/廃棄物の処理及び清掃に関する法律/本文/第7条の2.md|第七条の二]]第一項、[[laws/廃棄物の処理及び清掃に関する法律/本文/第14条の2.md|第十四条の二]]第一項又は[[laws/廃棄物の処理及び清掃に関する法律/本文/第14条の5.md|第十四条の五]]第一項の変更の許可を受けた者[[laws/廃棄物の処理及び清掃に関する法律/本文/第7条の3.md|第七条の三]]、[[laws/廃棄物の処理及び清掃に関する法律/本文/第14条の3.md|第十四条の三]]（[[laws/廃棄物の処理及び清掃に関する法律/本文/第14条の6.md|第十四条の六]]において読み替えて準用する場合を含む。）、[[laws/廃棄物の処理及び清掃に関する法律/本文/第19条の4.md|第十九条の四]]第一項、[[laws/廃棄物の処理及び清掃に関する法律/本文/第19条の4.md|第十九条の四]]の二第一項、[[laws/廃棄物の処理及び清掃に関する法律/本文/第19条の5.md|第十九条の五]]第一項（[[laws/廃棄物の処理及び清掃に関する法律/本文/第17条の2.md|第十七条の二]]第三項において準用する場合を含む。）又は[[laws/廃棄物の処理及び清掃に関する法律/本文/第19条の6.md|第十九条の六]]第一項の規定による命令に違反した者[[laws/廃棄物の処理及び清掃に関する法律/本文/第6条の2.md|第六条の二]]第六項、[[laws/廃棄物の処理及び清掃に関する法律/本文/第12条.md|第十二条]]第五項又は[[laws/廃棄物の処理及び清掃に関する法律/本文/第12条の2.md|第十二条の二]]第五項の規定に違反して、一般廃棄物又は産業廃棄物の処理を他人に委託した者[[laws/廃棄物の処理及び清掃に関する法律/本文/第7条の5.md|第七条の五]]、[[laws/廃棄物の処理及び清掃に関する法律/本文/第14条の3.md|第十四条の三]]の三又は[[laws/廃棄物の処理及び清掃に関する法律/本文/第14条の7.md|第十四条の七]]の規定に違反して、他人に一般廃棄物又は産業廃棄物の収集若しくは運搬又は処分を業として行わせた者[[laws/廃棄物の処理及び清掃に関する法律/本文/第8条.md|第八条]]第一項又は[[laws/廃棄物の処理及び清掃に関する法律/本文/第15条.md|第十五条]]第一項の規定に違反して、一般廃棄物処理施設又は産業廃棄物処理施設を設置した者不正の手段により[[laws/廃棄物の処理及び清掃に関する法律/本文/第8条.md|第八条]]第一項又は[[laws/廃棄物の処理及び清掃に関する法律/本文/第15条.md|第十五条]]第一項の許可を受けた者[[laws/廃棄物の処理及び清掃に関する法律/本文/第9条.md|第九条]]第一項又は[[laws/廃棄物の処理及び清掃に関する法律/本文/第15条の2.md|第十五条の二]]の六第一項の規定に違反して、[[laws/廃棄物の処理及び清掃に関する法律/本文/第8条.md|第八条]]第二項第四号から第七号までに掲げる事項又は[[laws/廃棄物の処理及び清掃に関する法律/本文/第15条.md|第十五条]]第二項第四号から第七号までに掲げる事項を変更した者不正の手段により[[laws/廃棄物の処理及び清掃に関する法律/本文/第9条.md|第九条]]第一項又は[[laws/廃棄物の処理及び清掃に関する法律/本文/第15条の2.md|第十五条の二]]の六第一項の変更の許可を受けた者[[laws/廃棄物の処理及び清掃に関する法律/本文/第10条.md|第十条]]第一項（[[laws/廃棄物の処理及び清掃に関する法律/本文/第15条の4.md|第十五条の四]]の七第一項において読み替えて準用する場合を含む。）の規定に違反して、一般廃棄物又は産業廃棄物を輸出した者[[laws/廃棄物の処理及び清掃に関する法律/本文/第14条.md|第十四条]]第十五項又は[[laws/廃棄物の処理及び清掃に関する法律/本文/第14条の4.md|第十四条の四]]第十五項の規定に違反して、産業廃棄物の処理を受託した者[[laws/廃棄物の処理及び清掃に関する法律/本文/第16条.md|第十六条]]の規定に違反して、廃棄物を捨てた者[[laws/廃棄物の処理及び清掃に関する法律/本文/第16条の2.md|第十六条の二]]の規定に違反して、廃棄物を焼却した者[[laws/廃棄物の処理及び清掃に関する法律/本文/第16条の3.md|第十六条の三]]の規定に違反して、指定有害廃棄物の保管、収集、運搬又は処分をした者

- 一 [[laws/廃棄物の処理及び清掃に関する法律/本文/第7条.md|第七条]]第一項若しくは第六項、[[laws/廃棄物の処理及び清掃に関する法律/本文/第14条.md|第十四条]]第一項若しくは第六項又は[[laws/廃棄物の処理及び清掃に関する法律/本文/第14条の4.md|第十四条の四]]第一項若しくは第六項の規定に違反して、一般廃棄物又は産業廃棄物の収集若しくは運搬又は処分を業として行つた者
- 二 不正の手段により[[laws/廃棄物の処理及び清掃に関する法律/本文/第7条.md|第七条]]第一項若しくは第六項、[[laws/廃棄物の処理及び清掃に関する法律/本文/第14条.md|第十四条]]第一項若しくは第六項又は[[laws/廃棄物の処理及び清掃に関する法律/本文/第14条の4.md|第十四条の四]]第一項若しくは第六項の許可（[[laws/廃棄物の処理及び清掃に関する法律/本文/第7条.md|第七条]]第二項若しくは第七項、[[laws/廃棄物の処理及び清掃に関する法律/本文/第14条.md|第十四条]]第二項若しくは第七項又は[[laws/廃棄物の処理及び清掃に関する法律/本文/第14条の4.md|第十四条の四]]第二項若しくは第七項の許可の更新を含む。）を受けた者
- 三 [[laws/廃棄物の処理及び清掃に関する法律/本文/第7条の2.md|第七条の二]]第一項、[[laws/廃棄物の処理及び清掃に関する法律/本文/第14条の2.md|第十四条の二]]第一項又は[[laws/廃棄物の処理及び清掃に関する法律/本文/第14条の5.md|第十四条の五]]第一項の規定に違反して、一般廃棄物又は産業廃棄物の収集若しくは運搬又は処分の事業を行つた者
- 四 不正の手段により[[laws/廃棄物の処理及び清掃に関する法律/本文/第7条の2.md|第七条の二]]第一項、[[laws/廃棄物の処理及び清掃に関する法律/本文/第14条の2.md|第十四条の二]]第一項又は[[laws/廃棄物の処理及び清掃に関する法律/本文/第14条の5.md|第十四条の五]]第一項の変更の許可を受けた者
- 五 [[laws/廃棄物の処理及び清掃に関する法律/本文/第7条の3.md|第七条の三]]、[[laws/廃棄物の処理及び清掃に関する法律/本文/第14条の3.md|第十四条の三]]（[[laws/廃棄物の処理及び清掃に関する法律/本文/第14条の6.md|第十四条の六]]において読み替えて準用する場合を含む。）、[[laws/廃棄物の処理及び清掃に関する法律/本文/第19条の4.md|第十九条の四]]第一項、[[laws/廃棄物の処理及び清掃に関する法律/本文/第19条の4.md|第十九条の四]]の二第一項、[[laws/廃棄物の処理及び清掃に関する法律/本文/第19条の5.md|第十九条の五]]第一項（[[laws/廃棄物の処理及び清掃に関する法律/本文/第17条の2.md|第十七条の二]]第三項において準用する場合を含む。）又は[[laws/廃棄物の処理及び清掃に関する法律/本文/第19条の6.md|第十九条の六]]第一項の規定による命令に違反した者
- 六 [[laws/廃棄物の処理及び清掃に関する法律/本文/第6条の2.md|第六条の二]]第六項、[[laws/廃棄物の処理及び清掃に関する法律/本文/第12条.md|第十二条]]第五項又は[[laws/廃棄物の処理及び清掃に関する法律/本文/第12条の2.md|第十二条の二]]第五項の規定に違反して、一般廃棄物又は産業廃棄物の処理を他人に委託した者
- 七 [[laws/廃棄物の処理及び清掃に関する法律/本文/第7条の5.md|第七条の五]]、[[laws/廃棄物の処理及び清掃に関する法律/本文/第14条の3.md|第十四条の三]]の三又は[[laws/廃棄物の処理及び清掃に関する法律/本文/第14条の7.md|第十四条の七]]の規定に違反して、他人に一般廃棄物又は産業廃棄物の収集若しくは運搬又は処分を業として行わせた者
- 八 [[laws/廃棄物の処理及び清掃に関する法律/本文/第8条.md|第八条]]第一項又は[[laws/廃棄物の処理及び清掃に関する法律/本文/第15条.md|第十五条]]第一項の規定に違反して、一般廃棄物処理施設又は産業廃棄物処理施設を設置した者
- 九 不正の手段により[[laws/廃棄物の処理及び清掃に関する法律/本文/第8条.md|第八条]]第一項又は[[laws/廃棄物の処理及び清掃に関する法律/本文/第15条.md|第十五条]]第一項の許可を受けた者

- 十二 [[laws/廃棄物の処理及び清掃に関する法律/本文/第10条.md|第十条]]第一項（[[laws/廃棄物の処理及び清掃に関する法律/本文/第15条の4.md|第十五条の四]]の七第一項において読み替えて準用する場合を含む。）の規定に違反して、一般廃棄物又は産業廃棄物を輸出した者
- 十三 [[laws/廃棄物の処理及び清掃に関する法律/本文/第14条.md|第十四条]]第十五項又は[[laws/廃棄物の処理及び清掃に関する法律/本文/第14条の4.md|第十四条の四]]第十五項の規定に違反して、産業廃棄物の処理を受託した者
- 十四 [[laws/廃棄物の処理及び清掃に関する法律/本文/第16条.md|第十六条]]の規定に違反して、廃棄物を捨てた者
- 十五 [[laws/廃棄物の処理及び清掃に関する法律/本文/第16条の2.md|第十六条の二]]の規定に違反して、廃棄物を焼却した者
- 十六 [[laws/廃棄物の処理及び清掃に関する法律/本文/第16条の3.md|第十六条の三]]の規定に違反して、指定有害廃棄物の保管、収集、運搬又は処分をした者
