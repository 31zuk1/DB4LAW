# 第十四条の三の三 （名義貸しの禁止）

## 
産業廃棄物収集運搬業者及び産業廃棄物処分業者は、自己の名義をもつて、他人に産業廃棄物の収集若しくは運搬又は処分を業として行わせてはならない。
