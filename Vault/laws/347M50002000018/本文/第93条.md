# 第九十三条 （処分等の承継）

## 
法の施行前に次に掲げる沖縄の規則の規定によりされた処分、手続その他の行為は、それぞれ労働省令等の相当規定によりされた処分、手続その他の行為とみなす。沖縄労災規則の規定沖縄失保規則（[[laws/347M50002000018/本文/第5条.md|第五条]]及び[[laws/347M50002000018/本文/第6条.md|第六条]]を除く。）の規定沖縄労基則[[laws/347M50002000018/沖縄の復帰に伴う労働省令等の適用の特別措_law.md|第三十一条]]第二項、[[laws/347M50002000018/沖縄の復帰に伴う労働省令等の適用の特別措_law.md|第三十三条]]第三十七号、[[laws/347M50002000018/沖縄の復帰に伴う労働省令等の適用の特別措_law.md|第三十九条]]、[[laws/347M50002000018/沖縄の復帰に伴う労働省令等の適用の特別措_law.md|第四十一条]]及び[[laws/347M50002000018/沖縄の復帰に伴う労働省令等の適用の特別措_law.md|第四十六条]]の規定沖縄の事業附属寄宿舎規程[[laws/347M50002000018/沖縄の復帰に伴う労働省令等の適用の特別措_law.md|第三十七条]]第一項の規定沖縄女年則[[laws/347M50002000018/本文/第7条.md|第七条]]ただし書の規定削除沖縄の職業安定法施行規則（千九百五十五年規則第百三十号）の規定沖縄軍離職者法規則の規定

- 一 沖縄労災規則の規定
- 二 沖縄失保規則（[[laws/347M50002000018/本文/第5条.md|第五条]]及び[[laws/347M50002000018/本文/第6条.md|第六条]]を除く。）の規定
- 三 沖縄労基則[[laws/347M50002000018/沖縄の復帰に伴う労働省令等の適用の特別措_law.md|第三十一条]]第二項、[[laws/347M50002000018/沖縄の復帰に伴う労働省令等の適用の特別措_law.md|第三十三条]]第三十七号、[[laws/347M50002000018/沖縄の復帰に伴う労働省令等の適用の特別措_law.md|第三十九条]]、[[laws/347M50002000018/沖縄の復帰に伴う労働省令等の適用の特別措_law.md|第四十一条]]及び[[laws/347M50002000018/沖縄の復帰に伴う労働省令等の適用の特別措_law.md|第四十六条]]の規定
- 四 沖縄の事業附属寄宿舎規程[[laws/347M50002000018/沖縄の復帰に伴う労働省令等の適用の特別措_law.md|第三十七条]]第一項の規定
- 五 沖縄女年則[[laws/347M50002000018/本文/第7条.md|第七条]]ただし書の規定
- 六 削除
- 七 沖縄の職業安定法施行規則（千九百五十五年規則第百三十号）の規定
- 八 沖縄軍離職者法規則の規定
