# 第八十一条 

## 
法の施行前に詐欺その他不正の行為によつて沖縄失保法の規定による保険給付を受けた者並びに当該給付に関し、虚偽の届出、報告又は証明をした事業主及び失業保険事務組合については、沖縄失保規則[[laws/沖縄の復帰に伴う労働省令等の適用の特別措置等に関する省令/本文/第45条の4.md|第四十五条の四]]、[[laws/沖縄の復帰に伴う労働省令等の適用の特別措置等に関する省令/本文/第46条の16.md|第四十六条の十六]]、[[laws/沖縄の復帰に伴う労働省令等の適用の特別措置等に関する省令/本文/第52条.md|第五十二条]]、[[laws/沖縄の復帰に伴う労働省令等の適用の特別措置等に関する省令/本文/第53条.md|第五十三条]]第一項及び[[laws/沖縄の復帰に伴う労働省令等の適用の特別措置等に関する省令/本文/第54条.md|第五十四条]]の規定は、なおその効力を有する。
