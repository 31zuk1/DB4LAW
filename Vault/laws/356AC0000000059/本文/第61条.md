# 第六十一条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、三年以下の拘禁刑若しくは三百万円以下の罰金に処し、又はこれを併科する。[[laws/356AC0000000059/本文/第4条.md|第四条]]第一項の規定に違反して、免許を受けないで銀行業を営んだとき。不正の手段により[[laws/356AC0000000059/本文/第4条.md|第四条]]第一項の免許を受けたとき。[[laws/356AC0000000059/本文/第9条.md|第九条]]の規定に違反して、他人に銀行業を営ませたとき。[[laws/356AC0000000059/本文/第13条の4.md|第十三条の四]]、[[laws/356AC0000000059/本文/第52条の2.md|第五十二条の二]]の五、[[laws/356AC0000000059/本文/第52条の45.md|第五十二条の四十五]]の二又は[[laws/356AC0000000059/本文/第52条の60.md|第五十二条の六十]]の十七において準用する金融商品取引法（以下「準用金融商品取引法」という。）第三十九条第一項の規定に違反したとき。[[laws/356AC0000000059/本文/第52条の36.md|第五十二条の三十六]]第一項の規定に違反して、許可を受けないで銀行代理業を営んだとき。不正の手段により[[laws/356AC0000000059/本文/第52条の36.md|第五十二条の三十六]]第一項の許可を受けたとき。[[laws/356AC0000000059/本文/第52条の41.md|第五十二条の四十一]]（[[laws/356AC0000000059/本文/第52条の2.md|第五十二条の二]]の十において準用する場合を含む。）の規定に違反して、他人に銀行代理業（[[laws/356AC0000000059/本文/第52条の2.md|第五十二条の二]]の十において準用する場合にあつては、外国銀行代理業務）を営ませたとき。不正の手段により[[laws/356AC0000000059/本文/第52条の60.md|第五十二条の六十]]の三の登録を受けたとき。[[laws/356AC0000000059/本文/第52条の60.md|第五十二条の六十]]の十の規定に違反して、他人に電子決済等取扱業を営ませたとき。[[laws/356AC0000000059/本文/第52条の60.md|第五十二条の六十]]の二十三第二項の規定による電子決済等代行業の廃止の命令に違反したとき。[[laws/356AC0000000059/本文/第52条の61.md|第五十二条の六十一]]の二の規定に違反して、登録を受けないで電子決済等代行業を営んだとき。不正の手段により[[laws/356AC0000000059/本文/第52条の61.md|第五十二条の六十一]]の二の登録を受けたとき。

- 一 [[laws/356AC0000000059/本文/第4条.md|第四条]]第一項の規定に違反して、免許を受けないで銀行業を営んだとき。
- 二 不正の手段により[[laws/356AC0000000059/本文/第4条.md|第四条]]第一項の免許を受けたとき。
- 三 [[laws/356AC0000000059/本文/第9条.md|第九条]]の規定に違反して、他人に銀行業を営ませたとき。
- 四 [[laws/356AC0000000059/本文/第13条の4.md|第十三条の四]]、[[laws/356AC0000000059/本文/第52条の2.md|第五十二条の二]]の五、[[laws/356AC0000000059/本文/第52条の45.md|第五十二条の四十五]]の二又は[[laws/356AC0000000059/本文/第52条の60.md|第五十二条の六十]]の十七において準用する金融商品取引法（以下「準用金融商品取引法」という。）第三十九条第一項の規定に違反したとき。
- 五 [[laws/356AC0000000059/本文/第52条の36.md|第五十二条の三十六]]第一項の規定に違反して、許可を受けないで銀行代理業を営んだとき。
- 六 不正の手段により[[laws/356AC0000000059/本文/第52条の36.md|第五十二条の三十六]]第一項の許可を受けたとき。
- 七 [[laws/356AC0000000059/本文/第52条の41.md|第五十二条の四十一]]（[[laws/356AC0000000059/本文/第52条の2.md|第五十二条の二]]の十において準用する場合を含む。）の規定に違反して、他人に銀行代理業（[[laws/356AC0000000059/本文/第52条の2.md|第五十二条の二]]の十において準用する場合にあつては、外国銀行代理業務）を営ませたとき。
- 八 不正の手段により[[laws/356AC0000000059/本文/第52条の60.md|第五十二条の六十]]の三の登録を受けたとき。
- 九 [[laws/356AC0000000059/本文/第52条の60.md|第五十二条の六十]]の十の規定に違反して、他人に電子決済等取扱業を営ませたとき。
- 十 [[laws/356AC0000000059/本文/第52条の60.md|第五十二条の六十]]の二十三第二項の規定による電子決済等代行業の廃止の命令に違反したとき。
- 十一 [[laws/356AC0000000059/本文/第52条の61.md|第五十二条の六十一]]の二の規定に違反して、登録を受けないで電子決済等代行業を営んだとき。
- 十二 不正の手段により[[laws/356AC0000000059/本文/第52条の61.md|第五十二条の六十一]]の二の登録を受けたとき。
