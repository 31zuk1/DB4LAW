# 第三条 （登録事項）

## 
名簿に登録する事項は、次のとおりとする。登録番号及び登録年月日氏名一級建築士試験合格の年月及び合格証書番号（外国の建築士免許を受けた者にあつては、その免許の名称、免許者名及び免許の年月日）法[[laws/325M50004000038/本文/第10条.md|第十条]]第一項の規定による戒告、業務停止又は免許の取消しの処分及びこれらの処分を受けた年月日法[[laws/325AC1000000202/本文/第10条の3.md|第十条の三]]第一項第一号若しくは同条第二項第一号又は法[[laws/325M50004000038/本文/第24条.md|第二十四条]]第二項に規定する講習の課程を修了した者にあつては、当該講習を修了した年月日及び当該講習の修了証の番号法[[laws/325M50004000038/本文/第22条の2.md|第二十二条の二]]に定める講習を受けた年月日及び当該講習の修了証の番号[[laws/325M50004000038/本文/第9条の3.md|第九条の三]]第三項の規定により構造設計一級建築士証若しくは設備設計一級建築士証の交付を受けた者にあつては、当該建築士証の番号及び当該建築士証の交付を受けた年月日構造設計一級建築士証若しくは設備設計一級建築士証の返納を行つた者にあつては、当該建築士証の返納を行つた年月日

- 一 登録番号及び登録年月日
- 二 氏名
- 三 一級建築士試験合格の年月及び合格証書番号（外国の建築士免許を受けた者にあつては、その免許の名称、免許者名及び免許の年月日）
- 四 法[[laws/325M50004000038/本文/第10条.md|第十条]]第一項の規定による戒告、業務停止又は免許の取消しの処分及びこれらの処分を受けた年月日
- 五 法[[laws/325AC1000000202/本文/第10条の3.md|第十条の三]]第一項第一号若しくは同条第二項第一号又は法[[laws/325M50004000038/本文/第24条.md|第二十四条]]第二項に規定する講習の課程を修了した者にあつては、当該講習を修了した年月日及び当該講習の修了証の番号
- 六 法[[laws/325M50004000038/本文/第22条の2.md|第二十二条の二]]に定める講習を受けた年月日及び当該講習の修了証の番号
- 七 [[laws/325M50004000038/本文/第9条の3.md|第九条の三]]第三項の規定により構造設計一級建築士証若しくは設備設計一級建築士証の交付を受けた者にあつては、当該建築士証の番号及び当該建築士証の交付を受けた年月日
- 八 構造設計一級建築士証若しくは設備設計一級建築士証の返納を行つた者にあつては、当該建築士証の返納を行つた年月日
