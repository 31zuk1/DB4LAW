# 第三条 （第一種大麻草採取栽培者名簿の記載事項）

## 
法[[laws/大麻草の栽培の規制に関する法律施行規則/本文/第6条.md|第六条]]第一項に規定する第一種大麻草採取栽培者名簿に登録すべき事項は、次に掲げる事項とする。登録番号及び登録年月日住所地、氏名又は名称及び生年月日（法人又は団体であるときは、その業務を行う役員の氏名を含み、生年月日を除く。）栽培地の数、位置及び面積業務上大麻を取り扱う事務所の位置栽培目的免許に付した条件免許証の再交付の事由及び年月日法[[laws/大麻草の栽培の規制に関する法律施行規則/本文/第12条の6.md|第十二条の六]]第二項の規定による登録の抹消の事由及び年月日

- 一 登録番号及び登録年月日
- 二 住所地、氏名又は名称及び生年月日（法人又は団体であるときは、その業務を行う役員の氏名を含み、生年月日を除く。）
- 三 栽培地の数、位置及び面積
- 四 業務上大麻を取り扱う事務所の位置
- 五 栽培目的
- 六 免許に付した条件
- 七 免許証の再交付の事由及び年月日
- 八 法[[laws/大麻草の栽培の規制に関する法律施行規則/本文/第12条の6.md|第十二条の六]]第二項の規定による登録の抹消の事由及び年月日
