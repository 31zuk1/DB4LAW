# 第三条 （健康保険法の一部改正に伴う経過措置）

## 
第一条又は第三条の規定の施行の日前に行われた診療、薬剤の支給若しくは手当又は訪問看護に係るこれらの条の規定による改正前の健康保険法の規定による保険給付については、それぞれなお従前の例による。
