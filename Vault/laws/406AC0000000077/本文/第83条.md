# 第八十三条 

## 
次の各号のいずれかに該当するときは、その違反行為をした者は、五十万円以下の罰金に処する。[[laws/406AC0000000077/本文/第8条.md|第八条]]第一項の許可申請書に虚偽の記載をして提出したとき。[[laws/406AC0000000077/本文/第17条.md|第十七条]]第三項（[[laws/406AC0000000077/本文/第50条.md|第五十条]]第二項において準用する場合を含む。）の規定に違反して、事務所を開設し、又は必要な措置を執らなかったとき。[[laws/406AC0000000077/本文/第24条.md|第二十四条]]第二項（[[laws/406AC0000000077/本文/第50条.md|第五十条]]第二項において準用する場合を含む。）の規定による記名のない書面を不動産特定共同事業契約の申込者に対し交付したとき。[[laws/406AC0000000077/本文/第25条.md|第二十五条]]第二項（[[laws/406AC0000000077/本文/第50条.md|第五十条]]第二項において準用する場合を含む。）の規定による記名のない書面を不動産特定共同事業契約の当事者に対し交付したとき。[[laws/406AC0000000077/本文/第28条.md|第二十八条]]第三項（[[laws/406AC0000000077/本文/第50条.md|第五十条]]第二項において準用する場合を含む。）の規定による記名のない書面を事業参加者に対し交付したとき。[[laws/406AC0000000077/本文/第29条.md|第二十九条]]（[[laws/406AC0000000077/本文/第50条.md|第五十条]]第二項において準用する場合を含む。）の規定に違反して、書類を備え置かず、若しくは事業参加者の求めに応じて閲覧させず、又は虚偽の記載のある書類を備え置き、若しくは事業参加者に閲覧させたとき。[[laws/406AC0000000077/本文/第32条.md|第三十二条]]（[[laws/406AC0000000077/本文/第57条.md|第五十七条]]において準用する場合を含む。）又は[[laws/406AC0000000077/本文/第61条.md|第六十一条]]第一項の規定に違反して、帳簿書類を作成せず、若しくは保存せず、又は虚偽の帳簿書類を作成し、若しくは保存したとき。[[laws/406AC0000000077/本文/第33条.md|第三十三条]]（[[laws/406AC0000000077/本文/第57条.md|第五十七条]]において準用する場合を含む。）又は[[laws/406AC0000000077/本文/第61条.md|第六十一条]]第二項の規定に違反して、事業報告書を作成せず、若しくは提出せず、又は虚偽の事業報告書を作成し、若しくは提出したとき。[[laws/406AC0000000077/本文/第37条.md|第三十七条]]第一項前段若しくは第二項若しくは[[laws/406AC0000000077/本文/第54条.md|第五十四条]]第一項前段若しくは第二項の規定による命令に違反して業務管理者（[[laws/406AC0000000077/本文/第17条.md|第十七条]]第一項（[[laws/406AC0000000077/本文/第50条.md|第五十条]]第二項において準用する場合を含む。）の規定により置かれた者をいう。以下この号において同じ。）を解任せず、又は[[laws/406AC0000000077/本文/第37条.md|第三十七条]]第一項後段（同条第三項において準用する場合を含む。）若しくは[[laws/406AC0000000077/本文/第54条.md|第五十四条]]第一項後段（同条第三項において準用する場合を含む。）の規定に違反して業務管理者を選任したとき。[[laws/406AC0000000077/本文/第40条.md|第四十条]]第一項若しくは[[laws/406AC0000000077/本文/第58条.md|第五十八条]]第九項の規定による命令に違反して、報告をせず、若しくは資料の提出をせず、若しくは虚偽の報告をし、若しくは虚偽の記載のある資料の提出をし、又はこれらの規定による立入検査を拒み、妨げ、若しくは忌避したとき。[[laws/406AC0000000077/本文/第58条.md|第五十八条]]第二項の規定による届出に関し虚偽の届出をしたとき。[[laws/406AC0000000077/本文/第58条.md|第五十八条]]第三項各号に掲げる書類に虚偽の記載をして提出したとき。

- 一 [[laws/406AC0000000077/本文/第8条.md|第八条]]第一項の許可申請書に虚偽の記載をして提出したとき。
- 二 [[laws/406AC0000000077/本文/第17条.md|第十七条]]第三項（[[laws/406AC0000000077/本文/第50条.md|第五十条]]第二項において準用する場合を含む。）の規定に違反して、事務所を開設し、又は必要な措置を執らなかったとき。
- 三 [[laws/406AC0000000077/本文/第24条.md|第二十四条]]第二項（[[laws/406AC0000000077/本文/第50条.md|第五十条]]第二項において準用する場合を含む。）の規定による記名のない書面を不動産特定共同事業契約の申込者に対し交付したとき。
- 四 [[laws/406AC0000000077/本文/第25条.md|第二十五条]]第二項（[[laws/406AC0000000077/本文/第50条.md|第五十条]]第二項において準用する場合を含む。）の規定による記名のない書面を不動産特定共同事業契約の当事者に対し交付したとき。
- 五 [[laws/406AC0000000077/本文/第28条.md|第二十八条]]第三項（[[laws/406AC0000000077/本文/第50条.md|第五十条]]第二項において準用する場合を含む。）の規定による記名のない書面を事業参加者に対し交付したとき。
- 六 [[laws/406AC0000000077/本文/第29条.md|第二十九条]]（[[laws/406AC0000000077/本文/第50条.md|第五十条]]第二項において準用する場合を含む。）の規定に違反して、書類を備え置かず、若しくは事業参加者の求めに応じて閲覧させず、又は虚偽の記載のある書類を備え置き、若しくは事業参加者に閲覧させたとき。
- 七 [[laws/406AC0000000077/本文/第32条.md|第三十二条]]（[[laws/406AC0000000077/本文/第57条.md|第五十七条]]において準用する場合を含む。）又は[[laws/406AC0000000077/本文/第61条.md|第六十一条]]第一項の規定に違反して、帳簿書類を作成せず、若しくは保存せず、又は虚偽の帳簿書類を作成し、若しくは保存したとき。
- 八 [[laws/406AC0000000077/本文/第33条.md|第三十三条]]（[[laws/406AC0000000077/本文/第57条.md|第五十七条]]において準用する場合を含む。）又は[[laws/406AC0000000077/本文/第61条.md|第六十一条]]第二項の規定に違反して、事業報告書を作成せず、若しくは提出せず、又は虚偽の事業報告書を作成し、若しくは提出したとき。
- 九 [[laws/406AC0000000077/本文/第37条.md|第三十七条]]第一項前段若しくは第二項若しくは[[laws/406AC0000000077/本文/第54条.md|第五十四条]]第一項前段若しくは第二項の規定による命令に違反して業務管理者（[[laws/406AC0000000077/本文/第17条.md|第十七条]]第一項（[[laws/406AC0000000077/本文/第50条.md|第五十条]]第二項において準用する場合を含む。）の規定により置かれた者をいう。以下この号において同じ。）を解任せず、又は[[laws/406AC0000000077/本文/第37条.md|第三十七条]]第一項後段（同条第三項において準用する場合を含む。）若しくは[[laws/406AC0000000077/本文/第54条.md|第五十四条]]第一項後段（同条第三項において準用する場合を含む。）の規定に違反して業務管理者を選任したとき。
- 十 [[laws/406AC0000000077/本文/第40条.md|第四十条]]第一項若しくは[[laws/406AC0000000077/本文/第58条.md|第五十八条]]第九項の規定による命令に違反して、報告をせず、若しくは資料の提出をせず、若しくは虚偽の報告をし、若しくは虚偽の記載のある資料の提出をし、又はこれらの規定による立入検査を拒み、妨げ、若しくは忌避したとき。
- 十一 [[laws/406AC0000000077/本文/第58条.md|第五十八条]]第二項の規定による届出に関し虚偽の届出をしたとき。
- 十二 [[laws/406AC0000000077/本文/第58条.md|第五十八条]]第三項各号に掲げる書類に虚偽の記載をして提出したとき。
