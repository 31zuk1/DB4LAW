# 第二十八条の三 （事務の区分）

## 
[[laws/薬剤師法/本文/第8条.md|第八条]]第五項及び第九項前段、同条第十一項及び第十二項（これらの規定を[[laws/薬剤師法/本文/第8条の2.md|第八条の二]]第五項において準用する場合を含む。）、[[laws/薬剤師法/本文/第8条.md|第八条]]第六項において準用する行政手続法第十五条第一項及び第三項（同法第二十二条第三項において準用する場合を含む。）、[[laws/行政手続法/本文/第16条.md|第十六条]]第四項、[[laws/行政手続法/本文/第18条.md|第十八条]]第一項及び第三項、[[laws/行政手続法/本文/第19条.md|第十九条]]第一項、[[laws/行政手続法/本文/第20条.md|第二十条]]第六項並びに[[laws/行政手続法/本文/第24条.md|第二十四条]]第三項、[[laws/行政手続法/本文/第8条.md|第八条]]第九項後段において準用する同法第二十二条第三項において準用する同法第十五条第三項並びに[[laws/行政手続法/本文/第9条.md|第九条]]の規定により都道府県が処理することとされている事務は、地方自治法（昭和二十二年法律第六十七号）第二条第九項第一号に規定する第一号法定受託事務とする。
