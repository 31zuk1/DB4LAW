# 第三十二条 

## 
次の各号のいずれかに該当する者は、五十万円以下の罰金に処する。[[laws/薬剤師法/本文/第8条の2.md|第八条の二]]第一項の規定による命令に違反して再教育研修を受けなかつた者[[laws/薬剤師法/本文/第8条の3.md|第八条の三]]第一項の規定による陳述をせず、報告をせず、若しくは虚偽の陳述若しくは報告をし、物件を提出せず、又は検査を拒み、妨げ、若しくは忌避した者[[laws/薬剤師法/本文/第9条.md|第九条]]の規定に違反した者[[laws/薬剤師法/本文/第19条.md|第十九条]]の規定に違反した医師、歯科医師又は獣医師[[laws/薬剤師法/本文/第20条.md|第二十条]]の規定に違反した者[[laws/薬剤師法/本文/第24条.md|第二十四条]]又は[[laws/薬剤師法/本文/第26条.md|第二十六条]]から[[laws/薬剤師法/本文/第28条.md|第二十八条]]までの規定に違反した者

- 一 [[laws/薬剤師法/本文/第8条の2.md|第八条の二]]第一項の規定による命令に違反して再教育研修を受けなかつた者
- 二 [[laws/薬剤師法/本文/第8条の3.md|第八条の三]]第一項の規定による陳述をせず、報告をせず、若しくは虚偽の陳述若しくは報告をし、物件を提出せず、又は検査を拒み、妨げ、若しくは忌避した者
- 三 [[laws/薬剤師法/本文/第9条.md|第九条]]の規定に違反した者
- 四 [[laws/薬剤師法/本文/第19条.md|第十九条]]の規定に違反した医師、歯科医師又は獣医師
- 五 [[laws/薬剤師法/本文/第20条.md|第二十条]]の規定に違反した者
- 六 [[laws/薬剤師法/本文/第24条.md|第二十四条]]又は[[laws/薬剤師法/本文/第26条.md|第二十六条]]から[[laws/薬剤師法/本文/第28条.md|第二十八条]]までの規定に違反した者
