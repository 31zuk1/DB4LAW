# 第三条の三 

## 
免許は、試験に合格した者の申請により、あん摩マツサージ指圧師名簿、はり師名簿又はきゆう師名簿に登録することによつて行う。

## 
厚生労働大臣は、免許を与えたときは、あん摩マツサージ指圧師免許証、はり師免許証又はきゆう師免許証（以下「免許証」という。）を交付する。
