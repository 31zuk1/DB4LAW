# 第四条 （認可申請書の添付書類）

## 
法[[laws/中小事業主が行う事業に従事する者等の労働災害等に係る共済事業に関する法律施行規則/本文/第5条.md|第五条]]第二項の厚生労働省令で定める書類は、次に掲げる書類（官公署が証明する書類については、法[[laws/中小事業主が行う事業に従事する者等の労働災害等に係る共済事業に関する法律施行規則/本文/第3条.md|第三条]]の認可の申請の日前三月以内に作成されたものに限る。）とする。一般社団法人又は一般財団法人の登記事項証明書共済事業（これに附帯する業務を含む。次号及び第十号において同じ。）に係る事業計画書共済事業以外の事業に係る事業計画書最終の貸借対照表、損益計算書その他の認可申請者の最近における業務、財産及び損益の状況を知ることができる書類一般社団法人にあってはその社員の名簿、一般財団法人にあってはその設立者及び評議員の名簿理事及び監事の履歴書理事及び監事が法[[laws/中小事業主が行う事業に従事する者等の労働災害等に係る共済事業に関する法律施行規則/本文/第6条.md|第六条]]第一項第一号ヘ（１）から（８）までのいずれにも該当しない者であることを当該理事及び監事が誓約する書面純資産額（法[[laws/中小事業主が行う事業に従事する者等の労働災害等に係る共済事業に関する法律施行規則/本文/第5条.md|第五条]]第一項第二号の規定により算定される額をいう。[[laws/中小事業主が行う事業に従事する者等の労働災害等に係る共済事業に関する法律施行規則/本文/第7条.md|第七条]]において同じ。）の算出根拠を記載した書面共済事業に関する知識及び経験を有する役員又は使用人の確保の状況を記載した書類共済事業以外の業務に係る次に掲げる事項を記載した書類当該業務の種類当該業務の方法当該業務の開始年月日又は開始予定年月日当該業務を所掌する組織及び人員配置当該業務の運営に関する内部規則等（内部規則その他これに準ずるものをいう。[[laws/中小事業主が行う事業に従事する者等の労働災害等に係る共済事業に関する法律施行規則/本文/第16条.md|第十六条]]第二項第三号及び[[laws/中小事業主が行う事業に従事する者等の労働災害等に係る共済事業に関する法律施行規則/本文/第23条.md|第二十三条]]において同じ。）認可申請者が子会社等（法[[laws/中小事業主が行う事業に従事する者等の労働災害等に係る共済事業に関する法律施行規則/本文/第11条.md|第十一条]]第四項に規定する子会社等をいう。以下同じ。）を有する場合には、次に掲げる書類当該子会社等の商号又は名称及び主たる営業所又は事務所の所在地を記載した書類当該子会社等の役員（役員が法人であるときは、その職務を行うべき者を含む。[[laws/中小事業主が行う事業に従事する者等の労働災害等に係る共済事業に関する法律施行規則/本文/第30条.md|第三十条]]第三項第二号において同じ。）の役職名及び氏名又は名称を記載した書類当該子会社等の業務の内容を記載した書類当該子会社等の最終の貸借対照表、損益計算書その他の当該子会社等の最近における業務、財産及び損益の状況を知ることができる書類前各号に掲げるもののほか、行政庁が必要と認める書類

- 一 一般社団法人又は一般財団法人の登記事項証明書
- 二 共済事業（これに附帯する業務を含む。次号及び第十号において同じ。）に係る事業計画書
- 三 共済事業以外の事業に係る事業計画書
- 四 最終の貸借対照表、損益計算書その他の認可申請者の最近における業務、財産及び損益の状況を知ることができる書類
- 五 一般社団法人にあってはその社員の名簿、一般財団法人にあってはその設立者及び評議員の名簿
- 六 理事及び監事の履歴書
- 七 理事及び監事が法[[laws/中小事業主が行う事業に従事する者等の労働災害等に係る共済事業に関する法律施行規則/本文/第6条.md|第六条]]第一項第一号ヘ（１）から（８）までのいずれにも該当しない者であることを当該理事及び監事が誓約する書面
- 八 純資産額（法[[laws/中小事業主が行う事業に従事する者等の労働災害等に係る共済事業に関する法律施行規則/本文/第5条.md|第五条]]第一項第二号の規定により算定される額をいう。[[laws/中小事業主が行う事業に従事する者等の労働災害等に係る共済事業に関する法律施行規則/本文/第7条.md|第七条]]において同じ。）の算出根拠を記載した書面
- 九 共済事業に関する知識及び経験を有する役員又は使用人の確保の状況を記載した書類
- 十 共済事業以外の業務に係る次に掲げる事項を記載した書類
- 十一 認可申請者が子会社等（法[[laws/中小事業主が行う事業に従事する者等の労働災害等に係る共済事業に関する法律施行規則/本文/第11条.md|第十一条]]第四項に規定する子会社等をいう。以下同じ。）を有する場合には、次に掲げる書類
- 十二 前各号に掲げるもののほか、行政庁が必要と認める書類
