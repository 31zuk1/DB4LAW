# 第二百条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、百万円以下の罰金に処する。[[laws/ガス事業法/本文/第7条.md|第七条]]第一項の規定に違反して[[laws/ガス事業法/本文/第4条.md|第四条]]第一項第三号から第五号までに掲げる事項を変更したとき。[[laws/ガス事業法/本文/第18条.md|第十八条]]、[[laws/ガス事業法/本文/第23条.md|第二十三条]]、[[laws/ガス事業法/本文/第52条.md|第五十二条]]、[[laws/ガス事業法/本文/第63条.md|第六十三条]]、[[laws/ガス事業法/本文/第78条.md|第七十八条]]又は[[laws/ガス事業法/本文/第91条.md|第九十一条]]の規定に違反して、記録をせず、虚偽の記録をし、又は記録を保存しなかつたとき。[[laws/ガス事業法/本文/第21条.md|第二十一条]]第二項（[[laws/ガス事業法/本文/第105条.md|第百五条]]において準用する場合を含む。）、[[laws/ガス事業法/本文/第61条.md|第六十一条]]第二項（[[laws/ガス事業法/本文/第84条.md|第八十四条]]第一項において準用する場合を含む。）又は[[laws/ガス事業法/本文/第96条.md|第九十六条]]第二項の規定による命令又は処分に違反したとき。[[laws/ガス事業法/本文/第32条.md|第三十二条]]第五項（[[laws/ガス事業法/本文/第105条.md|第百五条]]において準用する場合を含む。）、[[laws/ガス事業法/本文/第68条.md|第六十八条]]第五項（[[laws/ガス事業法/本文/第84条.md|第八十四条]]第一項において準用する場合を含む。）又は[[laws/ガス事業法/本文/第101条.md|第百一条]]第五項の規定による命令に違反してガス工作物の設置又は変更の工事をしたとき。[[laws/ガス事業法/本文/第33条.md|第三十三条]]第一項、[[laws/ガス事業法/本文/第69条.md|第六十九条]]第一項（[[laws/ガス事業法/本文/第84条.md|第八十四条]]第一項において準用する場合を含む。）又は[[laws/ガス事業法/本文/第102条.md|第百二条]]第一項の規定に違反してガス工作物を使用したとき。[[laws/ガス事業法/本文/第41条.md|第四十一条]]第一項、[[laws/ガス事業法/本文/第55条.md|第五十五条]]第七項又は[[laws/ガス事業法/本文/第72条.md|第七十二条]]第七項の規定による届出をせず、又は虚偽の届出をしたとき。[[laws/ガス事業法/本文/第41条.md|第四十一条]]第三項、[[laws/ガス事業法/本文/第55条.md|第五十五条]]第三項（同条第八項において準用する場合を含む。）又は[[laws/ガス事業法/本文/第72条.md|第七十二条]]第三項（同条第八項において準用する場合を含む。）の規定に違反したとき。[[laws/ガス事業法/本文/第51条.md|第五十一条]]第二項の規定に違反してガスを供給したとき。[[laws/ガス事業法/本文/第55条.md|第五十五条]]第一項又は[[laws/ガス事業法/本文/第72条.md|第七十二条]]第一項の規定による届出をせず、又は虚偽の届出をして特定ガス導管事業を営んだとき。[[laws/ガス事業法/本文/第55条.md|第五十五条]]第二項（同条第八項において準用する場合を含む。）、[[laws/ガス事業法/本文/第72条.md|第七十二条]]第二項（同条第八項において準用する場合を含む。）又は[[laws/ガス事業法/本文/第86条.md|第八十六条]]第二項の規定に違反して添付書類を提出せず、又は添付書類に虚偽の記載をして提出したとき。[[laws/ガス事業法/本文/第85条.md|第八十五条]]第三項又は[[laws/ガス事業法/本文/第106条の3.md|第百六条の三]]第一項の規定による命令に違反したとき。[[laws/ガス事業法/本文/第86条.md|第八十六条]]第一項の規定による届出をせず、又は虚偽の届出をしてガス製造事業を営んだとき。[[laws/ガス事業法/本文/第162条.md|第百六十二条]]の規定に違反したとき。

- 一 [[laws/ガス事業法/本文/第7条.md|第七条]]第一項の規定に違反して[[laws/ガス事業法/本文/第4条.md|第四条]]第一項第三号から第五号までに掲げる事項を変更したとき。
- 二 [[laws/ガス事業法/本文/第18条.md|第十八条]]、[[laws/ガス事業法/本文/第23条.md|第二十三条]]、[[laws/ガス事業法/本文/第52条.md|第五十二条]]、[[laws/ガス事業法/本文/第63条.md|第六十三条]]、[[laws/ガス事業法/本文/第78条.md|第七十八条]]又は[[laws/ガス事業法/本文/第91条.md|第九十一条]]の規定に違反して、記録をせず、虚偽の記録をし、又は記録を保存しなかつたとき。
- 三 [[laws/ガス事業法/本文/第21条.md|第二十一条]]第二項（[[laws/ガス事業法/本文/第105条.md|第百五条]]において準用する場合を含む。）、[[laws/ガス事業法/本文/第61条.md|第六十一条]]第二項（[[laws/ガス事業法/本文/第84条.md|第八十四条]]第一項において準用する場合を含む。）又は[[laws/ガス事業法/本文/第96条.md|第九十六条]]第二項の規定による命令又は処分に違反したとき。
- 四 [[laws/ガス事業法/本文/第32条.md|第三十二条]]第五項（[[laws/ガス事業法/本文/第105条.md|第百五条]]において準用する場合を含む。）、[[laws/ガス事業法/本文/第68条.md|第六十八条]]第五項（[[laws/ガス事業法/本文/第84条.md|第八十四条]]第一項において準用する場合を含む。）又は[[laws/ガス事業法/本文/第101条.md|第百一条]]第五項の規定による命令に違反してガス工作物の設置又は変更の工事をしたとき。
- 五 [[laws/ガス事業法/本文/第33条.md|第三十三条]]第一項、[[laws/ガス事業法/本文/第69条.md|第六十九条]]第一項（[[laws/ガス事業法/本文/第84条.md|第八十四条]]第一項において準用する場合を含む。）又は[[laws/ガス事業法/本文/第102条.md|第百二条]]第一項の規定に違反してガス工作物を使用したとき。
- 六 [[laws/ガス事業法/本文/第41条.md|第四十一条]]第一項、[[laws/ガス事業法/本文/第55条.md|第五十五条]]第七項又は[[laws/ガス事業法/本文/第72条.md|第七十二条]]第七項の規定による届出をせず、又は虚偽の届出をしたとき。
- 七 [[laws/ガス事業法/本文/第41条.md|第四十一条]]第三項、[[laws/ガス事業法/本文/第55条.md|第五十五条]]第三項（同条第八項において準用する場合を含む。）又は[[laws/ガス事業法/本文/第72条.md|第七十二条]]第三項（同条第八項において準用する場合を含む。）の規定に違反したとき。
- 八 [[laws/ガス事業法/本文/第51条.md|第五十一条]]第二項の規定に違反してガスを供給したとき。
- 九 [[laws/ガス事業法/本文/第55条.md|第五十五条]]第一項又は[[laws/ガス事業法/本文/第72条.md|第七十二条]]第一項の規定による届出をせず、又は虚偽の届出をして特定ガス導管事業を営んだとき。
- 十 [[laws/ガス事業法/本文/第55条.md|第五十五条]]第二項（同条第八項において準用する場合を含む。）、[[laws/ガス事業法/本文/第72条.md|第七十二条]]第二項（同条第八項において準用する場合を含む。）又は[[laws/ガス事業法/本文/第86条.md|第八十六条]]第二項の規定に違反して添付書類を提出せず、又は添付書類に虚偽の記載をして提出したとき。
- 十一 [[laws/ガス事業法/本文/第85条.md|第八十五条]]第三項又は[[laws/ガス事業法/本文/第106条の3.md|第百六条の三]]第一項の規定による命令に違反したとき。
- 十二 [[laws/ガス事業法/本文/第86条.md|第八十六条]]第一項の規定による届出をせず、又は虚偽の届出をしてガス製造事業を営んだとき。
- 十三 [[laws/ガス事業法/本文/第162条.md|第百六十二条]]の規定に違反したとき。
