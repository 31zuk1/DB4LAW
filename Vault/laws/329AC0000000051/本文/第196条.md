# 第百九十六条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、一年以下の拘禁刑若しくは百万円以下の罰金に処し、又はこれを併科する。[[laws/ガス事業法/本文/第3条.md|第三条]]の規定に違反してガス小売事業を営んだとき。[[laws/ガス事業法/本文/第17条.md|第十七条]]第一項の規定に違反してその名義を他人にガス小売事業のため利用させたとき。[[laws/ガス事業法/本文/第17条.md|第十七条]]第二項の規定に違反してガス小売事業を他人にその名において経営させたとき。[[laws/ガス事業法/本文/第54条の2.md|第五十四条の二]]又は[[laws/ガス事業法/本文/第80条の2.md|第八十条の二]]の規定に違反してガス小売事業又はガス製造事業を営んだとき。[[laws/ガス事業法/本文/第134条.md|第百三十四条]]（[[laws/ガス事業法/本文/第153条.md|第百五十三条]]第二項において準用する場合を含む。）の規定による検査又は適合性検査の業務の停止の命令に違反したとき。[[laws/ガス事業法/本文/第138条.md|第百三十八条]]第一項の規定に違反したとき。[[laws/ガス事業法/本文/第139条.md|第百三十九条]]の規定に違反して表示を付したとき。[[laws/ガス事業法/本文/第149条.md|第百四十九条]]第一項（第一号に係る部分に限る。）の規定による禁止に違反したとき。[[laws/ガス事業法/本文/第157条.md|第百五十七条]]の規定による命令に違反したとき。

- 一 [[laws/ガス事業法/本文/第3条.md|第三条]]の規定に違反してガス小売事業を営んだとき。
- 二 [[laws/ガス事業法/本文/第17条.md|第十七条]]第一項の規定に違反してその名義を他人にガス小売事業のため利用させたとき。
- 三 [[laws/ガス事業法/本文/第17条.md|第十七条]]第二項の規定に違反してガス小売事業を他人にその名において経営させたとき。
- 四 [[laws/ガス事業法/本文/第54条の2.md|第五十四条の二]]又は[[laws/ガス事業法/本文/第80条の2.md|第八十条の二]]の規定に違反してガス小売事業又はガス製造事業を営んだとき。
- 五 [[laws/ガス事業法/本文/第134条.md|第百三十四条]]（[[laws/ガス事業法/本文/第153条.md|第百五十三条]]第二項において準用する場合を含む。）の規定による検査又は適合性検査の業務の停止の命令に違反したとき。
- 六 [[laws/ガス事業法/本文/第138条.md|第百三十八条]]第一項の規定に違反したとき。
- 七 [[laws/ガス事業法/本文/第139条.md|第百三十九条]]の規定に違反して表示を付したとき。
- 八 [[laws/ガス事業法/本文/第149条.md|第百四十九条]]第一項（第一号に係る部分に限る。）の規定による禁止に違反したとき。
- 九 [[laws/ガス事業法/本文/第157条.md|第百五十七条]]の規定による命令に違反したとき。
