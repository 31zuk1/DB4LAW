# 第百六十五条 （公示）

## 
経済産業大臣は、次の場合には、その旨を官報に公示しなければならない。[[laws/329AC0000000051/本文/第29条.md|第二十九条]]第三項の指定をしたとき。[[laws/329AC0000000051/本文/第33条.md|第三十三条]]第一項、[[laws/329AC0000000051/本文/第69条.md|第六十九条]]第一項（[[laws/329AC0000000051/本文/第84条.md|第八十四条]]第一項において準用する場合を含む。）、[[laws/329AC0000000051/本文/第102条.md|第百二条]]第一項又は[[laws/329AC0000000051/本文/第146条.md|第百四十六条]]第一項の登録をしたとき。[[laws/329AC0000000051/本文/第113条.md|第百十三条]]の許可をしたとき。[[laws/329AC0000000051/本文/第120条.md|第百二十条]]の規定により指定を取り消し、又は同条第二項の規定により試験事務の全部若しくは一部の停止を命じたとき。[[laws/329AC0000000051/本文/第122条.md|第百二十二条]]第一項の規定により経済産業大臣が試験事務の全部若しくは一部を自ら行うものとするとき、又は自ら行つていたその試験事務の全部若しくは一部を行わないこととするとき。[[laws/329AC0000000051/本文/第128条.md|第百二十八条]]（[[laws/329AC0000000051/本文/第153条.md|第百五十三条]]第二項及び[[laws/329AC0000000051/本文/第155条.md|第百五十五条]]第二項において準用する場合を含む。）の規定による届出があつたとき。[[laws/329AC0000000051/本文/第130条.md|第百三十条]]（[[laws/329AC0000000051/本文/第153条.md|第百五十三条]]第二項及び[[laws/329AC0000000051/本文/第155条.md|第百五十五条]]第二項において準用する場合を含む。）の規定による届出があつたとき。[[laws/329AC0000000051/本文/第134条.md|第百三十四条]]（[[laws/329AC0000000051/本文/第153条.md|第百五十三条]]第二項において準用する場合を含む。）の規定により登録を取り消し、又は検査若しくは適合性検査の業務の停止を命じたとき。[[laws/329AC0000000051/本文/第136条.md|第百三十六条]]第一項の規定により経済産業大臣が検査の業務の全部若しくは一部を自ら行うものとするとき、又は自ら行つていた検査の業務の全部若しくは一部を行わないこととするとき。[[laws/329AC0000000051/本文/第149条.md|第百四十九条]]の規定により表示を付することを禁止したとき。[[laws/329AC0000000051/本文/第154条.md|第百五十四条]]第一項の規定により経済産業大臣が適合性検査の業務の全部若しくは一部を自ら行うものとするとき、又は自ら行つていた適合性検査の業務の全部若しくは一部を行わないこととするとき。[[laws/329AC0000000051/本文/第154条.md|第百五十四条]]第二項の規定により経済産業大臣が機構に適合性検査の業務の全部若しくは一部を行わせることとするとき、又は機構に行わせていた適合性検査の業務の全部若しくは一部を行わせないこととするとき。[[laws/329AC0000000051/本文/第156条.md|第百五十六条]]第一項の規定により登録を取り消したとき。

- 一 [[laws/329AC0000000051/本文/第29条.md|第二十九条]]第三項の指定をしたとき。
- 二 [[laws/329AC0000000051/本文/第33条.md|第三十三条]]第一項、[[laws/329AC0000000051/本文/第69条.md|第六十九条]]第一項（[[laws/329AC0000000051/本文/第84条.md|第八十四条]]第一項において準用する場合を含む。）、[[laws/329AC0000000051/本文/第102条.md|第百二条]]第一項又は[[laws/329AC0000000051/本文/第146条.md|第百四十六条]]第一項の登録をしたとき。
- 三 [[laws/329AC0000000051/本文/第113条.md|第百十三条]]の許可をしたとき。
- 四 [[laws/329AC0000000051/本文/第120条.md|第百二十条]]の規定により指定を取り消し、又は同条第二項の規定により試験事務の全部若しくは一部の停止を命じたとき。
- 五 [[laws/329AC0000000051/本文/第122条.md|第百二十二条]]第一項の規定により経済産業大臣が試験事務の全部若しくは一部を自ら行うものとするとき、又は自ら行つていたその試験事務の全部若しくは一部を行わないこととするとき。
- 六 [[laws/329AC0000000051/本文/第128条.md|第百二十八条]]（[[laws/329AC0000000051/本文/第153条.md|第百五十三条]]第二項及び[[laws/329AC0000000051/本文/第155条.md|第百五十五条]]第二項において準用する場合を含む。）の規定による届出があつたとき。
- 七 [[laws/329AC0000000051/本文/第130条.md|第百三十条]]（[[laws/329AC0000000051/本文/第153条.md|第百五十三条]]第二項及び[[laws/329AC0000000051/本文/第155条.md|第百五十五条]]第二項において準用する場合を含む。）の規定による届出があつたとき。
- 八 [[laws/329AC0000000051/本文/第134条.md|第百三十四条]]（[[laws/329AC0000000051/本文/第153条.md|第百五十三条]]第二項において準用する場合を含む。）の規定により登録を取り消し、又は検査若しくは適合性検査の業務の停止を命じたとき。
- 九 [[laws/329AC0000000051/本文/第136条.md|第百三十六条]]第一項の規定により経済産業大臣が検査の業務の全部若しくは一部を自ら行うものとするとき、又は自ら行つていた検査の業務の全部若しくは一部を行わないこととするとき。
- 十 [[laws/329AC0000000051/本文/第149条.md|第百四十九条]]の規定により表示を付することを禁止したとき。
- 十一 [[laws/329AC0000000051/本文/第154条.md|第百五十四条]]第一項の規定により経済産業大臣が適合性検査の業務の全部若しくは一部を自ら行うものとするとき、又は自ら行つていた適合性検査の業務の全部若しくは一部を行わないこととするとき。
- 十二 [[laws/329AC0000000051/本文/第154条.md|第百五十四条]]第二項の規定により経済産業大臣が機構に適合性検査の業務の全部若しくは一部を行わせることとするとき、又は機構に行わせていた適合性検査の業務の全部若しくは一部を行わせないこととするとき。
- 十三 [[laws/329AC0000000051/本文/第156条.md|第百五十六条]]第一項の規定により登録を取り消したとき。
