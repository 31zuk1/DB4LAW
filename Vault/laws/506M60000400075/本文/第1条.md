# 第一条 （定義）

## 
この省令において、次の各号に掲げる用語の意義は、それぞれ当該各号に定めるところによる。添付書面登録の申請をする場合において、二酸化炭素の貯留事業に関する法律[[laws/506M60000400075/本文/第2条.md|第二条]]第八項に規定する試掘権の登録に関する政令（以下「令」という。）[[laws/506M60000400075/本文/第17条.md|第十七条]]本文若しくは[[laws/506M60000400075/本文/第24条.md|第二十四条]]の規定、第三章の規定又はその他の法令の規定によりその申請書と併せて経済産業大臣に提出しなければならないものとされている書面をいう。嘱託書令[[laws/506M60000400075/本文/第12条.md|第十二条]]第一項に規定する登録の嘱託において、同条第二項において準用する令[[laws/506M60000400075/本文/第13条.md|第十三条]]の規定により嘱託者が経済産業大臣に提出しなければならない書面をいう。順位事項[[laws/506M60000400075/本文/第49条.md|第四十九条]]第一項の規定により権利部に記録される番号（以下「順位番号」という。）及び同条第二項の規定により権利部に記録される符号をいう。許可試掘区域図許可試掘区域（二酸化炭素の貯留事業に関する法律（令和六年法律第三十八号。以下「法」という。）[[laws/506M60000400075/本文/第14条.md|第十四条]]第二項第二号に規定する許可試掘区域をいう。以下同じ。）を示す図面をいう。申請書申請書記載事項を記載した書面をいう。試掘権番号[[laws/506M60000400075/本文/第44条.md|第四十四条]]の規定により表題部に記録される番号、記号その他の符号をいう。

- 一 添付書面登録の申請をする場合において、二酸化炭素の貯留事業に関する法律[[laws/506M60000400075/本文/第2条.md|第二条]]第八項に規定する試掘権の登録に関する政令（以下「令」という。）[[laws/506M60000400075/本文/第17条.md|第十七条]]本文若しくは[[laws/506M60000400075/本文/第24条.md|第二十四条]]の規定、第三章の規定又はその他の法令の規定によりその申請書と併せて経済産業大臣に提出しなければならないものとされている書面をいう。
- 二 嘱託書令[[laws/506M60000400075/本文/第12条.md|第十二条]]第一項に規定する登録の嘱託において、同条第二項において準用する令[[laws/506M60000400075/本文/第13条.md|第十三条]]の規定により嘱託者が経済産業大臣に提出しなければならない書面をいう。
- 三 順位事項[[laws/506M60000400075/本文/第49条.md|第四十九条]]第一項の規定により権利部に記録される番号（以下「順位番号」という。）及び同条第二項の規定により権利部に記録される符号をいう。
- 四 許可試掘区域図許可試掘区域（二酸化炭素の貯留事業に関する法律（令和六年法律第三十八号。以下「法」という。）[[laws/506M60000400075/本文/第14条.md|第十四条]]第二項第二号に規定する許可試掘区域をいう。以下同じ。）を示す図面をいう。
- 五 申請書申請書記載事項を記載した書面をいう。
- 六 試掘権番号[[laws/506M60000400075/本文/第44条.md|第四十四条]]の規定により表題部に記録される番号、記号その他の符号をいう。
