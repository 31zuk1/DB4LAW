# 第八十九条 

## 
次の各号のいずれかに該当する者は、五十万円以下の罰金に処する。[[laws/412AC0000000117/本文/第12条.md|第十二条]]第一項又は第二項の規定による届出をせず、又は虚偽の届出をした者[[laws/412AC0000000117/本文/第13条.md|第十三条]]第一項の承認を受けないで[[laws/412AC0000000117/本文/第11条.md|第十一条]]第一項の拠出金又は[[laws/412AC0000000117/本文/第11条の2.md|第十一条の二]]第一項の拠出金を納付する機構を変更した者[[laws/412AC0000000117/本文/第23条.md|第二十三条]]第一項の規定による報告をせず、又は虚偽の報告をした者[[laws/412AC0000000117/本文/第23条.md|第二十三条]]第一項の規定による検査又は調査を拒み、妨げ、又は忌避した者[[laws/412AC0000000117/本文/第25条.md|第二十五条]]第五項の規定に違反して、同条第一項の規定による立入りその他の行為を拒み、又は妨げた者[[laws/412AC0000000117/本文/第62条.md|第六十二条]]第二項の規定による資料を提出せず、又は虚偽の資料を提出した者[[laws/412AC0000000117/本文/第84条.md|第八十四条]]第一項の規定による報告をせず、又は虚偽の報告をした者[[laws/412AC0000000117/本文/第84条.md|第八十四条]]第一項の規定による検査を拒み、妨げ、又は忌避した者

- 一 [[laws/412AC0000000117/本文/第12条.md|第十二条]]第一項又は第二項の規定による届出をせず、又は虚偽の届出をした者
- 二 [[laws/412AC0000000117/本文/第13条.md|第十三条]]第一項の承認を受けないで[[laws/412AC0000000117/本文/第11条.md|第十一条]]第一項の拠出金又は[[laws/412AC0000000117/本文/第11条の2.md|第十一条の二]]第一項の拠出金を納付する機構を変更した者
- 三 [[laws/412AC0000000117/本文/第23条.md|第二十三条]]第一項の規定による報告をせず、又は虚偽の報告をした者
- 四 [[laws/412AC0000000117/本文/第23条.md|第二十三条]]第一項の規定による検査又は調査を拒み、妨げ、又は忌避した者
- 五 [[laws/412AC0000000117/本文/第25条.md|第二十五条]]第五項の規定に違反して、同条第一項の規定による立入りその他の行為を拒み、又は妨げた者
- 六 [[laws/412AC0000000117/本文/第62条.md|第六十二条]]第二項の規定による資料を提出せず、又は虚偽の資料を提出した者
- 七 [[laws/412AC0000000117/本文/第84条.md|第八十四条]]第一項の規定による報告をせず、又は虚偽の報告をした者
- 八 [[laws/412AC0000000117/本文/第84条.md|第八十四条]]第一項の規定による検査を拒み、妨げ、又は忌避した者
