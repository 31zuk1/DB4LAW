# 第一条 （施行期日）

## 
この法律は、平成二十五年四月一日から施行する。ただし、次の各号に掲げる規定は、当該各号に定める日から施行する。次に掲げる規定平成二十五年六月一日略第十条中東日本大震災からの復興のための施策を実施するために必要な財源の確保に関する特別措置法[[laws/東日本大震災からの復興のための施策を実施するために必要な財源の確保に関する特別措置法/本文/第33条.md|第三十三条]]第一項の表租税特別措置法の項の改正規定略次に掲げる規定平成二十八年一月一日略[[laws/東日本大震災からの復興のための施策を実施するために必要な財源の確保に関する特別措置法/本文/第10条.md|第十条]]中東日本大震災からの復興のための施策を実施するために必要な財源の確保に関する特別措置法[[laws/東日本大震災からの復興のための施策を実施するために必要な財源の確保に関する特別措置法/本文/第6条.md|第六条]]第七号の改正規定、同法第十条の改正規定及び同法第二十八条第一項の改正規定略次に掲げる規定福島復興再生特別措置法の一部を改正する法律（平成二十五年法律第十二号）の施行の日略第十条中東日本大震災からの復興のための施策を実施するために必要な財源の確保に関する特別措置法[[laws/東日本大震災からの復興のための施策を実施するために必要な財源の確保に関する特別措置法/本文/第52条.md|第五十二条]]第二項第四号の改正規定（「[[laws/東日本大震災からの復興のための施策を実施するために必要な財源の確保に関する特別措置法/本文/第25条の3.md|第二十五条の三]]第一項並びに[[laws/東日本大震災からの復興のための施策を実施するために必要な財源の確保に関する特別措置法/本文/第25条の3.md|第二十五条の三]]の二第一項」を「[[laws/東日本大震災からの復興のための施策を実施するために必要な財源の確保に関する特別措置法/本文/第25条の2.md|第二十五条の二]]の三第二項及び第三項、[[laws/東日本大震災からの復興のための施策を実施するために必要な財源の確保に関する特別措置法/本文/第25条の3.md|第二十五条の三]]第一項、[[laws/東日本大震災からの復興のための施策を実施するために必要な財源の確保に関する特別措置法/本文/第25条の3.md|第二十五条の三]]の二第一項並びに[[laws/東日本大震災からの復興のための施策を実施するために必要な財源の確保に関する特別措置法/本文/第25条の3.md|第二十五条の三]]の三第一項」に改める部分に限る。）

- 一 次に掲げる規定平成二十五年六月一日
- 二から五まで 略
- 六 次に掲げる規定平成二十八年一月一日
- 七から九まで 略
- 十 次に掲げる規定福島復興再生特別措置法の一部を改正する法律（平成二十五年法律第十二号）の施行の日
