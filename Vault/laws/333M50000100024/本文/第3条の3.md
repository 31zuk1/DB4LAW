# 第三条の三 （免許証の再交付申請）

## 
令[[laws/臨床検査技師等に関する法律施行規則/本文/第6条.md|第六条]]第二項の免許証の再交付の申請書は、様式第四によるものとする。

## ２
前項の申請書には、戸籍の謄本若しくは抄本又は住民票の写しを添えなければならない。

## ３
令[[laws/臨床検査技師等に関する法律施行規則/本文/第6条.md|第六条]]第三項の手数料の額は、三千百円とする。
