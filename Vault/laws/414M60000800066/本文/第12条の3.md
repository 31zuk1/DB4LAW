# 第十二条の三 （法第四十六条第十四項第二号イの国土交通省令で定める公園施設の種類）

## 
法[[laws/414M60000800066/本文/第46条.md|第四十六条]]第十四項第二号イの国土交通省令で定める公園施設は、次に掲げるものとする。休養施設遊戯施設運動施設教養施設便益施設都市公園法施行令[[laws/414M60000800066/本文/第5条.md|第五条]]第八項に規定する施設のうち、展望台又は集会所

- 一 休養施設
- 二 遊戯施設
- 三 運動施設
- 四 教養施設
- 五 便益施設
- 六 都市公園法施行令[[laws/414M60000800066/本文/第5条.md|第五条]]第八項に規定する施設のうち、展望台又は集会所
