# 第五十九条の三 （吸収合併存続会員商品取引所の事後開示事項）

## 
法[[laws/325AC0000000239/本文/第144条の2.md|第百四十四条の二]]第五項の主務省令で定める事項は、次に掲げるものとする。吸収合併の効力が生じた日吸収合併消滅会員商品取引所における次に掲げる事項法[[laws/417M60000600003/本文/第144条.md|第百四十四条]]第五項の規定による請求に係る手続の経過法[[laws/417M60000600003/本文/第144条.md|第百四十四条]]第六項において準用する法[[laws/417M60000600003/本文/第124条.md|第百二十四条]]の規定による手続の経過吸収合併存続会員商品取引所における次に掲げる事項法[[laws/325AC0000000239/本文/第144条の2.md|第百四十四条の二]]第三項の規定による請求に係る手続の経過法[[laws/325AC0000000239/本文/第144条の2.md|第百四十四条の二]]第四項において準用する法[[laws/417M60000600003/本文/第124条.md|第百二十四条]]の規定による手続の経過吸収合併により吸収合併存続会員商品取引所が吸収合併消滅会員商品取引所から承継した重要な権利義務に関する事項法[[laws/417M60000600003/本文/第144条.md|第百四十四条]]第一項の規定により吸収合併消滅会員商品取引所が備え置いた書面又は電磁的記録に記載又は記録がされた事項（吸収合併契約の内容を除く。）法[[laws/417M60000600003/本文/第147条.md|第百四十七条]]第一項の変更の登記をした日前各号に掲げるもののほか、吸収合併に関する重要な事項

- 一 吸収合併の効力が生じた日
- 二 吸収合併消滅会員商品取引所における次に掲げる事項
- 三 吸収合併存続会員商品取引所における次に掲げる事項
- 四 吸収合併により吸収合併存続会員商品取引所が吸収合併消滅会員商品取引所から承継した重要な権利義務に関する事項
- 五 法[[laws/417M60000600003/本文/第144条.md|第百四十四条]]第一項の規定により吸収合併消滅会員商品取引所が備え置いた書面又は電磁的記録に記載又は記録がされた事項（吸収合併契約の内容を除く。）
- 六 法[[laws/417M60000600003/本文/第147条.md|第百四十七条]]第一項の変更の登記をした日
- 七 前各号に掲げるもののほか、吸収合併に関する重要な事項
