# 第六十条 （合併認可の申請書の添付書類）

## 
法[[laws/商品先物取引法施行規則/本文/第145条.md|第百四十五条]]第三項の主務省令で定める書面は、次に掲げる書面（官公署が証明する書面の場合には、認可の申請の日前三月以内に作成されたものに限る。）とする。合併の理由を記載した書面次に掲げる場合に応じ、それぞれ次に定める書面合併後存続する商品取引所又は合併により設立される商品取引所の役員が外国人である場合当該役員の住民票の写し等、履歴書及びその者が法[[laws/商品先物取引法施行規則/本文/第15条.md|第十五条]]第二項第一号イからルまでのいずれにも該当しないことを誓約する書面合併後存続する商品取引所又は合併により設立される商品取引所の役員が法人である場合当該役員の登記事項証明書、沿革を記載した書面及び法[[laws/商品先物取引法施行規則/本文/第15条.md|第十五条]]第二項第一号ヲに該当しないことを誓約する書面合併後存続する商品取引所又は合併により設立される商品取引所の役員が外国人又は法人でない場合当該役員の住民票の写し等、履歴書、その者が法[[laws/商品先物取引法施行規則/本文/第15条.md|第十五条]]第二項第一号ロに該当しない旨の官公署の証明書並びにその者が同号イ及びハからルまでのいずれにも該当しないことを誓約する書面会員等の氏名又は商号若しくは名称及び主たる事務所又は本店の所在地を記載した書面、その者が法[[laws/商品先物取引法施行規則/本文/第31条.md|第三十一条]]第一項各号のいずれにも該当しないことを誓約する書面並びに申請に係る商品取引所が開設しようとする一以上の商品市場において法[[laws/商品先物取引法施行規則/本文/第105条.md|第百五条]]第一号に掲げる方法により決済を行う場合には認可の申請の日前三十日以内に様式第一号により作成したその者の純資産額に関する調書合併を行う各商品取引所の合併総会（会員商品取引所にあっては、法[[laws/商品先物取引法施行規則/本文/第144条.md|第百四十四条]]第四項、[[laws/商品先物取引法施行規則/本文/第144条の2.md|第百四十四条の二]]第二項又は[[laws/商品先物取引法施行規則/本文/第144条の3.md|第百四十四条の三]]第四項の会員総会をいい、株式会社商品取引所にあっては、法[[laws/商品先物取引法施行規則/本文/第144条の6.md|第百四十四条の六]]第一項、[[laws/商品先物取引法施行規則/本文/第144条の14.md|第百四十四条の十四]]第一項、会社法[[laws/会社法/本文/第783条.md|第七百八十三条]]第一項、[[laws/会社法/本文/第795条.md|第七百九十五条]]第一項又は[[laws/会社法/本文/第804条.md|第八百四条]]第一項の株主総会をいう。）の議事録その他必要な手続があったことを証する書面合併を行う各商品取引所の財産及び収支の状況を知ることができる書面（会員商品取引所にあっては最終事業年度の決算関係書類等、株式会社商品取引所にあっては最終事業年度の計算書類等及びその附属明細書）法[[laws/商品先物取引法施行規則/本文/第144条.md|第百四十四条]]第六項、[[laws/商品先物取引法施行規則/本文/第144条の2.md|第百四十四条の二]]第四項及び[[laws/商品先物取引法施行規則/本文/第144条の3.md|第百四十四条の三]]第六項において準用する法[[laws/商品先物取引法施行規則/本文/第124条.md|第百二十四条]]第二項、[[laws/会社法/本文/第144条の11.md|第百四十四条の十一]]第二項（[[laws/商品先物取引法施行規則/本文/第144条の19.md|第百四十四条の十九]]において準用する場合を含む。）、会社法[[laws/会社法/本文/第789条.md|第七百八十九条]]第二項、[[laws/会社法/本文/第799条.md|第七百九十九条]]第二項又は[[laws/会社法/本文/第810条.md|第八百十条]]第二項の規定による公告及び催告（[[laws/会社法/本文/第124条.md|第百二十四条]]第三項、[[laws/会社法/本文/第144条の11.md|第百四十四条の十一]]第三項（[[laws/会社法/本文/第144条の19.md|第百四十四条の十九]]において準用する場合を含む。）、会社法[[laws/会社法/本文/第789条.md|第七百八十九条]]第三項、[[laws/会社法/本文/第799条.md|第七百九十九条]]第三項又は[[laws/会社法/本文/第810条.md|第八百十条]]第三項の規定により公告を官報のほか時事に関する事項を掲載する日刊新聞紙又は電子公告によってした場合にあっては、これらの方法による公告）をしたこと並びに異議を述べた債権者があるときは、当該債権者に対し弁済し若しくは相当の担保を提供し若しくは当該債権者に弁済を受けさせることを目的として相当の財産を信託したこと又は当該合併をしても当該債権者を害するおそれがないことを証する書面合併により消滅する商品取引所の開設している商品市場における取引に関する業務の承継の方法を記載した書面商品取引所の業務に関する知識及び経験を有する従業員の確保の状況並びに当該従業員の配置の状況を記載した書面（合併後の商品取引所が株式会社商品取引所である場合に限る。）開設しようとする商品市場における合併後一年間の先物取引の取引量の見込みを記載した書面合併に際して上場商品に係る商品市場を開設しようとする場合にあっては、上場商品構成品を一の商品市場で取引をすることが適当である旨を明らかにすることができる書面合併に際して二以上の商品指数を一の上場商品指数として商品市場を開設しようとする場合にあっては、当該二以上の商品指数の対象となる物品又は電力の大部分が共通していることを明らかにすることができる書面

- 一 合併の理由を記載した書面
- 二 次に掲げる場合に応じ、それぞれ次に定める書面
- 三 会員等の氏名又は商号若しくは名称及び主たる事務所又は本店の所在地を記載した書面、その者が法[[laws/商品先物取引法施行規則/本文/第31条.md|第三十一条]]第一項各号のいずれにも該当しないことを誓約する書面並びに申請に係る商品取引所が開設しようとする一以上の商品市場において法[[laws/商品先物取引法施行規則/本文/第105条.md|第百五条]]第一号に掲げる方法により決済を行う場合には認可の申請の日前三十日以内に様式第一号により作成したその者の純資産額に関する調書
- 四 合併を行う各商品取引所の合併総会（会員商品取引所にあっては、法[[laws/商品先物取引法施行規則/本文/第144条.md|第百四十四条]]第四項、[[laws/商品先物取引法施行規則/本文/第144条の2.md|第百四十四条の二]]第二項又は[[laws/商品先物取引法施行規則/本文/第144条の3.md|第百四十四条の三]]第四項の会員総会をいい、株式会社商品取引所にあっては、法[[laws/商品先物取引法施行規則/本文/第144条の6.md|第百四十四条の六]]第一項、[[laws/商品先物取引法施行規則/本文/第144条の14.md|第百四十四条の十四]]第一項、会社法[[laws/会社法/本文/第783条.md|第七百八十三条]]第一項、[[laws/会社法/本文/第795条.md|第七百九十五条]]第一項又は[[laws/会社法/本文/第804条.md|第八百四条]]第一項の株主総会をいう。）の議事録その他必要な手続があったことを証する書面
- 五 合併を行う各商品取引所の財産及び収支の状況を知ることができる書面（会員商品取引所にあっては最終事業年度の決算関係書類等、株式会社商品取引所にあっては最終事業年度の計算書類等及びその附属明細書）
- 六 法[[laws/商品先物取引法施行規則/本文/第144条.md|第百四十四条]]第六項、[[laws/商品先物取引法施行規則/本文/第144条の2.md|第百四十四条の二]]第四項及び[[laws/商品先物取引法施行規則/本文/第144条の3.md|第百四十四条の三]]第六項において準用する法[[laws/商品先物取引法施行規則/本文/第124条.md|第百二十四条]]第二項、[[laws/商品先物取引法施行規則/本文/第144条の11.md|第百四十四条の十一]]第二項（[[laws/商品先物取引法施行規則/本文/第144条の19.md|第百四十四条の十九]]において準用する場合を含む。）、会社法[[laws/会社法/本文/第789条.md|第七百八十九条]]第二項、[[laws/会社法/本文/第799条.md|第七百九十九条]]第二項又は[[laws/会社法/本文/第810条.md|第八百十条]]第二項の規定による公告及び催告（[[laws/会社法/本文/第124条.md|第百二十四条]]第三項、[[laws/会社法/本文/第144条の11.md|第百四十四条の十一]]第三項（[[laws/会社法/本文/第144条の19.md|第百四十四条の十九]]において準用する場合を含む。）、会社法[[laws/会社法/本文/第789条.md|第七百八十九条]]第三項、[[laws/会社法/本文/第799条.md|第七百九十九条]]第三項又は[[laws/会社法/本文/第810条.md|第八百十条]]第三項の規定により公告を官報のほか時事に関する事項を掲載する日刊新聞紙又は電子公告によってした場合にあっては、これらの方法による公告）をしたこと並びに異議を述べた債権者があるときは、当該債権者に対し弁済し若しくは相当の担保を提供し若しくは当該債権者に弁済を受けさせることを目的として相当の財産を信託したこと又は当該合併をしても当該債権者を害するおそれがないことを証する書面
- 七 合併により消滅する商品取引所の開設している商品市場における取引に関する業務の承継の方法を記載した書面
- 八 商品取引所の業務に関する知識及び経験を有する従業員の確保の状況並びに当該従業員の配置の状況を記載した書面（合併後の商品取引所が株式会社商品取引所である場合に限る。）
- 九 開設しようとする商品市場における合併後一年間の先物取引の取引量の見込みを記載した書面
- 十 合併に際して上場商品に係る商品市場を開設しようとする場合にあっては、上場商品構成品を一の商品市場で取引をすることが適当である旨を明らかにすることができる書面
- 十一 合併に際して二以上の商品指数を一の上場商品指数として商品市場を開設しようとする場合にあっては、当該二以上の商品指数の対象となる物品又は電力の大部分が共通していることを明らかにすることができる書面
