# 第三条 

## 
法[[laws/中部圏の都市整備区域、都市開発区域及び保全区域の整備等に関する法律施行令/本文/第5条.md|第五条]]第一項の政令で定める施設は、次に掲げる施設とする。防火、防水又は防砂のための施設及び地すべり又は林地の荒廃の防止のための施設公園及び緑地道路、鉄道、索道、駐車場及びバスターミナル宿泊施設、食事施設及び休憩施設キャンプ場、水泳場及びスキー場水道、下水道及び汚物処理施設前各号に掲げる施設に類する施設博物館

- 一 防火、防水又は防砂のための施設及び地すべり又は林地の荒廃の防止のための施設
- 二 公園及び緑地
- 三 道路、鉄道、索道、駐車場及びバスターミナル
- 四 宿泊施設、食事施設及び休憩施設
- 五 キャンプ場、水泳場及びスキー場
- 六 水道、下水道及び汚物処理施設
- 七 前各号に掲げる施設に類する施設
- 八 博物館
