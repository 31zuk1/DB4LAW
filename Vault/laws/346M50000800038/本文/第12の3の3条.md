# 第十二条の三の三 （船舶発生廃棄物汚染防止規程を定めるべき船舶）

## 
法[[laws/海洋汚染等及び海上災害の防止に関する法律施行規則/本文/第10条の3.md|第十条の三]]第一項の国土交通省令で定める船舶は、総トン数百トン以上の船舶及び最大搭載人員（最大搭載人員の定めのない船舶にあつては、これに相当する搭載人員。[[laws/海洋汚染等及び海上災害の防止に関する法律施行規則/本文/第12条の3.md|第十二条の三]]の五において同じ。）十五人以上の船舶とする。
