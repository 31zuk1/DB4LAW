# 第八十一条 （準用）

## 
[[laws/405M50000400069/本文/第31条.md|第三十一条]]及び[[laws/405M50000400069/本文/第34条.md|第三十四条]]の規定は、法[[laws/404AC0000000051/本文/第127条.md|第百二十七条]]第一項の指定を受けた者に準用する。この場合において、[[laws/405M50000400069/本文/第31条.md|第三十一条]]及び[[laws/405M50000400069/本文/第34条.md|第三十四条]]中「その届出に係る工場又は事業場の所在地を管轄する都道府県知事」とあるのは「国の事業所にあっては、当該事業所の所在地を管轄する都道府県知事（その所在地が特定市町村の区域にある場合にあっては、特定市町村の長）を経由して当該事業所の所在地を管轄する経済産業局長に、その他の事業所にあっては、当該事業所の所在地が特定市町村の区域にある場合に限り特定市町村の長を経由して当該事業所の所在地を管轄する都道府県知事」と、[[laws/405M50000400069/本文/第31条.md|第三十一条]]第一項中「法[[laws/405M50000400069/本文/第62条.md|第六十二条]]第一項」とあるのは「法[[laws/405M50000400069/本文/第133条.md|第百三十三条]]において準用する法[[laws/405M50000400069/本文/第62条.md|第六十二条]]第一項」と、同条第二項中「法[[laws/405M50000400069/本文/第61条.md|第六十一条]]」とあるのは「法[[laws/405M50000400069/本文/第133条.md|第百三十三条]]において準用する法[[laws/405M50000400069/本文/第61条.md|第六十一条]]」と、「法[[laws/405M50000400069/本文/第62条.md|第六十二条]]第二項」とあるのは「法[[laws/405M50000400069/本文/第133条.md|第百三十三条]]において準用する法[[laws/405M50000400069/本文/第62条.md|第六十二条]]第二項」と、[[laws/405M50000400069/本文/第34条.md|第三十四条]]中「法[[laws/405M50000400069/本文/第65条.md|第六十五条]]」とあるのは「法[[laws/405M50000400069/本文/第133条.md|第百三十三条]]において準用する法[[laws/405M50000400069/本文/第65条.md|第六十五条]]」と読み替えるものとする。
