# 第四十四条の三 （法第百十三条の三第一項第二号の厚生労働省令で定める事務）

## 
法[[laws/333AC0000000192/本文/第113条の3.md|第百十三条の三]]第一項第二号の厚生労働省令で定める事務は、次に掲げる事務とする。法[[laws/333M50000100053/本文/第9条.md|第九条]]の規定による被保険者の資格の取得及び喪失に関する事項その他必要な事項の届出の受理、資格確認書の交付その他の事務法第四章の規定による保険給付の実施法[[laws/333AC0000000192/本文/第75条の3.md|第七十五条の三]]に規定する保険給付の審査及び支払法[[laws/333AC0000000192/本文/第76条.md|第七十六条]]第一項又は第二項の規定による保険料の徴収法[[laws/333AC0000000192/本文/第82条.md|第八十二条]]第一項の規定による保健事業の実施行政手続における特定の個人を識別するための番号の利用等に関する法律[[laws/425AC0000000027/本文/第19条.md|第十九条]]第八号に基づく利用特定個人情報の提供に関する命令（令和六年デジタル庁・総務省令第九号）[[laws/425AC0000000027/行政手続における特定の個人を識別するため_law.md|第七十一条]]各号又は[[laws/425AC0000000027/行政手続における特定の個人を識別するため_law.md|第七十三条]]に掲げる事務

- 一 法[[laws/333M50000100053/本文/第9条.md|第九条]]の規定による被保険者の資格の取得及び喪失に関する事項その他必要な事項の届出の受理、資格確認書の交付その他の事務
- 二 法第四章の規定による保険給付の実施
- 三 法[[laws/333AC0000000192/本文/第75条の3.md|第七十五条の三]]に規定する保険給付の審査及び支払
- 四 法[[laws/333AC0000000192/本文/第76条.md|第七十六条]]第一項又は第二項の規定による保険料の徴収
- 五 法[[laws/333AC0000000192/本文/第82条.md|第八十二条]]第一項の規定による保健事業の実施
- 六 行政手続における特定の個人を識別するための番号の利用等に関する法律第十九条第八号に基づく利用特定個人情報の提供に関する命令（令和六年デジタル庁・総務省令第九号）[[laws/425AC0000000027/行政手続における特定の個人を識別するため_law.md|第七十一条]]各号又は[[laws/425AC0000000027/行政手続における特定の個人を識別するため_law.md|第七十三条]]に掲げる事務
