# 第八条の三 （産業廃棄物の処分を委託できる者）

## 
法[[laws/346M50000100035/本文/第12条.md|第十二条]]第五項の環境省令で定める産業廃棄物の処分を委託できる者は、次のとおりとする。市町村又は都道府県（法[[laws/346M50000100035/本文/第11条.md|第十一条]]第二項又は第三項の規定により産業廃棄物の処分をその事務として行う場合に限る。）専ら再生利用の目的となる産業廃棄物のみの処分を業として行う者[[laws/346M50000100035/本文/第10条の3.md|第十条の三]]各号に掲げる者法[[laws/346M50000100035/本文/第15条の4.md|第十五条の四]]の二第一項の認定を受けた者（当該認定に係る産業廃棄物の当該認定に係る処分を行う場合に限る。）法[[laws/346M50000100035/本文/第15条の4.md|第十五条の四]]の三第一項の認定を受けた者（当該認定に係る産業廃棄物の当該認定に係る処分を行う場合に限るものとし、その委託を受けて当該認定に係る処分を業として行う者（同条第二項第二号に規定する者である者に限る。）を含む。）法[[laws/346M50000100035/本文/第15条の4.md|第十五条の四]]の四第一項の認定を受けた者（当該認定に係る産業廃棄物の当該認定に係る処分を行う場合に限る。）

- 一 市町村又は都道府県（法[[laws/346M50000100035/本文/第11条.md|第十一条]]第二項又は第三項の規定により産業廃棄物の処分をその事務として行う場合に限る。）
- 二 専ら再生利用の目的となる産業廃棄物のみの処分を業として行う者
- 三 [[laws/346M50000100035/本文/第10条の3.md|第十条の三]]各号に掲げる者
- 四 法[[laws/346M50000100035/本文/第15条の4.md|第十五条の四]]の二第一項の認定を受けた者（当該認定に係る産業廃棄物の当該認定に係る処分を行う場合に限る。）
- 五 法[[laws/346M50000100035/本文/第15条の4.md|第十五条の四]]の三第一項の認定を受けた者（当該認定に係る産業廃棄物の当該認定に係る処分を行う場合に限るものとし、その委託を受けて当該認定に係る処分を業として行う者（同条第二項第二号に規定する者である者に限る。）を含む。）
- 六 法[[laws/346M50000100035/本文/第15条の4.md|第十五条の四]]の四第一項の認定を受けた者（当該認定に係る産業廃棄物の当該認定に係る処分を行う場合に限る。）
