# 第一条の三の三 （石綿含有一般廃棄物）

## 
令[[laws/346M50000100035/本文/第3条.md|第三条]]第一号ホの規定による環境省令で定める一般廃棄物は、工作物の新築、改築又は除去に伴つて生じた一般廃棄物であつて、石綿をその重量の〇・一パーセントを超えて含有するものとする。
