# 第四十五条 

## 
次の各号の一に該当する者は、三十万円以下の罰金に処する。[[laws/407AC0000000065/本文/第7条.md|第七条]]第二項、[[laws/407AC0000000065/本文/第17条.md|第十七条]]第一項、[[laws/407AC0000000065/本文/第18条.md|第十八条]]第二項、[[laws/407AC0000000065/本文/第21条.md|第二十一条]]、[[laws/407AC0000000065/本文/第23条.md|第二十三条]]、[[laws/407AC0000000065/本文/第24条.md|第二十四条]]第二項から第四項まで若しくは[[laws/407AC0000000065/本文/第25条.md|第二十五条]]（これらの規定を[[laws/407AC0000000065/本文/第26条.md|第二十六条]]又は[[laws/407AC0000000065/本文/第27条.md|第二十七条]]において準用する場合を含む。）、[[laws/407AC0000000065/本文/第28条.md|第二十八条]]、[[laws/407AC0000000065/本文/第29条.md|第二十九条]]又は[[laws/407AC0000000065/本文/第31条.md|第三十一条]]第四項の規定による届出をせず、又は虚偽の届出をした者[[laws/407AC0000000065/本文/第16条.md|第十六条]]第二項、[[laws/407AC0000000065/本文/第17条.md|第十七条]]第四項又は[[laws/407AC0000000065/本文/第31条.md|第三十一条]]第三項の規定に違反した者[[laws/407AC0000000065/本文/第22条.md|第二十二条]]第一項の規定に違反して日誌を備えず、又は日誌に記録せず、若しくは虚偽の記録をした者[[laws/407AC0000000065/本文/第22条.md|第二十二条]]第二項の規定に違反して日誌を保存しなかった者[[laws/407AC0000000065/本文/第30条.md|第三十条]]第一項の規定による検査、撮影若しくは収去を拒み、妨げ、若しくは忌避し、又は質問に対して答弁をせず、若しくは虚偽の答弁をした者[[laws/407AC0000000065/本文/第30条.md|第三十条]]第二項の規定による立会いを拒み、妨げ、又は忌避した者[[laws/407AC0000000065/本文/第31条.md|第三十一条]]第一項の規定による封印又は装置の取付けを拒み、妨げ、又は忌避した者[[laws/407AC0000000065/本文/第32条.md|第三十二条]]の規定による報告をせず、又は虚偽の報告をした者[[laws/407AC0000000065/本文/第33条.md|第三十三条]]第一項の規定による検査若しくは収去を拒み、妨げ、若しくは忌避し、又は質問に対して答弁をせず、若しくは虚偽の答弁をした者[[laws/407AC0000000065/本文/第33条.md|第三十三条]]第二項の規定による検査を拒み、妨げ、若しくは忌避し、又は質問に対して答弁をせず、若しくは虚偽の答弁をした者

- 一 [[laws/407AC0000000065/本文/第7条.md|第七条]]第二項、[[laws/407AC0000000065/本文/第17条.md|第十七条]]第一項、[[laws/407AC0000000065/本文/第18条.md|第十八条]]第二項、[[laws/407AC0000000065/本文/第21条.md|第二十一条]]、[[laws/407AC0000000065/本文/第23条.md|第二十三条]]、[[laws/407AC0000000065/本文/第24条.md|第二十四条]]第二項から第四項まで若しくは[[laws/407AC0000000065/本文/第25条.md|第二十五条]]（これらの規定を[[laws/407AC0000000065/本文/第26条.md|第二十六条]]又は[[laws/407AC0000000065/本文/第27条.md|第二十七条]]において準用する場合を含む。）、[[laws/407AC0000000065/本文/第28条.md|第二十八条]]、[[laws/407AC0000000065/本文/第29条.md|第二十九条]]又は[[laws/407AC0000000065/本文/第31条.md|第三十一条]]第四項の規定による届出をせず、又は虚偽の届出をした者
- 二 [[laws/407AC0000000065/本文/第16条.md|第十六条]]第二項、[[laws/407AC0000000065/本文/第17条.md|第十七条]]第四項又は[[laws/407AC0000000065/本文/第31条.md|第三十一条]]第三項の規定に違反した者
- 三 [[laws/407AC0000000065/本文/第22条.md|第二十二条]]第一項の規定に違反して日誌を備えず、又は日誌に記録せず、若しくは虚偽の記録をした者
- 四 [[laws/407AC0000000065/本文/第22条.md|第二十二条]]第二項の規定に違反して日誌を保存しなかった者
- 五 [[laws/407AC0000000065/本文/第30条.md|第三十条]]第一項の規定による検査、撮影若しくは収去を拒み、妨げ、若しくは忌避し、又は質問に対して答弁をせず、若しくは虚偽の答弁をした者
- 六 [[laws/407AC0000000065/本文/第30条.md|第三十条]]第二項の規定による立会いを拒み、妨げ、又は忌避した者
- 七 [[laws/407AC0000000065/本文/第31条.md|第三十一条]]第一項の規定による封印又は装置の取付けを拒み、妨げ、又は忌避した者
- 八 [[laws/407AC0000000065/本文/第32条.md|第三十二条]]の規定による報告をせず、又は虚偽の報告をした者
- 九 [[laws/407AC0000000065/本文/第33条.md|第三十三条]]第一項の規定による検査若しくは収去を拒み、妨げ、若しくは忌避し、又は質問に対して答弁をせず、若しくは虚偽の答弁をした者
- 十 [[laws/407AC0000000065/本文/第33条.md|第三十三条]]第二項の規定による検査を拒み、妨げ、若しくは忌避し、又は質問に対して答弁をせず、若しくは虚偽の答弁をした者
