# 第四十二条 

## 
次のいずれかに該当する者は、六月以下の拘禁刑又は五十万円以下の罰金に処する。[[laws/323AC1000000186/本文/第8条.md|第八条]]第三項（[[laws/323AC1000000186/本文/第36条.md|第三十六条]]第一項において準用する場合を含む。）の規定による命令に違反した者[[laws/323AC1000000186/本文/第11条.md|第十一条]]第一項の規定に違反した者[[laws/323AC1000000186/本文/第11条.md|第十一条]]第五項の規定に違反した者[[laws/323AC1000000186/本文/第12条の2.md|第十二条の二]]第一項又は第二項の規定による命令に違反した者[[laws/323AC1000000186/本文/第12条の3.md|第十二条の三]]第一項の規定による命令又は処分に違反した者[[laws/323AC1000000186/本文/第13条.md|第十三条]]第一項の規定に違反して危険物保安監督者を定めないで事業を行つた者[[laws/323AC1000000186/本文/第13条.md|第十三条]]第三項の規定に違反した者[[laws/323AC1000000186/本文/第14条の2.md|第十四条の二]]第一項の規定に違反して危険物を貯蔵し、若しくは取り扱つた者又は同条第三項の規定による命令に違反した者[[laws/323AC1000000186/本文/第16条の3.md|第十六条の三]]第三項又は第四項の規定による命令に違反した者[[laws/323AC1000000186/本文/第17条の5.md|第十七条の五]]の規定に違反した者[[laws/323AC1000000186/本文/第25条.md|第二十五条]]第三項（[[laws/323AC1000000186/本文/第30条の2.md|第三十条の二]]及び[[laws/323AC1000000186/本文/第36条.md|第三十六条]]第八項において準用する場合を含む。）の規定による情報の提供を求められて、正当な理由がなく情報の提供をせず、又は虚偽の情報を提供した者

- 一 [[laws/323AC1000000186/本文/第8条.md|第八条]]第三項（[[laws/323AC1000000186/本文/第36条.md|第三十六条]]第一項において準用する場合を含む。）の規定による命令に違反した者
- 二 [[laws/323AC1000000186/本文/第11条.md|第十一条]]第一項の規定に違反した者
- 三 [[laws/323AC1000000186/本文/第11条.md|第十一条]]第五項の規定に違反した者
- 四 [[laws/323AC1000000186/本文/第12条の2.md|第十二条の二]]第一項又は第二項の規定による命令に違反した者
- 五 [[laws/323AC1000000186/本文/第12条の3.md|第十二条の三]]第一項の規定による命令又は処分に違反した者
- 六 [[laws/323AC1000000186/本文/第13条.md|第十三条]]第一項の規定に違反して危険物保安監督者を定めないで事業を行つた者
- 七 [[laws/323AC1000000186/本文/第13条.md|第十三条]]第三項の規定に違反した者
- 八 [[laws/323AC1000000186/本文/第14条の2.md|第十四条の二]]第一項の規定に違反して危険物を貯蔵し、若しくは取り扱つた者又は同条第三項の規定による命令に違反した者
- 九 [[laws/323AC1000000186/本文/第16条の3.md|第十六条の三]]第三項又は第四項の規定による命令に違反した者
- 十 [[laws/323AC1000000186/本文/第17条の5.md|第十七条の五]]の規定に違反した者
- 十一 [[laws/323AC1000000186/本文/第25条.md|第二十五条]]第三項（[[laws/323AC1000000186/本文/第30条の2.md|第三十条の二]]及び[[laws/323AC1000000186/本文/第36条.md|第三十六条]]第八項において準用する場合を含む。）の規定による情報の提供を求められて、正当な理由がなく情報の提供をせず、又は虚偽の情報を提供した者
## 
前項の罪を犯した者に対しては、情状により拘禁刑及び罰金を併科することができる。
