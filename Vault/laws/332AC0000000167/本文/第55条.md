# 第五十五条 

## 
次の各号のいずれかに該当する者は、百万円以下の罰金に処する。[[laws/332AC0000000167/本文/第3条の2.md|第三条の二]]第二項の規定による届出をしないで同項に規定する事項を変更した者[[laws/332AC0000000167/本文/第4条.md|第四条]]第二項の規定による届出をしないで同項に規定する事項を変更した者[[laws/332AC0000000167/本文/第10条.md|第十条]]第五項の規定による届出をせず、又は虚偽の届出をして同条第二項ただし書に規定する変更をした者[[laws/332AC0000000167/本文/第10条.md|第十条]]第六項の規定による届出をしないで[[laws/332AC0000000167/本文/第3条.md|第三条]]第二項第四号に掲げる事項を変更した者[[laws/332AC0000000167/本文/第12条の4.md|第十二条の四]]第二項の規定に違反して検査記録を作成せず、若しくは虚偽の記録をし、又は検査記録を保存しなかつた者[[laws/332AC0000000167/本文/第12条の9.md|第十二条の九]]第一項又は第二項の規定による定期検査を拒み、妨げ、又は忌避した者[[laws/332AC0000000167/本文/第12条の10.md|第十二条の十]]の規定による定期確認を拒み、妨げ、又は忌避した者[[laws/332AC0000000167/本文/第18条.md|第十八条]]第八項（[[laws/332AC0000000167/本文/第25条の5.md|第二十五条の五]]の規定により読み替えて適用する場合を含む。）の規定による警察官の停止命令に従わず、検査を拒み、若しくは妨げ、又は同項の規定による命令に従わなかつた者[[laws/332AC0000000167/本文/第20条.md|第二十条]]、[[laws/332AC0000000167/本文/第22条.md|第二十二条]]、[[laws/332AC0000000167/本文/第23条.md|第二十三条]]、[[laws/332AC0000000167/本文/第24条.md|第二十四条]]又は[[laws/332AC0000000167/本文/第36条の3.md|第三十六条の三]]第二項の規定に違反した者[[laws/332AC0000000167/本文/第25条.md|第二十五条]]第一項（[[laws/332AC0000000167/本文/第25条の2.md|第二十五条の二]]第四項の規定により読み替えて適用する場合を含む。）、第二項若しくは第三項の規定に違反して帳簿を備えず、帳簿に記載せず、若しくは虚偽の記載をし、又は[[laws/332AC0000000167/本文/第25条.md|第二十五条]]第四項の規定に違反して帳簿を保存しなかつた者[[laws/332AC0000000167/本文/第25条の7.md|第二十五条の七]]の規定に違反して、報告をせず、又は虚偽の報告をした者[[laws/332AC0000000167/本文/第25条の8.md|第二十五条の八]]又は[[laws/332AC0000000167/本文/第38条の3.md|第三十八条の三]]において準用する[[laws/332AC0000000167/本文/第36条の3.md|第三十六条の三]]第二項の規定に違反した者[[laws/332AC0000000167/本文/第25条の9.md|第二十五条の九]]第一項の規定に違反して帳簿を備えず、帳簿に記載せず、若しくは虚偽の記載をし、又は同条第二項の規定に違反して帳簿を保存しなかつた者[[laws/332AC0000000167/本文/第27条.md|第二十七条]]第一項若しくは第三項若しくは[[laws/332AC0000000167/本文/第32条.md|第三十二条]]の規定による届出をせず、又は虚偽の届出をした者[[laws/332AC0000000167/本文/第28条.md|第二十八条]]第二項又は第四項の規定に違反して同条第一項の措置を講じた者[[laws/332AC0000000167/本文/第28条.md|第二十八条]]第五項の規定に違反して、報告をせず、又は虚偽の報告をした者[[laws/332AC0000000167/本文/第42条.md|第四十二条]]第一項（同項に規定する運搬を委託された者に係る部分に限る。）若しくは第三項の報告をせず、又は虚偽の報告をした者[[laws/332AC0000000167/本文/第43条の2.md|第四十三条の二]]第一項（同項に規定する運搬を委託された者に係る部分に限る。）又は第二項の規定による立入り、検査若しくは収去を拒み、妨げ、若しくは忌避し、又は質問に対して陳述をせず、若しくは虚偽の陳述をした者

- 一 [[laws/332AC0000000167/本文/第3条の2.md|第三条の二]]第二項の規定による届出をしないで同項に規定する事項を変更した者
- 二 [[laws/332AC0000000167/本文/第4条.md|第四条]]第二項の規定による届出をしないで同項に規定する事項を変更した者
- 三 [[laws/332AC0000000167/本文/第10条.md|第十条]]第五項の規定による届出をせず、又は虚偽の届出をして同条第二項ただし書に規定する変更をした者
- 四 [[laws/332AC0000000167/本文/第10条.md|第十条]]第六項の規定による届出をしないで[[laws/332AC0000000167/本文/第3条.md|第三条]]第二項第四号に掲げる事項を変更した者
- 五 [[laws/332AC0000000167/本文/第12条の4.md|第十二条の四]]第二項の規定に違反して検査記録を作成せず、若しくは虚偽の記録をし、又は検査記録を保存しなかつた者
- 六 [[laws/332AC0000000167/本文/第12条の9.md|第十二条の九]]第一項又は第二項の規定による定期検査を拒み、妨げ、又は忌避した者
- 七 [[laws/332AC0000000167/本文/第12条の10.md|第十二条の十]]の規定による定期確認を拒み、妨げ、又は忌避した者
- 八 [[laws/332AC0000000167/本文/第18条.md|第十八条]]第八項（[[laws/332AC0000000167/本文/第25条の5.md|第二十五条の五]]の規定により読み替えて適用する場合を含む。）の規定による警察官の停止命令に従わず、検査を拒み、若しくは妨げ、又は同項の規定による命令に従わなかつた者
- 九 [[laws/332AC0000000167/本文/第20条.md|第二十条]]、[[laws/332AC0000000167/本文/第22条.md|第二十二条]]、[[laws/332AC0000000167/本文/第23条.md|第二十三条]]、[[laws/332AC0000000167/本文/第24条.md|第二十四条]]又は[[laws/332AC0000000167/本文/第36条の3.md|第三十六条の三]]第二項の規定に違反した者
- 十 [[laws/332AC0000000167/本文/第25条.md|第二十五条]]第一項（[[laws/332AC0000000167/本文/第25条の2.md|第二十五条の二]]第四項の規定により読み替えて適用する場合を含む。）、第二項若しくは第三項の規定に違反して帳簿を備えず、帳簿に記載せず、若しくは虚偽の記載をし、又は[[laws/332AC0000000167/本文/第25条.md|第二十五条]]第四項の規定に違反して帳簿を保存しなかつた者
- 十一 [[laws/332AC0000000167/本文/第25条の7.md|第二十五条の七]]の規定に違反して、報告をせず、又は虚偽の報告をした者
- 十二 [[laws/332AC0000000167/本文/第25条の8.md|第二十五条の八]]又は[[laws/332AC0000000167/本文/第38条の3.md|第三十八条の三]]において準用する[[laws/332AC0000000167/本文/第36条の3.md|第三十六条の三]]第二項の規定に違反した者
- 十三 [[laws/332AC0000000167/本文/第25条の9.md|第二十五条の九]]第一項の規定に違反して帳簿を備えず、帳簿に記載せず、若しくは虚偽の記載をし、又は同条第二項の規定に違反して帳簿を保存しなかつた者
- 十四 [[laws/332AC0000000167/本文/第27条.md|第二十七条]]第一項若しくは第三項若しくは[[laws/332AC0000000167/本文/第32条.md|第三十二条]]の規定による届出をせず、又は虚偽の届出をした者
- 十五 [[laws/332AC0000000167/本文/第28条.md|第二十八条]]第二項又は第四項の規定に違反して同条第一項の措置を講じた者
- 十六 [[laws/332AC0000000167/本文/第28条.md|第二十八条]]第五項の規定に違反して、報告をせず、又は虚偽の報告をした者
- 十七 [[laws/332AC0000000167/本文/第42条.md|第四十二条]]第一項（同項に規定する運搬を委託された者に係る部分に限る。）若しくは第三項の報告をせず、又は虚偽の報告をした者
- 十八 [[laws/332AC0000000167/本文/第43条の2.md|第四十三条の二]]第一項（同項に規定する運搬を委託された者に係る部分に限る。）又は第二項の規定による立入り、検査若しくは収去を拒み、妨げ、若しくは忌避し、又は質問に対して陳述をせず、若しくは虚偽の陳述をした者
