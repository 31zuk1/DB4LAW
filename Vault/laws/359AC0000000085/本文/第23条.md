# 第二十三条 

## 
次の各号のいずれかに掲げる違反があつた場合においては、その違反行為をした会社又は地域会社の取締役、会計参与（会計参与が法人であるときは、その職務を行うべき社員）又は監査役は、百万円以下の罰金に処する。[[laws/359AC0000000085/本文/第2条.md|第二条]]第二項、第四項若しくは第六項又は[[laws/359AC0000000085/本文/第10条.md|第十条]]第三項（[[laws/359AC0000000085/本文/第18条の2.md|第十八条の二]]の規定により読み替えて適用する場合を含む。）の規定による届出をせず、又は虚偽の届出をしたとき。[[laws/359AC0000000085/本文/第2条.md|第二条]]第五項の規定に違反して、地域電気通信業務を行つたとき。[[laws/359AC0000000085/本文/第2条.md|第二条]]（第五項を除く。）に規定する業務以外の業務を行つたとき。[[laws/359AC0000000085/本文/第4条.md|第四条]]第二項又は[[laws/359AC0000000085/本文/第5条.md|第五条]]第二項の規定に違反して、新株募集をしたとき若しくは株式交換若しくは株式交付に際して株式（自己株式を除く。）の交付をしたとき又は募集新株予約権を引き受ける者の募集をしたとき若しくは株式交換若しくは株式交付に際して新株予約権付社債（自己新株予約権付社債を除く。）の交付をしたとき。[[laws/359AC0000000085/本文/第5条.md|第五条]]第一項の規定に違反して、地域会社の株式を処分したとき。[[laws/359AC0000000085/本文/第12条.md|第十二条]]の規定に違反して、事業年度の開始前までに、又は変更に係る事業計画に基づく業務の実施前までに、認可の申請をしなかつたとき。[[laws/359AC0000000085/本文/第13条.md|第十三条]]の規定に違反して、貸借対照表、損益計算書若しくは事業報告書を提出せず、又は不実の記載又は記録をしたこれらのものを提出したとき。[[laws/359AC0000000085/本文/第14条.md|第十四条]]の規定に違反して、設備を譲渡し、又は担保に供したとき。[[laws/359AC0000000085/本文/第16条.md|第十六条]]第二項の規定による命令に違反したとき。[[laws/359AC0000000085/本文/第17条.md|第十七条]]の規定による報告をせず、又は虚偽の報告をしたとき。

- 一 [[laws/359AC0000000085/本文/第2条.md|第二条]]第二項、第四項若しくは第六項又は[[laws/359AC0000000085/本文/第10条.md|第十条]]第三項（[[laws/359AC0000000085/本文/第18条の2.md|第十八条の二]]の規定により読み替えて適用する場合を含む。）の規定による届出をせず、又は虚偽の届出をしたとき。
- 二 [[laws/359AC0000000085/本文/第2条.md|第二条]]第五項の規定に違反して、地域電気通信業務を行つたとき。
- 三 [[laws/359AC0000000085/本文/第2条.md|第二条]]（第五項を除く。）に規定する業務以外の業務を行つたとき。
- 四 [[laws/359AC0000000085/本文/第4条.md|第四条]]第二項又は[[laws/359AC0000000085/本文/第5条.md|第五条]]第二項の規定に違反して、新株募集をしたとき若しくは株式交換若しくは株式交付に際して株式（自己株式を除く。）の交付をしたとき又は募集新株予約権を引き受ける者の募集をしたとき若しくは株式交換若しくは株式交付に際して新株予約権付社債（自己新株予約権付社債を除く。）の交付をしたとき。
- 五 [[laws/359AC0000000085/本文/第5条.md|第五条]]第一項の規定に違反して、地域会社の株式を処分したとき。
- 六 [[laws/359AC0000000085/本文/第12条.md|第十二条]]の規定に違反して、事業年度の開始前までに、又は変更に係る事業計画に基づく業務の実施前までに、認可の申請をしなかつたとき。
- 七 [[laws/359AC0000000085/本文/第13条.md|第十三条]]の規定に違反して、貸借対照表、損益計算書若しくは事業報告書を提出せず、又は不実の記載又は記録をしたこれらのものを提出したとき。
- 八 [[laws/359AC0000000085/本文/第14条.md|第十四条]]の規定に違反して、設備を譲渡し、又は担保に供したとき。
- 九 [[laws/359AC0000000085/本文/第16条.md|第十六条]]第二項の規定による命令に違反したとき。
- 十 [[laws/359AC0000000085/本文/第17条.md|第十七条]]の規定による報告をせず、又は虚偽の報告をしたとき。
