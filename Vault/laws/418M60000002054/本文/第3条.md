# 第三条 （権利者集会の招集の場合における決定事項）

## 
法[[laws/418M60000002054/特定目的信託の権利者集会等に関する規則_law.md|第二百四十二条]]第五項において読み替えて準用する信託法（平成十八年法律第百八号）第百八条第四号に規定する内閣府令で定める事項は、次に掲げるものとする。[[laws/418M60000002054/本文/第5条.md|第五条]]の規定により権利者集会参考書類（法[[laws/418M60000002054/特定目的信託の権利者集会等に関する規則_law.md|第二百四十五条]]第二項において読み替えて準用する信託法第百十条第一項に規定する権利者集会参考書類をいう。次条及び[[laws/418M60000002054/本文/第5条.md|第五条]]において同じ。）に記載すべき事項書面による議決権の行使の期限（権利者集会の日時以前の時であって、法[[laws/418M60000002054/特定目的信託の権利者集会等に関する規則_law.md|第二百四十二条]]第二項の規定による通知を発した日から二週間を経過した日以後の時に限る。）一の受益証券の権利者が同一の議案につき法[[laws/418M60000002054/特定目的信託の権利者集会等に関する規則_law.md|第二百四十五条]]第一項（法[[laws/418M60000002054/特定目的信託の権利者集会等に関する規則_law.md|第二百四十二条]]第五項において読み替えて準用する信託法第百八条第三号に掲げる事項を定めた場合にあっては、法[[laws/418AC0000000108/本文/第245条.md|第二百四十五条]]第一項又は同条第二項において準用する信託法第百十六条第一項）の規定により重複して議決権を行使した場合において、当該同一の議案に対する議決権の行使の内容が異なるものであるときにおける当該受益証券の権利者の議決権の行使の取扱いに関する事項を定めるときは、その事項[[laws/418AC0000000108/本文/第6条.md|第六条]]第一項第一号の欄に記載がない議決権行使書面（法[[laws/418AC0000000108/本文/第245条.md|第二百四十五条]]第二項において読み替えて準用する信託法第百十条第一項に規定する議決権行使書面をいう。以下この条及び[[laws/418M60000002054/本文/第6条.md|第六条]]において同じ。）が招集者（法[[laws/418M60000002054/特定目的信託の権利者集会等に関する規則_law.md|第二百四十二条]]第五項において読み替えて準用する信託法第百八条に規定する招集者をいう。以下この号及び[[laws/418M60000002054/本文/第6条.md|第六条]]第二項において同じ。）に提出され、又は法[[laws/418M60000002054/特定目的信託の権利者集会等に関する規則_law.md|第二百四十五条]]第二項において読み替えて準用する信託法第百十六条第一項の規定により電磁的方法（法[[laws/418AC0000000108/本文/第242条.md|第二百四十二条]]第五項において読み替えて準用する信託法第百八条第三号に規定する電磁的方法をいう。以下同じ。）により招集者に提供された事項のうちに当該欄に記載すべきものがない場合における各議案についての賛成、反対又は棄権のいずれかの意思の表示があったものとする取扱いを定めるときは、その取扱いの内容法[[laws/418M60000002054/特定目的信託の権利者集会等に関する規則_law.md|第二百四十二条]]第五項において読み替えて準用する信託法第百八条第三号に掲げる事項を定めたときは、次に掲げる事項電磁的方法による議決権の行使の期限（権利者集会の日時以前の時であって、法[[laws/418AC0000000108/本文/第242条.md|第二百四十二条]]第二項の規定による通知を発した日から二週間を経過した日以後の時に限る。）法[[laws/418AC0000000108/本文/第242条.md|第二百四十二条]]第三項の承諾をした受益証券の権利者に対しては、当該受益証券の権利者の[[laws/418AC0000000108/本文/第6条.md|第六条]]第二項の請求があった時に法[[laws/418AC0000000108/本文/第245条.md|第二百四十五条]]第二項において読み替えて準用する信託法第百十条第一項の規定による議決権行使書面の交付（当該交付に代えて行う同条第二項の規定による電磁的方法による提供を含む。）をすることとするときは、その旨法[[laws/418AC0000000108/本文/第249条.md|第二百四十九条]]第一項において読み替えて準用する信託法第百十七条第一項の規定による通知の方法を定めるとき（特定目的信託契約に当該通知の方法についての定めがある場合を除く。）は、その方法

- 一 [[laws/418M60000002054/本文/第5条.md|第五条]]の規定により権利者集会参考書類（法[[laws/418M60000002054/特定目的信託の権利者集会等に関する規則_law.md|第二百四十五条]]第二項において読み替えて準用する信託法第百十条第一項に規定する権利者集会参考書類をいう。次条及び[[laws/418M60000002054/本文/第5条.md|第五条]]において同じ。）に記載すべき事項
- 二 書面による議決権の行使の期限（権利者集会の日時以前の時であって、法[[laws/418M60000002054/特定目的信託の権利者集会等に関する規則_law.md|第二百四十二条]]第二項の規定による通知を発した日から二週間を経過した日以後の時に限る。）
- 三 一の受益証券の権利者が同一の議案につき法[[laws/418M60000002054/特定目的信託の権利者集会等に関する規則_law.md|第二百四十五条]]第一項（法[[laws/418M60000002054/特定目的信託の権利者集会等に関する規則_law.md|第二百四十二条]]第五項において読み替えて準用する信託法第百八条第三号に掲げる事項を定めた場合にあっては、法[[laws/418AC0000000108/本文/第245条.md|第二百四十五条]]第一項又は同条第二項において準用する信託法第百十六条第一項）の規定により重複して議決権を行使した場合において、当該同一の議案に対する議決権の行使の内容が異なるものであるときにおける当該受益証券の権利者の議決権の行使の取扱いに関する事項を定めるときは、その事項
- 四 [[laws/418M60000002054/本文/第6条.md|第六条]]第一項第一号の欄に記載がない議決権行使書面（法[[laws/418M60000002054/特定目的信託の権利者集会等に関する規則_law.md|第二百四十五条]]第二項において読み替えて準用する信託法第百十条第一項に規定する議決権行使書面をいう。以下この条及び[[laws/418M60000002054/本文/第6条.md|第六条]]において同じ。）が招集者（法[[laws/418M60000002054/特定目的信託の権利者集会等に関する規則_law.md|第二百四十二条]]第五項において読み替えて準用する信託法第百八条に規定する招集者をいう。以下この号及び[[laws/418M60000002054/本文/第6条.md|第六条]]第二項において同じ。）に提出され、又は法[[laws/418M60000002054/特定目的信託の権利者集会等に関する規則_law.md|第二百四十五条]]第二項において読み替えて準用する信託法第百十六条第一項の規定により電磁的方法（法[[laws/418AC0000000108/本文/第242条.md|第二百四十二条]]第五項において読み替えて準用する信託法第百八条第三号に規定する電磁的方法をいう。以下同じ。）により招集者に提供された事項のうちに当該欄に記載すべきものがない場合における各議案についての賛成、反対又は棄権のいずれかの意思の表示があったものとする取扱いを定めるときは、その取扱いの内容
- 五 法[[laws/418M60000002054/特定目的信託の権利者集会等に関する規則_law.md|第二百四十二条]]第五項において読み替えて準用する信託法第百八条第三号に掲げる事項を定めたときは、次に掲げる事項
- 六 法[[laws/418M60000002054/特定目的信託の権利者集会等に関する規則_law.md|第二百四十九条]]第一項において読み替えて準用する信託法第百十七条第一項の規定による通知の方法を定めるとき（特定目的信託契約に当該通知の方法についての定めがある場合を除く。）は、その方法
