# 第五十七条 

## 
次の各号のいずれかに該当するときは、その違反行為をした者は、三十万円以下の罰金に処する。[[laws/不動産の鑑定評価に関する法律/本文/第14条の10.md|第十四条の十]]の許可を受けないで、実務修習業務の全部を廃止したとき。[[laws/不動産の鑑定評価に関する法律/本文/第14条の17.md|第十四条の十七]]の規定に違反して帳簿を備えず、帳簿に記載せず、若しくは帳簿に虚偽の記載をし、又は帳簿を保存しなかつたとき。[[laws/不動産の鑑定評価に関する法律/本文/第14条の19.md|第十四条の十九]]の規定による報告を求められて、報告をせず、又は虚偽の報告をしたとき。[[laws/不動産の鑑定評価に関する法律/本文/第14条の20.md|第十四条の二十]]の規定による検査を拒み、妨げ、又は忌避したとき。[[laws/不動産の鑑定評価に関する法律/本文/第14条の22.md|第十四条の二十二]]の規定による報告をせず、又は虚偽の報告をしたとき。[[laws/不動産の鑑定評価に関する法律/本文/第26条.md|第二十六条]]第一項の規定に違反して、事務所を廃止し、又は設けたとき。[[laws/不動産の鑑定評価に関する法律/本文/第27条.md|第二十七条]]第一項の規定に違反して、変更の登録を申請せず、又は虚偽の申請をしたとき。[[laws/不動産の鑑定評価に関する法律/本文/第28条.md|第二十八条]]の規定に違反して、書類の提出を怠り、又は虚偽の記載をして書類を提出したとき。[[laws/不動産の鑑定評価に関する法律/本文/第45条.md|第四十五条]]第一項の規定による報告を求められて、その報告をせず、若しくは虚偽の報告をし、又は同項の規定による立入検査を拒み、妨げ、若しくは忌避したとき。[[laws/不動産の鑑定評価に関する法律/本文/第51条.md|第五十一条]]の規定に違反して、不動産鑑定士の名称を用いたとき。

- 一 [[laws/不動産の鑑定評価に関する法律/本文/第14条の10.md|第十四条の十]]の許可を受けないで、実務修習業務の全部を廃止したとき。
- 二 [[laws/不動産の鑑定評価に関する法律/本文/第14条の17.md|第十四条の十七]]の規定に違反して帳簿を備えず、帳簿に記載せず、若しくは帳簿に虚偽の記載をし、又は帳簿を保存しなかつたとき。
- 三 [[laws/不動産の鑑定評価に関する法律/本文/第14条の19.md|第十四条の十九]]の規定による報告を求められて、報告をせず、又は虚偽の報告をしたとき。
- 四 [[laws/不動産の鑑定評価に関する法律/本文/第14条の20.md|第十四条の二十]]の規定による検査を拒み、妨げ、又は忌避したとき。
- 五 [[laws/不動産の鑑定評価に関する法律/本文/第14条の22.md|第十四条の二十二]]の規定による報告をせず、又は虚偽の報告をしたとき。
- 六 [[laws/不動産の鑑定評価に関する法律/本文/第26条.md|第二十六条]]第一項の規定に違反して、事務所を廃止し、又は設けたとき。
- 七 [[laws/不動産の鑑定評価に関する法律/本文/第27条.md|第二十七条]]第一項の規定に違反して、変更の登録を申請せず、又は虚偽の申請をしたとき。
- 八 [[laws/不動産の鑑定評価に関する法律/本文/第28条.md|第二十八条]]の規定に違反して、書類の提出を怠り、又は虚偽の記載をして書類を提出したとき。
- 九 [[laws/不動産の鑑定評価に関する法律/本文/第45条.md|第四十五条]]第一項の規定による報告を求められて、その報告をせず、若しくは虚偽の報告をし、又は同項の規定による立入検査を拒み、妨げ、若しくは忌避したとき。
- 十 [[laws/不動産の鑑定評価に関する法律/本文/第51条.md|第五十一条]]の規定に違反して、不動産鑑定士の名称を用いたとき。
