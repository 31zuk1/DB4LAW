# 第百四条 

## 
法及びこの省令に規定する国土交通大臣の権限のうち、次に掲げるものは、法[[laws/マンションの管理の適正化の推進に関する法律施行規則/本文/第59条.md|第五十九条]]の登録を受けた者又は受けようとする者及び管理業務主任者又は法[[laws/マンションの管理の適正化の推進に関する法律施行規則/本文/第60条.md|第六十条]]第二項の管理業務主任者証の交付を受けようとする者の住所地を管轄する地方整備局長及び北海道開発局長に委任する。ただし、第五号、第六号、第八号及び第十三号に掲げる権限については、国土交通大臣が自ら行うことを妨げない。法[[laws/マンションの管理の適正化の推進に関する法律施行規則/本文/第59条.md|第五十九条]]第一項の規定による登録をすること。法[[laws/マンションの管理の適正化の推進に関する法律施行規則/本文/第60条.md|第六十条]]第一項の規定による交付の申請を受理し、同条第四項の規定による返納を受理し、同条第五項の規定による提出を受理し、及び同条第六項の規定により返還すること。法[[laws/マンションの管理の適正化の推進に関する法律施行規則/本文/第61条.md|第六十一条]]第一項の規定による更新の申請を受理すること。法[[laws/マンションの管理の適正化の推進に関する法律施行規則/本文/第62条.md|第六十二条]]第一項の規定による届出を受理すること。法[[laws/マンションの管理の適正化の推進に関する法律施行規則/本文/第64条.md|第六十四条]]第一項の規定により必要な指示をし、及び同条第二項の規定により事務を行うことを禁止すること。法[[laws/マンションの管理の適正化の推進に関する法律施行規則/本文/第65条.md|第六十五条]]の規定により登録を取り消すこと。法[[laws/マンションの管理の適正化の推進に関する法律施行規則/本文/第66条.md|第六十六条]]の規定により登録を消除すること。法[[laws/マンションの管理の適正化の推進に関する法律施行規則/本文/第67条.md|第六十七条]]の規定により必要な報告をさせること。[[laws/マンションの管理の適正化の推進に関する法律施行規則/本文/第70条.md|第七十条]]第一項の規定による管理業務主任者登録申請書を受理すること。[[laws/マンションの管理の適正化の推進に関する法律施行規則/本文/第71条.md|第七十一条]]第一項の規定により通知し、並びに同条第二項の規定により登録を拒否し、及び通知すること。[[laws/マンションの管理の適正化の推進に関する法律施行規則/本文/第76条.md|第七十六条]]第二項の規定により登録し、及び通知すること。[[laws/マンションの管理の適正化の推進に関する法律施行規則/本文/第77条.md|第七十七条]]第一項の規定による再交付の申請を受理し、及び同条第四項の規定による返納を受理すること。[[laws/マンションの管理の適正化の推進に関する法律施行規則/本文/第78条.md|第七十八条]]第一項の規定により通知し、及び同条第二項の規定による返納を受理すること。[[laws/マンションの管理の適正化の推進に関する法律施行規則/本文/第80条.md|第八十条]]の規定により読み替えて準用する[[laws/マンションの管理の適正化の推進に関する法律施行規則/本文/第31条.md|第三十一条]]の規定による届出を受理すること。

- 一 法[[laws/マンションの管理の適正化の推進に関する法律施行規則/本文/第59条.md|第五十九条]]第一項の規定による登録をすること。
- 二 法[[laws/マンションの管理の適正化の推進に関する法律施行規則/本文/第60条.md|第六十条]]第一項の規定による交付の申請を受理し、同条第四項の規定による返納を受理し、同条第五項の規定による提出を受理し、及び同条第六項の規定により返還すること。
- 三 法[[laws/マンションの管理の適正化の推進に関する法律施行規則/本文/第61条.md|第六十一条]]第一項の規定による更新の申請を受理すること。
- 四 法[[laws/マンションの管理の適正化の推進に関する法律施行規則/本文/第62条.md|第六十二条]]第一項の規定による届出を受理すること。
- 五 法[[laws/マンションの管理の適正化の推進に関する法律施行規則/本文/第64条.md|第六十四条]]第一項の規定により必要な指示をし、及び同条第二項の規定により事務を行うことを禁止すること。
- 六 法[[laws/マンションの管理の適正化の推進に関する法律施行規則/本文/第65条.md|第六十五条]]の規定により登録を取り消すこと。
- 七 法[[laws/マンションの管理の適正化の推進に関する法律施行規則/本文/第66条.md|第六十六条]]の規定により登録を消除すること。
- 八 法[[laws/マンションの管理の適正化の推進に関する法律施行規則/本文/第67条.md|第六十七条]]の規定により必要な報告をさせること。
- 九 [[laws/マンションの管理の適正化の推進に関する法律施行規則/本文/第70条.md|第七十条]]第一項の規定による管理業務主任者登録申請書を受理すること。
- 十 [[laws/マンションの管理の適正化の推進に関する法律施行規則/本文/第71条.md|第七十一条]]第一項の規定により通知し、並びに同条第二項の規定により登録を拒否し、及び通知すること。
- 十一 [[laws/マンションの管理の適正化の推進に関する法律施行規則/本文/第76条.md|第七十六条]]第二項の規定により登録し、及び通知すること。
- 十二 [[laws/マンションの管理の適正化の推進に関する法律施行規則/本文/第77条.md|第七十七条]]第一項の規定による再交付の申請を受理し、及び同条第四項の規定による返納を受理すること。
- 十三 [[laws/マンションの管理の適正化の推進に関する法律施行規則/本文/第78条.md|第七十八条]]第一項の規定により通知し、及び同条第二項の規定による返納を受理すること。
- 十四 [[laws/マンションの管理の適正化の推進に関する法律施行規則/本文/第80条.md|第八十条]]の規定により読み替えて準用する[[laws/マンションの管理の適正化の推進に関する法律施行規則/本文/第31条.md|第三十一条]]の規定による届出を受理すること。
## ２
地方整備局長及び北海道開発局長は、前項の規定にかかわらず、当該地方整備局長及び北海道開発局長の管轄する区域内において事務を行う管理業務主任者に対し、同項第五号及び第八号に掲げる権限を行うことができる。
