# 第四条 （業務方法書の記載事項）

## 
機構に係る通則法[[laws/413M60000200048/本文/第28条.md|第二十八条]]第二項の主務省令で定める業務方法書に記載すべき事項は、次のとおりとする。機構法[[laws/413M60000200048/本文/第13条.md|第十三条]]第一項第一号に規定する試験及び研究、調査、分析、鑑定並びに講習に関する事項機構法[[laws/413M60000200048/本文/第13条.md|第十三条]]第一項第二号に規定する標本の生産及び配布に関する事項機構法[[laws/413M60000200048/本文/第13条.md|第十三条]]第一項第三号に規定する林木の優良な種苗の生産及び配布に関する事項機構法[[laws/413M60000200048/本文/第13条.md|第十三条]]第一項第四号に規定する森林の造成に関する事項機構法[[laws/413M60000200048/本文/第13条.md|第十三条]]第一項第五号に規定する出資並びに人的及び技術的援助に関する事項機構法[[laws/413M60000200048/本文/第13条.md|第十三条]]第二項第一号に規定する森林保険に関する事項業務委託の基準競争入札その他契約に関する基本的事項その他機構の業務の執行に関して必要な事項

- 一 機構法[[laws/413M60000200048/本文/第13条.md|第十三条]]第一項第一号に規定する試験及び研究、調査、分析、鑑定並びに講習に関する事項
- 二 機構法[[laws/413M60000200048/本文/第13条.md|第十三条]]第一項第二号に規定する標本の生産及び配布に関する事項
- 三 機構法[[laws/413M60000200048/本文/第13条.md|第十三条]]第一項第三号に規定する林木の優良な種苗の生産及び配布に関する事項
- 四 機構法[[laws/413M60000200048/本文/第13条.md|第十三条]]第一項第四号に規定する森林の造成に関する事項
- 五 機構法[[laws/413M60000200048/本文/第13条.md|第十三条]]第一項第五号に規定する出資並びに人的及び技術的援助に関する事項
- 六 機構法[[laws/413M60000200048/本文/第13条.md|第十三条]]第二項第一号に規定する森林保険に関する事項
- 七 業務委託の基準
- 八 競争入札その他契約に関する基本的事項
- 九 その他機構の業務の執行に関して必要な事項
