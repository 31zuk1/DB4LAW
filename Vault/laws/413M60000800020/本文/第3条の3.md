# 第三条の三 （適正業務管理官）

## 
国土地理院に、適正業務管理官一人を置く。

## ２
適正業務管理官は、命を受けて、国土地理院の所掌事務のうち、法令を遵守させるための指導その他の業務の適正な遂行を確保するための措置に関する特定事項に係るものを整理する。
