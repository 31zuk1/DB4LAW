# 第七十条 （地殻監視課の所掌事務）

## 
地殻監視課は、次に掲げる事務をつかさどる。地殻活動の連続観測を行うこと。験潮に関すること。前二号に掲げる事務に関する測量の成果及びその数値化情報の管理及び提供に関すること。地殻活動の監視を行うこと。前四号に掲げる事務に関する調査及び研究を行うこと（地理地殻活動研究センターの所掌に属するものを除く。）。験潮により設置した永久標識の維持及び復旧を行うこと。地震調査研究推進本部の庶務（地震調査委員会に係るものに限る。）及び火山調査研究推進本部の庶務（火山調査委員会に係るものに限る。）の処理を行うこと。

- 一 地殻活動の連続観測を行うこと。
- 二 験潮に関すること。
- 三 前二号に掲げる事務に関する測量の成果及びその数値化情報の管理及び提供に関すること。
- 四 地殻活動の監視を行うこと。
- 五 前四号に掲げる事務に関する調査及び研究を行うこと（地理地殻活動研究センターの所掌に属するものを除く。）。
- 六 験潮により設置した永久標識の維持及び復旧を行うこと。
- 七 地震調査研究推進本部の庶務（地震調査委員会に係るものに限る。）及び火山調査研究推進本部の庶務（火山調査委員会に係るものに限る。）の処理を行うこと。
