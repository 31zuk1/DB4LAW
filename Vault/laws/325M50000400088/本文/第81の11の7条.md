# 第八十一条の十一の七 （指定完成検査機関に係る構成員の構成）

## 
法[[laws/火薬類取締法施行規則/本文/第45条の25.md|第四十五条の二十五]]第三号の経済産業省令で定める構成員は、次の各号に掲げる法人の種類ごとに、それぞれ当該各号に掲げるものとする。一般社団法人社員会社法（平成十七年法律第八十六号）第二条第一号の株式会社株主会社法[[laws/会社法/本文/第2条.md|第二条]]第一号の合名会社、合資会社及び合同会社社員中小企業等協同組合法（昭和二十四年法律第百八十一号）第三条の事業協同組合、事業協同小組合及び企業組合並びに農業協同組合法（昭和二十二年法律第百三十二号）第三条第一項の農業協同組合組合員中小企業等協同組合法[[laws/会社法/本文/第3条.md|第三条]]の協同組合連合会及び農業協同組合法第三条第一項の農業協同組合連合会直接又は間接にこれらを構成する者その他の法人当該法人に応じて前各号に掲げる者に類するもの

- 一 一般社団法人社員
- 二 会社法（平成十七年法律第八十六号）第二条第一号の株式会社株主
- 三 会社法[[laws/会社法/本文/第2条.md|第二条]]第一号の合名会社、合資会社及び合同会社社員
- 四 中小企業等協同組合法（昭和二十四年法律第百八十一号）第三条の事業協同組合、事業協同小組合及び企業組合並びに農業協同組合法（昭和二十二年法律第百三十二号）第三条第一項の農業協同組合組合員
- 五 中小企業等協同組合法第三条の協同組合連合会及び農業協同組合法第三条第一項の農業協同組合連合会直接又は間接にこれらを構成する者
- 六 その他の法人当該法人に応じて前各号に掲げる者に類するもの
