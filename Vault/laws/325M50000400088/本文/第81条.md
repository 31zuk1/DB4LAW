# 第八十一条 （免状交付事務に係る公示）

## 
令[[laws/火薬類取締法施行規則/本文/第6条.md|第六条]]第二号の規定により、経済産業大臣又は都道府県知事が免状交付事務を委託したときは、次の各号に掲げる事項について公示するものとする。委託に係る免状交付事務の内容委託に係る免状交付事務を処理する場所

- 一 委託に係る免状交付事務の内容
- 二 委託に係る免状交付事務を処理する場所
