# 第三条 （史跡名勝天然記念物の場合）

## 
法[[laws/350M50000080029/国宝、重要文化財等の管理、修理等に関する_law.md|第百十八条]]及び法[[laws/350M50000080029/国宝、重要文化財等の管理、修理等に関する_law.md|第百二十条]]において準用する法[[laws/350M50000080029/国宝、重要文化財等の管理、修理等に関する_law.md|第四十七条]]第四項の規定により特別史跡、特別名勝若しくは特別天然記念物又は史跡、名勝若しくは天然記念物（以下「史跡名勝天然記念物」と総称する。）の管理又は復旧に関し技術的指導を求める場合には、次に掲げる事項を記載した書面をもつて行わなければならない。史跡名勝天然記念物の名称指定年月日所在地所有者の氏名又は名称及び住所並びに法人にあつては、その代表者の氏名管理責任者がある場合は、その氏名又は名称及び住所管理団体がある場合は、その名称及び住所並びに代表者の氏名技術的指導を必要とする理由その他参考となるべき事項

- 一 史跡名勝天然記念物の名称
- 二 指定年月日
- 三 所在地
- 四 所有者の氏名又は名称及び住所並びに法人にあつては、その代表者の氏名
- 五 管理責任者がある場合は、その氏名又は名称及び住所
- 六 管理団体がある場合は、その名称及び住所並びに代表者の氏名
- 七 技術的指導を必要とする理由
- 八 その他参考となるべき事項
## ２
前項の書面に添付すべき書類、図面又は写真については、[[laws/350M50000080029/本文/第1条.md|第一条]]第二項の規定を準用する。
