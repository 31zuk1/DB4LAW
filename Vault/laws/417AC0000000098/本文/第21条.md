# 第二十一条 

## 
次の各号のいずれかに該当する場合には、その違反行為をした会社の取締役、執行役、会計参与若しくはその職務を行うべき社員又は監査役は、百万円以下の過料に処する。[[laws/日本郵政株式会社法/本文/第4条.md|第四条]]第二項の規定に違反して、業務を行ったとき。[[laws/日本郵政株式会社法/本文/第6条.md|第六条]]の規定に違反して、日本郵便株式会社の株式を処分したとき。[[laws/日本郵政株式会社法/本文/第8条.md|第八条]]第一項の規定に違反して、募集株式若しくは募集新株予約権を引き受ける者の募集をし、又は株式交換若しくは株式交付に際して株式若しくは新株予約権を交付したとき。[[laws/日本郵政株式会社法/本文/第8条.md|第八条]]第二項の規定に違反して、株式を交付した旨の届出を行わなかったとき。[[laws/日本郵政株式会社法/本文/第10条.md|第十条]]の規定に違反して、事業計画の認可を受けなかったとき。[[laws/日本郵政株式会社法/本文/第12条.md|第十二条]]の規定に違反して、貸借対照表、損益計算書、事業報告書若しくは同条の総務省令で定める書類を提出せず、又は虚偽の記載若しくは記録をしたこれらのものを提出したとき。[[laws/日本郵政株式会社法/本文/第13条.md|第十三条]]第二項の規定による命令に違反したとき。[[laws/日本郵政株式会社法/本文/第16条.md|第十六条]]第一項又は第二項の規定による公表をせず、又は虚偽の公表をしたとき。

- 一 [[laws/日本郵政株式会社法/本文/第4条.md|第四条]]第二項の規定に違反して、業務を行ったとき。
- 二 [[laws/日本郵政株式会社法/本文/第6条.md|第六条]]の規定に違反して、日本郵便株式会社の株式を処分したとき。
- 三 [[laws/日本郵政株式会社法/本文/第8条.md|第八条]]第一項の規定に違反して、募集株式若しくは募集新株予約権を引き受ける者の募集をし、又は株式交換若しくは株式交付に際して株式若しくは新株予約権を交付したとき。
- 四 [[laws/日本郵政株式会社法/本文/第8条.md|第八条]]第二項の規定に違反して、株式を交付した旨の届出を行わなかったとき。
- 五 [[laws/日本郵政株式会社法/本文/第10条.md|第十条]]の規定に違反して、事業計画の認可を受けなかったとき。
- 六 [[laws/日本郵政株式会社法/本文/第12条.md|第十二条]]の規定に違反して、貸借対照表、損益計算書、事業報告書若しくは同条の総務省令で定める書類を提出せず、又は虚偽の記載若しくは記録をしたこれらのものを提出したとき。
- 七 [[laws/日本郵政株式会社法/本文/第13条.md|第十三条]]第二項の規定による命令に違反したとき。
- 八 [[laws/日本郵政株式会社法/本文/第16条.md|第十六条]]第一項又は第二項の規定による公表をせず、又は虚偽の公表をしたとき。
