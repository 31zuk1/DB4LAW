# 第十八条 （参事官の職務）

## 
参事官は、次に掲げる事務をつかさどる。子ども・子育て支援法[[laws/505CO0000000125/こども家庭庁組織令_law.md|第五十九条]]に規定する地域子ども・子育て支援事業に関する交付金に関すること。子ども・子育て支援法[[laws/505CO0000000125/こども家庭庁組織令_law.md|第六十九条]]第一項（第一号に係る部分を除く。）の規定による拠出金の徴収に関すること。児童福祉施設等及びその職員を養成する施設の施設及び設備の整備に関すること。こどもの国協会の解散及び事業の承継に関する法律（昭和五十五年法律第九十一号）[[laws/505CO0000000125/本文/第1条.md|第一条]]第三項に規定する指定法人に関すること。こどもの福祉のための文化の向上に関すること。保育、助産及び母子保護の実施に要する費用並びに児童福祉施設等の入所措置に要する費用の監査に関すること（支援局の所掌に属するものを除く。）。子ども・子育て支援特別会計（育児休業等給付勘定に係る部分を除く。次号において同じ。）の経理に関すること。子ども・子育て支援特別会計に属する国有財産の管理及び処分並びに物品の管理に関すること。こども家庭審議会児童福祉文化分科会の庶務の処理に関すること。

- 一 子ども・子育て支援法[[laws/505CO0000000125/こども家庭庁組織令_law.md|第五十九条]]に規定する地域子ども・子育て支援事業に関する交付金に関すること。
- 二 子ども・子育て支援法[[laws/505CO0000000125/こども家庭庁組織令_law.md|第六十九条]]第一項（第一号に係る部分を除く。）の規定による拠出金の徴収に関すること。
- 三 児童福祉施設等及びその職員を養成する施設の施設及び設備の整備に関すること。
- 四 こどもの国協会の解散及び事業の承継に関する法律（昭和五十五年法律第九十一号）[[laws/505CO0000000125/本文/第1条.md|第一条]]第三項に規定する指定法人に関すること。
- 五 こどもの福祉のための文化の向上に関すること。
- 六 保育、助産及び母子保護の実施に要する費用並びに児童福祉施設等の入所措置に要する費用の監査に関すること（支援局の所掌に属するものを除く。）。
- 七 子ども・子育て支援特別会計（育児休業等給付勘定に係る部分を除く。次号において同じ。）の経理に関すること。
- 八 子ども・子育て支援特別会計に属する国有財産の管理及び処分並びに物品の管理に関すること。
- 九 こども家庭審議会児童福祉文化分科会の庶務の処理に関すること。
