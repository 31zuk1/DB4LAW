# 第三十八条 

## 
次の各号のいずれかに該当する者は、百万円以下の罰金に処する。[[laws/326AC0100000161/本文/第9条.md|第九条]]第一項（[[laws/326AC0100000161/本文/第33条の2.md|第三十三条の二]]第二項において準用する場合を含む。）又は[[laws/326AC0100000161/本文/第22条の3.md|第二十二条の三]]第一項の規定による届出をしないで、又は届出をした運賃若しくは料金によらないで、運賃又は料金を収受した者[[laws/326AC0100000161/本文/第9条.md|第九条]]第二項（[[laws/326AC0100000161/本文/第22条の3.md|第二十二条の三]]第二項及び[[laws/326AC0100000161/本文/第33条の2.md|第三十三条の二]]第二項において準用する場合を含む。）の規定による命令に違反して運賃又は料金を収受した者[[laws/326AC0100000161/本文/第10条.md|第十条]]（[[laws/326AC0100000161/本文/第22条の4.md|第二十二条の四]]及び[[laws/326AC0100000161/本文/第33条の2.md|第三十三条の二]]第二項において準用する場合を含む。）の規定に違反して運賃又は料金の割戻しをした者[[laws/326AC0100000161/本文/第11条.md|第十一条]]第一項（[[laws/326AC0100000161/本文/第33条の2.md|第三十三条の二]]第二項において準用する場合を含む。）の規定による認可を受けないで、又は認可を受けた港湾運送約款によらないで、運送契約を締結した者[[laws/326AC0100000161/本文/第15条.md|第十五条]]（[[laws/326AC0100000161/本文/第33条の2.md|第三十三条の二]]第二項において準用する場合を含む。）の規定に違反した者[[laws/326AC0100000161/本文/第16条.md|第十六条]]第六項、[[laws/326AC0100000161/本文/第17条の2.md|第十七条の二]]第二項又は[[laws/326AC0100000161/本文/第21条.md|第二十一条]]の規定による命令に違反した者[[laws/326AC0100000161/本文/第17条.md|第十七条]]第一項の規定による認可を受けないで事業計画を変更した者[[laws/326AC0100000161/本文/第33条.md|第三十三条]]第一項の規定による報告をせず、又は虚偽の報告をした者[[laws/326AC0100000161/本文/第33条.md|第三十三条]]第二項の規定による検査を拒み、妨げ、又は忌避した者

- 一 [[laws/326AC0100000161/本文/第9条.md|第九条]]第一項（[[laws/326AC0100000161/本文/第33条の2.md|第三十三条の二]]第二項において準用する場合を含む。）又は[[laws/326AC0100000161/本文/第22条の3.md|第二十二条の三]]第一項の規定による届出をしないで、又は届出をした運賃若しくは料金によらないで、運賃又は料金を収受した者
- 二 [[laws/326AC0100000161/本文/第9条.md|第九条]]第二項（[[laws/326AC0100000161/本文/第22条の3.md|第二十二条の三]]第二項及び[[laws/326AC0100000161/本文/第33条の2.md|第三十三条の二]]第二項において準用する場合を含む。）の規定による命令に違反して運賃又は料金を収受した者
- 三 [[laws/326AC0100000161/本文/第10条.md|第十条]]（[[laws/326AC0100000161/本文/第22条の4.md|第二十二条の四]]及び[[laws/326AC0100000161/本文/第33条の2.md|第三十三条の二]]第二項において準用する場合を含む。）の規定に違反して運賃又は料金の割戻しをした者
- 四 [[laws/326AC0100000161/本文/第11条.md|第十一条]]第一項（[[laws/326AC0100000161/本文/第33条の2.md|第三十三条の二]]第二項において準用する場合を含む。）の規定による認可を受けないで、又は認可を受けた港湾運送約款によらないで、運送契約を締結した者
- 五 [[laws/326AC0100000161/本文/第15条.md|第十五条]]（[[laws/326AC0100000161/本文/第33条の2.md|第三十三条の二]]第二項において準用する場合を含む。）の規定に違反した者
- 六 [[laws/326AC0100000161/本文/第16条.md|第十六条]]第六項、[[laws/326AC0100000161/本文/第17条の2.md|第十七条の二]]第二項又は[[laws/326AC0100000161/本文/第21条.md|第二十一条]]の規定による命令に違反した者
- 七 [[laws/326AC0100000161/本文/第17条.md|第十七条]]第一項の規定による認可を受けないで事業計画を変更した者
- 八 [[laws/326AC0100000161/本文/第33条.md|第三十三条]]第一項の規定による報告をせず、又は虚偽の報告をした者
- 九 [[laws/326AC0100000161/本文/第33条.md|第三十三条]]第二項の規定による検査を拒み、妨げ、又は忌避した者
