# 第十九条 （法令の変更適用）

## 
法令の規定は、法律及び政令に特別の定のある場合を除いて、左のように変更してこれを適用する。通常裁判所とあるのは、裁判所とする。大審院とあるのは、最高裁判所とする。控訴院とあるのは、高等裁判所とする。区裁判所とあるのは、地方裁判所とする。判事とあるのは、裁判官とする。受命判事とあるのは、受命裁判官とする。受託判事とあるのは、受託裁判官とする。登記判事とあるのは、登記官吏とする。削除地方裁判所長の有する権限は、地方裁判所がこれを有する。

- 一 通常裁判所とあるのは、裁判所とする。
- 二 大審院とあるのは、最高裁判所とする。
- 三 控訴院とあるのは、高等裁判所とする。
- 四 区裁判所とあるのは、地方裁判所とする。
- 五 判事とあるのは、裁判官とする。
- 六 受命判事とあるのは、受命裁判官とする。
- 七 受託判事とあるのは、受託裁判官とする。
- 八 登記判事とあるのは、登記官吏とする。
- 九 削除
- 十 地方裁判所長の有する権限は、地方裁判所がこれを有する。
