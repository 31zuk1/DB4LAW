# 第七十二条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、二十万円以下の罰金に処する。[[laws/麻薬及び向精神薬取締法/本文/第7条.md|第七条]]第一項（同条第二項において準用する場合を含む。）若しくは第三項、[[laws/麻薬及び向精神薬取締法/本文/第15条.md|第十五条]]又は[[laws/麻薬及び向精神薬取締法/本文/第18条.md|第十八条]]第六項の規定に違反したとき。[[laws/麻薬及び向精神薬取締法/本文/第42条.md|第四十二条]]から[[laws/麻薬及び向精神薬取締法/本文/第45条.md|第四十五条]]まで、[[laws/麻薬及び向精神薬取締法/本文/第46条.md|第四十六条]]第一項又は[[laws/麻薬及び向精神薬取締法/本文/第47条.md|第四十七条]]から[[laws/麻薬及び向精神薬取締法/本文/第49条.md|第四十九条]]までの規定に違反して、届出をせず、又は虚偽の届出をしたとき。[[laws/麻薬及び向精神薬取締法/本文/第50条の4.md|第五十条の四]]又は[[laws/麻薬及び向精神薬取締法/本文/第50条の7.md|第五十条の七]]において準用する[[laws/麻薬及び向精神薬取締法/本文/第4条.md|第四条]]第三項の規定に違反したとき。向精神薬処方箋を偽造し、又は変造したとき。[[laws/麻薬及び向精神薬取締法/本文/第50条の18.md|第五十条の十八]]において準用する[[laws/麻薬及び向精神薬取締法/本文/第19条の2.md|第十九条の二]]の規定に違反したとき。[[laws/麻薬及び向精神薬取締法/本文/第50条の19.md|第五十条の十九]]の規定に違反したとき。[[laws/麻薬及び向精神薬取締法/本文/第50条の22.md|第五十条の二十二]]第一項の規定に違反して、届出をせず、又は虚偽の届出をしたとき。[[laws/麻薬及び向精神薬取締法/本文/第50条の23.md|第五十条の二十三]]第一項から第三項までの規定に違反して、記録をせず、又は虚偽の記録をしたとき。[[laws/麻薬及び向精神薬取締法/本文/第50条の23.md|第五十条の二十三]]第四項の規定に違反して、記録の保存をしなかつたとき。[[laws/麻薬及び向精神薬取締法/本文/第50条の27.md|第五十条の二十七]]の規定による届出をせず、又は虚偽の届出をしたとき。[[laws/麻薬及び向精神薬取締法/本文/第50条の38.md|第五十条の三十八]]第一項の規定による報告をせず、若しくは虚偽の報告をし、又は立入り、検査若しくは収去を拒み、妨げ、若しくは忌避したとき。

- 一 [[laws/麻薬及び向精神薬取締法/本文/第7条.md|第七条]]第一項（同条第二項において準用する場合を含む。）若しくは第三項、[[laws/麻薬及び向精神薬取締法/本文/第15条.md|第十五条]]又は[[laws/麻薬及び向精神薬取締法/本文/第18条.md|第十八条]]第六項の規定に違反したとき。
- 二 [[laws/麻薬及び向精神薬取締法/本文/第42条.md|第四十二条]]から[[laws/麻薬及び向精神薬取締法/本文/第45条.md|第四十五条]]まで、[[laws/麻薬及び向精神薬取締法/本文/第46条.md|第四十六条]]第一項又は[[laws/麻薬及び向精神薬取締法/本文/第47条.md|第四十七条]]から[[laws/麻薬及び向精神薬取締法/本文/第49条.md|第四十九条]]までの規定に違反して、届出をせず、又は虚偽の届出をしたとき。
- 三 [[laws/麻薬及び向精神薬取締法/本文/第50条の4.md|第五十条の四]]又は[[laws/麻薬及び向精神薬取締法/本文/第50条の7.md|第五十条の七]]において準用する[[laws/麻薬及び向精神薬取締法/本文/第4条.md|第四条]]第三項の規定に違反したとき。
- 四 向精神薬処方箋を偽造し、又は変造したとき。
- 五 [[laws/麻薬及び向精神薬取締法/本文/第50条の18.md|第五十条の十八]]において準用する[[laws/麻薬及び向精神薬取締法/本文/第19条の2.md|第十九条の二]]の規定に違反したとき。
- 六 [[laws/麻薬及び向精神薬取締法/本文/第50条の19.md|第五十条の十九]]の規定に違反したとき。
- 七 [[laws/麻薬及び向精神薬取締法/本文/第50条の22.md|第五十条の二十二]]第一項の規定に違反して、届出をせず、又は虚偽の届出をしたとき。
- 八 [[laws/麻薬及び向精神薬取締法/本文/第50条の23.md|第五十条の二十三]]第一項から第三項までの規定に違反して、記録をせず、又は虚偽の記録をしたとき。
- 九 [[laws/麻薬及び向精神薬取締法/本文/第50条の23.md|第五十条の二十三]]第四項の規定に違反して、記録の保存をしなかつたとき。
- 十 [[laws/麻薬及び向精神薬取締法/本文/第50条の27.md|第五十条の二十七]]の規定による届出をせず、又は虚偽の届出をしたとき。
- 十一 [[laws/麻薬及び向精神薬取締法/本文/第50条の38.md|第五十条の三十八]]第一項の規定による報告をせず、若しくは虚偽の報告をし、又は立入り、検査若しくは収去を拒み、妨げ、若しくは忌避したとき。
