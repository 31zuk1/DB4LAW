# 第六十九条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、三年以下の拘禁刑若しくは五十万円以下の罰金に処し、又はこれを併科する。[[laws/麻薬及び向精神薬取締法/本文/第14条.md|第十四条]]第一項の規定に違反して、許可を受けないで麻薬を輸入したとき。[[laws/麻薬及び向精神薬取締法/本文/第18条.md|第十八条]]第一項の規定に違反して、許可を受けないで麻薬を輸出したとき。[[laws/麻薬及び向精神薬取締法/本文/第21条.md|第二十一条]]第一項の規定に違反して、許可を受けないで麻薬又は家庭麻薬を製造したとき。[[laws/麻薬及び向精神薬取締法/本文/第23条.md|第二十三条]]第一項の規定に違反して、許可を受けないで麻薬を製剤し、又は小分けしたとき。[[laws/麻薬及び向精神薬取締法/本文/第25条.md|第二十五条]]の規定に違反したとき。[[laws/麻薬及び向精神薬取締法/本文/第29条の2.md|第二十九条の二]]の規定に違反したとき。[[laws/麻薬及び向精神薬取締法/本文/第51条.md|第五十一条]]第一項の規定による業務又は研究の停止の命令に違反したとき。

- 一 [[laws/麻薬及び向精神薬取締法/本文/第14条.md|第十四条]]第一項の規定に違反して、許可を受けないで麻薬を輸入したとき。
- 二 [[laws/麻薬及び向精神薬取締法/本文/第18条.md|第十八条]]第一項の規定に違反して、許可を受けないで麻薬を輸出したとき。
- 三 [[laws/麻薬及び向精神薬取締法/本文/第21条.md|第二十一条]]第一項の規定に違反して、許可を受けないで麻薬又は家庭麻薬を製造したとき。
- 四 [[laws/麻薬及び向精神薬取締法/本文/第23条.md|第二十三条]]第一項の規定に違反して、許可を受けないで麻薬を製剤し、又は小分けしたとき。
- 五 [[laws/麻薬及び向精神薬取締法/本文/第25条.md|第二十五条]]の規定に違反したとき。
- 六 [[laws/麻薬及び向精神薬取締法/本文/第29条の2.md|第二十九条の二]]の規定に違反したとき。
- 七 [[laws/麻薬及び向精神薬取締法/本文/第51条.md|第五十一条]]第一項の規定による業務又は研究の停止の命令に違反したとき。
