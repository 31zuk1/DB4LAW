# 第七十条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、一年以下の拘禁刑若しくは二十万円以下の罰金に処し、又はこれを併科する。[[laws/麻薬及び向精神薬取締法/本文/第4条.md|第四条]]第三項の規定に違反したとき。[[laws/麻薬及び向精神薬取締法/本文/第19条の2.md|第十九条の二]]の規定に違反したとき。[[laws/麻薬及び向精神薬取締法/本文/第27条.md|第二十七条]]第六項の規定による処方箋の記載に当たり、虚偽の記載をしたとき。[[laws/麻薬及び向精神薬取締法/本文/第29条.md|第二十九条]]の規定に違反して麻薬を廃棄したとき。[[laws/麻薬及び向精神薬取締法/本文/第30条.md|第三十条]]第一項から第三項まで又は[[laws/麻薬及び向精神薬取締法/本文/第31条.md|第三十一条]]の規定に違反したとき。[[laws/麻薬及び向精神薬取締法/本文/第32条.md|第三十二条]]第一項の規定による譲受証の交付を受けないで、又はこれと引き換えないで麻薬を交付したとき。[[laws/麻薬及び向精神薬取締法/本文/第32条.md|第三十二条]]第一項の規定による譲渡証を交付しないで麻薬を交付したとき。[[laws/麻薬及び向精神薬取締法/本文/第32条.md|第三十二条]]第一項の規定による譲受証若しくは譲渡証に虚偽の記載をし、又は同条第三項に規定する電磁的記録に虚偽の記録をしたとき。[[laws/麻薬及び向精神薬取締法/本文/第32条.md|第三十二条]]第三項、[[laws/麻薬及び向精神薬取締法/本文/第33条.md|第三十三条]]又は[[laws/麻薬及び向精神薬取締法/本文/第34条.md|第三十四条]]の規定に違反したとき。[[laws/麻薬及び向精神薬取締法/本文/第35条.md|第三十五条]]第一項若しくは第二項又は[[laws/麻薬及び向精神薬取締法/本文/第36条.md|第三十六条]]第一項若しくは第三項（これらの規定を同条第四項において準用する場合を含む。）の規定による届出に当たり、虚偽の届出をしたとき。[[laws/麻薬及び向精神薬取締法/本文/第37条.md|第三十七条]]第一項、[[laws/麻薬及び向精神薬取締法/本文/第38条.md|第三十八条]]第一項、[[laws/麻薬及び向精神薬取締法/本文/第39条.md|第三十九条]]第一項又は[[laws/麻薬及び向精神薬取締法/本文/第40条.md|第四十条]]第一項の規定に違反して、帳簿を備えず、又は帳簿に記載をせず、若しくは虚偽の記載をしたとき。[[laws/麻薬及び向精神薬取締法/本文/第37条.md|第三十七条]]第二項、[[laws/麻薬及び向精神薬取締法/本文/第38条.md|第三十八条]]第二項、[[laws/麻薬及び向精神薬取締法/本文/第39条.md|第三十九条]]第三項又は[[laws/麻薬及び向精神薬取締法/本文/第40条.md|第四十条]]第三項の規定に違反して、帳簿の保存をしなかつたとき。[[laws/麻薬及び向精神薬取締法/本文/第41条.md|第四十一条]]の規定による診療録又は診療簿の記載に当たり、虚偽の記載をしたとき。麻薬処方箋を偽造し、又は変造したとき。[[laws/麻薬及び向精神薬取締法/本文/第50条の9.md|第五十条の九]]第一項又は第二項の規定に違反して、許可を受けないで向精神薬を輸入したとき。[[laws/麻薬及び向精神薬取締法/本文/第50条の12.md|第五十条の十二]]第一項若しくは第二項又は[[laws/麻薬及び向精神薬取締法/本文/第50条の13.md|第五十条の十三]]第一項の規定に違反して、許可を受けないで向精神薬を輸出したとき。[[laws/麻薬及び向精神薬取締法/本文/第50条の17.md|第五十条の十七]]の規定に違反したとき。[[laws/麻薬及び向精神薬取締法/本文/第50条の18.md|第五十条の十八]]において準用する[[laws/麻薬及び向精神薬取締法/本文/第29条の2.md|第二十九条の二]]の規定に違反したとき。[[laws/麻薬及び向精神薬取締法/本文/第50条の39.md|第五十条の三十九]]から[[laws/麻薬及び向精神薬取締法/本文/第50条の41.md|第五十条の四十一]]までの規定による命令に違反したとき。[[laws/麻薬及び向精神薬取締法/本文/第51条.md|第五十一条]]第二項の規定による業務の停止の命令に違反したとき。[[laws/麻薬及び向精神薬取締法/本文/第58条の19.md|第五十八条の十九]]の規定に違反したとき。

- 一 [[laws/麻薬及び向精神薬取締法/本文/第4条.md|第四条]]第三項の規定に違反したとき。
- 二 [[laws/麻薬及び向精神薬取締法/本文/第19条の2.md|第十九条の二]]の規定に違反したとき。
- 三 [[laws/麻薬及び向精神薬取締法/本文/第27条.md|第二十七条]]第六項の規定による処方箋の記載に当たり、虚偽の記載をしたとき。
- 四 [[laws/麻薬及び向精神薬取締法/本文/第29条.md|第二十九条]]の規定に違反して麻薬を廃棄したとき。
- 五 [[laws/麻薬及び向精神薬取締法/本文/第30条.md|第三十条]]第一項から第三項まで又は[[laws/麻薬及び向精神薬取締法/本文/第31条.md|第三十一条]]の規定に違反したとき。
- 六 [[laws/麻薬及び向精神薬取締法/本文/第32条.md|第三十二条]]第一項の規定による譲受証の交付を受けないで、又はこれと引き換えないで麻薬を交付したとき。
- 七 [[laws/麻薬及び向精神薬取締法/本文/第32条.md|第三十二条]]第一項の規定による譲渡証を交付しないで麻薬を交付したとき。
- 八 [[laws/麻薬及び向精神薬取締法/本文/第32条.md|第三十二条]]第一項の規定による譲受証若しくは譲渡証に虚偽の記載をし、又は同条第三項に規定する電磁的記録に虚偽の記録をしたとき。
- 九 [[laws/麻薬及び向精神薬取締法/本文/第32条.md|第三十二条]]第三項、[[laws/麻薬及び向精神薬取締法/本文/第33条.md|第三十三条]]又は[[laws/麻薬及び向精神薬取締法/本文/第34条.md|第三十四条]]の規定に違反したとき。
- 十 [[laws/麻薬及び向精神薬取締法/本文/第35条.md|第三十五条]]第一項若しくは第二項又は[[laws/麻薬及び向精神薬取締法/本文/第36条.md|第三十六条]]第一項若しくは第三項（これらの規定を同条第四項において準用する場合を含む。）の規定による届出に当たり、虚偽の届出をしたとき。
- 十一 [[laws/麻薬及び向精神薬取締法/本文/第37条.md|第三十七条]]第一項、[[laws/麻薬及び向精神薬取締法/本文/第38条.md|第三十八条]]第一項、[[laws/麻薬及び向精神薬取締法/本文/第39条.md|第三十九条]]第一項又は[[laws/麻薬及び向精神薬取締法/本文/第40条.md|第四十条]]第一項の規定に違反して、帳簿を備えず、又は帳簿に記載をせず、若しくは虚偽の記載をしたとき。
- 十二 [[laws/麻薬及び向精神薬取締法/本文/第37条.md|第三十七条]]第二項、[[laws/麻薬及び向精神薬取締法/本文/第38条.md|第三十八条]]第二項、[[laws/麻薬及び向精神薬取締法/本文/第39条.md|第三十九条]]第三項又は[[laws/麻薬及び向精神薬取締法/本文/第40条.md|第四十条]]第三項の規定に違反して、帳簿の保存をしなかつたとき。
- 十三 [[laws/麻薬及び向精神薬取締法/本文/第41条.md|第四十一条]]の規定による診療録又は診療簿の記載に当たり、虚偽の記載をしたとき。
- 十四 麻薬処方箋を偽造し、又は変造したとき。
- 十五 [[laws/麻薬及び向精神薬取締法/本文/第50条の9.md|第五十条の九]]第一項又は第二項の規定に違反して、許可を受けないで向精神薬を輸入したとき。
- 十六 [[laws/麻薬及び向精神薬取締法/本文/第50条の12.md|第五十条の十二]]第一項若しくは第二項又は[[laws/麻薬及び向精神薬取締法/本文/第50条の13.md|第五十条の十三]]第一項の規定に違反して、許可を受けないで向精神薬を輸出したとき。
- 十七 [[laws/麻薬及び向精神薬取締法/本文/第50条の17.md|第五十条の十七]]の規定に違反したとき。
- 十八 [[laws/麻薬及び向精神薬取締法/本文/第50条の18.md|第五十条の十八]]において準用する[[laws/麻薬及び向精神薬取締法/本文/第29条の2.md|第二十九条の二]]の規定に違反したとき。
- 十九 [[laws/麻薬及び向精神薬取締法/本文/第50条の39.md|第五十条の三十九]]から[[laws/麻薬及び向精神薬取締法/本文/第50条の41.md|第五十条の四十一]]までの規定による命令に違反したとき。
- 二十 [[laws/麻薬及び向精神薬取締法/本文/第51条.md|第五十一条]]第二項の規定による業務の停止の命令に違反したとき。
- 二十一 [[laws/麻薬及び向精神薬取締法/本文/第58条の19.md|第五十八条の十九]]の規定に違反したとき。
