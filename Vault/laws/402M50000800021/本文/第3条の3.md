# 第三条の三 （聴聞決定予定日の通知）

## 
法[[laws/貨物自動車運送事業法施行規則/本文/第5条.md|第五条]]第五号の規定による通知をするときは、法[[laws/貨物自動車運送事業法施行規則/本文/第60条.md|第六十条]]第四項の規定による検査が行われた日（以下この条において「検査日」という。）から十日以内に、検査日から起算して六十日以内の特定の日を通知するものとする。
