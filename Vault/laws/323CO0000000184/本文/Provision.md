# 附則

## 
食品衛生法（以下法という。）[[laws/323CO0000000184/食品衛生法施行に伴う国庫補助に関する政令_law.md|第六十二条]]の規定による国庫補助は、都道府県の支弁する費用のうち、厚生労働大臣及び内閣総理大臣（第三号及び第五号に掲げる費用については、厚生労働大臣）の定める基準により、次に掲げる費用の支出精算額に対してこれを行う。法[[laws/323CO0000000184/食品衛生法施行に伴う国庫補助に関する政令_law.md|第二十八条]]第一項（法[[laws/323CO0000000184/食品衛生法施行に伴う国庫補助に関する政令_law.md|第六十八条]]第一項及び第三項において準用する場合を含む。）の規定による収去に要する費用については、運搬用具費及び人夫費法[[laws/323CO0000000184/食品衛生法施行に伴う国庫補助に関する政令_law.md|第三十条]]第一項（法[[laws/323CO0000000184/食品衛生法施行に伴う国庫補助に関する政令_law.md|第六十八条]]第一項及び第三項において準用する場合を含む。）の規定による食品衛生監視員の設置に要する費用については、俸給、その他の給与、旅費及び事務費法[[laws/323CO0000000184/食品衛生法施行に伴う国庫補助に関する政令_law.md|第五十五条]]第一項（法[[laws/323CO0000000184/食品衛生法施行に伴う国庫補助に関する政令_law.md|第六十八条]]第一項において準用する場合を含む。）の規定による営業の許可に要する費用については、食品衛生監視員が調査のために要する旅費法[[laws/323CO0000000184/食品衛生法施行に伴う国庫補助に関する政令_law.md|第五十九条]]（法[[laws/323CO0000000184/食品衛生法施行に伴う国庫補助に関する政令_law.md|第六十八条]]第一項及び第三項において準用する場合を含む。）の規定による廃棄に要する費用については、運搬用具費及び人夫費法[[laws/323CO0000000184/食品衛生法施行に伴う国庫補助に関する政令_law.md|第六十四条]]第一項又は第二項（法[[laws/323CO0000000184/食品衛生法施行に伴う国庫補助に関する政令_law.md|第六十八条]]第一項において準用する場合を含む。）の規定による死体の解剖に要する費用については、医師に対する報酬、施設及び用具の借入費、人夫費並びに雑費法の施行に関する訴訟事件に要する費用及びその結果支払う賠償の費用については、その全額

- 一 法[[laws/323CO0000000184/食品衛生法施行に伴う国庫補助に関する政令_law.md|第二十八条]]第一項（法[[laws/323CO0000000184/食品衛生法施行に伴う国庫補助に関する政令_law.md|第六十八条]]第一項及び第三項において準用する場合を含む。）の規定による収去に要する費用については、運搬用具費及び人夫費
- 二 法[[laws/323CO0000000184/食品衛生法施行に伴う国庫補助に関する政令_law.md|第三十条]]第一項（法[[laws/323CO0000000184/食品衛生法施行に伴う国庫補助に関する政令_law.md|第六十八条]]第一項及び第三項において準用する場合を含む。）の規定による食品衛生監視員の設置に要する費用については、俸給、その他の給与、旅費及び事務費
- 三 法[[laws/323CO0000000184/食品衛生法施行に伴う国庫補助に関する政令_law.md|第五十五条]]第一項（法[[laws/323CO0000000184/食品衛生法施行に伴う国庫補助に関する政令_law.md|第六十八条]]第一項において準用する場合を含む。）の規定による営業の許可に要する費用については、食品衛生監視員が調査のために要する旅費
- 四 法[[laws/323CO0000000184/食品衛生法施行に伴う国庫補助に関する政令_law.md|第五十九条]]（法[[laws/323CO0000000184/食品衛生法施行に伴う国庫補助に関する政令_law.md|第六十八条]]第一項及び第三項において準用する場合を含む。）の規定による廃棄に要する費用については、運搬用具費及び人夫費
- 五 法[[laws/323CO0000000184/食品衛生法施行に伴う国庫補助に関する政令_law.md|第六十四条]]第一項又は第二項（法[[laws/323CO0000000184/食品衛生法施行に伴う国庫補助に関する政令_law.md|第六十八条]]第一項において準用する場合を含む。）の規定による死体の解剖に要する費用については、医師に対する報酬、施設及び用具の借入費、人夫費並びに雑費
- 六 法の施行に関する訴訟事件に要する費用及びその結果支払う賠償の費用については、その全額
