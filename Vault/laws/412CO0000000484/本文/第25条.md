# 第二十五条 （保険媒介業務を行うことができる者等）

## 
法[[laws/金融サービスの提供及び利用環境の整備等に関する法律施行令/本文/第17条.md|第十七条]]第一項に規定する政令で定める者は、次に掲げる者とする。農業協同組合等漁業協同組合等信用協同組合及び協同組合連合会信用金庫及び信用金庫連合会長期信用銀行労働金庫及び労働金庫連合会農林中央金庫株式会社商工組合中央金庫

- 一 農業協同組合等
- 二 漁業協同組合等
- 三 信用協同組合及び協同組合連合会
- 四 信用金庫及び信用金庫連合会
- 五 長期信用銀行
- 六 労働金庫及び労働金庫連合会
- 七 農林中央金庫
- 八 株式会社商工組合中央金庫
## ２
法[[laws/金融サービスの提供及び利用環境の整備等に関する法律施行令/本文/第17条.md|第十七条]]第一項に規定する政令で定める法律は、次のとおりとする。農業協同組合法水産業協同組合法中小企業等協同組合法信用金庫法長期信用銀行法労働金庫法農林中央金庫法株式会社商工組合中央金庫法

- 一 農業協同組合法
- 二 水産業協同組合法
- 三 中小企業等協同組合法
- 四 信用金庫法
- 五 長期信用銀行法
- 六 労働金庫法
- 七 農林中央金庫法
- 八 株式会社商工組合中央金庫法
