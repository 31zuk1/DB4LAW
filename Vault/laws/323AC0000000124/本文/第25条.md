# 第二十五条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、一年以下の拘禁刑若しくは二十万円以下の罰金に処し、又はこれを併科する。[[laws/323AC0000000124/本文/第7条.md|第七条]]第二項（[[laws/323AC0000000124/本文/第13条.md|第十三条]]第二項において準用する場合を含む。）の規定に違反したとき。[[laws/323AC0000000124/本文/第10条.md|第十条]]第一項（[[laws/323AC0000000124/本文/第17条.md|第十七条]]第一項又は第二項において準用する場合を含む。）の規定に違反して、帳簿を備えず、又は帳簿に記載せず、若しくは虚偽の記載をしたとき。[[laws/323AC0000000124/本文/第10条.md|第十条]]第二項（[[laws/323AC0000000124/本文/第17条.md|第十七条]]第一項又は第二項において準用する場合を含む。）の規定に違反して、帳簿の保存をしなかつたとき。[[laws/323AC0000000124/本文/第12条.md|第十二条]]（[[laws/323AC0000000124/本文/第17条.md|第十七条]]第一項又は第二項において準用する場合を含む。）の規定に違反して、大麻を廃棄したとき。[[laws/323AC0000000124/本文/第12条の2.md|第十二条の二]]第一項、[[laws/323AC0000000124/本文/第12条の7.md|第十二条の七]]第一項若しくは第三項又は[[laws/323AC0000000124/本文/第12条の8.md|第十二条の八]]第三項（これらの規定を[[laws/323AC0000000124/本文/第17条.md|第十七条]]第一項又は第二項において準用する場合を含む。）の規定による届出をする場合において虚偽の届出をしたとき。[[laws/323AC0000000124/本文/第12条の4.md|第十二条の四]]第三項（[[laws/323AC0000000124/本文/第17条.md|第十七条]]第一項において準用する場合を含む。）の規定による報告をする場合において虚偽の報告をしたとき。[[laws/323AC0000000124/本文/第12条の5.md|第十二条の五]]又は[[laws/323AC0000000124/本文/第16条.md|第十六条]]の規定に違反したとき。[[laws/323AC0000000124/本文/第12条の8.md|第十二条の八]]第二項（[[laws/323AC0000000124/本文/第17条.md|第十七条]]第一項又は第二項において準用する場合を含む。）の規定に違反したとき。

- 一 [[laws/323AC0000000124/本文/第7条.md|第七条]]第二項（[[laws/323AC0000000124/本文/第13条.md|第十三条]]第二項において準用する場合を含む。）の規定に違反したとき。
- 二 [[laws/323AC0000000124/本文/第10条.md|第十条]]第一項（[[laws/323AC0000000124/本文/第17条.md|第十七条]]第一項又は第二項において準用する場合を含む。）の規定に違反して、帳簿を備えず、又は帳簿に記載せず、若しくは虚偽の記載をしたとき。
- 三 [[laws/323AC0000000124/本文/第10条.md|第十条]]第二項（[[laws/323AC0000000124/本文/第17条.md|第十七条]]第一項又は第二項において準用する場合を含む。）の規定に違反して、帳簿の保存をしなかつたとき。
- 四 [[laws/323AC0000000124/本文/第12条.md|第十二条]]（[[laws/323AC0000000124/本文/第17条.md|第十七条]]第一項又は第二項において準用する場合を含む。）の規定に違反して、大麻を廃棄したとき。
- 五 [[laws/323AC0000000124/本文/第12条の2.md|第十二条の二]]第一項、[[laws/323AC0000000124/本文/第12条の7.md|第十二条の七]]第一項若しくは第三項又は[[laws/323AC0000000124/本文/第12条の8.md|第十二条の八]]第三項（これらの規定を[[laws/323AC0000000124/本文/第17条.md|第十七条]]第一項又は第二項において準用する場合を含む。）の規定による届出をする場合において虚偽の届出をしたとき。
- 六 [[laws/323AC0000000124/本文/第12条の4.md|第十二条の四]]第三項（[[laws/323AC0000000124/本文/第17条.md|第十七条]]第一項において準用する場合を含む。）の規定による報告をする場合において虚偽の報告をしたとき。
- 七 [[laws/323AC0000000124/本文/第12条の5.md|第十二条の五]]又は[[laws/323AC0000000124/本文/第16条.md|第十六条]]の規定に違反したとき。
- 八 [[laws/323AC0000000124/本文/第12条の8.md|第十二条の八]]第二項（[[laws/323AC0000000124/本文/第17条.md|第十七条]]第一項又は第二項において準用する場合を含む。）の規定に違反したとき。
