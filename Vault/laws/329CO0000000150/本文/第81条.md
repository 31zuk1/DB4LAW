# 第八十一条 （留置された貨物についての準用規定）

## 
[[laws/329CO0000000150/本文/第70条.md|第七十条]]第二項及び[[laws/329CO0000000150/本文/第71条.md|第七十一条]]から前条までの規定は、法[[laws/329CO0000000150/本文/第86条.md|第八十六条]]第一項（旅客等の携帯品の留置）又は法[[laws/329CO0000000150/本文/第87条.md|第八十七条]]第一項（原産地を偽つた表示等がされている貨物の留置）の規定により留置された貨物について準用する。この場合において、[[laws/329CO0000000150/本文/第71条.md|第七十一条]]第一項中「法[[laws/329CO0000000150/本文/第83条.md|第八十三条]]第一項（収容の解除）に規定する承認」とあるのは「法[[laws/329CO0000000150/本文/第86条.md|第八十六条]]第二項又は法[[laws/329CO0000000150/本文/第87条.md|第八十七条]]第二項の規定による返還」と、「申請書を税関長に提出しなければならない。」とあるのは「申請書を税関長に提出しなければならない。ただし、法[[laws/329CO0000000150/本文/第86条.md|第八十六条]]第一項の規定により留置された携帯品については、留置証を税関長に提出することをもつて足りる。」と、同条第二項及び第三項中「申請書」とあるのは「申請書又は留置証」と読み替えるものとする。
