# 第六十条 

## 
左の場合においては、その行為をなした特別経理株式会社若しくは金融機関の取締役その他これに準ずる者又は特別管理人は、これを五千円以下の過料に処する。[[laws/企業再建整備法/本文/第9条.md|第九条]]第二項、[[laws/企業再建整備法/本文/第14条.md|第十四条]]第一項若しくは[[laws/企業再建整備法/本文/第18条.md|第十八条]]（[[laws/企業再建整備法/本文/第18条の3.md|第十八条の三]]第四項、[[laws/企業再建整備法/本文/第20条.md|第二十条]]第二項、[[laws/企業再建整備法/本文/第21条.md|第二十一条]]第二項及び[[laws/企業再建整備法/本文/第54条の2.md|第五十四条の二]]第二項において準用する場合を含む。以下同じ。）、[[laws/企業再建整備法/本文/第35条.md|第三十五条]]第三項、[[laws/企業再建整備法/本文/第35条の4.md|第三十五条の四]]、[[laws/企業再建整備法/本文/第37条.md|第三十七条]]第一項又は[[laws/企業再建整備法/本文/第41条.md|第四十一条]]第一項（[[laws/企業再建整備法/本文/第54条の2.md|第五十四条の二]]第二項において準用する場合を含む。）の規定による公告をせず、又は虚偽の公告をしたとき[[laws/企業再建整備法/本文/第9条.md|第九条]]第二項、[[laws/企業再建整備法/本文/第14条.md|第十四条]]第一項、[[laws/企業再建整備法/本文/第18条.md|第十八条]]、[[laws/企業再建整備法/本文/第35条.md|第三十五条]]第三項又は[[laws/企業再建整備法/本文/第35条の4.md|第三十五条の四]]の規定に違反して書類を備へ置かず、又は正当の事由なくして書類の閲覧を拒んだとき[[laws/企業再建整備法/本文/第9条.md|第九条]]第一項又は[[laws/企業再建整備法/本文/第35条.md|第三十五条]]第二項の規定に違反して特別管理人の承認を受けなかつたときこの法律又はこの法律に基いて発する命令に違反して登記又は登録を怠つたとき[[laws/企業再建整備法/本文/第26条の2.md|第二十六条の二]]第三項乃至第五項の規定による通知を怠り、又は虚偽の通知をしたとき[[laws/企業再建整備法/本文/第34条.md|第三十四条]]第四項の規定に違反して株式の併合をなさないとき[[laws/企業再建整備法/本文/第34条の2.md|第三十四条の二]]第一項（[[laws/企業再建整備法/本文/第54条の2.md|第五十四条の二]]第二項において準用する場合を含む。）の規定に違反して退職金を支給したとき[[laws/企業再建整備法/本文/第34条の4.md|第三十四条の四]]第五項の規定に違反して積立金を使用したとき[[laws/企業再建整備法/本文/第47条の2.md|第四十七条の二]]第一項又は[[laws/企業再建整備法/本文/第47条の3.md|第四十七条の三]]の規定による報告を怠り、又は虚偽の報告をしたとき正当な事由がなく、[[laws/企業再建整備法/本文/第47条の2.md|第四十七条の二]]第一項又は[[laws/企業再建整備法/本文/第47条の3.md|第四十七条の三]]の規定による検査を拒み、妨げ、又は忌避したとき[[laws/企業再建整備法/本文/第47条の2.md|第四十七条の二]]第二項の規定による報告を怠り、又は虚偽の報告をしたとき[[laws/企業再建整備法/本文/第49条.md|第四十九条]]第一項（[[laws/企業再建整備法/本文/第54条の2.md|第五十四条の二]]第二項において準用する場合を含む。）の規定による命令に違反したとき[[laws/企業再建整備法/本文/第26条.md|第二十六条]]第四項、[[laws/企業再建整備法/本文/第40条の3.md|第四十条の三]]又は[[laws/企業再建整備法/本文/第41条.md|第四十一条]]第一項（[[laws/企業再建整備法/本文/第54条の2.md|第五十四条の二]]第二項において準用する場合を含む。）の規定による報告を怠つたとき[[laws/企業再建整備法/本文/第42条の3.md|第四十二条の三]]第一項の規定による仮勘定監理人の選任を怠り、又は同条第二項において準用する会社経理応急措置法[[laws/企業再建整備法/本文/第17条.md|第十七条]]第五項の規定による届出を怠つたとき

- 一 [[laws/企業再建整備法/本文/第9条.md|第九条]]第二項、[[laws/企業再建整備法/本文/第14条.md|第十四条]]第一項若しくは[[laws/企業再建整備法/本文/第18条.md|第十八条]]（[[laws/企業再建整備法/本文/第18条の3.md|第十八条の三]]第四項、[[laws/企業再建整備法/本文/第20条.md|第二十条]]第二項、[[laws/企業再建整備法/本文/第21条.md|第二十一条]]第二項及び[[laws/企業再建整備法/本文/第54条の2.md|第五十四条の二]]第二項において準用する場合を含む。以下同じ。）、[[laws/企業再建整備法/本文/第35条.md|第三十五条]]第三項、[[laws/企業再建整備法/本文/第35条の4.md|第三十五条の四]]、[[laws/企業再建整備法/本文/第37条.md|第三十七条]]第一項又は[[laws/企業再建整備法/本文/第41条.md|第四十一条]]第一項（[[laws/企業再建整備法/本文/第54条の2.md|第五十四条の二]]第二項において準用する場合を含む。）の規定による公告をせず、又は虚偽の公告をしたとき
- 二 [[laws/企業再建整備法/本文/第9条.md|第九条]]第二項、[[laws/企業再建整備法/本文/第14条.md|第十四条]]第一項、[[laws/企業再建整備法/本文/第18条.md|第十八条]]、[[laws/企業再建整備法/本文/第35条.md|第三十五条]]第三項又は[[laws/企業再建整備法/本文/第35条の4.md|第三十五条の四]]の規定に違反して書類を備へ置かず、又は正当の事由なくして書類の閲覧を拒んだとき
- 三 [[laws/企業再建整備法/本文/第9条.md|第九条]]第一項又は[[laws/企業再建整備法/本文/第35条.md|第三十五条]]第二項の規定に違反して特別管理人の承認を受けなかつたとき
- 四 この法律又はこの法律に基いて発する命令に違反して登記又は登録を怠つたとき
- 四の二 [[laws/企業再建整備法/本文/第26条の2.md|第二十六条の二]]第三項乃至第五項の規定による通知を怠り、又は虚偽の通知をしたとき
- 五 [[laws/企業再建整備法/本文/第34条.md|第三十四条]]第四項の規定に違反して株式の併合をなさないとき
- 六 [[laws/企業再建整備法/本文/第34条の2.md|第三十四条の二]]第一項（[[laws/企業再建整備法/本文/第54条の2.md|第五十四条の二]]第二項において準用する場合を含む。）の規定に違反して退職金を支給したとき
- 七 [[laws/企業再建整備法/本文/第34条の4.md|第三十四条の四]]第五項の規定に違反して積立金を使用したとき
- 八 [[laws/企業再建整備法/本文/第47条の2.md|第四十七条の二]]第一項又は[[laws/企業再建整備法/本文/第47条の3.md|第四十七条の三]]の規定による報告を怠り、又は虚偽の報告をしたとき
- 九 正当な事由がなく、[[laws/企業再建整備法/本文/第47条の2.md|第四十七条の二]]第一項又は[[laws/企業再建整備法/本文/第47条の3.md|第四十七条の三]]の規定による検査を拒み、妨げ、又は忌避したとき
- 十 [[laws/企業再建整備法/本文/第47条の2.md|第四十七条の二]]第二項の規定による報告を怠り、又は虚偽の報告をしたとき
- 十一 [[laws/企業再建整備法/本文/第49条.md|第四十九条]]第一項（[[laws/企業再建整備法/本文/第54条の2.md|第五十四条の二]]第二項において準用する場合を含む。）の規定による命令に違反したとき
- 十二 [[laws/企業再建整備法/本文/第26条.md|第二十六条]]第四項、[[laws/企業再建整備法/本文/第40条の3.md|第四十条の三]]又は[[laws/企業再建整備法/本文/第41条.md|第四十一条]]第一項（[[laws/企業再建整備法/本文/第54条の2.md|第五十四条の二]]第二項において準用する場合を含む。）の規定による報告を怠つたとき
- 十三 [[laws/企業再建整備法/本文/第42条の3.md|第四十二条の三]]第一項の規定による仮勘定監理人の選任を怠り、又は同条第二項において準用する会社経理応急措置法[[laws/企業再建整備法/本文/第17条.md|第十七条]]第五項の規定による届出を怠つたとき
