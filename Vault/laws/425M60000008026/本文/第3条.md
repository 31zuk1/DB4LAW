# 第三条 （構造）

## 
エアゾール式簡易消火具の構造は、次の各号に適合するものでなければならない。エアゾール式簡易消火具に充塡された気体（以下「充塡ガス」という。）又は消火剤の圧力により消火剤を放射するものであること。充塡ガス及び消火剤を再充塡できないものであること。充塡ガス及び消火剤を充塡する容器は、内容積一リットル以下であること。粉末又は液体の消火剤（液化二酸化炭素を除く。）の容量は、容器の内容積の九十パーセント以下であること。容器の材質は、鋼又は軽金属であること。バルブが突出しているエアゾール式簡易消火具は、当該バルブの損傷を防止するための措置が講じられたものであること。

- 一 エアゾール式簡易消火具に充塡された気体（以下「充塡ガス」という。）又は消火剤の圧力により消火剤を放射するものであること。
- 二 充塡ガス及び消火剤を再充塡できないものであること。
- 三 充塡ガス及び消火剤を充塡する容器は、内容積一リットル以下であること。
- 四 粉末又は液体の消火剤（液化二酸化炭素を除く。）の容量は、容器の内容積の九十パーセント以下であること。
- 五 容器の材質は、鋼又は軽金属であること。
- 六 バルブが突出しているエアゾール式簡易消火具は、当該バルブの損傷を防止するための措置が講じられたものであること。
