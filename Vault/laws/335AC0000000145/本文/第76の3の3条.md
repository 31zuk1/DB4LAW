# 第七十六条の三の三 （関係行政機関の連携協力）

## 
厚生労働大臣、都道府県知事、保健所を設置する市の市長又は特別区の区長は、この章の規定による権限の行使が円滑に行われるよう、情報交換を行い、相互に緊密な連携を図りながら協力しなければならない。
