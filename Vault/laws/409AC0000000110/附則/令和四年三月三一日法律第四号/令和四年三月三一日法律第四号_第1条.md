# 第一条 （施行期日）

## 
この法律は、令和四年四月一日から施行する。ただし、次の各号に掲げる規定は、当該各号に定める日から施行する。略次に掲げる規定令和五年一月一日略第十七条の規定（同条中内国税の適正な課税の確保を図るための国外送金等に係る調書の提出等に関する法律[[laws/内国税の適正な課税の確保を図るための国外送金等に係る調書の提出等に関する法律/本文/第4条.md|第四条]]第二項第二号の改正規定及び同法第六条第六項の改正規定を除く。）並びに附則第七十二条第一項及び第三項から第五項までの規定略次に掲げる規定令和六年一月一日略第十七条中内国税の適正な課税の確保を図るための国外送金等に係る調書の提出等に関する法律[[laws/内国税の適正な課税の確保を図るための国外送金等に係る調書の提出等に関する法律/本文/第6条.md|第六条]]第六項の改正規定及び附則第七十二条第二項の規定

- 一及び二 略
- 三 次に掲げる規定令和五年一月一日
- 四及び五 略
- 六 次に掲げる規定令和六年一月一日
