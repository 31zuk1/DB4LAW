# 第一条 

## 
健康保険法（大正十一年法律第七十号。以下「法」という。）[[laws/健康保険法施行令/本文/第3条.md|第三条]]第三項第一号レの政令で定める者は、次のとおりとする。公証人司法書士土地家屋調査士行政書士海事代理士税理士社会保険労務士沖縄弁護士に関する政令（昭和四十七年政令第百六十九号）[[laws/健康保険法施行令/本文/第1条.md|第一条]]に規定する沖縄弁護士外国法事務弁護士弁理士

- 一 公証人
- 二 司法書士
- 三 土地家屋調査士
- 四 行政書士
- 五 海事代理士
- 六 税理士
- 七 社会保険労務士
- 八 沖縄弁護士に関する政令（昭和四十七年政令第百六十九号）[[laws/健康保険法施行令/本文/第1条.md|第一条]]に規定する沖縄弁護士
- 九 外国法事務弁護士
- 十 弁理士
