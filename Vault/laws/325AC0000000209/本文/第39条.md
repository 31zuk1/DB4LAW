# 第三十九条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、五十万円以下の罰金に処する。[[laws/325AC0000000209/本文/第9条.md|第九条]]第一項若しくは第四項、[[laws/325AC0000000209/本文/第13条.md|第十三条]]第八項又は[[laws/325AC0000000209/本文/第22条.md|第二十二条]]の規定に違反したとき。[[laws/325AC0000000209/本文/第9条.md|第九条]]第二項に規定する事項を種付台帳に記載せず、又は虚偽の記載をしたとき。[[laws/325AC0000000209/本文/第13条.md|第十三条]]第七項の規定による届出をせず、又は虚偽の届出をしたとき。[[laws/325AC0000000209/本文/第15条.md|第十五条]]第一項に規定する事項を家畜人工授精簿に記載せず、又は虚偽の記載をしたとき。[[laws/325AC0000000209/本文/第21条.md|第二十一条]]の規定に違反して、家畜人工授精師という名称を用いたとき。[[laws/325AC0000000209/本文/第30条.md|第三十条]]の規定に違反して、その名称中に家畜人工授精所たることを示す文字を用いたとき。[[laws/325AC0000000209/本文/第32条の6.md|第三十二条の六]]の規定による命令に違反したとき。[[laws/325AC0000000209/本文/第32条の12.md|第三十二条の十二]]の規定による業務の停止の命令に違反したとき。[[laws/325AC0000000209/本文/第34条.md|第三十四条]]第一項から第四項までの規定による報告をせず、又は虚偽の報告をしたとき。[[laws/325AC0000000209/本文/第35条.md|第三十五条]]第一項又は[[laws/325AC0000000209/本文/第35条の2.md|第三十五条の二]]第一項の規定による検査を拒み、妨げ、又は忌避したとき。

- 一 [[laws/325AC0000000209/本文/第9条.md|第九条]]第一項若しくは第四項、[[laws/325AC0000000209/本文/第13条.md|第十三条]]第八項又は[[laws/325AC0000000209/本文/第22条.md|第二十二条]]の規定に違反したとき。
- 二 [[laws/325AC0000000209/本文/第9条.md|第九条]]第二項に規定する事項を種付台帳に記載せず、又は虚偽の記載をしたとき。
- 三 [[laws/325AC0000000209/本文/第13条.md|第十三条]]第七項の規定による届出をせず、又は虚偽の届出をしたとき。
- 四 [[laws/325AC0000000209/本文/第15条.md|第十五条]]第一項に規定する事項を家畜人工授精簿に記載せず、又は虚偽の記載をしたとき。
- 五 [[laws/325AC0000000209/本文/第21条.md|第二十一条]]の規定に違反して、家畜人工授精師という名称を用いたとき。
- 六 [[laws/325AC0000000209/本文/第30条.md|第三十条]]の規定に違反して、その名称中に家畜人工授精所たることを示す文字を用いたとき。
- 七 [[laws/325AC0000000209/本文/第32条の6.md|第三十二条の六]]の規定による命令に違反したとき。
- 八 [[laws/325AC0000000209/本文/第32条の12.md|第三十二条の十二]]の規定による業務の停止の命令に違反したとき。
- 九 [[laws/325AC0000000209/本文/第34条.md|第三十四条]]第一項から第四項までの規定による報告をせず、又は虚偽の報告をしたとき。
- 十 [[laws/325AC0000000209/本文/第35条.md|第三十五条]]第一項又は[[laws/325AC0000000209/本文/第35条の2.md|第三十五条の二]]第一項の規定による検査を拒み、妨げ、又は忌避したとき。
