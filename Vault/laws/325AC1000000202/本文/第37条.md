# 第三十七条 

## 
次の各号のいずれかに該当するときは、その違反行為をした者は、一年以下の拘禁刑又は百万円以下の罰金に処する。一級建築士、二級建築士又は木造建築士の免許を受けないで、それぞれその業務を行う目的で一級建築士、二級建築士又は木造建築士の名称を用いたとき。虚偽又は不正の事実に基づいて一級建築士、二級建築士又は木造建築士の免許を受けたとき。[[laws/325AC1000000202/本文/第3条.md|第三条]]第一項（同条第二項の規定により適用される場合を含む。）、[[laws/325AC1000000202/本文/第3条の2.md|第三条の二]]第一項（同条第二項において準用する[[laws/325AC1000000202/本文/第3条.md|第三条]]第二項の規定により適用される場合を含む。）若しくは[[laws/325AC1000000202/本文/第3条の3.md|第三条の三]]第一項（同条第二項において準用する[[laws/325AC1000000202/本文/第3条.md|第三条]]第二項の規定により適用される場合を含む。）の規定又は[[laws/325AC1000000202/本文/第3条の2.md|第三条の二]]第三項（[[laws/325AC1000000202/本文/第3条の3.md|第三条の三]]第二項において読み替えて準用する場合を含む。）の規定に基づく条例の規定に違反して、建築物の設計又は工事監理をしたとき。[[laws/325AC1000000202/本文/第10条.md|第十条]]第一項の規定による業務停止命令に違反したとき。[[laws/325AC1000000202/本文/第10条の36.md|第十条の三十六]]第二項（[[laws/325AC1000000202/本文/第22条の3.md|第二十二条の三]]第二項及び[[laws/325AC1000000202/本文/第26条の5.md|第二十六条の五]]第二項において準用する場合を含む。）の規定による講習事務（[[laws/325AC1000000202/本文/第10条の22.md|第十条の二十二]]に規定する講習事務、[[laws/325AC1000000202/本文/第22条の3.md|第二十二条の三]]第二項において読み替えて準用する[[laws/325AC1000000202/本文/第10条の23.md|第十条の二十三]]第五号に規定する講習事務及び[[laws/325AC1000000202/本文/第26条の5.md|第二十六条の五]]第二項において読み替えて準用する[[laws/325AC1000000202/本文/第10条の23.md|第十条の二十三]]第五号に規定する講習事務をいう。[[laws/325AC1000000202/本文/第40条.md|第四十条]]第八号において同じ。）の停止の命令に違反したとき。[[laws/325AC1000000202/本文/第20条.md|第二十条]]第二項の規定に違反して、構造計算によつて建築物の安全性を確かめた場合でないのに、同項の証明書を交付したとき。[[laws/325AC1000000202/本文/第21条の2.md|第二十一条の二]]の規定に違反したとき。虚偽又は不正の事実に基づいて[[laws/325AC1000000202/本文/第23条の3.md|第二十三条の三]]第一項の規定による登録を受けたとき。[[laws/325AC1000000202/本文/第23条の10.md|第二十三条の十]]第一項又は第二項の規定に違反したとき。[[laws/325AC1000000202/本文/第24条.md|第二十四条]]第一項の規定に違反したとき。[[laws/325AC1000000202/本文/第24条の2.md|第二十四条の二]]の規定に違反して、他人に建築士事務所の業務を営ませたとき。[[laws/325AC1000000202/本文/第26条.md|第二十六条]]第二項の規定による建築士事務所の閉鎖命令に違反したとき。[[laws/325AC1000000202/本文/第32条.md|第三十二条]]の規定に違反して、事前に試験問題を漏らし、又は不正の採点をしたとき。

- 一 一級建築士、二級建築士又は木造建築士の免許を受けないで、それぞれその業務を行う目的で一級建築士、二級建築士又は木造建築士の名称を用いたとき。
- 二 虚偽又は不正の事実に基づいて一級建築士、二級建築士又は木造建築士の免許を受けたとき。
- 三 [[laws/325AC1000000202/本文/第3条.md|第三条]]第一項（同条第二項の規定により適用される場合を含む。）、[[laws/325AC1000000202/本文/第3条の2.md|第三条の二]]第一項（同条第二項において準用する[[laws/325AC1000000202/本文/第3条.md|第三条]]第二項の規定により適用される場合を含む。）若しくは[[laws/325AC1000000202/本文/第3条の3.md|第三条の三]]第一項（同条第二項において準用する[[laws/325AC1000000202/本文/第3条.md|第三条]]第二項の規定により適用される場合を含む。）の規定又は[[laws/325AC1000000202/本文/第3条の2.md|第三条の二]]第三項（[[laws/325AC1000000202/本文/第3条の3.md|第三条の三]]第二項において読み替えて準用する場合を含む。）の規定に基づく条例の規定に違反して、建築物の設計又は工事監理をしたとき。
- 四 [[laws/325AC1000000202/本文/第10条.md|第十条]]第一項の規定による業務停止命令に違反したとき。
- 五 [[laws/325AC1000000202/本文/第10条の36.md|第十条の三十六]]第二項（[[laws/325AC1000000202/本文/第22条の3.md|第二十二条の三]]第二項及び[[laws/325AC1000000202/本文/第26条の5.md|第二十六条の五]]第二項において準用する場合を含む。）の規定による講習事務（[[laws/325AC1000000202/本文/第10条の22.md|第十条の二十二]]に規定する講習事務、[[laws/325AC1000000202/本文/第22条の3.md|第二十二条の三]]第二項において読み替えて準用する[[laws/325AC1000000202/本文/第10条の23.md|第十条の二十三]]第五号に規定する講習事務及び[[laws/325AC1000000202/本文/第26条の5.md|第二十六条の五]]第二項において読み替えて準用する[[laws/325AC1000000202/本文/第10条の23.md|第十条の二十三]]第五号に規定する講習事務をいう。[[laws/325AC1000000202/本文/第40条.md|第四十条]]第八号において同じ。）の停止の命令に違反したとき。
- 六 [[laws/325AC1000000202/本文/第20条.md|第二十条]]第二項の規定に違反して、構造計算によつて建築物の安全性を確かめた場合でないのに、同項の証明書を交付したとき。
- 七 [[laws/325AC1000000202/本文/第21条の2.md|第二十一条の二]]の規定に違反したとき。
- 八 虚偽又は不正の事実に基づいて[[laws/325AC1000000202/本文/第23条の3.md|第二十三条の三]]第一項の規定による登録を受けたとき。
- 九 [[laws/325AC1000000202/本文/第23条の10.md|第二十三条の十]]第一項又は第二項の規定に違反したとき。
- 十 [[laws/325AC1000000202/本文/第24条.md|第二十四条]]第一項の規定に違反したとき。
- 十一 [[laws/325AC1000000202/本文/第24条の2.md|第二十四条の二]]の規定に違反して、他人に建築士事務所の業務を営ませたとき。
- 十二 [[laws/325AC1000000202/本文/第26条.md|第二十六条]]第二項の規定による建築士事務所の閉鎖命令に違反したとき。
- 十三 [[laws/325AC1000000202/本文/第32条.md|第三十二条]]の規定に違反して、事前に試験問題を漏らし、又は不正の採点をしたとき。
