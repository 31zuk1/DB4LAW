# 第三条の三 

## 
特例期間及び主務大臣が必要と認める期間においては、厚生年金保険経理（指定都市職員共済組合等にあつては、厚生年金保険預託金管理経理）の余裕金を他の経理単位に貸し付ける場合の利率については、[[laws/地方公務員等共済組合法施行規程/本文/第13条.md|第十三条]]第一項後段の規定にかかわらず、法に基づく厚生年金保険給付事業の財政の安定に配慮して主務大臣が総務大臣と協議して定める利率によることができる。
