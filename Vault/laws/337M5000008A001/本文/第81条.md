# 第八十一条 （貸倒引当金）

## 
福祉経理（貯金経理及び指定経理のうち主務大臣が定めるものを除く。）においては、毎事業年度末日において、貸付金（貸倒金の補てんを目的とする損害保険に付されているものを除く。）、売掛金その他事業に係る未収金の総額の百分の二に相当する金額に達するまでの金額を貸倒引当金として計上しなければならない。
