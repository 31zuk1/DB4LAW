# 第二条の三 （ロタウイルス感染症の予防接種の対象者）

## 
令[[laws/323M40000100036/本文/第3条.md|第三条]]第一項の表ロタウイルス感染症の項に規定する厚生労働省令で定めるワクチンは、次の表の上欄に掲げるワクチンとし、同項の厚生労働省令で定める日は、同欄に掲げるワクチンごとに、それぞれ同表の下欄に掲げる日とする。ワクチン日経口弱毒生ヒトロタウイルスワクチン生後二十四週に至る日の翌日五価経口弱毒生ロタウイルスワクチン生後三十二週に至る日の翌日
