# 第八十一条 （フロン類破壊業者の破壊証明書の写しの保存期間）

## 
[[laws/フロン類の使用の合理化及び管理の適正化に関する法律施行規則/本文/第66条.md|第六十六条]]の規定は、法[[laws/フロン類の使用の合理化及び管理の適正化に関する法律施行規則/本文/第70条.md|第七十条]]第一項の主務省令で定める期間について準用する。
