# 第一条 （売渡申出書の記載事項）

## 
文化財保護法（昭和二十五年法律第二百十四号。以下「法」という。）[[laws/326R00000011003/国宝、重要文化財又は重要有形民俗文化財売_law.md|第四十六条]]第一項（法[[laws/326R00000011003/国宝、重要文化財又は重要有形民俗文化財売_law.md|第八十三条]]において準用する場合を含む。）の規定による国宝、重要文化財又は重要有形民俗文化財の国に対する売渡しの申出書には、次に掲げる事項を記載するものとする。国宝、重要文化財又は重要有形民俗文化財の名称及び員数指定年月日及び指定書の記号番号又は番号国宝、重要文化財又は重要有形民俗文化財の所在の場所所有者の氏名又は名称及び住所管理責任者を定めてある場合は、その氏名又は名称及び住所譲渡の相手方の氏名又は名称及び住所予定対価の額（予定対価が金銭以外のものであるときは、これを時価を基準とした金銭に見積つた額）その他参考となるべき事項

- 一 国宝、重要文化財又は重要有形民俗文化財の名称及び員数
- 二 指定年月日及び指定書の記号番号又は番号
- 三 国宝、重要文化財又は重要有形民俗文化財の所在の場所
- 四 所有者の氏名又は名称及び住所
- 五 管理責任者を定めてある場合は、その氏名又は名称及び住所
- 六 譲渡の相手方の氏名又は名称及び住所
- 七 予定対価の額（予定対価が金銭以外のものであるときは、これを時価を基準とした金銭に見積つた額）
- 八 その他参考となるべき事項
