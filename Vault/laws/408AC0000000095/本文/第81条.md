# 第八十一条 （更生債権等の届出）

## 
会社更生法第百三十八条及び[[laws/414AC0000000154/本文/第139条.md|第百三十九条]]の規定は、協同組織金融機関の更生手続における更生債権等の届出について準用する。この場合において、同法第百三十八条第一項中「[[laws/414AC0000000154/本文/第42条.md|第四十二条]]第一項」とあるのは、「更生特例法[[laws/414AC0000000154/本文/第31条.md|第三十一条]]において準用する[[laws/414AC0000000154/本文/第42条.md|第四十二条]]第一項」と読み替えるものとする。
