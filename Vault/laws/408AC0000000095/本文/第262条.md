# 第二百六十二条 （剰余金の分配等）

## 
次に掲げる行為に関する条項においては、更生手続が行われていない場合に当該行為を行うとすれば社員総会（総代会を設けているときは、総代会）の決議その他の相互会社の機関の決定が必要となる事項を定めなければならない。剰余金の分配基金償却積立金の取崩し定款の変更事業譲渡等保険契約の移転をし、又は保険契約の移転を受けること。業務及び財産の管理の委託

- 一 剰余金の分配
- 二 基金償却積立金の取崩し
- 三 定款の変更
- 四 事業譲渡等
- 五 保険契約の移転をし、又は保険契約の移転を受けること。
- 六 業務及び財産の管理の委託
