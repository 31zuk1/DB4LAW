# 第三十二条 （登録の取消し等）

## 
経済産業大臣及び環境大臣は、登録講習機関が次の各号のいずれかに該当するときは、その登録を取り消し、又は期間を定めて講習の業務の全部若しくは一部の停止を命ずることができる。[[laws/346M50010D40003/本文/第20条.md|第二十条]]第一号又は第三号に該当するに至つたとき。[[laws/346M50010D40003/本文/第24条.md|第二十四条]]、[[laws/346M50010D40003/本文/第25条.md|第二十五条]]第一項、[[laws/346M50010D40003/本文/第26条.md|第二十六条]]、[[laws/346M50010D40003/本文/第27条.md|第二十七条]]第一項及び[[laws/346M50010D40003/本文/第28条.md|第二十八条]]の規定に違反して届出をせず、又は虚偽の届出をしたとき。[[laws/346M50010D40003/本文/第29条.md|第二十九条]]第一項又は次条の規定に違反したとき。正当な理由がないのに[[laws/346M50010D40003/本文/第29条.md|第二十九条]]第二項各号の規定による請求を拒んだとき。前二条の規定による勧告に従わなかつたとき。不正の手段により登録を受けたとき。

- 一 [[laws/346M50010D40003/本文/第20条.md|第二十条]]第一号又は第三号に該当するに至つたとき。
- 二 [[laws/346M50010D40003/本文/第24条.md|第二十四条]]、[[laws/346M50010D40003/本文/第25条.md|第二十五条]]第一項、[[laws/346M50010D40003/本文/第26条.md|第二十六条]]、[[laws/346M50010D40003/本文/第27条.md|第二十七条]]第一項及び[[laws/346M50010D40003/本文/第28条.md|第二十八条]]の規定に違反して届出をせず、又は虚偽の届出をしたとき。
- 三 [[laws/346M50010D40003/本文/第29条.md|第二十九条]]第一項又は次条の規定に違反したとき。
- 四 正当な理由がないのに[[laws/346M50010D40003/本文/第29条.md|第二十九条]]第二項各号の規定による請求を拒んだとき。
- 五 前二条の規定による勧告に従わなかつたとき。
- 六 不正の手段により登録を受けたとき。
