# 第三十五条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、百万円以下の罰金に処する。[[laws/債権管理回収業に関する特別措置法/本文/第7条.md|第七条]]第一項の規定に違反して、届出をせず、又は虚偽の届出をしたとき。[[laws/債権管理回収業に関する特別措置法/本文/第13条.md|第十三条]]第二項の規定に違反したとき。[[laws/債権管理回収業に関する特別措置法/本文/第15条.md|第十五条]]第一項の規定に違反して書面を交付せず、又は同項に規定する事項を記載しない書面若しくは虚偽の記載をした書面を交付したとき。[[laws/債権管理回収業に関する特別措置法/本文/第16条.md|第十六条]]の規定に違反して、証書を返還しなかったとき。[[laws/債権管理回収業に関する特別措置法/本文/第17条.md|第十七条]]第二項の規定に違反したとき。[[laws/債権管理回収業に関する特別措置法/本文/第18条.md|第十八条]]第一項の規定に違反したとき。[[laws/債権管理回収業に関する特別措置法/本文/第18条.md|第十八条]]第二項の規定に違反して、著しく事実に相違する表示をし、又は著しく人を誤認させるような表示をしたとき。[[laws/債権管理回収業に関する特別措置法/本文/第18条.md|第十八条]]第三項の規定に違反して、同項に規定する事項の記載又は記録をしていない委任状を取得したとき。[[laws/債権管理回収業に関する特別措置法/本文/第23条.md|第二十三条]]の規定による命令に違反したとき。

- 一 [[laws/債権管理回収業に関する特別措置法/本文/第7条.md|第七条]]第一項の規定に違反して、届出をせず、又は虚偽の届出をしたとき。
- 二 [[laws/債権管理回収業に関する特別措置法/本文/第13条.md|第十三条]]第二項の規定に違反したとき。
- 三 [[laws/債権管理回収業に関する特別措置法/本文/第15条.md|第十五条]]第一項の規定に違反して書面を交付せず、又は同項に規定する事項を記載しない書面若しくは虚偽の記載をした書面を交付したとき。
- 四 [[laws/債権管理回収業に関する特別措置法/本文/第16条.md|第十六条]]の規定に違反して、証書を返還しなかったとき。
- 五 [[laws/債権管理回収業に関する特別措置法/本文/第17条.md|第十七条]]第二項の規定に違反したとき。
- 六 [[laws/債権管理回収業に関する特別措置法/本文/第18条.md|第十八条]]第一項の規定に違反したとき。
- 七 [[laws/債権管理回収業に関する特別措置法/本文/第18条.md|第十八条]]第二項の規定に違反して、著しく事実に相違する表示をし、又は著しく人を誤認させるような表示をしたとき。
- 八 [[laws/債権管理回収業に関する特別措置法/本文/第18条.md|第十八条]]第三項の規定に違反して、同項に規定する事項の記載又は記録をしていない委任状を取得したとき。
- 九 [[laws/債権管理回収業に関する特別措置法/本文/第23条.md|第二十三条]]の規定による命令に違反したとき。
