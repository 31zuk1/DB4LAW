# 第四十四条 （許可の取消等）

## 
経済産業大臣は、製造業者又は販売業者が、左の各号の一に該当するときは、[[laws/325AC0000000149/本文/第3条.md|第三条]]若しくは[[laws/325AC0000000149/本文/第5条.md|第五条]]の許可を取り消し、又は期間を定めてその事業の停止を命ずることができる。[[laws/325AC0000000149/本文/第9条.md|第九条]]第一項若しくは第二項、[[laws/325AC0000000149/本文/第11条.md|第十一条]]第二項、[[laws/325AC0000000149/本文/第14条.md|第十四条]]第一項又は[[laws/325AC0000000149/本文/第27条の2.md|第二十七条の二]]の規定に違反し、災害を発生させ、又は公共の安全を害したとき。[[laws/325AC0000000149/本文/第11条.md|第十一条]]第一項、[[laws/325AC0000000149/本文/第13条.md|第十三条]]、[[laws/325AC0000000149/本文/第18条.md|第十八条]]、[[laws/325AC0000000149/本文/第19条.md|第十九条]]第一項、[[laws/325AC0000000149/本文/第23条.md|第二十三条]]第二項、[[laws/325AC0000000149/本文/第29条.md|第二十九条]]第三項、[[laws/325AC0000000149/本文/第30条.md|第三十条]]第一項若しくは第二項、[[laws/325AC0000000149/本文/第35条の2.md|第三十五条の二]]第一項又は[[laws/325AC0000000149/本文/第38条.md|第三十八条]]の規定に違反したとき。[[laws/325AC0000000149/本文/第10条.md|第十条]]第一項、[[laws/325AC0000000149/本文/第12条.md|第十二条]]第一項、[[laws/325AC0000000149/本文/第24条.md|第二十四条]]第一項又は[[laws/325AC0000000149/本文/第27条.md|第二十七条]]第一項の規定により許可を受けなければならない事項を許可を受けないでしたとき。[[laws/325AC0000000149/本文/第15条.md|第十五条]]の規定による完成検査を受けないで、火薬類の製造施設又は火薬庫を使用したとき。[[laws/325AC0000000149/本文/第36条.md|第三十六条]]第一項の規定による安定度試験を実施しなかつたとき。[[laws/325AC0000000149/本文/第9条.md|第九条]]第三項、[[laws/325AC0000000149/本文/第11条.md|第十一条]]第三項、[[laws/325AC0000000149/本文/第14条.md|第十四条]]第二項、[[laws/325AC0000000149/本文/第28条.md|第二十八条]]第四項、[[laws/325AC0000000149/本文/第34条.md|第三十四条]]、[[laws/325AC0000000149/本文/第36条.md|第三十六条]]第二項若しくは次条第一号の命令又は同条第二号の禁止若しくは制限に違反したとき。[[laws/325AC0000000149/本文/第6条.md|第六条]]第二号から第四号までの規定に該当するに至つたとき。[[laws/325AC0000000149/本文/第48条.md|第四十八条]]第一項の条件に違反したとき。

- 一 [[laws/325AC0000000149/本文/第9条.md|第九条]]第一項若しくは第二項、[[laws/325AC0000000149/本文/第11条.md|第十一条]]第二項、[[laws/325AC0000000149/本文/第14条.md|第十四条]]第一項又は[[laws/325AC0000000149/本文/第27条の2.md|第二十七条の二]]の規定に違反し、災害を発生させ、又は公共の安全を害したとき。
- 二 [[laws/325AC0000000149/本文/第11条.md|第十一条]]第一項、[[laws/325AC0000000149/本文/第13条.md|第十三条]]、[[laws/325AC0000000149/本文/第18条.md|第十八条]]、[[laws/325AC0000000149/本文/第19条.md|第十九条]]第一項、[[laws/325AC0000000149/本文/第23条.md|第二十三条]]第二項、[[laws/325AC0000000149/本文/第29条.md|第二十九条]]第三項、[[laws/325AC0000000149/本文/第30条.md|第三十条]]第一項若しくは第二項、[[laws/325AC0000000149/本文/第35条の2.md|第三十五条の二]]第一項又は[[laws/325AC0000000149/本文/第38条.md|第三十八条]]の規定に違反したとき。
- 三 [[laws/325AC0000000149/本文/第10条.md|第十条]]第一項、[[laws/325AC0000000149/本文/第12条.md|第十二条]]第一項、[[laws/325AC0000000149/本文/第24条.md|第二十四条]]第一項又は[[laws/325AC0000000149/本文/第27条.md|第二十七条]]第一項の規定により許可を受けなければならない事項を許可を受けないでしたとき。
- 四 [[laws/325AC0000000149/本文/第15条.md|第十五条]]の規定による完成検査を受けないで、火薬類の製造施設又は火薬庫を使用したとき。
- 五 [[laws/325AC0000000149/本文/第36条.md|第三十六条]]第一項の規定による安定度試験を実施しなかつたとき。
- 六 [[laws/325AC0000000149/本文/第9条.md|第九条]]第三項、[[laws/325AC0000000149/本文/第11条.md|第十一条]]第三項、[[laws/325AC0000000149/本文/第14条.md|第十四条]]第二項、[[laws/325AC0000000149/本文/第28条.md|第二十八条]]第四項、[[laws/325AC0000000149/本文/第34条.md|第三十四条]]、[[laws/325AC0000000149/本文/第36条.md|第三十六条]]第二項若しくは次条第一号の命令又は同条第二号の禁止若しくは制限に違反したとき。
- 七 [[laws/325AC0000000149/本文/第6条.md|第六条]]第二号から第四号までの規定に該当するに至つたとき。
- 八 [[laws/325AC0000000149/本文/第48条.md|第四十八条]]第一項の条件に違反したとき。
