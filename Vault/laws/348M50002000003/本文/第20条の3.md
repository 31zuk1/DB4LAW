# 第二十条の三 （指定登録機関が登録事務を行う場合における規定の適用）

## 
法[[laws/348M50002000003/労働安全コンサルタント及び労働衛生コンサ_law.md|第八十五条の二]]第一項に規定する指定登録機関（以下「指定登録機関」という。）が同条第一項に規定する登録事務（以下「登録事務」という。）を行う場合における[[laws/348M50002000003/本文/第17条.md|第十七条]]、[[laws/348M50002000003/本文/第18条.md|第十八条]]、[[laws/348M50002000003/本文/第18条の2.md|第十八条の二]]、[[laws/348M50002000003/本文/第18条の3.md|第十八条の三]]、[[laws/348M50002000003/本文/第19条.md|第十九条]]及び前条の規定の適用については、[[laws/348M50002000003/本文/第17条.md|第十七条]]、[[laws/348M50002000003/本文/第18条.md|第十八条]]、[[laws/348M50002000003/本文/第18条の2.md|第十八条の二]]及び前条中「厚生労働大臣」とあるのは「指定登録機関」と、[[laws/348M50002000003/本文/第17条.md|第十七条]]第三項中「当該申請者に通知するものとする。」とあるのは「当該申請者に通知するものとする。この場合において、指定登録機関は、遅滞なく、厚生労働大臣にその旨を報告しなければならない。」と、[[laws/348M50002000003/本文/第18条の3.md|第十八条の三]]第一項中「登録事項変更等申請書又は登録証再交付申請書に二千二百円に相当する額の収入印紙をはつて」とあるのは「法[[laws/348M50002000003/労働安全コンサルタント及び労働衛生コンサ_law.md|第八十五条の三]]において読み替えて準用する法[[laws/348M50002000003/労働安全コンサルタント及び労働衛生コンサ_law.md|第七十五条の六]]第一項に規定する規程で定めるところにより」と、[[laws/348M50002000003/本文/第19条.md|第十九条]]第二項中「厚生労働大臣」とあるのは「業務を廃止し、又は死亡したときにあつては指定登録機関に、同項第二号又は第三号に該当するに至つたときにあつては厚生労働大臣」とする。
