# 第八条 （試験科目）

## 
理学療法士国家試験の科目は、次のとおりとする。解剖学生理学運動学病理学概論臨床心理学リハビリテーション医学（リハビリテーション概論を含む。）臨床医学大要（人間発達学を含む。）理学療法

- 一 解剖学
- 二 生理学
- 三 運動学
- 四 病理学概論
- 五 臨床心理学
- 六 リハビリテーション医学（リハビリテーション概論を含む。）
- 七 臨床医学大要（人間発達学を含む。）
- 八 理学療法
## ２
作業療法士国家試験の科目は、次のとおりとする。解剖学生理学運動学病理学概論臨床心理学リハビリテーション医学（リハビリテーション概論を含む。）臨床医学大要（人間発達学を含む。）作業療法

- 一 解剖学
- 二 生理学
- 三 運動学
- 四 病理学概論
- 五 臨床心理学
- 六 リハビリテーション医学（リハビリテーション概論を含む。）
- 七 臨床医学大要（人間発達学を含む。）
- 八 作業療法
