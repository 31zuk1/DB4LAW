# 第三条 （業務の特例に係る業務方法書の記載事項）

## 
預金保険機構（以下「機構」という。）が法[[laws/特定住宅金融専門会社の債権債務の処理の促進等に関する特別措置法施行規則/本文/第3条.md|第三条]]に規定する業務を行う場合には、預金保険法[[laws/特定住宅金融専門会社の債権債務の処理の促進等に関する特別措置法施行規則/本文/第36条.md|第三十六条]]第二項に規定する内閣府令・財務省令で定める事項は、預金保険法施行規則（昭和四十六年大蔵省令第二十八号）[[laws/特定住宅金融専門会社の債権債務の処理の促進等に関する特別措置法施行規則/本文/第1条の2.md|第一条の二]]各号に掲げる事項のほか、次に掲げる事項とする。債権処理会社への出資に関する事項債権処理会社に対する助成金の交付に関する事項債権処理会社の借入れに係る債務の保証に関する事項法[[laws/特定住宅金融専門会社の債権債務の処理の促進等に関する特別措置法施行規則/本文/第3条.md|第三条]]第一項第六号に規定する財産の調査に関する事項法[[laws/特定住宅金融専門会社の債権債務の処理の促進等に関する特別措置法施行規則/本文/第3条.md|第三条]]第一項第七号に規定する債権の取立てに関する事項その他法[[laws/特定住宅金融専門会社の債権債務の処理の促進等に関する特別措置法施行規則/本文/第3条.md|第三条]]第一項に規定する業務の方法

- 一 債権処理会社への出資に関する事項
- 二 債権処理会社に対する助成金の交付に関する事項
- 三 債権処理会社の借入れに係る債務の保証に関する事項
- 四 法[[laws/特定住宅金融専門会社の債権債務の処理の促進等に関する特別措置法施行規則/本文/第3条.md|第三条]]第一項第六号に規定する財産の調査に関する事項
- 五 法[[laws/特定住宅金融専門会社の債権債務の処理の促進等に関する特別措置法施行規則/本文/第3条.md|第三条]]第一項第七号に規定する債権の取立てに関する事項
- 六 その他法[[laws/特定住宅金融専門会社の債権債務の処理の促進等に関する特別措置法施行規則/本文/第3条.md|第三条]]第一項に規定する業務の方法
