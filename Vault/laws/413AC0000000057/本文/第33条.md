# 第三十三条 

## 
次の各号のいずれかに該当する者は、二十万円以下の罰金に処する。[[laws/自動車運転代行業の業務の適正化に関する法律/本文/第5条.md|第五条]]第一項の申請書又は添付書類に虚偽の記載をして提出した者[[laws/自動車運転代行業の業務の適正化に関する法律/本文/第6条.md|第六条]]の規定に違反した者[[laws/自動車運転代行業の業務の適正化に関する法律/本文/第8条.md|第八条]]第一項の規定に違反して届出書の提出をせず、又は同項の届出書若しくは添付書類に虚偽の記載をして提出した者[[laws/自動車運転代行業の業務の適正化に関する法律/本文/第9条.md|第九条]]第一項の規定に違反して届出書の提出をせず、又は同項の届出書に虚偽の記載をして提出した者[[laws/自動車運転代行業の業務の適正化に関する法律/本文/第11条.md|第十一条]]の規定に違反した者[[laws/自動車運転代行業の業務の適正化に関する法律/本文/第13条.md|第十三条]]第一項又は第五項の規定に違反した者[[laws/自動車運転代行業の業務の適正化に関する法律/本文/第13条.md|第十三条]]第三項の規定による届出をしないで自動車運転代行業約款を掲示した者[[laws/自動車運転代行業の業務の適正化に関する法律/本文/第16条.md|第十六条]]の規定に違反した者[[laws/自動車運転代行業の業務の適正化に関する法律/本文/第17条.md|第十七条]]第一項又は第二項の規定に違反した者[[laws/自動車運転代行業の業務の適正化に関する法律/本文/第20条.md|第二十条]]第一項若しくは第二項の帳簿若しくは書類を備え付けず、又はこれらに必要な事項を記載せず、若しくは虚偽の記載をした者[[laws/自動車運転代行業の業務の適正化に関する法律/本文/第21条.md|第二十一条]]第一項若しくは第二項の規定に違反して報告をせず、若しくは資料の提出をせず、若しくは同条第一項若しくは第二項の規定による報告若しくは資料の提出について虚偽の報告をし、若しくは虚偽の資料を提出した者又は同条第一項若しくは第二項の規定による立入検査を拒み、妨げ、若しくは忌避した者

- 一 [[laws/自動車運転代行業の業務の適正化に関する法律/本文/第5条.md|第五条]]第一項の申請書又は添付書類に虚偽の記載をして提出した者
- 二 [[laws/自動車運転代行業の業務の適正化に関する法律/本文/第6条.md|第六条]]の規定に違反した者
- 三 [[laws/自動車運転代行業の業務の適正化に関する法律/本文/第8条.md|第八条]]第一項の規定に違反して届出書の提出をせず、又は同項の届出書若しくは添付書類に虚偽の記載をして提出した者
- 四 [[laws/自動車運転代行業の業務の適正化に関する法律/本文/第9条.md|第九条]]第一項の規定に違反して届出書の提出をせず、又は同項の届出書に虚偽の記載をして提出した者
- 五 [[laws/自動車運転代行業の業務の適正化に関する法律/本文/第11条.md|第十一条]]の規定に違反した者
- 六 [[laws/自動車運転代行業の業務の適正化に関する法律/本文/第13条.md|第十三条]]第一項又は第五項の規定に違反した者
- 七 [[laws/自動車運転代行業の業務の適正化に関する法律/本文/第13条.md|第十三条]]第三項の規定による届出をしないで自動車運転代行業約款を掲示した者
- 八 [[laws/自動車運転代行業の業務の適正化に関する法律/本文/第16条.md|第十六条]]の規定に違反した者
- 九 [[laws/自動車運転代行業の業務の適正化に関する法律/本文/第17条.md|第十七条]]第一項又は第二項の規定に違反した者
- 十 [[laws/自動車運転代行業の業務の適正化に関する法律/本文/第20条.md|第二十条]]第一項若しくは第二項の帳簿若しくは書類を備え付けず、又はこれらに必要な事項を記載せず、若しくは虚偽の記載をした者
- 十一 [[laws/自動車運転代行業の業務の適正化に関する法律/本文/第21条.md|第二十一条]]第一項若しくは第二項の規定に違反して報告をせず、若しくは資料の提出をせず、若しくは同条第一項若しくは第二項の規定による報告若しくは資料の提出について虚偽の報告をし、若しくは虚偽の資料を提出した者又は同条第一項若しくは第二項の規定による立入検査を拒み、妨げ、若しくは忌避した者
