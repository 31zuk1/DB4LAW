# 第二十八条 （書類及び帳簿の備付け）

## 
受託者は、信託事務を行う事務所に、次に掲げる書類及び帳簿を備えなければならない。信託行為及びこれに附属する書類委託者又はその相続人、受託者及び信託管理人の履歴書（これらの者が法人である場合にあっては、定款又は寄附行為）並びに運営委員会等の構成員の名簿及び履歴書許可、届出等に関する書類収入及び支出に関する帳簿及び証拠書類資産及び負債の状況を示す書類運営委員会等の議事に関する書類

- 一 信託行為及びこれに附属する書類
- 二 委託者又はその相続人、受託者及び信託管理人の履歴書（これらの者が法人である場合にあっては、定款又は寄附行為）並びに運営委員会等の構成員の名簿及び履歴書
- 三 許可、届出等に関する書類
- 四 収入及び支出に関する帳簿及び証拠書類
- 五 資産及び負債の状況を示す書類
- 六 運営委員会等の議事に関する書類
