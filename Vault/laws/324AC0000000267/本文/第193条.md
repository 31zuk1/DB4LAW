# 第百九十三条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、六月以下の拘禁刑又は三十万円以下の罰金に処する。[[laws/漁業法/本文/第26条.md|第二十六条]]第一項又は[[laws/漁業法/本文/第30条.md|第三十条]]第一項の規定による報告をせず、又は虚偽の報告をしたとき。[[laws/漁業法/本文/第52条.md|第五十二条]]第二項（[[laws/漁業法/本文/第58条.md|第五十八条]]において準用する場合を含む。）の規定による命令に違反したとき。[[laws/漁業法/本文/第52条.md|第五十二条]]第三項（[[laws/漁業法/本文/第58条.md|第五十八条]]において準用する場合を含む。）の規定に違反したとき。知事許可漁業の許可に付けた条件に違反して漁業を営んだとき。[[laws/漁業法/本文/第82条.md|第八十二条]]の規定に違反して漁業権を貸付けの目的としたとき。[[laws/漁業法/本文/第128条.md|第百二十八条]]第三項の規定による漁業監督官又は漁業監督吏員の検査を拒み、妨げ、若しくは忌避し、又はその質問に対し答弁をせず、若しくは虚偽の陳述をしたとき。[[laws/漁業法/本文/第165条.md|第百六十五条]]第四項の規定に違反したとき。[[laws/漁業法/本文/第176条.md|第百七十六条]]第一項の規定による報告を怠り、若しくは虚偽の報告をし、又は当該職員の検査を拒み、妨げ、若しくは忌避したとき。[[laws/漁業法/本文/第176条.md|第百七十六条]]第二項の規定による当該職員の測量、検査、移転又は除去を拒み、妨げ、又は忌避したとき。

- 一 [[laws/漁業法/本文/第26条.md|第二十六条]]第一項又は[[laws/漁業法/本文/第30条.md|第三十条]]第一項の規定による報告をせず、又は虚偽の報告をしたとき。
- 二 [[laws/漁業法/本文/第52条.md|第五十二条]]第二項（[[laws/漁業法/本文/第58条.md|第五十八条]]において準用する場合を含む。）の規定による命令に違反したとき。
- 三 [[laws/漁業法/本文/第52条.md|第五十二条]]第三項（[[laws/漁業法/本文/第58条.md|第五十八条]]において準用する場合を含む。）の規定に違反したとき。
- 四 知事許可漁業の許可に付けた条件に違反して漁業を営んだとき。
- 五 [[laws/漁業法/本文/第82条.md|第八十二条]]の規定に違反して漁業権を貸付けの目的としたとき。
- 六 [[laws/漁業法/本文/第128条.md|第百二十八条]]第三項の規定による漁業監督官又は漁業監督吏員の検査を拒み、妨げ、若しくは忌避し、又はその質問に対し答弁をせず、若しくは虚偽の陳述をしたとき。
- 七 [[laws/漁業法/本文/第165条.md|第百六十五条]]第四項の規定に違反したとき。
- 八 [[laws/漁業法/本文/第176条.md|第百七十六条]]第一項の規定による報告を怠り、若しくは虚偽の報告をし、又は当該職員の検査を拒み、妨げ、若しくは忌避したとき。
- 九 [[laws/漁業法/本文/第176条.md|第百七十六条]]第二項の規定による当該職員の測量、検査、移転又は除去を拒み、妨げ、又は忌避したとき。
