# 第百九十条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、三年以下の拘禁刑又は三百万円以下の罰金に処する。[[laws/漁業法/本文/第25条.md|第二十五条]]の規定に違反して特定水産資源を採捕したとき。[[laws/漁業法/本文/第27条.md|第二十七条]]、[[laws/漁業法/本文/第33条.md|第三十三条]]、[[laws/漁業法/本文/第34条.md|第三十四条]]又は[[laws/漁業法/本文/第131条.md|第百三十一条]]第一項の規定による命令に違反したとき。[[laws/漁業法/本文/第36条.md|第三十六条]]第一項又は[[laws/漁業法/本文/第57条.md|第五十七条]]第一項の規定に違反して大臣許可漁業又は知事許可漁業を営んだとき。[[laws/漁業法/本文/第47条.md|第四十七条]]（[[laws/漁業法/本文/第58条.md|第五十八条]]において準用する場合を含む。）の許可を受けずに、[[laws/漁業法/本文/第42条.md|第四十二条]]第一項（[[laws/漁業法/本文/第58条.md|第五十八条]]において読み替えて準用する場合を含む。以下この号において同じ。）の農林水産省令又は規則で定める事項について、同項の規定により定められた制限措置と異なる内容により、大臣許可漁業又は知事許可漁業を営んだとき。大臣許可漁業の許可、漁業権又は[[laws/漁業法/本文/第88条.md|第八十八条]]第一項（同条第五項において準用する場合を含む。）の規定による漁業の許可に付けた条件に違反して漁業を営んだとき。大臣許可漁業、知事許可漁業若しくは[[laws/漁業法/本文/第88条.md|第八十八条]]第一項（同条第五項において準用する場合を含む。）の規定により許可を受けた漁業の停止中その漁業を営み、[[laws/漁業法/本文/第60条.md|第六十条]]第二項に規定する定置漁業権若しくは区画漁業権の行使の停止中その漁業を営み、又は同項に規定する共同漁業権の行使の停止中その漁場において行使を停止した漁業を営んだとき。[[laws/漁業法/本文/第68条.md|第六十八条]]の規定に違反して定置漁業又は区画漁業を営んだとき。[[laws/漁業法/本文/第119条.md|第百十九条]]第一項の規定による禁止に違反して漁業を営み、又は同項の規定による許可を受けないで漁業を営んだとき。

- 一 [[laws/漁業法/本文/第25条.md|第二十五条]]の規定に違反して特定水産資源を採捕したとき。
- 二 [[laws/漁業法/本文/第27条.md|第二十七条]]、[[laws/漁業法/本文/第33条.md|第三十三条]]、[[laws/漁業法/本文/第34条.md|第三十四条]]又は[[laws/漁業法/本文/第131条.md|第百三十一条]]第一項の規定による命令に違反したとき。
- 三 [[laws/漁業法/本文/第36条.md|第三十六条]]第一項又は[[laws/漁業法/本文/第57条.md|第五十七条]]第一項の規定に違反して大臣許可漁業又は知事許可漁業を営んだとき。
- 四 [[laws/漁業法/本文/第47条.md|第四十七条]]（[[laws/漁業法/本文/第58条.md|第五十八条]]において準用する場合を含む。）の許可を受けずに、[[laws/漁業法/本文/第42条.md|第四十二条]]第一項（[[laws/漁業法/本文/第58条.md|第五十八条]]において読み替えて準用する場合を含む。以下この号において同じ。）の農林水産省令又は規則で定める事項について、同項の規定により定められた制限措置と異なる内容により、大臣許可漁業又は知事許可漁業を営んだとき。
- 五 大臣許可漁業の許可、漁業権又は[[laws/漁業法/本文/第88条.md|第八十八条]]第一項（同条第五項において準用する場合を含む。）の規定による漁業の許可に付けた条件に違反して漁業を営んだとき。
- 六 大臣許可漁業、知事許可漁業若しくは[[laws/漁業法/本文/第88条.md|第八十八条]]第一項（同条第五項において準用する場合を含む。）の規定により許可を受けた漁業の停止中その漁業を営み、[[laws/漁業法/本文/第60条.md|第六十条]]第二項に規定する定置漁業権若しくは区画漁業権の行使の停止中その漁業を営み、又は同項に規定する共同漁業権の行使の停止中その漁場において行使を停止した漁業を営んだとき。
- 七 [[laws/漁業法/本文/第68条.md|第六十八条]]の規定に違反して定置漁業又は区画漁業を営んだとき。
- 八 [[laws/漁業法/本文/第119条.md|第百十九条]]第一項の規定による禁止に違反して漁業を営み、又は同項の規定による許可を受けないで漁業を営んだとき。
