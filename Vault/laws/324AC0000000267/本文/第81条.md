# 第八十一条 （水面使用の権利義務）

## 
漁業権者が有する水面使用に関する権利義務（当該漁業権者が当該漁業に関し行政庁の許可、認可その他の処分に基づいて有する権利義務を含む。）は、漁業権の処分に従う。
