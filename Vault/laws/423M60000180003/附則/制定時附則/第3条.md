# 第三条 （助教授の在職に関する経過措置）

## 
学校教育法の一部を改正する法律（平成十七年法律第八十三号）による改正前の学校教育法[[laws/423M60000180003/精神障害者の保健及び福祉に関する科目を定_law.md|第五十八条]]第七項の助教授の職にあった者は、[[laws/423M60000180003/本文/第1条.md|第一条]]第三項第一号の規定の適用については、准教授の職にあった者とみなす。
