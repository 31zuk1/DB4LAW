# 第九十条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、二年以下の拘禁刑若しくは三百万円以下の罰金に処し、又はこれを併科する。[[laws/326AC1000000238/本文/第4条.md|第四条]]の規定に違反して、免許を受けないで金庫の事業を行つたとき。不正の手段により[[laws/326AC1000000238/本文/第4条.md|第四条]]の免許を受けたとき。[[laws/326AC1000000238/本文/第85条の2.md|第八十五条の二]]第一項の規定に違反して、許可を受けないで信用金庫代理業を行つたとき。不正の手段により[[laws/326AC1000000238/本文/第85条の2.md|第八十五条の二]]第一項の許可を受けたとき。不正の手段により[[laws/326AC1000000238/本文/第85条の3.md|第八十五条の三]]第一項の登録を受けたとき。[[laws/326AC1000000238/本文/第85条の4.md|第八十五条の四]]第一項の規定に違反して、登録を受けないで信用金庫電子決済等代行業を営んだとき。不正の手段により[[laws/326AC1000000238/本文/第85条の4.md|第八十五条の四]]第一項の登録を受けたとき。[[laws/326AC1000000238/本文/第85条の11.md|第八十五条の十一]]第四項の規定による信用金庫電子決済等代行業の廃止の命令に違反したとき。[[laws/326AC1000000238/本文/第89条.md|第八十九条]]第一項、第三項、第五項、第七項、第九項又は第十一項において準用する銀行法（以下[[laws/326AC1000000238/本文/第94条.md|第九十四条]]までにおいて「銀行法」という。）[[laws/326AC1000000238/本文/第9条.md|第九条]]の規定に違反して、他人に金庫の事業を行わせたとき。銀行法[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の四十一]]の規定に違反して、他人に外国銀行代理業務又は信用金庫代理業を行わせたとき。銀行法[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の六十]]の十の規定に違反して、他人に信用金庫電子決済等取扱業を行わせたとき。銀行法[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の六十]]の二十三第二項の規定による信用金庫電子決済等代行業の廃止の命令に違反したとき。

- 一 [[laws/326AC1000000238/本文/第4条.md|第四条]]の規定に違反して、免許を受けないで金庫の事業を行つたとき。
- 二 不正の手段により[[laws/326AC1000000238/本文/第4条.md|第四条]]の免許を受けたとき。
- 三 [[laws/326AC1000000238/本文/第85条の2.md|第八十五条の二]]第一項の規定に違反して、許可を受けないで信用金庫代理業を行つたとき。
- 四 不正の手段により[[laws/326AC1000000238/本文/第85条の2.md|第八十五条の二]]第一項の許可を受けたとき。
- 五 不正の手段により[[laws/326AC1000000238/本文/第85条の3.md|第八十五条の三]]第一項の登録を受けたとき。
- 六 [[laws/326AC1000000238/本文/第85条の4.md|第八十五条の四]]第一項の規定に違反して、登録を受けないで信用金庫電子決済等代行業を営んだとき。
- 七 不正の手段により[[laws/326AC1000000238/本文/第85条の4.md|第八十五条の四]]第一項の登録を受けたとき。
- 八 [[laws/326AC1000000238/本文/第85条の11.md|第八十五条の十一]]第四項の規定による信用金庫電子決済等代行業の廃止の命令に違反したとき。
- 九 [[laws/326AC1000000238/本文/第89条.md|第八十九条]]第一項、第三項、第五項、第七項、第九項又は第十一項において準用する銀行法（以下[[laws/326AC1000000238/本文/第94条.md|第九十四条]]までにおいて「銀行法」という。）[[laws/326AC1000000238/本文/第9条.md|第九条]]の規定に違反して、他人に金庫の事業を行わせたとき。
- 十 銀行法[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の四十一]]の規定に違反して、他人に外国銀行代理業務又は信用金庫代理業を行わせたとき。
- 十一 銀行法[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の六十]]の十の規定に違反して、他人に信用金庫電子決済等取扱業を行わせたとき。
- 十二 銀行法[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の六十]]の二十三第二項の規定による信用金庫電子決済等代行業の廃止の命令に違反したとき。
