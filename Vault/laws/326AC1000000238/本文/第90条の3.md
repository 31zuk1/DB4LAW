# 第九十条の三 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、一年以下の拘禁刑又は三百万円以下の罰金に処する。銀行法[[laws/326AC1000000238/本文/第19条.md|第十九条]]、[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の五十]]第一項、[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の六十]]の十九若しくは[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の六十一]]の十三の規定に違反して、これらの規定に規定する書類の提出をせず、又はこれらの書類に記載すべき事項を記載せず、若しくは虚偽の記載をしてこれらの書類の提出をしたとき。銀行法[[laws/326AC1000000238/本文/第21条.md|第二十一条]]第一項若しくは第二項、[[laws/326AC1000000238/本文/第52条の2.md|第五十二条の二]]の六第一項若しくは[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の五十一]]第一項の規定に違反して、これらの規定に規定する説明書類を公衆の縦覧に供せず、若しくは銀行法[[laws/326AC1000000238/本文/第21条.md|第二十一条]]第四項（同条第五項において準用する場合を含む。以下この号において同じ。）、[[laws/326AC1000000238/本文/第52条の2.md|第五十二条の二]]の六第二項若しくは[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の五十一]]第二項の規定に違反して、銀行法[[laws/326AC1000000238/本文/第21条.md|第二十一条]]第四項、[[laws/326AC1000000238/本文/第52条の2.md|第五十二条の二]]の六第二項若しくは[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の五十一]]第二項に規定する電磁的記録に記録された情報を電磁的方法により不特定多数の者が提供を受けることができる状態に置く措置として内閣府令で定めるものをとらず、又はこれらの規定に違反して、これらの書類に記載すべき事項を記載せず、若しくは虚偽の記載をして、公衆の縦覧に供し、若しくは電磁的記録に記録すべき事項を記録せず、若しくは虚偽の記録をして、電磁的記録に記録された情報を電磁的方法により不特定多数の者が提供を受けることができる状態に置く措置をとつたとき。銀行法[[laws/326AC1000000238/本文/第24条.md|第二十四条]]第一項若しくは第二項、[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の五十三]]、[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の六十]]の二十第一項若しくは第二項若しくは[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の六十一]]の十四第一項若しくは第二項の規定による報告若しくは資料の提出をせず、又は虚偽の報告若しくは資料の提出をしたとき。銀行法[[laws/326AC1000000238/本文/第25条.md|第二十五条]]第一項若しくは第二項、[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の五十四]]第一項、[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の六十]]の二十一第一項若しくは第二項若しくは[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の六十一]]の十五第一項若しくは第二項の規定による当該職員の質問に対して答弁をせず、若しくは虚偽の答弁をし、又はこれらの規定による検査を拒み、妨げ、若しくは忌避したとき。銀行法[[laws/326AC1000000238/本文/第45条.md|第四十五条]]第三項の規定による検査を拒み、妨げ、若しくは忌避し、又は同項の規定による命令に違反したとき。銀行法[[laws/326AC1000000238/本文/第46条.md|第四十六条]]第三項において準用する銀行法[[laws/326AC1000000238/本文/第25条.md|第二十五条]]第一項の規定による当該職員の質問に対して答弁をせず、若しくは虚偽の答弁をし、又は同項の規定による検査を拒み、妨げ、若しくは忌避したとき。銀行法[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の三十七]]第一項の規定による申請書若しくは同条第二項の規定によりこれに添付すべき書類、銀行法[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の六十]]の四第一項の規定による登録申請書若しくは同条第二項の規定によりこれに添付すべき書類又は銀行法[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の六十一]]の三第一項の規定による登録申請書若しくは同条第二項の規定によりこれに添付すべき書類に虚偽の記載をして提出したとき。銀行法[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の四十二]]第一項の規定による承認を受けないで信用金庫代理業及び信用金庫代理業に付随する業務以外の業務を行つたとき。銀行法[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の六十]]の三十六第三項の規定に違反して、同項の規定による公告をせず、又は当該公告をしなければならない書類に記載すべき事項を記載せず、若しくは虚偽の記載をして、公告をしたとき。

- 一 銀行法[[laws/326AC1000000238/本文/第19条.md|第十九条]]、[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の五十]]第一項、[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の六十]]の十九若しくは[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の六十一]]の十三の規定に違反して、これらの規定に規定する書類の提出をせず、又はこれらの書類に記載すべき事項を記載せず、若しくは虚偽の記載をしてこれらの書類の提出をしたとき。
- 一の二 銀行法[[laws/326AC1000000238/本文/第21条.md|第二十一条]]第一項若しくは第二項、[[laws/326AC1000000238/本文/第52条の2.md|第五十二条の二]]の六第一項若しくは[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の五十一]]第一項の規定に違反して、これらの規定に規定する説明書類を公衆の縦覧に供せず、若しくは銀行法[[laws/326AC1000000238/本文/第21条.md|第二十一条]]第四項（同条第五項において準用する場合を含む。以下この号において同じ。）、[[laws/326AC1000000238/本文/第52条の2.md|第五十二条の二]]の六第二項若しくは[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の五十一]]第二項の規定に違反して、銀行法[[laws/326AC1000000238/本文/第21条.md|第二十一条]]第四項、[[laws/326AC1000000238/本文/第52条の2.md|第五十二条の二]]の六第二項若しくは[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の五十一]]第二項に規定する電磁的記録に記録された情報を電磁的方法により不特定多数の者が提供を受けることができる状態に置く措置として内閣府令で定めるものをとらず、又はこれらの規定に違反して、これらの書類に記載すべき事項を記載せず、若しくは虚偽の記載をして、公衆の縦覧に供し、若しくは電磁的記録に記録すべき事項を記録せず、若しくは虚偽の記録をして、電磁的記録に記録された情報を電磁的方法により不特定多数の者が提供を受けることができる状態に置く措置をとつたとき。
- 二 銀行法[[laws/326AC1000000238/本文/第24条.md|第二十四条]]第一項若しくは第二項、[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の五十三]]、[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の六十]]の二十第一項若しくは第二項若しくは[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の六十一]]の十四第一項若しくは第二項の規定による報告若しくは資料の提出をせず、又は虚偽の報告若しくは資料の提出をしたとき。
- 三 銀行法[[laws/326AC1000000238/本文/第25条.md|第二十五条]]第一項若しくは第二項、[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の五十四]]第一項、[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の六十]]の二十一第一項若しくは第二項若しくは[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の六十一]]の十五第一項若しくは第二項の規定による当該職員の質問に対して答弁をせず、若しくは虚偽の答弁をし、又はこれらの規定による検査を拒み、妨げ、若しくは忌避したとき。
- 四 銀行法[[laws/326AC1000000238/本文/第45条.md|第四十五条]]第三項の規定による検査を拒み、妨げ、若しくは忌避し、又は同項の規定による命令に違反したとき。
- 五 銀行法[[laws/326AC1000000238/本文/第46条.md|第四十六条]]第三項において準用する銀行法[[laws/326AC1000000238/本文/第25条.md|第二十五条]]第一項の規定による当該職員の質問に対して答弁をせず、若しくは虚偽の答弁をし、又は同項の規定による検査を拒み、妨げ、若しくは忌避したとき。
- 六 銀行法[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の三十七]]第一項の規定による申請書若しくは同条第二項の規定によりこれに添付すべき書類、銀行法[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の六十]]の四第一項の規定による登録申請書若しくは同条第二項の規定によりこれに添付すべき書類又は銀行法[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の六十一]]の三第一項の規定による登録申請書若しくは同条第二項の規定によりこれに添付すべき書類に虚偽の記載をして提出したとき。
- 七 銀行法[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の四十二]]第一項の規定による承認を受けないで信用金庫代理業及び信用金庫代理業に付随する業務以外の業務を行つたとき。
- 八 銀行法[[laws/326AC1000000238/信用金庫法_law.md|第五十二条の六十]]の三十六第三項の規定に違反して、同項の規定による公告をせず、又は当該公告をしなければならない書類に記載すべき事項を記載せず、若しくは虚偽の記載をして、公告をしたとき。
