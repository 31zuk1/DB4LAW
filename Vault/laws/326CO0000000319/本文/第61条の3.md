# 第六十一条の三 （入国審査官）

## 
入国者収容所及び地方出入国在留管理局に、入国審査官を置く。

## ２
入国審査官は、次に掲げる事務を行う。上陸及び退去強制についての審査及び口頭審理並びに出国命令についての審査を行うこと。[[laws/326CO0000000319/本文/第22条の4.md|第二十二条の四]]第二項（[[laws/326CO0000000319/本文/第61条の2.md|第六十一条の二]]の十一第二項において準用する場合を含む。）の規定による意見の聴取、[[laws/326CO0000000319/本文/第22条の4.md|第二十二条の四]]第三項ただし書（[[laws/326CO0000000319/本文/第61条の2.md|第六十一条の二]]の十一第二項において準用する場合を含む。次条第二項第六号において同じ。）の規定による通知並びに[[laws/326CO0000000319/本文/第61条の8.md|第六十一条の八]]の二第四項及び第五項の規定による交付送達を行うこと。[[laws/326CO0000000319/本文/第19条の37.md|第十九条の三十七]]第一項、[[laws/326CO0000000319/本文/第44条の9.md|第四十四条の九]]第一項及び第二項、[[laws/326CO0000000319/本文/第52条の7.md|第五十二条の七]]第一項及び第二項、[[laws/326CO0000000319/本文/第59条の2.md|第五十九条の二]]第一項並びに[[laws/326CO0000000319/本文/第61条の2.md|第六十一条の二]]の十七第一項及び第二項に規定する事実の調査を行うこと。[[laws/326CO0000000319/本文/第19条の20.md|第十九条の二十]]第一項の規定による関係人に対する質問並びに特定技能所属機関に係る事業所その他特定技能外国人の受入れに関係のある場所への立入り及びその設備又は帳簿書類その他の物件の検査を行うこと。収容令書及び退去強制令書を発付すること。収容令書又は退去強制令書の発付を受けて収容されている者を仮放免すること。[[laws/326CO0000000319/本文/第44条の2.md|第四十四条の二]]第七項に規定する監理措置決定及び[[laws/326CO0000000319/本文/第52条の2.md|第五十二条の二]]第六項に規定する監理措置決定を行うこと。[[laws/326CO0000000319/本文/第44条の5.md|第四十四条の五]]第一項の規定による許可を行うこと。[[laws/326CO0000000319/本文/第52条.md|第五十二条]]第八項の規定による通知を行うこと。[[laws/326CO0000000319/本文/第52条.md|第五十二条]]第十二項の規定による命令を行うこと。[[laws/326CO0000000319/本文/第55条の2.md|第五十五条の二]]第一項の規定により本邦からの退去を命ずること。[[laws/326CO0000000319/本文/第55条の85.md|第五十五条の八十五]]第一項の規定による出国命令をすること。[[laws/326CO0000000319/本文/第63条の2.md|第六十三条の二]]第一項の規定により同項に規定する出国制限対象者に条件を付すこと及び同項の出国制限対象者条件指定書を交付すること。

- 一 上陸及び退去強制についての審査及び口頭審理並びに出国命令についての審査を行うこと。
- 二 [[laws/326CO0000000319/本文/第22条の4.md|第二十二条の四]]第二項（[[laws/326CO0000000319/本文/第61条の2.md|第六十一条の二]]の十一第二項において準用する場合を含む。）の規定による意見の聴取、[[laws/326CO0000000319/本文/第22条の4.md|第二十二条の四]]第三項ただし書（[[laws/326CO0000000319/本文/第61条の2.md|第六十一条の二]]の十一第二項において準用する場合を含む。次条第二項第六号において同じ。）の規定による通知並びに[[laws/326CO0000000319/本文/第61条の8.md|第六十一条の八]]の二第四項及び第五項の規定による交付送達を行うこと。
- 三 [[laws/326CO0000000319/本文/第19条の37.md|第十九条の三十七]]第一項、[[laws/326CO0000000319/本文/第44条の9.md|第四十四条の九]]第一項及び第二項、[[laws/326CO0000000319/本文/第52条の7.md|第五十二条の七]]第一項及び第二項、[[laws/326CO0000000319/本文/第59条の2.md|第五十九条の二]]第一項並びに[[laws/326CO0000000319/本文/第61条の2.md|第六十一条の二]]の十七第一項及び第二項に規定する事実の調査を行うこと。
- 四 [[laws/326CO0000000319/本文/第19条の20.md|第十九条の二十]]第一項の規定による関係人に対する質問並びに特定技能所属機関に係る事業所その他特定技能外国人の受入れに関係のある場所への立入り及びその設備又は帳簿書類その他の物件の検査を行うこと。
- 五 収容令書及び退去強制令書を発付すること。
- 六 収容令書又は退去強制令書の発付を受けて収容されている者を仮放免すること。
- 七 [[laws/326CO0000000319/本文/第44条の2.md|第四十四条の二]]第七項に規定する監理措置決定及び[[laws/326CO0000000319/本文/第52条の2.md|第五十二条の二]]第六項に規定する監理措置決定を行うこと。
- 八 [[laws/326CO0000000319/本文/第44条の5.md|第四十四条の五]]第一項の規定による許可を行うこと。
- 九 [[laws/326CO0000000319/本文/第52条.md|第五十二条]]第八項の規定による通知を行うこと。
- 十 [[laws/326CO0000000319/本文/第52条.md|第五十二条]]第十二項の規定による命令を行うこと。
- 十一 [[laws/326CO0000000319/本文/第55条の2.md|第五十五条の二]]第一項の規定により本邦からの退去を命ずること。
- 十二 [[laws/326CO0000000319/本文/第55条の85.md|第五十五条の八十五]]第一項の規定による出国命令をすること。
- 十三 [[laws/326CO0000000319/本文/第63条の2.md|第六十三条の二]]第一項の規定により同項に規定する出国制限対象者に条件を付すこと及び同項の出国制限対象者条件指定書を交付すること。
## ３
地方出入国在留管理局に置かれた入国審査官は、必要があるときは、その地方出入国在留管理局の管轄区域外においても、職務を行うことができる。
