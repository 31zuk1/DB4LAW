# 第七十二条 

## 
次の各号のいずれかに該当する者は、一年以下の拘禁刑若しくは二十万円以下の罰金に処し、又はこれを併科する。船舶観光上陸の許可を受けた者で、当該許可に係る指定旅客船が寄港する本邦の出入国港において下船した後当該出入国港から当該指定旅客船が出港するまでの間に帰船することなく逃亡したもの一時庇ひ護のための上陸の許可を受けた者で、[[laws/出入国管理及び難民認定法/本文/第18条の2.md|第十八条の二]]第四項の規定に基づき付された条件に違反して逃亡したもの[[laws/出入国管理及び難民認定法/本文/第44条の2.md|第四十四条の二]]第一項若しくは第六項又は[[laws/出入国管理及び難民認定法/本文/第52条の2.md|第五十二条の二]]第一項若しくは第五項の規定に基づき付された条件に違反して、逃亡し、又は正当な理由がなくて呼出しに応じない者[[laws/出入国管理及び難民認定法/本文/第52条.md|第五十二条]]第十項の規定により放免された者で、同項の規定に基づき付された条件に違反して、逃亡し、又は正当な理由がなくて呼出しに応じないもの[[laws/出入国管理及び難民認定法/本文/第52条.md|第五十二条]]第十二項の規定による命令に違反して同項に規定する行為をしなかつた者[[laws/出入国管理及び難民認定法/本文/第54条.md|第五十四条]]第二項の規定により仮放免された者で、同項の規定に基づき付された条件に違反して、逃亡し、又は正当な理由がなくて呼出しに応じないもの[[laws/出入国管理及び難民認定法/本文/第55条の2.md|第五十五条の二]]第一項の規定による命令に違反して本邦から退去しなかつた者[[laws/出入国管理及び難民認定法/本文/第55条の85.md|第五十五条の八十五]]第一項の規定により出国命令を受けた者で、同条第三項の規定に基づき付された条件に違反して逃亡したもの[[laws/出入国管理及び難民認定法/本文/第61条の2.md|第六十一条の二]]の四第一項の規定による許可を受けた者で、同条第三項の規定に基づき付された条件に違反して、逃亡し、又は正当な理由がなくて呼出しに応じないもの[[laws/出入国管理及び難民認定法/本文/第61条の2.md|第六十一条の二]]の十第四項又は[[laws/出入国管理及び難民認定法/本文/第61条の2.md|第六十一条の二]]の十六の規定に違反して難民認定証明書、難民旅行証明書又は補完的保護対象者認定証明書を返納しなかつた者[[laws/出入国管理及び難民認定法/本文/第61条の2.md|第六十一条の二]]の十五第八項の規定により難民旅行証明書の返納を命ぜられた者で、同項の規定により付された期限内にこれを返納しなかつたもの[[laws/出入国管理及び難民認定法/本文/第63条の2.md|第六十三条の二]]第一項の規定に基づき付された条件に違反して、逃亡し、又は正当な理由がなくて呼出しに応じない者

- 一 船舶観光上陸の許可を受けた者で、当該許可に係る指定旅客船が寄港する本邦の出入国港において下船した後当該出入国港から当該指定旅客船が出港するまでの間に帰船することなく逃亡したもの
- 二 一時庇ひ護のための上陸の許可を受けた者で、[[laws/出入国管理及び難民認定法/本文/第18条の2.md|第十八条の二]]第四項の規定に基づき付された条件に違反して逃亡したもの
- 三 [[laws/出入国管理及び難民認定法/本文/第44条の2.md|第四十四条の二]]第一項若しくは第六項又は[[laws/出入国管理及び難民認定法/本文/第52条の2.md|第五十二条の二]]第一項若しくは第五項の規定に基づき付された条件に違反して、逃亡し、又は正当な理由がなくて呼出しに応じない者
- 四 [[laws/出入国管理及び難民認定法/本文/第52条.md|第五十二条]]第十項の規定により放免された者で、同項の規定に基づき付された条件に違反して、逃亡し、又は正当な理由がなくて呼出しに応じないもの
- 五 [[laws/出入国管理及び難民認定法/本文/第52条.md|第五十二条]]第十二項の規定による命令に違反して同項に規定する行為をしなかつた者
- 六 [[laws/出入国管理及び難民認定法/本文/第54条.md|第五十四条]]第二項の規定により仮放免された者で、同項の規定に基づき付された条件に違反して、逃亡し、又は正当な理由がなくて呼出しに応じないもの
- 七 [[laws/出入国管理及び難民認定法/本文/第55条の2.md|第五十五条の二]]第一項の規定による命令に違反して本邦から退去しなかつた者
- 八 [[laws/出入国管理及び難民認定法/本文/第55条の85.md|第五十五条の八十五]]第一項の規定により出国命令を受けた者で、同条第三項の規定に基づき付された条件に違反して逃亡したもの
- 九 [[laws/出入国管理及び難民認定法/本文/第61条の2.md|第六十一条の二]]の四第一項の規定による許可を受けた者で、同条第三項の規定に基づき付された条件に違反して、逃亡し、又は正当な理由がなくて呼出しに応じないもの
- 十 [[laws/出入国管理及び難民認定法/本文/第61条の2.md|第六十一条の二]]の十第四項又は[[laws/出入国管理及び難民認定法/本文/第61条の2.md|第六十一条の二]]の十六の規定に違反して難民認定証明書、難民旅行証明書又は補完的保護対象者認定証明書を返納しなかつた者
- 十一 [[laws/出入国管理及び難民認定法/本文/第61条の2.md|第六十一条の二]]の十五第八項の規定により難民旅行証明書の返納を命ぜられた者で、同項の規定により付された期限内にこれを返納しなかつたもの
- 十二 [[laws/出入国管理及び難民認定法/本文/第63条の2.md|第六十三条の二]]第一項の規定に基づき付された条件に違反して、逃亡し、又は正当な理由がなくて呼出しに応じない者
