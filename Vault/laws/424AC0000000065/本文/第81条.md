# 第八十一条 

## 
[[laws/424AC0000000065/本文/第15条.md|第十五条]]第二項（[[laws/424AC0000000065/本文/第30条の3.md|第三十条の三]]において準用する場合を含む。以下この条において同じ。）の規定による報告若しくは物件の提出若しくは提示をせず、若しくは虚偽の報告若しくは虚偽の物件の提出若しくは提示をし、又は同項の規定による当該職員の質問に対して、答弁せず、若しくは虚偽の答弁をした者は、十万円以下の過料に処する。
