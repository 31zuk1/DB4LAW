# 第五十四条 （公示）

## 
農林水産大臣は、次に掲げる場合には、その旨を官報に公示しなければならない。[[laws/328AC1000000035/本文/第2条.md|第二条]]第三項又は[[laws/328AC1000000035/本文/第51条.md|第五十一条]]第一項の指定をしたとき。[[laws/328AC1000000035/本文/第7条.md|第七条]]第一項、[[laws/328AC1000000035/本文/第21条.md|第二十一条]]第一項、[[laws/328AC1000000035/本文/第27条.md|第二十七条]]第一項、[[laws/328AC1000000035/本文/第29条.md|第二十九条]]第一項又は[[laws/328AC1000000035/本文/第30条.md|第三十条]]第一項の登録をしたとき。[[laws/328AC1000000035/本文/第13条.md|第十三条]]第四項（[[laws/328AC1000000035/本文/第21条.md|第二十一条]]第三項、[[laws/328AC1000000035/本文/第29条.md|第二十九条]]第三項及び[[laws/328AC1000000035/本文/第30条.md|第三十条]]第三項において準用する場合を含む。）、[[laws/328AC1000000035/本文/第14条.md|第十四条]]（[[laws/328AC1000000035/本文/第21条.md|第二十一条]]第三項、[[laws/328AC1000000035/本文/第29条.md|第二十九条]]第三項及び[[laws/328AC1000000035/本文/第30条.md|第三十条]]第三項において準用する場合を含む。）、[[laws/328AC1000000035/本文/第39条.md|第三十九条]]又は[[laws/328AC1000000035/本文/第41条.md|第四十一条]]の規定による届出があつたとき。[[laws/328AC1000000035/本文/第18条.md|第十八条]]（[[laws/328AC1000000035/本文/第29条.md|第二十九条]]第三項において準用する場合を含む。）又は[[laws/328AC1000000035/本文/第22条.md|第二十二条]]第一項（[[laws/328AC1000000035/本文/第30条.md|第三十条]]第三項において準用する場合を含む。）の規定により登録を取り消したとき。[[laws/328AC1000000035/本文/第23条.md|第二十三条]]の規定による禁止をしたとき。公定規格又は[[laws/328AC1000000035/本文/第32条.md|第三十二条]]第一項の表示の基準となるべき事項の設定、改正又は廃止をしたとき。[[laws/328AC1000000035/本文/第45条.md|第四十五条]]の規定により[[laws/328AC1000000035/本文/第27条.md|第二十七条]]第一項の登録を取り消し、又は同項前段の検定の業務の停止を命じたとき。[[laws/328AC1000000035/本文/第47条.md|第四十七条]]第一項の規定により農林水産大臣が[[laws/328AC1000000035/本文/第27条.md|第二十七条]]第一項前段の検定の業務の全部若しくは一部を自ら行うものとするとき、又は自ら行つていた同項前段の検定の業務の全部若しくは一部を行わないこととするとき。

- 一 [[laws/328AC1000000035/本文/第2条.md|第二条]]第三項又は[[laws/328AC1000000035/本文/第51条.md|第五十一条]]第一項の指定をしたとき。
- 二 [[laws/328AC1000000035/本文/第7条.md|第七条]]第一項、[[laws/328AC1000000035/本文/第21条.md|第二十一条]]第一項、[[laws/328AC1000000035/本文/第27条.md|第二十七条]]第一項、[[laws/328AC1000000035/本文/第29条.md|第二十九条]]第一項又は[[laws/328AC1000000035/本文/第30条.md|第三十条]]第一項の登録をしたとき。
- 三 [[laws/328AC1000000035/本文/第13条.md|第十三条]]第四項（[[laws/328AC1000000035/本文/第21条.md|第二十一条]]第三項、[[laws/328AC1000000035/本文/第29条.md|第二十九条]]第三項及び[[laws/328AC1000000035/本文/第30条.md|第三十条]]第三項において準用する場合を含む。）、[[laws/328AC1000000035/本文/第14条.md|第十四条]]（[[laws/328AC1000000035/本文/第21条.md|第二十一条]]第三項、[[laws/328AC1000000035/本文/第29条.md|第二十九条]]第三項及び[[laws/328AC1000000035/本文/第30条.md|第三十条]]第三項において準用する場合を含む。）、[[laws/328AC1000000035/本文/第39条.md|第三十九条]]又は[[laws/328AC1000000035/本文/第41条.md|第四十一条]]の規定による届出があつたとき。
- 四 [[laws/328AC1000000035/本文/第18条.md|第十八条]]（[[laws/328AC1000000035/本文/第29条.md|第二十九条]]第三項において準用する場合を含む。）又は[[laws/328AC1000000035/本文/第22条.md|第二十二条]]第一項（[[laws/328AC1000000035/本文/第30条.md|第三十条]]第三項において準用する場合を含む。）の規定により登録を取り消したとき。
- 五 [[laws/328AC1000000035/本文/第23条.md|第二十三条]]の規定による禁止をしたとき。
- 六 公定規格又は[[laws/328AC1000000035/本文/第32条.md|第三十二条]]第一項の表示の基準となるべき事項の設定、改正又は廃止をしたとき。
- 七 [[laws/328AC1000000035/本文/第45条.md|第四十五条]]の規定により[[laws/328AC1000000035/本文/第27条.md|第二十七条]]第一項の登録を取り消し、又は同項前段の検定の業務の停止を命じたとき。
- 八 [[laws/328AC1000000035/本文/第47条.md|第四十七条]]第一項の規定により農林水産大臣が[[laws/328AC1000000035/本文/第27条.md|第二十七条]]第一項前段の検定の業務の全部若しくは一部を自ら行うものとするとき、又は自ら行つていた同項前段の検定の業務の全部若しくは一部を行わないこととするとき。
