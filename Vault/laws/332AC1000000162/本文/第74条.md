# 第七十四条 

## 
次の各号のいずれかに該当する場合には、その違反行為をした海運組合又は連合会の発起人、理事若しくは監事又は清算人は、二十万円以下の過料に処する。この法律の規定に基づいて海運組合又は連合会が行うことができる事業以外の事業を当該の海運組合又は連合会の事業として行つたとき。[[laws/内航海運組合法/本文/第7条.md|第七条]]第一項（[[laws/内航海運組合法/本文/第58条.md|第五十八条]]において準用する場合を含む。）の規定に基づく政令による登記を怠つたとき。[[laws/内航海運組合法/本文/第8条.md|第八条]]第二項（[[laws/内航海運組合法/本文/第58条.md|第五十八条]]において準用する場合を含む。）の規定に違反したとき。[[laws/内航海運組合法/本文/第15条.md|第十五条]]（[[laws/内航海運組合法/本文/第10条.md|第十条]]第二項及び[[laws/内航海運組合法/本文/第58条.md|第五十八条]]において準用する場合を含む。）又は[[laws/内航海運組合法/本文/第52条.md|第五十二条]]第二項（[[laws/内航海運組合法/本文/第58条.md|第五十八条]]において準用する場合を含む。）の規定による届出を怠つたとき。[[laws/内航海運組合法/本文/第20条.md|第二十条]]（[[laws/内航海運組合法/本文/第58条.md|第五十八条]]において準用する場合を含む。）の規定に違反したとき。[[laws/内航海運組合法/本文/第25条.md|第二十五条]]第二項後段又は[[laws/内航海運組合法/本文/第40条.md|第四十条]]第四項（これらの規定を[[laws/内航海運組合法/本文/第58条.md|第五十八条]]において準用する場合を含む。）の規定に違反したとき。[[laws/内航海運組合法/本文/第27条.md|第二十七条]]第七項、[[laws/内航海運組合法/本文/第34条.md|第三十四条]]第六項（[[laws/内航海運組合法/本文/第55条.md|第五十五条]]において準用する場合を含む。）若しくは[[laws/内航海運組合法/本文/第49条の3.md|第四十九条の三]]（これらの規定を[[laws/内航海運組合法/本文/第58条.md|第五十八条]]において準用する場合を含む。）の規定又は[[laws/内航海運組合法/本文/第55条.md|第五十五条]]（[[laws/内航海運組合法/本文/第58条.md|第五十八条]]において準用する場合を含む。）において準用する会社法[[laws/会社法/本文/第492条.md|第四百九十二条]]第一項の規定に違反して議事録、財産目録若しくは貸借対照表を作成せず、又はこれらの書類に記載すべき事項を記載せず、若しくは虚偽の記載をしたとき。[[laws/内航海運組合法/本文/第32条.md|第三十二条]]第五項（[[laws/内航海運組合法/本文/第51条.md|第五十一条]]第四項及び[[laws/会社法/本文/第58条.md|第五十八条]]において準用する場合を含む。）の規定に違反したとき。[[laws/内航海運組合法/本文/第36条.md|第三十六条]]第一項（[[laws/内航海運組合法/本文/第58条.md|第五十八条]]において準用する場合を含む。）の規定に違反して理事又は職員を兼ねたとき。[[laws/内航海運組合法/本文/第37条.md|第三十七条]]又は[[laws/会社法/本文/第38条.md|第三十八条]]（これらの規定を[[laws/内航海運組合法/本文/第58条.md|第五十八条]]において準用する場合を含む。）の規定に違反して書類を備えて置かず、その書類に記載すべき事項を記載せず、若しくは虚偽の記載をし、又は正当な理由がないのにその書類の閲覧若しくは謄写を拒んだとき。正当な理由がないのに[[laws/内航海運組合法/本文/第39条.md|第三十九条]]（[[laws/内航海運組合法/本文/第58条.md|第五十八条]]において準用する場合を含む。）又は[[laws/内航海運組合法/本文/第41条.md|第四十一条]]（[[laws/内航海運組合法/本文/第58条.md|第五十八条]]において準用する場合を含む。）において準用する会社法[[laws/会社法/本文/第389条.md|第三百八十九条]]第四項（第一号に係る部分に限る。）の規定による帳簿又は書類の閲覧又は謄写を拒んだとき。[[laws/内航海運組合法/本文/第34条の3.md|第三十四条の三]]第三項（[[laws/内航海運組合法/本文/第55条.md|第五十五条]]（[[laws/内航海運組合法/本文/第58条.md|第五十八条]]において準用する場合を含む。）及び[[laws/会社法/本文/第58条.md|第五十八条]]において準用する場合を含む。）又は[[laws/内航海運組合法/本文/第41条.md|第四十一条]]（[[laws/内航海運組合法/本文/第58条.md|第五十八条]]において準用する場合を含む。）において準用する会社法[[laws/会社法/本文/第430条の2.md|第四百三十条の二]]第四項の規定に違反して理事会若しくは清算人会に報告せず、又は虚偽の報告をしたとき。[[laws/内航海運組合法/本文/第41条.md|第四十一条]]（[[laws/内航海運組合法/本文/第58条.md|第五十八条]]において準用する場合を含む。）において準用する会社法[[laws/会社法/本文/第389条.md|第三百八十九条]]第四項の規定による報告を拒み、又は虚偽の報告をしたとき。[[laws/内航海運組合法/本文/第41条.md|第四十一条]]（[[laws/内航海運組合法/本文/第58条.md|第五十八条]]において準用する場合を含む。）において準用する会社法[[laws/会社法/本文/第389条.md|第三百八十九条]]第五項の規定による調査を妨げたとき。[[laws/内航海運組合法/本文/第42条.md|第四十二条]]（[[laws/内航海運組合法/本文/第58条.md|第五十八条]]において準用する場合を含む。）の規定に違反して通常総会の招集を怠つたとき。[[laws/内航海運組合法/本文/第55条.md|第五十五条]]（[[laws/内航海運組合法/本文/第58条.md|第五十八条]]において準用する場合を含む。）において準用する会社法[[laws/会社法/本文/第499条.md|第四百九十九条]]第一項の規定による公告を怠り、又は虚偽の公告をしたとき。清算の結了を遅延させることを目的として[[laws/内航海運組合法/本文/第55条.md|第五十五条]]（[[laws/内航海運組合法/本文/第58条.md|第五十八条]]において準用する場合を含む。）において準用する会社法[[laws/会社法/本文/第499条.md|第四百九十九条]]第一項の期間を不当に定めたとき。[[laws/内航海運組合法/本文/第55条.md|第五十五条]]（[[laws/内航海運組合法/本文/第58条.md|第五十八条]]において準用する場合を含む。）において準用する会社法[[laws/会社法/本文/第500条.md|第五百条]]第一項の規定に違反して債務の弁済をしたとき。[[laws/内航海運組合法/本文/第55条.md|第五十五条]]（[[laws/内航海運組合法/本文/第58条.md|第五十八条]]において準用する場合を含む。）において準用する会社法[[laws/会社法/本文/第502条.md|第五百二条]]の規定に違反して海運組合又は連合会の財産を処分したとき。

- 一 この法律の規定に基づいて海運組合又は連合会が行うことができる事業以外の事業を当該の海運組合又は連合会の事業として行つたとき。

- 六 [[laws/内航海運組合法/本文/第25条.md|第二十五条]]第二項後段又は[[laws/内航海運組合法/本文/第40条.md|第四十条]]第四項（これらの規定を[[laws/内航海運組合法/本文/第58条.md|第五十八条]]において準用する場合を含む。）の規定に違反したとき。
- 七 [[laws/内航海運組合法/本文/第27条.md|第二十七条]]第七項、[[laws/内航海運組合法/本文/第34条.md|第三十四条]]第六項（[[laws/内航海運組合法/本文/第55条.md|第五十五条]]において準用する場合を含む。）若しくは[[laws/内航海運組合法/本文/第49条の3.md|第四十九条の三]]（これらの規定を[[laws/内航海運組合法/本文/第58条.md|第五十八条]]において準用する場合を含む。）の規定又は[[laws/内航海運組合法/本文/第55条.md|第五十五条]]（[[laws/内航海運組合法/本文/第58条.md|第五十八条]]において準用する場合を含む。）において準用する会社法[[laws/会社法/本文/第492条.md|第四百九十二条]]第一項の規定に違反して議事録、財産目録若しくは貸借対照表を作成せず、又はこれらの書類に記載すべき事項を記載せず、若しくは虚偽の記載をしたとき。

- 九 [[laws/内航海運組合法/本文/第36条.md|第三十六条]]第一項（[[laws/内航海運組合法/本文/第58条.md|第五十八条]]において準用する場合を含む。）の規定に違反して理事又は職員を兼ねたとき。

- 十五 [[laws/内航海運組合法/本文/第55条.md|第五十五条]]（[[laws/内航海運組合法/本文/第58条.md|第五十八条]]において準用する場合を含む。）において準用する会社法[[laws/会社法/本文/第499条.md|第四百九十九条]]第一項の規定による公告を怠り、又は虚偽の公告をしたとき。
