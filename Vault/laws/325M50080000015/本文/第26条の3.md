# 第二十六条の三 （許可記録）

## 
許可記録（法[[laws/325M50080000015/無線局免許手続規則_law.md|第百条]]第五項において準用する法[[laws/325M50080000015/本文/第14条.md|第十四条]]第一項の規定により作成された電磁的記録をいう。以下同じ。）には、次に掲げる事項を記録する。許可の年月日及び許可の番号設置者（法[[laws/325M50080000015/無線局免許手続規則_law.md|第百条]]第一項の許可を受けた者をいう。以下同じ。）の氏名又は名称及び住所設備の種別設置の目的設備の設置場所高周波電流を通ずる線路の種別及び区間

- 一 許可の年月日及び許可の番号
- 二 設置者（法[[laws/325M50080000015/無線局免許手続規則_law.md|第百条]]第一項の許可を受けた者をいう。以下同じ。）の氏名又は名称及び住所
- 三 設備の種別
- 四 設置の目的
- 五 設備の設置場所
- 六 高周波電流を通ずる線路の種別及び区間
