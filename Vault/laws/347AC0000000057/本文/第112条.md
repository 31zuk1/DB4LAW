# 第百十二条 （手数料）

## 
次の者は、政令で定めるところにより、手数料を国（指定試験機関が行う免許試験を受けようとする者にあつては指定試験機関、指定コンサルタント試験機関が行う労働安全コンサルタント試験又は労働衛生コンサルタント試験を受けようとする者にあつては指定コンサルタント試験機関、指定登録機関が行う登録を受けようとする者にあつては指定登録機関）に納付しなければならない。免許を受けようとする者[[laws/347AC0000000057/本文/第14条.md|第十四条]]、[[laws/347AC0000000057/本文/第61条.md|第六十一条]]第一項又は[[laws/347AC0000000057/本文/第75条.md|第七十五条]]第三項の登録の更新を受けようとする者技能講習（登録教習機関が行うものを除く。）を受けようとする者[[laws/347AC0000000057/本文/第37条.md|第三十七条]]第一項の許可を受けようとする者[[laws/347AC0000000057/本文/第38条.md|第三十八条]]の検査（登録製造時等検査機関が行うものを除く。）を受けようとする者[[laws/347AC0000000057/本文/第38条.md|第三十八条]]第一項、[[laws/347AC0000000057/本文/第41条.md|第四十一条]]第二項、[[laws/347AC0000000057/本文/第44条.md|第四十四条]]第一項若しくは[[laws/347AC0000000057/本文/第44条の2.md|第四十四条の二]]第一項の登録又はその更新を受けようとする者検査証の再交付又は書替え（登録製造時等検査機関が行うものを除く。）を受けようとする者性能検査（登録性能検査機関が行うものを除く。）を受けようとする者個別検定（登録個別検定機関が行うものを除く。）を受けようとする者型式検定（登録型式検定機関が行うものを除く。）を受けようとする者[[laws/347AC0000000057/本文/第56条.md|第五十六条]]第一項の許可を受けようとする者[[laws/347AC0000000057/本文/第72条.md|第七十二条]]第一項の免許証の再交付又は書替えを受けようとする者免許の有効期間の更新を受けようとする者免許試験を受けようとする者労働安全コンサルタント試験又は労働衛生コンサルタント試験を受けようとする者[[laws/347AC0000000057/本文/第84条.md|第八十四条]]第一項の登録を受けようとする者

- 一 免許を受けようとする者
- 一の二 [[laws/347AC0000000057/本文/第14条.md|第十四条]]、[[laws/347AC0000000057/本文/第61条.md|第六十一条]]第一項又は[[laws/347AC0000000057/本文/第75条.md|第七十五条]]第三項の登録の更新を受けようとする者
- 二 技能講習（登録教習機関が行うものを除く。）を受けようとする者
- 三 [[laws/347AC0000000057/本文/第37条.md|第三十七条]]第一項の許可を受けようとする者
- 四 [[laws/347AC0000000057/本文/第38条.md|第三十八条]]の検査（登録製造時等検査機関が行うものを除く。）を受けようとする者
- 四の二 [[laws/347AC0000000057/本文/第38条.md|第三十八条]]第一項、[[laws/347AC0000000057/本文/第41条.md|第四十一条]]第二項、[[laws/347AC0000000057/本文/第44条.md|第四十四条]]第一項若しくは[[laws/347AC0000000057/本文/第44条の2.md|第四十四条の二]]第一項の登録又はその更新を受けようとする者
- 五 検査証の再交付又は書替え（登録製造時等検査機関が行うものを除く。）を受けようとする者
- 六 性能検査（登録性能検査機関が行うものを除く。）を受けようとする者
- 七 個別検定（登録個別検定機関が行うものを除く。）を受けようとする者
- 七の二 型式検定（登録型式検定機関が行うものを除く。）を受けようとする者
- 八 [[laws/347AC0000000057/本文/第56条.md|第五十六条]]第一項の許可を受けようとする者
- 九 [[laws/347AC0000000057/本文/第72条.md|第七十二条]]第一項の免許証の再交付又は書替えを受けようとする者
- 十 免許の有効期間の更新を受けようとする者
- 十一 免許試験を受けようとする者
- 十二 労働安全コンサルタント試験又は労働衛生コンサルタント試験を受けようとする者
- 十三 [[laws/347AC0000000057/本文/第84条.md|第八十四条]]第一項の登録を受けようとする者
## ２
前項の規定により指定試験機関、指定コンサルタント試験機関又は指定登録機関に納められた手数料は、それぞれ、指定試験機関、指定コンサルタント試験機関又は指定登録機関の収入とする。
