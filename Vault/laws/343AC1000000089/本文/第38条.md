# 第三十八条 

## 
次の各号のいずれかに該当する場合には、社会保険労務士法人の社員若しくは清算人又は社会保険労務士会若しくは連合会の役員は、三十万円以下の過料に処する。この法律に基づく政令の規定に違反して登記をすることを怠つたとき。[[laws/343AC1000000089/本文/第25条の23.md|第二十五条の二十三]]の二第二項又は第五項の規定に違反して合併をしたとき。[[laws/343AC1000000089/本文/第25条の23.md|第二十五条の二十三]]の二第六項において準用する会社法[[laws/417AC0000000086/本文/第941条.md|第九百四十一条]]の規定に違反して同条の調査を求めなかつたとき。定款又は[[laws/343AC1000000089/本文/第25条の25.md|第二十五条の二十五]]第一項において準用する会社法[[laws/417AC0000000086/本文/第615条.md|第六百十五条]]第一項の会計帳簿若しくは[[laws/417AC0000000086/会社法_law.md|第二十五条の二十五]]第一項において準用する同法第六百十七条第一項若しくは第二項の貸借対照表に記載し、若しくは記録すべき事項を記載せず、若しくは記録せず、又は虚偽の記載若しくは記録をしたとき。[[laws/343AC1000000089/本文/第25条の25.md|第二十五条の二十五]]第二項において準用する会社法[[laws/417AC0000000086/本文/第656条.md|第六百五十六条]]第一項の規定に違反して破産手続開始の申立てを怠つたとき。[[laws/343AC1000000089/本文/第25条の25.md|第二十五条の二十五]]第二項において準用する会社法[[laws/417AC0000000086/本文/第664条.md|第六百六十四条]]の規定に違反して財産を分配したとき。[[laws/343AC1000000089/本文/第25条の25.md|第二十五条の二十五]]第二項において準用する会社法[[laws/417AC0000000086/本文/第670条.md|第六百七十条]]第二項又は第五項の規定に違反して財産を処分したとき。

- 一 この法律に基づく政令の規定に違反して登記をすることを怠つたとき。
- 二 [[laws/343AC1000000089/本文/第25条の23.md|第二十五条の二十三]]の二第二項又は第五項の規定に違反して合併をしたとき。
- 三 [[laws/343AC1000000089/本文/第25条の23.md|第二十五条の二十三]]の二第六項において準用する会社法[[laws/417AC0000000086/本文/第941条.md|第九百四十一条]]の規定に違反して同条の調査を求めなかつたとき。
- 四 定款又は[[laws/343AC1000000089/本文/第25条の25.md|第二十五条の二十五]]第一項において準用する会社法[[laws/417AC0000000086/本文/第615条.md|第六百十五条]]第一項の会計帳簿若しくは[[laws/417AC0000000086/会社法_law.md|第二十五条の二十五]]第一項において準用する同法第六百十七条第一項若しくは第二項の貸借対照表に記載し、若しくは記録すべき事項を記載せず、若しくは記録せず、又は虚偽の記載若しくは記録をしたとき。
- 五 [[laws/343AC1000000089/本文/第25条の25.md|第二十五条の二十五]]第二項において準用する会社法[[laws/417AC0000000086/本文/第656条.md|第六百五十六条]]第一項の規定に違反して破産手続開始の申立てを怠つたとき。
- 六 [[laws/343AC1000000089/本文/第25条の25.md|第二十五条の二十五]]第二項において準用する会社法[[laws/417AC0000000086/本文/第664条.md|第六百六十四条]]の規定に違反して財産を分配したとき。
- 七 [[laws/343AC1000000089/本文/第25条の25.md|第二十五条の二十五]]第二項において準用する会社法[[laws/417AC0000000086/本文/第670条.md|第六百七十条]]第二項又は第五項の規定に違反して財産を処分したとき。
