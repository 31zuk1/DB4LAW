# 第三条 （本人確認書類の範囲等に関する経過措置）

## 
国民年金手帳（年金制度の機能強化のための国民年金法等の一部を改正する法律（令和二年法律第四十号）第二条の規定による改正前の国民年金法（昭和三十四年法律第百四十一号）第十三条第一項に規定する国民年金手帳をいう。）が年金制度の機能強化のための国民年金法等の一部を改正する法律の施行に伴う厚生労働省関係省令の整備に関する省令（令和三年厚生労働省令第百十五号）附則第六条第一項の規定により同項に規定する書類とみなされる間における消費税法施行規則[[laws/消費税法施行規則/本文/第15条の7.md|第十五条の七]]第一項の規定の適用については、同項第一号中「いずれかの書類」とあるのは「いずれかの書類又は年金制度の機能強化のための国民年金法等の一部を改正する法律（令和二年法律第四十号）第二条（国民年金法の一部改正）の規定による改正前の国民年金法第十三条第一項（国民年金手帳）に規定する国民年金手帳」と、同項第二号中「又はリに掲げるいずれかの書類」とあるのは「若しくはリに掲げるいずれかの書類又は年金制度の機能強化のための国民年金法等の一部を改正する法律第二条の規定による改正前の国民年金法第十三条第一項に規定する国民年金手帳」とする。
