# 第一条 （定義）

## 
この命令において、次の各号に掲げる用語の意義は、当該各号に定めるところによる。社債等社債、株式等の振替に関する法律（平成十三年法律第七十五号。以下「法」という。）[[laws/社債、株式等の振替に関する法律/本文/第2条.md|第二条]]第一項に規定する社債等のうち同項第二号に掲げるもの以外のものをいう。振替機関法[[laws/一般振替機関の監督に関する命令/本文/第2条.md|第二条]]第二項に規定する振替機関をいう。一般振替機関振替機関のうちその業務規程において国債を取り扱わないこととしているものをいう。加入者法[[laws/一般振替機関の監督に関する命令/本文/第2条.md|第二条]]第三項に規定する加入者をいう。口座管理機関法[[laws/一般振替機関の監督に関する命令/本文/第2条.md|第二条]]第四項に規定する口座管理機関をいう。振替業法[[laws/一般振替機関の監督に関する命令/本文/第3条.md|第三条]]第一項に規定する振替業をいう。業務規程法[[laws/一般振替機関の監督に関する命令/本文/第3条.md|第三条]]第一項第五号に規定する業務規程をいう。機関口座法[[laws/一般振替機関の監督に関する命令/本文/第12条.md|第十二条]]第二項に規定する機関口座をいう。特定合併法[[laws/一般振替機関の監督に関する命令/本文/第25条.md|第二十五条]]第一項に規定する特定合併をいう。特定合併後の振替機関法[[laws/一般振替機関の監督に関する命令/本文/第25条.md|第二十五条]]第二項に規定する特定合併後の振替機関をいう。新設分割法[[laws/一般振替機関の監督に関する命令/本文/第27条.md|第二十七条]]第一項に規定する新設分割をいう。設立会社法[[laws/会社法/本文/第27条.md|第二十七条]]第二項に規定する設立会社をいう。吸収分割法[[laws/一般振替機関の監督に関する命令/本文/第29条.md|第二十九条]]第一項に規定する吸収分割をいう。承継会社法[[laws/会社法/本文/第29条.md|第二十九条]]第二項に規定する承継会社をいう。事業譲渡法[[laws/一般振替機関の監督に関する命令/本文/第31条.md|第三十一条]]第一項に規定する事業譲渡をいう。譲受会社法[[laws/会社法/本文/第31条.md|第三十一条]]第二項に規定する譲受会社をいう。加入者集会法[[laws/一般振替機関の監督に関する命令/本文/第33条.md|第三十三条]]に規定する加入者集会をいう。短期社債法[[laws/一般振替機関の監督に関する命令/本文/第66条.md|第六十六条]]第一号に規定する短期社債をいう。

- 一 社債等社債、株式等の振替に関する法律（平成十三年法律第七十五号。以下「法」という。）[[laws/社債、株式等の振替に関する法律/本文/第2条.md|第二条]]第一項に規定する社債等のうち同項第二号に掲げるもの以外のものをいう。
- 二 振替機関法[[laws/一般振替機関の監督に関する命令/本文/第2条.md|第二条]]第二項に規定する振替機関をいう。
- 三 一般振替機関振替機関のうちその業務規程において国債を取り扱わないこととしているものをいう。
- 四 加入者法[[laws/一般振替機関の監督に関する命令/本文/第2条.md|第二条]]第三項に規定する加入者をいう。
- 五 口座管理機関法[[laws/一般振替機関の監督に関する命令/本文/第2条.md|第二条]]第四項に規定する口座管理機関をいう。
- 六 振替業法[[laws/一般振替機関の監督に関する命令/本文/第3条.md|第三条]]第一項に規定する振替業をいう。
- 七 業務規程法[[laws/一般振替機関の監督に関する命令/本文/第3条.md|第三条]]第一項第五号に規定する業務規程をいう。
- 八 機関口座法[[laws/一般振替機関の監督に関する命令/本文/第12条.md|第十二条]]第二項に規定する機関口座をいう。
- 九 特定合併法[[laws/一般振替機関の監督に関する命令/本文/第25条.md|第二十五条]]第一項に規定する特定合併をいう。
- 十 特定合併後の振替機関法[[laws/一般振替機関の監督に関する命令/本文/第25条.md|第二十五条]]第二項に規定する特定合併後の振替機関をいう。
- 十一 新設分割法[[laws/一般振替機関の監督に関する命令/本文/第27条.md|第二十七条]]第一項に規定する新設分割をいう。
- 十二 設立会社法[[laws/会社法/本文/第27条.md|第二十七条]]第二項に規定する設立会社をいう。
- 十三 吸収分割法[[laws/一般振替機関の監督に関する命令/本文/第29条.md|第二十九条]]第一項に規定する吸収分割をいう。
- 十四 承継会社法[[laws/会社法/本文/第29条.md|第二十九条]]第二項に規定する承継会社をいう。
- 十五 事業譲渡法[[laws/一般振替機関の監督に関する命令/本文/第31条.md|第三十一条]]第一項に規定する事業譲渡をいう。
- 十六 譲受会社法[[laws/会社法/本文/第31条.md|第三十一条]]第二項に規定する譲受会社をいう。
- 十七 加入者集会法[[laws/一般振替機関の監督に関する命令/本文/第33条.md|第三十三条]]に規定する加入者集会をいう。
- 十八 短期社債法[[laws/一般振替機関の監督に関する命令/本文/第66条.md|第六十六条]]第一号に規定する短期社債をいう。
