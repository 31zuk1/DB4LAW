# 第三条の三 

## 
日本銀行歳入代理店は、預託金規則[[laws/日本銀行の歳入金等の受入に関する特別取扱手続/本文/第8条の2.md|第八条の二]]第三項の規定により財政融資資金預託金の担当者から現金の払込みを受けたときは、これを領収して、領収済通知情報については財務省理財局長に、収納に係る記録については日本銀行本店に、送信しなければならない。この場合において、日本銀行歳入代理店は、領収証書を払込みを行つた財政融資資金預託金の担当者に交付することを要しない。

## 
日本銀行歳入代理店は、管理運用規則[[laws/日本銀行の歳入金等の受入に関する特別取扱手続/本文/第41条の2.md|第四十一条の二]]第三項及び[[laws/日本銀行の歳入金等の受入に関する特別取扱手続/本文/第42条の5.md|第四十二条の五]]第三項の規定により法人等又は地方公共団体から現金の払込みを受けたときは、これを領収して、領収済通知情報については財務省理財局長に、収納に係る記録については日本銀行本店に、送信しなければならない。この場合において、日本銀行歳入代理店は、領収証書を払込みを行つた法人等又は地方公共団体に交付することを要しない。
