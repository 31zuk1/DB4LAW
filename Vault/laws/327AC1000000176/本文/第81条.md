# 第八十一条 

## 
次の各号のいずれかに該当する者は、六月以下の拘禁刑若しくは百万円以下の罰金に処し、又はこれを併科する。[[laws/327AC1000000176/本文/第25条.md|第二十五条]]第五項（[[laws/327AC1000000176/本文/第26条.md|第二十六条]]第二項において準用する場合を含む。）、[[laws/327AC1000000176/本文/第32条.md|第三十二条]]又は[[laws/327AC1000000176/本文/第44条.md|第四十四条]]の規定に違反した者[[laws/327AC1000000176/本文/第47条.md|第四十七条]]の規定に違反して同条第三号に掲げる行為をした者

- 一 [[laws/327AC1000000176/本文/第25条.md|第二十五条]]第五項（[[laws/327AC1000000176/本文/第26条.md|第二十六条]]第二項において準用する場合を含む。）、[[laws/327AC1000000176/本文/第32条.md|第三十二条]]又は[[laws/327AC1000000176/本文/第44条.md|第四十四条]]の規定に違反した者
- 二 [[laws/327AC1000000176/本文/第47条.md|第四十七条]]の規定に違反して同条第三号に掲げる行為をした者
