# 第三条の三 （財産形成住宅貯蓄の利子所得等が非課税とされない場合から除かれる利子所得等）

## 
施行令[[laws/332M50000040015/租税特別措置法施行規則_law.md|第二条の八]]第一号に規定する財務省令で定める場合は、[[laws/332M50000040015/本文/第3条の8.md|第三条の八]]に定める預託金につき法[[laws/332M50000040015/本文/第4条の2.md|第四条の二]]第一項に規定する財産形成非課税住宅貯蓄申込書の提出をしなかつた場合とする。
