# 第三条の四 （油）

## 
法[[laws/水質汚濁防止法施行令/本文/第2条.md|第二条]]第五項の政令で定める油は、次に掲げる油とする。原油重油潤滑油軽油灯油揮発油動植物油

- 一 原油
- 二 重油
- 三 潤滑油
- 四 軽油
- 五 灯油
- 六 揮発油
- 七 動植物油
