# 第一条 （承継国債の告示）

## 
財務大臣は、本州四国連絡橋公団の債務の負担の軽減を図るために平成十五年度において緊急に講ずべき特別措置に関する法律[[laws/政府が承継した本州四国連絡橋公団債務に係る国債の取扱い等に関する省令/本文/第2条.md|第二条]]第一項の規定により、政府が本州四国連絡橋公団の債務を承継したときは、その承継した債務に係る国債（以下「承継国債」という。）について、遅滞なく次に掲げる事項を告示するものとする。名称及び記号額面総額額面金額の種類利率利子支払期償還期限償還金額その他必要な事項

- 一 名称及び記号
- 二 額面総額
- 三 額面金額の種類
- 四 利率
- 五 利子支払期
- 六 償還期限
- 七 償還金額
- 八 その他必要な事項
