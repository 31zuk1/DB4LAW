# 第六十四条の三 

## 
出願公開の請求をしようとする特許出願人は、次に掲げる事項を記載した請求書を特許庁長官に提出しなければならない。請求人の氏名又は名称及び住所又は居所出願公開の請求に係る特許出願の表示

- 一 請求人の氏名又は名称及び住所又は居所
- 二 出願公開の請求に係る特許出願の表示
