# 第百五条の三 （準用）

## 
[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第8条.md|第八条]]から[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第17条.md|第十七条]]まで、[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第19条.md|第十九条]]、[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第21条.md|第二十一条]]、[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第26条.md|第二十六条]]、[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第27条.md|第二十七条]]、[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第30条の2.md|第三十条の二]]、[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第32条.md|第三十二条]]から[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第34条.md|第三十四条]]まで、[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第35条.md|第三十五条]]、[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第36条.md|第三十六条]]、[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第37条の2.md|第三十七条の二]]、[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第38条.md|第三十八条]]、[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第52条.md|第五十二条]]、[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第92条.md|第九十二条]]、[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第94条.md|第九十四条]]及び[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第95条.md|第九十五条]]第四項並びに前節（[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第105条.md|第百五条]]を除く。）の規定は、共生型通所介護の事業について準用する。この場合において、[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第8条.md|第八条]]第一項中「[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第29条.md|第二十九条]]に規定する運営規程」とあるのは「運営規程（[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第100条.md|第百条]]に規定する運営規程をいう。[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第32条.md|第三十二条]]第一項において同じ。）」と、「訪問介護員等」とあるのは「共生型通所介護の提供に当たる従業者（以下「共生型通所介護従業者」という。）」と、[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第27条.md|第二十七条]]、[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第30条の2.md|第三十条の二]]第二項、[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第32条.md|第三十二条]]第一項並びに[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第37条の2.md|第三十七条の二]]第一号及び第三号中「訪問介護員等」とあるのは「共生型通所介護従業者」と、[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第95条.md|第九十五条]]第四項中「前項ただし書の場合（指定通所介護事業者が第一項に掲げる設備を利用し、夜間及び深夜に指定通所介護以外のサービスを提供する場合に限る。）」とあるのは「共生型通所介護事業者が共生型通所介護事業所の設備を利用し、夜間及び深夜に共生型通所介護以外のサービスを提供する場合」と、[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第98条.md|第九十八条]]第二号、[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第99条.md|第九十九条]]第五項、[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第101条.md|第百一条]]第三項及び第四項並びに[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第104条.md|第百四条]]第二項第一号及び第三号中「通所介護従業者」とあるのは「共生型通所介護従業者」と、[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第104条の4.md|第百四条の四]]第二項第二号中「次条において準用する[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第19条.md|第十九条]]第二項」とあるのは「[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第19条.md|第十九条]]第二項」と、同項第四号中「次条において準用する[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第26条.md|第二十六条]]」とあるのは「[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第26条.md|第二十六条]]」と、同項第五号中「次条において準用する[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第36条.md|第三十六条]]第二項」とあるのは「[[laws/指定居宅サービス等の事業の人員、設備及び運営に関する基準/本文/第36条.md|第三十六条]]第二項」と読み替えるものとする。
