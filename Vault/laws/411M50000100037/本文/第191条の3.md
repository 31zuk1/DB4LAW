# 第百九十一条の三 （記録の整備）

## 
指定特定施設入居者生活介護事業者は、従業者、設備、備品及び会計に関する諸記録を整備しておかなければならない。

## ２
指定特定施設入居者生活介護事業者は、利用者に対する指定特定施設入居者生活介護の提供に関する次の各号に掲げる記録を整備し、その完結の日から二年間保存しなければならない。特定施設サービス計画[[laws/411M50000100037/本文/第181条.md|第百八十一条]]第二項の規定による提供した具体的なサービスの内容等の記録[[laws/411M50000100037/本文/第183条.md|第百八十三条]]第五項の規定による身体的拘束等の態様及び時間、その際の利用者の心身の状況並びに緊急やむを得ない理由の記録[[laws/411M50000100037/本文/第190条.md|第百九十条]]第三項の規定による結果等の記録次条において準用する[[laws/411M50000100037/本文/第26条.md|第二十六条]]の規定による市町村への通知に係る記録次条において準用する[[laws/411M50000100037/本文/第36条.md|第三十六条]]第二項の規定による苦情の内容等の記録次条において準用する[[laws/411M50000100037/本文/第37条.md|第三十七条]]第二項の規定による事故の状況及び事故に際して採った処置についての記録

- 一 特定施設サービス計画
- 二 [[laws/411M50000100037/本文/第181条.md|第百八十一条]]第二項の規定による提供した具体的なサービスの内容等の記録
- 三 [[laws/411M50000100037/本文/第183条.md|第百八十三条]]第五項の規定による身体的拘束等の態様及び時間、その際の利用者の心身の状況並びに緊急やむを得ない理由の記録
- 四 [[laws/411M50000100037/本文/第190条.md|第百九十条]]第三項の規定による結果等の記録
- 五 次条において準用する[[laws/411M50000100037/本文/第26条.md|第二十六条]]の規定による市町村への通知に係る記録
- 六 次条において準用する[[laws/411M50000100037/本文/第36条.md|第三十六条]]第二項の規定による苦情の内容等の記録
- 七 次条において準用する[[laws/411M50000100037/本文/第37条.md|第三十七条]]第二項の規定による事故の状況及び事故に際して採った処置についての記録
