# 第三条の三 （特定配当等に係る予定納税額減額承認申請書の記載事項）

## 
法[[laws/租税条約等の実施に伴う所得税法、法人税法及び地方税法の特例等に関する法律の施行に関する省令/本文/第3条の2.md|第三条の二]]第十六項後段の規定の適用がある場合における所得税法施行規則[[laws/租税条約等の実施に伴う所得税法、法人税法及び地方税法の特例等に関する法律の施行に関する省令/本文/第46条.md|第四十六条]]第二号の規定の適用については、同号中「の総所得金額」とあるのは「の総所得金額、租税条約等の実施に伴う所得税法、法人税法及び地方税法の特例等に関する法律[[laws/租税条約等の実施に伴う所得税法、法人税法及び地方税法の特例等に関する法律の施行に関する省令/本文/第3条の2.md|第三条の二]]第十六項（特定利子に係る分離課税）に規定する特定利子に係る利子所得の金額」と、「課税総所得金額」とあるのは「課税総所得金額、当該特定利子に係る利子所得の金額（同条第十七項第三号の規定により読み替えられた法[[laws/租税条約等の実施に伴う所得税法、法人税法及び地方税法の特例等に関する法律の施行に関する省令/本文/第72条.md|第七十二条]]から[[laws/租税条約等の実施に伴う所得税法、法人税法及び地方税法の特例等に関する法律の施行に関する省令/本文/第87条.md|第八十七条]]まで（雑損控除等）の規定の適用がある場合には、その適用後の金額）」とする。
