# 第三条の三 （港湾施設の公示）

## 
法[[laws/港湾法施行規則/本文/第12条.md|第十二条]]第五項の規定により公示しなければならない事項は、港湾施設の種類、位置、数量及び能力とする。

## ２
前項の公示しなければならない事項のうち図面により表示することができるものは、図面により表示するものとする。
