# 第八十一条 （都市局に置く課等）

## 
都市局に、次の九課及び参事官一人を置く。総務課都市環境課国際・デジタル政策課都市安全課まちづくり推進課都市計画課市街地整備課街路交通施設課公園緑地・景観課
