# 第五条 （ダム使用権設定前の多目的ダムの利用の許可の申請）

## 
法[[laws/332AC0000000035/本文/第13条.md|第十三条]]の規定による許可を受けようとする者は、次の各号に掲げる事項を記載した申請書を国土交通大臣に提出しなければならない。ダム使用権の設定を受ける前に流水を特定用途（法[[laws/332M50004000018/本文/第2条.md|第二条]]第一項に規定する特定用途をいう。以下同じ。）に供する理由流水を特定用途に供しようとする時期

- 一 ダム使用権の設定を受ける前に流水を特定用途（法[[laws/332M50004000018/本文/第2条.md|第二条]]第一項に規定する特定用途をいう。以下同じ。）に供する理由
- 二 流水を特定用途に供しようとする時期
