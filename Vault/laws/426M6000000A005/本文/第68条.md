# 第六十八条 

## 
法別表百二十七の項の主務省令で定める事務は、次のとおりとする。子ども・子育て支援法（平成二十四年法律第六十五号）第十条の九第一項の妊婦給付認定の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務子ども・子育て支援法[[laws/426M6000000A005/本文/第10条の10.md|第十条の十]]の妊婦給付認定の取消しに関する事務子ども・子育て支援法[[laws/426M6000000A005/本文/第10条の12.md|第十条の十二]]第一項の妊婦支援給付金の支給に関する事務子ども・子育て支援法[[laws/426M6000000A005/行政手続における特定の個人を識別するため_law.md|第十条の十三]]第一項の届出の受理、その届出に係る事実についての審査又はその届出に対する応答に関する事務子ども・子育て支援法[[laws/426M6000000A005/行政手続における特定の個人を識別するため_law.md|第十条の十三]]第二項の情報の提供の求めに関する事務子ども・子育て支援法[[laws/426M6000000A005/本文/第16条.md|第十六条]]（[[laws/426M6000000A005/本文/第30条の3.md|第三十条の三]]の規定により準用する場合を含む。）の資料の提供等の求めに関する事務子ども・子育て支援法[[laws/426M6000000A005/本文/第20条.md|第二十条]]第一項の教育・保育給付認定若しくは同法第二十三条第一項の教育・保育給付認定の変更の認定の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務子ども・子育て支援法による支給認定証に関する事務子ども・子育て支援法[[laws/426M6000000A005/本文/第22条.md|第二十二条]]若しくは子ども・子育て支援法施行規則（平成二十六年内閣府令第四十四号）[[laws/426M6000000A005/本文/第15条.md|第十五条]]第一項の届出の受理、その届出に係る事実についての審査又はその届出に対する応答に関する事務子ども・子育て支援法[[laws/426M6000000A005/本文/第23条.md|第二十三条]]第四項の職権による教育・保育給付認定の変更の認定に関する事務子ども・子育て支援法[[laws/426M6000000A005/本文/第24条.md|第二十四条]]第一項の教育・保育給付認定の取消しに関する事務子ども・子育て支援法[[laws/426M6000000A005/本文/第27条.md|第二十七条]]第一項、[[laws/426M6000000A005/本文/第28条.md|第二十八条]]第一項、[[laws/426M6000000A005/本文/第29条.md|第二十九条]]第一項又は[[laws/426M6000000A005/本文/第30条.md|第三十条]]第一項の子どものための教育・保育給付に係る支給に関する事務子ども・子育て支援法[[laws/426M6000000A005/行政手続における特定の個人を識別するため_law.md|第三十条の五]]第一項の施設等利用給付認定若しくは同法第三十条の八第一項の施設等利用給付認定の変更の認定の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務子ども・子育て支援法[[laws/426M6000000A005/行政手続における特定の個人を識別するため_law.md|第三十条の五]]第七項の規定により教育・保育給付認定保護者が受けたものとみなされる施設等利用給付認定に係る事実についての審査に関する事務子ども・子育て支援法[[laws/426M6000000A005/行政手続における特定の個人を識別するため_law.md|第三十条の七]]若しくは子ども・子育て支援法施行規則[[laws/426M6000000A005/行政手続における特定の個人を識別するため_law.md|第二十八条の十二]]第一項の届出の受理、その届出に係る事実についての審査又はその届出に対する応答に関する事務子ども・子育て支援法[[laws/426M6000000A005/行政手続における特定の個人を識別するため_law.md|第三十条の八]]第四項の職権による施設等利用給付認定の変更の認定に関する事務子ども・子育て支援法[[laws/426M6000000A005/行政手続における特定の個人を識別するため_law.md|第三十条の九]]第一項の施設等利用給付認定の取消しに関する事務子ども・子育て支援法[[laws/426M6000000A005/行政手続における特定の個人を識別するため_law.md|第三十条の十一]]の子育てのための施設等利用給付に係る支給に関する事務子ども・子育て支援法[[laws/426M6000000A005/本文/第59条.md|第五十九条]]の地域子ども・子育て支援事業の実施に関する事務

- 一 子ども・子育て支援法（平成二十四年法律第六十五号）第十条の九第一項の妊婦給付認定の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務
- 二 子ども・子育て支援法[[laws/426M6000000A005/本文/第10条の10.md|第十条の十]]の妊婦給付認定の取消しに関する事務
- 三 子ども・子育て支援法[[laws/426M6000000A005/本文/第10条の12.md|第十条の十二]]第一項の妊婦支援給付金の支給に関する事務
- 四 子ども・子育て支援法[[laws/426M6000000A005/行政手続における特定の個人を識別するため_law.md|第十条の十三]]第一項の届出の受理、その届出に係る事実についての審査又はその届出に対する応答に関する事務
- 五 子ども・子育て支援法[[laws/426M6000000A005/行政手続における特定の個人を識別するため_law.md|第十条の十三]]第二項の情報の提供の求めに関する事務
- 六 子ども・子育て支援法[[laws/426M6000000A005/本文/第16条.md|第十六条]]（[[laws/426M6000000A005/本文/第30条の3.md|第三十条の三]]の規定により準用する場合を含む。）の資料の提供等の求めに関する事務
- 七 子ども・子育て支援法[[laws/426M6000000A005/本文/第20条.md|第二十条]]第一項の教育・保育給付認定若しくは同法第二十三条第一項の教育・保育給付認定の変更の認定の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務
- 八 子ども・子育て支援法による支給認定証に関する事務
- 九 子ども・子育て支援法[[laws/426M6000000A005/本文/第22条.md|第二十二条]]若しくは子ども・子育て支援法施行規則（平成二十六年内閣府令第四十四号）[[laws/426M6000000A005/本文/第15条.md|第十五条]]第一項の届出の受理、その届出に係る事実についての審査又はその届出に対する応答に関する事務
- 十 子ども・子育て支援法[[laws/426M6000000A005/本文/第23条.md|第二十三条]]第四項の職権による教育・保育給付認定の変更の認定に関する事務
- 十一 子ども・子育て支援法[[laws/426M6000000A005/本文/第24条.md|第二十四条]]第一項の教育・保育給付認定の取消しに関する事務
- 十二 子ども・子育て支援法[[laws/426M6000000A005/本文/第27条.md|第二十七条]]第一項、[[laws/426M6000000A005/本文/第28条.md|第二十八条]]第一項、[[laws/426M6000000A005/本文/第29条.md|第二十九条]]第一項又は[[laws/426M6000000A005/本文/第30条.md|第三十条]]第一項の子どものための教育・保育給付に係る支給に関する事務
- 十三 子ども・子育て支援法[[laws/426M6000000A005/行政手続における特定の個人を識別するため_law.md|第三十条の五]]第一項の施設等利用給付認定若しくは同法第三十条の八第一項の施設等利用給付認定の変更の認定の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務
- 十四 子ども・子育て支援法[[laws/426M6000000A005/行政手続における特定の個人を識別するため_law.md|第三十条の五]]第七項の規定により教育・保育給付認定保護者が受けたものとみなされる施設等利用給付認定に係る事実についての審査に関する事務
- 十五 子ども・子育て支援法[[laws/426M6000000A005/行政手続における特定の個人を識別するため_law.md|第三十条の七]]若しくは子ども・子育て支援法施行規則[[laws/426M6000000A005/行政手続における特定の個人を識別するため_law.md|第二十八条の十二]]第一項の届出の受理、その届出に係る事実についての審査又はその届出に対する応答に関する事務
- 十六 子ども・子育て支援法[[laws/426M6000000A005/行政手続における特定の個人を識別するため_law.md|第三十条の八]]第四項の職権による施設等利用給付認定の変更の認定に関する事務
- 十七 子ども・子育て支援法[[laws/426M6000000A005/行政手続における特定の個人を識別するため_law.md|第三十条の九]]第一項の施設等利用給付認定の取消しに関する事務
- 十八 子ども・子育て支援法[[laws/426M6000000A005/行政手続における特定の個人を識別するため_law.md|第三十条の十一]]の子育てのための施設等利用給付に係る支給に関する事務
- 十九 子ども・子育て支援法[[laws/426M6000000A005/本文/第59条.md|第五十九条]]の地域子ども・子育て支援事業の実施に関する事務
