# 第二十七条の三 

## 
法別表五十四の項の主務省令で定める事務は、次のとおりとする。薬剤師法（昭和三十五年法律第百四十六号）第二条の薬剤師の免許の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務薬剤師法による薬剤師免許証に関する事務薬剤師法[[laws/426M6000000A005/本文/第8条.md|第八条]]第一項の処分又は同条第三項の再免許に関する事務薬剤師法[[laws/426M6000000A005/本文/第11条.md|第十一条]]の薬剤師国家試験の受験願書の受理、その受験願書に係る事実についての審査又はその受験願書に対する応答に関する事務薬剤師法[[laws/426M6000000A005/本文/第17条.md|第十七条]]の薬剤師国家試験の受験の停止又はその試験の無効に関する事務薬剤師法施行令（昭和三十六年政令第十三号）[[laws/426M6000000A005/本文/第5条.md|第五条]]第一項の薬剤師の登録事項の変更の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務薬剤師法施行令[[laws/426M6000000A005/本文/第6条.md|第六条]]の薬剤師の登録の消除の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務薬剤師法施行規則（昭和三十六年厚生省令第五号）[[laws/426M6000000A005/本文/第11条.md|第十一条]]の薬剤師国家試験の合格証書の交付に関する事務薬剤師法施行規則[[laws/426M6000000A005/本文/第12条.md|第十二条]]第一項の薬剤師国家試験の合格証書の再交付の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務

- 一 薬剤師法（昭和三十五年法律第百四十六号）第二条の薬剤師の免許の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務
- 二 薬剤師法による薬剤師免許証に関する事務
- 三 薬剤師法[[laws/426M6000000A005/本文/第8条.md|第八条]]第一項の処分又は同条第三項の再免許に関する事務
- 四 薬剤師法[[laws/426M6000000A005/本文/第11条.md|第十一条]]の薬剤師国家試験の受験願書の受理、その受験願書に係る事実についての審査又はその受験願書に対する応答に関する事務
- 五 薬剤師法[[laws/426M6000000A005/本文/第17条.md|第十七条]]の薬剤師国家試験の受験の停止又はその試験の無効に関する事務
- 六 薬剤師法施行令（昭和三十六年政令第十三号）[[laws/426M6000000A005/本文/第5条.md|第五条]]第一項の薬剤師の登録事項の変更の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務
- 七 薬剤師法施行令[[laws/426M6000000A005/本文/第6条.md|第六条]]の薬剤師の登録の消除の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務
- 八 薬剤師法施行規則（昭和三十六年厚生省令第五号）[[laws/426M6000000A005/本文/第11条.md|第十一条]]の薬剤師国家試験の合格証書の交付に関する事務
- 九 薬剤師法施行規則[[laws/426M6000000A005/本文/第12条.md|第十二条]]第一項の薬剤師国家試験の合格証書の再交付の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務
