# 第二十二条の二 

## 
法別表三十九の項の主務省令で定める事務は、次のとおりとする。歯科技工士法（昭和三十年法律第百六十八号）第三条の歯科技工士の免許の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務歯科技工士法による歯科技工士免許証又は歯科技工士免許証明書に関する事務歯科技工士法[[laws/行政手続における特定の個人を識別するための番号の利用等に関する法律別表の主務省令で定める事務を定める命令/本文/第8条.md|第八条]]第一項の歯科技工士の免許の取消し若しくは業務の停止又は同条第三項の再免許に関する事務歯科技工士法[[laws/行政手続における特定の個人を識別するための番号の利用等に関する法律別表の主務省令で定める事務を定める命令/本文/第11条.md|第十一条]]の歯科技工士国家試験の受験願書の受理、その受験願書に係る事実についての審査又はその受験願書に対する応答に関する事務歯科技工士法[[laws/行政手続における特定の個人を識別するための番号の利用等に関する法律別表の主務省令で定める事務を定める命令/本文/第15条.md|第十五条]]第一項（同法第十五条の六第二項の規定により読み替えて適用する場合を含む。）又は[[laws/行政手続における特定の個人を識別するための番号の利用等に関する法律別表の主務省令で定める事務を定める命令/本文/第15条の6.md|第十五条の六]]第一項の歯科技工士国家試験の受験の停止又はその試験の無効に関する事務歯科技工士法施行令（昭和三十年政令第二百二十八号）[[laws/行政手続における特定の個人を識別するための番号の利用等に関する法律別表の主務省令で定める事務を定める命令/本文/第3条.md|第三条]]第一項の歯科技工士の登録事項の変更の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務歯科技工士法施行令[[laws/行政手続における特定の個人を識別するための番号の利用等に関する法律別表の主務省令で定める事務を定める命令/本文/第4条.md|第四条]]の歯科技工士の登録の消除の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務歯科技工士法施行規則（昭和三十年厚生省令第二十三号）[[laws/行政手続における特定の個人を識別するための番号の利用等に関する法律別表の主務省令で定める事務を定める命令/本文/第9条.md|第九条]]（同令[[laws/行政手続における特定の個人を識別するための番号の利用等に関する法律別表の主務省令で定める事務を定める命令/本文/第11条の2.md|第十一条の二]]第一項の規定により読み替えて適用する場合を含む。）の歯科技工士国家試験の合格証書の交付に関する事務歯科技工士法施行規則[[laws/行政手続における特定の個人を識別するための番号の利用等に関する法律別表の主務省令で定める事務を定める命令/本文/第10条.md|第十条]]第一項（同令[[laws/行政手続における特定の個人を識別するための番号の利用等に関する法律別表の主務省令で定める事務を定める命令/本文/第11条の2.md|第十一条の二]]第一項の規定により読み替えて適用する場合を含む。）の歯科技工士国家試験の合格証明書の交付の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務

- 一 歯科技工士法（昭和三十年法律第百六十八号）第三条の歯科技工士の免許の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務
- 二 歯科技工士法による歯科技工士免許証又は歯科技工士免許証明書に関する事務
- 三 歯科技工士法[[laws/行政手続における特定の個人を識別するための番号の利用等に関する法律別表の主務省令で定める事務を定める命令/本文/第8条.md|第八条]]第一項の歯科技工士の免許の取消し若しくは業務の停止又は同条第三項の再免許に関する事務
- 四 歯科技工士法[[laws/行政手続における特定の個人を識別するための番号の利用等に関する法律別表の主務省令で定める事務を定める命令/本文/第11条.md|第十一条]]の歯科技工士国家試験の受験願書の受理、その受験願書に係る事実についての審査又はその受験願書に対する応答に関する事務
- 五 歯科技工士法[[laws/行政手続における特定の個人を識別するための番号の利用等に関する法律別表の主務省令で定める事務を定める命令/本文/第15条.md|第十五条]]第一項（同法第十五条の六第二項の規定により読み替えて適用する場合を含む。）又は[[laws/行政手続における特定の個人を識別するための番号の利用等に関する法律別表の主務省令で定める事務を定める命令/本文/第15条の6.md|第十五条の六]]第一項の歯科技工士国家試験の受験の停止又はその試験の無効に関する事務
- 六 歯科技工士法施行令（昭和三十年政令第二百二十八号）[[laws/行政手続における特定の個人を識別するための番号の利用等に関する法律別表の主務省令で定める事務を定める命令/本文/第3条.md|第三条]]第一項の歯科技工士の登録事項の変更の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務
- 七 歯科技工士法施行令[[laws/行政手続における特定の個人を識別するための番号の利用等に関する法律別表の主務省令で定める事務を定める命令/本文/第4条.md|第四条]]の歯科技工士の登録の消除の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務
- 八 歯科技工士法施行規則（昭和三十年厚生省令第二十三号）[[laws/行政手続における特定の個人を識別するための番号の利用等に関する法律別表の主務省令で定める事務を定める命令/本文/第9条.md|第九条]]（同令[[laws/行政手続における特定の個人を識別するための番号の利用等に関する法律別表の主務省令で定める事務を定める命令/本文/第11条の2.md|第十一条の二]]第一項の規定により読み替えて適用する場合を含む。）の歯科技工士国家試験の合格証書の交付に関する事務
- 九 歯科技工士法施行規則[[laws/行政手続における特定の個人を識別するための番号の利用等に関する法律別表の主務省令で定める事務を定める命令/本文/第10条.md|第十条]]第一項（同令[[laws/行政手続における特定の個人を識別するための番号の利用等に関する法律別表の主務省令で定める事務を定める命令/本文/第11条の2.md|第十一条の二]]第一項の規定により読み替えて適用する場合を含む。）の歯科技工士国家試験の合格証明書の交付の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務
