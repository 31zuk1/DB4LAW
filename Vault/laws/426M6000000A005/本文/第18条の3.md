# 第十八条の三 

## 
法別表二十九の項の主務省令で定める事務は、次のとおりとする。税理士法（昭和二十六年法律第二百三十七号）第五条第一項第五号若しくは第三項の認定の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務税理士法[[laws/426M6000000A005/本文/第6条.md|第六条]]の税理士試験の受験願書の受理、その受験願書に係る事実についての審査又はその受験願書に対する応答に関する事務税理士法[[laws/426M6000000A005/本文/第7条.md|第七条]]第一項若しくは[[laws/426M6000000A005/本文/第8条.md|第八条]]第一項の試験科目の免除の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務税理士法[[laws/426M6000000A005/本文/第9条.md|第九条]]第一項の受験手数料又は同条第二項の認定手数料の納付に関する事務税理士法[[laws/426M6000000A005/本文/第10条.md|第十条]]第一項の税理士試験の停止若しくは合格の決定の取消し又は同条第二項の認定若しくは免除の取消しに関する事務税理士法[[laws/426M6000000A005/本文/第11条.md|第十一条]]第一項の合格証書の授与又は同条第二項の基準以上の成績を得た科目の通知に関する事務

- 一 税理士法（昭和二十六年法律第二百三十七号）第五条第一項第五号若しくは第三項の認定の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務
- 二 税理士法[[laws/426M6000000A005/本文/第6条.md|第六条]]の税理士試験の受験願書の受理、その受験願書に係る事実についての審査又はその受験願書に対する応答に関する事務
- 三 税理士法[[laws/426M6000000A005/本文/第7条.md|第七条]]第一項若しくは[[laws/426M6000000A005/本文/第8条.md|第八条]]第一項の試験科目の免除の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務
- 四 税理士法[[laws/426M6000000A005/本文/第9条.md|第九条]]第一項の受験手数料又は同条第二項の認定手数料の納付に関する事務
- 五 税理士法[[laws/426M6000000A005/本文/第10条.md|第十条]]第一項の税理士試験の停止若しくは合格の決定の取消し又は同条第二項の認定若しくは免除の取消しに関する事務
- 六 税理士法[[laws/426M6000000A005/本文/第11条.md|第十一条]]第一項の合格証書の授与又は同条第二項の基準以上の成績を得た科目の通知に関する事務
