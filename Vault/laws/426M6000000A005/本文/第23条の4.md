# 第二十三条の四 

## 
法別表四十三の二の項の主務省令で定める事務は、次のとおりとする。調理師法（昭和三十三年法律第百四十七号）第三条の調理師の免許の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務調理師法[[laws/426M6000000A005/行政手続における特定の個人を識別するため_law.md|第三条の二]]第一項の調理師試験の受験願書の受理、その受験願書に係る事実についての審査又はその受験願書に対する応答に関する事務調理師法による調理師免許証に関する事務調理師法[[laws/426M6000000A005/本文/第6条.md|第六条]]の調理師の免許の取消しに関する事務調理師法施行令（昭和三十三年政令第三百三号）[[laws/426M6000000A005/本文/第11条.md|第十一条]]第一項の調理師の登録事項の変更の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務調理師法施行令[[laws/426M6000000A005/本文/第12条.md|第十二条]]の調理師の登録の消除の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務

- 一 調理師法（昭和三十三年法律第百四十七号）第三条の調理師の免許の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務
- 二 調理師法[[laws/426M6000000A005/行政手続における特定の個人を識別するため_law.md|第三条の二]]第一項の調理師試験の受験願書の受理、その受験願書に係る事実についての審査又はその受験願書に対する応答に関する事務
- 三 調理師法による調理師免許証に関する事務
- 四 調理師法[[laws/426M6000000A005/本文/第6条.md|第六条]]の調理師の免許の取消しに関する事務
- 五 調理師法施行令（昭和三十三年政令第三百三号）[[laws/426M6000000A005/本文/第11条.md|第十一条]]第一項の調理師の登録事項の変更の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務
- 六 調理師法施行令[[laws/426M6000000A005/本文/第12条.md|第十二条]]の調理師の登録の消除の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務
