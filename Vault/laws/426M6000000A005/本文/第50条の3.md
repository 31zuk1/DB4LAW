# 第五十条の三 

## 
法別表百二の項の主務省令で定める事務は、次のとおりとする。精神保健福祉士法（平成九年法律第百三十一号）第五条の精神保健福祉士試験の受験の申込みの受理、その申込みに係る事実についての審査又はその申込みに対する応答に関する事務精神保健福祉士法[[laws/426M6000000A005/本文/第8条.md|第八条]]第一項（同法第十五条第一項の規定により読み替えて適用する場合を含む。）の精神保健福祉士試験の受験の停止又はその試験の無効に関する事務精神保健福祉士法[[laws/426M6000000A005/本文/第28条.md|第二十八条]]の精神保健福祉士の登録の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務精神保健福祉士法による精神保健福祉士登録証に関する事務精神保健福祉士法[[laws/426M6000000A005/本文/第31条.md|第三十一条]]第一項（同法第三十六条第一項の規定により読み替えて適用する場合を含む。）の精神保健福祉士の登録事項の変更の届出の受理、その届出に係る事実についての審査又はその届出に対する応答に関する事務精神保健福祉士法[[laws/426M6000000A005/本文/第31条.md|第三十一条]]第二項（同法第三十六条第一項の規定により読み替えて適用する場合を含む。）の精神保健福祉士の登録の変更を証する書類の交付に関する事務精神保健福祉士法[[laws/426M6000000A005/本文/第32条.md|第三十二条]]の精神保健福祉士の登録の取消し又は名称の使用の停止に関する事務精神保健福祉士法[[laws/426M6000000A005/本文/第33条.md|第三十三条]]（同法第三十六条第一項の規定により読み替えて適用する場合を含む。）の精神保健福祉士の登録の消除に関する事務精神保健福祉士法施行規則（平成十年厚生省令第十一号）[[laws/426M6000000A005/本文/第9条.md|第九条]]の精神保健福祉士試験の合格証書の交付に関する事務精神保健福祉士法施行規則[[laws/426M6000000A005/本文/第16条.md|第十六条]]（同令[[laws/426M6000000A005/本文/第19条.md|第十九条]]の規定により読み替えて適用する場合を含む。）の精神保健福祉士の死亡等の届出の受理、その届出に係る事実についての審査又はその届出に対する応答に関する事務

- 一 精神保健福祉士法（平成九年法律第百三十一号）第五条の精神保健福祉士試験の受験の申込みの受理、その申込みに係る事実についての審査又はその申込みに対する応答に関する事務
- 二 精神保健福祉士法[[laws/426M6000000A005/本文/第8条.md|第八条]]第一項（同法第十五条第一項の規定により読み替えて適用する場合を含む。）の精神保健福祉士試験の受験の停止又はその試験の無効に関する事務
- 三 精神保健福祉士法[[laws/426M6000000A005/本文/第28条.md|第二十八条]]の精神保健福祉士の登録の申請の受理、その申請に係る事実についての審査又はその申請に対する応答に関する事務
- 四 精神保健福祉士法による精神保健福祉士登録証に関する事務
- 五 精神保健福祉士法[[laws/426M6000000A005/本文/第31条.md|第三十一条]]第一項（同法第三十六条第一項の規定により読み替えて適用する場合を含む。）の精神保健福祉士の登録事項の変更の届出の受理、その届出に係る事実についての審査又はその届出に対する応答に関する事務
- 六 精神保健福祉士法[[laws/426M6000000A005/本文/第31条.md|第三十一条]]第二項（同法第三十六条第一項の規定により読み替えて適用する場合を含む。）の精神保健福祉士の登録の変更を証する書類の交付に関する事務
- 七 精神保健福祉士法[[laws/426M6000000A005/本文/第32条.md|第三十二条]]の精神保健福祉士の登録の取消し又は名称の使用の停止に関する事務
- 八 精神保健福祉士法[[laws/426M6000000A005/本文/第33条.md|第三十三条]]（同法第三十六条第一項の規定により読み替えて適用する場合を含む。）の精神保健福祉士の登録の消除に関する事務
- 九 精神保健福祉士法施行規則（平成十年厚生省令第十一号）[[laws/426M6000000A005/本文/第9条.md|第九条]]の精神保健福祉士試験の合格証書の交付に関する事務
- 十 精神保健福祉士法施行規則[[laws/426M6000000A005/本文/第16条.md|第十六条]]（同令[[laws/426M6000000A005/本文/第19条.md|第十九条]]の規定により読み替えて適用する場合を含む。）の精神保健福祉士の死亡等の届出の受理、その届出に係る事実についての審査又はその届出に対する応答に関する事務
