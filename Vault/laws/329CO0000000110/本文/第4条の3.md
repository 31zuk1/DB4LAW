# 第四条の三 （財務大臣への権限の委任）

## 
厚生労働大臣は、法[[laws/329AC0000000115/本文/第100条の5.md|第百条の五]]第一項の規定により滞納処分等その他の処分の権限を委任する場合においては、次に掲げるものを除き、その全部を財務大臣に委任する。法[[laws/329AC0000000115/本文/第89条.md|第八十九条]]の規定によりその例によるものとされる国税徴収法（昭和三十四年法律第百四十七号）第百三十八条の規定による告知法[[laws/329AC0000000115/本文/第89条.md|第八十九条]]の規定によりその例によるものとされる国税徴収法[[laws/329CO0000000110/厚生年金保険法施行令_law.md|第百五十三条]]第一項の規定による滞納処分の執行の停止法[[laws/329AC0000000115/本文/第89条.md|第八十九条]]の規定によりその例によるものとされる国税通則法（昭和三十七年法律第六十六号）第十一条の規定による延長法[[laws/329AC0000000115/本文/第89条.md|第八十九条]]の規定によりその例によるものとされる国税通則法[[laws/329AC0000000115/本文/第36条.md|第三十六条]]第一項の規定による告知法[[laws/329AC0000000115/本文/第89条.md|第八十九条]]の規定によりその例によるものとされる国税通則法[[laws/329AC0000000115/本文/第55条.md|第五十五条]]第一項の規定による受託法[[laws/329AC0000000115/本文/第89条.md|第八十九条]]の規定によりその例によるものとされる国税通則法[[laws/329AC0000000115/本文/第63条.md|第六十三条]]の規定による免除法[[laws/329AC0000000115/本文/第89条.md|第八十九条]]の規定によりその例によるものとされる国税通則法[[laws/329CO0000000110/厚生年金保険法施行令_law.md|第百二十三条]]第一項の規定による交付前各号に掲げるもののほか、厚生労働省令で定める権限

- 一 法[[laws/329AC0000000115/本文/第89条.md|第八十九条]]の規定によりその例によるものとされる国税徴収法（昭和三十四年法律第百四十七号）第百三十八条の規定による告知
- 二 法[[laws/329AC0000000115/本文/第89条.md|第八十九条]]の規定によりその例によるものとされる国税徴収法[[laws/329CO0000000110/厚生年金保険法施行令_law.md|第百五十三条]]第一項の規定による滞納処分の執行の停止
- 三 法[[laws/329AC0000000115/本文/第89条.md|第八十九条]]の規定によりその例によるものとされる国税通則法（昭和三十七年法律第六十六号）第十一条の規定による延長
- 四 法[[laws/329AC0000000115/本文/第89条.md|第八十九条]]の規定によりその例によるものとされる国税通則法[[laws/329AC0000000115/本文/第36条.md|第三十六条]]第一項の規定による告知
- 五 法[[laws/329AC0000000115/本文/第89条.md|第八十九条]]の規定によりその例によるものとされる国税通則法[[laws/329AC0000000115/本文/第55条.md|第五十五条]]第一項の規定による受託
- 六 法[[laws/329AC0000000115/本文/第89条.md|第八十九条]]の規定によりその例によるものとされる国税通則法[[laws/329AC0000000115/本文/第63条.md|第六十三条]]の規定による免除
- 七 法[[laws/329AC0000000115/本文/第89条.md|第八十九条]]の規定によりその例によるものとされる国税通則法[[laws/329CO0000000110/厚生年金保険法施行令_law.md|第百二十三条]]第一項の規定による交付
- 八 前各号に掲げるもののほか、厚生労働省令で定める権限
