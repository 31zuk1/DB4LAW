# 第二十二条 （短期借入金の認可の申請）

## 
機構は、法[[laws/428M60000110004/外国人技能実習機構の財務及び会計に関する_law.md|第九十五条]]第一項の規定により短期借入金の借入れの認可を受けようとするとき又は同条第二項ただし書の規定により短期借入金の借換えの認可を受けようとするときは、次に掲げる事項を記載した申請書を法務大臣及び厚生労働大臣に提出しなければならない。借入れを必要とする理由借入金の額借入先借入金の利率借入金の償還の方法及び期限利息の支払の方法及び期限その他必要な事項

- 一 借入れを必要とする理由
- 二 借入金の額
- 三 借入先
- 四 借入金の利率
- 五 借入金の償還の方法及び期限
- 六 利息の支払の方法及び期限
- 七 その他必要な事項
