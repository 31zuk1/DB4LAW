# 第三条 （介護等の体験を免除する者）

## 
特例法[[laws/409M50000080040/本文/第2条.md|第二条]]第三項に規定する介護等に関する専門的知識及び技術を有する者として文部科学省令で定めるものは次の各号の一に該当する者とする。保健師助産師看護師法（昭和二十三年法律第二百三号）第七条の規定により保健師の免許を受けている者保健師助産師看護師法[[laws/409M50000080040/小学校及び中学校の教諭の普通免許状授与に_law.md|第七条]]の規定により助産師の免許を受けている者保健師助産師看護師法[[laws/409M50000080040/小学校及び中学校の教諭の普通免許状授与に_law.md|第七条]]の規定により看護師の免許を受けている者保健師助産師看護師法[[laws/409M50000080040/小学校及び中学校の教諭の普通免許状授与に_law.md|第八条]]の規定により准看護師の免許を受けている者教育職員免許法（昭和二十四年法律第百四十七号）第五条第一項の規定により特別支援学校の教員の免許を受けている者理学療法士及び作業療法士法（昭和四十年法律第百三十七号）第三条の規定により理学療法士の免許を受けている者理学療法士及び作業療法士法[[laws/409M50000080040/本文/第3条.md|第三条]]の規定により作業療法士の免許を受けている者社会福祉士及び介護福祉士法（昭和六十二年法律第三十号）第四条の規定により社会福祉士の資格を有する者社会福祉士及び介護福祉士法[[laws/409M50000080040/小学校及び中学校の教諭の普通免許状授与に_law.md|第三十九条]]の規定により介護福祉士の資格を有する者義肢装具士法（昭和六十二年法律第六十一号）第三条の規定により義肢装具士の免許を受けている者

- 一 保健師助産師看護師法（昭和二十三年法律第二百三号）第七条の規定により保健師の免許を受けている者
- 二 保健師助産師看護師法[[laws/409M50000080040/小学校及び中学校の教諭の普通免許状授与に_law.md|第七条]]の規定により助産師の免許を受けている者
- 三 保健師助産師看護師法[[laws/409M50000080040/小学校及び中学校の教諭の普通免許状授与に_law.md|第七条]]の規定により看護師の免許を受けている者
- 四 保健師助産師看護師法[[laws/409M50000080040/小学校及び中学校の教諭の普通免許状授与に_law.md|第八条]]の規定により准看護師の免許を受けている者
- 五 教育職員免許法（昭和二十四年法律第百四十七号）第五条第一項の規定により特別支援学校の教員の免許を受けている者
- 六 理学療法士及び作業療法士法（昭和四十年法律第百三十七号）第三条の規定により理学療法士の免許を受けている者
- 七 理学療法士及び作業療法士法[[laws/409M50000080040/本文/第3条.md|第三条]]の規定により作業療法士の免許を受けている者
- 八 社会福祉士及び介護福祉士法（昭和六十二年法律第三十号）第四条の規定により社会福祉士の資格を有する者
- 九 社会福祉士及び介護福祉士法[[laws/409M50000080040/小学校及び中学校の教諭の普通免許状授与に_law.md|第三十九条]]の規定により介護福祉士の資格を有する者
- 十 義肢装具士法（昭和六十二年法律第六十一号）第三条の規定により義肢装具士の免許を受けている者
## ２
特例法[[laws/409M50000080040/本文/第2条.md|第二条]]第三項に規定する身体上の障害により介護等の体験を行うことが困難な者として文部科学省令で定めるものは、身体障害者福祉法[[laws/409M50000080040/本文/第4条.md|第四条]]に規定する身体障害者のうち、同法第十五条第四項の規定により交付を受けた身体障害者手帳に、障害の程度が一級から六級である者として記載されている者とする。
