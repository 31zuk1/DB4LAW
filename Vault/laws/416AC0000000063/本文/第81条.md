# 第八十一条 （管轄違い等の部分判決後の弁論の分離）

## 
[[laws/裁判員の参加する刑事裁判に関する法律/本文/第79条.md|第七十九条]]の部分判決は、当該部分判決をした事件に係る弁論を刑事訴訟法[[laws/刑事訴訟法/本文/第313条.md|第三百十三条]]第一項の決定により分離した場合には、その決定を告知した時に、終局の判決となるものとする。
