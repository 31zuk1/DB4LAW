# 第六十三条 

## 
左の場合においては、その行為をなした金融機関の代表者、代理人、使用人その他の従業者は、これを三年以下の懲役又は三万円以下の罰金に処する。[[laws/金融機関再建整備法/本文/第13条.md|第十三条]]第一項又は[[laws/金融機関再建整備法/本文/第15条.md|第十五条]]第一項の規定による認可の申請書に虚偽の記載をなして提出したとき[[laws/金融機関再建整備法/本文/第14条.md|第十四条]]第一項、[[laws/金融機関再建整備法/本文/第19条.md|第十九条]]、[[laws/金融機関再建整備法/本文/第20条.md|第二十条]]第三項又は[[laws/金融機関再建整備法/本文/第23条.md|第二十三条]]第一項の規定に違反して認可の申請を怠り、又はその認可の申請書に虚偽の記載をなして提出したとき[[laws/金融機関再建整備法/本文/第26条.md|第二十六条]]第三項（同条第五項において準用する場合を含む。）の規定に基く命令に違反して同項に規定する対価の処分を怠り、又はその処分をなしたとき[[laws/金融機関再建整備法/本文/第26条.md|第二十六条]]第六項の規定による命令に違反したとき[[laws/金融機関再建整備法/本文/第27条.md|第二十七条]]第一項（[[laws/金融機関再建整備法/本文/第30条.md|第三十条]]第二項において準用する場合を含む。）の規定に違反して最終処理方法書の認可の申請を怠り、又は虚偽の記載をなした最終処理方法書を提出して認可の申請をなしたとき[[laws/金融機関再建整備法/本文/第27条.md|第二十七条]]第二項（[[laws/金融機関再建整備法/本文/第30条.md|第三十条]]第二項において準用する場合を含む。）の規定に違反して監査委員の承認を受けることを怠り、又は虚偽の記載をなした最終処理方法書につき監査委員の承認を受けたとき[[laws/金融機関再建整備法/本文/第29条.md|第二十九条]]（[[laws/金融機関再建整備法/本文/第30条.md|第三十条]]第二項において準用する場合を含む。）の規定に違反して最終処理方法書に定めるところによる旧勘定の最終処理を行はないとき[[laws/金融機関再建整備法/本文/第37条.md|第三十七条]]（[[laws/金融機関再建整備法/本文/第37条の8.md|第三十七条の八]]の規定により準用する場合を含む。）の規定による経理を怠り又は同条に違反してその経理をなしたとき[[laws/金融機関再建整備法/本文/第37条の2.md|第三十七条の二]]の規定による利益金の処分を怠り又は同条の規定に違反してその処分をなしたとき[[laws/金融機関再建整備法/本文/第37条の3.md|第三十七条の三]]第二項若しくは第三項（[[laws/金融機関再建整備法/本文/第38条の8.md|第三十八条の八]]第四項において準用する場合を含む。）、[[laws/金融機関再建整備法/本文/第38条の5.md|第三十八条の五]]又は[[laws/金融機関再建整備法/本文/第38条の8.md|第三十八条の八]]第二項若しくは第三項の規定による支払若しくは分配を怠り、又はこれらの規定に違反してその支払若しくは分配をなしたとき[[laws/金融機関再建整備法/本文/第37条の4.md|第三十七条の四]]（[[laws/金融機関再建整備法/本文/第37条の8.md|第三十七条の八]]の規定により準用する場合を含む。）の規定に違反して資産を処分したとき[[laws/金融機関再建整備法/本文/第38条の4.md|第三十八条の四]]の規定による経理を怠り、又は同条の規定に違反してその経理をなしたとき[[laws/金融機関再建整備法/本文/第38条の6.md|第三十八条の六]]第二項（[[laws/金融機関再建整備法/本文/第38条の7.md|第三十八条の七]]第二項において準用する場合を含む。）の規定による返済を怠り、又は同項の規定に違反してその返済をなしたとき

- 二 [[laws/金融機関再建整備法/本文/第14条.md|第十四条]]第一項、[[laws/金融機関再建整備法/本文/第19条.md|第十九条]]、[[laws/金融機関再建整備法/本文/第20条.md|第二十条]]第三項又は[[laws/金融機関再建整備法/本文/第23条.md|第二十三条]]第一項の規定に違反して認可の申請を怠り、又はその認可の申請書に虚偽の記載をなして提出したとき
- 三 [[laws/金融機関再建整備法/本文/第26条.md|第二十六条]]第三項（同条第五項において準用する場合を含む。）の規定に基く命令に違反して同項に規定する対価の処分を怠り、又はその処分をなしたとき

- 六 [[laws/金融機関再建整備法/本文/第27条.md|第二十七条]]第二項（[[laws/金融機関再建整備法/本文/第30条.md|第三十条]]第二項において準用する場合を含む。）の規定に違反して監査委員の承認を受けることを怠り、又は虚偽の記載をなした最終処理方法書につき監査委員の承認を受けたとき
- 七 [[laws/金融機関再建整備法/本文/第29条.md|第二十九条]]（[[laws/金融機関再建整備法/本文/第30条.md|第三十条]]第二項において準用する場合を含む。）の規定に違反して最終処理方法書に定めるところによる旧勘定の最終処理を行はないとき
- 八 [[laws/金融機関再建整備法/本文/第37条.md|第三十七条]]（[[laws/金融機関再建整備法/本文/第37条の8.md|第三十七条の八]]の規定により準用する場合を含む。）の規定による経理を怠り又は同条に違反してその経理をなしたとき

- 十 [[laws/金融機関再建整備法/本文/第37条の3.md|第三十七条の三]]第二項若しくは第三項（[[laws/金融機関再建整備法/本文/第38条の8.md|第三十八条の八]]第四項において準用する場合を含む。）、[[laws/金融機関再建整備法/本文/第38条の5.md|第三十八条の五]]又は[[laws/金融機関再建整備法/本文/第38条の8.md|第三十八条の八]]第二項若しくは第三項の規定による支払若しくは分配を怠り、又はこれらの規定に違反してその支払若しくは分配をなしたとき
- 十一 [[laws/金融機関再建整備法/本文/第37条の4.md|第三十七条の四]]（[[laws/金融機関再建整備法/本文/第37条の8.md|第三十七条の八]]の規定により準用する場合を含む。）の規定に違反して資産を処分したとき
- 十二 [[laws/金融機関再建整備法/本文/第38条の4.md|第三十八条の四]]の規定による経理を怠り、又は同条の規定に違反してその経理をなしたとき
- 十三 [[laws/金融機関再建整備法/本文/第38条の6.md|第三十八条の六]]第二項（[[laws/金融機関再建整備法/本文/第38条の7.md|第三十八条の七]]第二項において準用する場合を含む。）の規定による返済を怠り、又は同項の規定に違反してその返済をなしたとき
