# 第二十三条 （会社法の準用）

## 
会社法（平成十七年法律第八十六号）第六百八十七条、[[laws/会社法/本文/第689条.md|第六百八十九条]]、[[laws/会社法/本文/第692条.md|第六百九十二条]]及び[[laws/会社法/本文/第701条.md|第七百一条]]の規定は、機構債券について準用する。この場合において、同法第六百八十七条、[[laws/会社法/本文/第689条.md|第六百八十九条]]及び[[laws/会社法/本文/第692条.md|第六百九十二条]]中「社債券」とあるのは、「債券」と読み替えるものとする。
