# 第二十八条 （書類及び帳簿の備付け）

## 
受託者は、信託事務を行う事務所に、次に掲げる書類及び帳簿を備え付けておかなければならない。信託行為及びこれに附属する書類委託者又はその相続人、受託者、信託管理人及び運営委員会等の構成員の氏名、住所及び略歴を記載した書類（法人にあつては、名称、代表者の氏名、主たる事務所の所在地を記載した書類並びに定款又は寄附行為）許可、認可、届出等に関する書類運営委員会等の議事に関する書類収入及び支出に関する帳簿及び証拠書類資産及び負債の状況を示す書類

- 一 信託行為及びこれに附属する書類
- 二 委託者又はその相続人、受託者、信託管理人及び運営委員会等の構成員の氏名、住所及び略歴を記載した書類（法人にあつては、名称、代表者の氏名、主たる事務所の所在地を記載した書類並びに定款又は寄附行為）
- 三 許可、認可、届出等に関する書類
- 四 運営委員会等の議事に関する書類
- 五 収入及び支出に関する帳簿及び証拠書類
- 六 資産及び負債の状況を示す書類
