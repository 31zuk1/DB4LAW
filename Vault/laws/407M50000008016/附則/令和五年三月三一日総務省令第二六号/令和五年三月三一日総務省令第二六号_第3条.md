# 第三条 （半島振興法第十七条の地方税の不均一課税に伴う措置が適用される場合等を定める省令の一部改正に伴う経過措置）

## 
第二条の規定による改正後の半島振興法第十七条の地方税の不均一課税に伴う措置が適用される場合等を定める省令[[laws/407M50000008016/本文/第1条.md|第一条]]の規定は、施行日以後に新設され、又は増設される施設又は設備について適用し、施行日前に新設され、又は増設された施設又は設備については、なお従前の例による。
