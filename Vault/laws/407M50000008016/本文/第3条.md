# 第三条 （法第十七条第二号に規定する総務省令で定める事業活動）

## 
法[[laws/半島振興法第十七条の地方税の不均一課税に伴う措置が適用される場合等を定める省令/本文/第17条.md|第十七条]]第二号に規定する総務省令で定める事業活動は、ポータルサイト・サーバ運営業、アプリケーション・サービス・コンテンツ・プロバイダ及びインターネット利用サポート業に係る事業活動とする。
