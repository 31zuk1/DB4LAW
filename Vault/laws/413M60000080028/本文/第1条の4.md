# 第一条の四 （業務方法書に記載すべき事項）

## 
研究所に係る通則法[[laws/413M60000080028/独立行政法人国立特別支援教育総合研究所に_law.md|第二十八条]]第二項の主務省令で定める業務方法書に記載すべき事項は、次のとおりとする。研究所法[[laws/413M60000080028/本文/第12条.md|第十二条]]第一号に規定する研究に関する事項研究所法[[laws/413M60000080028/本文/第12条.md|第十二条]]第二号に規定する研修に関する事項研究所法[[laws/413M60000080028/本文/第12条.md|第十二条]]第三号に規定する研究の成果の普及及び研究の促進に関する事項研究所法[[laws/413M60000080028/本文/第12条.md|第十二条]]第四号に規定する資料及び情報の収集、整理、保存及び提供に関する事項研究所法[[laws/413M60000080028/本文/第12条.md|第十二条]]第五号に規定する相談並びに助言、指導及び援助に関する事項業務委託の基準競争入札その他契約に関する基本的事項その他研究所の業務の執行に関して必要な事項

- 一 研究所法[[laws/413M60000080028/本文/第12条.md|第十二条]]第一号に規定する研究に関する事項
- 二 研究所法[[laws/413M60000080028/本文/第12条.md|第十二条]]第二号に規定する研修に関する事項
- 三 研究所法[[laws/413M60000080028/本文/第12条.md|第十二条]]第三号に規定する研究の成果の普及及び研究の促進に関する事項
- 四 研究所法[[laws/413M60000080028/本文/第12条.md|第十二条]]第四号に規定する資料及び情報の収集、整理、保存及び提供に関する事項
- 五 研究所法[[laws/413M60000080028/本文/第12条.md|第十二条]]第五号に規定する相談並びに助言、指導及び援助に関する事項
- 六 業務委託の基準
- 七 競争入札その他契約に関する基本的事項
- 八 その他研究所の業務の執行に関して必要な事項
