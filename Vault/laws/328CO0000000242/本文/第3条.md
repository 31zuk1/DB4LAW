# 第三条 （法第三十二条第一号の政令で定める労働に関する法律の規定）

## 
法[[laws/322AC0000000141/本文/第32条.md|第三十二条]]第一号（法[[laws/322AC0000000141/本文/第32条の6.md|第三十二条の六]]第六項、[[laws/322AC0000000141/本文/第33条.md|第三十三条]]第四項及び第五項並びに[[laws/322AC0000000141/本文/第33条の3.md|第三十三条の三]]第二項において準用する場合を含む。）の労働に関する法律の規定であって政令で定めるものは、次のとおりとする。労働基準法[[laws/328CO0000000242/職業安定法施行令_law.md|第百十七条]]及び[[laws/328CO0000000242/職業安定法施行令_law.md|第百十八条]]第一項（同法第六条及び[[laws/328CO0000000242/職業安定法施行令_law.md|第五十六条]]に係る部分に限る。）の規定並びにこれらの規定に係る同法第百二十一条の規定（これらの規定が労働者派遣法[[laws/322AC0000000141/本文/第44条.md|第四十四条]]（第四項を除く。）の規定により適用される場合を含む。）労働者派遣法[[laws/328CO0000000242/職業安定法施行令_law.md|第五十八条]]から[[laws/322AC0000000141/本文/第62条.md|第六十二条]]までの規定港湾労働法（昭和六十三年法律第四十号）第四十八条、[[laws/322AC0000000141/本文/第49条.md|第四十九条]]（第一号を除く。）及び[[laws/322AC0000000141/本文/第51条.md|第五十一条]]（第二号及び第三号に係る部分に限る。）の規定並びにこれらの規定に係る同法第五十二条の規定建設労働者の雇用の改善等に関する法律（昭和五十一年法律第三十三号）[[laws/322AC0000000141/本文/第49条.md|第四十九条]]、[[laws/322AC0000000141/本文/第50条.md|第五十条]]及び[[laws/322AC0000000141/本文/第51条.md|第五十一条]]（第二号及び第三号を除く。）の規定並びにこれらの規定に係る同法第五十二条の規定中小企業における労働力の確保及び良好な雇用の機会の創出のための雇用管理の改善の促進に関する法律（平成三年法律第五十七号）[[laws/322AC0000000141/本文/第19条.md|第十九条]]、[[laws/322AC0000000141/本文/第20条.md|第二十条]]及び[[laws/322AC0000000141/本文/第21条.md|第二十一条]]（第三号を除く。）の規定並びにこれらの規定に係る同法第二十二条の規定育児休業、介護休業等育児又は家族介護を行う労働者の福祉に関する法律[[laws/322AC0000000141/本文/第62条.md|第六十二条]]から[[laws/322AC0000000141/本文/第65条.md|第六十五条]]までの規定林業労働力の確保の促進に関する法律（平成八年法律第四十五号）[[laws/322AC0000000141/本文/第32条.md|第三十二条]]、[[laws/322AC0000000141/本文/第33条.md|第三十三条]]及び[[laws/322AC0000000141/本文/第34条.md|第三十四条]]（第三号を除く。）の規定並びにこれらの規定に係る同法第三十五条の規定外国人の技能実習の適正な実施及び技能実習生の保護に関する法律（平成二十八年法律第八十九号）[[laws/328CO0000000242/職業安定法施行令_law.md|第百八条]]、[[laws/328CO0000000242/職業安定法施行令_law.md|第百九条]]、[[laws/328CO0000000242/職業安定法施行令_law.md|第百十条]]（同法第四十四条に係る部分に限る。）、[[laws/328CO0000000242/職業安定法施行令_law.md|第百十一条]]（第一号を除く。）及び[[laws/328CO0000000242/職業安定法施行令_law.md|第百十二条]]（第一号（同法第三十五条第一項に係る部分に限る。）及び第六号から第十一号までに係る部分に限る。）の規定並びにこれらの規定に係る同法第百十三条の規定

- 一 労働基準法[[laws/328CO0000000242/職業安定法施行令_law.md|第百十七条]]及び[[laws/328CO0000000242/職業安定法施行令_law.md|第百十八条]]第一項（同法第六条及び[[laws/328CO0000000242/職業安定法施行令_law.md|第五十六条]]に係る部分に限る。）の規定並びにこれらの規定に係る同法第百二十一条の規定（これらの規定が労働者派遣法[[laws/322AC0000000141/本文/第44条.md|第四十四条]]（第四項を除く。）の規定により適用される場合を含む。）
- 二 労働者派遣法[[laws/328CO0000000242/職業安定法施行令_law.md|第五十八条]]から[[laws/322AC0000000141/本文/第62条.md|第六十二条]]までの規定
- 三 港湾労働法（昭和六十三年法律第四十号）第四十八条、[[laws/322AC0000000141/本文/第49条.md|第四十九条]]（第一号を除く。）及び[[laws/322AC0000000141/本文/第51条.md|第五十一条]]（第二号及び第三号に係る部分に限る。）の規定並びにこれらの規定に係る同法第五十二条の規定
- 四 建設労働者の雇用の改善等に関する法律（昭和五十一年法律第三十三号）[[laws/322AC0000000141/本文/第49条.md|第四十九条]]、[[laws/322AC0000000141/本文/第50条.md|第五十条]]及び[[laws/322AC0000000141/本文/第51条.md|第五十一条]]（第二号及び第三号を除く。）の規定並びにこれらの規定に係る同法第五十二条の規定
- 五 中小企業における労働力の確保及び良好な雇用の機会の創出のための雇用管理の改善の促進に関する法律（平成三年法律第五十七号）[[laws/322AC0000000141/本文/第19条.md|第十九条]]、[[laws/322AC0000000141/本文/第20条.md|第二十条]]及び[[laws/322AC0000000141/本文/第21条.md|第二十一条]]（第三号を除く。）の規定並びにこれらの規定に係る同法第二十二条の規定
- 六 育児休業、介護休業等育児又は家族介護を行う労働者の福祉に関する法律[[laws/322AC0000000141/本文/第62条.md|第六十二条]]から[[laws/322AC0000000141/本文/第65条.md|第六十五条]]までの規定
- 七 林業労働力の確保の促進に関する法律（平成八年法律第四十五号）[[laws/322AC0000000141/本文/第32条.md|第三十二条]]、[[laws/322AC0000000141/本文/第33条.md|第三十三条]]及び[[laws/322AC0000000141/本文/第34条.md|第三十四条]]（第三号を除く。）の規定並びにこれらの規定に係る同法第三十五条の規定
- 八 外国人の技能実習の適正な実施及び技能実習生の保護に関する法律（平成二十八年法律第八十九号）[[laws/328CO0000000242/職業安定法施行令_law.md|第百八条]]、[[laws/328CO0000000242/職業安定法施行令_law.md|第百九条]]、[[laws/328CO0000000242/職業安定法施行令_law.md|第百十条]]（同法第四十四条に係る部分に限る。）、[[laws/328CO0000000242/職業安定法施行令_law.md|第百十一条]]（第一号を除く。）及び[[laws/328CO0000000242/職業安定法施行令_law.md|第百十二条]]（第一号（同法第三十五条第一項に係る部分に限る。）及び第六号から第十一号までに係る部分に限る。）の規定並びにこれらの規定に係る同法第百十三条の規定
