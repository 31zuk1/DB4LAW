# 第二十八条の二十三 （可燃性の蒸気の滞留防止措置）

## 
配管を設置するために設ける隧すい道（人が立ち入る可能性のあるものに限る。）には、可燃性の蒸気が滞留しないよう必要な措置を講じなければならない。
