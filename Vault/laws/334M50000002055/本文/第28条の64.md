# 第二十八条の六十四 （アルキルアルミニウム等の一般取扱所の特例）

## 
[[laws/334M50000002055/本文/第13条の8.md|第十三条の八]]の規定は、アルキルアルミニウム等を取り扱う一般取扱所に係る令[[laws/334M50000002055/本文/第19条.md|第十九条]]第四項の規定による同条第一項の基準を超える特例について準用する。
