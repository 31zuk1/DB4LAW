# 第四十一条 （登録すべきものでないとき）

## 
令[[laws/505M60000200062/本文/第20条.md|第二十条]]第十一号の農林水産省令で定める登録すべきものでないときは、次のとおりとする。申請が漁港水面施設運営権等以外のものについての登録を目的とするとき。申請に係る登録をすることによって登録名義人となる者（[[laws/505M60000200062/本文/第16条.md|第十六条]]第十五号に規定する登録権利者を除く。）が権利能力を有しないとき。申請が令[[laws/505M60000200062/本文/第46条.md|第四十六条]]の規定により登録することができないとき。申請に係る登録の目的である権利が他の権利の全部又は一部を目的とする場合において、当該他の権利の全部又は一部が登録されていないとき。同一の漁港水面施設運営権に関し同時に二以上の申請がされた場合（令[[laws/505M60000200062/本文/第14条.md|第十四条]]第二項の規定により同時にされたものとみなされるときを含む。）において、申請に係る登録の目的である権利が相互に矛盾するとき。申請に係る登録の目的である権利が同一の漁港水面施設運営権について既にされた登録の目的である権利と矛盾するとき。前各号に掲げるもののほか、申請に係る登録が民法その他の法令の規定により無効とされることが申請書若しくは添付書面又は登録記録から明らかであるとき。

- 一 申請が漁港水面施設運営権等以外のものについての登録を目的とするとき。
- 二 申請に係る登録をすることによって登録名義人となる者（[[laws/505M60000200062/本文/第16条.md|第十六条]]第十五号に規定する登録権利者を除く。）が権利能力を有しないとき。
- 三 申請が令[[laws/505M60000200062/本文/第46条.md|第四十六条]]の規定により登録することができないとき。
- 四 申請に係る登録の目的である権利が他の権利の全部又は一部を目的とする場合において、当該他の権利の全部又は一部が登録されていないとき。
- 五 同一の漁港水面施設運営権に関し同時に二以上の申請がされた場合（令[[laws/505M60000200062/本文/第14条.md|第十四条]]第二項の規定により同時にされたものとみなされるときを含む。）において、申請に係る登録の目的である権利が相互に矛盾するとき。
- 六 申請に係る登録の目的である権利が同一の漁港水面施設運営権について既にされた登録の目的である権利と矛盾するとき。
- 七 前各号に掲げるもののほか、申請に係る登録が民法その他の法令の規定により無効とされることが申請書若しくは添付書面又は登録記録から明らかであるとき。
