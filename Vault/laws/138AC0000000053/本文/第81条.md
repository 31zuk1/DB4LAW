# 第八十一条 

## 
国土交通大臣ハ管理人ヲ監督シ、管理方法ニ付指揮ヲ為シ且管理人ニ与フヘキ報酬ノ額ヲ定ムヘシ

## 
国土交通大臣ハ前項ニ掲ケタル事項ニ付債務者、鉄道財団ノ所有者、抵当権者及鑑定人ノ意見ヲ聴クコトヲ得

## 
国土交通大臣ハ管理人ニ担保ヲ供スヘキコトヲ命シ又ハ之ヲ解任スルコトヲ得
