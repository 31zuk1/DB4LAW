# 第九十二条 

## 
次ノ場合ニ於テハ取締役、執行役又ハ管理人ヲ十万円以下ノ過料ニ処ス[[laws/138AC0000000053/本文/第8条.md|第八条]]第二項ノ公告ヲ為サザルトキ[[laws/138AC0000000053/本文/第9条.md|第九条]]ノ規定ニ違反シタルトキ[[laws/138AC0000000053/本文/第20条.md|第二十条]]ノ同意ヲ得ズシテ鉄道財団ニ属スルモノヲ鉄道財団ヨリ分離シタルトキ登録ニ関シ不正ノ申請ヲ為シタルトキ、[[laws/138AC0000000053/本文/第30条.md|第三十条]]ノ二第二項ノ登録ヲ為スコトヲ怠リタルトキ又ハ[[laws/138AC0000000053/本文/第31条.md|第三十一条]]ノ登録ノ申請ヲ為ササルトキ鉄道財団目録ニ不正ノ記載ヲ為シタルトキ、[[laws/138AC0000000053/本文/第34条.md|第三十四条]]ノ届出ヲ為ササルトキ又ハ不正ノ届出ヲ為シタルトキ管理方法ニ付国土交通大臣ノ命令ニ違反シタルトキ[[laws/138AC0000000053/本文/第88条.md|第八十八条]]ノ計算書ヲ差出ササルトキ又ハ不正ノ計算書ヲ差出シタルトキ配当額ノ交付ヲ為ササルトキ又ハ[[laws/138AC0000000053/本文/第87条.md|第八十七条]]若ハ[[laws/138AC0000000053/本文/第89条.md|第八十九条]]第一項ノ規定ニ違反シテ配当額ノ交付ヲ為シタルトキ[[laws/138AC0000000053/本文/第89条.md|第八十九条]]第二項ノ通知ヲ為ササルトキ

- 一 [[laws/138AC0000000053/本文/第8条.md|第八条]]第二項ノ公告ヲ為サザルトキ
- 二 [[laws/138AC0000000053/本文/第9条.md|第九条]]ノ規定ニ違反シタルトキ
- 三 [[laws/138AC0000000053/本文/第20条.md|第二十条]]ノ同意ヲ得ズシテ鉄道財団ニ属スルモノヲ鉄道財団ヨリ分離シタルトキ
- 四 登録ニ関シ不正ノ申請ヲ為シタルトキ、[[laws/138AC0000000053/本文/第30条.md|第三十条]]ノ二第二項ノ登録ヲ為スコトヲ怠リタルトキ又ハ[[laws/138AC0000000053/本文/第31条.md|第三十一条]]ノ登録ノ申請ヲ為ササルトキ
- 五 鉄道財団目録ニ不正ノ記載ヲ為シタルトキ、[[laws/138AC0000000053/本文/第34条.md|第三十四条]]ノ届出ヲ為ササルトキ又ハ不正ノ届出ヲ為シタルトキ
- 六 管理方法ニ付国土交通大臣ノ命令ニ違反シタルトキ
- 七 [[laws/138AC0000000053/本文/第88条.md|第八十八条]]ノ計算書ヲ差出ササルトキ又ハ不正ノ計算書ヲ差出シタルトキ
- 八 配当額ノ交付ヲ為ササルトキ又ハ[[laws/138AC0000000053/本文/第87条.md|第八十七条]]若ハ[[laws/138AC0000000053/本文/第89条.md|第八十九条]]第一項ノ規定ニ違反シテ配当額ノ交付ヲ為シタルトキ
- 九 [[laws/138AC0000000053/本文/第89条.md|第八十九条]]第二項ノ通知ヲ為ササルトキ
