# 第一条 （施行期日）

## 
この法律は、平成二十年四月一日から施行する。ただし、次の各号に掲げる規定は、それぞれ当該各号に定める日から施行する。第一条、第六条、第十三条、第十六条及び第十九条並びに附則第二十三条、第二十五条、第二十七条及び第二十八条の規定公布の日略第五条及び第十条並びに附則第十八条及び第十九条の規定平成二十三年四月一日

- 一 第一条、第六条、第十三条、第十六条及び第十九条並びに附則第二十三条、第二十五条、第二十七条及び第二十八条の規定公布の日
- 二から五まで 略
- 六 第五条及び第十条並びに附則第十八条及び第十九条の規定平成二十三年四月一日
