# 第三十八条 

## 
次の各号のいずれかに該当する者は、三十万円以下の罰金に処する。[[laws/原子力災害対策特別措置法/本文/第7条.md|第七条]]第三項、[[laws/原子力災害対策特別措置法/本文/第8条.md|第八条]]第四項前段、[[laws/原子力災害対策特別措置法/本文/第9条.md|第九条]]第五項又は[[laws/原子力災害対策特別措置法/本文/第11条.md|第十一条]]第三項の規定による届出をせず、又は虚偽の届出をした者[[laws/原子力災害対策特別措置法/本文/第10条.md|第十条]]第一項前段の規定に違反して通報しなかった者[[laws/原子力災害対策特別措置法/本文/第11条.md|第十一条]]第七項の規定に違反して放射線量の測定結果を記録せず、又は虚偽の記録をした者[[laws/原子力災害対策特別措置法/本文/第12条.md|第十二条]]第四項の規定に違反して資料を提出しなかった者[[laws/原子力災害対策特別措置法/本文/第13条の2.md|第十三条の二]]第一項又は[[laws/原子力災害対策特別措置法/本文/第31条.md|第三十一条]]の規定による報告をせず、又は虚偽の報告をした者[[laws/原子力災害対策特別措置法/本文/第32条.md|第三十二条]]第一項の規定による立入り若しくは検査を拒み、妨げ、若しくは忌避し、又は質問に対して陳述をせず、若しくは虚偽の陳述をした者

- 一 [[laws/原子力災害対策特別措置法/本文/第7条.md|第七条]]第三項、[[laws/原子力災害対策特別措置法/本文/第8条.md|第八条]]第四項前段、[[laws/原子力災害対策特別措置法/本文/第9条.md|第九条]]第五項又は[[laws/原子力災害対策特別措置法/本文/第11条.md|第十一条]]第三項の規定による届出をせず、又は虚偽の届出をした者
- 二 [[laws/原子力災害対策特別措置法/本文/第10条.md|第十条]]第一項前段の規定に違反して通報しなかった者
- 三 [[laws/原子力災害対策特別措置法/本文/第11条.md|第十一条]]第七項の規定に違反して放射線量の測定結果を記録せず、又は虚偽の記録をした者
- 四 [[laws/原子力災害対策特別措置法/本文/第12条.md|第十二条]]第四項の規定に違反して資料を提出しなかった者
- 五 [[laws/原子力災害対策特別措置法/本文/第13条の2.md|第十三条の二]]第一項又は[[laws/原子力災害対策特別措置法/本文/第31条.md|第三十一条]]の規定による報告をせず、又は虚偽の報告をした者
- 六 [[laws/原子力災害対策特別措置法/本文/第32条.md|第三十二条]]第一項の規定による立入り若しくは検査を拒み、妨げ、若しくは忌避し、又は質問に対して陳述をせず、若しくは虚偽の陳述をした者
