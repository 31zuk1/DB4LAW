# 第九十九条 

## 
次の各号のいずれかに該当する者は、一年以下の拘禁刑又は五十万円以下の罰金に処する。[[laws/津波防災地域づくりに関する法律/本文/第22条.md|第二十二条]]第一項の規定に違反して、津波防護施設区域を占用した者[[laws/津波防災地域づくりに関する法律/本文/第23条.md|第二十三条]]第一項の規定に違反して、同項各号に掲げる行為をした者[[laws/津波防災地域づくりに関する法律/本文/第73条.md|第七十三条]]第一項又は[[laws/津波防災地域づくりに関する法律/本文/第78条.md|第七十八条]]第一項の規定に違反して、特定開発行為をした者[[laws/津波防災地域づくりに関する法律/本文/第80条.md|第八十条]]の規定に違反して、[[laws/津波防災地域づくりに関する法律/本文/第73条.md|第七十三条]]第一項の制限用途の建築物の建築をした者[[laws/津波防災地域づくりに関する法律/本文/第82条.md|第八十二条]]又は[[laws/津波防災地域づくりに関する法律/本文/第87条.md|第八十七条]]第一項の規定に違反して、特定建築行為をした者[[laws/津波防災地域づくりに関する法律/本文/第88条.md|第八十八条]]第一項の規定による都道府県知事等の命令に違反した者

- 一 [[laws/津波防災地域づくりに関する法律/本文/第22条.md|第二十二条]]第一項の規定に違反して、津波防護施設区域を占用した者
- 二 [[laws/津波防災地域づくりに関する法律/本文/第23条.md|第二十三条]]第一項の規定に違反して、同項各号に掲げる行為をした者
- 三 [[laws/津波防災地域づくりに関する法律/本文/第73条.md|第七十三条]]第一項又は[[laws/津波防災地域づくりに関する法律/本文/第78条.md|第七十八条]]第一項の規定に違反して、特定開発行為をした者
- 四 [[laws/津波防災地域づくりに関する法律/本文/第80条.md|第八十条]]の規定に違反して、[[laws/津波防災地域づくりに関する法律/本文/第73条.md|第七十三条]]第一項の制限用途の建築物の建築をした者
- 五 [[laws/津波防災地域づくりに関する法律/本文/第82条.md|第八十二条]]又は[[laws/津波防災地域づくりに関する法律/本文/第87条.md|第八十七条]]第一項の規定に違反して、特定建築行為をした者
- 六 [[laws/津波防災地域づくりに関する法律/本文/第88条.md|第八十八条]]第一項の規定による都道府県知事等の命令に違反した者
