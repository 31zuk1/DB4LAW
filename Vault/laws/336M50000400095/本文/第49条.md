# 第四十九条 （包括信用購入あつせん関係受領契約に関する情報の提供等）

## 
法[[laws/割賦販売法施行規則/本文/第30条の2.md|第三十条の二]]の三第一項第三号の経済産業省令・内閣府令で定める事項は、次のとおりとする。ただし、第六号から第九号までに掲げる事項については、法[[laws/割賦販売法施行規則/本文/第30条.md|第三十条]]第一項に基づき、次条第一項第四号に定めるところにより情報を提供した場合には省略することができる。包括信用購入あつせん業者の名称及び住所又は電話番号並びに包括信用購入あつせん関係販売業者又は包括信用購入あつせん関係役務提供事業者の名称その他のこれらの者を特定することができる事項契約年月日支払分の支払回数包括信用購入あつせん関係受領契約について購入者等が問合わせ、相談等を行うことができる機関の名称及び住所又は電話番号法[[laws/割賦販売法施行規則/本文/第30条の4.md|第三十条の四]]の規定に関する事項包括信用購入あつせん関係受領契約の解除に関する定めがあるときは、その内容支払時期の到来していない支払分の支払を請求することについての定めがあるときは、その内容支払分の支払の義務が履行されない場合（包括信用購入あつせん関係受領契約が解除された場合を除く。）の損害賠償額の予定又は違約金の定めがあるときは、その内容前各号に掲げるもののほか特約があるときは、その内容

- 一 包括信用購入あつせん業者の名称及び住所又は電話番号並びに包括信用購入あつせん関係販売業者又は包括信用購入あつせん関係役務提供事業者の名称その他のこれらの者を特定することができる事項
- 二 契約年月日
- 三 支払分の支払回数
- 四 包括信用購入あつせん関係受領契約について購入者等が問合わせ、相談等を行うことができる機関の名称及び住所又は電話番号
- 五 法[[laws/割賦販売法施行規則/本文/第30条の4.md|第三十条の四]]の規定に関する事項
- 六 包括信用購入あつせん関係受領契約の解除に関する定めがあるときは、その内容
- 七 支払時期の到来していない支払分の支払を請求することについての定めがあるときは、その内容
- 八 支払分の支払の義務が履行されない場合（包括信用購入あつせん関係受領契約が解除された場合を除く。）の損害賠償額の予定又は違約金の定めがあるときは、その内容
- 九 前各号に掲げるもののほか特約があるときは、その内容
