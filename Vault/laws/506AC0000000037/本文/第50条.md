# 第五十条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、三十万円以下の罰金に処する。特定製造期間における承認製造者又は特定貯蔵期間における承認貯蔵所の所有者若しくは占有者が、[[laws/506AC0000000037/本文/第13条.md|第十三条]]第二項、[[laws/506AC0000000037/本文/第14条.md|第十四条]]第二項、[[laws/506AC0000000037/本文/第15条.md|第十五条]]、[[laws/506AC0000000037/本文/第16条.md|第十六条]]第一項において準用する高圧ガス保安法[[laws/506AC0000000037/本文/第26条.md|第二十六条]]第一項若しくは[[laws/506AC0000000037/脱炭素成長型経済構造への円滑な移行のため_law.md|第二十七条の二]]第五項（[[laws/506AC0000000037/本文/第16条.md|第十六条]]第一項において準用する同法第二十七条の二第一項第一号に係る部分に限り、[[laws/506AC0000000037/本文/第16条.md|第十六条]]第一項において準用する同法第三十三条第三項において準用する場合を含む。）若しくは第六項（[[laws/506AC0000000037/本文/第16条.md|第十六条]]第一項において準用する同法第二十七条の二第一項第一号に係る部分に限り、[[laws/506AC0000000037/本文/第16条.md|第十六条]]第一項において準用する同法第二十七条の三第三項において準用する場合を含む。）、[[laws/506AC0000000037/本文/第18条.md|第十八条]]第二項、[[laws/506AC0000000037/本文/第19条.md|第十九条]]第二項又は[[laws/506AC0000000037/本文/第20条.md|第二十条]]の規定による届出をせず、又は虚偽の届出をしたとき。[[laws/506AC0000000037/本文/第16条.md|第十六条]]第一項において準用する高圧ガス保安法[[laws/506AC0000000037/本文/第35条.md|第三十五条]]第一項の規定による検査を拒み、妨げ、又は忌避したとき。[[laws/506AC0000000037/本文/第16条.md|第十六条]]第一項において準用する高圧ガス保安法[[laws/506AC0000000037/脱炭素成長型経済構造への円滑な移行のため_law.md|第三十五条の二]]の規定による検査記録を作成せず、虚偽の検査記録を作成し、又は検査記録を保存しなかったとき。準用高圧ガス保安法[[laws/506AC0000000037/脱炭素成長型経済構造への円滑な移行のため_law.md|第六十条]]第一項の規定による帳簿の記載をせず、虚偽の記載をし、又は帳簿を保存しなかったとき。[[laws/506AC0000000037/本文/第37条.md|第三十七条]]第一項又は第二項の規定による報告をせず、又は虚偽の報告をしたとき。[[laws/506AC0000000037/本文/第38条.md|第三十八条]]第一項の規定による検査若しくは収去を拒み、妨げ、若しくは忌避し、又は同項の規定による質問に対し、答弁をせず、若しくは虚偽の答弁をしたとき。

- 一 特定製造期間における承認製造者又は特定貯蔵期間における承認貯蔵所の所有者若しくは占有者が、[[laws/506AC0000000037/本文/第13条.md|第十三条]]第二項、[[laws/506AC0000000037/本文/第14条.md|第十四条]]第二項、[[laws/506AC0000000037/本文/第15条.md|第十五条]]、[[laws/506AC0000000037/本文/第16条.md|第十六条]]第一項において準用する高圧ガス保安法[[laws/506AC0000000037/本文/第26条.md|第二十六条]]第一項若しくは[[laws/506AC0000000037/脱炭素成長型経済構造への円滑な移行のため_law.md|第二十七条の二]]第五項（[[laws/506AC0000000037/本文/第16条.md|第十六条]]第一項において準用する同法第二十七条の二第一項第一号に係る部分に限り、[[laws/506AC0000000037/本文/第16条.md|第十六条]]第一項において準用する同法第三十三条第三項において準用する場合を含む。）若しくは第六項（[[laws/506AC0000000037/本文/第16条.md|第十六条]]第一項において準用する同法第二十七条の二第一項第一号に係る部分に限り、[[laws/506AC0000000037/本文/第16条.md|第十六条]]第一項において準用する同法第二十七条の三第三項において準用する場合を含む。）、[[laws/506AC0000000037/本文/第18条.md|第十八条]]第二項、[[laws/506AC0000000037/本文/第19条.md|第十九条]]第二項又は[[laws/506AC0000000037/本文/第20条.md|第二十条]]の規定による届出をせず、又は虚偽の届出をしたとき。
- 二 [[laws/506AC0000000037/本文/第16条.md|第十六条]]第一項において準用する高圧ガス保安法[[laws/506AC0000000037/本文/第35条.md|第三十五条]]第一項の規定による検査を拒み、妨げ、又は忌避したとき。
- 三 [[laws/506AC0000000037/本文/第16条.md|第十六条]]第一項において準用する高圧ガス保安法[[laws/506AC0000000037/脱炭素成長型経済構造への円滑な移行のため_law.md|第三十五条の二]]の規定による検査記録を作成せず、虚偽の検査記録を作成し、又は検査記録を保存しなかったとき。
- 四 準用高圧ガス保安法[[laws/506AC0000000037/脱炭素成長型経済構造への円滑な移行のため_law.md|第六十条]]第一項の規定による帳簿の記載をせず、虚偽の記載をし、又は帳簿を保存しなかったとき。
- 五 [[laws/506AC0000000037/本文/第37条.md|第三十七条]]第一項又は第二項の規定による報告をせず、又は虚偽の報告をしたとき。
- 六 [[laws/506AC0000000037/本文/第38条.md|第三十八条]]第一項の規定による検査若しくは収去を拒み、妨げ、若しくは忌避し、又は同項の規定による質問に対し、答弁をせず、若しくは虚偽の答弁をしたとき。
