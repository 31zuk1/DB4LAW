# 第百二十二条 

## 
次の各号のいずれかに該当する者は、三十万円以下の過料に処する。[[laws/425AC0000000096/本文/第57条.md|第五十七条]]第四項の規定に違反して、正当な理由がないのに訴訟授権契約の締結を拒んだ者[[laws/425AC0000000096/本文/第57条.md|第五十七条]]第五項の規定に違反して、正当な理由がないのに訴訟授権契約を解除した者[[laws/425AC0000000096/本文/第74条.md|第七十四条]]第二項若しくは[[laws/425AC0000000096/本文/第101条.md|第百一条]]第二項の規定による掲示をせず、若しくは虚偽の掲示をし、又は[[laws/425AC0000000096/本文/第74条.md|第七十四条]]第二項若しくは[[laws/425AC0000000096/本文/第101条.md|第百一条]]第二項の規定に違反して公衆の閲覧に供せず、若しくは虚偽の事項を公衆の閲覧に供した者[[laws/425AC0000000096/本文/第76条.md|第七十六条]]、[[laws/425AC0000000096/本文/第77条.md|第七十七条]]第二項若しくは第七項、[[laws/425AC0000000096/本文/第78条.md|第七十八条]]第二項若しくは第七項、[[laws/425AC0000000096/本文/第79条.md|第七十九条]]第一項、[[laws/425AC0000000096/本文/第102条.md|第百二条]]、[[laws/425AC0000000096/本文/第103条.md|第百三条]]第二項若しくは第七項、[[laws/425AC0000000096/本文/第104条.md|第百四条]]第二項若しくは第七項又は[[laws/425AC0000000096/本文/第105条.md|第百五条]]第一項の規定による届出をせず、又は虚偽の届出をした者[[laws/425AC0000000096/本文/第84条.md|第八十四条]]第一項前段の規定による通知若しくは報告をせず、又は虚偽の通知若しくは報告をした者[[laws/425AC0000000096/本文/第85条.md|第八十五条]]第二項の規定に違反して、消費者の被害に関する情報を利用した者[[laws/425AC0000000096/本文/第87条.md|第八十七条]]の規定に違反して、同条の請求を拒んだ者[[laws/425AC0000000096/本文/第93条.md|第九十三条]]第九項の規定による被害回復関係業務の引継ぎを怠った者[[laws/425AC0000000096/本文/第96条.md|第九十六条]]第二項の規定に違反して、書類を同項に定める目的以外の目的のために利用し、又は提供した者[[laws/425AC0000000096/本文/第97条.md|第九十七条]]第二項の規定に違反して、情報を同項に定める目的以外の目的のために利用し、又は提供した者[[laws/425AC0000000096/本文/第110条.md|第百十条]]第一項の規定に違反して、財務諸表等を作成せず、又はこれに記載し、若しくは記録すべき事項を記載せず、若しくは記録せず、若しくは虚偽の記載若しくは記録をした者[[laws/425AC0000000096/本文/第110条.md|第百十条]]第二項の規定に違反して、書類を備え置かなかった者[[laws/425AC0000000096/本文/第110条.md|第百十条]]第三項の規定に違反して、書類を提出せず、又は書類に虚偽の記載若しくは記録をして提出した者

- 一 [[laws/425AC0000000096/本文/第57条.md|第五十七条]]第四項の規定に違反して、正当な理由がないのに訴訟授権契約の締結を拒んだ者
- 二 [[laws/425AC0000000096/本文/第57条.md|第五十七条]]第五項の規定に違反して、正当な理由がないのに訴訟授権契約を解除した者
- 三 [[laws/425AC0000000096/本文/第74条.md|第七十四条]]第二項若しくは[[laws/425AC0000000096/本文/第101条.md|第百一条]]第二項の規定による掲示をせず、若しくは虚偽の掲示をし、又は[[laws/425AC0000000096/本文/第74条.md|第七十四条]]第二項若しくは[[laws/425AC0000000096/本文/第101条.md|第百一条]]第二項の規定に違反して公衆の閲覧に供せず、若しくは虚偽の事項を公衆の閲覧に供した者
- 四 [[laws/425AC0000000096/本文/第76条.md|第七十六条]]、[[laws/425AC0000000096/本文/第77条.md|第七十七条]]第二項若しくは第七項、[[laws/425AC0000000096/本文/第78条.md|第七十八条]]第二項若しくは第七項、[[laws/425AC0000000096/本文/第79条.md|第七十九条]]第一項、[[laws/425AC0000000096/本文/第102条.md|第百二条]]、[[laws/425AC0000000096/本文/第103条.md|第百三条]]第二項若しくは第七項、[[laws/425AC0000000096/本文/第104条.md|第百四条]]第二項若しくは第七項又は[[laws/425AC0000000096/本文/第105条.md|第百五条]]第一項の規定による届出をせず、又は虚偽の届出をした者
- 五 [[laws/425AC0000000096/本文/第84条.md|第八十四条]]第一項前段の規定による通知若しくは報告をせず、又は虚偽の通知若しくは報告をした者
- 六 [[laws/425AC0000000096/本文/第85条.md|第八十五条]]第二項の規定に違反して、消費者の被害に関する情報を利用した者
- 七 [[laws/425AC0000000096/本文/第87条.md|第八十七条]]の規定に違反して、同条の請求を拒んだ者
- 八 [[laws/425AC0000000096/本文/第93条.md|第九十三条]]第九項の規定による被害回復関係業務の引継ぎを怠った者
- 九 [[laws/425AC0000000096/本文/第96条.md|第九十六条]]第二項の規定に違反して、書類を同項に定める目的以外の目的のために利用し、又は提供した者
- 十 [[laws/425AC0000000096/本文/第97条.md|第九十七条]]第二項の規定に違反して、情報を同項に定める目的以外の目的のために利用し、又は提供した者
- 十一 [[laws/425AC0000000096/本文/第110条.md|第百十条]]第一項の規定に違反して、財務諸表等を作成せず、又はこれに記載し、若しくは記録すべき事項を記載せず、若しくは記録せず、若しくは虚偽の記載若しくは記録をした者
- 十二 [[laws/425AC0000000096/本文/第110条.md|第百十条]]第二項の規定に違反して、書類を備え置かなかった者
- 十三 [[laws/425AC0000000096/本文/第110条.md|第百十条]]第三項の規定に違反して、書類を提出せず、又は書類に虚偽の記載若しくは記録をして提出した者
