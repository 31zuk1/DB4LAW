# 第百二条 

## 
次の各号のいずれかに該当する者は、三十万円以下の罰金に処する。[[laws/職業能力開発促進法/本文/第26条の5.md|第二十六条の五]]第二項の規定に違反した者[[laws/職業能力開発促進法/本文/第26条の6.md|第二十六条の六]]第五項において準用する職業安定法[[laws/職業能力開発促進法/本文/第50条.md|第五十条]]第一項の規定による報告をせず、又は虚偽の報告をした者[[laws/職業能力開発促進法/本文/第26条の6.md|第二十六条の六]]第五項において準用する職業安定法[[laws/職業能力開発促進法/本文/第50条.md|第五十条]]第二項の規定による立入り若しくは検査を拒み、妨げ、若しくは忌避し、又は質問に対して答弁をせず、若しくは虚偽の陳述をした者[[laws/職業能力開発促進法/本文/第26条の6.md|第二十六条の六]]第五項において準用する職業安定法[[laws/職業能力開発促進法/本文/第51条.md|第五十一条]]第一項の規定に違反して秘密を漏らした者[[laws/職業能力開発促進法/本文/第30条の22.md|第三十条の二十二]]第二項の規定によりキャリアコンサルタントの名称の使用の停止を命ぜられた者で、当該停止を命ぜられた期間中に、キャリアコンサルタントの名称を使用したもの[[laws/職業能力開発促進法/本文/第30条の28.md|第三十条の二十八]]の規定に違反した者[[laws/職業能力開発促進法/本文/第50条.md|第五十条]]第三項の規定により技能士の名称の使用の停止を命ぜられた者で、当該停止を命ぜられた期間中に、技能士の名称を使用したもの[[laws/職業能力開発促進法/本文/第50条.md|第五十条]]第四項の規定に違反した者

- 一 [[laws/職業能力開発促進法/本文/第26条の5.md|第二十六条の五]]第二項の規定に違反した者
- 二 [[laws/職業能力開発促進法/本文/第26条の6.md|第二十六条の六]]第五項において準用する職業安定法[[laws/職業能力開発促進法/本文/第50条.md|第五十条]]第一項の規定による報告をせず、又は虚偽の報告をした者
- 三 [[laws/職業能力開発促進法/本文/第26条の6.md|第二十六条の六]]第五項において準用する職業安定法[[laws/職業能力開発促進法/本文/第50条.md|第五十条]]第二項の規定による立入り若しくは検査を拒み、妨げ、若しくは忌避し、又は質問に対して答弁をせず、若しくは虚偽の陳述をした者
- 四 [[laws/職業能力開発促進法/本文/第26条の6.md|第二十六条の六]]第五項において準用する職業安定法[[laws/職業能力開発促進法/本文/第51条.md|第五十一条]]第一項の規定に違反して秘密を漏らした者
- 五 [[laws/職業能力開発促進法/本文/第30条の22.md|第三十条の二十二]]第二項の規定によりキャリアコンサルタントの名称の使用の停止を命ぜられた者で、当該停止を命ぜられた期間中に、キャリアコンサルタントの名称を使用したもの
- 六 [[laws/職業能力開発促進法/本文/第30条の28.md|第三十条の二十八]]の規定に違反した者
- 七 [[laws/職業能力開発促進法/本文/第50条.md|第五十条]]第三項の規定により技能士の名称の使用の停止を命ぜられた者で、当該停止を命ぜられた期間中に、技能士の名称を使用したもの
- 八 [[laws/職業能力開発促進法/本文/第50条.md|第五十条]]第四項の規定に違反した者
