# 第十四条 （法第二十二条第八項に規定する主務省令で定める事項）

## 
法[[laws/障害者の日常生活及び社会生活を総合的に支援するための法律施行規則/本文/第22条.md|第二十二条]]第八項に規定する主務省令で定める事項は、次の各号に掲げる事項とする。支給決定障害者等の氏名、居住地及び生年月日当該支給決定に係る障害者等が障害児である場合においては、当該障害児の氏名及び生年月日交付の年月日及び受給者証番号支給量（法[[laws/障害者の日常生活及び社会生活を総合的に支援するための法律施行規則/本文/第22条.md|第二十二条]]第七項に規定する支給量をいう。[[laws/障害者の日常生活及び社会生活を総合的に支援するための法律施行規則/本文/第16条.md|第十六条]]及び[[laws/障害者の日常生活及び社会生活を総合的に支援するための法律施行規則/本文/第19条.md|第十九条]]第二項において同じ。）支給決定の有効期間（法[[laws/障害者の日常生活及び社会生活を総合的に支援するための法律施行規則/本文/第23条.md|第二十三条]]に規定する支給決定の有効期間をいう。以下同じ。）障害支援区分負担上限月額に関する事項その他必要な事項

- 一 支給決定障害者等の氏名、居住地及び生年月日
- 二 当該支給決定に係る障害者等が障害児である場合においては、当該障害児の氏名及び生年月日
- 三 交付の年月日及び受給者証番号
- 四 支給量（法[[laws/障害者の日常生活及び社会生活を総合的に支援するための法律施行規則/本文/第22条.md|第二十二条]]第七項に規定する支給量をいう。[[laws/障害者の日常生活及び社会生活を総合的に支援するための法律施行規則/本文/第16条.md|第十六条]]及び[[laws/障害者の日常生活及び社会生活を総合的に支援するための法律施行規則/本文/第19条.md|第十九条]]第二項において同じ。）
- 五 支給決定の有効期間（法[[laws/障害者の日常生活及び社会生活を総合的に支援するための法律施行規則/本文/第23条.md|第二十三条]]に規定する支給決定の有効期間をいう。以下同じ。）
- 六 障害支援区分
- 七 負担上限月額に関する事項
- 八 その他必要な事項
