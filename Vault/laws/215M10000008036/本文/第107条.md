# 第百七条 （令第四十三条第七項の厚生労働省令で定める医療に関する給付）

## 
令[[laws/215M10000008036/本文/第43条.md|第四十三条]]第七項において読み替えて準用する法[[laws/215M10000008036/本文/第110条.md|第百十条]]第四項の厚生労働省令で定める医療に関する給付は、次のとおりとする。児童福祉法[[laws/215M10000008036/健康保険法施行規則_law.md|第十九条の二]]第一項の小児慢性特定疾病医療費の支給、同法第二十条第二項の医療に係る療育の給付又は同法第二十一条の五の二十九第一項の肢体不自由児通所医療費若しくは同法第二十四条の二十第一項（同法第二十四条の二十四第三項において適用する場合を含む。）の障害児入所医療費の支給障害者の日常生活及び社会生活を総合的に支援するための法律[[laws/215M10000008036/本文/第58条.md|第五十八条]]第一項の自立支援医療費、同法第七十条第一項の療養介護医療費又は同法第七十一条第一項の基準該当療養介護医療費の支給精神保健及び精神障害者福祉に関する法律[[laws/215M10000008036/本文/第30条.md|第三十条]]第一項の規定により費用の負担が行われる医療に関する給付生活保護法[[laws/215M10000008036/本文/第15条.md|第十五条]]の医療扶助削除麻薬及び向精神薬取締法[[laws/215M10000008036/健康保険法施行規則_law.md|第五十八条の十七]]第一項の規定により費用の負担が行われる医療に関する給付母子保健法[[laws/215M10000008036/本文/第20条.md|第二十条]]の養育医療の給付感染症の予防及び感染症の患者に対する医療に関する法律[[laws/215M10000008036/本文/第37条.md|第三十七条]]第一項、[[laws/215M10000008036/本文/第37条の2.md|第三十七条の二]]第一項又は[[laws/215M10000008036/健康保険法施行規則_law.md|第四十四条の三]]の二第一項の規定により費用の負担が行われる医療に関する給付石綿による健康被害の救済に関する法律[[laws/215M10000008036/本文/第4条.md|第四条]]第一項の医療費の支給特定Ｂ型肝炎ウイルス感染者給付金等の支給に関する特別措置法[[laws/215M10000008036/本文/第12条.md|第十二条]]第一項の定期検査費又は同法第十三条第一項の母子感染防止医療費の支給難病の患者に対する医療等に関する法律[[laws/215M10000008036/本文/第5条.md|第五条]]第一項の特定医療費の支給令[[laws/215M10000008036/本文/第41条.md|第四十一条]]第九項の規定による高額療養費の支給前各号に掲げる医療に関する給付に準ずるものとして厚生労働大臣が定める医療に関する給付

- 一 児童福祉法[[laws/215M10000008036/健康保険法施行規則_law.md|第十九条の二]]第一項の小児慢性特定疾病医療費の支給、同法第二十条第二項の医療に係る療育の給付又は同法第二十一条の五の二十九第一項の肢体不自由児通所医療費若しくは同法第二十四条の二十第一項（同法第二十四条の二十四第三項において適用する場合を含む。）の障害児入所医療費の支給
- 二 障害者の日常生活及び社会生活を総合的に支援するための法律[[laws/215M10000008036/本文/第58条.md|第五十八条]]第一項の自立支援医療費、同法第七十条第一項の療養介護医療費又は同法第七十一条第一項の基準該当療養介護医療費の支給
- 三 精神保健及び精神障害者福祉に関する法律[[laws/215M10000008036/本文/第30条.md|第三十条]]第一項の規定により費用の負担が行われる医療に関する給付
- 四 生活保護法[[laws/215M10000008036/本文/第15条.md|第十五条]]の医療扶助
- 五 削除
- 六 麻薬及び向精神薬取締法[[laws/215M10000008036/健康保険法施行規則_law.md|第五十八条の十七]]第一項の規定により費用の負担が行われる医療に関する給付
- 七 母子保健法[[laws/215M10000008036/本文/第20条.md|第二十条]]の養育医療の給付
- 八 感染症の予防及び感染症の患者に対する医療に関する法律[[laws/215M10000008036/本文/第37条.md|第三十七条]]第一項、[[laws/215M10000008036/本文/第37条の2.md|第三十七条の二]]第一項又は[[laws/215M10000008036/健康保険法施行規則_law.md|第四十四条の三]]の二第一項の規定により費用の負担が行われる医療に関する給付
- 八の二 石綿による健康被害の救済に関する法律[[laws/215M10000008036/本文/第4条.md|第四条]]第一項の医療費の支給
- 八の三 特定Ｂ型肝炎ウイルス感染者給付金等の支給に関する特別措置法[[laws/215M10000008036/本文/第12条.md|第十二条]]第一項の定期検査費又は同法第十三条第一項の母子感染防止医療費の支給
- 八の四 難病の患者に対する医療等に関する法律[[laws/215M10000008036/本文/第5条.md|第五条]]第一項の特定医療費の支給
- 九 令[[laws/215M10000008036/本文/第41条.md|第四十一条]]第九項の規定による高額療養費の支給
- 十 前各号に掲げる医療に関する給付に準ずるものとして厚生労働大臣が定める医療に関する給付
