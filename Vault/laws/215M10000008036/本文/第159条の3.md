# 第百五十九条の三 （機構による厚生労働大臣の保有する情報の提供に関する法律の規定）

## 
法[[laws/健康保険法施行規則/本文/第205条の2.md|第二百五条の二]]第一項第十二号の厚生労働省令で定める法律の規定は、次の各号に掲げるもの（当該法律又は他の法律において準用する場合を含む。）とする。ただし、当該法律又は他の法律の規定により適用を除外される場合におけるものを除く。法[[laws/健康保険法施行規則/本文/第51条の2.md|第五十一条の二]]船員保険法[[laws/健康保険法施行規則/本文/第28条.md|第二十八条]]及び[[laws/健康保険法施行規則/本文/第50条.md|第五十条]]削除労働保険の保険料の徴収等に関する法律[[laws/健康保険法施行規則/本文/第43条の2.md|第四十三条の二]]雇用の分野における男女の均等な機会及び待遇の確保等に関する法律（昭和四十七年法律第百十三号）[[laws/健康保険法施行規則/本文/第26条.md|第二十六条]]及び[[laws/健康保険法施行規則/本文/第28条.md|第二十八条]]第二項賃金の支払の確保等に関する法律（昭和五十一年法律第三十四号）[[laws/健康保険法施行規則/本文/第12条の2.md|第十二条の二]]高齢者医療確保法[[laws/健康保険法施行規則/本文/第138条.md|第百三十八条]]介護保険法[[laws/健康保険法施行規則/本文/第68条.md|第六十八条]]統計法[[laws/健康保険法施行規則/本文/第29条.md|第二十九条]]及び[[laws/健康保険法施行規則/本文/第31条.md|第三十一条]]平成二十五年厚生年金等改正法附則第五条第一項又は第三十八条第一項の規定によりなおその効力を有するものとされた平成二十五年厚生年金等改正法[[laws/健康保険法施行規則/本文/第1条.md|第一条]]の規定による改正前の厚生年金保険法[[laws/健康保険法施行規則/本文/第173条の2.md|第百七十三条の二]]

- 三 削除

- 五 雇用の分野における男女の均等な機会及び待遇の確保等に関する法律（昭和四十七年法律第百十三号）[[laws/健康保険法施行規則/本文/第26条.md|第二十六条]]及び[[laws/健康保険法施行規則/本文/第28条.md|第二十八条]]第二項
- 六 賃金の支払の確保等に関する法律（昭和五十一年法律第三十四号）[[laws/健康保険法施行規則/本文/第12条の2.md|第十二条の二]]
