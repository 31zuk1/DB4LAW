# 第五十三条 

## 
次の各号のいずれかに該当する者は、三十万円以下の過料に処する。[[laws/412AC0000000061/本文/第16条.md|第十六条]]第二項の規定による掲示をせず、若しくは虚偽の掲示をし、又は同項の規定に違反して公衆の閲覧に供せず、若しくは虚偽の事項を公衆の閲覧に供した者[[laws/412AC0000000061/本文/第18条.md|第十八条]]、[[laws/412AC0000000061/本文/第19条.md|第十九条]]第二項若しくは第七項、[[laws/412AC0000000061/本文/第20条.md|第二十条]]第二項若しくは第七項又は[[laws/412AC0000000061/本文/第21条.md|第二十一条]]第一項の規定による届出をせず、又は虚偽の届出をした者[[laws/412AC0000000061/本文/第23条.md|第二十三条]]第四項前段の規定による通知若しくは報告をせず、又は虚偽の通知若しくは報告をした者[[laws/412AC0000000061/本文/第24条.md|第二十四条]]の規定に違反して、消費者の被害に関する情報を利用した者[[laws/412AC0000000061/本文/第26条.md|第二十六条]]の規定に違反して、同条の請求を拒んだ者[[laws/412AC0000000061/本文/第31条.md|第三十一条]]第一項の規定に違反して、財務諸表等を作成せず、又はこれに記載し、若しくは記録すべき事項を記載せず、若しくは記録せず、若しくは虚偽の記載若しくは記録をした者[[laws/412AC0000000061/本文/第31条.md|第三十一条]]第二項の規定に違反して、書類を備え置かなかった者[[laws/412AC0000000061/本文/第31条.md|第三十一条]]第四項の規定に違反して、正当な理由がないのに同条第三項各号に掲げる請求を拒んだ者[[laws/412AC0000000061/本文/第31条.md|第三十一条]]第五項の規定に違反して、書類を提出せず、又は書類に虚偽の記載若しくは記録をして提出した者[[laws/412AC0000000061/本文/第40条.md|第四十条]]第二項の規定に違反して、情報を同項に定める目的以外の目的のために利用し、又は提供した者

- 一 [[laws/412AC0000000061/本文/第16条.md|第十六条]]第二項の規定による掲示をせず、若しくは虚偽の掲示をし、又は同項の規定に違反して公衆の閲覧に供せず、若しくは虚偽の事項を公衆の閲覧に供した者
- 二 [[laws/412AC0000000061/本文/第18条.md|第十八条]]、[[laws/412AC0000000061/本文/第19条.md|第十九条]]第二項若しくは第七項、[[laws/412AC0000000061/本文/第20条.md|第二十条]]第二項若しくは第七項又は[[laws/412AC0000000061/本文/第21条.md|第二十一条]]第一項の規定による届出をせず、又は虚偽の届出をした者
- 三 [[laws/412AC0000000061/本文/第23条.md|第二十三条]]第四項前段の規定による通知若しくは報告をせず、又は虚偽の通知若しくは報告をした者
- 四 [[laws/412AC0000000061/本文/第24条.md|第二十四条]]の規定に違反して、消費者の被害に関する情報を利用した者
- 五 [[laws/412AC0000000061/本文/第26条.md|第二十六条]]の規定に違反して、同条の請求を拒んだ者
- 六 [[laws/412AC0000000061/本文/第31条.md|第三十一条]]第一項の規定に違反して、財務諸表等を作成せず、又はこれに記載し、若しくは記録すべき事項を記載せず、若しくは記録せず、若しくは虚偽の記載若しくは記録をした者
- 七 [[laws/412AC0000000061/本文/第31条.md|第三十一条]]第二項の規定に違反して、書類を備え置かなかった者
- 八 [[laws/412AC0000000061/本文/第31条.md|第三十一条]]第四項の規定に違反して、正当な理由がないのに同条第三項各号に掲げる請求を拒んだ者
- 九 [[laws/412AC0000000061/本文/第31条.md|第三十一条]]第五項の規定に違反して、書類を提出せず、又は書類に虚偽の記載若しくは記録をして提出した者
- 十 [[laws/412AC0000000061/本文/第40条.md|第四十条]]第二項の規定に違反して、情報を同項に定める目的以外の目的のために利用し、又は提供した者
