# 第八十一条 （財政融資資金特別会計における財政融資資金の繰替使用）

## 
財政融資資金特別会計においては、財政融資資金に属する現金を繰り替えて使用することができる。

## ２
前項の規定による繰替金を返還する場合には、当該年度の歳入（附則第七十三条第二項の規定による積立金からの補足を含む。以下この項において同じ。）をもって返還しなければならない。ただし、歳入不足のため返還することができない場合には、[[laws/特別会計に関する法律/本文/第15条.md|第十五条]]第六項の規定にかかわらず、その返還することができない金額を限り、繰替使用をしたときから一年内に返還することができる。
