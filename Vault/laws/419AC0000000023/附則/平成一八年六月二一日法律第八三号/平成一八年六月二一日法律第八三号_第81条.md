# 第八十一条 （特別会計に関する法律の一部改正に伴う経過措置）

## 
附則第七十九条の規定による改正後の特別会計に関する法律の規定は、平成二十年度の予算から適用し、平成十九年度の収入及び支出並びに同年度以前の各年度の決算に関しては、なお従前の例による。
