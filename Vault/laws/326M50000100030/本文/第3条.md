# 第三条 （覚醒剤製造業者等の指定証）

## 
法[[laws/326M50000100030/本文/第5条.md|第五条]]第一項の規定により覚醒剤製造業者、覚醒剤施用機関又は覚醒剤研究者に交付する指定証は、別記第二号様式の定めるところによる。
