# 第三条の三 （譲渡しの許可申請書）

## 
法[[laws/326M50000100030/本文/第17条.md|第十七条]]第五項の規定により覚醒剤の譲渡しの許可を受けようとする者の提出すべき申請書は、別記第二号様式の三の定めるところによる。
