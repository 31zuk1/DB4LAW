# 第十七条 （登録局の無線設備の規格）

## 
法[[laws/325AC0000000131/本文/第27条の21.md|第二十七条の二十一]]第一項の総務省令で定める無線設備の規格は、次に掲げるものとする。設備規則[[laws/325M50080000014/電波法施行規則_law.md|第四十九条の八]]の三に規定する技術基準のうち基地局に係るもの設備規則[[laws/325M50080000014/電波法施行規則_law.md|第四十九条の八]]の三第四項に規定する技術基準のうち陸上移動局に係るもの設備規則[[laws/325M50080000014/電波法施行規則_law.md|第四十九条の九]]第一号に規定する技術基準設備規則[[laws/325M50080000014/電波法施行規則_law.md|第四十九条の九]]第三号に規定する技術基準設備規則[[laws/325M50080000014/電波法施行規則_law.md|第四十九条の二十]]の二第一項に規定する技術基準のうち基地局に係るもの設備規則[[laws/325M50080000014/電波法施行規則_law.md|第四十九条の二十]]の二第一項に規定する技術基準のうち陸上移動中継局に係るもの設備規則[[laws/325M50080000014/電波法施行規則_law.md|第四十九条の二十]]の二第三項に規定する技術基準のうち携帯基地局に係るもの設備規則[[laws/325M50080000014/電波法施行規則_law.md|第四十九条の二十]]の二第三項に規定する技術基準のうち携帯局（[[laws/325M50080000014/本文/第6条.md|第六条]]第四項第十一号に掲げるものを除く。）に係るもの削除設備規則[[laws/325M50080000014/電波法施行規則_law.md|第四十九条の三十四]]第一項に規定する技術基準設備規則[[laws/325M50080000014/電波法施行規則_law.md|第四十九条の三十四]]第二項に規定する技術基準設備規則[[laws/325M50080000014/本文/第54条.md|第五十四条]]第二号及び同条第二号の二に規定する技術基準

- 一 設備規則[[laws/325M50080000014/電波法施行規則_law.md|第四十九条の八]]の三に規定する技術基準のうち基地局に係るもの
- 一の二 設備規則[[laws/325M50080000014/電波法施行規則_law.md|第四十九条の八]]の三第四項に規定する技術基準のうち陸上移動局に係るもの
- 二 設備規則[[laws/325M50080000014/電波法施行規則_law.md|第四十九条の九]]第一号に規定する技術基準
- 三 設備規則[[laws/325M50080000014/電波法施行規則_law.md|第四十九条の九]]第三号に規定する技術基準
- 四 設備規則[[laws/325M50080000014/電波法施行規則_law.md|第四十九条の二十]]の二第一項に規定する技術基準のうち基地局に係るもの
- 五 設備規則[[laws/325M50080000014/電波法施行規則_law.md|第四十九条の二十]]の二第一項に規定する技術基準のうち陸上移動中継局に係るもの
- 六 設備規則[[laws/325M50080000014/電波法施行規則_law.md|第四十九条の二十]]の二第三項に規定する技術基準のうち携帯基地局に係るもの
- 七 設備規則[[laws/325M50080000014/電波法施行規則_law.md|第四十九条の二十]]の二第三項に規定する技術基準のうち携帯局（[[laws/325M50080000014/本文/第6条.md|第六条]]第四項第十一号に掲げるものを除く。）に係るもの
- 八から十まで 削除
- 十一 設備規則[[laws/325M50080000014/電波法施行規則_law.md|第四十九条の三十四]]第一項に規定する技術基準
- 十一の二 設備規則[[laws/325M50080000014/電波法施行規則_law.md|第四十九条の三十四]]第二項に規定する技術基準
- 十二 設備規則[[laws/325M50080000014/本文/第54条.md|第五十四条]]第二号及び同条第二号の二に規定する技術基準
