# 第五十一条の七 （業務規程の記載事項）

## 
法[[laws/325AC0000000131/本文/第102条の17.md|第百二条の十七]]第五項において準用する法[[laws/325AC0000000131/本文/第39条の5.md|第三十九条の五]]第一項の総務省令で定める法[[laws/325AC0000000131/本文/第102条の17.md|第百二条の十七]]第二項第一号から第三号までに掲げる業務（以下この条において「照会相談業務等」という。）の実施に関する事項は、次のとおりとする。照会相談業務等を行う時間及び休日に関する事項照会相談業務等を行う事務所に関する事項照会相談業務等の実施の方法に関する事項手数料の額及びその収納の方法に関する事項法[[laws/325AC0000000131/本文/第102条の17.md|第百二条の十七]]第二項第一号に掲げる業務に関する秘密の保持に関する事項その他照会相談業務等の実施に関し必要な事項

- 一 照会相談業務等を行う時間及び休日に関する事項
- 二 照会相談業務等を行う事務所に関する事項
- 三 照会相談業務等の実施の方法に関する事項
- 四 手数料の額及びその収納の方法に関する事項
- 五 法[[laws/325AC0000000131/本文/第102条の17.md|第百二条の十七]]第二項第一号に掲げる業務に関する秘密の保持に関する事項
- 六 その他照会相談業務等の実施に関し必要な事項
