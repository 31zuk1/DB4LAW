# 第三条 （組織的な殺人等）

## 
次の各号に掲げる罪に当たる行為が、団体の活動（団体の意思決定に基づく行為であって、その効果又はこれによる利益が当該団体に帰属するものをいう。以下同じ。）として、当該罪に当たる行為を実行するための組織により行われたときは、その罪を犯した者は、当該各号に定める刑に処する。刑法（明治四十年法律第四十五号）第九十六条（封印等破棄）の罪五年以下の拘禁刑若しくは五百万円以下の罰金又はこれらの併科刑法[[laws/140AC0000000045/本文/第96条の2.md|第九十六条の二]]（強制執行妨害目的財産損壊等）の罪五年以下の拘禁刑若しくは五百万円以下の罰金又はこれらの併科刑法[[laws/140AC0000000045/本文/第96条の3.md|第九十六条の三]]（強制執行行為妨害等）の罪五年以下の拘禁刑若しくは五百万円以下の罰金又はこれらの併科刑法[[laws/140AC0000000045/本文/第96条の4.md|第九十六条の四]]（強制執行関係売却妨害）の罪五年以下の拘禁刑若しくは五百万円以下の罰金又はこれらの併科刑法[[laws/140AC0000000045/本文/第186条.md|第百八十六条]]第一項（常習賭博）の罪五年以下の拘禁刑刑法[[laws/140AC0000000045/本文/第186条.md|第百八十六条]]第二項（賭博場開張等図利）の罪三月以上七年以下の拘禁刑刑法[[laws/140AC0000000045/本文/第199条.md|第百九十九条]]（殺人）の罪死刑又は無期若しくは六年以上の拘禁刑刑法[[laws/140AC0000000045/本文/第220条.md|第二百二十条]]（逮捕及び監禁）の罪三月以上十年以下の拘禁刑刑法[[laws/140AC0000000045/本文/第223条.md|第二百二十三条]]第一項又は第二項（強要）の罪五年以下の拘禁刑刑法[[laws/140AC0000000045/本文/第225条の2.md|第二百二十五条の二]]（身の代金目的略取等）の罪無期又は五年以上の拘禁刑刑法[[laws/140AC0000000045/本文/第233条.md|第二百三十三条]]（信用毀損及び業務妨害）の罪五年以下の拘禁刑又は五十万円以下の罰金刑法[[laws/140AC0000000045/本文/第234条.md|第二百三十四条]]（威力業務妨害）の罪五年以下の拘禁刑又は五十万円以下の罰金刑法[[laws/140AC0000000045/本文/第246条.md|第二百四十六条]]（詐欺）の罪一年以上の有期拘禁刑刑法[[laws/140AC0000000045/本文/第249条.md|第二百四十九条]]（恐喝）の罪一年以上の有期拘禁刑刑法[[laws/140AC0000000045/本文/第260条.md|第二百六十条]]前段（建造物等損壊）の罪七年以下の拘禁刑

- 一 刑法（明治四十年法律第四十五号）第九十六条（封印等破棄）の罪五年以下の拘禁刑若しくは五百万円以下の罰金又はこれらの併科
- 二 刑法[[laws/140AC0000000045/本文/第96条の2.md|第九十六条の二]]（強制執行妨害目的財産損壊等）の罪五年以下の拘禁刑若しくは五百万円以下の罰金又はこれらの併科
- 三 刑法[[laws/140AC0000000045/本文/第96条の3.md|第九十六条の三]]（強制執行行為妨害等）の罪五年以下の拘禁刑若しくは五百万円以下の罰金又はこれらの併科
- 四 刑法[[laws/140AC0000000045/本文/第96条の4.md|第九十六条の四]]（強制執行関係売却妨害）の罪五年以下の拘禁刑若しくは五百万円以下の罰金又はこれらの併科
- 五 刑法[[laws/140AC0000000045/本文/第186条.md|第百八十六条]]第一項（常習賭博）の罪五年以下の拘禁刑
- 六 刑法[[laws/140AC0000000045/本文/第186条.md|第百八十六条]]第二項（賭博場開張等図利）の罪三月以上七年以下の拘禁刑
- 七 刑法[[laws/140AC0000000045/本文/第199条.md|第百九十九条]]（殺人）の罪死刑又は無期若しくは六年以上の拘禁刑
- 八 刑法[[laws/140AC0000000045/本文/第220条.md|第二百二十条]]（逮捕及び監禁）の罪三月以上十年以下の拘禁刑
- 九 刑法[[laws/140AC0000000045/本文/第223条.md|第二百二十三条]]第一項又は第二項（強要）の罪五年以下の拘禁刑
- 十 刑法[[laws/140AC0000000045/本文/第225条の2.md|第二百二十五条の二]]（身の代金目的略取等）の罪無期又は五年以上の拘禁刑
- 十一 刑法[[laws/140AC0000000045/本文/第233条.md|第二百三十三条]]（信用毀損及び業務妨害）の罪五年以下の拘禁刑又は五十万円以下の罰金
- 十二 刑法[[laws/140AC0000000045/本文/第234条.md|第二百三十四条]]（威力業務妨害）の罪五年以下の拘禁刑又は五十万円以下の罰金
- 十三 刑法[[laws/140AC0000000045/本文/第246条.md|第二百四十六条]]（詐欺）の罪一年以上の有期拘禁刑
- 十四 刑法[[laws/140AC0000000045/本文/第249条.md|第二百四十九条]]（恐喝）の罪一年以上の有期拘禁刑
- 十五 刑法[[laws/140AC0000000045/本文/第260条.md|第二百六十条]]前段（建造物等損壊）の罪七年以下の拘禁刑
## ２
団体に不正権益（団体の威力に基づく一定の地域又は分野における支配力であって、当該団体の構成員による犯罪その他の不正な行為により当該団体又はその構成員が継続的に利益を得ることを容易にすべきものをいう。以下この項及び[[laws/411AC0000000136/本文/第6条の2.md|第六条の二]]第二項において同じ。）を得させ、又は団体の不正権益を維持し、若しくは拡大する目的で、前項各号（第五号、第六号及び第十三号を除く。）に掲げる罪を犯した者も、同項と同様とする。
