# 第十八条 （登録の取消し等）

## 
国土交通大臣は、登録認証機関が次の各号のいずれかに該当するときは、その登録を取り消し、又は期間を定めて認証事務の全部若しくは一部の停止を命ずることができる。[[laws/412M50004800012/本文/第8条.md|第八条]]第一号又は第三号に該当するに至ったとき。[[laws/412M50004800012/本文/第12条.md|第十二条]]から[[laws/412M50004800012/本文/第14条.md|第十四条]]まで、[[laws/412M50004800012/本文/第15条.md|第十五条]]第一項又は次条の規定に違反したとき。正当な理由がないのに[[laws/412M50004800012/本文/第15条.md|第十五条]]第二項の規定による請求を拒んだとき。前二条の規定による命令に違反したとき。[[laws/412M50004800012/本文/第20条.md|第二十条]]の規定による報告を求められて、報告をせず、又は虚偽の報告をしたとき。不正の手段により登録を受けたとき。

- 一 [[laws/412M50004800012/本文/第8条.md|第八条]]第一号又は第三号に該当するに至ったとき。
- 二 [[laws/412M50004800012/本文/第12条.md|第十二条]]から[[laws/412M50004800012/本文/第14条.md|第十四条]]まで、[[laws/412M50004800012/本文/第15条.md|第十五条]]第一項又は次条の規定に違反したとき。
- 三 正当な理由がないのに[[laws/412M50004800012/本文/第15条.md|第十五条]]第二項の規定による請求を拒んだとき。
- 四 前二条の規定による命令に違反したとき。
- 五 [[laws/412M50004800012/本文/第20条.md|第二十条]]の規定による報告を求められて、報告をせず、又は虚偽の報告をしたとき。
- 六 不正の手段により登録を受けたとき。
