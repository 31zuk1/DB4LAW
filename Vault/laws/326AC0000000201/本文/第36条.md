# 第三十六条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、六月以下の拘禁刑又は五十万円以下の罰金に処する。[[laws/検疫法/本文/第11条.md|第十一条]]第一項の規定に違反して明告書を提出せず、又は虚偽の事実を記載した明告書を提出したとき。[[laws/検疫法/本文/第11条.md|第十一条]]第二項の規定により、書類の提出又は提示若しくは写しの提出を求められて、これを提出せず、若しくは提示若しくは写しの提出をせず、又は虚偽の事実を記載したこれらの書類を提出し、若しくは提示若しくは写しの提出をしたとき。[[laws/検疫法/本文/第12条.md|第十二条]]の規定による質問に対し、答弁をせず、若しくは虚偽の答弁をし、又は同条の規定による情報の提出の求めに対し、虚偽の情報を提出したとき。[[laws/検疫法/本文/第13条.md|第十三条]]の規定により検疫所長又は検疫官が行う診察（[[laws/検疫法/本文/第34条の2.md|第三十四条の二]]第三項の規定により実施される場合を含む。）又は検査（同項の規定により実施される場合を含む。）を拒み、妨げ、又は忌避したとき。[[laws/検疫法/本文/第13条の3.md|第十三条の三]]の規定による指示（[[laws/検疫法/本文/第34条の2.md|第三十四条の二]]第三項の規定により実施される場合を含む。）に違反したとき。[[laws/検疫法/本文/第14条.md|第十四条]]第一項第一号、第二号、第五号、第八号又は第九号の規定により検疫所長又は検疫官が行う措置（[[laws/検疫法/本文/第34条の2.md|第三十四条の二]]第三項の規定により実施される場合を含む。）を拒み、妨げ、又は忌避したとき。[[laws/検疫法/本文/第14条.md|第十四条]]第一項第七号の処分（[[laws/検疫法/本文/第34条の2.md|第三十四条の二]]第三項の規定により実施される場合を含む。）に違反したとき。[[laws/検疫法/本文/第16条の3.md|第十六条の三]]第二項の規定による報告をせず、又は虚偽の報告をしたとき。[[laws/検疫法/本文/第18条.md|第十八条]]第二項の規定による旅券の提示（[[laws/検疫法/本文/第34条の2.md|第三十四条の二]]第三項の規定により実施される場合を含む。）をせず、又は報告（同項の規定により実施される場合を含む。）をせず、若しくは虚偽の報告をし、若しくは質問（同項の規定により実施される場合を含む。）に対し、答弁をせず、若しくは虚偽の答弁をしたとき。[[laws/検疫法/本文/第18条.md|第十八条]]第四項の規定による旅券の提示（[[laws/検疫法/本文/第34条の2.md|第三十四条の二]]第三項の規定により実施される場合を含む。）をせず、又は報告（同項の規定により実施される場合を含む。）をせず、若しくは虚偽の報告をしたとき。[[laws/検疫法/本文/第24条.md|第二十四条]]の規定により検疫所長又は検疫官が行う措置を拒み、妨げ、又は忌避したとき。[[laws/検疫法/本文/第29条.md|第二十九条]]の規定による検疫所長又は検疫官の立入りを拒み、妨げ、又は忌避したとき。[[laws/検疫法/本文/第34条の2.md|第三十四条の二]]第一項の規定により検疫所長又は検疫官が行う診察を拒み、妨げ、又は忌避したとき。

- 一 [[laws/検疫法/本文/第11条.md|第十一条]]第一項の規定に違反して明告書を提出せず、又は虚偽の事実を記載した明告書を提出したとき。
- 二 [[laws/検疫法/本文/第11条.md|第十一条]]第二項の規定により、書類の提出又は提示若しくは写しの提出を求められて、これを提出せず、若しくは提示若しくは写しの提出をせず、又は虚偽の事実を記載したこれらの書類を提出し、若しくは提示若しくは写しの提出をしたとき。
- 三 [[laws/検疫法/本文/第12条.md|第十二条]]の規定による質問に対し、答弁をせず、若しくは虚偽の答弁をし、又は同条の規定による情報の提出の求めに対し、虚偽の情報を提出したとき。
- 四 [[laws/検疫法/本文/第13条.md|第十三条]]の規定により検疫所長又は検疫官が行う診察（[[laws/検疫法/本文/第34条の2.md|第三十四条の二]]第三項の規定により実施される場合を含む。）又は検査（同項の規定により実施される場合を含む。）を拒み、妨げ、又は忌避したとき。
- 五 [[laws/検疫法/本文/第13条の3.md|第十三条の三]]の規定による指示（[[laws/検疫法/本文/第34条の2.md|第三十四条の二]]第三項の規定により実施される場合を含む。）に違反したとき。
- 六 [[laws/検疫法/本文/第14条.md|第十四条]]第一項第一号、第二号、第五号、第八号又は第九号の規定により検疫所長又は検疫官が行う措置（[[laws/検疫法/本文/第34条の2.md|第三十四条の二]]第三項の規定により実施される場合を含む。）を拒み、妨げ、又は忌避したとき。
- 七 [[laws/検疫法/本文/第14条.md|第十四条]]第一項第七号の処分（[[laws/検疫法/本文/第34条の2.md|第三十四条の二]]第三項の規定により実施される場合を含む。）に違反したとき。
- 八 [[laws/検疫法/本文/第16条の3.md|第十六条の三]]第二項の規定による報告をせず、又は虚偽の報告をしたとき。
- 九 [[laws/検疫法/本文/第18条.md|第十八条]]第二項の規定による旅券の提示（[[laws/検疫法/本文/第34条の2.md|第三十四条の二]]第三項の規定により実施される場合を含む。）をせず、又は報告（同項の規定により実施される場合を含む。）をせず、若しくは虚偽の報告をし、若しくは質問（同項の規定により実施される場合を含む。）に対し、答弁をせず、若しくは虚偽の答弁をしたとき。
- 十 [[laws/検疫法/本文/第18条.md|第十八条]]第四項の規定による旅券の提示（[[laws/検疫法/本文/第34条の2.md|第三十四条の二]]第三項の規定により実施される場合を含む。）をせず、又は報告（同項の規定により実施される場合を含む。）をせず、若しくは虚偽の報告をしたとき。
- 十一 [[laws/検疫法/本文/第24条.md|第二十四条]]の規定により検疫所長又は検疫官が行う措置を拒み、妨げ、又は忌避したとき。
- 十二 [[laws/検疫法/本文/第29条.md|第二十九条]]の規定による検疫所長又は検疫官の立入りを拒み、妨げ、又は忌避したとき。
- 十三 [[laws/検疫法/本文/第34条の2.md|第三十四条の二]]第一項の規定により検疫所長又は検疫官が行う診察を拒み、妨げ、又は忌避したとき。
