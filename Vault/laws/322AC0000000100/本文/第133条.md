# 第百三十三条 

## 
次の各号のいずれかに該当する者は、三十万円以下の罰金に処する。自己の船員手帳を棄損した者[[laws/船員法/本文/第50条.md|第五十条]]第四項の規定に基づく国土交通省令に違反した者偽りその他不正の行為により船員手帳の交付、再交付、訂正又は書換えを受けた者他人の船員手帳を行使した者[[laws/船員法/本文/第100条の25.md|第百条の二十五]]の規定による検査を拒み、妨げ、又は忌避した者[[laws/船員法/本文/第109条.md|第百九条]]の規定に違反した者[[laws/船員法/本文/第112条.md|第百十二条]]第一項に定める場合において、虚偽の申告をした者[[laws/船員法/本文/第120条の3.md|第百二十条の三]]第一項の規定による立入りを拒み、妨げ、又は忌避した者[[laws/船員法/本文/第120条の3.md|第百二十条の三]]第二項の規定による検査若しくは審査を拒み、妨げ、若しくは忌避し、又は質問に対し陳述をせず、若しくは虚偽の陳述をした者

- 一 自己の船員手帳を棄損した者
- 二 [[laws/船員法/本文/第50条.md|第五十条]]第四項の規定に基づく国土交通省令に違反した者
- 三 偽りその他不正の行為により船員手帳の交付、再交付、訂正又は書換えを受けた者
- 四 他人の船員手帳を行使した者
- 五 [[laws/船員法/本文/第100条の25.md|第百条の二十五]]の規定による検査を拒み、妨げ、又は忌避した者
- 六 [[laws/船員法/本文/第109条.md|第百九条]]の規定に違反した者
- 七 [[laws/船員法/本文/第112条.md|第百十二条]]第一項に定める場合において、虚偽の申告をした者
- 八 [[laws/船員法/本文/第120条の3.md|第百二十条の三]]第一項の規定による立入りを拒み、妨げ、又は忌避した者
- 九 [[laws/船員法/本文/第120条の3.md|第百二十条の三]]第二項の規定による検査若しくは審査を拒み、妨げ、若しくは忌避し、又は質問に対し陳述をせず、若しくは虚偽の陳述をした者
## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、三十万円以下の罰金に処する。[[laws/船員法/本文/第97条.md|第九十七条]]の規定による就業規則の作成若しくは届出をせず、又は虚偽の届出をしたとき。[[laws/船員法/本文/第98条.md|第九十八条]]の規定に違反したとき。[[laws/船員法/本文/第99条.md|第九十九条]]の規定による命令に違反したとき。[[laws/船員法/本文/第101条.md|第百一条]]第一項の規定による命令に違反したとき。[[laws/船員法/本文/第107条.md|第百七条]]第一項の規定による出頭の命令に応ぜず、帳簿書類を提出せず、若しくは虚偽の記載をした帳簿書類を提出し、報告をせず、若しくは虚偽の報告をし、立入り若しくは検査を拒み、妨げ、若しくは忌避し、又は質問に対し陳述をせず、若しくは虚偽の陳述をしたとき。[[laws/船員法/本文/第118条の5.md|第百十八条の五]]第二項の規定による命令に違反したとき。

- 一 [[laws/船員法/本文/第97条.md|第九十七条]]の規定による就業規則の作成若しくは届出をせず、又は虚偽の届出をしたとき。
- 二 [[laws/船員法/本文/第98条.md|第九十八条]]の規定に違反したとき。
- 三 [[laws/船員法/本文/第99条.md|第九十九条]]の規定による命令に違反したとき。
- 四 [[laws/船員法/本文/第101条.md|第百一条]]第一項の規定による命令に違反したとき。
- 五 [[laws/船員法/本文/第107条.md|第百七条]]第一項の規定による出頭の命令に応ぜず、帳簿書類を提出せず、若しくは虚偽の記載をした帳簿書類を提出し、報告をせず、若しくは虚偽の報告をし、立入り若しくは検査を拒み、妨げ、若しくは忌避し、又は質問に対し陳述をせず、若しくは虚偽の陳述をしたとき。
- 六 [[laws/船員法/本文/第118条の5.md|第百十八条の五]]第二項の規定による命令に違反したとき。
