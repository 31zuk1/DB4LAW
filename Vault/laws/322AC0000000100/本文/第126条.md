# 第百二十六条 

## 
船長が次の各号のいずれかに該当する場合には、三十万円以下の罰金に処する。[[laws/322AC0000000100/本文/第8条.md|第八条]]、[[laws/322AC0000000100/本文/第10条.md|第十条]]、[[laws/322AC0000000100/本文/第11条.md|第十一条]]、[[laws/322AC0000000100/本文/第14条の3.md|第十四条の三]]第一項、[[laws/322AC0000000100/本文/第16条.md|第十六条]]、[[laws/322AC0000000100/本文/第17条.md|第十七条]]、[[laws/322AC0000000100/本文/第50条.md|第五十条]]第二項、[[laws/322AC0000000100/本文/第55条.md|第五十五条]]又は[[laws/322AC0000000100/本文/第66条の2.md|第六十六条の二]]の規定に違反したとき。[[laws/322AC0000000100/本文/第9条.md|第九条]]の規定に違反して予定の航路を変更したとき。[[laws/322AC0000000100/本文/第13条.md|第十三条]]の規定に違反して告げなかつたとき。[[laws/322AC0000000100/本文/第13条の2.md|第十三条の二]]第一項の規定による通報をせず、又は虚偽の通報をしたとき。[[laws/322AC0000000100/本文/第15条.md|第十五条]]の規定に基づく国土交通省令に違反して水葬に付したとき。[[laws/322AC0000000100/本文/第18条.md|第十八条]]の規定による書類を備え置かず、又は同条第一項第二号若しくは第三号の書類に記載すべき事項を記載せず、若しくは虚偽の記載をしたとき。[[laws/322AC0000000100/本文/第19条.md|第十九条]]の規定による報告をせず、又は虚偽の報告をしたとき。[[laws/322AC0000000100/本文/第50条.md|第五十条]]第三項の規定に違反して、船員手帳に記載すべき事項を記載せず、又は虚偽の記載をしたとき。

- 一 [[laws/322AC0000000100/本文/第8条.md|第八条]]、[[laws/322AC0000000100/本文/第10条.md|第十条]]、[[laws/322AC0000000100/本文/第11条.md|第十一条]]、[[laws/322AC0000000100/本文/第14条の3.md|第十四条の三]]第一項、[[laws/322AC0000000100/本文/第16条.md|第十六条]]、[[laws/322AC0000000100/本文/第17条.md|第十七条]]、[[laws/322AC0000000100/本文/第50条.md|第五十条]]第二項、[[laws/322AC0000000100/本文/第55条.md|第五十五条]]又は[[laws/322AC0000000100/本文/第66条の2.md|第六十六条の二]]の規定に違反したとき。
- 二 [[laws/322AC0000000100/本文/第9条.md|第九条]]の規定に違反して予定の航路を変更したとき。
- 三 [[laws/322AC0000000100/本文/第13条.md|第十三条]]の規定に違反して告げなかつたとき。
- 四 [[laws/322AC0000000100/本文/第13条の2.md|第十三条の二]]第一項の規定による通報をせず、又は虚偽の通報をしたとき。
- 五 [[laws/322AC0000000100/本文/第15条.md|第十五条]]の規定に基づく国土交通省令に違反して水葬に付したとき。
- 六 [[laws/322AC0000000100/本文/第18条.md|第十八条]]の規定による書類を備え置かず、又は同条第一項第二号若しくは第三号の書類に記載すべき事項を記載せず、若しくは虚偽の記載をしたとき。
- 七 [[laws/322AC0000000100/本文/第19条.md|第十九条]]の規定による報告をせず、又は虚偽の報告をしたとき。
- 八 [[laws/322AC0000000100/本文/第50条.md|第五十条]]第三項の規定に違反して、船員手帳に記載すべき事項を記載せず、又は虚偽の記載をしたとき。
