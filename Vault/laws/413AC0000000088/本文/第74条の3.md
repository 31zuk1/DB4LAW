# 第七十四条の三 （脱退一時金相当額等又は残余財産の移換があった場合の運用の指図の特例）

## 
[[laws/413AC0000000088/本文/第25条の2.md|第二十五条の二]]の規定は、前条第一項の規定により移換される脱退一時金相当額等又は残余財産がある場合について準用する。この場合において、[[laws/413AC0000000088/本文/第25条の2.md|第二十五条の二]]第三項中「納付される事業主掛金等」とあるのは、「[[laws/413AC0000000088/本文/第74条の2.md|第七十四条の二]]第一項の規定により移換される脱退一時金相当額等又は残余財産」と読み替えるものとする。
