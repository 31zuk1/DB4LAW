# 第百二十三条 

## 
次の各号のいずれかに該当する者は、二十万円以下の過料に処する。[[laws/413AC0000000088/本文/第6条.md|第六条]]第一項の規定に違反して、届出をせず、又は虚偽の届出をした者[[laws/413AC0000000088/本文/第26条.md|第二十六条]]第三項（[[laws/413AC0000000088/本文/第73条.md|第七十三条]]において準用する場合を含む。）の規定に違反して、通知をしない者[[laws/413AC0000000088/本文/第26条.md|第二十六条]]第四項（[[laws/413AC0000000088/本文/第73条.md|第七十三条]]において準用する場合を含む。）の規定に違反して、公告を怠り、又は虚偽の公告をした者[[laws/413AC0000000088/本文/第49条.md|第四十九条]]の規定による帳簿書類の作成若しくは保存をせず、又は虚偽の帳簿書類を作成した者[[laws/413AC0000000088/本文/第50条.md|第五十条]]の規定に違反して、報告をせず、又は虚偽の報告をした者[[laws/413AC0000000088/本文/第52条.md|第五十二条]]第一項の規定による命令に違反した者[[laws/413AC0000000088/本文/第58条.md|第五十八条]]第一項の規定に違反して、届出をせず、又は虚偽の届出をした者[[laws/413AC0000000088/本文/第80条.md|第八十条]]第四項、[[laws/413AC0000000088/本文/第82条.md|第八十二条]]第二項又は[[laws/413AC0000000088/本文/第83条.md|第八十三条]]第二項の規定に違反して、通知をしない者[[laws/413AC0000000088/本文/第83条.md|第八十三条]]第三項の規定に違反して、公告を怠り、又は虚偽の公告をした者

- 一 [[laws/413AC0000000088/本文/第6条.md|第六条]]第一項の規定に違反して、届出をせず、又は虚偽の届出をした者
- 二 [[laws/413AC0000000088/本文/第26条.md|第二十六条]]第三項（[[laws/413AC0000000088/本文/第73条.md|第七十三条]]において準用する場合を含む。）の規定に違反して、通知をしない者
- 三 [[laws/413AC0000000088/本文/第26条.md|第二十六条]]第四項（[[laws/413AC0000000088/本文/第73条.md|第七十三条]]において準用する場合を含む。）の規定に違反して、公告を怠り、又は虚偽の公告をした者
- 四 [[laws/413AC0000000088/本文/第49条.md|第四十九条]]の規定による帳簿書類の作成若しくは保存をせず、又は虚偽の帳簿書類を作成した者
- 五 [[laws/413AC0000000088/本文/第50条.md|第五十条]]の規定に違反して、報告をせず、又は虚偽の報告をした者
- 六 [[laws/413AC0000000088/本文/第52条.md|第五十二条]]第一項の規定による命令に違反した者
- 七 [[laws/413AC0000000088/本文/第58条.md|第五十八条]]第一項の規定に違反して、届出をせず、又は虚偽の届出をした者
- 八 [[laws/413AC0000000088/本文/第80条.md|第八十条]]第四項、[[laws/413AC0000000088/本文/第82条.md|第八十二条]]第二項又は[[laws/413AC0000000088/本文/第83条.md|第八十三条]]第二項の規定に違反して、通知をしない者
- 九 [[laws/413AC0000000088/本文/第83条.md|第八十三条]]第三項の規定に違反して、公告を怠り、又は虚偽の公告をした者
