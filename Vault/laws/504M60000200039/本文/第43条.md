# 第四十三条 （交付事務規程の記載事項）

## 
法[[laws/504M60000200039/本文/第20条.md|第二十条]]第二項の農林水産省令で定める事項は、次に掲げるものとする。交付事務を行う時間及び休日に関する事項交付事務を行う事務所に関する事項交付事務の実施方法に関する事項交付事務を行う者の選任及び解任並びにその配置に関する事項交付事務に関する秘密の保持に関する事項交付事務に関する帳簿及び書類の管理に関する事項会計処理に関する事項前各号に掲げるもののほか、交付事務の実施に関し必要な事項

- 一 交付事務を行う時間及び休日に関する事項
- 二 交付事務を行う事務所に関する事項
- 三 交付事務の実施方法に関する事項
- 四 交付事務を行う者の選任及び解任並びにその配置に関する事項
- 五 交付事務に関する秘密の保持に関する事項
- 六 交付事務に関する帳簿及び書類の管理に関する事項
- 七 会計処理に関する事項
- 八 前各号に掲げるもののほか、交付事務の実施に関し必要な事項
