# 第二十三条 （変更等の届出）

## 
法[[laws/特定水産動植物等の国内流通の適正化等に関する法律施行規則/本文/第8条.md|第八条]]第二項の規定による変更の届出は、次に掲げる事項を記載した届出書を提出して行うものとする。氏名又は名称及び住所並びに法人にあっては、その代表者の氏名法[[laws/特定水産動植物等の国内流通の適正化等に関する法律施行規則/本文/第8条.md|第八条]]第一項の規定による届出をした年月日及び届出先[[laws/特定水産動植物等の国内流通の適正化等に関する法律施行規則/本文/第15条.md|第十五条]]第一号に掲げる番号変更した事項変更の年月日変更の理由

- 一 氏名又は名称及び住所並びに法人にあっては、その代表者の氏名
- 二 法[[laws/特定水産動植物等の国内流通の適正化等に関する法律施行規則/本文/第8条.md|第八条]]第一項の規定による届出をした年月日及び届出先
- 三 [[laws/特定水産動植物等の国内流通の適正化等に関する法律施行規則/本文/第15条.md|第十五条]]第一号に掲げる番号
- 四 変更した事項
- 五 変更の年月日
- 六 変更の理由
