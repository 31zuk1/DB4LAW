# 第二十八条 （標識の設置の方法）

## 
法[[laws/430M60000800083/本文/第20条.md|第二十条]]第一項の規定による標識の設置は、次に掲げる事項を表示した標識により行わなければならない。使用権設定土地が地域福利増進事業の用に供されている旨使用権者の氏名又は名称使用権設定土地の所在及び地番土地使用権等（法[[laws/430M60000800083/本文/第10条.md|第十条]]第一項に規定する土地使用権等をいう。次条において同じ。）の始期（物件所有権（同項第二号に規定する物件所有権をいう。）にあっては、その取得の時期。次条第一項第七号において同じ。）土地等使用権（法[[laws/430M60000800083/本文/第10条.md|第十条]]第二項第八号に規定する土地等使用権をいう。以下この号及び次条第一項第八号において同じ。）の存続期間（法[[laws/430M60000800083/本文/第19条.md|第十九条]]第四項において準用する法[[laws/430M60000800083/本文/第15条.md|第十五条]]の規定により土地等使用権の存続期間が延長された場合にあっては、当該延長後の存続期間。次条第一項第八号において同じ。）裁定を担当した都道府県の部局の名称及び連絡先法[[laws/430M60000800083/本文/第20条.md|第二十条]]第二項の規定に違反したときは、法[[laws/430AC0000000049/本文/第62条.md|第六十二条]]第一項第二号の規定により罰金に処せられる旨

- 一 使用権設定土地が地域福利増進事業の用に供されている旨
- 二 使用権者の氏名又は名称
- 三 使用権設定土地の所在及び地番
- 四 土地使用権等（法[[laws/430M60000800083/本文/第10条.md|第十条]]第一項に規定する土地使用権等をいう。次条において同じ。）の始期（物件所有権（同項第二号に規定する物件所有権をいう。）にあっては、その取得の時期。次条第一項第七号において同じ。）
- 五 土地等使用権（法[[laws/430M60000800083/本文/第10条.md|第十条]]第二項第八号に規定する土地等使用権をいう。以下この号及び次条第一項第八号において同じ。）の存続期間（法[[laws/430M60000800083/本文/第19条.md|第十九条]]第四項において準用する法[[laws/430M60000800083/本文/第15条.md|第十五条]]の規定により土地等使用権の存続期間が延長された場合にあっては、当該延長後の存続期間。次条第一項第八号において同じ。）
- 六 裁定を担当した都道府県の部局の名称及び連絡先
- 七 法[[laws/430M60000800083/本文/第20条.md|第二十条]]第二項の規定に違反したときは、法[[laws/430AC0000000049/本文/第62条.md|第六十二条]]第一項第二号の規定により罰金に処せられる旨
