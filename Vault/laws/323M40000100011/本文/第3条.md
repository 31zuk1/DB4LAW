# 第三条 

## 
令[[laws/児童福祉法施行規則/本文/第2条.md|第二条]]第一項の規定により、児童相談所の設置に関して報告すべき事項は、次のとおりとする。名称及び位置管轄区域及びその区域内の人口建物その他設備の規模及び構造並びにその図面職員の定数収支予算事業開始の年月日

- 一 名称及び位置
- 二 管轄区域及びその区域内の人口
- 三 建物その他設備の規模及び構造並びにその図面
- 四 職員の定数
- 五 収支予算
- 六 事業開始の年月日
## 
令[[laws/児童福祉法施行規則/本文/第2条.md|第二条]]第一項の規定により、児童相談所の設備の規模及び構造等の変更に関して報告すべき事項は、前項第一号から第四号までの事項とする。
