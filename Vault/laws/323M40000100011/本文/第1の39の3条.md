# 第一条の三十九の三 

## 
法[[laws/322AC0000000164/本文/第10条の3.md|第十条の三]]第一項に規定する内閣府令で定める場所は、次に掲げる場所とする。保育所幼稚園認定こども園法[[laws/323M40000100011/本文/第6条の3.md|第六条の三]]第六項に規定する地域子育て支援拠点事業を行う場所児童館前各号に掲げるもののほか、法[[laws/322AC0000000164/本文/第10条の3.md|第十条の三]]第一項に規定する相談及び助言を適切に行うことができると市町村長が認める場所

- 一 保育所
- 二 幼稚園
- 三 認定こども園
- 四 法[[laws/323M40000100011/本文/第6条の3.md|第六条の三]]第六項に規定する地域子育て支援拠点事業を行う場所
- 五 児童館
- 六 前各号に掲げるもののほか、法[[laws/322AC0000000164/本文/第10条の3.md|第十条の三]]第一項に規定する相談及び助言を適切に行うことができると市町村長が認める場所
