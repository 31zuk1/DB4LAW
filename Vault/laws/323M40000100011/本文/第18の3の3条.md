# 第十八条の三の三 

## 
令[[laws/323M40000100011/本文/第24条.md|第二十四条]]第三号に規定する内閣府令で定める者は、通所給付決定保護者と生計を一にする者であつて、次のいずれかに該当するものとする。当該通所給付決定保護者の児童であつた者当該通所給付決定保護者又はその配偶者の直系卑属（当該通所給付決定保護者の児童及び前号に掲げる者を除く。）

- 一 当該通所給付決定保護者の児童であつた者
- 二 当該通所給付決定保護者又はその配偶者の直系卑属（当該通所給付決定保護者の児童及び前号に掲げる者を除く。）
