# 第八十一条 

## 
次の各号のいずれかに該当する場合には、その違反行為をした者は、三十万円以下の罰金に処する。不正の手段によって[[laws/413AC0000000026/本文/第5条.md|第五条]]第一項の登録を受けたとき。[[laws/413AC0000000026/本文/第9条.md|第九条]]第一項、[[laws/413AC0000000026/本文/第11条.md|第十一条]]第三項又は[[laws/413AC0000000026/本文/第12条.md|第十二条]]第一項若しくは第二項の規定による届出をせず、又は虚偽の届出をしたとき。[[laws/413AC0000000026/本文/第14条.md|第十四条]]又は[[laws/413AC0000000026/本文/第34条.md|第三十四条]]第二項の規定に違反したとき。[[laws/413AC0000000026/本文/第24条.md|第二十四条]]第一項若しくは[[laws/413AC0000000026/本文/第36条.md|第三十六条]]第一項の規定による報告をせず、若しくは虚偽の報告をし、又はこれらの規定による検査を拒み、妨げ、若しくは忌避し、若しくはこれらの規定による質問に対して答弁せず、若しくは虚偽の答弁をしたとき。[[laws/413AC0000000026/本文/第34条.md|第三十四条]]第一項の規定に違反して、帳簿を備え付けず、帳簿に記載せず、若しくは帳簿に虚偽の記載をし、又は帳簿を保存しなかったとき。[[laws/413AC0000000026/本文/第37条.md|第三十七条]]第一項の規定による許可を受けないで登録事務の全部を廃止したとき。

- 一 不正の手段によって[[laws/413AC0000000026/本文/第5条.md|第五条]]第一項の登録を受けたとき。
- 二 [[laws/413AC0000000026/本文/第9条.md|第九条]]第一項、[[laws/413AC0000000026/本文/第11条.md|第十一条]]第三項又は[[laws/413AC0000000026/本文/第12条.md|第十二条]]第一項若しくは第二項の規定による届出をせず、又は虚偽の届出をしたとき。
- 三 [[laws/413AC0000000026/本文/第14条.md|第十四条]]又は[[laws/413AC0000000026/本文/第34条.md|第三十四条]]第二項の規定に違反したとき。
- 四 [[laws/413AC0000000026/本文/第24条.md|第二十四条]]第一項若しくは[[laws/413AC0000000026/本文/第36条.md|第三十六条]]第一項の規定による報告をせず、若しくは虚偽の報告をし、又はこれらの規定による検査を拒み、妨げ、若しくは忌避し、若しくはこれらの規定による質問に対して答弁せず、若しくは虚偽の答弁をしたとき。
- 五 [[laws/413AC0000000026/本文/第34条.md|第三十四条]]第一項の規定に違反して、帳簿を備え付けず、帳簿に記載せず、若しくは帳簿に虚偽の記載をし、又は帳簿を保存しなかったとき。
- 六 [[laws/413AC0000000026/本文/第37条.md|第三十七条]]第一項の規定による許可を受けないで登録事務の全部を廃止したとき。
