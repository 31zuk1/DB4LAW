# 第四十九条 （廃棄物対策課の所掌事務）

## 
廃棄物対策課は、次に掲げる事務をつかさどる。指定廃棄物の指定に関すること。特定廃棄物の処理に関すること（環境再生課の所掌に属するものを除く。）。放射性物質汚染対処特措法[[laws/417M60001000019/本文/第16条.md|第十六条]]に基づく報告の受理に関すること。放射性物質汚染対処特措法[[laws/417M60001000019/本文/第49条.md|第四十九条]]第二項及び第三項並びに[[laws/417M60001000019/本文/第50条.md|第五十条]]第二項及び第三項に基づく報告徴収、立入検査及び収去に関すること（環境再生課の所掌に属するものを除く。）。放射性物質汚染対処特措法施行規則[[laws/417M60001000019/本文/第6条.md|第六条]]、[[laws/417M60001000019/本文/第8条.md|第八条]]第一項第一号及び第二項第一号、[[laws/417M60001000019/本文/第9条.md|第九条]]、[[laws/417M60001000019/本文/第11条.md|第十一条]]、[[laws/417M60001000019/本文/第28条.md|第二十八条]]第二号イ及びロ、[[laws/417M60001000019/本文/第30条.md|第三十条]]第二号イ及びロ並びに第三号イ及びロ、[[laws/417M60001000019/本文/第32条.md|第三十二条]]第二号並びに[[laws/417M60001000019/本文/第34条.md|第三十四条]]第二号に規定する確認に関すること。放射性物質汚染対処特措法施行規則[[laws/417M60001000019/本文/第15条.md|第十五条]]第十三号の規定による届出の受理に関すること。減容化施設の整備に係る調査並びに工事の設計、施工及び管理に関すること。減容化施設の運営、保全その他の管理に関すること。前各号に掲げるもののほか、放射性物質汚染対処特措法に基づく事故由来放射性物質により汚染された廃棄物の処理に関する事務及び事業に関すること（他課の所掌に属するものを除く。）。東日本大震災により生じた災害廃棄物の処理に関する特別措置法に基づく国による災害廃棄物の処理の代行に関すること。

- 一 指定廃棄物の指定に関すること。
- 二 特定廃棄物の処理に関すること（環境再生課の所掌に属するものを除く。）。
- 三 放射性物質汚染対処特措法[[laws/417M60001000019/本文/第16条.md|第十六条]]に基づく報告の受理に関すること。
- 四 放射性物質汚染対処特措法[[laws/417M60001000019/本文/第49条.md|第四十九条]]第二項及び第三項並びに[[laws/417M60001000019/本文/第50条.md|第五十条]]第二項及び第三項に基づく報告徴収、立入検査及び収去に関すること（環境再生課の所掌に属するものを除く。）。
- 五 放射性物質汚染対処特措法施行規則[[laws/417M60001000019/本文/第6条.md|第六条]]、[[laws/417M60001000019/本文/第8条.md|第八条]]第一項第一号及び第二項第一号、[[laws/417M60001000019/本文/第9条.md|第九条]]、[[laws/417M60001000019/本文/第11条.md|第十一条]]、[[laws/417M60001000019/本文/第28条.md|第二十八条]]第二号イ及びロ、[[laws/417M60001000019/本文/第30条.md|第三十条]]第二号イ及びロ並びに第三号イ及びロ、[[laws/417M60001000019/本文/第32条.md|第三十二条]]第二号並びに[[laws/417M60001000019/本文/第34条.md|第三十四条]]第二号に規定する確認に関すること。
- 六 放射性物質汚染対処特措法施行規則[[laws/417M60001000019/本文/第15条.md|第十五条]]第十三号の規定による届出の受理に関すること。
- 七 減容化施設の整備に係る調査並びに工事の設計、施工及び管理に関すること。
- 八 減容化施設の運営、保全その他の管理に関すること。
- 九 前各号に掲げるもののほか、放射性物質汚染対処特措法に基づく事故由来放射性物質により汚染された廃棄物の処理に関する事務及び事業に関すること（他課の所掌に属するものを除く。）。
- 十 東日本大震災により生じた災害廃棄物の処理に関する特別措置法に基づく国による災害廃棄物の処理の代行に関すること。
