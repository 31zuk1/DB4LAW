# 第七十二条 （共済計理人の関与事項）

## 
法[[laws/水産業協同組合法施行規則/本文/第15条の24.md|第十五条の二十四]]第一項の農林水産省令で定める事項は、次に掲げるものに係る共済の数理に関する事項とする。共済掛金の算出方法責任準備金の算出方法契約者割戻しに係る算出方法契約者価額の算出方法未収共済掛金の算出支払備金の算出その他共済計理人がその職務を行うに際し必要な事項

- 一 共済掛金の算出方法
- 二 責任準備金の算出方法
- 三 契約者割戻しに係る算出方法
- 四 契約者価額の算出方法
- 五 未収共済掛金の算出
- 六 支払備金の算出
- 七 その他共済計理人がその職務を行うに際し必要な事項
