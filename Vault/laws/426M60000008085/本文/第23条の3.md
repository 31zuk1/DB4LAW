# 第二十三条の三 （個人番号カードの作成）

## 
機構は、令[[laws/行政手続における特定の個人を識別するための番号の利用等に関する法律に規定する個人番号、個人番号カード、特定個人情報の提供等に関する命令/本文/第13条.md|第十三条]]第一項又は第二項の規定により提出を受けた交付申請書に不備がないことを認めたときは、[[laws/行政手続における特定の個人を識別するための番号の利用等に関する法律に規定する個人番号、個人番号カード、特定個人情報の提供等に関する命令/本文/第34条.md|第三十四条]]に規定する個人番号カードに関する技術的基準に適合するように個人番号カードを作成するものとする。
