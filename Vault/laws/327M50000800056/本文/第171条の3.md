# 第百七十一条の三 （運航管理者の養成施設）

## 
[[laws/327M50000800056/本文/第50条の3.md|第五十条の三]]、[[laws/327M50000800056/本文/第50条の4.md|第五十条の四]]、[[laws/327M50000800056/本文/第50条の5.md|第五十条の五]]、[[laws/327M50000800056/本文/第50条の6.md|第五十条の六]]第一項、[[laws/327M50000800056/本文/第50条の7.md|第五十条の七]]、[[laws/327M50000800056/本文/第50条の8.md|第五十条の八]]第二項、[[laws/327M50000800056/本文/第50条の11.md|第五十条の十一]]及び[[laws/327M50000800056/本文/第50条の12.md|第五十条の十二]]の規定は、法[[laws/327M50000800056/本文/第78条.md|第七十八条]]第四項において準用する法[[laws/327M50000800056/本文/第29条.md|第二十九条]]第四項の規定による運航管理者の養成施設について準用する。この場合において、[[laws/327M50000800056/本文/第50条の3.md|第五十条の三]]第一項中「航空従事者養成施設指定申請書（第十九号の四様式）」とあるのは「運航管理者養成施設指定申請書（第二十九号の二様式）」と、同条第三項第二号中「法[[laws/327M50000800056/本文/第25条.md|第二十五条]]第一項、第二項及び第三項の限定、法[[laws/327AC0000000231/本文/第29条の2.md|第二十九条の二]]第一項の変更に係る限定、法[[laws/327M50000800056/本文/第33条.md|第三十三条]]第一項の航空英語能力証明、法[[laws/327M50000800056/本文/第34条.md|第三十四条]]第一項の計器飛行証明、同条第二項の操縦教育証明又は別表第三の一等航空整備士、二等航空整備士、一等航空運航整備士、二等航空運航整備士及び航空工場整備士の資格についての技能証明に係る整備の基本技術の科目の別ごとに定める課程」とあるのは「法[[laws/327M50000800056/本文/第78条.md|第七十八条]]第一項の運航管理者技能検定に係る課程」と、[[laws/327M50000800056/本文/第50条の4.md|第五十条の四]]第一号イ中「、法[[laws/327M50000800056/本文/第29条.md|第二十九条]]第一項（法[[laws/327AC0000000231/本文/第29条の2.md|第二十九条の二]]第二項、法[[laws/327M50000800056/本文/第33条.md|第三十三条]]第三項又は法[[laws/327M50000800056/本文/第34条.md|第三十四条]]第三項において準用する場合を含む。）の試験若しくは法[[laws/327AC0000000231/本文/第71条の3.md|第七十一条の三]]第一項の審査」とあるのは「若しくは法[[laws/327M50000800056/本文/第78条.md|第七十八条]]第四項において準用する法[[laws/327M50000800056/本文/第29条.md|第二十九条]]第一項の試験」と、[[laws/327M50000800056/本文/第50条の6.md|第五十条の六]]第一項中「法[[laws/327M50000800056/本文/第29条.md|第二十九条]]第四項」とあるのは「法[[laws/327M50000800056/本文/第78条.md|第七十八条]]第四項において準用する法[[laws/327M50000800056/本文/第29条.md|第二十九条]]第四項」と、[[laws/327M50000800056/本文/第50条の7.md|第五十条の七]]中「航空従事者養成施設指定書（第十九号の五様式）」とあるのは「運航管理者養成施設指定書（第二十九号の三様式）」と、[[laws/327M50000800056/本文/第50条の8.md|第五十条の八]]第二項中「前項」とあるのは「技能審査員」と、[[laws/327M50000800056/本文/第50条の11.md|第五十条の十一]]中「[[laws/327M50000800056/本文/第50条の2.md|第五十条の二]]第五項」とあるのは「[[laws/327M50000800056/本文/第168条.md|第百六十八条]]第一項第六号」と、「[[laws/327M50000800056/本文/第50条の2.md|第五十条の二]]第三項及び第四項」とあるのは「[[laws/327M50000800056/本文/第170条の6.md|第百七十条の六]]」と読み替えるものとする。
