# 第百九十二条 （編隊飛行の許可の申請）

## 
法[[laws/327M50000800056/本文/第84条.md|第八十四条]]第一項の許可を受けようとする者は、左に掲げる事項を記載した申請書を国土交通大臣に提出しなければならない。氏名及び住所航空機の型式並びに航空機の国籍及び登録記号飛行計画の概要（飛行の目的、日時及び径路を明記すること。）編隊飛行を行う日時及び場所操縦者の氏名及び資格同乗者の氏名及び同乗の目的その他参考となる事項

- 一 氏名及び住所
- 二 航空機の型式並びに航空機の国籍及び登録記号
- 三 飛行計画の概要（飛行の目的、日時及び径路を明記すること。）
- 四 編隊飛行を行う日時及び場所
- 五 操縦者の氏名及び資格
- 六 同乗者の氏名及び同乗の目的
- 七 その他参考となる事項
