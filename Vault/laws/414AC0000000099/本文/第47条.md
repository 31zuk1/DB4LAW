# 第四十七条 

## 
次の各号のいずれかに該当する者は、百万円以下の罰金に処する。[[laws/414AC0000000099/本文/第12条.md|第十二条]]第一項（[[laws/414AC0000000099/本文/第34条.md|第三十四条]]において準用する場合を含む。）の規定に違反して事業計画を変更した者[[laws/414AC0000000099/本文/第15条.md|第十五条]]第一項の規定に違反して一般信書便事業を休止し、又は廃止した者[[laws/414AC0000000099/本文/第19条.md|第十九条]]第一項の規定に違反して一般信書便役務の提供を拒んだ者[[laws/414AC0000000099/本文/第19条.md|第十九条]]第二項の規定又は同条第三項（[[laws/414AC0000000099/本文/第34条.md|第三十四条]]において準用する場合を含む。）の規定に違反して信書便の役務を提供した者[[laws/414AC0000000099/本文/第22条.md|第二十二条]]第一項（[[laws/414AC0000000099/本文/第34条.md|第三十四条]]において準用する場合を含む。）の規定に違反して信書便の業務を行った者[[laws/414AC0000000099/本文/第23条.md|第二十三条]]第一項（[[laws/414AC0000000099/本文/第34条.md|第三十四条]]において準用する場合を含む。）の規定に違反して信書便の業務の一部を委託した者[[laws/414AC0000000099/本文/第24条.md|第二十四条]]第一項又は[[laws/414AC0000000099/本文/第25条.md|第二十五条]]（これらの規定を[[laws/414AC0000000099/本文/第34条.md|第三十四条]]において準用する場合を含む。）の規定に違反して協定又は契約を締結した者[[laws/414AC0000000099/本文/第26条.md|第二十六条]]又は[[laws/414AC0000000099/本文/第27条.md|第二十七条]]（これらの規定を[[laws/414AC0000000099/本文/第34条.md|第三十四条]]において準用する場合を含む。）の規定による命令に違反した者[[laws/414AC0000000099/本文/第37条.md|第三十七条]]第一項の規定による報告をせず、又は虚偽の報告をした者[[laws/414AC0000000099/本文/第37条.md|第三十七条]]第二項の規定による検査を拒み、妨げ、若しくは忌避し、又は質問に対して陳述をせず、若しくは虚偽の陳述をした者

- 一 [[laws/414AC0000000099/本文/第12条.md|第十二条]]第一項（[[laws/414AC0000000099/本文/第34条.md|第三十四条]]において準用する場合を含む。）の規定に違反して事業計画を変更した者
- 二 [[laws/414AC0000000099/本文/第15条.md|第十五条]]第一項の規定に違反して一般信書便事業を休止し、又は廃止した者
- 三 [[laws/414AC0000000099/本文/第19条.md|第十九条]]第一項の規定に違反して一般信書便役務の提供を拒んだ者
- 四 [[laws/414AC0000000099/本文/第19条.md|第十九条]]第二項の規定又は同条第三項（[[laws/414AC0000000099/本文/第34条.md|第三十四条]]において準用する場合を含む。）の規定に違反して信書便の役務を提供した者
- 五 [[laws/414AC0000000099/本文/第22条.md|第二十二条]]第一項（[[laws/414AC0000000099/本文/第34条.md|第三十四条]]において準用する場合を含む。）の規定に違反して信書便の業務を行った者
- 六 [[laws/414AC0000000099/本文/第23条.md|第二十三条]]第一項（[[laws/414AC0000000099/本文/第34条.md|第三十四条]]において準用する場合を含む。）の規定に違反して信書便の業務の一部を委託した者
- 七 [[laws/414AC0000000099/本文/第24条.md|第二十四条]]第一項又は[[laws/414AC0000000099/本文/第25条.md|第二十五条]]（これらの規定を[[laws/414AC0000000099/本文/第34条.md|第三十四条]]において準用する場合を含む。）の規定に違反して協定又は契約を締結した者
- 八 [[laws/414AC0000000099/本文/第26条.md|第二十六条]]又は[[laws/414AC0000000099/本文/第27条.md|第二十七条]]（これらの規定を[[laws/414AC0000000099/本文/第34条.md|第三十四条]]において準用する場合を含む。）の規定による命令に違反した者
- 九 [[laws/414AC0000000099/本文/第37条.md|第三十七条]]第一項の規定による報告をせず、又は虚偽の報告をした者
- 十 [[laws/414AC0000000099/本文/第37条.md|第三十七条]]第二項の規定による検査を拒み、妨げ、若しくは忌避し、又は質問に対して陳述をせず、若しくは虚偽の陳述をした者
