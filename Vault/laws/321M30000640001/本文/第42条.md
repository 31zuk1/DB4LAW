# 第四十二条 

## 
法[[laws/金融機関再建整備法施行規則/本文/第27条.md|第二十七条]]第一項（法[[laws/金融機関再建整備法施行規則/本文/第30条.md|第三十条]]第二項において準用する場合を含む。）の認可を受けようとする金融機関の理事機関は、法[[laws/金融機関再建整備法施行規則/本文/第18条.md|第十八条]]第二号に該当するに至つた日（[[laws/金融機関再建整備法施行規則/本文/第30条.md|第三十条]]第二項において準用する場合は、同条第一項の規定により最終処理方法書を改訂すべき事由を生じた日）の属する月の翌月末日までに、左に掲げる事項を記載した最終処理方法書を、主務大臣に提出しなければならない。確定損及び確定益の額積立金の種類及び額並びにその取崩額法[[laws/金融機関再建整備法施行規則/本文/第24条.md|第二十四条]]の規定により確定損の整理負担額を計算した結果の一覧表資本の未払込金を徴収すべきときは、その一株につき徴収すべき金額及び徴収すべき時期、徴収可能見込金額並びに失権した株式の処分方法最終処理を完了すべき時期異議のある債権があるときは、その債権者の氏名又は称号、債権の額及び異議の内容[[laws/金融機関再建整備法施行規則/本文/第30条.md|第三十条]]第一項の規定により最終処理方法書を改訂する場合においては、その改訂の内容及び理由監査委員があるときは、法[[laws/金融機関再建整備法施行規則/本文/第27条.md|第二十七条]]第二項の規定により、その承認を受けたこと法[[laws/金融機関再建整備法施行規則/本文/第39条.md|第三十九条]]の規定により、整備計画書を作成し、その認可を受けなければならない場合は、その旨その他参考となるべき事項

- 一 確定損及び確定益の額
- 二 積立金の種類及び額並びにその取崩額
- 三 法[[laws/金融機関再建整備法施行規則/本文/第24条.md|第二十四条]]の規定により確定損の整理負担額を計算した結果の一覧表
- 四 資本の未払込金を徴収すべきときは、その一株につき徴収すべき金額及び徴収すべき時期、徴収可能見込金額並びに失権した株式の処分方法
- 五 最終処理を完了すべき時期
- 六 異議のある債権があるときは、その債権者の氏名又は称号、債権の額及び異議の内容
- 七 [[laws/金融機関再建整備法施行規則/本文/第30条.md|第三十条]]第一項の規定により最終処理方法書を改訂する場合においては、その改訂の内容及び理由
- 八 監査委員があるときは、法[[laws/金融機関再建整備法施行規則/本文/第27条.md|第二十七条]]第二項の規定により、その承認を受けたこと
- 九 法[[laws/金融機関再建整備法施行規則/本文/第39条.md|第三十九条]]の規定により、整備計画書を作成し、その認可を受けなければならない場合は、その旨
- 十 その他参考となるべき事項
