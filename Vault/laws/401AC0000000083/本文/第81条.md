# 第八十一条 

## 
次の各号のいずれかに該当する者は、五十万円以下の過料に処する。[[laws/401AC0000000083/本文/第9条.md|第九条]]第三項（[[laws/401AC0000000083/本文/第35条.md|第三十五条]]第六項において準用する場合を含む。）の規定に違反して、軽微な事項に関する事業計画の変更を届け出なかった者[[laws/401AC0000000083/本文/第11条.md|第十一条]]の規定による掲示をせず、若しくは虚偽の掲示をし、又は同条の規定に違反して公衆の閲覧に供せず、若しくは虚偽の事項を公衆の閲覧に供した者正当な理由なく、[[laws/401AC0000000083/本文/第18条.md|第十八条]]の規定による命令に違反して、運行管理者資格者証を返納しなかった者[[laws/401AC0000000083/本文/第23条.md|第二十三条]]（[[laws/401AC0000000083/本文/第35条.md|第三十五条]]第六項、[[laws/401AC0000000083/本文/第36条.md|第三十六条]]第二項及び[[laws/401AC0000000083/本文/第37条の2.md|第三十七条の二]]第三項において準用する場合を含む。）の規定による報告をせず、又は虚偽の報告をした者[[laws/401AC0000000083/本文/第23条の3.md|第二十三条の三]]（[[laws/401AC0000000083/本文/第35条.md|第三十五条]]第六項及び[[laws/401AC0000000083/本文/第37条の2.md|第三十七条の二]]第三項において準用する場合を含む。）の規定による公表をせず、又は虚偽の公表をした者[[laws/401AC0000000083/本文/第36条.md|第三十六条]]第三項から第五項までの規定に違反した者

- 一 [[laws/401AC0000000083/本文/第9条.md|第九条]]第三項（[[laws/401AC0000000083/本文/第35条.md|第三十五条]]第六項において準用する場合を含む。）の規定に違反して、軽微な事項に関する事業計画の変更を届け出なかった者
- 二 [[laws/401AC0000000083/本文/第11条.md|第十一条]]の規定による掲示をせず、若しくは虚偽の掲示をし、又は同条の規定に違反して公衆の閲覧に供せず、若しくは虚偽の事項を公衆の閲覧に供した者
- 三 正当な理由なく、[[laws/401AC0000000083/本文/第18条.md|第十八条]]の規定による命令に違反して、運行管理者資格者証を返納しなかった者
- 四 [[laws/401AC0000000083/本文/第23条.md|第二十三条]]（[[laws/401AC0000000083/本文/第35条.md|第三十五条]]第六項、[[laws/401AC0000000083/本文/第36条.md|第三十六条]]第二項及び[[laws/401AC0000000083/本文/第37条の2.md|第三十七条の二]]第三項において準用する場合を含む。）の規定による報告をせず、又は虚偽の報告をした者
- 五 [[laws/401AC0000000083/本文/第23条の3.md|第二十三条の三]]（[[laws/401AC0000000083/本文/第35条.md|第三十五条]]第六項及び[[laws/401AC0000000083/本文/第37条の2.md|第三十七条の二]]第三項において準用する場合を含む。）の規定による公表をせず、又は虚偽の公表をした者
- 六 [[laws/401AC0000000083/本文/第36条.md|第三十六条]]第三項から第五項までの規定に違反した者
