# 第百十九条 

## 
次の各号のいずれかに該当する者は、三年以下の拘禁刑に処する。[[laws/329AC0000000165/本文/第61条.md|第六十一条]]第一項の規定に違反した者[[laws/329AC0000000165/本文/第64条.md|第六十四条]]第一項の規定に違反して組合その他の団体を結成した者[[laws/329AC0000000165/本文/第64条.md|第六十四条]]第二項の規定に違反した者[[laws/329AC0000000165/本文/第70条.md|第七十条]]第一項第一号の規定による防衛招集命令を受けた予備自衛官又は[[laws/329AC0000000165/本文/第75条の4.md|第七十五条の四]]第一項第一号若しくは第三号の規定による防衛招集命令若しくは治安招集命令を受けた即応予備自衛官で、正当な理由がなくて指定された日から三日を過ぎてなお指定された場所に出頭しないもの[[laws/329AC0000000165/本文/第77条.md|第七十七条]]又は[[laws/329AC0000000165/本文/第79条.md|第七十九条]]第一項の規定による出動待機命令を受けた者で、正当な理由がなくて職務の場所を離れ七日を過ぎたもの又は職務の場所につくように命ぜられた日から正当な理由がなくて七日を過ぎてなお職務の場所につかないもの[[laws/329AC0000000165/本文/第78条.md|第七十八条]]第一項又は[[laws/329AC0000000165/本文/第81条.md|第八十一条]]第二項に規定する治安出動命令を受けた者で、上官の職務上の命令に反抗し、又はこれに服従しないもの上官の職務上の命令に対し多数共同して反抗した者正当な権限がなくて又は上官の職務上の命令に違反して自衛隊の部隊を指揮した者

- 一 [[laws/329AC0000000165/本文/第61条.md|第六十一条]]第一項の規定に違反した者
- 二 [[laws/329AC0000000165/本文/第64条.md|第六十四条]]第一項の規定に違反して組合その他の団体を結成した者
- 三 [[laws/329AC0000000165/本文/第64条.md|第六十四条]]第二項の規定に違反した者
- 四 [[laws/329AC0000000165/本文/第70条.md|第七十条]]第一項第一号の規定による防衛招集命令を受けた予備自衛官又は[[laws/329AC0000000165/本文/第75条の4.md|第七十五条の四]]第一項第一号若しくは第三号の規定による防衛招集命令若しくは治安招集命令を受けた即応予備自衛官で、正当な理由がなくて指定された日から三日を過ぎてなお指定された場所に出頭しないもの
- 五 [[laws/329AC0000000165/本文/第77条.md|第七十七条]]又は[[laws/329AC0000000165/本文/第79条.md|第七十九条]]第一項の規定による出動待機命令を受けた者で、正当な理由がなくて職務の場所を離れ七日を過ぎたもの又は職務の場所につくように命ぜられた日から正当な理由がなくて七日を過ぎてなお職務の場所につかないもの
- 六 [[laws/329AC0000000165/本文/第78条.md|第七十八条]]第一項又は[[laws/329AC0000000165/本文/第81条.md|第八十一条]]第二項に規定する治安出動命令を受けた者で、上官の職務上の命令に反抗し、又はこれに服従しないもの
- 七 上官の職務上の命令に対し多数共同して反抗した者
- 八 正当な権限がなくて又は上官の職務上の命令に違反して自衛隊の部隊を指揮した者
## ２
前項第二号若しくは第四号から第六号までに規定する行為の遂行を教唆し、若しくはその幇ほう助をした者又は同項第三号、第七号若しくは第八号に規定する行為の遂行を共謀し、教唆し、若しくは煽せん動した者は、それぞれ同項の刑に処する。
