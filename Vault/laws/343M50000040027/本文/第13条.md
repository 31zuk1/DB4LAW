# 第十三条 （吸収合併存続協同組織金融機関の事後開示事項）

## 
法[[laws/343M50000040027/金融機関の合併及び転換の手続等に関する内_law.md|第四十四条]]第一項に規定する内閣府令で定める事項（法[[laws/343M50000040027/本文/第11条.md|第十一条]]第一項の場合に限る。）は、次に掲げる事項とする。吸収合併が効力を生じた日吸収合併消滅銀行における次に掲げる事項法[[laws/343M50000040027/金融機関の合併及び転換の手続等に関する内_law.md|第二十三条の二]]の規定による請求に係る手続の経過法[[laws/343M50000040027/本文/第24条.md|第二十四条]]から[[laws/343M50000040027/本文/第26条.md|第二十六条]]までの規定による手続の経過吸収合併存続信用金庫における次に掲げる事項法[[laws/343M50000040027/金融機関の合併及び転換の手続等に関する内_law.md|第四十二条の二]]本文の規定による請求に係る手続の経過法[[laws/343M50000040027/金融機関の合併及び転換の手続等に関する内_law.md|第四十三条]]において読み替えて準用する法[[laws/343M50000040027/金融機関の合併及び転換の手続等に関する内_law.md|第三十七条]]第一項及び第二項並びに[[laws/343M50000040027/金融機関の合併及び転換の手続等に関する内_law.md|第三十八条]]（第二項第二号ロを除く。）の規定による手続の経過吸収合併により吸収合併存続信用金庫が吸収合併消滅銀行から承継した重要な権利義務に関する事項法[[laws/343M50000040027/本文/第21条.md|第二十一条]]第一項の規定により吸収合併消滅銀行が備え置いた書面又は電磁的記録に記載又は記録がされた事項（吸収合併契約の内容を除く。）法[[laws/343M50000040027/金融機関の合併及び転換の手続等に関する内_law.md|第五十二条]]第一項の変更の登記をした日前各号に掲げるもののほか、吸収合併に関する重要な事項

- 一 吸収合併が効力を生じた日
- 二 吸収合併消滅銀行における次に掲げる事項
- 三 吸収合併存続信用金庫における次に掲げる事項
- 四 吸収合併により吸収合併存続信用金庫が吸収合併消滅銀行から承継した重要な権利義務に関する事項
- 五 法[[laws/343M50000040027/本文/第21条.md|第二十一条]]第一項の規定により吸収合併消滅銀行が備え置いた書面又は電磁的記録に記載又は記録がされた事項（吸収合併契約の内容を除く。）
- 六 法[[laws/343M50000040027/金融機関の合併及び転換の手続等に関する内_law.md|第五十二条]]第一項の変更の登記をした日
- 七 前各号に掲げるもののほか、吸収合併に関する重要な事項
## ２
法[[laws/343M50000040027/金融機関の合併及び転換の手続等に関する内_law.md|第四十四条]]第一項に規定する内閣府令で定める事項（法[[laws/343M50000040027/本文/第17条.md|第十七条]]第一項の場合に限る。）は、次に掲げる事項とする。吸収合併が効力を生じた日吸収合併消滅協同組織金融機関における次に掲げる事項法[[laws/343M50000040027/金融機関の合併及び転換の手続等に関する内_law.md|第三十六条の二]]の規定による請求に係る手続の経過法[[laws/343M50000040027/金融機関の合併及び転換の手続等に関する内_law.md|第三十七条]]及び[[laws/343M50000040027/金融機関の合併及び転換の手続等に関する内_law.md|第三十八条]]の規定による手続の経過吸収合併存続協同組織金融機関における次に掲げる事項法[[laws/343M50000040027/金融機関の合併及び転換の手続等に関する内_law.md|第四十二条の二]]本文の規定による請求に係る手続の経過法[[laws/343M50000040027/金融機関の合併及び転換の手続等に関する内_law.md|第四十三条]]において読み替えて準用する法[[laws/343M50000040027/金融機関の合併及び転換の手続等に関する内_law.md|第三十七条]]第一項及び第二項並びに[[laws/343M50000040027/金融機関の合併及び転換の手続等に関する内_law.md|第三十八条]]（第二項第二号ロを除く。）の規定による手続の経過吸収合併により吸収合併存続協同組織金融機関が吸収合併消滅協同組織金融機関から承継した重要な権利義務に関する事項法[[laws/343M50000040027/金融機関の合併及び転換の手続等に関する内_law.md|第三十四条]]第一項の規定により吸収合併消滅協同組織金融機関が備え置いた書面又は電磁的記録に記載又は記録がされた事項（吸収合併契約の内容を除く。）法[[laws/343M50000040027/金融機関の合併及び転換の手続等に関する内_law.md|第五十二条]]第一項の変更の登記をした日前各号に掲げるもののほか、吸収合併に関する重要な事項

- 一 吸収合併が効力を生じた日
- 二 吸収合併消滅協同組織金融機関における次に掲げる事項
- 三 吸収合併存続協同組織金融機関における次に掲げる事項
- 四 吸収合併により吸収合併存続協同組織金融機関が吸収合併消滅協同組織金融機関から承継した重要な権利義務に関する事項
- 五 法[[laws/343M50000040027/金融機関の合併及び転換の手続等に関する内_law.md|第三十四条]]第一項の規定により吸収合併消滅協同組織金融機関が備え置いた書面又は電磁的記録に記載又は記録がされた事項（吸収合併契約の内容を除く。）
- 六 法[[laws/343M50000040027/金融機関の合併及び転換の手続等に関する内_law.md|第五十二条]]第一項の変更の登記をした日
