# 第百八十九条 （身分を示す証明書の様式）

## 
職員が携帯すべき身分を示す証明書の様式は、次の各号の区分に応じ、当該各号に定めるところによる。法[[laws/船員保険法施行規則/本文/第49条.md|第四十九条]]第一項の規定により質問を行う場合に同条第三項の規定により当該職員が携帯すべき証明書様式第九号法[[laws/船員保険法施行規則/本文/第49条.md|第四十九条]]第二項の規定により質問を行う場合に同条第三項の規定により当該職員が携帯すべき証明書様式第十号療養の給付、入院時食事療養費の支給、入院時生活療養費の支給又は保険外併用療養費の支給に関し、法[[laws/船員保険法施行規則/本文/第59条.md|第五十九条]]、[[laws/船員保険法施行規則/本文/第61条.md|第六十一条]]第七項、[[laws/船員保険法施行規則/本文/第62条.md|第六十二条]]第四項及び[[laws/船員保険法施行規則/本文/第63条.md|第六十三条]]第四項において準用する健康保険法[[laws/船員保険法施行規則/本文/第78条.md|第七十八条]]の規定に基づく保険医療機関若しくは保険薬局の関係者に対する質問又は保険医療機関若しくは保険薬局の設備若しくは診療録、帳簿書類その他の物件の検査を行う場合において、当該職員が携帯すべき証明書様式第十一号訪問看護療養費の支給又は家族訪問看護療養費の支給に関し、法[[laws/船員保険法施行規則/本文/第65条.md|第六十五条]]第十二項及び[[laws/船員保険法施行規則/本文/第78条.md|第七十八条]]第三項において準用する健康保険法[[laws/船員保険法施行規則/本文/第94条.md|第九十四条]]の規定に基づく指定訪問看護事業者の関係者に対する質問又は訪問看護ステーションにつき帳簿書類その他の物件の検査を行う場合において、当該職員が携帯すべき証明書様式第十二号法[[laws/船員保険法施行規則/本文/第143条の3.md|第百四十三条の三]]第二項において準用する法[[laws/船員保険法施行規則/本文/第49条.md|第四十九条]]第三項の規定により当該職員が携帯すべき証明書様式第十二号の二法[[laws/船員保険法施行規則/本文/第146条.md|第百四十六条]]第二項の規定により当該職員が携帯すべき証明書様式第十三号

- 一 法[[laws/船員保険法施行規則/本文/第49条.md|第四十九条]]第一項の規定により質問を行う場合に同条第三項の規定により当該職員が携帯すべき証明書様式第九号
- 二 法[[laws/船員保険法施行規則/本文/第49条.md|第四十九条]]第二項の規定により質問を行う場合に同条第三項の規定により当該職員が携帯すべき証明書様式第十号
- 三 療養の給付、入院時食事療養費の支給、入院時生活療養費の支給又は保険外併用療養費の支給に関し、法[[laws/船員保険法施行規則/本文/第59条.md|第五十九条]]、[[laws/船員保険法施行規則/本文/第61条.md|第六十一条]]第七項、[[laws/船員保険法施行規則/本文/第62条.md|第六十二条]]第四項及び[[laws/船員保険法施行規則/本文/第63条.md|第六十三条]]第四項において準用する健康保険法[[laws/船員保険法施行規則/本文/第78条.md|第七十八条]]の規定に基づく保険医療機関若しくは保険薬局の関係者に対する質問又は保険医療機関若しくは保険薬局の設備若しくは診療録、帳簿書類その他の物件の検査を行う場合において、当該職員が携帯すべき証明書様式第十一号
- 四 訪問看護療養費の支給又は家族訪問看護療養費の支給に関し、法[[laws/船員保険法施行規則/本文/第65条.md|第六十五条]]第十二項及び[[laws/船員保険法施行規則/本文/第78条.md|第七十八条]]第三項において準用する健康保険法[[laws/船員保険法施行規則/本文/第94条.md|第九十四条]]の規定に基づく指定訪問看護事業者の関係者に対する質問又は訪問看護ステーションにつき帳簿書類その他の物件の検査を行う場合において、当該職員が携帯すべき証明書様式第十二号
- 五 法[[laws/船員保険法施行規則/本文/第143条の3.md|第百四十三条の三]]第二項において準用する法[[laws/船員保険法施行規則/本文/第49条.md|第四十九条]]第三項の規定により当該職員が携帯すべき証明書様式第十二号の二
- 六 法[[laws/船員保険法施行規則/本文/第146条.md|第百四十六条]]第二項の規定により当該職員が携帯すべき証明書様式第十三号
