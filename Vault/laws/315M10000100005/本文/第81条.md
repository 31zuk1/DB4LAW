# 第八十一条 （家族療養費の支払）

## 
被保険者の被扶養者が[[laws/船員保険法施行規則/本文/第80条.md|第八十条]]において準用する[[laws/船員保険法施行規則/本文/第42条.md|第四十二条]]、[[laws/船員保険法施行規則/本文/第45条.md|第四十五条]]、[[laws/船員保険法施行規則/本文/第93条.md|第九十三条]]第五項又は[[laws/船員保険法施行規則/本文/第95条.md|第九十五条]]第四項の規定により保険医療機関等又は保険薬局等から療養を受けた場合においては、法[[laws/船員保険法施行規則/本文/第76条.md|第七十六条]]第四項の規定によりその被保険者に支給すべき家族療養費は当該保険医療機関等又は保険薬局等に対して支払うものとする。
