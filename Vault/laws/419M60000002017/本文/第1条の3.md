# 第一条の三 （消費者契約の条項の開示要請に係る手続）

## 
法[[laws/412AC0000000061/本文/第12条の3.md|第十二条の三]]第一項の規定による要請は、次に掲げる事項を記載し、又は記録した書面又は電磁的記録を交付し、又は提供して行うものとする。名称及び住所並びに代表者の氏名電話番号、電子メールアドレス（電子メールの利用者を識別するための文字、番号、記号その他の符号をいう。以下同じ。）及びファクシミリの番号（差止請求関係業務においてファクシミリ装置を用いて送受信しようとする場合に限る。以下同じ。）当該事業者又はその代理人の氏名又は名称法[[laws/412AC0000000061/本文/第12条の3.md|第十二条の三]]第一項の規定による要請である旨要請の理由開示を要請する消費者契約の条項の要旨希望する開示の実施の方法及び開示を実施するために必要な事項

- 一 名称及び住所並びに代表者の氏名
- 二 電話番号、電子メールアドレス（電子メールの利用者を識別するための文字、番号、記号その他の符号をいう。以下同じ。）及びファクシミリの番号（差止請求関係業務においてファクシミリ装置を用いて送受信しようとする場合に限る。以下同じ。）
- 三 当該事業者又はその代理人の氏名又は名称
- 四 法[[laws/412AC0000000061/本文/第12条の3.md|第十二条の三]]第一項の規定による要請である旨
- 五 要請の理由
- 六 開示を要請する消費者契約の条項の要旨
- 七 希望する開示の実施の方法及び開示を実施するために必要な事項
