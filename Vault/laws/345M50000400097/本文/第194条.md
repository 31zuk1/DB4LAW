# 第百九十四条 （帳簿）

## 
法[[laws/ガス事業法施行規則/本文/第135条.md|第百三十五条]]の経済産業省令で定める事項は次のとおりとする。検査の申請をした者の氏名又は名称及び住所並びに法人にあつては、その代表者の氏名検査の申請を受けた年月日検査対象ガス工作物の名称及び所在地検査を行つたガス工作物の概要検査を行つた年月日検査を実施した検査員の氏名検査の概要及び結果

- 一 検査の申請をした者の氏名又は名称及び住所並びに法人にあつては、その代表者の氏名
- 二 検査の申請を受けた年月日
- 三 検査対象ガス工作物の名称及び所在地
- 四 検査を行つたガス工作物の概要
- 五 検査を行つた年月日
- 六 検査を実施した検査員の氏名
- 七 検査の概要及び結果
## ２
登録ガス工作物検査機関は、法[[laws/ガス事業法施行規則/本文/第135条.md|第百三十五条]]の規定により帳簿を保存するときは、記載の日から三年間保存しなければならない。
