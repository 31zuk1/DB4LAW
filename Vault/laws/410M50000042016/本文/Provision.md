# 附則

## 
預金保険機構が金融機能の再生のための緊急措置に関する法律（以下「法」という。）[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第六十条]]に規定する業務を行う場合における法[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第七十一条]]において適用する預金保険法[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第三十六条]]第二項に規定する内閣府令・財務省令で定める事項は、預金保険法施行規則（昭和四十六年大蔵省令第二十八号）[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第一条の二]]各号に掲げる事項のほか、次に掲げる事項とする。金融整理管財人又は金融整理管財人代理として行う業務に関する事項法[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第二十九条]]第一項の規定による承継銀行（法[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第二条]]第七項に規定する承継銀行をいう。以下同じ。）となる株式会社の設立及び同条第二項の規定による出資に関する事項法[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第三十条]]第一項の規定による承継銀行の経営管理に関する事項法[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第三十二条]]第一項の規定による承継銀行との協定（同項に規定する協定をいう。）の締結に関する事項法[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第三十三条]]第一項の規定による協定承継銀行（法[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第三十二条]]第一項第一号にいう協定承継銀行をいう。以下同じ。）に対する資金の貸付け及び協定承継銀行が行う資金の借入れに係る債務の保証に関する事項協定承継銀行に対する法[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第三十四条]]の規定による損失の補てんに関する事項取得株式（法[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第三十九条]]第二項に規定する取得株式をいう。）の対価の支払に関する事項法[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第四十五条]]の規定による特別公的管理銀行（法[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第二条]]第八項にいう特別公的管理銀行をいう。以下同じ。）の取締役及び監査役の選任又は解任に関する事項法[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第五十三条]]第一項の規定による資産の買取り及びその委託に関する事項法[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第六十一条]]の規定による特別公的管理銀行に対する資金の貸付けに関する事項特別公的管理銀行に対する法[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第六十二条]]の規定による損失の補てんに関する事項法[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第六十三条]]の規定による株式等の引受け等（同条第一項に規定する株式等の引受け等をいう。）に関する事項法[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第七十二条]]の規定による特例資金援助（同条第一項に規定する特例資金援助をいう。）に関する事項その他法[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第六十条]]に規定する業務の方法

- 一 金融整理管財人又は金融整理管財人代理として行う業務に関する事項
- 二 法[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第二十九条]]第一項の規定による承継銀行（法[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第二条]]第七項に規定する承継銀行をいう。以下同じ。）となる株式会社の設立及び同条第二項の規定による出資に関する事項
- 三 法[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第三十条]]第一項の規定による承継銀行の経営管理に関する事項
- 四 法[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第三十二条]]第一項の規定による承継銀行との協定（同項に規定する協定をいう。）の締結に関する事項
- 五 法[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第三十三条]]第一項の規定による協定承継銀行（法[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第三十二条]]第一項第一号にいう協定承継銀行をいう。以下同じ。）に対する資金の貸付け及び協定承継銀行が行う資金の借入れに係る債務の保証に関する事項
- 六 協定承継銀行に対する法[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第三十四条]]の規定による損失の補てんに関する事項
- 七 取得株式（法[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第三十九条]]第二項に規定する取得株式をいう。）の対価の支払に関する事項
- 八 法[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第四十五条]]の規定による特別公的管理銀行（法[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第二条]]第八項にいう特別公的管理銀行をいう。以下同じ。）の取締役及び監査役の選任又は解任に関する事項
- 九 法[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第五十三条]]第一項の規定による資産の買取り及びその委託に関する事項
- 十 法[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第六十一条]]の規定による特別公的管理銀行に対する資金の貸付けに関する事項
- 十一 特別公的管理銀行に対する法[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第六十二条]]の規定による損失の補てんに関する事項
- 十二 法[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第六十三条]]の規定による株式等の引受け等（同条第一項に規定する株式等の引受け等をいう。）に関する事項
- 十三 法[[laws/410M50000042016/金融機能の再生のための緊急措置に関する法_law.md|第七十二条]]の規定による特例資金援助（同条第一項に規定する特例資金援助をいう。）に関する事項
