# 第五十八条 

## 
法に規定する国土交通大臣の権限のうち、次に掲げるものは、地方整備局長及び北海道開発局長に委任する。法[[laws/水道法施行規則/本文/第5条の3.md|第五条の三]]第八項（同条第十項において準用する場合を含む。）の規定による水道基盤強化計画の報告を受理すること。法[[laws/水道法施行規則/本文/第13条.md|第十三条]]第一項（法[[laws/水道法施行規則/本文/第31条.md|第三十一条]]において準用する場合を含む。）の規定による給水開始前の届出を受理し、及び法[[laws/水道法施行規則/本文/第45条の4.md|第四十五条の四]]第三項の規定により環境大臣に通知すること。法[[laws/水道法施行規則/本文/第14条.md|第十四条]]第五項の規定による料金の変更の届出を受理すること。法[[laws/水道法施行規則/本文/第24条の3.md|第二十四条の三]]第二項（法[[laws/水道法施行規則/本文/第31条.md|第三十一条]]において準用する場合を含む。）の規定による業務の委託の届出及び委託に係る契約が効力を失つたときの届出を受理すること。国の設置する専用水道に係る法[[laws/水道法施行規則/本文/第34条.md|第三十四条]]第一項において準用する法[[laws/水道法施行規則/本文/第13条.md|第十三条]]第一項の規定による給水開始前の届出を受理し、及び法[[laws/水道法施行規則/本文/第45条の4.md|第四十五条の四]]第三項の規定により環境大臣に通知すること。国の設置する専用水道に係る法[[laws/水道法施行規則/本文/第34条.md|第三十四条]]第一項において準用する法[[laws/水道法施行規則/本文/第24条の3.md|第二十四条の三]]第二項の規定による業務の委託の届出及び委託に係る契約が効力を失つたときの届出を受理すること。

- 一 法[[laws/水道法施行規則/本文/第5条の3.md|第五条の三]]第八項（同条第十項において準用する場合を含む。）の規定による水道基盤強化計画の報告を受理すること。
- 二 法[[laws/水道法施行規則/本文/第13条.md|第十三条]]第一項（法[[laws/水道法施行規則/本文/第31条.md|第三十一条]]において準用する場合を含む。）の規定による給水開始前の届出を受理し、及び法[[laws/水道法施行規則/本文/第45条の4.md|第四十五条の四]]第三項の規定により環境大臣に通知すること。
- 三 法[[laws/水道法施行規則/本文/第14条.md|第十四条]]第五項の規定による料金の変更の届出を受理すること。
- 四 法[[laws/水道法施行規則/本文/第24条の3.md|第二十四条の三]]第二項（法[[laws/水道法施行規則/本文/第31条.md|第三十一条]]において準用する場合を含む。）の規定による業務の委託の届出及び委託に係る契約が効力を失つたときの届出を受理すること。
- 五 国の設置する専用水道に係る法[[laws/水道法施行規則/本文/第34条.md|第三十四条]]第一項において準用する法[[laws/水道法施行規則/本文/第13条.md|第十三条]]第一項の規定による給水開始前の届出を受理し、及び法[[laws/水道法施行規則/本文/第45条の4.md|第四十五条の四]]第三項の規定により環境大臣に通知すること。
- 六 国の設置する専用水道に係る法[[laws/水道法施行規則/本文/第34条.md|第三十四条]]第一項において準用する法[[laws/水道法施行規則/本文/第24条の3.md|第二十四条の三]]第二項の規定による業務の委託の届出及び委託に係る契約が効力を失つたときの届出を受理すること。
