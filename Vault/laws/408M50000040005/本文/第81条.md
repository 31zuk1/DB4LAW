# 第八十一条 （責任準備金に関して確認の対象となる契約）

## 
法[[laws/保険業法施行規則/本文/第121条.md|第百二十一条]]第一項第一号に規定する内閣府令で定める保険契約は、生命保険会社にあっては、当該生命保険会社が引き受けているすべての保険契約、損害保険会社にあっては、[[laws/保険業法施行規則/本文/第76条.md|第七十六条]]各号に掲げる保険契約を除くすべての保険契約とする。
