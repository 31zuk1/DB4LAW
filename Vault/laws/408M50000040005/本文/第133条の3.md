# 第百三十三条の三 （法第百九十三条第二項において準用する会社法第八百十九条第三項の規定による措置）

## 
法[[laws/保険業法施行規則/本文/第193条.md|第百九十三条]]第二項において準用する会社法[[laws/会社法/本文/第819条.md|第八百十九条]]第三項（貸借対照表に相当するものの公告）の規定による措置は、[[laws/会社法/本文/第14条の5.md|第十四条の五]]第一項第一号ロに掲げる方法のうち、インターネットに接続された自動公衆送信装置を使用する方法によって行わなければならない。
