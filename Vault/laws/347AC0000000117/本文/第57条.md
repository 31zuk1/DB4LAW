# 第五十七条 

## 
次の各号のいずれかに該当する者は、百万円以下の罰金に処する。[[laws/警備業法/本文/第5条.md|第五条]]第一項の規定による認定の申請をしないで、又はこれに係る同条第二項若しくは第三項の規定による通知を受ける前に警備業を営んだ者[[laws/警備業法/本文/第7条.md|第七条]]第一項の規定による認定の有効期間の更新の申請をしないで、認定の有効期間の満了後引き続き警備業を営んだ者[[laws/警備業法/本文/第13条.md|第十三条]]の規定に違反して他人に警備業を営ませた者[[laws/警備業法/本文/第19条.md|第十九条]]の規定に違反して、書面を交付せず、又は同条に規定する事項が記載されていない書面若しくは虚偽の記載のある書面を交付した者[[laws/警備業法/本文/第22条.md|第二十二条]]第一項の規定に違反して警備員指導教育責任者を選任しなかつた者[[laws/警備業法/本文/第40条.md|第四十条]]の規定に違反して届出書の提出をしなかつた者[[laws/警備業法/本文/第48条.md|第四十八条]]の規定による指示に違反した者偽りその他不正の手段により認定又は[[laws/警備業法/本文/第7条.md|第七条]]第一項の規定による認定の有効期間の更新を受けた者

- 一 [[laws/警備業法/本文/第5条.md|第五条]]第一項の規定による認定の申請をしないで、又はこれに係る同条第二項若しくは第三項の規定による通知を受ける前に警備業を営んだ者
- 二 [[laws/警備業法/本文/第7条.md|第七条]]第一項の規定による認定の有効期間の更新の申請をしないで、認定の有効期間の満了後引き続き警備業を営んだ者
- 三 [[laws/警備業法/本文/第13条.md|第十三条]]の規定に違反して他人に警備業を営ませた者
- 四 [[laws/警備業法/本文/第19条.md|第十九条]]の規定に違反して、書面を交付せず、又は同条に規定する事項が記載されていない書面若しくは虚偽の記載のある書面を交付した者
- 五 [[laws/警備業法/本文/第22条.md|第二十二条]]第一項の規定に違反して警備員指導教育責任者を選任しなかつた者
- 六 [[laws/警備業法/本文/第40条.md|第四十条]]の規定に違反して届出書の提出をしなかつた者
- 七 [[laws/警備業法/本文/第48条.md|第四十八条]]の規定による指示に違反した者
- 八 偽りその他不正の手段により認定又は[[laws/警備業法/本文/第7条.md|第七条]]第一項の規定による認定の有効期間の更新を受けた者
