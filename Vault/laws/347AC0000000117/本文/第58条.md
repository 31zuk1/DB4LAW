# 第五十八条 

## 
次の各号のいずれかに該当する者は、三十万円以下の罰金に処する。[[laws/警備業法/本文/第5条.md|第五条]]第一項（[[laws/警備業法/本文/第7条.md|第七条]]第四項において準用する場合を含む。）の認定申請書若しくは認定更新申請書又は添付書類に虚偽の記載をして提出した者[[laws/警備業法/本文/第6条.md|第六条]]の規定に違反した者[[laws/警備業法/本文/第9条.md|第九条]]、[[laws/警備業法/本文/第10条.md|第十条]]第一項、[[laws/警備業法/本文/第11条.md|第十一条]]第一項（同条第三項、[[laws/警備業法/本文/第16条.md|第十六条]]第三項及び[[laws/警備業法/本文/第17条.md|第十七条]]第二項において準用する場合を含む。以下この号において同じ。）、[[laws/警備業法/本文/第16条.md|第十六条]]第二項（[[laws/警備業法/本文/第17条.md|第十七条]]第二項において準用する場合を含む。以下この号において同じ。）若しくは[[laws/警備業法/本文/第41条.md|第四十一条]]の規定に違反して届出書の提出をせず、又は[[laws/警備業法/本文/第9条.md|第九条]]、[[laws/警備業法/本文/第10条.md|第十条]]第一項、[[laws/警備業法/本文/第11条.md|第十一条]]第一項、[[laws/警備業法/本文/第16条.md|第十六条]]第二項、[[laws/警備業法/本文/第40条.md|第四十条]]若しくは[[laws/警備業法/本文/第41条.md|第四十一条]]の届出書若しくは添付書類に虚偽の記載をして提出した者[[laws/警備業法/本文/第22条.md|第二十二条]]第七項（[[laws/警備業法/本文/第23条.md|第二十三条]]第五項及び[[laws/警備業法/本文/第42条.md|第四十二条]]第三項において準用する場合を含む。）の規定による命令に違反した者[[laws/警備業法/本文/第31条.md|第三十一条]]の規定による届出をせず、又は虚偽の届出をした者[[laws/警備業法/本文/第36条.md|第三十六条]]の規定に違反して帳簿を備えず、帳簿に記載せず、若しくは虚偽の記載をし、又は帳簿を保存しなかつた者[[laws/警備業法/本文/第37条.md|第三十七条]]若しくは[[laws/警備業法/本文/第46条.md|第四十六条]]の規定による報告若しくは資料の提出をせず、若しくは虚偽の報告若しくは資料の提出をし、又は[[laws/警備業法/本文/第38条.md|第三十八条]]第一項若しくは[[laws/警備業法/本文/第47条.md|第四十七条]]第一項の規定による検査を拒み、妨げ、若しくは忌避した者[[laws/警備業法/本文/第42条.md|第四十二条]]第一項の規定に違反して機械警備業務管理者を選任しなかつた者[[laws/警備業法/本文/第44条.md|第四十四条]]又は[[laws/警備業法/本文/第45条.md|第四十五条]]に規定する書類を備え付けず、又はこれに必要な事項を記載せず、若しくは虚偽の記載をした者

- 一 [[laws/警備業法/本文/第5条.md|第五条]]第一項（[[laws/警備業法/本文/第7条.md|第七条]]第四項において準用する場合を含む。）の認定申請書若しくは認定更新申請書又は添付書類に虚偽の記載をして提出した者
- 二 [[laws/警備業法/本文/第6条.md|第六条]]の規定に違反した者
- 三 [[laws/警備業法/本文/第9条.md|第九条]]、[[laws/警備業法/本文/第10条.md|第十条]]第一項、[[laws/警備業法/本文/第11条.md|第十一条]]第一項（同条第三項、[[laws/警備業法/本文/第16条.md|第十六条]]第三項及び[[laws/警備業法/本文/第17条.md|第十七条]]第二項において準用する場合を含む。以下この号において同じ。）、[[laws/警備業法/本文/第16条.md|第十六条]]第二項（[[laws/警備業法/本文/第17条.md|第十七条]]第二項において準用する場合を含む。以下この号において同じ。）若しくは[[laws/警備業法/本文/第41条.md|第四十一条]]の規定に違反して届出書の提出をせず、又は[[laws/警備業法/本文/第9条.md|第九条]]、[[laws/警備業法/本文/第10条.md|第十条]]第一項、[[laws/警備業法/本文/第11条.md|第十一条]]第一項、[[laws/警備業法/本文/第16条.md|第十六条]]第二項、[[laws/警備業法/本文/第40条.md|第四十条]]若しくは[[laws/警備業法/本文/第41条.md|第四十一条]]の届出書若しくは添付書類に虚偽の記載をして提出した者
- 四 [[laws/警備業法/本文/第22条.md|第二十二条]]第七項（[[laws/警備業法/本文/第23条.md|第二十三条]]第五項及び[[laws/警備業法/本文/第42条.md|第四十二条]]第三項において準用する場合を含む。）の規定による命令に違反した者
- 五 [[laws/警備業法/本文/第31条.md|第三十一条]]の規定による届出をせず、又は虚偽の届出をした者
- 六 [[laws/警備業法/本文/第36条.md|第三十六条]]の規定に違反して帳簿を備えず、帳簿に記載せず、若しくは虚偽の記載をし、又は帳簿を保存しなかつた者
- 七 [[laws/警備業法/本文/第37条.md|第三十七条]]若しくは[[laws/警備業法/本文/第46条.md|第四十六条]]の規定による報告若しくは資料の提出をせず、若しくは虚偽の報告若しくは資料の提出をし、又は[[laws/警備業法/本文/第38条.md|第三十八条]]第一項若しくは[[laws/警備業法/本文/第47条.md|第四十七条]]第一項の規定による検査を拒み、妨げ、若しくは忌避した者
- 八 [[laws/警備業法/本文/第42条.md|第四十二条]]第一項の規定に違反して機械警備業務管理者を選任しなかつた者
- 九 [[laws/警備業法/本文/第44条.md|第四十四条]]又は[[laws/警備業法/本文/第45条.md|第四十五条]]に規定する書類を備え付けず、又はこれに必要な事項を記載せず、若しくは虚偽の記載をした者
