# 第八十一条 （建築工事の完了の公告等）

## 
施行者は、施行再建マンションの建築工事が完了したときは、速やかに、その旨を、公告するとともに、[[laws/414AC0000000078/本文/第71条.md|第七十一条]]第二項又は第三項の規定により施行再建マンションに関し権利を取得する者に通知しなければならない。
