# 第二百二十九条 

## 
次の各号のいずれかに該当する場合においては、その行為をした組合の理事、監事又は清算人を、二十万円以下の過料に処する。マンション建替組合がマンション建替事業以外の事業を営んだとき。マンション敷地売却組合がマンション敷地売却事業以外の事業を営んだとき。敷地分割組合が敷地分割事業以外の事業を営んだとき。[[laws/マンションの建替え等の円滑化に関する法律/本文/第24条.md|第二十四条]]第八項（[[laws/マンションの建替え等の円滑化に関する法律/本文/第126条.md|第百二十六条]]第三項及び[[laws/マンションの建替え等の円滑化に関する法律/本文/第175条.md|第百七十五条]]第三項において準用する場合を含む。）の規定に違反して監事が理事又は組合の職員と兼ねたとき。[[laws/マンションの建替え等の円滑化に関する法律/本文/第28条.md|第二十八条]]第一項、第三項又は第六項（[[laws/マンションの建替え等の円滑化に関する法律/本文/第31条.md|第三十一条]]第四項、[[laws/マンションの建替え等の円滑化に関する法律/本文/第129条.md|第百二十九条]]、[[laws/マンションの建替え等の円滑化に関する法律/本文/第131条.md|第百三十一条]]第四項、[[laws/マンションの建替え等の円滑化に関する法律/本文/第178条.md|第百七十八条]]及び[[laws/マンションの建替え等の円滑化に関する法律/本文/第180条.md|第百八十条]]第四項において準用する場合を含む。）の規定に違反して総会又は総代会を招集しなかったとき。[[laws/マンションの建替え等の円滑化に関する法律/本文/第34条.md|第三十四条]]第三項、[[laws/マンションの建替え等の円滑化に関する法律/本文/第38条.md|第三十八条]]第三項、[[laws/マンションの建替え等の円滑化に関する法律/本文/第134条.md|第百三十四条]]第三項、[[laws/マンションの建替え等の円滑化に関する法律/本文/第137条.md|第百三十七条]]第三項、[[laws/マンションの建替え等の円滑化に関する法律/本文/第183条.md|第百八十三条]]第三項又は[[laws/マンションの建替え等の円滑化に関する法律/本文/第186条.md|第百八十六条]]第三項の規定に違反したとき。[[laws/マンションの建替え等の円滑化に関する法律/本文/第40条.md|第四十条]]又は[[laws/マンションの建替え等の円滑化に関する法律/本文/第42条.md|第四十二条]]（これらの規定を[[laws/マンションの建替え等の円滑化に関する法律/本文/第138条.md|第百三十八条]]及び[[laws/マンションの建替え等の円滑化に関する法律/本文/第187条.md|第百八十七条]]において準用する場合を含む。）に規定する書類に記載すべき事項を記載せず、又は不実の記載をしたとき。[[laws/マンションの建替え等の円滑化に関する法律/本文/第41条.md|第四十一条]]（[[laws/マンションの建替え等の円滑化に関する法律/本文/第138条.md|第百三十八条]]及び[[laws/マンションの建替え等の円滑化に関する法律/本文/第187条.md|第百八十七条]]において準用する場合を含む。）の規定に違反して組合の残余財産を処分したとき。[[laws/マンションの建替え等の円滑化に関する法律/本文/第95条.md|第九十五条]]第一項、[[laws/マンションの建替え等の円滑化に関する法律/本文/第158条.md|第百五十八条]]第一項又は[[laws/マンションの建替え等の円滑化に関する法律/本文/第211条.md|第二百十一条]]第一項の規定に違反してこれらの規定に規定する簿書を備えず、又はその簿書に記載すべき事項を記載せず、若しくは不実の記載をしたとき。[[laws/マンションの建替え等の円滑化に関する法律/本文/第95条.md|第九十五条]]第二項、[[laws/マンションの建替え等の円滑化に関する法律/本文/第158条.md|第百五十八条]]第二項又は[[laws/マンションの建替え等の円滑化に関する法律/本文/第211条.md|第二百十一条]]第二項の規定に違反してこれらの規定に規定する簿書の閲覧を拒んだとき。都道府県知事等又は総会若しくは総代会に対し、不実の申立てをし、又は事実を隠したとき。この法律の規定による公告をせず、又は不実の公告をしたとき。

- 一 マンション建替組合がマンション建替事業以外の事業を営んだとき。
- 二 マンション敷地売却組合がマンション敷地売却事業以外の事業を営んだとき。
- 三 敷地分割組合が敷地分割事業以外の事業を営んだとき。
- 四 [[laws/マンションの建替え等の円滑化に関する法律/本文/第24条.md|第二十四条]]第八項（[[laws/マンションの建替え等の円滑化に関する法律/本文/第126条.md|第百二十六条]]第三項及び[[laws/マンションの建替え等の円滑化に関する法律/本文/第175条.md|第百七十五条]]第三項において準用する場合を含む。）の規定に違反して監事が理事又は組合の職員と兼ねたとき。
- 五 [[laws/マンションの建替え等の円滑化に関する法律/本文/第28条.md|第二十八条]]第一項、第三項又は第六項（[[laws/マンションの建替え等の円滑化に関する法律/本文/第31条.md|第三十一条]]第四項、[[laws/マンションの建替え等の円滑化に関する法律/本文/第129条.md|第百二十九条]]、[[laws/マンションの建替え等の円滑化に関する法律/本文/第131条.md|第百三十一条]]第四項、[[laws/マンションの建替え等の円滑化に関する法律/本文/第178条.md|第百七十八条]]及び[[laws/マンションの建替え等の円滑化に関する法律/本文/第180条.md|第百八十条]]第四項において準用する場合を含む。）の規定に違反して総会又は総代会を招集しなかったとき。
- 六 [[laws/マンションの建替え等の円滑化に関する法律/本文/第34条.md|第三十四条]]第三項、[[laws/マンションの建替え等の円滑化に関する法律/本文/第38条.md|第三十八条]]第三項、[[laws/マンションの建替え等の円滑化に関する法律/本文/第134条.md|第百三十四条]]第三項、[[laws/マンションの建替え等の円滑化に関する法律/本文/第137条.md|第百三十七条]]第三項、[[laws/マンションの建替え等の円滑化に関する法律/本文/第183条.md|第百八十三条]]第三項又は[[laws/マンションの建替え等の円滑化に関する法律/本文/第186条.md|第百八十六条]]第三項の規定に違反したとき。
- 七 [[laws/マンションの建替え等の円滑化に関する法律/本文/第40条.md|第四十条]]又は[[laws/マンションの建替え等の円滑化に関する法律/本文/第42条.md|第四十二条]]（これらの規定を[[laws/マンションの建替え等の円滑化に関する法律/本文/第138条.md|第百三十八条]]及び[[laws/マンションの建替え等の円滑化に関する法律/本文/第187条.md|第百八十七条]]において準用する場合を含む。）に規定する書類に記載すべき事項を記載せず、又は不実の記載をしたとき。
- 八 [[laws/マンションの建替え等の円滑化に関する法律/本文/第41条.md|第四十一条]]（[[laws/マンションの建替え等の円滑化に関する法律/本文/第138条.md|第百三十八条]]及び[[laws/マンションの建替え等の円滑化に関する法律/本文/第187条.md|第百八十七条]]において準用する場合を含む。）の規定に違反して組合の残余財産を処分したとき。
- 九 [[laws/マンションの建替え等の円滑化に関する法律/本文/第95条.md|第九十五条]]第一項、[[laws/マンションの建替え等の円滑化に関する法律/本文/第158条.md|第百五十八条]]第一項又は[[laws/マンションの建替え等の円滑化に関する法律/本文/第211条.md|第二百十一条]]第一項の規定に違反してこれらの規定に規定する簿書を備えず、又はその簿書に記載すべき事項を記載せず、若しくは不実の記載をしたとき。
- 十 [[laws/マンションの建替え等の円滑化に関する法律/本文/第95条.md|第九十五条]]第二項、[[laws/マンションの建替え等の円滑化に関する法律/本文/第158条.md|第百五十八条]]第二項又は[[laws/マンションの建替え等の円滑化に関する法律/本文/第211条.md|第二百十一条]]第二項の規定に違反してこれらの規定に規定する簿書の閲覧を拒んだとき。
- 十一 都道府県知事等又は総会若しくは総代会に対し、不実の申立てをし、又は事実を隠したとき。
- 十二 この法律の規定による公告をせず、又は不実の公告をしたとき。
