# 第三条 （試験の実施に係る基準）

## 
法[[laws/動物用医薬品の安全性に関する非臨床試験の実施の基準に関する省令/本文/第14条.md|第十四条]]又は[[laws/動物用医薬品の安全性に関する非臨床試験の実施の基準に関する省令/本文/第19条の2.md|第十九条の二]]の規定による承認を受けようとする者又は受けた者が行う試験の実施に係る法[[laws/動物用医薬品の安全性に関する非臨床試験の実施の基準に関する省令/本文/第14条.md|第十四条]]第三項及び第十二項並びに[[laws/動物用医薬品の安全性に関する非臨床試験の実施の基準に関する省令/本文/第14条の4.md|第十四条の四]]第五項及び[[laws/動物用医薬品の安全性に関する非臨床試験の実施の基準に関する省令/本文/第14条の6.md|第十四条の六]]第四項に規定する資料の収集及び作成については、次条から[[laws/動物用医薬品の安全性に関する非臨床試験の実施の基準に関する省令/本文/第19条.md|第十九条]]までに定めるところによる。
