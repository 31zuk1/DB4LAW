# 第二十五条 （補償の種類等）

## 
基金の行う補償の種類は、次に掲げるものとする。療養補償休業補償傷病補償年金障害補償障害補償年金障害補償一時金介護補償遺族補償遺族補償年金遺族補償一時金葬祭補償

- 一 療養補償
- 二 休業補償
- 三 傷病補償年金
- 四 障害補償
- 五 介護補償
- 六 遺族補償
- 七 葬祭補償
## ２
前項各号（第三号を除く。）に掲げる補償は、当該補償を受けるべき職員若しくは遺族又は葬祭を行う者の請求に基づいて行う。
