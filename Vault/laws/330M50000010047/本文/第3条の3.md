# 第三条の三 （登録簿の滅失）

## 
登記官は、登録簿の全部又は一部が滅失したときは、速やかに、その状況を調査し、当該登記官を監督する法務局又は地方法務局の長に対し、滅失の理由、その年月日、滅失した登録簿の冊数その他令[[laws/330M50000010047/本文/第10条.md|第十条]]の規定による告示をするのに必要な事項及び回復の登録に必要な期間を報告しなければならない。

## ２
前項の法務局又は地方法務局の長は、同項の報告を受けたときは、相当の調査をし、法務大臣に対し、意見を述べなければならない。
