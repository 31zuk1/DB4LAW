# 第七条 

## 
官地民木林台帳ニハ左ノ事項ヲ記載スヘシ記入番号官地民木林ノ所在、字、地番林別国有林野地籍台帳面積貸渡又ハ地上権設定区域ノ面積期間樹木ノ種類及数成立ノ原因貸賃又ハ地代ヲ徴収スルモノハ其ノ年額樹木所有者ノ氏名又ハ名称及住所成立ノ年月日指令番号

- 一 記入番号
- 二 官地民木林ノ所在、字、地番
- 三 林別
- 四 国有林野地籍台帳面積
- 五 貸渡又ハ地上権設定区域ノ面積
- 六 期間
- 七 樹木ノ種類及数
- 八 成立ノ原因
- 九 貸賃又ハ地代ヲ徴収スルモノハ其ノ年額
- 十 樹木所有者ノ氏名又ハ名称及住所
- 十一 成立ノ年月日
- 十二 指令番号
