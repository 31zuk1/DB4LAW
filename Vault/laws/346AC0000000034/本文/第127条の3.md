# 第百二十七条の三 （預金等の払戻しに関する会社法の特例）

## 
[[laws/346AC0000000034/本文/第69条の4.md|第六十九条の四]]第三項から第五項までの規定は、[[laws/346AC0000000034/本文/第127条.md|第百二十七条]]第一項において準用する[[laws/346AC0000000034/本文/第69条の3.md|第六十九条の三]]第一項の規定による資金の貸付けを行う旨の決定があるときについて準用する。この場合において、[[laws/346AC0000000034/本文/第69条の4.md|第六十九条の四]]第三項中「前条第一項に規定する決済債務の弁済」とあるのは「[[laws/346AC0000000034/本文/第127条.md|第百二十七条]]第一項に規定する支払対象預金等の払戻し」と、同条第四項及び第五項中「弁済を行う決済債務の種類」とあるのは「払戻しを行う支払対象預金等の種別」と、「弁済の」とあるのは「払戻しの」と、「弁済をする」とあるのは「払戻しをする」と読み替えるものとする。
