# 第三十一条 （許可の取消し等）

## 
財務大臣は、小売販売業者が次の各号のいずれかに該当するときは、[[laws/たばこ事業法/本文/第22条.md|第二十二条]]第一項の許可を取り消し、又は一月以内の期間を定めてその営業の停止を命ずることができる。[[laws/たばこ事業法/本文/第23条.md|第二十三条]]第一号に掲げる者に該当することとなつたとき。[[laws/たばこ事業法/本文/第24条.md|第二十四条]]第一項（[[laws/たばこ事業法/本文/第26条.md|第二十六条]]第二項において準用する場合を含む。）の規定による条件に違反したとき。[[laws/たばこ事業法/本文/第25条.md|第二十五条]]第一項、[[laws/たばこ事業法/本文/第26条.md|第二十六条]]第一項、[[laws/たばこ事業法/本文/第36条.md|第三十六条]]又は[[laws/たばこ事業法/本文/第39条.md|第三十九条]]第二項の規定に違反したとき。[[laws/たばこ事業法/本文/第27条.md|第二十七条]]第三項（[[laws/たばこ事業法/本文/第28条.md|第二十八条]]において準用する場合を含む。）又は前二条の規定による届出をせず、又は虚偽の届出をしたとき。この条の規定による命令に違反したとき。破産手続開始の決定を受けたとき。正当な理由がないのに、一月以内にその営業を開始せず、又は一月を超えて引き続きその営業を休止したとき。不正の手段により[[laws/たばこ事業法/本文/第22条.md|第二十二条]]第一項の許可を受けたとき。二十歳未満ノ者ノ喫煙ノ禁止ニ関スル法律（明治三十三年法律第三十三号）[[laws/たばこ事業法/本文/第5条.md|第五条]]の規定に違反して処罰されたとき。法人であつて、その代表者のうちに第一号、第六号又は前号に該当する者があるとき。未成年者であつて、その法定代理人が第一号、第六号、第九号又は前号に該当する者であるとき。

- 一 [[laws/たばこ事業法/本文/第23条.md|第二十三条]]第一号に掲げる者に該当することとなつたとき。
- 二 [[laws/たばこ事業法/本文/第24条.md|第二十四条]]第一項（[[laws/たばこ事業法/本文/第26条.md|第二十六条]]第二項において準用する場合を含む。）の規定による条件に違反したとき。
- 三 [[laws/たばこ事業法/本文/第25条.md|第二十五条]]第一項、[[laws/たばこ事業法/本文/第26条.md|第二十六条]]第一項、[[laws/たばこ事業法/本文/第36条.md|第三十六条]]又は[[laws/たばこ事業法/本文/第39条.md|第三十九条]]第二項の規定に違反したとき。
- 四 [[laws/たばこ事業法/本文/第27条.md|第二十七条]]第三項（[[laws/たばこ事業法/本文/第28条.md|第二十八条]]において準用する場合を含む。）又は前二条の規定による届出をせず、又は虚偽の届出をしたとき。
- 五 この条の規定による命令に違反したとき。
- 六 破産手続開始の決定を受けたとき。
- 七 正当な理由がないのに、一月以内にその営業を開始せず、又は一月を超えて引き続きその営業を休止したとき。
- 八 不正の手段により[[laws/たばこ事業法/本文/第22条.md|第二十二条]]第一項の許可を受けたとき。
- 九 二十歳未満ノ者ノ喫煙ノ禁止ニ関スル法律（明治三十三年法律第三十三号）[[laws/たばこ事業法/本文/第5条.md|第五条]]の規定に違反して処罰されたとき。
- 十 法人であつて、その代表者のうちに第一号、第六号又は前号に該当する者があるとき。
- 十一 未成年者であつて、その法定代理人が第一号、第六号、第九号又は前号に該当する者であるとき。
