# 第四十九条 

## 
次の各号の一に該当する者は、三十万円以下の罰金に処する。[[laws/359AC0000000068/本文/第20条.md|第二十条]]の規定に違反して、製造たばこの卸売販売を業として行つた者[[laws/359AC0000000068/本文/第21条.md|第二十一条]]において準用する[[laws/359AC0000000068/本文/第17条.md|第十七条]]の規定による営業の停止の命令に違反した者[[laws/359AC0000000068/本文/第22条.md|第二十二条]]第一項の規定に違反して、製造たばこの小売販売を業として行つた者[[laws/359AC0000000068/本文/第24条.md|第二十四条]]第一項（[[laws/359AC0000000068/本文/第26条.md|第二十六条]]第二項において準用する場合を含む。）の規定による条件に違反した者[[laws/359AC0000000068/本文/第25条.md|第二十五条]]第一項の規定に違反して、営業所を移転して製造たばこの小売販売を行つた者[[laws/359AC0000000068/本文/第26条.md|第二十六条]]第一項の規定に違反して、営業所以外の場所に出張して製造たばこの小売販売を行つた者[[laws/359AC0000000068/本文/第31条.md|第三十一条]]の規定による営業の停止の命令に違反した者[[laws/359AC0000000068/本文/第36条.md|第三十六条]]の規定に違反して、製造たばこの小売販売を行つた者

- 一 [[laws/359AC0000000068/本文/第20条.md|第二十条]]の規定に違反して、製造たばこの卸売販売を業として行つた者
- 二 [[laws/359AC0000000068/本文/第21条.md|第二十一条]]において準用する[[laws/359AC0000000068/本文/第17条.md|第十七条]]の規定による営業の停止の命令に違反した者
- 三 [[laws/359AC0000000068/本文/第22条.md|第二十二条]]第一項の規定に違反して、製造たばこの小売販売を業として行つた者
- 四 [[laws/359AC0000000068/本文/第24条.md|第二十四条]]第一項（[[laws/359AC0000000068/本文/第26条.md|第二十六条]]第二項において準用する場合を含む。）の規定による条件に違反した者
- 五 [[laws/359AC0000000068/本文/第25条.md|第二十五条]]第一項の規定に違反して、営業所を移転して製造たばこの小売販売を行つた者
- 六 [[laws/359AC0000000068/本文/第26条.md|第二十六条]]第一項の規定に違反して、営業所以外の場所に出張して製造たばこの小売販売を行つた者
- 七 [[laws/359AC0000000068/本文/第31条.md|第三十一条]]の規定による営業の停止の命令に違反した者
- 八 [[laws/359AC0000000068/本文/第36条.md|第三十六条]]の規定に違反して、製造たばこの小売販売を行つた者
