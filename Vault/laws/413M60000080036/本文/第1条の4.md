# 第一条の四 （業務方法書に記載すべき事項）

## 
機構に係る通則法[[laws/国立研究開発法人物質・材料研究機構に関する省令/本文/第28条.md|第二十八条]]第二項の主務省令で定める業務方法書に記載すべき事項は、次のとおりとする。機構法[[laws/国立研究開発法人物質・材料研究機構に関する省令/本文/第15条.md|第十五条]]第一号に規定する基礎研究及び基盤的研究開発に関する事項機構法[[laws/国立研究開発法人物質・材料研究機構に関する省令/本文/第15条.md|第十五条]]第二号に規定する成果の普及及び成果の活用の促進に関する事項機構法[[laws/国立研究開発法人物質・材料研究機構に関する省令/本文/第15条.md|第十五条]]第三号に規定する施設及び設備の共用に関する事項機構法[[laws/国立研究開発法人物質・材料研究機構に関する省令/本文/第15条.md|第十五条]]第四号に規定する研究者及び技術者の養成及び資質の向上に関する事項機構法[[laws/国立研究開発法人物質・材料研究機構に関する省令/本文/第15条.md|第十五条]]第五号に規定する出資並びに人的及び技術的援助に関する事項業務委託の基準競争入札その他契約に関する基本的事項その他機構の業務の執行に関して必要な事項

- 一 機構法[[laws/国立研究開発法人物質・材料研究機構に関する省令/本文/第15条.md|第十五条]]第一号に規定する基礎研究及び基盤的研究開発に関する事項
- 二 機構法[[laws/国立研究開発法人物質・材料研究機構に関する省令/本文/第15条.md|第十五条]]第二号に規定する成果の普及及び成果の活用の促進に関する事項
- 三 機構法[[laws/国立研究開発法人物質・材料研究機構に関する省令/本文/第15条.md|第十五条]]第三号に規定する施設及び設備の共用に関する事項
- 四 機構法[[laws/国立研究開発法人物質・材料研究機構に関する省令/本文/第15条.md|第十五条]]第四号に規定する研究者及び技術者の養成及び資質の向上に関する事項
- 五 機構法[[laws/国立研究開発法人物質・材料研究機構に関する省令/本文/第15条.md|第十五条]]第五号に規定する出資並びに人的及び技術的援助に関する事項
- 六 業務委託の基準
- 七 競争入札その他契約に関する基本的事項
- 八 その他機構の業務の執行に関して必要な事項
