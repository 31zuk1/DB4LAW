# 第三条 （保険証書の記載事項）

## 
法[[laws/森林保険法施行規則/本文/第7条.md|第七条]]の保険証書には、次に掲げる事項並びに記号及び番号を記載し、機構の理事長がこれに記名しなければならない。保険の目的の所在及び地番保険の目的の樹種、林齢及び面積並びに本数又は材積保険金額保険期間保険料及びその支払方法保険契約者及び被保険者又はその代表者の氏名又は名称保険証書作成の年月日

- 一 保険の目的の所在及び地番
- 二 保険の目的の樹種、林齢及び面積並びに本数又は材積
- 三 保険金額
- 四 保険期間
- 五 保険料及びその支払方法
- 六 保険契約者及び被保険者又はその代表者の氏名又は名称
- 七 保険証書作成の年月日
