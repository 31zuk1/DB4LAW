# 第四十六条 （予定納税額減額承認申請書の記載事項）

## 
法[[laws/所得税法施行規則/本文/第112条.md|第百十二条]]第一項（予定納税額の減額の承認の申請手続）に規定する財務省令で定める事項は、次に掲げる事項とする。法[[laws/所得税法施行規則/本文/第112条.md|第百十二条]]第一項に規定する申請書を提出する者の氏名及び住所（国内に住所がない場合には、居所）並びに住所地（国内に住所がない場合には、居所地）と納税地とが異なる場合には、その納税地その年分の総所得金額及び山林所得金額並びに課税総所得金額及び課税山林所得金額の見積額法[[laws/所得税法施行規則/本文/第90条.md|第九十条]]第一項（変動所得及び臨時所得の平均課税）の規定の適用を受けようとする場合には、その年分の変動所得及び臨時所得の金額の見積額並びに同条第三項に規定する平均課税対象金額の見積額前二号に掲げるもののほか、法[[laws/所得税法施行規則/本文/第112条.md|第百十二条]]第一項に規定する申請書に記載された同項に規定する申告納税見積額の計算の基礎法[[laws/所得税法施行規則/本文/第104条.md|第百四条]]第一項（予定納税額の納付）に規定する予定納税基準額次に掲げる場合の区分に応じ、それぞれ次に掲げる金額法[[laws/所得税法施行規則/本文/第111条.md|第百十一条]]第一項（予定納税額の減額の承認の申請）の規定による申請をする場合同項に規定する申告納税見積額の三分の一に相当する金額法[[laws/所得税法施行規則/本文/第111条.md|第百十一条]]第二項第一号に掲げる居住者が同項の規定による申請をする場合同項に規定する申告納税見積額から法[[laws/所得税法施行規則/本文/第104条.md|第百四条]]第一項の規定により第一期において納付すべき予定納税額（令和六年分の所得税につき当該居住者が当該申請をする場合には、租税特別措置法[[laws/所得税法施行規則/本文/第41条の3.md|第四十一条の三]]の六第四項第一号（令和六年分の所得税の予定納税額の減額の承認の申請の特例）に規定する控除前第一期予定納税額）を控除した金額の二分の一に相当する金額法[[laws/所得税法施行規則/本文/第111条.md|第百十一条]]第二項第二号に掲げる居住者が同項の規定による申請をする場合同項に規定する申告納税見積額の二分の一に相当する金額令和六年分の所得税につき法[[laws/所得税法施行規則/本文/第111条.md|第百十一条]]第一項又は第二項の規定による申請をする場合において、租税特別措置法[[laws/所得税法施行規則/本文/第41条の3.md|第四十一条の三]]の五第一項若しくは第二項（令和六年分の所得税に係る予定納税に係る特別控除の額の控除）又は[[laws/所得税法施行規則/本文/第41条の3.md|第四十一条の三]]の六第一項の規定の適用があるときは、同法第四十一条の三の五第三項に規定する予定納税特別控除額又は同法第四十一条の三の六第六項に規定する減額の承認に係る予定納税特別控除額租税特別措置法[[laws/所得税法施行規則/本文/第41条の3.md|第四十一条の三]]の六第四項第一号に規定する控除未済等予定納税特別控除額がある場合には、当該控除未済等予定納税特別控除額その他参考となるべき事項

- 一 法[[laws/所得税法施行規則/本文/第112条.md|第百十二条]]第一項に規定する申請書を提出する者の氏名及び住所（国内に住所がない場合には、居所）並びに住所地（国内に住所がない場合には、居所地）と納税地とが異なる場合には、その納税地
- 二 その年分の総所得金額及び山林所得金額並びに課税総所得金額及び課税山林所得金額の見積額
- 三 法[[laws/所得税法施行規則/本文/第90条.md|第九十条]]第一項（変動所得及び臨時所得の平均課税）の規定の適用を受けようとする場合には、その年分の変動所得及び臨時所得の金額の見積額並びに同条第三項に規定する平均課税対象金額の見積額
- 四 前二号に掲げるもののほか、法[[laws/所得税法施行規則/本文/第112条.md|第百十二条]]第一項に規定する申請書に記載された同項に規定する申告納税見積額の計算の基礎
- 五 法[[laws/所得税法施行規則/本文/第104条.md|第百四条]]第一項（予定納税額の納付）に規定する予定納税基準額
- 六 次に掲げる場合の区分に応じ、それぞれ次に掲げる金額
- 七 令和六年分の所得税につき法[[laws/所得税法施行規則/本文/第111条.md|第百十一条]]第一項又は第二項の規定による申請をする場合において、租税特別措置法[[laws/所得税法施行規則/本文/第41条の3.md|第四十一条の三]]の五第一項若しくは第二項（令和六年分の所得税に係る予定納税に係る特別控除の額の控除）又は[[laws/所得税法施行規則/本文/第41条の3.md|第四十一条の三]]の六第一項の規定の適用があるときは、同法第四十一条の三の五第三項に規定する予定納税特別控除額又は同法第四十一条の三の六第六項に規定する減額の承認に係る予定納税特別控除額
- 八 租税特別措置法[[laws/所得税法施行規則/本文/第41条の3.md|第四十一条の三]]の六第四項第一号に規定する控除未済等予定納税特別控除額がある場合には、当該控除未済等予定納税特別控除額
- 九 その他参考となるべき事項
