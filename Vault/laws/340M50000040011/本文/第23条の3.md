# 第二十三条の三 （分割型分割により取得した株式等の取得価額）

## 
令[[laws/340AC0000000033/本文/第113条.md|第百十三条]]第一項（分割型分割により取得した株式等の取得価額）に規定する財務省令で定める関係は、法人税法[[laws/340M50000040011/本文/第2条.md|第二条]]第十二号の九（定義）に規定する分割型分割の直前に当該分割型分割に係る同条第十二号の三に規定する分割承継法人と当該分割承継法人以外の法人との間に当該法人による完全支配関係がある場合の当該完全支配関係とする。
