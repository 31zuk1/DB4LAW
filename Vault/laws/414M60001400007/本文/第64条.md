# 第六十四条 （破砕業に係る変更の届出）

## 
法[[laws/414M60001400007/本文/第71条.md|第七十一条]]第一項の規定により変更の届出をしようとする破砕業者は、様式第十一による届出書に当該破砕業者が法[[laws/414M60001400007/本文/第62条.md|第六十二条]]第一項第二号イからヌまでのいずれにも該当しないことを誓約する書面及び次に掲げる書類（その届出に係る変更後の書類をいう。）を添えて、都道府県知事に届け出なければならない。破砕業者が個人であり、かつ、法[[laws/414M60001400007/本文/第68条.md|第六十八条]]第一項第一号に掲げる事項に変更があったとき住民票の写し及び法[[laws/414M60001400007/本文/第62条.md|第六十二条]]第一項第二号イに該当しないかどうかを審査するために必要と認められる書類破砕業者が法人であり、かつ、法[[laws/414M60001400007/本文/第68条.md|第六十八条]]第一項第一号に掲げる事項に変更があったとき定款又は寄附行為及び登記事項証明書法[[laws/414M60001400007/本文/第68条.md|第六十八条]]第一項第三号に掲げる事項に変更があったとき当該変更に係る事業所に関する[[laws/414M60001400007/本文/第60条.md|第六十条]]第一項第一号及び第二号に掲げる書類破砕業者が法人であり、かつ、法[[laws/414M60001400007/本文/第68条.md|第六十八条]]第一項第四号に掲げる役員に関する事項に変更があったとき当該変更に係る者の住民票の写し、法[[laws/414M60001400007/本文/第62条.md|第六十二条]]第一項第二号イに該当しないかどうかを審査するために必要と認められる書類及び登記事項証明書破砕業者が法人であり、かつ、法[[laws/414M60001400007/本文/第68条.md|第六十八条]]第一項第四号に掲げる使用人に関する事項に変更があったとき当該変更に係る者の住民票の写し及び法[[laws/414M60001400007/本文/第62条.md|第六十二条]]第一項第二号イに該当しないかどうかを審査するために必要と認められる書類破砕業者が未成年者であり、かつ、その法定代理人が個人である場合において、法[[laws/414M60001400007/本文/第68条.md|第六十八条]]第一項第五号に掲げる事項に変更があったときその法定代理人の住民票の写し及び法[[laws/414M60001400007/本文/第62条.md|第六十二条]]第一項第二号イに該当しないかどうかを審査するために必要と認められる書類破砕業者が未成年者であり、かつ、その法定代理人が法人である場合において、法[[laws/414M60001400007/本文/第68条.md|第六十八条]]第一項第五号に掲げる事項のうち、名称及び住所並びにその代表者の氏名のいずれかに変更があったとき定款又は寄附行為及び登記事項証明書破砕業者が未成年者であり、かつ、その法定代理人が法人である場合において、法[[laws/414M60001400007/本文/第68条.md|第六十八条]]第一項第五号に掲げる事項のうち、役員に関する事項に変更があったとき当該変更に係る者の住民票の写し、法[[laws/414M60001400007/本文/第62条.md|第六十二条]]第一項第二号イに該当しないかどうかを審査するために必要と認められる書類及び登記事項証明書法[[laws/414M60001400007/本文/第68条.md|第六十八条]]第一項第六号に掲げる事項に変更があったとき当該変更に係る施設に関する[[laws/414M60001400007/本文/第60条.md|第六十条]]第一項第一号及び第二号に掲げる書類破砕業者が法人であり、かつ、[[laws/414M60001400007/本文/第60条.md|第六十条]]第四項第五号に掲げる事項に変更があったとき当該変更に係る者の有する株式の数又は当該変更に係る者のなした出資の金額を記載した書類並びに当該変更に係る者の住民票の写し及び法[[laws/414M60001400007/本文/第62条.md|第六十二条]]第一項第二号イに該当しないかどうかを審査するために必要と認められる書類（これらの者が法人である場合には、登記事項証明書）破砕業者が個人であり、かつ、[[laws/414M60001400007/本文/第60条.md|第六十条]]第四項第六号に掲げる事項に変更があったとき当該変更に係る者の住民票の写し及び法[[laws/414M60001400007/本文/第62条.md|第六十二条]]第一項第二号イに該当しないかどうかを審査するために必要と認められる書類

- 一 破砕業者が個人であり、かつ、法[[laws/414M60001400007/本文/第68条.md|第六十八条]]第一項第一号に掲げる事項に変更があったとき住民票の写し及び法[[laws/414M60001400007/本文/第62条.md|第六十二条]]第一項第二号イに該当しないかどうかを審査するために必要と認められる書類
- 二 破砕業者が法人であり、かつ、法[[laws/414M60001400007/本文/第68条.md|第六十八条]]第一項第一号に掲げる事項に変更があったとき定款又は寄附行為及び登記事項証明書
- 三 法[[laws/414M60001400007/本文/第68条.md|第六十八条]]第一項第三号に掲げる事項に変更があったとき当該変更に係る事業所に関する[[laws/414M60001400007/本文/第60条.md|第六十条]]第一項第一号及び第二号に掲げる書類
- 四 破砕業者が法人であり、かつ、法[[laws/414M60001400007/本文/第68条.md|第六十八条]]第一項第四号に掲げる役員に関する事項に変更があったとき当該変更に係る者の住民票の写し、法[[laws/414M60001400007/本文/第62条.md|第六十二条]]第一項第二号イに該当しないかどうかを審査するために必要と認められる書類及び登記事項証明書
- 五 破砕業者が法人であり、かつ、法[[laws/414M60001400007/本文/第68条.md|第六十八条]]第一項第四号に掲げる使用人に関する事項に変更があったとき当該変更に係る者の住民票の写し及び法[[laws/414M60001400007/本文/第62条.md|第六十二条]]第一項第二号イに該当しないかどうかを審査するために必要と認められる書類
- 六 破砕業者が未成年者であり、かつ、その法定代理人が個人である場合において、法[[laws/414M60001400007/本文/第68条.md|第六十八条]]第一項第五号に掲げる事項に変更があったときその法定代理人の住民票の写し及び法[[laws/414M60001400007/本文/第62条.md|第六十二条]]第一項第二号イに該当しないかどうかを審査するために必要と認められる書類
- 七 破砕業者が未成年者であり、かつ、その法定代理人が法人である場合において、法[[laws/414M60001400007/本文/第68条.md|第六十八条]]第一項第五号に掲げる事項のうち、名称及び住所並びにその代表者の氏名のいずれかに変更があったとき定款又は寄附行為及び登記事項証明書
- 八 破砕業者が未成年者であり、かつ、その法定代理人が法人である場合において、法[[laws/414M60001400007/本文/第68条.md|第六十八条]]第一項第五号に掲げる事項のうち、役員に関する事項に変更があったとき当該変更に係る者の住民票の写し、法[[laws/414M60001400007/本文/第62条.md|第六十二条]]第一項第二号イに該当しないかどうかを審査するために必要と認められる書類及び登記事項証明書
- 九 法[[laws/414M60001400007/本文/第68条.md|第六十八条]]第一項第六号に掲げる事項に変更があったとき当該変更に係る施設に関する[[laws/414M60001400007/本文/第60条.md|第六十条]]第一項第一号及び第二号に掲げる書類
- 十 破砕業者が法人であり、かつ、[[laws/414M60001400007/本文/第60条.md|第六十条]]第四項第五号に掲げる事項に変更があったとき当該変更に係る者の有する株式の数又は当該変更に係る者のなした出資の金額を記載した書類並びに当該変更に係る者の住民票の写し及び法[[laws/414M60001400007/本文/第62条.md|第六十二条]]第一項第二号イに該当しないかどうかを審査するために必要と認められる書類（これらの者が法人である場合には、登記事項証明書）
- 十一 破砕業者が個人であり、かつ、[[laws/414M60001400007/本文/第60条.md|第六十条]]第四項第六号に掲げる事項に変更があったとき当該変更に係る者の住民票の写し及び法[[laws/414M60001400007/本文/第62条.md|第六十二条]]第一項第二号イに該当しないかどうかを審査するために必要と認められる書類
