# 第百二十条 

## 
法[[laws/使用済自動車の再資源化等に関する法律施行規則/本文/第100条.md|第百条]]の主務省令で定める事項は、次のとおりとする。法[[laws/使用済自動車の再資源化等に関する法律施行規則/本文/第73条.md|第七十三条]]第一項から第三項までの規定により預託された再資源化等預託金の額の総額法[[laws/使用済自動車の再資源化等に関する法律施行規則/本文/第73条.md|第七十三条]]第四項の規定により預託された情報管理預託金の額の総額法[[laws/使用済自動車の再資源化等に関する法律施行規則/本文/第76条.md|第七十六条]]第一項（同条第三項において準用する場合を含む。）又は第四項の規定による請求に基づき自動車製造業者等又は指定再資源化機関に払い渡した再資源化等預託金の額の総額法[[laws/使用済自動車の再資源化等に関する法律施行規則/本文/第76条.md|第七十六条]]第六項の規定による請求に基づき情報管理センターに払い渡した情報管理預託金の額の総額法[[laws/使用済自動車の再資源化等に関する法律施行規則/本文/第78条.md|第七十八条]]第一項の規定により自動車の所有者に払い渡した再資源化預託金等の額の総額再資源化預託金等を運用して得た利息その他の運用利益金の総額

- 一 法[[laws/使用済自動車の再資源化等に関する法律施行規則/本文/第73条.md|第七十三条]]第一項から第三項までの規定により預託された再資源化等預託金の額の総額
- 二 法[[laws/使用済自動車の再資源化等に関する法律施行規則/本文/第73条.md|第七十三条]]第四項の規定により預託された情報管理預託金の額の総額
- 三 法[[laws/使用済自動車の再資源化等に関する法律施行規則/本文/第76条.md|第七十六条]]第一項（同条第三項において準用する場合を含む。）又は第四項の規定による請求に基づき自動車製造業者等又は指定再資源化機関に払い渡した再資源化等預託金の額の総額
- 四 法[[laws/使用済自動車の再資源化等に関する法律施行規則/本文/第76条.md|第七十六条]]第六項の規定による請求に基づき情報管理センターに払い渡した情報管理預託金の額の総額
- 五 法[[laws/使用済自動車の再資源化等に関する法律施行規則/本文/第78条.md|第七十八条]]第一項の規定により自動車の所有者に払い渡した再資源化預託金等の額の総額
- 六 再資源化預託金等を運用して得た利息その他の運用利益金の総額
