# 第八十一条 （内閣府令への委任）

## 
この法律に定めるもののほか、この法律の規定による認可、承認、登録、認定又は指定に関する申請の手続、書類の提出の手続その他この法律を実施するため必要な事項は、内閣府令で定める。
