# 第百五十一条 

## 
次の各号のいずれかに該当するときは、その違反行為をした者は、三十万円以下の罰金に処する。[[laws/金融サービスの提供及び利用環境の整備等に関する法律/本文/第19条.md|第十九条]]の規定に違反したとき。[[laws/金融サービスの提供及び利用環境の整備等に関する法律/本文/第20条.md|第二十条]]第一項又は第二項の規定に違反したとき。[[laws/金融サービスの提供及び利用環境の整備等に関する法律/本文/第20条.md|第二十条]]第三項の規定に違反して同条第一項の規定による標識又はこれに類似する標識を掲示したとき。[[laws/金融サービスの提供及び利用環境の整備等に関する法律/本文/第47条.md|第四十七条]]後段の規定に違反したとき。[[laws/金融サービスの提供及び利用環境の整備等に関する法律/本文/第57条.md|第五十七条]]第一項に規定する報告をせず、又は虚偽の報告をしたとき。[[laws/金融サービスの提供及び利用環境の整備等に関する法律/本文/第67条.md|第六十七条]]第一項、[[laws/金融サービスの提供及び利用環境の整備等に関する法律/本文/第68条.md|第六十八条]]又は[[laws/金融サービスの提供及び利用環境の整備等に関する法律/本文/第72条.md|第七十二条]]第二項の規定による届出をせず、又は虚偽の届出をしたとき。[[laws/金融サービスの提供及び利用環境の整備等に関する法律/本文/第72条.md|第七十二条]]第三項又は[[laws/金融サービスの提供及び利用環境の整備等に関する法律/本文/第73条.md|第七十三条]]第四項の規定に違反して通知をせず、又は虚偽の通知をしたとき。[[laws/金融サービスの提供及び利用環境の整備等に関する法律/本文/第77条.md|第七十七条]]において準用する金融商品取引法第六十四条の四の規定による届出をせず、又は虚偽の届出をしたとき。[[laws/金融サービスの提供及び利用環境の整備等に関する法律/本文/第78条.md|第七十八条]]第四項の規定に違反したとき。

- 一 [[laws/金融サービスの提供及び利用環境の整備等に関する法律/本文/第19条.md|第十九条]]の規定に違反したとき。
- 二 [[laws/金融サービスの提供及び利用環境の整備等に関する法律/本文/第20条.md|第二十条]]第一項又は第二項の規定に違反したとき。
- 三 [[laws/金融サービスの提供及び利用環境の整備等に関する法律/本文/第20条.md|第二十条]]第三項の規定に違反して同条第一項の規定による標識又はこれに類似する標識を掲示したとき。
- 四 [[laws/金融サービスの提供及び利用環境の整備等に関する法律/本文/第47条.md|第四十七条]]後段の規定に違反したとき。
- 五 [[laws/金融サービスの提供及び利用環境の整備等に関する法律/本文/第57条.md|第五十七条]]第一項に規定する報告をせず、又は虚偽の報告をしたとき。
- 六 [[laws/金融サービスの提供及び利用環境の整備等に関する法律/本文/第67条.md|第六十七条]]第一項、[[laws/金融サービスの提供及び利用環境の整備等に関する法律/本文/第68条.md|第六十八条]]又は[[laws/金融サービスの提供及び利用環境の整備等に関する法律/本文/第72条.md|第七十二条]]第二項の規定による届出をせず、又は虚偽の届出をしたとき。
- 七 [[laws/金融サービスの提供及び利用環境の整備等に関する法律/本文/第72条.md|第七十二条]]第三項又は[[laws/金融サービスの提供及び利用環境の整備等に関する法律/本文/第73条.md|第七十三条]]第四項の規定に違反して通知をせず、又は虚偽の通知をしたとき。
- 八 [[laws/金融サービスの提供及び利用環境の整備等に関する法律/本文/第77条.md|第七十七条]]において準用する金融商品取引法第六十四条の四の規定による届出をせず、又は虚偽の届出をしたとき。
- 九 [[laws/金融サービスの提供及び利用環境の整備等に関する法律/本文/第78条.md|第七十八条]]第四項の規定に違反したとき。
