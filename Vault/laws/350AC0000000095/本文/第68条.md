# 第六十八条 

## 
次の各号のいずれかに該当する者は、三十万円以下の罰金に処する。[[laws/350AC0000000095/本文/第19条.md|第十九条]]（[[laws/350AC0000000095/本文/第44条.md|第四十四条]]及び[[laws/350AC0000000095/本文/第52条.md|第五十二条]]において準用する場合を含む。）の規定に違反した者[[laws/350AC0000000095/本文/第20条.md|第二十条]]第一項、[[laws/350AC0000000095/本文/第45条.md|第四十五条]]第一項又は[[laws/350AC0000000095/本文/第53条.md|第五十三条]]第一項の規定に違反した者[[laws/350AC0000000095/本文/第20条.md|第二十条]]第二項、[[laws/350AC0000000095/本文/第45条.md|第四十五条]]第二項又は[[laws/350AC0000000095/本文/第53条.md|第五十三条]]第二項の規定の違反となるような行為をした者[[laws/350AC0000000095/本文/第28条.md|第二十八条]]第一項又は第二項の規定による報告をせず、又は虚偽の報告をした者[[laws/350AC0000000095/本文/第58条.md|第五十八条]]第一項の規定による通報をせず、又は虚偽の通報をして入港をした船長[[laws/350AC0000000095/本文/第58条.md|第五十八条]]第二項の規定による通報に際して虚偽の通報をした者（当該特定船舶が入港をした場合に限る。）[[laws/350AC0000000095/本文/第58条.md|第五十八条]]第三項の規定による通報をせず、又は虚偽の通報をした船長[[laws/350AC0000000095/本文/第59条.md|第五十九条]]第一項の規定による報告をせず、又は虚偽の報告をした者[[laws/350AC0000000095/本文/第59条.md|第五十九条]]第一項の規定による検査を拒み、妨げ、若しくは忌避し、又は質問に対し陳述をせず、若しくは虚偽の陳述をした者[[laws/350AC0000000095/本文/第59条.md|第五十九条]]第二項の規定による報告をせず、若しくは資料の提出をせず、又は虚偽の報告をし、若しくは虚偽の資料の提出をした者

- 一 [[laws/350AC0000000095/本文/第19条.md|第十九条]]（[[laws/350AC0000000095/本文/第44条.md|第四十四条]]及び[[laws/350AC0000000095/本文/第52条.md|第五十二条]]において準用する場合を含む。）の規定に違反した者
- 二 [[laws/350AC0000000095/本文/第20条.md|第二十条]]第一項、[[laws/350AC0000000095/本文/第45条.md|第四十五条]]第一項又は[[laws/350AC0000000095/本文/第53条.md|第五十三条]]第一項の規定に違反した者
- 三 [[laws/350AC0000000095/本文/第20条.md|第二十条]]第二項、[[laws/350AC0000000095/本文/第45条.md|第四十五条]]第二項又は[[laws/350AC0000000095/本文/第53条.md|第五十三条]]第二項の規定の違反となるような行為をした者
- 四 [[laws/350AC0000000095/本文/第28条.md|第二十八条]]第一項又は第二項の規定による報告をせず、又は虚偽の報告をした者
- 五 [[laws/350AC0000000095/本文/第58条.md|第五十八条]]第一項の規定による通報をせず、又は虚偽の通報をして入港をした船長
- 六 [[laws/350AC0000000095/本文/第58条.md|第五十八条]]第二項の規定による通報に際して虚偽の通報をした者（当該特定船舶が入港をした場合に限る。）
- 七 [[laws/350AC0000000095/本文/第58条.md|第五十八条]]第三項の規定による通報をせず、又は虚偽の通報をした船長
- 八 [[laws/350AC0000000095/本文/第59条.md|第五十九条]]第一項の規定による報告をせず、又は虚偽の報告をした者
- 九 [[laws/350AC0000000095/本文/第59条.md|第五十九条]]第一項の規定による検査を拒み、妨げ、若しくは忌避し、又は質問に対し陳述をせず、若しくは虚偽の陳述をした者
- 十 [[laws/350AC0000000095/本文/第59条.md|第五十九条]]第二項の規定による報告をせず、若しくは資料の提出をせず、又は虚偽の報告をし、若しくは虚偽の資料の提出をした者
