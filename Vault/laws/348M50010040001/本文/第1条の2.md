# 第一条の二 （業務方法書の記載事項）

## 
農水産業協同組合貯金保険法（昭和四十八年法律第五十三号。以下「法」という。）[[laws/348M50010040001/本文/第36条.md|第三十六条]]第二項に規定する主務省令で定める事項は、次に掲げる事項とする。保険関係に関する事項保険金及び仮払金に関する事項法[[laws/348AC0000000053/本文/第60条.md|第六十条]]第一項若しくは第三項の規定により取得し、又は法[[laws/348AC0000000053/本文/第70条.md|第七十条]]第一項の買取りを行うことにより取得した債権の行使に関する事項法[[laws/348AC0000000053/本文/第69条の3.md|第六十九条の三]]の規定による資金の貸付けに関する事項資金援助に関する事項貯金等債権の買取りに関する事項法第五章の規定による協定債権回収会社に対する出資その他同章の規定による業務に関する事項法[[laws/348AC0000000053/本文/第86条.md|第八十六条]]第二項の規定による管理人又は管理人代理の業務に関する事項法第七章の規定による優先出資の引受け等その他同章の規定による業務に関する事項法第七章の二の規定による特別監視その他同章の規定による業務に関する事項法[[laws/348AC0000000053/本文/第111条.md|第百十一条]]又は法[[laws/348AC0000000053/本文/第112条.md|第百十二条]]においてそれぞれ準用する法[[laws/348AC0000000053/本文/第69条の3.md|第六十九条の三]]の規定による資金の貸付け及び法[[laws/348AC0000000053/本文/第112条の2.md|第百十二条の二]]の規定による資産の買取りに関する事項農水産業協同組合の再生手続の特例等に関する法律（平成十二年法律第九十五号）第二章及び第三章の規定による貯金者表の提出その他これらの規定による業務に関する事項業務の委託に関する事項その他法[[laws/348M50010040001/本文/第34条.md|第三十四条]]に規定する業務の方法

- 一 保険関係に関する事項
- 二 保険金及び仮払金に関する事項
- 三 法[[laws/348AC0000000053/本文/第60条.md|第六十条]]第一項若しくは第三項の規定により取得し、又は法[[laws/348AC0000000053/本文/第70条.md|第七十条]]第一項の買取りを行うことにより取得した債権の行使に関する事項
- 四 法[[laws/348AC0000000053/本文/第69条の3.md|第六十九条の三]]の規定による資金の貸付けに関する事項
- 五 資金援助に関する事項
- 六 貯金等債権の買取りに関する事項
- 七 法第五章の規定による協定債権回収会社に対する出資その他同章の規定による業務に関する事項
- 八 法[[laws/348AC0000000053/本文/第86条.md|第八十六条]]第二項の規定による管理人又は管理人代理の業務に関する事項
- 九 法第七章の規定による優先出資の引受け等その他同章の規定による業務に関する事項
- 十 法第七章の二の規定による特別監視その他同章の規定による業務に関する事項
- 十一 法[[laws/348AC0000000053/本文/第111条.md|第百十一条]]又は法[[laws/348AC0000000053/本文/第112条.md|第百十二条]]においてそれぞれ準用する法[[laws/348AC0000000053/本文/第69条の3.md|第六十九条の三]]の規定による資金の貸付け及び法[[laws/348AC0000000053/本文/第112条の2.md|第百十二条の二]]の規定による資産の買取りに関する事項
- 十二 農水産業協同組合の再生手続の特例等に関する法律（平成十二年法律第九十五号）第二章及び第三章の規定による貯金者表の提出その他これらの規定による業務に関する事項
- 十三 業務の委託に関する事項
- 十四 その他法[[laws/348M50010040001/本文/第34条.md|第三十四条]]に規定する業務の方法
