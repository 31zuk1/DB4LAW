# 第六十条 

## 
次の各号のいずれかに該当する場合においては、組合の発起人、理事、監事、参事、清算人又は[[laws/船主相互保険組合法/本文/第52条.md|第五十二条]]第二項において準用する保険業法第二百四十二条第二項若しくは第四項の規定により選任された保険管理人は、十万円以下の過料に処する。この法律又はこの法律において準用する保険業法若しくは会社法の規定による公告若しくは届出をすることを怠り、又は不正の公告若しくは届出をしたとき。[[laws/船主相互保険組合法/本文/第11条.md|第十一条]]第一項の規定に基づく政令に違反して、登記をすることを怠つたとき。[[laws/船主相互保険組合法/本文/第21条.md|第二十一条]]第五項の規定に違反したとき。[[laws/船主相互保険組合法/本文/第26条.md|第二十六条]]第一項の規定に違反して、組合員の持分を取得し、又は質権の目的としてこれを受けたとき。[[laws/船主相互保険組合法/本文/第26条.md|第二十六条]]第二項の規定に違反して組合員の持分を処分することを怠つたとき。[[laws/船主相互保険組合法/本文/第27条.md|第二十七条]]第四項の規定に違反して弁明の機会を与えなかつたとき。[[laws/船主相互保険組合法/本文/第30条.md|第三十条]]第一項（[[laws/船主相互保険組合法/本文/第48条.md|第四十八条]]第二項において準用する場合を含む。）の規定に違反して総会を招集しなかつたとき。[[laws/船主相互保険組合法/本文/第33条の2.md|第三十三条の二]]第一項（[[laws/船主相互保険組合法/本文/第15条.md|第十五条]]第七項において準用する場合を含む。）の規定又は[[laws/船主相互保険組合法/本文/第48条.md|第四十八条]]第一項において準用する会社法[[laws/会社法/本文/第492条.md|第四百九十二条]]第一項若しくは[[laws/会社法/本文/第507条.md|第五百七条]]第一項の規定に違反して、書類若しくは電磁的記録を作成せず、又は書類若しくは電磁的記録に記載し、若しくは記録すべき事項を記載せず、若しくは記録せず、若しくは虚偽の記載若しくは記録をしたとき。[[laws/船主相互保険組合法/本文/第33条の2.md|第三十三条の二]]第二項若しくは第三項（[[laws/船主相互保険組合法/本文/第15条.md|第十五条]]第七項において準用する場合を含む。）、[[laws/会社法/本文/第38条.md|第三十八条]]第一項（[[laws/船主相互保険組合法/本文/第48条.md|第四十八条]]第二項において準用する場合を含む。）若しくは[[laws/会社法/本文/第44条の6.md|第四十四条の六]]第一項若しくは第二項の規定又は[[laws/船主相互保険組合法/本文/第48条.md|第四十八条]]第一項において準用する会社法[[laws/会社法/本文/第496条.md|第四百九十六条]]第一項の規定に違反して、書類又は電磁的記録を備え置かなかつたとき。[[laws/船主相互保険組合法/本文/第33条の2.md|第三十三条の二]]第四項（[[laws/船主相互保険組合法/本文/第15条.md|第十五条]]第七項又は[[laws/会社法/本文/第38条.md|第三十八条]]第三項において準用する場合を含む。）の規定、[[laws/船主相互保険組合法/本文/第40条.md|第四十条]]において準用する会社法[[laws/会社法/本文/第389条.md|第三百八十九条]]第四項の規定、[[laws/会社法/本文/第44条の2.md|第四十四条の二]]若しくは[[laws/会社法/本文/第44条の6.md|第四十四条の六]]第三項の規定又は[[laws/会社法/本文/第48条.md|第四十八条]]第一項において準用する同法第四百九十六条第二項の規定に違反して、正当な理由がないのに、書類若しくは電磁的記録に記録された事項を内閣府令で定める方法により表示したものの閲覧若しくは謄写又は書類の謄本若しくは抄本の交付、電磁的記録に記録された事項を電磁的方法により提供すること若しくはその事項を記載した書面の交付を拒んだとき。[[laws/船主相互保険組合法/本文/第36条.md|第三十六条]]第一項又は第二項（これらの規定を[[laws/船主相互保険組合法/本文/第48条.md|第四十八条]]第二項において準用する場合を含む。）の規定に違反したとき。組合員名簿、監査報告、会計帳簿、計算書類、事業報告、事務報告又は[[laws/船主相互保険組合法/本文/第44条の4.md|第四十四条の四]]第二項若しくは[[laws/船主相互保険組合法/本文/第48条.md|第四十八条]]第一項において準用する同法第四百九十四条第一項の附属明細書に記載し、若しくは記録すべき事項を記載せず、若しくは記録せず、又は虚偽の記載若しくは記録をしたとき。[[laws/船主相互保険組合法/本文/第45条の2.md|第四十五条の二]]又は[[laws/船主相互保険組合法/本文/第45条の4.md|第四十五条の四]]第二項若しくは第五項の規定に違反して組合の合併をしたとき。[[laws/船主相互保険組合法/本文/第52条.md|第五十二条]]第二項において準用する保険業法第二百四十三条第二項の規定に違反して、正当な理由がないのに、保険管理人となることを拒否したとき。[[laws/船主相互保険組合法/本文/第55条.md|第五十五条]]第三項において準用する会社法[[laws/会社法/本文/第941条.md|第九百四十一条]]の規定に違反して同条の調査を求めなかつたとき。

- 一 この法律又はこの法律において準用する保険業法若しくは会社法の規定による公告若しくは届出をすることを怠り、又は不正の公告若しくは届出をしたとき。
- 二 [[laws/船主相互保険組合法/本文/第11条.md|第十一条]]第一項の規定に基づく政令に違反して、登記をすることを怠つたとき。
- 三 [[laws/船主相互保険組合法/本文/第21条.md|第二十一条]]第五項の規定に違反したとき。
- 四 [[laws/船主相互保険組合法/本文/第26条.md|第二十六条]]第一項の規定に違反して、組合員の持分を取得し、又は質権の目的としてこれを受けたとき。
- 五 [[laws/船主相互保険組合法/本文/第26条.md|第二十六条]]第二項の規定に違反して組合員の持分を処分することを怠つたとき。
- 六 [[laws/船主相互保険組合法/本文/第27条.md|第二十七条]]第四項の規定に違反して弁明の機会を与えなかつたとき。
- 七 [[laws/船主相互保険組合法/本文/第30条.md|第三十条]]第一項（[[laws/船主相互保険組合法/本文/第48条.md|第四十八条]]第二項において準用する場合を含む。）の規定に違反して総会を招集しなかつたとき。
- 八 [[laws/船主相互保険組合法/本文/第33条の2.md|第三十三条の二]]第一項（[[laws/船主相互保険組合法/本文/第15条.md|第十五条]]第七項において準用する場合を含む。）の規定又は[[laws/船主相互保険組合法/本文/第48条.md|第四十八条]]第一項において準用する会社法[[laws/会社法/本文/第492条.md|第四百九十二条]]第一項若しくは[[laws/会社法/本文/第507条.md|第五百七条]]第一項の規定に違反して、書類若しくは電磁的記録を作成せず、又は書類若しくは電磁的記録に記載し、若しくは記録すべき事項を記載せず、若しくは記録せず、若しくは虚偽の記載若しくは記録をしたとき。
- 九 [[laws/船主相互保険組合法/本文/第33条の2.md|第三十三条の二]]第二項若しくは第三項（[[laws/船主相互保険組合法/本文/第15条.md|第十五条]]第七項において準用する場合を含む。）、[[laws/船主相互保険組合法/本文/第38条.md|第三十八条]]第一項（[[laws/船主相互保険組合法/本文/第48条.md|第四十八条]]第二項において準用する場合を含む。）若しくは[[laws/船主相互保険組合法/本文/第44条の6.md|第四十四条の六]]第一項若しくは第二項の規定又は[[laws/船主相互保険組合法/本文/第48条.md|第四十八条]]第一項において準用する会社法[[laws/会社法/本文/第496条.md|第四百九十六条]]第一項の規定に違反して、書類又は電磁的記録を備え置かなかつたとき。
- 十 [[laws/船主相互保険組合法/本文/第33条の2.md|第三十三条の二]]第四項（[[laws/船主相互保険組合法/本文/第15条.md|第十五条]]第七項又は[[laws/船主相互保険組合法/本文/第38条.md|第三十八条]]第三項において準用する場合を含む。）の規定、[[laws/船主相互保険組合法/本文/第40条.md|第四十条]]において準用する会社法[[laws/会社法/本文/第389条.md|第三百八十九条]]第四項の規定、[[laws/会社法/本文/第44条の2.md|第四十四条の二]]若しくは[[laws/会社法/本文/第44条の6.md|第四十四条の六]]第三項の規定又は[[laws/会社法/本文/第48条.md|第四十八条]]第一項において準用する同法第四百九十六条第二項の規定に違反して、正当な理由がないのに、書類若しくは電磁的記録に記録された事項を内閣府令で定める方法により表示したものの閲覧若しくは謄写又は書類の謄本若しくは抄本の交付、電磁的記録に記録された事項を電磁的方法により提供すること若しくはその事項を記載した書面の交付を拒んだとき。
- 十一 [[laws/船主相互保険組合法/本文/第36条.md|第三十六条]]第一項又は第二項（これらの規定を[[laws/船主相互保険組合法/本文/第48条.md|第四十八条]]第二項において準用する場合を含む。）の規定に違反したとき。
- 十二 組合員名簿、監査報告、会計帳簿、計算書類、事業報告、事務報告又は[[laws/船主相互保険組合法/本文/第44条の4.md|第四十四条の四]]第二項若しくは[[laws/船主相互保険組合法/本文/第48条.md|第四十八条]]第一項において準用する同法第四百九十四条第一項の附属明細書に記載し、若しくは記録すべき事項を記載せず、若しくは記録せず、又は虚偽の記載若しくは記録をしたとき。
- 十三 [[laws/船主相互保険組合法/本文/第45条の2.md|第四十五条の二]]又は[[laws/船主相互保険組合法/本文/第45条の4.md|第四十五条の四]]第二項若しくは第五項の規定に違反して組合の合併をしたとき。
- 十四 [[laws/船主相互保険組合法/本文/第52条.md|第五十二条]]第二項において準用する保険業法第二百四十三条第二項の規定に違反して、正当な理由がないのに、保険管理人となることを拒否したとき。
- 十五 [[laws/船主相互保険組合法/本文/第55条.md|第五十五条]]第三項において準用する会社法[[laws/会社法/本文/第941条.md|第九百四十一条]]の規定に違反して同条の調査を求めなかつたとき。
