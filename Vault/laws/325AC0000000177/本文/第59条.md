# 第五十九条 

## 
次の各号のいずれかに該当する場合においては、組合の発起人、理事、監事、参事、設立委員、清算人又は[[laws/船主相互保険組合法/本文/第52条.md|第五十二条]]第二項において準用する保険業法第二百四十二条第二項若しくは第四項の規定により選任された保険管理人は、二十万円以下の過料に処する。この法律又はこの法律において準用する保険業法の規定に基づいてする内閣総理大臣の命令に違反したとき。[[laws/船主相互保険組合法/本文/第4条.md|第四条]]第一項ただし書若しくは第二項ただし書の規定に違反したとき、同条第三項の規定に違反して承認を受けないで同条第一項各号若しくは第二項各号に掲げる事業を行つたとき、又は同条第五項の規定に違反したとき。[[laws/船主相互保険組合法/本文/第6条.md|第六条]]の規定に違反したとき。[[laws/船主相互保険組合法/本文/第16条.md|第十六条]]第四項の規定に違反して、認可を受けないで同条第二項第一号から第三号までに掲げる書類に記載した事項を変更したとき。[[laws/船主相互保険組合法/本文/第35条.md|第三十五条]]第二項ただし書（[[laws/船主相互保険組合法/本文/第15条.md|第十五条]]第七項において準用する場合を含む。）又は[[laws/船主相互保険組合法/本文/第45条の6.md|第四十五条の六]]第二項ただし書の規定に違反して、認可を受けないで理事又は監事を選任したとき。[[laws/船主相互保険組合法/本文/第41条.md|第四十一条]]第一項の規定に違反して書類を提出しなかつたとき。[[laws/船主相互保険組合法/本文/第42条.md|第四十二条]]、[[laws/船主相互保険組合法/本文/第46条の2.md|第四十六条の二]]若しくは[[laws/船主相互保険組合法/本文/第46条の3.md|第四十六条の三]]の規定若しくは[[laws/船主相互保険組合法/本文/第48条.md|第四十八条]]第一項において準用する会社法[[laws/会社法/本文/第502条.md|第五百二条]]の規定又は定款の定めに違反して、剰余金若しくは残余財産を分配し、又は組合財産を処分したとき。[[laws/船主相互保険組合法/本文/第43条.md|第四十三条]]又は[[laws/会社法/本文/第47条.md|第四十七条]]の規定に違反して、認可を受けないで保険金を削減し、又は保険料を追徴したとき。[[laws/船主相互保険組合法/本文/第41条の2.md|第四十一条の二]]の規定に違反して、損失てん補準備金を積み立てず、又は取り崩したとき。[[laws/船主相互保険組合法/本文/第44条の8.md|第四十四条の八]]において準用する保険業法第百十六条第一項の規定に違反して、責任準備金を積み立てなかつたとき。[[laws/船主相互保険組合法/本文/第48条.md|第四十八条]]第一項において準用する会社法[[laws/会社法/本文/第484条.md|第四百八十四条]]第一項の規定に違反して破産手続開始の申立てを怠つたとき。清算の結了を遅延させる目的で、[[laws/船主相互保険組合法/本文/第48条.md|第四十八条]]第一項において準用する会社法[[laws/会社法/本文/第499条.md|第四百九十九条]]第一項の期間を不当に定めたとき。[[laws/船主相互保険組合法/本文/第48条.md|第四十八条]]第一項において準用する会社法[[laws/会社法/本文/第500条.md|第五百条]]第一項の規定に違反して債務の弁済をしたとき。

- 一 この法律又はこの法律において準用する保険業法の規定に基づいてする内閣総理大臣の命令に違反したとき。
- 二 [[laws/船主相互保険組合法/本文/第4条.md|第四条]]第一項ただし書若しくは第二項ただし書の規定に違反したとき、同条第三項の規定に違反して承認を受けないで同条第一項各号若しくは第二項各号に掲げる事業を行つたとき、又は同条第五項の規定に違反したとき。
- 三 [[laws/船主相互保険組合法/本文/第6条.md|第六条]]の規定に違反したとき。
- 四 [[laws/船主相互保険組合法/本文/第16条.md|第十六条]]第四項の規定に違反して、認可を受けないで同条第二項第一号から第三号までに掲げる書類に記載した事項を変更したとき。
- 五 [[laws/船主相互保険組合法/本文/第35条.md|第三十五条]]第二項ただし書（[[laws/船主相互保険組合法/本文/第15条.md|第十五条]]第七項において準用する場合を含む。）又は[[laws/船主相互保険組合法/本文/第45条の6.md|第四十五条の六]]第二項ただし書の規定に違反して、認可を受けないで理事又は監事を選任したとき。
- 六 [[laws/船主相互保険組合法/本文/第41条.md|第四十一条]]第一項の規定に違反して書類を提出しなかつたとき。
- 七 [[laws/船主相互保険組合法/本文/第42条.md|第四十二条]]、[[laws/船主相互保険組合法/本文/第46条の2.md|第四十六条の二]]若しくは[[laws/船主相互保険組合法/本文/第46条の3.md|第四十六条の三]]の規定若しくは[[laws/船主相互保険組合法/本文/第48条.md|第四十八条]]第一項において準用する会社法[[laws/会社法/本文/第502条.md|第五百二条]]の規定又は定款の定めに違反して、剰余金若しくは残余財産を分配し、又は組合財産を処分したとき。
- 八 [[laws/船主相互保険組合法/本文/第43条.md|第四十三条]]又は[[laws/船主相互保険組合法/本文/第47条.md|第四十七条]]の規定に違反して、認可を受けないで保険金を削減し、又は保険料を追徴したとき。
- 九 [[laws/船主相互保険組合法/本文/第41条の2.md|第四十一条の二]]の規定に違反して、損失てん補準備金を積み立てず、又は取り崩したとき。
- 十 [[laws/船主相互保険組合法/本文/第44条の8.md|第四十四条の八]]において準用する保険業法第百十六条第一項の規定に違反して、責任準備金を積み立てなかつたとき。
- 十一 [[laws/船主相互保険組合法/本文/第48条.md|第四十八条]]第一項において準用する会社法[[laws/会社法/本文/第484条.md|第四百八十四条]]第一項の規定に違反して破産手続開始の申立てを怠つたとき。
- 十二 清算の結了を遅延させる目的で、[[laws/船主相互保険組合法/本文/第48条.md|第四十八条]]第一項において準用する会社法[[laws/会社法/本文/第499条.md|第四百九十九条]]第一項の期間を不当に定めたとき。
- 十三 [[laws/船主相互保険組合法/本文/第48条.md|第四十八条]]第一項において準用する会社法[[laws/会社法/本文/第500条.md|第五百条]]第一項の規定に違反して債務の弁済をしたとき。
