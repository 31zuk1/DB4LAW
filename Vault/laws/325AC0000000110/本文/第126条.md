# 第百二十六条 

## 
次の各号のいずれかに該当する者は、一年以下の拘禁刑又は二十万円以下の罰金に処する。[[laws/資産再評価法/本文/第102条.md|第百二条]]又は[[laws/資産再評価法/本文/第109条の4.md|第百九条の四]]の規定に違反した者[[laws/資産再評価法/本文/第103条.md|第百三条]]から[[laws/資産再評価法/本文/第105条.md|第百五条]]までの規定に違反した者[[laws/資産再評価法/本文/第107条.md|第百七条]]第一項の規定に違反した者[[laws/資産再評価法/本文/第108条.md|第百八条]]又は[[laws/資産再評価法/本文/第109条の5.md|第百九条の五]]の規定に違反した者[[laws/資産再評価法/本文/第110条.md|第百十条]]の規定に違反した者[[laws/資産再評価法/本文/第122条.md|第百二十二条]]第一項の規定による報告をせず、又は虚偽の報告をした者[[laws/資産再評価法/本文/第122条.md|第百二十二条]]第一項の規定による質問に答弁せず、又は虚偽の答弁をした者[[laws/資産再評価法/本文/第122条.md|第百二十二条]]第一項の規定による検査を拒み、妨げ、又は忌避した者[[laws/資産再評価法/本文/第122条.md|第百二十二条]]第一項の規定による検査に際し虚偽の記載をした帳簿書類を提示した者

- 一 [[laws/資産再評価法/本文/第102条.md|第百二条]]又は[[laws/資産再評価法/本文/第109条の4.md|第百九条の四]]の規定に違反した者
- 二 [[laws/資産再評価法/本文/第103条.md|第百三条]]から[[laws/資産再評価法/本文/第105条.md|第百五条]]までの規定に違反した者
- 三 [[laws/資産再評価法/本文/第107条.md|第百七条]]第一項の規定に違反した者
- 四 [[laws/資産再評価法/本文/第108条.md|第百八条]]又は[[laws/資産再評価法/本文/第109条の5.md|第百九条の五]]の規定に違反した者
- 五 [[laws/資産再評価法/本文/第110条.md|第百十条]]の規定に違反した者
- 六 [[laws/資産再評価法/本文/第122条.md|第百二十二条]]第一項の規定による報告をせず、又は虚偽の報告をした者
- 七 [[laws/資産再評価法/本文/第122条.md|第百二十二条]]第一項の規定による質問に答弁せず、又は虚偽の答弁をした者
- 八 [[laws/資産再評価法/本文/第122条.md|第百二十二条]]第一項の規定による検査を拒み、妨げ、又は忌避した者
- 九 [[laws/資産再評価法/本文/第122条.md|第百二十二条]]第一項の規定による検査に際し虚偽の記載をした帳簿書類を提示した者
