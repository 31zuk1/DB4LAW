# 第五十二条 （計算表）

## 
財務省理財局は、財政融資資金の受払いに関し、次の計算表を作成するものとする。財政融資資金貸借対照表財政融資資金運用資産明細表財政融資資金収支計算表財政融資資金受払残高表財政融資資金預託金明細表財政融資資金公債発行収入金明細表財政融資資金借入金明細表財政融資資金証券発行高明細表財政融資資金一時借入金収入金明細表

- 一 財政融資資金貸借対照表
- 二 財政融資資金運用資産明細表
- 三 財政融資資金収支計算表
- 四 財政融資資金受払残高表
- 五 財政融資資金預託金明細表
- 六 財政融資資金公債発行収入金明細表
- 七 財政融資資金借入金明細表
- 八 財政融資資金証券発行高明細表
- 九 財政融資資金一時借入金収入金明細表
