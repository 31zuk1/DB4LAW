# 第一条の四 （業務方法書に記載すべき事項）

## 
機構に係る通則法[[laws/独立行政法人国立文化財機構に関する省令/本文/第28条.md|第二十八条]]第二項の主務省令で定める業務方法書に記載すべき事項は、次のとおりとする。機構法[[laws/独立行政法人国立文化財機構に関する省令/本文/第12条.md|第十二条]]第一項第一号の規定に基づく東京国立博物館、京都国立博物館、奈良国立博物館、九州国立博物館及び皇居三の丸尚蔵館の設置に関する事項機構法[[laws/独立行政法人国立文化財機構に関する省令/本文/第12条.md|第十二条]]第一項第二号に規定する有形文化財の収集、保管及び供覧に関する事項機構法[[laws/独立行政法人国立文化財機構に関する省令/本文/第12条.md|第十二条]]第一項第三号に規定する教育及び普及の事業に関する事項機構法[[laws/独立行政法人国立文化財機構に関する省令/本文/第12条.md|第十二条]]第一項第四号に規定する博物館の供用に関する事項機構法[[laws/独立行政法人国立文化財機構に関する省令/本文/第12条.md|第十二条]]第一項第五号に規定する調査及び研究に関する事項機構法[[laws/独立行政法人国立文化財機構に関する省令/本文/第12条.md|第十二条]]第一項第六号に規定する成果の普及及び成果の活用の促進に関する事項機構法[[laws/独立行政法人国立文化財機構に関する省令/本文/第12条.md|第十二条]]第一項第七号に規定する情報及び資料の収集、整理及び提供に関する事項機構法[[laws/独立行政法人国立文化財機構に関する省令/本文/第12条.md|第十二条]]第一項第八号に規定する研修に関する事項機構法[[laws/独立行政法人国立文化財機構に関する省令/本文/第12条.md|第十二条]]第一項第九号に規定する援助及び助言に関する事項機構法[[laws/独立行政法人国立文化財機構に関する省令/本文/第12条.md|第十二条]]第一項第十号に規定する附帯業務に関する事項機構法[[laws/独立行政法人国立文化財機構に関する省令/本文/第12条.md|第十二条]]第二項に規定する催しの主催又は博物館の供用に関する事項業務委託の基準競争入札その他契約に関する基本的事項その他機構の業務の執行に関して必要な事項

- 一 機構法[[laws/独立行政法人国立文化財機構に関する省令/本文/第12条.md|第十二条]]第一項第一号の規定に基づく東京国立博物館、京都国立博物館、奈良国立博物館、九州国立博物館及び皇居三の丸尚蔵館の設置に関する事項
- 二 機構法[[laws/独立行政法人国立文化財機構に関する省令/本文/第12条.md|第十二条]]第一項第二号に規定する有形文化財の収集、保管及び供覧に関する事項
- 三 機構法[[laws/独立行政法人国立文化財機構に関する省令/本文/第12条.md|第十二条]]第一項第三号に規定する教育及び普及の事業に関する事項
- 四 機構法[[laws/独立行政法人国立文化財機構に関する省令/本文/第12条.md|第十二条]]第一項第四号に規定する博物館の供用に関する事項
- 五 機構法[[laws/独立行政法人国立文化財機構に関する省令/本文/第12条.md|第十二条]]第一項第五号に規定する調査及び研究に関する事項
- 六 機構法[[laws/独立行政法人国立文化財機構に関する省令/本文/第12条.md|第十二条]]第一項第六号に規定する成果の普及及び成果の活用の促進に関する事項
- 七 機構法[[laws/独立行政法人国立文化財機構に関する省令/本文/第12条.md|第十二条]]第一項第七号に規定する情報及び資料の収集、整理及び提供に関する事項
- 八 機構法[[laws/独立行政法人国立文化財機構に関する省令/本文/第12条.md|第十二条]]第一項第八号に規定する研修に関する事項
- 九 機構法[[laws/独立行政法人国立文化財機構に関する省令/本文/第12条.md|第十二条]]第一項第九号に規定する援助及び助言に関する事項
- 十 機構法[[laws/独立行政法人国立文化財機構に関する省令/本文/第12条.md|第十二条]]第一項第十号に規定する附帯業務に関する事項
- 十一 機構法[[laws/独立行政法人国立文化財機構に関する省令/本文/第12条.md|第十二条]]第二項に規定する催しの主催又は博物館の供用に関する事項
- 十二 業務委託の基準
- 十三 競争入札その他契約に関する基本的事項
- 十四 その他機構の業務の執行に関して必要な事項
