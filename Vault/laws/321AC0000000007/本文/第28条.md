# 第二十八条 

## 
次の場合においては、その行為をした会社の代表者、代理人、使用人その他の従業者は、三年以下の拘禁刑又は三万円以下の罰金に処する。[[laws/321AC0000000007/本文/第1条.md|第一条]]第二項又は第三項の規定による文書に、虚偽の記載をしたとき。[[laws/321AC0000000007/本文/第2条.md|第二条]]第三項の規定による認可又は指定の申請を怠つたとき。[[laws/321AC0000000007/本文/第7条.md|第七条]]第八項の規定に違反して帳簿を作成せず、又は帳簿に虚偽の記載をしたとき。[[laws/321AC0000000007/本文/第8条.md|第八条]]第二項又は第五項の規定に違反して明細書について公証人の認証を受けず、又は虚偽の記載をした明細書について公証人の認証を受けたとき。[[laws/321AC0000000007/本文/第14条.md|第十四条]]第一項の規定に違反して弁済その他債権を消滅させる行為をしたとき。[[laws/321AC0000000007/本文/第14条.md|第十四条]]第二項又は第三項の規定による特別管理人の承認又は主務大臣の承認を受けないで弁済をしたとき。[[laws/321AC0000000007/本文/第21条.md|第二十一条]]の規定による財産の処分、保全その他の管理について特別管理人の決定に従わなかつたとき。[[laws/321AC0000000007/本文/第22条.md|第二十二条]]第一項の規定による特別管理人（特別管理人が選任されていないときには主務大臣）の承認を受けないで財産を処分したとき。

- 一 [[laws/321AC0000000007/本文/第1条.md|第一条]]第二項又は第三項の規定による文書に、虚偽の記載をしたとき。
- 二 [[laws/321AC0000000007/本文/第2条.md|第二条]]第三項の規定による認可又は指定の申請を怠つたとき。
- 三 [[laws/321AC0000000007/本文/第7条.md|第七条]]第八項の規定に違反して帳簿を作成せず、又は帳簿に虚偽の記載をしたとき。
- 四 [[laws/321AC0000000007/本文/第8条.md|第八条]]第二項又は第五項の規定に違反して明細書について公証人の認証を受けず、又は虚偽の記載をした明細書について公証人の認証を受けたとき。
- 五 [[laws/321AC0000000007/本文/第14条.md|第十四条]]第一項の規定に違反して弁済その他債権を消滅させる行為をしたとき。
- 六 [[laws/321AC0000000007/本文/第14条.md|第十四条]]第二項又は第三項の規定による特別管理人の承認又は主務大臣の承認を受けないで弁済をしたとき。
- 七 [[laws/321AC0000000007/本文/第21条.md|第二十一条]]の規定による財産の処分、保全その他の管理について特別管理人の決定に従わなかつたとき。
- 八 [[laws/321AC0000000007/本文/第22条.md|第二十二条]]第一項の規定による特別管理人（特別管理人が選任されていないときには主務大臣）の承認を受けないで財産を処分したとき。
