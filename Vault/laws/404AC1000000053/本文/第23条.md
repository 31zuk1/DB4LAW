# 第二十三条 

## 
次の各号の一に該当する者は、五十万円以下の罰金に処する。[[laws/404AC1000000053/本文/第3条.md|第三条]]第一項の規定による届出をせず、又は虚偽の届出をして募集をした者[[laws/404AC1000000053/本文/第4条.md|第四条]]の規定に違反して、会員契約の締結をした者[[laws/404AC1000000053/本文/第5条.md|第五条]]第一項から第三項までの規定に違反して、書面を交付せず、又はこれらの規定に規定する事項が記載されていない書面若しくは虚偽の記載のある書面を交付した者[[laws/404AC1000000053/本文/第6条.md|第六条]]の規定に違反して、著しく事実に相違する表示をし、又は実際のものより著しく優良であり、若しくは有利であると人を誤認させるような表示をした者[[laws/404AC1000000053/本文/第9条.md|第九条]]の規定に違反して、書類を備え置かず、若しくは会員の求めに応じて閲覧させず、又は虚偽の記載のある書類を備え置き、若しくは会員に閲覧させた者[[laws/404AC1000000053/本文/第17条.md|第十七条]]第一項の規定による報告をせず、若しくは虚偽の報告をし、又は同項の規定による検査を拒み、妨げ、若しくは忌避した者[[laws/404AC1000000053/本文/第17条.md|第十七条]]第二項の規定による報告若しくは資料の提出をせず、若しくは虚偽の報告若しくは虚偽の資料の提出をし、又は同項の規定による検査を拒み、妨げ、若しくは忌避した者

- 一 [[laws/404AC1000000053/本文/第3条.md|第三条]]第一項の規定による届出をせず、又は虚偽の届出をして募集をした者
- 二 [[laws/404AC1000000053/本文/第4条.md|第四条]]の規定に違反して、会員契約の締結をした者
- 三 [[laws/404AC1000000053/本文/第5条.md|第五条]]第一項から第三項までの規定に違反して、書面を交付せず、又はこれらの規定に規定する事項が記載されていない書面若しくは虚偽の記載のある書面を交付した者
- 四 [[laws/404AC1000000053/本文/第6条.md|第六条]]の規定に違反して、著しく事実に相違する表示をし、又は実際のものより著しく優良であり、若しくは有利であると人を誤認させるような表示をした者
- 五 [[laws/404AC1000000053/本文/第9条.md|第九条]]の規定に違反して、書類を備え置かず、若しくは会員の求めに応じて閲覧させず、又は虚偽の記載のある書類を備え置き、若しくは会員に閲覧させた者
- 六 [[laws/404AC1000000053/本文/第17条.md|第十七条]]第一項の規定による報告をせず、若しくは虚偽の報告をし、又は同項の規定による検査を拒み、妨げ、若しくは忌避した者
- 七 [[laws/404AC1000000053/本文/第17条.md|第十七条]]第二項の規定による報告若しくは資料の提出をせず、若しくは虚偽の報告若しくは虚偽の資料の提出をし、又は同項の規定による検査を拒み、妨げ、若しくは忌避した者
