# 第四十二条 

## 
次の各号のいずれかに該当する者は、五十万円以下の罰金に処する。[[laws/415AC0000000097/本文/第13条.md|第十三条]]第一項の規定に違反して確認を受けないで第二種使用等をした者偽りその他不正の手段により[[laws/415AC0000000097/本文/第13条.md|第十三条]]第一項の確認を受けた者[[laws/415AC0000000097/本文/第16条.md|第十六条]]の規定による届出をせず、又は虚偽の届出をして輸入した者[[laws/415AC0000000097/本文/第26条.md|第二十六条]]第一項の規定による情報の提供をせず、又は虚偽の情報を提供して遺伝子組換え生物等を譲渡し、若しくは提供し、又は委託して使用等をさせた者[[laws/415AC0000000097/本文/第27条.md|第二十七条]]の規定による通告をせず、又は虚偽の通告をして輸出した者[[laws/415AC0000000097/本文/第28条.md|第二十八条]]の規定による表示をせず、又は虚偽の表示をして輸出した者

- 一 [[laws/415AC0000000097/本文/第13条.md|第十三条]]第一項の規定に違反して確認を受けないで第二種使用等をした者
- 二 偽りその他不正の手段により[[laws/415AC0000000097/本文/第13条.md|第十三条]]第一項の確認を受けた者
- 三 [[laws/415AC0000000097/本文/第16条.md|第十六条]]の規定による届出をせず、又は虚偽の届出をして輸入した者
- 四 [[laws/415AC0000000097/本文/第26条.md|第二十六条]]第一項の規定による情報の提供をせず、又は虚偽の情報を提供して遺伝子組換え生物等を譲渡し、若しくは提供し、又は委託して使用等をさせた者
- 五 [[laws/415AC0000000097/本文/第27条.md|第二十七条]]の規定による通告をせず、又は虚偽の通告をして輸出した者
- 六 [[laws/415AC0000000097/本文/第28条.md|第二十八条]]の規定による表示をせず、又は虚偽の表示をして輸出した者
