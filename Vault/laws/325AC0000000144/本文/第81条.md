# 第八十一条 （後見人選任の請求）

## 
被保護者が未成年者又は成年被後見人である場合において、親権者及び後見人の職務を行う者がないときは、保護の実施機関は、すみやかに、後見人の選任を家庭裁判所に請求しなければならない。
