# 第二十八条 （特定物納申請書の記載事項）

## 
法[[laws/相続税法施行規則/本文/第48条の2.md|第四十八条の二]]第二項に規定する財務省令で定める事項は、次に掲げる事項とする。[[laws/相続税法施行規則/本文/第13条.md|第十三条]]第一項第三号及び第四号に掲げる事項法[[laws/相続税法施行規則/本文/第48条の2.md|第四十八条の二]]第一項に規定する特定物納対象税額法[[laws/相続税法施行規則/本文/第48条の2.md|第四十八条の二]]第一項の規定による物納（以下この条において「特定物納」という。）を求めようとする税額法[[laws/相続税法施行規則/本文/第39条.md|第三十九条]]第三十項（法[[laws/相続税法施行規則/本文/第44条.md|第四十四条]]第二項において準用する場合を含む。）の規定により変更された条件による延納によつても金銭で納付することを困難とする事由並びにその困難とする金額及びその計算の明細特定物納に係る相続税の申告期限特定物納に充てようとする財産の種類及び数量並びに当該特定物納の許可の申請をする時における当該財産の価額、その計算の明細及び所在場所法[[laws/相続税法施行規則/本文/第48条の2.md|第四十八条の二]]第六項において準用する法[[laws/相続税法施行規則/本文/第41条.md|第四十一条]]第四項に規定する物納劣後財産を特定物納に充てようとする場合には、同項に規定する事由その他当該財産を特定物納に充てようとする特別の事由法[[laws/相続税法施行規則/本文/第48条の2.md|第四十八条の二]]第六項において準用する法[[laws/相続税法施行規則/本文/第41条.md|第四十一条]]第二項第二号又は第三号に掲げる財産（[[laws/相続税法施行規則/本文/第21条の2.md|第二十一条の二]]第三項に規定する財産を除く。）を特定物納に充てようとする場合には、法[[laws/相続税法施行規則/本文/第41条.md|第四十一条]]第五項に規定する事由その他当該財産を特定物納に充てようとする特別の事由その他参考となるべき事項

- 一 [[laws/相続税法施行規則/本文/第13条.md|第十三条]]第一項第三号及び第四号に掲げる事項
- 二 法[[laws/相続税法施行規則/本文/第48条の2.md|第四十八条の二]]第一項に規定する特定物納対象税額
- 三 法[[laws/相続税法施行規則/本文/第48条の2.md|第四十八条の二]]第一項の規定による物納（以下この条において「特定物納」という。）を求めようとする税額
- 四 法[[laws/相続税法施行規則/本文/第39条.md|第三十九条]]第三十項（法[[laws/相続税法施行規則/本文/第44条.md|第四十四条]]第二項において準用する場合を含む。）の規定により変更された条件による延納によつても金銭で納付することを困難とする事由並びにその困難とする金額及びその計算の明細
- 五 特定物納に係る相続税の申告期限
- 六 特定物納に充てようとする財産の種類及び数量並びに当該特定物納の許可の申請をする時における当該財産の価額、その計算の明細及び所在場所
- 七 法[[laws/相続税法施行規則/本文/第48条の2.md|第四十八条の二]]第六項において準用する法[[laws/相続税法施行規則/本文/第41条.md|第四十一条]]第四項に規定する物納劣後財産を特定物納に充てようとする場合には、同項に規定する事由その他当該財産を特定物納に充てようとする特別の事由
- 八 法[[laws/相続税法施行規則/本文/第48条の2.md|第四十八条の二]]第六項において準用する法[[laws/相続税法施行規則/本文/第41条.md|第四十一条]]第二項第二号又は第三号に掲げる財産（[[laws/相続税法施行規則/本文/第21条の2.md|第二十一条の二]]第三項に規定する財産を除く。）を特定物納に充てようとする場合には、法[[laws/相続税法施行規則/本文/第41条.md|第四十一条]]第五項に規定する事由その他当該財産を特定物納に充てようとする特別の事由
- 九 その他参考となるべき事項
