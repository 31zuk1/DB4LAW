# 第二十六条 （物納の撤回に係る延納申請書の記載事項）

## 
法[[laws/相続税法施行規則/本文/第47条.md|第四十七条]]第二項に規定する財務省令で定める事項は、次に掲げる事項とする。この場合において、[[laws/相続税法施行規則/本文/第20条.md|第二十条]]第一項後段の規定は、第二号（同項第五号及び第六号に関する部分に限る。）に掲げる事項について準用する。[[laws/相続税法施行規則/本文/第13条.md|第十三条]]第一項第三号及び第四号に掲げる事項[[laws/相続税法施行規則/本文/第20条.md|第二十条]]第一項第五号から第七号までに掲げる事項物納の撤回に係る相続税額法[[laws/相続税法施行規則/本文/第47条.md|第四十七条]]第五項に規定する未経過延納税額のうち金銭で一時に納付することを困難とする金額及びその困難とする事由施行令[[laws/相続税法施行規則/本文/第25条の5.md|第二十五条の五]]第一項において準用する施行令[[laws/相続税法施行規則/本文/第12条.md|第十二条]]第一項第二号に掲げる額及びその計算の明細その他参考となるべき事項

- 一 [[laws/相続税法施行規則/本文/第13条.md|第十三条]]第一項第三号及び第四号に掲げる事項
- 二 [[laws/相続税法施行規則/本文/第20条.md|第二十条]]第一項第五号から第七号までに掲げる事項
- 三 物納の撤回に係る相続税額
- 四 法[[laws/相続税法施行規則/本文/第47条.md|第四十七条]]第五項に規定する未経過延納税額のうち金銭で一時に納付することを困難とする金額及びその困難とする事由
- 五 施行令[[laws/相続税法施行規則/本文/第25条の5.md|第二十五条の五]]第一項において準用する施行令[[laws/相続税法施行規則/本文/第12条.md|第十二条]]第一項第二号に掲げる額及びその計算の明細
- 六 その他参考となるべき事項
