# 第三十四条 

## 
次の各号のいずれかに該当する場合には、その違反行為をした会社の取締役、執行役、会計参与若しくはその職務を行うべき社員又は監査役は、百万円以下の過料に処する。[[laws/419AC0000000085/本文/第3条.md|第三条]]第二項の規定に違反して、業務を営んだとき。[[laws/419AC0000000085/本文/第4条.md|第四条]]第二項の規定に違反して、兼職の届出を行わなかったとき。[[laws/419AC0000000085/本文/第9条.md|第九条]]第一項の規定に違反して、預金の受入れ又は日本政策投資銀行債の発行を開始したとき。[[laws/419AC0000000085/本文/第12条.md|第十二条]]第一項の規定に違反して、募集株式若しくは募集新株予約権を引き受ける者の募集をし、又は株式交換若しくは株式交付に際して株式若しくは新株予約権を交付したとき。[[laws/419AC0000000085/本文/第12条.md|第十二条]]第二項の規定に違反して、株式を交付した旨の届出を行わなかったとき。[[laws/419AC0000000085/本文/第13条.md|第十三条]]第一項の規定に違反して、基本方針の認可を受けなかったとき。[[laws/419AC0000000085/本文/第13条.md|第十三条]]第二項の規定に違反して、社債若しくは日本政策投資銀行債を発行した旨又は借入金の借入れをした旨の届出を行わなかったとき。[[laws/419AC0000000085/本文/第14条.md|第十四条]]第一項又は第二項の規定に違反して、限度額又は合計額を超えることとなったとき。[[laws/419AC0000000085/本文/第16条.md|第十六条]]第一項の規定に違反して、兼職の認可を受けなかったとき。[[laws/419AC0000000085/本文/第17条.md|第十七条]]の規定に違反して、事業計画の認可を受けなかったとき。[[laws/419AC0000000085/本文/第18条.md|第十八条]]の規定に違反して、償還計画の認可を受けなかったとき。[[laws/419AC0000000085/本文/第19条.md|第十九条]]の規定に違反して、認可対象子会社を子会社としたとき。[[laws/419AC0000000085/本文/第21条.md|第二十一条]]の規定に違反して、貸借対照表、損益計算書若しくは事業報告書を提出せず、又は虚偽の記載若しくは記録をしたこれらのものを提出したとき。[[laws/419AC0000000085/本文/第26条.md|第二十六条]]第二項の規定による命令に違反したとき。

- 一 [[laws/419AC0000000085/本文/第3条.md|第三条]]第二項の規定に違反して、業務を営んだとき。
- 二 [[laws/419AC0000000085/本文/第4条.md|第四条]]第二項の規定に違反して、兼職の届出を行わなかったとき。
- 三 [[laws/419AC0000000085/本文/第9条.md|第九条]]第一項の規定に違反して、預金の受入れ又は日本政策投資銀行債の発行を開始したとき。
- 四 [[laws/419AC0000000085/本文/第12条.md|第十二条]]第一項の規定に違反して、募集株式若しくは募集新株予約権を引き受ける者の募集をし、又は株式交換若しくは株式交付に際して株式若しくは新株予約権を交付したとき。
- 五 [[laws/419AC0000000085/本文/第12条.md|第十二条]]第二項の規定に違反して、株式を交付した旨の届出を行わなかったとき。
- 六 [[laws/419AC0000000085/本文/第13条.md|第十三条]]第一項の規定に違反して、基本方針の認可を受けなかったとき。
- 七 [[laws/419AC0000000085/本文/第13条.md|第十三条]]第二項の規定に違反して、社債若しくは日本政策投資銀行債を発行した旨又は借入金の借入れをした旨の届出を行わなかったとき。
- 八 [[laws/419AC0000000085/本文/第14条.md|第十四条]]第一項又は第二項の規定に違反して、限度額又は合計額を超えることとなったとき。
- 九 [[laws/419AC0000000085/本文/第16条.md|第十六条]]第一項の規定に違反して、兼職の認可を受けなかったとき。
- 十 [[laws/419AC0000000085/本文/第17条.md|第十七条]]の規定に違反して、事業計画の認可を受けなかったとき。
- 十一 [[laws/419AC0000000085/本文/第18条.md|第十八条]]の規定に違反して、償還計画の認可を受けなかったとき。
- 十二 [[laws/419AC0000000085/本文/第19条.md|第十九条]]の規定に違反して、認可対象子会社を子会社としたとき。
- 十三 [[laws/419AC0000000085/本文/第21条.md|第二十一条]]の規定に違反して、貸借対照表、損益計算書若しくは事業報告書を提出せず、又は虚偽の記載若しくは記録をしたこれらのものを提出したとき。
- 十四 [[laws/419AC0000000085/本文/第26条.md|第二十六条]]第二項の規定による命令に違反したとき。
