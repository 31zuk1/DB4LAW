# 第三十三条の五 （株券及び優先出資証券に準ずる有価証券）

## 
法[[laws/金融商品取引法施行令/本文/第172条.md|第百七十二条]]第一項第一号に規定する政令で定める有価証券は、次に掲げるものとする。[[laws/金融商品取引法施行令/本文/第2条の8.md|第二条の八]]に規定する有価証券（元本（発行時に確定するものに限る。）の償還を受けることができるものを除く。）法[[laws/金融商品取引法施行令/本文/第2条.md|第二条]]第一項第四号に掲げる有価証券であつて、転換特定社債券（資産流動化法に規定する転換特定社債券をいう。第四号において同じ。）及び新優先出資引受権付特定社債券以外のもの（元本（発行時に確定するものに限る。）の償還を受けることができるものを除く。）法[[laws/金融商品取引法施行令/本文/第2条.md|第二条]]第一項第五号に掲げる有価証券であつて、法[[laws/金融商品取引法施行令/本文/第3条.md|第三条]]に規定する政府が元本の償還及び利息の支払について保証している社債券及び新株予約権付社債券以外のもの（元本（発行時に確定するものに限る。）の償還を受けることができるものを除く。）新株予約権付社債券、転換特定社債券又は新優先出資引受権付特定社債券法[[laws/金融商品取引法施行令/本文/第2条.md|第二条]]第一項第八号及び第九号に掲げる有価証券（株券を除く。）法[[laws/金融商品取引法施行令/本文/第2条.md|第二条]]第一項第十号に掲げる有価証券法[[laws/金融商品取引法施行令/本文/第2条.md|第二条]]第一項第十一号に掲げる有価証券で、投資信託及び投資法人に関する法律に規定する投資法人債券若しくは外国投資証券で投資法人債券に類する証券（元本（発行時に確定するものに限る。）の償還を受けることができるものを除く。）又は投資証券等若しくは新投資口予約権証券等法[[laws/金融商品取引法施行令/本文/第2条.md|第二条]]第一項第十三号に掲げる有価証券（元本（発行時に確定するものに限る。）の償還を受けることができるものを除く。）法[[laws/金融商品取引法施行令/本文/第2条.md|第二条]]第一項第十四号に掲げる有価証券（元本（発行時に確定するものに限る。）の償還を受けることができるもの及び次号に掲げるものを除く。）有価証券信託受益証券（株券、優先出資証券又は前各号若しくは次号から第十七号までに掲げる有価証券を受託有価証券とするものに限る。）法[[laws/金融商品取引法施行令/本文/第2条.md|第二条]]第一項第十六号に掲げる有価証券（元本（発行時に確定するものに限る。）の償還を受けることができるものを除く。）法[[laws/金融商品取引法施行令/本文/第2条.md|第二条]]第一項第十七号に掲げる有価証券（[[laws/金融商品取引法施行令/本文/第2条の11.md|第二条の十一]]に規定する債券を除く。）で、株券、優先出資証券又は前各号（第六号及び第七号を除く。）に掲げる有価証券の性質を有するもの法[[laws/金融商品取引法施行令/本文/第2条.md|第二条]]第一項第十八号に掲げる有価証券（元本（発行時に確定するものに限る。）の償還を受けることができるものを除く。）法[[laws/金融商品取引法施行令/本文/第2条.md|第二条]]第一項第十九号に掲げる有価証券で、株券、優先出資証券、前各号、次号若しくは第十六号に掲げる有価証券又は法[[laws/金融商品取引法施行令/本文/第2条.md|第二条]]第二項の規定により有価証券とみなされる同項各号に掲げる権利（有価証券投資事業権利等又は電子記録移転権利（有価証券信託受益証券に該当するものを除く。）に該当するものに限り、元本（発生時に確定するものに限る。）の償還を受けることができるものを除く。第十八号において同じ。）に係るオプションを表示するもの法[[laws/金融商品取引法施行令/本文/第2条.md|第二条]]第一項第二十号に掲げる有価証券で、株券、優先出資証券又は前各号に掲げる有価証券に係る権利を表示するもの[[laws/金融商品取引法施行令/本文/第1条.md|第一条]]第二号に規定する有価証券（元本（発行時に確定するものに限る。）の償還を受けることができるものを除く。）株券、優先出資証券又は前各号に掲げる有価証券に表示されるべき権利であつて、法[[laws/金融商品取引法施行令/本文/第2条.md|第二条]]第二項の規定により有価証券とみなされるもの法[[laws/金融商品取引法施行令/本文/第2条.md|第二条]]第二項の規定により有価証券とみなされる同項各号に掲げる権利

- 一 [[laws/金融商品取引法施行令/本文/第2条の8.md|第二条の八]]に規定する有価証券（元本（発行時に確定するものに限る。）の償還を受けることができるものを除く。）
- 二 法[[laws/金融商品取引法施行令/本文/第2条.md|第二条]]第一項第四号に掲げる有価証券であつて、転換特定社債券（資産流動化法に規定する転換特定社債券をいう。第四号において同じ。）及び新優先出資引受権付特定社債券以外のもの（元本（発行時に確定するものに限る。）の償還を受けることができるものを除く。）
- 三 法[[laws/金融商品取引法施行令/本文/第2条.md|第二条]]第一項第五号に掲げる有価証券であつて、法[[laws/金融商品取引法施行令/本文/第3条.md|第三条]]に規定する政府が元本の償還及び利息の支払について保証している社債券及び新株予約権付社債券以外のもの（元本（発行時に確定するものに限る。）の償還を受けることができるものを除く。）
- 四 新株予約権付社債券、転換特定社債券又は新優先出資引受権付特定社債券
- 五 法[[laws/金融商品取引法施行令/本文/第2条.md|第二条]]第一項第八号及び第九号に掲げる有価証券（株券を除く。）
- 六 法[[laws/金融商品取引法施行令/本文/第2条.md|第二条]]第一項第十号に掲げる有価証券
- 七 法[[laws/金融商品取引法施行令/本文/第2条.md|第二条]]第一項第十一号に掲げる有価証券で、投資信託及び投資法人に関する法律に規定する投資法人債券若しくは外国投資証券で投資法人債券に類する証券（元本（発行時に確定するものに限る。）の償還を受けることができるものを除く。）又は投資証券等若しくは新投資口予約権証券等
- 八 法[[laws/金融商品取引法施行令/本文/第2条.md|第二条]]第一項第十三号に掲げる有価証券（元本（発行時に確定するものに限る。）の償還を受けることができるものを除く。）
- 九 法[[laws/金融商品取引法施行令/本文/第2条.md|第二条]]第一項第十四号に掲げる有価証券（元本（発行時に確定するものに限る。）の償還を受けることができるもの及び次号に掲げるものを除く。）
- 十 有価証券信託受益証券（株券、優先出資証券又は前各号若しくは次号から第十七号までに掲げる有価証券を受託有価証券とするものに限る。）
- 十一 法[[laws/金融商品取引法施行令/本文/第2条.md|第二条]]第一項第十六号に掲げる有価証券（元本（発行時に確定するものに限る。）の償還を受けることができるものを除く。）
- 十二 法[[laws/金融商品取引法施行令/本文/第2条.md|第二条]]第一項第十七号に掲げる有価証券（[[laws/金融商品取引法施行令/本文/第2条の11.md|第二条の十一]]に規定する債券を除く。）で、株券、優先出資証券又は前各号（第六号及び第七号を除く。）に掲げる有価証券の性質を有するもの
- 十三 法[[laws/金融商品取引法施行令/本文/第2条.md|第二条]]第一項第十八号に掲げる有価証券（元本（発行時に確定するものに限る。）の償還を受けることができるものを除く。）
- 十四 法[[laws/金融商品取引法施行令/本文/第2条.md|第二条]]第一項第十九号に掲げる有価証券で、株券、優先出資証券、前各号、次号若しくは第十六号に掲げる有価証券又は法[[laws/金融商品取引法施行令/本文/第2条.md|第二条]]第二項の規定により有価証券とみなされる同項各号に掲げる権利（有価証券投資事業権利等又は電子記録移転権利（有価証券信託受益証券に該当するものを除く。）に該当するものに限り、元本（発生時に確定するものに限る。）の償還を受けることができるものを除く。第十八号において同じ。）に係るオプションを表示するもの
- 十五 法[[laws/金融商品取引法施行令/本文/第2条.md|第二条]]第一項第二十号に掲げる有価証券で、株券、優先出資証券又は前各号に掲げる有価証券に係る権利を表示するもの
- 十六 [[laws/金融商品取引法施行令/本文/第1条.md|第一条]]第二号に規定する有価証券（元本（発行時に確定するものに限る。）の償還を受けることができるものを除く。）
- 十七 株券、優先出資証券又は前各号に掲げる有価証券に表示されるべき権利であつて、法[[laws/金融商品取引法施行令/本文/第2条.md|第二条]]第二項の規定により有価証券とみなされるもの
- 十八 法[[laws/金融商品取引法施行令/本文/第2条.md|第二条]]第二項の規定により有価証券とみなされる同項各号に掲げる権利
