# 第八十六条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、三十万円以下の罰金に処する。[[laws/414AC0000000088/本文/第9条.md|第九条]]第十項若しくは第十一項、[[laws/414AC0000000088/本文/第15条.md|第十五条]]第八項若しくは第九項、[[laws/414AC0000000088/本文/第18条.md|第十八条]]、[[laws/414AC0000000088/本文/第18条の9.md|第十八条の九]]、[[laws/414AC0000000088/本文/第21条.md|第二十一条]]第一項、[[laws/414AC0000000088/本文/第24条.md|第二十四条]]第七項若しくは第八項、[[laws/414AC0000000088/本文/第25条.md|第二十五条]]第五項、[[laws/414AC0000000088/本文/第35条.md|第三十五条]]第九項若しくは第十項、[[laws/414AC0000000088/本文/第37条.md|第三十七条]]第八項若しくは第九項、[[laws/414AC0000000088/本文/第38条の2.md|第三十八条の二]]第八項若しくは第九項、[[laws/414AC0000000088/本文/第54条.md|第五十四条]]、[[laws/414AC0000000088/本文/第62条.md|第六十二条]]第一項又は[[laws/414AC0000000088/本文/第65条.md|第六十五条]]の規定に違反したとき。[[laws/414AC0000000088/本文/第9条.md|第九条]]第十二項の規定に違反して表示をしないで猟具を使用して鳥獣の捕獲等をしたとき。[[laws/414AC0000000088/本文/第9条.md|第九条]]第十三項、[[laws/414AC0000000088/本文/第66条.md|第六十六条]]又は[[laws/414AC0000000088/本文/第75条.md|第七十五条]]第一項の規定による報告をせず、又は虚偽の報告をしたとき。[[laws/414AC0000000088/本文/第15条.md|第十五条]]第十三項（[[laws/414AC0000000088/本文/第28条.md|第二十八条]]第九項及び[[laws/414AC0000000088/本文/第29条.md|第二十九条]]第四項において準用する場合を含む。）、[[laws/414AC0000000088/本文/第34条.md|第三十四条]]第五項（[[laws/414AC0000000088/本文/第35条.md|第三十五条]]第十二項において準用する場合を含む。）若しくは[[laws/414AC0000000088/本文/第70条.md|第七十条]]第二項の標識又は[[laws/414AC0000000088/本文/第28条.md|第二十八条]]第十一項の施設を移転し、汚損し、毀損し、又は除去したとき。[[laws/414AC0000000088/本文/第18条の7.md|第十八条の七]]第三項、[[laws/414AC0000000088/本文/第46条.md|第四十六条]]第一項又は[[laws/414AC0000000088/本文/第61条.md|第六十一条]]第四項の規定による届出をせず、又は虚偽の届出をしたとき。[[laws/414AC0000000088/本文/第31条.md|第三十一条]]第四項の規定に違反して、同条第一項の規定による立入りを拒み、又は妨げたとき。[[laws/414AC0000000088/本文/第62条.md|第六十二条]]第二項の規定に違反して狩猟者記章を着用しないで狩猟をしたとき。[[laws/414AC0000000088/本文/第62条.md|第六十二条]]第三項の規定に違反して表示をしないで猟具を使用して狩猟をしたとき。[[laws/414AC0000000088/本文/第71条.md|第七十一条]]第一項の規定に違反して都道府県知事の認可を受けないで猟区管理規程を変更し、又は猟区を廃止したとき。[[laws/414AC0000000088/本文/第75条.md|第七十五条]]第二項の規定による立入検査若しくは立入調査を拒み、妨げ、若しくは忌避し、又は質問に対して陳述をせず、若しくは虚偽の陳述をしたとき。[[laws/414AC0000000088/本文/第75条.md|第七十五条]]第三項の規定による立入検査を拒み、妨げ、又は忌避したとき。[[laws/414AC0000000088/本文/第75条.md|第七十五条]]第四項の規定による立入検査を拒み、妨げ、若しくは忌避し、又は質問に対して陳述をせず、若しくは虚偽の陳述をしたとき。

- 一 [[laws/414AC0000000088/本文/第9条.md|第九条]]第十項若しくは第十一項、[[laws/414AC0000000088/本文/第15条.md|第十五条]]第八項若しくは第九項、[[laws/414AC0000000088/本文/第18条.md|第十八条]]、[[laws/414AC0000000088/本文/第18条の9.md|第十八条の九]]、[[laws/414AC0000000088/本文/第21条.md|第二十一条]]第一項、[[laws/414AC0000000088/本文/第24条.md|第二十四条]]第七項若しくは第八項、[[laws/414AC0000000088/本文/第25条.md|第二十五条]]第五項、[[laws/414AC0000000088/本文/第35条.md|第三十五条]]第九項若しくは第十項、[[laws/414AC0000000088/本文/第37条.md|第三十七条]]第八項若しくは第九項、[[laws/414AC0000000088/本文/第38条の2.md|第三十八条の二]]第八項若しくは第九項、[[laws/414AC0000000088/本文/第54条.md|第五十四条]]、[[laws/414AC0000000088/本文/第62条.md|第六十二条]]第一項又は[[laws/414AC0000000088/本文/第65条.md|第六十五条]]の規定に違反したとき。
- 二 [[laws/414AC0000000088/本文/第9条.md|第九条]]第十二項の規定に違反して表示をしないで猟具を使用して鳥獣の捕獲等をしたとき。
- 三 [[laws/414AC0000000088/本文/第9条.md|第九条]]第十三項、[[laws/414AC0000000088/本文/第66条.md|第六十六条]]又は[[laws/414AC0000000088/本文/第75条.md|第七十五条]]第一項の規定による報告をせず、又は虚偽の報告をしたとき。
- 四 [[laws/414AC0000000088/本文/第15条.md|第十五条]]第十三項（[[laws/414AC0000000088/本文/第28条.md|第二十八条]]第九項及び[[laws/414AC0000000088/本文/第29条.md|第二十九条]]第四項において準用する場合を含む。）、[[laws/414AC0000000088/本文/第34条.md|第三十四条]]第五項（[[laws/414AC0000000088/本文/第35条.md|第三十五条]]第十二項において準用する場合を含む。）若しくは[[laws/414AC0000000088/本文/第70条.md|第七十条]]第二項の標識又は[[laws/414AC0000000088/本文/第28条.md|第二十八条]]第十一項の施設を移転し、汚損し、毀損し、又は除去したとき。
- 五 [[laws/414AC0000000088/本文/第18条の7.md|第十八条の七]]第三項、[[laws/414AC0000000088/本文/第46条.md|第四十六条]]第一項又は[[laws/414AC0000000088/本文/第61条.md|第六十一条]]第四項の規定による届出をせず、又は虚偽の届出をしたとき。
- 六 [[laws/414AC0000000088/本文/第31条.md|第三十一条]]第四項の規定に違反して、同条第一項の規定による立入りを拒み、又は妨げたとき。
- 七 [[laws/414AC0000000088/本文/第62条.md|第六十二条]]第二項の規定に違反して狩猟者記章を着用しないで狩猟をしたとき。
- 八 [[laws/414AC0000000088/本文/第62条.md|第六十二条]]第三項の規定に違反して表示をしないで猟具を使用して狩猟をしたとき。
- 九 [[laws/414AC0000000088/本文/第71条.md|第七十一条]]第一項の規定に違反して都道府県知事の認可を受けないで猟区管理規程を変更し、又は猟区を廃止したとき。
- 十 [[laws/414AC0000000088/本文/第75条.md|第七十五条]]第二項の規定による立入検査若しくは立入調査を拒み、妨げ、若しくは忌避し、又は質問に対して陳述をせず、若しくは虚偽の陳述をしたとき。
- 十一 [[laws/414AC0000000088/本文/第75条.md|第七十五条]]第三項の規定による立入検査を拒み、妨げ、又は忌避したとき。
- 十二 [[laws/414AC0000000088/本文/第75条.md|第七十五条]]第四項の規定による立入検査を拒み、妨げ、若しくは忌避し、又は質問に対して陳述をせず、若しくは虚偽の陳述をしたとき。
