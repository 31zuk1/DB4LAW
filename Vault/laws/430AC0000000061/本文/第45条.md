# 第四十五条 

## 
次の各号のいずれかに該当する者は、一年以下の拘禁刑又は五十万円以下の罰金に処する。偽りその他不正の手段により有害物質一覧表確認証書又は再資源化解体準備証書の交付を受けた者[[laws/船舶の再資源化解体の適正な実施に関する法律/本文/第5条.md|第五条]]第一項の規定に違反して、特別特定日本船舶を日本国領海等以外の水域において航行の用に供した者[[laws/船舶の再資源化解体の適正な実施に関する法律/本文/第10条.md|第十条]]第一項の規定に違反して、特定船舶の再資源化解体を開始した者偽りその他不正の手段により[[laws/船舶の再資源化解体の適正な実施に関する法律/本文/第10条.md|第十条]]第一項の許可又は[[laws/船舶の再資源化解体の適正な実施に関する法律/本文/第11条.md|第十一条]]第一項の更新を受けた者[[laws/船舶の再資源化解体の適正な実施に関する法律/本文/第12条.md|第十二条]]第一項の規定に違反して、[[laws/船舶の再資源化解体の適正な実施に関する法律/本文/第10条.md|第十条]]第二項第五号又は第六号に掲げる事項を変更した者偽りその他不正の手段により[[laws/船舶の再資源化解体の適正な実施に関する法律/本文/第12条.md|第十二条]]第一項の許可を受けた者偽りその他不正の手段により[[laws/船舶の再資源化解体の適正な実施に関する法律/本文/第13条.md|第十三条]]第一項から第三項までの認可を受けた者偽りその他不正の手段により[[laws/船舶の再資源化解体の適正な実施に関する法律/本文/第18条.md|第十八条]]第一項又は[[laws/船舶の再資源化解体の適正な実施に関する法律/本文/第25条.md|第二十五条]]第一項の承認を受けた者[[laws/船舶の再資源化解体の適正な実施に関する法律/本文/第23条.md|第二十三条]]第一項の規定に違反して特定日本船舶の譲渡し等若しくは譲受け等をした者又は同条第二項の規定に違反して特定外国船舶の譲受け等をした者[[laws/船舶の再資源化解体の適正な実施に関する法律/本文/第25条.md|第二十五条]]第二項若しくは第七項において準用する[[laws/船舶の再資源化解体の適正な実施に関する法律/本文/第23条.md|第二十三条]]第一項の規定に違反して特定日本船舶の再資源化解体を開始した者又は[[laws/船舶の再資源化解体の適正な実施に関する法律/本文/第25条.md|第二十五条]]第二項において準用する[[laws/船舶の再資源化解体の適正な実施に関する法律/本文/第23条.md|第二十三条]]第二項の規定に違反して特定外国船舶の再資源化解体を開始した者

- 一 偽りその他不正の手段により有害物質一覧表確認証書又は再資源化解体準備証書の交付を受けた者
- 二 [[laws/船舶の再資源化解体の適正な実施に関する法律/本文/第5条.md|第五条]]第一項の規定に違反して、特別特定日本船舶を日本国領海等以外の水域において航行の用に供した者
- 三 [[laws/船舶の再資源化解体の適正な実施に関する法律/本文/第10条.md|第十条]]第一項の規定に違反して、特定船舶の再資源化解体を開始した者
- 四 偽りその他不正の手段により[[laws/船舶の再資源化解体の適正な実施に関する法律/本文/第10条.md|第十条]]第一項の許可又は[[laws/船舶の再資源化解体の適正な実施に関する法律/本文/第11条.md|第十一条]]第一項の更新を受けた者
- 五 [[laws/船舶の再資源化解体の適正な実施に関する法律/本文/第12条.md|第十二条]]第一項の規定に違反して、[[laws/船舶の再資源化解体の適正な実施に関する法律/本文/第10条.md|第十条]]第二項第五号又は第六号に掲げる事項を変更した者
- 六 偽りその他不正の手段により[[laws/船舶の再資源化解体の適正な実施に関する法律/本文/第12条.md|第十二条]]第一項の許可を受けた者
- 七 偽りその他不正の手段により[[laws/船舶の再資源化解体の適正な実施に関する法律/本文/第13条.md|第十三条]]第一項から第三項までの認可を受けた者
- 八 偽りその他不正の手段により[[laws/船舶の再資源化解体の適正な実施に関する法律/本文/第18条.md|第十八条]]第一項又は[[laws/船舶の再資源化解体の適正な実施に関する法律/本文/第25条.md|第二十五条]]第一項の承認を受けた者
- 九 [[laws/船舶の再資源化解体の適正な実施に関する法律/本文/第23条.md|第二十三条]]第一項の規定に違反して特定日本船舶の譲渡し等若しくは譲受け等をした者又は同条第二項の規定に違反して特定外国船舶の譲受け等をした者
- 十 [[laws/船舶の再資源化解体の適正な実施に関する法律/本文/第25条.md|第二十五条]]第二項若しくは第七項において準用する[[laws/船舶の再資源化解体の適正な実施に関する法律/本文/第23条.md|第二十三条]]第一項の規定に違反して特定日本船舶の再資源化解体を開始した者又は[[laws/船舶の再資源化解体の適正な実施に関する法律/本文/第25条.md|第二十五条]]第二項において準用する[[laws/船舶の再資源化解体の適正な実施に関する法律/本文/第23条.md|第二十三条]]第二項の規定に違反して特定外国船舶の再資源化解体を開始した者
