# 第八十一条 

## 
法人の代表者又は法人若しくは人の代理人、使用人その他の従業者が、その法人又は人の業務に関して、次の各号に掲げる規定の違反行為をしたときは、行為者を罰するほか、その法人に対して当該各号に定める罰金刑を、その人に対して各本条の罰金刑を科する。[[laws/産業標準化法/本文/第78条.md|第七十八条]]第一号又は第二号一億円以下の罰金刑[[laws/産業標準化法/本文/第78条.md|第七十八条]]第三号若しくは第四号又は前二条各本条の罰金刑

- 一 [[laws/産業標準化法/本文/第78条.md|第七十八条]]第一号又は第二号一億円以下の罰金刑
- 二 [[laws/産業標準化法/本文/第78条.md|第七十八条]]第三号若しくは第四号又は前二条各本条の罰金刑
