# 第二百二十八条 

## 
次に掲げる者が、自己若しくは第三者の利益を図り又は投資法人に損害を加える目的で、その任務に背く行為をし、当該投資法人に財産上の損害を加えたときは、十年以下の拘禁刑若しくは千万円以下の罰金に処し、又はこれを併科する。投資法人の設立企画人投資法人の設立時執行役員又は設立時監督役員投資法人の執行役員又は監督役員民事保全法（平成元年法律第九十一号）第五十六条に規定する仮処分命令により選任された投資法人の執行役員又は監督役員の職務を代行する者[[laws/民事保全法/本文/第108条.md|第百八条]]第二項の規定により選任された投資法人の一時役員の職務を行うべき者一般事務受託者投資法人の検査役

- 一 投資法人の設立企画人
- 二 投資法人の設立時執行役員又は設立時監督役員
- 三 投資法人の執行役員又は監督役員
- 四 民事保全法（平成元年法律第九十一号）第五十六条に規定する仮処分命令により選任された投資法人の執行役員又は監督役員の職務を代行する者
- 五 [[laws/投資信託及び投資法人に関する法律/本文/第108条.md|第百八条]]第二項の規定により選任された投資法人の一時役員の職務を行うべき者
- 六 一般事務受託者
- 七 投資法人の検査役
## ２
次に掲げる者が、自己若しくは第三者の利益を図り又は清算投資法人に損害を加える目的で、その任務に背く行為をし、当該清算投資法人に財産上の損害を加えたときも、前項と同様とする。清算投資法人の清算執行人又は清算監督人民事保全法[[laws/民事保全法/本文/第56条.md|第五十六条]]に規定する仮処分命令により選任された清算投資法人の清算執行人又は清算監督人の職務を代行する者[[laws/民事保全法/本文/第153条.md|第百五十三条]]第二項において準用する[[laws/民事保全法/本文/第108条.md|第百八条]]第二項の規定により選任された清算投資法人の一時清算執行人又は清算監督人の職務を行うべき者清算投資法人の清算執行人代理（[[laws/民事保全法/本文/第164条.md|第百六十四条]]第四項において読み替えて準用する会社法[[laws/会社法/本文/第525条.md|第五百二十五条]]第一項の規定により選任された清算執行人代理をいう。[[laws/投資信託及び投資法人に関する法律/本文/第249条.md|第二百四十九条]]において同じ。）清算投資法人の監督委員（[[laws/民事保全法/本文/第164条.md|第百六十四条]]第四項において準用する会社法[[laws/会社法/本文/第527条.md|第五百二十七条]]第一項の規定により選任された監督委員をいう。[[laws/投資信託及び投資法人に関する法律/本文/第249条.md|第二百四十九条]]において同じ。）清算投資法人の調査委員（[[laws/民事保全法/本文/第164条.md|第百六十四条]]第四項において準用する会社法[[laws/会社法/本文/第533条.md|第五百三十三条]]の規定により選任された調査委員をいう。[[laws/投資信託及び投資法人に関する法律/本文/第249条.md|第二百四十九条]]において同じ。）

- 一 清算投資法人の清算執行人又は清算監督人
- 二 民事保全法第五十六条に規定する仮処分命令により選任された清算投資法人の清算執行人又は清算監督人の職務を代行する者
- 三 [[laws/投資信託及び投資法人に関する法律/本文/第153条.md|第百五十三条]]第二項において準用する[[laws/投資信託及び投資法人に関する法律/本文/第108条.md|第百八条]]第二項の規定により選任された清算投資法人の一時清算執行人又は清算監督人の職務を行うべき者
- 四 清算投資法人の清算執行人代理（[[laws/投資信託及び投資法人に関する法律/本文/第164条.md|第百六十四条]]第四項において読み替えて準用する会社法[[laws/会社法/本文/第525条.md|第五百二十五条]]第一項の規定により選任された清算執行人代理をいう。[[laws/投資信託及び投資法人に関する法律/本文/第249条.md|第二百四十九条]]において同じ。）
- 五 清算投資法人の監督委員（[[laws/投資信託及び投資法人に関する法律/本文/第164条.md|第百六十四条]]第四項において準用する会社法[[laws/会社法/本文/第527条.md|第五百二十七条]]第一項の規定により選任された監督委員をいう。[[laws/投資信託及び投資法人に関する法律/本文/第249条.md|第二百四十九条]]において同じ。）
- 六 清算投資法人の調査委員（[[laws/投資信託及び投資法人に関する法律/本文/第164条.md|第百六十四条]]第四項において準用する会社法[[laws/会社法/本文/第533条.md|第五百三十三条]]の規定により選任された調査委員をいう。[[laws/投資信託及び投資法人に関する法律/本文/第249条.md|第二百四十九条]]において同じ。）
## ３
前二項の罪の未遂は、罰する。
