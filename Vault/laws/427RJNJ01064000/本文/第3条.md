# 第三条 （派遣除外職員）

## 
令和三年オリンピック・パラリンピック特措法[[laws/427RJNJ01064000/人事院規則一―六四（職員の公益財団法人東_law.md|第十六条]]第一項の人事院規則で定める職員は、次に掲げる職員とする。条件付採用期間中の職員勤務延長職員休職者停職者派遣法[[laws/427RJNJ01064000/本文/第2条.md|第二条]]第一項の規定により派遣されている職員官民人事交流法[[laws/427RJNJ01064000/本文/第8条.md|第八条]]第二項に規定する交流派遣職員法科大学院派遣法[[laws/427RJNJ01064000/本文/第4条.md|第四条]]第三項又は[[laws/427RJNJ01064000/本文/第11条.md|第十一条]]第一項の規定により派遣されている職員福島復興再生特別措置法（平成二十四年法律第二十五号）第四十八条の三第一項又は[[laws/427RJNJ01064000/人事院規則一―六四（職員の公益財団法人東_law.md|第八十九条の三]]第一項の規定により派遣されている職員令和七年国際博覧会特措法[[laws/427RJNJ01064000/人事院規則一―六四（職員の公益財団法人東_law.md|第二十五条]]第一項の規定により派遣されている職員令和九年国際園芸博覧会特措法[[laws/427RJNJ01064000/人事院規則一―六四（職員の公益財団法人東_law.md|第十五条]]第一項の規定により派遣されている職員判事補及び検事の弁護士職務経験に関する法律（平成十六年法律第百二十一号）[[laws/427RJNJ01064000/本文/第2条.md|第二条]]第四項の規定により弁護士となってその職務を行う職員規則八―一二（職員の任免）[[laws/427RJNJ01064000/人事院規則一―六四（職員の公益財団法人東_law.md|第四十二条]]第二項の規定により任期を定めて採用された職員その他任期を限られた職員

- 一 条件付採用期間中の職員
- 二 勤務延長職員
- 三 休職者
- 四 停職者
- 五 派遣法[[laws/427RJNJ01064000/本文/第2条.md|第二条]]第一項の規定により派遣されている職員
- 六 官民人事交流法[[laws/427RJNJ01064000/本文/第8条.md|第八条]]第二項に規定する交流派遣職員
- 七 法科大学院派遣法[[laws/427RJNJ01064000/本文/第4条.md|第四条]]第三項又は[[laws/427RJNJ01064000/本文/第11条.md|第十一条]]第一項の規定により派遣されている職員
- 八 福島復興再生特別措置法（平成二十四年法律第二十五号）第四十八条の三第一項又は[[laws/427RJNJ01064000/人事院規則一―六四（職員の公益財団法人東_law.md|第八十九条の三]]第一項の規定により派遣されている職員
- 九 令和七年国際博覧会特措法[[laws/427RJNJ01064000/人事院規則一―六四（職員の公益財団法人東_law.md|第二十五条]]第一項の規定により派遣されている職員
- 十 令和九年国際園芸博覧会特措法[[laws/427RJNJ01064000/人事院規則一―六四（職員の公益財団法人東_law.md|第十五条]]第一項の規定により派遣されている職員
- 十一 判事補及び検事の弁護士職務経験に関する法律（平成十六年法律第百二十一号）[[laws/427RJNJ01064000/本文/第2条.md|第二条]]第四項の規定により弁護士となってその職務を行う職員
- 十二 規則八―一二（職員の任免）[[laws/427RJNJ01064000/人事院規則一―六四（職員の公益財団法人東_law.md|第四十二条]]第二項の規定により任期を定めて採用された職員その他任期を限られた職員
