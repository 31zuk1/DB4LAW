# 第五十五条 （登録の取消し等）

## 
内閣総理大臣は、登録試験機関が次の各号のいずれかに該当するときは、その登録を取り消し、又は期間を定めて許可試験の業務の全部若しくは一部の停止を命ずることができる。[[laws/414AC0000000103/本文/第45条.md|第四十五条]]第一号又は第三号に該当するに至ったとき。[[laws/414AC0000000103/本文/第48条.md|第四十八条]]、[[laws/414AC0000000103/本文/第49条.md|第四十九条]]、[[laws/414AC0000000103/本文/第51条.md|第五十一条]]、[[laws/414AC0000000103/本文/第52条.md|第五十二条]]第一項又は次条の規定に違反したとき。正当な理由がないのに[[laws/414AC0000000103/本文/第52条.md|第五十二条]]第二項各号の規定による請求を拒んだとき。[[laws/414AC0000000103/本文/第50条.md|第五十条]]第一項の認可を受けた試験業務規程によらないで許可試験を行ったとき。[[laws/414AC0000000103/本文/第50条.md|第五十条]]第三項又は前条の規定による命令に違反したとき。不正の手段により[[laws/414AC0000000103/本文/第43条.md|第四十三条]]第三項の登録（[[laws/414AC0000000103/本文/第47条.md|第四十七条]]第一項の登録の更新を含む。）を受けたとき。

- 一 [[laws/414AC0000000103/本文/第45条.md|第四十五条]]第一号又は第三号に該当するに至ったとき。
- 二 [[laws/414AC0000000103/本文/第48条.md|第四十八条]]、[[laws/414AC0000000103/本文/第49条.md|第四十九条]]、[[laws/414AC0000000103/本文/第51条.md|第五十一条]]、[[laws/414AC0000000103/本文/第52条.md|第五十二条]]第一項又は次条の規定に違反したとき。
- 三 正当な理由がないのに[[laws/414AC0000000103/本文/第52条.md|第五十二条]]第二項各号の規定による請求を拒んだとき。
- 四 [[laws/414AC0000000103/本文/第50条.md|第五十条]]第一項の認可を受けた試験業務規程によらないで許可試験を行ったとき。
- 五 [[laws/414AC0000000103/本文/第50条.md|第五十条]]第三項又は前条の規定による命令に違反したとき。
- 六 不正の手段により[[laws/414AC0000000103/本文/第43条.md|第四十三条]]第三項の登録（[[laws/414AC0000000103/本文/第47条.md|第四十七条]]第一項の登録の更新を含む。）を受けたとき。
