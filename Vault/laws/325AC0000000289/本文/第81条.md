# 第八十一条 （消滅の請求）

## 
一般採掘権者は、租鉱権者が租鉱料を支払うべき場合において、その支払を遅滞したときは、三月以上の期間を定めてその履行を催告し、その期間内に履行しないときは、租鉱権の消滅を請求することができる。
