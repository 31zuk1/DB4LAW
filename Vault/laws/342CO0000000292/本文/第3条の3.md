# 第三条の三 （介護保険の被保険者の資格に関する住民票の記載事項）

## 
法[[laws/住民基本台帳法施行令/本文/第7条.md|第七条]]第十号の三に規定する介護保険の被保険者の資格に関する事項で政令で定めるものは、介護保険の被保険者となり、又は介護保険の被保険者でなくなつた年月日とする。
