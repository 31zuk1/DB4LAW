# 第三条の三 （農林水産大臣の同意を要する保安林の指定の解除の規模）

## 
法[[laws/森林法施行令/本文/第26条の2.md|第二十六条の二]]第四項第一号の政令で定める規模は、同条第一項の規定により解除をしようとする場合にあつては一ヘクタールとし、同条第二項の規定により解除をしようとする場合にあつては五ヘクタールとする。
