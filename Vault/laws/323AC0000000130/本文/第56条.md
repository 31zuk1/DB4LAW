# 第五十六条 （許可の欠格事由）

## 
次の各号のいずれかに該当する者は、前条第一項の許可を受けることができない。拘禁刑以上の刑に処せられ、又はこの法律その他労働に関する法律の規定（次号に規定する規定を除く。）であつて政令で定めるもの若しくは暴力団員による不当な行為の防止等に関する法律の規定（同法第五十条（第二号に係る部分に限る。）及び[[laws/323AC0000000130/本文/第52条.md|第五十二条]]の規定を除く。）により、若しくは刑法[[laws/140AC0000000045/本文/第204条.md|第二百四条]]、[[laws/140AC0000000045/本文/第206条.md|第二百六条]]、[[laws/140AC0000000045/本文/第208条.md|第二百八条]]、[[laws/140AC0000000045/本文/第208条の2.md|第二百八条の二]]、[[laws/140AC0000000045/本文/第222条.md|第二百二十二条]]若しくは[[laws/140AC0000000045/本文/第247条.md|第二百四十七条]]の罪、暴力行為等処罰に関する法律の罪若しくは出入国管理及び難民認定法第七十三条の二第一項の罪を犯したことにより、罰金の刑に処せられ、その執行を終わり、又は執行を受けることがなくなつた日から起算して五年を経過しない者健康保険法[[laws/326CO0000000319/出入国管理及び難民認定法_law.md|第二百八条]]、[[laws/140AC0000000045/刑法_law.md|第二百十三条の二]]若しくは[[laws/140AC0000000045/本文/第214条.md|第二百十四条]]第一項、船員保険法[[laws/326CO0000000319/出入国管理及び難民認定法_law.md|第百五十六条]]、[[laws/140AC0000000045/本文/第159条.md|第百五十九条]]若しくは[[laws/140AC0000000045/本文/第160条.md|第百六十条]]第一項、労働者災害補償保険法[[laws/326CO0000000319/本文/第51条.md|第五十一条]]前段若しくは[[laws/326CO0000000319/本文/第54条.md|第五十四条]]第一項（同法第五十一条前段の規定に係る部分に限る。）、厚生年金保険法[[laws/326CO0000000319/出入国管理及び難民認定法_law.md|第百二条]]、[[laws/140AC0000000045/刑法_law.md|第百三条の二]]若しくは[[laws/140AC0000000045/本文/第104条.md|第百四条]]第一項（同法第百二条又は[[laws/326CO0000000319/出入国管理及び難民認定法_law.md|第百三条の二]]の規定に係る部分に限る。）、労働保険の保険料の徴収等に関する法律[[laws/326CO0000000319/本文/第46条.md|第四十六条]]前段若しくは[[laws/326CO0000000319/本文/第48条.md|第四十八条]]第一項（同法第四十六条前段の規定に係る部分に限る。）又は雇用保険法[[laws/323AC0000000130/本文/第83条.md|第八十三条]]若しくは[[laws/323AC0000000130/本文/第86条.md|第八十六条]]（同法第八十三条の規定に係る部分に限る。）の規定により罰金の刑に処せられ、その執行を終わり、又は執行を受けることがなくなつた日から起算して五年を経過しない者心身の故障により船員派遣事業を的確に遂行することができない者として国土交通省令で定めるもの破産手続開始の決定を受けて復権を得ない者[[laws/323AC0000000130/本文/第103条.md|第百三条]]第一項の規定により船員派遣事業の許可を取り消され、当該取消しの日から起算して五年を経過しない者[[laws/323AC0000000130/本文/第103条.md|第百三条]]第一項又は第三項の規定により船員派遣事業の許可を取り消された者が法人である場合（同項の規定により許可を取り消された場合については、当該法人が第一号又は第二号に規定する者に該当することとなつたことによる場合に限る。）において、当該取消しの処分を受ける原因となつた事項が発生した当時現に当該法人の役員であつた者で、当該取消しの日から起算して五年を経過しないもの[[laws/323AC0000000130/本文/第103条.md|第百三条]]第一項又は第三項の規定による船員派遣事業の許可の取消しの処分に係る行政手続法（平成五年法律第八十八号）第十五条の規定による通知があつた日から当該処分をする日又は処分をしないことを決定する日までの間に[[laws/405AC0000000088/行政手続法_law.md|第六十二条]]第一項の規定による船員派遣事業の廃止の届出をした者（当該船員派遣事業の廃止について相当の理由がある者を除く。）で、当該届出の日から起算して五年を経過しないもの前号に規定する期間内に[[laws/405AC0000000088/行政手続法_law.md|第六十二条]]第一項の規定による船員派遣事業の廃止の届出をした者が法人である場合において、同号の通知の日前六十日以内に当該法人（当該船員派遣事業の廃止について相当の理由がある法人を除く。）の役員であつた者で、当該届出の日から起算して五年を経過しないもの暴力団員等営業に関し成年者と同一の行為能力を有しない未成年者であつて、その法定代理人が前各号又は次号のいずれかに該当するもの法人であつて、その役員のうちに前各号のいずれかに該当する者があるもの暴力団員等がその事業活動を支配する者暴力団員等をその業務に従事させ、又はその業務の補助者として使用するおそれのある者

- 一 拘禁刑以上の刑に処せられ、又はこの法律その他労働に関する法律の規定（次号に規定する規定を除く。）であつて政令で定めるもの若しくは暴力団員による不当な行為の防止等に関する法律の規定（同法第五十条（第二号に係る部分に限る。）及び[[laws/323AC0000000130/本文/第52条.md|第五十二条]]の規定を除く。）により、若しくは刑法[[laws/140AC0000000045/本文/第204条.md|第二百四条]]、[[laws/140AC0000000045/本文/第206条.md|第二百六条]]、[[laws/140AC0000000045/本文/第208条.md|第二百八条]]、[[laws/140AC0000000045/本文/第208条の2.md|第二百八条の二]]、[[laws/140AC0000000045/本文/第222条.md|第二百二十二条]]若しくは[[laws/140AC0000000045/本文/第247条.md|第二百四十七条]]の罪、暴力行為等処罰に関する法律の罪若しくは出入国管理及び難民認定法第七十三条の二第一項の罪を犯したことにより、罰金の刑に処せられ、その執行を終わり、又は執行を受けることがなくなつた日から起算して五年を経過しない者
- 二 健康保険法[[laws/323AC0000000130/船員職業安定法_law.md|第二百八条]]、[[laws/323AC0000000130/船員職業安定法_law.md|第二百十三条の二]]若しくは[[laws/323AC0000000130/船員職業安定法_law.md|第二百十四条]]第一項、船員保険法[[laws/323AC0000000130/船員職業安定法_law.md|第百五十六条]]、[[laws/323AC0000000130/船員職業安定法_law.md|第百五十九条]]若しくは[[laws/323AC0000000130/船員職業安定法_law.md|第百六十条]]第一項、労働者災害補償保険法[[laws/323AC0000000130/本文/第51条.md|第五十一条]]前段若しくは[[laws/323AC0000000130/本文/第54条.md|第五十四条]]第一項（同法第五十一条前段の規定に係る部分に限る。）、厚生年金保険法[[laws/323AC0000000130/本文/第102条.md|第百二条]]、[[laws/323AC0000000130/船員職業安定法_law.md|第百三条の二]]若しくは[[laws/323AC0000000130/本文/第104条.md|第百四条]]第一項（同法第百二条又は[[laws/323AC0000000130/船員職業安定法_law.md|第百三条の二]]の規定に係る部分に限る。）、労働保険の保険料の徴収等に関する法律[[laws/323AC0000000130/本文/第46条.md|第四十六条]]前段若しくは[[laws/323AC0000000130/本文/第48条.md|第四十八条]]第一項（同法第四十六条前段の規定に係る部分に限る。）又は雇用保険法[[laws/323AC0000000130/本文/第83条.md|第八十三条]]若しくは[[laws/323AC0000000130/本文/第86条.md|第八十六条]]（同法第八十三条の規定に係る部分に限る。）の規定により罰金の刑に処せられ、その執行を終わり、又は執行を受けることがなくなつた日から起算して五年を経過しない者
- 三 心身の故障により船員派遣事業を的確に遂行することができない者として国土交通省令で定めるもの
- 四 破産手続開始の決定を受けて復権を得ない者
- 五 [[laws/323AC0000000130/本文/第103条.md|第百三条]]第一項の規定により船員派遣事業の許可を取り消され、当該取消しの日から起算して五年を経過しない者
- 六 [[laws/323AC0000000130/本文/第103条.md|第百三条]]第一項又は第三項の規定により船員派遣事業の許可を取り消された者が法人である場合（同項の規定により許可を取り消された場合については、当該法人が第一号又は第二号に規定する者に該当することとなつたことによる場合に限る。）において、当該取消しの処分を受ける原因となつた事項が発生した当時現に当該法人の役員であつた者で、当該取消しの日から起算して五年を経過しないもの
- 七 [[laws/323AC0000000130/本文/第103条.md|第百三条]]第一項又は第三項の規定による船員派遣事業の許可の取消しの処分に係る行政手続法（平成五年法律第八十八号）第十五条の規定による通知があつた日から当該処分をする日又は処分をしないことを決定する日までの間に[[laws/405AC0000000088/行政手続法_law.md|第六十二条]]第一項の規定による船員派遣事業の廃止の届出をした者（当該船員派遣事業の廃止について相当の理由がある者を除く。）で、当該届出の日から起算して五年を経過しないもの
- 八 前号に規定する期間内に[[laws/323AC0000000130/本文/第62条.md|第六十二条]]第一項の規定による船員派遣事業の廃止の届出をした者が法人である場合において、同号の通知の日前六十日以内に当該法人（当該船員派遣事業の廃止について相当の理由がある法人を除く。）の役員であつた者で、当該届出の日から起算して五年を経過しないもの
- 九 暴力団員等
- 十 営業に関し成年者と同一の行為能力を有しない未成年者であつて、その法定代理人が前各号又は次号のいずれかに該当するもの
- 十一 法人であつて、その役員のうちに前各号のいずれかに該当する者があるもの
- 十二 暴力団員等がその事業活動を支配する者
- 十三 暴力団員等をその業務に従事させ、又はその業務の補助者として使用するおそれのある者
