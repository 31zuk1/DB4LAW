# 第九十九条の三 

## 
次の各号のいずれかに該当する者は、三十万円以下の罰金に処する。準用銀行法[[laws/413AC0000000093/農林中央金庫法_law.md|第五十二条の三十九]]第二項若しくは[[laws/413AC0000000093/農林中央金庫法_law.md|第五十二条の五十二]]、[[laws/413AC0000000093/本文/第95条の5.md|第九十五条の五]]の十第一項において準用する銀行法[[laws/413AC0000000093/農林中央金庫法_law.md|第五十二条の六十一]]の六第三項若しくは[[laws/413AC0000000093/農林中央金庫法_law.md|第五十二条の六十一]]の七第一項若しくは[[laws/413AC0000000093/本文/第95条の8.md|第九十五条の八]]第一項において準用する同法第五十二条の七十八第一項、[[laws/413AC0000000093/農林中央金庫法_law.md|第五十二条の七十九]]若しくは[[laws/413AC0000000093/農林中央金庫法_law.md|第五十二条の八十三]]第二項の規定による届出をせず、又は虚偽の届出をした者準用銀行法[[laws/413AC0000000093/農林中央金庫法_law.md|第五十二条の四十]]第一項又は第二項の規定に違反した者準用銀行法[[laws/413AC0000000093/農林中央金庫法_law.md|第五十二条の四十]]第三項の規定に違反して、同条第一項の標識又はこれに類似する標識を掲示した者[[laws/413AC0000000093/本文/第95条の5.md|第九十五条の五]]の十第一項において準用する銀行法[[laws/413AC0000000093/農林中央金庫法_law.md|第五十二条の六十一]]の二十一第三項の規定に違反してその名称中に認定農林中央金庫電子決済等代行事業者協会の協会員と誤認されるおそれのある文字を使用した者[[laws/413AC0000000093/本文/第95条の8.md|第九十五条の八]]第一項において準用する銀行法[[laws/413AC0000000093/農林中央金庫法_law.md|第五十二条の六十八]]第一項の規定による報告をせず、又は虚偽の報告をした者[[laws/413AC0000000093/本文/第95条の8.md|第九十五条の八]]第一項において準用する銀行法[[laws/413AC0000000093/農林中央金庫法_law.md|第五十二条の八十三]]第三項若しくは[[laws/413AC0000000093/農林中央金庫法_law.md|第五十二条の八十四]]第三項の規定による通知をせず、又は虚偽の通知をした者[[laws/413AC0000000093/本文/第96条の2.md|第九十六条の二]]第四項において準用する会社法[[laws/417AC0000000086/本文/第955条.md|第九百五十五条]]第一項の規定に違反して、調査記録簿等（同項に規定する調査記録簿等をいう。以下この号において同じ。）に同項に規定する電子公告調査に関し法務省令で定めるものを記載せず、若しくは記録せず、若しくは虚偽の記載若しくは記録をし、又は同項の規定に違反して調査記録簿等を保存しなかった者

- 一 準用銀行法[[laws/413AC0000000093/農林中央金庫法_law.md|第五十二条の三十九]]第二項若しくは[[laws/413AC0000000093/農林中央金庫法_law.md|第五十二条の五十二]]、[[laws/413AC0000000093/本文/第95条の5.md|第九十五条の五]]の十第一項において準用する銀行法[[laws/413AC0000000093/農林中央金庫法_law.md|第五十二条の六十一]]の六第三項若しくは[[laws/413AC0000000093/農林中央金庫法_law.md|第五十二条の六十一]]の七第一項若しくは[[laws/413AC0000000093/本文/第95条の8.md|第九十五条の八]]第一項において準用する同法第五十二条の七十八第一項、[[laws/413AC0000000093/農林中央金庫法_law.md|第五十二条の七十九]]若しくは[[laws/413AC0000000093/農林中央金庫法_law.md|第五十二条の八十三]]第二項の規定による届出をせず、又は虚偽の届出をした者
- 二 準用銀行法[[laws/413AC0000000093/農林中央金庫法_law.md|第五十二条の四十]]第一項又は第二項の規定に違反した者
- 三 準用銀行法[[laws/413AC0000000093/農林中央金庫法_law.md|第五十二条の四十]]第三項の規定に違反して、同条第一項の標識又はこれに類似する標識を掲示した者
- 四 [[laws/413AC0000000093/本文/第95条の5.md|第九十五条の五]]の十第一項において準用する銀行法[[laws/413AC0000000093/農林中央金庫法_law.md|第五十二条の六十一]]の二十一第三項の規定に違反してその名称中に認定農林中央金庫電子決済等代行事業者協会の協会員と誤認されるおそれのある文字を使用した者
- 五 [[laws/413AC0000000093/本文/第95条の8.md|第九十五条の八]]第一項において準用する銀行法[[laws/413AC0000000093/農林中央金庫法_law.md|第五十二条の六十八]]第一項の規定による報告をせず、又は虚偽の報告をした者
- 六 [[laws/413AC0000000093/本文/第95条の8.md|第九十五条の八]]第一項において準用する銀行法[[laws/413AC0000000093/農林中央金庫法_law.md|第五十二条の八十三]]第三項若しくは[[laws/413AC0000000093/農林中央金庫法_law.md|第五十二条の八十四]]第三項の規定による通知をせず、又は虚偽の通知をした者
- 七 [[laws/413AC0000000093/本文/第96条の2.md|第九十六条の二]]第四項において準用する会社法[[laws/417AC0000000086/本文/第955条.md|第九百五十五条]]第一項の規定に違反して、調査記録簿等（同項に規定する調査記録簿等をいう。以下この号において同じ。）に同項に規定する電子公告調査に関し法務省令で定めるものを記載せず、若しくは記録せず、若しくは虚偽の記載若しくは記録をし、又は同項の規定に違反して調査記録簿等を保存しなかった者
