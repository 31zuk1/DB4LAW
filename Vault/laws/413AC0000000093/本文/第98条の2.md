# 第九十八条の二 

## 
次の各号のいずれかに該当する者は、三年以下の拘禁刑若しくは三百万円以下の罰金に処し、又はこれを併科する。[[laws/農林中央金庫法/本文/第3条.md|第三条]]第八項の規定に違反して他人に農林中央金庫の業務を営ませた者[[laws/農林中央金庫法/本文/第59条の3.md|第五十九条の三]]、[[laws/農林中央金庫法/本文/第59条の7.md|第五十九条の七]]又は[[laws/農林中央金庫法/本文/第95条の5.md|第九十五条の五]]において準用する金融商品取引法（以下「準用金融商品取引法」という。）第三十九条第一項の規定に違反した者[[laws/農林中央金庫法/本文/第95条の2.md|第九十五条の二]]第一項の規定に違反して許可を受けないで農林中央金庫代理業を営んだ者不正の手段により[[laws/農林中央金庫法/本文/第95条の2.md|第九十五条の二]]第一項の許可を受けた者[[laws/農林中央金庫法/本文/第59条の8.md|第五十九条の八]]又は[[laws/農林中央金庫法/本文/第95条の4.md|第九十五条の四]]第一項において準用する銀行法（以下「準用銀行法」という。）[[laws/農林中央金庫法/本文/第52条の41.md|第五十二条の四十一]]の規定に違反して他人に外国銀行代理業務又は農林中央金庫代理業を営ませた者[[laws/農林中央金庫法/本文/第95条の5.md|第九十五条の五]]の二第一項の規定に違反して登録を受けないで農林中央金庫電子決済等代行業を営んだ者不正の手段により[[laws/農林中央金庫法/本文/第95条の5.md|第九十五条の五]]の二第一項の登録を受けた者[[laws/農林中央金庫法/本文/第95条の5.md|第九十五条の五]]の九第四項の規定による農林中央金庫電子決済等代行業の廃止の命令に違反した者

- 一 [[laws/農林中央金庫法/本文/第3条.md|第三条]]第八項の規定に違反して他人に農林中央金庫の業務を営ませた者
- 二 [[laws/農林中央金庫法/本文/第59条の3.md|第五十九条の三]]、[[laws/農林中央金庫法/本文/第59条の7.md|第五十九条の七]]又は[[laws/農林中央金庫法/本文/第95条の5.md|第九十五条の五]]において準用する金融商品取引法（以下「準用金融商品取引法」という。）第三十九条第一項の規定に違反した者
- 三 [[laws/農林中央金庫法/本文/第95条の2.md|第九十五条の二]]第一項の規定に違反して許可を受けないで農林中央金庫代理業を営んだ者
- 四 不正の手段により[[laws/農林中央金庫法/本文/第95条の2.md|第九十五条の二]]第一項の許可を受けた者
- 五 [[laws/農林中央金庫法/本文/第59条の8.md|第五十九条の八]]又は[[laws/農林中央金庫法/本文/第95条の4.md|第九十五条の四]]第一項において準用する銀行法（以下「準用銀行法」という。）[[laws/農林中央金庫法/本文/第52条の41.md|第五十二条の四十一]]の規定に違反して他人に外国銀行代理業務又は農林中央金庫代理業を営ませた者
- 六 [[laws/農林中央金庫法/本文/第95条の5.md|第九十五条の五]]の二第一項の規定に違反して登録を受けないで農林中央金庫電子決済等代行業を営んだ者
- 七 不正の手段により[[laws/農林中央金庫法/本文/第95条の5.md|第九十五条の五]]の二第一項の登録を受けた者
- 八 [[laws/農林中央金庫法/本文/第95条の5.md|第九十五条の五]]の九第四項の規定による農林中央金庫電子決済等代行業の廃止の命令に違反した者
