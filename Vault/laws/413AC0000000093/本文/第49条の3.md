# 第四十九条の三 （延期又は続行の決議）

## 
総会においてその延期又は続行について決議があった場合には、[[laws/413AC0000000093/本文/第46条の2.md|第四十六条の二]]及び[[laws/413AC0000000093/本文/第46条の3.md|第四十六条の三]]の規定は、適用しない。
