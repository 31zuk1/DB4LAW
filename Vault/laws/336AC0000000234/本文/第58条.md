# 第五十八条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、三十万円以下の罰金に処する。[[laws/電気用品安全法/本文/第3条.md|第三条]]の規定による届出をせず、又は虚偽の届出をしたとき。[[laws/電気用品安全法/本文/第8条.md|第八条]]第二項の規定に違反して検査を行わず、検査記録を作成せず、若しくは虚偽の検査記録を作成し、又は検査記録を保存しなかつたとき。[[laws/電気用品安全法/本文/第8条.md|第八条]]第三項前段の規定に違反して、検査記録の写しを提供しなかつたとき。[[laws/電気用品安全法/本文/第8条.md|第八条]]第三項後段の規定に違反して、検査記録の写しを保存しなかつたとき。[[laws/電気用品安全法/本文/第9条.md|第九条]]第一項の規定に違反して、証明書の交付を受けず、又は証明書を保存しなかつたとき。[[laws/電気用品安全法/本文/第9条.md|第九条]]第三項前段の規定に違反して、同項に規定する写しを提供しなかつたとき。[[laws/電気用品安全法/本文/第9条.md|第九条]]第三項後段の規定に違反して、同項に規定する写しを保存しなかつたとき。[[laws/電気用品安全法/本文/第36条.md|第三十六条]]の規定による届出をせず、又は虚偽の届出をしたとき。[[laws/電気用品安全法/本文/第42条.md|第四十二条]]第一項の規定に違反して同項に規定する事項の記載をせず、若しくは虚偽の記載をし、又は同条第二項の規定に違反して帳簿を保存しなかつたとき。[[laws/電気用品安全法/本文/第45条.md|第四十五条]]第一項又は第二項の規定による報告をせず、又は虚偽の報告をしたとき。[[laws/電気用品安全法/本文/第46条.md|第四十六条]]第一項又は第二項の規定による検査を拒み、妨げ、若しくは忌避し、又は同項の規定による質問に対して、正当な理由なく陳述をせず、若しくは虚偽の陳述をしたとき。[[laws/電気用品安全法/本文/第46条の2.md|第四十六条の二]]第一項の規定による命令に違反したとき。

- 一 [[laws/電気用品安全法/本文/第3条.md|第三条]]の規定による届出をせず、又は虚偽の届出をしたとき。
- 二 [[laws/電気用品安全法/本文/第8条.md|第八条]]第二項の規定に違反して検査を行わず、検査記録を作成せず、若しくは虚偽の検査記録を作成し、又は検査記録を保存しなかつたとき。
- 三 [[laws/電気用品安全法/本文/第8条.md|第八条]]第三項前段の規定に違反して、検査記録の写しを提供しなかつたとき。
- 四 [[laws/電気用品安全法/本文/第8条.md|第八条]]第三項後段の規定に違反して、検査記録の写しを保存しなかつたとき。
- 五 [[laws/電気用品安全法/本文/第9条.md|第九条]]第一項の規定に違反して、証明書の交付を受けず、又は証明書を保存しなかつたとき。
- 六 [[laws/電気用品安全法/本文/第9条.md|第九条]]第三項前段の規定に違反して、同項に規定する写しを提供しなかつたとき。
- 七 [[laws/電気用品安全法/本文/第9条.md|第九条]]第三項後段の規定に違反して、同項に規定する写しを保存しなかつたとき。
- 八 [[laws/電気用品安全法/本文/第36条.md|第三十六条]]の規定による届出をせず、又は虚偽の届出をしたとき。
- 九 [[laws/電気用品安全法/本文/第42条.md|第四十二条]]第一項の規定に違反して同項に規定する事項の記載をせず、若しくは虚偽の記載をし、又は同条第二項の規定に違反して帳簿を保存しなかつたとき。
- 十 [[laws/電気用品安全法/本文/第45条.md|第四十五条]]第一項又は第二項の規定による報告をせず、又は虚偽の報告をしたとき。
- 十一 [[laws/電気用品安全法/本文/第46条.md|第四十六条]]第一項又は第二項の規定による検査を拒み、妨げ、若しくは忌避し、又は同項の規定による質問に対して、正当な理由なく陳述をせず、若しくは虚偽の陳述をしたとき。
- 十二 [[laws/電気用品安全法/本文/第46条の2.md|第四十六条の二]]第一項の規定による命令に違反したとき。
