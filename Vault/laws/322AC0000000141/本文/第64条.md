# 第六十四条 

## 
次の各号のいずれかに該当するときは、その違反行為をした者は、一年以下の拘禁刑又は百万円以下の罰金に処する。[[laws/322AC0000000141/本文/第30条.md|第三十条]]第一項の規定に違反したとき。偽りその他不正の行為により、[[laws/322AC0000000141/本文/第30条.md|第三十条]]第一項の許可、[[laws/322AC0000000141/本文/第32条の6.md|第三十二条の六]]第二項（[[laws/322AC0000000141/本文/第33条.md|第三十三条]]第四項において準用する場合を含む。）の規定による許可の有効期間の更新、[[laws/322AC0000000141/本文/第33条.md|第三十三条]]第一項の許可、[[laws/322AC0000000141/本文/第36条.md|第三十六条]]第一項の許可又は[[laws/322AC0000000141/本文/第45条.md|第四十五条]]の許可を受けたとき。[[laws/322AC0000000141/本文/第32条の9.md|第三十二条の九]]第二項（[[laws/322AC0000000141/本文/第33条.md|第三十三条]]第四項、[[laws/322AC0000000141/本文/第33条の2.md|第三十三条の二]]第七項及び[[laws/322AC0000000141/本文/第33条の3.md|第三十三条の三]]第二項において準用する場合を含む。）の規定による事業の停止の命令に違反したとき。[[laws/322AC0000000141/本文/第32条の10.md|第三十二条の十]]（[[laws/322AC0000000141/本文/第33条.md|第三十三条]]第四項、[[laws/322AC0000000141/本文/第33条の2.md|第三十三条の二]]第七項及び[[laws/322AC0000000141/本文/第33条の3.md|第三十三条の三]]第二項において準用する場合を含む。）の規定に違反したとき。[[laws/322AC0000000141/本文/第32条の11.md|第三十二条の十一]]第一項の規定に違反したとき。[[laws/322AC0000000141/本文/第33条.md|第三十三条]]第一項の規定に違反したとき。[[laws/322AC0000000141/本文/第33条の3.md|第三十三条の三]]第二項において準用する[[laws/322AC0000000141/本文/第32条の9.md|第三十二条の九]]第一項の規定による事業の廃止の命令に違反したとき。[[laws/322AC0000000141/本文/第36条.md|第三十六条]]第一項の規定に違反したとき。[[laws/322AC0000000141/本文/第41条.md|第四十一条]]第一項（[[laws/322AC0000000141/本文/第46条.md|第四十六条]]において準用する場合を含む。）の規定による労働者の募集の業務若しくは労働者供給事業の停止又は[[laws/322AC0000000141/本文/第41条.md|第四十一条]]第二項の規定による労働者の募集の業務の廃止若しくは停止の命令に違反したとき。[[laws/322AC0000000141/本文/第43条の4.md|第四十三条の四]]の規定による特定募集情報等提供事業の停止の命令に違反したとき。[[laws/322AC0000000141/本文/第44条.md|第四十四条]]の規定に違反したとき。

- 一 [[laws/322AC0000000141/本文/第30条.md|第三十条]]第一項の規定に違反したとき。
- 一の二 偽りその他不正の行為により、[[laws/322AC0000000141/本文/第30条.md|第三十条]]第一項の許可、[[laws/322AC0000000141/本文/第32条の6.md|第三十二条の六]]第二項（[[laws/322AC0000000141/本文/第33条.md|第三十三条]]第四項において準用する場合を含む。）の規定による許可の有効期間の更新、[[laws/322AC0000000141/本文/第33条.md|第三十三条]]第一項の許可、[[laws/322AC0000000141/本文/第36条.md|第三十六条]]第一項の許可又は[[laws/322AC0000000141/本文/第45条.md|第四十五条]]の許可を受けたとき。
- 二 [[laws/322AC0000000141/本文/第32条の9.md|第三十二条の九]]第二項（[[laws/322AC0000000141/本文/第33条.md|第三十三条]]第四項、[[laws/322AC0000000141/本文/第33条の2.md|第三十三条の二]]第七項及び[[laws/322AC0000000141/本文/第33条の3.md|第三十三条の三]]第二項において準用する場合を含む。）の規定による事業の停止の命令に違反したとき。
- 三 [[laws/322AC0000000141/本文/第32条の10.md|第三十二条の十]]（[[laws/322AC0000000141/本文/第33条.md|第三十三条]]第四項、[[laws/322AC0000000141/本文/第33条の2.md|第三十三条の二]]第七項及び[[laws/322AC0000000141/本文/第33条の3.md|第三十三条の三]]第二項において準用する場合を含む。）の規定に違反したとき。
- 四 [[laws/322AC0000000141/本文/第32条の11.md|第三十二条の十一]]第一項の規定に違反したとき。
- 五 [[laws/322AC0000000141/本文/第33条.md|第三十三条]]第一項の規定に違反したとき。
- 六 [[laws/322AC0000000141/本文/第33条の3.md|第三十三条の三]]第二項において準用する[[laws/322AC0000000141/本文/第32条の9.md|第三十二条の九]]第一項の規定による事業の廃止の命令に違反したとき。
- 七 [[laws/322AC0000000141/本文/第36条.md|第三十六条]]第一項の規定に違反したとき。
- 八 [[laws/322AC0000000141/本文/第41条.md|第四十一条]]第一項（[[laws/322AC0000000141/本文/第46条.md|第四十六条]]において準用する場合を含む。）の規定による労働者の募集の業務若しくは労働者供給事業の停止又は[[laws/322AC0000000141/本文/第41条.md|第四十一条]]第二項の規定による労働者の募集の業務の廃止若しくは停止の命令に違反したとき。
- 九 [[laws/322AC0000000141/本文/第43条の4.md|第四十三条の四]]の規定による特定募集情報等提供事業の停止の命令に違反したとき。
- 十 [[laws/322AC0000000141/本文/第44条.md|第四十四条]]の規定に違反したとき。
