# 第六十五条 

## 
次の各号のいずれかに該当するときは、その違反行為をした者は、六月以下の拘禁刑又は三十万円以下の罰金に処する。[[laws/職業安定法/本文/第11条.md|第十一条]]第三項の規定に違反したとき。[[laws/職業安定法/本文/第32条の3.md|第三十二条の三]]第一項又は第二項の規定に違反したとき。[[laws/職業安定法/本文/第33条の2.md|第三十三条の二]]第一項又は[[laws/職業安定法/本文/第33条の3.md|第三十三条の三]]第一項の規定による届出をしないで、無料の職業紹介事業を行つたとき。[[laws/職業安定法/本文/第36条.md|第三十六条]]第二項又は第三項の規定に違反したとき。[[laws/職業安定法/本文/第37条.md|第三十七条]]の規定による制限又は指示に従わなかつたとき。[[laws/職業安定法/本文/第39条.md|第三十九条]]、[[laws/職業安定法/本文/第40条.md|第四十条]]又は[[laws/職業安定法/本文/第43条の3.md|第四十三条の三]]の規定に違反したとき。[[laws/職業安定法/本文/第43条の2.md|第四十三条の二]]第一項の規定による届出をしないで、特定募集情報等提供事業を行つたとき。[[laws/職業安定法/本文/第48条の3.md|第四十八条の三]]第一項の規定による命令に違反したとき。虚偽の広告をなし、又は虚偽の条件を提示して、職業紹介、労働者の募集、募集情報等提供若しくは労働者の供給を行い、又はこれらに従事したとき。虚偽の条件を提示して、公共職業安定所又は職業紹介を行う者に求人の申込みを行つたとき。労働条件が法令に違反する工場事業場等のために、職業紹介、労働者の募集若しくは労働者の供給を行い、又はこれに従事したとき。

- 一 [[laws/職業安定法/本文/第11条.md|第十一条]]第三項の規定に違反したとき。
- 二 [[laws/職業安定法/本文/第32条の3.md|第三十二条の三]]第一項又は第二項の規定に違反したとき。
- 三 [[laws/職業安定法/本文/第33条の2.md|第三十三条の二]]第一項又は[[laws/職業安定法/本文/第33条の3.md|第三十三条の三]]第一項の規定による届出をしないで、無料の職業紹介事業を行つたとき。
- 四 [[laws/職業安定法/本文/第36条.md|第三十六条]]第二項又は第三項の規定に違反したとき。
- 五 [[laws/職業安定法/本文/第37条.md|第三十七条]]の規定による制限又は指示に従わなかつたとき。
- 六 [[laws/職業安定法/本文/第39条.md|第三十九条]]、[[laws/職業安定法/本文/第40条.md|第四十条]]又は[[laws/職業安定法/本文/第43条の3.md|第四十三条の三]]の規定に違反したとき。
- 七 [[laws/職業安定法/本文/第43条の2.md|第四十三条の二]]第一項の規定による届出をしないで、特定募集情報等提供事業を行つたとき。
- 八 [[laws/職業安定法/本文/第48条の3.md|第四十八条の三]]第一項の規定による命令に違反したとき。
- 九 虚偽の広告をなし、又は虚偽の条件を提示して、職業紹介、労働者の募集、募集情報等提供若しくは労働者の供給を行い、又はこれらに従事したとき。
- 十 虚偽の条件を提示して、公共職業安定所又は職業紹介を行う者に求人の申込みを行つたとき。
- 十一 労働条件が法令に違反する工場事業場等のために、職業紹介、労働者の募集若しくは労働者の供給を行い、又はこれに従事したとき。
