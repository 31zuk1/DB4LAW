# 第四十条 （権限の委任）

## 
法に規定する国土交通大臣の権限のうち、次に掲げるもの以外のものは、地方整備局長及び北海道開発局長に委任する。ただし、法[[laws/都市再開発法施行規則/本文/第124条.md|第百二十四条]]第一項並びに[[laws/都市再開発法施行規則/本文/第126条.md|第百二十六条]]第一項及び第二項の規定に基づく権限については、国土交通大臣が自ら行うことを妨げない。法[[laws/都市再開発法施行規則/本文/第2条の2.md|第二条の二]]第五項の規定により市街地再開発事業を施行する必要があると認め、及び同条第六項の規定により自動車専用道路の新設又は改築が著しく困難であると認めること。法[[laws/都市再開発法施行規則/本文/第58条.md|第五十八条]]第一項の規定により施行規程及び事業計画を認可し、同条第三項（同条第四項において準用する場合を含む。）において準用する法[[laws/都市再開発法施行規則/本文/第16条.md|第十六条]]第一項の規定により施行規程及び事業計画を公衆の縦覧に供させ、同条第二項の規定による意見書を受理し、並びに同条第三項の規定により意見書の内容を審査し、及び必要な修正を命じ、又は通知し、並びに法[[laws/都市再開発法施行規則/本文/第58条.md|第五十八条]]第三項において準用する法[[laws/都市再開発法施行規則/本文/第19条.md|第十九条]]第一項の規定により図書を送付すること（独立行政法人都市再生機構が施行する市街地再開発事業（以下この条において「機構施行事業」という。）に係るものに限る。）。法[[laws/都市再開発法施行規則/本文/第72条.md|第七十二条]]第一項後段（同条第四項において準用する場合を含む。）の規定による権利変換計画の認可をすること（機構施行事業に係るものに限る。）。法[[laws/都市再開発法施行規則/本文/第99条の3.md|第九十九条の三]]第三項（法[[laws/都市再開発法施行規則/本文/第118条の28.md|第百十八条の二十八]]第二項において準用する場合を含む。）の規定による特定建築者の決定の承認をすること（機構施行事業に係るものに限る。）。法[[laws/都市再開発法施行規則/本文/第118条の6.md|第百十八条の六]]第一項後段（同条第四項において準用する場合を含む。）の規定による管理処分計画の認可をすること（機構施行事業に係るものに限る。）。法[[laws/都市再開発法施行規則/本文/第120条.md|第百二十条]]第三項の規定により裁定し、当事者の意見を聴き、及び総務大臣と協議すること（機構施行事業に係るものに限る。）。法[[laws/都市再開発法施行規則/本文/第128条.md|第百二十八条]]第一項の規定による審査請求又は同条第二項の規定による再審査請求に対して裁決をすること。法[[laws/都市再開発法施行規則/本文/第133条.md|第百三十三条]]第一項の規定による管理規約の認可をすること（機構施行事業に係るものに限る。）。

- 一 法[[laws/都市再開発法施行規則/本文/第2条の2.md|第二条の二]]第五項の規定により市街地再開発事業を施行する必要があると認め、及び同条第六項の規定により自動車専用道路の新設又は改築が著しく困難であると認めること。
- 二 法[[laws/都市再開発法施行規則/本文/第58条.md|第五十八条]]第一項の規定により施行規程及び事業計画を認可し、同条第三項（同条第四項において準用する場合を含む。）において準用する法[[laws/都市再開発法施行規則/本文/第16条.md|第十六条]]第一項の規定により施行規程及び事業計画を公衆の縦覧に供させ、同条第二項の規定による意見書を受理し、並びに同条第三項の規定により意見書の内容を審査し、及び必要な修正を命じ、又は通知し、並びに法[[laws/都市再開発法施行規則/本文/第58条.md|第五十八条]]第三項において準用する法[[laws/都市再開発法施行規則/本文/第19条.md|第十九条]]第一項の規定により図書を送付すること（独立行政法人都市再生機構が施行する市街地再開発事業（以下この条において「機構施行事業」という。）に係るものに限る。）。
- 三 法[[laws/都市再開発法施行規則/本文/第72条.md|第七十二条]]第一項後段（同条第四項において準用する場合を含む。）の規定による権利変換計画の認可をすること（機構施行事業に係るものに限る。）。
- 四 法[[laws/都市再開発法施行規則/本文/第99条の3.md|第九十九条の三]]第三項（法[[laws/都市再開発法施行規則/本文/第118条の28.md|第百十八条の二十八]]第二項において準用する場合を含む。）の規定による特定建築者の決定の承認をすること（機構施行事業に係るものに限る。）。
- 五 法[[laws/都市再開発法施行規則/本文/第118条の6.md|第百十八条の六]]第一項後段（同条第四項において準用する場合を含む。）の規定による管理処分計画の認可をすること（機構施行事業に係るものに限る。）。
- 六 法[[laws/都市再開発法施行規則/本文/第120条.md|第百二十条]]第三項の規定により裁定し、当事者の意見を聴き、及び総務大臣と協議すること（機構施行事業に係るものに限る。）。
- 七 法[[laws/都市再開発法施行規則/本文/第128条.md|第百二十八条]]第一項の規定による審査請求又は同条第二項の規定による再審査請求に対して裁決をすること。
- 八 法[[laws/都市再開発法施行規則/本文/第133条.md|第百三十三条]]第一項の規定による管理規約の認可をすること（機構施行事業に係るものに限る。）。
