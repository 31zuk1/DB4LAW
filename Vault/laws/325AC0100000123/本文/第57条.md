# 第五十七条 

## 
次の各号のいずれかに該当する者は、十万円以下の過料に処する。[[laws/精神保健及び精神障害者福祉に関する法律/本文/第19条の4.md|第十九条の四]]の二（[[laws/精神保健及び精神障害者福祉に関する法律/本文/第21条.md|第二十一条]]第五項、[[laws/精神保健及び精神障害者福祉に関する法律/本文/第33条.md|第三十三条]]第四項及び[[laws/精神保健及び精神障害者福祉に関する法律/本文/第33条の6.md|第三十三条の六]]第三項において準用する場合を含む。）の規定に違反した者[[laws/精神保健及び精神障害者福祉に関する法律/本文/第19条の6.md|第十九条の六]]の九の規定による届出をせず、又は虚偽の届出をした者[[laws/精神保健及び精神障害者福祉に関する法律/本文/第19条の6.md|第十九条の六]]の十第一項の規定に違反して財務諸表等を備えて置かず、財務諸表等に記載すべき事項を記載せず、若しくは虚偽の記載をし、又は正当な理由がないのに同条第二項各号の規定による請求を拒んだ者[[laws/精神保健及び精神障害者福祉に関する法律/本文/第19条の6.md|第十九条の六]]の十四の規定に違反して同条に規定する事項の記載をせず、若しくは虚偽の記載をし、又は帳簿を保存しなかつた者[[laws/精神保健及び精神障害者福祉に関する法律/本文/第21条.md|第二十一条]]第七項の規定に違反した者正当な理由がなく、[[laws/精神保健及び精神障害者福祉に関する法律/本文/第31条.md|第三十一条]]第二項の規定による報告をせず、又は虚偽の報告をした者[[laws/精神保健及び精神障害者福祉に関する法律/本文/第33条.md|第三十三条]]第九項の規定に違反した者[[laws/精神保健及び精神障害者福祉に関する法律/本文/第33条の6.md|第三十三条の六]]第五項の規定に違反した者[[laws/精神保健及び精神障害者福祉に関する法律/本文/第38条の2.md|第三十八条の二]]第一項の規定に違反した者

- 一 [[laws/精神保健及び精神障害者福祉に関する法律/本文/第19条の4.md|第十九条の四]]の二（[[laws/精神保健及び精神障害者福祉に関する法律/本文/第21条.md|第二十一条]]第五項、[[laws/精神保健及び精神障害者福祉に関する法律/本文/第33条.md|第三十三条]]第四項及び[[laws/精神保健及び精神障害者福祉に関する法律/本文/第33条の6.md|第三十三条の六]]第三項において準用する場合を含む。）の規定に違反した者
- 二 [[laws/精神保健及び精神障害者福祉に関する法律/本文/第19条の6.md|第十九条の六]]の九の規定による届出をせず、又は虚偽の届出をした者
- 三 [[laws/精神保健及び精神障害者福祉に関する法律/本文/第19条の6.md|第十九条の六]]の十第一項の規定に違反して財務諸表等を備えて置かず、財務諸表等に記載すべき事項を記載せず、若しくは虚偽の記載をし、又は正当な理由がないのに同条第二項各号の規定による請求を拒んだ者
- 四 [[laws/精神保健及び精神障害者福祉に関する法律/本文/第19条の6.md|第十九条の六]]の十四の規定に違反して同条に規定する事項の記載をせず、若しくは虚偽の記載をし、又は帳簿を保存しなかつた者
- 五 [[laws/精神保健及び精神障害者福祉に関する法律/本文/第21条.md|第二十一条]]第七項の規定に違反した者
- 六 正当な理由がなく、[[laws/精神保健及び精神障害者福祉に関する法律/本文/第31条.md|第三十一条]]第二項の規定による報告をせず、又は虚偽の報告をした者
- 七 [[laws/精神保健及び精神障害者福祉に関する法律/本文/第33条.md|第三十三条]]第九項の規定に違反した者
- 八 [[laws/精神保健及び精神障害者福祉に関する法律/本文/第33条の6.md|第三十三条の六]]第五項の規定に違反した者
- 九 [[laws/精神保健及び精神障害者福祉に関する法律/本文/第38条の2.md|第三十八条の二]]第一項の規定に違反した者
