# 第三条 （防衛省の特別職から除かれる職）

## 
法[[laws/人事院規則一―五（特別職）/本文/第2条.md|第二条]]第三項第十六号の規定に基づき、次に掲げる防衛省の職員の職を特別職から除かれる職とする。防衛人事審議会の委員自衛隊員倫理審査会の委員防衛調達審議会の委員防衛施設中央審議会の委員防衛施設地方審議会の委員捕虜資格認定等審査会の委員地方協力局労務管理課の職員

- 一 防衛人事審議会の委員
- 二 自衛隊員倫理審査会の委員
- 三 防衛調達審議会の委員
- 四 防衛施設中央審議会の委員
- 五 防衛施設地方審議会の委員
- 六 捕虜資格認定等審査会の委員
- 七 地方協力局労務管理課の職員
