# 第八十一条 （法第四十六条第一項第十三号及び第十五号に規定する厚生労働省令で定める権限）

## 
法[[laws/430M60000100151/本文/第46条.md|第四十六条]]第一項第十三号及び第十五号に規定する厚生労働省令で定める権限は、次に掲げる権限とする。法[[laws/430M60000100151/本文/第31条.md|第三十一条]]第二項において準用する国民年金法[[laws/430M60000100151/本文/第96条.md|第九十六条]]第一項の規定による督促法[[laws/430M60000100151/本文/第31条.md|第三十一条]]第二項において準用する国民年金法[[laws/430M60000100151/本文/第96条.md|第九十六条]]第二項の規定による督促状の発行

- 一 法[[laws/430M60000100151/本文/第31条.md|第三十一条]]第二項において準用する国民年金法[[laws/430M60000100151/本文/第96条.md|第九十六条]]第一項の規定による督促
- 二 法[[laws/430M60000100151/本文/第31条.md|第三十一条]]第二項において準用する国民年金法[[laws/430M60000100151/本文/第96条.md|第九十六条]]第二項の規定による督促状の発行
