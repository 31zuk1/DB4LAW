# 第七十三条 （法第四十一条第一項第十一号に規定する厚生労働省令で定める権限）

## 
法[[laws/年金生活者支援給付金の支給に関する法律施行規則/本文/第41条.md|第四十一条]]第一項第十一号に規定する厚生労働省令で定める権限は、次に掲げる権限とする。法[[laws/年金生活者支援給付金の支給に関する法律施行規則/本文/第29条.md|第二十九条]]に規定する返還金債権その他給付の過誤払による返還金債権に係る債権の行使[[laws/年金生活者支援給付金の支給に関する法律施行規則/本文/第5条.md|第五条]]第四項の規定による厚生労働大臣の指定[[laws/年金生活者支援給付金の支給に関する法律施行規則/本文/第2条.md|第二条]]第四項、[[laws/年金生活者支援給付金の支給に関する法律施行規則/本文/第17条.md|第十七条]]第四項、[[laws/年金生活者支援給付金の支給に関する法律施行規則/本文/第32条.md|第三十二条]]第四項及び[[laws/年金生活者支援給付金の支給に関する法律施行規則/本文/第47条.md|第四十七条]]第四項の規定による確認[[laws/年金生活者支援給付金の支給に関する法律施行規則/本文/第7条.md|第七条]]ただし書、[[laws/年金生活者支援給付金の支給に関する法律施行規則/本文/第22条.md|第二十二条]]ただし書、[[laws/年金生活者支援給付金の支給に関する法律施行規則/本文/第37条.md|第三十七条]]ただし書及び[[laws/年金生活者支援給付金の支給に関する法律施行規則/本文/第52条.md|第五十二条]]ただし書の規定による確認[[laws/年金生活者支援給付金の支給に関する法律施行規則/本文/第66条.md|第六十六条]]の規定による経由の省略[[laws/年金生活者支援給付金の支給に関する法律施行規則/本文/第100条.md|第百条]]の規定による送付及び請求書の受理

- 一 法[[laws/年金生活者支援給付金の支給に関する法律施行規則/本文/第29条.md|第二十九条]]に規定する返還金債権その他給付の過誤払による返還金債権に係る債権の行使
- 二 [[laws/年金生活者支援給付金の支給に関する法律施行規則/本文/第5条.md|第五条]]第四項の規定による厚生労働大臣の指定
- 三 [[laws/年金生活者支援給付金の支給に関する法律施行規則/本文/第2条.md|第二条]]第四項、[[laws/年金生活者支援給付金の支給に関する法律施行規則/本文/第17条.md|第十七条]]第四項、[[laws/年金生活者支援給付金の支給に関する法律施行規則/本文/第32条.md|第三十二条]]第四項及び[[laws/年金生活者支援給付金の支給に関する法律施行規則/本文/第47条.md|第四十七条]]第四項の規定による確認
- 四 [[laws/年金生活者支援給付金の支給に関する法律施行規則/本文/第7条.md|第七条]]ただし書、[[laws/年金生活者支援給付金の支給に関する法律施行規則/本文/第22条.md|第二十二条]]ただし書、[[laws/年金生活者支援給付金の支給に関する法律施行規則/本文/第37条.md|第三十七条]]ただし書及び[[laws/年金生活者支援給付金の支給に関する法律施行規則/本文/第52条.md|第五十二条]]ただし書の規定による確認
- 五 [[laws/年金生活者支援給付金の支給に関する法律施行規則/本文/第66条.md|第六十六条]]の規定による経由の省略
- 六 [[laws/年金生活者支援給付金の支給に関する法律施行規則/本文/第100条.md|第百条]]の規定による送付及び請求書の受理
