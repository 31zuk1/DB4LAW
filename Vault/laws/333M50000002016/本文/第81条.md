# 第八十一条 （年少射撃資格講習修了証明書の様式）

## 
法[[laws/333AC0000000006/本文/第9条の14.md|第九条の十四]]第二項の年少射撃資格講習修了証明書は、別記様式第六十九号のとおりとする。
