# 第一条 （道路の附属物）

## 
公共土木施設災害復旧事業費国庫負担法施行令（以下「令」という。）[[laws/412M50004800014/本文/第1条.md|第一条]]第七号に規定する主務大臣の指定する道路の附属物は、次のとおりとする。道路法（昭和二十七年法律第百八十号）第二条第二項第一号に規定する道路上の柵又は駒止め道路法[[laws/412M50004800014/本文/第2条.md|第二条]]第二項第二号に規定する街灯道路法[[laws/412M50004800014/本文/第2条.md|第二条]]第二項第三号に規定する道路標識道路法[[laws/412M50004800014/本文/第2条.md|第二条]]第二項第四号に規定する道路情報管理施設道路法[[laws/412M50004800014/本文/第2条.md|第二条]]第二項第六号に規定する道路の維持又は修繕に用いる機械、器具又は材料の常置場道路法[[laws/412M50004800014/本文/第2条.md|第二条]]第二項第七号に規定する自動車駐車場又は自転車駐車場道路法[[laws/412M50004800014/本文/第2条.md|第二条]]第二項第九号に規定する共同溝又は電線共同溝道路法施行令（昭和二十七年政令第四百七十九号）[[laws/412M50004800014/公共土木施設災害復旧事業費国庫負担法施行_law.md|第三十四条の三]]第一号に規定する道路の防雪又は防砂のための施設

- 一 道路法（昭和二十七年法律第百八十号）第二条第二項第一号に規定する道路上の柵又は駒止め
- 二 道路法[[laws/412M50004800014/本文/第2条.md|第二条]]第二項第二号に規定する街灯
- 三 道路法[[laws/412M50004800014/本文/第2条.md|第二条]]第二項第三号に規定する道路標識
- 四 道路法[[laws/412M50004800014/本文/第2条.md|第二条]]第二項第四号に規定する道路情報管理施設
- 五 道路法[[laws/412M50004800014/本文/第2条.md|第二条]]第二項第六号に規定する道路の維持又は修繕に用いる機械、器具又は材料の常置場
- 六 道路法[[laws/412M50004800014/本文/第2条.md|第二条]]第二項第七号に規定する自動車駐車場又は自転車駐車場
- 七 道路法[[laws/412M50004800014/本文/第2条.md|第二条]]第二項第九号に規定する共同溝又は電線共同溝
- 八 道路法施行令（昭和二十七年政令第四百七十九号）[[laws/412M50004800014/公共土木施設災害復旧事業費国庫負担法施行_law.md|第三十四条の三]]第一号に規定する道路の防雪又は防砂のための施設
