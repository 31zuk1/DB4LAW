# 第一条 （承継国債の告示）

## 
財務大臣は、石油公団法及び金属鉱業事業団法の廃止等に関する法律附則第十条第二項及び第十二条第二項の規定により、国が石油公団の債務を承継したときは、その承継した債務に係る国債（以下「承継国債」という。）について、遅滞なく次に掲げる事項を告示するものとする。名称及び記号額面総額額面金額の種類利率利子支払期償還期限償還金額その他必要な事項

- 一 名称及び記号
- 二 額面総額
- 三 額面金額の種類
- 四 利率
- 五 利子支払期
- 六 償還期限
- 七 償還金額
- 八 その他必要な事項
