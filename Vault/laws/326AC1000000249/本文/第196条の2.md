# 第百九十六条の二 （事務の区分）

## 
この法律の規定により地方公共団体が処理することとされている事務のうち、次に掲げるものは、地方自治法（昭和二十二年法律第六十七号）第二条第九項第一号に規定する第一号法定受託事務とする。[[laws/326AC1000000249/本文/第25条の2.md|第二十五条の二]]、[[laws/326AC1000000249/本文/第26条の2.md|第二十六条の二]]、[[laws/326AC1000000249/本文/第27条.md|第二十七条]]第一項、[[laws/326AC1000000249/本文/第33条の2.md|第三十三条の二]]及び[[laws/326AC1000000249/本文/第39条.md|第三十九条]]第一項の規定により都道府県が処理することとされている事務（[[laws/326AC1000000249/本文/第25条.md|第二十五条]]第一項第一号から第三号までに掲げる目的を達成するための指定に係る保安林に関するものに限る。）[[laws/326AC1000000249/本文/第27条.md|第二十七条]]第二項及び第三項（申請書に意見書を付する事務に関する部分を除く。）、[[laws/326AC1000000249/本文/第30条.md|第三十条]]並びに[[laws/326AC1000000249/本文/第33条.md|第三十三条]]第三項（これらの規定を[[laws/326AC1000000249/本文/第33条の3.md|第三十三条の三]]において準用する場合を含む。）の規定により都道府県が処理することとされている事務[[laws/326AC1000000249/本文/第30条の2.md|第三十条の二]]第一項、同条第二項において準用する[[laws/326AC1000000249/本文/第30条.md|第三十条]]後段、[[laws/326AC1000000249/本文/第32条.md|第三十二条]]第二項及び第三項並びに[[laws/326AC1000000249/本文/第33条.md|第三十三条]]第六項において準用する同条第一項及び第三項（これらの規定を[[laws/326AC1000000249/本文/第33条の3.md|第三十三条の三]]において準用する場合を含む。）の規定により都道府県が処理することとされている事務（[[laws/326AC1000000249/本文/第25条.md|第二十五条]]第一項第一号から第三号までに掲げる目的を達成するための指定に係る保安林に関するものに限る。）[[laws/326AC1000000249/本文/第31条.md|第三十一条]]、[[laws/326AC1000000249/本文/第32条.md|第三十二条]]第一項（[[laws/326AC1000000249/本文/第33条の3.md|第三十三条の三]]において準用する場合を含む。）、[[laws/326AC1000000249/本文/第34条.md|第三十四条]]から[[laws/326AC1000000249/本文/第34条の3.md|第三十四条の三]]まで、[[laws/326AC1000000249/本文/第38条.md|第三十八条]]及び[[laws/326AC1000000249/本文/第39条の2.md|第三十九条の二]]第一項の規定により都道府県が処理することとされている事務（民有林にあつては、[[laws/326AC1000000249/本文/第25条.md|第二十五条]]第一項第一号から第三号までに掲げる目的を達成するための指定に係る保安林に関するものに限る。）[[laws/326AC1000000249/本文/第44条.md|第四十四条]]において準用する[[laws/326AC1000000249/本文/第27条.md|第二十七条]]第二項及び第三項（申請書に意見書を付する事務に関する部分を除く。）、[[laws/326AC1000000249/本文/第30条.md|第三十条]]、[[laws/326AC1000000249/本文/第31条.md|第三十一条]]、[[laws/326AC1000000249/本文/第32条.md|第三十二条]]第一項、[[laws/326AC1000000249/本文/第33条.md|第三十三条]]第三項、[[laws/326AC1000000249/本文/第34条.md|第三十四条]]から[[laws/326AC1000000249/本文/第34条の3.md|第三十四条の三]]まで並びに[[laws/326AC1000000249/本文/第39条.md|第三十九条]]第一項の規定並びに[[laws/326AC1000000249/本文/第46条の2.md|第四十六条の二]]第一項の規定により都道府県が処理することとされている事務[[laws/326AC1000000249/本文/第10条の7.md|第十条の七]]の二第二項の規定により市町村が処理することとされている事務（[[laws/326AC1000000249/本文/第25条.md|第二十五条]]第一項第一号から第三号までに掲げる目的を達成するための指定に係る保安林又は保安施設地区の区域内の森林に関するものに限る。）

- 一 [[laws/326AC1000000249/本文/第25条の2.md|第二十五条の二]]、[[laws/326AC1000000249/本文/第26条の2.md|第二十六条の二]]、[[laws/326AC1000000249/本文/第27条.md|第二十七条]]第一項、[[laws/326AC1000000249/本文/第33条の2.md|第三十三条の二]]及び[[laws/326AC1000000249/本文/第39条.md|第三十九条]]第一項の規定により都道府県が処理することとされている事務（[[laws/326AC1000000249/本文/第25条.md|第二十五条]]第一項第一号から第三号までに掲げる目的を達成するための指定に係る保安林に関するものに限る。）
- 二 [[laws/326AC1000000249/本文/第27条.md|第二十七条]]第二項及び第三項（申請書に意見書を付する事務に関する部分を除く。）、[[laws/326AC1000000249/本文/第30条.md|第三十条]]並びに[[laws/326AC1000000249/本文/第33条.md|第三十三条]]第三項（これらの規定を[[laws/326AC1000000249/本文/第33条の3.md|第三十三条の三]]において準用する場合を含む。）の規定により都道府県が処理することとされている事務
- 三 [[laws/326AC1000000249/本文/第30条の2.md|第三十条の二]]第一項、同条第二項において準用する[[laws/326AC1000000249/本文/第30条.md|第三十条]]後段、[[laws/326AC1000000249/本文/第32条.md|第三十二条]]第二項及び第三項並びに[[laws/326AC1000000249/本文/第33条.md|第三十三条]]第六項において準用する同条第一項及び第三項（これらの規定を[[laws/326AC1000000249/本文/第33条の3.md|第三十三条の三]]において準用する場合を含む。）の規定により都道府県が処理することとされている事務（[[laws/326AC1000000249/本文/第25条.md|第二十五条]]第一項第一号から第三号までに掲げる目的を達成するための指定に係る保安林に関するものに限る。）
- 四 [[laws/326AC1000000249/本文/第31条.md|第三十一条]]、[[laws/326AC1000000249/本文/第32条.md|第三十二条]]第一項（[[laws/326AC1000000249/本文/第33条の3.md|第三十三条の三]]において準用する場合を含む。）、[[laws/326AC1000000249/本文/第34条.md|第三十四条]]から[[laws/326AC1000000249/本文/第34条の3.md|第三十四条の三]]まで、[[laws/326AC1000000249/本文/第38条.md|第三十八条]]及び[[laws/326AC1000000249/本文/第39条の2.md|第三十九条の二]]第一項の規定により都道府県が処理することとされている事務（民有林にあつては、[[laws/326AC1000000249/本文/第25条.md|第二十五条]]第一項第一号から第三号までに掲げる目的を達成するための指定に係る保安林に関するものに限る。）
- 五 [[laws/326AC1000000249/本文/第44条.md|第四十四条]]において準用する[[laws/326AC1000000249/本文/第27条.md|第二十七条]]第二項及び第三項（申請書に意見書を付する事務に関する部分を除く。）、[[laws/326AC1000000249/本文/第30条.md|第三十条]]、[[laws/326AC1000000249/本文/第31条.md|第三十一条]]、[[laws/326AC1000000249/本文/第32条.md|第三十二条]]第一項、[[laws/326AC1000000249/本文/第33条.md|第三十三条]]第三項、[[laws/326AC1000000249/本文/第34条.md|第三十四条]]から[[laws/326AC1000000249/本文/第34条の3.md|第三十四条の三]]まで並びに[[laws/326AC1000000249/本文/第39条.md|第三十九条]]第一項の規定並びに[[laws/326AC1000000249/本文/第46条の2.md|第四十六条の二]]第一項の規定により都道府県が処理することとされている事務
- 六 [[laws/326AC1000000249/本文/第10条の7.md|第十条の七]]の二第二項の規定により市町村が処理することとされている事務（[[laws/326AC1000000249/本文/第25条.md|第二十五条]]第一項第一号から第三号までに掲げる目的を達成するための指定に係る保安林又は保安施設地区の区域内の森林に関するものに限る。）
## ２
[[laws/326AC1000000249/本文/第10条の7.md|第十条の七]]の二第二項の規定により市町村が処理することとされている事務（[[laws/326AC1000000249/本文/第25条.md|第二十五条]]第一項第四号から第十一号までに掲げる目的を達成するための指定に係る保安林に関するものに限る。）は、地方自治法第二条第九項第二号に規定する第二号法定受託事務とする。
