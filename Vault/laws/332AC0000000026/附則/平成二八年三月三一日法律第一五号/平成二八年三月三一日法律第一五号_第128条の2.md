# 第百二十八条の二 （適格請求書発行事業者の登録の取消し等に関する特例に関する経過措置）

## 
新租税特別措置法[[laws/租税特別措置法/本文/第86条の5.md|第八十六条の五]]第十三項の規定は、同項の適格請求書発行事業者が令和五年十月一日以後に五年改正規定による改正後の消費税法第五十七条の二第十項第一号の規定による届出書を提出する場合について適用し、新租税特別措置法[[laws/租税特別措置法/本文/第86条の5.md|第八十六条の五]]第十四項の規定は、同項の適格請求書発行事業者が同日以後に同条第三項の届出書を提出する場合について適用する。
