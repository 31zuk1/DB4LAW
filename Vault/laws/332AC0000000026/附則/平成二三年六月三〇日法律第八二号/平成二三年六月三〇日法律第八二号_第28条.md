# 第二十八条 （上場証券投資信託等の償還金等に係る課税の特例等に関する経過措置）

## 
旧租税特別措置法[[laws/租税特別措置法/本文/第9条の4.md|第九条の四]]の二第三項に規定する償還金等の支払をする者が平成二十四年一月一日前に提出した同項に規定する光ディスク等については、なお従前の例による。
