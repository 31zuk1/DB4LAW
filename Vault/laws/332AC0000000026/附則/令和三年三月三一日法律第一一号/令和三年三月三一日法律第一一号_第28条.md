# 第二十八条 （特定中小事業者が経営改善設備を取得した場合の特別償却又は所得税額の特別控除に関する経過措置）

## 
個人が施行日前に取得又は製作若しくは建設をした旧租税特別措置法[[laws/租税特別措置法/本文/第10条の5.md|第十条の五]]の二第一項に規定する経営改善設備については、なお従前の例による。
