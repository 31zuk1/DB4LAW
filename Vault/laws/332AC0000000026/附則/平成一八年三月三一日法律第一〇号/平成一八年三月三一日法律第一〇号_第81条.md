# 第八十一条 （情報基盤強化設備等を取得した場合等の特別償却又は所得税額の特別控除に関する経過措置）

## 
新租税特別措置法[[laws/332AC0000000026/本文/第10条の6.md|第十条の六]]の規定は、個人が施行日以後に取得若しくは製作又は賃借をする同条第一項に規定する情報基盤強化設備等について適用する。
