# 第八十一条 （国家戦略特別区域において機械等を取得した場合の特別償却等又は法人税額の特別控除に関する経過措置）

## 
法人が施行日前に取得又は製作をした旧租税特別措置法[[laws/租税特別措置法/本文/第42条の10.md|第四十二条の十]]第三項に規定する開発研究用資産に係る同項の規定の適用については、なお従前の例による。
