# 第百二十七条 （不服申立て）

## 
次に掲げる処分又はその不作為については、審査請求をすることができない。[[laws/都市再開発法/本文/第11条.md|第十一条]]第一項若しくは第三項又は[[laws/都市再開発法/本文/第38条.md|第三十八条]]第一項の規定による認可（事業基本方針の変更に係るものを除く。）[[laws/都市再開発法/本文/第16条.md|第十六条]]第三項（[[laws/都市再開発法/本文/第38条.md|第三十八条]]第二項、[[laws/都市再開発法/本文/第50条の6.md|第五十条の六]]、[[laws/都市再開発法/本文/第50条の9.md|第五十条の九]]第二項、[[laws/都市再開発法/本文/第53条.md|第五十三条]]第二項（[[laws/都市再開発法/本文/第56条.md|第五十六条]]において準用する場合を含む。）並びに[[laws/都市再開発法/本文/第58条.md|第五十八条]]第三項及び第四項において準用する場合を含む。）の規定による通知[[laws/都市再開発法/本文/第50条の2.md|第五十条の二]]第一項又は[[laws/都市再開発法/本文/第50条の9.md|第五十条の九]]第一項の規定による認可[[laws/都市再開発法/本文/第51条.md|第五十一条]]第一項（[[laws/都市再開発法/本文/第56条.md|第五十六条]]において準用する場合を含む。）の規定による認可[[laws/都市再開発法/本文/第58条.md|第五十八条]]第一項の規定による認可[[laws/都市再開発法/本文/第83条.md|第八十三条]]第三項（同条第五項において準用する場合を含む。）の規定による通知[[laws/都市再開発法/本文/第118条の10.md|第百十八条の十]]において準用する[[laws/都市再開発法/本文/第83条.md|第八十三条]]第三項（同条第五項において準用する場合を含む。）の規定による通知

- 一 [[laws/都市再開発法/本文/第11条.md|第十一条]]第一項若しくは第三項又は[[laws/都市再開発法/本文/第38条.md|第三十八条]]第一項の規定による認可（事業基本方針の変更に係るものを除く。）
- 二 [[laws/都市再開発法/本文/第16条.md|第十六条]]第三項（[[laws/都市再開発法/本文/第38条.md|第三十八条]]第二項、[[laws/都市再開発法/本文/第50条の6.md|第五十条の六]]、[[laws/都市再開発法/本文/第50条の9.md|第五十条の九]]第二項、[[laws/都市再開発法/本文/第53条.md|第五十三条]]第二項（[[laws/都市再開発法/本文/第56条.md|第五十六条]]において準用する場合を含む。）並びに[[laws/都市再開発法/本文/第58条.md|第五十八条]]第三項及び第四項において準用する場合を含む。）の規定による通知
- 三 [[laws/都市再開発法/本文/第50条の2.md|第五十条の二]]第一項又は[[laws/都市再開発法/本文/第50条の9.md|第五十条の九]]第一項の規定による認可
- 四 [[laws/都市再開発法/本文/第51条.md|第五十一条]]第一項（[[laws/都市再開発法/本文/第56条.md|第五十六条]]において準用する場合を含む。）の規定による認可
- 五 [[laws/都市再開発法/本文/第58条.md|第五十八条]]第一項の規定による認可
- 六 [[laws/都市再開発法/本文/第83条.md|第八十三条]]第三項（同条第五項において準用する場合を含む。）の規定による通知
- 七 [[laws/都市再開発法/本文/第118条の10.md|第百十八条の十]]において準用する[[laws/都市再開発法/本文/第83条.md|第八十三条]]第三項（同条第五項において準用する場合を含む。）の規定による通知
