# 第百四十六条 

## 
次の各号のいずれかに該当する場合においては、その行為をした組合の理事、監事又は清算人は、二十万円以下の過料に処する。組合が第一種市街地再開発事業以外の事業を営んだとき。[[laws/都市再開発法/本文/第27条.md|第二十七条]]第九項の規定に違反して正当な理由がないのに帳簿及び書類の閲覧又は謄写を拒んだとき。[[laws/都市再開発法/本文/第27条.md|第二十七条]]第十項の規定に違反して監事が理事又は組合の職員と兼ねたとき。[[laws/都市再開発法/本文/第31条.md|第三十一条]]第一項（[[laws/都市再開発法/本文/第35条.md|第三十五条]]第四項において準用する場合を含む。）又は第三項若しくは第六項（[[laws/都市再開発法/本文/第34条.md|第三十四条]]第三項及び[[laws/都市再開発法/本文/第35条.md|第三十五条]]第四項において準用する場合を含む。）の規定に違反して総会、総会の部会又は総代会を招集しなかつたとき。[[laws/都市再開発法/本文/第31条.md|第三十一条]]第九項の規定に違反して書類を備えず、又はその書類に記載すべき事項を記載せず、若しくは不実の記載をしたとき。[[laws/都市再開発法/本文/第31条.md|第三十一条]]第十項の規定に違反して正当な理由がないのに書類の閲覧又は謄写を拒んだとき。[[laws/都市再開発法/本文/第38条.md|第三十八条]]第二項において準用する[[laws/都市再開発法/本文/第7条の16.md|第七条の十六]]第三項又は[[laws/都市再開発法/本文/第45条.md|第四十五条]]第三項の規定に違反したとき。[[laws/都市再開発法/本文/第47条.md|第四十七条]]又は[[laws/都市再開発法/本文/第49条.md|第四十九条]]に掲げる書類に記載すべき事項を記載せず、又は不実の記載をしたとき。[[laws/都市再開発法/本文/第48条.md|第四十八条]]の規定に違反して組合の残余財産を処分したとき。[[laws/都市再開発法/本文/第134条.md|第百三十四条]]第一項の規定に違反して簿書を備えず、又はその簿書に記載すべき事項を記載せず、若しくは不実の記載をしたとき。[[laws/都市再開発法/本文/第134条.md|第百三十四条]]第二項の規定に違反して正当な理由がないのに簿書の閲覧又は謄写を拒んだとき。都道府県知事若しくは市町村長又は総会、総会の部会若しくは総代会に対し、不実の申立てをし、又は事実を隠したとき。組合がこの法律の規定による公告をすべき場合において、公告をせず、又は不実の公告をしたとき。

- 一 組合が第一種市街地再開発事業以外の事業を営んだとき。
- 二 [[laws/都市再開発法/本文/第27条.md|第二十七条]]第九項の規定に違反して正当な理由がないのに帳簿及び書類の閲覧又は謄写を拒んだとき。
- 三 [[laws/都市再開発法/本文/第27条.md|第二十七条]]第十項の規定に違反して監事が理事又は組合の職員と兼ねたとき。
- 四 [[laws/都市再開発法/本文/第31条.md|第三十一条]]第一項（[[laws/都市再開発法/本文/第35条.md|第三十五条]]第四項において準用する場合を含む。）又は第三項若しくは第六項（[[laws/都市再開発法/本文/第34条.md|第三十四条]]第三項及び[[laws/都市再開発法/本文/第35条.md|第三十五条]]第四項において準用する場合を含む。）の規定に違反して総会、総会の部会又は総代会を招集しなかつたとき。
- 五 [[laws/都市再開発法/本文/第31条.md|第三十一条]]第九項の規定に違反して書類を備えず、又はその書類に記載すべき事項を記載せず、若しくは不実の記載をしたとき。
- 六 [[laws/都市再開発法/本文/第31条.md|第三十一条]]第十項の規定に違反して正当な理由がないのに書類の閲覧又は謄写を拒んだとき。
- 七 [[laws/都市再開発法/本文/第38条.md|第三十八条]]第二項において準用する[[laws/都市再開発法/本文/第7条の16.md|第七条の十六]]第三項又は[[laws/都市再開発法/本文/第45条.md|第四十五条]]第三項の規定に違反したとき。
- 八 [[laws/都市再開発法/本文/第47条.md|第四十七条]]又は[[laws/都市再開発法/本文/第49条.md|第四十九条]]に掲げる書類に記載すべき事項を記載せず、又は不実の記載をしたとき。
- 九 [[laws/都市再開発法/本文/第48条.md|第四十八条]]の規定に違反して組合の残余財産を処分したとき。
- 十 [[laws/都市再開発法/本文/第134条.md|第百三十四条]]第一項の規定に違反して簿書を備えず、又はその簿書に記載すべき事項を記載せず、若しくは不実の記載をしたとき。
- 十一 [[laws/都市再開発法/本文/第134条.md|第百三十四条]]第二項の規定に違反して正当な理由がないのに簿書の閲覧又は謄写を拒んだとき。
- 十二 都道府県知事若しくは市町村長又は総会、総会の部会若しくは総代会に対し、不実の申立てをし、又は事実を隠したとき。
- 十三 組合がこの法律の規定による公告をすべき場合において、公告をせず、又は不実の公告をしたとき。
