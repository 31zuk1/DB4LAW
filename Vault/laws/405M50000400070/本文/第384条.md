# 第三百八十四条 （検定公差）

## 
燃料油メーターの検定公差は、それぞれ次の各号に掲げる日本産業規格による。自動車等給油メーター日本産業規格Ｂ八五七二―一（二〇〇八）小型車載燃料油メーター日本産業規格Ｂ八五七二―二（二〇一一）大型車載燃料油メーター日本産業規格Ｂ八五七二―四（二〇一四）簡易燃料油メーター日本産業規格Ｂ八五七二―四（二〇一四）微流量燃料油メーター日本産業規格Ｂ八五七二―三（二〇一一）定置燃料油メーター日本産業規格Ｂ八五七二―四（二〇一四）

- 一 自動車等給油メーター日本産業規格Ｂ八五七二―一（二〇〇八）
- 二 小型車載燃料油メーター日本産業規格Ｂ八五七二―二（二〇一一）
- 三 大型車載燃料油メーター日本産業規格Ｂ八五七二―四（二〇一四）
- 四 簡易燃料油メーター日本産業規格Ｂ八五七二―四（二〇一四）
- 五 微流量燃料油メーター日本産業規格Ｂ八五七二―三（二〇一一）
- 六 定置燃料油メーター日本産業規格Ｂ八五七二―四（二〇一四）
