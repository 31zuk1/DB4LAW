# 第百十八条 （表記）

## 
質量計の表記事項は、それぞれ次の各号に掲げる日本産業規格による。非自動はかり日本産業規格Ｂ七六一一―二（二〇一五）ホッパースケール日本産業規格Ｂ七六〇三（二〇二四）附属書充塡用自動はかり日本産業規格Ｂ七六〇四―一（二〇二四）附属書及び日本産業規格Ｂ七六〇四―二（二〇二一）コンベヤスケール日本産業規格Ｂ七六〇六―一（二〇二四）附属書及び日本産業規格Ｂ七六〇六―二（二〇一九）自動捕捉式はかり日本産業規格Ｂ七六〇七（二〇二四）附属書分銅、定量おもり及び定量増おもり（以下「分銅等」という。）日本産業規格Ｂ七六一一―三（二〇一五）

- 一 非自動はかり日本産業規格Ｂ七六一一―二（二〇一五）
- 二 ホッパースケール日本産業規格Ｂ七六〇三（二〇二四）附属書
- 三 充塡用自動はかり日本産業規格Ｂ七六〇四―一（二〇二四）附属書及び日本産業規格Ｂ七六〇四―二（二〇二一）
- 四 コンベヤスケール日本産業規格Ｂ七六〇六―一（二〇二四）附属書及び日本産業規格Ｂ七六〇六―二（二〇一九）
- 五 自動捕捉式はかり日本産業規格Ｂ七六〇七（二〇二四）附属書
- 六 分銅、定量おもり及び定量増おもり（以下「分銅等」という。）日本産業規格Ｂ七六一一―三（二〇一五）
