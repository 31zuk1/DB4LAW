# 第五十九条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、三十万円以下の罰金に処する。[[laws/348AC0000000031/本文/第6条.md|第六条]]の規定による届出をする場合において虚偽の届出をしたとき。[[laws/348AC0000000031/本文/第11条.md|第十一条]]第二項の規定に違反して、検査を行わず、検査記録を作成せず、若しくは虚偽の検査記録を作成し、又は検査記録を保存しなかつたとき。[[laws/348AC0000000031/本文/第11条.md|第十一条]]第三項前段の規定に違反して、検査記録の写しを提供しなかつたとき。[[laws/348AC0000000031/本文/第11条.md|第十一条]]第三項後段の規定に違反して、検査記録の写しを保存しなかつたとき。[[laws/348AC0000000031/本文/第12条.md|第十二条]]第一項の規定に違反して、証明書の交付を受けず、又は証明書を保存しなかつたとき。[[laws/348AC0000000031/本文/第12条.md|第十二条]]第三項前段の規定に違反して、同項に規定する写しを提供しなかつたとき。[[laws/348AC0000000031/本文/第12条.md|第十二条]]第三項後段の規定に違反して、同項に規定する写しを保存しなかつたとき。[[laws/348AC0000000031/本文/第12条の2.md|第十二条の二]]第二項の規定に違反して、同項に規定する文言を表示しなかつたとき。[[laws/348AC0000000031/本文/第23条.md|第二十三条]]の規定による届出をせず、又は虚偽の届出をしたとき。[[laws/348AC0000000031/本文/第28条.md|第二十八条]]の規定に違反して同条に規定する事項の記載をせず、虚偽の記載をし、又は帳簿を保存しなかつたとき。[[laws/348AC0000000031/本文/第32条の4.md|第三十二条の四]]第一項の規定による届出をせず、又は虚偽の届出をしたとき。[[laws/348AC0000000031/本文/第40条.md|第四十条]]の規定による報告をせず、又は虚偽の報告をしたとき。[[laws/348AC0000000031/本文/第41条.md|第四十一条]]第一項から第三項までの規定による検査を拒み、妨げ、又は忌避したとき。[[laws/348AC0000000031/本文/第42条.md|第四十二条]]第一項又は第二項の規定による命令に違反したとき。

- 一 [[laws/348AC0000000031/本文/第6条.md|第六条]]の規定による届出をする場合において虚偽の届出をしたとき。
- 二 [[laws/348AC0000000031/本文/第11条.md|第十一条]]第二項の規定に違反して、検査を行わず、検査記録を作成せず、若しくは虚偽の検査記録を作成し、又は検査記録を保存しなかつたとき。
- 三 [[laws/348AC0000000031/本文/第11条.md|第十一条]]第三項前段の規定に違反して、検査記録の写しを提供しなかつたとき。
- 四 [[laws/348AC0000000031/本文/第11条.md|第十一条]]第三項後段の規定に違反して、検査記録の写しを保存しなかつたとき。
- 五 [[laws/348AC0000000031/本文/第12条.md|第十二条]]第一項の規定に違反して、証明書の交付を受けず、又は証明書を保存しなかつたとき。
- 六 [[laws/348AC0000000031/本文/第12条.md|第十二条]]第三項前段の規定に違反して、同項に規定する写しを提供しなかつたとき。
- 七 [[laws/348AC0000000031/本文/第12条.md|第十二条]]第三項後段の規定に違反して、同項に規定する写しを保存しなかつたとき。
- 八 [[laws/348AC0000000031/本文/第12条の2.md|第十二条の二]]第二項の規定に違反して、同項に規定する文言を表示しなかつたとき。
- 九 [[laws/348AC0000000031/本文/第23条.md|第二十三条]]の規定による届出をせず、又は虚偽の届出をしたとき。
- 十 [[laws/348AC0000000031/本文/第28条.md|第二十八条]]の規定に違反して同条に規定する事項の記載をせず、虚偽の記載をし、又は帳簿を保存しなかつたとき。
- 十一 [[laws/348AC0000000031/本文/第32条の4.md|第三十二条の四]]第一項の規定による届出をせず、又は虚偽の届出をしたとき。
- 十二 [[laws/348AC0000000031/本文/第40条.md|第四十条]]の規定による報告をせず、又は虚偽の報告をしたとき。
- 十三 [[laws/348AC0000000031/本文/第41条.md|第四十一条]]第一項から第三項までの規定による検査を拒み、妨げ、又は忌避したとき。
- 十四 [[laws/348AC0000000031/本文/第42条.md|第四十二条]]第一項又は第二項の規定による命令に違反したとき。
