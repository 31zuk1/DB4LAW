# 第四十六条 （公示）

## 
主務大臣は、次の場合には、その旨を官報に公示しなければならない。[[laws/消費生活用製品安全法/本文/第12条.md|第十二条]]第一項の登録をしたとき。[[laws/消費生活用製品安全法/本文/第15条.md|第十五条]]の規定により表示を付することを禁止したとき。[[laws/消費生活用製品安全法/本文/第21条.md|第二十一条]]（[[laws/消費生活用製品安全法/本文/第30条.md|第三十条]]第二項において準用する場合を含む。）の規定による届出があつたとき。[[laws/消費生活用製品安全法/本文/第23条.md|第二十三条]]（[[laws/消費生活用製品安全法/本文/第30条.md|第三十条]]第二項において準用する場合を含む。）の規定による届出があつたとき。[[laws/消費生活用製品安全法/本文/第27条.md|第二十七条]]の規定により登録を取り消し、又は適合性検査の業務の停止を命じたとき。[[laws/消費生活用製品安全法/本文/第29条.md|第二十九条]]第一項の規定により主務大臣が適合性検査の業務の全部若しくは一部を自ら行うものとするとき、又は自ら行つていた適合性検査の業務の全部若しくは一部を行わないこととするとき。[[laws/消費生活用製品安全法/本文/第29条.md|第二十九条]]第二項の規定により主務大臣が機構に適合性検査の業務の全部若しくは一部を行わせることとするとき、又は機構に行わせていた適合性検査の業務の全部若しくは一部を行わせないこととするとき。[[laws/消費生活用製品安全法/本文/第31条.md|第三十一条]]第一項の規定により登録を取り消したとき。

- 一 [[laws/消費生活用製品安全法/本文/第12条.md|第十二条]]第一項の登録をしたとき。
- 二 [[laws/消費生活用製品安全法/本文/第15条.md|第十五条]]の規定により表示を付することを禁止したとき。
- 三 [[laws/消費生活用製品安全法/本文/第21条.md|第二十一条]]（[[laws/消費生活用製品安全法/本文/第30条.md|第三十条]]第二項において準用する場合を含む。）の規定による届出があつたとき。
- 四 [[laws/消費生活用製品安全法/本文/第23条.md|第二十三条]]（[[laws/消費生活用製品安全法/本文/第30条.md|第三十条]]第二項において準用する場合を含む。）の規定による届出があつたとき。
- 五 [[laws/消費生活用製品安全法/本文/第27条.md|第二十七条]]の規定により登録を取り消し、又は適合性検査の業務の停止を命じたとき。
- 六 [[laws/消費生活用製品安全法/本文/第29条.md|第二十九条]]第一項の規定により主務大臣が適合性検査の業務の全部若しくは一部を自ら行うものとするとき、又は自ら行つていた適合性検査の業務の全部若しくは一部を行わないこととするとき。
- 七 [[laws/消費生活用製品安全法/本文/第29条.md|第二十九条]]第二項の規定により主務大臣が機構に適合性検査の業務の全部若しくは一部を行わせることとするとき、又は機構に行わせていた適合性検査の業務の全部若しくは一部を行わせないこととするとき。
- 八 [[laws/消費生活用製品安全法/本文/第31条.md|第三十一条]]第一項の規定により登録を取り消したとき。
