# 第八十一条 （災害防止措置に係る費用負担）

## 
都道府県知事は、法[[laws/337M50004000003/本文/第39条.md|第三十九条]]第六項（法[[laws/337M50004000003/本文/第42条.md|第四十二条]]第三項において準用する場合を含む。）の規定により当該災害防止措置に要した費用を負担させようとするときは、当該工事主等又は土地所有者等に対し負担させようとする費用の額の算定基礎を明示するものとする。
