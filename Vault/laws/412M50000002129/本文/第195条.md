# 第百九十五条 （吸収合併存続法人の事後開示事項）

## 
法[[laws/投資信託及び投資法人に関する法律施行規則/本文/第149条の10.md|第百四十九条の十]]第一項に規定する内閣府令で定める事項は、次に掲げる事項とする。吸収合併が効力を生じた日吸収合併消滅法人における次に掲げる事項法[[laws/投資信託及び投資法人に関する法律施行規則/本文/第149条の3.md|第百四十九条の三]]及び[[laws/投資信託及び投資法人に関する法律施行規則/本文/第149条の3.md|第百四十九条の三]]の二の規定並びに法[[laws/投資信託及び投資法人に関する法律施行規則/本文/第149条の4.md|第百四十九条の四]]の規定による手続の経過法[[laws/投資信託及び投資法人に関する法律施行規則/本文/第150条.md|第百五十条]]において準用する会社法[[laws/会社法/本文/第784条の2.md|第七百八十四条の二]]の規定による請求に係る手続の経過吸収合併存続法人における次に掲げる事項法[[laws/会社法/本文/第149条の8.md|第百四十九条の八]]の規定及び法[[laws/会社法/本文/第149条の9.md|第百四十九条の九]]において準用する法[[laws/会社法/本文/第149条の4.md|第百四十九条の四]]の規定による手続の経過法[[laws/会社法/本文/第150条.md|第百五十条]]において準用する会社法[[laws/会社法/本文/第796条の2.md|第七百九十六条の二]]の規定による請求に係る手続の経過吸収合併により吸収合併存続法人が吸収合併消滅法人から承継した重要な権利義務に関する事項法[[laws/会社法/本文/第149条.md|第百四十九条]]第一項の規定により吸収合併消滅法人が備え置いた書面又は電磁的記録に記載又は記録がされた事項（吸収合併契約の内容を除く。）法[[laws/投資信託及び投資法人に関する法律施行規則/本文/第169条.md|第百六十九条]]第一項の変更の登記をした日前各号に掲げるもののほか、吸収合併に関する重要な事項

- 一 吸収合併が効力を生じた日
- 二 吸収合併消滅法人における次に掲げる事項
- 三 吸収合併存続法人における次に掲げる事項
- 四 吸収合併により吸収合併存続法人が吸収合併消滅法人から承継した重要な権利義務に関する事項
- 五 法[[laws/投資信託及び投資法人に関する法律施行規則/本文/第149条.md|第百四十九条]]第一項の規定により吸収合併消滅法人が備え置いた書面又は電磁的記録に記載又は記録がされた事項（吸収合併契約の内容を除く。）
- 六 法[[laws/投資信託及び投資法人に関する法律施行規則/本文/第169条.md|第百六十九条]]第一項の変更の登記をした日
- 七 前各号に掲げるもののほか、吸収合併に関する重要な事項
