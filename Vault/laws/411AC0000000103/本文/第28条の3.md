# 第二十八条の三 （研究開発の事務及び事業に関する事項に係る指針の案の作成）

## 
総合科学技術・イノベーション会議は、総務大臣の求めに応じ、研究開発の事務及び事業の特性を踏まえ、前条第一項の指針のうち、研究開発の事務及び事業に関する事項に係る指針の案を作成する。
