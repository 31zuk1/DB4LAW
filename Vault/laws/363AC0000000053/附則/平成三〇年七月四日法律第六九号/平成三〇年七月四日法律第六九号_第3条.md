# 第三条 （報告）

## 
経済産業大臣は、新法第三条第一項第一号に規定する生産量及び消費量の算定を行うため、平成二十三年から平成二十五年までの間に議定書附属書Ｆに掲げる物質の製造、輸出又は輸入を行った者に対し、当該物質について新法第二条第二項に規定する特定物質代替物質に係る同条第四項の規定の例により算定した製造数量、輸出数量又は輸入数量の報告を求めることができる。
