# 第三条の三 （倉庫の基準）

## 
[[laws/倉庫業法施行規則/本文/第3条.md|第三条]]第一号から第九号までに掲げる倉庫に係る法[[laws/倉庫業法施行規則/本文/第6条.md|第六条]]第一項第四号の倉庫の施設又は設備の基準（以下「施設設備基準」という。）は、次のとおりとする。申請者が、その営業に使用する倉庫及びその敷地について所有権その他の使用権原を有すること。[[laws/倉庫業法施行規則/本文/第3条.md|第三条]]各号に掲げる倉庫の種類ごとに国土交通大臣の定める建築基準法（昭和二十五年法律第二百一号）その他の法令の規定に適合していること。

- 一 申請者が、その営業に使用する倉庫及びその敷地について所有権その他の使用権原を有すること。
- 二 [[laws/倉庫業法施行規則/本文/第3条.md|第三条]]各号に掲げる倉庫の種類ごとに国土交通大臣の定める建築基準法（昭和二十五年法律第二百一号）その他の法令の規定に適合していること。
