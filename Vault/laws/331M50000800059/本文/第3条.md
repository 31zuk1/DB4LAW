# 第三条 （倉庫の種類）

## 
法[[laws/331M50000800059/本文/第4条.md|第四条]]第一項第三号の国土交通省令で定める倉庫の種類は、次のとおりとする。一類倉庫二類倉庫三類倉庫野積倉庫水面倉庫貯蔵槽倉庫危険品倉庫冷蔵倉庫トランクルーム特別の倉庫

- 一 一類倉庫
- 二 二類倉庫
- 三 三類倉庫
- 四 野積倉庫
- 五 水面倉庫
- 六 貯蔵槽倉庫
- 七 危険品倉庫
- 八 冷蔵倉庫
- 九 トランクルーム
- 十 特別の倉庫
