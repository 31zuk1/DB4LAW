# 第四十八条の三の三 （被災事業用資産の損失等に係る純損失の金額）

## 
法[[laws/325AC0000000226/本文/第313条.md|第三百十三条]]第九項に規定する政令で定める純損失の金額は、[[laws/325CO0000000245/本文/第7条の9.md|第七条の九]]の三に規定する純損失の金額とする。
