# 第百四十四条 

## 
次に掲げる場合には、土地改良区若しくは土地改良区連合又は連合会の理事若しくは監事又は清算人は、二十万円以下の過料に処する。[[laws/324AC0000000195/本文/第15条.md|第十五条]]又は[[laws/324AC0000000195/本文/第111条の9.md|第百十一条の九]]に規定する事業以外の事業を営んだとき。[[laws/324AC0000000195/本文/第18条.md|第十八条]]第七項又は[[laws/324AC0000000195/本文/第82条.md|第八十二条]]第四項の規定に違反してこれらの規定に規定する者に該当する者を監事に選任しなかつたとき。[[laws/324AC0000000195/本文/第20条.md|第二十条]]（[[laws/324AC0000000195/本文/第111条の28.md|第百十一条の二十八]]において準用する場合を含む。）の規定に違反したとき。[[laws/324AC0000000195/本文/第24条.md|第二十四条]]第一項の規定に違反して通知することを怠り、又は不正の通知をしたとき。[[laws/324AC0000000195/本文/第24条.md|第二十四条]]第二項若しくは第四項又は[[laws/324AC0000000195/本文/第25条.md|第二十五条]]第一項、[[laws/324AC0000000195/本文/第26条.md|第二十六条]]第一項若しくは[[laws/324AC0000000195/本文/第27条.md|第二十七条]]（これらの規定を[[laws/324AC0000000195/本文/第111条の28.md|第百十一条の二十八]]において準用する場合を含む。）の規定に違反したとき。[[laws/324AC0000000195/本文/第29条.md|第二十九条]]第一項（[[laws/324AC0000000195/本文/第111条の28.md|第百十一条の二十八]]において準用する場合を含む。）の規定に違反して書簿を備えず、若しくは保存せず、又は[[laws/324AC0000000195/本文/第29条.md|第二十九条]]第三項の規定による農林水産省令に違反してその書簿に記載すべき事項を記載せず、若しくは虚偽の記載をしたとき。[[laws/324AC0000000195/本文/第29条.md|第二十九条]]第四項（[[laws/324AC0000000195/本文/第111条の28.md|第百十一条の二十八]]において準用する場合を含む。）の規定に違反して書簿の閲覧を拒んだとき。[[laws/324AC0000000195/本文/第41条.md|第四十一条]]第一項の規定に違反したとき。[[laws/324AC0000000195/本文/第69条.md|第六十九条]]第一項又は[[laws/324AC0000000195/本文/第71条.md|第七十一条]]（これらの規定を[[laws/324AC0000000195/本文/第111条の28.md|第百十一条の二十八]]において準用する場合を含む。）の書類又は電磁的記録に記載し、若しくは記録すべき事項を記載せず、若しくは記録せず、又は虚偽の記載若しくは記録をしたとき。[[laws/324AC0000000195/本文/第69条の2.md|第六十九条の二]]第一項（[[laws/324AC0000000195/本文/第111条の28.md|第百十一条の二十八]]において準用する場合を含む。）の期間内に債権者に弁済をしたとき。[[laws/324AC0000000195/本文/第70条.md|第七十条]]（[[laws/324AC0000000195/本文/第111条の28.md|第百十一条の二十八]]において準用する場合を含む。）の規定に違反して土地改良区の残余財産を分配したとき。[[laws/324AC0000000195/本文/第111条の22.md|第百十一条の二十二]]第一項若しくは第四項又は[[laws/324AC0000000195/本文/第111条の24.md|第百十一条の二十四]]の規定により農林水産大臣の認可を受けなければならない場合において、その認可を受けなかつたとき。[[laws/324AC0000000195/本文/第111条の25.md|第百十一条の二十五]]の規定に違反して業務上の余裕金を運用したとき。[[laws/324AC0000000195/本文/第134条.md|第百三十四条]]又は[[laws/324AC0000000195/本文/第134条の2.md|第百三十四条の二]]の規定による命令に違反したとき。この法律の規定による公告（[[laws/324AC0000000195/本文/第76条の3.md|第七十六条の三]]第二項（[[laws/324AC0000000195/本文/第76条の16.md|第七十六条の十六]]において準用する場合を含む。）の規定による公告を除く。）をせず、又は不正の公告をしたとき。この法律の規定による登記（[[laws/324AC0000000195/本文/第76条の7.md|第七十六条の七]]第一項の規定による登記を除く。）をすることを怠つたとき。

- 一 [[laws/324AC0000000195/本文/第15条.md|第十五条]]又は[[laws/324AC0000000195/本文/第111条の9.md|第百十一条の九]]に規定する事業以外の事業を営んだとき。
- 二 [[laws/324AC0000000195/本文/第18条.md|第十八条]]第七項又は[[laws/324AC0000000195/本文/第82条.md|第八十二条]]第四項の規定に違反してこれらの規定に規定する者に該当する者を監事に選任しなかつたとき。
- 三 [[laws/324AC0000000195/本文/第20条.md|第二十条]]（[[laws/324AC0000000195/本文/第111条の28.md|第百十一条の二十八]]において準用する場合を含む。）の規定に違反したとき。
- 四 [[laws/324AC0000000195/本文/第24条.md|第二十四条]]第一項の規定に違反して通知することを怠り、又は不正の通知をしたとき。
- 五 [[laws/324AC0000000195/本文/第24条.md|第二十四条]]第二項若しくは第四項又は[[laws/324AC0000000195/本文/第25条.md|第二十五条]]第一項、[[laws/324AC0000000195/本文/第26条.md|第二十六条]]第一項若しくは[[laws/324AC0000000195/本文/第27条.md|第二十七条]]（これらの規定を[[laws/324AC0000000195/本文/第111条の28.md|第百十一条の二十八]]において準用する場合を含む。）の規定に違反したとき。
- 六 [[laws/324AC0000000195/本文/第29条.md|第二十九条]]第一項（[[laws/324AC0000000195/本文/第111条の28.md|第百十一条の二十八]]において準用する場合を含む。）の規定に違反して書簿を備えず、若しくは保存せず、又は[[laws/324AC0000000195/本文/第29条.md|第二十九条]]第三項の規定による農林水産省令に違反してその書簿に記載すべき事項を記載せず、若しくは虚偽の記載をしたとき。
- 七 [[laws/324AC0000000195/本文/第29条.md|第二十九条]]第四項（[[laws/324AC0000000195/本文/第111条の28.md|第百十一条の二十八]]において準用する場合を含む。）の規定に違反して書簿の閲覧を拒んだとき。
- 八 [[laws/324AC0000000195/本文/第41条.md|第四十一条]]第一項の規定に違反したとき。
- 九 [[laws/324AC0000000195/本文/第69条.md|第六十九条]]第一項又は[[laws/324AC0000000195/本文/第71条.md|第七十一条]]（これらの規定を[[laws/324AC0000000195/本文/第111条の28.md|第百十一条の二十八]]において準用する場合を含む。）の書類又は電磁的記録に記載し、若しくは記録すべき事項を記載せず、若しくは記録せず、又は虚偽の記載若しくは記録をしたとき。
- 十 [[laws/324AC0000000195/本文/第69条の2.md|第六十九条の二]]第一項（[[laws/324AC0000000195/本文/第111条の28.md|第百十一条の二十八]]において準用する場合を含む。）の期間内に債権者に弁済をしたとき。
- 十一 [[laws/324AC0000000195/本文/第70条.md|第七十条]]（[[laws/324AC0000000195/本文/第111条の28.md|第百十一条の二十八]]において準用する場合を含む。）の規定に違反して土地改良区の残余財産を分配したとき。
- 十二 [[laws/324AC0000000195/本文/第111条の22.md|第百十一条の二十二]]第一項若しくは第四項又は[[laws/324AC0000000195/本文/第111条の24.md|第百十一条の二十四]]の規定により農林水産大臣の認可を受けなければならない場合において、その認可を受けなかつたとき。

- 十四 [[laws/324AC0000000195/本文/第134条.md|第百三十四条]]又は[[laws/324AC0000000195/本文/第134条の2.md|第百三十四条の二]]の規定による命令に違反したとき。
- 十五 この法律の規定による公告（[[laws/324AC0000000195/本文/第76条の3.md|第七十六条の三]]第二項（[[laws/324AC0000000195/本文/第76条の16.md|第七十六条の十六]]において準用する場合を含む。）の規定による公告を除く。）をせず、又は不正の公告をしたとき。
