# 第九十三条の三 （予定外廃水の排除等のための措置）

## 
国又は都道府県が管理規程を定めて農業用用排水路の管理（委託を受けて行なう管理を含む。）を行なう場合には、[[laws/324AC0000000195/本文/第57条の3.md|第五十七条の三]]の規定を準用する。
