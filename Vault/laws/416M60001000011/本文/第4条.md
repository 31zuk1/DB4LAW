# 第四条 （業務方法書の記載事項）

## 
機構に係る通則法[[laws/416M60001000011/本文/第28条.md|第二十八条]]第二項の主務省令で定める業務方法書に記載すべき事項は、次のとおりとする。独立行政法人環境再生保全機構法（以下「機構法」という。）[[laws/416M60001000011/本文/第10条.md|第十条]]第一項第一号に規定する公害に係る健康被害の補償に関する事項機構法[[laws/416M60001000011/本文/第10条.md|第十条]]第一項第二号に規定する大気の汚染の影響による健康被害の予防に関する事項機構法[[laws/416M60001000011/本文/第10条.md|第十条]]第一項第三号に規定する助成金の交付に関する事項機構法[[laws/416M60001000011/本文/第10条.md|第十条]]第一項第四号に規定する調査研究、情報の収集、整理及び提供並びに研修に関する事項機構法[[laws/416M60001000011/本文/第10条.md|第十条]]第一項第五号に規定する助成金の交付に関する事項機構法[[laws/416M60001000011/本文/第10条.md|第十条]]第一項第六号に規定する維持管理積立金の管理に関する事項機構法[[laws/416M60001000011/本文/第10条.md|第十条]]第一項第七号に規定する石綿による健康被害の救済に関する事項機構法[[laws/416M60001000011/本文/第10条.md|第十条]]第一項第八号に規定する研究及び技術開発に関する事項機構法[[laws/416M60001000011/本文/第10条.md|第十条]]第一項第九号に規定する成果の普及及びその活用の促進に関する事項機構法[[laws/416M60001000011/本文/第10条.md|第十条]]第一項第十号に規定する助成金の交付に関する事項機構法[[laws/416M60001000011/本文/第10条.md|第十条]]第一項第十一号に規定する情報の整理、分析及び提供に関する事項機構法[[laws/416M60001000011/本文/第10条.md|第十条]]第一項第十二号に規定する情報の収集、整理、分析及び提供並びに研修に関する事項機構法[[laws/416M60001000011/本文/第10条.md|第十条]]第一項第十三号に規定する情報の収集、整理、分析及び提供並びに地域における生物の多様性の増進のための活動の促進等に関する法律（令和六年法律第十八号。以下「地域生物多様性増進法」という。）[[laws/416M60001000011/本文/第14条.md|第十四条]]に規定する事務に関する事項機構法[[laws/416M60001000011/本文/第10条.md|第十条]]第二項に規定する調査研究、情報の収集、整理及び提供並びに研修に関する事項業務委託の基準競争入札その他契約に関する基本的事項その他機構の業務の執行に関して必要な事項

- 一 独立行政法人環境再生保全機構法（以下「機構法」という。）[[laws/416M60001000011/本文/第10条.md|第十条]]第一項第一号に規定する公害に係る健康被害の補償に関する事項
- 二 機構法[[laws/416M60001000011/本文/第10条.md|第十条]]第一項第二号に規定する大気の汚染の影響による健康被害の予防に関する事項
- 三 機構法[[laws/416M60001000011/本文/第10条.md|第十条]]第一項第三号に規定する助成金の交付に関する事項
- 四 機構法[[laws/416M60001000011/本文/第10条.md|第十条]]第一項第四号に規定する調査研究、情報の収集、整理及び提供並びに研修に関する事項
- 五 機構法[[laws/416M60001000011/本文/第10条.md|第十条]]第一項第五号に規定する助成金の交付に関する事項
- 六 機構法[[laws/416M60001000011/本文/第10条.md|第十条]]第一項第六号に規定する維持管理積立金の管理に関する事項
- 七 機構法[[laws/416M60001000011/本文/第10条.md|第十条]]第一項第七号に規定する石綿による健康被害の救済に関する事項
- 八 機構法[[laws/416M60001000011/本文/第10条.md|第十条]]第一項第八号に規定する研究及び技術開発に関する事項
- 九 機構法[[laws/416M60001000011/本文/第10条.md|第十条]]第一項第九号に規定する成果の普及及びその活用の促進に関する事項
- 十 機構法[[laws/416M60001000011/本文/第10条.md|第十条]]第一項第十号に規定する助成金の交付に関する事項
- 十一 機構法[[laws/416M60001000011/本文/第10条.md|第十条]]第一項第十一号に規定する情報の整理、分析及び提供に関する事項
- 十二 機構法[[laws/416M60001000011/本文/第10条.md|第十条]]第一項第十二号に規定する情報の収集、整理、分析及び提供並びに研修に関する事項
- 十三 機構法[[laws/416M60001000011/本文/第10条.md|第十条]]第一項第十三号に規定する情報の収集、整理、分析及び提供並びに地域における生物の多様性の増進のための活動の促進等に関する法律（令和六年法律第十八号。以下「地域生物多様性増進法」という。）[[laws/416M60001000011/本文/第14条.md|第十四条]]に規定する事務に関する事項
- 十四 機構法[[laws/416M60001000011/本文/第10条.md|第十条]]第二項に規定する調査研究、情報の収集、整理及び提供並びに研修に関する事項
- 十五 業務委託の基準
- 十六 競争入札その他契約に関する基本的事項
- 十七 その他機構の業務の執行に関して必要な事項
