# 第四十一条 

## 
次の各号のいずれかに該当する者は、三十万円以下の罰金に処する。[[laws/323AC0000000125/本文/第8条.md|第八条]]第一項（[[laws/323AC0000000125/本文/第11条.md|第十一条]]第二項又は第三項において準用する場合を含む。）、[[laws/323AC0000000125/本文/第14条の8.md|第十四条の八]]第一項、[[laws/323AC0000000125/本文/第18条.md|第十八条]]第四項又は[[laws/323AC0000000125/本文/第20条.md|第二十条]]の規定による届出をせず、又は虚偽の届出をした者[[laws/323AC0000000125/本文/第18条.md|第十八条]]第一項の規定による掲示をせず、又は虚偽の掲示をした者[[laws/323AC0000000125/本文/第18条.md|第十八条]]第二項の規定に違反した者（前号の規定に該当する者を除く。）[[laws/323AC0000000125/本文/第18条.md|第十八条]]第三項の規定に違反して、温泉成分分析を受けず、又は掲示の内容を変更しなかつた者[[laws/323AC0000000125/本文/第27条.md|第二十七条]]の規定に違反した者[[laws/323AC0000000125/本文/第28条.md|第二十八条]]第一項又は[[laws/323AC0000000125/本文/第34条.md|第三十四条]]の規定による報告をせず、又は虚偽の報告をした者[[laws/323AC0000000125/本文/第28条.md|第二十八条]]第一項又は[[laws/323AC0000000125/本文/第35条.md|第三十五条]]第一項の規定による立入検査を拒み、妨げ、若しくは忌避し、又は質問に対して陳述をせず、若しくは虚偽の陳述をした者

- 一 [[laws/323AC0000000125/本文/第8条.md|第八条]]第一項（[[laws/323AC0000000125/本文/第11条.md|第十一条]]第二項又は第三項において準用する場合を含む。）、[[laws/323AC0000000125/本文/第14条の8.md|第十四条の八]]第一項、[[laws/323AC0000000125/本文/第18条.md|第十八条]]第四項又は[[laws/323AC0000000125/本文/第20条.md|第二十条]]の規定による届出をせず、又は虚偽の届出をした者
- 二 [[laws/323AC0000000125/本文/第18条.md|第十八条]]第一項の規定による掲示をせず、又は虚偽の掲示をした者
- 三 [[laws/323AC0000000125/本文/第18条.md|第十八条]]第二項の規定に違反した者（前号の規定に該当する者を除く。）
- 四 [[laws/323AC0000000125/本文/第18条.md|第十八条]]第三項の規定に違反して、温泉成分分析を受けず、又は掲示の内容を変更しなかつた者
- 五 [[laws/323AC0000000125/本文/第27条.md|第二十七条]]の規定に違反した者
- 六 [[laws/323AC0000000125/本文/第28条.md|第二十八条]]第一項又は[[laws/323AC0000000125/本文/第34条.md|第三十四条]]の規定による報告をせず、又は虚偽の報告をした者
- 七 [[laws/323AC0000000125/本文/第28条.md|第二十八条]]第一項又は[[laws/323AC0000000125/本文/第35条.md|第三十五条]]第一項の規定による立入検査を拒み、妨げ、若しくは忌避し、又は質問に対して陳述をせず、若しくは虚偽の陳述をした者
