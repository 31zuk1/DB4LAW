# 第二十五条 （業務規程の記載事項）

## 
法[[laws/419AC0000000102/本文/第59条.md|第五十九条]]に規定する主務省令で定める事項は、次に掲げるものとする。記録事項に関する事項電子記録の請求に関する事項電子記録の実施の方法に関する事項法[[laws/419AC0000000102/本文/第47条の3.md|第四十七条の三]]第五項及び[[laws/419AC0000000102/本文/第47条の5.md|第四十七条の五]]第三項の規定による通知の方法に関する事項法[[laws/419AC0000000102/本文/第62条.md|第六十二条]]第一項に規定する口座間送金決済に関する契約又は法[[laws/419AC0000000102/本文/第64条.md|第六十四条]]に規定する契約に係る事項電子債権記録機関を利用する者に関する事項電子債権記録業を行う時間及び休日に関する事項記録原簿の安全性の確保に関する事項記録事項の開示その他の情報の提供に関する事項その他電子債権記録業に関し必要な事項

- 一 記録事項に関する事項
- 二 電子記録の請求に関する事項
- 三 電子記録の実施の方法に関する事項
- 四 法[[laws/419AC0000000102/本文/第47条の3.md|第四十七条の三]]第五項及び[[laws/419AC0000000102/本文/第47条の5.md|第四十七条の五]]第三項の規定による通知の方法に関する事項
- 五 法[[laws/419AC0000000102/本文/第62条.md|第六十二条]]第一項に規定する口座間送金決済に関する契約又は法[[laws/419AC0000000102/本文/第64条.md|第六十四条]]に規定する契約に係る事項
- 六 電子債権記録機関を利用する者に関する事項
- 七 電子債権記録業を行う時間及び休日に関する事項
- 八 記録原簿の安全性の確保に関する事項
- 九 記録事項の開示その他の情報の提供に関する事項
- 十 その他電子債権記録業に関し必要な事項
