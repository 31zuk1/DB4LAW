# 第一条 （生産条件不利補正対象農産物の要件）

## 
農業の担い手に対する経営安定のための交付金の交付に関する法律施行令（以下「令」という。）[[laws/418M60000200059/本文/第1条.md|第一条]]の農林水産省令で定める要件は、次の各号に掲げる生産条件不利補正対象農産物（農業の担い手に対する経営安定のための交付金の交付に関する法律（以下「法」という。）[[laws/418M60000200059/本文/第2条.md|第二条]]第二項に規定する生産条件不利補正対象農産物をいう。以下同じ。）の種類に応じ、当該各号に定めるものとする。麦種子又は麦芽の原料として使用されるもの以外のもの（春期には種する小麦、秋期には種する小麦、二条大麦、六条大麦及びはだか麦に限る。）であること。大豆種子として使用されるもの又は黒大豆以外のものであること。てん菜砂糖及びでん粉の価格調整に関する法律（昭和四十年法律第百九号。以下「価格調整法」という。）[[laws/418M60000200059/農業の担い手に対する経営安定のための交付_law.md|第二十一条]]の国内産糖交付金の交付対象となり、又は交付対象となることが確実と見込まれる価格調整法[[laws/418M60000200059/本文/第2条.md|第二条]]第二項に規定する国内産糖の製造の用に供されるものであって、価格調整法[[laws/418M60000200059/農業の担い手に対する経営安定のための交付_law.md|第十九条]]第一項に規定する指定地域の区域内において生産されるものであること。でん粉の製造の用に供するばれいしょ価格調整法[[laws/418M60000200059/農業の担い手に対する経営安定のための交付_law.md|第三十五条]]の国内産いもでん粉交付金の交付対象となり、又は交付対象となることが確実と見込まれる価格調整法[[laws/418M60000200059/本文/第2条.md|第二条]]第七項に規定する国内産いもでん粉の製造の用に供されるものであって、価格調整法[[laws/418M60000200059/農業の担い手に対する経営安定のための交付_law.md|第三十三条]]第一項に規定する指定地域の区域内において生産されるものであること。そば種子として使用されるもの以外のものであること。菜種食用植物油脂の製造の用に供されるものであること。

- 一 麦種子又は麦芽の原料として使用されるもの以外のもの（春期には種する小麦、秋期には種する小麦、二条大麦、六条大麦及びはだか麦に限る。）であること。
- 二 大豆種子として使用されるもの又は黒大豆以外のものであること。
- 三 てん菜砂糖及びでん粉の価格調整に関する法律（昭和四十年法律第百九号。以下「価格調整法」という。）[[laws/418M60000200059/農業の担い手に対する経営安定のための交付_law.md|第二十一条]]の国内産糖交付金の交付対象となり、又は交付対象となることが確実と見込まれる価格調整法[[laws/418M60000200059/本文/第2条.md|第二条]]第二項に規定する国内産糖の製造の用に供されるものであって、価格調整法[[laws/418M60000200059/農業の担い手に対する経営安定のための交付_law.md|第十九条]]第一項に規定する指定地域の区域内において生産されるものであること。
- 四 でん粉の製造の用に供するばれいしょ価格調整法[[laws/418M60000200059/農業の担い手に対する経営安定のための交付_law.md|第三十五条]]の国内産いもでん粉交付金の交付対象となり、又は交付対象となることが確実と見込まれる価格調整法[[laws/418M60000200059/本文/第2条.md|第二条]]第七項に規定する国内産いもでん粉の製造の用に供されるものであって、価格調整法[[laws/418M60000200059/農業の担い手に対する経営安定のための交付_law.md|第三十三条]]第一項に規定する指定地域の区域内において生産されるものであること。
- 五 そば種子として使用されるもの以外のものであること。
- 六 菜種食用植物油脂の製造の用に供されるものであること。
