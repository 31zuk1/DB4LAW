# 第三条 

## 
協議会は、会則を定めなければならない。

## ２
協議会の会則には、次の事項を定めなければならない。名称事務所の所在地役員に関する事項会議に関する事項会計に関する事項会則の変更に関する事項

- 一 名称
- 二 事務所の所在地
- 三 役員に関する事項
- 四 会議に関する事項
- 五 会計に関する事項
- 六 会則の変更に関する事項
