# 第一条 （施行期日）

## 
この法律は、平成二十五年四月一日から施行する。ただし、次の各号に掲げる規定は、当該各号に定める日から施行する。略第七条中租税条約等の実施に伴う所得税法、法人税法及び地方税法の特例等に関する法律[[laws/344AC0000000046/本文/第11条.md|第十一条]]の改正規定及び同法第十一条の二の改正規定平成二十五年七月一日略次に掲げる規定平成二十八年一月一日略第七条中租税条約等の実施に伴う所得税法、法人税法及び地方税法の特例等に関する法律[[laws/344AC0000000046/本文/第3条の2.md|第三条の二]]の改正規定

- 一 略
- 二 第七条中租税条約等の実施に伴う所得税法、法人税法及び地方税法の特例等に関する法律[[laws/344AC0000000046/本文/第11条.md|第十一条]]の改正規定及び同法第十一条の二の改正規定平成二十五年七月一日
- 三から五まで 略
- 六 次に掲げる規定平成二十八年一月一日
