# 第一条 （施行期日）

## 
この法律は、平成二十七年四月一日から施行する。ただし、次の各号に掲げる規定は、当該各号に定める日から施行する。略次に掲げる規定平成二十七年七月一日略第七条中租税条約等の実施に伴う所得税法、法人税法及び地方税法の特例等に関する法律[[laws/344AC0000000046/本文/第3条.md|第三条]]の改正規定略次に掲げる規定平成二十八年四月一日略[[laws/344AC0000000046/本文/第7条.md|第七条]]中租税条約等の実施に伴う所得税法、法人税法及び地方税法の特例等に関する法律[[laws/344AC0000000046/本文/第3条の2.md|第三条の二]]第十三項及び[[laws/344AC0000000046/本文/第4条.md|第四条]]第一項から第六項までの改正規定並びに同法第七条第四項の表法人税法第百四十五条の項の改正規定第七条中租税条約等の実施に伴う所得税法、法人税法及び地方税法の特例等に関する法律[[laws/344AC0000000046/本文/第9条.md|第九条]]第一項の改正規定、同法第十条の四の次に五条を加える改正規定、同法第十一条の二第一項の改正規定及び同法第十三条第四項の改正規定平成二十九年一月一日

- 一 略
- 二 次に掲げる規定平成二十七年七月一日
- 三及び四 略
- 五 次に掲げる規定平成二十八年四月一日
- 六 第七条中租税条約等の実施に伴う所得税法、法人税法及び地方税法の特例等に関する法律[[laws/344AC0000000046/本文/第9条.md|第九条]]第一項の改正規定、同法第十条の四の次に五条を加える改正規定、同法第十一条の二第一項の改正規定及び同法第十三条第四項の改正規定平成二十九年一月一日
