# 第六十五条 

## 
次の各号のいずれかに該当する場合には、その違反行為をした日本銀行の役員又は職員は、五十万円以下の過料に処する。この法律の規定（[[laws/日本銀行法/本文/第43条.md|第四十三条]]第一項の規定を除く。）により財務大臣若しくは財務大臣及び内閣総理大臣の認可又は財務大臣の承認を受けなければならない場合において、その認可又は承認を受けなかったとき。この法律の規定により財務大臣又は財務大臣及び内閣総理大臣に届出をしなければならない場合において、その届出をせず、又は虚偽の届出をしたとき。この法律の規定により公表をしなければならない場合において、その公表をせず、又は虚偽の公表をしたとき。[[laws/日本銀行法/本文/第12条.md|第十二条]]第一項の規定による政令に違反して登記することを怠ったとき。[[laws/日本銀行法/本文/第26条.md|第二十六条]]第一項の規定に違反して報酬のある他の職務に従事し、又は営利事業を営み、その他金銭上の利益を目的とする業務を行ったとき。[[laws/日本銀行法/本文/第43条.md|第四十三条]]第一項の規定に違反して日本銀行の業務とされた業務以外の業務を行ったとき。[[laws/日本銀行法/本文/第48条.md|第四十八条]]の規定に違反したとき。[[laws/日本銀行法/本文/第52条.md|第五十二条]]第三項の規定に違反して財務諸表、決算報告書若しくは監事の意見書を備え置かず、又は閲覧に供しなかったとき。[[laws/日本銀行法/本文/第53条.md|第五十三条]]第一項の規定に違反して準備金を積み立てなかったとき。[[laws/日本銀行法/本文/第53条.md|第五十三条]]第三項の規定に違反して準備金を取り崩したとき。[[laws/日本銀行法/本文/第53条.md|第五十三条]]第四項ただし書の規定に違反して配当をしたとき。[[laws/日本銀行法/本文/第56条.md|第五十六条]]第二項の規定による報告をせず、又は虚偽の報告をしたとき。[[laws/日本銀行法/本文/第58条.md|第五十八条]]の規定による報告若しくは資料の提出をせず、又は虚偽の報告若しくは資料の提出をしたとき。

- 一 この法律の規定（[[laws/日本銀行法/本文/第43条.md|第四十三条]]第一項の規定を除く。）により財務大臣若しくは財務大臣及び内閣総理大臣の認可又は財務大臣の承認を受けなければならない場合において、その認可又は承認を受けなかったとき。
- 二 この法律の規定により財務大臣又は財務大臣及び内閣総理大臣に届出をしなければならない場合において、その届出をせず、又は虚偽の届出をしたとき。
- 三 この法律の規定により公表をしなければならない場合において、その公表をせず、又は虚偽の公表をしたとき。
- 四 [[laws/日本銀行法/本文/第12条.md|第十二条]]第一項の規定による政令に違反して登記することを怠ったとき。
- 五 [[laws/日本銀行法/本文/第26条.md|第二十六条]]第一項の規定に違反して報酬のある他の職務に従事し、又は営利事業を営み、その他金銭上の利益を目的とする業務を行ったとき。
- 六 [[laws/日本銀行法/本文/第43条.md|第四十三条]]第一項の規定に違反して日本銀行の業務とされた業務以外の業務を行ったとき。
- 七 [[laws/日本銀行法/本文/第48条.md|第四十八条]]の規定に違反したとき。
- 八 [[laws/日本銀行法/本文/第52条.md|第五十二条]]第三項の規定に違反して財務諸表、決算報告書若しくは監事の意見書を備え置かず、又は閲覧に供しなかったとき。
- 九 [[laws/日本銀行法/本文/第53条.md|第五十三条]]第一項の規定に違反して準備金を積み立てなかったとき。
- 十 [[laws/日本銀行法/本文/第53条.md|第五十三条]]第三項の規定に違反して準備金を取り崩したとき。
- 十一 [[laws/日本銀行法/本文/第53条.md|第五十三条]]第四項ただし書の規定に違反して配当をしたとき。
- 十二 [[laws/日本銀行法/本文/第56条.md|第五十六条]]第二項の規定による報告をせず、又は虚偽の報告をしたとき。
- 十三 [[laws/日本銀行法/本文/第58条.md|第五十八条]]の規定による報告若しくは資料の提出をせず、又は虚偽の報告若しくは資料の提出をしたとき。
