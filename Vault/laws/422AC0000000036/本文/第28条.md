# 第二十八条 （木材利用促進本部員）

## 
本部に、木材利用促進本部員（次項において「本部員」という。）を置く。

## ２
本部員は、次に掲げる者をもって充てる。総務大臣文部科学大臣経済産業大臣国土交通大臣環境大臣前各号に掲げる者のほか、農林水産大臣以外の国務大臣のうちから、農林水産大臣の申出により、内閣総理大臣が指定する者

- 一 総務大臣
- 二 文部科学大臣
- 三 経済産業大臣
- 四 国土交通大臣
- 五 環境大臣
- 六 前各号に掲げる者のほか、農林水産大臣以外の国務大臣のうちから、農林水産大臣の申出により、内閣総理大臣が指定する者
