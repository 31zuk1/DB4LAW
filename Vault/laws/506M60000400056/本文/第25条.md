# 第二十五条 （附属明細書）

## 
附属明細書には、次に掲げる事項のほか、貸借対照表、損益計算書及び業務報告書の記載を補足する重要な事項を記載しなければならない。投資の明細及び投資の時価の明細投資先事業者の状況及び主要な財務数値組合員の持分に関する明細分配金の明細投資損益の明細その他の勘定明細

- 一 投資の明細及び投資の時価の明細
- 二 投資先事業者の状況及び主要な財務数値
- 三 組合員の持分に関する明細
- 四 分配金の明細
- 五 投資損益の明細
- 六 その他の勘定明細
