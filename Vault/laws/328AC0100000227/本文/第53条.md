# 第五十三条 （特別の議決）

## 
次の事項については、総会員（個人会員を除く。）の半数以上の代議員（臨時代議員を含む。）が出席し、その議決権の三分の二以上の多数による決議を必要とする。定款の変更解散又は合併会員の除名事業の全部の譲渡[[laws/労働金庫法/本文/第12条.md|第十二条]]第三項ただし書の規定による承諾[[laws/労働金庫法/本文/第42条.md|第四十二条]]第四項に規定する責任の免除

- 一 定款の変更
- 二 解散又は合併
- 三 会員の除名
- 四 事業の全部の譲渡
- 五 [[laws/労働金庫法/本文/第12条.md|第十二条]]第三項ただし書の規定による承諾
- 六 [[laws/労働金庫法/本文/第42条.md|第四十二条]]第四項に規定する責任の免除
