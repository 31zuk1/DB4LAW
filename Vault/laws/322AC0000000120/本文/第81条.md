# 第八十一条 （適用除外）

## 
次に掲げる職員の分限（定年に係るものを除く。次項において同じ。）については、[[laws/322AC0000000120/本文/第75条.md|第七十五条]]、[[laws/322AC0000000120/本文/第78条.md|第七十八条]]から前条まで及び[[laws/322AC0000000120/本文/第89条.md|第八十九条]]並びに行政不服審査法（平成二十六年法律第六十八号）の規定は、適用しない。臨時的職員条件付採用期間中の職員

- 一 臨時的職員
- 二 条件付採用期間中の職員
## 
前項各号に掲げる職員の分限については、人事院規則で必要な事項を定めることができる。
