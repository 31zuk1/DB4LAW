# 第九十四条 

## 
次の各号のいずれかに該当する者は、一年以下の拘禁刑若しくは百万円以下の罰金に処し、又はこれを併科する。[[laws/信託業法/本文/第6条.md|第六条]]の規定に違反して、認可を受けないで資本金の額を減少した者[[laws/信託業法/本文/第11条.md|第十一条]]第五項の規定に違反して、信託業務を開始した者[[laws/信託業法/本文/第13条.md|第十三条]]第一項の規定に違反して、認可を受けないで業務方法書を変更した者[[laws/信託業法/本文/第16条.md|第十六条]]第一項の規定に違反して、承認を受けないで他の会社の常務に従事し、又は事業を営んだ者[[laws/信託業法/本文/第18条.md|第十八条]]（[[laws/信託業法/本文/第20条.md|第二十条]]において準用する場合を含む。）の規定による命令に違反した者[[laws/信託業法/本文/第21条.md|第二十一条]]第四項（[[laws/信託業法/本文/第63条.md|第六十三条]]第二項において準用する場合を含む。）の規定に違反して、承認を受けないで業務の内容又は方法を変更した者[[laws/信託業法/本文/第24条の2.md|第二十四条の二]]において準用する金融商品取引法（以下「準用金融商品取引法」という。）第三十九条第二項（第二号を除く。）の規定に違反した者[[laws/信託業法/本文/第85条の4.md|第八十五条の四]]第一項の規定に違反して、その職務に関して知り得た秘密を漏らし、又は自己の利益のために使用した者

- 一 [[laws/信託業法/本文/第6条.md|第六条]]の規定に違反して、認可を受けないで資本金の額を減少した者
- 二 [[laws/信託業法/本文/第11条.md|第十一条]]第五項の規定に違反して、信託業務を開始した者
- 三 [[laws/信託業法/本文/第13条.md|第十三条]]第一項の規定に違反して、認可を受けないで業務方法書を変更した者
- 四 [[laws/信託業法/本文/第16条.md|第十六条]]第一項の規定に違反して、承認を受けないで他の会社の常務に従事し、又は事業を営んだ者
- 五 [[laws/信託業法/本文/第18条.md|第十八条]]（[[laws/信託業法/本文/第20条.md|第二十条]]において準用する場合を含む。）の規定による命令に違反した者
- 六 [[laws/信託業法/本文/第21条.md|第二十一条]]第四項（[[laws/信託業法/本文/第63条.md|第六十三条]]第二項において準用する場合を含む。）の規定に違反して、承認を受けないで業務の内容又は方法を変更した者
- 七 [[laws/信託業法/本文/第24条の2.md|第二十四条の二]]において準用する金融商品取引法（以下「準用金融商品取引法」という。）第三十九条第二項（第二号を除く。）の規定に違反した者
- 八 [[laws/信託業法/本文/第85条の4.md|第八十五条の四]]第一項の規定に違反して、その職務に関して知り得た秘密を漏らし、又は自己の利益のために使用した者
