# 第九十六条 

## 
次の各号のいずれかに該当する者は、六月以下の拘禁刑若しくは五十万円以下の罰金に処し、又はこれを併科する。[[laws/416AC0000000154/本文/第11条.md|第十一条]]第八項の規定に違反して、供託を行わなかった者[[laws/416AC0000000154/本文/第17条.md|第十七条]]第一項（[[laws/416AC0000000154/本文/第20条.md|第二十条]]において準用する場合を含む。）の規定による届出書若しくは[[laws/416AC0000000154/本文/第17条.md|第十七条]]第二項（[[laws/416AC0000000154/本文/第20条.md|第二十条]]において準用する場合を含む。）の規定によりこれに添付すべき書類を提出せず、又は虚偽の届出書若しくはこれに添付すべき書類を提出した者[[laws/416AC0000000154/本文/第21条.md|第二十一条]]第三項（[[laws/416AC0000000154/本文/第63条.md|第六十三条]]第二項において準用する場合を含む。）の規定による申請書又はこれに添付すべき書類に虚偽の記載をして提出した者準用金融商品取引法[[laws/323AC0000000025/本文/第37条.md|第三十七条]]第一項（第二号を除く。）に規定する事項を表示せず、又は虚偽の表示をした者準用金融商品取引法[[laws/323AC0000000025/本文/第37条.md|第三十七条]]第二項の規定に違反した者準用金融商品取引法[[laws/323AC0000000025/本文/第37条の3.md|第三十七条の三]]第一項（第二号から第四号まで及び第六号を除く。以下この号において同じ。）の規定に違反して、同項の規定による情報の提供をせず、又は虚偽の情報の提供をした者[[laws/323AC0000000025/本文/第26条.md|第二十六条]]第一項の規定に違反して、同項の規定による情報の提供をせず、又は虚偽の情報の提供をした者[[laws/323AC0000000025/本文/第29条.md|第二十九条]]第三項の規定に違反して、同項の規定による情報の提供をせず、又は虚偽の情報の提供をした者

- 一 [[laws/416AC0000000154/本文/第11条.md|第十一条]]第八項の規定に違反して、供託を行わなかった者
- 二 [[laws/416AC0000000154/本文/第17条.md|第十七条]]第一項（[[laws/416AC0000000154/本文/第20条.md|第二十条]]において準用する場合を含む。）の規定による届出書若しくは[[laws/416AC0000000154/本文/第17条.md|第十七条]]第二項（[[laws/416AC0000000154/本文/第20条.md|第二十条]]において準用する場合を含む。）の規定によりこれに添付すべき書類を提出せず、又は虚偽の届出書若しくはこれに添付すべき書類を提出した者
- 三 [[laws/416AC0000000154/本文/第21条.md|第二十一条]]第三項（[[laws/416AC0000000154/本文/第63条.md|第六十三条]]第二項において準用する場合を含む。）の規定による申請書又はこれに添付すべき書類に虚偽の記載をして提出した者
- 四 準用金融商品取引法[[laws/323AC0000000025/本文/第37条.md|第三十七条]]第一項（第二号を除く。）に規定する事項を表示せず、又は虚偽の表示をした者
- 五 準用金融商品取引法[[laws/323AC0000000025/本文/第37条.md|第三十七条]]第二項の規定に違反した者
- 六 準用金融商品取引法[[laws/323AC0000000025/本文/第37条の3.md|第三十七条の三]]第一項（第二号から第四号まで及び第六号を除く。以下この号において同じ。）の規定に違反して、同項の規定による情報の提供をせず、又は虚偽の情報の提供をした者
- 七 [[laws/416AC0000000154/本文/第26条.md|第二十六条]]第一項の規定に違反して、同項の規定による情報の提供をせず、又は虚偽の情報の提供をした者
- 八 [[laws/416AC0000000154/本文/第29条.md|第二十九条]]第三項の規定に違反して、同項の規定による情報の提供をせず、又は虚偽の情報の提供をした者
