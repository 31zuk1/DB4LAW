# 第八十一条 （業務改善命令）

## 
内閣総理大臣は、信託契約代理店の業務の状況に照らして、当該信託契約代理店の信託契約代理業務の健全かつ適切な運営を確保するため必要があると認めるときは、当該信託契約代理店に対し、その必要の限度において、業務方法書の変更その他業務の運営の改善に必要な措置を命ずることができる。
