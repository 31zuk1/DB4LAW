# 第二十二条の三 

## 
法[[laws/325AC0100000123/本文/第41条.md|第四十一条]]第二項第二号の厚生労働省令で定める場所は、次に掲げる場所とする。精神障害者の居宅法[[laws/325M50000100031/本文/第6条.md|第六条]]第一項に規定する精神保健福祉センター地域保健法（昭和二十二年法律第百一号）第五条第一項に規定する保健所医療法（昭和二十三年法律第二百五号）第一条の五第一項に規定する病院及び同条第二項に規定する診療所（入院している精神障害者のみに対して医療を提供する場所を除く。）障害者の日常生活及び社会生活を総合的に支援するための法律[[laws/323AC0000000205/本文/第5条.md|第五条]]第十八項に規定する共同生活援助を行う住居前各号に掲げるもののほか、精神障害者に対して保健医療サービス及び福祉サービスを提供する場所

- 一 精神障害者の居宅
- 二 法[[laws/325M50000100031/本文/第6条.md|第六条]]第一項に規定する精神保健福祉センター
- 三 地域保健法（昭和二十二年法律第百一号）第五条第一項に規定する保健所
- 四 医療法（昭和二十三年法律第二百五号）第一条の五第一項に規定する病院及び同条第二項に規定する診療所（入院している精神障害者のみに対して医療を提供する場所を除く。）
- 五 障害者の日常生活及び社会生活を総合的に支援するための法律[[laws/325M50000100031/本文/第5条.md|第五条]]第十八項に規定する共同生活援助を行う住居
- 六 前各号に掲げるもののほか、精神障害者に対して保健医療サービス及び福祉サービスを提供する場所
