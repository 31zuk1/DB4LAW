# 第四十五条 （所掌事務）

## 
委員会は、次に掲げる事務をつかさどる。総務大臣の諮問に応じて統計及び統計制度の発達及び改善に関する基本的事項を調査審議すること。前号に掲げる事項に関し、総務大臣に意見を述べること。[[laws/419AC0000000053/本文/第4条.md|第四条]]第四項（同条第六項において準用する場合を含む。）、[[laws/419AC0000000053/本文/第7条.md|第七条]]第一項（同条第三項において準用する場合を含む。）、[[laws/419AC0000000053/本文/第9条.md|第九条]]第四項（[[laws/419AC0000000053/本文/第11条.md|第十一条]]第二項において準用する場合を含む。）、[[laws/419AC0000000053/本文/第12条.md|第十二条]]第二項、[[laws/419AC0000000053/本文/第26条.md|第二十六条]]第三項、[[laws/419AC0000000053/本文/第28条.md|第二十八条]]第二項、[[laws/419AC0000000053/本文/第31条.md|第三十一条]]第二項、次条又は[[laws/419AC0000000053/本文/第55条.md|第五十五条]]第三項の規定により総務大臣に意見を述べること。[[laws/419AC0000000053/本文/第4条.md|第四条]]第七項の規定により総務大臣又は総務大臣を通じて関係行政機関の長に勧告すること。[[laws/419AC0000000053/本文/第6条.md|第六条]]第二項の規定により内閣総理大臣に意見を述べること。[[laws/419AC0000000053/本文/第35条.md|第三十五条]]第二項の規定により行政機関の長に意見を述べること。[[laws/419AC0000000053/本文/第55条.md|第五十五条]]第三項の規定により関係行政機関の長に意見を述べること。前各号に定めるもののほか、この法律の規定によりその権限に属させられた事項を処理すること。

- 一 総務大臣の諮問に応じて統計及び統計制度の発達及び改善に関する基本的事項を調査審議すること。
- 二 前号に掲げる事項に関し、総務大臣に意見を述べること。
- 三 [[laws/419AC0000000053/本文/第4条.md|第四条]]第四項（同条第六項において準用する場合を含む。）、[[laws/419AC0000000053/本文/第7条.md|第七条]]第一項（同条第三項において準用する場合を含む。）、[[laws/419AC0000000053/本文/第9条.md|第九条]]第四項（[[laws/419AC0000000053/本文/第11条.md|第十一条]]第二項において準用する場合を含む。）、[[laws/419AC0000000053/本文/第12条.md|第十二条]]第二項、[[laws/419AC0000000053/本文/第26条.md|第二十六条]]第三項、[[laws/419AC0000000053/本文/第28条.md|第二十八条]]第二項、[[laws/419AC0000000053/本文/第31条.md|第三十一条]]第二項、次条又は[[laws/419AC0000000053/本文/第55条.md|第五十五条]]第三項の規定により総務大臣に意見を述べること。
- 四 [[laws/419AC0000000053/本文/第4条.md|第四条]]第七項の規定により総務大臣又は総務大臣を通じて関係行政機関の長に勧告すること。
- 五 [[laws/419AC0000000053/本文/第6条.md|第六条]]第二項の規定により内閣総理大臣に意見を述べること。
- 六 [[laws/419AC0000000053/本文/第35条.md|第三十五条]]第二項の規定により行政機関の長に意見を述べること。
- 七 [[laws/419AC0000000053/本文/第55条.md|第五十五条]]第三項の規定により関係行政機関の長に意見を述べること。
- 八 前各号に定めるもののほか、この法律の規定によりその権限に属させられた事項を処理すること。
