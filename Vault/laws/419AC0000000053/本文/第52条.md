# 第五十二条 （個人情報の保護に関する法律の適用除外）

## 
個人情報（個人情報の保護に関する法律（平成十五年法律第五十七号）[[laws/419AC0000000053/本文/第2条.md|第二条]]第一項に規定する個人情報をいう。以下この条において同じ。）であって、次に掲げるものについては、同法第五章の規定は、適用しない。基幹統計調査及び一般統計調査に係る調査票情報に含まれる個人情報地方公共団体（指定地方公共団体以外の地方公共団体にあっては、当該地方公共団体の統計調査条例（地方公共団体が行う統計調査の実施及び結果の利用に関し必要な事項を定める当該地方公共団体の条例をいう。以下この号及び次号において同じ。）に[[laws/419AC0000000053/本文/第39条.md|第三十九条]]第一項（第二号に係る部分に限る。）及び第二項、[[laws/419AC0000000053/本文/第40条.md|第四十条]]第一項、[[laws/419AC0000000053/本文/第41条.md|第四十一条]]（第二号及び第四号に係る部分に限る。）、[[laws/419AC0000000053/本文/第57条.md|第五十七条]]第一項（第二号に係る部分に限る。）並びに[[laws/419AC0000000053/本文/第59条.md|第五十九条]]第一項の規定に相当する規定を設けているものに限る。）が行った統計調査に係る調査票情報（当該地方公共団体の統計調査条例の規定により当該地方公共団体以外の者に提供されたものを除く。）に含まれる個人情報地方公共団体（当該地方公共団体の統計調査条例に[[laws/419AC0000000053/本文/第42条.md|第四十二条]]第一項（第一号に係る部分に限る。）及び第二項、[[laws/419AC0000000053/本文/第43条.md|第四十三条]]、[[laws/419AC0000000053/本文/第57条.md|第五十七条]]第一項（第三号に係る部分に限る。）並びに[[laws/419AC0000000053/本文/第59条.md|第五十九条]]第二項の規定に相当する規定を設けているものに限る。）が行った統計調査に係る調査票情報（当該地方公共団体の統計調査条例の規定により当該地方公共団体以外の者に提供されたものに限る。）に含まれる個人情報指定独立行政法人等であって、個人情報の保護に関する法律[[laws/419AC0000000053/本文/第2条.md|第二条]]第九項に規定する独立行政法人等に該当するものが行った統計調査に係る調査票情報に含まれる個人情報事業所母集団データベースに記録されている情報に含まれる個人情報[[laws/419AC0000000053/本文/第29条.md|第二十九条]]第一項の規定により他の行政機関から提供を受けた行政記録情報に含まれる個人情報

- 一 基幹統計調査及び一般統計調査に係る調査票情報に含まれる個人情報
- 二 地方公共団体（指定地方公共団体以外の地方公共団体にあっては、当該地方公共団体の統計調査条例（地方公共団体が行う統計調査の実施及び結果の利用に関し必要な事項を定める当該地方公共団体の条例をいう。以下この号及び次号において同じ。）に[[laws/419AC0000000053/本文/第39条.md|第三十九条]]第一項（第二号に係る部分に限る。）及び第二項、[[laws/419AC0000000053/本文/第40条.md|第四十条]]第一項、[[laws/419AC0000000053/本文/第41条.md|第四十一条]]（第二号及び第四号に係る部分に限る。）、[[laws/419AC0000000053/本文/第57条.md|第五十七条]]第一項（第二号に係る部分に限る。）並びに[[laws/419AC0000000053/本文/第59条.md|第五十九条]]第一項の規定に相当する規定を設けているものに限る。）が行った統計調査に係る調査票情報（当該地方公共団体の統計調査条例の規定により当該地方公共団体以外の者に提供されたものを除く。）に含まれる個人情報
- 三 地方公共団体（当該地方公共団体の統計調査条例に[[laws/419AC0000000053/本文/第42条.md|第四十二条]]第一項（第一号に係る部分に限る。）及び第二項、[[laws/419AC0000000053/本文/第43条.md|第四十三条]]、[[laws/419AC0000000053/本文/第57条.md|第五十七条]]第一項（第三号に係る部分に限る。）並びに[[laws/419AC0000000053/本文/第59条.md|第五十九条]]第二項の規定に相当する規定を設けているものに限る。）が行った統計調査に係る調査票情報（当該地方公共団体の統計調査条例の規定により当該地方公共団体以外の者に提供されたものに限る。）に含まれる個人情報
- 四 指定独立行政法人等であって、個人情報の保護に関する法律[[laws/419AC0000000053/本文/第2条.md|第二条]]第九項に規定する独立行政法人等に該当するものが行った統計調査に係る調査票情報に含まれる個人情報
- 五 事業所母集団データベースに記録されている情報に含まれる個人情報
- 六 [[laws/419AC0000000053/本文/第29条.md|第二十九条]]第一項の規定により他の行政機関から提供を受けた行政記録情報に含まれる個人情報
