# 第四十一条 （守秘義務）

## 
次の各号に掲げる者は、当該各号に定める業務に関して知り得た個人又は法人その他の団体の秘密を漏らしてはならない。[[laws/419AC0000000053/本文/第39条.md|第三十九条]]第一項第一号に定める情報の取扱いに従事する行政機関の職員又は職員であった者当該情報を取り扱う業務[[laws/419AC0000000053/本文/第39条.md|第三十九条]]第一項第二号又は第三号に定める情報の取扱いに従事する地方公共団体の職員又は職員であった者当該情報を取り扱う業務[[laws/419AC0000000053/本文/第39条.md|第三十九条]]第一項第四号又は第五号に定める情報の取扱いに従事する独立行政法人等の役員若しくは職員又はこれらの職にあった者当該情報を取り扱う業務行政機関等から前三号の情報の取扱いに関する業務の委託を受けた者その他の当該委託に係る業務に従事する者又は従事していた者当該委託に係る業務地方公共団体が[[laws/419AC0000000053/本文/第16条.md|第十六条]]の規定により基幹統計調査に関する事務の一部を行うこととされた場合において、基幹統計調査に係る調査票情報、事業所母集団データベースに記録されている情報及び[[laws/419AC0000000053/本文/第29条.md|第二十九条]]第一項の規定により他の行政機関から提供を受けた行政記録情報の取扱いに従事する当該地方公共団体の職員又は職員であった者当該情報を取り扱う業務前号に規定する地方公共団体から同号の情報の取扱いに関する業務の委託を受けた者その他の当該委託に係る業務に従事する者又は従事していた者当該委託に係る業務

- 一 [[laws/419AC0000000053/本文/第39条.md|第三十九条]]第一項第一号に定める情報の取扱いに従事する行政機関の職員又は職員であった者当該情報を取り扱う業務
- 二 [[laws/419AC0000000053/本文/第39条.md|第三十九条]]第一項第二号又は第三号に定める情報の取扱いに従事する地方公共団体の職員又は職員であった者当該情報を取り扱う業務
- 三 [[laws/419AC0000000053/本文/第39条.md|第三十九条]]第一項第四号又は第五号に定める情報の取扱いに従事する独立行政法人等の役員若しくは職員又はこれらの職にあった者当該情報を取り扱う業務
- 四 行政機関等から前三号の情報の取扱いに関する業務の委託を受けた者その他の当該委託に係る業務に従事する者又は従事していた者当該委託に係る業務
- 五 地方公共団体が[[laws/419AC0000000053/本文/第16条.md|第十六条]]の規定により基幹統計調査に関する事務の一部を行うこととされた場合において、基幹統計調査に係る調査票情報、事業所母集団データベースに記録されている情報及び[[laws/419AC0000000053/本文/第29条.md|第二十九条]]第一項の規定により他の行政機関から提供を受けた行政記録情報の取扱いに従事する当該地方公共団体の職員又は職員であった者当該情報を取り扱う業務
- 六 前号に規定する地方公共団体から同号の情報の取扱いに関する業務の委託を受けた者その他の当該委託に係る業務に従事する者又は従事していた者当該委託に係る業務
