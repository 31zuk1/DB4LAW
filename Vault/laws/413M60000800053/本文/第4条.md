# 第四条 （業務方法書の記載事項）

## 
大学校に係る通則法[[laws/独立行政法人航空大学校に関する省令/本文/第28条.md|第二十八条]]第二項の主務省令で定める事項は、次のとおりとする。大学校法[[laws/独立行政法人航空大学校に関する省令/本文/第11条.md|第十一条]]第一号に規定する養成に関する事項大学校法[[laws/独立行政法人航空大学校に関する省令/本文/第11条.md|第十一条]]第二号に規定する附帯業務に関する事項業務に使用する航空機の運航及び整備に関する事項業務の委託に関する基準競争入札その他の契約に関する事項その他業務の執行に関して必要な事項

- 一 大学校法[[laws/独立行政法人航空大学校に関する省令/本文/第11条.md|第十一条]]第一号に規定する養成に関する事項
- 二 大学校法[[laws/独立行政法人航空大学校に関する省令/本文/第11条.md|第十一条]]第二号に規定する附帯業務に関する事項
- 三 業務に使用する航空機の運航及び整備に関する事項
- 四 業務の委託に関する基準
- 五 競争入札その他の契約に関する事項
- 六 その他業務の執行に関して必要な事項
