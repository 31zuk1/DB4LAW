# 第八十一条 （表示）

## 
法[[laws/特定設備検査規則/本文/第56条の6.md|第五十六条の六]]の十五第一項において準用する法[[laws/特定設備検査規則/本文/第56条の5.md|第五十六条の五]]第一項の規定により特定設備基準適合証の交付を受けた者が行う表示は、[[laws/特定設備検査規則/本文/第56条.md|第五十六条]]の例によるものとする。この場合において、「特定設備の製造業者」とあるのは「登録特定設備製造業者又は外国登録特定設備製造業者」と、「検査機関」とあるのは「特定設備基準適合証交付機関」と、「特定設備検査合格証」とあるのは「特定設備基準適合証」と読み替えるものとする。
