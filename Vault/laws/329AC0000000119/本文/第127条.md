# 第百二十七条 （不服申立て）

## 
次に掲げる処分又はその不作為については、審査請求をすることができない。[[laws/329AC0000000119/本文/第14条.md|第十四条]]第一項若しくは第三項又は[[laws/329AC0000000119/本文/第39条.md|第三十九条]]第一項の規定による認可（事業基本方針の変更に係るものを除く。）[[laws/329AC0000000119/本文/第20条.md|第二十条]]第三項（[[laws/329AC0000000119/本文/第39条.md|第三十九条]]第二項において準用する場合を含む。）の規定による通知[[laws/329AC0000000119/本文/第51条の2.md|第五十一条の二]]第一項又は[[laws/329AC0000000119/本文/第51条の10.md|第五十一条の十]]第一項の規定による認可[[laws/329AC0000000119/本文/第51条の8.md|第五十一条の八]]第三項（[[laws/329AC0000000119/本文/第51条の10.md|第五十一条の十]]第二項において準用する場合を含む。）の規定による通知都道府県又は市町村が[[laws/329AC0000000119/本文/第52条.md|第五十二条]]第一項の規定によつてする事業計画の決定（事業計画の変更を含む。）[[laws/329AC0000000119/本文/第52条.md|第五十二条]]第一項又は[[laws/329AC0000000119/本文/第55条.md|第五十五条]]第十二項の規定による認可[[laws/329AC0000000119/本文/第55条.md|第五十五条]]第四項（同条第十三項において準用する場合を含む。）の規定による通知国土交通大臣が[[laws/329AC0000000119/本文/第66条.md|第六十六条]]第一項の規定によつてする事業計画の決定（事業計画の変更を含む。）[[laws/329AC0000000119/本文/第69条.md|第六十九条]]第三項（同条第十項において準用する場合を含む。）の規定による通知[[laws/329AC0000000119/本文/第71条の2.md|第七十一条の二]]第一項又は[[laws/329AC0000000119/本文/第71条の3.md|第七十一条の三]]第十四項の規定による認可[[laws/329AC0000000119/本文/第71条の3.md|第七十一条の三]]第八項（同条第十五項において準用する場合を含む。）の規定による通知[[laws/329AC0000000119/本文/第88条.md|第八十八条]]第四項（[[laws/329AC0000000119/本文/第97条.md|第九十七条]]第三項において準用する場合を含む。）の規定による通知

- 一 [[laws/329AC0000000119/本文/第14条.md|第十四条]]第一項若しくは第三項又は[[laws/329AC0000000119/本文/第39条.md|第三十九条]]第一項の規定による認可（事業基本方針の変更に係るものを除く。）
- 二 [[laws/329AC0000000119/本文/第20条.md|第二十条]]第三項（[[laws/329AC0000000119/本文/第39条.md|第三十九条]]第二項において準用する場合を含む。）の規定による通知
- 三 [[laws/329AC0000000119/本文/第51条の2.md|第五十一条の二]]第一項又は[[laws/329AC0000000119/本文/第51条の10.md|第五十一条の十]]第一項の規定による認可
- 四 [[laws/329AC0000000119/本文/第51条の8.md|第五十一条の八]]第三項（[[laws/329AC0000000119/本文/第51条の10.md|第五十一条の十]]第二項において準用する場合を含む。）の規定による通知
- 五 都道府県又は市町村が[[laws/329AC0000000119/本文/第52条.md|第五十二条]]第一項の規定によつてする事業計画の決定（事業計画の変更を含む。）
- 六 [[laws/329AC0000000119/本文/第52条.md|第五十二条]]第一項又は[[laws/329AC0000000119/本文/第55条.md|第五十五条]]第十二項の規定による認可
- 七 [[laws/329AC0000000119/本文/第55条.md|第五十五条]]第四項（同条第十三項において準用する場合を含む。）の規定による通知
- 八 国土交通大臣が[[laws/329AC0000000119/本文/第66条.md|第六十六条]]第一項の規定によつてする事業計画の決定（事業計画の変更を含む。）
- 九 [[laws/329AC0000000119/本文/第69条.md|第六十九条]]第三項（同条第十項において準用する場合を含む。）の規定による通知
- 十 [[laws/329AC0000000119/本文/第71条の2.md|第七十一条の二]]第一項又は[[laws/329AC0000000119/本文/第71条の3.md|第七十一条の三]]第十四項の規定による認可
- 十一 [[laws/329AC0000000119/本文/第71条の3.md|第七十一条の三]]第八項（同条第十五項において準用する場合を含む。）の規定による通知
