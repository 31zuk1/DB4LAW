# 第百四十五条 

## 
次の各号のいずれかに該当する場合においては、その行為をした区画整理会社の役員又は清算人は、二十万円以下の過料に処する。[[laws/土地区画整理法/本文/第51条の10.md|第五十一条の十]]第三項、[[laws/土地区画整理法/本文/第51条の13.md|第五十一条の十三]]第三項又は[[laws/土地区画整理法/本文/第128条.md|第百二十八条]]第三項の規定に違反したとき。[[laws/土地区画整理法/本文/第84条.md|第八十四条]]第一項の規定に違反して簿書を備えず、又はその簿書に記載すべき事項を記載せず、若しくは不実の記載をしたとき。[[laws/土地区画整理法/本文/第84条.md|第八十四条]]第二項の規定に違反して正当な理由がないのに簿書の閲覧又は謄写を拒んだとき。[[laws/土地区画整理法/本文/第125条の2.md|第百二十五条の二]]第一項又は第二項の規定による都道府県知事の検査を妨げたとき。[[laws/土地区画整理法/本文/第125条の2.md|第百二十五条の二]]第三項の規定による都道府県知事の命令に違反したとき。国土交通大臣又は都道府県知事若しくは市町村長に対し、不実の申立てをし、又は事実を隠ぺいしたとき。区画整理会社がこの法律の規定による公告をすべき場合において、公告をせず、又は不実の公告をしたとき。

- 一 [[laws/土地区画整理法/本文/第51条の10.md|第五十一条の十]]第三項、[[laws/土地区画整理法/本文/第51条の13.md|第五十一条の十三]]第三項又は[[laws/土地区画整理法/本文/第128条.md|第百二十八条]]第三項の規定に違反したとき。
- 二 [[laws/土地区画整理法/本文/第84条.md|第八十四条]]第一項の規定に違反して簿書を備えず、又はその簿書に記載すべき事項を記載せず、若しくは不実の記載をしたとき。
- 三 [[laws/土地区画整理法/本文/第84条.md|第八十四条]]第二項の規定に違反して正当な理由がないのに簿書の閲覧又は謄写を拒んだとき。
- 四 [[laws/土地区画整理法/本文/第125条の2.md|第百二十五条の二]]第一項又は第二項の規定による都道府県知事の検査を妨げたとき。
- 五 [[laws/土地区画整理法/本文/第125条の2.md|第百二十五条の二]]第三項の規定による都道府県知事の命令に違反したとき。
- 六 国土交通大臣又は都道府県知事若しくは市町村長に対し、不実の申立てをし、又は事実を隠ぺいしたとき。
- 七 区画整理会社がこの法律の規定による公告をすべき場合において、公告をせず、又は不実の公告をしたとき。
