# 第百四十四条 

## 
次の各号のいずれかに該当する場合においては、その行為をした組合の理事、監事又は清算人は、二十万円以下の過料に処する。組合が土地区画整理事業以外の事業を営んだとき。[[laws/土地区画整理法/本文/第28条.md|第二十八条]]第九項の規定に違反して正当な理由がないのに帳簿及び書類の閲覧又は謄写を拒んだとき。[[laws/土地区画整理法/本文/第28条.md|第二十八条]]第十項の規定に違反したとき。[[laws/土地区画整理法/本文/第32条.md|第三十二条]]第一項（[[laws/土地区画整理法/本文/第36条.md|第三十六条]]第四項において準用する場合を含む。）又は第三項、第六項若しくは第七項（[[laws/土地区画整理法/本文/第35条.md|第三十五条]]第三項及び[[laws/土地区画整理法/本文/第36条.md|第三十六条]]第四項において準用する場合を含む。）の規定に違反したとき。[[laws/土地区画整理法/本文/第32条.md|第三十二条]]第十一項の規定に違反して書類を備えず、又はその書類に記載すべき事項を記載せず、若しくは不実の記載をしたとき。[[laws/土地区画整理法/本文/第32条.md|第三十二条]]第十二項の規定に違反して正当な理由がないのに書類の閲覧又は謄写を拒んだとき。[[laws/土地区画整理法/本文/第39条.md|第三十九条]]第三項、[[laws/土地区画整理法/本文/第45条.md|第四十五条]]第四項、[[laws/土地区画整理法/本文/第50条.md|第五十条]]第五項又は[[laws/土地区画整理法/本文/第128条.md|第百二十八条]]第三項の規定に違反したとき。[[laws/土地区画整理法/本文/第47条.md|第四十七条]]又は[[laws/土地区画整理法/本文/第49条.md|第四十九条]]に規定する書類に記載すべき事項を記載せず、又は不実の記載をしたとき。[[laws/土地区画整理法/本文/第48条.md|第四十八条]]の規定に違反して組合の残余財産を処分したとき。[[laws/土地区画整理法/本文/第84条.md|第八十四条]]第一項の規定に違反して簿書を備えず、又はその簿書に記載すべき事項を記載せず、若しくは不実の記載をしたとき。[[laws/土地区画整理法/本文/第84条.md|第八十四条]]第二項の規定に違反して正当な理由がないのに簿書の閲覧又は謄写を拒んだとき。[[laws/土地区画整理法/本文/第125条.md|第百二十五条]]第一項又は第二項の規定による都道府県知事の検査を妨げたとき。[[laws/土地区画整理法/本文/第125条.md|第百二十五条]]第三項の規定による都道府県知事の命令に違反したとき。国土交通大臣、都道府県知事若しくは市町村長又は総会、総会の部会若しくは総代会に対し、不実の申立てをし、又は事実を隠ぺいしたとき。組合がこの法律の規定による公告をすべき場合において、公告をせず、又は不実の公告をしたとき。

- 一 組合が土地区画整理事業以外の事業を営んだとき。
- 二 [[laws/土地区画整理法/本文/第28条.md|第二十八条]]第九項の規定に違反して正当な理由がないのに帳簿及び書類の閲覧又は謄写を拒んだとき。
- 三 [[laws/土地区画整理法/本文/第28条.md|第二十八条]]第十項の規定に違反したとき。
- 四 [[laws/土地区画整理法/本文/第32条.md|第三十二条]]第一項（[[laws/土地区画整理法/本文/第36条.md|第三十六条]]第四項において準用する場合を含む。）又は第三項、第六項若しくは第七項（[[laws/土地区画整理法/本文/第35条.md|第三十五条]]第三項及び[[laws/土地区画整理法/本文/第36条.md|第三十六条]]第四項において準用する場合を含む。）の規定に違反したとき。
- 五 [[laws/土地区画整理法/本文/第32条.md|第三十二条]]第十一項の規定に違反して書類を備えず、又はその書類に記載すべき事項を記載せず、若しくは不実の記載をしたとき。
- 六 [[laws/土地区画整理法/本文/第32条.md|第三十二条]]第十二項の規定に違反して正当な理由がないのに書類の閲覧又は謄写を拒んだとき。
- 七 [[laws/土地区画整理法/本文/第39条.md|第三十九条]]第三項、[[laws/土地区画整理法/本文/第45条.md|第四十五条]]第四項、[[laws/土地区画整理法/本文/第50条.md|第五十条]]第五項又は[[laws/土地区画整理法/本文/第128条.md|第百二十八条]]第三項の規定に違反したとき。
- 八 [[laws/土地区画整理法/本文/第47条.md|第四十七条]]又は[[laws/土地区画整理法/本文/第49条.md|第四十九条]]に規定する書類に記載すべき事項を記載せず、又は不実の記載をしたとき。
- 九 [[laws/土地区画整理法/本文/第48条.md|第四十八条]]の規定に違反して組合の残余財産を処分したとき。
- 十 [[laws/土地区画整理法/本文/第84条.md|第八十四条]]第一項の規定に違反して簿書を備えず、又はその簿書に記載すべき事項を記載せず、若しくは不実の記載をしたとき。
- 十一 [[laws/土地区画整理法/本文/第84条.md|第八十四条]]第二項の規定に違反して正当な理由がないのに簿書の閲覧又は謄写を拒んだとき。
- 十二 [[laws/土地区画整理法/本文/第125条.md|第百二十五条]]第一項又は第二項の規定による都道府県知事の検査を妨げたとき。
- 十三 [[laws/土地区画整理法/本文/第125条.md|第百二十五条]]第三項の規定による都道府県知事の命令に違反したとき。
- 十四 国土交通大臣、都道府県知事若しくは市町村長又は総会、総会の部会若しくは総代会に対し、不実の申立てをし、又は事実を隠ぺいしたとき。
- 十五 組合がこの法律の規定による公告をすべき場合において、公告をせず、又は不実の公告をしたとき。
