# 第三条の三 （市町村等事務の運営に関する基準）

## 
法[[laws/417AC0000000123/本文/第11条の2.md|第十一条の二]]第一項に規定する指定事務受託法人（以下「指定事務受託法人」という。）は、内閣府令・厚生労働省令で定める市町村等事務の運営に関する基準に従い、市町村等事務を行わなければならない。
