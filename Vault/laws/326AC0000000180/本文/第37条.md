# 第三十七条 

## 
次の各号のいずれかに該当する者は、三十万円以下の罰金に処する。国土調査の実施を妨げた者[[laws/326AC0000000180/本文/第22条の2.md|第二十二条の二]]、[[laws/326AC0000000180/本文/第23条.md|第二十三条]]又は[[laws/326AC0000000180/本文/第23条の5.md|第二十三条の五]]の規定により報告又は資料の提出を求められた場合において、報告若しくは資料の提出をせず、又は虚偽の記載をした報告をし、若しくは虚偽の資料の提出をした者[[laws/326AC0000000180/本文/第24条.md|第二十四条]]の規定による立入りを拒み、又は妨げた者[[laws/326AC0000000180/本文/第25条.md|第二十五条]]第一項の規定による立会い又は同条第二項の規定による出頭を拒んだ者[[laws/326AC0000000180/本文/第27条.md|第二十七条]]の規定による土地の使用の一時制限に違反し、又は土地、工作物若しくは樹木の一時使用を拒み、若しくは妨げた者[[laws/326AC0000000180/本文/第28条.md|第二十八条]]の規定による試験材料の採取収集を拒み、又は妨げた者

- 一 国土調査の実施を妨げた者
- 二 [[laws/326AC0000000180/本文/第22条の2.md|第二十二条の二]]、[[laws/326AC0000000180/本文/第23条.md|第二十三条]]又は[[laws/326AC0000000180/本文/第23条の5.md|第二十三条の五]]の規定により報告又は資料の提出を求められた場合において、報告若しくは資料の提出をせず、又は虚偽の記載をした報告をし、若しくは虚偽の資料の提出をした者
- 三 [[laws/326AC0000000180/本文/第24条.md|第二十四条]]の規定による立入りを拒み、又は妨げた者
- 四 [[laws/326AC0000000180/本文/第25条.md|第二十五条]]第一項の規定による立会い又は同条第二項の規定による出頭を拒んだ者
- 五 [[laws/326AC0000000180/本文/第27条.md|第二十七条]]の規定による土地の使用の一時制限に違反し、又は土地、工作物若しくは樹木の一時使用を拒み、若しくは妨げた者
- 六 [[laws/326AC0000000180/本文/第28条.md|第二十八条]]の規定による試験材料の採取収集を拒み、又は妨げた者
