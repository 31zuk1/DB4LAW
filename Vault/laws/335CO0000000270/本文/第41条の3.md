# 第四十一条の三 （特定小型原動機付自転車危険行為等）

## 
法[[laws/道路交通法施行令/本文/第108条の3.md|第百八条の三]]の五第一項の政令で定める行為は、特定小型原動機付自転車の運転に関し行われた次に掲げる行為とする。法[[laws/道路交通法施行令/本文/第7条.md|第七条]]（信号機の信号等に従う義務）の規定に違反する行為法[[laws/道路交通法施行令/本文/第8条.md|第八条]]（通行の禁止等）第一項の規定に違反する行為法[[laws/道路交通法施行令/本文/第9条.md|第九条]]（歩行者用道路を通行する車両の義務）の規定に違反する行為法[[laws/道路交通法施行令/本文/第17条.md|第十七条]]（通行区分）第一項、第四項又は第六項の規定に違反する行為法[[laws/道路交通法施行令/本文/第17条の2.md|第十七条の二]]（特例特定小型原動機付自転車の歩道通行）第二項の規定に違反する行為法[[laws/道路交通法施行令/本文/第17条の3.md|第十七条の三]]（特例特定小型原動機付自転車等の路側帯通行）第二項の規定に違反する行為法[[laws/道路交通法施行令/本文/第33条.md|第三十三条]]（踏切の通過）第二項の規定に違反する行為法[[laws/道路交通法施行令/本文/第36条.md|第三十六条]]（交差点における他の車両等との関係等）の規定に違反する行為法[[laws/道路交通法施行令/本文/第37条.md|第三十七条]]（交差点における他の車両等との関係等）の規定に違反する行為法[[laws/道路交通法施行令/本文/第37条の2.md|第三十七条の二]]（環状交差点における他の車両等との関係等）の規定に違反する行為法[[laws/道路交通法施行令/本文/第43条.md|第四十三条]]（指定場所における一時停止）の規定に違反する行為法[[laws/道路交通法施行令/本文/第62条.md|第六十二条]]（整備不良車両の運転の禁止）の規定に違反する行為法[[laws/道路交通法施行令/本文/第65条.md|第六十五条]]（酒気帯び運転等の禁止）第一項の規定に違反する行為法[[laws/道路交通法施行令/本文/第68条.md|第六十八条]]（共同危険行為等の禁止）の規定に違反する行為法[[laws/道路交通法施行令/本文/第70条.md|第七十条]]（安全運転の義務）の規定に違反する行為法[[laws/道路交通法施行令/本文/第71条.md|第七十一条]]（運転者の遵守事項）第五号の五の規定に違反する行為（別表第二の備考の二の１６又は２３に規定する行為に該当するものに限る。）法[[laws/道路交通法施行令/本文/第117条の2.md|第百十七条の二]]第一項第四号又は法[[laws/道路交通法施行令/本文/第117条の2.md|第百十七条の二]]の二第一項第八号の罪に当たる行為

- 一 法[[laws/道路交通法施行令/本文/第7条.md|第七条]]（信号機の信号等に従う義務）の規定に違反する行為
- 二 法[[laws/道路交通法施行令/本文/第8条.md|第八条]]（通行の禁止等）第一項の規定に違反する行為
- 三 法[[laws/道路交通法施行令/本文/第9条.md|第九条]]（歩行者用道路を通行する車両の義務）の規定に違反する行為
- 四 法[[laws/道路交通法施行令/本文/第17条.md|第十七条]]（通行区分）第一項、第四項又は第六項の規定に違反する行為
- 五 法[[laws/道路交通法施行令/本文/第17条の2.md|第十七条の二]]（特例特定小型原動機付自転車の歩道通行）第二項の規定に違反する行為
- 六 法[[laws/道路交通法施行令/本文/第17条の3.md|第十七条の三]]（特例特定小型原動機付自転車等の路側帯通行）第二項の規定に違反する行為
- 七 法[[laws/道路交通法施行令/本文/第33条.md|第三十三条]]（踏切の通過）第二項の規定に違反する行為
- 八 法[[laws/道路交通法施行令/本文/第36条.md|第三十六条]]（交差点における他の車両等との関係等）の規定に違反する行為
- 九 法[[laws/道路交通法施行令/本文/第37条.md|第三十七条]]（交差点における他の車両等との関係等）の規定に違反する行為
- 十 法[[laws/道路交通法施行令/本文/第37条の2.md|第三十七条の二]]（環状交差点における他の車両等との関係等）の規定に違反する行為
- 十一 法[[laws/道路交通法施行令/本文/第43条.md|第四十三条]]（指定場所における一時停止）の規定に違反する行為
- 十二 法[[laws/道路交通法施行令/本文/第62条.md|第六十二条]]（整備不良車両の運転の禁止）の規定に違反する行為
- 十三 法[[laws/道路交通法施行令/本文/第65条.md|第六十五条]]（酒気帯び運転等の禁止）第一項の規定に違反する行為
- 十四 法[[laws/道路交通法施行令/本文/第68条.md|第六十八条]]（共同危険行為等の禁止）の規定に違反する行為
- 十五 法[[laws/道路交通法施行令/本文/第70条.md|第七十条]]（安全運転の義務）の規定に違反する行為
- 十六 法[[laws/道路交通法施行令/本文/第71条.md|第七十一条]]（運転者の遵守事項）第五号の五の規定に違反する行為（別表第二の備考の二の１６又は２３に規定する行為に該当するものに限る。）
- 十七 法[[laws/道路交通法施行令/本文/第117条の2.md|第百十七条の二]]第一項第四号又は法[[laws/道路交通法施行令/本文/第117条の2.md|第百十七条の二]]の二第一項第八号の罪に当たる行為
