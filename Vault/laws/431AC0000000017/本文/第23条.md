# 第二十三条 

## 
次の各号のいずれかに該当する者は、五十万円以下の罰金に処する。[[laws/431AC0000000017/本文/第8条.md|第八条]]第一項の規定に違反して、同項の許可を受けなければならない行為をした者[[laws/431AC0000000017/本文/第9条.md|第九条]]第一項の規定に違反して、届出をしないで、又は虚偽の届出をして、防災工事を施行した者[[laws/431AC0000000017/本文/第9条.md|第九条]]第二項の規定による命令に違反して、防災工事を施行した者[[laws/431AC0000000017/本文/第9条.md|第九条]]第三項の規定による届出をせず、又は虚偽の届出をした者[[laws/431AC0000000017/本文/第10条.md|第十条]]第一項又は第二項の規定による命令に違反した者[[laws/431AC0000000017/本文/第18条.md|第十八条]]第一項の規定による報告をせず、若しくは虚偽の報告をし、又は同項の規定による測量若しくは調査を拒み、妨げ、若しくは忌避した者[[laws/431AC0000000017/本文/第18条.md|第十八条]]第五項の規定に違反して、土地の立入りを拒み、又は妨げた者

- 一 [[laws/431AC0000000017/本文/第8条.md|第八条]]第一項の規定に違反して、同項の許可を受けなければならない行為をした者
- 二 [[laws/431AC0000000017/本文/第9条.md|第九条]]第一項の規定に違反して、届出をしないで、又は虚偽の届出をして、防災工事を施行した者
- 三 [[laws/431AC0000000017/本文/第9条.md|第九条]]第二項の規定による命令に違反して、防災工事を施行した者
- 四 [[laws/431AC0000000017/本文/第9条.md|第九条]]第三項の規定による届出をせず、又は虚偽の届出をした者
- 五 [[laws/431AC0000000017/本文/第10条.md|第十条]]第一項又は第二項の規定による命令に違反した者
- 六 [[laws/431AC0000000017/本文/第18条.md|第十八条]]第一項の規定による報告をせず、若しくは虚偽の報告をし、又は同項の規定による測量若しくは調査を拒み、妨げ、若しくは忌避した者
- 七 [[laws/431AC0000000017/本文/第18条.md|第十八条]]第五項の規定に違反して、土地の立入りを拒み、又は妨げた者
