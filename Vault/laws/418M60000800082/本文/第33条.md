# 第三十三条 （法第三十四条第二項の国土交通省令で定める基準）

## 
法[[laws/国土交通省関係中心市街地の活性化に関する法律施行規則/本文/第34条.md|第三十四条]]第二項の国土交通省令で定める基準は、次に掲げるもののほか、住宅が賃貸住宅である場合にあっては次条から[[laws/国土交通省関係中心市街地の活性化に関する法律施行規則/本文/第42条.md|第四十二条]]まで、住宅が分譲住宅である場合にあっては[[laws/国土交通省関係中心市街地の活性化に関する法律施行規則/本文/第43条.md|第四十三条]]から[[laws/国土交通省関係中心市街地の活性化に関する法律施行規則/本文/第48条.md|第四十八条]]までに定めるとおりとする。法[[laws/国土交通省関係中心市街地の活性化に関する法律施行規則/本文/第9条.md|第九条]]第二項第四号に掲げる事項として認定基本計画に定められているものに適合するものであること。良好な住居の環境の確保その他の市街地の環境の確保又は向上に資するものであること。都市福利施設の整備と併せて建設し、又は都市福利施設と隣接し、若しくは近接するものであること。共同住宅が地階を除く階数が三以上の建築物の全部又は一部をなすものであり、かつ、当該建築物の敷地面積が三百平方メートル以上であること。住宅の戸数が、十戸以上であること。住宅の規模、構造及び設備が、次に掲げる基準に適合するものであること。各戸が床面積五十平方メートル（同居親族がない者の居住の用に供する住宅にあっては、二十五平方メートル）以上であり、かつ、二以上の居住室を有するものであること。耐火構造の住宅又は準耐火構造の住宅であること。各戸が台所、水洗便所、収納設備、洗面設備及び浴室を備えたものであること。

- 一 法[[laws/国土交通省関係中心市街地の活性化に関する法律施行規則/本文/第9条.md|第九条]]第二項第四号に掲げる事項として認定基本計画に定められているものに適合するものであること。
- 二 良好な住居の環境の確保その他の市街地の環境の確保又は向上に資するものであること。
- 三 都市福利施設の整備と併せて建設し、又は都市福利施設と隣接し、若しくは近接するものであること。
- 四 共同住宅が地階を除く階数が三以上の建築物の全部又は一部をなすものであり、かつ、当該建築物の敷地面積が三百平方メートル以上であること。
- 五 住宅の戸数が、十戸以上であること。
- 六 住宅の規模、構造及び設備が、次に掲げる基準に適合するものであること。
