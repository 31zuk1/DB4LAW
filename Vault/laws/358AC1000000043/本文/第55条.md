# 第五十五条 （聴聞の方法の特例）

## 
次に掲げる処分に係る聴聞の期日における審理は、公開により行わなければならない。[[laws/358AC1000000043/本文/第18条.md|第十八条]]第一項、第二項又は第三項の規定による認定の取消し[[laws/358AC1000000043/本文/第32条.md|第三十二条]]第二項の規定による浄化槽工事業者の登録の取消し[[laws/358AC1000000043/本文/第41条.md|第四十一条]]第二項の規定による浄化槽清掃業者の許可の取消し[[laws/358AC1000000043/本文/第42条.md|第四十二条]]第三項の規定による浄化槽設備士免状の返納命令[[laws/358AC1000000043/本文/第43条の12.md|第四十三条の十二]]（[[laws/358AC1000000043/本文/第46条の2.md|第四十六条の二]]において準用する場合を含む。）の規定による指定試験機関の指定の取消し[[laws/358AC1000000043/本文/第43条の25.md|第四十三条の二十五]]（[[laws/358AC1000000043/本文/第46条の2.md|第四十六条の二]]において準用する場合を含む。）の規定による指定講習機関の指定の取消し[[laws/358AC1000000043/本文/第45条.md|第四十五条]]第三項の規定による浄化槽管理士免状の返納命令

- 六 [[laws/358AC1000000043/本文/第43条の25.md|第四十三条の二十五]]（[[laws/358AC1000000043/本文/第46条の2.md|第四十六条の二]]において準用する場合を含む。）の規定による指定講習機関の指定の取消し
