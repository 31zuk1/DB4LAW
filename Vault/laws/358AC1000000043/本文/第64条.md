# 第六十四条 

## 
次の各号のいずれかに該当する者は、三十万円以下の罰金に処する。[[laws/浄化槽法/本文/第5条.md|第五条]]第四項の規定に違反して浄化槽工事を施工した者[[laws/浄化槽法/本文/第10条.md|第十条]]第二項の規定に違反して技術管理者を置かなかつた者[[laws/浄化槽法/本文/第12条の8.md|第十二条の八]]第三項（[[laws/浄化槽法/本文/第12条の10.md|第十二条の十]]第二項において準用する場合を含む。）の規定による命令に違反した者[[laws/浄化槽法/本文/第12条の10.md|第十二条の十]]第一項の規定に違反して承認を受けないで排水設備を設置した者[[laws/浄化槽法/本文/第12条の12.md|第十二条の十二]]第一項の規定による検査を拒み、妨げ、又は忌避した者[[laws/浄化槽法/本文/第12条の15.md|第十二条の十五]]第六項の規定に違反して土地の立入りを拒み、又は妨げた者[[laws/浄化槽法/本文/第12条の16.md|第十二条の十六]]第一項の規定に違反して排水設備の使用を廃止した者[[laws/浄化槽法/本文/第17条.md|第十七条]]第一項の規定に違反して表示を付さなかつた者[[laws/浄化槽法/本文/第17条.md|第十七条]]第二項の規定に違反して表示を付した者[[laws/浄化槽法/本文/第29条.md|第二十九条]]第二項の規定に違反して措置をとらなかつた者[[laws/浄化槽法/本文/第29条.md|第二十九条]]第三項の規定に違反して浄化槽工事を行つた者[[laws/浄化槽法/本文/第31条.md|第三十一条]]又は[[laws/浄化槽法/本文/第40条.md|第四十条]]の規定に違反して帳簿を備えず、帳簿に記載せず、若しくは虚偽の記載をし、又は帳簿を保存しなかつた者[[laws/浄化槽法/本文/第43条.md|第四十三条]]第五項又は[[laws/浄化槽法/本文/第46条.md|第四十六条]]第五項の規定に違反して故意に不正の採点をした者[[laws/浄化槽法/本文/第44条.md|第四十四条]]又は[[laws/浄化槽法/本文/第47条.md|第四十七条]]の規定に違反した者[[laws/浄化槽法/本文/第53条.md|第五十三条]]第一項（第七号又は第八号に係る部分を除く。）の規定による報告をせず、又は虚偽の報告をした者[[laws/浄化槽法/本文/第53条.md|第五十三条]]第二項（同条第一項第七号又は第八号に掲げる者に係る部分を除く。以下この号において同じ。）の規定による検査を拒み、妨げ、若しくは忌避し、又は同条第二項の規定による質問に対して答弁をせず、若しくは虚偽の答弁をした者

- 一 [[laws/浄化槽法/本文/第5条.md|第五条]]第四項の規定に違反して浄化槽工事を施工した者
- 二 [[laws/浄化槽法/本文/第10条.md|第十条]]第二項の規定に違反して技術管理者を置かなかつた者
- 三 [[laws/浄化槽法/本文/第12条の8.md|第十二条の八]]第三項（[[laws/浄化槽法/本文/第12条の10.md|第十二条の十]]第二項において準用する場合を含む。）の規定による命令に違反した者
- 四 [[laws/浄化槽法/本文/第12条の10.md|第十二条の十]]第一項の規定に違反して承認を受けないで排水設備を設置した者
- 五 [[laws/浄化槽法/本文/第12条の12.md|第十二条の十二]]第一項の規定による検査を拒み、妨げ、又は忌避した者
- 六 [[laws/浄化槽法/本文/第12条の15.md|第十二条の十五]]第六項の規定に違反して土地の立入りを拒み、又は妨げた者
- 七 [[laws/浄化槽法/本文/第12条の16.md|第十二条の十六]]第一項の規定に違反して排水設備の使用を廃止した者
- 八 [[laws/浄化槽法/本文/第17条.md|第十七条]]第一項の規定に違反して表示を付さなかつた者
- 九 [[laws/浄化槽法/本文/第17条.md|第十七条]]第二項の規定に違反して表示を付した者
- 十 [[laws/浄化槽法/本文/第29条.md|第二十九条]]第二項の規定に違反して措置をとらなかつた者
- 十一 [[laws/浄化槽法/本文/第29条.md|第二十九条]]第三項の規定に違反して浄化槽工事を行つた者
- 十二 [[laws/浄化槽法/本文/第31条.md|第三十一条]]又は[[laws/浄化槽法/本文/第40条.md|第四十条]]の規定に違反して帳簿を備えず、帳簿に記載せず、若しくは虚偽の記載をし、又は帳簿を保存しなかつた者
- 十三 [[laws/浄化槽法/本文/第43条.md|第四十三条]]第五項又は[[laws/浄化槽法/本文/第46条.md|第四十六条]]第五項の規定に違反して故意に不正の採点をした者
- 十四 [[laws/浄化槽法/本文/第44条.md|第四十四条]]又は[[laws/浄化槽法/本文/第47条.md|第四十七条]]の規定に違反した者
- 十五 [[laws/浄化槽法/本文/第53条.md|第五十三条]]第一項（第七号又は第八号に係る部分を除く。）の規定による報告をせず、又は虚偽の報告をした者
- 十六 [[laws/浄化槽法/本文/第53条.md|第五十三条]]第二項（同条第一項第七号又は第八号に掲げる者に係る部分を除く。以下この号において同じ。）の規定による検査を拒み、妨げ、若しくは忌避し、又は同条第二項の規定による質問に対して答弁をせず、若しくは虚偽の答弁をした者
