# 第二十七条 （無形固定資産の範囲）

## 
次に掲げる資産は、無形固定資産に属するものとする。借地権地上権特許権ソフトウェアリース資産（有価証券発行学校法人がファイナンス・リース取引におけるリース物件の借主である資産であって当該リース物件が前各号及び次号に掲げるものである場合に限る。）その他の無形資産であって流動資産又は投資である資産に属しないもの

- 一 借地権
- 二 地上権
- 三 特許権
- 四 ソフトウェア
- 五 リース資産（有価証券発行学校法人がファイナンス・リース取引におけるリース物件の借主である資産であって当該リース物件が前各号及び次号に掲げるものである場合に限る。）
- 六 その他の無形資産であって流動資産又は投資である資産に属しないもの
