# 第六十四条 （支給停止）

## 
遺族厚生年金は、当該被保険者又は被保険者であつた者の死亡について労働基準法[[laws/厚生年金保険法/本文/第79条.md|第七十九条]]の規定による遺族補償の支給が行われるべきものであるときは、死亡の日から六年間、その支給を停止する。
