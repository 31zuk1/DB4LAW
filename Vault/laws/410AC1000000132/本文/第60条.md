# 第六十条 （機構の業務の特例）

## 
機構は、預金保険法[[laws/410AC1000000132/本文/第34条.md|第三十四条]]に規定する業務のほか、[[laws/410AC1000000132/本文/第1条.md|第一条]]の目的を達成するため、次の業務を行うことができる。[[laws/410AC1000000132/本文/第29条.md|第二十九条]]第一項の規定により承継銀行となる株式会社の設立の発起人となり、及び設立のための出資を行い、並びに同条第二項の規定により承継銀行に対し出資を行うこと。[[laws/410AC1000000132/本文/第30条.md|第三十条]]第一項の規定により承継銀行の経営管理を行うこと。[[laws/410AC1000000132/本文/第32条.md|第三十二条]]第一項の規定により承継銀行と協定を締結すること。[[laws/410AC1000000132/本文/第33条.md|第三十三条]]第一項の規定により協定承継銀行に対し資金の貸付け又は債務の保証を行うこと。[[laws/410AC1000000132/本文/第34条.md|第三十四条]]の規定により協定承継銀行に対しその業務の実施により生じた損失の補てんを行うこと。[[laws/410AC1000000132/本文/第39条.md|第三十九条]]第一項の規定により特別公的管理銀行の株式を取得すること。[[laws/410AC1000000132/本文/第45条.md|第四十五条]]の規定により特別公的管理銀行の取締役及び監査役を選任し、又は解任すること。[[laws/410AC1000000132/本文/第53条.md|第五十三条]]第一項に規定する業務を行うこと。次条の規定により特別公的管理銀行に対しその業務に必要な資金の貸付けを行うこと。[[laws/410AC1000000132/本文/第62条.md|第六十二条]]の規定により特別公的管理銀行に対しその業務の実施により生じた損失の補てんを行うこと。[[laws/410AC1000000132/本文/第63条.md|第六十三条]]の規定により破綻金融機関（預金保険法[[laws/410AC1000000132/本文/第2条.md|第二条]]第四項に規定する破綻金融機関をいう。[[laws/410AC1000000132/本文/第63条.md|第六十三条]]において同じ。）、承継銀行又は特別公的管理銀行（[[laws/410AC1000000132/本文/第62条.md|第六十二条]]の規定による損失の補てん又は[[laws/410AC1000000132/本文/第72条.md|第七十二条]]の規定による特例資金援助を受けた特別公的管理銀行に限る。[[laws/410AC1000000132/本文/第63条.md|第六十三条]]において同じ。）の営業若しくは事業を譲り受け、若しくはその株式を譲り受ける金融機関の発行する株式その他政令で定める有価証券（以下「株式等」という。）の引受けを行い、又は当該金融機関に対する劣後特約付金銭消費貸借（元利金の支払について劣後的内容を有する特約が付された金銭の消費貸借であって、内閣府令で定めるものをいう。[[laws/410AC1000000132/本文/第63条.md|第六十三条]]において同じ。）による貸付けを行うこと。前各号の業務に附帯する業務を行うこと。

- 一 [[laws/410AC1000000132/本文/第29条.md|第二十九条]]第一項の規定により承継銀行となる株式会社の設立の発起人となり、及び設立のための出資を行い、並びに同条第二項の規定により承継銀行に対し出資を行うこと。
- 二 [[laws/410AC1000000132/本文/第30条.md|第三十条]]第一項の規定により承継銀行の経営管理を行うこと。
- 三 [[laws/410AC1000000132/本文/第32条.md|第三十二条]]第一項の規定により承継銀行と協定を締結すること。
- 四 [[laws/410AC1000000132/本文/第33条.md|第三十三条]]第一項の規定により協定承継銀行に対し資金の貸付け又は債務の保証を行うこと。
- 五 [[laws/410AC1000000132/本文/第34条.md|第三十四条]]の規定により協定承継銀行に対しその業務の実施により生じた損失の補てんを行うこと。
- 六 [[laws/410AC1000000132/本文/第39条.md|第三十九条]]第一項の規定により特別公的管理銀行の株式を取得すること。
- 七 [[laws/410AC1000000132/本文/第45条.md|第四十五条]]の規定により特別公的管理銀行の取締役及び監査役を選任し、又は解任すること。
- 八 [[laws/410AC1000000132/本文/第53条.md|第五十三条]]第一項に規定する業務を行うこと。
- 九 次条の規定により特別公的管理銀行に対しその業務に必要な資金の貸付けを行うこと。
- 十 [[laws/410AC1000000132/本文/第62条.md|第六十二条]]の規定により特別公的管理銀行に対しその業務の実施により生じた損失の補てんを行うこと。
- 十一 [[laws/410AC1000000132/本文/第63条.md|第六十三条]]の規定により破綻金融機関（預金保険法[[laws/410AC1000000132/本文/第2条.md|第二条]]第四項に規定する破綻金融機関をいう。[[laws/410AC1000000132/本文/第63条.md|第六十三条]]において同じ。）、承継銀行又は特別公的管理銀行（[[laws/410AC1000000132/本文/第62条.md|第六十二条]]の規定による損失の補てん又は[[laws/410AC1000000132/本文/第72条.md|第七十二条]]の規定による特例資金援助を受けた特別公的管理銀行に限る。[[laws/410AC1000000132/本文/第63条.md|第六十三条]]において同じ。）の営業若しくは事業を譲り受け、若しくはその株式を譲り受ける金融機関の発行する株式その他政令で定める有価証券（以下「株式等」という。）の引受けを行い、又は当該金融機関に対する劣後特約付金銭消費貸借（元利金の支払について劣後的内容を有する特約が付された金銭の消費貸借であって、内閣府令で定めるものをいう。[[laws/410AC1000000132/本文/第63条.md|第六十三条]]において同じ。）による貸付けを行うこと。
- 十二 前各号の業務に附帯する業務を行うこと。
