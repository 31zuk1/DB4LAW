# 第八十一条 

## 
[[laws/金融機能の再生のための緊急措置に関する法律/本文/第17条.md|第十七条]]の規定に違反してその職務上知ることのできた秘密を漏らした者は、一年以下の拘禁刑又は五十万円以下の罰金に処する。
