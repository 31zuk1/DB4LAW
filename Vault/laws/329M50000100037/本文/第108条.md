# 第百八条 （地方厚生局長等への権限の委任）

## 
法[[laws/329AC0000000115/本文/第100条の9.md|第百条の九]]第一項の規定により、次の各号に掲げる厚生労働大臣の権限は、地方厚生局長に委任する。ただし、厚生労働大臣が当該権限を自ら行うことを妨げない。法[[laws/329M50000100037/本文/第89条.md|第八十九条]]の規定によりその例によるものとされる国税通則法[[laws/329M50000100037/本文/第46条.md|第四十六条]]の規定による納付の猶予法[[laws/329M50000100037/本文/第89条.md|第八十九条]]の規定によりその例によるものとされる国税通則法[[laws/329M50000100037/本文/第49条.md|第四十九条]]の規定による納付の猶予の取消し法[[laws/329AC0000000115/本文/第100条の2.md|第百条の二]]第二項の規定による資料の提供の求め（訂正請求に係るものに限る。）並びに同条第五項の規定による資料の提供の求め及び報告の求め（訂正請求に係るものに限る。）法[[laws/329AC0000000115/本文/第100条の4.md|第百条の四]]第三項の規定により厚生労働大臣が同条第一項各号に掲げる権限の全部又は一部を自ら行うこととした場合における当該権限法[[laws/329AC0000000115/本文/第100条の4.md|第百条の四]]第四項の規定による公示法[[laws/329AC0000000115/本文/第100条の4.md|第百条の四]]第五項の規定による通知法[[laws/329AC0000000115/本文/第100条の6.md|第百条の六]]第一項及び第二項の規定による認可法[[laws/329AC0000000115/本文/第100条の6.md|第百条の六]]第三項の規定による報告の受理法[[laws/329AC0000000115/本文/第100条の8.md|第百条の八]]第一項の規定による認可法[[laws/329AC0000000115/本文/第100条の10.md|第百条の十]]第二項の規定により厚生労働大臣が同条第一項各号に掲げる事務の全部又は一部を自ら行うこととした場合における当該権限法[[laws/329AC0000000115/本文/第100条の11.md|第百条の十一]]第二項の規定による認可法[[laws/329AC0000000115/本文/第100条の11.md|第百条の十一]]第四項の規定による報告の受理

- 一 法[[laws/329M50000100037/本文/第89条.md|第八十九条]]の規定によりその例によるものとされる国税通則法[[laws/329M50000100037/本文/第46条.md|第四十六条]]の規定による納付の猶予
- 二 法[[laws/329M50000100037/本文/第89条.md|第八十九条]]の規定によりその例によるものとされる国税通則法[[laws/329M50000100037/本文/第49条.md|第四十九条]]の規定による納付の猶予の取消し
- 三 法[[laws/329AC0000000115/本文/第100条の2.md|第百条の二]]第二項の規定による資料の提供の求め（訂正請求に係るものに限る。）並びに同条第五項の規定による資料の提供の求め及び報告の求め（訂正請求に係るものに限る。）
- 四 法[[laws/329AC0000000115/本文/第100条の4.md|第百条の四]]第三項の規定により厚生労働大臣が同条第一項各号に掲げる権限の全部又は一部を自ら行うこととした場合における当該権限
- 五 法[[laws/329AC0000000115/本文/第100条の4.md|第百条の四]]第四項の規定による公示
- 六 法[[laws/329AC0000000115/本文/第100条の4.md|第百条の四]]第五項の規定による通知
- 七 法[[laws/329AC0000000115/本文/第100条の6.md|第百条の六]]第一項及び第二項の規定による認可
- 八 法[[laws/329AC0000000115/本文/第100条の6.md|第百条の六]]第三項の規定による報告の受理
- 九 法[[laws/329AC0000000115/本文/第100条の8.md|第百条の八]]第一項の規定による認可
- 十 法[[laws/329AC0000000115/本文/第100条の10.md|第百条の十]]第二項の規定により厚生労働大臣が同条第一項各号に掲げる事務の全部又は一部を自ら行うこととした場合における当該権限
- 十一 法[[laws/329AC0000000115/本文/第100条の11.md|第百条の十一]]第二項の規定による認可
- 十二 法[[laws/329AC0000000115/本文/第100条の11.md|第百条の十一]]第四項の規定による報告の受理
## ２
法[[laws/329AC0000000115/本文/第100条の9.md|第百条の九]]第二項の規定により、前項各号に掲げる権限のうち地方厚生支局の管轄区域に係るものは、地方厚生支局長に委任する。ただし、地方厚生局長が当該権限を自ら行うことを妨げない。
