# 第百十一条 （法第百条の十第一項第三十九号に規定する厚生労働省令で定める事務）

## 
法[[laws/厚生年金保険法施行規則/本文/第100条の10.md|第百条の十]]第一項第三十九号に規定する厚生労働省令で定める事務は、次に掲げる事務とする。[[laws/厚生年金保険法施行規則/本文/第32条の3.md|第三十二条の三]]第三項の規定による届書及び書類の提出の求めに係る事務、[[laws/厚生年金保険法施行規則/本文/第35条.md|第三十五条]]第一項、[[laws/厚生年金保険法施行規則/本文/第51条.md|第五十一条]]第一項及び[[laws/厚生年金保険法施行規則/本文/第68条.md|第六十八条]]第一項の規定による確認に係る事務、[[laws/厚生年金保険法施行規則/本文/第35条.md|第三十五条]]第二項及び第三項、[[laws/厚生年金保険法施行規則/本文/第51条.md|第五十一条]]第二項及び第三項並びに[[laws/厚生年金保険法施行規則/本文/第68条.md|第六十八条]]第二項及び第三項の規定による報告及び書類の提出の求めに係る事務並びに[[laws/厚生年金保険法施行規則/本文/第35条の2.md|第三十五条の二]]第三項、[[laws/厚生年金保険法施行規則/本文/第40条の2.md|第四十条の二]]第三項、[[laws/厚生年金保険法施行規則/本文/第51条の2.md|第五十一条の二]]第三項、[[laws/厚生年金保険法施行規則/本文/第56条の2.md|第五十六条の二]]第三項、[[laws/厚生年金保険法施行規則/本文/第68条の2.md|第六十八条の二]]第三項及び[[laws/厚生年金保険法施行規則/本文/第73条の2.md|第七十三条の二]]第三項の規定による書類の提出の求めに係る事務[[laws/厚生年金保険法施行規則/本文/第32条の3.md|第三十二条の三]]第三項の規定による指定に係る事務[[laws/厚生年金保険法施行規則/本文/第35条の2.md|第三十五条の二]]第一項、[[laws/厚生年金保険法施行規則/本文/第51条の2.md|第五十一条の二]]第一項及び[[laws/厚生年金保険法施行規則/本文/第68条の2.md|第六十八条の二]]第一項の規定による届書の提出の求めに係る事務[[laws/厚生年金保険法施行規則/本文/第60条の3.md|第六十条の三]]の規定による裁定等の請求の求めに係る事務[[laws/厚生年金保険法施行規則/本文/第81条.md|第八十一条]]の規定による基礎年金番号通知書の作成及び交付に係る事務[[laws/厚生年金保険法施行規則/本文/第82条.md|第八十二条]]第一項の規定による通知に係る事務（当該通知を除く。）[[laws/厚生年金保険法施行規則/本文/第86条.md|第八十六条]]の規定による年金証書の作成及び交付に係る事務[[laws/厚生年金保険法施行規則/本文/第87条.md|第八十七条]]第三項及び第六項から第八項までの規定による添付書類の省略に係る事務住民基本台帳法[[laws/住民基本台帳法/本文/第30条の9.md|第三十条の九]]の規定による機構保存本人確認情報の提供を受けることに係る事務厚生年金保険法等の一部を改正する法律の施行に伴う国家公務員共済組合法による長期給付等に関する経過措置に関する政令（平成九年政令第八十六号）[[laws/住民基本台帳法/本文/第4条.md|第四条]]第八項又は[[laws/住民基本台帳法/本文/第29条.md|第二十九条]]第六項の規定による求めに応じた資料の提供に係る事務（当該資料の提供を除く。）厚生年金保険制度及び農林漁業団体職員共済組合制度の統合を図るための農林漁業団体職員共済組合法等を廃止する等の法律の施行に伴う存続組合が支給する特例年金等に関する政令（平成十四年政令第四十五号）[[laws/住民基本台帳法/本文/第28条.md|第二十八条]]第三項の規定による求めに応じた資料の提供に係る事務（当該資料の提供を除く。）番号利用法[[laws/厚生年金保険法施行規則/本文/第22条.md|第二十二条]]第一項の規定による利用特定個人情報（番号利用法[[laws/厚生年金保険法施行規則/本文/第19条.md|第十九条]]第八号に規定する利用特定個人情報をいう。）の提供を受けることに係る事務

- 一 [[laws/厚生年金保険法施行規則/本文/第32条の3.md|第三十二条の三]]第三項の規定による届書及び書類の提出の求めに係る事務、[[laws/厚生年金保険法施行規則/本文/第35条.md|第三十五条]]第一項、[[laws/厚生年金保険法施行規則/本文/第51条.md|第五十一条]]第一項及び[[laws/厚生年金保険法施行規則/本文/第68条.md|第六十八条]]第一項の規定による確認に係る事務、[[laws/厚生年金保険法施行規則/本文/第35条.md|第三十五条]]第二項及び第三項、[[laws/厚生年金保険法施行規則/本文/第51条.md|第五十一条]]第二項及び第三項並びに[[laws/厚生年金保険法施行規則/本文/第68条.md|第六十八条]]第二項及び第三項の規定による報告及び書類の提出の求めに係る事務並びに[[laws/厚生年金保険法施行規則/本文/第35条の2.md|第三十五条の二]]第三項、[[laws/厚生年金保険法施行規則/本文/第40条の2.md|第四十条の二]]第三項、[[laws/厚生年金保険法施行規則/本文/第51条の2.md|第五十一条の二]]第三項、[[laws/厚生年金保険法施行規則/本文/第56条の2.md|第五十六条の二]]第三項、[[laws/厚生年金保険法施行規則/本文/第68条の2.md|第六十八条の二]]第三項及び[[laws/厚生年金保険法施行規則/本文/第73条の2.md|第七十三条の二]]第三項の規定による書類の提出の求めに係る事務
- 一の二 [[laws/厚生年金保険法施行規則/本文/第32条の3.md|第三十二条の三]]第三項の規定による指定に係る事務
- 二 [[laws/厚生年金保険法施行規則/本文/第35条の2.md|第三十五条の二]]第一項、[[laws/厚生年金保険法施行規則/本文/第51条の2.md|第五十一条の二]]第一項及び[[laws/厚生年金保険法施行規則/本文/第68条の2.md|第六十八条の二]]第一項の規定による届書の提出の求めに係る事務
- 三 [[laws/厚生年金保険法施行規則/本文/第60条の3.md|第六十条の三]]の規定による裁定等の請求の求めに係る事務
- 四 [[laws/厚生年金保険法施行規則/本文/第81条.md|第八十一条]]の規定による基礎年金番号通知書の作成及び交付に係る事務
- 五 [[laws/厚生年金保険法施行規則/本文/第82条.md|第八十二条]]第一項の規定による通知に係る事務（当該通知を除く。）
- 六 [[laws/厚生年金保険法施行規則/本文/第86条.md|第八十六条]]の規定による年金証書の作成及び交付に係る事務
- 七 [[laws/厚生年金保険法施行規則/本文/第87条.md|第八十七条]]第三項及び第六項から第八項までの規定による添付書類の省略に係る事務
- 八 住民基本台帳法第三十条の九の規定による機構保存本人確認情報の提供を受けることに係る事務
- 九 厚生年金保険法等の一部を改正する法律の施行に伴う国家公務員共済組合法による長期給付等に関する経過措置に関する政令（平成九年政令第八十六号）[[laws/厚生年金保険法施行規則/本文/第4条.md|第四条]]第八項又は[[laws/厚生年金保険法施行規則/本文/第29条.md|第二十九条]]第六項の規定による求めに応じた資料の提供に係る事務（当該資料の提供を除く。）
- 十 厚生年金保険制度及び農林漁業団体職員共済組合制度の統合を図るための農林漁業団体職員共済組合法等を廃止する等の法律の施行に伴う存続組合が支給する特例年金等に関する政令（平成十四年政令第四十五号）[[laws/厚生年金保険法施行規則/本文/第28条.md|第二十八条]]第三項の規定による求めに応じた資料の提供に係る事務（当該資料の提供を除く。）
- 十一 番号利用法[[laws/厚生年金保険法施行規則/本文/第22条.md|第二十二条]]第一項の規定による利用特定個人情報（番号利用法[[laws/厚生年金保険法施行規則/本文/第19条.md|第十九条]]第八号に規定する利用特定個人情報をいう。）の提供を受けることに係る事務
