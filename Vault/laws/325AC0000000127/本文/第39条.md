# 第三十九条 

## 
次の各号のいずれかに該当する者は、三十万円以下の罰金に処する。[[laws/325AC0000000127/本文/第11条.md|第十一条]]の規定に違反した者[[laws/325AC0000000127/本文/第13条.md|第十三条]]第三項の規定による届出若しくは申請をせず、又は虚偽の届出をした者[[laws/325AC0000000127/本文/第22条の3.md|第二十二条の三]]第三項の規定による命令に違反した者[[laws/325AC0000000127/本文/第27条.md|第二十七条]]第一項又は第二項の規定に違反して、帳簿を備え付けず、記載をせず、又は虚偽の記載をした者[[laws/325AC0000000127/本文/第29条.md|第二十九条]]第一項（[[laws/325AC0000000127/本文/第33条の2.md|第三十三条の二]]第六項において準用する場合を含む。）、第二項又は第三項の規定による命令に対し報告をせず、又は虚偽の報告をした者[[laws/325AC0000000127/本文/第30条.md|第三十条]]第一項若しくは第三項若しくは[[laws/325AC0000000127/本文/第30条の2.md|第三十条の二]]第一項の規定による立入り、検査若しくは収去を拒み、妨げ、若しくは忌避し、又はこれらの規定による質問に対し答弁をせず、若しくは虚偽の答弁をした者[[laws/325AC0000000127/本文/第30条.md|第三十条]]第二項若しくは[[laws/325AC0000000127/本文/第33条の3.md|第三十三条の三]]第一項若しくは第二項の規定による立入り若しくは検査を拒み、妨げ、若しくは忌避し、又はこれらの規定による質問に対し答弁をせず、若しくは虚偽の答弁をした者

- 一 [[laws/325AC0000000127/本文/第11条.md|第十一条]]の規定に違反した者
- 二 [[laws/325AC0000000127/本文/第13条.md|第十三条]]第三項の規定による届出若しくは申請をせず、又は虚偽の届出をした者
- 三 [[laws/325AC0000000127/本文/第22条の3.md|第二十二条の三]]第三項の規定による命令に違反した者
- 四 [[laws/325AC0000000127/本文/第27条.md|第二十七条]]第一項又は第二項の規定に違反して、帳簿を備え付けず、記載をせず、又は虚偽の記載をした者
- 五 [[laws/325AC0000000127/本文/第29条.md|第二十九条]]第一項（[[laws/325AC0000000127/本文/第33条の2.md|第三十三条の二]]第六項において準用する場合を含む。）、第二項又は第三項の規定による命令に対し報告をせず、又は虚偽の報告をした者
- 六 [[laws/325AC0000000127/本文/第30条.md|第三十条]]第一項若しくは第三項若しくは[[laws/325AC0000000127/本文/第30条の2.md|第三十条の二]]第一項の規定による立入り、検査若しくは収去を拒み、妨げ、若しくは忌避し、又はこれらの規定による質問に対し答弁をせず、若しくは虚偽の答弁をした者
- 七 [[laws/325AC0000000127/本文/第30条.md|第三十条]]第二項若しくは[[laws/325AC0000000127/本文/第33条の3.md|第三十三条の三]]第一項若しくは第二項の規定による立入り若しくは検査を拒み、妨げ、若しくは忌避し、又はこれらの規定による質問に対し答弁をせず、若しくは虚偽の答弁をした者
