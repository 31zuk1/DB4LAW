# 第五十一条 （私学行政課の所掌事務）

## 
私学行政課は、次に掲げる事務をつかさどる。私学部の所掌事務に関する総合調整に関すること。私立学校に関する行政の制度の企画及び立案並びにこれらの行政の組織及び一般的運営に関する指導、助言及び勧告に関すること（参事官の所掌に属するものを除く。）。文部科学大臣が所轄庁である学校法人についての認可及び認定に関すること。私立学校教職員の共済制度に関すること。大学設置・学校法人審議会学校法人分科会の庶務に関すること。前各号に掲げるもののほか、私学部の所掌事務で他の所掌に属しないものに関すること。

- 一 私学部の所掌事務に関する総合調整に関すること。
- 二 私立学校に関する行政の制度の企画及び立案並びにこれらの行政の組織及び一般的運営に関する指導、助言及び勧告に関すること（参事官の所掌に属するものを除く。）。
- 三 文部科学大臣が所轄庁である学校法人についての認可及び認定に関すること。
- 四 私立学校教職員の共済制度に関すること。
- 五 大学設置・学校法人審議会学校法人分科会の庶務に関すること。
- 六 前各号に掲げるもののほか、私学部の所掌事務で他の所掌に属しないものに関すること。
