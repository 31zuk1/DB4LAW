# 附則

## １
この省令は、公布の日から施行する。

## ２
次に掲げる省令の規定は、令和四年三月三十一日以後に終了する事業年度に係る会計監査報告について適用し、同日前に終了する事業年度に係る会計監査報告については、なお従前の例による。略第六条の規定による改正後の独立行政法人労働者健康安全機構の業務運営、財務及び会計並びに人事管理に関する省令第十三条の二

- 一から五まで 略
- 六 第六条の規定による改正後の独立行政法人労働者健康安全機構の業務運営、財務及び会計並びに人事管理に関する省令第十三条の二
