# 第一条の四 （業務方法書の記載事項）

## 
機構に係る通則法[[laws/416M60000100056/独立行政法人労働者健康安全機構の業務運営_law.md|第二十八条]]第二項の主務省令で定める事項は、次のとおりとする。機構法[[laws/416M60000100056/本文/第12条.md|第十二条]]第一項第一号に規定する療養施設の設置及び運営に関する事項機構法[[laws/416M60000100056/本文/第12条.md|第十二条]]第一項第二号に規定する施設の設置及び運営に関する事項機構法[[laws/416M60000100056/本文/第12条.md|第十二条]]第一項第三号に規定する調査及び研究に関する事項機構法[[laws/416M60000100056/本文/第12条.md|第十二条]]第一項第四号に規定する調査に関する事項機構法[[laws/416M60000100056/本文/第12条.md|第十二条]]第一項第五号に規定する成果の普及に関する事項機構法[[laws/416M60000100056/本文/第12条.md|第十二条]]第一項第六号に規定する賃金の支払の確保等に関する法律（昭和五十一年法律第三十四号）第三章に規定する事業の実施に関する事項機構法[[laws/416M60000100056/本文/第12条.md|第十二条]]第一項第七号に規定する納骨堂の設置及び運営に関する事項機構法[[laws/416M60000100056/本文/第12条.md|第十二条]]第一項第八号に規定する給付金の支払及び追加給付金の支払に関する事項機構法[[laws/416M60000100056/本文/第12条.md|第十二条]]第二項に規定する調査及び立入検査に関する事項機構法[[laws/416M60000100056/本文/第12条.md|第十二条]]第三項に規定する検診の受託に関する事項業務委託の基準競争入札その他契約に関する基本的事項その他機構の業務の執行に関して必要な事項

- 一 機構法[[laws/416M60000100056/本文/第12条.md|第十二条]]第一項第一号に規定する療養施設の設置及び運営に関する事項
- 二 機構法[[laws/416M60000100056/本文/第12条.md|第十二条]]第一項第二号に規定する施設の設置及び運営に関する事項
- 三 機構法[[laws/416M60000100056/本文/第12条.md|第十二条]]第一項第三号に規定する調査及び研究に関する事項
- 四 機構法[[laws/416M60000100056/本文/第12条.md|第十二条]]第一項第四号に規定する調査に関する事項
- 五 機構法[[laws/416M60000100056/本文/第12条.md|第十二条]]第一項第五号に規定する成果の普及に関する事項
- 六 機構法[[laws/416M60000100056/本文/第12条.md|第十二条]]第一項第六号に規定する賃金の支払の確保等に関する法律（昭和五十一年法律第三十四号）第三章に規定する事業の実施に関する事項
- 七 機構法[[laws/416M60000100056/本文/第12条.md|第十二条]]第一項第七号に規定する納骨堂の設置及び運営に関する事項
- 八 機構法[[laws/416M60000100056/本文/第12条.md|第十二条]]第一項第八号に規定する給付金の支払及び追加給付金の支払に関する事項
- 九 機構法[[laws/416M60000100056/本文/第12条.md|第十二条]]第二項に規定する調査及び立入検査に関する事項
- 十 機構法[[laws/416M60000100056/本文/第12条.md|第十二条]]第三項に規定する検診の受託に関する事項
- 十一 業務委託の基準
- 十二 競争入札その他契約に関する基本的事項
- 十三 その他機構の業務の執行に関して必要な事項
