# 第百十二条 （免許等に関する手数料）

## 
都道府県は、第六章（[[laws/335AC0000000105/本文/第105条の2.md|第百五条の二]]第二項及び第四項を除く。）及び第六章の二の規定により公安委員会が行うものとされている事務に係る手数料の徴収については、次の各号に掲げる者から、それぞれ当該各号に定める手数料の種別ごとに政令で定める区分に応じて、物件費及び施設費に対応する部分として政令で定める額に人件費に対応する部分として政令で定める額を標準とする額を加えた額を徴収することを標準として条例を定めなければならない。[[laws/335AC0000000105/本文/第89条.md|第八十九条]]第一項の規定による運転免許試験を受けようとする者運転免許試験手数料[[laws/335AC0000000105/本文/第89条.md|第八十九条]]第三項の規定による検査を受けようとする者検査手数料[[laws/335AC0000000105/本文/第100条の2.md|第百条の二]]第一項の規定による再試験を受けようとする者再試験手数料[[laws/335AC0000000105/本文/第92条.md|第九十二条]]第一項又は[[laws/335AC0000000105/本文/第95条の2.md|第九十五条の二]]第十一項の規定による免許証の交付を受けようとする者免許証交付手数料[[laws/335AC0000000105/本文/第94条.md|第九十四条]]第二項の規定による免許証の再交付を受けようとする者免許証再交付手数料[[laws/335AC0000000105/本文/第95条の2.md|第九十五条の二]]第三項の規定による特定免許情報の記録又は[[laws/335AC0000000105/本文/第95条の3.md|第九十五条の三]]の規定により読み替えて適用する[[laws/335AC0000000105/本文/第92条.md|第九十二条]]第二項の規定若しくは[[laws/335AC0000000105/本文/第106条の4.md|第百六条の四]]第二項の規定による免許情報記録の書換えを受けようとする者（免許の効力の停止の期間が満了した場合又は免許の効力の停止が解除された場合に[[laws/335AC0000000105/本文/第95条の2.md|第九十五条の二]]第一項の規定による申請をした者その他の政令で定める者を除く。）特定免許情報記録手数料[[laws/335AC0000000105/本文/第101条.md|第百一条]]第一項又は[[laws/335AC0000000105/本文/第101条の2.md|第百一条の二]]第一項の規定による免許証等の更新を受けようとする者免許証等更新手数料[[laws/335AC0000000105/本文/第101条の2.md|第百一条の二]]の二第一項の規定により免許証等の更新の申請をしようとする者経由手数料認知機能検査を受けようとする者認知機能検査手数料運転技能検査を受けようとする者運転技能検査手数料[[laws/335AC0000000105/本文/第91条.md|第九十一条]]又は[[laws/335AC0000000105/本文/第91条の2.md|第九十一条の二]]第二項の規定により運転することができる自動車等の種類を限定された者で、その限定の全部又は一部の解除を受けるため、公安委員会の審査を受けようとするもの審査手数料[[laws/335AC0000000105/本文/第99条の2.md|第九十九条の二]]第四項の規定による技能検定員資格者証の交付を受けようとする者技能検定員資格者証交付手数料[[laws/335AC0000000105/本文/第99条の2.md|第九十九条の二]]第四項第一号イの規定による審査を受けようとする者技能検定員審査手数料[[laws/335AC0000000105/本文/第99条の3.md|第九十九条の三]]第四項の規定による教習指導員資格者証の交付を受けようとする者教習指導員資格者証交付手数料[[laws/335AC0000000105/本文/第99条の3.md|第九十九条の三]]第四項第一号イの規定による審査を受けようとする者教習指導員審査手数料[[laws/335AC0000000105/本文/第107条の7.md|第百七条の七]]第一項の規定による国外運転免許証の交付を受けようとする者国外運転免許証交付手数料[[laws/335AC0000000105/本文/第108条の2.md|第百八条の二]]第一項各号に掲げる講習を受けようとする者講習手数料初心運転者講習、[[laws/335AC0000000105/本文/第108条の2.md|第百八条の二]]第一項第十三号に掲げる講習又は若年運転者講習を受けようとする者通知手数料

- 一 [[laws/335AC0000000105/本文/第89条.md|第八十九条]]第一項の規定による運転免許試験を受けようとする者運転免許試験手数料
- 一の二 [[laws/335AC0000000105/本文/第89条.md|第八十九条]]第三項の規定による検査を受けようとする者検査手数料
- 二 [[laws/335AC0000000105/本文/第100条の2.md|第百条の二]]第一項の規定による再試験を受けようとする者再試験手数料
- 三 [[laws/335AC0000000105/本文/第92条.md|第九十二条]]第一項又は[[laws/335AC0000000105/本文/第95条の2.md|第九十五条の二]]第十一項の規定による免許証の交付を受けようとする者免許証交付手数料
- 四 [[laws/335AC0000000105/本文/第94条.md|第九十四条]]第二項の規定による免許証の再交付を受けようとする者免許証再交付手数料
- 四の二 [[laws/335AC0000000105/本文/第95条の2.md|第九十五条の二]]第三項の規定による特定免許情報の記録又は[[laws/335AC0000000105/本文/第95条の3.md|第九十五条の三]]の規定により読み替えて適用する[[laws/335AC0000000105/本文/第92条.md|第九十二条]]第二項の規定若しくは[[laws/335AC0000000105/本文/第106条の4.md|第百六条の四]]第二項の規定による免許情報記録の書換えを受けようとする者（免許の効力の停止の期間が満了した場合又は免許の効力の停止が解除された場合に[[laws/335AC0000000105/本文/第95条の2.md|第九十五条の二]]第一項の規定による申請をした者その他の政令で定める者を除く。）特定免許情報記録手数料
- 五 [[laws/335AC0000000105/本文/第101条.md|第百一条]]第一項又は[[laws/335AC0000000105/本文/第101条の2.md|第百一条の二]]第一項の規定による免許証等の更新を受けようとする者免許証等更新手数料
- 五の二 [[laws/335AC0000000105/本文/第101条の2.md|第百一条の二]]の二第一項の規定により免許証等の更新の申請をしようとする者経由手数料
- 五の三 認知機能検査を受けようとする者認知機能検査手数料
- 五の四 運転技能検査を受けようとする者運転技能検査手数料
- 六 [[laws/335AC0000000105/本文/第91条.md|第九十一条]]又は[[laws/335AC0000000105/本文/第91条の2.md|第九十一条の二]]第二項の規定により運転することができる自動車等の種類を限定された者で、その限定の全部又は一部の解除を受けるため、公安委員会の審査を受けようとするもの審査手数料
- 七 [[laws/335AC0000000105/本文/第99条の2.md|第九十九条の二]]第四項の規定による技能検定員資格者証の交付を受けようとする者技能検定員資格者証交付手数料
- 八 [[laws/335AC0000000105/本文/第99条の2.md|第九十九条の二]]第四項第一号イの規定による審査を受けようとする者技能検定員審査手数料
- 九 [[laws/335AC0000000105/本文/第99条の3.md|第九十九条の三]]第四項の規定による教習指導員資格者証の交付を受けようとする者教習指導員資格者証交付手数料
- 十 [[laws/335AC0000000105/本文/第99条の3.md|第九十九条の三]]第四項第一号イの規定による審査を受けようとする者教習指導員審査手数料
- 十一 [[laws/335AC0000000105/本文/第107条の7.md|第百七条の七]]第一項の規定による国外運転免許証の交付を受けようとする者国外運転免許証交付手数料
- 十二 [[laws/335AC0000000105/本文/第108条の2.md|第百八条の二]]第一項各号に掲げる講習を受けようとする者講習手数料
- 十三 初心運転者講習、[[laws/335AC0000000105/本文/第108条の2.md|第百八条の二]]第一項第十三号に掲げる講習又は若年運転者講習を受けようとする者通知手数料
## ２
前項の場合においては、都道府県は、条例で定めるところにより、指定講習機関が行う特定講習に係る同項第十二号の講習手数料を当該指定講習機関へ納めさせ、その収入とすることができる。
