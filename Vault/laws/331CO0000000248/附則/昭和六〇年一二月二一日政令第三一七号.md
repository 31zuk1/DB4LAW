# 附則

## １
この政令は、公布の日から施行する。ただし、第四十二条の規定は、昭和六十一年一月一日から施行する。

## ２
この政令（第四十二条の規定を除く。）による改正後の次に掲げる政令の規定は、昭和六十年七月一日から適用する。略労働保険審査官及び労働保険審査会法施行令

- 一から五まで 略
- 六 労働保険審査官及び労働保険審査会法施行令
