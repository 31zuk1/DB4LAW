# 第六十五条 

## 
次の各号のいずれかに該当する場合には、税理士法人の社員若しくは清算人又は税理士会若しくは日本税理士会連合会の役員は、三十万円以下の過料に処する。この法律に基づく政令の規定に違反して登記をすることを怠つたとき。[[laws/税理士法/本文/第48条の19.md|第四十八条の十九]]の二第二項又は第五項の規定に違反して合併をしたとき。[[laws/税理士法/本文/第48条の19.md|第四十八条の十九]]の二第六項（[[laws/税理士法/本文/第49条の12.md|第四十九条の十二]]第三項において準用する場合を含む。）において準用する会社法[[laws/会社法/本文/第941条.md|第九百四十一条]]の規定に違反して同条の調査を求めなかつたとき。定款又は[[laws/税理士法/本文/第48条の21.md|第四十八条の二十一]]第一項において準用する会社法[[laws/会社法/本文/第615条.md|第六百十五条]]第一項の会計帳簿若しくは[[laws/会社法/本文/第48条の21.md|第四十八条の二十一]]第一項において準用する同法第六百十七条第一項若しくは第二項の貸借対照表に記載し、若しくは記録すべき事項を記載せず、若しくは記録せず、又は虚偽の記載若しくは記録をしたとき。[[laws/税理士法/本文/第48条の21.md|第四十八条の二十一]]第二項において準用する会社法[[laws/会社法/本文/第656条.md|第六百五十六条]]第一項の規定に違反して破産手続開始の申立てを怠つたとき。[[laws/税理士法/本文/第48条の21.md|第四十八条の二十一]]第二項において準用する会社法[[laws/会社法/本文/第664条.md|第六百六十四条]]の規定に違反して財産を分配したとき。[[laws/税理士法/本文/第48条の21.md|第四十八条の二十一]]第二項において準用する会社法[[laws/会社法/本文/第670条.md|第六百七十条]]第二項又は第五項の規定に違反して財産を処分したとき。

- 一 この法律に基づく政令の規定に違反して登記をすることを怠つたとき。
- 二 [[laws/税理士法/本文/第48条の19.md|第四十八条の十九]]の二第二項又は第五項の規定に違反して合併をしたとき。
- 三 [[laws/税理士法/本文/第48条の19.md|第四十八条の十九]]の二第六項（[[laws/税理士法/本文/第49条の12.md|第四十九条の十二]]第三項において準用する場合を含む。）において準用する会社法[[laws/会社法/本文/第941条.md|第九百四十一条]]の規定に違反して同条の調査を求めなかつたとき。
- 四 定款又は[[laws/税理士法/本文/第48条の21.md|第四十八条の二十一]]第一項において準用する会社法[[laws/会社法/本文/第615条.md|第六百十五条]]第一項の会計帳簿若しくは[[laws/会社法/本文/第48条の21.md|第四十八条の二十一]]第一項において準用する同法第六百十七条第一項若しくは第二項の貸借対照表に記載し、若しくは記録すべき事項を記載せず、若しくは記録せず、又は虚偽の記載若しくは記録をしたとき。
- 五 [[laws/税理士法/本文/第48条の21.md|第四十八条の二十一]]第二項において準用する会社法[[laws/会社法/本文/第656条.md|第六百五十六条]]第一項の規定に違反して破産手続開始の申立てを怠つたとき。
- 六 [[laws/税理士法/本文/第48条の21.md|第四十八条の二十一]]第二項において準用する会社法[[laws/会社法/本文/第664条.md|第六百六十四条]]の規定に違反して財産を分配したとき。
- 七 [[laws/税理士法/本文/第48条の21.md|第四十八条の二十一]]第二項において準用する会社法[[laws/会社法/本文/第670条.md|第六百七十条]]第二項又は第五項の規定に違反して財産を処分したとき。
