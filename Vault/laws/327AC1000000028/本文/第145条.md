# 第百四十五条 

## 
次の場合には、組合の役員又は清算人を二十万円以下の過料に処する。この法律の規定により農林水産大臣の認可又は承認を受けなければならない場合にその認可又は承認を受けなかつたとき。この法律による登記をすることを怠つたとき。組合がこの法律の規定により行うことができる事業以外の事業を行つたとき。[[laws/漁船損害等補償法/本文/第26条.md|第二十六条]]第二項又は[[laws/漁船損害等補償法/本文/第40条.md|第四十条]]第五項（[[laws/漁船損害等補償法/本文/第46条.md|第四十六条]]第九項において準用する場合を含む。）の規定に違反したとき。[[laws/漁船損害等補償法/本文/第32条.md|第三十二条]]の規定に違反したとき。[[laws/漁船損害等補償法/本文/第34条.md|第三十四条]]第一項、[[laws/漁船損害等補償法/本文/第35条.md|第三十五条]]第一項又は[[laws/漁船損害等補償法/本文/第36条.md|第三十六条]]の規定に違反したとき。[[laws/漁船損害等補償法/本文/第38条.md|第三十八条]]第一項若しくは第二項若しくは[[laws/漁船損害等補償法/本文/第39条.md|第三十九条]]第一項の規定に違反して書類を備えて置かず、その書類に記載すべき事項を記載せず、若しくは虚偽の記載をし、又は正当な理由がないのに[[laws/漁船損害等補償法/本文/第38条.md|第三十八条]]第三項若しくは[[laws/漁船損害等補償法/本文/第39条.md|第三十九条]]第二項の規定による閲覧を拒んだとき。[[laws/漁船損害等補償法/本文/第53条.md|第五十三条]]又は[[laws/漁船損害等補償法/本文/第54条.md|第五十四条]]第一項若しくは第四項の規定に違反して組合の合併をしたとき。[[laws/漁船損害等補償法/本文/第59条.md|第五十九条]]又は[[laws/漁船損害等補償法/本文/第61条.md|第六十一条]]の書類又は電磁的記録に記載し、若しくは記録すべき事項を記載せず、若しくは記録せず、又は虚偽の記載若しくは記録をしたとき。[[laws/漁船損害等補償法/本文/第59条の2.md|第五十九条の二]]第一項の期間内に債権者に弁済をしたとき。[[laws/漁船損害等補償法/本文/第59条の2.md|第五十九条の二]]第一項又は[[laws/漁船損害等補償法/本文/第59条の4.md|第五十九条の四]]第一項の規定による公告を怠り、又は虚偽の公告をしたとき。[[laws/漁船損害等補償法/本文/第59条の4.md|第五十九条の四]]第一項の規定に違反して破産手続開始の申立てを怠つたとき。[[laws/漁船損害等補償法/本文/第102条.md|第百二条]]（[[laws/漁船損害等補償法/本文/第143条の11.md|第百四十三条の十一]]第一項において準用する場合を含む。）の規定に違反したとき。法令又は定款に違反して保険金の額を削減し、又は剰余金を処分したとき。[[laws/漁船損害等補償法/本文/第105条.md|第百五条]]又は[[laws/漁船損害等補償法/本文/第106条.md|第百六条]]（これらの規定を[[laws/漁船損害等補償法/本文/第143条の11.md|第百四十三条の十一]]第一項において準用する場合を含む。）の規定に違反したとき。

- 一 この法律の規定により農林水産大臣の認可又は承認を受けなければならない場合にその認可又は承認を受けなかつたとき。
- 二 この法律による登記をすることを怠つたとき。
- 三 組合がこの法律の規定により行うことができる事業以外の事業を行つたとき。
- 四 [[laws/漁船損害等補償法/本文/第26条.md|第二十六条]]第二項又は[[laws/漁船損害等補償法/本文/第40条.md|第四十条]]第五項（[[laws/漁船損害等補償法/本文/第46条.md|第四十六条]]第九項において準用する場合を含む。）の規定に違反したとき。
- 五 [[laws/漁船損害等補償法/本文/第32条.md|第三十二条]]の規定に違反したとき。
- 六 [[laws/漁船損害等補償法/本文/第34条.md|第三十四条]]第一項、[[laws/漁船損害等補償法/本文/第35条.md|第三十五条]]第一項又は[[laws/漁船損害等補償法/本文/第36条.md|第三十六条]]の規定に違反したとき。
- 七 [[laws/漁船損害等補償法/本文/第38条.md|第三十八条]]第一項若しくは第二項若しくは[[laws/漁船損害等補償法/本文/第39条.md|第三十九条]]第一項の規定に違反して書類を備えて置かず、その書類に記載すべき事項を記載せず、若しくは虚偽の記載をし、又は正当な理由がないのに[[laws/漁船損害等補償法/本文/第38条.md|第三十八条]]第三項若しくは[[laws/漁船損害等補償法/本文/第39条.md|第三十九条]]第二項の規定による閲覧を拒んだとき。
- 八 [[laws/漁船損害等補償法/本文/第53条.md|第五十三条]]又は[[laws/漁船損害等補償法/本文/第54条.md|第五十四条]]第一項若しくは第四項の規定に違反して組合の合併をしたとき。
- 九 [[laws/漁船損害等補償法/本文/第59条.md|第五十九条]]又は[[laws/漁船損害等補償法/本文/第61条.md|第六十一条]]の書類又は電磁的記録に記載し、若しくは記録すべき事項を記載せず、若しくは記録せず、又は虚偽の記載若しくは記録をしたとき。
- 十 [[laws/漁船損害等補償法/本文/第59条の2.md|第五十九条の二]]第一項の期間内に債権者に弁済をしたとき。
- 十一 [[laws/漁船損害等補償法/本文/第59条の2.md|第五十九条の二]]第一項又は[[laws/漁船損害等補償法/本文/第59条の4.md|第五十九条の四]]第一項の規定による公告を怠り、又は虚偽の公告をしたとき。
- 十二 [[laws/漁船損害等補償法/本文/第59条の4.md|第五十九条の四]]第一項の規定に違反して破産手続開始の申立てを怠つたとき。
- 十三 [[laws/漁船損害等補償法/本文/第102条.md|第百二条]]（[[laws/漁船損害等補償法/本文/第143条の11.md|第百四十三条の十一]]第一項において準用する場合を含む。）の規定に違反したとき。
- 十四 法令又は定款に違反して保険金の額を削減し、又は剰余金を処分したとき。
- 十五 [[laws/漁船損害等補償法/本文/第105条.md|第百五条]]又は[[laws/漁船損害等補償法/本文/第106条.md|第百六条]]（これらの規定を[[laws/漁船損害等補償法/本文/第143条の11.md|第百四十三条の十一]]第一項において準用する場合を含む。）の規定に違反したとき。
