# 第八十一条 

## 
歳出支払未済繰越金月計突合表は、日本銀行本店において、その取り扱つた歳出支払未済繰越金の越高、受入額、支払額及び残額を掲げ毎月（歳出支払未済繰越金の受入額及び支払額のない月を除く。）これを作成し、翌月の第七営業日までに到達の日取りをもつてセンター支出官に送付しなければならない。

## 
日本銀行本店は、センター支出官から、当該突合表を送付した月の第十二営業日までに誤りがある旨の通知を受けたときは、その訂正の手続をし、再度歳出支払未済繰越金月計突合表を作成し、直ちにセンター支出官に送付しなければならない。
