# 第七十七条 

## 
日本銀行は、国庫金の出納に関し、次の計算報告表を作成しなければならない。国庫金貸借対照表第十二号書式国庫金受払報告表第十三号書式削除別口預金（指定預金）受払内訳表第十五号書式歳入金月計突合表第十六号書式収納済歳入額突合表書式は、第十六号書式に準ずる歳出金月計突合表第十七号書式歳出支払未済繰越金月計突合表第十八号書式国税収納金整理資金受入金月計突合表第十八号の二書式国税収納金整理資金支払金月計突合表第十八号の三書式国税資金支払未済繰越金月計突合表第十八号の四書式預託金月計突合表第十九号書式保管金月計突合表第二十号書式削除財政融資資金月計突合表第二十二号の二書式某月出納計算書書式は、[[laws/322M40000040093/本文/第86条.md|第八十六条]]に規定する国庫金の出納計算書に準ずる

- 一 国庫金貸借対照表第十二号書式
- 二 国庫金受払報告表第十三号書式
- 三 削除
- 四 別口預金（指定預金）受払内訳表第十五号書式
- 五 歳入金月計突合表第十六号書式
- 五の二 収納済歳入額突合表書式は、第十六号書式に準ずる
- 六 歳出金月計突合表第十七号書式
- 七 歳出支払未済繰越金月計突合表第十八号書式
- 七の二 国税収納金整理資金受入金月計突合表第十八号の二書式
- 七の三 国税収納金整理資金支払金月計突合表第十八号の三書式
- 七の四 国税資金支払未済繰越金月計突合表第十八号の四書式
- 八 預託金月計突合表第十九号書式
- 九 保管金月計突合表第二十号書式
- 十及び十一 削除
- 十一の二 財政融資資金月計突合表第二十二号の二書式
- 十二 某月出納計算書書式は、[[laws/322M40000040093/本文/第86条.md|第八十六条]]に規定する国庫金の出納計算書に準ずる
