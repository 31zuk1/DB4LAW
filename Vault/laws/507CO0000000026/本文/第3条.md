# 第三条 （指定に関する記録の作成）

## 
法[[laws/重要経済安保情報の保護及び活用に関する法律施行令/本文/第3条.md|第三条]]第二項の規定による指定に関する記録の作成は、法[[laws/重要経済安保情報の保護及び活用に関する法律施行令/本文/第18条.md|第十八条]]第一項の基準（以下「運用基準」という。）で定めるところにより、法[[laws/重要経済安保情報の保護及び活用に関する法律施行令/本文/第3条.md|第三条]]第一項の規定による指定（以下「指定」という。）及びその解除を適切に管理するための帳簿（その作成に代えて電磁的記録（同条第二項第一号に規定する電磁的記録をいう。以下同じ。）の作成がされている場合における当該電磁的記録を含む。以下「指定管理簿」という。）に次に掲げる事項を記載し、又は記録することにより行うものとする。指定をした年月日指定の有効期間及びその満了する年月日指定に係る重要経済安保情報の概要指定に係る重要経済安保情報である情報が法[[laws/重要経済安保情報の保護及び活用に関する法律施行令/本文/第2条.md|第二条]]第四項各号のいずれの事項に関するものであるかの別法[[laws/重要経済安保情報の保護及び活用に関する法律施行令/本文/第3条.md|第三条]]第二項の規定により講ずる措置が同項各号のいずれの措置であるかの別前各号に掲げるもののほか、指定を適切に管理するために必要なものとして運用基準で定める事項

- 一 指定をした年月日
- 二 指定の有効期間及びその満了する年月日
- 三 指定に係る重要経済安保情報の概要
- 四 指定に係る重要経済安保情報である情報が法[[laws/重要経済安保情報の保護及び活用に関する法律施行令/本文/第2条.md|第二条]]第四項各号のいずれの事項に関するものであるかの別
- 五 法[[laws/重要経済安保情報の保護及び活用に関する法律施行令/本文/第3条.md|第三条]]第二項の規定により講ずる措置が同項各号のいずれの措置であるかの別
- 六 前各号に掲げるもののほか、指定を適切に管理するために必要なものとして運用基準で定める事項
