# 第十七条 （公示）

## 
こども家庭庁長官は、次に掲げる率又は額を年度ごとにあらかじめ公示するものとする。算定率（各年度における全ての被用者保険等保険者に係る[[laws/507M60000002093/本文/第1条.md|第一条]]第一項第一号の合計額の総額を当該年度における全ての被用者保険等保険者に係る標準報酬総額の見込額の合計額で除して得た率をいう。以下同じ。）に小数点以下第八位未満の端数があるときは、これを四捨五入して得た率算定率に小数点以下第四位未満の端数があるときは、その端数を切り上げた率[[laws/507M60000002093/本文/第2条.md|第二条]]第一項第二号に規定するこども家庭庁長官が定める率[[laws/507M60000002093/本文/第2条.md|第二条]]第六項の規定により読み替えて準用される同条第一項第二号に規定するこども家庭庁長官が定める率[[laws/507M60000002093/本文/第6条.md|第六条]]に規定する総報酬割概算負担率[[laws/507M60000002093/本文/第8条.md|第八条]]第二項に規定するこども家庭庁長官が定める額[[laws/507M60000002093/本文/第10条.md|第十条]]に規定する総報酬割確定負担率被用者保険等保険者が、健康保険法[[laws/507M60000002093/子ども・子育て支援納付金の算定等に関する_law.md|第百六十条の二]]に規定する子ども・子育て支援金率（共済組合又は日本私立学校振興・共済事業団にあっては、子ども・子育て支援納付金に係る掛金の割合）を定めるに当たって参酌すべき率として、算定率を基礎としてこども家庭庁長官が定める率

- 一 算定率（各年度における全ての被用者保険等保険者に係る[[laws/507M60000002093/本文/第1条.md|第一条]]第一項第一号の合計額の総額を当該年度における全ての被用者保険等保険者に係る標準報酬総額の見込額の合計額で除して得た率をいう。以下同じ。）に小数点以下第八位未満の端数があるときは、これを四捨五入して得た率
- 二 算定率に小数点以下第四位未満の端数があるときは、その端数を切り上げた率
- 三 [[laws/507M60000002093/本文/第2条.md|第二条]]第一項第二号に規定するこども家庭庁長官が定める率
- 四 [[laws/507M60000002093/本文/第2条.md|第二条]]第六項の規定により読み替えて準用される同条第一項第二号に規定するこども家庭庁長官が定める率
- 五 [[laws/507M60000002093/本文/第6条.md|第六条]]に規定する総報酬割概算負担率
- 六 [[laws/507M60000002093/本文/第8条.md|第八条]]第二項に規定するこども家庭庁長官が定める額
- 七 [[laws/507M60000002093/本文/第10条.md|第十条]]に規定する総報酬割確定負担率
- 八 被用者保険等保険者が、健康保険法[[laws/507M60000002093/子ども・子育て支援納付金の算定等に関する_law.md|第百六十条の二]]に規定する子ども・子育て支援金率（共済組合又は日本私立学校振興・共済事業団にあっては、子ども・子育て支援納付金に係る掛金の割合）を定めるに当たって参酌すべき率として、算定率を基礎としてこども家庭庁長官が定める率
