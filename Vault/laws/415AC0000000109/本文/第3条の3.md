# 第三条の三 （関連請求の併合による管轄権）

## 
一の訴えで人事訴訟に係る請求と当該請求の原因である事実によって生じた損害の賠償に関する請求（当該人事訴訟における当事者の一方から他の一方に対するものに限る。）とをする場合においては、日本の裁判所が当該人事訴訟に係る請求について管轄権を有するときに限り、日本の裁判所にその訴えを提起することができる。
