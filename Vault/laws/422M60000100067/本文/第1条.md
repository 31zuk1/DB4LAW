# 第一条 （法第十三条第一項第二号に規定する厚生労働省令で定める権限）

## 
厚生年金保険の保険給付及び国民年金の給付の支払の遅延に係る加算金の支給に関する法律（以下「法」という。）[[laws/422M60000100067/本文/第13条.md|第十三条]]第一項第二号に規定する厚生労働省令で定める権限は、次の各号に掲げる権限とする。国税徴収法（昭和三十四年法律第百四十七号）第百三十八条の規定の例による納入の告知（納入告知書の発送又は交付に係る権限を除く。）国税通則法（昭和三十七年法律第六十六号）第十一条の規定の例による延長国税通則法[[laws/422M60000100067/厚生年金保険の保険給付及び国民年金の給付_law.md|第三十六条]]第一項の規定の例による納入の告知（納入告知書の発送又は交付に係る権限を除く。）国税通則法[[laws/422M60000100067/厚生年金保険の保険給付及び国民年金の給付_law.md|第四十二条]]において準用する民法（明治二十九年法律第八十九号）第四百二十三条第一項の規定の例による納付義務者に属する権利の行使国税通則法[[laws/129AC0000000089/民法_law.md|第四十二条]]において準用する民法[[laws/129AC0000000089/本文/第424条.md|第四百二十四条]]第一項の規定の例による法律行為の取消しの裁判所への請求国税通則法[[laws/129AC0000000089/民法_law.md|第四十六条]]の規定の例による納付の猶予国税通則法[[laws/129AC0000000089/民法_law.md|第四十九条]]の規定の例による納付の猶予の取消し国税通則法[[laws/129AC0000000089/民法_law.md|第六十三条]]の規定の例による免除

- 一 国税徴収法（昭和三十四年法律第百四十七号）第百三十八条の規定の例による納入の告知（納入告知書の発送又は交付に係る権限を除く。）
- 二 国税通則法（昭和三十七年法律第六十六号）第十一条の規定の例による延長
- 三 国税通則法[[laws/422M60000100067/厚生年金保険の保険給付及び国民年金の給付_law.md|第三十六条]]第一項の規定の例による納入の告知（納入告知書の発送又は交付に係る権限を除く。）
- 四 国税通則法[[laws/422M60000100067/厚生年金保険の保険給付及び国民年金の給付_law.md|第四十二条]]において準用する民法（明治二十九年法律第八十九号）第四百二十三条第一項の規定の例による納付義務者に属する権利の行使
- 五 国税通則法[[laws/422M60000100067/厚生年金保険の保険給付及び国民年金の給付_law.md|第四十二条]]において準用する民法[[laws/129AC0000000089/本文/第424条.md|第四百二十四条]]第一項の規定の例による法律行為の取消しの裁判所への請求
- 六 国税通則法[[laws/422M60000100067/厚生年金保険の保険給付及び国民年金の給付_law.md|第四十六条]]の規定の例による納付の猶予
- 七 国税通則法[[laws/422M60000100067/厚生年金保険の保険給付及び国民年金の給付_law.md|第四十九条]]の規定の例による納付の猶予の取消し
- 八 国税通則法[[laws/422M60000100067/厚生年金保険の保険給付及び国民年金の給付_law.md|第六十三条]]の規定の例による免除
