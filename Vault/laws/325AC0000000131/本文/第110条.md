# 第百十条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、一年以下の拘禁刑又は百万円以下の罰金に処する。[[laws/325AC0000000131/本文/第4条.md|第四条]]の規定による免許又は[[laws/325AC0000000131/本文/第27条の21.md|第二十七条の二十一]]第一項の規定による登録がないのに、無線局を開設したとき。[[laws/325AC0000000131/本文/第4条.md|第四条]]の規定による免許又は[[laws/325AC0000000131/本文/第27条の21.md|第二十七条の二十一]]第一項の規定による登録がないのに、かつ、[[laws/325AC0000000131/本文/第70条の7.md|第七十条の七]]第一項、[[laws/325AC0000000131/本文/第70条の8.md|第七十条の八]]第一項又は[[laws/325AC0000000131/本文/第70条の9.md|第七十条の九]]第一項の規定によらないで、無線局を運用したとき。[[laws/325AC0000000131/本文/第27条の7.md|第二十七条の七]]の規定に違反して特定無線局を開設したとき。[[laws/325AC0000000131/本文/第100条.md|第百条]]第一項の規定による許可がないのに、同項の設備を運用したとき。[[laws/325AC0000000131/本文/第52条.md|第五十二条]]、[[laws/325AC0000000131/本文/第53条.md|第五十三条]]、[[laws/325AC0000000131/本文/第54条.md|第五十四条]]第一号又は[[laws/325AC0000000131/本文/第55条.md|第五十五条]]の規定に違反して無線局を運用したとき。[[laws/325AC0000000131/本文/第18条.md|第十八条]]第一項の規定に違反して無線設備を運用したとき。[[laws/325AC0000000131/本文/第71条の5.md|第七十一条の五]]（[[laws/325AC0000000131/本文/第100条.md|第百条]]第五項において準用する場合を含む。）の規定による命令に違反したとき。[[laws/325AC0000000131/本文/第72条.md|第七十二条]]第一項（[[laws/325AC0000000131/本文/第100条.md|第百条]]第五項において準用する場合を含む。）又は[[laws/325AC0000000131/本文/第76条.md|第七十六条]]第一項（[[laws/325AC0000000131/本文/第70条の7.md|第七十条の七]]第四項、[[laws/325AC0000000131/本文/第70条の8.md|第七十条の八]]第三項、[[laws/325AC0000000131/本文/第70条の9.md|第七十条の九]]第三項及び[[laws/325AC0000000131/本文/第100条.md|第百条]]第五項において準用する場合を含む。）の規定によつて電波の発射又は運用を停止された無線局又は[[laws/325AC0000000131/本文/第100条.md|第百条]]第一項の設備を運用したとき。[[laws/325AC0000000131/本文/第74条.md|第七十四条]]第一項の規定による処分に違反したとき。[[laws/325AC0000000131/本文/第76条.md|第七十六条]]第二項の規定による禁止に違反して無線局を開設したとき。[[laws/325AC0000000131/本文/第38条の22.md|第三十八条の二十二]]第一項（[[laws/325AC0000000131/本文/第38条の29.md|第三十八条の二十九]]及び[[laws/325AC0000000131/本文/第38条の38.md|第三十八条の三十八]]において準用する場合を含む。）の規定による命令に違反したとき。[[laws/325AC0000000131/本文/第38条の28.md|第三十八条の二十八]]第一項（第一号に係る部分に限る。）、[[laws/325AC0000000131/本文/第38条の36.md|第三十八条の三十六]]第一項（第一号に係る部分に限る。）又は[[laws/325AC0000000131/本文/第38条の37.md|第三十八条の三十七]]第一項の規定による禁止に違反したとき。

- 一 [[laws/325AC0000000131/本文/第4条.md|第四条]]の規定による免許又は[[laws/325AC0000000131/本文/第27条の21.md|第二十七条の二十一]]第一項の規定による登録がないのに、無線局を開設したとき。
- 二 [[laws/325AC0000000131/本文/第4条.md|第四条]]の規定による免許又は[[laws/325AC0000000131/本文/第27条の21.md|第二十七条の二十一]]第一項の規定による登録がないのに、かつ、[[laws/325AC0000000131/本文/第70条の7.md|第七十条の七]]第一項、[[laws/325AC0000000131/本文/第70条の8.md|第七十条の八]]第一項又は[[laws/325AC0000000131/本文/第70条の9.md|第七十条の九]]第一項の規定によらないで、無線局を運用したとき。
- 三 [[laws/325AC0000000131/本文/第27条の7.md|第二十七条の七]]の規定に違反して特定無線局を開設したとき。
- 四 [[laws/325AC0000000131/本文/第100条.md|第百条]]第一項の規定による許可がないのに、同項の設備を運用したとき。
- 五 [[laws/325AC0000000131/本文/第52条.md|第五十二条]]、[[laws/325AC0000000131/本文/第53条.md|第五十三条]]、[[laws/325AC0000000131/本文/第54条.md|第五十四条]]第一号又は[[laws/325AC0000000131/本文/第55条.md|第五十五条]]の規定に違反して無線局を運用したとき。
- 六 [[laws/325AC0000000131/本文/第18条.md|第十八条]]第一項の規定に違反して無線設備を運用したとき。
- 七 [[laws/325AC0000000131/本文/第71条の5.md|第七十一条の五]]（[[laws/325AC0000000131/本文/第100条.md|第百条]]第五項において準用する場合を含む。）の規定による命令に違反したとき。
- 八 [[laws/325AC0000000131/本文/第72条.md|第七十二条]]第一項（[[laws/325AC0000000131/本文/第100条.md|第百条]]第五項において準用する場合を含む。）又は[[laws/325AC0000000131/本文/第76条.md|第七十六条]]第一項（[[laws/325AC0000000131/本文/第70条の7.md|第七十条の七]]第四項、[[laws/325AC0000000131/本文/第70条の8.md|第七十条の八]]第三項、[[laws/325AC0000000131/本文/第70条の9.md|第七十条の九]]第三項及び[[laws/325AC0000000131/本文/第100条.md|第百条]]第五項において準用する場合を含む。）の規定によつて電波の発射又は運用を停止された無線局又は[[laws/325AC0000000131/本文/第100条.md|第百条]]第一項の設備を運用したとき。
- 九 [[laws/325AC0000000131/本文/第74条.md|第七十四条]]第一項の規定による処分に違反したとき。
- 十 [[laws/325AC0000000131/本文/第76条.md|第七十六条]]第二項の規定による禁止に違反して無線局を開設したとき。
- 十一 [[laws/325AC0000000131/本文/第38条の22.md|第三十八条の二十二]]第一項（[[laws/325AC0000000131/本文/第38条の29.md|第三十八条の二十九]]及び[[laws/325AC0000000131/本文/第38条の38.md|第三十八条の三十八]]において準用する場合を含む。）の規定による命令に違反したとき。
- 十二 [[laws/325AC0000000131/本文/第38条の28.md|第三十八条の二十八]]第一項（第一号に係る部分に限る。）、[[laws/325AC0000000131/本文/第38条の36.md|第三十八条の三十六]]第一項（第一号に係る部分に限る。）又は[[laws/325AC0000000131/本文/第38条の37.md|第三十八条の三十七]]第一項の規定による禁止に違反したとき。
