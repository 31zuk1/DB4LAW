# 第百九十六条 

## 
次の各号のいずれかに該当する場合には、その違反行為をした郵便貯金銀行又は郵便保険会社の取締役、会計参与若しくはその職務を行うべき社員、監査役、執行役又は支配人は、百万円以下の過料に処する。ただし、その行為について刑を科すべきときは、この限りでない。[[laws/郵政民営化法/本文/第110条.md|第百十条]]第一項の規定による認可を受けないで同項各号に掲げる業務を行ったとき。[[laws/郵政民営化法/本文/第110条の2.md|第百十条の二]]第一項後段、[[laws/郵政民営化法/本文/第112条.md|第百十二条]]第一項若しくは第二項、[[laws/郵政民営化法/本文/第120条.md|第百二十条]]第一項、[[laws/郵政民営化法/本文/第138条の2.md|第百三十八条の二]]第一項後段、[[laws/郵政民営化法/本文/第140条.md|第百四十条]]第一項又は[[laws/郵政民営化法/本文/第149条.md|第百四十九条]]第一項の規定による届出をせず、又は虚偽の届出をしたとき。[[laws/郵政民営化法/本文/第111条.md|第百十一条]]第一項の規定による認可を受けないで子会社対象金融機関等（同条第九項に規定する子会社対象金融機関等をいう。以下この号において同じ。）を子会社（同条第一項に規定する子会社をいう。以下この号及び次号において同じ。）としたとき（銀行法[[laws/郵政民営化法/本文/第16条の2.md|第十六条の二]]第一項第十五号に掲げる会社（同条第四項に規定する内閣府令で定める会社を除く。）にあっては、郵便貯金銀行又はその子会社が、合算してその基準議決権数（[[laws/郵政民営化法/本文/第111条.md|第百十一条]]第一項に規定する基準議決権数をいう。以下この号において同じ。）を超える議決権を取得し、又は保有したとき）、同条第三項において準用する同条第一項の規定による認可を受けないで同法第十六条の二第一項各号に掲げる会社を当該各号のうち他の号に掲げる会社（子会社対象金融機関等に限る。）に該当する子会社としたとき、又は[[laws/郵政民営化法/本文/第111条.md|第百十一条]]第四項の規定による認可を受けないで同項に規定する子会社対象会社が同法第十六条の二第一項第十五号に掲げる会社となったことを知った日から一年を超えて郵便貯金銀行若しくはその子会社が当該同号に掲げる会社の議決権を合算してその基準議決権数を超えて保有したとき。[[laws/郵政民営化法/本文/第111条.md|第百十一条]]第七項の規定に違反して、銀行（同項に規定する銀行をいう。）を子会社としたとき。[[laws/郵政民営化法/本文/第119条.md|第百十九条]]第一項又は[[laws/郵政民営化法/本文/第147条.md|第百四十七条]]第一項の規定による命令（業務の全部又は一部の停止の命令を除く。）に違反したとき。[[laws/郵政民営化法/本文/第121条.md|第百二十一条]]第一項又は[[laws/郵政民営化法/本文/第150条.md|第百五十条]]第一項の規定により付した条件に違反したとき。[[laws/郵政民営化法/本文/第138条.md|第百三十八条]]第一項の規定に違反して、認可を受けないで同項に規定する保険の種類以外の種類の保険の引受けを行ったとき。[[laws/郵政民営化法/本文/第138条.md|第百三十八条]]第二項の規定に違反して、認可を受けないで同項に規定する方法以外の方法により資産の運用を行ったとき。[[laws/郵政民営化法/本文/第138条.md|第百三十八条]]第三項の規定に違反して、認可を受けないで業務を行ったとき。[[laws/郵政民営化法/本文/第139条.md|第百三十九条]]第一項の規定による認可を受けないで同条第九項に規定する子会社対象会社を子会社（同条第一項に規定する子会社をいう。以下この号及び次号において同じ。）としたとき（保険業法第百六条第一項第十六号に掲げる会社（同条第四項に規定する内閣府令で定める会社を除く。）にあっては、郵便保険会社又はその子会社が、合算してその基準議決権数（[[laws/保険業法/本文/第139条.md|第百三十九条]]第一項に規定する基準議決権数をいう。以下この号において同じ。）を超える議決権を取得し、又は保有したとき）、同条第三項において準用する同条第一項の規定による認可を受けないで同法第百六条第一項各号に掲げる会社を当該各号のうち他の号に掲げる会社（同条第九項に規定する子会社対象会社に限る。）に該当する子会社としたとき、又は[[laws/保険業法/本文/第139条.md|第百三十九条]]第四項の規定による認可を受けないで同項に規定する子会社対象会社が同法第百六条第一項第十六号に掲げる会社となったことを知った日から一年を超えて郵便保険会社若しくはその子会社が当該同号に掲げる会社の議決権を合算してその基準議決権数を超えて保有したとき。[[laws/郵政民営化法/本文/第139条.md|第百三十九条]]第七項の規定に違反して、保険会社等（同項に規定する保険会社等をいう。）を子会社としたとき。

- 一 [[laws/郵政民営化法/本文/第110条.md|第百十条]]第一項の規定による認可を受けないで同項各号に掲げる業務を行ったとき。
- 二 [[laws/郵政民営化法/本文/第110条の2.md|第百十条の二]]第一項後段、[[laws/郵政民営化法/本文/第112条.md|第百十二条]]第一項若しくは第二項、[[laws/郵政民営化法/本文/第120条.md|第百二十条]]第一項、[[laws/郵政民営化法/本文/第138条の2.md|第百三十八条の二]]第一項後段、[[laws/郵政民営化法/本文/第140条.md|第百四十条]]第一項又は[[laws/郵政民営化法/本文/第149条.md|第百四十九条]]第一項の規定による届出をせず、又は虚偽の届出をしたとき。
- 三 [[laws/郵政民営化法/本文/第111条.md|第百十一条]]第一項の規定による認可を受けないで子会社対象金融機関等（同条第九項に規定する子会社対象金融機関等をいう。以下この号において同じ。）を子会社（同条第一項に規定する子会社をいう。以下この号及び次号において同じ。）としたとき（銀行法[[laws/郵政民営化法/本文/第16条の2.md|第十六条の二]]第一項第十五号に掲げる会社（同条第四項に規定する内閣府令で定める会社を除く。）にあっては、郵便貯金銀行又はその子会社が、合算してその基準議決権数（[[laws/郵政民営化法/本文/第111条.md|第百十一条]]第一項に規定する基準議決権数をいう。以下この号において同じ。）を超える議決権を取得し、又は保有したとき）、同条第三項において準用する同条第一項の規定による認可を受けないで同法第十六条の二第一項各号に掲げる会社を当該各号のうち他の号に掲げる会社（子会社対象金融機関等に限る。）に該当する子会社としたとき、又は[[laws/郵政民営化法/本文/第111条.md|第百十一条]]第四項の規定による認可を受けないで同項に規定する子会社対象会社が同法第十六条の二第一項第十五号に掲げる会社となったことを知った日から一年を超えて郵便貯金銀行若しくはその子会社が当該同号に掲げる会社の議決権を合算してその基準議決権数を超えて保有したとき。
- 四 [[laws/郵政民営化法/本文/第111条.md|第百十一条]]第七項の規定に違反して、銀行（同項に規定する銀行をいう。）を子会社としたとき。
- 五 [[laws/郵政民営化法/本文/第119条.md|第百十九条]]第一項又は[[laws/郵政民営化法/本文/第147条.md|第百四十七条]]第一項の規定による命令（業務の全部又は一部の停止の命令を除く。）に違反したとき。
- 六 [[laws/郵政民営化法/本文/第121条.md|第百二十一条]]第一項又は[[laws/郵政民営化法/本文/第150条.md|第百五十条]]第一項の規定により付した条件に違反したとき。
- 七 [[laws/郵政民営化法/本文/第138条.md|第百三十八条]]第一項の規定に違反して、認可を受けないで同項に規定する保険の種類以外の種類の保険の引受けを行ったとき。
- 八 [[laws/郵政民営化法/本文/第138条.md|第百三十八条]]第二項の規定に違反して、認可を受けないで同項に規定する方法以外の方法により資産の運用を行ったとき。
- 九 [[laws/郵政民営化法/本文/第138条.md|第百三十八条]]第三項の規定に違反して、認可を受けないで業務を行ったとき。
- 十 [[laws/郵政民営化法/本文/第139条.md|第百三十九条]]第一項の規定による認可を受けないで同条第九項に規定する子会社対象会社を子会社（同条第一項に規定する子会社をいう。以下この号及び次号において同じ。）としたとき（保険業法第百六条第一項第十六号に掲げる会社（同条第四項に規定する内閣府令で定める会社を除く。）にあっては、郵便保険会社又はその子会社が、合算してその基準議決権数（[[laws/保険業法/本文/第139条.md|第百三十九条]]第一項に規定する基準議決権数をいう。以下この号において同じ。）を超える議決権を取得し、又は保有したとき）、同条第三項において準用する同条第一項の規定による認可を受けないで同法第百六条第一項各号に掲げる会社を当該各号のうち他の号に掲げる会社（同条第九項に規定する子会社対象会社に限る。）に該当する子会社としたとき、又は[[laws/保険業法/本文/第139条.md|第百三十九条]]第四項の規定による認可を受けないで同項に規定する子会社対象会社が同法第百六条第一項第十六号に掲げる会社となったことを知った日から一年を超えて郵便保険会社若しくはその子会社が当該同号に掲げる会社の議決権を合算してその基準議決権数を超えて保有したとき。
- 十一 [[laws/郵政民営化法/本文/第139条.md|第百三十九条]]第七項の規定に違反して、保険会社等（同項に規定する保険会社等をいう。）を子会社としたとき。
