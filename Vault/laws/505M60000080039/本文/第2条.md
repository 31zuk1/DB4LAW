# 第二条 （学則）

## 
前条第三項第九号の学則中には、少なくとも、次に掲げる事項（留学のための課程を置かない日本語教育機関にあっては、第十号に掲げる事項を除く。）を記載しなければならない。日本語教育課程の修業期間、学期及び授業を行わない日に関する事項教育課程及び授業日時数に関する事項学習の評価及び日本語教育課程修了の要件に関する事項収容定員に関する事項教員及び職員の体制に関する事項入学、退学、転学、休学及び卒業に関する事項授業料、入学料その他の費用徴収及び返還に関する事項賞罰に関する事項寄宿舎を置く場合には、寄宿舎に関する事項健康診断に関する事項

- 一 日本語教育課程の修業期間、学期及び授業を行わない日に関する事項
- 二 教育課程及び授業日時数に関する事項
- 三 学習の評価及び日本語教育課程修了の要件に関する事項
- 四 収容定員に関する事項
- 五 教員及び職員の体制に関する事項
- 六 入学、退学、転学、休学及び卒業に関する事項
- 七 授業料、入学料その他の費用徴収及び返還に関する事項
- 八 賞罰に関する事項
- 九 寄宿舎を置く場合には、寄宿舎に関する事項
- 十 健康診断に関する事項
