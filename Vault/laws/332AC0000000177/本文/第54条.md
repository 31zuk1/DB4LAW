# 第五十四条 

## 
次の各号のいずれかに該当する者は、百万円以下の罰金に処する。[[laws/332AC0000000177/本文/第9条.md|第九条]]第一項（[[laws/332AC0000000177/本文/第10条.md|第十条]]第二項において準用する場合を含む。）の規定により認可に付された条件に違反した者[[laws/332AC0000000177/本文/第13条.md|第十三条]]第一項（[[laws/332AC0000000177/本文/第31条.md|第三十一条]]及び[[laws/332AC0000000177/本文/第34条.md|第三十四条]]第一項において準用する場合を含む。）の規定に違反して水質検査又は施設検査を行わなかつた者[[laws/332AC0000000177/本文/第20条.md|第二十条]]第一項（[[laws/332AC0000000177/本文/第31条.md|第三十一条]]及び[[laws/332AC0000000177/本文/第34条.md|第三十四条]]第一項において準用する場合を含む。）の規定に違反した者[[laws/332AC0000000177/本文/第21条.md|第二十一条]]第一項（[[laws/332AC0000000177/本文/第31条.md|第三十一条]]及び[[laws/332AC0000000177/本文/第34条.md|第三十四条]]第一項において準用する場合を含む。）の規定に違反した者[[laws/332AC0000000177/本文/第22条.md|第二十二条]]（[[laws/332AC0000000177/本文/第31条.md|第三十一条]]及び[[laws/332AC0000000177/本文/第34条.md|第三十四条]]第一項において準用する場合を含む。）の規定に違反した者[[laws/332AC0000000177/本文/第29条.md|第二十九条]]第一項（[[laws/332AC0000000177/本文/第30条.md|第三十条]]第二項において準用する場合を含む。）の規定により認可に付された条件に違反した者[[laws/332AC0000000177/本文/第32条.md|第三十二条]]の規定による確認を受けないで専用水道の布設工事に着手した者[[laws/332AC0000000177/本文/第34条の2.md|第三十四条の二]]第二項の規定に違反した者

- 一 [[laws/332AC0000000177/本文/第9条.md|第九条]]第一項（[[laws/332AC0000000177/本文/第10条.md|第十条]]第二項において準用する場合を含む。）の規定により認可に付された条件に違反した者
- 二 [[laws/332AC0000000177/本文/第13条.md|第十三条]]第一項（[[laws/332AC0000000177/本文/第31条.md|第三十一条]]及び[[laws/332AC0000000177/本文/第34条.md|第三十四条]]第一項において準用する場合を含む。）の規定に違反して水質検査又は施設検査を行わなかつた者
- 三 [[laws/332AC0000000177/本文/第20条.md|第二十条]]第一項（[[laws/332AC0000000177/本文/第31条.md|第三十一条]]及び[[laws/332AC0000000177/本文/第34条.md|第三十四条]]第一項において準用する場合を含む。）の規定に違反した者
- 四 [[laws/332AC0000000177/本文/第21条.md|第二十一条]]第一項（[[laws/332AC0000000177/本文/第31条.md|第三十一条]]及び[[laws/332AC0000000177/本文/第34条.md|第三十四条]]第一項において準用する場合を含む。）の規定に違反した者
- 五 [[laws/332AC0000000177/本文/第22条.md|第二十二条]]（[[laws/332AC0000000177/本文/第31条.md|第三十一条]]及び[[laws/332AC0000000177/本文/第34条.md|第三十四条]]第一項において準用する場合を含む。）の規定に違反した者
- 六 [[laws/332AC0000000177/本文/第29条.md|第二十九条]]第一項（[[laws/332AC0000000177/本文/第30条.md|第三十条]]第二項において準用する場合を含む。）の規定により認可に付された条件に違反した者
- 七 [[laws/332AC0000000177/本文/第32条.md|第三十二条]]の規定による確認を受けないで専用水道の布設工事に着手した者
- 八 [[laws/332AC0000000177/本文/第34条の2.md|第三十四条の二]]第二項の規定に違反した者
