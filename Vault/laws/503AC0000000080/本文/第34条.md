# 第三十四条 （認可の取消し等）

## 
行政庁は、共済団体が次の各号のいずれかに該当することとなったときは、当該共済団体の業務の全部若しくは一部の停止若しくは理事、監事若しくは会計監査人の解任を命じ、又は[[laws/503AC0000000080/本文/第3条.md|第三条]]の認可を取り消すことができる。[[laws/503AC0000000080/本文/第6条.md|第六条]]第一号イからハまで、ホ又はヘに該当することとなったとき。[[laws/503AC0000000080/本文/第6条.md|第六条]]第二号から第四号まで又は第七号から第九号までに掲げる基準に適合しなくなったとき。不正の手段により[[laws/503AC0000000080/本文/第3条.md|第三条]]の認可を受けたとき。法令、法令に基づく行政庁の処分又は[[laws/503AC0000000080/本文/第5条.md|第五条]]第二項各号に掲げる書類に定めた事項のうち特に重要なものに違反したとき。当該認可に付された条件に違反したとき。公益を害する行為をしたとき。

- 一 [[laws/503AC0000000080/本文/第6条.md|第六条]]第一号イからハまで、ホ又はヘに該当することとなったとき。
- 二 [[laws/503AC0000000080/本文/第6条.md|第六条]]第二号から第四号まで又は第七号から第九号までに掲げる基準に適合しなくなったとき。
- 三 不正の手段により[[laws/503AC0000000080/本文/第3条.md|第三条]]の認可を受けたとき。
- 四 法令、法令に基づく行政庁の処分又は[[laws/503AC0000000080/本文/第5条.md|第五条]]第二項各号に掲げる書類に定めた事項のうち特に重要なものに違反したとき。
- 五 当該認可に付された条件に違反したとき。
- 六 公益を害する行為をしたとき。
