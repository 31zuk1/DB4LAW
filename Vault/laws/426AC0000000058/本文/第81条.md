# 第八十一条 （一人で行う宗教上の行為）

## 
在院者が一人で行う礼拝その他の宗教上の行為は、これを禁止し、又は制限してはならない。ただし、少年院の規律及び秩序の維持その他管理運営上支障を生ずるおそれがある場合は、この限りでない。
