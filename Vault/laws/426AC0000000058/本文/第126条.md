# 第百二十六条 （法務大臣の措置）

## 
法務大臣は、救済の申出の内容がその申出をした者に対する次に掲げる少年院の長の措置に係るものであって、その措置が違法又は不当であることを確認した場合において、必要があると認めるときは、その措置の全部又は一部を取り消し、又は変更するものとする。[[laws/少年院法/本文/第55条.md|第五十五条]]第一項の規定による診療を受けることを許さない処分又は同条第四項の規定による診療の中止[[laws/少年院法/本文/第71条.md|第七十一条]]の規定による領置されている現金の使用又は[[laws/少年院法/本文/第72条.md|第七十二条]]の規定による領置されている金品の交付を許さない処分[[laws/少年院法/本文/第79条.md|第七十九条]]第三項の規定による費用を負担させる処分[[laws/少年院法/本文/第81条.md|第八十一条]]に規定する宗教上の行為の禁止又は制限[[laws/少年院法/本文/第100条.md|第百条]]、[[laws/少年院法/本文/第101条.md|第百一条]]、[[laws/少年院法/本文/第102条.md|第百二条]]第一項又は[[laws/少年院法/本文/第105条.md|第百五条]]の規定による信書の発受又は文書図画の交付の禁止、差止め又は制限[[laws/少年院法/本文/第104条.md|第百四条]]第五項前段の規定による発受禁止信書等の引渡しをしない処分[[laws/少年院法/本文/第109条.md|第百九条]]第一項又は第二項の規定による費用を負担させる処分[[laws/少年院法/本文/第113条.md|第百十三条]]第一項の規定による懲戒[[laws/少年院法/本文/第116条.md|第百十六条]]の規定による物を国庫に帰属させる処分[[laws/少年院法/本文/第117条.md|第百十七条]]第四項の規定による措置

- 一 [[laws/少年院法/本文/第55条.md|第五十五条]]第一項の規定による診療を受けることを許さない処分又は同条第四項の規定による診療の中止
- 二 [[laws/少年院法/本文/第71条.md|第七十一条]]の規定による領置されている現金の使用又は[[laws/少年院法/本文/第72条.md|第七十二条]]の規定による領置されている金品の交付を許さない処分
- 三 [[laws/少年院法/本文/第79条.md|第七十九条]]第三項の規定による費用を負担させる処分
- 四 [[laws/少年院法/本文/第81条.md|第八十一条]]に規定する宗教上の行為の禁止又は制限
- 五 [[laws/少年院法/本文/第100条.md|第百条]]、[[laws/少年院法/本文/第101条.md|第百一条]]、[[laws/少年院法/本文/第102条.md|第百二条]]第一項又は[[laws/少年院法/本文/第105条.md|第百五条]]の規定による信書の発受又は文書図画の交付の禁止、差止め又は制限
- 六 [[laws/少年院法/本文/第104条.md|第百四条]]第五項前段の規定による発受禁止信書等の引渡しをしない処分
- 七 [[laws/少年院法/本文/第109条.md|第百九条]]第一項又は第二項の規定による費用を負担させる処分
- 八 [[laws/少年院法/本文/第113条.md|第百十三条]]第一項の規定による懲戒
- 九 [[laws/少年院法/本文/第116条.md|第百十六条]]の規定による物を国庫に帰属させる処分
- 十 [[laws/少年院法/本文/第117条.md|第百十七条]]第四項の規定による措置
## ２
法務大臣は、救済の申出の内容がその申出をした者に対する[[laws/少年院法/本文/第121条.md|第百二十一条]]第一項第五号から第七号までに掲げる少年院の職員による行為に係るものであって、同項第五号に掲げる行為にあってはその行為が違法であることを、同項第六号又は第七号に掲げる行為にあってはその行為が違法又は不当であることを確認した場合において、必要があると認めるときは、同様の行為の再発の防止のため必要な措置その他の措置を執るものとする。
