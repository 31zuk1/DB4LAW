# 第二百三十二条 （限定責任信託の定めの登記）

## 
信託行為において[[laws/信託法/本文/第216条.md|第二百十六条]]第一項の定めがされたときは、限定責任信託の定めの登記は、二週間以内に、次に掲げる事項を登記してしなければならない。限定責任信託の目的限定責任信託の名称受託者の氏名又は名称及び住所限定責任信託の事務処理地[[laws/信託法/本文/第64条.md|第六十四条]]第一項（[[laws/信託法/本文/第74条.md|第七十四条]]第六項において準用する場合を含む。）の規定により信託財産管理者又は信託財産法人管理人が選任されたときは、その氏名又は名称及び住所[[laws/信託法/本文/第163条.md|第百六十三条]]第九号の規定による信託の終了についての信託行為の定めがあるときは、その定め会計監査人設置信託（[[laws/信託法/本文/第248条.md|第二百四十八条]]第三項に規定する会計監査人設置信託をいう。[[laws/信託法/本文/第240条.md|第二百四十条]]第三号において同じ。）であるときは、その旨及び会計監査人の氏名又は名称

- 六 [[laws/信託法/本文/第163条.md|第百六十三条]]第九号の規定による信託の終了についての信託行為の定めがあるときは、その定め
