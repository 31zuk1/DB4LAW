# 第八十一条 （検疫衛生課の所掌事務）

## 
検疫衛生課は、港及び飛行場における診察、検査、隔離、停留その他の検疫及び予防接種その他の防疫（検疫感染症に関する情報の収集及び分析並びにこれらの結果の提供を含む。）を行うこと（輸入食品・検疫検査センターの所掌に属するものを除く。）をつかさどる。
