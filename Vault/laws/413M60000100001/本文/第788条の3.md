# 第七百八十八条の三 （訓練課の所掌事務）

## 
訓練課は、次に掲げる事務をつかさどる。訓練受講者の職業紹介及び職業指導に関すること。訓練受講者の職業の安定に関する政策の企画及び立案に関すること。公共職業訓練に関すること。技能検定に関すること。職業能力開発促進法[[laws/厚生労働省組織規則/本文/第4条.md|第四条]]第二項に規定する事業主その他の関係者による職業能力の開発及び向上の促進並びに労働者の自発的な職業能力の開発及び向上に関すること（他省及び労働基準部の所掌に属するものを除く。）。勤労青少年の福祉の増進に関すること。

- 一 訓練受講者の職業紹介及び職業指導に関すること。
- 二 訓練受講者の職業の安定に関する政策の企画及び立案に関すること。
- 三 公共職業訓練に関すること。
- 四 技能検定に関すること。
- 五 職業能力開発促進法[[laws/厚生労働省組織規則/本文/第4条.md|第四条]]第二項に規定する事業主その他の関係者による職業能力の開発及び向上の促進並びに労働者の自発的な職業能力の開発及び向上に関すること（他省及び労働基準部の所掌に属するものを除く。）。
- 六 勤労青少年の福祉の増進に関すること。
