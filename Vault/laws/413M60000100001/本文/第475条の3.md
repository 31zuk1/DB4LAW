# 第四百七十五条の三 （総務部の所掌事務）

## 
総務部は、次に掲げる事務をつかさどる。公印の保管及び公文書類に関すること。退所者及び非入所者の入所並びに入所者の厚生及び退所に関すること。医療に関する統計に関すること。診療記録の保管に関すること。入所者の給食に関すること。前各号に掲げるもののほか、国立ハンセン病療養所の所掌事務で他の所掌に属しないものに関すること。

- 一 公印の保管及び公文書類に関すること。
- 二 退所者及び非入所者の入所並びに入所者の厚生及び退所に関すること。
- 三 医療に関する統計に関すること。
- 四 診療記録の保管に関すること。
- 五 入所者の給食に関すること。
- 六 前各号に掲げるもののほか、国立ハンセン病療養所の所掌事務で他の所掌に属しないものに関すること。
