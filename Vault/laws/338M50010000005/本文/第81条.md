# 第八十一条 （さめの魚体の所持等の制限）

## 
沿岸まぐろはえ縄漁業を営む者は、採捕したさめを所持したときは、次に掲げる行為をしなければならない。ただし、当該沿岸まぐろはえ縄漁業を営む者が日本国外で当該さめの一部を陸揚げした場合は、この限りでない。当該さめの全ての部分（頭部、内臓及び皮を除く。）を陸揚げまでの間、船上において所持すること。当該さめを陸揚げするときに、前号の規定により所持したものを陸揚げすること。

- 一 当該さめの全ての部分（頭部、内臓及び皮を除く。）を陸揚げまでの間、船上において所持すること。
- 二 当該さめを陸揚げするときに、前号の規定により所持したものを陸揚げすること。
