# 第五十六条 

## 
次の各号のいずれかに該当する者は、三十万円以下の罰金に処する。[[laws/347AC0000000085/本文/第20条.md|第二十条]]、[[laws/347AC0000000085/本文/第29条.md|第二十九条]]第一項又は[[laws/347AC0000000085/本文/第35条の6.md|第三十五条の六]]第一項の規定による報告をせず、又は虚偽の報告をした者[[laws/347AC0000000085/本文/第28条.md|第二十八条]]第一項の規定による届出をせず、又は虚偽の届出をして、同項各号に掲げる行為をした者[[laws/347AC0000000085/本文/第28条.md|第二十八条]]第四項又は[[laws/347AC0000000085/本文/第35条の5.md|第三十五条の五]]第三項の規定に違反した者[[laws/347AC0000000085/本文/第29条.md|第二十九条]]第一項又は[[laws/347AC0000000085/本文/第35条の6.md|第三十五条の六]]第一項の規定による立入検査又は立入調査を拒み、妨げ、又は忌避した者[[laws/347AC0000000085/本文/第31条.md|第三十一条]]第五項の規定に違反して、同条第一項の規定による立入りその他の行為を拒み、又は妨げた者[[laws/347AC0000000085/本文/第35条の5.md|第三十五条の五]]第一項の規定による届出をせず、又は虚偽の届出をして、特定行為をした者

- 一 [[laws/347AC0000000085/本文/第20条.md|第二十条]]、[[laws/347AC0000000085/本文/第29条.md|第二十九条]]第一項又は[[laws/347AC0000000085/本文/第35条の6.md|第三十五条の六]]第一項の規定による報告をせず、又は虚偽の報告をした者
- 二 [[laws/347AC0000000085/本文/第28条.md|第二十八条]]第一項の規定による届出をせず、又は虚偽の届出をして、同項各号に掲げる行為をした者
- 三 [[laws/347AC0000000085/本文/第28条.md|第二十八条]]第四項又は[[laws/347AC0000000085/本文/第35条の5.md|第三十五条の五]]第三項の規定に違反した者
- 四 [[laws/347AC0000000085/本文/第29条.md|第二十九条]]第一項又は[[laws/347AC0000000085/本文/第35条の6.md|第三十五条の六]]第一項の規定による立入検査又は立入調査を拒み、妨げ、又は忌避した者
- 五 [[laws/347AC0000000085/本文/第31条.md|第三十一条]]第五項の規定に違反して、同条第一項の規定による立入りその他の行為を拒み、又は妨げた者
- 六 [[laws/347AC0000000085/本文/第35条の5.md|第三十五条の五]]第一項の規定による届出をせず、又は虚偽の届出をして、特定行為をした者
