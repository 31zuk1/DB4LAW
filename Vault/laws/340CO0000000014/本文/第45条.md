# 第四十五条 （国土交通大臣の認可）

## 
法[[laws/河川法施行令/本文/第79条.md|第七十九条]]第一項の一級河川の管理で政令で定めるものは、次に掲げるものとする。河川整備計画を定め、又は変更すること。次に掲げる施設に係る改良工事ダム（基礎地盤から堤頂までの高さが十五メートル未満のものを除く。）地下に設ける河川管理施設で国土交通省令で定めるもの前号ロに掲げる施設に係る改良工事につき、法[[laws/河川法施行令/本文/第16条の3.md|第十六条の三]]第一項の規定による協議に応じること。特定水利使用以外の水利使用で[[laws/河川法施行令/本文/第20条の2.md|第二十条の二]]各号に掲げるものに関する法[[laws/河川法施行令/本文/第23条.md|第二十三条]]の許可、法[[laws/河川法施行令/本文/第24条.md|第二十四条]]若しくは[[laws/河川法施行令/本文/第26条.md|第二十六条]]第一項の許可（法[[laws/河川法施行令/本文/第23条の2.md|第二十三条の二]]の登録の対象となる流水の占用に係る水利使用に関する許可を除く。）若しくは法[[laws/河川法施行令/本文/第34条.md|第三十四条]]第一項に規定する許可（法[[laws/河川法施行令/本文/第23条の2.md|第二十三条の二]]の登録の対象となる流水の占用に係る水利使用に関する法[[laws/河川法施行令/本文/第24条.md|第二十四条]]の許可を除く。）に係る同項の承認又はこれらの許可若しくは承認に係る法[[laws/河川法施行令/本文/第75条.md|第七十五条]]の規定による処分ダム、水門、閘こう門、橋その他の工作物で治水上又は利水上影響が著しいと認められるものに係る法[[laws/河川法施行令/本文/第26条.md|第二十六条]]第一項の許可（水利使用に関するものを除く。）及び当該許可に係る法[[laws/河川法施行令/本文/第75条.md|第七十五条]]の規定による処分河川区域内の土地の現状に著しい影響を及ぼすおそれがあると認められる土地の掘削等に係る法[[laws/河川法施行令/本文/第27条.md|第二十七条]]第一項の許可

- 一 河川整備計画を定め、又は変更すること。
- 二 次に掲げる施設に係る改良工事
- 三 前号ロに掲げる施設に係る改良工事につき、法[[laws/河川法施行令/本文/第16条の3.md|第十六条の三]]第一項の規定による協議に応じること。
- 四 特定水利使用以外の水利使用で[[laws/河川法施行令/本文/第20条の2.md|第二十条の二]]各号に掲げるものに関する法[[laws/河川法施行令/本文/第23条.md|第二十三条]]の許可、法[[laws/河川法施行令/本文/第24条.md|第二十四条]]若しくは[[laws/河川法施行令/本文/第26条.md|第二十六条]]第一項の許可（法[[laws/河川法施行令/本文/第23条の2.md|第二十三条の二]]の登録の対象となる流水の占用に係る水利使用に関する許可を除く。）若しくは法[[laws/河川法施行令/本文/第34条.md|第三十四条]]第一項に規定する許可（法[[laws/河川法施行令/本文/第23条の2.md|第二十三条の二]]の登録の対象となる流水の占用に係る水利使用に関する法[[laws/河川法施行令/本文/第24条.md|第二十四条]]の許可を除く。）に係る同項の承認又はこれらの許可若しくは承認に係る法[[laws/河川法施行令/本文/第75条.md|第七十五条]]の規定による処分
- 五 ダム、水門、閘こう門、橋その他の工作物で治水上又は利水上影響が著しいと認められるものに係る法[[laws/河川法施行令/本文/第26条.md|第二十六条]]第一項の許可（水利使用に関するものを除く。）及び当該許可に係る法[[laws/河川法施行令/本文/第75条.md|第七十五条]]の規定による処分
- 六 河川区域内の土地の現状に著しい影響を及ぼすおそれがあると認められる土地の掘削等に係る法[[laws/河川法施行令/本文/第27条.md|第二十七条]]第一項の許可
