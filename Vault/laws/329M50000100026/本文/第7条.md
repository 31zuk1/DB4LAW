# 第七条 （事故の届出書）

## 
法[[laws/329M50000100026/本文/第20条.md|第二十条]]（法[[laws/329AC0000000071/本文/第37条.md|第三十七条]]の規定において準用する場合を含む。）の規定による事故の届出は、左に掲げる事項を記載した届出書（第七号様式）によるものとする。栽培許可証の番号及び許可の年月日けし栽培者の種別事故発生の場所事故の内容及び発生の状況事故発生の年月日事故があつたあへん又はけしがらの数量

- 一 栽培許可証の番号及び許可の年月日
- 二 けし栽培者の種別
- 三 事故発生の場所
- 四 事故の内容及び発生の状況
- 五 事故発生の年月日
- 六 事故があつたあへん又はけしがらの数量
## ２
前項の届出書には、前項第三号の場所を示す略図を添附しなければならない。
