# 第百十四条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、三十万円以下の罰金に処する。[[laws/資金決済に関する法律/本文/第5条.md|第五条]]第三項、[[laws/資金決済に関する法律/本文/第11条.md|第十一条]]第一項、[[laws/資金決済に関する法律/本文/第11条の2.md|第十一条の二]]第一項若しくは第二項、[[laws/資金決済に関する法律/本文/第40条の2.md|第四十条の二]]第二項、[[laws/資金決済に関する法律/本文/第41条.md|第四十一条]]第三項若しくは第四項、[[laws/資金決済に関する法律/本文/第62条の7.md|第六十二条の七]]第三項若しくは第四項若しくは[[laws/資金決済に関する法律/本文/第63条の6.md|第六十三条の六]]第一項若しくは第二項の規定による届出をせず、又は虚偽の届出をしたとき。[[laws/資金決済に関する法律/本文/第13条.md|第十三条]]第一項の規定による情報の提供をせず、又は虚偽の情報の提供をしたとき。[[laws/資金決済に関する法律/本文/第20条.md|第二十条]]第四項、[[laws/資金決済に関する法律/本文/第61条.md|第六十一条]]第七項、[[laws/資金決済に関する法律/本文/第62条の25.md|第六十二条の二十五]]第七項若しくは[[laws/資金決済に関する法律/本文/第63条の20.md|第六十三条の二十]]第七項において準用する会社法[[laws/会社法/本文/第955条.md|第九百五十五条]]第一項の規定に違反して、調査記録簿等（同項に規定する調査記録簿等をいう。以下この号において同じ。）に同項に規定する電子公告調査に関し法務省令で定めるものを記載せず、若しくは記録せず、若しくは虚偽の記載若しくは記録をし、又は同項の規定に違反して調査記録簿等を保存しなかったとき。[[laws/資金決済に関する法律/本文/第25条.md|第二十五条]]の規定による命令に違反したとき。[[laws/資金決済に関する法律/本文/第30条.md|第三十条]]第二項の規定による届出書若しくは同条第三項の規定による添付書類を提出せず、又は虚偽の記載をした届出書若しくは添付書類を提出したとき。[[laws/資金決済に関する法律/本文/第30条.md|第三十条]]第四項の規定による届出をせず、又は虚偽の届出をしたとき。[[laws/資金決済に関する法律/本文/第63条の27.md|第六十三条の二十七]]第二項、[[laws/会社法/本文/第63条の33.md|第六十三条の三十三]]第二項、[[laws/会社法/本文/第69条.md|第六十九条]]第二項若しくは[[laws/資金決済に関する法律/本文/第77条.md|第七十七条]]の規定による届出をせず、又は虚偽の届出をしたとき。[[laws/資金決済に関する法律/本文/第63条の32.md|第六十三条の三十二]]又は[[laws/資金決済に関する法律/本文/第76条.md|第七十六条]]の規定に違反したとき。[[laws/資金決済に関する法律/本文/第89条.md|第八十九条]]第三項の規定に違反して、その名称中に認定資金決済事業者協会の会員（[[laws/資金決済に関する法律/本文/第87条.md|第八十七条]]第二号に規定する会員をいう。以下同じ。）と誤認されるおそれのある文字を用いたとき。[[laws/資金決済に関する法律/本文/第100条.md|第百条]]第三項の規定による通知をせず、又は虚偽の通知をしたとき。

- 一 [[laws/資金決済に関する法律/本文/第5条.md|第五条]]第三項、[[laws/資金決済に関する法律/本文/第11条.md|第十一条]]第一項、[[laws/資金決済に関する法律/本文/第11条の2.md|第十一条の二]]第一項若しくは第二項、[[laws/資金決済に関する法律/本文/第40条の2.md|第四十条の二]]第二項、[[laws/資金決済に関する法律/本文/第41条.md|第四十一条]]第三項若しくは第四項、[[laws/資金決済に関する法律/本文/第62条の7.md|第六十二条の七]]第三項若しくは第四項若しくは[[laws/資金決済に関する法律/本文/第63条の6.md|第六十三条の六]]第一項若しくは第二項の規定による届出をせず、又は虚偽の届出をしたとき。
- 二 [[laws/資金決済に関する法律/本文/第13条.md|第十三条]]第一項の規定による情報の提供をせず、又は虚偽の情報の提供をしたとき。
- 三 [[laws/資金決済に関する法律/本文/第20条.md|第二十条]]第四項、[[laws/資金決済に関する法律/本文/第61条.md|第六十一条]]第七項、[[laws/資金決済に関する法律/本文/第62条の25.md|第六十二条の二十五]]第七項若しくは[[laws/資金決済に関する法律/本文/第63条の20.md|第六十三条の二十]]第七項において準用する会社法[[laws/会社法/本文/第955条.md|第九百五十五条]]第一項の規定に違反して、調査記録簿等（同項に規定する調査記録簿等をいう。以下この号において同じ。）に同項に規定する電子公告調査に関し法務省令で定めるものを記載せず、若しくは記録せず、若しくは虚偽の記載若しくは記録をし、又は同項の規定に違反して調査記録簿等を保存しなかったとき。
- 四 [[laws/資金決済に関する法律/本文/第25条.md|第二十五条]]の規定による命令に違反したとき。
- 五 [[laws/資金決済に関する法律/本文/第30条.md|第三十条]]第二項の規定による届出書若しくは同条第三項の規定による添付書類を提出せず、又は虚偽の記載をした届出書若しくは添付書類を提出したとき。
- 六 [[laws/資金決済に関する法律/本文/第30条.md|第三十条]]第四項の規定による届出をせず、又は虚偽の届出をしたとき。
- 七 [[laws/資金決済に関する法律/本文/第63条の27.md|第六十三条の二十七]]第二項、[[laws/資金決済に関する法律/本文/第63条の33.md|第六十三条の三十三]]第二項、[[laws/資金決済に関する法律/本文/第69条.md|第六十九条]]第二項若しくは[[laws/資金決済に関する法律/本文/第77条.md|第七十七条]]の規定による届出をせず、又は虚偽の届出をしたとき。
- 八 [[laws/資金決済に関する法律/本文/第63条の32.md|第六十三条の三十二]]又は[[laws/資金決済に関する法律/本文/第76条.md|第七十六条]]の規定に違反したとき。
- 九 [[laws/資金決済に関する法律/本文/第89条.md|第八十九条]]第三項の規定に違反して、その名称中に認定資金決済事業者協会の会員（[[laws/資金決済に関する法律/本文/第87条.md|第八十七条]]第二号に規定する会員をいう。以下同じ。）と誤認されるおそれのある文字を用いたとき。
- 十 [[laws/資金決済に関する法律/本文/第100条.md|第百条]]第三項の規定による通知をせず、又は虚偽の通知をしたとき。
