# 第百九条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、一年以下の拘禁刑若しくは三百万円以下の罰金に処し、又はこれを併科する。[[laws/資金決済に関する法律/本文/第20条.md|第二十条]]第二項、[[laws/資金決済に関する法律/本文/第61条.md|第六十一条]]第三項、[[laws/資金決済に関する法律/本文/第62条の25.md|第六十二条の二十五]]第三項若しくは[[laws/資金決済に関する法律/本文/第63条の20.md|第六十三条の二十]]第三項の規定による公告をせず、又は虚偽の公告をしたとき。[[laws/資金決済に関する法律/本文/第43条.md|第四十三条]]第一項の規定に違反して、供託を行わなかったとき。[[laws/資金決済に関する法律/本文/第45条の2.md|第四十五条の二]]第一項後段の規定に違反して、同項第一号に規定する預貯金等管理方法による管理を行わなかったとき。[[laws/資金決済に関する法律/本文/第46条.md|第四十六条]]の規定による命令に違反して、供託を行わなかったとき。[[laws/資金決済に関する法律/本文/第52条.md|第五十二条]]、[[laws/資金決済に関する法律/本文/第62条の18.md|第六十二条の十八]]、[[laws/資金決済に関する法律/本文/第63条の13.md|第六十三条の十三]]若しくは[[laws/資金決済に関する法律/本文/第78条.md|第七十八条]]の規定による帳簿書類の作成若しくは保存をせず、又は虚偽の帳簿書類の作成をしたとき。[[laws/資金決済に関する法律/本文/第53条.md|第五十三条]]第一項若しくは第二項、[[laws/資金決済に関する法律/本文/第62条の19.md|第六十二条の十九]]第一項若しくは第二項、[[laws/資金決済に関する法律/本文/第63条の14.md|第六十三条の十四]]第一項若しくは第二項、[[laws/資金決済に関する法律/本文/第63条の34.md|第六十三条の三十四]]若しくは[[laws/資金決済に関する法律/本文/第79条.md|第七十九条]]の規定による報告書若しくは[[laws/資金決済に関する法律/本文/第53条.md|第五十三条]]第三項、[[laws/資金決済に関する法律/本文/第62条の19.md|第六十二条の十九]]第三項若しくは第四項若しくは[[laws/資金決済に関する法律/本文/第63条の14.md|第六十三条の十四]]第三項若しくは第四項の規定による添付書類を提出せず、又は虚偽の記載をした報告書若しくは添付書類を提出したとき。[[laws/資金決済に関する法律/本文/第54条.md|第五十四条]]第一項若しくは第二項、[[laws/資金決済に関する法律/本文/第62条の20.md|第六十二条の二十]]第一項若しくは第二項、[[laws/資金決済に関する法律/本文/第63条の15.md|第六十三条の十五]]第一項若しくは第二項、[[laws/資金決済に関する法律/本文/第63条の35.md|第六十三条の三十五]]第一項若しくは第二項若しくは[[laws/資金決済に関する法律/本文/第80条.md|第八十条]]第一項若しくは第二項の規定による報告若しくは資料の提出をせず、又は虚偽の報告若しくは資料の提出をしたとき。[[laws/資金決済に関する法律/本文/第54条.md|第五十四条]]第一項若しくは第二項、[[laws/資金決済に関する法律/本文/第62条の20.md|第六十二条の二十]]第一項若しくは第二項、[[laws/資金決済に関する法律/本文/第63条の15.md|第六十三条の十五]]第一項若しくは第二項、[[laws/資金決済に関する法律/本文/第63条の35.md|第六十三条の三十五]]第一項若しくは第二項若しくは[[laws/資金決済に関する法律/本文/第80条.md|第八十条]]第一項若しくは第二項の規定による当該職員の質問に対して答弁をせず、若しくは虚偽の答弁をし、又はこれらの規定による検査を拒み、妨げ、若しくは忌避したとき。[[laws/資金決済に関する法律/本文/第62条の17.md|第六十二条の十七]]第一項において準用する金融商品取引法（以下「準用金融商品取引法」という。）第三十八条（第一号に係る部分に限る。）の規定に違反したとき。[[laws/資金決済に関する法律/本文/第63条の9.md|第六十三条の九]]の三の規定に違反して、同条第一号に掲げる行為をしたとき。[[laws/資金決済に関する法律/本文/第63条の24.md|第六十三条の二十四]]第一項（[[laws/資金決済に関する法律/本文/第63条の33.md|第六十三条の三十三]]第三項において準用する場合を含む。）の規定による許可申請書又は[[laws/資金決済に関する法律/本文/第63条の24.md|第六十三条の二十四]]第二項（[[laws/資金決済に関する法律/本文/第63条の33.md|第六十三条の三十三]]第三項において準用する場合を含む。）の規定による添付書類に虚偽の記載をして提出したとき。[[laws/資金決済に関する法律/本文/第65条.md|第六十五条]]第一項の規定による免許申請書又は同条第二項の規定による添付書類に虚偽の記載をして提出したとき。

- 一 [[laws/資金決済に関する法律/本文/第20条.md|第二十条]]第二項、[[laws/資金決済に関する法律/本文/第61条.md|第六十一条]]第三項、[[laws/資金決済に関する法律/本文/第62条の25.md|第六十二条の二十五]]第三項若しくは[[laws/資金決済に関する法律/本文/第63条の20.md|第六十三条の二十]]第三項の規定による公告をせず、又は虚偽の公告をしたとき。
- 二 [[laws/資金決済に関する法律/本文/第43条.md|第四十三条]]第一項の規定に違反して、供託を行わなかったとき。
- 三 [[laws/資金決済に関する法律/本文/第45条の2.md|第四十五条の二]]第一項後段の規定に違反して、同項第一号に規定する預貯金等管理方法による管理を行わなかったとき。
- 四 [[laws/資金決済に関する法律/本文/第46条.md|第四十六条]]の規定による命令に違反して、供託を行わなかったとき。
- 五 [[laws/資金決済に関する法律/本文/第52条.md|第五十二条]]、[[laws/資金決済に関する法律/本文/第62条の18.md|第六十二条の十八]]、[[laws/資金決済に関する法律/本文/第63条の13.md|第六十三条の十三]]若しくは[[laws/資金決済に関する法律/本文/第78条.md|第七十八条]]の規定による帳簿書類の作成若しくは保存をせず、又は虚偽の帳簿書類の作成をしたとき。
- 六 [[laws/資金決済に関する法律/本文/第53条.md|第五十三条]]第一項若しくは第二項、[[laws/資金決済に関する法律/本文/第62条の19.md|第六十二条の十九]]第一項若しくは第二項、[[laws/資金決済に関する法律/本文/第63条の14.md|第六十三条の十四]]第一項若しくは第二項、[[laws/資金決済に関する法律/本文/第63条の34.md|第六十三条の三十四]]若しくは[[laws/資金決済に関する法律/本文/第79条.md|第七十九条]]の規定による報告書若しくは[[laws/資金決済に関する法律/本文/第53条.md|第五十三条]]第三項、[[laws/資金決済に関する法律/本文/第62条の19.md|第六十二条の十九]]第三項若しくは第四項若しくは[[laws/資金決済に関する法律/本文/第63条の14.md|第六十三条の十四]]第三項若しくは第四項の規定による添付書類を提出せず、又は虚偽の記載をした報告書若しくは添付書類を提出したとき。
- 七 [[laws/資金決済に関する法律/本文/第54条.md|第五十四条]]第一項若しくは第二項、[[laws/資金決済に関する法律/本文/第62条の20.md|第六十二条の二十]]第一項若しくは第二項、[[laws/資金決済に関する法律/本文/第63条の15.md|第六十三条の十五]]第一項若しくは第二項、[[laws/資金決済に関する法律/本文/第63条の35.md|第六十三条の三十五]]第一項若しくは第二項若しくは[[laws/資金決済に関する法律/本文/第80条.md|第八十条]]第一項若しくは第二項の規定による報告若しくは資料の提出をせず、又は虚偽の報告若しくは資料の提出をしたとき。
- 八 [[laws/資金決済に関する法律/本文/第54条.md|第五十四条]]第一項若しくは第二項、[[laws/資金決済に関する法律/本文/第62条の20.md|第六十二条の二十]]第一項若しくは第二項、[[laws/資金決済に関する法律/本文/第63条の15.md|第六十三条の十五]]第一項若しくは第二項、[[laws/資金決済に関する法律/本文/第63条の35.md|第六十三条の三十五]]第一項若しくは第二項若しくは[[laws/資金決済に関する法律/本文/第80条.md|第八十条]]第一項若しくは第二項の規定による当該職員の質問に対して答弁をせず、若しくは虚偽の答弁をし、又はこれらの規定による検査を拒み、妨げ、若しくは忌避したとき。
- 九 [[laws/資金決済に関する法律/本文/第62条の17.md|第六十二条の十七]]第一項において準用する金融商品取引法（以下「準用金融商品取引法」という。）第三十八条（第一号に係る部分に限る。）の規定に違反したとき。
- 十 [[laws/資金決済に関する法律/本文/第63条の9.md|第六十三条の九]]の三の規定に違反して、同条第一号に掲げる行為をしたとき。
- 十一 [[laws/資金決済に関する法律/本文/第63条の24.md|第六十三条の二十四]]第一項（[[laws/資金決済に関する法律/本文/第63条の33.md|第六十三条の三十三]]第三項において準用する場合を含む。）の規定による許可申請書又は[[laws/資金決済に関する法律/本文/第63条の24.md|第六十三条の二十四]]第二項（[[laws/資金決済に関する法律/本文/第63条の33.md|第六十三条の三十三]]第三項において準用する場合を含む。）の規定による添付書類に虚偽の記載をして提出したとき。
- 十二 [[laws/資金決済に関する法律/本文/第65条.md|第六十五条]]第一項の規定による免許申請書又は同条第二項の規定による添付書類に虚偽の記載をして提出したとき。
