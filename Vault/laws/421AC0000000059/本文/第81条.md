# 第八十一条 （業務改善命令）

## 
内閣総理大臣は、資金清算業の適正かつ確実な遂行のために必要があると認めるときは、その必要の限度において、資金清算機関に対し、業務の運営又は財産の状況の改善に必要な措置その他監督上必要な措置をとるべきことを命ずることができる。
