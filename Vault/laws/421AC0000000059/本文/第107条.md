# 第百七条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、三年以下の拘禁刑若しくは三百万円以下の罰金に処し、又はこれを併科する。[[laws/421AC0000000059/本文/第7条.md|第七条]]の登録を受けないで第三者型前払式支払手段（[[laws/421AC0000000059/本文/第3条.md|第三条]]第五項に規定する第三者型前払式支払手段をいう。第三号において同じ。）の発行の業務を行ったとき。不正の手段により[[laws/421AC0000000059/本文/第7条.md|第七条]]、[[laws/421AC0000000059/本文/第37条.md|第三十七条]]、[[laws/421AC0000000059/本文/第62条の3.md|第六十二条の三]]若しくは[[laws/421AC0000000059/本文/第63条の2.md|第六十三条の二]]の登録又は[[laws/421AC0000000059/本文/第41条.md|第四十一条]]第一項若しくは[[laws/421AC0000000059/本文/第62条の7.md|第六十二条の七]]第一項の変更登録を受けたとき。[[laws/421AC0000000059/本文/第12条.md|第十二条]]の規定に違反して、他人に第三者型前払式支払手段の発行の業務を行わせたとき。[[laws/421AC0000000059/本文/第37条の2.md|第三十七条の二]]第二項の規定により読み替えて適用する[[laws/421AC0000000059/本文/第56条.md|第五十六条]]第一項の規定による特定資金移動業の廃止の命令に違反したとき。[[laws/421AC0000000059/本文/第37条の2.md|第三十七条の二]]第三項の規定による届出をしないで特定資金移動業を営み、若しくは虚偽の届出をし、又は同項の規定により当該届出に添付すべき書類に虚偽の記載をしてこれを提出したとき。[[laws/421AC0000000059/本文/第41条.md|第四十一条]]第一項の変更登録を受けないで新たな種別の資金移動業を営んだとき。[[laws/421AC0000000059/本文/第42条.md|第四十二条]]の規定に違反して、他人に資金移動業を営ませたとき。[[laws/421AC0000000059/本文/第62条の3.md|第六十二条の三]]の規定に違反して、同条の登録を受けないで電子決済手段等取引業を行ったとき。[[laws/421AC0000000059/本文/第62条の7.md|第六十二条の七]]第一項の変更登録を受けないで新たな種別の電子決済手段等取引業を行ったとき。[[laws/421AC0000000059/本文/第62条の8.md|第六十二条の八]]第二項の規定により読み替えて適用する[[laws/421AC0000000059/本文/第62条の22.md|第六十二条の二十二]]第一項の規定による電子決済手段等取引業の廃止の命令に違反したとき。[[laws/421AC0000000059/本文/第62条の9.md|第六十二条の九]]の規定に違反して、他人に電子決済手段等取引業を行わせたとき。[[laws/421AC0000000059/本文/第63条の2.md|第六十三条の二]]の登録を受けないで暗号資産交換業を行ったとき。[[laws/421AC0000000059/本文/第63条の7.md|第六十三条の七]]の規定に違反して、他人に暗号資産交換業を行わせたとき。[[laws/421AC0000000059/本文/第63条の23.md|第六十三条の二十三]]の規定に違反して、同条の許可を受けないで為替取引分析業を行ったとき。不正の手段により[[laws/421AC0000000059/本文/第63条の23.md|第六十三条の二十三]]又は[[laws/421AC0000000059/本文/第63条の33.md|第六十三条の三十三]]第一項の許可を受けたとき。[[laws/421AC0000000059/本文/第63条の26.md|第六十三条の二十六]]の規定に違反して、他人に為替取引分析業を行わせたとき。[[laws/421AC0000000059/本文/第63条の33.md|第六十三条の三十三]]第一項の許可を受けないで新たな種別の為替取引分析業を行ったとき。[[laws/421AC0000000059/本文/第64条.md|第六十四条]]第一項の規定に違反して、同項の免許を受けないで資金清算業を行ったとき。不正の手段により[[laws/421AC0000000059/本文/第64条.md|第六十四条]]第一項の免許を受けたとき。

- 一 [[laws/421AC0000000059/本文/第7条.md|第七条]]の登録を受けないで第三者型前払式支払手段（[[laws/421AC0000000059/本文/第3条.md|第三条]]第五項に規定する第三者型前払式支払手段をいう。第三号において同じ。）の発行の業務を行ったとき。
- 二 不正の手段により[[laws/421AC0000000059/本文/第7条.md|第七条]]、[[laws/421AC0000000059/本文/第37条.md|第三十七条]]、[[laws/421AC0000000059/本文/第62条の3.md|第六十二条の三]]若しくは[[laws/421AC0000000059/本文/第63条の2.md|第六十三条の二]]の登録又は[[laws/421AC0000000059/本文/第41条.md|第四十一条]]第一項若しくは[[laws/421AC0000000059/本文/第62条の7.md|第六十二条の七]]第一項の変更登録を受けたとき。
- 三 [[laws/421AC0000000059/本文/第12条.md|第十二条]]の規定に違反して、他人に第三者型前払式支払手段の発行の業務を行わせたとき。
- 四 [[laws/421AC0000000059/本文/第37条の2.md|第三十七条の二]]第二項の規定により読み替えて適用する[[laws/421AC0000000059/本文/第56条.md|第五十六条]]第一項の規定による特定資金移動業の廃止の命令に違反したとき。
- 五 [[laws/421AC0000000059/本文/第37条の2.md|第三十七条の二]]第三項の規定による届出をしないで特定資金移動業を営み、若しくは虚偽の届出をし、又は同項の規定により当該届出に添付すべき書類に虚偽の記載をしてこれを提出したとき。
- 六 [[laws/421AC0000000059/本文/第41条.md|第四十一条]]第一項の変更登録を受けないで新たな種別の資金移動業を営んだとき。
- 七 [[laws/421AC0000000059/本文/第42条.md|第四十二条]]の規定に違反して、他人に資金移動業を営ませたとき。
- 八 [[laws/421AC0000000059/本文/第62条の3.md|第六十二条の三]]の規定に違反して、同条の登録を受けないで電子決済手段等取引業を行ったとき。
- 九 [[laws/421AC0000000059/本文/第62条の7.md|第六十二条の七]]第一項の変更登録を受けないで新たな種別の電子決済手段等取引業を行ったとき。
- 十 [[laws/421AC0000000059/本文/第62条の8.md|第六十二条の八]]第二項の規定により読み替えて適用する[[laws/421AC0000000059/本文/第62条の22.md|第六十二条の二十二]]第一項の規定による電子決済手段等取引業の廃止の命令に違反したとき。
- 十一 [[laws/421AC0000000059/本文/第62条の9.md|第六十二条の九]]の規定に違反して、他人に電子決済手段等取引業を行わせたとき。
- 十二 [[laws/421AC0000000059/本文/第63条の2.md|第六十三条の二]]の登録を受けないで暗号資産交換業を行ったとき。
- 十三 [[laws/421AC0000000059/本文/第63条の7.md|第六十三条の七]]の規定に違反して、他人に暗号資産交換業を行わせたとき。
- 十四 [[laws/421AC0000000059/本文/第63条の23.md|第六十三条の二十三]]の規定に違反して、同条の許可を受けないで為替取引分析業を行ったとき。
- 十五 不正の手段により[[laws/421AC0000000059/本文/第63条の23.md|第六十三条の二十三]]又は[[laws/421AC0000000059/本文/第63条の33.md|第六十三条の三十三]]第一項の許可を受けたとき。
- 十六 [[laws/421AC0000000059/本文/第63条の26.md|第六十三条の二十六]]の規定に違反して、他人に為替取引分析業を行わせたとき。
- 十七 [[laws/421AC0000000059/本文/第63条の33.md|第六十三条の三十三]]第一項の許可を受けないで新たな種別の為替取引分析業を行ったとき。
- 十八 [[laws/421AC0000000059/本文/第64条.md|第六十四条]]第一項の規定に違反して、同項の免許を受けないで資金清算業を行ったとき。
- 十九 不正の手段により[[laws/421AC0000000059/本文/第64条.md|第六十四条]]第一項の免許を受けたとき。
