# 第百十二条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、六月以下の拘禁刑若しくは五十万円以下の罰金に処し、又はこれを併科する。[[laws/421AC0000000059/本文/第5条.md|第五条]]第一項の規定による届出書若しくは同条第二項の規定による添付書類を提出せず、又は虚偽の記載をした届出書若しくは添付書類を提出したとき。[[laws/421AC0000000059/本文/第8条.md|第八条]]第一項の規定による登録申請書若しくは同条第二項の規定による添付書類、[[laws/421AC0000000059/本文/第38条.md|第三十八条]]第一項（[[laws/421AC0000000059/本文/第41条.md|第四十一条]]第二項において準用する場合を含む。）の規定による登録申請書若しくは[[laws/421AC0000000059/本文/第38条.md|第三十八条]]第二項（[[laws/421AC0000000059/本文/第41条.md|第四十一条]]第二項において準用する場合を含む。）の規定による添付書類、[[laws/421AC0000000059/本文/第62条の4.md|第六十二条の四]]第一項（[[laws/421AC0000000059/本文/第62条の7.md|第六十二条の七]]第二項において準用する場合を含む。）の規定による登録申請書若しくは[[laws/421AC0000000059/本文/第62条の4.md|第六十二条の四]]第二項（[[laws/421AC0000000059/本文/第62条の7.md|第六十二条の七]]第二項において準用する場合を含む。）の規定による添付書類又は[[laws/421AC0000000059/本文/第63条の3.md|第六十三条の三]]第一項の規定による登録申請書若しくは同条第二項の規定による添付書類に虚偽の記載をして提出したとき。[[laws/421AC0000000059/本文/第14条.md|第十四条]]第一項又は第二項の規定に違反して、供託を行わなかったとき。[[laws/421AC0000000059/本文/第17条.md|第十七条]]の規定による命令に違反して、供託を行わなかったとき。[[laws/421AC0000000059/本文/第22条.md|第二十二条]]の規定による帳簿書類の作成若しくは保存をせず、又は虚偽の帳簿書類の作成をしたとき。[[laws/421AC0000000059/本文/第23条.md|第二十三条]]第一項の規定による報告書若しくは同条第二項の規定による添付書類を提出せず、又は虚偽の記載をした報告書若しくは添付書類を提出したとき。[[laws/421AC0000000059/本文/第24条.md|第二十四条]]第一項若しくは第二項の規定による報告若しくは資料の提出をせず、又は虚偽の報告若しくは資料の提出をしたとき。[[laws/421AC0000000059/本文/第24条.md|第二十四条]]第一項若しくは第二項の規定による当該職員の質問に対して答弁をせず、若しくは虚偽の答弁をし、又はこれらの規定による検査を拒み、妨げ、若しくは忌避したとき。準用金融商品取引法[[laws/323AC0000000025/本文/第37条.md|第三十七条]]第一項に規定する事項を表示せず、又は虚偽の表示をしたとき。準用金融商品取引法[[laws/323AC0000000025/本文/第37条.md|第三十七条]]第二項の規定に違反したとき。準用金融商品取引法[[laws/323AC0000000025/本文/第37条の3.md|第三十七条の三]]第一項の規定に違反して、同項の規定による情報の提供をせず、又は虚偽の情報の提供をしたとき。準用金融商品取引法[[laws/323AC0000000025/本文/第37条の4.md|第三十七条の四]]の規定に違反して、同条の規定による情報の提供をせず、又は虚偽の情報の提供をしたとき。[[laws/421AC0000000059/本文/第63条の9.md|第六十三条の九]]の二に規定する事項を表示しなかったとき。[[laws/421AC0000000059/本文/第63条の9.md|第六十三条の九]]の三の規定に違反して、同条第二号又は第三号に掲げる行為をしたとき。[[laws/421AC0000000059/本文/第95条.md|第九十五条]]の規定による報告若しくは資料の提出をせず、又は虚偽の報告若しくは資料の提出をしたとき。[[laws/421AC0000000059/本文/第95条.md|第九十五条]]の規定による当該職員の質問に対して答弁をせず、若しくは虚偽の答弁をし、又は同条の規定による検査を拒み、妨げ、若しくは忌避したとき。

- 一 [[laws/421AC0000000059/本文/第5条.md|第五条]]第一項の規定による届出書若しくは同条第二項の規定による添付書類を提出せず、又は虚偽の記載をした届出書若しくは添付書類を提出したとき。
- 二 [[laws/421AC0000000059/本文/第8条.md|第八条]]第一項の規定による登録申請書若しくは同条第二項の規定による添付書類、[[laws/421AC0000000059/本文/第38条.md|第三十八条]]第一項（[[laws/421AC0000000059/本文/第41条.md|第四十一条]]第二項において準用する場合を含む。）の規定による登録申請書若しくは[[laws/421AC0000000059/本文/第38条.md|第三十八条]]第二項（[[laws/421AC0000000059/本文/第41条.md|第四十一条]]第二項において準用する場合を含む。）の規定による添付書類、[[laws/421AC0000000059/本文/第62条の4.md|第六十二条の四]]第一項（[[laws/421AC0000000059/本文/第62条の7.md|第六十二条の七]]第二項において準用する場合を含む。）の規定による登録申請書若しくは[[laws/421AC0000000059/本文/第62条の4.md|第六十二条の四]]第二項（[[laws/421AC0000000059/本文/第62条の7.md|第六十二条の七]]第二項において準用する場合を含む。）の規定による添付書類又は[[laws/421AC0000000059/本文/第63条の3.md|第六十三条の三]]第一項の規定による登録申請書若しくは同条第二項の規定による添付書類に虚偽の記載をして提出したとき。
- 三 [[laws/421AC0000000059/本文/第14条.md|第十四条]]第一項又は第二項の規定に違反して、供託を行わなかったとき。
- 四 [[laws/421AC0000000059/本文/第17条.md|第十七条]]の規定による命令に違反して、供託を行わなかったとき。
- 五 [[laws/421AC0000000059/本文/第22条.md|第二十二条]]の規定による帳簿書類の作成若しくは保存をせず、又は虚偽の帳簿書類の作成をしたとき。
- 六 [[laws/421AC0000000059/本文/第23条.md|第二十三条]]第一項の規定による報告書若しくは同条第二項の規定による添付書類を提出せず、又は虚偽の記載をした報告書若しくは添付書類を提出したとき。
- 七 [[laws/421AC0000000059/本文/第24条.md|第二十四条]]第一項若しくは第二項の規定による報告若しくは資料の提出をせず、又は虚偽の報告若しくは資料の提出をしたとき。
- 八 [[laws/421AC0000000059/本文/第24条.md|第二十四条]]第一項若しくは第二項の規定による当該職員の質問に対して答弁をせず、若しくは虚偽の答弁をし、又はこれらの規定による検査を拒み、妨げ、若しくは忌避したとき。
- 九 準用金融商品取引法[[laws/323AC0000000025/本文/第37条.md|第三十七条]]第一項に規定する事項を表示せず、又は虚偽の表示をしたとき。
- 十 準用金融商品取引法[[laws/323AC0000000025/本文/第37条.md|第三十七条]]第二項の規定に違反したとき。
- 十一 準用金融商品取引法[[laws/323AC0000000025/本文/第37条の3.md|第三十七条の三]]第一項の規定に違反して、同項の規定による情報の提供をせず、又は虚偽の情報の提供をしたとき。
- 十二 準用金融商品取引法[[laws/323AC0000000025/本文/第37条の4.md|第三十七条の四]]の規定に違反して、同条の規定による情報の提供をせず、又は虚偽の情報の提供をしたとき。
- 十三 [[laws/421AC0000000059/本文/第63条の9.md|第六十三条の九]]の二に規定する事項を表示しなかったとき。
- 十四 [[laws/421AC0000000059/本文/第63条の9.md|第六十三条の九]]の三の規定に違反して、同条第二号又は第三号に掲げる行為をしたとき。
- 十五 [[laws/421AC0000000059/本文/第95条.md|第九十五条]]の規定による報告若しくは資料の提出をせず、又は虚偽の報告若しくは資料の提出をしたとき。
- 十六 [[laws/421AC0000000059/本文/第95条.md|第九十五条]]の規定による当該職員の質問に対して答弁をせず、若しくは虚偽の答弁をし、又は同条の規定による検査を拒み、妨げ、若しくは忌避したとき。
