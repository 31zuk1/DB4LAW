# 第七十条 

## 
次の各号のいずれかに該当するときは、その違反行為をした者は、百万円以下の罰金に処する。[[laws/鉄道事業法/本文/第7条.md|第七条]]第一項、[[laws/鉄道事業法/本文/第9条.md|第九条]]第一項（[[laws/鉄道事業法/本文/第12条.md|第十二条]]第四項（[[laws/鉄道事業法/本文/第38条.md|第三十八条]]において準用する場合を含む。）及び[[laws/鉄道事業法/本文/第38条.md|第三十八条]]において準用する場合を含む。）、[[laws/鉄道事業法/本文/第12条.md|第十二条]]第一項（[[laws/鉄道事業法/本文/第38条.md|第三十八条]]において準用する場合を含む。）又は[[laws/鉄道事業法/本文/第15条.md|第十五条]]第一項若しくは第二項の規定により認可を受けてしなければならない事項を認可を受けないでしたとき。[[laws/鉄道事業法/本文/第13条.md|第十三条]]第一項又は第二項の規定による確認を受けないで車両を旅客又は貨物の運送を行う事業の用に供したとき。[[laws/鉄道事業法/本文/第16条.md|第十六条]]第三項若しくは第八項若しくは[[laws/鉄道事業法/本文/第36条.md|第三十六条]]の規定による届出をしないで、又はこれらの規定若しくは[[laws/鉄道事業法/本文/第16条.md|第十六条]]第四項の規定により届け出た運賃若しくは料金によらないで、運賃又は料金を収受したとき。[[laws/鉄道事業法/本文/第16条.md|第十六条]]第九項の規定による命令に違反して、運賃又は料金を収受したとき。[[laws/鉄道事業法/本文/第17条.md|第十七条]]の規定による届出をしないで運行をしたとき。[[laws/鉄道事業法/本文/第18条.md|第十八条]]（[[laws/鉄道事業法/本文/第38条.md|第三十八条]]において準用する場合を含む。）の規定による届出をしないで、又は虚偽の届出をして、協定を締結し、又はその内容を変更したとき。[[laws/鉄道事業法/本文/第18条の3.md|第十八条の三]]第一項（[[laws/鉄道事業法/本文/第38条.md|第三十八条]]において準用する場合を含む。）の規定による届出をしないで、又は届け出た安全管理規程（[[laws/鉄道事業法/本文/第18条の3.md|第十八条の三]]第二項第二号及び第三号（これらの規定を[[laws/鉄道事業法/本文/第38条.md|第三十八条]]において準用する場合を含む。）に係る部分に限る。）によらないで、事業を行つたとき。[[laws/鉄道事業法/本文/第18条の3.md|第十八条の三]]第三項若しくは第七項（これらの規定を[[laws/鉄道事業法/本文/第38条.md|第三十八条]]において準用する場合を含む。）、[[laws/鉄道事業法/本文/第22条の3.md|第二十二条の三]]第三項、[[laws/鉄道事業法/本文/第25条.md|第二十五条]]第三項（[[laws/鉄道事業法/本文/第38条.md|第三十八条]]において準用する場合を含む。）又は[[laws/鉄道事業法/本文/第38条.md|第三十八条]]及び[[laws/鉄道事業法/本文/第39条.md|第三十九条]]第二項において準用する[[laws/鉄道事業法/本文/第23条.md|第二十三条]]第一項の規定による命令に違反したとき。[[laws/鉄道事業法/本文/第18条の3.md|第十八条の三]]第四項（[[laws/鉄道事業法/本文/第38条.md|第三十八条]]において準用する場合を含む。）の規定に違反して、安全統括管理者、運転管理者又は索道技術管理者を選任しなかつたとき。[[laws/鉄道事業法/本文/第18条の3.md|第十八条の三]]第五項（[[laws/鉄道事業法/本文/第38条.md|第三十八条]]において準用する場合を含む。）の規定による届出をせず、又は虚偽の届出をしたとき。[[laws/鉄道事業法/本文/第23条.md|第二十三条]]第一項の規定による命令に違反したとき（前条第二号に該当する場合を除く。）。[[laws/鉄道事業法/本文/第28条.md|第二十八条]]第一項の規定による届出をしないで、又は虚偽の届出をして、鉄道事業の全部又は一部を休止したとき。[[laws/鉄道事業法/本文/第28条の2.md|第二十八条の二]]第一項若しくは第六項の規定による届出をしないで、又は虚偽の届出をして、鉄道事業の全部又は一部を廃止したとき。[[laws/鉄道事業法/本文/第37条.md|第三十七条]]第二項の規定による届出をしないで、又は虚偽の届出をして、索道事業の全部又は一部を再開したとき。[[laws/鉄道事業法/本文/第55条.md|第五十五条]]の規定による報告をせず、又は虚偽の報告をしたとき。[[laws/鉄道事業法/本文/第56条.md|第五十六条]]第一項から第三項までの規定による検査を拒み、妨げ、若しくは忌避し、又は質問に対して陳述をせず、若しくは虚偽の陳述をしたとき。[[laws/鉄道事業法/本文/第61条.md|第六十一条]]第一項の規定に違反して、鉄道線路を敷設したとき。

- 一 [[laws/鉄道事業法/本文/第7条.md|第七条]]第一項、[[laws/鉄道事業法/本文/第9条.md|第九条]]第一項（[[laws/鉄道事業法/本文/第12条.md|第十二条]]第四項（[[laws/鉄道事業法/本文/第38条.md|第三十八条]]において準用する場合を含む。）及び[[laws/鉄道事業法/本文/第38条.md|第三十八条]]において準用する場合を含む。）、[[laws/鉄道事業法/本文/第12条.md|第十二条]]第一項（[[laws/鉄道事業法/本文/第38条.md|第三十八条]]において準用する場合を含む。）又は[[laws/鉄道事業法/本文/第15条.md|第十五条]]第一項若しくは第二項の規定により認可を受けてしなければならない事項を認可を受けないでしたとき。
- 二 [[laws/鉄道事業法/本文/第13条.md|第十三条]]第一項又は第二項の規定による確認を受けないで車両を旅客又は貨物の運送を行う事業の用に供したとき。
- 三 [[laws/鉄道事業法/本文/第16条.md|第十六条]]第三項若しくは第八項若しくは[[laws/鉄道事業法/本文/第36条.md|第三十六条]]の規定による届出をしないで、又はこれらの規定若しくは[[laws/鉄道事業法/本文/第16条.md|第十六条]]第四項の規定により届け出た運賃若しくは料金によらないで、運賃又は料金を収受したとき。
- 四 [[laws/鉄道事業法/本文/第16条.md|第十六条]]第九項の規定による命令に違反して、運賃又は料金を収受したとき。
- 五 [[laws/鉄道事業法/本文/第17条.md|第十七条]]の規定による届出をしないで運行をしたとき。
- 六 [[laws/鉄道事業法/本文/第18条.md|第十八条]]（[[laws/鉄道事業法/本文/第38条.md|第三十八条]]において準用する場合を含む。）の規定による届出をしないで、又は虚偽の届出をして、協定を締結し、又はその内容を変更したとき。
- 七 [[laws/鉄道事業法/本文/第18条の3.md|第十八条の三]]第一項（[[laws/鉄道事業法/本文/第38条.md|第三十八条]]において準用する場合を含む。）の規定による届出をしないで、又は届け出た安全管理規程（[[laws/鉄道事業法/本文/第18条の3.md|第十八条の三]]第二項第二号及び第三号（これらの規定を[[laws/鉄道事業法/本文/第38条.md|第三十八条]]において準用する場合を含む。）に係る部分に限る。）によらないで、事業を行つたとき。
- 八 [[laws/鉄道事業法/本文/第18条の3.md|第十八条の三]]第三項若しくは第七項（これらの規定を[[laws/鉄道事業法/本文/第38条.md|第三十八条]]において準用する場合を含む。）、[[laws/鉄道事業法/本文/第22条の3.md|第二十二条の三]]第三項、[[laws/鉄道事業法/本文/第25条.md|第二十五条]]第三項（[[laws/鉄道事業法/本文/第38条.md|第三十八条]]において準用する場合を含む。）又は[[laws/鉄道事業法/本文/第38条.md|第三十八条]]及び[[laws/鉄道事業法/本文/第39条.md|第三十九条]]第二項において準用する[[laws/鉄道事業法/本文/第23条.md|第二十三条]]第一項の規定による命令に違反したとき。
- 九 [[laws/鉄道事業法/本文/第18条の3.md|第十八条の三]]第四項（[[laws/鉄道事業法/本文/第38条.md|第三十八条]]において準用する場合を含む。）の規定に違反して、安全統括管理者、運転管理者又は索道技術管理者を選任しなかつたとき。
- 十 [[laws/鉄道事業法/本文/第18条の3.md|第十八条の三]]第五項（[[laws/鉄道事業法/本文/第38条.md|第三十八条]]において準用する場合を含む。）の規定による届出をせず、又は虚偽の届出をしたとき。
- 十一 [[laws/鉄道事業法/本文/第23条.md|第二十三条]]第一項の規定による命令に違反したとき（前条第二号に該当する場合を除く。）。
- 十二 [[laws/鉄道事業法/本文/第28条.md|第二十八条]]第一項の規定による届出をしないで、又は虚偽の届出をして、鉄道事業の全部又は一部を休止したとき。
- 十三 [[laws/鉄道事業法/本文/第28条の2.md|第二十八条の二]]第一項若しくは第六項の規定による届出をしないで、又は虚偽の届出をして、鉄道事業の全部又は一部を廃止したとき。
- 十四 [[laws/鉄道事業法/本文/第37条.md|第三十七条]]第二項の規定による届出をしないで、又は虚偽の届出をして、索道事業の全部又は一部を再開したとき。
- 十五 [[laws/鉄道事業法/本文/第55条.md|第五十五条]]の規定による報告をせず、又は虚偽の報告をしたとき。
- 十六 [[laws/鉄道事業法/本文/第56条.md|第五十六条]]第一項から第三項までの規定による検査を拒み、妨げ、若しくは忌避し、又は質問に対して陳述をせず、若しくは虚偽の陳述をしたとき。
- 十七 [[laws/鉄道事業法/本文/第61条.md|第六十一条]]第一項の規定に違反して、鉄道線路を敷設したとき。
