# 第六十四条 （年金数理に関する業務に係る書類）

## 
法[[laws/国民年金基金規則/本文/第139条の2.md|第百三十九条の二]]に規定する厚生労働省令で定める書類は、次の各号に掲げる書類とする。[[laws/国民年金基金規則/本文/第3条.md|第三条]]第三号及び第四号に規定する書類[[laws/国民年金基金規則/本文/第4条.md|第四条]]第一号及び第二号に規定する書類[[laws/国民年金基金規則/本文/第5条.md|第五条]]第二号（[[laws/国民年金基金規則/本文/第63条.md|第六十三条]]において準用する場合を含む。）に規定する書類[[laws/国民年金基金規則/本文/第5条の2.md|第五条の二]]第二項第二号に規定する責任準備金の額の明細を示した書類[[laws/国民年金基金規則/本文/第5条の5.md|第五条の五]]第二項第二号に規定する責任準備金の額の明細を示した書類財政再計算報告書[[laws/国民年金基金規則/本文/第53条.md|第五十三条]]に規定する書類[[laws/国民年金基金規則/本文/第54条.md|第五十四条]]第二項に規定する書類財務会計省令[[laws/国民年金基金規則/本文/第8条.md|第八条]]第四項（財務会計省令[[laws/国民年金基金規則/本文/第20条.md|第二十条]]において準用する場合を含む。）に規定する書類財務会計省令[[laws/国民年金基金規則/本文/第14条.md|第十四条]]第一号（財務会計省令[[laws/国民年金基金規則/本文/第20条.md|第二十条]]において準用する場合を含む。）及び第四号（財務会計省令[[laws/国民年金基金規則/本文/第20条.md|第二十条]]において準用する場合を含む。）に規定する書類財務会計省令[[laws/国民年金基金規則/本文/第17条.md|第十七条]]第五項（財務会計省令[[laws/国民年金基金規則/本文/第20条.md|第二十条]]において準用する場合を含む。）に規定する危険準備金の取崩しの処分を示した書類

- 一 [[laws/国民年金基金規則/本文/第3条.md|第三条]]第三号及び第四号に規定する書類
- 二 [[laws/国民年金基金規則/本文/第4条.md|第四条]]第一号及び第二号に規定する書類
- 三 [[laws/国民年金基金規則/本文/第5条.md|第五条]]第二号（[[laws/国民年金基金規則/本文/第63条.md|第六十三条]]において準用する場合を含む。）に規定する書類
- 三の二 [[laws/国民年金基金規則/本文/第5条の2.md|第五条の二]]第二項第二号に規定する責任準備金の額の明細を示した書類
- 三の三 [[laws/国民年金基金規則/本文/第5条の5.md|第五条の五]]第二項第二号に規定する責任準備金の額の明細を示した書類
- 四 財政再計算報告書
- 五 [[laws/国民年金基金規則/本文/第53条.md|第五十三条]]に規定する書類
- 六 [[laws/国民年金基金規則/本文/第54条.md|第五十四条]]第二項に規定する書類
- 七 財務会計省令[[laws/国民年金基金規則/本文/第8条.md|第八条]]第四項（財務会計省令[[laws/国民年金基金規則/本文/第20条.md|第二十条]]において準用する場合を含む。）に規定する書類
- 八 財務会計省令[[laws/国民年金基金規則/本文/第14条.md|第十四条]]第一号（財務会計省令[[laws/国民年金基金規則/本文/第20条.md|第二十条]]において準用する場合を含む。）及び第四号（財務会計省令[[laws/国民年金基金規則/本文/第20条.md|第二十条]]において準用する場合を含む。）に規定する書類
- 九 財務会計省令[[laws/国民年金基金規則/本文/第17条.md|第十七条]]第五項（財務会計省令[[laws/国民年金基金規則/本文/第20条.md|第二十条]]において準用する場合を含む。）に規定する危険準備金の取崩しの処分を示した書類
