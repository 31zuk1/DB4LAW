# 第百十一条の三 （都道府県の設置する任意制ポスター掲示場）

## 
法[[laws/公職選挙法施行令/本文/第144条の2.md|第百四十四条の二]]第八項又は法[[laws/公職選挙法施行令/本文/第144条の4.md|第百四十四条の四]]の規定によつて都道府県の議会の議員の選挙についてポスター掲示場を設けることとした場合においては、市町村の選挙管理委員会は、当該都道府県の条例の定めるところにより、ポスター掲示場の設置に関する事務を行わなければならない。
