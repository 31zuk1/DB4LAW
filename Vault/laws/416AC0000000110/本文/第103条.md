# 第百三条 

## 
次の各号のいずれかに該当する者は、三十万円以下の罰金に処する。[[laws/416AC0000000110/本文/第16条.md|第十六条]]第一項又は第二項の規定に違反して、届出をせず、又は虚偽の届出をした者[[laws/416AC0000000110/本文/第17条.md|第十七条]]第七項又は[[laws/416AC0000000110/本文/第71条.md|第七十一条]]第一項の規定による報告をせず、又は虚偽の報告をした者[[laws/416AC0000000110/本文/第17条.md|第十七条]]第七項の規定による立入検査若しくは立入調査又は[[laws/416AC0000000110/本文/第71条.md|第七十一条]]第一項の規定による立入検査を拒み、妨げ、又は忌避した者[[laws/416AC0000000110/本文/第18条.md|第十八条]]第一項の規定に違反して、届出に係る行為に着手した者[[laws/416AC0000000110/本文/第22条.md|第二十二条]]第一項又は[[laws/416AC0000000110/本文/第31条.md|第三十一条]]第一項の規定に違反して、行為をした者[[laws/416AC0000000110/本文/第22条.md|第二十二条]]第三項（[[laws/416AC0000000110/本文/第31条.md|第三十一条]]第二項において準用する場合を含む。）の規定により許可に付された条件に違反した者[[laws/416AC0000000110/本文/第23条.md|第二十三条]]第一項（[[laws/416AC0000000110/本文/第32条.md|第三十二条]]第一項において準用する場合を含む。）の規定による景観行政団体の長の命令に違反した者[[laws/416AC0000000110/本文/第68条.md|第六十八条]]の規定に違反して、認定があった旨の表示をせず、又は認定を受けた計画の写しを備えて置かなかった者

- 一 [[laws/416AC0000000110/本文/第16条.md|第十六条]]第一項又は第二項の規定に違反して、届出をせず、又は虚偽の届出をした者
- 二 [[laws/416AC0000000110/本文/第17条.md|第十七条]]第七項又は[[laws/416AC0000000110/本文/第71条.md|第七十一条]]第一項の規定による報告をせず、又は虚偽の報告をした者
- 三 [[laws/416AC0000000110/本文/第17条.md|第十七条]]第七項の規定による立入検査若しくは立入調査又は[[laws/416AC0000000110/本文/第71条.md|第七十一条]]第一項の規定による立入検査を拒み、妨げ、又は忌避した者
- 四 [[laws/416AC0000000110/本文/第18条.md|第十八条]]第一項の規定に違反して、届出に係る行為に着手した者
- 五 [[laws/416AC0000000110/本文/第22条.md|第二十二条]]第一項又は[[laws/416AC0000000110/本文/第31条.md|第三十一条]]第一項の規定に違反して、行為をした者
- 六 [[laws/416AC0000000110/本文/第22条.md|第二十二条]]第三項（[[laws/416AC0000000110/本文/第31条.md|第三十一条]]第二項において準用する場合を含む。）の規定により許可に付された条件に違反した者
- 七 [[laws/416AC0000000110/本文/第23条.md|第二十三条]]第一項（[[laws/416AC0000000110/本文/第32条.md|第三十二条]]第一項において準用する場合を含む。）の規定による景観行政団体の長の命令に違反した者
- 八 [[laws/416AC0000000110/本文/第68条.md|第六十八条]]の規定に違反して、認定があった旨の表示をせず、又は認定を受けた計画の写しを備えて置かなかった者
