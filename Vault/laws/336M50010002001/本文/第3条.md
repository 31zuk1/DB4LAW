# 第三条 （貸付対象法人）

## 
法[[laws/336M50010002001/本文/第4条.md|第四条]]第二号の主務省令で定める法人は、次の各号に掲げる法人とする。漁業協同組合及び水産加工業協同組合農業協同組合森林組合事業協同組合、事業協同小組合及び信用協同組合商工組合環境衛生同業組合

- 一 漁業協同組合及び水産加工業協同組合
- 二 農業協同組合
- 三 森林組合
- 四 事業協同組合、事業協同小組合及び信用協同組合
- 五 商工組合
- 六 環境衛生同業組合
