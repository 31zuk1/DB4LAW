# 第四十三条 

## 
法及びこの省令に規定する国土交通大臣の権限のうち、次に掲げるものは、不動産鑑定士又は法[[laws/339M50004000009/本文/第15条.md|第十五条]]の登録を受けようとする者の住所地（第十号にあっては、法[[laws/338AC0000000152/本文/第48条.md|第四十八条]]の規定による届出をした社団又は財団の主たる事務所の所在地）を管轄する地方整備局長及び北海道開発局長に委任する。ただし、第四号、第五号及び第八号から第十号までに掲げる権限については、国土交通大臣が自ら行うことを妨げない。法[[laws/339M50004000009/本文/第17条.md|第十七条]]第一項の規定による登録申請書を受理し、及び同条第三項の規定による登録をすること。法[[laws/339M50004000009/本文/第18条.md|第十八条]]の規定による変更の登録の申請書を受理すること。法[[laws/339M50004000009/本文/第19条.md|第十九条]]の規定による届出を受理すること。法[[laws/339M50004000009/本文/第20条.md|第二十条]]の規定により登録を消除すること。法[[laws/339M50004000009/本文/第40条.md|第四十条]]第一項の規定により鑑定評価等業務を行うことを禁止し、又は登録を消除し、同条第二項の規定により戒告を与え、又は鑑定評価等業務を行うことを禁止し、及び同条第三項の規定により登録を消除すること。法[[laws/339M50004000009/本文/第42条.md|第四十二条]]の規定による不当な鑑定評価等に対する措置の要求を受理すること。法[[laws/339M50004000009/本文/第43条.md|第四十三条]]第一項の規定により聴聞を行い、同条第二項の規定により意見を聴き、及び同条第三項の規定により支給すること（法[[laws/339M50004000009/本文/第40条.md|第四十条]]の規定による処分についてするものに限る。）。法[[laws/339M50004000009/本文/第43条.md|第四十三条]]第四項の規定により意見を聴くこと。法[[laws/338AC0000000152/本文/第44条.md|第四十四条]]の規定により公告すること（法[[laws/339M50004000009/本文/第40条.md|第四十条]]の規定による処分についてするものに限る。）。法[[laws/338AC0000000152/本文/第50条.md|第五十条]]の規定により報告を徴収し、又は助言若しくは勧告をすること。[[laws/339M50004000009/本文/第21条.md|第二十一条]]第三項の規定により公衆の閲覧に供すること。[[laws/339M50004000009/本文/第23条.md|第二十三条]]第一項の規定により通知し、同条第二項の規定により登録を拒否し、及び通知し、並びに同条第三項の規定により記載すること。[[laws/339M50004000009/本文/第24条.md|第二十四条]]第二項の規定により変更の登録をし、及び通知すること。[[laws/339M50004000009/本文/第26条.md|第二十六条]]第一項の規定により通知し、及び同条第二項（[[laws/339M50004000009/本文/第35条.md|第三十五条]]第二項において準用する場合を除く。）の規定により保存すること。

- 一 法[[laws/339M50004000009/本文/第17条.md|第十七条]]第一項の規定による登録申請書を受理し、及び同条第三項の規定による登録をすること。
- 二 法[[laws/339M50004000009/本文/第18条.md|第十八条]]の規定による変更の登録の申請書を受理すること。
- 三 法[[laws/339M50004000009/本文/第19条.md|第十九条]]の規定による届出を受理すること。
- 四 法[[laws/339M50004000009/本文/第20条.md|第二十条]]の規定により登録を消除すること。
- 五 法[[laws/339M50004000009/本文/第40条.md|第四十条]]第一項の規定により鑑定評価等業務を行うことを禁止し、又は登録を消除し、同条第二項の規定により戒告を与え、又は鑑定評価等業務を行うことを禁止し、及び同条第三項の規定により登録を消除すること。
- 六 法[[laws/339M50004000009/本文/第42条.md|第四十二条]]の規定による不当な鑑定評価等に対する措置の要求を受理すること。
- 七 法[[laws/339M50004000009/本文/第43条.md|第四十三条]]第一項の規定により聴聞を行い、同条第二項の規定により意見を聴き、及び同条第三項の規定により支給すること（法[[laws/339M50004000009/本文/第40条.md|第四十条]]の規定による処分についてするものに限る。）。
- 八 法[[laws/339M50004000009/本文/第43条.md|第四十三条]]第四項の規定により意見を聴くこと。
- 九 法[[laws/338AC0000000152/本文/第44条.md|第四十四条]]の規定により公告すること（法[[laws/339M50004000009/本文/第40条.md|第四十条]]の規定による処分についてするものに限る。）。
- 十 法[[laws/338AC0000000152/本文/第50条.md|第五十条]]の規定により報告を徴収し、又は助言若しくは勧告をすること。
- 十一 [[laws/339M50004000009/本文/第21条.md|第二十一条]]第三項の規定により公衆の閲覧に供すること。
- 十二 [[laws/339M50004000009/本文/第23条.md|第二十三条]]第一項の規定により通知し、同条第二項の規定により登録を拒否し、及び通知し、並びに同条第三項の規定により記載すること。
- 十三 [[laws/339M50004000009/本文/第24条.md|第二十四条]]第二項の規定により変更の登録をし、及び通知すること。
- 十四 [[laws/339M50004000009/本文/第26条.md|第二十六条]]第一項の規定により通知し、及び同条第二項（[[laws/339M50004000009/本文/第35条.md|第三十五条]]第二項において準用する場合を除く。）の規定により保存すること。
## ２
地方整備局長及び北海道開発局長は、前項の規定にかかわらず、当該地方整備局長及び北海道開発局長の管轄する区域内において鑑定評価等業務を行う不動産鑑定士に対し、同項第五号（法[[laws/339M50004000009/本文/第40条.md|第四十条]]第一項又は第三項の規定による登録の消除を除く。）から第九号までに掲げる権限を行うことができる。
