# 第二条の三 （専門職大学が授与する学位の授与の要件）

## 
法[[laws/328M50000080009/学位規則_law.md|第百四条]]第二項の規定による前条の学士（専門職）の学位の授与は、専門職大学が、当該専門職大学を卒業した者に対し行うものとする。

## ２
法[[laws/328M50000080009/学位規則_law.md|第百四条]]第二項の規定による前条の短期大学士（専門職）の学位の授与は、専門職大学が、当該専門職大学の前期課程を修了した者に対し行うものとする。
