# 第四十六条 （運営規程）

## 
特定地域型保育事業者は、次の各号に掲げる事業の運営についての重要事項に関する規程（[[laws/426M60000002039/本文/第50条.md|第五十条]]において準用する[[laws/426M60000002039/本文/第23条.md|第二十三条]]において「運営規程」という。）を定めておかなければならない。事業の目的及び運営の方針提供する特定地域型保育の内容職員の職種、員数及び職務の内容特定地域型保育の提供を行う日及び時間、提供を行わない日[[laws/426M60000002039/本文/第43条.md|第四十三条]]の規定により教育・保育給付認定保護者から支払を受ける費用の種類、支払を求める理由及びその額利用定員特定地域型保育事業の利用の開始、終了に関する事項及び利用に当たっての留意事項（[[laws/426M60000002039/本文/第39条.md|第三十九条]]第二項に規定する選考方法を含む。）緊急時等における対応方法非常災害対策虐待の防止のための措置に関する事項その他特定地域型保育事業の運営に関する重要事項

- 一 事業の目的及び運営の方針
- 二 提供する特定地域型保育の内容
- 三 職員の職種、員数及び職務の内容
- 四 特定地域型保育の提供を行う日及び時間、提供を行わない日
- 五 [[laws/426M60000002039/本文/第43条.md|第四十三条]]の規定により教育・保育給付認定保護者から支払を受ける費用の種類、支払を求める理由及びその額
- 六 利用定員
- 七 特定地域型保育事業の利用の開始、終了に関する事項及び利用に当たっての留意事項（[[laws/426M60000002039/本文/第39条.md|第三十九条]]第二項に規定する選考方法を含む。）
- 八 緊急時等における対応方法
- 九 非常災害対策
- 十 虐待の防止のための措置に関する事項
- 十一 その他特定地域型保育事業の運営に関する重要事項
