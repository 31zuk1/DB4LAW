# 第三条の二 （指定に関する報告事項）

## 
令[[laws/診療放射線技師学校養成所指定規則/本文/第7条.md|第七条]]第二項の主務省令で定める事項は、次に掲げる事項（国の設置する養成所にあつては、第一号に掲げる事項を除く。）とする。設置者の氏名及び住所（法人にあつては、名称及び主たる事務所の所在地）名称位置指定をした年月日及び設置年月日（設置されていない場合にあつては、設置予定年月日）学則（修業年限及び入所定員に関する事項に限る。）長の氏名

- 一 設置者の氏名及び住所（法人にあつては、名称及び主たる事務所の所在地）
- 二 名称
- 三 位置
- 四 指定をした年月日及び設置年月日（設置されていない場合にあつては、設置予定年月日）
- 五 学則（修業年限及び入所定員に関する事項に限る。）
- 六 長の氏名
