# 第三条 （報告）

## 
工場適地の調査及び工場立地の動向の調査について法[[laws/334AC0000000024/本文/第15条の3.md|第十五条の三]]の規定により経済産業大臣が報告をさせることができる事項は、次のとおりとする。工場又は事業場の敷地面積及び建築面積生産数量及び生産能力工業用水及び電力の使用の状況燃料、原材料、外注部品及び製品の輸送の状況従業員の雇用の状況公害防止施設の状況工場又は事業場の設置に関する計画又は長期の見通し

- 一 工場又は事業場の敷地面積及び建築面積
- 二 生産数量及び生産能力
- 三 工業用水及び電力の使用の状況
- 四 燃料、原材料、外注部品及び製品の輸送の状況
- 五 従業員の雇用の状況
- 六 公害防止施設の状況
- 七 工場又は事業場の設置に関する計画又は長期の見通し
## ２
工場立地に伴う公害の防止に関する調査について法[[laws/334AC0000000024/本文/第15条の3.md|第十五条の三]]の規定により経済産業大臣及び環境大臣が報告をさせることができる事項は、次のとおりとする。工場又は事業場の敷地面積生産数量及び生産能力生産施設、公害防止施設その他の施設の配置燃料、原材料及び工業用水の使用の状況汚染物質の発生の状況汚染物質の処理その他の公害防止のための措置の内容

- 一 工場又は事業場の敷地面積
- 二 生産数量及び生産能力
- 三 生産施設、公害防止施設その他の施設の配置
- 四 燃料、原材料及び工業用水の使用の状況
- 五 汚染物質の発生の状況
- 六 汚染物質の処理その他の公害防止のための措置の内容
