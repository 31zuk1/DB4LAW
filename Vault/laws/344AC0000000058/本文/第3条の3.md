# 第三条の三 （基本指針の変更）

## 
農林水産大臣は、経済事情の変動その他情勢の推移により必要が生じたときは、基本指針を変更するものとする。

## ２
前条第三項から第六項までの規定は、基本指針の変更について準用する。
