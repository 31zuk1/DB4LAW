# 第百四十一条 （即時抗告）

## 
次の各号に掲げる審判に対しては、当該各号に定める者（第一号にあっては、申立人を除く。）は、即時抗告をすることができる。補助開始の審判民法[[laws/129AC0000000089/本文/第15条.md|第十五条]]第一項本文及び任意後見契約法[[laws/129AC0000000089/本文/第10条.md|第十条]]第二項に規定する者補助開始の申立てを却下する審判申立人補助開始の審判の取消しの申立てを却下する審判民法[[laws/129AC0000000089/本文/第18条.md|第十八条]]第一項に規定する者補助人の同意に代わる許可の申立てを却下する審判申立人補助人の解任の審判補助人補助人の解任の申立てを却下する審判申立人、補助監督人並びに被補助人及びその親族補助監督人の解任の審判補助監督人補助監督人の解任の申立てを却下する審判申立人並びに被補助人及びその親族

- 一 補助開始の審判民法[[laws/129AC0000000089/本文/第15条.md|第十五条]]第一項本文及び任意後見契約法[[laws/129AC0000000089/本文/第10条.md|第十条]]第二項に規定する者
- 二 補助開始の申立てを却下する審判申立人
- 三 補助開始の審判の取消しの申立てを却下する審判民法[[laws/129AC0000000089/本文/第18条.md|第十八条]]第一項に規定する者
- 四 補助人の同意に代わる許可の申立てを却下する審判申立人
- 五 補助人の解任の審判補助人
- 六 補助人の解任の申立てを却下する審判申立人、補助監督人並びに被補助人及びその親族
- 七 補助監督人の解任の審判補助監督人
- 八 補助監督人の解任の申立てを却下する審判申立人並びに被補助人及びその親族
## ２
審判の告知を受ける者でない者及び被補助人となるべき者による補助開始の審判に対する即時抗告の期間は、被補助人となるべき者が審判の告知を受けた日及び民法[[laws/129AC0000000089/本文/第876条の7.md|第八百七十六条の七]]第一項の規定により補助人に選任される者が審判の告知を受けた日のうち最も遅い日から進行する。
