# 第八十一条 （実習の実施）

## 
就労継続支援Ａ型事業者は、利用者が[[laws/障害者の日常生活及び社会生活を総合的に支援するための法律に基づく障害福祉サービス事業の設備及び運営に関する基準/本文/第85条.md|第八十五条]]において準用する[[laws/障害者の日常生活及び社会生活を総合的に支援するための法律に基づく障害福祉サービス事業の設備及び運営に関する基準/本文/第17条.md|第十七条]]の就労継続支援Ａ型計画に基づいて実習できるよう、実習の受入先の確保に努めなければならない。

## ２
就労継続支援Ａ型事業者は、前項の実習の受入先の確保に当たっては、公共職業安定所、障害者就業・生活支援センター及び特別支援学校等の関係機関と連携して、利用者の就労に対する意向及び適性を踏まえて行うよう努めなければならない。
