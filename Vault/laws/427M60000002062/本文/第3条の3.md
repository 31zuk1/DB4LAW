# 第三条の三 （通知事項）

## 
簡易確定手続申立団体が法[[laws/消費者の財産的被害等の集団的な回復のための民事の裁判手続の特例に関する法律施行規則/本文/第27条.md|第二十七条]]第一項の規定による通知をする場合における[[laws/消費者の財産的被害等の集団的な回復のための民事の裁判手続の特例に関する法律施行規則/本文/第3条.md|第三条]]第三号の規定の適用については、同号中「法[[laws/消費者の財産的被害等の集団的な回復のための民事の裁判手続の特例に関する法律施行規則/本文/第26条.md|第二十六条]]第一項の規定による公告」とあるのは「法[[laws/消費者の財産的被害等の集団的な回復のための民事の裁判手続の特例に関する法律施行規則/本文/第27条.md|第二十七条]]第一項の規定による通知」と、「同項の規定による公告」とあるのは「同項の規定による通知」とする。

## ２
法[[laws/消費者の財産的被害等の集団的な回復のための民事の裁判手続の特例に関する法律施行規則/本文/第27条.md|第二十七条]]第二項第三号の内閣府令で定める事項は、次に掲げる事項とする。法[[laws/消費者の財産的被害等の集団的な回復のための民事の裁判手続の特例に関する法律施行規則/本文/第27条.md|第二十七条]]第一項の規定による通知を受けた対象消費者等が法[[laws/消費者の財産的被害等の集団的な回復のための民事の裁判手続の特例に関する法律施行規則/本文/第26条.md|第二十六条]]第一項の規定による公告の内容を確認するために必要な事項（当該公告がインターネットの利用による場合には、公告を掲載したウェブサイトのアドレス（二次元コードその他のこれに代わるものを含む。）。[[laws/消費者の財産的被害等の集団的な回復のための民事の裁判手続の特例に関する法律施行規則/本文/第3条の6.md|第三条の六]]第一項において同じ。）法[[laws/消費者の財産的被害等の集団的な回復のための民事の裁判手続の特例に関する法律施行規則/本文/第26条.md|第二十六条]]第一項各号に掲げる事項のうち、法[[laws/消費者の財産的被害等の集団的な回復のための民事の裁判手続の特例に関する法律施行規則/本文/第27条.md|第二十七条]]第二項の規定により記載しないものとする事項の項目及びこれらの項目が法[[laws/消費者の財産的被害等の集団的な回復のための民事の裁判手続の特例に関する法律施行規則/本文/第26条.md|第二十六条]]第一項の規定による公告の対象である旨
