# 第五条 

## 
職員が給与期間の中途において次の各号のいずれかに該当する場合におけるその給与期間の俸給は、日割計算により支給する。休職にされ、又は休職の終了により復職した場合法[[laws/328RJNJ09007000/人事院規則九―七（俸給等の支給）_law.md|第百八条の六]]第一項ただし書に規定する許可（以下「専従許可」という。）を受け、又は専従許可の有効期間の終了により復職した場合派遣法[[laws/328RJNJ09007000/本文/第2条.md|第二条]]第一項の規定により派遣され、又は派遣の終了により職務に復帰した場合育児休業法[[laws/328RJNJ09007000/本文/第3条.md|第三条]]の規定により育児休業を始め、又は育児休業の終了により職務に復帰した場合交流派遣（官民人事交流法[[laws/328RJNJ09007000/本文/第2条.md|第二条]]第三項に規定する交流派遣をいう。以下同じ。）をされ、又は交流派遣後職務に復帰した場合法科大学院派遣法[[laws/328RJNJ09007000/本文/第11条.md|第十一条]]第一項の規定により派遣され、又は当該派遣後職務に復帰した場合自己啓発等休業（自己啓発等休業法[[laws/328RJNJ09007000/本文/第2条.md|第二条]]第五項に規定する自己啓発等休業をいう。以下同じ。）を始め、又は自己啓発等休業の終了により職務に復帰した場合福島復興再生特別措置法（平成二十四年法律第二十五号）第四十八条の三第一項若しくは[[laws/328RJNJ09007000/人事院規則九―七（俸給等の支給）_law.md|第八十九条の三]]第一項の規定により派遣され、又は当該派遣後職務に復帰した場合配偶者同行休業（配偶者同行休業法[[laws/328RJNJ09007000/本文/第2条.md|第二条]]第四項に規定する配偶者同行休業をいう。以下同じ。）を始め、又は配偶者同行休業の終了により職務に復帰した場合令和七年国際博覧会特措法[[laws/328RJNJ09007000/人事院規則九―七（俸給等の支給）_law.md|第二十五条]]第一項の規定により派遣され、又は当該派遣後職務に復帰した場合令和九年国際園芸博覧会特措法[[laws/328RJNJ09007000/人事院規則九―七（俸給等の支給）_law.md|第十五条]]第一項の規定により派遣され、又は当該派遣後職務に復帰した場合停職にされ、又は停職の終了により職務に復帰した場合

- 一 休職にされ、又は休職の終了により復職した場合
- 二 法[[laws/328RJNJ09007000/人事院規則九―七（俸給等の支給）_law.md|第百八条の六]]第一項ただし書に規定する許可（以下「専従許可」という。）を受け、又は専従許可の有効期間の終了により復職した場合
- 三 派遣法[[laws/328RJNJ09007000/本文/第2条.md|第二条]]第一項の規定により派遣され、又は派遣の終了により職務に復帰した場合
- 四 育児休業法[[laws/328RJNJ09007000/本文/第3条.md|第三条]]の規定により育児休業を始め、又は育児休業の終了により職務に復帰した場合
- 五 交流派遣（官民人事交流法[[laws/328RJNJ09007000/本文/第2条.md|第二条]]第三項に規定する交流派遣をいう。以下同じ。）をされ、又は交流派遣後職務に復帰した場合
- 六 法科大学院派遣法[[laws/328RJNJ09007000/本文/第11条.md|第十一条]]第一項の規定により派遣され、又は当該派遣後職務に復帰した場合
- 七 自己啓発等休業（自己啓発等休業法[[laws/328RJNJ09007000/本文/第2条.md|第二条]]第五項に規定する自己啓発等休業をいう。以下同じ。）を始め、又は自己啓発等休業の終了により職務に復帰した場合
- 八 福島復興再生特別措置法（平成二十四年法律第二十五号）第四十八条の三第一項若しくは[[laws/328RJNJ09007000/人事院規則九―七（俸給等の支給）_law.md|第八十九条の三]]第一項の規定により派遣され、又は当該派遣後職務に復帰した場合
- 九 配偶者同行休業（配偶者同行休業法[[laws/328RJNJ09007000/本文/第2条.md|第二条]]第四項に規定する配偶者同行休業をいう。以下同じ。）を始め、又は配偶者同行休業の終了により職務に復帰した場合
- 十 令和七年国際博覧会特措法[[laws/328RJNJ09007000/人事院規則九―七（俸給等の支給）_law.md|第二十五条]]第一項の規定により派遣され、又は当該派遣後職務に復帰した場合
- 十一 令和九年国際園芸博覧会特措法[[laws/328RJNJ09007000/人事院規則九―七（俸給等の支給）_law.md|第十五条]]第一項の規定により派遣され、又は当該派遣後職務に復帰した場合
- 十二 停職にされ、又は停職の終了により職務に復帰した場合
## ２
給与期間の初日から引き続いて休職にされ、専従許可を受け、派遣法[[laws/328RJNJ09007000/本文/第2条.md|第二条]]第一項の規定により派遣され、育児休業法[[laws/328RJNJ09007000/本文/第3条.md|第三条]]の規定により育児休業をし、交流派遣をされ、法科大学院派遣法[[laws/328RJNJ09007000/本文/第11条.md|第十一条]]第一項の規定により派遣され、自己啓発等休業をし、福島復興再生特別措置法[[laws/328RJNJ09007000/人事院規則九―七（俸給等の支給）_law.md|第四十八条の三]]第一項若しくは[[laws/328RJNJ09007000/人事院規則九―七（俸給等の支給）_law.md|第八十九条の三]]第一項の規定により派遣され、配偶者同行休業をし、令和七年国際博覧会特措法[[laws/328RJNJ09007000/人事院規則九―七（俸給等の支給）_law.md|第二十五条]]第一項の規定により派遣され、令和九年国際園芸博覧会特措法[[laws/328RJNJ09007000/人事院規則九―七（俸給等の支給）_law.md|第十五条]]第一項の規定により派遣され、又は停職にされている職員が、俸給の支給定日後に復職し、又は職務に復帰した場合には、その給与期間中の俸給をその際支給する。
