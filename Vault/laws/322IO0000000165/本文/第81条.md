# 第八十一条 （開札）

## 
契約担当官等は、公告に示した競争執行の場所及び日時に、入札者を立ち会わせて開札をしなければならない。この場合において、入札者が立ち会わないときは、入札事務に関係のない職員を立ち会わせなければならない。
