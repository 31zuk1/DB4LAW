# 第三条 （令第二十四条の内閣府令で定める部隊等の長）

## 
令[[laws/災害対策基本法施行規則/本文/第24条.md|第二十四条]]の自衛隊法（昭和二十九年法律第百六十五号）第八条に規定する部隊等の長は、次に掲げる者とする。方面総監師団長旅団長駐屯地司令の職にある自衛隊法[[laws/災害対策基本法施行規則/本文/第8条.md|第八条]]に規定する部隊等（第十二号において「部隊等」という。）の長航空群司令（航空方面隊司令部の所在地に所在する航空群の長を除く。）地方総監地区総監基地隊司令航空隊司令（航空群司令部、地方総監部又は地区総監部の所在地に所在する航空隊の長を除く。）教育航空群司令航空総隊司令官航空方面隊司令官基地司令の職にある部隊等の長（駐屯地の所在地に所在する基地又は航空総隊司令部若しくは航空方面隊司令部の所在する基地の基地司令の職にある部隊等の長を除く。）

- 一 方面総監
- 二 師団長
- 三 旅団長
- 四 駐屯地司令の職にある自衛隊法[[laws/災害対策基本法施行規則/本文/第8条.md|第八条]]に規定する部隊等（第十二号において「部隊等」という。）の長
- 五 航空群司令（航空方面隊司令部の所在地に所在する航空群の長を除く。）
- 六 地方総監
- 七 地区総監
- 八 基地隊司令
- 九 航空隊司令（航空群司令部、地方総監部又は地区総監部の所在地に所在する航空隊の長を除く。）
- 十 教育航空群司令
- 十一 航空総隊司令官
- 十二 航空方面隊司令官
- 十三 基地司令の職にある部隊等の長（駐屯地の所在地に所在する基地又は航空総隊司令部若しくは航空方面隊司令部の所在する基地の基地司令の職にある部隊等の長を除く。）
