# 第四十六条 

## 
次の各号のいずれかに該当する者は、一年以下の拘禁刑又は百万円以下の罰金に処する。[[laws/食鳥処理の事業の規制及び食鳥検査に関する法律/本文/第8条.md|第八条]]の規定による命令に違反した者[[laws/食鳥処理の事業の規制及び食鳥検査に関する法律/本文/第9条.md|第九条]]の規定による禁止又は命令に違反した者[[laws/食鳥処理の事業の規制及び食鳥検査に関する法律/本文/第18条.md|第十八条]]第一項又は第二項の規定に違反して、食鳥とたい、食鳥中抜とたい又は食鳥肉等を譲り受けた者[[laws/食鳥処理の事業の規制及び食鳥検査に関する法律/本文/第19条.md|第十九条]]の規定に違反して、食鳥、食鳥とたい、食鳥中抜とたい若しくは食鳥肉等を消毒、廃棄又は食用に供することができないようにする措置を講じなかった者[[laws/食鳥処理の事業の規制及び食鳥検査に関する法律/本文/第20条.md|第二十条]]第一号の規定による禁止又は同条第二号の規定による命令に違反した者[[laws/食鳥処理の事業の規制及び食鳥検査に関する法律/本文/第20条.md|第二十条]]第二号又は第三号の規定による都道府県の職員の職務の執行を拒み、妨げ、若しくは忌避した者

- 一 [[laws/食鳥処理の事業の規制及び食鳥検査に関する法律/本文/第8条.md|第八条]]の規定による命令に違反した者
- 二 [[laws/食鳥処理の事業の規制及び食鳥検査に関する法律/本文/第9条.md|第九条]]の規定による禁止又は命令に違反した者
- 三 [[laws/食鳥処理の事業の規制及び食鳥検査に関する法律/本文/第18条.md|第十八条]]第一項又は第二項の規定に違反して、食鳥とたい、食鳥中抜とたい又は食鳥肉等を譲り受けた者
- 四 [[laws/食鳥処理の事業の規制及び食鳥検査に関する法律/本文/第19条.md|第十九条]]の規定に違反して、食鳥、食鳥とたい、食鳥中抜とたい若しくは食鳥肉等を消毒、廃棄又は食用に供することができないようにする措置を講じなかった者
- 五 [[laws/食鳥処理の事業の規制及び食鳥検査に関する法律/本文/第20条.md|第二十条]]第一号の規定による禁止又は同条第二号の規定による命令に違反した者
- 六 [[laws/食鳥処理の事業の規制及び食鳥検査に関する法律/本文/第20条.md|第二十条]]第二号又は第三号の規定による都道府県の職員の職務の執行を拒み、妨げ、若しくは忌避した者
