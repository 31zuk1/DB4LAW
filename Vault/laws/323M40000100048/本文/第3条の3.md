# 第三条の三 

## 
歯科医師又はその法定代理人若しくは同居の親族は、当該歯科医師が精神の機能の障害を有する状態となり歯科医師の業務の継続が著しく困難となつたときは、厚生労働大臣にその旨を届け出るものとする。この場合においては、その病名、障害の程度、病因、病後の経過、治癒の見込みその他参考となる所見を記載した医師の診断書を添付しなければならない。
