# 第八十一条 

## 
次の各号のいずれかに該当する者は、三十万円以下の罰金に処する。[[laws/中心市街地の活性化に関する法律/本文/第30条.md|第三十条]]第一項の規定による補助を受けた認定事業者で、当該補助に係る中心市街地共同住宅供給事業により建設される住宅についての[[laws/中心市街地の活性化に関する法律/本文/第28条.md|第二十八条]]の規定による市町村長の命令に違反したもの[[laws/中心市街地の活性化に関する法律/本文/第31条.md|第三十一条]]第一項又は第三項の規定に違反した者

- 一 [[laws/中心市街地の活性化に関する法律/本文/第30条.md|第三十条]]第一項の規定による補助を受けた認定事業者で、当該補助に係る中心市街地共同住宅供給事業により建設される住宅についての[[laws/中心市街地の活性化に関する法律/本文/第28条.md|第二十八条]]の規定による市町村長の命令に違反したもの
- 二 [[laws/中心市街地の活性化に関する法律/本文/第31条.md|第三十一条]]第一項又は第三項の規定に違反した者
