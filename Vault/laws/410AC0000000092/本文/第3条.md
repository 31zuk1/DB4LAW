# 第三条 （基本理念）

## 
中心市街地の活性化は、中心市街地が地域住民等の生活と交流の場であることを踏まえつつ、地域における社会的、経済的及び文化的活動の拠点となるにふさわしい魅力ある市街地の形成を図ることを基本とし、地方公共団体、地域住民及び関連事業者が相互に密接な連携を図りつつ主体的に取り組むことの重要性にかんがみ、その取組に対して国が集中的かつ効果的に支援を行うことを旨として、行われなければならない。
