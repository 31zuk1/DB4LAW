# 第二百七十三条 （金融商品仲介業者と密接な関係を有する者から除かれる者）

## 
令[[laws/金融商品取引業等に関する内閣府令/本文/第18条の2.md|第十八条の二]]各号列記以外の部分に規定する内閣府令で定める者は、次に掲げるものとする。金融商品取引業者（有価証券等管理業務を行う者に限る。）銀行協同組織金融機関保険会社信託会社株式会社商工組合中央金庫

- 一 金融商品取引業者（有価証券等管理業務を行う者に限る。）
- 二 銀行
- 三 協同組織金融機関
- 四 保険会社
- 五 信託会社
- 六 株式会社商工組合中央金庫
