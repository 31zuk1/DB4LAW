# 第二百三十二条の五 （許可申請書の添付書類）

## 
法[[laws/419M60000002052/金融商品取引業等に関する内閣府令_law.md|第六十条の十四]]第二項において準用する法[[laws/419M60000002052/本文/第60条の2.md|第六十条の二]]第三項第六号に規定する内閣府令で定める書類は、次に掲げる書類とする。電子店頭デリバティブ取引等業務の開始を決議した役員会等の議事録本店又は電子店頭デリバティブ取引等店（法[[laws/419M60000002052/金融商品取引業等に関する内閣府令_law.md|第六十条の十四]]第二項において読み替えて準用する法[[laws/419M60000002052/本文/第60条の2.md|第六十条の二]]第一項第三号に規定する電子店頭デリバティブ取引等店をいう。以下同じ。）が所在する全ての国において登録等を受けていることを証する書面全ての電子店頭デリバティブ取引等店において、電子店頭デリバティブ取引等業務と同種類の業務を一年以上継続して行っていること、又は令[[laws/419M60000002052/金融商品取引業等に関する内閣府令_law.md|第十七条の十]]の四第二項に定める場合に該当することを証する書面純財産額を算出した書面役員、電子店頭デリバティブ取引等店所在国における代表者（法[[laws/419M60000002052/金融商品取引業等に関する内閣府令_law.md|第六十条の十四]]第二項において読み替えて準用する法[[laws/419M60000002052/本文/第60条の2.md|第六十条の二]]第一項第三号に規定する電子店頭デリバティブ取引等店所在国における代表者をいう。）及び国内における代表者（以下この款において「役員等」という。）の履歴書（役員が法人であるときは、当該役員の沿革を記載した書面）役員等の住民票の抄本（役員が法人であるときは、当該役員の登記事項証明書）又はこれに代わる書面役員等の旧氏及び名を当該役員等の氏名に併せて法[[laws/419M60000002052/金融商品取引業等に関する内閣府令_law.md|第六十条の十四]]第二項において準用する法[[laws/419M60000002052/本文/第60条の2.md|第六十条の二]]第一項の許可申請書に記載した場合において、前号に掲げる書類が当該役員等の旧氏及び名を証するものでないときは、当該旧氏及び名を証する書面役員等が法[[laws/419M60000002052/金融商品取引業等に関する内閣府令_law.md|第二十九条の四]]第一項第二号ロに該当しない旨の官公署の証明書又はこれに代わる書面役員等が法[[laws/419M60000002052/金融商品取引業等に関する内閣府令_law.md|第二十九条の四]]第一項第二号イ又はハからリまでのいずれにも該当しない者であることを当該役員等が誓約する書面電子店頭デリバティブ取引等業務を管理する責任者の履歴書電子店頭デリバティブ取引等業務に関する社内規則電子店頭デリバティブ取引等業務に関し顧客と取引を行う際に使用する契約書類及びその添付書類電子店頭デリバティブ取引等業務を行う際に使用する電子情報処理組織において、不公正な取引の防止を図るために講じている措置を記載した書面前条第十四号に掲げるものに関する許可申請者と特別の利害関係のない者の評価書

- 一 電子店頭デリバティブ取引等業務の開始を決議した役員会等の議事録
- 二 本店又は電子店頭デリバティブ取引等店（法[[laws/419M60000002052/金融商品取引業等に関する内閣府令_law.md|第六十条の十四]]第二項において読み替えて準用する法[[laws/419M60000002052/本文/第60条の2.md|第六十条の二]]第一項第三号に規定する電子店頭デリバティブ取引等店をいう。以下同じ。）が所在する全ての国において登録等を受けていることを証する書面
- 三 全ての電子店頭デリバティブ取引等店において、電子店頭デリバティブ取引等業務と同種類の業務を一年以上継続して行っていること、又は令[[laws/419M60000002052/金融商品取引業等に関する内閣府令_law.md|第十七条の十]]の四第二項に定める場合に該当することを証する書面
- 四 純財産額を算出した書面
- 五 役員、電子店頭デリバティブ取引等店所在国における代表者（法[[laws/419M60000002052/金融商品取引業等に関する内閣府令_law.md|第六十条の十四]]第二項において読み替えて準用する法[[laws/419M60000002052/本文/第60条の2.md|第六十条の二]]第一項第三号に規定する電子店頭デリバティブ取引等店所在国における代表者をいう。）及び国内における代表者（以下この款において「役員等」という。）の履歴書（役員が法人であるときは、当該役員の沿革を記載した書面）
- 六 役員等の住民票の抄本（役員が法人であるときは、当該役員の登記事項証明書）又はこれに代わる書面
- 七 役員等の旧氏及び名を当該役員等の氏名に併せて法[[laws/419M60000002052/金融商品取引業等に関する内閣府令_law.md|第六十条の十四]]第二項において準用する法[[laws/419M60000002052/本文/第60条の2.md|第六十条の二]]第一項の許可申請書に記載した場合において、前号に掲げる書類が当該役員等の旧氏及び名を証するものでないときは、当該旧氏及び名を証する書面
- 八 役員等が法[[laws/419M60000002052/金融商品取引業等に関する内閣府令_law.md|第二十九条の四]]第一項第二号ロに該当しない旨の官公署の証明書又はこれに代わる書面
- 九 役員等が法[[laws/419M60000002052/金融商品取引業等に関する内閣府令_law.md|第二十九条の四]]第一項第二号イ又はハからリまでのいずれにも該当しない者であることを当該役員等が誓約する書面
- 十 電子店頭デリバティブ取引等業務を管理する責任者の履歴書
- 十一 電子店頭デリバティブ取引等業務に関する社内規則
- 十二 電子店頭デリバティブ取引等業務に関し顧客と取引を行う際に使用する契約書類及びその添付書類
- 十三 電子店頭デリバティブ取引等業務を行う際に使用する電子情報処理組織において、不公正な取引の防止を図るために講じている措置を記載した書面
- 十四 前条第十四号に掲げるものに関する許可申請者と特別の利害関係のない者の評価書
