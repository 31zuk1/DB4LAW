# 第二百五十四条 （協会の外務員登録事務）

## 
法[[laws/金融商品取引業等に関する内閣府令/本文/第64条の7.md|第六十四条の七]]第一項及び第二項の規定に基づき、次に掲げる登録に関する事務であって、協会に所属する金融商品取引業者等の外務員に係るものを当該協会に、協会に所属しない金融商品取引業者等に係るものを同項の規定により金融庁長官が定める協会に行わせるものとする。法[[laws/金融商品取引業等に関する内閣府令/本文/第64条.md|第六十四条]]第三項の規定による登録申請書の受理法[[laws/金融商品取引業等に関する内閣府令/本文/第64条.md|第六十四条]]第五項の規定による登録法[[laws/金融商品取引業等に関する内閣府令/本文/第64条.md|第六十四条]]第六項、[[laws/金融商品取引業等に関する内閣府令/本文/第64条の2.md|第六十四条の二]]第三項及び[[laws/金融商品取引業等に関する内閣府令/本文/第64条の5.md|第六十四条の五]]第三項の規定による通知法[[laws/金融商品取引業等に関する内閣府令/本文/第64条の2.md|第六十四条の二]]第一項の規定による登録の拒否法[[laws/金融商品取引業等に関する内閣府令/本文/第64条の2.md|第六十四条の二]]第二項の規定による審問法[[laws/金融商品取引業等に関する内閣府令/本文/第64条の4.md|第六十四条の四]]の規定による届出の受理法[[laws/金融商品取引業等に関する内閣府令/本文/第64条の5.md|第六十四条の五]]第一項の規定による登録の取消し及び職務の停止の命令法[[laws/金融商品取引業等に関する内閣府令/本文/第64条の5.md|第六十四条の五]]第二項の規定による聴聞法[[laws/金融商品取引業等に関する内閣府令/本文/第64条の6.md|第六十四条の六]]の規定による登録の抹消

- 一 法[[laws/金融商品取引業等に関する内閣府令/本文/第64条.md|第六十四条]]第三項の規定による登録申請書の受理
- 二 法[[laws/金融商品取引業等に関する内閣府令/本文/第64条.md|第六十四条]]第五項の規定による登録
- 三 法[[laws/金融商品取引業等に関する内閣府令/本文/第64条.md|第六十四条]]第六項、[[laws/金融商品取引業等に関する内閣府令/本文/第64条の2.md|第六十四条の二]]第三項及び[[laws/金融商品取引業等に関する内閣府令/本文/第64条の5.md|第六十四条の五]]第三項の規定による通知
- 四 法[[laws/金融商品取引業等に関する内閣府令/本文/第64条の2.md|第六十四条の二]]第一項の規定による登録の拒否
- 五 法[[laws/金融商品取引業等に関する内閣府令/本文/第64条の2.md|第六十四条の二]]第二項の規定による審問
- 六 法[[laws/金融商品取引業等に関する内閣府令/本文/第64条の4.md|第六十四条の四]]の規定による届出の受理
- 七 法[[laws/金融商品取引業等に関する内閣府令/本文/第64条の5.md|第六十四条の五]]第一項の規定による登録の取消し及び職務の停止の命令
- 八 法[[laws/金融商品取引業等に関する内閣府令/本文/第64条の5.md|第六十四条の五]]第二項の規定による聴聞
- 九 法[[laws/金融商品取引業等に関する内閣府令/本文/第64条の6.md|第六十四条の六]]の規定による登録の抹消
