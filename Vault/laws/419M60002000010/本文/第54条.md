# 第五十四条 （施設企画課の所掌事務）

## 
施設企画課は、次に掲げる事務をつかさどる。次号から第六号まで及び[[laws/419M60002000010/本文/第56条.md|第五十六条]]から[[laws/419M60002000010/本文/第58条.md|第五十八条]]までに規定する事務に関する企画、立案及び総括に関すること。[[laws/419M60002000010/本文/第15条.md|第十五条]]第一項第二号から第四号まで、[[laws/419M60002000010/本文/第21条.md|第二十一条]]第一項第一号から第三号まで及び第五号から第七号まで、[[laws/419M60002000010/本文/第33条.md|第三十三条]]第一項第三号並びに[[laws/419M60002000010/本文/第51条.md|第五十一条]]第一項第二十六号に掲げる事務合衆国軍協定[[laws/419M60002000010/本文/第18条.md|第十八条]]の規定に基づく請求の処理に関すること。日本国における国際連合の軍隊の地位に関する協定[[laws/419M60002000010/本文/第18条.md|第十八条]]の規定に基づく請求の処理をするための駐留軍、利害関係人又は関係行政機関との連絡及び交渉、調査並びに資料の収集整理に関すること。被害者等給付金支給法の規定による給付金の支給をするための利害関係人又は関係行政機関との連絡及び交渉、調査並びに資料の収集整理に関すること。第二号から第四号まで及び[[laws/419M60002000010/本文/第56条.md|第五十六条]]から[[laws/419M60002000010/本文/第58条.md|第五十八条]]までに規定する事務に関する争訟に関すること。

- 一 次号から第六号まで及び[[laws/419M60002000010/本文/第56条.md|第五十六条]]から[[laws/419M60002000010/本文/第58条.md|第五十八条]]までに規定する事務に関する企画、立案及び総括に関すること。
- 二 [[laws/419M60002000010/本文/第15条.md|第十五条]]第一項第二号から第四号まで、[[laws/419M60002000010/本文/第21条.md|第二十一条]]第一項第一号から第三号まで及び第五号から第七号まで、[[laws/419M60002000010/本文/第33条.md|第三十三条]]第一項第三号並びに[[laws/419M60002000010/本文/第51条.md|第五十一条]]第一項第二十六号に掲げる事務
- 三 合衆国軍協定[[laws/419M60002000010/本文/第18条.md|第十八条]]の規定に基づく請求の処理に関すること。
- 四 日本国における国際連合の軍隊の地位に関する協定[[laws/419M60002000010/本文/第18条.md|第十八条]]の規定に基づく請求の処理をするための駐留軍、利害関係人又は関係行政機関との連絡及び交渉、調査並びに資料の収集整理に関すること。
- 五 被害者等給付金支給法の規定による給付金の支給をするための利害関係人又は関係行政機関との連絡及び交渉、調査並びに資料の収集整理に関すること。
- 六 第二号から第四号まで及び[[laws/419M60002000010/本文/第56条.md|第五十六条]]から[[laws/419M60002000010/本文/第58条.md|第五十八条]]までに規定する事務に関する争訟に関すること。
