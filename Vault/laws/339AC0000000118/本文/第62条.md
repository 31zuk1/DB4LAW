# 第六十二条 

## 
次の各号のいずれかに該当する場合には、その違反行為をした労働災害防止団体の発起人、役員又は清算人は、二十万円以下の過料に処する。この法律に基づいて労働災害防止団体が行うことができる業務以外の業務を行つたとき。[[laws/339AC0000000118/本文/第10条.md|第十条]]第一項の政令に違反して登記することを怠つたとき。[[laws/339AC0000000118/本文/第14条.md|第十四条]]第二項（[[laws/339AC0000000118/本文/第42条.md|第四十二条]]第二項において準用する場合を含む。）の規定に違反したとき。[[laws/339AC0000000118/本文/第32条の2.md|第三十二条の二]]第二項又は[[laws/339AC0000000118/本文/第33条の7.md|第三十三条の七]]第一項（これらの規定を[[laws/339AC0000000118/本文/第50条.md|第五十条]]において準用する場合を含む。）の規定による破産手続開始の申立てをしなかつたとき。[[laws/339AC0000000118/本文/第33条の5.md|第三十三条の五]]第一項又は[[laws/339AC0000000118/本文/第33条の7.md|第三十三条の七]]第一項（これらの規定を[[laws/339AC0000000118/本文/第50条.md|第五十条]]において準用する場合を含む。）の規定による公告をせず、又は不正の公告をしたとき。[[laws/339AC0000000118/本文/第34条.md|第三十四条]]（[[laws/339AC0000000118/本文/第50条.md|第五十条]]において準用する場合を含む。）の認可を受けないで財産処分をしたとき。[[laws/339AC0000000118/本文/第51条.md|第五十一条]]第一項に規定する書類を同項に規定する期間内に提出しなかつたとき。定款、事業報告書、貸借対照表、収支決算書又は財産目録に記載すべき事項を記載せず、又は不実の記載をしたとき。

- 一 この法律に基づいて労働災害防止団体が行うことができる業務以外の業務を行つたとき。
- 二 [[laws/339AC0000000118/本文/第10条.md|第十条]]第一項の政令に違反して登記することを怠つたとき。
- 三 [[laws/339AC0000000118/本文/第14条.md|第十四条]]第二項（[[laws/339AC0000000118/本文/第42条.md|第四十二条]]第二項において準用する場合を含む。）の規定に違反したとき。
- 四 [[laws/339AC0000000118/本文/第32条の2.md|第三十二条の二]]第二項又は[[laws/339AC0000000118/本文/第33条の7.md|第三十三条の七]]第一項（これらの規定を[[laws/339AC0000000118/本文/第50条.md|第五十条]]において準用する場合を含む。）の規定による破産手続開始の申立てをしなかつたとき。
- 五 [[laws/339AC0000000118/本文/第33条の5.md|第三十三条の五]]第一項又は[[laws/339AC0000000118/本文/第33条の7.md|第三十三条の七]]第一項（これらの規定を[[laws/339AC0000000118/本文/第50条.md|第五十条]]において準用する場合を含む。）の規定による公告をせず、又は不正の公告をしたとき。
- 六 [[laws/339AC0000000118/本文/第34条.md|第三十四条]]（[[laws/339AC0000000118/本文/第50条.md|第五十条]]において準用する場合を含む。）の認可を受けないで財産処分をしたとき。
- 七 [[laws/339AC0000000118/本文/第51条.md|第五十一条]]第一項に規定する書類を同項に規定する期間内に提出しなかつたとき。
- 八 定款、事業報告書、貸借対照表、収支決算書又は財産目録に記載すべき事項を記載せず、又は不実の記載をしたとき。
