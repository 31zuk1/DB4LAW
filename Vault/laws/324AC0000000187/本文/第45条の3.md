# 第四十五条の三 （手数料）

## 
次に掲げる者は、実費を勘案して国土交通省令で定める額の手数料を国（指定試験機関が行う試験を受けようとする者にあつては、当該指定試験機関）に納めなければならない。[[laws/324AC0000000187/本文/第32条の3.md|第三十二条の三]]第一項の規定による安全統括管理者資格者証の交付を申請する者安全統括管理者資格者証の再交付を申請する者総合安全統括管理者試験、大型船舶安全統括管理者試験又は小型船舶安全統括管理者試験を受ける者[[laws/324AC0000000187/本文/第32条の5.md|第三十二条の五]]第二項の規定による安全統括管理者資格者証の有効期間の更新を申請する者安全統括管理者講習（国土交通大臣が行うものに限る。）を受ける者[[laws/324AC0000000187/本文/第32条の7.md|第三十二条の七]]第一項の規定による運航管理者資格者証の交付を申請する者運航管理者資格者証の再交付を申請する者総合運航管理者試験、大型船舶運航管理者試験又は小型船舶運航管理者試験を受ける者[[laws/324AC0000000187/本文/第32条の9.md|第三十二条の九]]第二項の規定による運航管理者資格者証の有効期間の更新を申請する者運航管理者講習（国土交通大臣が行うものに限る。）を受ける者[[laws/324AC0000000187/本文/第38条.md|第三十八条]]第三項又は第八項の規定による測度を申請する者[[laws/324AC0000000187/本文/第38条.md|第三十八条]]第四項又は第九項の規定による検査（国土交通大臣が行うものに限る。）を申請する者

- 一 [[laws/324AC0000000187/本文/第32条の3.md|第三十二条の三]]第一項の規定による安全統括管理者資格者証の交付を申請する者
- 二 安全統括管理者資格者証の再交付を申請する者
- 三 総合安全統括管理者試験、大型船舶安全統括管理者試験又は小型船舶安全統括管理者試験を受ける者
- 四 [[laws/324AC0000000187/本文/第32条の5.md|第三十二条の五]]第二項の規定による安全統括管理者資格者証の有効期間の更新を申請する者
- 五 安全統括管理者講習（国土交通大臣が行うものに限る。）を受ける者
- 六 [[laws/324AC0000000187/本文/第32条の7.md|第三十二条の七]]第一項の規定による運航管理者資格者証の交付を申請する者
- 七 運航管理者資格者証の再交付を申請する者
- 八 総合運航管理者試験、大型船舶運航管理者試験又は小型船舶運航管理者試験を受ける者
- 九 [[laws/324AC0000000187/本文/第32条の9.md|第三十二条の九]]第二項の規定による運航管理者資格者証の有効期間の更新を申請する者
- 十 運航管理者講習（国土交通大臣が行うものに限る。）を受ける者
- 十一 [[laws/324AC0000000187/本文/第38条.md|第三十八条]]第三項又は第八項の規定による測度を申請する者
- 十二 [[laws/324AC0000000187/本文/第38条.md|第三十八条]]第四項又は第九項の規定による検査（国土交通大臣が行うものに限る。）を申請する者
## ２
前項の規定により指定試験機関に納められた手数料は、指定試験機関の収入とする。
