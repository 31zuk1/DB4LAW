# 第五十六条 

## 
次の各号のいずれかに該当する者は、五十万円以下の過料に処する。[[laws/324AC0000000187/本文/第10条.md|第十条]]（[[laws/324AC0000000187/本文/第19条の6.md|第十九条の六]]第二項及び[[laws/324AC0000000187/本文/第19条の16.md|第十九条の十六]]第一項において準用する場合並びに[[laws/324AC0000000187/本文/第20条.md|第二十条]]第二項及び[[laws/324AC0000000187/本文/第20条の2.md|第二十条の二]]第三項において読み替えて準用する場合を含む。）の規定による公示をしなかつた者[[laws/324AC0000000187/本文/第11条.md|第十一条]]第三項（[[laws/324AC0000000187/本文/第19条の6.md|第十九条の六]]第二項及び[[laws/324AC0000000187/本文/第21条の5.md|第二十一条の五]]において準用する場合を含む。）、[[laws/324AC0000000187/本文/第11条の2.md|第十一条の二]]第四項若しくは[[laws/324AC0000000187/本文/第20条の2.md|第二十条の二]]第二項の規定若しくは[[laws/324AC0000000187/本文/第23条.md|第二十三条]]第一項若しくは第二項（これらの規定を[[laws/324AC0000000187/本文/第33条.md|第三十三条]]において準用する場合を含む。）の規定による届出をせず、又は虚偽の届出をした者[[laws/324AC0000000187/本文/第19条の4.md|第十九条の四]]（[[laws/324AC0000000187/本文/第19条の6.md|第十九条の六]]第二項、[[laws/324AC0000000187/本文/第19条の16.md|第十九条の十六]]第一項、[[laws/324AC0000000187/本文/第20条.md|第二十条]]第二項、[[laws/324AC0000000187/本文/第21条の5.md|第二十一条の五]]及び[[laws/324AC0000000187/本文/第22条.md|第二十二条]]第二項において準用する場合を含む。）の規定による公表をせず、又は虚偽の公表をした者[[laws/324AC0000000187/本文/第19条の13.md|第十九条の十三]]第一項（[[laws/324AC0000000187/本文/第20条.md|第二十条]]第二項及び[[laws/324AC0000000187/本文/第22条.md|第二十二条]]第二項において準用する場合を含む。）の規定による届出をしないで、又は虚偽の届出をして、事業を廃止した者[[laws/324AC0000000187/本文/第20条の2.md|第二十条の二]]第一項の規定による届出をしないで、又は虚偽の届出をして、貨物専用定期航路事業を営んだ者正当な理由がなく、[[laws/324AC0000000187/本文/第32条の6.md|第三十二条の六]]の規定による命令に違反して、安全統括管理者資格者証を返納しなかつた者正当な理由がなく、[[laws/324AC0000000187/本文/第32条の10.md|第三十二条の十]]の規定による命令に違反して、運航管理者資格者証を返納しなかつた者

- 一 [[laws/324AC0000000187/本文/第10条.md|第十条]]（[[laws/324AC0000000187/本文/第19条の6.md|第十九条の六]]第二項及び[[laws/324AC0000000187/本文/第19条の16.md|第十九条の十六]]第一項において準用する場合並びに[[laws/324AC0000000187/本文/第20条.md|第二十条]]第二項及び[[laws/324AC0000000187/本文/第20条の2.md|第二十条の二]]第三項において読み替えて準用する場合を含む。）の規定による公示をしなかつた者
- 二 [[laws/324AC0000000187/本文/第11条.md|第十一条]]第三項（[[laws/324AC0000000187/本文/第19条の6.md|第十九条の六]]第二項及び[[laws/324AC0000000187/本文/第21条の5.md|第二十一条の五]]において準用する場合を含む。）、[[laws/324AC0000000187/本文/第11条の2.md|第十一条の二]]第四項若しくは[[laws/324AC0000000187/本文/第20条の2.md|第二十条の二]]第二項の規定若しくは[[laws/324AC0000000187/本文/第23条.md|第二十三条]]第一項若しくは第二項（これらの規定を[[laws/324AC0000000187/本文/第33条.md|第三十三条]]において準用する場合を含む。）の規定による届出をせず、又は虚偽の届出をした者
- 三 [[laws/324AC0000000187/本文/第19条の4.md|第十九条の四]]（[[laws/324AC0000000187/本文/第19条の6.md|第十九条の六]]第二項、[[laws/324AC0000000187/本文/第19条の16.md|第十九条の十六]]第一項、[[laws/324AC0000000187/本文/第20条.md|第二十条]]第二項、[[laws/324AC0000000187/本文/第21条の5.md|第二十一条の五]]及び[[laws/324AC0000000187/本文/第22条.md|第二十二条]]第二項において準用する場合を含む。）の規定による公表をせず、又は虚偽の公表をした者
- 四 [[laws/324AC0000000187/本文/第19条の13.md|第十九条の十三]]第一項（[[laws/324AC0000000187/本文/第20条.md|第二十条]]第二項及び[[laws/324AC0000000187/本文/第22条.md|第二十二条]]第二項において準用する場合を含む。）の規定による届出をしないで、又は虚偽の届出をして、事業を廃止した者
- 五 [[laws/324AC0000000187/本文/第20条の2.md|第二十条の二]]第一項の規定による届出をしないで、又は虚偽の届出をして、貨物専用定期航路事業を営んだ者
- 六 正当な理由がなく、[[laws/324AC0000000187/本文/第32条の6.md|第三十二条の六]]の規定による命令に違反して、安全統括管理者資格者証を返納しなかつた者
- 七 正当な理由がなく、[[laws/324AC0000000187/本文/第32条の10.md|第三十二条の十]]の規定による命令に違反して、運航管理者資格者証を返納しなかつた者
