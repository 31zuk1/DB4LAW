# 第三十二条の二十三 （指定の取消し等）

## 
国土交通大臣は、指定試験機関が次の各号のいずれかに該当するときは、その指定を取り消し、又は期間を定めて試験事務に関する業務の全部若しくは一部の停止を命ずることができる。[[laws/324AC0000000187/本文/第32条の13.md|第三十二条の十三]]第一項各号のいずれかに適合しなくなつたと認められるとき。[[laws/324AC0000000187/本文/第32条の13.md|第三十二条の十三]]第二項第二号に該当するに至つたとき。[[laws/324AC0000000187/本文/第32条の14.md|第三十二条の十四]]第二項、[[laws/324AC0000000187/本文/第32条の16.md|第三十二条の十六]]第一項から第三項まで若しくは第六項、[[laws/324AC0000000187/本文/第32条の18.md|第三十二条の十八]]又は[[laws/324AC0000000187/本文/第32条の19.md|第三十二条の十九]]の規定に違反したとき。[[laws/324AC0000000187/本文/第32条の16.md|第三十二条の十六]]第四項、[[laws/324AC0000000187/本文/第32条の17.md|第三十二条の十七]]第二項又は[[laws/324AC0000000187/本文/第32条の21.md|第三十二条の二十一]]の規定による命令に違反したとき。[[laws/324AC0000000187/本文/第32条の17.md|第三十二条の十七]]第一項の規定により認可を受けた試験事務規程によらないで試験事務を行つたとき。不正の手段により指定を受けたとき。

- 一 [[laws/324AC0000000187/本文/第32条の13.md|第三十二条の十三]]第一項各号のいずれかに適合しなくなつたと認められるとき。
- 二 [[laws/324AC0000000187/本文/第32条の13.md|第三十二条の十三]]第二項第二号に該当するに至つたとき。
- 三 [[laws/324AC0000000187/本文/第32条の14.md|第三十二条の十四]]第二項、[[laws/324AC0000000187/本文/第32条の16.md|第三十二条の十六]]第一項から第三項まで若しくは第六項、[[laws/324AC0000000187/本文/第32条の18.md|第三十二条の十八]]又は[[laws/324AC0000000187/本文/第32条の19.md|第三十二条の十九]]の規定に違反したとき。
- 四 [[laws/324AC0000000187/本文/第32条の16.md|第三十二条の十六]]第四項、[[laws/324AC0000000187/本文/第32条の17.md|第三十二条の十七]]第二項又は[[laws/324AC0000000187/本文/第32条の21.md|第三十二条の二十一]]の規定による命令に違反したとき。
- 五 [[laws/324AC0000000187/本文/第32条の17.md|第三十二条の十七]]第一項の規定により認可を受けた試験事務規程によらないで試験事務を行つたとき。
- 六 不正の手段により指定を受けたとき。
## ２
国土交通大臣は、前項の規定により指定を取り消し、又は試験事務に関する業務の全部若しくは一部の停止を命じたときは、その旨を官報で公示しなければならない。
