# 第五十二条 

## 
次の各号のいずれかに該当する場合には、当該違反行為をした者は、三十万円以下の罰金に処する。[[laws/324AC0000000187/本文/第15条.md|第十五条]]（[[laws/324AC0000000187/本文/第19条の16.md|第十九条の十六]]第一項、[[laws/324AC0000000187/本文/第21条の5.md|第二十一条の五]]並びに[[laws/324AC0000000187/本文/第22条.md|第二十二条]]第四項及び第五項において準用する場合を含む。）の規定に違反して、旅客名簿を備え置かず、又は旅客名簿に記載すべき事項を記載せず、若しくは虚偽の記載をしたとき。[[laws/324AC0000000187/本文/第32条の19.md|第三十二条の十九]]又は[[laws/324AC0000000187/本文/第32条の32.md|第三十二条の三十二]]（[[laws/324AC0000000187/本文/第32条の40.md|第三十二条の四十]]第二項において準用する場合を含む。）の規定に違反して、帳簿を備えず、帳簿に記載せず、若しくは帳簿に虚偽の記載をし、又は帳簿を保存しなかつたとき。[[laws/324AC0000000187/本文/第32条の22.md|第三十二条の二十二]]第一項の規定による許可を受けないで試験事務の全部を廃止したとき。[[laws/324AC0000000187/本文/第32条の36.md|第三十二条の三十六]]の規定による届出をしないで安全統括管理者講習の実施に関する事務に関する業務の全部若しくは一部を休止し、若しくは廃止し、又は虚偽の届出をしたとき。[[laws/324AC0000000187/本文/第32条の40.md|第三十二条の四十]]第二項において準用する[[laws/324AC0000000187/本文/第32条の36.md|第三十二条の三十六]]の規定による届出をしないで運航管理者講習の実施に関する事務に関する業務の全部若しくは一部を休止し、若しくは廃止し、又は虚偽の届出をしたとき。[[laws/324AC0000000187/本文/第32条の41.md|第三十二条の四十一]]第一項の規定による報告をせず、若しくは虚偽の報告をし、同項の規定による検査を拒み、妨げ、若しくは忌避し、又は同項の規定による質問に対して陳述をせず、若しくは虚偽の陳述をしたとき。[[laws/324AC0000000187/本文/第37条の3.md|第三十七条の三]]第一項若しくは[[laws/324AC0000000187/本文/第44条の2.md|第四十四条の二]]の規定による届出をしないで、又は虚偽の届出をして、譲渡又は貸渡しをしたとき。[[laws/324AC0000000187/本文/第39条の6.md|第三十九条の六]]第一項の規定による届出をしないで、又は虚偽の届出をして、譲渡をしたとき。[[laws/324AC0000000187/本文/第39条の6.md|第三十九条の六]]第二項の規定による届出をせず、又は虚偽の届出をしたとき。[[laws/324AC0000000187/本文/第39条の18.md|第三十九条の十八]]の規定による報告をせず、又は虚偽の報告をしたとき。[[laws/324AC0000000187/本文/第39条の30.md|第三十九条の三十]]の規定に違反して、帳簿を備えず、帳簿に記載せず、若しくは帳簿に虚偽の記載をし、又は帳簿を保存しなかつたとき。[[laws/324AC0000000187/本文/第39条の32.md|第三十九条の三十二]]第一項の規定による届出をしないで導入促進業務の全部若しくは一部を休止し、若しくは廃止し、又は虚偽の届出をしたとき。[[laws/324AC0000000187/本文/第39条の36.md|第三十九条の三十六]]の規定による報告をせず、又は虚偽の報告をしたとき。[[laws/324AC0000000187/本文/第39条の37.md|第三十九条の三十七]]第一項の規定による報告をせず、若しくは虚偽の報告をし、又は同項の規定による検査を拒み、妨げ、若しくは忌避したとき。

- 一 [[laws/324AC0000000187/本文/第15条.md|第十五条]]（[[laws/324AC0000000187/本文/第19条の16.md|第十九条の十六]]第一項、[[laws/324AC0000000187/本文/第21条の5.md|第二十一条の五]]並びに[[laws/324AC0000000187/本文/第22条.md|第二十二条]]第四項及び第五項において準用する場合を含む。）の規定に違反して、旅客名簿を備え置かず、又は旅客名簿に記載すべき事項を記載せず、若しくは虚偽の記載をしたとき。
- 二 [[laws/324AC0000000187/本文/第32条の19.md|第三十二条の十九]]又は[[laws/324AC0000000187/本文/第32条の32.md|第三十二条の三十二]]（[[laws/324AC0000000187/本文/第32条の40.md|第三十二条の四十]]第二項において準用する場合を含む。）の規定に違反して、帳簿を備えず、帳簿に記載せず、若しくは帳簿に虚偽の記載をし、又は帳簿を保存しなかつたとき。
- 三 [[laws/324AC0000000187/本文/第32条の22.md|第三十二条の二十二]]第一項の規定による許可を受けないで試験事務の全部を廃止したとき。
- 四 [[laws/324AC0000000187/本文/第32条の36.md|第三十二条の三十六]]の規定による届出をしないで安全統括管理者講習の実施に関する事務に関する業務の全部若しくは一部を休止し、若しくは廃止し、又は虚偽の届出をしたとき。
- 五 [[laws/324AC0000000187/本文/第32条の40.md|第三十二条の四十]]第二項において準用する[[laws/324AC0000000187/本文/第32条の36.md|第三十二条の三十六]]の規定による届出をしないで運航管理者講習の実施に関する事務に関する業務の全部若しくは一部を休止し、若しくは廃止し、又は虚偽の届出をしたとき。
- 六 [[laws/324AC0000000187/本文/第32条の41.md|第三十二条の四十一]]第一項の規定による報告をせず、若しくは虚偽の報告をし、同項の規定による検査を拒み、妨げ、若しくは忌避し、又は同項の規定による質問に対して陳述をせず、若しくは虚偽の陳述をしたとき。
- 七 [[laws/324AC0000000187/本文/第37条の3.md|第三十七条の三]]第一項若しくは[[laws/324AC0000000187/本文/第44条の2.md|第四十四条の二]]の規定による届出をしないで、又は虚偽の届出をして、譲渡又は貸渡しをしたとき。
- 八 [[laws/324AC0000000187/本文/第39条の6.md|第三十九条の六]]第一項の規定による届出をしないで、又は虚偽の届出をして、譲渡をしたとき。
- 九 [[laws/324AC0000000187/本文/第39条の6.md|第三十九条の六]]第二項の規定による届出をせず、又は虚偽の届出をしたとき。
- 十 [[laws/324AC0000000187/本文/第39条の18.md|第三十九条の十八]]の規定による報告をせず、又は虚偽の報告をしたとき。
- 十一 [[laws/324AC0000000187/本文/第39条の30.md|第三十九条の三十]]の規定に違反して、帳簿を備えず、帳簿に記載せず、若しくは帳簿に虚偽の記載をし、又は帳簿を保存しなかつたとき。
- 十二 [[laws/324AC0000000187/本文/第39条の32.md|第三十九条の三十二]]第一項の規定による届出をしないで導入促進業務の全部若しくは一部を休止し、若しくは廃止し、又は虚偽の届出をしたとき。
- 十三 [[laws/324AC0000000187/本文/第39条の36.md|第三十九条の三十六]]の規定による報告をせず、又は虚偽の報告をしたとき。
- 十四 [[laws/324AC0000000187/本文/第39条の37.md|第三十九条の三十七]]第一項の規定による報告をせず、若しくは虚偽の報告をし、又は同項の規定による検査を拒み、妨げ、若しくは忌避したとき。
