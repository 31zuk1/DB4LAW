# 第五十七条 

## 
次の各号のいずれかに該当する場合には、協会の役員、代理人又は清算人を二十万円以下の過料に処する。第二章の規定により主務大臣の認可を受けなければならない場合において、その認可を受けなかつたとき。[[laws/328AC0000000196/本文/第4条.md|第四条]]第一項の規定に基づく政令の規定による登記をすることを怠つたとき。[[laws/328AC0000000196/本文/第12条.md|第十二条]]の規定に違反したとき。[[laws/328AC0000000196/本文/第15条.md|第十五条]]又は[[laws/328AC0000000196/本文/第17条.md|第十七条]]の規定に違反して定款その他の書類を備えて置かず、これらの書類に記載すべき事項を記載せず、若しくは虚偽の記載をし、又は正当な理由がないのにこれらの書類の閲覧を拒んだとき。[[laws/328AC0000000196/本文/第20条.md|第二十条]]第一項及び第二項に規定する業務以外の業務を行つたとき。[[laws/328AC0000000196/本文/第22条.md|第二十二条]]の規定に違反したとき。[[laws/328AC0000000196/本文/第25条.md|第二十五条]]の規定に違反して合併したとき。[[laws/328AC0000000196/本文/第25条.md|第二十五条]]第二項の規定による公告をする場合において虚偽の公告をしたとき。[[laws/328AC0000000196/本文/第28条の6.md|第二十八条の六]]第一項の規定に違反して破産手続開始の申立てを怠つたとき。[[laws/328AC0000000196/本文/第29条.md|第二十九条]]に規定する書類に記載すべき事項を記載せず、又は虚偽の記載をしたとき。[[laws/328AC0000000196/本文/第29条の2.md|第二十九条の二]]第一項の規定による公告を怠り、又は虚偽の公告をしたとき。[[laws/328AC0000000196/本文/第29条の2.md|第二十九条の二]]第一項に規定する期間内に債権者に弁済したとき。[[laws/328AC0000000196/本文/第30条.md|第三十条]]第一項又は第二項の規定に違反したとき。[[laws/328AC0000000196/本文/第31条.md|第三十一条]]第一項に規定する書類に記載すべき事項を記載せず、又は虚偽の記載をしたとき。

- 一 第二章の規定により主務大臣の認可を受けなければならない場合において、その認可を受けなかつたとき。
- 二 [[laws/328AC0000000196/本文/第4条.md|第四条]]第一項の規定に基づく政令の規定による登記をすることを怠つたとき。
- 三 [[laws/328AC0000000196/本文/第12条.md|第十二条]]の規定に違反したとき。
- 四 [[laws/328AC0000000196/本文/第15条.md|第十五条]]又は[[laws/328AC0000000196/本文/第17条.md|第十七条]]の規定に違反して定款その他の書類を備えて置かず、これらの書類に記載すべき事項を記載せず、若しくは虚偽の記載をし、又は正当な理由がないのにこれらの書類の閲覧を拒んだとき。
- 五 [[laws/328AC0000000196/本文/第20条.md|第二十条]]第一項及び第二項に規定する業務以外の業務を行つたとき。
- 六 [[laws/328AC0000000196/本文/第22条.md|第二十二条]]の規定に違反したとき。
- 七 [[laws/328AC0000000196/本文/第25条.md|第二十五条]]の規定に違反して合併したとき。
- 八 [[laws/328AC0000000196/本文/第25条.md|第二十五条]]第二項の規定による公告をする場合において虚偽の公告をしたとき。
- 九 [[laws/328AC0000000196/本文/第28条の6.md|第二十八条の六]]第一項の規定に違反して破産手続開始の申立てを怠つたとき。
- 十 [[laws/328AC0000000196/本文/第29条.md|第二十九条]]に規定する書類に記載すべき事項を記載せず、又は虚偽の記載をしたとき。
- 十一 [[laws/328AC0000000196/本文/第29条の2.md|第二十九条の二]]第一項の規定による公告を怠り、又は虚偽の公告をしたとき。
- 十二 [[laws/328AC0000000196/本文/第29条の2.md|第二十九条の二]]第一項に規定する期間内に債権者に弁済したとき。
- 十三 [[laws/328AC0000000196/本文/第30条.md|第三十条]]第一項又は第二項の規定に違反したとき。
- 十四 [[laws/328AC0000000196/本文/第31条.md|第三十一条]]第一項に規定する書類に記載すべき事項を記載せず、又は虚偽の記載をしたとき。
