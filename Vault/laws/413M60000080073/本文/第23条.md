# 第二十三条 （裁定申請書）

## 
法[[laws/著作権等管理事業法施行規則/本文/第24条.md|第二十四条]]第一項の規定により裁定を申請しようとする者は、次に掲げる事項を記載した裁定申請書を提出しなければならない。名称又は氏名及び住所協議の相手方の名称又は氏名法[[laws/著作権等管理事業法施行規則/本文/第23条.md|第二十三条]]第四項の協議の開始又は再開が命ぜられた年月日裁定を受けようとする事項求める裁定の内容前号の裁定を求める理由裁定申請に至った経緯

- 一 名称又は氏名及び住所
- 二 協議の相手方の名称又は氏名
- 三 法[[laws/著作権等管理事業法施行規則/本文/第23条.md|第二十三条]]第四項の協議の開始又は再開が命ぜられた年月日
- 四 裁定を受けようとする事項
- 五 求める裁定の内容
- 六 前号の裁定を求める理由
- 七 裁定申請に至った経緯
## ２
[[laws/著作権等管理事業法施行規則/本文/第16条.md|第十六条]]第三項の規定は、前項の裁定申請書について準用する。この場合において、「指定著作権等管理事業者」とあるのは「相手方」と読み替えるものとする。
