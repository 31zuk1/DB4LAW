# 第二十八条 （定款）

## 
商工会の定款には、次の事項を記載しなければならない。目的名称事業地区事務所の所在地会員たる資格に関する事項会員の加入及び脱退に関する事項会員の権利及び義務に関する事項会費に関する事項役員に関する事項総会に関する事項経理に関する事項事業年度公告の方法

- 一 目的
- 二 名称
- 三 事業
- 四 地区
- 五 事務所の所在地
- 六 会員たる資格に関する事項
- 七 会員の加入及び脱退に関する事項
- 八 会員の権利及び義務に関する事項
- 九 会費に関する事項
- 十 役員に関する事項
- 十一 総会に関する事項
- 十二 経理に関する事項
- 十三 事業年度
- 十四 公告の方法
