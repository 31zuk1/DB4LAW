# 第二十三条 （個人番号の利用による預貯金口座の管理に関する広報啓発）

## 
国は、預金保険機構及び金融機関と協力して、個人番号の利用による預貯金口座の管理について国民一般の理解を高めるために必要な広報その他の啓発活動を行うものとする。
