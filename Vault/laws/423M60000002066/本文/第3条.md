# 第三条 （付記登録）

## 
次に掲げる登録は、付記登録によってするものとする。登録名義人の氏名若しくは名称又は住所についての変更の登録又は更正の登録次に掲げる登録その他の令[[laws/公共施設等運営権登録令施行規則/本文/第29条.md|第二十九条]]に規定する場合における権利部の登録事項についての変更の登録又は更正の登録債権の分割による抵当権の変更の登録民法（明治二十九年法律第八十九号）第三百九十八条の八第一項又は第二項の合意の登録民法[[laws/民法/本文/第398条の12.md|第三百九十八条の十二]]第二項に規定する根抵当権を分割して譲り渡す場合においてする極度額の減額による変更の登録民法[[laws/民法/本文/第398条の14.md|第三百九十八条の十四]]第一項ただし書の定めの登録登録事項の一部が抹消されている場合においてする抹消された登録の回復抵当権を目的とする権利に関する登録（処分の制限の登録を含む。）抵当権の移転の登録登録の目的である公共施設等運営権等の消滅に関する定めの登録民法[[laws/民法/本文/第393条.md|第三百九十三条]]の規定による代位の登録買戻しの特約の登録

- 一 登録名義人の氏名若しくは名称又は住所についての変更の登録又は更正の登録
- 二 次に掲げる登録その他の令[[laws/公共施設等運営権登録令施行規則/本文/第29条.md|第二十九条]]に規定する場合における権利部の登録事項についての変更の登録又は更正の登録
- 三 登録事項の一部が抹消されている場合においてする抹消された登録の回復
- 四 抵当権を目的とする権利に関する登録（処分の制限の登録を含む。）
- 五 抵当権の移転の登録
- 六 登録の目的である公共施設等運営権等の消滅に関する定めの登録
- 七 民法[[laws/民法/本文/第393条.md|第三百九十三条]]の規定による代位の登録
- 八 買戻しの特約の登録
