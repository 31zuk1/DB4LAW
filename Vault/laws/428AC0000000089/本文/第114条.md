# 第百十四条 

## 
次の各号のいずれかに該当する場合には、その違反行為をした機構の役員は、二十万円以下の過料に処する。第三章の規定により主務大臣の認可又は承認を受けなければならない場合において、その認可又は承認を受けなかったとき。[[laws/外国人の技能実習の適正な実施及び技能実習生の保護に関する法律/本文/第62条.md|第六十二条]]第一項の規定による政令に違反して登記することを怠ったとき。[[laws/外国人の技能実習の適正な実施及び技能実習生の保護に関する法律/本文/第87条.md|第八十七条]]に規定する業務以外の業務を行ったとき。[[laws/外国人の技能実習の適正な実施及び技能実習生の保護に関する法律/本文/第93条.md|第九十三条]]第三項の規定に違反して、書類を備え置かず、又は縦覧に供しなかったとき。[[laws/外国人の技能実習の適正な実施及び技能実習生の保護に関する法律/本文/第97条.md|第九十七条]]の規定に違反して業務上の余裕金を運用したとき。[[laws/外国人の技能実習の適正な実施及び技能実習生の保護に関する法律/本文/第99条.md|第九十九条]]第二項の規定による主務大臣の命令に違反したとき。

- 一 第三章の規定により主務大臣の認可又は承認を受けなければならない場合において、その認可又は承認を受けなかったとき。
- 二 [[laws/外国人の技能実習の適正な実施及び技能実習生の保護に関する法律/本文/第62条.md|第六十二条]]第一項の規定による政令に違反して登記することを怠ったとき。
- 三 [[laws/外国人の技能実習の適正な実施及び技能実習生の保護に関する法律/本文/第87条.md|第八十七条]]に規定する業務以外の業務を行ったとき。
- 四 [[laws/外国人の技能実習の適正な実施及び技能実習生の保護に関する法律/本文/第93条.md|第九十三条]]第三項の規定に違反して、書類を備え置かず、又は縦覧に供しなかったとき。
- 五 [[laws/外国人の技能実習の適正な実施及び技能実習生の保護に関する法律/本文/第97条.md|第九十七条]]の規定に違反して業務上の余裕金を運用したとき。
- 六 [[laws/外国人の技能実習の適正な実施及び技能実習生の保護に関する法律/本文/第99条.md|第九十九条]]第二項の規定による主務大臣の命令に違反したとき。
