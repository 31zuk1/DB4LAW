# 第三条 （指定の基準）

## 
厚生労働大臣は、法[[laws/428AC1000000012/本文/第10条.md|第十条]]第一項の指定の申請があった場合においては、その申請が次の各号のいずれにも適合していると認めるときでなければ、同項の指定をしてはならない。営利を目的とするものでないこと。法[[laws/428AC1000000012/本文/第11条.md|第十一条]]に規定する業務を行うことを当該法人の目的の一部としていること。法[[laws/428AC1000000012/本文/第11条.md|第十一条]]に規定する業務を特定の地域に偏ることなく行う能力を有すること。法[[laws/428AC1000000012/本文/第11条.md|第十一条]]に規定する業務を行うに当たっては、当該業務を行う地域の属する国又は当該地域の法令を遵守するものであり、かつ、当該地域において当該業務の円滑な実施に支障を及ぼすおそれがないものであること。法[[laws/428AC1000000012/本文/第11条.md|第十一条]]に規定する業務を適正かつ確実に行うために必要な経理的基礎を有すること。法[[laws/428AC1000000012/本文/第11条.md|第十一条]]に規定する業務の実施について利害関係を有しないこと。法[[laws/428AC1000000012/本文/第11条.md|第十一条]]に規定する業務以外の業務を行っているときは、その業務を行うことによって同条に規定する業務の運営が不公正になるおそれがないこと。役員の構成が法[[laws/428AC1000000012/本文/第11条.md|第十一条]]に規定する業務の公正な運営に支障を及ぼすおそれがないものであること。公平かつ適正な法[[laws/428AC1000000012/本文/第11条.md|第十一条]]に規定する業務を行うことができる手続を定めていること。

- 一 営利を目的とするものでないこと。
- 二 法[[laws/428AC1000000012/本文/第11条.md|第十一条]]に規定する業務を行うことを当該法人の目的の一部としていること。
- 三 法[[laws/428AC1000000012/本文/第11条.md|第十一条]]に規定する業務を特定の地域に偏ることなく行う能力を有すること。
- 四 法[[laws/428AC1000000012/本文/第11条.md|第十一条]]に規定する業務を行うに当たっては、当該業務を行う地域の属する国又は当該地域の法令を遵守するものであり、かつ、当該地域において当該業務の円滑な実施に支障を及ぼすおそれがないものであること。
- 五 法[[laws/428AC1000000012/本文/第11条.md|第十一条]]に規定する業務を適正かつ確実に行うために必要な経理的基礎を有すること。
- 六 法[[laws/428AC1000000012/本文/第11条.md|第十一条]]に規定する業務の実施について利害関係を有しないこと。
- 七 法[[laws/428AC1000000012/本文/第11条.md|第十一条]]に規定する業務以外の業務を行っているときは、その業務を行うことによって同条に規定する業務の運営が不公正になるおそれがないこと。
- 八 役員の構成が法[[laws/428AC1000000012/本文/第11条.md|第十一条]]に規定する業務の公正な運営に支障を及ぼすおそれがないものであること。
- 九 公平かつ適正な法[[laws/428AC1000000012/本文/第11条.md|第十一条]]に規定する業務を行うことができる手続を定めていること。
