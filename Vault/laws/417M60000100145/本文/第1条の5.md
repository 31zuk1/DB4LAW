# 第一条の五 （業務方法書の記載事項）

## 
機構に係る通則法[[laws/417M60000100145/独立行政法人地域医療機能推進機構の業務運_law.md|第二十八条]]第二項の主務省令で定める事項は、次のとおりとする。法[[laws/417M60000100145/本文/第13条.md|第十三条]]第一項第一号に規定する病院の設置及び運営に関する事項法[[laws/417M60000100145/本文/第13条.md|第十三条]]第一項第二号に規定する介護老人保健施設の設置及び運営に関する事項法[[laws/417M60000100145/本文/第13条.md|第十三条]]第一項第三号に規定する看護師養成施設の設置及び運営に関する事項法[[laws/417M60000100145/本文/第13条.md|第十三条]]第三項及び[[laws/417M60000100145/本文/第1条.md|第一条]]に規定する事業に係る業務の実施に関する事項業務委託の基準競争入札その他契約に関する基本的事項その他機構の業務の執行に関して必要な事項

- 一 法[[laws/417M60000100145/本文/第13条.md|第十三条]]第一項第一号に規定する病院の設置及び運営に関する事項
- 二 法[[laws/417M60000100145/本文/第13条.md|第十三条]]第一項第二号に規定する介護老人保健施設の設置及び運営に関する事項
- 三 法[[laws/417M60000100145/本文/第13条.md|第十三条]]第一項第三号に規定する看護師養成施設の設置及び運営に関する事項
- 四 法[[laws/417M60000100145/本文/第13条.md|第十三条]]第三項及び[[laws/417M60000100145/本文/第1条.md|第一条]]に規定する事業に係る業務の実施に関する事項
- 五 業務委託の基準
- 六 競争入札その他契約に関する基本的事項
- 七 その他機構の業務の執行に関して必要な事項
