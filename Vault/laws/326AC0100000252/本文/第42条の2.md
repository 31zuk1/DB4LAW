# 第四十二条の二 

## 
次の各号の一に該当する者は、二十万円以下の罰金に処する。[[laws/326AC0100000252/本文/第9条.md|第九条]]（業務の廃止等の届出）又は同条第二項に関する[[laws/326AC0100000252/本文/第36条.md|第三十六条]]第一項（国又は地方公共団体の開設する覚醒剤施用機関における届出等の義務者の変更）の規定に違反した者[[laws/326AC0100000252/本文/第18条.md|第十八条]]第三項（譲渡証及び譲受証並びに電磁的記録の保存）の規定に違反した者[[laws/326AC0100000252/本文/第28条.md|第二十八条]]第二項（帳簿の保存）の規定に違反した者[[laws/326AC0100000252/本文/第30条の4.md|第三十条の四]]（業務の廃止等の届出）の規定に違反した者[[laws/326AC0100000252/本文/第30条の10.md|第三十条の十]]第三項（譲渡証及び譲受証並びに電磁的記録の保存）の規定に違反した者[[laws/326AC0100000252/本文/第30条の17.md|第三十条の十七]]第四項（帳簿の保存）の規定に違反した者[[laws/326AC0100000252/本文/第31条.md|第三十一条]]（報告の徴収）の規定による報告をせず、又は虚偽の報告をした者[[laws/326AC0100000252/本文/第32条.md|第三十二条]]第一項又は第二項（立入検査、収去及び質問）の規定による立入検査若しくは収去を拒み、妨げ、若しくは忌避し、又は質問に対して答弁をせず、若しくは虚偽の陳述をした者

- 一 [[laws/326AC0100000252/本文/第9条.md|第九条]]（業務の廃止等の届出）又は同条第二項に関する[[laws/326AC0100000252/本文/第36条.md|第三十六条]]第一項（国又は地方公共団体の開設する覚醒剤施用機関における届出等の義務者の変更）の規定に違反した者
- 二 [[laws/326AC0100000252/本文/第18条.md|第十八条]]第三項（譲渡証及び譲受証並びに電磁的記録の保存）の規定に違反した者
- 三 [[laws/326AC0100000252/本文/第28条.md|第二十八条]]第二項（帳簿の保存）の規定に違反した者
- 四 [[laws/326AC0100000252/本文/第30条の4.md|第三十条の四]]（業務の廃止等の届出）の規定に違反した者
- 五 [[laws/326AC0100000252/本文/第30条の10.md|第三十条の十]]第三項（譲渡証及び譲受証並びに電磁的記録の保存）の規定に違反した者
- 六 [[laws/326AC0100000252/本文/第30条の17.md|第三十条の十七]]第四項（帳簿の保存）の規定に違反した者
- 七 [[laws/326AC0100000252/本文/第31条.md|第三十一条]]（報告の徴収）の規定による報告をせず、又は虚偽の報告をした者
- 八 [[laws/326AC0100000252/本文/第32条.md|第三十二条]]第一項又は第二項（立入検査、収去及び質問）の規定による立入検査若しくは収去を拒み、妨げ、若しくは忌避し、又は質問に対して答弁をせず、若しくは虚偽の陳述をした者
