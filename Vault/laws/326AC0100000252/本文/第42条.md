# 第四十二条 

## 
次の各号のいずれかに該当する者は、一年以下の拘禁刑若しくは二十万円以下の罰金に処し、又はこれを併科する。[[laws/326AC0100000252/本文/第5条.md|第五条]]第三項（指定証の譲渡及び貸与の禁止）の規定に違反した者[[laws/326AC0100000252/本文/第16条.md|第十六条]]（覚醒剤施用機関の管理者）の規定に違反した者[[laws/326AC0100000252/本文/第18条.md|第十八条]]第一項（譲渡証及び譲受証の交付）の規定に違反して譲渡証若しくは譲受証を交付せず、又はこれに虚偽の記載をし、若しくは同条第三項（譲渡証及び譲受証並びに電磁的記録の保存）に規定する電磁的記録に虚偽の記録をした者[[laws/326AC0100000252/本文/第18条.md|第十八条]]第四項（譲渡証及び譲受証並びに電磁的記録の譲渡の禁止）の規定に違反した者[[laws/326AC0100000252/本文/第21条.md|第二十一条]]第一項（証紙による封入）又は第二項（証紙による封を施さない覚醒剤の譲渡及び譲受の禁止）の規定に違反した者[[laws/326AC0100000252/本文/第22条.md|第二十二条]]（保管及び保管換）の規定に違反した者[[laws/326AC0100000252/本文/第22条の2.md|第二十二条の二]]（廃棄）の規定に違反した者[[laws/326AC0100000252/本文/第23条.md|第二十三条]]（事故の届出）の規定による届出をせず、又は虚偽の届出をした者[[laws/326AC0100000252/本文/第24条.md|第二十四条]]第一項（指定失効の際に所有していた覚醒剤の品名及び数量の報告）、第二項（指定失効の際に所有していた覚醒剤の譲渡及びその報告）若しくは第四項（死亡又は解散の場合における報告義務の転移）の規定又は同条第一項及び第二項に関する[[laws/326AC0100000252/本文/第36条.md|第三十六条]]第一項（国又は地方公共団体の開設する覚醒剤施用機関における届出等の義務者の変更）の規定による報告をせず、又は虚偽の報告をした者[[laws/326AC0100000252/本文/第24条.md|第二十四条]]第三項（指定失効の際に所有していた覚醒剤の処分）若しくは第四項（死亡若しくは解散の場合における譲渡及び処分義務の転移）の規定又は同条第三項に関する[[laws/326AC0100000252/本文/第36条.md|第三十六条]]第二項（国又は地方公共団体の開設する覚醒剤施用機関における処分の義務者の変更）の規定に違反した者[[laws/326AC0100000252/本文/第28条.md|第二十八条]]第一項（帳簿の備付け及び記入）の規定による帳簿の備付けをせず、又は帳簿の記入をせず、若しくは虚偽の記入をした者[[laws/326AC0100000252/本文/第29条.md|第二十九条]]（覚醒剤製造業者の報告）の規定による報告をせず、又は虚偽の報告をした者[[laws/326AC0100000252/本文/第30条.md|第三十条]]（覚醒剤施用機関の管理者及び覚醒剤研究者の報告）の規定による報告をせず、又は虚偽の報告をした者[[laws/326AC0100000252/本文/第30条の5.md|第三十条の五]]（指定及び届出に関する準用規定）において準用する[[laws/326AC0100000252/本文/第5条.md|第五条]]第三項の規定に違反した者[[laws/326AC0100000252/本文/第30条の6.md|第三十条の六]]の二（輸出の際の表示）の規定に違反した者[[laws/326AC0100000252/本文/第30条の9.md|第三十条の九]]第二項（覚醒剤原料の廃棄）の規定に違反した者[[laws/326AC0100000252/本文/第30条の10.md|第三十条の十]]第一項（譲渡証及び譲受証の交付）の規定に違反して譲渡証若しくは譲受証を交付せず、又はこれに虚偽の記載をし、若しくは同条第三項（譲渡証及び譲受証並びに電磁的記録の保存）に規定する電磁的記録に虚偽の記録をした者[[laws/326AC0100000252/本文/第30条の12.md|第三十条の十二]]（保管）の規定に違反した者[[laws/326AC0100000252/本文/第30条の13.md|第三十条の十三]]（廃棄）の規定に違反した者[[laws/326AC0100000252/本文/第30条の14.md|第三十条の十四]]第一項から第三項まで（事故等の届出）の規定による届出をせず、又は虚偽の届出をした者[[laws/326AC0100000252/本文/第30条の15.md|第三十条の十五]]第一項（指定失効等の際に所有し又は所持していた覚醒剤原料の品名及び数量の報告）若しくは第二項（指定失効等の際に所有し又は所持していた覚醒剤原料の譲渡及びその報告）又は同条第四項において準用する[[laws/326AC0100000252/本文/第24条.md|第二十四条]]第四項（死亡又は解散の場合における報告義務の転移）の規定による報告をせず、又は虚偽の報告をした者[[laws/326AC0100000252/本文/第30条の15.md|第三十条の十五]]第三項（指定失効等の際に所有し又は所持していた覚醒剤原料の廃棄その他の処分）の規定又は同条第四項において準用する[[laws/326AC0100000252/本文/第24条.md|第二十四条]]第四項（死亡又は解散の場合における処分義務の転移）の規定に違反した者[[laws/326AC0100000252/本文/第30条の17.md|第三十条の十七]]第一項から第三項まで（帳簿の備付け及び記入）の規定による帳簿の備付けをせず、又は帳簿の記入をせず、若しくは虚偽の記入をした者

- 一 [[laws/326AC0100000252/本文/第5条.md|第五条]]第三項（指定証の譲渡及び貸与の禁止）の規定に違反した者
- 二 [[laws/326AC0100000252/本文/第16条.md|第十六条]]（覚醒剤施用機関の管理者）の規定に違反した者
- 三 [[laws/326AC0100000252/本文/第18条.md|第十八条]]第一項（譲渡証及び譲受証の交付）の規定に違反して譲渡証若しくは譲受証を交付せず、又はこれに虚偽の記載をし、若しくは同条第三項（譲渡証及び譲受証並びに電磁的記録の保存）に規定する電磁的記録に虚偽の記録をした者
- 四 [[laws/326AC0100000252/本文/第18条.md|第十八条]]第四項（譲渡証及び譲受証並びに電磁的記録の譲渡の禁止）の規定に違反した者
- 五 [[laws/326AC0100000252/本文/第21条.md|第二十一条]]第一項（証紙による封入）又は第二項（証紙による封を施さない覚醒剤の譲渡及び譲受の禁止）の規定に違反した者
- 六 [[laws/326AC0100000252/本文/第22条.md|第二十二条]]（保管及び保管換）の規定に違反した者
- 七 [[laws/326AC0100000252/本文/第22条の2.md|第二十二条の二]]（廃棄）の規定に違反した者
- 八 [[laws/326AC0100000252/本文/第23条.md|第二十三条]]（事故の届出）の規定による届出をせず、又は虚偽の届出をした者
- 九 [[laws/326AC0100000252/本文/第24条.md|第二十四条]]第一項（指定失効の際に所有していた覚醒剤の品名及び数量の報告）、第二項（指定失効の際に所有していた覚醒剤の譲渡及びその報告）若しくは第四項（死亡又は解散の場合における報告義務の転移）の規定又は同条第一項及び第二項に関する[[laws/326AC0100000252/本文/第36条.md|第三十六条]]第一項（国又は地方公共団体の開設する覚醒剤施用機関における届出等の義務者の変更）の規定による報告をせず、又は虚偽の報告をした者
- 十 [[laws/326AC0100000252/本文/第24条.md|第二十四条]]第三項（指定失効の際に所有していた覚醒剤の処分）若しくは第四項（死亡若しくは解散の場合における譲渡及び処分義務の転移）の規定又は同条第三項に関する[[laws/326AC0100000252/本文/第36条.md|第三十六条]]第二項（国又は地方公共団体の開設する覚醒剤施用機関における処分の義務者の変更）の規定に違反した者
- 十一 [[laws/326AC0100000252/本文/第28条.md|第二十八条]]第一項（帳簿の備付け及び記入）の規定による帳簿の備付けをせず、又は帳簿の記入をせず、若しくは虚偽の記入をした者
- 十二 [[laws/326AC0100000252/本文/第29条.md|第二十九条]]（覚醒剤製造業者の報告）の規定による報告をせず、又は虚偽の報告をした者
- 十三 [[laws/326AC0100000252/本文/第30条.md|第三十条]]（覚醒剤施用機関の管理者及び覚醒剤研究者の報告）の規定による報告をせず、又は虚偽の報告をした者
- 十四 [[laws/326AC0100000252/本文/第30条の5.md|第三十条の五]]（指定及び届出に関する準用規定）において準用する[[laws/326AC0100000252/本文/第5条.md|第五条]]第三項の規定に違反した者

- 十六 [[laws/326AC0100000252/本文/第30条の9.md|第三十条の九]]第二項（覚醒剤原料の廃棄）の規定に違反した者
- 十七 [[laws/326AC0100000252/本文/第30条の10.md|第三十条の十]]第一項（譲渡証及び譲受証の交付）の規定に違反して譲渡証若しくは譲受証を交付せず、又はこれに虚偽の記載をし、若しくは同条第三項（譲渡証及び譲受証並びに電磁的記録の保存）に規定する電磁的記録に虚偽の記録をした者
- 十八 [[laws/326AC0100000252/本文/第30条の12.md|第三十条の十二]]（保管）の規定に違反した者
- 十九 [[laws/326AC0100000252/本文/第30条の13.md|第三十条の十三]]（廃棄）の規定に違反した者

- 二十一 [[laws/326AC0100000252/本文/第30条の15.md|第三十条の十五]]第一項（指定失効等の際に所有し又は所持していた覚醒剤原料の品名及び数量の報告）若しくは第二項（指定失効等の際に所有し又は所持していた覚醒剤原料の譲渡及びその報告）又は同条第四項において準用する[[laws/326AC0100000252/本文/第24条.md|第二十四条]]第四項（死亡又は解散の場合における報告義務の転移）の規定による報告をせず、又は虚偽の報告をした者
- 二十二 [[laws/326AC0100000252/本文/第30条の15.md|第三十条の十五]]第三項（指定失効等の際に所有し又は所持していた覚醒剤原料の廃棄その他の処分）の規定又は同条第四項において準用する[[laws/326AC0100000252/本文/第24条.md|第二十四条]]第四項（死亡又は解散の場合における処分義務の転移）の規定に違反した者
- 二十三 [[laws/326AC0100000252/本文/第30条の17.md|第三十条の十七]]第一項から第三項まで（帳簿の備付け及び記入）の規定による帳簿の備付けをせず、又は帳簿の記入をせず、若しくは虚偽の記入をした者
