# 第七十二条の三 

## 
組合の清算については、会社法[[laws/会社法/本文/第475条.md|第四百七十五条]]（第三号に係る部分を除く。）、[[laws/会社法/本文/第476条.md|第四百七十六条]]及び[[laws/会社法/本文/第499条.md|第四百九十九条]]から[[laws/会社法/本文/第503条.md|第五百三条]]までの規定を、組合の清算人については、[[laws/農業協同組合法/本文/第27条.md|第二十七条]]、[[laws/会社法/本文/第29条の2.md|第二十九条の二]]、[[laws/会社法/本文/第30条の3.md|第三十条の三]]、[[laws/会社法/本文/第30条の4.md|第三十条の四]]、[[laws/会社法/本文/第30条の5.md|第三十条の五]]第二項及び第三項、[[laws/会社法/本文/第32条.md|第三十二条]]、[[laws/会社法/本文/第33条.md|第三十三条]]、[[laws/会社法/本文/第34条.md|第三十四条]]第五項及び第六項、[[laws/会社法/本文/第35条.md|第三十五条]]（第二項を除く。）、[[laws/会社法/本文/第35条の2.md|第三十五条の二]]、[[laws/会社法/本文/第35条の3.md|第三十五条の三]]第二項及び第三項、[[laws/会社法/本文/第35条の4.md|第三十五条の四]]、[[laws/会社法/本文/第35条の5.md|第三十五条の五]]第一項から第三項まで、[[laws/会社法/本文/第35条の6.md|第三十五条の六]]第一項から第三項まで、第八項、第九項（第一号に係る部分に限る。）及び第十項、[[laws/会社法/本文/第36条.md|第三十六条]]（第一項及び第十項を除く。）、[[laws/会社法/本文/第39条.md|第三十九条]]第一項、[[laws/会社法/本文/第43条の3.md|第四十三条の三]]第二項から第四項まで、[[laws/会社法/本文/第43条の4.md|第四十三条の四]]、[[laws/農業協同組合法/本文/第43条の5.md|第四十三条の五]]第二項、[[laws/農業協同組合法/本文/第46条の2.md|第四十六条の二]]並びに[[laws/農業協同組合法/本文/第46条の4.md|第四十六条の四]]第二項から第四項まで並びに同法第三百八十三条第一項本文、第二項及び第三項、[[laws/会社法/本文/第384条.md|第三百八十四条]]、[[laws/会社法/本文/第385条.md|第三百八十五条]]、[[laws/会社法/本文/第386条.md|第三百八十六条]]第一項（第一号に係る部分に限る。）及び第二項（第一号及び第二号に係る部分に限る。）、[[laws/農業協同組合法/本文/第478条.md|第四百七十八条]]第二項及び第四項、[[laws/農業協同組合法/本文/第479条.md|第四百七十九条]]第一項及び第二項（各号列記以外の部分に限る。）、[[laws/農業協同組合法/本文/第483条.md|第四百八十三条]]第四項及び第五項、[[laws/農業協同組合法/本文/第484条.md|第四百八十四条]]、[[laws/農業協同組合法/本文/第485条.md|第四百八十五条]]、[[laws/農業協同組合法/本文/第489条.md|第四百八十九条]]第三項から第五項まで、[[laws/農業協同組合法/本文/第508条.md|第五百八条]]、第七編第二章第二節（[[laws/農業協同組合法/本文/第847条.md|第八百四十七条]]第二項、[[laws/農業協同組合法/本文/第847条の2.md|第八百四十七条の二]]、[[laws/農業協同組合法/本文/第847条の3.md|第八百四十七条の三]]、[[laws/農業協同組合法/本文/第849条.md|第八百四十九条]]第二項、第三項第二号及び第三号並びに第六項から第十一項まで、[[laws/農業協同組合法/本文/第849条の2.md|第八百四十九条の二]]第二号及び第三号、[[laws/農業協同組合法/本文/第851条.md|第八百五十一条]]並びに[[laws/農業協同組合法/本文/第853条.md|第八百五十三条]]第一項第二号及び第三号を除く。）、[[laws/農業協同組合法/本文/第868条.md|第八百六十八条]]第一項、[[laws/農業協同組合法/本文/第869条.md|第八百六十九条]]、[[laws/農業協同組合法/本文/第870条.md|第八百七十条]]第一項（第一号及び第二号に係る部分に限る。）、[[laws/農業協同組合法/本文/第871条.md|第八百七十一条]]、[[laws/農業協同組合法/本文/
