# 第九十八条の三 

## 
内閣総理大臣は、[[laws/農業協同組合法/本文/第10条.md|第十条]]第一項第三号の事業を行う組合に対し次に掲げる処分をしたときは、速やかに、その旨を財務大臣に通知するものとする。[[laws/農業協同組合法/本文/第97条.md|第九十七条]]の規定による届出（同条第十二号に係るもののうち、農林水産省令・内閣府令・財務省令で定めるものに限る。）があつたときも、同様とする。[[laws/農業協同組合法/本文/第11条.md|第十一条]]第一項又は第三項（同項の規定にあつては、信用事業規程の廃止に係る場合に限る。）の規定による承認[[laws/農業協同組合法/本文/第60条.md|第六十条]]の規定による設立の認可[[laws/農業協同組合法/本文/第64条.md|第六十四条]]第二項又は[[laws/農業協同組合法/本文/第65条.md|第六十五条]]第二項（[[laws/農業協同組合法/本文/第70条.md|第七十条]]第二項において準用する場合を含む。）の規定による認可[[laws/農業協同組合法/本文/第64条.md|第六十四条]]第七項第二号に規定する不認可の処分[[laws/農業協同組合法/本文/第94条の2.md|第九十四条の二]]第一項若しくは第二項又は[[laws/農業協同組合法/本文/第95条.md|第九十五条]]第一項若しくは第二項の規定による命令（改善計画の提出を求めることを含み、信用事業に関するものに限る。）[[laws/農業協同組合法/本文/第95条.md|第九十五条]]第三項の規定による[[laws/農業協同組合法/本文/第11条.md|第十一条]]第一項の承認の取消し[[laws/農業協同組合法/本文/第95条の2.md|第九十五条の二]]の規定による解散の命令

- 一 [[laws/農業協同組合法/本文/第11条.md|第十一条]]第一項又は第三項（同項の規定にあつては、信用事業規程の廃止に係る場合に限る。）の規定による承認
- 二 [[laws/農業協同組合法/本文/第60条.md|第六十条]]の規定による設立の認可
- 三 [[laws/農業協同組合法/本文/第64条.md|第六十四条]]第二項又は[[laws/農業協同組合法/本文/第65条.md|第六十五条]]第二項（[[laws/農業協同組合法/本文/第70条.md|第七十条]]第二項において準用する場合を含む。）の規定による認可
- 四 [[laws/農業協同組合法/本文/第64条.md|第六十四条]]第七項第二号に規定する不認可の処分
- 五 [[laws/農業協同組合法/本文/第94条の2.md|第九十四条の二]]第一項若しくは第二項又は[[laws/農業協同組合法/本文/第95条.md|第九十五条]]第一項若しくは第二項の規定による命令（改善計画の提出を求めることを含み、信用事業に関するものに限る。）
- 六 [[laws/農業協同組合法/本文/第95条.md|第九十五条]]第三項の規定による[[laws/農業協同組合法/本文/第11条.md|第十一条]]第一項の承認の取消し
- 七 [[laws/農業協同組合法/本文/第95条の2.md|第九十五条の二]]の規定による解散の命令
