# 第五十一条の二の三 （救急業務に関する基礎的な講習の課程を修了した者と同等以上の学識経験を有する者）

## 
令[[laws/消防法施行規則/本文/第44条.md|第四十四条]]第六項第二号の総務省令で定める者は、次の各号に掲げる者とする。医師保健師看護師准看護師救急救命士[[laws/消防法施行規則/本文/第51条.md|第五十一条]]に規定する講習の課程を修了した者

- 一 医師
- 二 保健師
- 三 看護師
- 四 准看護師
- 五 救急救命士
- 六 [[laws/消防法施行規則/本文/第51条.md|第五十一条]]に規定する講習の課程を修了した者
