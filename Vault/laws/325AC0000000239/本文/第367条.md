# 第三百六十七条 

## 
次の各号のいずれかに該当する者は、六月以下の拘禁刑若しくは五十万円以下の罰金に処し、又はこれを併科する。[[laws/商品先物取引法/本文/第4条.md|第四条]]第二項、[[laws/商品先物取引法/本文/第55条.md|第五十五条]]（[[laws/商品先物取引法/本文/第77条.md|第七十七条]]第二項において準用する場合を含む。）、[[laws/商品先物取引法/本文/第91条.md|第九十一条]]第一項（同条第二項において準用する場合を含む。）、[[laws/商品先物取引法/本文/第105条.md|第百五条]]、[[laws/商品先物取引法/本文/第106条.md|第百六条]]又は[[laws/商品先物取引法/本文/第272条.md|第二百七十二条]]第二項の規定に違反した者[[laws/商品先物取引法/本文/第86条.md|第八十六条]]第三項、[[laws/商品先物取引法/本文/第96条の19.md|第九十六条の十九]]第三項（[[laws/商品先物取引法/本文/第96条の25.md|第九十六条の二十五]]第四項又は[[laws/商品先物取引法/本文/第96条の31.md|第九十六条の三十一]]第四項において準用する場合を含む。）若しくは[[laws/商品先物取引法/本文/第96条の28.md|第九十六条の二十八]]第三項の規定による届出をせず、又は虚偽の届出をした者[[laws/商品先物取引法/本文/第86条の2.md|第八十六条の二]]第一項若しくは[[laws/商品先物取引法/本文/第96条の29.md|第九十六条の二十九]]の規定による対象議決権保有届出書を提出せず、又は虚偽の記載をした対象議決権保有届出書を提出した者[[laws/商品先物取引法/本文/第200条.md|第二百条]]第三項若しくは第四項（[[laws/商品先物取引法/本文/第240条の11.md|第二百四十条の十一]]においてこれらの規定を準用する場合を含む。）又は[[laws/商品先物取引法/本文/第335条.md|第三百三十五条]]第二項（[[laws/商品先物取引法/本文/第345条.md|第三百四十五条]]において準用する場合を含む。）の規定による申請書又は添付書類に虚偽の記載をして提出した者[[laws/商品先物取引法/本文/第213条の2.md|第二百十三条の二]]第一項若しくは[[laws/商品先物取引法/本文/第240条の13.md|第二百四十条の十三]]第一項に規定する事項を表示せず、又は虚偽の表示をした者[[laws/商品先物取引法/本文/第213条の2.md|第二百十三条の二]]第二項又は[[laws/商品先物取引法/本文/第240条の13.md|第二百四十条の十三]]第二項の規定に違反した者[[laws/商品先物取引法/本文/第217条.md|第二百十七条]]第一項の規定に違反して、書面を交付せず、若しくは同項に規定する事項を記載しない書面若しくは虚偽の記載をした書面を交付した者又は同条第二項に規定する方法により当該事項を欠いた提供若しくは虚偽の事項の提供をした者[[laws/商品先物取引法/本文/第220条.md|第二百二十条]]第一項の規定に違反して、通知せず、若しくは同項に規定する事項を記載しない書面若しくは虚偽の記載をした書面により通知した者又は同条第二項において読み替えて準用する[[laws/商品先物取引法/本文/第217条.md|第二百十七条]]第二項に規定する方法により当該事項を欠いた通知若しくは虚偽の事項の通知をした者[[laws/商品先物取引法/本文/第220条の2.md|第二百二十条の二]]第一項の規定に違反して、書面を交付せず、若しくは同項に規定する事項を記載しない書面若しくは虚偽の記載をした書面を交付した者又は同条第二項において準用する[[laws/商品先物取引法/本文/第217条.md|第二百十七条]]第二項に規定する方法により当該事項を欠いた提供若しくは虚偽の事項の提供をした者[[laws/商品先物取引法/本文/第244条.md|第二百四十四条]]第一項の規定に違反して、その名称中に商品先物取引協会であると誤認されるおそれのある文字を用いた者

- 一 [[laws/商品先物取引法/本文/第4条.md|第四条]]第二項、[[laws/商品先物取引法/本文/第55条.md|第五十五条]]（[[laws/商品先物取引法/本文/第77条.md|第七十七条]]第二項において準用する場合を含む。）、[[laws/商品先物取引法/本文/第91条.md|第九十一条]]第一項（同条第二項において準用する場合を含む。）、[[laws/商品先物取引法/本文/第105条.md|第百五条]]、[[laws/商品先物取引法/本文/第106条.md|第百六条]]又は[[laws/商品先物取引法/本文/第272条.md|第二百七十二条]]第二項の規定に違反した者
- 二 [[laws/商品先物取引法/本文/第86条.md|第八十六条]]第三項、[[laws/商品先物取引法/本文/第96条の19.md|第九十六条の十九]]第三項（[[laws/商品先物取引法/本文/第96条の25.md|第九十六条の二十五]]第四項又は[[laws/商品先物取引法/本文/第96条の31.md|第九十六条の三十一]]第四項において準用する場合を含む。）若しくは[[laws/商品先物取引法/本文/第96条の28.md|第九十六条の二十八]]第三項の規定による届出をせず、又は虚偽の届出をした者
- 三 [[laws/商品先物取引法/本文/第86条の2.md|第八十六条の二]]第一項若しくは[[laws/商品先物取引法/本文/第96条の29.md|第九十六条の二十九]]の規定による対象議決権保有届出書を提出せず、又は虚偽の記載をした対象議決権保有届出書を提出した者
- 四 [[laws/商品先物取引法/本文/第200条.md|第二百条]]第三項若しくは第四項（[[laws/商品先物取引法/本文/第240条の11.md|第二百四十条の十一]]においてこれらの規定を準用する場合を含む。）又は[[laws/商品先物取引法/本文/第335条.md|第三百三十五条]]第二項（[[laws/商品先物取引法/本文/第345条.md|第三百四十五条]]において準用する場合を含む。）の規定による申請書又は添付書類に虚偽の記載をして提出した者
- 五 [[laws/商品先物取引法/本文/第213条の2.md|第二百十三条の二]]第一項若しくは[[laws/商品先物取引法/本文/第240条の13.md|第二百四十条の十三]]第一項に規定する事項を表示せず、又は虚偽の表示をした者
- 六 [[laws/商品先物取引法/本文/第213条の2.md|第二百十三条の二]]第二項又は[[laws/商品先物取引法/本文/第240条の13.md|第二百四十条の十三]]第二項の規定に違反した者
- 七 [[laws/商品先物取引法/本文/第217条.md|第二百十七条]]第一項の規定に違反して、書面を交付せず、若しくは同項に規定する事項を記載しない書面若しくは虚偽の記載をした書面を交付した者又は同条第二項に規定する方法により当該事項を欠いた提供若しくは虚偽の事項の提供をした者
- 八 [[laws/商品先物取引法/本文/第220条.md|第二百二十条]]第一項の規定に違反して、通知せず、若しくは同項に規定する事項を記載しない書面若しくは虚偽の記載をした書面により通知した者又は同条第二項において読み替えて準用する[[laws/商品先物取引法/本文/第217条.md|第二百十七条]]第二項に規定する方法により当該事項を欠いた通知若しくは虚偽の事項の通知をした者
- 九 [[laws/商品先物取引法/本文/第220条の2.md|第二百二十条の二]]第一項の規定に違反して、書面を交付せず、若しくは同項に規定する事項を記載しない書面若しくは虚偽の記載をした書面を交付した者又は同条第二項において準用する[[laws/商品先物取引法/本文/第217条.md|第二百十七条]]第二項に規定する方法により当該事項を欠いた提供若しくは虚偽の事項の提供をした者
- 十 [[laws/商品先物取引法/本文/第244条.md|第二百四十四条]]第一項の規定に違反して、その名称中に商品先物取引協会であると誤認されるおそれのある文字を用いた者
