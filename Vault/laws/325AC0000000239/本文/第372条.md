# 第三百七十二条 

## 
次の各号に掲げる違反があつた場合においては、その行為をした商品取引所の役員（仮理事並びに仮取締役及び仮執行役を含む。）又は清算人は、百万円以下の過料に処する。[[laws/商品先物取引法/本文/第77条.md|第七十七条]]第一項において準用する会社法[[laws/会社法/本文/第484条.md|第四百八十四条]]第一項の規定に違反して、破産手続開始の申立てをすることを怠つたとき。清算の結了を遅延させる目的をもつて[[laws/商品先物取引法/本文/第77条.md|第七十七条]]第一項において準用する会社法[[laws/会社法/本文/第499条.md|第四百九十九条]]第一項の期間を不当に定めたとき。[[laws/商品先物取引法/本文/第77条.md|第七十七条]]第一項において準用する会社法[[laws/会社法/本文/第500条.md|第五百条]]第一項の規定に違反して、債務を弁済したとき。[[laws/商品先物取引法/本文/第96条の3.md|第九十六条の三]]第一項の規定に違反して、自主規制委員の過半数を社外取締役に選定しなかつたとき。[[laws/商品先物取引法/本文/第96条の14.md|第九十六条の十四]]第一項の規定に違反して、議事録を備え置かなかつたとき。[[laws/商品先物取引法/本文/第96条の16.md|第九十六条の十六]]の規定による名簿を公衆の縦覧に供することを怠つたとき。[[laws/商品先物取引法/本文/第130条.md|第百三十条]]第一項又は第四項の規定による通知をすることを怠り、又は不正の通知をしたとき。[[laws/商品先物取引法/本文/第134条.md|第百三十四条]]第一項の規定による登記をすることを怠つたとき。

- 一 [[laws/商品先物取引法/本文/第77条.md|第七十七条]]第一項において準用する会社法[[laws/会社法/本文/第484条.md|第四百八十四条]]第一項の規定に違反して、破産手続開始の申立てをすることを怠つたとき。
- 二 清算の結了を遅延させる目的をもつて[[laws/商品先物取引法/本文/第77条.md|第七十七条]]第一項において準用する会社法[[laws/会社法/本文/第499条.md|第四百九十九条]]第一項の期間を不当に定めたとき。
- 三 [[laws/商品先物取引法/本文/第77条.md|第七十七条]]第一項において準用する会社法[[laws/会社法/本文/第500条.md|第五百条]]第一項の規定に違反して、債務を弁済したとき。
- 四 [[laws/商品先物取引法/本文/第96条の3.md|第九十六条の三]]第一項の規定に違反して、自主規制委員の過半数を社外取締役に選定しなかつたとき。
- 五 [[laws/商品先物取引法/本文/第96条の14.md|第九十六条の十四]]第一項の規定に違反して、議事録を備え置かなかつたとき。
- 六 [[laws/商品先物取引法/本文/第96条の16.md|第九十六条の十六]]の規定による名簿を公衆の縦覧に供することを怠つたとき。
- 七 [[laws/商品先物取引法/本文/第130条.md|第百三十条]]第一項又は第四項の規定による通知をすることを怠り、又は不正の通知をしたとき。
- 八 [[laws/商品先物取引法/本文/第134条.md|第百三十四条]]第一項の規定による登記をすることを怠つたとき。
