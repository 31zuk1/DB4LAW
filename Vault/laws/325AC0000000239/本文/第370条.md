# 第三百七十条 

## 
次の各号に掲げる違反があつた場合においては、その行為をした商品取引所、商品取引清算機関、協会又は委託者保護基金の代表者、代理人、使用人その他の従業者は、三十万円以下の罰金に処する。[[laws/商品先物取引法/本文/第19条.md|第十九条]]第一項若しくは[[laws/商品先物取引法/本文/第85条.md|第八十五条]]第一項の規定による届出書を提出せず、若しくは虚偽の記載をした届出書を提出し、又は[[laws/商品先物取引法/本文/第19条.md|第十九条]]第二項若しくは[[laws/商品先物取引法/本文/第85条.md|第八十五条]]第二項の規定による添付書類を提出せず、若しくは添付書類に虚偽の記載をして提出したとき。[[laws/商品先物取引法/本文/第70条.md|第七十条]]又は[[laws/商品先物取引法/本文/第95条.md|第九十五条]]の規定に違反したとき。[[laws/商品先物取引法/本文/第88条.md|第八十八条]]第一項又は[[laws/商品先物取引法/本文/第206条.md|第二百六条]]第三項（[[laws/商品先物取引法/本文/第240条の11.md|第二百四十条の十一]]において準用する場合を含む。）の規定に違反したとき。[[laws/商品先物取引法/本文/第170条.md|第百七十条]]第三項又は[[laws/商品先物取引法/本文/第250条.md|第二百五十条]]第三項前段の規定による届出をせず、又は虚偽の届出をしたとき。[[laws/商品先物取引法/本文/第171条.md|第百七十一条]]の規定による届出をせず、若しくは虚偽の届出をし、又は同条の規定による書類を添付せず、若しくは虚偽の記載をした書類を添付したとき。[[laws/商品先物取引法/本文/第250条.md|第二百五十条]]第二項の規定による申請書又は添付書類に虚偽の記載をして提出したとき。[[laws/商品先物取引法/本文/第305条.md|第三百五条]]第四項又は[[laws/商品先物取引法/本文/第308条.md|第三百八条]]第五項の規定に違反して報告をせず、又は虚偽の報告をしたとき。

- 一 [[laws/商品先物取引法/本文/第19条.md|第十九条]]第一項若しくは[[laws/商品先物取引法/本文/第85条.md|第八十五条]]第一項の規定による届出書を提出せず、若しくは虚偽の記載をした届出書を提出し、又は[[laws/商品先物取引法/本文/第19条.md|第十九条]]第二項若しくは[[laws/商品先物取引法/本文/第85条.md|第八十五条]]第二項の規定による添付書類を提出せず、若しくは添付書類に虚偽の記載をして提出したとき。
- 二 [[laws/商品先物取引法/本文/第70条.md|第七十条]]又は[[laws/商品先物取引法/本文/第95条.md|第九十五条]]の規定に違反したとき。
- 三 [[laws/商品先物取引法/本文/第88条.md|第八十八条]]第一項又は[[laws/商品先物取引法/本文/第206条.md|第二百六条]]第三項（[[laws/商品先物取引法/本文/第240条の11.md|第二百四十条の十一]]において準用する場合を含む。）の規定に違反したとき。
- 四 [[laws/商品先物取引法/本文/第170条.md|第百七十条]]第三項又は[[laws/商品先物取引法/本文/第250条.md|第二百五十条]]第三項前段の規定による届出をせず、又は虚偽の届出をしたとき。
- 五 [[laws/商品先物取引法/本文/第171条.md|第百七十一条]]の規定による届出をせず、若しくは虚偽の届出をし、又は同条の規定による書類を添付せず、若しくは虚偽の記載をした書類を添付したとき。
- 六 [[laws/商品先物取引法/本文/第250条.md|第二百五十条]]第二項の規定による申請書又は添付書類に虚偽の記載をして提出したとき。
- 七 [[laws/商品先物取引法/本文/第305条.md|第三百五条]]第四項又は[[laws/商品先物取引法/本文/第308条.md|第三百八条]]第五項の規定に違反して報告をせず、又は虚偽の報告をしたとき。
