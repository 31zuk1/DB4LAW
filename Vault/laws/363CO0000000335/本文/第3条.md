# 第三条 （法第十三条第一号の政令で定める労働に関する法律の規定）

## 
法[[laws/港湾労働法施行令/本文/第13条.md|第十三条]]第一号（法[[laws/港湾労働法施行令/本文/第17条.md|第十七条]]第五項及び[[laws/港湾労働法施行令/本文/第18条.md|第十八条]]第二項において準用する場合を含む。）の労働に関する法律の規定であつて政令で定めるものは、次のとおりとする。労働基準法（昭和二十二年法律第四十九号）第百十七条、[[laws/港湾労働法施行令/本文/第118条.md|第百十八条]]第一項（同法第六条及び[[laws/港湾労働法施行令/本文/第56条.md|第五十六条]]に係る部分に限る。）、[[laws/港湾労働法施行令/本文/第119条.md|第百十九条]]（同法第十六条、[[laws/港湾労働法施行令/本文/第17条.md|第十七条]]、[[laws/港湾労働法施行令/本文/第18条.md|第十八条]]第一項及び[[laws/港湾労働法施行令/本文/第37条.md|第三十七条]]に係る部分に限る。）及び[[laws/港湾労働法施行令/本文/第120条.md|第百二十条]]（同法第十八条第七項及び[[laws/港湾労働法施行令/本文/第23条.md|第二十三条]]から[[laws/港湾労働法施行令/本文/第27条.md|第二十七条]]までに係る部分に限る。）の規定並びにこれらの規定に係る同法第百二十一条の規定（これらの規定が労働者派遣事業の適正な運営の確保及び派遣労働者の保護等に関する法律（昭和六十年法律第八十八号。第十号において「労働者派遣法」という。）[[laws/港湾労働法施行令/本文/第44条.md|第四十四条]]（第四項を除く。）の規定により適用される場合を含む。）職業安定法（昭和二十二年法律第百四十一号）第六十三条、[[laws/港湾労働法施行令/本文/第64条.md|第六十四条]]、[[laws/港湾労働法施行令/本文/第65条.md|第六十五条]]（第一号を除く。）及び[[laws/港湾労働法施行令/本文/第66条.md|第六十六条]]の規定並びにこれらの規定に係る同法第六十七条の規定最低賃金法（昭和三十四年法律第百三十七号）第四十条の規定及び同条の規定に係る同法第四十二条の規定建設労働者の雇用の改善等に関する法律（昭和五十一年法律第三十三号）[[laws/港湾労働法施行令/本文/第49条.md|第四十九条]]、[[laws/港湾労働法施行令/本文/第50条.md|第五十条]]及び[[laws/港湾労働法施行令/本文/第51条.md|第五十一条]]（第二号及び第三号を除く。）の規定並びにこれらの規定に係る同法第五十二条の規定賃金の支払の確保等に関する法律（昭和五十一年法律第三十四号）[[laws/港湾労働法施行令/本文/第18条.md|第十八条]]の規定及び同条の規定に係る同法第二十条の規定中小企業における労働力の確保及び良好な雇用の機会の創出のための雇用管理の改善の促進に関する法律（平成三年法律第五十七号）[[laws/港湾労働法施行令/本文/第19条.md|第十九条]]、[[laws/港湾労働法施行令/本文/第20条.md|第二十条]]及び[[laws/港湾労働法施行令/本文/第21条.md|第二十一条]]（第三号を除く。）の規定並びにこれらの規定に係る同法第二十二条の規定育児休業、介護休業等育児又は家族介護を行う労働者の福祉に関する法律（平成三年法律第七十六号）[[laws/港湾労働法施行令/本文/第62条.md|第六十二条]]から[[laws/港湾労働法施行令/本文/第65条.md|第六十五条]]までの規定林業労働力の確保の促進に関する法律（平成八年法律第四十五号）[[laws/港湾労働法施行令/本文/第32条.md|第三十二条]]、[[laws/港湾労働法施行令/本文/第33条.md|第三十三条]]及び[[laws/港湾労働法施行令/本文/第34条.md|第三十四条]]（第三号を除く。）の規定並びにこれらの規定に係る同法第三十五条の規定外国人の技能実習の適正な実施及び技能実習生の保護に関する法律（平成二十八年法律第八十九号）[[laws/港湾労働法施行令/本文/第108条.md|第百八条]]、[[laws/港湾労働法施行令/本文/第109条.md|第百九条]]、[[laws/港湾労働法施行令/本文/第110条.md|第百十条]]（同法第四十四条に係る部分に限る。）、[[laws/港湾労働法施行令/本文/第111条.md|第百十一条]]（第一号を除く。）及び[[laws/港湾労働法施行令/本文/第112条.md|第百十二条]]（第一号（同法第三十五条第一項に係る部分に限る。）及び第六号から第十一号までに係る部分に限る。）の規定並びにこれらの規定に係る同法第百十三条の規定労働者派遣法[[laws/港湾労働法施行令/本文/第44条.md|第四十四条]]第四項の規定により適用される労働基準法[[laws/港湾労働法施行令/本文/第118条.md|第百十八条]]、[[laws/港湾労働法施行令/本文/第119条.md|第百十九条]]及び[[laws/港湾労働法施行令/本文/第121条.md|第百二十一条]]の規定並びに労働者派遣法[[laws/港湾労働法施行令/本文/第45条.md|第四十五条]]第七項の規定により適用される労働安全衛生法（昭和四十七年法律第五十七号）第百十九条及び[[laws/港湾労働法施行令/本文/第122条.md|第百二十二条]]の規定

- 一 労働基準法（昭和二十二年法律第四十九号）第百十七条、[[laws/港湾労働法施行令/本文/第118条.md|第百十八条]]第一項（同法第六条及び[[laws/港湾労働法施行令/本文/第56条.md|第五十六条]]に係る部分に限る。）、[[laws/港湾労働法施行令/本文/第119条.md|第百十九条]]（同法第十六条、[[laws/港湾労働法施行令/本文/第17条.md|第十七条]]、[[laws/港湾労働法施行令/本文/第18条.md|第十八条]]第一項及び[[laws/港湾労働法施行令/本文/第37条.md|第三十七条]]に係る部分に限る。）及び[[laws/港湾労働法施行令/本文/第120条.md|第百二十条]]（同法第十八条第七項及び[[laws/港湾労働法施行令/本文/第23条.md|第二十三条]]から[[laws/港湾労働法施行令/本文/第27条.md|第二十七条]]までに係る部分に限る。）の規定並びにこれらの規定に係る同法第百二十一条の規定（これらの規定が労働者派遣事業の適正な運営の確保及び派遣労働者の保護等に関する法律（昭和六十年法律第八十八号。第十号において「労働者派遣法」という。）[[laws/港湾労働法施行令/本文/第44条.md|第四十四条]]（第四項を除く。）の規定により適用される場合を含む。）
- 二 職業安定法（昭和二十二年法律第百四十一号）第六十三条、[[laws/港湾労働法施行令/本文/第64条.md|第六十四条]]、[[laws/港湾労働法施行令/本文/第65条.md|第六十五条]]（第一号を除く。）及び[[laws/港湾労働法施行令/本文/第66条.md|第六十六条]]の規定並びにこれらの規定に係る同法第六十七条の規定
- 三 最低賃金法（昭和三十四年法律第百三十七号）第四十条の規定及び同条の規定に係る同法第四十二条の規定
- 四 建設労働者の雇用の改善等に関する法律（昭和五十一年法律第三十三号）[[laws/港湾労働法施行令/本文/第49条.md|第四十九条]]、[[laws/港湾労働法施行令/本文/第50条.md|第五十条]]及び[[laws/港湾労働法施行令/本文/第51条.md|第五十一条]]（第二号及び第三号を除く。）の規定並びにこれらの規定に係る同法第五十二条の規定
- 五 賃金の支払の確保等に関する法律（昭和五十一年法律第三十四号）[[laws/港湾労働法施行令/本文/第18条.md|第十八条]]の規定及び同条の規定に係る同法第二十条の規定
- 六 中小企業における労働力の確保及び良好な雇用の機会の創出のための雇用管理の改善の促進に関する法律（平成三年法律第五十七号）[[laws/港湾労働法施行令/本文/第19条.md|第十九条]]、[[laws/港湾労働法施行令/本文/第20条.md|第二十条]]及び[[laws/港湾労働法施行令/本文/第21条.md|第二十一条]]（第三号を除く。）の規定並びにこれらの規定に係る同法第二十二条の規定
- 七 育児休業、介護休業等育児又は家族介護を行う労働者の福祉に関する法律（平成三年法律第七十六号）[[laws/港湾労働法施行令/本文/第62条.md|第六十二条]]から[[laws/港湾労働法施行令/本文/第65条.md|第六十五条]]までの規定
- 八 林業労働力の確保の促進に関する法律（平成八年法律第四十五号）[[laws/港湾労働法施行令/本文/第32条.md|第三十二条]]、[[laws/港湾労働法施行令/本文/第33条.md|第三十三条]]及び[[laws/港湾労働法施行令/本文/第34条.md|第三十四条]]（第三号を除く。）の規定並びにこれらの規定に係る同法第三十五条の規定
- 九 外国人の技能実習の適正な実施及び技能実習生の保護に関する法律（平成二十八年法律第八十九号）[[laws/港湾労働法施行令/本文/第108条.md|第百八条]]、[[laws/港湾労働法施行令/本文/第109条.md|第百九条]]、[[laws/港湾労働法施行令/本文/第110条.md|第百十条]]（同法第四十四条に係る部分に限る。）、[[laws/港湾労働法施行令/本文/第111条.md|第百十一条]]（第一号を除く。）及び[[laws/港湾労働法施行令/本文/第112条.md|第百十二条]]（第一号（同法第三十五条第一項に係る部分に限る。）及び第六号から第十一号までに係る部分に限る。）の規定並びにこれらの規定に係る同法第百十三条の規定
- 十 労働者派遣法[[laws/港湾労働法施行令/本文/第44条.md|第四十四条]]第四項の規定により適用される労働基準法[[laws/港湾労働法施行令/本文/第118条.md|第百十八条]]、[[laws/港湾労働法施行令/本文/第119条.md|第百十九条]]及び[[laws/港湾労働法施行令/本文/第121条.md|第百二十一条]]の規定並びに労働者派遣法[[laws/港湾労働法施行令/本文/第45条.md|第四十五条]]第七項の規定により適用される労働安全衛生法（昭和四十七年法律第五十七号）第百十九条及び[[laws/港湾労働法施行令/本文/第122条.md|第百二十二条]]の規定
