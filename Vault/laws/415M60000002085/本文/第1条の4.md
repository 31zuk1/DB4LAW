# 第一条の四 （業務方法書に記載すべき事項）

## 
センターに係る通則法[[laws/415M60000002085/独立行政法人国民生活センターの業務運営、_law.md|第二十八条]]第二項の主務省令で定める業務方法書に記載すべき事項は、次のとおりとする。センター法[[laws/415M60000002085/本文/第10条.md|第十条]]第一号に規定する国民生活の改善に関する情報の提供に関する事項センター法[[laws/415M60000002085/本文/第10条.md|第十条]]第二号に規定する国民からの苦情、問合せ等に対する情報の提供に関する事項センター法[[laws/415M60000002085/本文/第10条.md|第十条]]第三号に規定する行政庁、団体等の依頼に応じて行う国民生活に関する情報の提供に関する事項センター法[[laws/415M60000002085/本文/第10条.md|第十条]]第四号に規定する国民生活の実情及び動向に関する総合的な調査研究に関する事項センター法[[laws/415M60000002085/本文/第10条.md|第十条]]第五号に規定する情報収集に関する事項センター法[[laws/415M60000002085/本文/第10条.md|第十条]]第六号に規定する差止請求関係業務の円滑な実施のために必要な援助に関する事項センター法[[laws/415M60000002085/本文/第10条.md|第十条]]第七号に規定する重要消費者紛争の解決に関する事項センター法[[laws/415M60000002085/本文/第10条.md|第十条]]第八号に規定する仮差押命令の立担保に関する事項センター法[[laws/415M60000002085/本文/第10条.md|第十条]]第九号に規定する附帯業務に関する事項業務委託の基準競争入札その他契約に関する基本的事項その他センターの業務の執行に関して必要な事項

- 一 センター法[[laws/415M60000002085/本文/第10条.md|第十条]]第一号に規定する国民生活の改善に関する情報の提供に関する事項
- 二 センター法[[laws/415M60000002085/本文/第10条.md|第十条]]第二号に規定する国民からの苦情、問合せ等に対する情報の提供に関する事項
- 三 センター法[[laws/415M60000002085/本文/第10条.md|第十条]]第三号に規定する行政庁、団体等の依頼に応じて行う国民生活に関する情報の提供に関する事項
- 四 センター法[[laws/415M60000002085/本文/第10条.md|第十条]]第四号に規定する国民生活の実情及び動向に関する総合的な調査研究に関する事項
- 五 センター法[[laws/415M60000002085/本文/第10条.md|第十条]]第五号に規定する情報収集に関する事項
- 五の二 センター法[[laws/415M60000002085/本文/第10条.md|第十条]]第六号に規定する差止請求関係業務の円滑な実施のために必要な援助に関する事項
- 六 センター法[[laws/415M60000002085/本文/第10条.md|第十条]]第七号に規定する重要消費者紛争の解決に関する事項
- 六の二 センター法[[laws/415M60000002085/本文/第10条.md|第十条]]第八号に規定する仮差押命令の立担保に関する事項
- 七 センター法[[laws/415M60000002085/本文/第10条.md|第十条]]第九号に規定する附帯業務に関する事項
- 八 業務委託の基準
- 九 競争入札その他契約に関する基本的事項
- 十 その他センターの業務の執行に関して必要な事項
