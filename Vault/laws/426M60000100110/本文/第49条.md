# 第四十九条 （審査等業務の適切な実施のために必要な基準）

## 
法[[laws/426M60000100110/本文/第26条.md|第二十六条]]第四項第五号の厚生労働省令で定める基準は、次のとおりとする。再生医療等委員会に、委員長を置くこと。審査等業務が適正かつ公正に行えるよう、その活動の自由及び独立が保障されていること。審査等業務に関する規程が定められていること。審査等業務の透明性を確保するため、審査等業務に関する規程、委員名簿その他再生医療等委員会の認定に関する事項及び審査等業務の過程に関する記録に関する事項について、厚生労働省が整備するデータベースに記録することにより公表すること。ただし、[[laws/426M60000100110/本文/第43条.md|第四十三条]]第一項、[[laws/426M60000100110/本文/第51条.md|第五十一条]]若しくは[[laws/426M60000100110/本文/第58条.md|第五十八条]]第一項に規定する申請書又は[[laws/426M60000100110/本文/第53条.md|第五十三条]]若しくは[[laws/426M60000100110/本文/第55条.md|第五十五条]]第一項に規定する届書に記載された事項及び当該申請書又は当該届書に添付された書類に記載された事項については、当該事項を公表したものとみなす。審査等業務を継続的に実施できる体制を有すること。苦情及び問合せを受け付けるための窓口を設置していること。

- 一 再生医療等委員会に、委員長を置くこと。
- 二 審査等業務が適正かつ公正に行えるよう、その活動の自由及び独立が保障されていること。
- 三 審査等業務に関する規程が定められていること。
- 四 審査等業務の透明性を確保するため、審査等業務に関する規程、委員名簿その他再生医療等委員会の認定に関する事項及び審査等業務の過程に関する記録に関する事項について、厚生労働省が整備するデータベースに記録することにより公表すること。ただし、[[laws/426M60000100110/本文/第43条.md|第四十三条]]第一項、[[laws/426M60000100110/本文/第51条.md|第五十一条]]若しくは[[laws/426M60000100110/本文/第58条.md|第五十八条]]第一項に規定する申請書又は[[laws/426M60000100110/本文/第53条.md|第五十三条]]若しくは[[laws/426M60000100110/本文/第55条.md|第五十五条]]第一項に規定する届書に記載された事項及び当該申請書又は当該届書に添付された書類に記載された事項については、当該事項を公表したものとみなす。
- 五 審査等業務を継続的に実施できる体制を有すること。
- 六 苦情及び問合せを受け付けるための窓口を設置していること。
