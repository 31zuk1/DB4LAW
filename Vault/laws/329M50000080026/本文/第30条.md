# 第三十条 

## 
[[laws/教育職員免許法施行規則/本文/第27条.md|第二十七条]]の教員養成機関の指定を受けようとするときは、その設置者は、次の事項を記載した申請書を、これに指導と承認を受けようとする大学の意見書を添え、文部科学大臣に提出しなければならない。設置者の名称及び住所目的名称及び位置開設年月日教育課程生徒定員長の氏名及び履歴教員の氏名、職名、履歴、担任科目及び教員種別施設、設備、実習施設等に関する事項収支予算学則法人の寄附行為その他設置者において必要と認める事項

- 一 設置者の名称及び住所
- 二 目的
- 三 名称及び位置
- 四 開設年月日
- 五 教育課程
- 六 生徒定員
- 七 長の氏名及び履歴
- 八 教員の氏名、職名、履歴、担任科目及び教員種別
- 九 施設、設備、実習施設等に関する事項
- 十 収支予算
- 十一 学則
- 十二 法人の寄附行為
- 十三 その他設置者において必要と認める事項
