# 第百七十三条 

## 
次の各号のいずれかに該当する者は、五十万円以下の罰金に処する。[[laws/計量法/本文/第8条.md|第八条]]第一項若しくは第二項、[[laws/計量法/本文/第9条.md|第九条]]第一項、[[laws/計量法/本文/第18条.md|第十八条]]、[[laws/計量法/本文/第19条.md|第十九条]]第一項若しくは第二項、[[laws/計量法/本文/第49条.md|第四十九条]]第二項、[[laws/計量法/本文/第63条.md|第六十三条]]第二項、[[laws/計量法/本文/第85条.md|第八十五条]]又は[[laws/計量法/本文/第124条.md|第百二十四条]]の規定に違反した者[[laws/計量法/本文/第15条.md|第十五条]]第三項、[[laws/計量法/本文/第56条.md|第五十六条]]、[[laws/計量法/本文/第64条.md|第六十四条]]、[[laws/計量法/本文/第86条.md|第八十六条]]、[[laws/計量法/本文/第98条.md|第九十八条]]、[[laws/計量法/本文/第111条.md|第百十一条]]、[[laws/計量法/本文/第123条.md|第百二十三条]]又は[[laws/計量法/本文/第131条.md|第百三十一条]]の規定による命令に違反した者[[laws/計量法/本文/第25条.md|第二十五条]]第三項（[[laws/計量法/本文/第120条.md|第百二十条]]第二項において準用する場合を含む。）の規定に違反して、[[laws/計量法/本文/第23条.md|第二十三条]]第一項各号に適合する旨を証明書に記載した計量士[[laws/計量法/本文/第50条.md|第五十条]]第三項又は[[laws/計量法/本文/第54条.md|第五十四条]]第三項の規定に違反して表示を付した者[[laws/計量法/本文/第54条.md|第五十四条]]第一項の規定に違反して表示を付さなかった者[[laws/計量法/本文/第55条.md|第五十五条]]の規定に違反して特定計量器を販売し、又は販売の目的で陳列した者[[laws/計量法/本文/第95条.md|第九十五条]]第二項の規定に違反して検査を行わず、検査記録を作成せず、虚偽の検査記録を作成し、又は検査記録を保存しなかった者[[laws/計量法/本文/第110条の2.md|第百十条の二]]第二項、[[laws/計量法/本文/第121条の3.md|第百二十一条の三]]第二項、[[laws/計量法/本文/第136条.md|第百三十六条]]第二項又は[[laws/計量法/本文/第144条.md|第百四十四条]]第三項の規定に違反して標章を付した者[[laws/計量法/本文/第129条.md|第百二十九条]]の規定に違反して検査の結果を記載せず、虚偽の記載をし、又は帳簿を保存しなかった者[[laws/計量法/本文/第130条.md|第百三十条]]第二項の規定に違反して標識を掲げた者

- 一 [[laws/計量法/本文/第8条.md|第八条]]第一項若しくは第二項、[[laws/計量法/本文/第9条.md|第九条]]第一項、[[laws/計量法/本文/第18条.md|第十八条]]、[[laws/計量法/本文/第19条.md|第十九条]]第一項若しくは第二項、[[laws/計量法/本文/第49条.md|第四十九条]]第二項、[[laws/計量法/本文/第63条.md|第六十三条]]第二項、[[laws/計量法/本文/第85条.md|第八十五条]]又は[[laws/計量法/本文/第124条.md|第百二十四条]]の規定に違反した者
- 二 [[laws/計量法/本文/第15条.md|第十五条]]第三項、[[laws/計量法/本文/第56条.md|第五十六条]]、[[laws/計量法/本文/第64条.md|第六十四条]]、[[laws/計量法/本文/第86条.md|第八十六条]]、[[laws/計量法/本文/第98条.md|第九十八条]]、[[laws/計量法/本文/第111条.md|第百十一条]]、[[laws/計量法/本文/第123条.md|第百二十三条]]又は[[laws/計量法/本文/第131条.md|第百三十一条]]の規定による命令に違反した者
- 三 [[laws/計量法/本文/第25条.md|第二十五条]]第三項（[[laws/計量法/本文/第120条.md|第百二十条]]第二項において準用する場合を含む。）の規定に違反して、[[laws/計量法/本文/第23条.md|第二十三条]]第一項各号に適合する旨を証明書に記載した計量士
- 四 [[laws/計量法/本文/第50条.md|第五十条]]第三項又は[[laws/計量法/本文/第54条.md|第五十四条]]第三項の規定に違反して表示を付した者
- 五 [[laws/計量法/本文/第54条.md|第五十四条]]第一項の規定に違反して表示を付さなかった者
- 六 [[laws/計量法/本文/第55条.md|第五十五条]]の規定に違反して特定計量器を販売し、又は販売の目的で陳列した者
- 七 [[laws/計量法/本文/第95条.md|第九十五条]]第二項の規定に違反して検査を行わず、検査記録を作成せず、虚偽の検査記録を作成し、又は検査記録を保存しなかった者
- 八 [[laws/計量法/本文/第110条の2.md|第百十条の二]]第二項、[[laws/計量法/本文/第121条の3.md|第百二十一条の三]]第二項、[[laws/計量法/本文/第136条.md|第百三十六条]]第二項又は[[laws/計量法/本文/第144条.md|第百四十四条]]第三項の規定に違反して標章を付した者
- 九 [[laws/計量法/本文/第129条.md|第百二十九条]]の規定に違反して検査の結果を記載せず、虚偽の記載をし、又は帳簿を保存しなかった者
- 十 [[laws/計量法/本文/第130条.md|第百三十条]]第二項の規定に違反して標識を掲げた者
