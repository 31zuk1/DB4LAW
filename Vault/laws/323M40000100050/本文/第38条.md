# 第三十八条 （医療法人台帳の記載事項）

## 
令[[laws/323M40000100050/医療法施行規則_law.md|第五条の十一]]第一項の医療法人台帳に記載しなければならない事項は、次のとおりとする。名称事務所の所在地理事長の氏名開設する病院、診療所、介護老人保健施設又は介護医療院の名称及び所在地法[[laws/323M40000100050/本文/第42条.md|第四十二条]]各号に掲げる業務を行う場合はその業務設立認可年月日及び設立登記年月日設立認可当時の資産役員に関する事項法[[laws/323M40000100050/本文/第42条の2.md|第四十二条の二]]第一項の収益業務を行う場合はその業務その他必要な事項

- 一 名称
- 二 事務所の所在地
- 三 理事長の氏名
- 四 開設する病院、診療所、介護老人保健施設又は介護医療院の名称及び所在地
- 五 法[[laws/323M40000100050/本文/第42条.md|第四十二条]]各号に掲げる業務を行う場合はその業務
- 六 設立認可年月日及び設立登記年月日
- 七 設立認可当時の資産
- 八 役員に関する事項
- 九 法[[laws/323M40000100050/本文/第42条の2.md|第四十二条の二]]第一項の収益業務を行う場合はその業務
- 十 その他必要な事項
## ２
前項各号の記載事項に変更を生じたときは、都道府県知事は、遅滞なく訂正しなければならない。
